#### 1. [2608.28514](https://arxiv.org/abs/2608.28514) — Fast and efficient nested sampling with BEST
- **作者**: Andreas Nygaard
- 相关性 5/10 · novelty: `new_method`
- **摘要**: 本文提出一种新的嵌套采样实现BEST，完全基于TensorFlow编写，利用XLA编译在CPU和GPU上高效运行。核心创新在于通过聚类和切片采样同时更新多个活点，打破传统嵌套采样的严格顺序结构，从而利用现代向量化似然和模拟器。为纠正批处理引入的偏差，作者引入排序和基于历史的修正。在Gaussian、Rosenbrock和多峰似然上测试，并与JAXNS和UltraNest比较，表明在m/N_live≲0.1的适度批大小下可保持准确的证据估计。最后，在27维宇宙学似然模拟器上展示，批处理活点更新能大幅减少墙钟时间，且结果与顺序采样在报告不确定性内一致。该工作为快速向量化似然和模拟器推理提供了高效的嵌套采样工具，对您作为统计计算方向的研究者具有直接参考价值。
- **关键技术**: `nested sampling`, `batch live-point updates`, `XLA compilation`, `slice sampling`, `clustering`, `history-based bias correction`
- **为什么对您有用**: 本文属于统计计算方向，直接对应您的primary interest中的'statistical computing (numerical methods, algorithm)'。您对软件开发和高效算法有浓厚兴趣，且熟悉TensorFlow等工具，因此本文的批处理策略和偏差修正方法可立即用于您自己的贝叶斯计算项目（立即可做）。

### 天体统计  *(astrostats, 4 篇)*

#### 1. [2608.27786](https://arxiv.org/abs/2608.27786) — JUG: JAX-based Unified pulsar timinG
- **作者**: Matthew T. Miles, Stephen R. Taylor, Matthew Bailes, Aurelien Chalumeau, H. Thankful Cromartie, Kyle A. Gersbach et al.
- 相关性 5/10 · novelty: `application`
- **摘要**: 本文介绍 JUG，一个基于 JAX 的脉冲星计时软件包，完全独立实现从数据加载、时钟校正到计时模型拟合的完整流水线。JUG 支持 Python API 和交互式 GUI，可在 CPU 和 GPU 上运行，速度比现有软件 PINT 快 50 倍以上，与 Tempo2 相当，能处理数百万个到达时间，精度达到皮秒级。软件内置了复杂随机噪声建模、连续引力波确定性信号拟合以及贝叶斯噪声分析功能，桥接了频率学派计时与贝叶斯噪声分析。验证实验表明 JUG 能可靠恢复已知的计时模型和噪声参数。对您而言，这是一篇优秀的入门级天文统计软件文章，清晰展示了脉冲星计时阵列的数据结构、噪声模型和计算挑战，适合作为进入天文统计方向的起点。
- **关键技术**: `JAX-based automatic differentiation`, `GPU-accelerated pulsar timing`, `stochastic noise modeling`, `Bayesian noise analysis`, `continuous gravitational wave detection`
- **为什么对您有用**: 本文属于 astrostatistics 的 gateway reading，清晰阐述了脉冲星计时阵列的数据结构（百万级到达时间）、噪声模型（红噪声、白噪声）和计算瓶颈（大规模似然优化），适合作为统计学家进入该领域的入门读物。您的武器库中 'software development' 和 'high-dimensional asymptotics' 足以理解其计算加速原理和噪声参数估计的统计框架，但脉冲星计时特有的物理模型（如色散量、自转频率导数）需要额外学习。值得花时间读全文以了解天文统计中的真实数据挑战。

#### 2. [2608.27775](https://arxiv.org/abs/2608.27775) — PolPy: A universal tool for X-ray/gamma-ray polarimetry using common data format standards
- **作者**: Sujay Mate, Hancheng Li, Utkarsh Pathak, Yashowardhan Rai, Nicolas De Angelis, Varun Bhalerao et al.
- 相关性 5/10 · novelty: `application`
- **摘要**: 本文针对高能天体物理（X射线/伽马射线）偏振测量领域缺乏标准化分析框架的问题，开发了通用工具 PolPy。该工具作为 Multi-Mission Maximum Likelihood (3ML) 框架的插件，引入了基于 IAU 约定的标准化数据与响应格式以及公共参考系。核心算法采用基于似然的模板匹配方法进行偏振参数估计。作者通过模拟伽马射线暴（GRB）注入两个不同任务质量模型（POLAR 和 Daksha）的数据，验证了 PolPy 能无系统偏差地恢复注入的偏振角和偏振度。同时展示了跨探测器/仪器的联合拟合能显著改善参数约束。本文是典型的软件工具论文，方法学 novelty 有限，但为多任务联合偏振分析提供了可复用的基础设施。对您而言，这是一篇 astrostatistics 方向的入门级阅读材料，武器库中的软件开发和统计计算经验足以理解其框架设计，但该领域的具体物理模型（如偏振响应矩阵）需要额外学习。
- **关键技术**: `Maximum Likelihood estimation`, `template matching`, `joint fitting across instruments`, `standardized data formats (IAU conventions)`, `plugin architecture (3ML framework)`
- **为什么对您有用**: 本文属于 astrostatistics 方向的 gateway reading。它清晰阐述了高能偏振测量的数据结构和分析流程（数据格式、响应矩阵、似然函数），对统计学家友好。武器库中的软件开发和统计计算经验足以支撑理解其框架，但核心偏振物理（如调制因子、响应矩阵建模）不在当前武器库中，属于暂不可做方向。不过作为入门读物，值得花时间读全文以了解该领域的数据分析挑战。

#### 3. [2608.28322](https://arxiv.org/abs/2608.28322) — JWST telemetry combined with active coronagraphy: raw contrast predictions for exoplanet imaging with the Habitable Worlds Observatory
- **作者**: Raphaël Pourcelot, Laurent A. Pueyo, Emiel H. Por, Marshall D. Perrin, Iva Laginja, Bryony Nickson et al.
- 相关性 4/10 · novelty: `application`
- **摘要**: 本文利用 JWST 在轨遥测数据（主镜分段镜面位置与波前误差），结合 Roman 望远镜日冕仪（Apodized Pupil Lyot Coronagraph）和主动变形镜波前控制模型，模拟 JWST 级望远镜在类日恒星周围直接成像类地行星所需的原始对比度（raw contrast）水平。目标对比度为 10^{-10}，这是 Habitable Worlds Observatory (HWO) 的关键技术指标。模拟表明，对于亮星（星等 < 4），在 100 Hz 快速控制频率下可接近 10^{-10} 对比度；但对于暗星，JWST 的振幅误差（amplitude errors）无法被充分校正。若波前稳定性提升一个数量级（且无反应轮振动），则可在 1-100 Hz 全频率范围内对星等 ≤ 11 的恒星实现 10^{-10} 对比度。文章建立了从 JWST 实测热机械稳定性到 HWO 需求的定量桥梁，指出波前稳定性是 HWO 实现类地行星成像的关键技术缺口。对您而言，这是一篇典型的 astrostatistics 入门级读物：它清晰展示了天文仪器建模中数据（遥测波前误差）与模型（控制算法、对比度预测）的交互，但方法学上不涉及您熟悉的因果推断或高维统计工具，适合作为跨学科背景阅读。
- **关键技术**: `wavefront control`, `coronagraphy`, `raw contrast simulation`, `active deformable mirror`, `segmented telescope telemetry`
- **为什么对您有用**: 本文属于 astrostatistics 的 gateway reading：它用 JWST 真实遥测数据驱动模拟，清晰展示了天文仪器建模中数据（波前误差时序）与模型（控制算法、对比度预测）的交互，适合作为统计学家进入天文方向的入门读物。您的武器库（非参数统计、高维渐近）不直接适用于本文的物理光学模型，但本文对数据结构和噪声的清晰阐述（第 (d) 条）使其值得花时间阅读全文以拓宽视野。

#### 1. [2608.28115](https://arxiv.org/abs/2608.28115) — Causal Non-causal State Space Models and the Modelling of Financial Bubbles
- **作者**: Frederik Bjerg Krabbe
- 相关性 4/10 · novelty: `application`
- **摘要**: 本文研究因果-非因果状态空间模型（causal non-causal state space models），用于建模金融泡沫中局部指数增长后急剧下降的时间序列（如股票价格）。作者首先证明Gourieroux和Zakoian (2017)提出的因果-非因果卷积自回归模型与理性预期股价模型一致，为模型提供了经济学理论基础。核心方法贡献包括：在因果-非因果状态空间模型框架下讨论状态和参数推断问题，并给出卷积自回归模型的新理论结果。实证部分以稳定非因果自回归模型为基准，用因果-非因果卷积自回归模型对互联网泡沫规模进行实时和后验估计。对您而言，本文是经济理论方向的应用型工作，展示了非因果时间序列模型在金融泡沫检测中的实际价值，可作为了解该领域数据结构和建模思路的入门读物。
- **关键技术**: `causal non-causal state space models`, `convolution autoregressive model`, `rational expectations stock price model`, `state and parameter inference`, `financial bubble estimation`
- **为什么对您有用**: 本文属于经济理论（金融时间序列建模）的应用工作，作为gateway reading，它清晰阐述了非因果模型在泡沫检测中的动机和实证流程，对统计学家友好。武器库中'非参数统计'和'高维渐近'的功底可帮助理解其推断框架，但核心机器（非因果时间序列的似然推断）不在当前武器库中，属于暂不可做方向。不过本文可作为了解该领域数据结构和建模思路的入门读物，值得花时间读全文。
