#### 1. [2606.17486](https://arxiv.org/abs/2606.17486) — Improving Linear Regression on Small Datasets via Gaussian Process and Extreme Value Theory-Based Data Augmentation
- **作者**: Ibrahim Salay, Jagath Senarathne
- **分类**: stat.ME · stat.CO
- 相关性 4/10 · novelty: `new_method`
- **摘要**: 该论文针对小样本（n=10–20）线性回归中正态性、同方差、残差独立等经典假设易被违反的问题，提出一种结合高斯过程（GP）与极值理论（EVT）的数据增强方法 GP-MEVT。核心机制是：用 GP 拟合观测数据并外推预测变量范围之外的新点，同时基于残差变异性和 EVT 控制生成的预测变量的极值行为，从而在保持线性结构的前提下扩展预测空间并引入可控变异。通过模拟（方差 σ=2/5/8）和真实数据实验，将 GP-MEVT 与标准 Bootstrap 及加噪 Bootstrap 对比，发现 GP-MEVT 在假设满足率（真实数据达 67.1% vs 对照组的 17.3%/21.2%）、参数估计精度（截距/斜率更接近真值）和 RMSE 拟合性能上均有显著优势。该方法本质上是为小样本回归量身定做的一种非参数预处理策略，其算法设计思路对统计计算中“数据饥饿”场景的推断工具开发有参考价值。
- **关键技术**: `Gaussian Process regression`, `Extreme Value Theory`, `Data Augmentation`, `Small-sample linear regression`, `Bootstrap comparison`
- **为什么对您有用**: 该文直接属于统计计算中的算法设计（数据增强方法），与您的 primary interest 中“statistical computing (numerical methods, algorithm)”对接。您熟悉的非参数统计和软件工程技能可以快速理解 GP 拟合和残差变异性建模，但极值理论的细节可能需要查阅（若想复现或扩展该方法，属于“中期可做”：需在 moderately_familiar 的“M-estimation 理论”基础上补充 EVT 背景）。整体而言，本文提供了一个小样本线性回归的实用算法案例，值得作为 gateway reading 评估其理论严密度和可推广性。

#### 1. [2606.17717](https://arxiv.org/abs/2606.17717) — Double zero-inflated spatio-temporal modeling of daily precipitation under detection thresholds
- **作者**: Juan Marcen-Gutierrez, Jorge Castillo-Mateo, Alan E. Gelfand, Jes\'us As\'in, Ana C. Cebri\'an
- **分类**: stat.ME · stat.AP
- 相关性 5/10 · novelty: `application`
- **摘要**: 本文针对日降水数据中两类零值（无降水与低于检测限）及正降水量检测阈值问题，提出多水平时空模型。模型通过probit回归刻画零概率，Gamma回归建模潜在正降水量，并引入阈值诱导的删失机制；空间依赖性由高斯过程描述，贝叶斯框架实现完整的不确定性量化。将模型应用于西班牙埃布罗河流域70个站点15年春季日降水数据，发现检测阈值显著影响观测降水发生，尤其湿润地区，对总积累量影响较小但对高分位数有实质影响。该建模策略为处理含检测限的环境数据提供了可借鉴的框架，对流行病学中暴露变量（如污染物浓度）的测量误差问题具有方法参考价值。
- **关键技术**: `two-type zero-inflated model`, `probit regression`, `Gamma regression`, `threshold-induced censoring`, `Gaussian processes`, `Bayesian inference`
- **为什么对您有用**: 本文属于环境时空统计应用，与您的secondary interest 流行病学中暴露数据建模直接相关——检测限导致的零膨胀是常见测量误差来源。您武器库中 very_familiar 的 nonparametric statistics（高斯过程）可用于理解其空间依赖建模的局限与扩展，而 moderately_familiar 的 identification theory in causal inference 可帮助评估检测限下暴露-结果关系的可识别性。作为 gateway reading 方向，本文是否值得读：是，方法exposition清晰，可作为进入含检测限零膨胀效应建模的入门文献，且武器库足以支撑您理解并潜在改进其模型。
