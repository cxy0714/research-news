- **为什么对您有用**: 本文属于极值统计与贝叶斯回归的应用，与您的主要兴趣（因果推断、高维、半参数等）无直接交集，但作为 astrostatistics 之外的跨领域应用，其协变量区域推断思路可能对您处理高维协变量与极端事件关系有启发。作为 gateway reading，本文对统计学家友好，数据与模型描述清晰，但方法学 novelty 一般，不值得深读。

#### 3. [2609.39519](https://arxiv.org/abs/2609.39519) — B-GRASP: A Bayesian Framework for Inferring Graph Weights from SPDE-Inspired Dynamics
- **作者**: Christina Schenk, Babak Maboudi Afkham

- **摘要**: 本文提出 B-GRASP，一个在随机图动力学系统中推断未知边权重的贝叶斯框架。未知边权重参数化图微分算子，直接控制图过程的演化；受 PDE/SPDE 与其图对应物之间联系的启发，作者构建了包含扩散、反应动力学和随机强迫的随机图模型。该分层公式联合表示图结构和随机强迫的不确定性：潜在图变量决定正边权重和相应的图拉普拉斯算子，潜在布朗变量表示随机强迫。给定这些变量，图动力学定义确定性前向映射，由此构造似然和后验；作者使用 MAP 估计和 No-U-Turn Sampler 表征后验，实现点估计和不确定性量化。数值实验涵盖一维逆热传导问题、平稳和非平稳图反应-扩散系统以及美国州级 COVID-19 数据，结果表明后验不确定性提供了点估计无法捕捉的信息，尤其对弱可识别或高传导边。

#### 4. [2609.40242](https://arxiv.org/abs/2609.40242) — Riemannian Regression
- **作者**: Oldemar Rodríguez
- **机构**: Universidad de Costa Rica
- 相关性 5/10 · novelty: `minor`
- **摘要**: 本文提出 Riemannian Regression，将经典线性回归推广到具有局部距离结构的数据上。核心思想是用数据依赖的相似度矩阵 S 构造局部度量，定义非对称的相减运算 x_i ⊖ x_j = ρ_{ij}(x_i - x_j)，其中 ρ_{ij}=1-S_{ij}。通过选取离散 Fréchet 均值作为 Riemannian 中心，对中心化变量做加权最小二乘，得到形如 β̂_R = (X' W² X)^{-1} X' W² y 的估计量。文中给出三种构造局部度量的方式：基于 UMAP 的模糊相似度、基于 ISOMAP 的归一化测地距离、基于 DBSCAN 的密度相似度。模拟和 Abalone 数据表明该方法能降低局部异常点的影响并适应不同局部密度区域。该方法本质上是加权最小二乘的变体，缺乏严格的理论性质分析（如一致性、收敛速率），且与真正的流形回归（如内在回归）不同。
- **关键技术**: `weighted least squares`, `Fréchet mean`, `UMAP similarity`, `ISOMAP geodesic distance`, `DBSCAN density similarity`
- **为什么对您有用**: 本文属于统计计算与算法方向，与您的 statistical computing 兴趣相关，但方法学贡献有限，主要是将现有降维/聚类工具的输出作为权重引入回归。作为 gateway reading，它展示了如何将流形几何信息融入经典回归，但理论深度不足。您可以用 very_familiar 的软件开发和数值方法技能快速实现并验证其性能，但该方向并非您的主要兴趣，且缺乏可迁移的深刻理论。

#### 5. [2609.38759](https://arxiv.org/abs/2609.38759) — BOP2-ENR: a Bayesian optimal phase II design for adaptive enrichment with family-wise error rate control and a bound on joint-claim power
- **作者**: Kentaro Takeda, Belay B. Yimer, Masahiro Kojima
- **机构**: Astellas Pharma (United States) · Astellas Pharma (Netherlands) · Chuo University
- 相关性 4/10 · novelty: `new_method`
- **摘要**: 本文提出 BOP2-ENR，一种用于适应性富集设计的贝叶斯最优 II 期临床试验设计，扩展了 BOP2 框架以处理生物标志物指导的富集和多重性控制。设计分别监测生物标志物阴性（NG）和阳性（PG）队列，允许中期富集至 PG，并校准合并与 PG 限制的声明。在预设的单调活性参数空间上定义了强族系错误率（FWER）控制，并证明在混合配置下，虚假联合声明的概率受 NG 通过无效性监测的概率约束，该精确单队列界不依赖最终疗效阈值，同时给出联合声明功效的上界。对于疗效-毒性监测，亚组无效性由联合零假设定义，安全性在各亚组内分别建立。在多种场景和二元、共同主要及疗效-毒性终点下，所选设计均满足预设的精确界和蒙特卡洛验证标准；敏感性分析显示误差控制量的点估计低于名义水平，但功效对关联敏感。该设计将 BOP2 框架扩展到适应性富集，并阐明 NG 无效性门控主导混合配置下的强误差控制和联合声明的可达功效。
- **关键技术**: `Bayesian optimal phase II design`, `adaptive enrichment`, `family-wise error rate control`, `joint-claim power bound`, `Monte Carlo calibration`
- **为什么对您有用**: 本文属于临床试验设计领域，与您的主要兴趣（因果推断、高维统计等）无直接交集，但其中对多重性控制和误差率界的精确处理可能对您在高维假设检验中的 FWER 控制问题有启发。作为方法学论文，其 novelty 在于将 BOP2 扩展到适应性富集并给出理论界，但整体属于应用导向的设计方法，方法学深度有限。
