#### 1. [2606.17424](https://arxiv.org/abs/2606.17424) — The dangers of using three-number summaries to estimate unknown standard deviations: sensitivity analyses and some possible improvements incorporating shape
- **作者**: Udara Kumaranathunga, Alysha De Livera, Luke A. Prendergast
- **分类**: stat.ME
- 相关性 4/10 · novelty: `new_method`
- **摘要**: 在 meta-analysis 设定下，部分研究仅报告 three-number summaries（最小值、最大值、中位数），目标是据此估计未知均值与标准差（SD）。本文指出三个数字的摘要信息量不足以可靠估计 SD，极端偏态下估计偏差可严重扭曲后续推断。作者提出一套 sensitivity analysis 框架，帮助研究者识别潜在偏倚来源或增强结果可信度。进一步，通过引入关于数据分布形状的额外先验信息，提出基于 scaled Beta 分布的新 SD 估计量。模拟与真实数据展示了该估计量在不同形状设定下的优劣，并附带 Web 应用供实操。对您而言，本文展示了在信息受限（非完整样本）下做推断的风险与补救，但方法学核心是经验建模而非 semiparametric efficiency 或 minimax 理论。
- **关键技术**: `three-number summary conversion`, `scaled Beta distribution estimation`, `sensitivity analysis for quantile-based SD`, `meta-analysis data extraction`
- **为什么对您有用**: 本文属于 meta-analysis 中的经验性数据转换问题，与您 primary interests（semiparametric efficiency、minimax bounds、causal identification）无直接交集。若从 identification 视角看，三个数字摘要确实无法 nonparametrically identify SD，本文的 scaled Beta 假设本质上是一个 parametric identification 补救，但未触及您熟悉的 semiparametric bound 或效率理论。武器库中 very_familiar 的 nonparametric statistics 与 minimax bounds 理论可以用来严格量化'三个数字摘要估计 SD 的 minimax risk 下界'，但这属于**中期可做**——需先在 moderately_familiar 的 semiparametric theory 上构建一个部分识别（partial identification）框架来刻画 SD 的 bounds，而非点估计。
