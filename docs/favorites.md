# 收藏

> 登录账户后，你在 **每日 arXiv**、**期刊某期**、**精读报告** 页面点论文旁边的
> <b>☆ 收藏</b> 按钮，论文就会自动收进这里——不用再手动维护。
>
> - **总收藏**（默认）：按论文类别分大类，类内按日期排。
> - **按周**：按 ISO 周号分组，周内再按类别 / 日期排。
> - 每篇都能直接在网页上写 **评论 / 笔记**，多设备同步。
>
> 没看到收藏按钮？点右下角 **👤 登录**（用一个带 `gist` 权限的 GitHub Token），
> 已读状态与收藏会存进你 GitHub 账号下的一个私密 Gist。
>
> 未登录的访客看到的是 **公开收藏快照**（每日自动刷新，带论文摘要与你的评论）。

## ✍️ 手动录入论文（申请精读）

> 想读某篇没出现在每日 / 期刊列表里的论文？把 **arXiv 链接 / 编号** 粘进来即可（手机直接敲编号也行，可多条、每行一篇）。论文会 **默认加入收藏**，并进入 **精读队列**（与收藏一起存在你的私密 Gist 里，多设备同步）。**下一次定时任务**会自动抓取、打分、下载 PDF 并 **精读**，结果放进当天日报的「✍️ 手动录入的论文」章节，也会进 [精读存档](all_deep_reads.md)。
>
> **非 arXiv 论文也行**：直接粘 **标题 / 整条引用 / DOI**。定时任务会先按标题去 arXiv **找预印本**——找到就照常精读（很多期刊论文其实有预印本），找不到就**只当书签收藏**（留题目 + DOI/链接）。每条的状态（排队中 / 已精读 / 未找到预印本）会显示在下面。
