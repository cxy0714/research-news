# 收藏

> 登录账户后，你在 **每日 arXiv**、**期刊某期**、**精读报告** 页面点论文旁边的
> <b>☆ 收藏</b> 按钮，论文就会自动收进这里——不用再手动维护。
>
> - **总收藏**（默认）：按论文类别分大类，类内按日期排。
> - **按周**：按 ISO 周号分组，周内再按类别 / 日期排。
> - 每篇都能直接在网页上写 **评论 / 笔记**，多设备同步。
>
> 没看到收藏按钮？点右下角 **👤 登录**（用一个带 `gist` 权限的 GitHub Token），
> 已读状态与收藏会存进你 GitHub 账号下的一个私密 Gist。
>
> 未登录的访客看到的是 **公开收藏快照**（每日自动刷新，带论文摘要与你的评论）。
