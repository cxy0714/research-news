## 端到端科研 Agent

### 1. DiscoveryAgent: A Framework for Scientist-centric Agentic AI
- **链接**: [论文页](https://arxiv.org/abs/2611.21950) · [PDF](https://arxiv.org/pdf/2611.21950) · [arXiv](https://arxiv.org/abs/2611.21950)
- **作者**: Owen Queen, Ioana Ciuca, Emma Dann, Jean Somalwar, Carine You, Steven Dillmann, Viraj Manwadkar, Evan Gorrell, Harrison G Zhang, Jonathan K Pritchard, Risa H Wechsler, James Zou
- **来源**: arXiv · cs.AI
- 相关性 8/10 · 自动化程度 `semi_autonomous`
- **自动化的环节**: 自动化了实验执行、结果分析与审计追溯，但假设选择与方向调整仍由科学家主导。
- **摘要**: DiscoveryAgent 提出一个以科学家为中心的科研 agent 框架，在自主调查与科学家假设引导之间取得平衡。系统由研究 agent 执行多轮实验，科学家可在轮次间选择、细化或替换假设，审计 agent 通过检查点记录追溯声明、复现分析并辅助决策。在变星分类任务中达到最佳基线性能，在蛋白质变异效应预测中经科学家引导后仅逊于 ProteinGym 106 个基线中的一个。审计 agent 自主识别错误的比率高于先前 AI 科学家 agent，与科学家协作时发现的错误量是纯人工评审的 14 倍。三个领域专家主导的案例研究覆盖物理、社会与生命科学，分别实现红移估计 AUROC 0.971、揭示佛罗里达房主保险保费 83% 上涨、识别 CD4+ T 细胞中继基因。
- **为什么值得看**: 该工作提供了科学家在环的端到端科研自动化证据，并量化了审计 agent 对错误发现的增益，是评估人机协作与可追溯性在 auto-research 中作用的重要参考。
- **关键技术**: `checkpointing`, `audit agents`, `scientist-in-the-loop`, `hypothesis steering`, `multi-agent pipeline`

### 2. The Between-Round Decision in Autonomous Research: An LLM Controller That Reads the Whole Trajectory
- **链接**: [论文页](https://arxiv.org/abs/2611.22661) · [PDF](https://arxiv.org/pdf/2611.22661) · [arXiv](https://arxiv.org/abs/2611.22661)
- **作者**: Caoxin Wang, Shengkai Gan, Xiang Hu, Lili Pan
- **来源**: arXiv · cs.AI
- 相关性 8/10 · 自动化程度 `semi_autonomous`
- **自动化的环节**: 自动化了实验后的决策环节（改进 vs 新方向、选择解、设定目标），但实验执行和结果分析仍需外部系统或人工介入。
- **摘要**: 本文提出 BRED，一个基于 LLM 的控制器，专门负责自主科研中的“轮间决策”：每轮实验后，根据累积证据决定是改进当前最优解还是开启新方向、基于哪个解继续、设定什么目标。系统维护一个“冠军”解（最佳已验证解）和过往轮次日志，每轮仅做一次决策，不依赖搜索树或规则等外部结构。在三个研究智能体基准任务上，BRED 在 ETTh1 上 MAE 降至 0.4172（提升 4.80%），SST-2 准确率 95.07%（提升 3.44 点），CIFAR-100 准确率 84.63%（提升 3.43 点），均超过已发表结果。消融实验显示，若不读取累积证据，性能下降（ETTh1 MAE 0.4299，CIFAR-100 83.71%），证明读取历史的重要性。在新任务（语音抑郁检测，无泄漏协议）上，宏 F1 达 0.6164，比基线高 5.5 点，比最强已发表系统高 4.0 点。代码已开源。
- **为什么值得看**: 该论文聚焦于自主科研中一个关键但常被忽视的环节——轮间决策，并提供了消融证据表明读取完整轨迹对性能的必要性，为自动化程度提供了定量分析。
- **关键技术**: `LLM controller`, `between-round decision`, `champion solution`, `trajectory reading`, `ablation study`

### 3. Inventa: Decentralized Self-Improving Agents for Autonomous Scientific Discovery
- **链接**: [论文页](https://arxiv.org/abs/2611.21847) · [PDF](https://arxiv.org/pdf/2611.21847) · [arXiv](https://arxiv.org/abs/2611.21847)
- **作者**: Prithwish Jana, Nikos Kanakaris, Purak Jain, Anoop Deoras, Sahika Genc
- **来源**: arXiv · cs.LG
- 相关性 7/10 · 自动化程度 `semi_autonomous`
- **自动化的环节**: 自动化了想法生成、策略调整和验证记录环节，但人仍负责定义基准任务和最终评估研究质量。
- **摘要**: Inventa 提出一个去中心化的自改进科研 agent 框架，旨在解决多 agent 科研系统中想法趋同、共享记忆传播未验证主张、搜索策略停滞等问题。系统由多个自治研究单元组成，每个单元通过 mutator agent 生成候选想法谱系，local orchestrator 定期调整 mutator 的搜索策略，并在进展停滞时更换模型或重启演化过程。verifier 评估每个候选想法，并将验证过的改进、有用组件和约束违规记录到共享知识库中，该知识库是单元间唯一的通信渠道。在五个覆盖科研周期不同环节的基准上评估：检索（ScholarCatalyst）、构思（IdeaBench）、提案写作（IdeaScientist）、科学定律发现（EurekaBench、SciLaws-Bench），均取得领先，EurekaBench 上 73.6% 对比 CORAL 的 56.2%，IdeaBench 上每篇论文发现 26.0 个新颖想法，对比 ResearchAgent 的 18.6，且模型调用减少 82%。
- **为什么值得看**: 该工作提供了端到端科研自动化的证据，但人仍负责设定基准和最终验证；其去中心化架构和验证共享知识机制是对抗错误累积和想法趋同的具体尝试，值得关注其失败模式的量化。
- **关键技术**: `multi-agent pipeline`, `mutator agent`, `orchestrator agent`, `shared knowledge base`, `verifier`, `idea evolution`

### 4. Colombo: A Frontier-to-Frontier Autoresearch System for Oracle-Based Optimization
- **链接**: [论文页](https://arxiv.org/abs/2611.23080) · [PDF](https://arxiv.org/pdf/2611.23080) · [arXiv](https://arxiv.org/abs/2611.23080)
- **作者**: Haihan Zhang, Wendao Wu, Chenheng Zhang, Chunyuan Zheng, Yanyi Li, Cong Fang, Haoxuan Li, Zhouchen Lin
- **来源**: arXiv · cs.AI
- 相关性 7/10 · 自动化程度 `semi_autonomous`
- **自动化的环节**: 自动化了猜想形成、算法设计与证明验证环节，但设定选择、形式化验证和最终判断仍需人工介入。
- **摘要**: Colombo 是一个面向 oracle-based optimization 的自组织 AI 科研系统，目标是自动化从猜想形成、数学研究到算法与下界证明的闭环。系统由多个组件构成：Complexity Atlas 记录前沿设定与已知结果，Self-Organization 将未解决 gap 转化为自适应研究计划，Adversarial Co-Ascent 通过算法与困难族群的对抗推动方法改进，独立评审与 Lean 形式化验证检查数学主张，Long-Term Memory 跨设定积累经验。证据方面，Colombo 已在 Atlas 中超过 50 个设定上建立最优或近最优速率，但论文未提供与人类数学家或现有自动定理证明器的定量对比，也未报告失败模式或计算成本。该系统主要自动化数学研究中的猜想与证明环节，但选题（设定选择）和最终验证仍依赖人工或形式化工具兜底。
- **为什么值得看**: Colombo 展示了数学研究闭环的自动化尝试，但证据停留在任务数量而非质量对比，缺乏对失败模式（如错误累积、不可证明猜想）的量化分析，是评估端到端科研 agent 证据缺口的重要案例。
- **关键技术**: `self-organizing research programme`, `adversarial co-ascent`, `Lean formal certification`, `long-term memory`, `complexity atlas`
