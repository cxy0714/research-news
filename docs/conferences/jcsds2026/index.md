# 第四届统计与数据科学联合会议（JCSDS 2026）

> 2026 年 7 月 11–13 日 · 贵州 · [官方日程](https://jcsds2026.scimeeting.cn/cn/web/program/31392)

- **主题导航**：按研究方向聚合分会场，每个专题页含摘要检索与逐场精读。
