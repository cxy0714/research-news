**相关性**: 6/10  
**链接**: <https://arxiv.org/abs/2610.00962>

### 一、领域脉络与小综述

**这个方向是什么**：全基因组关联研究（GWAS）已经发现了大量与复杂性状相关的遗传位点，而"多效性"（pleiotropy）——单个遗传变异（SNP）同时影响多个性状——被认为是理解遗传结构的关键现象。本文聚焦于其中更严格的子问题：**如何利用 GWAS 汇总统计量（z-score），在控制多重检验错误率的前提下，检验一个 SNP 是否与至少 r 个（r ≥ 2）性状同时关联**，并进一步估计该 SNP 最少关联的性状数量。这个子方向处于统计遗传学与多重假设检验的交叉处，成熟度属于"方法正在快速涌现但尚无统一框架"的阶段：已有方法要么限于两个性状，要么需要个体水平数据，要么在性状数量增大时计算困难。

**发展脉络**：

- **奠基工作**：多效性的概念框架由 Solovieff et al. (2013) 系统梳理（"Pleiotropy in complex traits: challenges and strategies"），指出多效性是复杂性状遗传结构的普遍特征，并总结了早期检测方法的局限。Stearns (2010) 则从进化生物学角度回顾了多效性的一百年研究史，为统计方法提供了生物学动机。
- **双性状严格多效性检验的突破**：Ray & Chatterjee (2020) 提出 PLACO（Pleiotropic Analysis under Composite null），首次将"严格多效性"形式化为复合零假设——SNP 与两个性状中至多一个关联——并利用 GWAS 汇总 z-score 构造检验统计量。这是本文最直接的前驱。随后 Park & Ray (2025) 提出 PLACO Plus，通过膨胀方差模型处理两个 GWAS 样本重叠导致的 z-score 相关性，弥补了 PLACO 假设独立性的缺口。
- **多性状与混合模型方法**：Sun et al. (2023) 提出条件对称多维高斯混合模型（csmGmm），将严格多效性检验推广到 K 个性状，通过经验贝叶斯框架控制 FDR。但本文指出该方法"faces substantial computational challenges when the number of traits is large"（引言），且其参数数量随性状数增长较快。
- **需要个体数据的方法**：Schaid et al. (2016) 提出了跨性状的序贯检验框架，但本文明确指出"their method requires individual-level data, which limits its applicability"——在实际中 GWAS 汇总统计量往往比个体数据更容易获取。
- **当前 frontier 与本文位置**：当前前沿是在**仅使用汇总统计量**、**允许性状间任意相关**（样本重叠 + 遗传相关）、**性状数量较大**的三重约束下，同时做到错误率控制和计算可扩展性。本文声称同时解决这三个问题：SQT 控制 FWER，lfdr-VGM 控制 FDR，两者都只依赖 z-score，且计算复杂度随 K 线性增长（相对 csmGmm 的指数级配置空间）。

**子线索聚类**：被引文献大致落在三条线索上——

1. **复合零假设下的频率学检验**（PLACO、PLACO Plus、Schaid et al.）：核心是将"严格多效性"表述为"至少 r 个关联"的复合假设，用 z-score 的乘积或顺序统计量构造检验。优点是频率学保证清晰，缺点是扩展到 K > 2 时解析分布推导困难。
2. **经验贝叶斯/混合模型方法**（csmGmm、Efron 的局部 FDR 框架）：对 z-score 的联合分布建立混合模型，每个混合成分对应一种关联模式（如影响 0 个、1 个、2 个……性状），通过 EM 算法估计后验概率。优点是自然处理 K 个性状和相关性，缺点是计算复杂度高、对模型假设敏感。
3. **GWAS 多性状联合分析方法**（metaUSAT、多元 GWAS 方法）：这类方法主要目标是提高单性状关联检测的效力，而非专门检验多效性模式，但为 z-score 联合分布建模提供了基础工具。

**这个方向在追问的核心问题**：
1. **复合零假设下的错误率控制**：当零假设是"关联性状数 ≤ r-1"这种复合集合时，如何构造检验统计量并保证其在零假设的所有子情形下都控制错误率？
2. **汇总统计量的充分性**：仅凭每个性状的 GWAS z-score（而非个体水平数据），能否一致地检验多效性？信息损失有多大？
3. **相关性的处理**：性状间相关（来自样本重叠或遗传相关）如何影响零分布？如何在不估计高维相关矩阵的前提下稳健控制错误率？
4. **可扩展性**：当 K 达到数十或数百时，如何避免对 2^K 个配置的穷举？

**⚠️ 作者的 framing（这是作者的说法）**：作者在引言中把缺口 frame 成——现有方法"are either restricted to a small number of traits or become computationally challenging as the number of traits increases"（摘要），而本文的贡献是"both methods rely only on z-scores available from GWAS and are applicable to independent as well as correlated traits"（摘要），且能"determine the corresponding minimum number of associated traits"。作者将 PLACO/PLACO Plus 定位为"限于两性状"、将 csmGmm 定位为"计算困难"，从而让本文成为"显然的下一步"。被淡化的方面：PLACO Plus 实际上已经处理了相关性状，csmGmm 虽然计算复杂但在 K 较小时表现良好；作者没有讨论当 K 很大时混合模型中 2^K 个配置的求和是否仍然可行（只在讨论部分承认"computationally challenging as the number of traits increases"）。**什么明显该被引却没出现**：引言未提及多元 GWAS 中的贝叶斯方法（如 GPA、CHEERS），也未提及孟德尔随机化文献中处理多效性的工具（如 MR-Egger），这些方法虽然目标不同，但都涉及"一个 SNP 影响多个性状"的推断，可能是作者有意划清界限。

**张力**：未见明显对立引用（即没有两篇论文在相同条件下得出相反结论）。但存在一个方法学张力：PLACO 声称控制错误率，但本文模拟显示其"can have substantially inflated FWER because it does not guarantee suitable error rate control under each sub-null hypothesis"（第 4 节）——这暗示 PLACO 的错误率控制是"平均意义"上的，而非"逐子零假设"上的。另一个张力是 csmGmm 的保守性（FDR 远低于名义水平）与 lfdr-VGM 的效率之间的权衡，本文用模拟展示了这一点。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

**符号**（逐个点名）：

| 记号 | 含义 | 类型 |
|---|---|---|
| \(K\) | 性状总数 | 固定常数（本文模拟取 2 或 5） |
| \(j = 1, \dots, p\) | SNP 索引 | 固定常数（GWAS 中通常 \(p \sim 10^6\)） |
| \(k = 1, \dots, K\) | 性状索引 | 固定常数 |
| \(Y_{ik}\) | 第 \(i\) 个个体第 \(k\) 个性状的取值 | 随机变量（观测） |
| \(S_{ij}\) | 第 \(i\) 个个体第 \(j\) 个 SNP 的基因型（0/1/2） | 随机变量（观测） |
| \(Z_i\) | 第 \(i\) 个个体的协变量向量（年龄、性别、主成分等） | 随机变量（观测） |
| \(\beta_{jk}\) | SNP \(j\) 对性状 \(k\) 的边际效应 | **参数（待检验）** |
| \(W_{jk} = \hat\beta_{jk} / \text{se}(\hat\beta_{jk})\) | SNP \(j\) 对性状 \(k\) 的 Wald z-score | 随机变量（由 GWAS 汇总统计量给出，**可观测**） |
| \(r\) | 最小关联性状数阈值 | 假设参数（检验目标） |
| \(H^r_0\) | 复合零假设：SNP 关联的性状数 ≤ \(r-1\) | 假设 |
| \(H^r_a\) | 备择假设：存在至少 \(r\) 个性状同时关联 | 假设 |
| \(p_{(1),j} \le \cdots \le p_{(K),j}\) | SNP \(j\) 的 K 个 p 值升序排列 | 可观测（由 z-score 转换） |
| \(Z_j \in \{0,1\}^K\) | SNP \(j\) 的潜在关联配置（\(Z_{jk}=1\) 表示影响性状 \(k\)） | **潜在变量（不可观测）** |
| \(\pi_z = P(Z_j = z)\) | 配置 \(z\) 的先验概率 | 参数（需估计） |
| \(\sigma_k^2\) | 有效关联时 z-score 的方差 | 参数（需估计） |
| \(\rho^b_{kk'}\) | 不同性状间**真实遗传效应**的相关系数 | 参数（需估计） |
| \(\rho^e_{kk'}\) | 不同性状间**估计误差**的相关系数（来自样本重叠） | 参数（需估计） |

**模型**（数据生成机制）：

1. **单性状 GWAS 模型**：对每个性状 \(k\)，研究者拟合线性或逻辑回归
   \[
   Y_k = \beta_{jk0} + \beta_{jk} S_j + Z_k^\top \gamma_{jk} + \epsilon_{jk}
   \]
   得到 Wald 统计量 \(W_{jk}\)。在零假设 \(\beta_{jk}=0\) 下，\(W_{jk} \sim N(0,1)\)（渐近）。

2. **多性状联合模型**（lfdr-VGM 的核心假设）：对每个 SNP \(j\)，存在潜在配置 \(Z_j \in \{0,1\}^K\)。给定 \(Z_j\)，z-score 向量 \(W_j = (W_{j1}, \ldots, W_{jK})^\top\) 服从
   \[
   W_j \mid Z_j = z \;\sim\; N(0, \Sigma(z))
   \]
   其中 \(\Sigma(z)\) 的对角线元素为：若 \(z_k = 0\)（无效应），方差为 1；若 \(z_k = 1\)（有效应），方差为 \(\sigma_k^2 > 1\)。非对角线元素由 \(\rho^b_{kk'}\)（当 \(z_k = z_{k'} = 1\)）和 \(\rho^e_{kk'}\)（当 \(z_k = 0\) 或 \(z_{k'} = 0\)）决定。

2. **可观测数据**：研究者**只能观测到**每个 SNP 对每个性状的 z-score \(W_{jk}\)（或等价的 p 值）。**观测不到**的是：
   - 潜在配置 \(Z_j\)（SNP 究竟影响了哪些性状）；
   - 真实效应大小 \(\beta_{jk}\)；
   - 性状间的遗传相关 \(\rho^b_{kk'}\) 和样本重叠相关 \(\rho^e_{kk'}\)（这些是**需要估计的 nuisance 参数**）。

#### 第二步：最小内核

**最简特例：K = 2, r = 2**（检验 SNP 是否同时影响两个性状）。

**假设检验问题**：
\[
H^2_0: \text{SNP 影响至多 1 个性状} \quad \text{vs} \quad H^2_a: \text{SNP 同时影响 2 个性状}
\]

零假设 \(H^2_0\) 是复合的，包含三种子情形：
- 子情形 A：SNP 对两个性状都无效应（\(\beta_{j1} = \beta_{j2} = 0\)）
- 子情形 B：SNP 只影响性状 1（\(\beta_{j1} \neq 0, \beta_{j2} = 0\)）
- 子情形 C：SNP 只影响性状 2（\(\beta_{j1} = 0, \beta_{j2} \neq 0\)）

**SQT 的核心思想**：考虑检验统计量
\[
T_j = \min(|W_{j1}|, |W_{j2}|)
\]
即两个 z-score 绝对值中的较小者。

- 在子情形 A 下：\(|W_{j1}|\) 和 \(|W_{j2}|\) 都近似服从标准半正态，因此 \(T_j\) 的分布是**两个独立半正态的最小值**，其尾部概率可以精确计算。
- 在子情形 B 下：\(|W_{j1}|\) 可能很大（因为有效应），但 \(|W_{j2}|\) 仍然服从标准半正态，因此 \(T_j = |W_{j2}|\) 的分布与子情形 A 相同。
- 在子情形 C 下：同理，\(T_j = |W_{j1}|\) 服从标准半正态。

**关键观察**：无论零假设的哪个子情形成立，\(T_j\) 的分布都**不超过**两个独立半正态最小值的分布（在随机占优意义上）。因此，只要阈值 \(c_\alpha\) 满足
\[
P\left(\min(|Z_1|, |Z_2|) > c_\alpha\right) = \alpha,
\]
其中 \(Z_1, Z_2 \sim N(0,1)\) 独立，那么检验"\(T_j > c_\alpha\) 则拒绝 \(H^2_0\)"就在所有子情形下控制了第一类错误率。这就是命题 1 的内容：**最小值检验是复合零假设下的有效检验**，且不需要知道哪个子情形成立。

**为什么这个内核是"支撑整篇论文的"**：
- 对于一般的 \(r\) 和 \(K\)，SQT 将上述思想推广为：对每个 SNP 的 K 个 p 值排序，依次检验第 r 小的 p 值是否小于阈值 \(c_r = \alpha / (q(K-r+1))\)，其中 q 是当前存活的 SNP 数。这本质上是一个**序贯的顺序统计量检验**，每一步都在控制"至少 r 个关联"的复合零假设。
- lfdr-VGM 则是从另一个角度处理同一个问题：不直接检验顺序统计量，而是对 z-score 向量建立混合模型，估计每个 SNP 属于"影响 0 个、1 个、2 个……性状"的后验概率，然后基于局部错误发现率做决策。它的最小内核是：**在 K = 2 时，混合模型只有 4 个成分（00, 10, 01, 11），EM 算法可以显式求解**；本文将其推广到一般 K，并用方差-均值参数化（VGM）减少参数数量。

**这个最小内核揭示了论文的本质**：严格多效性检验的数学困难不在于"检测关联"（单性状 GWAS 已经解决），而在于**在复合零假设下构造一个对零假设所有子情形都有效的检验统计量**。SQT 用顺序统计量绕开了对子情形的识别，lfdr-VGM 用混合模型显式建模子情形的分布。两者都只需要 z-score，这是它们相对于需要个体数据的方法（如 Schaid et al.）的核心优势。

### 三、这篇论文做了什么

**三句话**：
1. **研究了什么问题**：在 GWAS 汇总统计量（z-score）可得的设定下，如何检验一个 SNP 是否与至少 r 个（r ≥ 2）性状同时关联（严格多效性），并估计该 SNP 最少关联的性状数量。
2. **核心工具 / 方法**：提出了两种方法——SQT（Sequential Quantile-based Test），一个基于 p 值顺序统计量的序贯检验，控制 FWER；lfdr-VGM（local false discovery rate with Variance-Gaussian Mixture），一个基于高斯混合模型的经验贝叶斯方法，控制 FDR。
3. **主要结论**：两种方法在模拟中均能维持名义错误率（FWER/FDR），且 lfdr-VGM 在 K = 5 时比 csmGMM 具有更高的功效；应用于 AD 相关生物标志物数据，识别出 APOE 区域的多效性 SNP，并估计了它们的最小关联性状数。

---

#### 关键设定与假设

**设定**：
- 输入：K 个 GWAS 的汇总 z-score 矩阵（\(p \times K\)），每个 SNP 一行，每个性状一列。
- 目标：对每个 SNP，检验 \(H^r_0\)（关联性状数 ≤ r-1）vs \(H^r_a\)（关联性状数 ≥ r），并估计最小关联性状数 \(\hat{r}_j = \min\{r: H^r_0 \text{ 被拒绝}\}\)。
- 允许 K 个 GWAS 的样本**部分或完全重叠**，因此 z-score 之间存在相关性。

**假设**：
1. **零假设下 z-score 渐近正态**：对无效关联，\(W_{jk} \sim N(0,1)\)（渐近）。这是 GWAS 汇总统计量的标准性质。
2. **相关性结构可估计**：z-score 间的相关矩阵 \(\Sigma\) 可以分解为遗传相关（\(\rho^b\)）和样本重叠相关（\(\rho^e\)），且可以通过**无关联 SNP 的 z-score 经验相关矩阵**来估计（这是 GWAS 领域的常用技巧，如 LD score regression 的思路）。
3. **混合模型假设**（仅 lfdr-VGM）：z-score 的边际分布服从混合高斯，其中"无效"成分方差为 1，"有效"成分方差为 \(\sigma_k^2 > 1\)。这是一个简化假设——真实效应大小是连续的，但混合模型用大方差成分近似。
4. **效应方向不建模**：z-score 取绝对值，因此正负效应被同等对待。这是一个重要的简化——如果 SNP 对两个性状的效应方向相反（拮抗多效性），绝对值方法仍然有效，但会丢失方向信息。

**相比现有文献的放宽/强化**：
- 相比 PLACO（Ray & Chatterjee 2020）：放宽了"两个性状"的限制，支持任意 K。
- 相比 csmGMM（Sun et al. 2023）：**强化**了计算效率——csmGMM 需要对 2^K 个配置的混合成分进行 EM 迭代，而 lfdr-VGM 通过方差-均值参数化将参数数量从 O(2^K) 降到 O(K^2)（本文第 3 节："the number of parameters grows as O(K^2)"）。
- 相比 Schaid et al. (2016)：放宽了"需要个体水平数据"的限制，仅用汇总统计量。

#### 主要结果

**SQT（频率学方法）**：
- 命题 1：对 \(H^K_0\)（SNP 影响所有 K 个性状），检验统计量 \(T_{j,K} = \min_k |W_{jk}|\) 在零假设下满足 \(\lim_{n \to \infty} \sup_{\theta \in \Theta_0} P_\theta(T_{j,K} > c_\alpha) = \alpha\)，其中 \(c_\alpha = \Phi^{-1}(1 - \alpha/2)\)。即**最小值检验渐近控制第一类错误率**，且不依赖于相关性结构（因为最小值在零假设下被标准正态随机变量随机占优）。
- 命题 3（序贯版本）：对一般的 \(H^r_0\)，算法从 r = 1 开始，逐步检验第 r 小的 p 值是否小于 \(c_r = \alpha / (q(K-r+1))\)，其中 q 是当前存活的 SNP 数。每一步的阈值都经过 Bonferroni 校正，因此**整体 FWER 控制在 α**。
- 关键性质：SQT 不需要估计任何 nuisance 参数（如相关性），因此计算极其简单，且对相关性结构稳健。

**lfdr-VGM（贝叶斯方法）**：
- 模型：\(W_j \sim \sum_{z \in \{0,1\}^K} \pi_z N(0, \Sigma(z))\)，其中 \(\Sigma(z)\) 的对角线元素为 \(1 + z_k(\sigma_k^2 - 1)\)。
- 估计：用 EM 算法估计 \(\{\pi_z, \sigma_k^2, \rho^b_{kk'}, \rho^e_{kk'}\}\)。关键创新是**方差-均值参数化**（VGM）：将 \(\sigma_k^2\) 分解为遗传效应方差和估计误差方差，从而避免对每个配置 z 单独估计协方差矩阵。
- 决策规则：对每个 SNP，计算后验概率 \(P(|Z_j| \ge r | W_j)\)，若超过阈值则拒绝 \(H^r_0\)。FDR 通过将后验概率排序并应用 Benjamini-Hochberg 程序控制。
- 模拟结果（第 4 节）：在 K = 2 时，lfdr-VGM 的 FDR 控制在名义水平附近，而 csmGMM 的 FDR 显著低于名义水平（即过于保守）；在 K = 5 时，lfdr-VGM 在检测"至少 r 个关联"上的功效一致高于 csmGMM，尤其在 r ≥ 3 时优势明显。

**真实数据应用（第 5 节）**：
- 数据：AD 相关生物标志物的 GWAS 汇总统计量，包括 Aβ42、p-tau、NFL、SNAP-25、神经颗粒蛋白（neurogranin）。
- 分析：对 K = 2（Aβ 和 p-tau）和 K = 5 分别应用四种方法。
- 结果：所有方法都识别出 APOE 区域（19 号染色体）的多效性 SNP。lfdr-VGM 额外识别出一些 SNP 与 4 个生物标志物同时关联，而 SQT 在这些 SNP 上未达到显著性。表 4 报告了独立 SNP 及其最小关联性状数。

#### 证明路线与技术技巧

**SQT 的证明路线**：
1. **第一步**：证明单个 SNP 的最小值检验在 \(H^K_0\) 下控制第一类错误率。关键技巧是**随机占优**：在零假设下，\(|W_{jk}|\) 被 \(|Z| \sim \text{Half-Normal}(0,1)\) 随机占优（对每个 k），因此 \(\min_k |W_{jk}|\) 被 \(\min_{k} |Z_k|\) 随机占优。这不需要任何相关性假设——即使 z-score 高度相关，最小值仍然被独立半正态的最小值占优。
2. **第二步**：将单 SNP 检验扩展到全基因组。对每个 SNP 使用阈值 \(c_\alpha\)，则全基因组 FWER ≤ α（Bonferroni）。但直接 Bonferroni 过于保守，因此引入**序贯淘汰**：先检验 r = 1（至少一个关联），淘汰不显著的 SNP，再在存活的 SNP 中检验 r = 2，以此类推。每一步的阈值 \(c_r = \alpha / (q(K-r+1))\) 中，q 是上一步存活的 SNP 数，\(K-r+1\) 是剩余待检验的性状数。这个设计的巧妙之处在于：**每一步只需控制该步的第一类错误率，而整体 FWER 由序贯结构自动保证**（因为只有通过前一步的 SNP 才会进入下一步）。
3. **第三步**：证明序贯检验的 FWDR 控制。关键引理是：在 \(H^r_0\) 下，第 r 小的 p 值被均匀分布的顺序统计量占优，因此 \(P(p_{(r),j} < c_r) \le c_r (K-r+1)\)。乘以 q 后得到 FWER ≤ α。

**lfdr-VGM 的证明/推导路线**：
1. **模型建立**：将 z-score 的联合分布建模为混合高斯，混合成分由潜在配置 z ∈ {0,1}^K 索引。关键假设是：给定 z，z-score 的协方差矩阵 \(\Sigma(z)\) 可以分解为
   \[
   \Sigma(z) = \Sigma^e + D(z)^{1/2} \Sigma^b D(z)^{1/2}
   \]
   其中 \(\Sigma^e\) 是估计误差相关（来自样本重叠），\(\Sigma^b\) 是遗传效应相关，\(D(z)\) 是对角矩阵，第 k 个对角元素为 \(z_k\)（即只有被影响的性状才有遗传效应方差）。这个分解是 VGM 的核心——它将 2^K 个配置的协方差矩阵用 K 个方差参数和两个相关矩阵参数化。
2. **EM 算法**：潜在变量 z 的期望步需要计算 \(P(z | W_j)\)，这涉及对 2^K 个配置的求和。本文的技巧是**利用高斯密度的解析形式**：\(N(W_j; 0, \Sigma(z))\) 可以写成 z 的指数族形式，从而期望步可以分解为对每个性状的边际计算，避免显式枚举所有配置。
3. **FDR 控制**：基于估计的后验概率 \(\hat{P}(|Z_j| \ge r | W_j)\)，应用 Benjamini-Hochberg 程序。本文通过模拟验证 FDR 控制，而非给出解析证明——这是一个值得注意的局限。

**技术技巧点名**：
- **随机占优（stochastic domination）**：用于证明最小值检验在复合零假设下的有效性，这是 SQT 的核心技巧。
- **序贯淘汰（sequential screening）**：将全基因组检验分解为 r = 1, 2, ..., K 的逐步检验，每一步只对存活的 SNP 进行，大幅降低多重检验负担。
- **方差-均值高斯混合（VGM）**：用方差参数化替代均值参数化，避免对每个配置估计均值，从而将参数数量从 O(2^K) 降到 O(K^2)。
- **经验贝叶斯 / 局部 FDR**：借鉴 Efron (2008) 的框架，但扩展到多维 z-score 和复合零假设。
- **EM 算法的解析期望步**：利用高斯密度的指数族形式，避免数值积分或蒙特卡洛。

#### 🔎 结论是否比证明窄

**是，存在几处"证明窄于声称"的地方**：

1. **SQT 的 FWDR 控制是渐近的**：命题 1 的陈述是 \(\lim_{n \to \infty} \sup_{\theta \in \Theta_0} P_\theta(T_{N,j,K} > c_\alpha) = \alpha\)，即**渐近**控制。但 GWAS 的样本量虽然大，z-score 的渐近正态性依赖于每个 SNP 的效应估计，而弱效应 SNP 的渐近可能很慢。论文没有给出有限样本界或收敛速度。

2. **lfdr-VGM 的 FDR 控制缺乏解析证明**：论文仅通过模拟验证 FDR 控制（第 4 节），没有给出类似定理 2 的解析结果。这意味着 FDR 控制可能依赖于模型假设（混合高斯、方差分解）的正确性，而论文没有讨论模型误设的后果。

3. **"适用于任意 K"的声称被计算复杂性削弱**：虽然 VGM 参数化将参数数量降到 O(K^2)，但 EM 算法的期望步仍然需要对 2^K 个配置求和（尽管有解析技巧）。论文在讨论部分承认"computationally challenging as the number of traits increases"，但没有给出 K 的实际上限。

4. **相关性的估计**：论文假设 z-score 的相关矩阵可以分解为 \(\rho^b\) 和 \(\rho^e\)，但实际中这两个相关矩阵的估计依赖于**无关联 SNP 的 z-score**（这是标准做法），而论文没有讨论估计误差对 FDR 控制的影响。

5. **效应方向的信息丢失**：论文使用 |z-score|，因此无法区分"一个 SNP 对两个性状的效应方向相反"（拮抗多效性）与"方向相同"（协同多效性）。这在生物学上是有意义的信息，但论文没有讨论。

### 四、开放问题

以下开放问题均扎根于论文的具体语句或局限：

1. **有限样本下的错误率控制**：命题 1 只给出渐近控制（"\(\lim_{n \to \infty} \sup_{\theta \in \Theta_0} P_\theta\)"）。能否推导出有限样本界，特别是当 GWAS 样本量中等（如 \(n \approx 10^4\)）且效应较弱时？这需要非渐近的 z-score 分布理论（如 Berry-Esseen 型不等式）。

2. **模型误设下的 FDR 控制**：lfdr-VGM 的 FDR 控制仅通过模拟验证（第 4 节），没有解析证明。当真实效应分布不是高斯混合（例如重尾分布）时，FDR 是否仍然受控？这需要研究混合模型的稳健性。

3. **K 很大时的计算可扩展性**：论文承认"computationally challenging as the number of traits increases"（讨论部分）。当 K = 50 或 K = 100 时，EM 算法的期望步是否仍然可行？能否用变分推断或采样方法近似？

4. **相关矩阵的估计误差**：论文假设 \(\rho^b\) 和 \(\rho^e\) 可以估计（第 3 节），但没有分析估计误差对检验水平的影响。当 GWAS 样本重叠程度未知或 LD 结构复杂时，相关矩阵的估计误差是否会导致 FDR 膨胀？

5. **效应方向与拮抗多效性**：论文使用 |z-score|，丢失了效应方向信息。如何扩展方法以区分协同多效性与拮抗多效性？这可能需要引入有符号的 z-score 和方向性假设。

6. **与孟德尔随机化的衔接**：论文在引言中提到"identifying such pleiotropic variants can also lead to a proper genetic 'instrument' for testing for causal effects of latent exposures"（引用 Jin et al. 2024），但未深入讨论。严格多效性检验的结果如何与 MR 中的多效性稳健方法（如 MR-Egger）结合？这是一个跨领域的开放问题。
