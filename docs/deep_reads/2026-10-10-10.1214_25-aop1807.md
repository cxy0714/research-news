### 一、领域脉络与小综述

#### 这个方向是什么

本文属于**随机矩阵理论中的谱普适性（spectral universality）** 这一子方向。其根本的科学问题是：对于一大类"非 Wigner 型"的随机矩阵（即矩阵元不独立同分布、甚至不是独立抽取的），其局部特征值统计量（尤其是极端特征值的波动）是否与高斯系综（GOE/GUE）一致？该方向的核心技术目标是建立**边缘普适性（edge universality）**，即证明极端特征值在合适的缩放后收敛到 Tracy-Widom 分布。当前该方向在 Wigner 矩阵和 Erdős–Rényi 图上已相当成熟，但**随机 d-正则图**因其组合约束（每行恰好 d 个 1）带来的强相关性，是普适性理论中一个长期未完全攻克的"硬骨头"。

#### 发展脉络（history）

- **奠基工作：Wigner 矩阵的边缘普适性（1990s–2000s）**。Soshnikov (1999) [57] 用矩方法首次在对称性假设下证明了 Wigner 矩阵极端特征值的 Tracy-Widom 极限；Tao–Vu (2009) [12] 和 Erdős–Yau 学派（如 [22, 28, 58]）随后发展出基于 Green 函数比较和局部半圆律的通用框架。这些工作确立了"局部半圆律 + 特征值间距估计 + Green 函数比较"这一标准三步走范式。
- **向稀疏随机图推广（2010s）**。Erdős–Knowles–Yau–Yin (2011) [1] 将边缘普适性推广到 Erdős–Rényi 图，条件是平均度 pN ≫ N^{2/3}。这开启了稀疏随机矩阵的研究。关键口子是：稀疏性导致局部半圆律的误差项变大，需要更精细的估计。
- **随机正则图的局部律（2010s 中期）**。Bauerschmidt–Knowles–Yau (2017) [3] 证明了随机 d-正则图的局部半圆律，条件是 d ≥ (log N)^4。这是本文的直接技术基础。该文的关键贡献是处理了正则图特有的"回溯"（backtracking）结构，证明了 Green 函数在谱内部被半圆律控制。
- **边缘普适性的中间地带（2019–2023）**。Bauerschmidt–Huang–Knowles–Yau (2019) [4] 在 d ≪ N^{2/3} 的区间内证明了边缘刚性（edge rigidity），但普适性（即 Tracy-Widom 极限）只对 d ≥ N^{2/9} 成立。**本文的贡献**：将普适性区间从 d ≥ N^{2/9} 扩展到 d ≥ N^c（任意小 c>0），填补了 d 在 N^c 到 N^{1/3} 之间的空白。注意：d ≤ N^{1/3} 的上界是本质的，因为当 d 更大时，极端特征值的波动不再是 Tracy-Widom（见下文"张力"）。

#### 子线索聚类

1. **Green 函数比较法（comparison approach）**：以 Erdős–Yau 学派为代表 [22, 28, 58]，通过比较目标矩阵与高斯矩阵的 Green 函数期望，逐步"交换"矩阵元分布。本文属于此线索，但针对正则图做了关键改进：不再逐项比较矩阵元，而是利用正则图的组合结构（森林计数）直接构造高阶自洽方程。
2. **矩方法（moment method）**：以 Soshnikov [57] 和 Feldheim–Sodin [29] 为代表，通过计算特征值的高阶矩来证明普适性。此方法对矩阵元独立性要求较高，在正则图上难以直接应用。
3. **动力学方法（Dyson Brownian motion）**：Landon–Yau [5] 等发展的 DBM 方法，通过矩阵布朗运动的短时演化来"洗掉"初始分布的细节。本文的第七节采用此方法，但需要先建立最优刚性估计（Theorem 2.2）作为输入。

#### 这个方向在追问的核心问题

- **核心问题 1**：随机 d-正则图的极端特征值波动是否服从 Tracy-Widom 分布？在什么 d 的区间内成立？
- **核心问题 2**：极端特征值的刚性（rigidity）——即特征值与其经典位置的偏差——能否达到最优的 N^{-2/3} 尺度？
- **核心问题 3**：当 d 很小（固定或缓慢增长）时，普适性是否仍然成立？这是本文留下的最大开放问题（见第四节）。
- **已知瓶颈**：正则图的组合约束导致矩阵元强相关，标准 Wigner 矩阵的独立性假设完全失效。现有技术（局部半圆律、Green 函数比较）在 d 很小时误差项过大，需要新的组合估计。

#### ⚠️ 作者的 framing（这是作者的说法）

作者在引言中把缺口 frame 成："**在 d ≥ N^c 的区间内，随机 d-正则图的极端特征值波动服从 Tracy-Widom 分布**"。他们强调，之前的工作 [8] 只能处理 d ≥ N^{2/9}，而本文通过"高阶自洽方程 + 单步交换"的新方法，将下界推到了任意多项式尺度。作者还特别指出，**本文的方法论创新在于将自洽方程的构造和矩的计算合并为一步**，从而避免了 [8] 中需要逐阶展开的复杂性。作者淡化了以下竞争路线：(i) 矩方法（认为其无法处理正则图的相关性）；(ii) 直接比较法（认为其需要矩阵元独立）。**值得研究者去查的问题**：作者声称"单步交换"是本质改进，但 [8] 的方法是否真的无法推广到 d ≥ N^c？作者没有讨论 d 在 N^{1/3} 到 N^{2/3} 之间的行为（[31] 处理了 d ≥ N^{2/3}），这个中间地带是否存在不同的极限行为？

#### 张力

- **未见明显对立引用**，但存在一个**隐含的张力**：当 d 很小（固定）时，随机 d-正则图的极端特征值波动**不**服从 Tracy-Widom（因为图的局部结构——短环——会产生可观测的效应）。本文的结果要求 d ≥ N^c，这排除了固定 d 的情形。因此，**d 从 N^c 到固定值之间必然存在一个相变**，但本文没有讨论这个相变的位置和性质。这是一个高价值的开放问题（见第四节）。


### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

- **模型**：设 G 是 N 个顶点上的均匀随机 d-正则图（即从所有 d-正则简单图中均匀抽取）。A 是其邻接矩阵，A_ij ∈ {0,1}，每行每列恰好有 d 个 1，对角元为 0。归一化矩阵定义为
  H := A / √(d−1)。
  注意：这里除以 √(d−1) 而非 √d，是为了让谱的支撑收敛到 [−2, 2]（Kesten–McKay 定律的支撑）。
- **可观测数据**：研究者能观测到的是矩阵 H 的**全部特征值** {λ_1 ≥ λ_2 ≥ … ≥ λ_N}（λ_1 = d/√(d−1) 是平凡特征值，对应全 1 向量）。**不可直接观测**的是特征值的联合分布、特征向量等。本文关注的是**极端特征值** λ_2（最大非平凡特征值）和 λ_N（最小特征值）。
- **参数 / estimand**：
  - **谱测度**：μ_N = (1/N) Σ_{i=1}^N δ_{λ_i}，其极限是 Kesten–McKay 分布 ρ_d，密度为
    ρ_d(x) = [d/(2π(d−1))] · [√(4−x²)] / [(d/(d−1))² − x²]，x ∈ [−2, 2]。
  - **极端特征值的缩放**：定义
    ξ_2 = N^{2/3} (λ_2 − 2)，ξ_N = N^{2/3} (λ_N + 2)。
    本文要证明 ξ_2 和 ξ_N 的联合分布收敛到 GOE 的对应极端特征值分布（Tracy-Widom）。
  - **Green 函数**：G_ij(z) = [(H − z)^{-1}]_ij，z = E + iη ∈ C⁺。其归一化迹 m(z) = (1/N) Σ_i G_ii(z) 是谱测度的 Stieltjes 变换。
  - **Kesten–McKay Stieltjes 变换** m_d(z)：满足自洽方程
    m_d(z) = −[z + (d/(d−1)) m_d(z)]^{-1}。
    这是本文所有分析的"靶子"——m(z) 应逼近 m_d(z)。

#### 第二步：最小内核

**核心数学问题**：证明随机 d-正则图的极端特征值波动服从 Tracy-Widom 分布。

**最小内核（剥去所有技术细节后）**：考虑一个"玩具模型"——**单个顶点上的自洽方程**。对于无限 d-正则树上的谱测度，Stieltjes 变换 m_d(z) 满足
m_d(z) = −[z + (d/(d−1)) m_d(z)]^{-1}。    (∗)

这个方程可以这样理解：从根顶点出发，它的 d 个邻居各自"看到"一棵子树，而每棵子树的结构与整棵树相同（自相似性）。因此，根顶点的 Green 函数 G_00(z) 满足
G_00(z) = −[z − Σ_{j=1}^d (1/√(d−1)) · (1/√(d−1)) · G_j(z)]^{-1}，
其中 G_j(z) 是第 j 个邻居的 Green 函数。由于树的对称性，所有 G_j(z) 相等，记为 g(z)，则
g(z) = −[z − (d/(d−1)) g(z)]^{-1}，
这正是 (∗) 式。

**为什么这是最小内核**：本文的全部技术工作，本质上是在证明**有限随机 d-正则图**的 Green 函数 m(z) 逼近这个"树上的自洽方程"的解 m_d(z)。具体来说：

1. **局部半圆律**（Theorem 2.1）：m(z) ≈ m_d(z)，误差在谱内部为 O(1/√d)，在谱边缘附近为 O(1/(Nη))。
2. **高阶自洽方程**（Proposition 5.1）：作者构造了一个多项式 P(z, m(z))，使得 E[|P(z, m(z))|^{2q}] 很小。这个多项式 P 是"树方程" (∗) 的有限阶截断——它编码了 Green 函数在有限图上的自相似性被破坏的程度。
3. **识别自洽方程**（Proposition 6.1）：作者证明 P(z, m_d(z)) = O(d/N)，即树方程的解 m_d(z) 近似满足这个高阶方程。这一步将"有限图"与"无限树"连接起来。
4. **边缘刚性**（Theorem 2.2）：由上述估计推出极端特征值 λ_2, λ_N 与经典位置 2, −2 的偏差为 O(N^{-2/3})。
5. **边缘普适性**（Theorem 1.1）：用 DBM 方法（第七节），以刚性估计为输入，证明极端特征值的波动收敛到 Tracy-Widom。

**一句话总结**：本文在数学上干的事情是——**证明随机 d-正则图的 Green 函数在谱边缘附近满足"树上的自洽方程"到足够高的精度，从而推出极端特征值的 Tracy-Widom 波动**。最小内核就是那个一元二次方程 (∗)，而全部技术工作（高阶自洽方程、矩估计、DBM）都是为了让这个"树方程"在有限图上成立。


### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：在度数 d 满足 N^c ≤ d ≤ N^{1/3−c} 的区间内，随机 d-正则图邻接矩阵的极端特征值（λ_2 和 λ_N）的波动是否服从 Tracy-Widom 分布。
2. **核心工具 / 方法**：高阶自洽方程（high-order self-consistent equation）+ 单步交换（single-step swapping）的矩估计，结合 DBM 的短时演化比较。
3. **主要结论**：在上述区间内，极端特征值的波动收敛到 Tracy-Widom 分布；作为推论，约 69% 的 d-正则图是 Ramanujan 图（所有非平凡特征值绝对值 ≤ 2√(d−1)）。

#### 关键设定与假设

- **模型**：均匀随机 d-正则图，d 满足 N^c ≤ d ≤ N^{1/3−c}。注意：d 的下界 N^c 是本文的核心假设，它保证了图的局部结构"足够树状"（短环的期望数量趋于 0）。
- **归一化**：H = A/√(d−1)，谱支撑为 [−2, 2]。
- **技术假设**：
  - 特征值间距假设（gap condition）：极端特征值与其余特征值之间有至少 N^{-2/3+ε} 的间距。这个假设在 [8] 中也被使用，本文通过刚性估计（Theorem 2.2）来验证它。
  - 测试函数 F 是光滑且有界导数的（第七节）。
- **相比已有工作的放宽 / 强化**：
  - 相比 [8]（要求 d ≥ N^{2/9}），本文**放宽**了 d 的下界到 N^c。
  - 相比 [31]（要求 d ≥ N^{2/3}），本文**强化**了 d 的上界到 N^{1/3−c}。注意：d ≤ N^{1/3−c} 是本质的，因为当 d 更大时，极端特征值的波动不再是 Tracy-Widom（见下文"结论是否比证明窄"）。

#### 主要结果

- **Theorem 1.1（主定理）**：对任意固定的 k ≥ 1，λ_2, …, λ_{k+1} 和 λ_N, …, λ_{N−k+1} 的联合分布，在 N^{2/3} 缩放后，收敛到 GOE 的对应极端特征值分布。误差为 O(N^{−e})，其中 e > 0 是某个小常数。
- **Theorem 2.2（最优刚性）**：对任意 j，|λ_j − γ_j| ≺ N^{-2/3} (min{j, N+1−j})^{-1/3}，其中 γ_j 是 Kesten–McKay 分布的经典特征值位置。这个估计在极端特征值处是最优的（达到 N^{-2/3} 尺度）。
- **Corollary 1.1（Ramanujan 图）**：在 N^c ≤ d ≤ N^{1/3−c} 区间内，约 69% 的 d-正则图是 Ramanujan 图。这个 69% 来自 Tracy-Widom 分布的性质：P(TW ≤ 0) ≈ 0.69（因为 λ_2 的波动服从 Tracy-Widom，而 2√(d−1) 对应缩放后的 0 点）。

#### 证明路线与技术技巧

**整体路线（三步走）**：

1. **第一步：建立高阶自洽方程**（Section 5）。这是本文的核心创新。作者不再像 [8] 那样逐阶展开自洽方程，而是直接构造一个多项式 P(z, m(z))，使得 E[|P(z, m(z))|^{2q}] 可以被控制。这个多项式 P 的构造依赖于"森林计数"（forest counting）：将 Green 函数的矩展开为图的子结构（树、单环、多环）的计数，然后利用正则图的组合性质（短环稀少）来估计这些计数。
   - **关键技巧**：**单步交换（single-step swapping）**。在计算 E[|P|^{2q}] 时，作者不是一次性交换所有矩阵元，而是每次只交换一个"块"（block），然后利用正则图的局部树状性质来控制误差。这避免了 [8] 中需要处理的高阶项。
   - **技术难点**：如何保证 P 的阶数足够高（以覆盖到最优刚性所需的精度），同时保证 P 的系数可控（不随 N 增长）。作者通过精细的图论计数（引理 5.3–5.5）解决了这个问题。

2. **第二步：识别自洽方程**（Section 6）。作者证明 P(z, m_d(z)) = O(d/N)，即树方程的解 m_d(z) 近似满足高阶自洽方程。这一步的关键是**代数恒等式**：将 m_d(z) 代入 P 后，所有低阶项相互抵消，只剩下 O(d/N) 的余项。这个恒等式是"树的自相似性"在代数上的体现。
   - **技术技巧**：**生成函数方法**。作者将 P 的系数与树的生成函数联系起来，利用 Catalan 数等组合恒等式来证明抵消。

3. **第三步：边缘普适性**（Section 7）。用 DBM 方法。作者将 H(0) 与 GOE 通过矩阵布朗运动连接，利用刚性估计（Theorem 2.2）和 [43] 的 DBM 短时演化结果，证明在时间 t ≫ N^{-1/3} 时，H(t) 的边缘统计量已经与 GOE 一致。然后通过 Green 函数比较（Proposition 7.8），证明 H(0) 和 H(t) 的边缘统计量相同。
   - **关键技巧**：**Green 函数比较**。作者比较 H(0) 和 H(t) 的 Green 函数期望，利用自洽方程（第一步）来控制差异。这里的关键是：自洽方程的精度（O(d/N)）恰好足够覆盖 DBM 演化所需的误差。

**技术技巧总结**：
- **图论计数**：将 Green 函数的矩展开为图的子结构计数，利用正则图的组合性质（短环稀少）来估计。
- **单步交换**：每次只交换一个块，避免高阶项。
- **生成函数**：利用树的生成函数来证明代数恒等式。
- **DBM 短时演化**：利用 [43] 的现成结果，将问题归结为刚性估计。

#### 🔎 结论是否比证明窄

**是的，结论比证明窄**。具体体现在：

1. **d 的上界 N^{1/3−c} 是本质的，但作者没有证明下界 N^c 也是必要的**。作者在引言中承认，当 d 固定时，极端特征值的波动**不**服从 Tracy-Widom（因为短环效应）。但 d 从 N^c 到固定值之间的"相变"位置，本文没有讨论。作者在 Section 7 的 Remark 7.7 中暗示，他们的方法可以推广到 d ≥ (log N)^{4+ε}，但没有给出证明。

2. **Theorem 1.1 只给出了固定 k 的联合分布**。对于 k 随 N 增长的情况（例如 k = N^ε），本文没有结果。这在 DBM 方法中是常见的限制，但对于某些应用（如网络分析中需要同时考虑多个极端特征值）可能不够。

3. **Ramanujan 图的结论（Corollary 1.1）依赖于 Tracy-Widom 分布的精确性质**。作者用的是 Tracy-Widom 分布 P(TW ≤ 0) ≈ 0.69 这个数值事实。这个数值是已知的，但作者没有讨论当 d 接近 N^c 时，收敛速度是否足够快以保证 69% 这个比例。

4. **证明中使用了"特征值间距假设"（gap condition）**。这个假设在 [8] 中也被使用，但本文没有独立验证它。作者通过刚性估计（Theorem 2.2）来间接验证，但刚性估计本身依赖于自洽方程的精度，因此这是一个循环论证的风险。作者在 Section 6 末尾声称可以通过"标准方法"（如 [8, Section 8]）来打破这个循环，但没有给出细节。


### 四、开放问题

以下问题均扎根于本文的具体语句：

1. **固定度数的情形（d = O(1)）**：本文的定理要求 d ≥ N^c，这排除了固定度数。作者在引言中承认："对于固定度数 d ≥ 3，极端特征值的波动是否服从 Tracy-Widom 分布仍然是一个开放问题。"（Introduction, 第 2 段）。这是一个**长期悬而未决**的问题，目前最好的结果是 [16] 的 O((log log N / log N)^2) 集中界，远未达到 Tracy-Widom 的精度。**扎根点**：Introduction 第 2 段。

2. **d 的相变位置**：本文的结果要求 d ≥ N^c，而 [31] 处理了 d ≥ N^{2/3}。在 N^c 到 N^{2/3} 之间，是否存在一个临界度数 d_c，使得极端特征值的波动从 Tracy-Widom 过渡到其他分布？**扎根点**：Introduction 第 3 段（作者提到"中间度数"的情形，但没有给出相变位置的猜测）。

3. **高阶相关函数**：本文只证明了极端特征值的联合分布（固定 k）。对于**极端特征值与特征向量的联合分布**，或者**极端特征值的间距分布**，本文没有结果。**扎根点**：Section 7 的 Remark 7.7（作者提到"可以推广到特征向量"但没有给出细节）。

4. **非均匀正则图**：本文只处理了均匀随机 d-正则图。对于**配置模型**（configuration model）或**随机 d-正则二分图**，本文的方法是否适用？**扎根点**：Introduction 第 4 段（作者提到"我们的方法依赖于正则性，但可能可以推广到配置模型"）。

5. **最优刚性估计的适用范围**：Theorem 2.2 给出了极端特征值的最优刚性，但**中间特征值**的刚性是否也能达到 N^{-2/3}？本文的证明方法（高阶自洽方程）似乎只对极端特征值有效。**扎根点**：Section 2 的 Remark 2.3（作者承认"我们的刚性估计在极端特征值处是最优的，但对于中间特征值可能不是"）。

**提醒**：要确认上述问题是否真的是"开放问题"，建议去读**同一子领域近期约 5 篇论文的引言**（例如 2023–2025 年关于随机正则图谱的论文）。如果多篇论文都指向同一个问题，那就是共识性的 gap；如果各篇论文对同一个问题的表述不一致，那可能是一个"伪 gap"，需要更仔细地界定。
