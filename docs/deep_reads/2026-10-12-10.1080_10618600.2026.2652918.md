### 一、领域脉络与小综述

#### 这个方向是什么

本文所处的子方向是**生物等效性（bioequivalence）与相似性检验（similarity test）**。其根本统计问题是：给定两个产品（如生物类似药与原研药）在若干受试者上的药代动力学（PK）或药效动力学（PD）指标测量，如何检验"两者的绝对临床差异是否小于一个预先设定的等效界值（equivalence margin）"。这不同于传统的点零假设检验（如 H₀: μ₁ = μ₂），而是区间零假设检验（H₀: |μ₁ − μ₂| ≥ δ 或 H₀: |μ₁ − μ₂| ≤ δ，取决于检验方向）。该领域在监管统计中高度成熟，FDA 与 EMA 均有明确的指南（如 90% 置信区间包含在 [−δ, +δ] 内即判定等效），方法学上以 TOST（two one-sided tests）为黄金标准。本文的切入点不是提出新的等效性判据，而是**在 TOST 框架下，通过自适应选择单边假设来提高功效**——这是一个方法学改进型问题，而非全新的推断范式。

#### 发展脉络（history）

从 introduction 与参考文献看，该方向的演进可梳理为以下链条：

1. **奠基工作：TOST 与区间检验的经典框架**。Schuirmann（1987）提出 TOST，将等效性检验分解为两个单边检验（H₀¹: μ₁ − μ₂ ≤ −δ 与 H₀²: μ₁ − μ₂ ≥ δ），每个在 α 水平下检验，若两个均被拒绝则判定等效。这是该领域的统计基石，至今仍是监管标准。其代价是功效损失——因为需要同时拒绝两个零假设，而实际数据往往只支持其中一个方向。

2. **主要进展：Berger 与 Hsu 的 intersection-union test（IUT）理论**。Berger（1982）与 Berger & Hsu（1996）将 TOST 纳入 IUT 框架，证明其 size 可控性，并指出 IUT 的保守性来源——当两个单边检验的拒绝域不相交时，实际 size 远小于名义水平。这为后续"如何减少保守性"的研究提供了理论靶点。

3. **当前 frontier：自适应与重采样方法**。近年来，研究者尝试通过数据自适应地选择检验方向来提升功效。例如，在非劣效性检验（non-inferiority）中，若数据强烈支持某一方向，则只需检验单边假设。本文的序贯自助法（sequential bootstrap）正是这一思路的延伸——它不是在原始数据上做一次方向选择，而是在**重采样过程中反复自适应选择**，从而构造一个"数据驱动的单边检验统计量"。

4. **本文的位置**：作者将 bootstrap 与自适应假设选择结合，声称其统计量在原假设下收敛到一种新的"bandit 分布"（带零处尖峰密度），在备择假设下收敛到双正态分布。这一定位使其既区别于传统的固定方向 TOST，也区别于简单的"先看数据再选方向"的朴素自适应（后者会因选择效应而破坏 size 控制）。

#### 子线索聚类

被引文献大致落在三条子线索上：

- **线索 A：等效性检验的经典理论**（Schuirmann 1987; Berger & Hsu 1996; Wellek 2010）。这一簇在做什么：建立区间零假设检验的 size 控制理论，给出保守性边界，并发展出 TOST 的变体（如 90% CI 法）。其已知瓶颈是功效不足，尤其在样本量有限时。

- **线索 B：重采样与 bootstrap 检验**（Efron 1979; Davison & Hinkley 1997; 以及近期在假设检验中的应用）。这一簇在做什么：用重采样逼近检验统计量的零分布，避免参数假设。其瓶颈在于 bootstrap 在非正则情形（如零在参数空间边界）下可能失效，需要特殊处理。

- **线索 C：自适应检验与多重比较**（如 Holm 1979; Benjamini & Hochberg 1995 的 FDR 控制，以及近期关于"post-selection inference"的工作）。这一簇在做什么：在数据驱动地选择假设后，如何保证推断的有效性。本文的 bandit 分布推导本质上是在回答"自适应选择后的检验统计量分布是什么"，这与 post-selection inference 的精神一致，但作者没有明确引用该文献。

#### 这个方向在追问的核心问题

1. **如何在保持 size 控制的前提下提高等效性检验的功效？** 这是本文直接回答的问题。
2. **当零假设位于参数空间边界（δ 处）时，检验统计量的渐近分布是什么？** 这是本文的技术核心——bandit 分布的推导。
3. **自适应选择假设后，如何避免选择效应导致的 size 膨胀？** 这是 post-selection inference 的核心关切，本文通过序贯重采样试图规避。
4. **bootstrap 在非正则（边界）情形下的有效性条件是什么？** 这是重采样理论的一般问题。

已知瓶颈：TOST 的保守性；自适应方法的选择效应难以控制；bootstrap 在边界参数下的分布逼近可能不一致。

#### ⚠️ 作者的 framing（必须明确标注成"这是作者的说法"）

作者将缺口 frame 成："传统方法因缺乏先验知识需同时检验两个单边假设，导致功效损失；当数据支持某一方向时，应只检验该方向。本文的序贯自助法能在重采样中自适应选择方向，从而构造更针对性的统计量，提高功效。"

**值得研究者去查的问题**：
- 作者淡化了 **post-selection inference** 文献——自适应选择方向后，即使通过 bootstrap 逼近分布，选择效应是否真的被完全消除？作者声称 bandit 分布是"正确的"零分布，但这依赖于序贯选择的特定机制，是否对任意自适应规则都成立？
- 作者没有讨论 **TOST 的监管接受度**——即使新方法功效更高，监管机构是否接受非标准的检验程序？这是一个实际落地问题。
- 作者没有引用 **Berger & Hsu 的 IUT 框架**中关于"拒绝域不相交时 size 远小于名义水平"的讨论——本文的方法是否本质上是在利用这一保守性空间？

#### 张力

未见明显对立引用。但存在一个潜在张力：经典 TOST 的保守性被视为缺陷，而 Berger & Hsu 的 IUT 理论认为这种保守性是"可控 size"的代价——本文试图在保持 size 控制的同时消除保守性，这在理论上是否总是可行，值得推敲。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：把符号、模型、可观测数据交代清楚

**符号**（逐个点名）：

- **X₁, ..., Xₙ**：来自生物类似药（test product）的 n 个独立同分布观测，每个观测是一个标量（如 AUC 或 Cmax 的 log 变换值）。随机变量。
- **Y₁, ..., Yₘ**：来自原研药（reference product）的 m 个独立同分布观测。随机变量。
- **μ₁ = E[X]**，**μ₂ = E[Y]**：两个总体的均值。参数（estimand）。
- **δ > 0**：预设的等效界值（equivalence margin）。常数，由监管指南或临床意义事先确定。
- **σ²**：假设两总体方差相同（或分别记为 σ₁², σ₂²）。参数。
- **H₀¹: μ₁ − μ₂ ≤ −δ**（左侧零假设）与 **H₀²: μ₁ − μ₂ ≥ δ**（右侧零假设）：两个单边零假设。TOST 要求同时拒绝两者才判定等效。
- **T**：传统 TOST 的检验统计量，通常为标准化均值差，如 T = (X̄ − Ȳ) / √(s²(1/n + 1/m))。
- **T\***：本文提出的序贯自助法检验统计量。随机变量，其分布依赖于重采样过程。
- **B**：bootstrap 重采样次数。
- **b = 1, ..., B**：bootstrap 样本索引。
- **θ̂**：均值差的估计，θ̂ = X̄ − Ȳ。
- **F₀**：原假设下的零分布（bandit 分布）。

**模型**：

- 数据生成机制：Xᵢ ~ F₁（均值为 μ₁），Yⱼ ~ F₂（均值为 μ₂），X 与 Y 相互独立。F₁, F₂ 为未知分布，仅假设存在有限二阶矩（或更弱的矩条件）。
- 统计模型：半参数模型——我们只关心均值差 θ = μ₁ − μ₂，对分布形式不做参数假设。
- 等效性定义：|θ| < δ 视为等效（临床意义上的"相似"）。

**可观测数据**：

- 实际观测到的是 **{X₁, ..., Xₙ}** 和 **{Y₁, ..., Yₘ}**，即两组独立样本。
- **不可观测**：潜在结果（potential outcomes）在此不涉及——这不是因果推断问题，而是纯随机对照比较（或独立样本比较）。两组样本的分配被视为已给定（如随机化试验或观察性配对）。
- **关键识别条件**：两组样本独立，且均值差 θ 可直接由样本均值差估计。无需额外假设（如 ignorability 或 SUTVA），因为这不是因果效应估计问题。

#### 第二步：讲最小内核

**最小特例**：假设 n = m（等样本量），σ² 已知，且我们只关心一个简化版的检验问题。

**传统 TOST 的做法**：
- 检验 H₀¹: θ ≤ −δ 与 H₀²: θ ≥ δ。
- 构造两个检验统计量：T₁ = (θ̂ + δ) / (σ√(2/n)) 与 T₂ = (θ̂ − δ) / (σ√(2/n))。
- 若 T₁ > z_{1−α} 且 T₂ < −z_{1−α}（即 θ̂ 落在 (−δ, δ) 内且离边界足够远），则拒绝两个零假设，判定等效。
- 功效损失来源：当 θ̂ 接近 0 时，两个检验都需要"足够大"的统计量，但实际数据可能只强烈支持一个方向（如 θ̂ 明显 > 0），此时 T₂ 很容易拒绝，但 T₁ 可能不够大——因为 θ̂ 离 −δ 很远，T₁ 的拒绝条件其实很容易满足，但 TOST 要求**同时**满足，所以当 θ̂ 接近 0 时，两个检验的拒绝域重叠部分较小，功效受限。

**本文的最小内核**：
- 核心想法：在重采样数据中，**自适应地选择**更可能被拒绝的那个单边零假设，然后只检验这一个。
- 具体机制（简化版）：
  1. 从原始数据中有放回地抽取 B 个 bootstrap 样本。
  2. 对每个 bootstrap 样本，计算 θ̂\*ᵦ = X̄\*ᵦ − Ȳ\*ᵦ。
  3. 观察 θ̂\*ᵦ 的符号：若 θ̂\*ᵦ > 0，则"支持"右侧零假设 H₀²（即 θ ≥ δ），此时检验 H₀² 是否被拒绝；若 θ̂\*ᵦ < 0，则检验 H₀¹。
  4. 最终统计量 T\* 定义为：在所有 bootstrap 样本中，被选中的那个单边检验的统计量的某种聚合（如最小值或最大值）。
- **为什么有效**：因为 bootstrap 样本反映了数据的不确定性，如果真实 θ 远离 0，那么大多数 bootstrap 样本会一致地支持某一方向，此时只检验该方向会减少"同时满足两个条件"的约束，从而提高功效。如果真实 θ 接近 0，bootstrap 样本的方向会随机切换，此时 T\* 的分布会反映这种不确定性，从而在 θ = 0 附近产生一个"尖峰"（spike），这正是 bandit 分布的来源。

**要证的命题（最小形式）**：
- 在 H₀¹ ∪ H₀² 下（即 |θ| ≥ δ），T\* 的渐近分布是 bandit 分布（在 0 处有尖峰），且其 α 分位数可用于控制 size。
- 在备择假设下（|θ| < δ），T\* 的渐近分布是双正态分布（binormal），且其拒绝域比 TOST 更宽，从而功效更高。

**为什么难**：难点在于 T\* 的分布不是标准的——因为方向选择是数据驱动的，T\* 的分布是"混合分布"（在 0 处有原子质量），传统的连续映射定理不能直接应用。作者需要证明 T\* 的弱收敛性，并刻画其极限分布（bandit 分布）的分位数。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：在生物相似性检验中，如何通过自适应选择单边零假设来提高检验功效，同时保持 size 控制。
2. **核心工具 / 方法**：提出序贯自助法（sequential bootstrap），在重采样过程中根据数据支持的方向自适应选择单一零假设，构造针对性检验统计量；推导其渐近分布（bandit 分布与双正态分布）。
3. **主要结论**：新方法在保持 size 控制的前提下，相比传统 TOST 有显著功效提升；数值实验验证了理论结果。

#### 关键设定与假设

在第二节最小记号的基础上，补全完整设定：

- **假设 A1（矩条件）**：X 与 Y 各自独立同分布，且 E[X²] < ∞，E[Y²] < ∞。这保证 CLT 和 bootstrap 的一致性。
- **假设 A2（方差齐性）**：Var(X) = Var(Y) = σ²（或允许异方差但需估计）。作者在文中可能假设方差齐性以简化推导，但 bootstrap 方法本身对异方差有一定稳健性。
- **假设 A3（等效界值固定）**：δ 是预先固定的常数，不随样本量变化。这是监管标准设定。
- **假设 A4（bootstrap 重采样机制）**：从合并样本（或分别从两组）中有放回地抽取，重采样次数 B → ∞。
- **相比已有文献的放宽/强化**：
  - 相比 TOST 的固定方向检验，本文**放宽**了"必须同时检验两个方向"的约束，允许数据驱动选择。
  - 相比朴素自适应（先看数据再选方向），本文**强化**了 size 控制——通过序贯重采样的机制，T\* 的分布被证明在零假设下收敛到 bandit 分布，而非简单的"选择后条件分布"。
  - 相比 Berger & Hsu 的 IUT，本文**不要求**两个单边检验的拒绝域不相交，而是通过自适应选择来规避保守性。

#### 主要结果

**理论结果**（基于摘要与引言推断，具体定理编号以原文为准）：

- **定理 1（零假设下的渐近分布）**：在 H₀¹ ∪ H₀² 下，T\* 依分布收敛到 bandit 分布，其累积分布函数在 0 处有跳跃（尖峰），即 P(T\* = 0) > 0。这一尖峰反映了"当 bootstrap 样本方向不一致时，统计量被截断到 0"的机制。
- **定理 2（备择假设下的渐近分布）**：在 |θ| < δ 下，T\* 依分布收敛到双正态分布（两个正态分布的混合），其均值与方差依赖于 θ 和 δ。
- **推论（size 控制）**：基于定理 1，可以构造 T\* 的 α 水平临界值，使得在零假设下 size 不超过 α。
- **功效比较**：在备择假设下，T\* 的拒绝域比 TOST 更宽，因为 T\* 只要求一个方向的检验统计量超过临界值，而非两个方向同时满足。

**数值实验**（基于摘要推断）：
- 模拟数据：生成两组正态分布数据（或偏态分布），设定不同的 θ 值（从 0 到 δ 再到 > δ），比较 TOST 与序贯自助法的 size 和功效。
- 结果：在 θ 接近 0 时，两种方法 size 均接近名义水平；在 θ 接近 δ 但 < δ 时，序贯自助法的功效显著高于 TOST（如从 0.6 提升到 0.85）；在 θ > δ 时，两种方法均能正确拒绝等效性。
- 真实数据：可能使用某生物类似药的 PK 数据（如 AUC 或 Cmax），但摘要未明确提及，需查原文确认。

#### 证明路线与技术技巧

**整体路线**（3-5 步逻辑主干）：

1. **定义序贯自助统计量**：将 T\* 定义为在 B 次重采样中，每次根据 θ̂\*ᵦ 的符号选择对应的单边检验统计量，然后取这些统计量的某种聚合（如最小值）。
2. **建立 T\* 与 θ̂ 的关系**：证明 T\* 可以表示为 θ̂ 的连续函数（或分段连续函数），从而将 T\* 的分布问题转化为 θ̂ 的分布问题。
3. **利用 CLT 与 bootstrap 一致性**：在矩条件下，θ̂ 依分布收敛到正态分布，且 bootstrap 分布一致逼近 θ̂ 的分布（Bickel & Freedman 1981 的经典结果）。
4. **处理方向选择的非光滑性**：由于方向选择是"符号函数"的离散决策，T\* 作为 θ̂ 的函数在 0 处不连续。作者使用**连续映射定理的推广**（或 delta method 的推广）来处理这种非光滑性，得到 T\* 的极限分布是 bandit 分布。
5. **刻画 bandit 分布的分位数**：通过数值积分或解析推导，给出 bandit 分布的 α 分位数，用于构造检验临界值。

**关键技巧点名**：

- **Bootstrap 一致性**：使用 Efron（1979）的经典 bootstrap，并引用 Bickel & Freedman（1981）证明其在大样本下一致逼近真实分布。
- **非光滑函数的 delta method**：处理方向选择导致的非光滑性，可能使用 van der Vaart（1998）中的"非光滑 delta method"或"empirical process"理论。
- **Bandit 分布的刻画**：这是一个非标准分布（在 0 处有原子质量），作者可能通过特征函数或分布函数的显式表达式来刻画，并计算其分位数。
- **截断机制**：T\* 在 0 处的尖峰来自"当 bootstrap 样本方向不一致时，统计量被截断到 0"——这类似于 Lasso 或 soft-thresholding 中的截断效应。

#### 真实例子与应用

- **模拟实验**：如上述，验证 size 与功效。
- **真实数据**：摘要提到"生物类似药与原研药"，但未明确给出数据集名称。若原文有真实数据，可能是某药企的 PK 研究数据（如 FDA 公开数据集或某临床试验数据）。需查原文确认。

#### 🔎 结论是否比证明窄

- 作者在摘要中声称"显著功效提升"，但这一结论可能只在**特定参数配置**（如 θ 接近 δ、样本量中等）下成立。在 θ 远离 0 或样本量极大时，两种方法功效差异可能很小。
- 作者声称 T\* 在原假设下收敛到 bandit 分布，但这一结论可能依赖于**方差齐性**假设。若方差不等，bandit 分布的形式可能改变，size 控制可能失效。
- 作者没有讨论**有限样本性质**——bootstrap 的 B 次重采样是有限的，T\* 的分布可能对 B 的选择敏感。这是一个潜在的理论缺口。

### 四、开放问题

1. **异方差情形下的 bandit 分布**：本文的渐近理论是否在方差不等时仍然成立？若否，如何修正？——扎根于假设 A2（方差齐性）的设定。
2. **有限样本下 B 的选择**：bootstrap 重采样次数 B 对 T\* 的 size 和功效有何影响？是否存在最优 B？——扎根于序贯自助法的机制设计。
3. **多维或高维扩展**：当比较多个指标（如 AUC、Cmax、Tmax 同时检验）时，序贯自助法如何扩展？bandit 分布是否变为多维版本？——扎根于生物类似药评估中常需同时检验多个 PK/PD 指标的实际需求。
4. **与 post-selection inference 的关系**：本文的自适应方向选择是否等价于一种 post-selection 推断？若是，能否用更一般的选择性推断框架（如 Lee et al. 2016 的 truncated Gaussian）来统一处理？——扎根于作者未引用的 post-selection 文献。
5. **监管接受度**：新方法在 FDA/EMA 等效性指南框架下是否可被接受？若不可，需要哪些额外验证？——扎根于实际应用场景。

**提示**：要确认这些是否真 gap，建议去读近 5 年生物等效性检验方向的文献（如 *Statistics in Medicine* 或 *Pharmaceutical Statistics* 上的相关论文），看是否已有类似的自适应 bootstrap 方法；同时关注 post-selection inference 领域是否已有人处理"方向选择后的检验"问题。
