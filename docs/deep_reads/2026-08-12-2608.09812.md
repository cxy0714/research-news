### 一、领域脉络与小综述

#### 这个方向是什么

这个子方向是**有限总体因果推断中的最优实验设计与估计**。核心问题是：给定一个有限总体（N个单元），每个单元有固定的潜在结果Yi(0)和Yi(1)，研究者要设计一个随机化实验（选择分配机制δ）和一个估计量ˆβ，以最小化估计平均处理效应（ATE）β = (1/N)∑(Yi(1)-Yi(0))的**最坏情况均方误差（MSE）**。这里的“最坏情况”是对抗性的——研究者不知道潜在结果的具体值，只能假设它们落在某个已知的集合（如[L,U]^2N）中。这个方向当前处于**成熟但仍有突破空间**的阶段：经典结果（如完全随机化+差分之差）已被广泛接受，但本文证明，当潜在结果有界时，这个经典处方不再是最优的。

#### 发展脉络（history）

**奠基工作（1950s-1980s）**：
- **Godambe (1955)**：证明在广泛的抽样设计和无限制总体值下，不存在一致最小方差的线性无偏估计量。这奠定了“没有免费午餐”的基调。
- **Godambe and Joshi (1965)**：在无偏估计量类中，证明了Horvitz-Thompson估计量的可容许性（admissibility）。这是设计无偏估计的黄金标准。
- **Bickel and Lehmann (1981)**：对有限总体离散度施加界，证明在简单随机抽样下样本均值是minimax的。这是对无界情形的一个早期minimax结果。
- **Hodges and Lehmann (1982)**：**最直接的前身**。证明如果所有有限总体值都在已知区间内，则简单随机抽样下的minimax估计量将样本均值向区间中点收缩；并且简单随机抽样+该估计量在所有抽样和估计策略中是minimax的。本文的核心逻辑（有界支持+中点调整+收缩）直接继承于此。

**现代minimax结果（2018-2023）**：
- **Kallus (2018, 2021)**：证明当相关条件均值类为置换对称时，完全随机化是minimax的（Kallus, 2021）；同时发展了基于核分配的协变量平衡设计（Kallus, 2018）。这些结果**支持完全随机化**，但假设潜在结果无界。
- **Bai (2023)**：在置换不变性下证明完全随机化+差分之差是minimax最优的。这是对无界情形的正式minimax证明。
- **Bai (2022)**：在等概率处理的分层设计中，证明适当构造的配对设计是最优的。这展示了**分层可以改进完全随机化**，但同样假设无界。

**当前frontier与本文位置**：
- **Aronow and Lopatto (2026)**：**最接近的当代工作**。研究有限总体总和（而非ATE）的minimax无偏估计，假设每个单元的结果有已知（可能单元特异）的支持区间。他们证明：当且仅当包含指标两两独立时，中点差分的Horvitz-Thompson估计量达到下界。本文与之共享“有界支持+中点调整”逻辑，但有两个关键差异：(1) 本文是因果设定（从每对潜在结果中“各取一个”）；(2) 本文不限制无偏性，最终优化所有可测估计量。
- **本文（Hull, 2026）**：证明当潜在结果有界时，**独立随机分配**（而非完全随机化）与**中点中心化结果对去均值处理的回归（无截距）** 的组合达到minimax最优。这**反转**了无界情形下的经典结论。

#### 子线索聚类

1. **无界潜在结果下的minimax最优性**：Kallus (2018, 2021)、Bai (2023) 支持完全随机化+差分之差。这些工作假设潜在结果无界（或仅受置换对称性约束），结论是平衡设计最优。
2. **有界结果下的minimax抽样与估计**：Hodges and Lehmann (1982)、Aronow and Lopatto (2026)、本文。这些工作利用有界支持，得到独立随机化（或两两独立包含）最优，且估计量涉及中点调整或收缩。
3. **利用协变量信息改进设计**：Bai (2022)、Tabord-Meehan (2023)、Harshaw et al. (2024)。这些工作使用基线协变量或前期实验数据来改进完全随机化，但通常不假设结果有界。本文的Proposition 3（配对随机化最坏情况MSE翻倍）可视为对这类方法的一个**警示**：当分层不具预后信息时，过度平衡可能代价高昂。
4. **去均值估计量（recentered estimators）**：Borusyak and Hull (2023, 2026)、Borusyak et al. (2026)。这些工作发展基于设计的识别与估计方法，使用去均值处理变量。本文的ˆβ*估计量（中点中心化结果对去均值处理的回归）直接继承于此线索。

#### 这个方向在追问的核心问题

1. **什么分配机制和估计量组合在minimax意义下最优？** 经典答案是“完全随机化+差分之差”，但本文证明这依赖于无界假设。
2. **有界支持如何改变最优设计？** 核心洞察：当结果有界时，处理份额的随机性本身携带信息，因为对抗者无法通过让结果任意大/小来放大估计误差。
3. **非线性估计量能否进一步改进？** 本文的Theorem 1和Corollary 1证明可以，但改进幅度随N增大而衰减。
4. **如何将预后信息（如协变量、分层）纳入minimax框架？** 本文的结论（配对随机化最坏情况MSE翻倍）与Bai (2022)的结论（配对设计在等概率分层中最优）看似矛盾——但这是因为后者假设了预后信息（配对基于基线结果），而本文的minimax分析没有。这指向一个开放问题：如何将预后结构纳入minimax框架？

#### ⚠️ 作者的framing

**作者把缺口frame成什么**：作者声称“完全随机化的形式最优性取决于研究者没有潜在结果的先验界”——即经典结果（Kallus 2021, Bai 2023）的成立条件是潜在结果无界。一旦有界，最优设计就反转了。作者把自己定位为“补充这些分析，它们让结果位置无限制”（原文：“My results are best viewed as complementing these analyses which leave outcome location unrestricted”）。

**哪些竞争路线被淡化或回避了**：
- **Bai (2022)的配对设计最优性**：作者在Proposition 3中展示配对随机化最坏情况MSE翻倍，但立即承认“minimax分析可能过于悲观，因为它没有纳入潜在结果在配对内相似性的先验信息”。这实际上回避了Bai (2022)的核心论点——当配对基于预后信息时，配对设计确实最优。
- **Harshaw et al. (2024)的Gram-Schmidt Walk设计**：该设计在协变量平衡与最坏情况稳健性之间做显式权衡。作者仅在脚注中提及，未深入比较。

**什么明显该被引/该存在、却没出现在intro里**：
- **de Chaisemartin (2024)**：该文在分层实验中，假设分层特异ATE有界，推导minimax线性组合。这与本文的“有界ATE”逻辑高度相关，但作者仅在脚注6中提及，未在正文中展开比较。
- **Wu (1981)和Bickel and Herzberg (1979)**：关于随机化对模型误设的稳健性。作者在脚注5中提及，但未深入讨论这些工作与本文的关联（如独立随机化作为对抗未知依赖的保护）。

#### 张力

未见明显对立引用。但有一个**隐含张力**：Bai (2022)证明配对设计在等概率分层中最优（假设预后信息），而本文Proposition 3证明配对设计最坏情况MSE翻倍（无预后信息）。这并非矛盾——它们在不同假设下成立——但指向一个关键问题：**minimax最优性对预后信息的敏感性**。研究者可以追问：在什么条件下，Bai (2022)的结论会反转？本文的minimax框架能否扩展以纳入预后结构？

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据交代清楚

**符号**：
- **N**：有限总体中的单元数（固定）。
- **Yi(0), Yi(1)**：单元i的**潜在结果**（固定但未知）。Yi(0)是未处理时的结果，Yi(1)是处理时的结果。
- **β = (1/N)∑(Yi(1)-Yi(0))**：**平均处理效应（ATE）**，要估计的参数（estimand）。
- **Di ∈ {0,1}**：单元i的**处理分配**（随机变量）。Di=1表示处理，Di=0表示对照。
- **Yi = Yi(0)(1-Di) + Yi(1)Di**：**可观测结果**（随机变量）。这是实际观测到的，取决于分配。
- **δ ∈ Δ({0,1}^N)**：**设计**，即所有可能分配向量上的概率分布。研究者选择δ。
- **ˆβ**：**估计量**，是(D,Y)的函数。研究者选择ˆβ。
- **L, U**：已知的**下界和上界**，满足L < U，且对所有i有Yi(0), Yi(1) ∈ [L,U]。
- **M = (U+L)/2**：**支持中点**。
- **r = (U-L)/2**：**半宽**。

**模型**：
- 这是一个**有限总体**模型：潜在结果Yi(0), Yi(1)是固定的（非随机），但未知。
- 研究者只知道它们落在区间[L,U]内，没有其他分布假设。
- 处理分配Di是随机的，由设计δ控制。
- 可观测数据是(Di, Yi)对，i=1,...,N。

**可观测数据**：
- 研究者**实际能观测到**的是：每个单元i的处理分配Di和结果Yi。
- 研究者**观测不到**的是：每个单元的**两个**潜在结果——只能看到其中一个（取决于Di）。这是因果推断的基本困难。
- 研究者**知道但未观测到**的是：潜在结果的上界U和下界L（已知常数）。

#### 第二步：讲最小内核

**最简特例：N=2，二元结果（L=0, U=1）**

考虑最简单的非平凡情形：只有两个单元（N=2），潜在结果是二元的（L=0, U=1，即Yi(0), Yi(1) ∈ {0,1}）。ATE是β = (1/2)[(Y1(1)-Y1(0)) + (Y2(1)-Y2(0))]。

**可观测数据**：研究者随机分配处理，观测到(D1, Y1)和(D2, Y2)。每个Yi要么是Yi(0)（如果Di=0），要么是Yi(1)（如果Di=1）。

**经典处方（完全随机化+差分之差）**：
- 完全随机化：从{ (0,1), (1,0) }中均匀随机选一个（即恰好一个单元被处理）。
- 差分之差估计量：ˆβ_DM = (Y1 - Y2) × (2D1 - 1)（即处理组均值减对照组均值）。
- 最坏情况MSE：考虑对抗性潜在结果。对抗者可以设Y1(0)=Y1(1)=0, Y2(0)=Y2(1)=1（或反过来）。此时β=0，但ˆβ_DM = ±1，MSE=1。更一般地，可以证明最坏情况MSE = (U-L)^2/(N-1) = 1（因为N=2时N-1=1）。

**本文的处方（独立随机化+中点中心化回归）**：
- 独立随机化：D1, D2独立同分布于Bernoulli(0.5)。这意味着可能得到(0,0)、(0,1)、(1,0)、(1,1)四种分配，每种概率1/4。
- 估计量：ˆβ* = (2/N)∑(2Di-1)(Yi - M) = (2D1-1)(Y1-0.5) + (2D2-1)(Y2-0.5)。（因为M=0.5）
- 最坏情况MSE：同样考虑对抗性潜在结果。设Y1(0)=Y1(1)=0, Y2(0)=Y2(1)=0（即所有结果都是0）。则β=0，且：
  - 若(D1,D2)=(0,0)：ˆβ* = (-1)(-0.5) + (-1)(-0.5) = 1
  - 若(D1,D2)=(1,0)：ˆβ* = (1)(-0.5) + (-1)(-0.5) = 0
  - 若(D1,D2)=(0,1)：ˆβ* = (-1)(-0.5) + (1)(-0.5) = 0
  - 若(D1,D2)=(1,1)：ˆβ* = (1)(-0.5) + (1)(-0.5) = -1
  - MSE = (1/4)(1^2 + 0^2 + 0^2 + (-1)^2) = 0.5
- 更一般地，可以证明最坏情况MSE = (U-L)^2/N = 1/2。

**为什么独立随机化更好？** 在完全随机化下，对抗者可以设一个单元全0、另一个全1，使得差分之差估计量恰好捕捉到这个差异（MSE=1）。在独立随机化下，即使对抗者设所有结果相同，处理份额的随机性也会产生估计误差（因为当两个单元都被处理或都不被处理时，估计量会偏离），但**这个误差的方差被中点中心化控制住了**——因为Yi-M在[L,U]内，其绝对值不超过r=(U-L)/2。对抗者无法通过让结果任意大来放大误差。

**核心数学困难**：在一般N下，证明独立随机化+ˆβ*达到下界的关键是：对于任何满足equivariance条件(2)的仿射估计量，对抗者可以通过将每个单元的两个潜在结果都设为L或U（即“无效应”配置）来迫使MSE至少为(U-L)^2/N。而独立随机化消除了单元间处理分配的负相关，使得这个下界可达。完全随机化则因为处理分配间的负相关（固定处理数），迫使对抗者可以构造一个更坏的配置（一半单元全L、一半全U），使MSE膨胀到(U-L)^2/(N-1)。

### 三、这篇论文做了什么

#### 三句话

1. **研究问题**：在潜在结果已知有界（如二元结果）的有限总体中，估计ATE的最优实验设计与估计问题，目标是最小化最坏情况MSE。
2. **核心工具/方法**：minimax决策理论，结合有限总体抽样理论、中点中心化、以及Hodges-Lehmann型最小不利先验表示。
3. **主要结论**：独立随机分配（而非完全随机化）与中点中心化结果对去均值处理的回归（无截距）的组合达到minimax最优；完全随机化严格次优（MSE膨胀因子N/(N-1)）；配对随机化更差（MSE翻倍）；非线性最优估计量可进一步降低最坏情况MSE 15-30%（中等样本量）。

#### 关键设定与假设

在第二节最小记号的基础上，补全完整设定：

- **有限总体**：N个单元，每个有固定潜在结果Yi(0), Yi(1) ∈ [L,U]，L<U已知。
- **参数**：ATE β = (1/N)∑(Yi(1)-Yi(0))。
- **设计δ**：{0,1}^N上的概率分布。研究者选择δ。
- **估计量ˆβ**：可观测数据(D,Y)的函数。论文先限制为仿射估计量ˆβ = a(D) + b(D)'Y，再推广到所有可测估计量。
- **equivariance条件(2)**：b(D)'(D - (1/2)1) = 1，δ-几乎必然。这确保估计量对中点保持的处理效应平移是等变的（即如果每个处理效应都加t，估计量也加t）。常见估计量（差分之差、OLS、加权最小二乘、匹配估计量）都满足。
- **minimax准则**：inf_{δ,ˆβ} sup_{Y(·)∈[L,U]^{2N}} E_δ[(ˆβ-β)^2]。

**相比已有文献的放宽/强化**：
- **放宽**：不要求无偏性（对比Aronow and Lopatto 2026、Godambe and Joshi 1965）。
- **强化**：假设潜在结果有界（对比Kallus 2021、Bai 2023的无界假设）。
- **等价**：与Hodges and Lehmann (1982)的设定类似，但这里是因果推断（从每对潜在结果中观测一个），而非抽样（从总体中观测一个）。

#### 主要结果

**Proposition 1（核心结果）**：
- **陈述**：在满足equivariance条件(2)的仿射估计量类中，minimax MSE = (U-L)^2/N。达到该界的策略是：独立随机分配（Di iid Bernoulli(0.5)）与估计量ˆβ* = (2/N)∑(2Di-1)(Yi-M)（即中点中心化结果对去均值处理的回归，无截距）。
- **直觉**：对抗者可以通过将每个单元的两个潜在结果都设为L或U（无效应配置）来迫使MSE至少为(U-L)^2/N。独立随机分配消除了单元间处理分配的负相关，使得这个下界可达。
- **必要条件**：N任意（不要求偶数）。估计量必须满足equivariance条件(2)。
- **解决的技术难点**：证明下界时，需要处理对抗者选择的任意端点模式。关键技巧是：对每个固定s∈{-1,1}^N，考虑无效应配置Yi(0)=Yi(1)=M+rsi，然后平均所有2^N种模式。利用∑s=0和∑ss'=I，将风险分解为{a(D)+Mb(D)'1}^2 + r^2||b(D)||^2。再利用equivariance条件和Cauchy-Schwarz得到||b(D)||^2 ≥ 4/N。

**Proposition 2（完全随机化次优）**：
- **陈述**：N为偶数时，在完全随机化下，minimax MSE ≥ (U-L)^2/(N-1) = (N/(N-1))V*。差分之差估计量达到该界。
- **直觉**：完全随机化产生处理分配间的轻微负相关，对抗者可以通过设一半单元全L、一半全U来利用这种相关，使MSE膨胀N/(N-1)倍。
- **技术细节**：下界证明类似Proposition 1，但平均的端点模式限制在∑si=0（平衡模式），且∑ss' = (N/(N-1))P（P是投影到正交补的矩阵）。

**Proposition 3（配对随机化更差）**：
- **陈述**：N=2J个单元分成J对，每对内恰好一个被处理（独立跨对），则minimax MSE ≥ (U-L)^2/J = 2V*。配对固定效应回归估计量达到该界。
- **直觉**：每对内的完美负相关（恰好一个被处理）使对抗者可以在每对内设一个全L、一个全U，每对贡献独立误差(U-L)^2，总MSE翻倍。
- **技术细节**：下界证明利用每对内的处理分配关系（Hj = 2Dj1-1，则2Dj2-1 = -Hj），将风险分解为每对系数差平方和。

**Theorem 1（一般估计量）**：
- **陈述**：在所有可测估计量中，minimax MSE = (U-L)^2 κN，其中κN由有限维凸规划(4)定义。独立随机分配仍然最优，最优估计量ˆβ*_NL = ˆβ* + (U-L)∑(d*_x - 2x/N) px(Z)，其中d*是(4)的解，px(Z)是给定Z下∑Bi=x的概率（Bi独立Bernoulli(Zi)）。
- **直觉**：通过对称化论证（均匀混合所有可能的单元标签置换和潜在结果交换），可以证明独立随机分配是minimax最优的。然后问题简化为在顶点（每个潜在结果为0或1）上优化，这等价于一个有限维凸规划。
- **必要条件**：N任意。不要求估计量满足任何条件。
- **解决的技术难点**：对称化论证（Step 1）需要证明：任何设计+估计量都可以被一个独立随机分配+对称估计量占优。这通过均匀混合所有可能的“交换”变换（交换每个单元的Ai和Ci）和置换变换来实现，然后应用Jensen不等式。

**Corollary 1（最优仿射估计量）**：
- **陈述**：在所有仿射估计量（不要求equivariance）中，minimax MSE = (U-L)^2/(√N+1)^2。达到该界的策略是：独立随机分配与收缩估计量ˆβ*_A = (√N/(√N+1)) ˆβ*。当N>2时，κN < 1/(√N+1)^2，即非线性估计量严格优于最优仿射估计量。
- **直觉**：放弃equivariance条件允许向零收缩（引入偏差），这降低了方差，使最坏情况MSE从(U-L)^2/N降到(U-L)^2/(√N+1)^2。但非线性估计量可以做得更好。

**数值结果（Figure 1）**：
- 非线性最优估计量相对于仿射最优估计量的最坏情况MSE降低：N=100时约30%，N=1000时约15%，随N增大衰减。
- 最优仿射估计量相对于equivariant仿射估计量的降低：N=100时约(100/(10+1)^2)/(1/100) ≈ 0.83，即约17%降低。

#### 证明路线与技术技巧

**整体路线（以Theorem 1为例）**：

1. **归一化**：将问题转化为估计θ = (1/N)∑(Ai+Ci)，其中Ai = (Yi(1)-L)/Δ, Ci = (U-Yi(0))/Δ ∈ [0,1]。β = Δ(θ-1)。风险缩放Δ^2倍。

2. **对称化（Step 1）**：证明可以无损失地限制到独立随机分配和对称估计量。
   - 对每个单元，考虑“交换”变换：交换Ai和Ci，同时交换Di和1-Di（即交换处理状态）。这保持Z和θ不变。
   - 均匀混合所有2^N种交换变换，得到的设计是独立Bernoulli(0.5)分配。
   - 再对单元标签的置换均匀混合，得到对称估计量。
   - 应用Jensen不等式：用条件均值替换随机估计量不增加风险。

3. **下界（Step 2）**：将参数空间限制到顶点（Ai, Ci ∈ {0,1}）。每个顶点由(k,m)刻画：k个(1,1)对，m个混合对，N-k-m个(0,0)对。目标θ_{k,m} = (2k+m)/N。在独立随机分配下，X = ∑Zi的分布是pk,m(x) = 2^{-m} C(m, x-k)。对称估计量由dx = ˆt(z)（当∑zi=x）完全描述。风险是∑pk,m(x)(dx - θ_{k,m})^2。最小化最大风险得到κN。

4. **上界（Step 3）**：构造Bernstein扩展Bd(z) = ∑dx px(z)，其中px(z)是独立Bernoulli(zi)变量之和等于x的概率。证明Bd在[0,1]^{2N}上是逐坐标凸的，因此最大值在顶点达到。取d=d*（(4)的解），则每个顶点风险≤κN，所以整个立方体上的风险≤κN。

5. **最小不利先验表示**：利用minimax定理，κN = max_π min_d ∑π_{k,m} ∑pk,m(x)(dx-θ_{k,m})^2。d*是π*下的Bayes规则，d*_x = E_{π*}[θ_{k,m}|X=x]（当后验概率为正时）。

**关键跳跃点**：
- **对称化论证**：这是最吃功夫的部分。需要证明任何设计+估计量都可以被独立随机分配+对称估计量占优。关键在于“交换”变换保持Z和θ不变，而均匀混合所有交换等价于独立随机分配。这个论证借鉴了Hodges and Lehmann (1982)的类似技巧。
- **逐坐标凸性**：证明Bd在[0,1]^{2N}上最大值在顶点达到。这需要证明Bd对每个Ai和Ci是凸的。证明依赖于：当固定其他坐标时，Bd是Ai的线性函数（当gi=1时）或常数（当gi=0时），而目标θ是Ai的线性函数，因此平方差是凸的。

**技术技巧点名**：
- **对称化（symmetrization）**：通过均匀混合所有可能的变换来简化设计。这是minimax理论中的标准技巧。
- **Bernstein扩展**：将定义在顶点上的规则扩展到整个立方体。这是从Hodges and Lehmann (1982)继承的技巧。
- **逐坐标凸性论证**：证明最大值在顶点达到。这是处理高维立方体上优化问题的常用技巧。
- **minimax定理**：用于建立最小不利先验表示。需要验证紧致性和凸性条件。
- **有限维凸规划**：问题(4)是N+1维凸规划，有O(N^2)个二次约束。可以直接求解（N≤几千）或通过约束生成求解（更大N）。

- **Proposition 1的“minimax”声明**：证明的是“在满足equivariance条件(2)的仿射估计量类中”的minimax性。作者在正文中有时简化为“among affine estimators”，但脚注8指出条件(2)也适用于许多非线性过程（如中位数差、修剪均值差）。严格来说，证明只覆盖了满足(2)的仿射估计量，但作者声称许多常见估计量都满足。
- **Theorem 1的“minimax”声明**：证明的是“在所有可测估计量中”的minimax性。但证明依赖于对称化论证，这要求参数空间在交换和置换下不变——这成立。所以这个声明是严格的。
- **关于完全随机化次优性的猜想**：作者在脚注11中写道“我已在小的N下数值验证了这一点，并猜想它成立，但尚未证明”。所以Theorem 1的结论（独立随机分配最优）并不直接蕴含完全随机化次优——它只证明独立随机分配是最优的之一，但未证明完全随机化不是最优的。作者明确承认这是猜想。
- **非线性改进的渐近衰减**：Figure 1显示非线性改进随N增大而衰减，但作者未给出理论证明（如收敛速度）。这是一个开放问题。
