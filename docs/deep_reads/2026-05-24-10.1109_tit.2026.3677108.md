### 一、领域脉络与小综述

#### 这个方向是什么

本文所处的子方向是**经验过程的均匀（uniform）尾界理论**。其根本的统计问题是：给定一个函数类 F，如何以高概率（≥ 1−e⁻ʳ）同时控制所有 f ∈ F 的经验均值 Eₙf(X) 不超过其真实（或期望）水平加上一个随置信水平 r 增长的偏差项。经典结果（如 DKW 不等式、VC 型一致收敛、Talagrand 集中不等式）给出的界通常依赖于函数类的**最坏情况偏差**（worst-case deviation），即 sup_{f∈F} Var(f) 或 sup_{f∈F} ∥f∥_∞ 等全局量。该方向的成熟度较高——从 1970 年代的 VC 理论到 1990 年代的 Talagrand 集中不等式，再到 2000 年代以来的局部 Rademacher 复杂度（local Rademacher complexity），已经形成了相当完整的工具链。本文试图在这个成熟领域中打开一个新的维度：**将最坏情况偏差替换为每个函数 f 自身的偏差（instance-dependent deviation）**，从而在函数类包含"大多数行为良好、少数异常"的成员时，避免过度保守的均匀界。

#### 发展脉络（history）

1. **奠基工作：VC 理论与熵方法。** 论文引言明确将 VC 维 [VC71; Vap98] 列为复杂度度量的起点。这一阶段的核心是用组合维数（VC 维、伪维数）控制一致收敛速度，得到的界形如 O(√(d/n))，其中 d 是 VC 维。这类界是**最坏情况**的——它对函数类中所有成员一视同仁。

2. **Talagrand 的 γ 泛函与 majorizing measures。** 论文的核心技术工具是 Talagrand 的 generic chaining 方法 [Tal87; Tal14]。γ 泛函（特别是 γ₂）通过分层覆盖（admissible sequences）刻画随机过程的复杂度，比熵积分更精细。Talagrand 的 majorizing measures 定理表明，对高斯过程，γ₂ 与期望上确界是等价的（up to constants）。这一阶段的关键进展是：复杂度度量从"组合维数"转向"度量空间的几何结构"。

3. **Rademacher 复杂度与局部化。** 论文引用了 Koltchinskii–Panchenko [KP00] 和 van der Vaart–Wellner [vdVW12] 的工作，它们用 Rademacher 平均替代熵积分，得到数据相关的界。进一步地，局部 Rademacher 复杂度 [BBM05] 通过考虑"方差较小的子类"来改进界——这是**最接近本文思想的前驱**：它已经意识到不同函数的偏差不同，但局部化仍然是在子类层面做文章，而非逐函数地给出 instance-dependent 界。

4. **比率型经验过程。** 论文引言特别提到 Giné–Koltchinski–Wellner [GKW03] 和 Giné–Koltchinski [GK06] 的比率型经验过程尾界。这类结果通过"切片"（slicing/peeling）函数类，使得每个切片内的函数具有相近的方差，从而获得更精细的界。这是本文的直接前驱——但 [GK06] 的切片方法仍然是在**类**的层面做文章，且要求函数有界（[0,1] 值）。

5. **直接灵感：Lugosi–Mendelson 的 instance-dependent 高斯过程界。** 论文引言明确说其灵感来自 Lugosi–Mendelson [LM24] 关于高斯过程的结果。LM24 对以 centered Euclidean ball 为指标集的高斯过程给出了依赖于查询方向 u 的偏差项 √(uᵀΣu) 的尾界，而非最坏情况 √(tr(Σ))。本文将此思想从高斯过程推广到一般经验过程，这是本文的**直接定位**。

6. **本文的位置**：在上述脉络中，本文处于"从最坏情况界到 instance-dependent 界"的转折点上。它把 LM24 的高斯特例推广到一般经验过程，用 Cramér 函数诱导的范数替代高斯方差，并引入"deflation"步骤来压缩函数类的复杂度。与 [GK06] 的切片方法相比，本文的 deflation 是**逐函数**的，而非逐子类。

#### 子线索聚类

- **线索 A：复杂度度量理论。** 包括 Talagrand 的 γ 泛函 [Tal87; Tal14]、van Handel 的 chaining 与插值方法 [vHan18]、Dudley 熵积分 [Ver18]。这条线索关心的是"如何度量一个函数类/随机过程的复杂度"，是本文的技术基础。
- **线索 B：集中不等式与尾界。** 包括 Boucheron–Lugosi–Massart 的集中不等式专著 [BLM13]、Talagrand 集中不等式、以及比率型经验过程的尾界 [GKW03; GK06]。这条线索关心的是"对单个函数或函数类的上确界，如何给出高概率界"。
- **线索 C：局部化与自适应界。** 包括局部 Rademacher 复杂度 [BBM05]、offset Rademacher 复杂度 [LRS15]、以及 LM24 的 instance-dependent 高斯界。这条线索关心的是"如何利用函数/子类的实际方差来改进界"——**本文属于这条线索**，且是其中最激进的一支（逐函数而非逐子类）。
- **线索 D：大偏差与 Orlicz 范数。** 包括 Varadhan 的大偏差理论 [Var84; DZ10]、Pinelis 的分位数变分近似 [Pin14]、van de Geer–Lederer 的 Bernstein–Orlicz 范数 [vdGL12]、Wellner 的 Bennett–Orlicz 范数 [Wel17]。这条线索为本文提供了"无指数矩"情形下的替代工具。

#### 这个方向在追问的核心问题

1. **如何刻画函数类的"有效复杂度"？** 经典答案是 γ₂ 泛函或熵积分，但这些都是全局量。本文追问：能否用**逐函数**的偏差来替代全局偏差，从而获得更紧的界？
2. **在无界函数、无指数矩的情形下，均匀尾界是否仍然可能？** 经典结果（如 Talagrand 集中不等式）通常要求函数有界或具有指数矩。本文第 5 节试图在 L¹ 情形下给出类似结果。
3. **instance-dependent 界与 minimax 最优性之间是什么关系？** 本文第 4 节通过高斯例子说明，instance-dependent 界可以显著优于最坏情况界，但代价是界的形式更复杂（涉及谱分解）。

#### ⚠️ 作者的 framing（这是作者的说法）

作者在引言中把缺口 frame 成：**"现有均匀尾界均以最坏情况偏差表述，而 LM24 的高斯结果提示我们，instance-dependent 界是可能的且更紧。本文将此推广到一般经验过程。"** 具体来说，作者声称：(i) 通过引入 deflation 步骤，可以将 generic chaining 的参数从"覆盖整个函数类"改为"覆盖 deflated 函数类"，从而降低复杂度项；(ii) 在无指数矩时，用 Cramér 函数诱导的范数替代 Orlicz 范数，仍可得到类似界。**被淡化或回避的竞争路线**：(a) 局部 Rademacher 复杂度 [BBM05] 已经能处理"部分函数方差小"的情形，作者没有系统比较本文与局部 Rademacher 界的优劣；(b) 作者回避了 deflation 映射 A[·] 的构造问题——定理 1 假设存在这样的映射，但如何对一般函数类构造它并未讨论；(c) 第 5 节的 L¹ 结果虽然声称"更一般"，但代价是界的形式高度隐式（依赖样本量 n 的方式不透明）。

**值得研究者去查的问题**：论文引言没有引用 Talagrand 关于经验过程的一般集中不等式（如 [Tal96] 或 [BLM13] 第 12 章），也没有引用 Mendelson 关于局部 Rademacher 复杂度的后续工作（如 [Men14]）。这些文献是否已经包含类似 instance-dependent 的界？另外，LM24 的 Gaussian 结果是否已有后续推广到 sub-Gaussian 情形的工作？

#### 张力

未见明显对立引用。但有一个微妙的张力：**LM24 的 Gaussian 界依赖于高斯过程的特殊结构（方差由协方差矩阵完全刻画），而本文试图在一般经验过程中复制这一结果，但 Cramér 函数诱导的范数并不像高斯方差那样具有清晰的统计解释**。这个张力在论文中未被明确讨论。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

**符号清单**（按类别分组）：

| 符号 | 含义 | 类别 |
|------|------|------|
| X, X₁, …, Xₙ | i.i.d. 随机变量，取值于空间 X | 可观测数据 |
| Eₙ | 经验测度期望：Eₙf(X) = n⁻¹∑ᵢ₌₁ⁿ f(Xᵢ) | 可观测量 |
| F ⊂ ℝ^X | 中心化函数类（零均值） | 参数/未知对象 |
| V | 包含 F 的向量空间 | 结构假设 |
| Eₙf(X) | 经验过程在 f 处的取值 | 随机变量 |
| r ≥ 0 | 置信水平参数（尾概率 e⁻ʳ） | 用户指定 |
| Tᵣ(g) | Cramér 函数诱导的偏差度量：inf_{λ≥0} (r + log E e^{λg(X)}) / λ | 关键工具 |
| Tᵣ(g) | Tᵣ 的偶包络（even envelope），即 max{Tᵣ(g), Tᵣ(−g)} | 关键工具 |
| A : F → F | deflation 映射 | 设计参数 |
| A = {f − A[f] : f ∈ F} | deflated 函数类 | 导出对象 |
| γ(A; r, ℓ, n) | 广义 γ 泛函（见式 (5)） | 复杂度度量 |
| radₛ(A) | A 在 Tₛ 下的半径：max_{a∈A} Tₛ(a) | 复杂度度量 |
| ϱᵣ(g, h) | 伪度量：Tᵣ(g − h) | 度量 |
| ℓ = ⌊log₂(r/3)⌋ | 截断层数 | 技术参数 |
| k | 满足 |A[F]| ≤ eᵏ 的非负整数 | 技术参数 |

**模型**：数据生成机制为 X₁, …, Xₙ ~ i.i.d. P，其中 P 是 X 上的未知概率测度。函数类 F 中的每个函数 f 满足 E f(X) = 0（中心化假设）。**要估计的对象**是 sup_{f∈F} Eₙf(X) 的上尾行为——即找到一个尽可能小的函数 B(r, F, n)，使得 P( sup_{f∈F} Eₙf(X) > B(r, F, n) ) ≤ e⁻ʳ。

**可观测 vs 不可观测**：研究者可以观测到 X₁, …, Xₙ 以及每个 f ∈ F 在样本上的取值 f(Xᵢ)。**不可观测**的是：真实分布 P、函数 f 的真实矩 E f(X)²、以及 Tᵣ(f) 中涉及的 E e^{λf(X)}（除非额外假设）。因此，Tᵣ(f) 本身是一个**理论量**，在实际应用中需要用样本估计（如经验 Cramér 函数），但本文不讨论估计问题。

#### 第二步：最小内核

**核心问题（最简形式）**：设 F 是有限集，|F| = N。对每个 f ∈ F，Chernoff 界给出：

P( Eₙf(X) > T_{r/n}(f) ) ≤ e⁻ʳ。

对 F 取并集界（union bound），得到：

P( ∃ f ∈ F : Eₙf(X) > T_{r/n}(f) ) ≤ N e⁻ʳ = e^{-(r − log N)}。

因此，以概率 ≥ 1 − e^{-(r − log N)}，对所有 f ∈ F 有 Eₙf(X) ≤ T_{r/n}(f)。**这就是最朴素的均匀尾界**——但它的代价是：置信水平从 r 降到 r − log N，即偏差项 T_{r/n}(f) 中的 r 被替换为 r + log N。

**本文的改进**：如果函数类 F 中大多数函数的 T_{r/n}(f) 很小，只有少数函数的 T_{r/n}(f) 很大，那么上述并集界是**保守的**——它让所有函数都承担了 log N 的代价。本文的想法是：**先通过一个 deflation 映射 A[·] 将每个 f 分解为"主体" A[f]（复杂度低）和"残差" f − A[f]（偏差小）**，然后对主体部分用 generic chaining 控制复杂度，对残差部分用逐函数的 Chernoff 界控制偏差。

**最简例子（为什么 deflation 有用）**：设 X ~ N(0, 1)，F = {f_u(x) = ux : u ∈ ℝ, |u| ≤ 1}。对每个 f_u，Tᵣ(f_u) ≈ √(2r) |u|（因为 uX ~ N(0, u²)）。最坏情况偏差是 sup_u Tᵣ(f_u) = √(2r)。但如果我们查询的方向 u 的范数很小，那么 Tᵣ(f_u) 也小。**Instance-dependent 界**应该给出：对每个 u，偏差项 ≈ √(2r) |u|，而非统一的 √(2r)。这正是 LM24 的高斯结果。本文的定理 1 将此推广到一般经验过程：**对每个 f，偏差项是 T_{r/n}(f − A[f])（残差的偏差），而非 T_{r/n}(f)（f 本身的偏差）**。如果 A[f] 捕捉了 f 的"高风险"部分，那么残差 f − A[f] 的偏差就小。

**数学上最难的点**：如何控制残差部分在**所有 f 上一致**的贡献。并集界给出的代价是 log |A|（deflated 类的对数大小），而 generic chaining 给出的代价是 γ 泛函。本文的核心技术贡献在于：**将 γ 泛函的定义从"覆盖 F"改为"覆盖 A"**，从而在 A 的复杂度远小于 F 时获得更紧的界。但代价是引入了额外的残差项 2T_{r/n}(f − A[f])，需要在"deflation 的力度"（A 越小越好）和"残差的大小"（A[f] 越接近 f 越好）之间权衡。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：本文研究经验过程 sup_{f∈F} (Eₙf(X) − T_{r/n}(f)) 的均匀上尾界，目标是获得**依赖于每个函数 f 自身偏差**的 instance-dependent 界，而非传统的最坏情况界。
2. **核心工具/方法**：在标准 generic chaining 论证中引入一个初始的 "deflation" 步骤——通过映射 A : F → F 将函数类压缩为 A = {f − A[f]}，然后对 A 应用广义 γ 泛函（式 (5)），对残差 f − A[f] 应用逐函数的 Chernoff 界。
3. **主要结论**：定理 1 给出以概率 ≥ 1 − 2e⁻ʳ 成立的均匀界 Eₙf(X) ≤ T_{(r+k)/n}(f) + 2γ(A; r, ℓ, n) + min{2T_{(2r+1)/n}(f − A[f]), rad_{(2r+1)/n}(A)}；定理 2 将结果推广到无指数矩的 L¹ 情形；第 4 节通过高斯例子和"中位数排名"例子说明界的最优性或近最优性。

#### 关键设定与假设

- **核心假设**：F 中每个函数的累积生成函数在 0 的邻域内有限（即存在指数矩）。这是 Tᵣ(f) 良定义的前提。
- **deflation 映射 A[·]**：满足两个条件：(i) T_{(r+k)/n}(A[f]) ≤ T_{(r+k)/n}(f)（不增加偏差）；(ii) |A[F]| ≤ eᵏ（值域大小受控）。条件 (ii) 是本文与标准 generic chaining 的关键区别——标准方法要求覆盖 F 本身，本文只要求覆盖 A[F]。
- **与已有文献的对比**：相比 [GK06] 的切片方法（要求函数 [0,1] 有界），本文允许无界函数（只要指数矩有限）；相比 [LM24] 的高斯特例，本文适用于一般经验过程，但代价是界的形式更复杂（涉及广义 γ 泛函而非简单的协方差谱）。
- **被强化的假设**：本文的定理 1 要求 A[F] 有限（或至少可数），这在应用中可能需要额外的离散化步骤。定理 2 虽然放宽到 L¹，但代价是界对 n 的依赖变得隐式。

#### 主要结果

**定理 1（指数矩情形）**：对任意 r ≥ log 2，以概率 ≥ 1 − 2e⁻ʳ，对所有 f ∈ F 有

Eₙf(X) ≤ T_{(r+k)/n}(f) + 2γ(A; r, ℓ, n) + min{ 2T_{(2r+1)/n}(f − A[f]), rad_{(2r+1)/n}(A) }.

**直觉**：三项分别对应：(i) 主体 A[f] 的偏差（被 k 略微放大）；(ii) deflated 类 A 的复杂度（γ 泛函）；(iii) 残差 f − A[f] 的偏差（逐函数）或 A 的半径（最坏情况）。取 min 是因为残差项和半径项可以权衡。

**定理 2（L¹ 情形）**：将 Tᵣ 替换为 T♯_{r,n}(g) = inf_{t∈ℝ} (t + eʳ E((Eₙg(X) − t)₊))，在无指数矩假设下得到类似界。**关键区别**：T♯ 是数据相关的（依赖 Eₙ），因此定理 2 的界是**经验界**，而非理论界。

**推论（高斯例子）**：当 F = {⟨u, ·⟩ : ∥u∥₂ ≤ 1}，X ~ N(0, Σ) 时，定理 1 可以复现 LM24 的界（式 (12)），且常数因子相当。

#### 证明路线与技术技巧

**整体路线（5 步）**：

1. **分解**：将每个 f 分解为 f = A[f] + (f − A[f])，则 Eₙf(X) = EₙA[f](X) + Eₙ(f − A[f])(X)。
2. **控制主体**：对 A[f] 部分，用 Chernoff 界 + 并集界（利用 |A[F]| ≤ eᵏ）得到 EₙA[f](X) ≤ T_{(r+k)/n}(A[f]) ≤ T_{(r+k)/n}(f)，以概率 ≥ 1 − e⁻ʳ。
3. **控制残差（关键步骤）**：对 f − A[f] 部分，需要控制 sup_{a∈A} Eₙa(X)。这里**不能**直接用并集界（因为 A 可能很大），而是用 generic chaining：构造 A 的 admissible sequence (A_ℓ)，将 a 分解为望远镜和 ∑(A_{ℓ+1}[a] − A_ℓ[a])，对每一层用 Chernoff 界 + 并集界。
4. **截断**：由于 Tᵣ 只对指数矩有限的函数有定义，需要对残差进行截断（truncation），将 a 分解为"有界部分"和"尾部部分"。这是 Dirksen [Dir15] 的技巧，本文沿用。
5. **优化**：对 admissible sequence 取 inf，得到 γ(A; r, ℓ, n)；对残差项取 min{2T, rad}，得到定理 1 的最终形式。

**关键技术技巧**：

- **Cramér 函数与 Legendre 变换**：Tᵣ(g) 的定义本质上是 Chernoff 界的逆——它给出了"以概率 ≥ 1 − e⁻ʳ 成立的最大偏差"。本文的关键在于证明 Tᵣ 满足三角不等式（引理 1(iv)），这使得 generic chaining 的望远镜和可以逐项控制。
- **截断 + 并集界的精细平衡**：在步骤 4 中，截断阈值的选择需要平衡"截断后的有界部分的复杂度"和"尾部部分的概率质量"。本文通过引入参数 ℓ = ⌊log₂(r/3)⌋ 来实现这一平衡。
- **偶包络**：Tᵣ(g) = max{Tᵣ(g), Tᵣ(−g)} 的引入是为了处理符号问题——generic chaining 需要对称的伪度量。

**证明的难点**：步骤 3 中，残差 a = f − A[f] 的 Tᵣ(a) 可能远小于 Tᵣ(f)，但**一致地**控制 sup_{a∈A} Eₙa(X) 需要 A 的复杂度。本文的 γ 泛函（式 (5)）将"复杂度"和"偏差"耦合在一起——每一层的伪度量 ϱ_{r_ℓ/n}(·, ·) 依赖于该层的置信水平 r_ℓ，这与标准 γ₂ 不同（标准 γ₂ 的伪度量是固定的）。这种"尺度依赖"的 γ 泛函是本文的技术创新，但也使得界的计算更加困难。

#### 真实例子与应用

**例子 1（高斯向量的边际，第 4.1 节）**：F = {⟨u, ·⟩ : ∥u∥₂ ≤ 1}，X ~ N(0, Σ)。这是 LM24 的问题。本文展示了定理 1 如何复现 LM24 的界（式 (12)），并指出当 Σ 的谱衰减快时，instance-dependent 界显著优于最坏情况界 √(tr(Σ)/n)。**这个例子说明**：deflation 映射 A[f_u] = f_{P_k u}（投影到前 k 个主成分）是自然的选择，残差 f_u − A[f_u] 的 Tᵣ 由 Σ 的尾部特征值控制。

**例子 2（中位数排名，第 4.2 节）**：给定 θ ∈ ℝᵈ 和观测 θ̂ = θ + X（X ~ N(0, Σ)），构造 θ̂ 的 m-th 最大项的置信区间。这里 F 是 θ̂ 的坐标的某种函数类，deflation 映射将 θ̂ 投影到其"前 k 个最大坐标"的子空间。本文证明：当 m = o(d) 时，instance-dependent 界给出的置信区间宽度与 minimax 下界（命题 3）匹配到常数因子。

**例子 3（抽象例子，第 4.2.2 节）**：Y(θ) = inf_{S∈𝒮} sup_u (⟨u, θ⟩ − y*_S(u)) 的估计问题，其中 𝒮 是子空间族。本文指出，只要 Y(θ) 有这种变分表示，instance-dependent 尾界就可以直接应用。这为未来工作提供了一个通用框架。

**这些例子的作用**：它们不是简单的数值实验，而是**理论验证**——证明定理 1 的界在具体问题中可以达到或接近 minimax 最优。特别是例子 2 展示了 instance-dependent 界在"稀疏/低秩"结构中的优势。

#### 🔎 结论是否比证明窄

**是的，存在几处"证明严格、结论泛化"的差距**：

1. **定理 1 的 deflation 映射存在性**：定理 1 假设存在满足条件的 A[·]，但并未给出构造方法。在例子中，A[·] 是显式构造的（投影到主成分/稀疏子空间），但一般函数类如何构造 A[·] 是一个开放问题。作者在引言中暗示"deflation 步骤是通用的"，但证明仅对有限类严格成立。

2. **第 5 节的 L¹ 结果**：定理 2 声称适用于无指数矩的情形，但证明中依赖 T♯_{r,n}(g) 的样本估计（式 (19)），而 T♯ 本身是数据相关的。作者没有讨论 T♯ 的估计误差如何影响最终界——这是一个潜在的 gap。

3. **命题 3 的 minimax 下界**：下界只对高斯位置模型证明，且假设 Σ 已知。在实际应用中 Σ 通常未知，需要估计。作者没有讨论 Σ 估计误差对置信区间覆盖概率的影响。

4. **"最优性"的声明**：作者在 4.2 节末尾声称界"最优到常数因子"，但严格来说，命题 3 的下界只对特定参数类 Θ 成立，且只考虑平方损失。对于更一般的损失或参数类，最优性未经验证。

### 四、开放问题

以下问题均扎根于论文的具体语句，供你自行判断价值：

1. **deflation 映射的自动构造**（扎根于定理 1 的假设 "Let A : F → F be a mapping such that ..."）：是否存在系统化的方法，对给定的 F 自动选择最优的 A[·]？这类似于"如何选择局部 Rademacher 复杂度的半径"——但本文的 deflation 更灵活，也更有挑战性。**可查方向**：van Handel [vHan18] 的插值方法可能提供构造性思路。

2. **L¹ 情形的显式界**（扎根于第 5 节和引理 3）：定理 2 的界依赖 T♯_{r,n}(g)，但 T♯ 的样本估计误差没有被量化。能否给出 T♯ 的估计误差界，从而得到完全显式的、依赖 n 的尾界？**可查方向**：Pinelis [Pin14] 的分位数变分近似可能提供工具。

3. **deflation 与 minimax 最优性的统一**（扎根于命题 3 和 4.2.2 节的抽象框架）：本文的 minimax 下界只对高斯位置模型证明。能否将下界推广到更一般的参数类（如稀疏、低秩、光滑函数类），从而建立 instance-dependent 界的**一般最优性理论**？**可查方向**：LM24 的后续工作、以及局部 minimax 理论。

4. **数据相关的 deflation**（扎根于 2.1 节的 "Data-dependent bounds" 讨论）：本文的 deflation 映射 A[·] 是固定的（不依赖数据）。能否构造数据相关的 Â[·]（如基于样本协方差矩阵的投影），并证明其自适应最优性？**可查方向**：自适应估计中的 Lepski 方法、以及 offset Rademacher 复杂度 [LRS15]。

5. **高阶 U-统计量的 instance-dependent 界**（扎根于引言对经验过程的设定，但未涉及 U-统计量）：本文的框架是否适用于 U-统计量（即 f 是多元函数）？U-统计量的尾界通常涉及 Hoeffding 分解和退化核，deflation 步骤如何与这些结构交互？**可查方向**：你的高阶 U-统计量工作与 generic chaining 的结合点。

**提醒**：要确认上述问题是否是真 gap，建议去读 generic chaining 和局部 Rademacher 复杂度方向的近期综述（如 van Handel 的 lecture notes、以及 Bousquet–Boucheron–Lugosi 的集中不等式综述）的引言部分——如果多个近期工作都指向同一个未解决问题，那大概率是真 gap；如果只有本文提到，则需要谨慎。
