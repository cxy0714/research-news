# A fast and sound algorithm to simplify summations in interventional queries expressions

**作者**: Ivano Lodato, Simran Hiranandani, Aditya Varna Iyer  
**主题**: 因果推断  
**相关性**: 6/10  
**链接**: <https://arxiv.org/abs/2611.18416>

### 一、领域脉络与小综述

#### 这个方向是什么

本文属于**因果推断中识别（identification）公式的代数化简**这一子方向。根本问题是：当 ID 算法（或 do-calculus 的手工推导）给出一个 interventional query 的识别表达式后，该表达式往往包含可以消去的求和项（summation），而保留这些求和项会导致估计时方差增大、计算开销上升，甚至在存在 generalized random zeros（整行零计数）时产生未定义的条件概率。因此，目标是在**不改变表达式所表示的联合分布**的前提下，自动检测并移除可消去的求和项，得到一个更简洁、更利于估计的表达式。该子方向的成熟度属于"应用驱动、理论尚不完整"的阶段——已有可用的工具（R 包 `causaleffect`），但对化简能力的刻画（何时完备、何时不完备）仍缺乏系统性理论。

#### 发展脉络（history）

- **奠基工作：do-calculus 与 ID 算法的完备性**。Pearl (1995) 提出 do-calculus 三条规则；Huang & Valtorta (2006) 证明 do-calculus 对可识别性问题是完备的，即任何可识别的因果效应都存在一串 do-calculus 规则将其化为仅含观测量的表达式。Shpitser & Pearl (2006) 给出构造性的 ID 算法。这一阶段确立了"识别公式存在且可自动生成"，但**未关注公式的简洁性**。
- **主要进展：识别公式的自动化简**。Tikka & Karvanen (2017, JMLR) 提出第一个系统性的化简算法（TK），其核心思路是：通过链式法则（chain rule）将表达式中的因子（terms）合并为联合分布，并在缺失变量处插入因子（insertion），从而将求和转化为边际化（marginalization）并消去。该算法已实现于 R 包 `causaleffect`。TK 的局限在于：它需要搜索幂集来寻找合适的合并方式，且插入变量的选择也依赖搜索，导致计算开销大且可能遗漏某些可消去的求和。
- **当前 frontier：更高效、更完备的化简**。本文（Lodato, Hiranandani, Iyer, 2026）对 TK 做了两点关键修改：(1) 只合并**涉及被求和变量**的因子（participating terms），而非所有因子；(2) 每个因子都写成**最小条件集**形式。这两点修改将幂集搜索简化为单一测试，且插入变量预先固定，从而在保持正确性的同时移除了 TK 未能消去的求和项。作者还证明了：对最小输入项，该算法在连接（join）和插入（insertion）操作下对每个单独消去是完备的。
- **相关但不同的线索：非独立性等式约束**。Richardson, Evans, Robins & Shpitser (2023, AoS) 提出 nested Markov property，刻画了 marginals of DAG models 中**非条件独立**的等式约束（如 Verma constraint）。本文明确将这些约束排除在化简手段之外（见 Section 6 脚注），只使用条件独立性。这是一个值得注意的边界设定。

#### 子线索聚类

1. **识别性判定**（ID 算法、do-calculus 完备性）：Shpitser & Pearl 2006; Huang & Valtorta 2006。回答"能否识别"。
2. **识别公式的代数化简**（本文所在线索）：Tikka & Karvanen 2017; 本文。回答"识别公式能否更简洁"。
3. **非独立性约束的刻画**（相邻但未被本文采用）：Richardson et al. 2023。回答"除条件独立外还有哪些约束可用于化简"。

#### 这个方向在追问的核心问题

- **Q1（化简的完备性）**：给定一个原子表达式（atomic expression），是否存在一个基于条件独立性的化简步骤序列能消去某个求和项？本文给出了对"连接+插入"操作的完备性，但未回答是否存在其他类型的化简步骤。
- **Q2（化简的复杂度）**：如何在不牺牲完备性的前提下，将化简算法的计算复杂度从指数级（幂集搜索）降到多项式级？本文通过"只合并参与因子 + 最小条件集"实现了这一点，但代价是可能遗漏某些需要非参与因子的化简。
- **Q3（化简与估计的交互）**：化简后的表达式在有限样本下的估计性质（方差、偏差）如何？本文引用了作者自己的相关工作（Lodato et al. 2025, arXiv:2511.05755）说明 generalized random zeros 场景下化简的实际必要性，但未给出系统的估计理论分析。

#### ⚠️ 作者的 framing（这是作者的说法）

作者将缺口 frame 成："TK 的搜索式化简虽然正确，但**既慢又不完备**——它可能遗漏可消去的求和项，且搜索幂集的开销随图规模指数增长。" 因此本文的贡献被定位为"显然的下一步"：用两个结构性修改（参与因子 + 最小条件集）将搜索变为单一测试，同时**严格证明**在连接和插入操作下的完备性。被淡化或回避的竞争路线包括：(1) 使用 nested Markov constraints（Verma constraint 等）进行化简——作者承认这类约束存在，但声称"未意识到有使用这类约束消去求和的例子"；(2) 对化简步骤的**全局最优排序**进行搜索——作者承认结果可能依赖消去顺序（Example A.1），但未给出系统性的排序策略。

**值得研究者去查的问题**：作者声称"没有意识到使用 nested Markov constraints 消去求和的例子"——这是一个经验性断言，不是证明。去查一下 Verma constraint 在特定图（如 bow graph）中是否真的无法帮助消去求和，可能是一个切入点。另外，作者对"拓扑一致性"（topological consistency）的放弃（Section 2 脚注 1）意味着他们的算法不要求因子条件集包含祖先，这与 TK 的假设不同——这个放松是否会影响其他性质（如估计的因果解释）？

#### 张力

未见明显对立引用。TK 与本文的关系是"改进"而非"对立"；Richardson et al. 的 nested Markov 框架与本文是"互补但未整合"的关系，而非矛盾。唯一潜在的张力是：TK 假设拓扑一致性（条件集包含祖先），而本文放弃这一假设——这可能导致本文算法在非拓扑一致的表达式上产生与 TK 不同的化简结果，但作者未对此进行系统比较。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据交代清楚

**图模型设定**：
- $G$：有向无环图（DAG），包含有向边（表示直接因果）和双向边（表示潜在共同原因）。
- $V$：图中所有顶点的集合（观测变量）。
- $\pi$：$V$ 上的一个拓扑序，$u < v$ 表示 $u$ 在 $\pi$ 中先于 $v$。
- $P(v)$：观测分布，假设对 $G$ 是**正**的（所有条件概率有定义）且**忠实**的（条件独立与 d-分离一致）。

**干预与查询**：
- $P(y \mid \hat{x})$：interventional query，即在干预 $do(X = x)$ 下 $Y = y$ 的分布。
- ID 算法（Shpitser & Pearl 2006）：输入 $(G, P(v), x, y)$，输出一个仅含观测分布的表达式（若可识别），否则输出 FAIL。

**表达式与项（terms）**：
- **项（term）**：条件分布 $P(W \mid C)$，其中 $W$ 是**头（head）**，$C$ 是**条件集（conditioning set）**，$W \cap C = \emptyset$。
- **原子表达式（atomic expression）**：形如 $\sum_S \prod_i P(V_i \mid C_i)$，其中 $S$ 是求和变量集合，$\prod_i$ 是项的乘积。
- **求和变量（summation variable）**：$S$ 中的变量，被求和消去。
- **参与因子（participating terms）** $P_S$：**定义 2.2**——那些在头或条件集中包含 $S$ 的项。例如，若 $S = a$，则 $P(a)$ 和 $P(c \mid a, b)$ 都是参与因子，而 $P(d \mid c)$ 不是。
- **非参与因子** $O_S = T \setminus P_S$：不包含 $S$ 的项。

**关键概念**：
- **最小条件集（minimal conditioning set）**：**定义 2.1**——条件 $c \in C$ 是**惰性的（idle）**，若 $P(W \mid C \setminus \{c\}) = P(W \mid C)$，即 $W \perp\!\!\!\perp c \mid C \setminus \{c\}$。$C$ 是最小的，当没有条件是惰性的。函数 $\text{Minimize}(W, C, G)$ 反复删除惰性条件直到没有。
- **连接（join）**：两个项 $P(J \mid D)$ 和 $P(V \mid C)$ 通过链式法则合并为 $P(J, V \mid Z)$，其中 $Z$ 是某个条件集。
- **插入（insertion）**：当链式法则需要某个缺失变量的因子时，乘以 $P(M \mid E)$ 再除以它（在求和后），其中 $M$ 是缺失变量，$E$ 是其条件集。
- **消除（elimination）**：将参与因子组装成联合分布 $P(J \mid D)$，其中 $S \in J$ 且 $S \notin D$，然后求和 $\sum_S P(J \mid D) = P(J \setminus \{S\} \mid D)$。

**可观测数据**：观测分布 $P(v)$ 的样本（即 i.i.d. 观测），以及图 $G$ 的结构。**不可观测**：潜在变量（由双向边表示）、干预分布 $P(y \mid \hat{x})$ 本身（只能通过识别公式间接估计）。

#### 第二步：最小内核

**最小内核**：考虑最简单的非平凡例子——**collider 图** $G = a \to c \leftarrow b$，拓扑序 $a < b < c$。查询 $P(c \mid \hat{b})$。

**ID 算法输出**：
$$P(c \mid \hat{b}) = \sum_a P(a) P(c \mid a, b).$$

**为什么这个求和可以消去？** 因为 $a$ 和 $b$ 在图上是 d-分离的（$a \perp\!\!\!\perp b$，因为 collider $c$ 未给定），所以 $P(a) = P(a \mid b)$。于是：
$$P(c \mid a, b) P(a) = P(c \mid a, b) P(a \mid b) = P(a, c \mid b).$$
这里 $P(a, c \mid b)$ 是 $a$ 和 $c$ 在给定 $b$ 下的联合分布。现在 $\sum_a P(a, c \mid b) = P(c \mid b)$，求和消去。

**这个例子的要点**：
1. **参与因子**：$S = a$，参与因子是 $P(a)$ 和 $P(c \mid a, b)$。非参与因子为空。
2. **连接**：$P(a)$ 和 $P(c \mid a, b)$ 在条件集 $\{b\}$ 处连接为 $P(a, c \mid b)$。注意：$P(a)$ 原本没有条件集，但 $P(a) = P(a \mid b)$ 因为 $a \perp\!\!\!\perp b$。
3. **求和**：$\sum_a P(a, c \mid b) = P(c \mid b)$，因为 $a$ 是联合分布的头且不在条件集中。
4. **最小条件集**：$P(c \mid a, b)$ 的条件集 $\{a, b\}$ 是最小的吗？$c$ 依赖 $a$ 和 $b$（因为 $a \to c \leftarrow b$），所以 $\{a, b\}$ 是最小的。$P(a)$ 的条件集 $\emptyset$ 也是最小的。

**这个例子的"数学本质"**：消去求和 $S$ 的关键是**将参与因子组装成一个联合分布，其中 $S$ 是头且不在条件集中**。这需要两个条件：
- **连接条件**（定理 3.1 的 (5) 式）：$J \perp\!\!\!\perp (C \cup \{V\}) \setminus D \mid D$ 和 $V \perp\!\!\!\perp (D \setminus \{V\}) \setminus C \mid C$。直观地说，两个项可以在 $C$ 处连接，当且仅当它们各自的条件集已经包含了所有必要的依赖信息。
- **插入条件**（引理 4.1 的 (b)）：插入的变量 $M$ 必须不依赖 $S$（给定其他条件），即 $M \perp\!\!\!\perp S \mid E_M \setminus \{S\}$。

**为什么本文的算法更快**：TK 需要搜索所有可能的条件集 $Z$（幂集），而本文的定理 3.1 证明：对**最小项**，连接只能在唯一的集合 $C$ 处发生。因此，单一测试就足够了。

**这个最小内核如何推广**：在一般图中，参与因子可能不止两个，且可能有多个求和变量。但核心逻辑不变：**每次消去一个求和变量 $S$，只组装参与因子，用定理 3.1 的单一测试判断连接是否可行，用引理 4.1 判断插入是否可行**。如果测试失败，就跳过 $S$，尝试下一个求和变量。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：ID 算法输出的 interventional query 表达式常包含可消去的求和项，而现有的 TK 化简算法（Tikka & Karvanen 2017）通过搜索幂集来寻找合并方式，既计算开销大（指数级）又可能遗漏可消去的求和。
2. **核心方法**：对 TK 做两点修改——(1) 只合并**参与因子**（包含被求和变量的项），(2) 每个因子保持**最小条件集**——从而将幂集搜索简化为单一测试，且插入变量预先固定。
3. **主要结论**：新算法是**可靠的**（sound，只使用恒等变换），对**最小输入项**在连接和插入操作下对**每个单独消去是完备的**（complete），并能移除 TK 留下的求和项；计算复杂度为多项式级（$O(k^2 n^3)$ 次 d-分离测试）。

#### 关键设定与假设

- **正分布与忠实性**：$P$ 对 $G$ 正且忠实，因此条件独立与 d-分离等价。这是所有基于图的化简算法的标准假设。
- **最小项**：所有项的条件集都是最小的（定义 2.1）。作者证明 ID 算法的输出满足这一性质（Section 2 引用了 Tian & Pearl 的 c-component factorization 引理），且算法在每次求和后通过 `Minimize` 恢复这一性质。
- **拓扑序**：固定一个拓扑序 $\pi$，项的头按 $\pi$ 降序组装。作者假设所有项只条件化在头以下的变量上（Section 2 末尾），这比 TK 的"拓扑一致性"（条件集包含所有祖先）更弱。
- **原子表达式**：算法处理的是单个求和变量 $S$ 的消去，整个表达式可能包含多个求和变量，按降序逐个尝试。

**相比 TK 的放宽/强化**：
- **放宽**：不要求拓扑一致性（条件集包含祖先），只要求条件集在头以下。
- **强化**：要求项是最小的（TK 不要求，因此 TK 的搜索可能被惰性条件误导）。

#### 主要结果

**定理 3.1（唯一连接集）**：设 $P(J \mid D)$ 和 $P(V \mid C)$ 是最小项，$J \cap (C \cup \{V\}) = \emptyset$。则它们可以在某个集合 $Z$ 处连接为 $P(J, V \mid Z)$，当且仅当它们在 $C$ 处连接，即：
$$J \perp\!\!\!\perp (C \cup \{V\}) \setminus D \mid D \quad \text{和} \quad V \perp\!\!\!\perp (D \setminus \{V\}) \setminus C \mid C.$$
此时 $C$ 是唯一的连接集，且 $C$ 是 $P(J, V \mid C)$ 的最小条件集。**直觉**：对最小项，连接集不是搜索出来的，而是由两个项的条件集直接决定的。

**引理 4.1（通过插入消去）**：存在不依赖 $S$ 的项 $t_M$（$M \in R$）使得参与因子可以组装成联合分布 $P(H \cup R \mid L)$，当且仅当：
- (a) 每个参与因子 $P(h \mid C_h)$ 满足 $P(h \mid C_h) = P(h \mid E_h)$，其中 $E_h$ 是链式法则分配给 $h$ 的条件集；
- (b) 每个插入的 $M \in R$ 满足 $M \perp\!\!\!\perp S \mid E_M \setminus \{S\}$。

**命题 5.1（可靠性 + 单消去完备性）**：如果参与因子是最小的且循环完成，则算法输出的表达式等于原表达式（sound）；如果存在一个通过连接和插入的组装能消去 $S$，则循环一定完成（complete for each individual elimination）。

**命题 5.2（计算复杂度）**：一次消去尝试至多进行 $2m$ 次 d-分离测试（$m = |H \cup R| \leq n$），每次测试线性时间，因此单次消去为 $O(n^3)$；整个运行至多 $k(k+1)/2$ 次尝试（$k$ 为求和变量数），总计 $O(k^2 n^3)$。

**与 TK 的对比**：
- TK 对每个连接尝试最多 $2^{|J^\pi \setminus \text{An}^*(V)|}$ 个候选集（指数级），本文只需 1 个。
- 例 2.6 和例 4.3 展示了本文能消去 TK 不能消去的求和（因为 TK 的"全因子组装"策略被非参与因子阻塞，而本文只组装参与因子）。
- 例 5.3 展示了一个完整运行，其中本文消去了 3 个求和中的 2 个，而 TK 一个都消不去。

#### 真实例子与应用

**例 2.6（保留因子阻塞 TK）**：图 $X \to A \to B \to Y$，$X \to Y$（$X$ 是 $A, B, Y$ 的共同祖先），查询 $P(Y \mid \hat{X})$。ID 输出 $\sum_{A,B} P(A) P(B \mid A) P(Y \mid X, B)$。TK 试图消去 $B$ 时，必须组装所有头在 $B$ 和 $Y$ 之间的项，包括 $P(Y \mid X, B)$，其条件集 $\{X, B\}$ 包含 $X$，导致连接失败。本文只组装参与因子 $P(B \mid A)$ 和 $P(Y \mid X, B)$，连接集为 $\{A, X\}$，成功消去 $B$，得到 $\sum_A P(A) P(Y \mid X, A)$（back-door 公式）。

**例 4.2（插入项的条件集）**：图 $v_0 \to v_1 \to v_2 \to v_4$，$v_1 \to v_3 \to v_4$，$v_0 \to v_3$，查询 $P(v_2, v_5 \mid \hat{v}_0, \hat{v}_4)$。ID 输出 $\sum_{v_1} P(v_1 \mid v_0) P(v_2 \mid v_1) P(v_5 \mid v_1, v_4)$。消去 $v_1$ 需要插入 $v_4$，其条件集 $E_{v_4} = \{v_0, v_1, v_2\}$ 由**后加入的** $P(v_2 \mid v_1)$ 决定，而非由 $P(v_5 \mid v_1, v_4)$ 决定。这展示了"插入项的条件集由链式法则整体决定"这一关键点。

**例 5.3（完整运行）**：图 $v_0 \to v_1 \to v_2 \to v_4$，$v_1 \to v_3 \to v_4$，$v_0 \to v_3$，$v_2 \to v_5 \to v_6$，$v_3 \to v_6$，查询 $P(v_4, v_5 \mid \hat{v}_2)$。ID 输出 $\sum_{v_0,v_1,v_3} P(v_0) P(v_1 \mid v_0) P(v_3 \mid v_1) P(v_4 \mid v_0, v_1, v_3) P(v_5 \mid v_1, v_2, v_3)$。本文按降序 $v_3, v_1, v_0$ 尝试：$v_3$ 失败（需要插入 $v_5$，但 $v_5 \not\perp\!\!\!\perp v_3$），$v_1$ 失败（插入 $v_5$ 需要 $v_5 \perp\!\!\!\perp v_1$，失败），$v_0$ 成功（插入 $v_3$，$v_3 \perp\!\!\!\perp v_0 \mid v_1$，成立），得到 $\sum_{v_1,v_3} P(v_1) P(v_3 \mid v_1) P(v_4 \mid v_1, v_3) P(v_5 \mid v_1, v_2, v_3)$。TK 在此图上无法消去任何求和。

**本文为纯理论方法论文，无真实数据实验**。所有例子均为合成图与查询。

#### 🔎 结论是否比证明窄

- **明确承认的局限**：完备性只针对**单个消去**（each individual elimination），不针对**整个消去序列**。例 A.1 展示了消去顺序会影响最终结果：本文的默认顺序（降序）可能不如其他顺序。作者建议用回溯搜索来探索顺序，但未在算法中实现。
- **未证明的猜想**：Section 6 末尾的 conjecture——"没有其他基于条件独立性的步骤能消去求和"——只是猜想，不是定理。作者只证明了"连接+插入"的完备性，未排除其他类型的操作。
- **被泛化的地方**：作者声称算法"对最小输入项完备"，但最小性依赖 `Minimize` 的正确性，而 `Minimize` 的贪心删除策略（逐个删除惰性条件）是否总能找到全局最小条件集，文中未给出证明（只说明"反复删除直到没有"）。在非忠实的分布下，贪心策略可能失败。
- **未处理的边界**：nested Markov constraints（Verma 等）被明确排除，但作者未证明这些约束**不能**帮助消去求和——只是声称"未意识到例子"。

### 四、开放问题

1. **消去顺序的全局最优性**（扎根于例 A.1 和 Section 5 末尾）：本文的默认顺序（降序）不是最优的，例 A.1 展示了不同顺序导致不同结果。要证明什么：是否存在一个多项式时间的顺序选择策略，使得最终表达式在所有可能的顺序中具有最少的求和项？还是说这个问题本身是 NP-hard 的？

2. **非条件独立等式的利用**（扎根于 Section 6 脚注 4）：作者承认 nested Markov constraints（如 Verma constraint）是图模型蕴含的等式约束，但未探索它们能否帮助消去求和。要证明什么：是否存在一个图，其中某个求和项无法通过条件独立消去，但可以通过 Verma-type 约束消去？如果存在，本文的完备性猜想（Section 6 末尾）就被证伪。

3. **`Minimize` 的全局最优性**（扎根于算法 5 的贪心策略）：贪心删除惰性条件是否总能得到全局最小条件集？在忠实分布下，条件独立由 d-分离决定，贪心策略可能失败（删除一个条件可能使另一个条件变得非惰性，反之亦然）。要证明什么：贪心策略的失败案例是否存在？如果存在，是否存在多项式时间的全局最小化算法？

4. **消去序列的完备性**（扎根于 Corollary 6.1 的"单个消去"限定）：本文证明了每个单独消去的完备性，但未证明整个消去序列的完备性。要证明什么：是否存在一个表达式，其中每个单独的消去都可行，但按任何顺序执行都会导致某个后续消去失败？如果存在，需要什么样的全局规划？

5. **与估计理论的连接**（扎根于引言中 generalized random zeros 的动机）：化简后的表达式在 generalized random zeros 存在时的估计性质如何？本文引用了作者自己的相关工作（arXiv:2511.05755），但未给出化简对估计方差、偏差影响的定量分析。要证明什么：化简是否总是降低估计方差？在什么条件下化简可能引入偏差？

**顺带提醒**：要确认上述问题是否是真 gap，建议去读 Tikka & Karvanen 后续工作、以及 nested Markov model 相关文献（Richardson et al. 2023 及其引用）的近期约 5 篇 intro——如果多个独立工作都指向同一个未解决问题，那大概率是真 gap；如果各说各话，则需要更谨慎。
