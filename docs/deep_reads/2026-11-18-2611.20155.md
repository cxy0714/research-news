### 一、领域脉络与小综述

#### 这个方向是什么

本文所处的子方向是**因果推断与生存分析的交叉地带**：在 DAG（有向无环图）框架下，研究时间-事件（time-to-event）响应变量的因果效应分解。具体而言，它关注的是如何将一个协变量对事件发生时间的总效应，分解为"直接效应"（通过自身对风险函数的贡献）与"间接效应"（通过影响其他中间协变量，再间接作用于事件时间）。统计建模上采用 Aalen 加性风险模型（additive hazard model）刻画协变量对事件过程的直接影响，用多元线性回归刻画 DAG 中前层协变量之间的关系。这个子方向的根本问题是：**在生存数据（含右删失）的约束下，如何对因果路径上的效应分量进行非参数估计，并得到可用的极限分布以进行推断。**

该方向的成熟度属于**发展中**：Aalen 模型本身（1978）是经典框架，DAG 因果推断（2000年代后）也已成熟，但将**order-restricted inference（序约束推断）**引入 Aalen 模型并用于因果效应分解，是近两年的新尝试。本文的直接前作是作者自己的 arXiv:2606.23882（2026），即 [5]，本文是它的因果推断延伸。

#### 发展脉络（history）

- **奠基工作**：Aalen (1978) [1] 提出加性风险模型，将协变量对事件过程的影响建模为可加的时间函数 β_k(t)，并给出基于计数过程鞅理论的估计方法。这是整个框架的统计基础——它允许协变量效应随时间变化，且估计方程是线性的，便于后续的序约束投影。
- **序约束推断的理论基础**：Anevski & Hössjer (2006) [4] 建立了**一般随机过程的序约束推断极限理论**，给出了 greatest convex minorant（GCM）及其导数的极限分布，涵盖独立、弱相依和长程相依数据。这一工作为 [5] 和本文提供了"非标准 n^{1/3} 速率 + Chernoff 极限分布"的理论工具箱。
- **直接前作**：Anevski & Merai (2026) [5] 提出 Aalen 模型中参数函数的 order-restricted 估计量——将 Aalen 估计的局部增量投影到单调函数锥上，得到单调的 β_k(t) 估计，并证明了 n^{1/3} 点态收敛速率和 Chernoff 极限分布。**本文的引用语境明确说明**：[5] 的进一步动机是"作为在生存分析中使用图模型的第一步，从而将协变量效应分类为直接与间接效应"。
- **DAG 因果分解的引入**：Fosen et al. (2006) [8] 和 Aalen et al. (2008) [9] 提出在加性风险模型框架下用 DAG 分解直接与间接效应。本文的贡献在于：**将 [5] 的 order-restricted 估计量嵌入这个 DAG 分解框架**，从而允许间接效应中的 β₂(t) 分量具有单调性约束（早发型/晚发型效应），并给出 plug-in 估计量的极限分布。

#### 子线索聚类

被引文献大致落在三条子线索上：

1. **加性风险模型的估计理论**（[1][2][3]）：Aalen 模型的定义、最小二乘估计、计数过程鞅理论。这条线成熟度高，是本文的统计基础。
2. **序约束推断的极限理论**（[4][5]）：从一般随机过程的 GCM 极限理论，到 Aalen 模型中单调参数函数的估计。这条线是本文的方法论核心，[5] 是直接前作。
3. **DAG 因果效应分解**（[8][9]）：在生存分析中引入图模型，区分直接与间接效应。这条线是本文的应用动机，但**注意**：本文引用的 [8][9] 是 2006/2008 年的工作，没有引用更近期的因果中介分析文献（如 VanderWeele 的 mediation analysis 框架），这是一个值得注意的空白。

#### 这个方向在追问的核心问题

1. **如何在不指定参数形式的前提下，估计 Aalen 模型中随时间变化的协变量效应 β_k(t)？** 主流方法是 Aalen 估计器（累积效应 B_k(t) 的线性估计），但直接估计 β_k(t) 需要平滑或序约束。已知瓶颈：非参数估计的收敛速率慢（n^{1/3}），且极限分布非正态。
2. **如何在生存数据（右删失）下识别并估计因果路径上的直接与间接效应？** 主流方法是结构方程 + 计数过程建模，但需要强假设（无未测量混杂、序贯可忽略性等）。已知瓶颈：间接效应是乘积形式 θ₁(t)β₂(t)，两个因子的估计误差会叠加。
3. **序约束（单调性）假设在因果推断中能带来什么统计收益？** 这是本文试图回答的问题——单调性约束将估计速率从 n^{1/2} 降为 n^{1/3}（表面上看是"变差"），但换来了对早发型/晚发型效应的可解释性。**这是一个值得研究者注意的张力**：通常统计推断追求更快的收敛速率，而这里序约束反而降低了速率，但获得了临床可解释性。

#### ⚠️ 作者的 framing（这是作者的说法）

作者将缺口 frame 为："[5] 的工作是第一步，但尚未与 DAG 结合；本文是第二步——将 order-restricted 估计量嵌入 DAG 分解，从而同时处理早发型/晚发型效应与直接/间接效应。" 作者淡化的竞争路线包括：(a) 更现代的因果中介分析方法（如 natural direct/indirect effects 框架），(b) 高维协变量下的 Aalen 模型估计，(c) 非单调性约束下的平滑估计方法。**值得研究者去查的问题**：为什么 [8][9] 之后近 20 年没有人在 Aalen 模型 + DAG 框架下做 order-restricted 推断？是技术障碍还是应用需求不足？

#### 张力

被引工作之间未见明显对立结论。但有一个**隐含张力**：[4] 的序约束极限理论是针对一般随机过程的，而 [5] 将其应用于 Aalen 模型的局部增量时，需要验证计数过程的鞅结构满足 [4] 的条件。本文直接引用 [5] 的定理 3 而不重新验证，这在逻辑上是合理的（因为 [5] 已验证），但读者需要注意：**如果数据生成过程偏离 [5] 的假设（例如协变量随时间变化的路径依赖），n^{1/3} 速率是否仍然成立？** 这是一个未被本文讨论的开放问题。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

**符号清单**（逐个点名）：

| 记号 | 含义 | 类型 |
|------|------|------|
| T_i | 个体 i 的事件发生时间 | 随机变量（潜在，可能被删失） |
| C_i | 个体 i 的删失时间 | 随机变量（可观测） |
| t_i = min(T_i, C_i) | 观测到的随访时间 | 可观测数据 |
| δ_i = 1{T_i ≤ C_i} | 事件是否被观测到（非删失指示） | 可观测数据 |
| N_i(t) = 1{t_i ≤ t, δ_i = 1} | 个体 i 的计数过程 | 可观测数据（由 t_i, δ_i 派生） |
| Y_i(t) = 1{t_i ≥ t} | 个体 i 的风险过程（at-risk indicator） | 可观测数据（由 t_i 派生） |
| X_1(t) | 独立协变量（如基因型、治疗） | 可观测数据（可能时变） |
| X_2(t) | 依赖协变量（中间变量，受 X_1 影响） | 可观测数据（可能时变） |
| h(t) | 个体风险函数（hazard function） | 模型对象 |
| β_k(t) | Aalen 模型中第 k 个协变量的效应函数 | **参数/estimand**（要估计的对象） |
| B_k(t) = ∫₀ᵗ β_k(u)du | 累积效应函数 | **参数/estimand**（实际被估计的对象） |
| θ₀(t), θ₁(t) | 线性回归 X₂ ~ X₁ 的截距和斜率 | **参数/estimand**（要估计的对象） |
| I(t) = θ₁(t)β₂(t) | 间接效应 | **参数/estimand**（目标量） |
| β₁(t) | 直接效应 | **参数/estimand** |
| ε(t) | 回归误差项 | 随机变量（不可观测） |
| M_i(t) | 个体 i 的鞅过程 | 潜在量（用于证明） |
| τ | 固定时间区间终点 | 常数（研究设计） |
| n | 样本量 | 常数 |

**模型**（数据生成机制）：

1. **Aalen 加性风险模型**（式 4）：
   dN_i(t) = Y_i(t){β₀(t) + β₁(t)X₁(t) + β₂(t)X₂(t)}dt + dM_i(t)
   
   其中 M_i 是鞅。直观理解：在时刻 t，处于风险状态的个体 i 发生事件的"瞬时概率"（风险）是协变量的线性组合，系数随时间变化。

2. **协变量结构方程**（式 5）：
   X₂(t) = θ₀(t) + θ₁(t)X₁(t) + ε(t)
   
   即依赖协变量 X₂ 是独立协变量 X₁ 的线性函数加上噪声。

3. **可观测数据**：对每个个体 i，观测到 (t_i, δ_i, X₁_i(t), X₂_i(t))，其中 X 协变量在整个随访期间被记录（或至少在事件/删失时刻被记录）。

**关键点——可观测与不可观测的区分**：
- **可观测**：t_i, δ_i, X₁_i(t), X₂_i(t)（在风险集内个体的协变量值）
- **不可观测/潜在**：T_i（真实事件时间，被删失掩盖）、M_i(t)（鞅过程）、ε(t)（回归误差）

#### 第二步：最小内核

**剥掉所有一般性假设后，本文的核心数学问题是什么？**

考虑最简单的设定：**两个协变量，X₁ 是二值治疗指示（0/1），X₂ 是连续中间变量，β₂(t) 被假设为非增函数（早发型效应）**。数据：n 个独立个体，每个个体有 (t_i, δ_i, X₁_i, X₂_i)。

**要估计的目标量**：间接效应 I(t₀) = θ₁(t₀)β₂(t₀)，在某个固定时间点 t₀。

**估计步骤**：
1. 用 Aalen 最小二乘估计器得到累积效应 B̂₂(t)，然后通过局部增量得到 β₂ 的初步估计。
2. 将 β₂ 的初步估计投影到非增函数锥上，得到 order-restricted 估计量 β̃₂(t)。
3. 用 OLS 回归 X₂ ~ X₁ 得到 θ̂₁(t₀)。
4. Plug-in：Î(t₀) = θ̂₁(t₀)β̃₂(t₀)。

**核心数学命题（本文定理 3.2 的本质）**：

> 在适当正则条件下，n^{1/3}·c(t₀)·(Î(t₀) − I(t₀)) 依分布收敛到 θ₁(t₀)·S'(−s² + w(s))|_{s=0}，其中 w 是双边布朗运动，S 是 GCM 算子。

**为什么这个命题成立（直觉）**：
- θ̂₁ 以 n^{1/2} 速率收敛（标准 OLS），β̃₂ 以 n^{1/3} 速率收敛（order-restricted 推断的非标准速率）。
- 由于 n^{-1/2} = o(n^{-1/3})，乘积的收敛速率由较慢的因子 β̃₂ 决定。
- 因此 Î 的极限分布完全由 β̃₂ 的极限分布决定，乘以固定的 θ₁(t₀)。
- β̃₂ 的极限分布来自 [5] 的定理 3：order-restricted 估计量在真值点处的局部极限是 GCM 的导数在 0 处的泛函，即 Chernoff 分布。

**这个最小内核的"数学动作"**：**将一个 n^{1/2} 速率的估计量（θ̂₁）与一个 n^{1/3} 速率的估计量（β̃₂）相乘，证明慢速因子主导极限分布。** 证明的关键是 Slutsky 型论证：θ̂₁ 依概率收敛到 θ₁，而 n^{1/3}(β̃₂ − β₂) 依分布收敛，因此乘积的极限由后者决定。

**为什么 n^{1/3} 而不是 n^{1/2}**：order-restricted 估计量（如 isotonic regression）在真值点处（特别是拐点处）的收敛速率是 n^{1/3}，因为投影到锥上的操作引入了"边界效应"——估计量在约束边界附近的偏差项以 n^{-1/3} 的速率衰减，而不是通常的 n^{-1/2}。这是非光滑约束推断的典型现象。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：在 DAG 框架下，当最终响应变量是时间-事件数据（含右删失）时，如何估计协变量 X₁ 对事件时间的间接效应 I(t) = θ₁(t)β₂(t)，其中 β₂(t) 来自 Aalen 加性风险模型且被施加单调性约束。
2. **核心工具/方法**：将 [5] 中提出的 order-restricted Aalen 估计量（isotonic regression 投影）与 OLS 估计的 θ₁ 结合，构造 plug-in 估计量 Î(t) = θ̂₁(t)β̃₂(t)。
3. **主要结论**：在正则条件下，Î(t₀) 的点态收敛速率为 n^{1/3}，极限分布为 Chernoff 分布乘以常数 θ₁(t₀)；估计的渐近行为完全由 order-restricted 分量 β̃₂ 决定，θ̂₁ 的估计误差在一阶渐近中可忽略。

#### 关键设定与假设

**设定**：
- 右删失生存数据，观测区间 [0, τ]。
- 两个协变量：X₁（独立）、X₂（依赖，受 X₁ 影响）。
- 结构方程：X₂(t) = θ₀(t) + θ₁(t)X₁(t) + ε(t)。
- Aalen 模型：dN_i(t) = Y_i(t){β₀(t) + β₁(t)X₁(t) + β₂(t)X₂(t)}dt + dM_i(t)。
- β₂ 被假设为非增函数（对应"早发型效应"——效应随年龄/时间衰减）。

**假设**（本文明确列出或从 [5] 继承）：
- **假设 2.1**：θ̂₁(t₀) 满足 n^{1/2} 速率的中心极限定理（标准 OLS 正则条件）。
- **假设 3.1**：引用 [5] 的假设 1、2、3，加上 β₂ 在 t₀ 附近可微且 β′₂(t₀) < 0（严格单调递减）。这些条件保证：(i) 设计矩阵和风险过程的局部正则性；(ii) 极限设计矩阵非奇异；(iii) 真值点处约束是"活跃"的（即真值在锥的内部边界上），这是 n^{1/3} 速率成立的关键。

**相比已有文献的放宽/强化**：
- 相比 [5]：本文不假设 θ₁ 已知，而是估计它——这是从纯估计问题到因果推断问题的关键一步。
- 相比 [8][9]：本文引入了 order-restricted 估计量，允许 β₂ 具有单调性约束，而 [8][9] 使用的是无约束的 Aalen 估计。
- **未讨论的假设**：本文没有讨论未测量混杂（unmeasured confounding）问题，也没有讨论 X₁ 的外生性假设是否可检验。这是一个明显的局限。

#### 主要结果

**定理 3.2（核心结果）**：

在假设 2.1 和 3.1 下，
n^{1/3}·c(t₀)·(Î(t₀) − I(t₀)) →ᵈ θ₁(t₀)·S'(−s² + w(s))|_{s=0}

其中：
- c(t₀) = 2^{−1/3}|β′₂(t₀)|^{1/3}(σ²₂)^{−4/3}，σ²₂ 是 [5] 中指定的常数（与设计矩阵和风险过程的极限有关）。
- w 是双边标准布朗运动。
- S 是 GCM（greatest convex minorant）算子，S'(−s² + w(s))|_{s=0} 是 Chernoff 分布（的某种缩放版本）。

**结果的统计含义**：
1. **速率**：n^{1/3} 是 order-restricted 推断的标准速率，比参数估计的 n^{1/2} 慢，但比非参数平滑估计（通常 n^{2/5} 或更慢）快。
2. **极限分布**：Chernoff 分布是非正态的、非对称的，其分位数需要数值计算或查表。这意味着**置信区间的构造不能使用标准正态临界值**。
3. **主导项**：θ₁(t₀) 作为乘数出现，说明间接效应的极限分布是 Chernoff 分布的缩放版本。如果 θ₁(t₀) = 0（即 X₁ 对 X₂ 无效应），则间接效应为 0，极限分布退化。

**证明路线**：
1. **分解**：将 Î(t₀) − I(t₀) 分解为三项：
   - θ̂₁(t₀)(β̃₂(t₀) − β₂(t₀))：主导项，由 order-restricted 估计的极限决定。
   - β₂(t₀)(θ̂₁(t₀) − θ₁(t₀))：n^{1/2} 速率项，乘以 n^{1/3} 后为 o_P(1)。
   - (θ̂₁(t₀) − θ₁(t₀))(β̃₂(t₀) − β₂(t₀))：二阶交互项，o_P(n^{−1/3})。
2. **主导项处理**：利用 [5] 的定理 3，直接得到 n^{1/3}(β̃₂(t₀) − β₂(t₀)) 的极限分布。
3. **余项处理**：利用假设 2.1（θ̂₁ 的 CLT）和 Slutsky 定理，证明余项乘以 n^{1/3} 后趋于零。
4. **合并**：将主导项的极限乘以 θ₁(t₀)（由 θ̂₁ 的相合性），得到最终结果。

**技术技巧点名**：
- **GCM（greatest convex minorant）**：order-restricted 估计的核心工具，将无约束估计投影到凸锥上。
- **双边布朗运动**：出现在局部极限中，因为 order-restricted 估计在真值点附近的偏差由双边随机游走的 GCM 决定。
- **Slutsky 定理**：用于处理不同速率的估计量乘积。
- **鞅中心极限定理**：隐含在 [5] 的证明中，用于处理计数过程的随机波动。

#### 真实例子与应用

**本文没有真实数据应用**。作者在结论部分仅指出"should be highly interesting for modelling complex diseases with time-to-event as response variable"，但未提供任何模拟或实证分析。这是一个明显的短板：**读者无法从本文判断该估计量在有限样本下的实际表现**（例如，n 需要多大才能达到 n^{1/3} 速率的渐近近似？Chernoff 分布的近似在多大样本下才可靠？）。

2. **假设 3.1 要求 β₂ 在 t₀ 处严格单调递减（β′₂ < 0）**，但作者在讨论中暗示该方法适用于"early onset or late onset"效应。如果 β₂ 在 t₀ 处是常数（即效应不随时间变化），则 n^{1/3} 速率可能不成立，极限分布也会不同。**作者没有讨论这种"约束不活跃"的情形**。
3. **θ₁(t) 被假设为确定性函数**，但在实际应用中，X₁ 和 X₂ 的关系可能随时间变化且受未测量混杂影响。作者没有讨论 θ₁(t) 的估计误差对间接效应推断的影响（虽然从证明看，θ̂₁ 的 n^{1/2} 速率确实不影响一阶渐近，但这依赖于 θ₁(t) 的估计是相合的）。
