### 一、领域脉络与小综述

#### 这个方向是什么

本文属于**数学基础（Mathematical Foundations）**与**计算复杂性理论（Computational Complexity）**的交叉地带，具体而言是"**用数理逻辑的标尺来度量优化理论中各类定理的证明强度与计算代价**"。它要回答的根本问题是：优化理论中的三类核心定理——**存在性**（最优解存在）、**收敛性**（算法达到最优解）、**对偶性**（最优性可由对偶问题验证）——各自需要多少"数学公理"才能证明？以及在有限计算资源下，这些定理的"算法实现"又需要多少信息？

这个子方向的成熟度处于**"正在成形"**阶段：逆向数学（Reverse Mathematics）和证明挖掘（Proof Mining）各自已有数十年历史，但将两者系统性地应用于优化理论并绘制统一图谱的工作，在本文之前是缺失的。作者在引言中明确指出："这些结果散落在几个几乎不互相引用的文献中"（"these results are scattered over several literatures that rarely cite each other"），本文的贡献在于**首次将它们汇编成一张连贯的地图**。

#### 发展脉络

**奠基工作**（1960s–1980s）：
- **Friedman**（1967, [65]）创立逆向数学纲领，提出"确定证明某个定理所需的最小存在性公理"这一核心问题。
- **Specker**（1949, [161]）构造了有界递增有理数序列，其极限不是可计算实数——这是本文第4节"梯度下降极限不可计算"的经典源头。
- **Simpson**（2009, [158]）系统化逆向数学的五大子系统（RCA₀ ⊂ WKL₀ ⊂ ACA₀ ⊂ ATR₀ ⊂ Π¹₁-CA₀），为本文提供了分级标尺。

**主要进展**（1990s–2010s）：
- **Kohlenbach**（1993, [93]）开创证明挖掘，从非构造性证明中提取显式界；其与Oliva（[108]）对Chebyshev逼近的分析是"模量提取"的典范。
- **Kohlenbach & Leuştean**（[107]）与**Leuştean**（[125]）对Halpern迭代和渐近正则性给出显式率，这是本文第4节的核心技术来源。
- **Neumann**（[137]）在Weihrauch格中分类了不动点问题的计算难度，证明投影到凸集与求极限等价。
- **Brown & Simpson**（[31]）证明可分Hahn-Banach定理等价于WKL₀，为第6节的对偶性分类奠定基础。

**当前前沿**（2015–至今）：
- **Fearnley et al.**（[54]）证明CLS = PPAD ∩ PLS，将连续优化问题嵌入有限复杂性类。
- **Neri, Pischke & Powell**（[133, 134]）将证明挖掘推广到随机逼近，给出Robbins–Siegmund定理的定量版本。
- **Fernández-Duque, Shafer & Yokoyama**（[58]）对Ekeland变分原理的逆向数学分类，本文第3.6节直接引用。

#### 子线索聚类

这些被引文献大致落在**四条子线索**上：

1. **逆向数学分类**（[52, 80, 158, 65, 66, 79, 31, 85, 1, 154, 167]）：确定优化定理在五大子系统中的精确位置。核心工具是"等价性证明"——证明某定理与某公理在弱基系统上互推。

2. **Weihrauch复杂度**（[29, 137, 121, 92, 142, 27, 22, 23, 28, 26]）：度量"从数据到解"这一映射的计算难度。核心概念是**选择问题**（choice）：闭集选择C_X、凸选择XC_n、连通选择CC_X，它们构成了一个精细的难度层级。

3. **证明挖掘与定量化**（[98, 100, 105, 93, 94, 95, 96, 99, 107, 113, 114, 125, 126, 127, 102, 103, 104, 146, 110, 36, 37, 50, 109, 159, 147, 111, 145, 63, 131, 132, 133, 134, 135, 148]）：从已知证明中提取显式界、率或模量。核心工具是Gödel的功能解释和Kreisel的no-counterexample解释。

4. **有限世界与复杂性类**（[32, 54, 55, 47, 88, 49, 35, 48, 140, 117, 33, 72, 73, 74, 71, 116, 138, 42, 120, 121, 141, 143, 144, 156, 157, 160, 161, 162, 163, 164, 165, 166, 167, 168, 169, 170, 171]）：在多项式时间内可解的搜索问题（TFNP）中定位优化问题。核心概念是PLS（局部搜索）、PPAD（不动点）、CLS（连续局部搜索）。

#### 这个方向在追问的核心问题

1. **存在性定理的"真实成本"是什么？** 连续函数在紧集上取到最大值，这个看似简单的定理，其证明需要WKL₀（弱Kőnig引理）。但凸函数在紧区间上取到最小值，却只需要RCA₀（递归理解公理）。**凸性如何"买断"了紧致性的成本？** 这是第3节的核心问题。

2. **收敛性定理为何比存在性定理"更贵"？** 梯度下降的收敛性（而非仅仅存在极限）等价于ACA₀——算术概括公理，这比WKL₀整整高了一级。**"算法收敛到某点"与"存在某点"之间的逻辑鸿沟，其本质是什么？** 第4节的回答是：**选择**（selection）——算法必须选定一个特定的极限点，而这个选择行为本身携带了图灵跳跃的信息。

3. **对偶性定理在逻辑层级中的位置？** 有限维线性规划对偶在RCA₀中可证，但分离定理在无限维需要WKL₀，严格分离需要ACA₀。**对偶证书的"无限性"如何决定其逻辑强度？** 第6节给出了精确分类。

4. **有限世界的复杂性类与无限世界的逻辑层级如何对应？** CLS = PPAD ∩ PLS的发现表明，连续优化的"困难核心"在有限世界中是局部搜索与不动点的交集。**这种对应关系能否为统计-计算权衡提供新的视角？** 第7节初步探索了这一问题。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

在展开论文的技术细节之前，先建立一套贯穿全文的记号。本文的核心研究对象是**优化问题的逻辑强度**，因此需要同时描述"问题本身"和"证明该问题所需的理论"。

**记号清单**：

| 记号 | 含义 | 类型 |
|------|------|------|
| $f: [0,1]^n \to \mathbb{R}$ | 目标函数 | 可观测数据（作为代码给出） |
| $g = \nabla f$ | 梯度（若$f$可微） | 可观测数据（作为代码给出） |
| $x^* \in \arg\min f$ | 最优解 | 目标量（estimand） |
| $f^* = \inf f$ | 最优值 | 目标量 |
| $(x_k)_{k \geq 0}$ | 梯度下降迭代序列 | 可观测数据（由算法生成） |
| $L$ | 光滑参数：$\|\nabla f(x) - \nabla f(y)\| \leq L\|x-y\|$ | 已知常数 |
| $\varepsilon > 0$ | 精度参数 | 已知常数 |
| RCA₀, WKL₀, ACA₀, ATR₀, Π¹₁-CA₀ | 二阶算术的子系统 | 逻辑框架（证明强度标尺） |
| $\lim$ | 极限算子：收敛序列 → 极限 | 计算问题（Weihrauch度） |
| $C_X$ | 闭选择：非空闭集 → 其中的点 | 计算问题 |
| $XC_n$ | 凸选择：$[0,1]^n$中非空凸闭集 → 其中的点 | 计算问题 |
| $\text{CLS}, \text{PPAD}, \text{PLS}$ | 有限搜索问题的复杂性类 | 计算复杂性标尺 |

**模型**：本文的"模型"不是一个概率模型，而是一个**形式化数学理论**。具体而言：
- **二阶算术的语言**：变量分为数变量（$n \in \mathbb{N}$）和集变量（$X \subseteq \mathbb{N}$）。实数被编码为有理数的快速柯西序列（即一个集）。
- **连续函数**被编码为"邻域条件"的集合：$f$的代码是一个集$F$，使得$(q, r, s) \in F$当且仅当$|x - q| < r \Rightarrow |f(x) - s| < 1$（即$s$是$f(q)$的$1$-逼近）。这种编码使得"$f$在点$x$处的值"是一个$\Sigma^0_1$语句。
- **可观测数据**：研究者能"看到"的是$f$的代码（一个集）、初始点$x_0$（一个实数）、光滑参数$L$（一个有理数）。研究者**看不到**的是最优解$x^*$本身——它必须被构造或证明存在。
- **目标量**：$\lim_k x_k$（梯度下降的极限）、$f^*$（最优值）、$x^*$（某个最优解）。

**关键区分**：本文反复强调"**存在某个解**"与"**算法收敛到某个解**"是逻辑上不同的命题。前者是$\Sigma^1_1$语句（"存在一个实数$x$使得..."），后者是$\Pi^0_3$语句（"对任意$\varepsilon$，存在$N$，使得..."）。这个区分是理解全文的钥匙。

#### 第二步：最小内核

**核心命题（最小内核）**：考虑一维凸光滑函数$f: [0,1] \to \mathbb{R}$，梯度下降迭代
$$x_{k+1} = x_k - \frac{1}{L} f'(x_k), \quad x_0 = 0.$$
问：**证明"序列$(x_k)$收敛"需要什么逻辑公理？**

**答案（本文Theorem 4.1）**：需要ACA₀（算术概括公理）。即：
$$\text{RCA}_0 \vdash \text{"梯度下降收敛"} \iff \text{ACA}_0.$$

**为什么？——直觉解释**：

1. **存在性很便宜**：凸函数在$[0,1]$上取到最小值，这在RCA₀中就可证明（Theorem 3.2(a)）。原因是凸性排除了"局部极小值陷阱"——函数值单调下降的序列必然趋向全局最小值。证明只需要$\Sigma^0_1$归纳，不需要任何集合存在公理。

2. **收敛性很贵**：梯度下降的极限$x_\infty$是**所有迭代的极限**。要证明这个极限存在，需要知道序列$(x_k)$是柯西序列。而"$(x_k)$是柯西序列"是一个$\Pi^0_3$语句：
$$\forall \varepsilon > 0 \ \exists N \ \forall i, j \geq N \ |x_i - x_j| < \varepsilon.$$
要证明这样的语句，需要能够**同时考察所有$i, j$**——这需要集合存在公理。具体地，ACA₀提供了"算术可定义集合"的存在性，足以构造出极限点。

3. **选择是代价的根源**：梯度下降不仅证明极限存在，还**选定了一个特定的极限点**——即从初始点$x_0$出发、沿梯度方向走到的那个点。这个"选择"行为在计算上等价于求一个序列的上确界，而求上确界在Weihrauch格中恰好是$\lim$——图灵跳跃的化身。**"算法收敛"意味着算法必须做出一个选择，而这个选择本身携带了不可计算的信息。**

**最小内核的数学表述**：

设$\mathcal{C}$为所有凸$L$-光滑函数$f: [0,1] \to \mathbb{R}$（有最小值）的集合。定义问题：
$$\text{GDLim}_1: \text{输入}(f, x_0), \text{输出} \lim_{k \to \infty} x_k.$$

**定理（Theorem 4.1的Weihrauch版本）**：$\text{GDLim}_1 \equiv_{\mathrm{sW}} \lim$。

即：梯度下降的极限问题与"求收敛序列的极限"这一问题**强Weihrauch等价**。这意味着：
- 给定一个能求极限的预言机，可以计算梯度下降的极限；
- 反之，给定一个能计算梯度下降极限的预言机，可以计算任意收敛序列的极限。

**为什么这个内核重要？** 因为它揭示了"收敛性"这一计算概念的本质代价：**收敛 = 存在 + 选择**。存在性可以很便宜（RCA₀），但选择——即从众多可能的极限点中挑出一个——需要完整的算术概括能力（ACA₀）。这个洞察贯穿全文：第4节的每个定理都是这个内核在不同算法（近端点法、Halpern迭代、Krasnosel'skiĭ–Mann迭代）中的变体。

**证明思路（三步走）**：

1. **上界（GDLim₁ ≤_sW lim）**：给定极限预言机，模拟梯度下降迭代。每一步迭代需要计算$f'(x_k)$，这需要$f$的代码（一个集）。由于$f$是凸光滑的，梯度下降的迭代是良定义的，且序列收敛。用极限预言机求出极限即可。

2. **下界（lim ≤_sW GDLim₁）**：给定一个收敛序列$(y_k)$，构造一个凸光滑函数$f$，使得梯度下降的极限恰好是$\lim_k y_k$。构造的关键是使用"锯齿函数"：在$[0,1]$上定义一个分段线性凸函数，其极小值点由$(y_k)$决定。梯度下降从0出发，会沿着锯齿"滑向"极限点。

3. **逆向数学版本**：将上述Weihrauch等价"翻译"为逆向数学的等价性。关键步骤是证明"梯度下降收敛"蕴含"算术概括"——这通过构造一个特殊的凸函数$f_y$（如公式(3)）实现，其中$y = (y_k)$是一个递增有界序列。若梯度下降收敛，则其极限给出了$\sup_k y_k$，而求上确界等价于ACA₀。

**这个内核的启示**：对于统计学家而言，这个结果暗示了一个深刻的类比：**在统计推断中，"估计量存在"与"估计量收敛"也是两个逻辑上不同的问题**。前者可能只需要弱假设（如紧致性），后者则需要更强的正则性条件（如唯一性、可识别性）。本文的框架为这种直觉提供了一个精确的逻辑标尺。
