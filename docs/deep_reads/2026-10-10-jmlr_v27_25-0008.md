### 一、领域脉络与小综述

#### 这个方向是什么

本文所处的子方向是**随机优化算法的统计推断**，其根本科学问题是：当我们用随机梯度下降（SGD）或其平均变体（ASGD）求解一个随机优化问题时，如何基于算法输出的迭代轨迹，对真实最优参数构造具有渐近精确覆盖率的置信区间。这个问题的核心困难在于，SGD 迭代序列 $\{x_t\}$ 是强序列相关的非平稳过程，其渐近分布的协方差矩阵结构复杂，且与数据生成分布、步长选取、迭代次数等密切相关。该方向当前处于"方法百花齐放但各有短板"的成熟度阶段：已有方法要么需要二阶信息（Hessian），要么需要复杂的调参，要么计算开销巨大。

#### 发展脉络

- **奠基工作**：**Chen et al. (2020)**（即被引文献[1]）是这一方向的里程碑。它首次系统性地提出了两种SGD推断框架：基于delta方法的plug-in估计（利用 $\tilde{G}_n^{-1}\tilde{S}_n\tilde{G}_n^{-1}$ 形式的协方差估计）和基于batch means的估计。前者统计上有效但需要Hessian信息（$\tilde{G}_n$），这在反向传播只能提供一阶梯度的场景中不可用；后者避免了Hessian但引入了batch数量这一需要仔细调节的超参数。**Polyak and Juditsky (1992)** 的经典工作则奠定了ASGD渐近正态性的理论基础，是几乎所有后续推断方法的前提。
- **主要进展**：**Lee et al. (2022)**（被引文献[2]）提出了random scaling方法，通过构造渐近枢轴统计量避免了显式协方差估计，但需要在线更新 $d\times d$ 的缩放矩阵，内存开销为 $O(d^2)$。**Su and Zhu (2023)**（被引文献[5]）的HiGrad方法通过"分裂"SGD轨迹构造多个子轨迹，利用t分布构造置信区间，但代价是**彻底改变了原始SGD的运行方式**——不再存在一条"原始的"SGD轨迹。**Fang et al. (2018)**（被引文献[6]）提出了在线bootstrap方法，维持 $B$ 条并行扰动轨迹，但为了保证bootstrap有效性需要 $B$ 很大（实验中常取 $B=200$），计算开销是原始SGD的数百倍。
- **理论工具**：**Shao and Zhang (2022)**（被引文献[3]）和**Anastasiou et al. (2019)**（被引文献[14]）分别给出了ASGD和SGD的Berry-Esseen型非渐近界，为后续证明提供了关键工具。这些界给出了 $\sqrt{n}(\bar{x}_n - x^*)$ 与高斯分布之间的Kolmogorov距离的显式上界，是本文证明的核心依赖。
- **当前frontier与本文位置**：现有方法的共同痛点是——**要么需要二阶信息（delta），要么需要大量bootstrap重复（online bootstrap），要么需要修改SGD本身（HiGrad），要么需要 $O(d^2)$ 内存（random scaling）**。本文的位置是：利用"廉价bootstrap"思想（Lam, 2022a; Lam and Liu, 2023; Lam, 2022b），将bootstrap重复次数 $B$ 从"必须很大"（如200）降到"可以很小"（如3），同时保持渐近精确覆盖。其关键洞察是：**不追求用bootstrap分布逼近整个采样分布，而是只利用bootstrap样本与原始估计的联合渐近分布来构造枢轴统计量**，从而将 $B$ 从"蒙特卡洛精度需求"中解放出来。

#### 子线索聚类

1. **基于渐近方差的显式估计**：delta方法（Chen et al., 2020）、batch means（Chen et al., 2020; Zhu and Dong, 2021）。这条线索的优点是统计效率高，缺点是依赖Hessian或需要调节batch参数。
2. **基于枢轴统计量的方法**：random scaling（Lee et al., 2022）。避免了协方差估计，但需要 $O(d^2)$ 内存。
3. **基于轨迹分裂/扰动的方法**：HiGrad（Su and Zhu, 2023）、online bootstrap（Fang et al., 2018）。通过构造多个相关估计量来规避协方差估计，但计算开销大或修改原始算法。
4. **廉价bootstrap**（本文）：属于第三条线索的延伸，但通过理论创新将 $B$ 降到常数。

#### 这个方向在追问的核心问题

1. **如何在无Hessian、无 $O(d^2)$ 内存、不修改SGD的前提下构造渐近有效的置信区间？** 这是本文直接回答的问题。
2. **bootstrap重复次数 $B$ 到底需要多大？** 传统智慧认为 $B$ 要足够大以逼近bootstrap分布，本文证明在特定构造下 $B$ 可以是常数。
3. **SGD迭代的序列相关性如何被bootstrap机制正确处理？** 这是所有bootstrap类方法的理论难点。

#### ⚠️ 作者的 framing（这是作者的说法）

作者在引言中把现有方法的缺陷概括为"要么需要复杂的调参（batch means）、要么需要二阶信息（delta）、要么需要大量计算（online bootstrap）、要么需要修改SGD本身（HiGrad）"，从而将本文定位为"同时解决这些问题的显然下一步"。作者淡化的竞争路线包括：**random scaling方法**——它同样无需Hessian且无需调参，但作者仅以"需要更新 $d\times d$ 矩阵"一笔带过，未深入讨论其在 $d$ 中等维度时是否真的构成瓶颈；**基于鞅近似的方法**——引言中未提及任何基于鞅差分解或扩散近似的推断路线。**值得去查的问题**：为什么引言没有引用 **Zhu and Dong (2021)** 关于batch means的后续改进工作？为什么没有讨论 **Chen et al. (2020)** 中delta方法在广义线性模型外的适用性边界？

#### 张力

未见明显对立引用。各方法之间的差异主要体现在"计算-统计权衡"的不同取舍点上，而非相互矛盾的结论。唯一值得注意的张力是：**Fang et al. (2018)** 的online bootstrap需要 $B=200$ 才能获得良好覆盖，而本文声称 $B=3$ 即可——这并非矛盾，而是因为两者构造置信区间的方式根本不同（前者用bootstrap分布的分位数，后者用t分布），但这一差异在引言中未被明确点出。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

**符号清单**（按类别分组）：

| 类别 | 符号 | 含义 |
|------|------|------|
| **参数/estimand** | $x^* \in \mathbb{R}^d$ | 优化问题(1)的唯一全局最优解，即 $\nabla H(x^*) = 0$ |
| | $H(x) = \mathbb{E}_\zeta[h(x,\zeta)]$ | 总体目标函数（期望损失） |
| | $G(x) = \nabla^2 H(x)$ | 总体Hessian矩阵 |
| | $S(x) = \mathbb{E}[\nabla h(x,\zeta)\nabla h(x,\zeta)^\top]$ | 梯度外积的期望（协方差矩阵） |
| **随机变量/样本** | $\zeta_t$ | 第 $t$ 个独立同分布数据点，来自分布 $P$ |
| | $x_t$ | SGD迭代序列，由(2)定义 |
| | $\bar{x}_n = \frac{1}{n}\sum_{t=1}^n x_t$ | ASGD输出（平均迭代） |
| | $x_n$ | SGD输出（末次迭代） |
| | $W_{t,b}$ | 第 $b$ 条bootstrap轨迹在第 $t$ 步的扰动因子，$W_{t,b} \sim \text{Exp}(1)$ |
| | $x^*_b$ | 第 $b$ 条bootstrap轨迹的ASGD输出 |
| **维数/样本量** | $d$ | 参数维度（固定） |
| | $n$ | 数据量/迭代次数（趋于无穷） |
| | $B$ | bootstrap重复次数（固定，可小至1或2） |
| **潜在量** | $\hat{x}_n$ | 样本平均逼近（SAA）解，即 $\min_x \frac{1}{n}\sum_{i=1}^n h(x,\zeta_i)$ |
| | $\tilde{G}_n, \tilde{S}_n$ | 基于迭代轨迹的Hessian和梯度协方差的plug-in估计 |

**模型**（数据生成机制）：

1. 数据 $\{\zeta_t\}_{t=1}^n$ 独立同分布地来自未知分布 $P$。
2. 目标函数 $H(x) = \mathbb{E}_\zeta[h(x,\zeta)]$ 满足强凸性（Hessian特征值在 $[l, L]$ 内，$0 < l < L$）和光滑性（Hessian Lipschitz）。
3. SGD更新规则：$x_{t+1} = x_t - \eta_t \nabla h(x_t, \zeta_{t+1})$，步长 $\eta_t = \eta t^{-\alpha}$，$\alpha \in (1/2, 1]$。
4. 梯度噪声 $\nabla h(x_{t-1}, \zeta_t) - \nabla H(x_{t-1})$ 是鞅差序列（Assumption 2）。

**可观测数据**：研究者实际能观测到的是**完整的SGD迭代轨迹** $\{x_t\}_{t=0}^n$ 以及**原始数据集** $\{\zeta_t\}_{t=1}^n$。注意，这里与经典bootstrap不同：我们**不能**重新从总体 $P$ 中抽样，只能从经验分布 $\hat{P}_n$ 中重抽样。**想要但观测不到**的是：总体梯度 $\nabla H(x)$、总体Hessian $G(x)$、总体协方差 $S(x)$，以及真实最优解 $x^*$ 的精确分布。

#### 第二步：最小内核

**核心数学问题**：如何仅用一条SGD轨迹 $\{x_t\}$ 和数据集 $\{\zeta_t\}$，构造 $x^*$ 的渐近精确置信区间，且计算开销接近原始SGD？

**最小例子**：考虑 $d=1$ 的强凸二次问题 $h(x,\zeta) = \frac{1}{2}(x - \zeta)^2$，其中 $\zeta \sim \mathcal{N}(\mu, 1)$。此时 $H(x) = \frac{1}{2}(x-\mu)^2$，$x^* = \mu$，$G(x) \equiv 1$，$S(x) \equiv 1$。ASGD输出 $\bar{x}_n$ 满足经典结果：
\[
\sqrt{n}(\bar{x}_n - \mu) \xrightarrow{d} \mathcal{N}(0, 1).
\]
**传统bootstrap的做法**：从 $\{\zeta_t\}$ 中有放回地重抽样 $B$ 次（$B$ 很大，如 $B=1000$），每次重抽样后重新跑完整的ASGD，得到 $B$ 个bootstrap估计 $\{\bar{x}^*_b\}$，然后用这些bootstrap估计的经验分布分位数构造置信区间。**问题**：计算量是原始SGD的 $B$ 倍。

**廉价bootstrap的核心洞察**：我们不需要bootstrap分布本身，只需要一个**与原始估计渐近独立且同分布**的"参考量"来构造枢轴统计量。具体地，考虑**单条**bootstrap轨迹（$B=1$），其输出为 $\bar{x}^*_1$。在适当的条件下，可以证明：
\[
\sqrt{n}\begin{pmatrix} \bar{x}_n - \mu \\ \bar{x}^*_1 - \bar{x}_n \end{pmatrix} \xrightarrow{d} \mathcal{N}\left(0, \begin{pmatrix} \sigma^2 & 0 \\ 0 & \sigma^2 \end{pmatrix}\right),
\]
即原始估计的误差与bootstrap估计的误差**渐近独立**（因为bootstrap重抽样引入了额外的随机性，且与原始数据独立）。于是：
\[
T_n := \frac{\bar{x}_n - \mu}{|\bar{x}^*_1 - \bar{x}_n|} \xrightarrow{d} \frac{Z_0}{|Z_1|},
\]
其中 $Z_0, Z_1 \overset{\text{i.i.d.}}{\sim} \mathcal{N}(0,1)$。注意 $\frac{Z_0}{|Z_1|}$ 的分布**不依赖于任何未知参数**——它就是标准柯西分布的"符号版本"（实际上 $\frac{Z_0}{|Z_1|}$ 服从标准柯西分布）。因此，我们可以用**固定分位数**（与 $B$ 无关）构造置信区间：
\[
CI = \left[\bar{x}_n - q_{1-\gamma/2} \cdot |\bar{x}^*_1 - \bar{x}_n|, \quad \bar{x}_n + q_{1-\gamma/2} \cdot |\bar{x}^*_1 - \bar{x}_n|\right],
\]
其中 $q_{1-\gamma/2}$ 是柯西分布的 $1-\gamma/2$ 分位数。**关键点**：$B=1$ 就足够了！因为枢轴统计量的极限分布是固定的（柯西），不需要用bootstrap分布来逼近。

**为什么这能work**：传统bootstrap需要 $B$ 大是因为它试图用经验分布逼近整个采样分布；廉价bootstrap只需要 $B$ 个bootstrap样本与原始估计的**联合分布**，而联合分布的极限是已知的（高斯），因此 $B$ 可以极小。**代价**是置信区间更宽（柯西分布比正态分布尾部更厚），但覆盖率的精确性不受影响。

**一般情形**：对于一般的强凸光滑问题，上述论证需要两个关键步骤：
1. **联合渐近正态性**：证明 $(\sqrt{n}(\bar{x}_n - x^*), \sqrt{n}(\bar{x}^*_1 - \bar{x}_n))$ 联合收敛到 $2d$ 维高斯分布，且协方差结构为 $\text{block-diagonal}$（即两部分渐近独立）。这需要推广Shao and Zhang (2022)的Berry-Esseen界到bootstrap设置。
2. **枢轴统计量的构造**：对于 $d>1$，需要对每个坐标构造类似 $t$ 统计量的枢轴量，并用 $t_B$ 分布（而非柯西）作为极限分布。这就是为什么本文使用 $t_B$ 分布的分位数——$B$ 是自由度，$B=3$ 时 $t_3$ 分布尾部比正态分布宽但比柯西窄。

**为什么这个最小内核是"整篇论文的骨架"**：本文的所有技术工作——Theorem 2（条件收敛）、Theorem 3（均匀非渐近界）、Theorem 4（联合渐近独立性）——都是在为上述两步论证提供严格的数学基础。而实验部分则验证了 $B=3$ 在实际问题中的表现。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：在SGD/ASGD框架下，如何用极少的bootstrap重复次数（$B$ 可小至1或2）构造渐近精确的置信区间，同时避免Hessian计算、batch调参和算法修改。
2. **核心方法**：提出两种廉价bootstrap方法——COfB（离线版，对数据有放回重抽样后重跑ASGD）和COnB（在线版，在SGD迭代中乘以指数随机扰动因子），利用bootstrap样本与原始估计的联合渐近分布构造 $t$ 统计量。
3. **主要结论**：在强凸光滑假设下，对于任意固定 $B \geq 1$（ASGD）或 $B \geq 2$（SGD），所构造的置信区间具有渐近精确覆盖率；数值实验表明 $B=3$ 即可在覆盖率和区间宽度间取得良好平衡。

#### 关键设定与假设

- **强凸性与光滑性**（Assumption 1）：$h(\cdot, \zeta)$ 的Hessian特征值在 $[l, L]$ 内，且Hessian关于 $x$ 是Lipschitz连续的。这保证了 $H$ 的强凸性和 $x^*$ 的唯一性，是SGD收敛和渐近正态性的基础。
- **鞅差噪声**（Assumption 2）：梯度噪声 $\nabla h(x_{t-1}, \zeta_t) - \nabla H(x_{t-1})$ 关于历史滤子是鞅差序列。这是SGD渐近分析的标准假设，保证了中心极限定理的适用性。
- **矩条件**（Assumption 3）：$\|\nabla h(x^*, \zeta)\|_4 \leq \tau$，即梯度在最优点的四阶矩有界。这是Berry-Esseen界所需的矩条件。
- **步长条件**（Assumptions 5-6）：ASGD要求 $\eta_t = \eta t^{-\alpha}$，$\alpha \in (1/2, 1]$；SGD要求 $\eta_t = \eta t^{-1}$ 且 $\eta l > 1/2$。这些条件保证了SGD的收敛速率和渐近方差的有限性。
- **Glivenko-Cantelli条件**（Assumptions 5-6）：Hessian二阶偏导函数类 $\mathcal{F}_{i,j}$ 是 $P$-Glivenko-Cantelli的，即经验过程一致收敛。这是将固定分布的Berry-Esseen界推广到经验分布（bootstrap）的关键。

**相比已有工作的变化**：
- 相比Chen et al. (2020)的delta方法：**不要求Hessian可计算**，只需一阶梯度信息。
- 相比Fang et al. (2018)的online bootstrap：**$B$ 从 $O(100)$ 降到 $O(1)$**，计算开销大幅降低。
- 相比Su and Zhu (2023)的HiGrad：**不修改原始SGD轨迹**，COfB完全复用原始ASGD输出，COnB仅需并行 $B$ 条轻量轨迹。
- 相比Lee et al. (2022)的random scaling：**内存开销从 $O(d^2)$ 降到 $O(d)$**，因为不需要维护缩放矩阵。

#### 主要结果

**定理1（主定理）**：在Assumptions 1-5下，COfB和COnB生成的置信区间渐近精确，即
\[
\lim_{n\to\infty} P(x^*_i \in I^{\text{COfB}}_{i,n}) = 1-\gamma, \quad \lim_{n\to\infty} P(x^*_i \in I^{\text{COnB}}_{i,n}) = 1-\gamma.
\]
对任意固定 $B \geq 1$（ASGD）或 $B \geq 2$（SGD）成立。

**定理2（条件收敛）**：建立了bootstrap样本的误差 $\sqrt{n}(\bar{x}^*_b - \bar{x}_n)$ 在给定原始数据条件下收敛到与原始误差 $\sqrt{n}(\bar{x}_n - x^*)$ **独立同分布**的高斯变量。这是整个方法的理论基础。

**定理3（均匀非渐近界）**：将Shao and Zhang (2022)的Berry-Esseen界推广到**所有数据分布**（包括经验分布 $\hat{P}_n$）上一致成立。这是从固定分布到bootstrap的关键技术步骤。

**定理4（联合渐近独立性）**：严格证明了原始估计与bootstrap估计的误差在联合分布意义下渐近独立。这是构造 $t$ 统计量的前提。

**定理5（高维稀疏扩展）**：在Lasso模型选择后，对选出的非零系数应用COfB/COnB，覆盖率渐近精确。

#### 证明路线与技术技巧

**整体路线**（以COfB-ASGD为例）：
1. **分解误差**：将 $\sqrt{n}(\bar{x}^*_b - \bar{x}_n)$ 分解为"bootstrap重抽样引入的统计误差"与"SGD迭代误差"两部分。
2. **条件收敛**：利用Shao and Zhang (2022)的Berry-Esseen界，证明在给定原始数据条件下，bootstrap误差的条件分布收敛到高斯分布，且协方差与原始误差的极限协方差相同。
3. **均匀性**：关键技巧是将Shao-Zhang界中的常数统一为不依赖于数据分布的常数（通过Glivenko-Cantelli条件和有界矩条件），从而可以同时应用于原始分布 $P$ 和经验分布 $\hat{P}_n$。
4. **联合收敛**：利用"原始误差"与"bootstrap误差"的条件独立性（因为bootstrap重抽样在给定原始数据后是独立的），结合Slutsky引理，得到联合收敛。
5. **枢轴统计量**：构造 $t$ 统计量 $T_n = \frac{\sqrt{n}((\bar{x}_n)_i - x^*_i)}{\sqrt{\frac{1}{B}\sum_b (\sqrt{n}((\bar{x}^*_b)_i - (\bar{x}_n)_i))^2}}$，利用联合收敛得到 $T_n \xrightarrow{d} t_B$。

**关键技术技巧**：
- **鞅差分解**：将SGD迭代误差分解为鞅差序列的和，利用鞅中心极限定理。
- **线性化**：利用强凸性将SGD迭代线性化为 $x_{t+1} - x^* \approx (I - \eta_t G(x^*))(x_t - x^*) + \eta_t \text{noise}$，从而将非线性问题转化为线性递推。
- **均匀Berry-Esseen界**：这是本文最核心的技术贡献。Shao and Zhang (2022)的原始结果针对固定分布，本文通过精细的常数追踪，证明该界对**所有满足矩条件的分布**一致成立，从而可以直接应用于bootstrap的经验分布。
- **$t$ 分布自由度**：对于ASGD，bootstrap样本与原始估计的极限协方差相同，因此 $t$ 统计量的自由度是 $B$；对于SGD，由于末次迭代的渐近分布与bootstrap的差异，需要 $B-1$ 自由度。这一微妙差异在定理1中通过不同的 $B$ 要求体现。

#### 真实例子与应用

**实验设置**：
- **数据**：线性回归（$\zeta = (a,b)$，$b = a^\top x^* + \epsilon$）和逻辑回归，$n = 10^4$ 或 $10^5$，$d \in \{5, 20, 200\}$。
- **协方差结构**：单位阵、Toeplitz（$\Sigma_{ij} = 0.5^{|i-j|}$）、等相关（$\Sigma_{ij} = 0.2$ for $i \neq j$）。
- **基线方法**：delta方法（Chen et al., 2020）、batch means（Chen et al., 2020）、random scaling（Lee et al., 2022）、online bootstrap（Fang et al., 2018，$B=100,200$）、HiGrad（Su and Zhu, 2023）。
- **评估指标**：覆盖率（目标95%）、区间宽度、运行时间。

**关键结果**：
1. **覆盖率**：COfB和COnB在几乎所有配置下覆盖率在94%-96%之间，与online bootstrap（$B=100$）相当，优于delta方法在高维时的表现（$d=200$ 时delta覆盖率降至37%）。
2. **区间宽度**：COfB和COnB的区间宽度随 $B$ 增大而减小，$B=10$ 时已接近online bootstrap（$B=100$）的宽度。$B=3$ 时宽度约为最优宽度的1.5倍。
3. **计算效率**：COfB（$B=3$）的运行时间约为原始ASGD的4倍，COnB（$B=3$）约为3倍，而online bootstrap（$B=100$）约为100倍。在 $d=2000$ 时，COfB比delta方法快约10倍（delta需要 $O(d^3)$ 的矩阵求逆）。
4. **鲁棒性**：在逻辑回归中，当 $d=200$ 时，delta方法覆盖率降至54%，而COfB/COnB仍保持94%以上。在ill-conditioned（$\kappa(\Sigma)=10^3$）时，所有方法覆盖率下降，但COfB/COnB的下降幅度小于delta和batch means。

**例子想说明什么**：实验的核心信息是——**在保持渐近精确覆盖率的前提下，bootstrap重复次数可以从 $O(100)$ 降到 $O(1)$**，从而在计算效率和统计精度之间取得更好的平衡。特别地，COnB作为在线方法，在流式数据场景下具有独特优势。

#### 🔎 结论是否比证明窄

**值得注意的gap**：
1. **定理1的渐近性**：所有理论结果都是 $n \to \infty$ 的渐近结论，但实验中的 $n$ 有限（$10^4$ 或 $10^5$）。论文未提供有限样本的Berry-Esseen界（虽然定理3的界是显式的，但未在实验部分验证其紧性）。
2. **高维扩展的局限**：定理5要求模型选择阶段（Lasso）能正确恢复支撑集，且 $p$ 固定。对于 $p$ 随 $n$ 增长的情形，论文未给出理论保证。实验中的 $d=200$ 远小于 $n=10^5$，未真正触及高维困难。
3. **步长条件的限制**：Assumption 5要求 $\alpha \in (1/2, 1]$，排除了常数步长（$\alpha = 0$）和 $\alpha \leq 1/2$ 的情形。常数步长SGD在实践中很常见，但本文理论不覆盖。
4. **COnB的适用性**：COnB的bootstrap轨迹与原始轨迹共享相同的数据流，但论文未讨论数据流非平稳或存在概念漂移时的表现。
5. **区间宽度的理论刻画**：论文证明了覆盖率的渐近精确性，但未给出区间宽度的渐近表达式或最优 $B$ 的选择准则。实验显示 $B=10$ 已接近最优宽度，但缺乏理论解释。

### 四、开放问题

1. **有限样本精度的刻画**：定理3的Berry-Esseen界是 $O(n^{-\alpha + 1/2 + \epsilon})$ 量级，但未给出常数。能否得到显式的有限样本覆盖率误差界，从而指导 $B$ 和 $n$ 的选择？（扎根于定理3的陈述和附录A.4-A.5的证明。）

2. **自适应步长与动量方法**：本文只覆盖了 $\alpha \in (1/2, 1]$ 的步长衰减。对于Adam、RMSProp等自适应步长方法，SGD轨迹的渐近分布是否仍满足联合正态性？这需要推广Shao and Zhang (2022)的框架。（扎根于Assumption 5对步长的限制，以及引言中"driven by applications in exploration and as stopping criteria"的表述。）

3. **高维稀疏推断的精细理论**：定理5要求Lasso模型选择一致。能否在放松的Irrepresentable条件下，给出bootstrap覆盖率的一阶校正？或者，能否将COfB/COnB与debiased Lasso结合，构造同时适用于稀疏和非稀疏系数的置信区间？（扎根于定理5的假设和附录A.6的证明。）

4. **bootstrap重复次数 $B$ 的自适应选择**：实验显示 $B=3$ 已足够，但 $B$ 的最优值是否依赖于维度 $d$、条件数 $\kappa(\Sigma)$ 和步长参数？能否给出数据驱动的 $B$ 选择准则？（扎根于第6.1.3节关于区间宽度随 $B$ 变化的讨论，以及图1中 $B$ 对覆盖率的影响。）

5. **非光滑目标与约束优化**：本文假设 $H$ 强凸且光滑。对于Lasso、SVM等非光滑目标，或带约束的SGD，bootstrap的渐近理论如何变化？（扎根于Assumption 1的强凸光滑假设，以及附录C中关于放松条件的讨论。）

6. **COnB的方差缩减变体**：COnB的bootstrap轨迹使用指数扰动因子，但未利用方差缩减技术（如SVRG、SAGA）。能否将廉价bootstrap与方差缩减结合，在保持覆盖率的同时进一步降低bootstrap轨迹的方差？（扎根于COnB的算法设计，即Algorithm 2中 $W_{t,b} \sim \text{Exp}(1)$ 的扰动机制。）
