### 一、领域脉络与小综述

#### 这个方向是什么

本文所处的子方向是**平台试验（platform trials）中因果估计量的定义与估计**。平台试验是一种多臂、多阶段的适应性临床试验设计，允许试验臂在不同时间点进入或退出，共享一个持续招募的对照组。其根本的统计问题是：当试验跨越较长的日历时间、且存在时间趋势（time trends，即患者特征、标准治疗、疾病流行病学随时间变化）时，如何精确定义"治疗效应"这一因果目标，并选择恰当的估计方法。该方向的成熟度处于**中期发展阶段**：估计方法（回归、G-computation、AIPW）本身是成熟的半参数工具，但**估计量的目标（estimand）定义**在平台试验情境下仍存在模糊性，尤其是"条件于日历时间的效应"与"边际效应"之间的张力。

#### 发展脉络（history）

**奠基工作：平台试验设计与非并发对照的引入。** Berry et al. (2015) [1] 和 Saville & Berry (2016) [2] 奠定了平台试验的基本架构——多臂共享对照、臂的进入与退出。Koenig et al. (2024) [10] 系统梳理了平台试验的十大关键问题，指出非并发对照（non-concurrent controls, NCC）的使用是核心争议点之一。这一阶段的文献主要关注**设计层面**的效率与灵活性，对估计量的目标定义着墨不多。

**主要进展：非并发对照的统计方法。** Lee & Wason (2020) [11] 通过模拟研究了使用 NCC 的收益与风险，发现时间趋势存在时朴素合并 NCC 会导致 I 型错误膨胀。Bofill Roig et al. (2022) [8] 系统比较了多种模型化时间趋势的方法（线性、分段、阶梯函数），指出模型选择对偏差的影响。Krotka et al. (2024) [14] 提出了用样条和随机效应建模时间趋势的扩展。这一阶段的方法论共识是：**必须对时间趋势建模**，但"建模后估计的是什么效应"这一问题被搁置。

**当前 frontier：估计量的形式化与因果推断框架。** 两条并行的前沿线索在此交汇。第一条线索是**因果推断框架下的识别与估计**：Santacatterina et al. (2024) [19] 从潜在结果框架出发，系统讨论了使用 NCC 时所需的识别假设，指出"时间趋势可建模"（即给定日历时间的可交换性）是核心假设，并推荐以并发平均处理效应（concurrent ATE, cATE）作为稳健的估计目标。第二条线索是**监管与 estimand 框架的对接**：Van Lancker et al. (2024) [9] 和 Bannick et al. (2026) [17] 强调 ICH E9(R1) [24] 的 estimand 框架要求明确目标人群、处理条件、终点和汇总指标，而平台试验的时间维度使得"目标人群"的界定变得复杂。Qian et al. (2024) [18] 提出了"Entire Concurrently Eligible (ECE)"人群作为目标人群，试图统一不同试验臂的时间窗口。

**本文的位置**：本文站在上述两条线索的交汇点，系统性地完成了三项工作：① 形式化定义了平台试验中多种目标人群（ECE、ACA、LACC）对应的 estimand；② 建立了条件效应与边际效应在时间趋势下不一致的精确条件（命题 1）；③ 对未调整、回归、G-computation、AIPW 四类估计量进行了偏差与方差的系统比较，并给出了何时使用非并发数据的明确建议。本文的独特贡献在于**将 estimand 定义与估计量选择解耦**，明确指出"估计量的无偏性必须相对于其声称估计的 estimand 来评估"。

#### 子线索聚类

1. **估计方法线**：Tsiatis et al. (2008) [3]（半参数效率理论奠基）、Van Lancker et al. (2024) [1]（数据自适应协变量调整）、Robins et al. (1986, 1994) [21, 22]（G-computation 与 AIPW 的起源）。这条线关注**给定 estimand 后如何高效估计**。

2. **识别与因果假设线**：Santacatterina et al. (2024) [19]（NCC 的识别假设）、Guo et al. (2024) [16]（倾向性评分加权处理时间漂移）、Marschner & Schou (2024) [15]（区分随机化与非随机化信息）。这条线关注**哪些 estimand 在何种假设下可识别**。

3. **监管与 estimand 框架线**：ICH E9(R1) [24]、Van Lancker et al. (2024) [9]、Bannick et al. (2026) [17]。这条线关注**如何将统计目标转化为监管可接受的科学问题**。

4. **设计效率线**：Lee & Wason (2020) [11]、Kopp-Schneider et al. (2019) [13]（外部信息借用的不可能性）、Sridhara et al. (2022) [4]（监管视角下的 NCC 使用）。这条线关注**数据使用范围与试验效率的权衡**。

#### 这个方向在追问的核心问题

1. **当存在时间趋势时，条件于日历时间的处理效应与跨时间平均的边际效应何时不一致？** 本文命题 1 给出了精确条件：当且仅当存在治疗-时期交互或治疗-协变量交互且协变量分布随时间变化时，二者不一致。

2. **非并发对照数据应如何使用？** 是仅用于提高协变量效应的估计精度（不进入处理效应估计），还是直接参与处理效应估计（需要更强的假设）？本文的模拟表明，在模型正确设定时 NCC 带来的方差缩减有限（约 10%），但模型误设时偏差风险显著。

3. **如何选择目标人群？** ECE、ACA、LACC 对应不同的科学问题：ECE 回答"如果所有符合条件的患者都被纳入试验，效应是多少"，ACA 回答"实际被随机化的患者中的效应"，LACC 回答"最近期患者中的效应"。本文指出，监管决策通常关注近期人群（LACC），而科学问题可能更关注 ECE。

4. **非线性模型（如 logistic）下边际效应如何定义与估计？** 本文第 7 节指出，在 logit 链接下，条件 log-odds ratio 与边际 log-odds ratio 的差异不仅来自非可压缩性（non-collapsibility），还来自时间趋势导致的边际人群构成变化。

#### ⚠️ 作者的 framing（这是作者的说法）

作者将缺口 frame 为："**尽管已有大量文献讨论如何在平台试验中调整时间趋势，但对于'调整后估计的是什么效应'这一更基本的问题关注不足**"（引言第 2 段）。作者进一步声称，现有方法（尤其是模型化时间趋势的回归方法）"隐含地估计了一个信息加权的混合效应，该效应既不等于任何明确的目标人群的效应，也不具有清晰的政策含义"（第 3 节）。作者将本文定位为"**为平台试验中的 estimand 选择提供形式化框架**"，并强调"估计量的选择应服从于 estimand 的选择，而非相反"（讨论部分）。

**被作者淡化或回避的竞争路线**：① 贝叶斯动态借用方法（如 Bayesian Time Machine [7]）——作者仅在引言中提及"贝叶斯方法也可用于此目的"，但未将其纳入比较框架；② 基于设计的方法（如仅使用并发对照）——作者承认这是最稳健的选择，但认为其效率损失在长期试验中不可接受；③ 将时间视为工具变量的方法——作者完全未提及这一路线。

**值得研究者去查的问题**：为什么作者没有引用或讨论**时间作为工具变量**的识别策略？在存在未观测时间混杂的情况下，工具变量方法可能提供另一种识别路径。此外，作者对"目标人群"的定义完全基于日历时间，但未讨论**基于患者特征的目标人群**（如"符合某臂入组标准的所有患者"）与基于日历时间的人群之间的差异。

#### 张力

**未见明显对立引用**，但存在一个值得注意的张力：Santacatterina et al. (2024) [19] 强调"非并发对照的使用需要不可验证的假设"，而本文的模拟表明在模型正确设定时 NCC 的收益虽小但确实存在。这两者并不矛盾，但反映了**效率与稳健性之间的根本权衡**——这正是本文第 8 节讨论的核心。另一个张力存在于 [11]（Lee & Wason 发现 NCC 在时间趋势下导致 I 型错误膨胀）与 [8]（Bofill Roig 等发现模型化时间趋势可以纠正偏差）之间，本文通过区分"估计量偏差"与"estimand 错配"为这一张力提供了新的解释视角。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

**符号清单**（按类别分组）：

| 类别 | 符号 | 含义 |
|------|------|------|
| **指标** | $a \in \{0, 1, 2\}$ | 处理组：0=对照，1=臂1，2=臂2 |
| | $s \in \{1, 2, 3\}$ | 日历时期（period） |
| | $C_a$ | 臂 $a$ 活跃的时期集合（如 $C_1 = \{1,2\}$, $C_2 = \{2,3\}$） |
| | $L_a$ | 臂 $a$ 活跃的最后一个时期 |
| | $U_a$ | 从试验开始到 $L_a$ 的所有时期 |
| **样本量** | $N_s$ | 时期 $s$ 的总入组人数（固定设计量） |
| | $n_{a,s}$ | 时期 $s$ 分配到臂 $a$ 的人数 |
| | $m_{a,s} = n_{a,s} + n_{0,s}$ | 时期 $s$ 中臂 $a$ 或对照的入组人数 |
| **变量** | $Y$ | 结局（连续或二元） |
| | $X$ | 基线协变量向量 |
| | $S$ | 日历时期（随机变量） |
| | $A$ | 处理分配（随机变量） |
| | $Y^{(a)}$ | 潜在结局（potential outcome） |
| **参数/估计目标** | $\Delta_{a,s}(x)$ | 条件时期特异性效应：$E[Y^{(a)} - Y^{(0)} \mid S=s, X=x]$ |
| | $\Delta_{a,s}$ | 边际时期特异性效应：$E[\Delta_{a,s}(X) \mid S=s]$ |
| | $\Delta^{(P)}_a$ | 目标人群 $P$ 上的边际效应（estimand） |
| | $w^{(P)}_{a,s}$ | 目标人群 $P$ 下时期 $s$ 的权重 |
| **模型参数** | $\alpha_s$ | 时期效应（截距） |
| | $\theta_a$ | 处理主效应 |
| | $\phi_{a,s}$ | 处理-时期交互 |
| | $\beta$ | 协变量主效应 |
| | $\kappa_s$ | 协变量-时期交互 |
| | $\psi_a$ | 处理-协变量交互 |
| | $\sigma^2_{a,s}$ | 时期 $s$、臂 $a$ 的误差方差 |

**数据生成机制**（模型 14）：

对于连续结局：
$$Y_i^{(a)} = \alpha_{S_i} + \theta_a + \phi_{a,S_i} + (\beta + \kappa_{S_i} + \psi_a) X_i + \varepsilon_i^{(a)}, \quad \varepsilon_i^{(a)} \mid S_i = s \sim N(0, \sigma^2_{a,s})$$

其中 $X_i \mid S_i = s \sim F_s$（时期特异性协变量分布）。

**可观测数据**：$\{(Y_i, A_i, S_i, X_i)\}_{i=1}^{N}$，其中 $N = \sum_s N_s$。关键结构性特征：
- 时期 $s$ 内，$A$ 与 $(Y^{(0)}, Y^{(1)}, Y^{(2)}, X)$ 条件独立（随机化）；
- 时期 $s$ 内，$X$ 与潜在结局独立（时期特异性协变量分布）；
- 时期之间，$X$ 的分布 $F_s$ 可以变化（时间趋势的来源之一）；
- 臂 $a$ 在时期 $s \notin C_a$ 时不可用，因此 $P(A=a \mid S=s) = 0$。

**估计目标**：给定目标人群 $P$（ECE、ACA 或 LACC），估计
$$\Delta^{(P)}_a = \sum_{s \in C_a} w^{(P)}_{a,s} \Delta_{a,s}, \quad \sum_{s \in C_a} w^{(P)}_{a,s} = 1$$

其中权重 $w^{(P)}_{a,s}$ 由目标人群定义决定：
- ECE：$w^{ECE}_{a,s} = N_s / \sum_{t \in C_a} N_t$（按时期入组人数加权）
- ACA：$w^{ACA}_{a,s} = m_{a,s} / \sum_{t \in C_a} m_{a,t}$（按实际随机化人数加权）
- LACC：$w^{LACC}_{a,s} = 1$ 若 $s = L_a$，否则 0

#### 第二步：最小内核

**最小内核**：考虑最简单的平台试验——两个时期（$s=1,2$），臂 1 仅在时期 1 活跃，臂 2 仅在时期 2 活跃，对照在两个时期都活跃。即 $C_1 = \{1\}$, $C_2 = \{2\}$。此时：

- ECE 和 ACA 对臂 1 的估计目标相同（只有一个时期），但 ECE 的权重 $w^{ECE}_{1,1} = N_1/N_1 = 1$，ACA 的权重 $w^{ACA}_{1,1} = m_{1,1}/m_{1,1} = 1$，两者一致。
- 关键差异出现在臂 2：ECE 权重 $w^{ECE}_{2,2} = N_2/N_2 = 1$，ACA 权重 $w^{ACA}_{2,2} = m_{2,2}/m_{2,2} = 1$，也一致。

**要让 ECE 和 ACA 真正不同，需要至少三个时期**，且臂 1 在时期 1 和 2 都活跃，臂 2 在时期 2 和 3 都活跃。此时 $C_1 = \{1,2\}$, $C_2 = \{2,3\}$。对于臂 1 的估计：
- ECE 权重：$w^{ECE}_{1,1} = N_1/(N_1+N_2)$, $w^{ECE}_{1,2} = N_2/(N_1+N_2)$
- ACA 权重：$w^{ACA}_{1,1} = m_{1,1}/(m_{1,1}+m_{1,2})$, $w^{ACA}_{1,2} = m_{1,2}/(m_{1,1}+m_{1,2})$

当 $N_s \neq m_{1,s}$（即时期 $s$ 有臂 2 的患者入组）时，ECE 和 ACA 的权重不同，估计目标也不同。

**核心数学问题**：在模型 (14) 下，时期特异性边际效应为
$$\Delta_{a,s} = \theta_a + \phi_{a,s} + \psi_a \cdot E[X \mid S=s]$$

当 $\psi_a \neq 0$（存在处理-协变量交互）且 $E[X \mid S=s]$ 随 $s$ 变化（协变量分布漂移）时，$\Delta_{a,s}$ 随 $s$ 变化。此时：
- 条件效应（给定 $S=s$）是常数 $\theta_a + \phi_{a,s}$（若 $\phi_{a,s}$ 恒定则为 $\theta_a$）；
- 边际效应 $\Delta^{(P)}_a$ 是时期特异性效应的加权平均，权重由目标人群决定。

**本文的核心数学贡献**（命题 1）：ECE、ACA、LACC 三个 estimand 相等当且仅当 $\Delta_{a,s}$ 在 $s \in C_a$ 上恒定。在模型 (14) 下，这等价于 $\phi_{a,s}$ 恒定且（$\psi_a = 0$ 或 $E[X \mid S=s]$ 恒定）。当此条件不满足时，三个 estimand 代表不同的科学问题，不能互换使用。

**为什么这个内核是"最小"的**：它剥离了所有一般性技术假设（协变量维度、非线性链接、多重比较、适应性设计），只保留平台试验的本质特征——臂在不同时期进入/退出、时间趋势存在、目标人群选择影响估计目标。理解了这一内核，论文第 4-7 节的所有内容都是它的"加壳"：第 4 节引入具体估计量，第 5 节推导方差公式，第 6-7 节通过模拟验证有限样本表现。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：在存在时间趋势的平台试验中，条件于日历时间的处理效应与跨时期边际处理效应何时不一致，以及不同目标人群（ECE、ACA、LACC）对应的 estimand 应如何定义和估计。
2. **核心工具/方法**：潜在结果框架下的 estimand 形式化定义；未调整估计量、线性回归、G-computation、AIPW 四种估计量的偏差与方差分析；解析方差公式推导（命题 2-4）与大规模蒙特卡洛模拟验证。
3. **主要结论**：① ECE、ACA、LACC 三个 estimand 在无处理-时期交互且无处理-协变量交互作用于漂移协变量分布时重合，否则不同；② 在模型正确设定时，G-computation 和 AIPW 对所有 estimand 均一致，但方差随目标人群和数据集选择而变化；③ 在模型误设时，AIPW 的倍差鲁棒性使其成为最稳健的选择，但方差估计在近阳性（near-positivity）时会膨胀；④ 非并发数据的使用应限于提高协变量效应估计精度，而非直接进入处理效应估计。

#### 关键设定与假设

**核心假设**（第 2 节）：
- **一致性**：$Y_i = Y_i^{(A_i)}$；
- **时期内的可交换性**：$A \perp \{Y^{(0)}, Y^{(1)}, Y^{(2)}, X\} \mid S$（随机化保证）；
- **阳性性**：$P(A = a \mid S = s) > 0$ 且 $P(A = 0 \mid S = s) > 0$ 对所有 $s \in C_a$；
- **无干扰**（SUTVA 的一部分）：一个患者的处理不影响其他患者的结局。

**模型假设**（第 5 节，用于解析结果）：
- 数据生成模型 (14)：线性、可加、正态误差；
- 条件同方差：$\sigma^2_{a,s} = \sigma^2$（命题 2-4 中简化假设）；
- 协变量分布 $F_s$ 可以跨时期变化，但协变量效应 $\beta, \kappa_s$ 是常数。

**相比已有文献的放宽/强化**：
- **放宽**：允许任意形式的时期特异性协变量分布 $F_s$（[19] 假设 $F_s$ 已知或可估计）；允许处理-时期交互 $\phi_{a,s}$ 存在（[8] 假设无交互）。
- **强化**：假设随机化概率已知（平台试验中确实如此）；假设结局模型为线性（第 7 节放宽到 logistic）。

#### 主要结果

**命题 1（estimand 一致性条件）**：ECE、ACA、LACC 三个 estimand 相等当且仅当 $\Delta_{a,s}$ 在 $s \in C_a$ 上恒定。在模型 (14) 下，这等价于：
$$\phi_{a,s} = \phi_a \text{ 对所有 } s \in C_a, \quad \text{且} \quad (\psi_a = 0 \text{ 或 } E[X \mid S=s] \text{ 在 } s \in C_a \text{ 上恒定})$$

**命题 2-4（方差比较）**：在模型 (14) 和条件 A、B（常数方差、常数分配比）下：
- 未调整估计量的方差：$\text{Var}(\hat{\Delta}^{unadj}_{a,s}) = \sigma^2(1/n_{a,s} + 1/n_{0,s})$
- G-computation 的方差：$\text{Var}(\hat{\Delta}^{G}_{a,s}) = \sigma^2(1/n_{a,s} + 1/n_{0,s}) \cdot (1 - R^2_{X \mid S})$，其中 $R^2_{X \mid S}$ 是协变量在时期 $s$ 内解释的方差比例
- AIPW 的方差：$\text{Var}(\hat{\Delta}^{AIPW}_{a,s}) = \text{Var}(\hat{\Delta}^{G}_{a,s}) + \text{额外项}$，额外项来自倾向性得分估计的不确定性

**推论（效率排序）**：在模型正确设定时，G-computation 和 AIPW 的方差 ≤ 回归估计量的方差 ≤ 未调整估计量的方差。但 AIPW 的方差在倾向性得分接近 0 或 1 时会急剧膨胀（近阳性问题）。

**第 7 节（二元结局）**：在 logistic 模型下，条件 log-odds ratio 与边际 log-odds ratio 的差异不仅来自非可压缩性，还来自时期特异性基线风险 $\alpha_s$ 和协变量分布 $F_s$ 的变化。作者证明，即使条件效应恒定（$\phi_{a,s} = 0$），边际 log-odds ratio 仍随时期变化，因此 ECE、ACA、LACC 在二元结局下几乎总是不一致。

#### 模拟设置与结果

**模拟设计**：3 个时期，臂 1 在时期 1-2 活跃，臂 2 在时期 2-3 活跃，对照全程活跃。样本量 $N_s = 100$（时期 1、3），$N_2 = 300$。9 个场景覆盖：无交互、处理-时期交互、处理-协变量交互、协变量分布漂移、极端分配比等。

**关键结果**：
1. **偏差**：在无交互场景（场景 1-5），所有估计量对所有 estimand 均近似无偏。在交互场景（场景 6-7），未调整估计量和回归估计量对 ECE/LACC 有显著偏差（相对偏差 10-25%），而 AIPW 对所有 estimand 均近似无偏。
2. **方差**：G-computation 和 AIPW 的方差比未调整估计量低 15-40%（取决于协变量预测强度）。AIPW 在近阳性场景（场景 8）方差膨胀约 2-3 倍。
3. **方差估计**：模型化方差估计在模型正确时校准良好（比率 0.95-1.05），但在交互场景中系统性高估（比率 1.2-1.5），与 [23] 的发现一致。

#### 🔎 结论是否比证明窄

**是，存在三处"证明窄于结论"的情况**：

1. **命题 1 的充分性方向**：命题 1 声称"ECE、ACA、LACC 相等当且仅当 $\Delta_{a,s}$ 恒定"，但证明仅覆盖了模型 (14) 下的线性可加情形。作者在脚注 3 中承认"对于非线性模型，充分性可能不成立"，但正文结论的表述未加此限定。

2. **方差比较的适用范围**：命题 2-4 的方差公式在条件 A、B（常数方差、常数分配比）下推导，但模拟中场景 8-9 明确违反条件 B。作者在讨论中承认"方差比较在极端分配比下可能不成立"，但未给出修正公式。

3. **AIPV 的"总是无偏"声明**：第 4.4 节声称 AIPW 对每个 estimand 均一致，但这一结论依赖于倾向性得分的正确设定。在场景 8 中，AIPW 的点估计确实无偏，但其方差膨胀严重，作者在讨论中承认"在近阳性下 AIPW 的置信区间覆盖可能不足"，但未给出有限样本修正。

**最值得注意的"窄结论"**：作者在第 5.6 节推导了 AIPW 的精确有限样本分布（高斯线性模型下），但这一结果仅适用于连续结局和线性模型。第 7 节的二元结局分析仅给出数值结果，没有解析证明。因此，论文的核心理论贡献（命题 1-4）严格限于线性可加模型，对非线性模型的结论主要依赖模拟。

### 四、开放问题

以下开放问题均扎根于论文的具体语句：

1. **非线性模型下的 estimand 一致性条件**（扎根于第 7 节末尾："The conditions under which the concurrent estimands coincide in nonlinear models remain an open question"）。作者仅通过数值例子展示了 logistic 模型下 ECE/ACA/LACC 的差异，但未给出类似命题 1 的解析条件。要确认这是否为真 gap，可查阅近期关于非可压缩性（non-collapsibility）的文献（如 Daniel et al. 2021 [5]），看是否已有针对平台试验的推广。

2. **最优权重的解析刻画**（扎根于第 5.5 节末尾："The optimal choice of weights for combining period-specific estimates remains an open problem"）。作者证明了 ACA 权重在常数分配比下是方差最优的，但未给出一般分配比下的最优权重。这与经典的效率理论（如 Tsiatis et al. 2008 [3] 的半参数效率界）直接相关——可尝试用半参数效率理论推导最优权重。

3. **近阳性下的方差修正**（扎根于第 6.1 节场景 8 讨论："The variance estimator for AIPW under near-positivity requires further investigation"）。作者观察到 AIPW 的方差在近阳性下膨胀，但未给出修正的方差估计量。这与 [23] 中关于 AIPW 方差估计的讨论直接相关——可尝试将倍差鲁棒方差估计推广到平台试验情境。

4. **非并发数据的最优使用策略**（扎根于第 8 节："The question of how to optimally use non-concurrent data remains open"）。作者建议非并发数据仅用于提高协变量效应估计精度，但未给出这一策略的最优性证明。这与 [19] 的 cATE 推荐直接相关——可尝试证明在何种条件下这一策略是 minimax 最优的。

5. **适应性设计中 estimand 的时变性**（扎根于第 8 节："In adaptive designs, the estimand itself may change over time, which is not addressed in this work"）。当试验设计因中期分析而改变时（如臂的提前终止），目标人群的定义可能需要动态调整。这与 [10] 中提到的适应性设计挑战直接相关——目前文献中缺乏对时变 estimand 的形式化处理。

---

**确认 gap 的操作建议**：要验证上述开放问题是否为真 gap，建议检索近 2-3 年（2023-2026）发表在 *Biometrics*、*Statistics in Medicine*、*Clinical Trials* 上的平台试验方法论论文，特别关注是否已有工作解决了非线性模型下的 estimand 一致性条件或近阳性下的方差修正问题。如果这些方向近期已有工作，则本文的开放问题已部分解决，需要重新定位研究切入点。
