### 一、领域脉络与小综述

#### 这个方向是什么

本文所处的子方向是**因果推断中的识别理论**，具体而言：在观察性研究中，当"无混杂性"（unconfoundedness / ignorability）这一核心识别假设不成立时，我们能否用更弱、更可解释的信息约束来刻画选择机制，并判断在什么条件下这些约束足以恢复因果效应的识别。该方向的核心张力在于：完全的无混杂性（$Y^d \perp\!\!\!\perp D \mid X$）在实证中往往过于强，而完全放弃它则导致识别失败；因此研究者试图在"允许一定程度的不可观测选择"与"仍能识别因果参数"之间寻找中间地带。该方向当前处于活跃发展阶段，但尚未形成统一框架——不同论文用不同的偏离度量（如选择比、偏误放大因子、信息论量）来参数化"偏离无混杂性的程度"。

#### 发展脉络

- **奠基工作：倾向得分与无混杂性**。Rosenbaum and Rubin (1983, 1984) 建立了无混杂性下基于倾向得分的识别与估计框架，这是整个方向的基准。本文引用其作为"标准假设"的起点，并明确指出自己的目标是**允许**偏离这一假设。
- **敏感性分析传统**：当无混杂性被质疑时，实证研究者通常转向敏感性分析。本文引言中提到的 Altonji, Elder, and Taber (2005) 和 Oster (2019) 代表了一条重要线索：用"选择关于可观测变量的强度"来推断"选择关于不可观测变量的强度"，从而评估结论的稳健性。Oster (2019) 的核心贡献是将系数移动与 R² 移动联系起来，构造偏误的显式表达式。这条线索的局限在于：它假设可观测与不可观测选择的**比例关系**，而非从信息论角度刻画选择机制本身。
- **部分识别与信息论界限**：另一条线索是用信息论量来界定因果效应。Janzing, Balduzzi, and Schölkopf (2013) 提出用信息流度量因果强度；Jung and Kang (2026) 建立无混杂性下基于 f-散度的因果效应界限。本文与后者的区别在于：Jung-Kang 用信息论量做**部分识别**（给出效应区间），而 Breunig 用信息论约束做**点识别**（在约束下恢复无混杂性）。
- **工具变量与内生选择**：d'Haultfœuille (2010) 用工具变量处理内生选择，其识别策略基于工具与选择指标的独立性。本文在 IV 扩展部分（第 4.3 节）直接对话这条线索，用互信息约束替代工具变量的完全外生性。
- **本文的位置**：Breunig 的贡献在于**用条件互信息（CMI）作为偏离无混杂性的度量**，并证明了一个双向等价：CMI 约束 ⇔ 处理概率的乘法分解。这既统一了上述多条线索（敏感性分析、部分识别、IV），又给出了一个可检验的充分条件（倾向得分的秩条件）使得弱约束等价于强识别。

#### 子线索聚类

1. **基于倾向得分的识别与估计**（Rosenbaum-Rubin 1983/1984; Hirano-Imbens 2004; Imbens 2004）：核心是"给定 X 后处理分配与潜在结果独立"，方法上依赖倾向得分的估计与加权/分层/匹配。本文的乘法分解直接推广了这一框架——当无混杂性失败但 CMI 约束成立时，倾向得分仍可分解为"潜变量部分 × 协变量部分"。
2. **基于选择可观测性的敏感性分析**（Altonji-Elder-Taber 2005; Oster 2019; Chernozhukov et al. 2026）：核心是"用可观测选择强度推断不可观测选择强度"，产出是偏误的界限或校正估计量。本文的 CMI 约束提供了一种**非参数**的替代：不假设比例关系，而是假设"潜在结果关于处理的信息不超过潜在异质性关于处理的信息"。
3. **信息论因果度量与界限**（Ay-Polani 2008; Janzing et al. 2013; Jung-Kang 2026）：核心是用互信息、f-散度等量度量因果强度或界定效应。本文的独特之处在于**用信息论约束做等价性刻画**（而非界限），即 CMI 约束在秩条件下等价于无混杂性。
4. **工具变量与内生选择识别**（d'Haultfœuille 2010; Abadie 2003; Imbens-Angrist 1994）：核心是用工具变量排除不可观测混淆。本文第 4.3 节将 CMI 框架扩展到 IV 设定，用互信息约束替代工具外生性。

#### 这个方向在追问的核心问题

1. **偏离无混杂性的程度如何度量？** 现有答案包括：选择比（AET 2005）、偏误放大因子（Oster 2019）、f-散度界限（Jung-Kang 2026）。本文的答案是：条件互信息 $I(Y^d; D \mid X)$。
2. **在什么条件下，弱约束足以恢复点识别？** 本文的答案是：倾向得分向量的二阶矩矩阵满秩（对多元处理），或倾向得分非常数（对二元处理）。
3. **这些约束是否可检验？** 本文的答案是：秩条件只涉及可观测的 $(D, X)$ 联合分布，可用 Chen-Fang (2019) 的秩检验评估（附录 B 做了模拟）。

#### ⚠️ 作者的 framing（这是作者的说法）

作者将 CMI 约束 $I(Y^d; D \mid X) \le I(U^d; D)$ 框定为"允许内生选择，但要求潜在结果关于处理的信息不超过潜在异质性关于处理的信息"。他声称这一约束"在允许内生选择的模型中"成立，且"尽管 CMI 限制允许内生选择，但当处理概率随协变量变化足够丰富时，该限制等价于无混杂性"。**注意**：作者将 CMI 约束与无混杂性的等价性作为核心卖点，但这一等价性依赖于两个关键假设：(i) 潜在结果的可加/可乘表示 $Y^d = m^d(X, U^d)$ 且 $U^d \perp\!\!\!\perp X$；(ii) 秩条件（倾向得分向量二阶矩满秩）。**作者淡化了 (i) 中 $U^d \perp\!\!\!\perp X$ 这一假设的强度**——它本身就是一个排除工具变量与协变量相关的约束。**值得研究者去查的问题**：如果 $U^d$ 与 $X$ 相关（例如，潜在异质性本身受协变量影响），CMI 约束是否还能推出乘法分解？作者在第 4.1 节用 $W$ 条件化部分回应了这一点，但 $U^d \perp\!\!\!\perp X \mid W$ 仍然是一个强假设。

#### 张力

- **未见明显对立引用**：本文引用的工作之间没有直接矛盾。但存在一个**隐含张力**：Oster (2019) 和 Chernozhukov et al. (2026) 的敏感性分析框架允许研究者**显式地参数化**不可观测选择，而本文的 CMI 约束是一个**非参数**约束。前者更灵活但依赖参数假设，后者更一般但可能难以在实证中验证（互信息的估计需要密度估计）。这个张力值得研究者注意：**CMI 约束的可检验性**（通过秩条件）是间接的——它检验的是"倾向得分是否足够变化"，而非"CMI 约束本身是否成立"。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

**符号清单**（逐个点名）：

| 记号 | 含义 | 类型 |
|------|------|------|
| $D$ | 处理变量，取值于 $\mathcal{D} = \{0, 1, \ldots, K\}$ | 可观测随机变量 |
| $Y^d$ | 潜在结果（potential outcome），$d \in \mathcal{D}$ | 潜在（反事实）量 |
| $Y$ | 观测结果，$Y = \sum_{d \in \mathcal{D}} \mathbf{1}\{D = d\} Y^d$ | 可观测随机变量 |
| $X$ | 协变量向量 | 可观测随机变量 |
| $U^d$ | 潜在异质性（latent heterogeneity），$U^d \perp\!\!\!\perp X$ | 潜在（不可观测）量 |
| $m^d(x, u)$ | 潜在结果的确定性函数，$Y^d = m^d(X, U^d)$ | 结构函数（未知） |
| $p(X) = (P(D=0 \mid X), \ldots, P(D=K \mid X))^\top$ | 倾向得分向量 | 由可观测分布识别 |
| $I(V; R)$ | 互信息 | 信息论量 |
| $I(V; R \mid X)$ | 条件互信息 | 信息论量 |
| $I^d(V; R)$ | $d$-specific 互信息（对 $D=d$ 条件化） | 信息论量 |

**模型**（数据生成机制）：

1. **潜在结果表示**：对每个 $d \in \mathcal{D}$，$Y^d = m^d(X, U^d)$，其中 $U^d \perp\!\!\!\perp X$。这个表示总是可以通过条件秩变换（conditional rank transform）得到：取 $U^d = F_{Y^d \mid X}(Y^d \mid X)$，则 $U^d \sim \text{Unif}(0,1)$ 且 $U^d \perp\!\!\!\perp X$，$Y^d$ 可由 $m^d(x, u) = F^{-1}_{Y^d \mid X}(u \mid x)$ 恢复。**注意**：这个表示是"无成本的"——它不施加任何可检验的约束，只是重新参数化。

2. **技术条件 (2.2)**：$U^d \perp\!\!\!\perp D \mid (Y^d, X)$。这个条件要求：给定潜在结果和协变量后，潜在异质性不再提供关于处理的额外信息。在 $m^d(x, \cdot)$ 几乎处处单射的条件下，这等价于 $U^d \perp\!\!\!\perp D \mid (Y^d, X)$ 与 $Y^d$ 可逆，此时 $U^d$ 可由 $(Y^d, X)$ 恢复。

3. **CMI 约束**：$I(Y^d; D \mid X) \le I(U^d; D)$。在模型 (2.1)–(2.2) 下，由 Lemma A.1，$I(Y^d; D \mid X) = I(U^d; D \mid X)$，因此 CMI 约束等价于 $I(U^d; D \mid X) \le I(U^d; D)$，即条件互信息不超过无条件互信息。

**可观测数据**：研究者观测到 $(Y, D, X)$ 的 $n$ 个独立同分布样本。**不可观测**：$U^d$（对所有 $d$）、$Y^d$（对 $d \neq D$）。

**目标 estimand**：平均处理效应 $\text{ATE} = \mathbb{E}[Y^1 - Y^0]$，或条件平均处理效应 $\text{CATE}(x) = \mathbb{E}[Y^1 - Y^0 \mid X = x]$。

#### 第二步：最小内核

**核心命题（最小版本）**：考虑二元处理 $D \in \{0, 1\}$，潜在结果 $Y^d = m^d(X, U^d)$，$U^d \perp\!\!\!\perp X$，且 $U^d \perp\!\!\!\perp D \mid (Y^d, X)$。假设倾向得分 $p(X) = P(D=1 \mid X)$ 不是常数。则 CMI 约束 $I(Y^d; D \mid X) \le I(U^d; D)$ 成立当且仅当 $Y^d \perp\!\!\!\perp D \mid X$（即无混杂性）。

**为什么这个命题成立？** 关键在于 Lemma A.2 的等价链：

1. 由 Lemma A.1，在模型 (2.1)–(2.2) 下，$I(Y^d; D \mid X) = I(U^d; D \mid X)$。
2. 因此 CMI 约束 $I(Y^d; D \mid X) \le I(U^d; D)$ 等价于 $I(U^d; D \mid X) \le I(U^d; D)$。
3. 由互信息的性质，$I(U^d; D) - I(U^d; D \mid X) = I(U^d; D; X)$（三变量交互信息）。交互信息可正可负。
4. 但由 $U^d \perp\!\!\!\perp X$（模型假设），$I(U^d; X) = 0$。由交互信息的对称性，$I(U^d; D; X) = I(U^d; X) - I(U^d; X \mid D) = -I(U^d; X \mid D) \le 0$。
5. 因此 $I(U^d; D \mid X) \le I(U^d; D)$ 恒成立，且等号当且仅当 $I(U^d; X \mid D) = 0$，即 $U^d \perp\!\!\!\perp X \mid D$。
6. 结合 $U^d \perp\!\!\!\perp X$ 和 $U^d \perp\!\!\!\perp X \mid D$，可得 $U^d \perp\!\!\!\perp (X, D)$，从而 $U^d \perp\!\!\!\perp D \mid X$。
7. 由于 $Y^d = m^d(X, U^d)$，$U^d \perp\!\!\!\perp D \mid X$ 蕴含 $Y^d \perp\!\!\!\perp D \mid X$，即无混杂性。

**为什么需要"倾向得分非常数"？** 在步骤 6 中，从 $U^d \perp\!\!\!\perp X$ 和 $U^d \perp\!\!\!\perp X \mid D$ 推出 $U^d \perp\!\!\!\perp (X, D)$ 需要 $D$ 与 $X$ 相关（否则 $X \mid D$ 的条件分布与 $X$ 的无条件分布相同，无法提供额外信息）。这正是秩条件/非常数倾向得分的作用。**直观理解**：如果倾向得分是常数，那么 $D$ 与 $X$ 独立，条件化于 $D$ 不会改变 $X$ 的分布，因此 $U^d \perp\!\!\!\perp X \mid D$ 不提供任何关于 $U^d$ 与 $D$ 独立性的信息。

**这个最小内核揭示了什么？** 论文的核心数学贡献是：**一个看似允许内生选择的弱信息约束（CMI），在倾向得分足够变化的条件下，实际上等价于无混杂性**。换句话说，CMI 约束并没有真正"放松"无混杂性——它只是用信息论语言重新表述了它。这是一个**负结果**（在好意义上）：它告诉我们，仅靠"信息不超过潜在异质性"这类约束，无法在不假设无混杂性的情况下识别因果效应；必须要么加强约束（如状态特定约束），要么放弃点识别（转向部分识别）。

**最小内核的推广方向**（论文第 3、4 节）：
- **状态特定约束**（Theorem 3.3）：只对特定处理状态 $d'$ 施加 CMI 约束，允许其他状态存在任意选择。此时边界支撑条件（$P(D=d' \mid X)$ 可以任意接近 1）取代秩条件，给出状态特定的外生性。
- **连续处理**（第 4.2 节）：用条件密度的完备性条件取代秩条件。
- **工具变量**（第 4.3 节）：将 CMI 约束施加在工具变量 $Z$ 与潜在结果之间，而非处理与潜在结果之间。


### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：在允许内生选择的潜在结果模型中，一个基于条件互信息（CMI）的弱信息约束——"潜在结果关于处理的条件信息不超过潜在异质性关于处理的信息"——在什么条件下等价于无混杂性，从而保证因果效应的点识别。
2. **核心工具/方法**：交互信息（interaction information）的对称性分解、乘法因子分解定理（Theorem 3.1）、秩条件（倾向得分向量二阶矩满秩）与边界支撑条件。
3. **主要结论**：在模型 (2.1)–(2.2) 下，CMI 约束等价于处理概率的乘法分解；当倾向得分向量二阶矩满秩时（多元处理）或倾向得分非常数时（二元处理），CMI 约束等价于无混杂性；状态特定 CMI 约束在边界支撑条件下给出状态特定的外生性；连续处理和 IV 设定有相应推广。

#### 关键设定与假设

- **模型 (2.1)**：$Y^d = m^d(X, U^d)$，$U^d \perp\!\!\!\perp X$。这是潜在结果的结构表示，**总是可行**（通过条件秩变换），不施加可检验约束。
- **技术条件 (2.2)**：$U^d \perp\!\!\!\perp D \mid (Y^d, X)$。这要求潜在异质性在给定潜在结果和协变量后不提供额外处理信息。**相比无混杂性 $Y^d \perp\!\!\!\perp D \mid X$，这是一个更弱的条件**——它允许 $D$ 与 $Y^d$ 相关，只要这种相关性完全通过 $X$ 和 $U^d$ 中可被 $Y^d$ 捕捉的部分传导。
- **CMI 约束**：$I(Y^d; D \mid X) \le I(U^d; D)$。这是论文的核心假设，允许 $Y^d$ 与 $D$ 在给定 $X$ 后仍然相关，但要求这种相关性不超过 $U^d$ 与 $D$ 的无条件相关性。
- **秩条件（Assumption 1）**：$E[p(X)p(X)^\top]$ 满秩。对二元处理，等价于 $P(D=1 \mid X)$ 不是常数。**相比已有文献**：这是对倾向得分的变化性要求，与重叠条件（overlap）不同——重叠要求 $0 < P(D=d \mid X) < 1$，而秩条件只要求倾向得分随 $X$ 变化。
- **边界支撑条件（Theorem 3.3）**：$P(P(D=d' \mid X) > 1-\varepsilon) > 0$ 对所有 $\varepsilon > 0$。这允许倾向得分任意接近 1，但不要求达到 1。

#### 主要结果

1. **Theorem 3.1（乘法分解）**：在模型 (2.1)–(2.2) 下，CMI 约束等价于 $P(D=d' \mid U^d, X) = g_{d,d'}(U^d) h_{d'}(X)$，即处理概率分解为潜变量部分和协变量部分的乘积。**证明路线**：由 Lemma A.1 将 CMI 约束转化为 $I(U^d; D \mid X) \le I(U^d; D)$，再由 Lemma A.2 等价于 $I(U^d; X \mid D) = 0$（利用 $U^d \perp\!\!\!\perp X$），最后通过条件密度的乘法分解得到结论。**关键技巧**：交互信息的对称性——$I(U^d; D; X) = I(U^d; D) - I(U^d; D \mid X) = I(U^d; X) - I(U^d; X \mid D)$，结合 $I(U^d; X) = 0$ 将 CMI 约束转化为条件独立性。

2. **Theorem 3.2（等价于无混杂性）**：在模型 (2.1)–(2.2) 和 Assumption 1 下，CMI 约束等价于 $Y^d \perp\!\!\!\perp D \mid X$。**证明路线**：由乘法分解和秩条件，利用 $E[p(X)p(X)^\top]$ 满秩推出 $g_{d,d'}(U^d) = 1$ 几乎必然，从而 $P(D=d' \mid U^d, X) = P(D=d' \mid X)$，即 $D \perp\!\!\!\perp U^d \mid X$，进而 $Y^d \perp\!\!\!\perp D \mid X$。**难点**：从乘法分解到 $g=1$ 的步骤需要秩条件——如果 $p(X)$ 不满秩，则存在非零向量 $a$ 使得 $a^\top p(X) = 0$ 几乎必然，无法识别 $g$。

3. **Theorem 3.3（状态特定约束）**：在模型 (2.1)–(2.2) 下，若 CMI 约束只对状态 $d'$ 成立，且 $P(D=d' \mid X)$ 可以任意接近 1，则 $Y^d \perp\!\!\!\perp \mathbf{1}\{D=d'\} \mid X$。**证明路线**：利用 $I^{d'}(Y^d; D \mid X) \le I^{d'}(U^d; D)$ 和边界支撑条件，通过类似 Lemma A.2 的论证得到 $U^d \perp\!\!\!\perp \mathbf{1}\{D=d'\} \mid X$。**与 Theorem 3.2 的区别**：这里不需要秩条件，但需要边界支撑——直观上，如果某个协变量组中 $D=d'$ 几乎必然发生，那么在这个组内 $D$ 不提供关于 $U^d$ 的信息。

4. **Theorem 4.2（连续处理）**：在连续处理下，若 $Y^d$ 有界、$r^d(\cdot, u) - 1 \in H$、点态相关性和 Lipschitz 条件成立，则 $E[Y^d \mid X] = E[Y \mid D=d, X]$。**证明路线**：利用乘法分解的连续版本和点态相关性条件，通过条件期望的展开和 Lipschitz 控制误差项。**技术技巧**：将离散处理的秩条件替换为连续处理的完备性条件（点态相关性），用 Lipschitz 条件控制 $D$ 接近 $d$ 时的近似误差。

#### 真实例子与应用

- **Example 2.4（选择可观测与不可观测）**：一个三状态处理（不参与、培训类型 1、培训类型 2）的例子。参与决策基于潜变量 $U^d$，类型分配基于协变量 $X$。该例子说明 CMI 约束允许"参与选择"但排除"类型选择"中的不可观测混杂。
- **Example 3.1（ATT）**：用 CMI 约束识别平均处理效应（ATT）。核心逻辑：只需对未处理状态施加 CMI 约束，结合边界支撑条件（$P(D=1 \mid X)$ 可以任意接近 0），即可识别 $E[Y^0 \mid D=1]$。
- **Example 3.2（Roy 模型）**：三部门 Roy 模型，说明状态特定 CMI 约束如何排除基于比较优势的选择，同时允许基于绝对优势的选择。
- **附录 B（模拟）**：用 Chen-Fang (2019) 秩检验评估 Assumption 1 的有限样本表现。设计：$D \in \{0,1,2\}$，$X$ 离散（3 个取值）或连续（正态），$\theta$ 控制选择机制。结果：离散设计在 $n=500$ 时秩检验过度拒绝（拒绝率 0.087–0.193），$n=5000$ 时接近名义水平；连续设计在所有样本量下表现良好。**这个模拟说明**：秩条件的检验在离散协变量和小样本下可能不可靠，需要谨慎解释。

#### 🔎 结论是否比证明窄

- **Theorem 3.2 的陈述**是"CMI 约束等价于无混杂性"，但**证明依赖于模型 (2.1)–(2.2)**，特别是 $U^d \perp\!\!\!\perp X$ 和 $U^d \perp\!\!\!\perp D \mid (Y^d, X)$。作者在引言中声称"CMI 约束允许内生选择"，但 Theorem 3.2 表明在秩条件下它**不允许**——这是一个值得注意的落差。**具体语句**：Theorem 3.2 的陈述是"Then CMIR(d) is equivalent to $Y^d \perp\!\!\!\perp D \mid X$"，但证明中使用了 Lemma A.2，而 Lemma A.2 的证明依赖于 $U^d \perp\!\!\!\perp X$。如果 $U^d$ 与 $X$ 相关（例如，潜在异质性受协变量影响），则 CMI 约束不再等价于无混杂性。
- **Theorem 3.3 的陈述**是"状态特定 CMI 约束 + 边界支撑 ⇒ 状态特定外生性"，但**证明中假设了 $P(D=d' \mid X)$ 可以任意接近 1**。这个边界支撑条件在实证中可能难以验证——它要求存在协变量组使得处理状态几乎必然发生。作者在讨论中承认这一点，但**没有提供检验边界支撑的方法**。
- **Theorem 4.2 的陈述**是"连续处理下 CMI 约束 + 点态相关性 ⇒ 条件均值识别"，但**证明中假设了 Lipschitz 条件和 $r^d(\cdot, u) - 1 \in H$**。这些条件在实证中难以验证，且 $H$ 的选择会影响结论。作者没有讨论 $H$ 的选择如何影响识别结果。

### 四、开放问题

1. **CMI 约束的可检验性**（扎根于 Theorem 3.2 和附录 B）：作者证明了 CMI 约束在秩条件下等价于无混杂性，但秩条件本身（Assumption 1）只涉及可观测的 $(D, X)$ 分布，可以用 Chen-Fang (2019) 检验。然而，**CMI 约束本身是否可检验**？作者没有给出直接检验 CMI 约束的方法——他检验的是秩条件，而非 CMI 约束。如果 CMI 约束不可检验，那么它在实证中的价值就仅限于"理论上的合理性论证"。

2. **$U^d \perp\!\!\!\perp X$ 的稳健性**（扎根于模型 (2.1)）：这个假设是 Lemma A.2 的关键，但作者没有讨论如果 $U^d$ 与 $X$ 相关会怎样。在实证中，潜在异质性几乎必然与协变量相关（例如，能力与教育相关）。**一个值得探索的问题**：如果 $U^d$ 与 $X$ 相关，CMI 约束是否仍然有界？能否推导出识别偏误的界限？

3. **边界支撑条件的验证**（扎根于 Theorem 3.3）：作者证明了边界支撑条件下状态特定 CMI 约束等价于状态特定外生性，但**没有提供检验边界支撑的方法**。在实证中，如何判断是否存在协变量组使得处理状态几乎必然发生？这可能需要新的检验方法。

4. **连续处理的完备性条件**（扎根于 Assumption 2 和 Theorem 4.2）：作者用完备性条件取代秩条件，但完备性条件在实证中更难验证。**一个开放问题**：能否用更弱的条件（如近似完备性）替代？近似完备性条件下的识别偏误有多大？

5. **信息论约束与参数模型的衔接**（扎根于引言中的文献综述）：CMI 约束是非参数的，但实证研究者通常使用参数模型（如 Logit/Probit 倾向得分模型）。**一个值得探索的问题**：在参数模型中，CMI 约束对应什么参数约束？能否用似然比检验来验证？
