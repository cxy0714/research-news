### 一、子领域定位

- **本文属于天文学的哪一支**：**河外天文学与星系演化**（galactic astronomy / galaxy evolution），具体是**星系团（galaxy cluster）**方向。核心科学问题是：星系团（宇宙中最大的引力束缚结构）如何形成和演化？其中的星系（从巨椭圆星系到矮星系）如何在不同环境（团中心高密度 vs. 团外围低密度）中诞生、成长、并最终"熄灭"（停止形成恒星）？这个领域目前处于"大巡天时代"：用大型望远镜对天区进行深度成像，产出包含成千上万个天体的目录，再基于目录做统计推断。成熟度很高，但数据产品的质量控制和选择效应处理是永恒主题。
- **本文在这个子领域里的位置**：它不解决某个具体的科学问题，而是**发布核心数据产品**——室女座星系团（Virgo Cluster）的最终星系目录。它针对的切片是：**"我们到底知道这个最近的大星系团里有哪些星系？"** 这是几乎所有后续研究（恒星质量函数、形态-环境关系、星系 quenching 机制等）的基础设施。没有可靠的目录，一切下游统计都是空中楼阁。

### 二、关键术语扫盲（充分展开，目标是读者将来能继续读该领域文献）

1. **星系团（Galaxy Cluster）**：由数百到数千个星系组成的巨大结构，被暗物质（dark matter）的引力束缚在一起。室女座星系团是离我们最近的大星系团，距离约 1650 万光年（16.5 Mpc），是研究星系演化的"天然实验室"。
2. **巡天（Survey）**：系统性、大范围地观测天空的计划。NGVS 就是一个巡天：用加拿大-法国-夏威夷望远镜（CFHT）上的 MegaCam 相机，对室女座星系团所在的 104 平方度天区进行深度成像。
3. **测光（Photometry）**：测量天体在不同波段（如紫外、光学、红外）的亮度。通过比较不同波段的亮度（颜色），可以推断天体的物理性质（如温度、恒星质量、恒星形成历史）。本文的 `u*`、`g`、`i`、`z` 就是四个不同的光学/近红外波段。
4. **星等（Magnitude）**：天文学中表示亮度的对数单位。星等越小越亮。`g = 8.42` 到 `g = 24.41` 意味着目录里的星系亮度跨度达 250 万倍。星等系统是理解数据动态范围的关键。
5. **红移（Redshift, z）**：由于宇宙膨胀，遥远天体的光会向长波方向移动。红移越大，天体越远。本文用 `z < 1` 表示背景星系团的距离。对于室女座星系团本身，其红移接近 0（非常近）。
6. **光谱（Spectroscopy）**：将天体的光分解成不同波长的光谱，可以精确测量红移、化学成分、恒星运动速度等。本文中，光谱数据（径向速度）用于确认星系是否真的属于室女座星系团（即"成员资格"）。
7. **径向速度（Radial Velocity, v）**：天体沿视线方向的运动速度。通过测量星系的光谱线偏移可以得到。本文用 `v < 3,500 km/s` 作为判断星系是否属于室女座星系团的标准。
8. **Sérsic 轮廓（Sérsic Profile）**：描述星系表面亮度随半径分布的数学函数。参数 `n`（Sérsic 指数）描述星系中心亮度的集中程度：`n` 大（如 4）对应椭圆星系，`n` 小（如 1）对应盘状星系。这是量化星系形态的核心工具。
9. **有效半径（Effective Radius, Re）**：星系总亮度一半所在的半径。是描述星系大小的标准量。
10. **恒星质量（Stellar Mass, M★）**：星系中所有恒星的总质量。本文通过测光数据（颜色）和光谱能量分布（SED）拟合来估计。这是连接观测与理论的桥梁。
11. **恒星形成（Star Formation）**：星系中气体坍缩形成新恒星的过程。恒星形成活跃的星系通常呈蓝色，而停止恒星形成的星系（quiescent）通常呈红色。这是星系演化的核心指标。
12. **形态分类（Morphological Classification）**：根据星系的外观（椭圆、旋涡、不规则等）进行分类。本文使用的分类体系（E, S, I 等）是理解星系类型与环境关系的基础。
13. **核星团（Nuclear Star Cluster, NSC）**：位于星系正中心的、致密的恒星集团。其存在与否与星系的质量、环境密切相关。
14. **完备性（Completeness）**：目录中包含的真实天体比例。由于观测深度和算法限制，暗弱天体可能被遗漏。本文通过注入人工星系（模拟）来评估完备性。
15. **纯度（Purity）**：目录中真正属于目标类别（这里是室女座星系团成员）的天体比例。背景星系、前景恒星都可能被误判为成员。
16. **选择效应（Selection Effect）**：由于观测限制（如亮度极限、天区覆盖）导致的样本偏差。这是天文统计中最核心的挑战之一。
17. **视星等 vs 绝对星等（Apparent vs Absolute Magnitude）**：视星等是地球上看到的亮度，绝对星等是天体在统一距离（10秒差距）下的亮度。绝对星等反映了天体的真实光度。
18. **距离模数（Distance Modulus）**：视星等与绝对星等之差，由天体距离决定。本文假设室女座星系团所有星系距离相同（16.5 Mpc），因此视星等差等于绝对星等差。
19. **尘埃消光（Extinction）**：星际尘埃会吸收和散射星光，使天体看起来更暗、更红。本文用 `E(B-V)` 来校正银河系前景尘埃的影响。
20. **点扩散函数（Point Spread Function, PSF）**：描述点光源（如恒星）在望远镜图像中如何扩散的函数。PSF 的宽度决定了图像的分辨率，也影响对星系核的探测。

### 三、天文学家关心的问题

天文学家在追问一个宏大问题：**星系是如何在宇宙时间中形成和演化的？** 具体到星系团环境，他们关心：

1. **环境如何影响星系？** 在星系团这种高密度环境中，星系会经历与在空旷区域完全不同的物理过程：与团内高温气体的相互作用（冲压剥离，ram-pressure stripping）、与其它星系的碰撞合并（merger）、以及被团引力场束缚而失去气体供应。这些过程会"熄灭"（quench）星系的恒星形成，将其从蓝色、活跃的旋涡星系转变为红色、宁静的椭圆星系。**形态-密度关系**（morphology-density relation）——即椭圆星系更可能出现在高密度区域——是这一领域最经典的观测事实之一。
2. **星系的"人口普查"是怎样的？** 星系团里有多少星系？它们的质量分布如何（恒星质量函数）？有多少矮星系、多少巨星系？这个"人口结构"是星系形成理论的直接预测，也是检验宇宙学模型的标尺。
3. **星系团本身的结构如何？** 星系团不是均匀的球体，它有子结构（substructure）、有正在坠入的星系群（infalling groups）、有潮汐尾（tidal tails）等。这些结构记录了星系团自身的形成历史。
4. **暗物质如何分布？** 通过星系的位置和运动，可以反推星系团的总质量分布（包括暗物质）。这为检验暗物质模型提供了关键约束。

**本文的角色**：它不直接回答这些问题，而是提供回答这些问题所需的**最基础、最可靠的"名单"**——谁是室女座星系团的成员？它们有多亮、多大、什么形状、多少恒星质量？这份名单的完备性和纯度，直接决定了所有下游研究的可靠性。本文的核心贡献在于：**用深度、均匀、多波段的观测数据，加上严格的完备性检验，产出了一份比以往任何目录都更完整、更可靠的星系名单。**

**主流分析方法与局限**（结合被引文献）：
- **星系探测与测光**：主流方法是使用 `SExtractor`（Bertin & Arnouts 1996）等软件在图像上探测天体并测量其亮度。局限：对暗弱、弥散的低表面亮度星系（如矮星系）探测效率低，容易遗漏；对靠近亮星的区域（如星系团中心）探测困难。本文的 `VCands` 算法（详见第四节）正是针对这一局限设计的。
- **星系结构拟合**：使用 `GALFIT`（Peng et al. 2002）等软件对星系图像进行二维拟合，提取 Sérsic 参数（亮度、有效半径、Sérsic 指数等）。局限：对复杂形态（如旋臂、棒、潮汐尾）拟合不佳，参数可能不唯一。
- **恒星质量估计**：通过测光数据（多波段颜色）与恒星种群合成模型（如 Bruzual & Charlot 2003）拟合，估计恒星质量。局限：模型依赖初始质量函数（IMF）、恒星形成历史等假设，不同模型间存在系统差异。
- **成员资格判定**：主要依赖光谱红移（径向速度）。局限：对暗弱星系难以获得光谱，导致成员资格判定不完整。本文结合形态、颜色、表面亮度等多种判据，并利用背景场（background fields）来估计污染率。

### 四、数据问题（统计学家最该关注的部分）

- **数据来源**：加拿大-法国-夏威夷望远镜（CFHT）上的 MegaCam 相机。这是一个宽视场光学相机，单次曝光覆盖 1 平方度天区。
- **数据形态**：
  - **成像数据（Imaging）**：在 `u*`、`g`、`i`、`z` 四个波段对 104 平方度天区进行深度成像。这是**二维图像**，每个像素记录了该位置的亮度（流量）。
  - **目录（Catalog）**：从图像中提取出的天体列表，每个天体包含位置（赤经、赤纬）、各波段亮度（星等）、形态参数（Sérsic 指数、有效半径、椭率等）、颜色、恒星质量等。这是**表格数据**，是统计分析的主要对象。
  - **光谱数据（Spectroscopy）**：部分星系有径向速度测量，用于确认成员资格。
- **维度和量级**：104 平方度天区，约 11,000 个候选天体经过人工目视检查，最终 3,680 个被确认为室女座星系团成员。光度范围 `g = 8.42` 到 `g = 24.41` 等（跨度 250 万倍）。
- **噪声模型 & 测量误差**：
  - **光子噪声（Poisson noise）**：亮度测量的基本噪声，暗弱天体噪声相对更大。
  - **天空背景（Sky background）**：大气和仪器产生的背景光，需要精确扣除，其不确定性是低表面亮度测量的主要误差来源。
  - **PSF 变化**：不同位置、不同波段的图像清晰度（PSF）有差异，影响对星系结构的测量。
  - **测光误差**：目录中给出了每个星系的星等误差，但**这些误差可能被低估**，因为它们通常只考虑光子噪声，而忽略了系统误差（如背景扣除不准、PSF 模型不准）。
- **选择效应 / 系统性偏倚**：
  - **完备性（Completeness）**：暗弱、低表面亮度的星系容易被遗漏。本文通过注入人工星系模拟来量化完备性，发现目录在 `g = 18.6` 等（对应 `M_g = -12.5` 等）处完全完备，在 `g = 22.0` 等（`M_g = -9.1` 等）处 50% 完备。
  - **纯度（Purity）**：背景星系、前景恒星可能被误判为团成员。本文通过背景场观测和多种判据（形态、颜色、速度）来控制污染，估计污染率低于 1%。
  - **表面亮度选择效应**：这是最隐蔽的偏倚。目录对高表面亮度的星系（即使是暗弱的）探测效率高，但对低表面亮度的弥散星系（如超弥散星系 UDG）探测效率低。**这意味着目录在"表面亮度-星等"平面上是不均匀的**，任何基于该目录的统计推断都必须考虑这一点。
  - **Malmquist 偏倚**：在星等极限附近，由于测量误差， intrinsically 更亮的星系更容易被探测到，导致亮端计数偏高。本文通过完备性模拟来校正。
- **缺失 / 截断 / 计算约束**：
  - **缺失**：并非所有星系都有光谱（径向速度），因此成员资格判定依赖多种信息。
  - **截断**：目录在星等和表面亮度上都有截断，这是本质上的数据缺失。
  - **计算约束**：对 11,000 个天体进行人工目视检查是极其耗时的，这本身就是一种"人工"质量控制，但也引入了主观性。

**哪些是"漂亮的统计学问题"**：
1. **完备性函数的估计**：如何从注入模拟中准确估计探测概率作为星等、表面亮度、形态的函数？这是一个典型的**缺失数据问题**，可以用广义线性模型或非参数方法建模。
2. **成员资格分类的不确定性**：每个星系都有一定的概率是团成员，如何将这个概率传播到下游的统计推断（如恒星质量函数）中？这是一个**测量误差模型**问题。
3. **多波段数据的联合建模**：如何利用 `u*`、`g`、`i`、`z` 四个波段的信息来更准确地估计物理参数（如恒星质量、恒星形成率）？这是一个**多指标测量误差**问题。

**哪些是"纯工程难题"**：
1. **图像处理**：暗弱天体的探测、去混叠（deblending）、背景扣除，这些需要复杂的图像处理算法，但更多是工程问题而非统计问题。
2. **PSF 建模**：精确测量和建模 PSF 的空间变化，是天文数据处理的常规但繁琐的任务。
3. **人工目视检查**：虽然必要，但效率低、主观性强，是当前流程的瓶颈。

### 五、模型问题（统计学家最该关注的部分）

- **文章建立的模型/方法用直白语言重述**：
  1. **星系探测模型（`VCands`）**：这是一个**多步骤的启发式算法**，而非概率模型。它首先用 `SExtractor` 进行初步探测，然后通过一系列基于形态和光度的判据（如表面亮度、浓度指数）筛选候选体，最后通过人工目视检查确认。其核心思想是：**针对低表面亮度星系优化探测**，通过图像预处理（如平滑、背景扣除）和判据调整来提高对弥散天体的灵敏度。
  2. **星系结构模型**：用 Sérsic 函数（或 core-Sérsic 函数）拟合星系的表面亮度分布。这是一个**参数模型**，参数包括总星等、有效半径、Sérsic 指数 `n`、椭率等。拟合方法是最小二乘法（`GALFIT`）或贝叶斯方法（`Typhon`）。
  3. **恒星质量估计模型**：通过 SED 拟合（`Prospector` + `FSPS`）来估计恒星质量。这是一个**物理模型**，将观测到的多波段亮度与恒星种群合成模型的预测进行比较，通过 MCMC 采样得到参数的后验分布。
  4. **成员资格判定模型**：这是一个**分类问题**，综合了多种信息（形态、颜色、表面亮度、径向速度）来判定星系是否属于室女座星系团。本文采用的是**经验判据 + 人工检查**，而非概率分类器。

- **模型的关键假设**：
  - **Sérsic 模型假设**：假设星系的表面亮度分布可以用 Sérsic 函数描述。这对大多数星系是合理的，但对形态复杂的星系（如相互作用星系、有潮汐尾的星系）可能不适用。
  - **SED 拟合假设**：假设恒星种群合成模型（FSPS）是准确的，且初始质量函数（IMF）已知（本文采用 Chabrier IMF）。这些假设存在系统不确定性。
  - **成员资格判定假设**：假设形态、颜色等判据能有效区分团成员和背景星系。这个假设在高红移或特殊星系（如极蓝的矮星系）上可能失效。

- **推断手段**：
  - **点估计与误差传播**：对于结构参数，使用最小二乘拟合，误差由拟合协方差矩阵给出。
  - **贝叶斯推断**：对于恒星质量，使用 MCMC（`emcee`）采样，得到参数的后验分布。
  - **模型选择**：使用 BIC（贝叶斯信息准则）在"含尘"与"不含尘"模型之间进行选择。
  - **经验校准**：通过注入模拟来校准完备性，通过背景场来估计污染率。

- **核心数值结论与不确定性量化方式**：
  - **目录规模**：3,680 个星系，其中 1,690 个（46%）为确定成员，802 个（22%）为可能成员，1,188 个（32%）为疑似成员。
  - **完备性**：在 `g = 18.6` 等（`M_g = -12.5` 等）处完全完备，在 `g = 22.0` 等（`M_g = -9.1` 等）处 50% 完备。
  - **污染率**：通过背景场估计，污染率低于 1%。
  - **不确定性量化**：对于每个星系，给出了星等、结构参数、恒星质量的误差估计。但**这些误差估计可能没有完全包含系统误差**（如模型选择、背景扣除、PSF 不确定性）。

1. **这篇文章作为入门读物质量如何？**
   - **打分：2/5**
   - **理由**：这是一篇**数据发布论文**，其核心是目录本身，而非方法或科学发现。对完全不懂天文的统计学家来说，它**不是**好的第一篇。文章充满了天文术语（Sérsic 指数、星等、红移、PSF）和大量表格，但没有对核心概念进行解释。它假设读者已经熟悉星系天文学的基本框架。作为入门读物，它更像是一本"电话簿"，而不是一本"教科书"。**更好的入门选择**是：先读一篇关于星系形成的综述（如 Mo, van den Bosch & White 的《Galaxy Formation and Evolution》教材），或者一篇关于星系团研究的综述文章。

2. **这个问题值不值得统计学家进入工作？**
   - **(i) 科学重要性**：**高**。星系团是理解宇宙结构形成和星系演化的关键。室女座星系团作为最近的大星系团，是检验星系演化模型的"标准实验室"。这份目录是未来十年该领域研究的基础数据。天文学家**非常在乎**这份目录的可靠性和完备性。
   - **(ii) 方法学空间**：**中等偏上**。虽然本文使用的方法是相对标准的（SExtractor + GALFIT + SED fitting），但数据本身提出了几个**真正的统计挑战**：
       - **完备性函数的非参数估计**：如何准确估计探测概率作为星等、表面亮度、形态的复杂函数？这需要灵活的统计模型，且要处理高维协变量。
       - **测量误差的传播**：星等、结构参数、恒星质量都有不确定性，如何将这些不确定性正确传播到下游的统计推断（如恒星质量函数、形态-密度关系）中？这是一个典型的**errors-in-variables** 问题。
       - **成员资格的不确定性**：如何将成员资格的概率性（而非确定性）纳入统计分析？这类似于**分类不确定性**问题。
       - **选择效应的建模**：如何对"表面亮度-星等"平面上的复杂选择效应进行建模和校正？这需要**逆概率加权**或**多重插补**等思想。
   - **(iii) 社区开放性**：**中等**。天文学界对方法学贡献的接受度在提高，但**门槛较高**。统计学家需要证明其方法能解决天文学家真正关心的问题，并且要处理真实数据的复杂性（如系统误差、计算约束）。合作是关键。作者团队中目前没有统计学家，但这类大型巡天项目通常对方法学合作持开放态度。
   - **(iv) 武器库匹配度**：
     - **非参数统计**：完备性函数的估计、Sérsic 轮廓的非参数拟合，直接用到你的非参数方法。**够用**。
     - **高维渐近与极小极大界**：处理高维协变量（星等、颜色、表面亮度、形态）下的完备性估计，你的高维理论背景**直接相关**。
     - **逆问题**：从观测的二维图像反推星系的物理参数（如质量分布），是一个典型的**逆问题**，你的逆问题理论背景**有用**。
     - **高阶 U-统计量**：星系团中星系的**成对关联函数**（two-point correlation function）是宇宙学统计的核心对象，其估计量本质上是 U-统计量。你的 U-统计量计算复杂度理论（treewidth / tensor contraction）**可能**在计算大规模星系目录的关联函数时找到应用，但这需要额外的领域知识。
     - **因果推断**：天文学中"环境对星系演化的因果效应"是一个热门话题，但**识别假设极难成立**（无法随机分配星系到不同环境）。你的因果推断背景**可能**有用，但需要非常谨慎地处理。
     - **缺失数据**：成员资格缺失、部分星系缺乏光谱数据，你的缺失数据理论**直接相关**。
     - **软件工程**：你的软件工程能力是巨大优势，天文数据分析需要大量可复现的工具。
   - **结论**：**值得进入**。这个方向有真实的科学价值，且数据特性（高维、强选择效应、复杂测量误差）提出了非平凡的统计挑战。你的非参数、高维、逆问题背景**足够**应对核心挑战。**主要缺口**是：需要补充天文学背景知识（至少理解星系的基本物理和观测手段），以及需要与天文学家建立合作。

3. **若值得进入，研究者能做的具体问题（最多 2 条）**：
   - **问题 1：完备性函数的非参数估计与不确定性量化**。`VCands` 的完备性目前是通过注入模拟 + 人工检查来评估的，但这种方法没有给出完备性函数的**形式化统计模型**，也无法方便地传播不确定性。你可以开发一个**非参数模型**（如高斯过程或稀疏加性模型），将探测概率建模为星等、表面亮度、有效半径、Sérsic 指数等协变量的函数，并利用注入模拟数据（已知真实标签）来拟合。这直接用到你的**非参数统计**和**高维渐近**武器。第一步动作：仔细阅读本文第 4 节和 NGVS-XIV 的模拟部分，理解注入模拟的数据生成过程，然后设计一个模拟研究来比较不同非参数估计器的表现。
   - **问题 2：测量误差对恒星质量函数估计的影响**。恒星质量是通过 SED 拟合得到的，带有不确定性。当估计恒星质量函数（SMF）时，这些不确定性会导致**埃德温顿偏倚**（Eddington bias），即质量函数被"抹平"。你可以开发一个**测量误差模型**，将 SED 拟合的后验分布作为"代理"变量，来校正 SMF 的估计。这直接用到你的**逆问题**和**半参数理论**背景。第一步动作：阅读本文第 6 节，理解恒星质量的估计过程，然后设计一个模拟研究，比较朴素估计量与你的测量误差校正估计量的偏差和方差。

4. **如果一个统计学家想进入这个方向，下一步该读什么？**
   - **入门综述**：
     - **《Galaxy Formation and Evolution》by Mo, van den Bosch & White (2010)**：这是星系形成领域的标准教材，第 1-4 章提供了必要的天文学背景（星系的基本性质、观测手段、宇宙学背景）。
     - **《The Large-Scale Structure of the Universe》by P.J.E. Peebles (1980)**：经典教材，提供了宇宙学统计（关联函数、功率谱）的数学基础。
   - **方法学奠基论文**：
     - **Bertin, E., & Arnouts, S. 1996, A&AS, 117, 393**：`SExtractor` 的原始论文，是星系探测的标准工具，理解其算法是理解所有巡天数据的基础。
     - **Peng, C. Y., et al. 2002, AJ, 124, 266**：`GALFIT` 的原始论文，是星系结构拟合的标准工具。
     - **Conroy, C., Gunn, J. E., & White, M. 2009, ApJ, 699, 990**：`FSPS` 恒星种群合成模型的论文，是理解恒星质量估计的基础。
     - **Kim, S., et al. 2014, ApJS, 215, 22**：EVCC 论文，是理解室女座星系团成员资格判定的关键参考。
   - **可上手的数据集**：
     - **室女座星系团目录**：本文发布的目录（NGVS 官网可下载）。
     - **SDSS 星系目录**：斯隆数字巡天（Sloan Digital Sky Survey）的公开数据，是练习星系统计的绝佳数据集。
     - **KiDS / DES 弱引力透镜数据**：如果对宇宙学统计感兴趣，这些是当前的前沿数据。

### 七、术语表

| 英文术语 | 中文 | 一句话解释 |
| :--- | :--- | :--- |
| **Galaxy Cluster** | 星系团 | 由数百至数千个星系组成的巨大引力束缚结构，是宇宙中最大的平衡结构。 |
| **Virgo Cluster** | 室女座星系团 | 离我们最近的大星系团，距离约 1650 万光年，是研究星系演化的理想实验室。 |
| **Survey** | 巡天 | 对大面积天区进行系统性观测的计划，目的是产出均匀、完整的天体目录。 |
| **Photometry** | 测光 | 测量天体在不同波段（如 `u*`、`g`、`i`、`z`）亮度的技术。 |
| **Magnitude** | 星等 | 天文学中表示亮度的对数单位，数值越小越亮。 |
| **Redshift (z)** | 红移 | 由于宇宙膨胀，天体光谱线向长波方向移动的量，用于衡量天体距离。 |
| **Spectroscopy** | 光谱学 | 将天体的光分解成不同波长成分的技术，用于测量红移、化学成分、运动速度等。 |
| **Radial Velocity** | 径向速度 | 天体沿视线方向的运动速度，通过光谱线偏移测量。 |
| **Sérsic Profile** | Sérsic 轮廓 | 描述星系表面亮度分布的数学函数，参数 `n` 刻画中心集中度。 |
| **Effective Radius (Re)** | 有效半径 | 星系总亮度一半所在的半径，是描述星系大小的标准量。 |
| **Stellar Mass (M★)** | 恒星质量 | 星系中所有恒星的总质量，是连接观测与理论的核心物理量。 |
| **Star Formation** | 恒星形成 | 星系中气体坍缩形成新恒星的过程，是星系演化的核心指标。 |
| **Morphological Classification** | 形态分类 | 根据星系外观（椭圆、旋涡、不规则等）进行分类。 |
| **Nuclear Star Cluster (NSC)** | 核星团 | 星系正中心的致密恒星集团，其存在与星系性质密切相关。 |
| **Completeness** | 完备性 | 目录中包含的真实天体比例，是衡量数据质量的关键指标。 |
| **Purity** | 纯度 | 目录中真正属于目标类别的天体比例，衡量污染程度。 |
| **Selection Effect** | 选择效应 | 由于观测限制（如亮度极限）导致的样本系统性偏差。 |
| **Malmquist Bias** | 马尔姆奎斯特偏倚 | 在星等极限附近，测量误差导致 intrinsically 更亮的天体更容易被探测到，从而高估亮端计数。 |
| **Point Spread Function (PSF)** | 点扩散函数 | 描述点光源在图像中如何扩散的函数，决定图像分辨率。 |
| **Extinction** | 消光 | 星际尘埃对星光的吸收和散射，使天体变暗变红。 |
| **SED Fitting** | 光谱能量分布拟合 | 通过多波段测光数据与理论模型比较，估计星系的物理参数（如恒星质量）。 |
| **SExtractor** | 源提取器 | 一种广泛使用的软件，用于在天文图像中探测天体并测量其性质。 |
| **GALFIT** | 星系拟合软件 | 一种用于对星系图像进行二维拟合，提取结构参数的软件。 |
| **Prospector** | 光谱能量分布拟合软件 | 一种用于 SED 拟合的软件包，基于贝叶斯方法。 |
| **FSPS** | 灵活恒星种群合成 | 一种用于生成恒星种群光谱模型的代码库，是 SED 拟合的基础。 |
| **Quenching** | 熄灭 | 星系停止形成恒星的过程，是星系演化的关键转变。 |
| **Ram-Pressure Stripping** | 冲压剥离 | 星系在星系团中高速运动时，被团内高温气体剥离自身气体的过程。 |
