### 一、领域脉络与小综述

#### 这个方向是什么

本文属于**纯数学中的表示论（representation theory）**，具体是 Artin 代数的同调代数性质研究。核心问题是 **Cartan 行列式猜想（Cartan determinant conjecture）**：对有限整体维数（finite global dimension）的 Artin 代数，其 Cartan 矩阵的行列式是否总为正（即等于 1，因为可逆整数矩阵的行列式只能是 ±1）。这是一个自 1954 年 Eilenberg 奠基以来悬而未决的猜想，目前只在若干特殊代数类上被证实。该方向与统计推断、高维统计、计算复杂性**无直接关联**，属于纯代数结构理论。

#### 发展脉络（history）

- **奠基工作（1954）**：Eilenberg [3] 证明了有限整体维数的有限维代数的 Cartan 矩阵是**幺模的（unimodular）**，即行列式为 ±1。这为猜想提供了"符号问题"的框架——行列式非零已知，但符号是否恒为正未知。
- **关键进展（1983）**：Zacharia [6] 证明了**整体维数至多 2** 的 Artin 代数的 Cartan 行列式猜想。这是本文的直接基石——本文的证明最终归结为对 Zacharia 定理的调用。
- **约化方法（1998）**：Burgess–Fuller [1] 发展了通过投射分解进行矩阵约化的技术，将 Cartan 行列式的计算与 idempotent corner 的行列式联系起来。这是本文证明的核心工具之一。
- **表示有限型（2026，预印本）**：Chen–Guo [2] 证明了表示有限型（representation-finite）Artin 代数的猜想。这是近期最重要的进展之一。
- **idempotent 子代数比较（2017）**：Ingalls–Paquette [4] 在 Yoneda 代数的有限整体维数假设下比较代数与其 corner 的同调行为，提供了另一种约化视角。
- **本文位置（2026）**：Tang 证明了**整体维数至多 2 的 Artin 代数的任意有限整体维数 corner** 满足猜想，并由此推出 **torsionless-finite Artin 代数** 的情形。这是对 Zacharia 定理的推广——Zacharia 处理的是代数本身，本文处理的是其 corner。

#### 子线索聚类

1. **直接证明线索**：Zacharia [6] 对 gl.dim ≤ 2 的直接证明；Chen–Guo [2] 对表示有限型代数的证明。本文属于此线索的延伸。
2. **约化/比较线索**：Burgess–Fuller [1] 的矩阵约化；Ingalls–Paquette [4] 的 idempotent 子代数比较。本文的证明方法属于此线索——通过 corner 约化将一般情形化归到 Zacharia 定理。
3. **特殊代数类线索**：torsionless-finite 代数（Ringel [5] 引入的概念）——本文的 Theorem B 属于此线索。

#### 这个方向在追问的核心问题

1. **猜想的一般形式**：是否所有有限整体维数的 Artin 代数都满足 det C = 1？目前无反例也无完整证明。
2. **约化方法的极限**：corner 约化能覆盖哪些代数类？是否存在无法通过 corner 约化处理的障碍？
3. **torsionless-finite 与表示有限型的关系**：torsionless-finite 是比表示有限型更广的类，本文的 Theorem B 是 Chen–Guo [2] 结果的推广。

#### ⚠️ 作者的 framing（必须明确标注成"这是作者的说法"）

作者将本文定位为"Zacharia 定理的 corner 推广"：**"Zacharia proved this for Artin algebras of global dimension at most two in 1983 [6]"**，而本文证明的是 **"the Cartan determinant conjecture for every corner of finite global dimension in an Artin algebra of global dimension at most two"**。作者通过 corner 约化将问题化归到 Zacharia 定理，并由此推出 torsionless-finite 情形。**注意**：作者在摘要中声称"Consequently, the conjecture holds for torsionless-finite Artin algebras"，这是作者对 Theorem B 的 framing——torsionless-finite 代数的整体维数有限时，其自身作为 corner（取 e=1）满足 Theorem A 的条件。

**值得研究者去查的问题**：作者在引言中未提及任何关于猜想一般形式的负面结果或障碍。一个值得查证的问题是：**是否存在整体维数 > 2 的 Artin 代数，其 corner 的 Cartan 行列式为负？** 如果存在，则 corner 约化方法有本质局限。另一个问题是：**Chen–Guo [2] 的表示有限型结果与本文的 torsionless-finite 结果之间是否有重叠或包含关系？** 作者未讨论这一点。

#### 张力

未见明显对立引用。各工作之间是递进关系：Eilenberg → Zacharia → Burgess–Fuller → Chen–Guo → 本文。唯一潜在的张力是：**corner 约化方法是否对所有代数都有效**——作者证明了 gl.dim ≤ 2 的情形，但未讨论一般情形下 corner 约化的可行性。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：把符号、模型、可观测数据交代清楚

**符号**（逐个点名）：

- **A**：Artin 代数（作为交换 Artin 环 K 上的有限生成模），是本文的研究对象。
- **S₁, ..., Sₙ**：A 的右模的**单模同构类代表元**（simple right modules）。
- **P₁, ..., Pₙ**：对应的**不可分解投射覆盖**（indecomposable projective covers）。
- **C_A = ( [Pⱼ : Sᵢ] )_{1≤i,j≤n}**：**Cartan 矩阵**，其中 [Pⱼ : Sᵢ] 是 Pⱼ 的合成列中 Sᵢ 的**合成重数**（composition multiplicity）。这是整数矩阵，行指标 i 对应单模，列指标 j 对应投射模。
- **gl.dim A**：A 的**整体维数**（global dimension），即所有右模的投射维数的上确界。
- **e ∈ A**：**幂等元**（idempotent，e² = e）。**corner** eAe 是以 e 为单位元的子代数。
- **det C_A**：Cartan 矩阵的行列式。**猜想断言：若 gl.dim A < ∞，则 det C_A = 1**。
- **mod B / proj B**：B 的有限生成右模范畴 / 投射模范畴。
- **pd_B N**：模 N 的投射维数。
- **ℓ_K V**：K-模 V 的**合成长度**（composition length）。
- **add W**：由对象 W 的有限直和的直和因子构成的加法子范畴。
- **F: mod R → mod A, F(N) = Ne**：**求值函子**（evaluation functor），把 R-模映到其在 e 上的分量。这是本文证明的核心工具——它把 R 的投射模映到 A 的投射模。

**模型 / 数据生成机制**：

- **代数结构**：A 是 Artin 代数，其模范畴 mod A 是 Krull–Schmidt 范畴（每个对象唯一分解为不可分解对象的直和）。
- **Cartan 矩阵的构造**：对每个不可分解投射模 Pⱼ，计算其合成列中每个单模 Sᵢ 出现的次数，填入矩阵第 i 行第 j 列。
- **有限整体维数假设**：gl.dim A < ∞ 保证每个模有有限投射分解，从而 Cartan 矩阵的幺模性（Eilenberg）成立。

**可观测数据**：

- 在纯数学中，"可观测"即**代数的具体结构**：A 的箭图（quiver）、关系（relations）、单模和投射模的列表、合成列的重数。
- **想要但观测不到的量**：det C_A 的符号。它由 A 的表示论结构决定，但无法直接从 A 的定义读出，需要通过同调代数计算。

#### 第二步：讲最小内核

**最小特例**：取 **A = K[x]/(x²)**（K 是域），即**对偶数代数**（dual numbers）。

- **单模**：只有一个，S = K（平凡模）。
- **不可分解投射模**：只有一个，P = A（正则模），合成列为 0 → S → P → S → 0，所以 [P : S] = 2。
- **Cartan 矩阵**：C_A = (2)，det C_A = 2 ≠ 1。
- **整体维数**：gl.dim A = ∞（因为 K 作为 A-模有无限投射分解）。所以**此例不满足猜想的前提**，不构成反例。

**满足前提的最小例子**：取 **A = K × K**（两个域的直积）。

- **单模**：S₁ = K × 0，S₂ = 0 × K。
- **不可分解投射模**：P₁ = K × 0，P₂ = 0 × K，各自合成列只有自身，所以 [Pᵢ : Sᵢ] = 1，其余为 0。
- **Cartan 矩阵**：C_A = I₂（单位矩阵），det C_A = 1。
- **整体维数**：gl.dim A = 0（半单代数）。**猜想在此例成立**。

**最小内核的数学命题**：对任意 Artin 代数 A，若 gl.dim A ≤ 2，则 det C_A = 1（Zacharia 定理）。本文的推广是：**若 gl.dim A ≤ 2 且 e ∈ A 是幂等元，则 det C_{eAe} = 1**（只要 eAe 有有限整体维数）。

**为什么这个命题非平凡**：corner eAe 的表示论结构与 A 的表示论结构**不同**——eAe 的模不直接是 A 的模，而是通过求值函子 F(N) = Ne 关联。本文的核心技术贡献是证明了**如何通过 A 的 Cartan 矩阵的约化来计算 eAe 的 Cartan 矩阵**，并利用 Zacharia 定理确定符号。

**证明的核心思想**（用最小例子说明）：取 A = K × K，e = (1, 0)。则 eAe ≅ K，det C_{eAe} = 1。这里 eAe 是半单代数，平凡。更一般的例子需要 A 有非半单结构，但 corner 约化后仍保持 gl.dim ≤ 2。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：证明了 Cartan 行列式猜想对**整体维数至多 2 的 Artin 代数的任意有限整体维数 corner** 成立，并由此推出对 **torsionless-finite Artin 代数** 成立。
2. **核心工具 / 方法**：利用**求值函子** F(N) = Ne 将 corner eAe 的表示论嵌入 A 的表示论，通过**对象商范畴**（object quotient）和 **Cartan 矩阵的行列式约化**，将 eAe 的 Cartan 行列式分解为 A 的 Cartan 行列式与若干辅助代数（Z, D₀, ..., Dₐ）的行列式之积。
3. **主要结论**：若 gl.dim A ≤ 2 且 gl.dim eAe < ∞，则 det C_{eAe} = 1；若 A 是 torsionless-finite 且 gl.dim A < ∞，则 det C_A = 1。

#### 关键设定与假设

- **A 是 Artin 代数**：保证模范畴是 Krull–Schmidt 的，且 Hom 空间是有限长度的。
- **gl.dim A ≤ 2**：这是 Zacharia 定理的适用范围，也是本文证明的起点。
- **e ∈ A 是非零幂等元**：corner eAe 是 Artin 代数。
- **gl.dim eAe < ∞**：保证 eAe 的 Cartan 矩阵有定义且幺模。
- **torsionless-finite**：A 的 torsionless 模（嵌入投射模的模）只有有限多个不可分解同构类。这个假设保证 Sub(A_A) 的加法生成元的端环有有限整体维数。

**相比已有文献的放宽/强化**：
- 相比 Zacharia [6]：本文不要求 corner 本身 gl.dim ≤ 2，只要求**有限**整体维数。
- 相比 Chen–Guo [2]：torsionless-finite 是比表示有限型更广的类（表示有限型 ⇒ torsionless-finite，反之不然）。

#### 主要结果

**定理 A**（核心定理）：设 A 是 Artin 代数，gl.dim A ≤ 2，e ∈ A 是非零幂等元。若 eAe 有有限整体维数，则 det C_{eAe} = 1。

**定理 B**（推论）：设 A 是 torsionless-finite Artin 代数。若 gl.dim A < ∞，则 det C_A = 1。

**证明路线**（3-5 步逻辑主干）：

1. **构造滤过**：对 0 ≤ m ≤ a = gl.dim A，定义 Eₘ = {P ∈ proj R : pd_A(Pe) ≤ m}。这些是 proj R 的递增子范畴，P = add(eR) ⊆ E₀，Eₐ = proj R。
2. **对象商范畴**：对每个 m，考虑商范畴 Eₘ/Eₘ₋₁。引理 2.2 证明这些商范畴的端环 Dₘ 有 gl.dim ≤ 2，且 Cartan 行列式满足约化公式 det C_{Γₘ} = det C_{Γₘ₋₁} · det C_{Dₘ}。
3. **初始层处理**：对 E₀，构造 L₀ = add(P ∪ Z)，其中 Z = {P ∈ proj R : Pe = 0}。证明 L₀ 的端环的 Cartan 行列式分解为 det C_A · det C_Z，且 Z 的端环有 gl.dim ≤ 2。
4. **乘积公式**：将上述约化叠乘，得到 det C_R = det C_A · det C_Z · ∏ₘ det C_{Dₘ}。
5. **符号判定**：由 Zacharia 定理，所有因子（Z, D₀, ..., Dₐ 的 Cartan 行列式）均为 1，故 det C_A = 1。

**技术技巧点名**：

- **求值函子** F(N) = Ne：将 corner 的模嵌入原代数的模，是连接 eAe 与 A 的桥梁。
- **对象商范畴**（object quotient）：通过商掉低维层，将复杂的投射模滤过分解为简单块的直和。
- **Cartan 矩阵的列操作**：引理 2.2 的证明中，通过替换列为线性组合（保持行列式不变）实现块三角化。
- **Zacharia 定理的调用**：作为黑箱，确定所有辅助代数的 Cartan 行列式符号。

#### 真实例子与应用

**本文为纯理论，无实证例子**。但定理 B 有明确的代数类应用：torsionless-finite Artin 代数。这类代数包含但不限于表示有限型代数。一个具体的例子是**特殊双列代数**（special biserial algebras）中的某些类，它们可以是 torsionless-finite 但不是表示有限型。作者未给出具体数值例子，但定理的证明构造本身（滤过、商范畴、行列式约化）就是"例子"——它展示了如何将 corner 的 Cartan 行列式分解为已知量的乘积。

#### 🔎 结论是否比证明窄

**是**。具体表现：

1. **定理 A 的证明依赖于 gl.dim A ≤ 2**，但结论可能对更广的代数类成立。作者在引言中未讨论 gl.dim A > 2 时 corner 约化是否仍然有效。
2. **定理 B 的证明依赖于 torsionless-finite 假设**，但作者未讨论这个假设是否必要。是否存在非 torsionless-finite 但 Cartan 行列式猜想成立的代数？
3. **证明中的滤过构造依赖于 a = gl.dim A 有限**，但定理 A 只要求 eAe 有限整体维数。作者未讨论 A 本身整体维数无限但 corner 有限的情形。
4. **作者在摘要中声称"Consequently, the conjecture holds for torsionless-finite Artin algebras"**，但定理 B 的证明需要 gl.dim A < ∞ 且 torsionless-finite。**注意**：torsionless-finite 是否蕴含 gl.dim < ∞？作者未讨论这一点。如果存在 torsionless-finite 但 gl.dim = ∞ 的代数，则定理 B 的适用范围比摘要声称的窄。

### 四、开放问题

1. **一般情形的 corner 约化**：定理 A 的证明能否推广到 gl.dim A > 2？具体要证：若 gl.dim A < ∞ 且 eAe 有限整体维数，是否 det C_{eAe} = 1？扎根于定理 A 的证明——滤过构造在 m > 2 时是否仍然给出 gl.dim ≤ 2 的辅助代数？

2. **torsionless-finite 与整体维数的关系**：torsionless-finite 是否蕴含 gl.dim < ∞？如果否，定理 B 的适用范围需要重新表述。扎根于定理 B 的证明——它需要 gl.dim A < ∞ 作为前提，但摘要的 framing 暗示 torsionless-finite 本身足够。

3. **corner 约化的完备性**：是否存在有限整体维数的 Artin 代数，其 Cartan 行列式猜想成立，但无法通过 corner 约化证明？这需要构造一个反例或证明 corner 约化是完备的。扎根于引理 2.2 的约化公式——它只适用于 gl.dim ≤ 2 的层。

4. **Chen–Guo 结果与本文结果的关系**：表示有限型代数是否都是 torsionless-finite？如果是，本文定理 B 是 Chen–Guo [2] 的推广；如果不是，两者覆盖不同的代数类。扎根于引言——作者未讨论这一关系。

**顺带提醒**：要确认上述问题是否是真 gap，建议去读表示论中关于 Cartan 行列式猜想的近期文献（如 2023-2026 年的相关工作），看是否已有其他证明方法或反例。如果多篇近期论文都指向 corner 约化的局限性，则问题 1 和 3 是真 gap；如果互相打架，则说明该方向仍有争议。
