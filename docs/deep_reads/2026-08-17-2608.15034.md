### 一、领域脉络与小综述

- **这个方向是什么**：本子方向研究的是**高维M-估计量的渐近正态性**。具体来说，当数据维度 \(p\) 与样本量 \(n\) 成比例增长（即 \(p = O(n)\)，称为“比例极限”或“proportional regime”）时，能否证明正则化经验风险最小化（ERM）估计量 \(\hat{\theta}\) 的任意线性泛函 \(u^\top \hat{\theta}\) 在合适的标准化后收敛到标准正态分布？这是一个连接高维统计与经典推断理论的核心问题，其成熟度处于**活跃前沿**：已有若干重要结果，但大多依赖于较强的分布假设（如高斯设计、独立同分布条目），而本文试图在更弱的假设下建立定量CLT。

- **发展脉络（history）**：
    - **奠基工作**：固定维度下的经典M-估计理论（Huber [10], van der Vaart [18]）建立了 \(\sqrt{n}\)-一致性和渐近正态性，但无法处理 \(p\) 随 \(n\) 增长的情形。
    - **主要进展（慢速增长维度）**：Portnoy [14]、Mammen [13]、He–Shao [9] 等人在 \(p^2/n \to 0\) 或 \(p\) 增长较慢的条件下证明了CLT。这些结果要求维度增长足够慢，无法覆盖比例极限。
    - **当前frontier（比例极限下的精确渐近）**：
        - **高斯设计路线**：Donoho–Montanari [5]、Sur–Candès [17]、Zhao–Sur–Candès [19]、Bellec–Shen–Zhang [2] 在**高斯设计**（可能具有一般协方差）下，通过近似消息传递（AMP）或留一法（leave-one-out）得到了精确的渐近描述（如方差公式和CLT）。这些结果非常精确，但严重依赖高斯性。
        - **非高斯设计路线**：El Karoui 等人 [7, 6] 允许非高斯设计，但假设列向量是**独立同分布、各向同性或具有独立条目**，并需要强浓度性质。Lei–Bickel–El Karoui [12] 在**固定设计**下证明了坐标正态性，但设计矩阵被视为非随机的。
    - **本文的位置**：本文声称在**更弱的分布假设**下证明定量CLT。它不要求高斯性、各向同性、独立条目或同分布，核心假设是列向量满足**均匀的Poincaré不等式**（一种比次高斯性更弱的浓度条件）。这填补了从强结构假设（高斯、iid）到弱结构假设（仅需Poincaré不等式）之间的空白。

- **子线索聚类**：
    1.  **高斯设计下的精确渐近**：以 Donoho–Montanari [5], Sur–Candès [17], Bellec–Shen–Zhang [2] 为代表。方法：AMP、留一法。特点：结果精确（方差公式、CLT），但假设强。
    2.  **非高斯设计下的坐标/线性泛函正态性**：以 El Karoui [6, 7], Lei–Bickel–El Karoui [12] 为代表。方法：随机矩阵理论、留一法。特点：允许非高斯，但仍有较强结构（iid、各向同性、独立条目）或固定设计。
    3.  **定量CLT与弱假设**：本文（Louart）属于此簇。方法：留一展开 + 扰动正态逼近（Chatterjee [4]）。特点：假设最弱（仅Poincaré不等式），但结论是**定量**的（给出Wasserstein距离下的收敛速率），且需要正则化是二次的。

- **这个方向在追问的核心问题（2-4个）**：
    1.  **CLT是否成立？** 在比例极限下，\(\sqrt{n} u^\top \hat{\theta}\) 是否收敛到正态？这是最基本的推断问题。
    2.  **需要多强的分布假设？** 从高斯到次高斯，再到更弱的Poincaré不等式，能否进一步放松到仅需有限矩？
    3.  **收敛速率是多少？** 能否得到Berry-Esseen型的定量界？速率是 \(n^{-1/2}\) 还是更慢？
    4.  **方差如何估计？** 渐近方差 \(\sigma_n^2\) 的表达式是什么？如何一致地估计它以进行推断？

- **⚠️ 作者的 framing（必须明确标注成"这是作者的说法"）**：
    - **作者把缺口 frame 成什么**：作者在引言中明确说：“The present paper proves a quantitative central limit theorem under weaker distributional assumptions on the design.” 他把缺口定位为“在比例极限下，现有CLT结果要么依赖高斯设计，要么依赖iid/各向同性/独立条目等强结构”，而本文通过引入**Poincaré不等式**作为核心假设，填补了这一空白。他声称这是“更弱的分布假设”。
    - **哪些竞争路线被他淡化或回避了**：
        - **AMP路线**：作者在引言中仅提及Donoho–Montanari [5] 和 Sur–Candès [17] 等“在Gaussian-design假设下”工作，但未深入讨论AMP方法在非高斯设计下的局限性（如状态演化方程可能失效）。他选择用留一法而非AMP，可能因为留一法对分布假设更鲁棒。
        - **固定设计路线**：Lei–Bickel–El Karoui [12] 的固定设计结果被提及，但作者未讨论其与随机设计结果的联系或优劣。固定设计下设计矩阵是确定的，而本文处理随机设计，这是不同的设定。
        - **非二次正则化**：本文明确假设正则化 \(\rho\) 是**二次的**（即 \(\nabla^3 \rho \equiv 0\)）。作者在定理2.1中明确写出这一条件，但未讨论将其推广到一般强凸正则化的可能性或困难。这可能是未来工作的一个明确方向。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：把符号、模型、可观测数据交代清楚

- **符号**：
    - \(n\): 样本量。
    - \(p\): 参数维度。假设 \(p = O(n)\)（比例极限）。
    - \(X = (x_1, \ldots, x_n) \in \mathbb{R}^{p \times n}\): 设计矩阵，其列 \(x_i \in \mathbb{R}^p\) 是**独立**的随机向量。
    - \(\theta \in \mathbb{R}^p\): 待估参数向量。
    - \(L: \mathbb{R} \to \mathbb{R}\): 损失函数，作用在预测值 \(x_i^\top \theta\) 上。假设光滑且一致凸（\(L'' \ge \kappa_L > 0\)）。
    - \(\rho: \mathbb{R}^p \to \mathbb{R}\): 正则化项。假设强凸（\(\nabla^2 \rho \succeq \kappa I_p\)），且在主要定理中进一步假设为**二次的**（\(\nabla^3 \rho \equiv 0\)）。
    - \(\Psi_X(\theta) = \frac{1}{n} \sum_{i=1}^n L(x_i^\top \theta) + \rho(\theta)\): 正则化经验风险。
    - \(\hat{\theta} = \arg\min_{\theta \in \mathbb{R}^p} \Psi_X(\theta)\): 正则化M-估计量（**目标估计量**）。
    - \(u \in \mathbb{R}^p\): 一个**确定性**的方向向量，满足 \(|u|_2 \le 1\)。我们关心的是线性泛函 \(u^\top \hat{\theta}\)。
    - \(f_n(X) = \sqrt{n} u^\top \hat{\theta}\): 缩放后的线性泛函。
    - \(\sigma_n^2 = \text{Var}(f_n(X))\): \(f_n\) 的方差。
    - \(W_n = (f_n(X) - \mathbb{E}[f_n(X)]) / \sigma_n\): 标准化后的统计量，是CLT的目标。
    - \(G = [\nabla^2 \Psi_X(\hat{\theta})]^{-1}\): 目标函数在 \(\hat{\theta}\) 处的Hessian矩阵的逆，是证明中的关键工具。
    - \(s_i = L'(x_i^\top \hat{\theta})\): 第 \(i\) 个样本的“训练得分”（train score）。
    - \(\hat{\theta}^{-i}\): 去掉第 \(i\) 个样本后的M-估计量（leave-one-out estimator）。
    - \(\delta_i \hat{\theta} = \hat{\theta} - \hat{\theta}^{-i}\): 留一扰动（leave-one-out displacement）。
    - \(d_W\): Wasserstein距离，用于度量分布收敛。

- **模型**：
    - **数据生成机制**：列向量 \(x_1, \ldots, x_n\) 是独立的，但**不必同分布**。它们可以是任意分布，只要满足**均匀的列向Poincaré不等式**（Assumption 4）：存在常数 \(C_P = O(1)\)，使得对每个 \(i\) 和任意光滑函数 \(f\)，有 \(\text{Var}(f(x_i)) \le C_P \mathbb{E}[|\nabla f(x_i)|_2^2]\)。这是一个比次高斯性更弱的浓度条件（例如，对数凹分布满足此条件）。
    - **统计模型**：我们观测到 \(X\)，并假设损失函数 \(L\) 和正则化 \(\rho\) 是已知的。参数 \(\theta\) 是未知的，通过最小化 \(\Psi_X(\theta)\) 来估计。
    - **已知/假设**：\(L\) 和 \(\rho\) 的光滑性和曲率（Assumptions 5-7）是已知的。Poincaré常数 \(C_P\) 是 \(O(1)\) 的，但具体值未知。

- **可观测数据**：
    - **可观测**：设计矩阵 \(X\) 是**完全可观测**的。方向向量 \(u\) 是研究者选择的确定性向量。
    - **想要但观测不到**：真实的参数 \(\theta^*\)（如果存在）是未知的。估计量 \(\hat{\theta}\) 是 \(X\) 的函数，因此是随机变量。其分布、期望、方差都是我们想要推断但未知的。特别是，我们想要知道 \(u^\top \hat{\theta}\) 的分布是否接近正态。

#### 第二步：讲最小内核

本文的核心思路是证明一个**定量CLT**，其证明依赖于一个**二阶留一展开**。为了理解这个展开，我们考虑一个**最简特例**：\(p=1\)，\(n \to \infty\)，损失函数 \(L\) 是二次的（即 \(L(t) = t^2/2\)），正则化 \(\rho\) 也是二次的（即 \(\rho(\theta) = \lambda \theta^2/2\)，\(\lambda > 0\)）。此时，问题退化为**岭回归**。

- **最简特例下的设定**：
    - \(p=1\)，所以 \(x_i\) 是标量，\(\theta\) 是标量。
    - \(L(t) = t^2/2\)，所以 \(L'(t) = t\)，\(L''(t) = 1\)。
    - \(\rho(\theta) = \lambda \theta^2/2\)，所以 \(\rho'(\theta) = \lambda \theta\)，\(\rho''(\theta) = \lambda\)。
    - 目标函数：\(\Psi_X(\theta) = \frac{1}{n} \sum_{i=1}^n \frac{1}{2} (x_i \theta)^2 + \frac{\lambda}{2} \theta^2\)。
    - 估计量：\(\hat{\theta} = \arg\min_\theta \Psi_X(\theta) = \frac{0}{\frac{1}{n} \sum_{i=1}^n x_i^2 + \lambda}\)。实际上，由于没有响应变量 \(y_i\)，这里的“M-估计”退化为一个纯正则化问题。为了让它有意义，我们假设存在一个真实的线性模型 \(y_i = x_i \theta^* + \epsilon_i\)，但为了最小内核，我们只关注 \(\hat{\theta}\) 本身的分布。更准确地说，我们考虑一个更简单的设定：假设我们观测到 \(x_i\)，并定义 \(\hat{\theta}\) 为上述最小化问题的解。这个解是 \(\hat{\theta} = 0\)，因为损失函数在 \(\theta=0\) 处最小。这太trivial了。

    **修正的最简特例**：为了让问题非平凡，我们考虑一个**有响应变量**的线性回归模型，但为了保持最小内核，我们假设响应变量 \(y_i\) 是已知的且与 \(x_i\) 独立。更直接地，我们考虑一个**有意义的M-估计问题**：假设 \(L(t) = (t - y_i)^2/2\)，其中 \(y_i\) 是观测到的响应。但这样会引入额外的变量。

    **真正的最小内核**：本文的核心困难在于处理**设计矩阵 \(X\) 的随机性**，而不是响应变量。因此，最简特例可以设定为：**\(p=1\)，\(L(t) = t^2/2\)，\(\rho(\theta) = \lambda \theta^2/2\)，且我们关心的是 \(\hat{\theta}\) 的分布，其中 \(\hat{\theta}\) 是 \(\Psi_X(\theta) = \frac{1}{n} \sum_{i=1}^n \frac{1}{2} (x_i \theta)^2 + \frac{\lambda}{2} \theta^2\) 的最小值点**。这个问题的解是 \(\hat{\theta} = 0\)，因为 \(\Psi_X(\theta)\) 在 \(\theta=0\) 处取最小值0。这仍然trivial。

    **关键洞察**：本文的M-估计问题中，损失函数 \(L\) 作用在**线性预测** \(x_i^\top \theta\) 上，但没有响应变量。这实际上是一个**无监督**的正则化M-估计。为了让问题非平凡，我们需要 \(L\) 不是偶函数，或者有非零的“真实”参数。但为了最小内核，我们考虑一个**有监督**的版本，但将响应变量视为固定的。

    **最简特例（最终版）**：考虑一个**单变量线性回归**问题：\(y_i = x_i \theta^* + \epsilon_i\)，其中 \(\epsilon_i\) 是独立噪声。我们使用平方损失 \(L(t) = (t - y_i)^2/2\) 和二次正则化 \(\rho(\theta) = \lambda \theta^2/2\)。那么 \(\hat{\theta} = \arg\min_\theta \frac{1}{n} \sum_{i=1}^n (x_i \theta - y_i)^2 + \lambda \theta^2\)。其解为 \(\hat{\theta} = \frac{\frac{1}{n} \sum_{i=1}^n x_i y_i}{\frac{1}{n} \sum_{i=1}^n x_i^2 + \lambda}\)。在这个特例下，\(\sqrt{n} u^\top \hat{\theta} = \sqrt{n} \hat{\theta}\) 的渐近正态性可以通过经典的中心极限定理和Slutsky定理证明，只要 \(x_i\) 和 \(\epsilon_i\) 有有限矩。这个特例揭示了本文的核心思路：**通过留一展开，将高维问题转化为一系列一维问题，每个一维问题类似于这个最简特例**。在一般高维情形下，\(\hat{\theta}\) 的每个坐标或线性泛函的行为，可以通过分析去掉一个样本后估计量的变化（即 \(\delta_i \hat{\theta}\)）来理解，而这个变化可以近似为一个一维问题的解。

    **本文的核心数学困难**：在比例极限 \(p = O(n)\) 下，\(\hat{\theta}\) 的每个分量都依赖于所有 \(p\) 个变量，经典的一维CLT不直接适用。本文的关键想法是：**利用留一展开，将 \(\sqrt{n} u^\top \hat{\theta}\) 的增量 \(\delta_i f_n(X) = \sqrt{n} u^\top (\hat{\theta} - \hat{\theta}^{-i})\) 近似为一个仅依赖于第 \(i\) 个样本 \(x_i\) 的简单函数**。然后，通过Chatterjee的扰动正态逼近方法，将整个统计量的正态性归约为这些增量的条件协方差和条件三阶矩的控制。这个思路将高维问题分解为 \(n\) 个独立的一维问题，每个问题都可以用Poincaré不等式等工具处理。

### 三、这篇论文做了什么

- **三句话**：
    1.  **研究了什么问题**：在比例极限 \(p = O(n)\) 下，证明了正则化M-估计量 \(\hat{\theta}\) 的任意非退化线性泛函 \(\sqrt{n} u^\top \hat{\theta}\) 的定量中心极限定理。
    2.  **核心工具 / 方法**：证明结合了**二阶留一展开**（second-order leave-one-out expansion）和**Chatterjee的扰动正态逼近方法**（perturbative normal-approximation method）。留一展开用于精确刻画 \(\hat{\theta}\) 对单个样本的敏感性，而扰动方法将CLT的证明转化为对条件协方差和条件三阶矩的估计。
    3.  **主要结论**：在Wasserstein距离下，标准化后的统计量 \(W_n\) 以速率 \(O((\log n)^7 n^{-1/4})\) 收敛到标准正态分布（Theorem 2.1）。同时证明了方差上界 \(\text{Var}(u^\top \hat{\theta}) \le C |u|_2^2 / n\)，确认了 \(\sqrt{n}\) 的波动尺度。

- **关键设定与假设**：
    - **Assumption 1 (比例极限)**：\(p = O(n)\)。这是高维设定。
    - **Assumption 2 (初始值有界)**：\(|L'(0)| = O(1)\) 和 \(|\nabla \rho(0)|_2 = O(1)\)。确保问题在原点附近是良定义的。
    - **Assumption 3 (列均值有界)**：\(\sup_i |\mathbb{E}[x_i]|_2 = O(1)\)。控制列向量的均值。
    - **Assumption 4 (Poincaré不等式)**：这是**核心假设**。每个列向量 \(x_i\) 满足均匀的Poincaré不等式。这比次高斯性更弱，允许更广泛的分布（如对数凹分布）。它提供了矩控制和浓度性质。
    - **Assumption 5 (一致曲率和光滑性)**：\(L\) 是 \(C^2\) 的，\(L''\) 有界且一致正（\(\kappa_L > 0\)）；\(\rho\) 是 \(C^2\) 且 \(\kappa\)-强凸。这保证了目标函数是强凸的，从而 \(\hat{\theta}\) 唯一存在，并提供了基本的稳定性。
    - **Assumption 6 (二阶光滑性)**：\(L''\) 和 \(\nabla^2 \rho\) 是全局Lipschitz的。用于一阶留一展开的误差控制。
    - **Assumption 7 (三阶曲率)**：\(L\) 是 \(C^4\) 且 \(L'''\) 和 \(L''''\) 有界；\(\rho\) 是 \(C^3\) 且其三阶微分张量有界且Lipschitz。用于**二阶**留一展开。
    - **定理2.1的额外假设**：\(\rho\) 是**二次的**（\(\nabla^3 \rho \equiv 0\)），且 \(\sigma_n^{-1} = O(1)\)（非退化条件）。二次正则化假设简化了二阶展开，因为正则化部分的二阶余项消失。非退化条件排除了方差趋于0的退化情形。

- **主要结果**：
    - **Theorem 2.1 (CLT)**：在Assumptions 1-7及二次正则化、非退化条件下，\(d_W(W_n, N(0,1)) = O((\log n)^{13} / \sqrt{n})\)。这是一个**定量**的CLT，给出了Wasserstein距离下的收敛速率。速率是 \(n^{-1/2}\) 乘以一个对数因子，接近经典Berry-Esseen界的 \(n^{-1/2}\)。
    - **方差上界 (Remark 3.16)**：\(\sigma_n^2 = n \text{Var}(u^\top \hat{\theta}) = O(1)\)。这确认了 \(\sqrt{n}\) 的波动尺度，是CLT成立的前提。
    - **证明路线中的关键中间结果**：
        - **ω_Δ 界 (4.6)**：\(\omega_\Delta = \sup_i \|\delta_i f_n(X)\|_{L^3} = O(\log n / \sqrt{n})\)。控制了留一增量的三阶矩。
        - **ω_c 界 (Corollary 5.14)**：\(\omega_c = O((\log n)^{13} / n^{3/2})\)。控制了留一增量的条件协方差的方差。这是证明中最精细的部分。

- **证明路线与技术技巧（理论型必写，要具体）**：
    - **整体路线**：
        1.  **将CLT转化为对留一增量的控制**：利用Chatterjee的扰动正态逼近方法（Theorem 2.2），将证明 \(W_n\) 的Wasserstein CLT转化为证明两个量很小：\(n \omega_c / \sigma_n^2\) 和 \(n \omega_\Delta^3 / \sigma_n^3\)。其中 \(\omega_c\) 与留一增量的条件协方差的波动有关，\(\omega_\Delta\) 与留一增量的三阶矩有关。
        2.  **控制 \(\omega_\Delta\)**：通过一阶留一展开（Theorem 4.9），将 \(\delta_i \hat{\theta}\) 近似为 \(-\frac{s_i}{n} G_{-i} x_i\)。然后利用Poincaré不等式和矩估计，证明 \(\|\sqrt{n} u^\top \delta_i \hat{\theta}\|_{L^3} = O(\log n / \sqrt{n})\)。
        3.  **控制 \(\omega_c\)**：这是最困难的部分。需要更精确的**二阶留一展开**（Theorem 4.19）。核心想法是：一阶近似 \(\delta_i^{(0)} \hat{\theta} = -\frac{s_i^\zeta}{n} G_{-i} x_i\) 中，训练得分 \(s_i\) 依赖于 \(x_i\)，这导致条件协方差难以控制。通过引入一个“平均杠杆得分” \(\gamma_i\)，构造一个“平均化得分” \(s_i^\zeta\)，它仅通过 \(x_i^\top \hat{\theta}^{-i}\) 依赖于 \(x_i\)，从而简化了依赖结构。然后，在二阶展开中，将 \(\delta_i \hat{\theta}\) 进一步近似为 \(\delta_i^{(0)} \hat{\theta} + \delta_i^{(1)} \hat{\theta}\)，其中 \(\delta_i^{(1)} \hat{\theta}\) 是一个二次项，用于修正一阶近似的误差。最后，通过一系列复杂的敏感性分析（Section 5），证明基于这个二阶近似的条件协方差的方差是 \(O((\log n)^{13} / n^{3/2})\)。
    - **关键跳跃点**：
        - **从一阶到二阶展开**：一阶展开的误差 \(O(\log n / n)\) 对于控制 \(\omega_c\) 来说太大（见Remark 4.11）。必须进行二阶展开，将误差降低到 \(O((\log n)^2 / n^{3/2})\)，才能得到所需的 \(\omega_c\) 界。
        - **引入平均化得分 \(s_i^\zeta\)**：这是二阶展开的关键。原始得分 \(s_i = L'(x_i^\top \hat{\theta})\) 通过 \(\hat{\theta}\) 间接依赖于所有 \(x_j\)，结构复杂。通过解一个隐式方程 \(z + \gamma_i L'(z) = x_i^\top \hat{\theta}^{-i}\) 定义 \(s_i^\zeta = L'(\zeta_i(x_i^\top \hat{\theta}^{-i}))\)，使得 \(s_i^\zeta\) 仅通过线性预测 \(x_i^\top \hat{\theta}^{-i}\) 依赖于 \(x_i\)，这大大简化了后续的协方差分析。
        - **控制背景矩阵的导数**：在分析 \(\omega_c\) 时，需要计算 \(y = Gu\) 和 \(Y = G X D X^\top G\) 等背景量对设计矩阵的导数。这些导数涉及复杂的链式法则和矩阵微分，是证明中最技术性的部分。Lemma 5.9, 5.12, 5.13 系统地处理了这些导数，并给出了它们在 \(L^r\) 范数下的界。
    - **技术技巧点名**：
        - **留一展开 (Leave-one-out expansion)**：核心技巧，用于分析 \(\hat{\theta}\) 对单个样本的敏感性。
        - **Poincaré不等式**：提供矩控制和浓度性质，是处理非高斯分布的主要工具。其张量化形式（Lemma 3.1）和 \(L^k\) 版本（Lemma B.2）被反复使用。
        - **Chatterjee的扰动正态逼近方法**：将CLT证明转化为对条件协方差和三阶矩的估计，提供了一个系统性的框架。
        - **Sherman-Morrison公式**：在Lemma 5.4中用于分解全样本Hessian逆 \(G\) 与留一样本Hessian逆 \(G_{-j}\) 的关系。
        - **隐函数定理 / 隐式微分**：用于定义平均化得分 \(s_i^\zeta\) 并计算其导数（Lemma 4.14）。
        - **张量化的Poincaré不等式**：用于控制背景矩阵（如 \(Y\)）的导数，这些导数本身是复杂的函数。

- **真实例子与应用**：本文为**纯理论**，无实证例子。论文没有模拟实验或真实数据分析。

- **🔎 结论是否比证明窄**：
    - **明确更窄的假设**：定理2.1明确要求正则化 \(\rho\) 是**二次的**（\(\nabla^3 \rho \equiv 0\)）。这是证明中二阶展开能够简化的关键。作者在Assumption 7中允许 \(\rho\) 有非零的三阶导数，但在主要定理中却假设其为零。这表明**将结果推广到一般强凸正则化（如Lasso的 \(\ell_1\) 正则化）是一个开放问题**，且可能非常困难，因为 \(\ell_1\) 正则化甚至不是光滑的。
    - **非退化假设**：定理要求 \(\sigma_n^{-1} = O(1)\)。这是一个合理的非退化条件，但证明中并未给出 \(\sigma_n\) 的下界何时成立的具体刻画。这留给读者去判断。
    - **收敛速率**：速率 \(O((\log n)^{13} / \sqrt{n})\) 中的对数幂次很高，可能不是最优的。作者没有声称这是最优速率。一个自然的问题是：能否改进到 \(O(1/\sqrt{n})\) 或 \(O(\log n / \sqrt{n})\)？

### 四、开放问题（点到为止，扎根具体语句）

1.  **推广到非二次正则化**：定理2.1要求 \(\nabla^3 \rho \equiv 0\)。能否将CLT推广到更一般的强凸、光滑的正则化（如弹性网）？这需要处理二阶展开中来自正则化的额外余项。**扎根**：Theorem 2.1 的陈述明确包含“assume in addition that \(\rho\) is quadratic, in the sense that \(\nabla^3 \rho \equiv 0\)”。

2.  **改进收敛速率**：本文得到的Wasserstein速率为 \(O((\log n)^{13} n^{-1/4})\)。能否改进到 \(O(n^{-1/2})\) 或至少降低对数幂次？这可能需要对 \(\omega_c\) 的界进行更精细的估计，或者采用不同的正态逼近方法。**扎根**：Theorem 2.1 的结论给出了具体的速率。

3.  **刻画非退化条件**：定理要求 \(\sigma_n^{-1} = O(1)\)。在什么条件下这个下界成立？能否给出一个基于设计矩阵 \(X\) 和方向 \(u\) 的显式条件？**扎根**：Theorem 2.1 的陈述包含“\(\sigma_n^{-1} = O(1)\)”作为假设。

4.  **推广到更一般的损失函数**：本文假设损失函数 \(L\) 是 \(C^4\) 且具有一致曲率。能否将结果推广到非光滑损失（如Huber损失）或曲率可以为零的损失（如逻辑回归的损失在尾部是线性的）？这可能需要不同的技术来处理非光滑性或非强凸性。**扎根**：Assumptions 5-7 对 \(L\) 的光滑性和曲率有严格要求。
