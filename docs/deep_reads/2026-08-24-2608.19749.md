### 一、领域脉络与小综述

#### 这个方向是什么

本文所处的子方向是**观测性生存分析中的异质性处理效应（HTE）估计**，其根本科学问题是：在时间-事件（time-to-event）结局存在右删失、且存在未测混杂（unmeasured confounding）的情况下，如何从观测数据中灵活、非参数地估计条件平均处理效应（CATE）随协变量的变化。该方向的成熟度处于"方法快速扩张但理论根基尚浅"的阶段——已有大量基于随机森林的 HTE 学习器（如 causal forest、causal survival forest），但绝大多数依赖无未测混杂（ignorability）假设；而 proximal causal inference（PCI）虽能处理未测混杂，却主要聚焦于平均处理效应（ATE）的估计，缺乏与灵活非参数机器学习工具的深度结合。本文试图填补的正是"PCI 框架 × 生存结局 × 森林式 HTE 学习器"这一交叉空白。

#### 发展脉络

- **奠基工作：随机森林用于因果推断**。Wager & Athey (2015) 建立了 causal forest 的渐近理论，证明其点态一致性与渐近正态性，奠定了"用森林做 HTE 估计"的统计基础。Athey & Imbens (2015) 提出 honest tree 的递归划分框架，强调用样本分割消除划分带来的偏差，这是后续所有 honest forest 方法的设计基石。Athey, Tibshirani & Wager (2016) 进一步将随机森林推广为广义矩估计（GMM）求解器，使森林不仅能估计条件均值，还能估计由矩条件定义的任意目标参数。
- **主要进展：生存结局的 HTE 学习**。Cui, Kosorok, Wager 等 (2020) 将 causal forest 扩展到右删失生存数据，提出 causal survival forest（CSF），通过逆删失概率加权（IPCW）构造伪结局，并利用正交矩条件实现 nuisance 估计的鲁棒性。这是本文最直接的前身——本文的"基线"（Censored Baseline）正是 CSF 框架在无未测混杂设定下的实现。
- **主要进展：proximal causal inference 的理论化**。Miao, Geng & Tchetgen Tchetgen (2016) 提出用 negative control 变量识别存在未测混杂时的因果效应，核心工具是 bridge function 和 completeness 条件。Cui, Pu, Shi, Miao & Tchetgen Tchetgen (2020) 建立了 semiparametric proximal causal inference 的完整理论，包括效率界和双稳健估计。Kallus, Mao & Uehara (2021) 进一步将 bridge function 的估计形式化为 minimax 学习问题，放宽了此前对 bridge function 参数形式的限制。Li, Linderman, Shi & Tchetgen Tchetgen (2024) 将 PCI 扩展到右删失生存数据，但仅针对 ATE，且依赖参数化建模。
- **当前 frontier**：将 PCI 与灵活非参数学习器（森林、神经网络）结合，同时处理删失、未测混杂和 HTE 三个维度。本文的位置正在于此——它声称是第一个将 negative control 与 causal survival forest 结合的工作，且提供了局部渐近正态性（LAN）理论。

#### 子线索聚类

1. **森林式 HTE 学习器**（Wager & Athey 2015; Athey & Imbens 2015; Athey et al. 2016; Cui et al. 2020）：核心问题是"如何用自适应划分实现非参数 CATE 估计并保证推断有效性"。共同技术手段是 honest splitting、subsampling、正交矩条件。共同瓶颈是**依赖 ignorability**。
2. **Proximal causal inference 的识别与估计**（Miao et al. 2016; Cui et al. 2020; Kallus et al. 2021; Liu et al. 2024）：核心问题是"如何用 negative control 变量在未测混杂下识别因果参数"。共同技术手段是 bridge function、completeness 条件、minimax 学习。共同瓶颈是**主要聚焦 ATE，缺乏 HTE 的灵活建模**。
3. **生存数据的因果推断**（Cui et al. 2020; Li et al. 2024）：核心问题是"如何在删失下处理因果估计"。共同技术手段是 IPCW、协变量条件删失假设。共同瓶颈是**要么假设无未测混杂，要么假设参数化模型**。

#### 这个方向在追问的核心问题

1. **识别问题**：在未测混杂存在时，negative control 变量需要满足什么条件才能非参数地识别 CATE？completeness 条件是否可检验、是否可放宽？
2. **估计问题**：如何将 bridge function 的估计与森林的递归划分结合，使得 nuisance 估计误差不主导最终 CATE 估计的误差？正交性（orthogonality）在森林框架下如何实现？
3. **推断问题**：在 nuisance 函数以非参数速率估计时，CATE 估计是否仍能获得 $\sqrt{n}$ 速率和渐近正态性？需要什么样的 nuisance 收敛速率条件？

#### ⚠️ 作者的 framing

**这是作者的说法**：作者将缺口 frame 成"现有 causal survival forest 依赖无未测混杂假设，而现有 proximal causal inference 方法要么只处理 ATE、要么依赖参数化建模，因此需要一种将两者结合的非参数 HTE 学习器"。作者声称其贡献在于：(i) 设计了融合 negative control 的损失函数；(ii) 证明了局部正交性（local orthogonality）；(iii) 提供了局部渐近正态性理论。作者淡化的竞争路线包括：**敏感性分析**（如 Huang et al. 2019 的 E-value 方法）——作者未在 intro 中讨论"与其假设 negative control 有效，不如对未测混杂做敏感性分析"这一替代思路；以及**工具变量方法**——当工具变量可用时，IV 框架可能比 negative control 更直接，但作者未比较这两条路径的适用条件。

#### 张力

未见明显对立引用。但值得注意的是：Kallus et al. (2021) 的 minimax 方法强调 bridge function 估计的**最坏情况**保证，而本文的森林方法依赖**点态一致性**和局部正交性——这两种理论框架对 nuisance 估计误差的度量方式不同（全局范数 vs. 局部条件期望），在有限样本下可能导致不同的行为。作者未在文中讨论这一张力。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

**符号清单**（逐个点名）：

| 记号 | 含义 | 类型 |
|------|------|------|
| $A_i \in \{0,1\}$ | 二元处理 | 可观测随机变量 |
| $X_i$ | 观测协变量（$d_x$ 维） | 可观测随机变量 |
| $U_i$ | 未测混杂（标量，简化） | 潜在（不可观测）随机变量 |
| $Z_i$ | negative control treatment（$d_z$ 维） | 可观测随机变量 |
| $W_i$ | negative control outcome（$d_w$ 维） | 可观测随机变量 |
| $T_i(a)$ | 处理 $a$ 下的潜在事件时间 | 潜在（counterfactual）随机变量 |
| $C_i(a)$ | 处理 $a$ 下的潜在删失时间 | 潜在（counterfactual）随机变量 |
| $Y_i = \min(T_i, C_i)$ | 观测到的生存时间 | 可观测随机变量 |
| $\Delta_i = I\{T_i \le C_i\}$ | 事件指示符 | 可观测随机变量 |
| $h$ | 固定时间水平 | 常数 |
| $G_i(a;h)$ | 处理 $a$ 下的水平 $h$ 结局：RMST 为 $\min(T_i(a), h)$，生存概率为 $I\{T_i(a) > h\}$ | 潜在随机变量 |
| $q(Z_i, X_i)$ | 处理 bridge function，满足 $q(z,x) = P(A=1 \mid X=x, U=u)$ 的某种表示 | 待估 nuisance 函数 |
| $f_a(W_i, X_i)$ | 结局 bridge function，满足 $E[f_a(W,X) \mid X, U] = E[G(a;h) \mid X, U]$ | 待估 nuisance 函数 |
| $\tau(x)$ | CATE：$E[G(1;h) - G(0;h) \mid X=x]$ | 目标 estimand |
| $\tau^w(x)$ | 加权 CATE（见 Proposition 3.3） | 目标 estimand（加权版） |
| $m(x,w,z) = q(z,x) f_1(w,x) + (1-q(z,x)) f_0(w,x)$ | bridge 混合结局 | 构造量 |
| $S_C(t \mid \cdot)$ | 删失生存函数 | 待估 nuisance 函数 |
| $\Lambda_C(t \mid \cdot)$ | 删失累积风险 | 待估 nuisance 函数 |
| $\rho_a(t, \cdot; h)$ | 条件期望结局函数 | 待估 nuisance 函数 |

**模型**（数据生成机制）：

1. **未测混杂结构**：$A_i$ 依赖于 $(X_i, U_i)$，$G_i(a;h)$ 依赖于 $(X_i, U_i)$，因此 $A_i$ 与 $G_i(a;h)$ 在给定 $X_i$ 后仍通过 $U_i$ 相关——即存在未测混杂。
2. **Negative control 假设**（图 1 的 DAG）：
   - $Z_i$ 与 $A_i$ 相关（通过 $U_i$），但与 $(T_i(a), C_i(a), W_i)$ 在给定 $(X_i, U_i)$ 后条件独立；
   - $W_i$ 与 $G_i(a;h)$ 相关（通过 $U_i$），但与 $(A_i, Z_i)$ 在给定 $(X_i, U_i)$ 后条件独立。
3. **Bridge function 存在性**（公式 2）：存在函数 $q$ 和 $f_a$ 使得
   $$E[q(Z_i, X_i) \mid X_i, U_i] = P(A_i=1 \mid X_i, U_i), \quad E[f_a(W_i, X_i) \mid X_i, U_i] = E[G_i(a;h) \mid X_i, U_i].$$
4. **条件独立删失**（公式 3）：$C_i(a) \perp T_i(a) \mid (X_i, W_i, Z_i, A_i=a)$。
5. **可观测数据**：$\{(X_i, W_i, Z_i, A_i, Y_i, \Delta_i)\}_{i=1}^n$，其中 $Y_i = \min(T_i, C_i)$，$\Delta_i$ 为事件指示符。

**关键区分**：
- **可观测**：$X, W, Z, A, Y, \Delta$
- **不可观测（潜在）**：$U$（混杂）、$T_i(a), C_i(a)$（反事实）、$G_i(a;h)$（反事实结局）

#### 第二步：最小内核

**剥掉所有一般性假设后，本文的核心数学问题是什么？**

考虑最简单的设定：**无删失**（$C_i = \infty$ 几乎必然）、**无协变量**（$X_i$ 为空）、**线性 bridge function**。此时：

- 可观测数据：$(A_i, Z_i, W_i, G_i)$，其中 $G_i = G_i(A_i;h)$ 是观测到的结局。
- 未测混杂 $U_i$ 同时影响 $A_i$、$Z_i$、$W_i$ 和 $G_i(a)$。
- Bridge function 简化为：$q(z) = P(A=1 \mid U)$ 的某种线性表示，$f_a(w) = E[G(a;h) \mid U]$ 的某种线性表示。

**核心问题**：如何仅用 $(A_i, Z_i, W_i, G_i)$ 的联合分布，识别并估计
$$\tau = E[G(1;h) - G(0;h)]?$$

**关键步骤**：

1. **构造残差**：定义 $A^{\text{res}}_i = A_i - q(Z_i)$。由 bridge 性质，$E[A^{\text{res}}_i \mid U_i] = 0$，即 $A^{\text{res}}$ 与 $U$ 在给定 $X$ 后不相关。
2. **构造残差结局**：$G^{\text{res}}_i = G_i - m(W_i, Z_i)$，其中 $m(w,z) = q(z) f_1(w) + (1-q(z)) f_0(w)$。由 bridge 性质，$E[G^{\text{res}}_i \mid U_i] = 0$。
3. **正交矩条件**：考虑损失 $\ell = \sum_i (G^{\text{res}}_i - \tau A^{\text{res}}_i)^2$。其得分函数在真值处满足 $E[\partial \ell / \partial \tau] = 0$，且对 nuisance 函数 $q, f_a$ 的 Gateaux 导数在真值处为零（Proposition 3.5 的局部正交性）。
4. **识别**：$\tau^w = \frac{E[A^{\text{res}} G^{\text{res}}]}{E[(A^{\text{res}})^2]}$，这是对 $\tau(x,u)$ 的加权平均，权重正比于 $(A - q(Z,X))^2$（Proposition 3.3）。

**为什么这个最小内核能成立？**

关键在于 **bridge function 的双重角色**：
- $q$ 消除了 $A$ 中与 $U$ 相关的部分（类似倾向得分，但不需要 ignorability）；
- $f_a$ 消除了 $G$ 中与 $U$ 相关的部分（类似 outcome regression，但允许未测混杂）；
- 两者结合使得残差 $A^{\text{res}}$ 和 $G^{\text{res}}$ 在给定 $X$ 后互不相关，从而识别出加权 CATE。

**证明的难点**：在一般设定下（有删失、有协变量、非线性 bridge），需要证明：
- 可观测矩条件（公式 6）确实隐含 bridge 方程（公式 2）——这需要 completeness 条件；
- 得分函数的正交性在 nuisance 估计误差为 $o_p(n^{-1/4})$ 时仍成立——这是 Proposition 3.6 的 LAN 结论；
- 删失修正（IPCW）不破坏正交性——这是 Proposition 3.5 的删失部分。

**一句话总结**：本文在数学上干的事是——**构造一个对 nuisance 估计误差一阶不敏感的、基于 negative control bridge function 的正交损失函数，并用随机森林最小化该损失以估计加权 CATE，同时证明该估计量的 $\sqrt{n}$ 渐近正态性**。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：在观测性生存分析中，当结局存在右删失且存在未测混杂时，如何用 negative control 变量非参数地估计异质性处理效应（HTE）。
2. **核心工具 / 方法**：将 proximal causal inference 的 bridge function 嵌入 causal survival forest 的损失函数，通过 Neyman 正交化构造对 nuisance 估计误差稳健的残差，并用随机森林最小化该损失。
3. **主要结论**：所提出的 NC-CSF 估计量在 nuisance 估计误差为 $o_p(n^{-1/4})$ 时，对加权 CATE 估计量具有 $\sqrt{n}$ 一致性和渐近正态性；在模拟中相比现有基线（CSF、RSF、BART）显著降低偏差和估计误差，在真实数据上验证了已知发现并揭示了新的异质性模式。

#### 关键设定与假设

在第二节最小记号的基础上，补全如下：

- **假设 1（Negative control 结构，公式 1）**：$(A_i, Z_i) \perp (T_i(a), C_i(a), W_i) \mid (X_i, U_i)$。这是 PCI 的核心假设，它比 ignorability 弱——允许 $A$ 依赖 $U$，但要求 $Z$ 和 $W$ 是 $U$ 的"纯代理"。
- **假设 2（Bridge function 存在性，公式 2）**：存在 $q$ 和 $f_a$ 满足两个条件期望方程。这等价于要求 $Z$ 对 $U$ 的"覆盖"足够强（completeness），是 PCI 识别性的关键。
- **假设 3（条件独立删失，公式 3）**：$C_i(a) \perp T_i(a) \mid (X_i, W_i, Z_i, A_i=a)$。这是生存分析的标准假设，但注意它是在包含 negative control 的变量集上做的——比 CSF 的删失假设更强（需要 $W, Z$ 也进入删失模型）。
- **假设 4（正则性条件）**：Proposition 3.6 要求 nuisance 估计量满足 $L^2$ 误差 $o_p(n^{-1/4})$，且残差方差有界、处理分配概率有界远离 0/1（overlap）。
- **相比已有文献的放宽/强化**：
  - 相比 CSF（Cui et al. 2020）：**放宽**了 ignorability，允许未测混杂；**强化**了删失假设（需要 negative control 也进入删失模型）。
  - 相比 PCI 的 ATE 估计（Cui et al. 2020; Kallus et al. 2021）：**放宽**了参数化 bridge function 的限制，允许非参数森林估计；**强化**了目标——从 ATE 扩展到 CATE。
  - 相比 Li et al. (2024) 的生存 PCI：**放宽**了参数化假设，但**未处理** competing risks。

#### 主要结果

**理论结果**：

- **Proposition 3.2（可观测矩条件）**：在假设 1-2 下，bridge 方程（2）等价于可观测矩条件（6）。这为估计提供了基础——不需要观测 $U$，只需用 $(X, W, Z, A, G)$ 的矩条件。
- **Proposition 3.3（得分有效性）**：NC-CSF 的得分函数在真值处条件期望为零，且其零点对应于加权 CATE $\tau^w(x)$。权重正比于 $(A - q(Z,X))^2$，即处理分配不确定性越大的子群，权重越高。
- **Proposition 3.5（Neyman 正交性）**：得分函数对 nuisance 参数 $q, m, S_C, \rho_a, \Lambda_C$ 的 Gateaux 导数在真值处为零。这意味着 nuisance 估计误差只产生二阶影响。
- **Proposition 3.6（局部渐近正态性）**：在 nuisance 估计 $L^2$ 误差为 $o_p(n^{-1/4})$ 的条件下，固定子群 $S$ 内的估计量满足 $\sqrt{n_S}(\hat{\tau}_S - \tau^w_S) \xrightarrow{d} N(0, \sigma^2_S)$，其中 $\sigma^2_S$ 有显式公式。

**证明路线与技术技巧**：

1. **整体路线**（3-5 步）：
   - **Step 1**：建立 bridge function 与可观测矩条件的等价性（Prop 3.2），将不可观测的 $U$ 积分掉。
   - **Step 2**：构造正交损失函数（公式 5），将 nuisance 估计（$q, f_a, S_C, \Lambda_C, \rho_a$）与目标参数 $\tau$ 分离。
   - **Step 3**：证明得分函数的 Neyman 正交性（Prop 3.5），通过对 nuisance 参数的 Gateaux 导数逐项计算，利用 bridge 方程和条件独立性假设消去所有一阶项。
   - **Step 4**：在正交性基础上，将估计量分解为目标项 +  nuisance 误差二阶项 + 经验过程项，利用交叉拟合（cross-fitting）和 nuisance 收敛速率条件控制各项。
   - **Step 5**：应用 Lyapunov CLT 和 delta method 得到渐近正态性（Prop 3.6）。

2. **关键技巧**：
   - **交叉拟合（cross-fitting）**：Algorithm 1 中 nuisance 估计和最终森林拟合使用不同的数据分割，避免过拟合导致的偏差。
   - **IPCW 伪结局**：用逆删失概率加权处理右删失，将删失问题转化为加权最小二乘问题。
   - **Bridge 混合结局**：$m(x,w,z) = q(z,x) f_1(w,x) + (1-q(z,x)) f_0(w,x)$ 将两个 bridge function 组合成一个可估计的回归函数。
   - **Neyman 正交化**：通过残差化（$A^{\text{res}} = A - q$）和中心化（$G^{\text{res}} = G - m$）同时消除处理分配和结局中的 $U$ 相关部分。

**实证结果**：

- **模拟**：在 12 个基础配置 × 22 个维度设置 = 264 个配置上评估。NC-CSF 相比 Censored Baseline 在 RMST 上 RMSE 降低 40.2%，在生存概率上 RMSE 降低 22.2%；相比 grf R-CSF 分别降低 17.9% 和 10.6%。组件消融（附录 11）显示 bridge 调整是最大的贡献来源。
- **真实数据**：
  - **ACTG175**：NC-CSF 估计的年龄异质性模式与 R-CSF 定性一致，但幅度更保守（峰值 6.37 天 vs 14.43 天），且 NC-CSF 在年轻组给出负值估计，与已有临床建议一致。
  - **RHC**：NC-CSF 估计的 ATE 为 −0.0433，介于 Kallus et al. 的 DR 估计（−0.0219）和线性 bridge 估计（−0.0607）之间，且置信区间更窄。
  - **MIMIC-IV**：在阳性对照组（他克莫司 + CYP3A 抑制剂）中，NC-CSF 估计 7 天无 AKI 生存率降低 0.2410，约为 CSF 估计（−0.1176）的两倍；在惰性对照组中无显著效应，支持其区分能力。

#### 🔎 结论是否比证明窄

**是，存在多处"证明窄于结论"的情况**：

1. **Proposition 3.6 的适用条件**：定理要求 nuisance 估计满足 $L^2$ 误差 $o_p(n^{-1/4})$，但文中未给出森林估计器满足该速率的充分条件（如稀疏性、光滑性、树深限制等）。作者在 Remark 3.7 中承认"递归学习的森林是否恢复唯一 oracle 划分"未证明，仅假设了固定或独立学习的子群。这意味着定理的实际适用范围比摘要中"非参数 HTE 学习器"的表述窄。

2. **加权目标**：Proposition 3.3 明确 $\tau^w(x)$ 是加权 CATE，权重正比于 $(A - q(Z,X))^2$。但摘要和引言中多处使用"HTE"和"$\tau(x)$"的表述，未强调这一加权。当 $U$ 对处理效应有修饰作用时，$\tau^w(x) \neq \tau(x)$（Remark 3.4 承认了这一点），但结论部分仍以"异质性处理效应"概括。

3. **删失假设的强度**：假设 3 要求删失独立于事件时间给定 $(X, W, Z, A)$，这比 CSF 的假设更强（需要 $W, Z$ 进入删失模型）。但文中未讨论当 $W, Z$ 不满足该条件时偏差的方向或大小。

4. **bridge function 的估计**：文中对 $q$ 使用 logistic 回归、对 $f_a$ 使用 ExtraTrees，但未给出这些估计器的收敛速率条件。Proposition 3.6 的 $o_p(n^{-1/4})$ 条件在实际中是否满足取决于这些 nuisance 估计器的性质，文中未验证。

### 四、开放问题

以下问题均扎根于文中具体语句，供研究者自行判断价值与可行性：

1. **递归划分的渐近理论**（扎根于 Remark 3.7）："It does not prove that a recursively learned forest recovers a unique oracle partition." 要证明递归学习的森林在 nuisance 函数估计误差存在时仍能恢复最优划分，需要什么样的条件？这与 exact recovery 的 minimax 速率（如 Padilla et al. 2021 的 lattice partition recovery）有何联系？

2. **加权目标的解释与替代**（扎根于 Remark 3.4 和公式 7）：$\tau^w(x)$ 与 $\tau(x)$ 的差异由 $\text{Cov}(\omega(x,U), \tau(x,U) \mid X=x)$ 决定。能否构造一个估计量直接针对 $\tau(x)$ 而非加权版本？需要什么样的额外假设？或者，能否给出 $\tau^w(x)$ 在何种决策意义上的最优性？

3. **bridge function 估计的正则化理论**（扎根于附录 A 和 Proposition 3.6 的条件）：当 bridge function 属于非参数函数类时，minimax 估计速率是多少？在什么条件下能达到 $o_p(n^{-1/4})$？这与 ill-posed inverse problem 的谱条件有何关联？

4. **删失假设的放松**（扎根于公式 3）：如果删失依赖于未测混杂 $U$（即 $C_i(a) \not\perp T_i(a) \mid (X_i, W_i, Z_i, A_i=a)$），偏差有多大？能否用 negative control 变量同时修正删失和混杂？

5. **negative control 的检验**（扎根于假设 1 的不可检验性）：文中承认 negative control 假设"not testable from the observed data alone"。能否构造部分可检验的 implication（如矩条件不等式）？这与 sensitivity analysis 的边界方法有何联系？

6. **效率界**（文中未讨论）：NC-CSF 估计量是否达到 semiparametric efficiency bound？其渐近方差 $\sigma^2_S$ 与半参数效率界的关系如何？是否存在更高效的估计量？
