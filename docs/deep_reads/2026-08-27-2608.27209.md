### 一、领域脉络与小综述

#### 这个方向是什么

这个子方向致力于为**全秩相关矩阵**（full-rank correlation matrices）的统计推断（尤其是假设检验）建立内在的黎曼几何框架，并探索该几何框架与经典渐近检验统计量之间的深层联系。其核心问题是：能否将相关矩阵的流形结构（即商空间结构）与基于Fisher信息的经典推断理论统一起来，从而为相关矩阵的相等性检验、置信区域构造等提供几何上自然、统计上有效的工具。当前，该方向处于“连接与统一”的早期阶段：2019年才引入商仿射度量，2021-2022年才得到闭式表达式，而本文是首次将该几何与1970年的经典检验结果建立精确的解析联系。

#### 发展脉络（history）

1. **奠基工作：经典检验的建立**  
   - **Jennrich (1970)**：在多元正态抽样假设下，推导了两个相关矩阵相等性的渐近χ²检验。其核心是：从高斯Fisher信息矩阵中，通过Schur补（profile information）消除边际标准差（nuisance parameters），得到相关矩阵的有效信息，并构造二次型统计量。该统计量包含一个“校正项”，用于消除边际尺度变化的影响。这是该领域的经典基准。

2. **主要进展：相关矩阵的黎曼几何**  
   - **David & Gu (2019)**：首次将全秩相关矩阵的流形识别为商空间 `Cor⁺(p) = SPD(p) / Diag⁺(p)`，其中正对角矩阵通过共轭作用 `Σ ↦ DΣD` 作用于协方差矩阵。每个纤维包含具有相同相关结构但不同边际尺度的协方差矩阵。在SPD(p)上赋予仿射不变度量 `G_Σ(A, B) = tr(Σ⁻¹A Σ⁻¹B)`，诱导出Cor⁺(p)上的商度量 `g^Q`。这是几何框架的奠基。
   - **Thanwerdas & Pennec (2021, 2022)**：推导了商仿射度量的闭式表达式（定理3），并研究了其测地线与曲率。他们指出，该度量的测地距离 `d_Q` 没有闭式解，其Riemannian对数也无闭式表达式，计算 `d_Q(C₁, C₂)` 需要最小化纤维上的仿射不变距离，且最小化器的唯一性未知。此外，作者声称“我们不知道这个距离的解析渐近零分布”。

3. **当前frontier与本文位置**：  
   - 本文（Kuketayev, 2026）是首次将上述两条线索连接起来的工作。作者证明：Jennrich统计量中的二次型恰好是商仿射度量张量的一半（Proposition 1）。这一恒等式的根源在于：从高斯Fisher信息中消除边际标准差（通过Schur补）与商掉对角缩放（通过商空间构造）执行了相同的投影操作。因此，Jennrich统计量直接评估了局部商仿射二次型。基于此，作者推导了商仿射测地距离的渐近零分布：对于两个独立高斯样本，经有效样本量缩放后的平方测地距离依分布收敛到 `4χ²_d`，其中 `d = p(p-1)/2`（Corollary 1）。当 `p=2` 时，该结果退化为两样本Fisher z检验。

#### 子线索聚类

- **线索一：经典假设检验与渐近理论**  
  以Jennrich (1970) 为核心，后续有Neudecker & Satorra (1996) 验证了Jennrich统计量的方差表达式与另一个独立推导的表达式代数等价。Neudecker (1996) 将结果推广到椭圆分布族，指出在共同峰度参数κ下，极限分布变为 `4(1+κ)χ²_d`。这条线索关注的是**统计量的构造、渐近分布及其对非正态分布的稳健性**。

- **线索二：相关矩阵的黎曼几何**  
  以David & Gu (2019) 和 Thanwerdas & Pennec (2021, 2022) 为核心。这条线索关注的是**相关矩阵流形的内在几何结构**（商空间、仿射不变度量、测地线、曲率），但此前缺乏与统计推断（尤其是假设检验）的直接联系。其测地距离的计算复杂，且无已知的渐近分布。

#### 这个方向在追问的核心问题

1. **几何距离的统计推断**：如何将相关矩阵流形上的内在距离（如商仿射测地距离）用于假设检验？其渐近零分布是什么？是否具有枢轴量性质（不依赖于未知总体相关矩阵）？
2. **几何与信息的统一**：商仿射度量张量与基于Fisher信息的有效信息矩阵之间是否存在精确的代数关系？这种关系能否为经典检验统计量提供几何解释？
3. **非高斯与高维推广**：在非高斯（如椭圆分布）或高维（p随n增长）设定下，上述几何-统计联系是否仍然成立？极限分布如何变化？
4. **有限样本精度**：由于测地距离的全局非线性，其局部二次型近似在有限样本或较大分离下的误差有多大？曲率如何影响高阶近似？

#### ⚠️ 作者的framing

作者将缺口frame成：“商仿射测地距离没有闭式解，且我们不知道其解析渐近零分布。” 然后通过证明Jennrich统计量恰好是局部商仿射二次型的一半，将Jennrich的渐近理论“转移”到测地距离上，从而填补了这一缺口。作者淡化了以下竞争路线：
- **其他Riemannian度量**：作者在第二节指出，对于p=2，多种度量重合，因此无法区分。但未讨论其他度量（如log-Euclidean、Cholesky等）是否也能与经典检验建立类似联系。
- **直接计算测地距离的数值方法**：作者承认测地距离计算复杂，但未将其作为主要障碍，而是通过局部二次型近似绕过了全局计算。
- **非参数或高维设定**：作者仅在第四节末尾提到椭圆分布下的推广（引用Neudecker 1996），但未深入讨论高维或非参数情形。

**什么明显该被引/该存在、却没出现在intro里？**  
- 没有引用关于相关矩阵流形上其他度量（如log-Euclidean、Cholesky、正定锥上的仿射不变度量）的统计推断工作。这些度量是否也能与Jennrich检验或其他经典检验建立联系？这是一个值得研究者去查的问题。
- 没有引用关于相关矩阵相等性检验的现代高维方法（如基于随机矩阵理论、稀疏性假设的方法）。这些方法在高维下可能比Jennrich检验更有效，但本文的几何框架能否推广到高维？这是一个开放问题。

#### 张力

未见明显对立引用。Jennrich (1970) 与 Thanwerdas & Pennec (2021) 的工作在数学上被本文统一，而非对立。Neudecker (1996) 的椭圆分布推广与本文的高斯假设是包含关系（椭圆包含高斯），而非矛盾。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：把符号、模型、可观测数据交代清楚

- **符号**：
  - `p`：变量维数（固定）。
  - `Cor⁺(p)`：所有 `p×p` 全秩相关矩阵构成的流形。一个相关矩阵 `C` 满足：`C = C^T`，`diag(C) = 1_p`（对角元全为1），且正定。
  - `SPD(p)`：所有 `p×p` 正定对称矩阵构成的流形（协方差矩阵）。
  - `Diag⁺(p)`：所有 `p×p` 正对角矩阵构成的群（边际尺度）。
  - `Σ = Δ C Δ`：协方差矩阵的分解，其中 `Δ = diag(σ₁, ..., σ_p)` 是正对角矩阵（边际标准差），`C` 是相关矩阵。
  - `G_Σ(A, B) = tr(Σ⁻¹A Σ⁻¹B)`：SPD(p)上的仿射不变度量（Riemannian度量）。
  - `g^Q_C(Y, Y)`：Cor⁺(p)上的商仿射度量，由 `G` 通过商空间构造诱导得到。`Y` 是 `C` 处的切向量（对称空心矩阵：`Y = Y^T`，`diag(Y) = 0`）。
  - `d_Q(C₁, C₂)`：Cor⁺(p)上关于 `g^Q` 的测地距离。
  - `R₁, R₂`：两个独立样本的样本相关矩阵，基于样本量 `n₁, n₂`。
  - `C`：共同的总体相关矩阵（零假设下）。
  - `a_n = n₁ n₂ / (n₁ + n₂)`：有效样本量（调和均值的一半）。
  - `n_eff = 2 a_n`：本文定义的缩放有效样本量。
  - `J_n`：Jennrich统计量。
  - `χ²_d`：自由度为 `d = p(p-1)/2` 的卡方分布。
  - `z = arctanh(ρ)`：Fisher z变换。

- **模型**：
  - 数据生成机制：两个独立的高斯总体，`X₁ ~ N(0, Σ₁)`，`X₂ ~ N(0, Σ₂)`，其中 `Σ₁ = Δ₁ C₁ Δ₁`，`Σ₂ = Δ₂ C₂ Δ₂`。零假设 `H₀: C₁ = C₂ = C`（相关矩阵相等），但边际标准差 `Δ₁, Δ₂` 可以不同（nuisance parameters）。
  - 统计模型：参数空间为 `(μ, σ, ρ)`，其中 `μ` 为均值（可设为0），`σ` 为边际标准差，`ρ` 为相关系数。本文关注的是 `ρ` 的推断。

- **可观测数据**：
  - **可观测**：两个独立样本的观测值矩阵（`n₁ × p` 和 `n₂ × p`），由此可计算样本协方差矩阵 `S₁, S₂` 和样本相关矩阵 `R₁, R₂`。`R₁, R₂` 是 `C` 的相合估计（在零假设下）。
  - **想要但观测不到**：总体相关矩阵 `C`（未知参数），以及边际标准差 `Δ₁, Δ₂`（nuisance parameters）。`C` 是推断目标，`Δ` 是干扰参数。

#### 第二步：讲最小内核——p=2的二元情形

本文的核心思路是：**商仿射测地距离的局部二次型近似恰好等于Jennrich统计量，因此测地距离继承了Jennrich检验的渐近分布**。这个思路在 `p=2` 的二元情形下变得完全显式且一目了然。

- **最简特例**：`p=2`，变量维数退化为1（只有一个相关系数 `ρ`）。此时 `Cor⁺(2)` 是一维流形，参数化为 `C(ρ) = [[1, ρ], [ρ, 1]]`，`ρ ∈ (-1, 1)`。

- **在已交代记号下的展开**：
  - **商仿射测地距离**：Thanwerdas & Pennec (2021, Theorem 6) 给出闭式解：
    ```
    d_Q(C(ρ₁), C(ρ₂)) = √2 |z(ρ₂) - z(ρ₁)|,  其中 z = arctanh (Fisher z变换).
    ```
    即，测地距离恰好是 `√2` 倍的两个Fisher z分数之差。这是全局结果，不是局部近似。

  - **Jennrich统计量**：对于 `p=2`，Jennrich统计量 `J_n` 退化为（经过计算）：
    ```
    J_n = a_n * (z(r₁) - z(r₂))²,
    ```
    其中 `r₁, r₂` 是样本相关系数。这正是两样本Fisher z检验的统计量。

  - **恒等式**：由上述两式，立即得到：
    ```
    n_eff * d_Q² = 2a_n * [√2 |z(r₁)-z(r₂)|]² = 4a_n (z(r₁)-z(r₂))² = 4 J_n.
    ```
    这正是Corollary 1在 `p=2` 时的形式。

  - **渐近分布**：在零假设 `ρ₁ = ρ₂ = ρ` 下，经典结果给出：
    ```
    √(a_n) (z(r₁) - z(r₂)) → N(0, 1)  (依分布收敛).
    ```
    因此：
    ```
    n_eff * d_Q² = 4 J_n → 4 χ²_1  (依分布收敛).
    ```
    这就是Corollary 1。

- **为什么这个特例揭示了核心**：
  - 在 `p=2` 时，商仿射测地距离有**全局闭式解**（`√2`倍Fisher z差），而不仅仅是局部二次型。因此，恒等式 `n_eff d_Q² = 4 J_n` 是**精确的**，不依赖于局部近似。这直接展示了“测地距离 = 经典检验统计量的缩放”这一核心思想。
  - 对于 `p > 2`，测地距离没有闭式解，但局部二次型近似仍然成立，且该二次型恰好等于Jennrich统计量。因此，`p=2` 是理解全文的“理想实验室”：它去掉了所有为一般性服务的技术复杂性（局部展开、泰勒余项、相合估计替换），直接展示了恒等式的本质。
  - 作者在第二节明确指出：“二元情形是一维的，因此无法将商仿射度量与其他Riemannian度量区分开；它是一个导向，而非一个变换的特例。” 这意味着 `p=2` 虽然简单，但足以揭示核心代数关系，而更高维的推广则需要处理更复杂的几何结构（如曲率）。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：建立了全秩相关矩阵的商仿射Riemannian几何（2019年引入）与Jennrich (1970) 经典相关矩阵相等性检验之间的精确联系。
2. **核心工具/方法**：通过证明Jennrich统计量中的二次型恰好是商仿射度量张量的一半（Proposition 1），将Jennrich的渐近理论“转移”到商仿射测地距离上，从而推导出该测地距离的渐近零分布。
3. **主要结论**：对于两个独立高斯样本，在共同总体相关矩阵下，经有效样本量缩放后的平方商仿射测地距离依分布收敛到 `4χ²_d`，其中 `d = p(p-1)/2`（Corollary 1）。该极限不依赖于总体相关矩阵，因此测地距离是渐近枢轴量。

#### 关键设定与假设

- **设定**：
  - 两个独立的高斯总体，`N(0, Σ₁)` 和 `N(0, Σ₂)`。
  - 零假设 `H₀: C₁ = C₂ = C`，其中 `C ∈ Cor⁺(p)` 是未知的总体相关矩阵。
  - 边际标准差 `Δ₁, Δ₂` 是nuisance parameters，可以不同。
  - 维数 `p` 固定，样本量 `n₁, n₂ → ∞`，且 `n₁/(n₁+n₂) → η ∈ (0,1)`。

- **假设**：
  - **高斯性**：数据来自多元正态分布。这是Jennrich检验和本文Corollary 1的核心假设。作者在第四节提到，对于椭圆分布族（共同峰度参数κ），极限分布变为 `4(1+κ)χ²_d`（引用Neudecker 1996），但本文未证明。
  - **共同总体相关矩阵**：零假设下，两个总体的相关矩阵相等。
  - **固定维数**：`p` 固定，不随样本量增长。这是经典渐近框架。
  - **全秩**：总体相关矩阵 `C` 是正定的（全秩），这是商空间构造 `Cor⁺(p) = SPD(p)/Diag⁺(p)` 的前提。

- **相比已有文献的放宽/强化**：
  - **放宽**：相比直接计算商仿射测地距离（需要数值优化，无闭式解），本文通过局部二次型近似绕过了全局计算，使得渐近推断成为可能。
  - **强化**：相比Jennrich (1970) 的纯统计推导，本文为其“校正项”提供了几何解释：它恰好是商掉边际尺度方向后去除的分量。这是对经典结果的重新诠释，而非放宽假设。

#### 主要结果

- **Proposition 1（核心恒等式）**：
  - **陈述**：对于任意 `C ∈ Cor⁺(p)` 和任意切向量 `Y ∈ T_C Cor⁺(p)`（对称空心矩阵），Jennrich二次型 `χ²_J(Y, C)` 等于商仿射度量 `g^Q_C(Y, Y)` 的一半。
  - **直觉**：这个恒等式是代数上的直接验证（比较公式(1)和(2)），但其统计意义深远：Jennrich统计量本质上是在评估局部商仿射几何。证明的关键在于认识到，从高斯Fisher信息中消除边际标准差（通过Schur补）与商掉对角缩放（通过商空间构造）执行了相同的投影操作。
  - **必要条件**：高斯性（Fisher信息公式(3)成立），以及 `C` 的全秩性。
  - **解决的技术难点**：将两个看似无关的表达式（一个来自统计推断，一个来自Riemannian几何）识别为同一个对象。这需要理解剖面信息（profile information）与水平投影（horizontal projection）的等价性（引用Fewster & Jupp 2013）。

- **Corollary 1（渐近零分布）**：
  - **陈述**：在固定 `p`、高斯抽样、共同总体相关矩阵 `C` 下，`n_eff * d_Q²(R₁, R₂) → 4χ²_d`（依分布收敛），其中 `d = p(p-1)/2`。
  - **直觉**：由于 `R₁, R₂` 在 `n^{-1/2}` 尺度上接近 `C`，测地距离的全局非线性可以局部近似为其切空间上的二次型（即商仿射度量）。Proposition 1 将该二次型与Jennrich统计量等同，而Jennrich统计量的渐近分布已知为 `χ²_d`。因此，测地距离的渐近分布是 `4χ²_d`。
  - **必要条件**：除了Proposition 1的条件外，还需要 `R₁, R₂` 是 `C` 的 `√n`-相合估计（高斯抽样保证），以及测地距离在 `(C, C)` 附近的光滑性（Taylor展开成立）。
  - **解决的技术难点**：将局部二次型近似（公式(7)）与Jennrich统计量的表达式（公式(6)）结合，并处理用相合估计 `R̄` 替换未知 `C` 带来的额外误差（`o_p(1)`）。

#### 证明路线与技术技巧

- **整体路线**（3-5步逻辑主干）：
  1. **建立恒等式**：直接验证Jennrich二次型 `χ²_J(Y, C)` 与商仿射度量 `g^Q_C(Y, Y)` 的代数关系（Proposition 1）。这一步是精确的，不涉及渐近。
  2. **将Jennrich统计量表示为局部二次型**：利用Proposition 1，将Jennrich统计量 `J_n = χ²_J(X_n, R̄)` 写为 `J_n = (a_n/2) * g^Q_{R̄}(R₁-R₂, R₁-R₂)`（公式(6)）。这里 `X_n = √(a_n)(R₁-R₂)`，`R̄` 是 pooled 样本相关矩阵。
  3. **将测地距离展开为局部二次型**：在 `(C, C)` 附近对 `d_Q²(R₁, R₂)` 进行Taylor展开（公式(7)），得到 `d_Q² = g^Q_C(R₁-R₂, R₁-R₂) + O_p(a_n^{-3/2})`。由于主项是 `O_p(a_n^{-1})`，余项是 `o_p(a_n^{-1})`。
  4. **替换未知总体参数**：用相合估计 `R̄` 替换 `C`，证明 `g^Q_{R̄}(R₁-R₂, R₁-R₂) = g^Q_C(R₁-R₂, R₁-R₂) + o_p(a_n^{-1})`。
  5. **合并得到渐近分布**：结合步骤2-4，得到 `n_eff * d_Q² = 4J_n + o_p(1)`。由于 `J_n → χ²_d`（Jennrich 1970），Slutsky定理给出 `n_eff * d_Q² → 4χ²_d`。

- **关键跳跃点**：
  - **从全局测地距离到局部二次型**（公式(7)）：这是最关键的跳跃。作者声称“平方Riemannian距离在靠近对角线处是光滑的”，因此可以进行Taylor展开。但这一光滑性在商流形上需要验证，因为商流形的坐标图可能不是全局的。作者没有给出严格证明，而是将其作为已知事实（“smooth near the diagonal”）。对于固定 `p`，由于 `Cor⁺(p)` 是光滑流形，且 `d_Q²` 是光滑函数，这一展开在适当的坐标图下是合理的。但严格证明需要用到Riemannian法坐标（normal coordinates）的性质。
  - **用 `R̄` 替换 `C` 的误差控制**：作者声称“Replacing `C` by the consistent `R̄` perturbs the quadratic term by `o_p(a_n^{-1})` also”。这需要证明 `g^Q_C(Y, Y)` 作为 `C` 的函数是Lipschitz连续的，且 `R̄ - C = O_p(1/√(n₁+n₂))`。由于 `Y = R₁-R₂ = O_p(1/√(a_n))`，乘积的误差是 `O_p(1/√(n₁+n₂)) * O_p(1/a_n) = o_p(1/a_n)`。这一论证是标准的，但作者未展开。

- **技术技巧点名**：
  - **Schur补/剖面信息**：用于从高斯Fisher信息中消除边际标准差，得到相关矩阵的有效信息。这是Jennrich (1970) 的核心技巧，也是本文恒等式的统计根源。
  - **商空间构造与水平投影**：用于从SPD(p)上的仿射不变度量诱导出Cor⁺(p)上的商度量。Fewster & Jupp (2013) 的“水平信息”（horizontal information）概念是连接Schur补与商投影的桥梁。
  - **Taylor展开/局部二次型近似**：用于将全局测地距离近似为切空间上的二次型。这是将恒等式（局部）推广到距离（全局）的关键。
  - **Slutsky定理**：用于将 `n_eff * d_Q² = 4J_n + o_p(1)` 转化为分布收敛。

#### 真实例子与应用

本文为**纯理论论文，无真实数据例子或模拟实验**。唯一的“例子”是第二节的 `p=2` 二元情形，但这是作为理论推导的导向（orientation），而非实证验证。作者没有展示任何数值模拟来验证Corollary 1在有限样本下的表现（如经验size、power），也没有与任何baseline方法（如直接使用Jennrich检验）进行对比。因此，本文的贡献完全是理论性的：建立几何与统计的联系，并推导渐近分布。

#### 🔎 结论是否比证明窄

- **Corollary 1的局部性**：作者在第四节明确承认：“Proposition 1是一个精确的恒等式，而Corollary 1是局部的和渐近的：度量张量仅在两个样本矩阵以 `n^{-1/2}` 尺度相互接近时才主导行为。对于有限或更大的分离，完整的非线性几何不一定能被Jennrich的二次型近似所捕捉。” 这意味着Corollary 1的结论（测地距离的渐近分布）严格依赖于“局部”假设，不能直接推广到 `d_Q` 较大的情形。这是一个重要的窄化。
- **高斯假设的必要性**：Corollary 1的证明依赖于Jennrich (1970) 的渐近结果，而后者假设高斯性。作者提到椭圆分布下的推广（Neudecker 1996），但未证明在椭圆分布下Proposition 1是否仍然成立（因为Fisher信息公式(3)在高斯下才成立）。因此，Corollary 1的适用范围严格限于高斯总体。
- **固定维数**：所有结果都假设 `p` 固定。对于高维情形（`p` 随 `n` 增长），Jennrich检验本身可能失效（统计量发散或分布非χ²），因此Corollary 1不能直接推广。作者未讨论高维设定。

### 四、开放问题（点到为止，扎根具体语句）

1. **非高斯推广**：Corollary 1的证明依赖于高斯Fisher信息公式(3)。对于非高斯分布（如椭圆分布），Fisher信息的形式不同，Proposition 1的恒等式是否仍然成立？若不成立，商仿射测地距离的渐近分布是什么？**扎根**：第四节提到“如果两个总体是椭圆分布且具有共同峰度参数κ，Neudecker (1996) 的比例性结果将极限替换为 `4(1+κ)χ²_d`。” 但本文未证明这一结果是否可以从几何角度推导，也未讨论κ未知时的推断。

2. **高维设定**：当 `p` 随 `n` 增长时，Jennrich统计量的渐近分布不再是 `χ²_d`（因为 `d` 发散）。商仿射测地距离在高维下的行为如何？是否存在一个“高维极限”或“随机矩阵理论”框架？**扎根**：全文假设“固定p”，未讨论高维情形。这是经典渐近理论的固有局限。

3. **有限样本精度与曲率校正**：Corollary 1是局部渐近结果。对于有限样本或中等分离，测地距离的全局非线性会导致多大误差？能否利用商仿射流形的曲率（Thanwerdas & Pennec 2021, 2022 已给出闭式表达式）进行高阶校正，从而改进有限样本下的近似？**扎根**：第四节末尾提到“在法坐标中，曲率在四阶进入展开”，但“量化由此产生的近似误差是一个单独的问题”。

4. **其他Riemannian度量的统计推断**：商仿射度量只是相关矩阵流形上的一种度量。其他度量（如log-Euclidean、Cholesky、正定锥上的仿射不变度量）是否也能与Jennrich检验或其他经典检验建立类似联系？**扎根**：引言中未引用其他度量的统计推断工作。这是一个值得研究者去查的潜在gap：去读同子领域近期约5篇的intro，看是否都指向“商仿射度量是唯一与Jennrich检验有联系的”，还是存在其他竞争路线。
