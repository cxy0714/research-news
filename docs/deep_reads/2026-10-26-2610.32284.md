### 一、领域脉络与小综述

- **这个方向是什么**：本文研究的是高维随机矩阵理论（RMT）中的一个基础问题：当观测数据来自一个**非平稳**的向量自回归（VAR）过程时，样本相关矩阵的谱（特征值分布）会呈现什么样的极限行为？传统RMT（如Marchenko-Pastur定律）处理的是独立同分布（i.i.d.）或弱相关数据，而时间序列（尤其是非平稳时间序列）会引入强依赖结构，使得经典结论失效。本文的核心贡献在于刻画了**特征多项式根的位置**（单位圆上 vs. 单位圆外）如何决定样本相关矩阵的谱行为——是退化为零点的点质量，还是保持非平凡结构。这个子方向处于"高维统计 + 时间序列 + RMT"的交叉地带，目前成熟度中等：平稳情形的理论已较完善，但非平稳情形的系统性结果非常少。

- **发展脉络（history）**：
    - **奠基工作**：经典RMT中，样本协方差矩阵的极限谱分布由Marchenko-Pastur定律刻画（Bai & Silverstein [1] 的专著是标准参考）。样本相关矩阵（即对每行做标准化后的协方差矩阵）的谱理论由 Jiang [17] 和 Bai & Zhou [2] 奠定，他们证明了在**独立或弱相关**样本下，相关矩阵的谱行为与协方差矩阵类似，且极端特征值服从Tracy-Widom（TW）定律 [4, 22]。
    - **主要进展（平稳时间序列）**：当数据来自**平稳**VAR过程时，Mei, Wang & Yao [21] 建立了样本协方差矩阵的极限谱分布（广义Marchenko-Pastur分布），这是本文的直接对标物。该工作表明，平稳性（根在单位圆内）保证了谱分布的非退化性。
    - **当前frontier（非平稳与强依赖）**：非平稳时间序列（单位根或爆炸根）的谱理论是当前活跃但尚未充分探索的方向。Heiny & Yao [16] 研究了重尾情形下的相关矩阵，但未涉及非平稳VAR。本文是首个系统处理**非平稳VAR**样本相关矩阵谱性质的工作，填补了"根在单位圆上/外"这一空白。
    - **本文的位置**：作者将 [21] 的平稳结果推广到非平稳情形，并发现了一个**本质不同的现象**：非平稳性导致谱分布退化到零点，但极端特征值仍携带信息，且其极限行为由特征多项式根的**代数结构**（而非统计噪声）决定。这构成了对 [21] 的非平凡扩展。

- **子线索聚类**：
    1.  **样本相关矩阵的谱理论**：Jiang [17], Bai & Zhou [2], Bao et al. [3], Zheng et al. [32]。这条线关注相关矩阵（而非协方差矩阵）的极限谱分布和极端特征值，强调标准化带来的非线性效应。
    2.  **时间序列的随机矩阵极限**：Mei, Wang & Yao [21]（平稳VAR），Heiny & Yao [16]（重尾）。这条线将RMT工具应用于时间序列数据，核心难点是处理时间依赖。
    3.  **非平稳过程的渐近理论**：本文引用的 [15]（Toeplitz矩阵理论）和 [20]（循环矩阵谱分解）是处理非平稳VAR的技术基础，它们提供了分析单位根/爆炸根过程生成矩阵的工具。
    4.  **极端特征值的极限分布**：Bao, Pan & Zhou [4], Pillai & Yin [22]。这条线关注最大特征值的波动性，本文的定理2.1属于此范畴，但结论是**非TW型**的，而是由有限维随机矩阵决定。

- **这个方向在追问的核心问题**：
    1.  **谱分布的退化性**：非平稳性是否必然导致经验谱分布（ESD）退化到零点？退化速度如何？（本文定理2.2给出肯定答案，且退化速度与根的位置有关。）
    2.  **极端特征值的极限**：当谱分布退化时，最大的几个特征值是否仍发散？发散速率和极限分布是什么？（本文定理2.1和3.1给出答案：发散速率由根决定，极限分布由有限维随机矩阵决定。）
    3.  **秩的渐近行为**：非平稳性是否导致样本相关矩阵渐近低秩？秩的渐近上界是什么？（本文定理3.1给出：超非平稳情形下秩渐近不超过某个有限常数。）
    4.  **与平稳情形的分界**：根从单位圆内移到单位圆上/外，谱行为如何从非退化连续过渡到退化？（这是本文未完全回答、但隐含在定理2.1和3.1中的问题。）

- **⚠️ 作者的 framing（这是作者的说法）**：作者将缺口frame成"非平稳VAR的谱理论完全空白，而实际数据（如宏观经济、金融）常呈现非平稳性，因此需要建立相应的极限理论"。他们强调，**根的位置**是决定谱行为的唯一关键因素，并据此将问题分为N（非平稳）和SN（超非平稳）两种情形。**被淡化/回避的竞争路线**：
    - 作者假设噪声ε_t的四阶矩有限且密度有界（假设2.1），但未讨论**重尾**情形（Heiny & Yao [16] 处理过），这限制了结果的适用范围。
    - 作者假设VAR的系数是**标量**（a_l ∈ R），而非矩阵。高维VAR（系数为矩阵）是更一般的设定，但本文未涉及。
    - 作者未讨论**推断问题**（如如何基于这些极限结果做假设检验），只停留在描述性极限理论。
    - **明显该被引、却没出现在intro里**：作者未引用Bai & Silverstein [1] 中关于**样本协方差矩阵谱分布的一般性条件**（如矩条件、维度比例），也未引用关于**非平稳时间序列的泛函中心极限定理**（如Phillips-Perron检验的谱理论），这些可能为他们的结果提供更广泛的背景或替代证明路径。

- **张力**：未见明显对立引用。但存在一个**隐含张力**：Mei, Wang & Yao [21] 的平稳结果中，谱分布是非退化的（广义Marchenko-Pastur），而本文的非平稳结果中谱分布退化到零点。这两者之间如何过渡（当根从单位圆内趋近单位圆时）是一个未被讨论的连续性问题，可能蕴含更深刻的相变现象。


### 二、最核心、最简单的例子 / 数学问题

**第一步：把符号、模型、可观测数据交代清楚**

- **数据生成机制**：观测数据矩阵 X = [X_1, ..., X_T] ∈ R^{n×T}，其中每一列 X_t ∈ R^n 是 n 维时间序列在时刻 t 的观测。X_t 由如下 n 维 VAR(d) 过程生成：
  ```
  X_t + a_1 X_{t-1} + ... + a_d X_{t-d} = Γ ε_t
  ```
  其中：
  - **a_l ∈ R**（标量系数，l = 1,...,d），d 固定。
  - **Γ ∈ R^{n×n}**：截面相关矩阵（cross-sectional dependence），控制 n 个分量之间的同期相关性。
  - **ε_t = (ε_{1,t}, ..., ε_{n,t})'**：噪声向量，ε_{i,t} 独立同分布，均值为 0，方差为 1，四阶矩有限，密度有界（假设2.1）。
- **特征多项式与根**：定义特征多项式 f_X(x) = x^d + a_1 x^{d-1} + ... + a_d，其根为 r_1, ..., r_d ∈ C。根的模长决定时间序列的平稳性：
  - |r_l| < 1：平稳根（stationary）；
  - |r_l| = 1：非平稳根（nonstationary）；
  - |r_l| > 1：超非平稳根（super-nonstationary）。
- **可观测数据**：研究者能观测到的是 X（n×T 矩阵），以及假设已知的 d 和系数 a_l。**不可观测**的是：噪声 ε_t、截面相关矩阵 Γ、以及特征多项式的根 r_l（虽然可由 a_l 计算，但根的性质是理论分析的对象）。
- **目标量（estimand）**：
  - **样本相关矩阵**：R̂ = diag(XX')^{-1/2} XX' diag(XX')^{-1/2}。注意这里是对**行**（即每个分量的时间序列）做标准化，而非对列（时间点）。
  - **经验谱分布（ESD）**：ν_n(x) = (1/n) Σ_{k=1}^n 1_{λ_k ≤ x}，其中 λ_k 是 R̂ 的特征值。
  - **极端特征值**：λ̂_1 ≥ ... ≥ λ̂_n，特别是最大的 K 个（K 固定）。
- **关键参数**：
  - **维度比**：c = lim_{n,T→∞} n/T ∈ (0,∞)（假设1.1）。
  - **根的重数**：d_1 = max{d_l : l = 1,...,m}，其中 m 是非平稳根的个数；m_0 = #{l : d_l = d_1} 是达到最大重数的非平稳根个数。
  - **系数**：a_l = lim_{z→r_l} f_X(z)/(z-r_l)^{d_l}，即特征多项式在根 r_l 处的留数。

**第二步：讲最小内核**

本文的核心数学问题可以归结为：**当 X_t 由非平稳 VAR 生成时，样本相关矩阵 R̂ 的谱行为由什么决定？**

**最小内核（最简特例）**：考虑最简单的非平稳情形——**一阶VAR（d=1）且只有一个单位根**：
```
X_t = X_{t-1} + Γ ε_t,   X_0 = 0
```
此时特征多项式 f_X(x) = x - 1，唯一的根 r_1 = 1（在单位圆上），重数 d_1 = 1，m_0 = 1。

- **可观测数据**：X_t = Γ Σ_{s=1}^t ε_s，即 X 是噪声的累积和（随机游走）。
- **关键观察**：由于 X_t 是累积和，X 的每一行（每个分量的时间序列）都是 O_p(√T) 的量级，而非平稳情形的 O_p(1)。因此，标准化后的行向量 X_i / ||X_i|| 会收敛到一个**随机方向**，这个方向由 Γ 和噪声的长期累积决定。
- **核心结论**：此时 R̂ 的谱行为如下：
    1.  **ESD退化**：几乎所有特征值都趋于 0，因为 R̂ 的秩最多为 T（实际上由于标准化，秩为 n），但非平稳性使得大部分特征值集中在 0 附近。
    2.  **最大特征值**：λ̂_1 / n 依概率收敛到一个常数 c_1 ∈ (0,1)。这个常数由 Γ 和根的结构决定，具体地，c_1 = λ_max(Γ Γ') / (λ_max(Γ Γ') + 某个由根决定的常数)。
    3.  **极限分布**：√n(λ̂_1/n - c_1) 的极限分布等于一个 **k_0 × k_0 对称随机矩阵的最大特征值**的分布，其中 k_0 = 1（因为只有一个单位根）。这个随机矩阵的元素是高斯随机变量的函数，其协方差结构由 Γ 和根决定。

**为什么这个特例是"最小内核"**：
- 它剥离了所有技术复杂性（高阶VAR、多个根、超非平稳），只保留了非平稳性的本质——**累积效应**。
- 它展示了本文最核心的机制：**非平稳性导致 X 的行向量发散，标准化后收敛到随机方向，从而使得 R̂ 的谱由这些随机方向的"内积矩阵"决定**。这个内积矩阵是有限维的（维度等于最大重数的根个数），因此极端特征值的极限分布是有限维随机矩阵的特征值分布。
- 一般情形（多个根、高阶VAR、超非平稳）只是这个机制的"加壳"：不同的根对应不同的累积速率，超非平稳根（|r|>1）导致指数级发散，但核心的"标准化→随机方向→有限维内积矩阵"的逻辑不变。

**数学上，本文干的事情是**：证明在非平稳VAR下，R̂ 的谱行为由特征多项式根的**模长和重数**决定，且极端特征值的极限分布可以显式地用有限维随机矩阵表示。这个有限维随机矩阵的维度等于最大模长根的重数之和，其元素是高斯随机变量的函数。


### 三、这篇论文做了什么

**三句话**：
1. **研究了什么问题**：高维非平稳VAR过程生成的样本相关矩阵 R̂ 的经验谱分布（ESD）和极端特征值的渐近行为。
2. **核心工具/方法**：将 VAR 过程分解为特征多项式根的贡献（部分分式分解），利用 Toeplitz 矩阵的谱理论（[15]）和循环矩阵的谱分解（[20]）刻画 U = T^{-1} 的奇异值结构，再结合 Lindeberg 替换原理和随机矩阵的有限维近似。
3. **主要结论**：在非平稳（N）和超非平稳（SN）两种情形下，R̂ 的ESD均退化为零点处的点质量；极端特征值经缩放后依分布收敛到由特征多项式根决定的有限维对称随机矩阵的特征值；在SN情形下，R̂ 依概率退化为有限秩矩阵。

**关键设定与假设**：
- **假设1.1（维度比）**：n/T → c ∈ (0,∞)。这是高维RMT的标准设定，保证维度与样本量同阶。
- **假设2.1（噪声矩条件）**：ε_{i,t} 独立，均值为0，方差为1，四阶矩有限（E[ε^4] < ∞），且密度函数一致有界。四阶矩有限用于控制标准化分母的波动；密度有界用于Lindeberg替换（保证替换后的分布接近）。
- **假设2.2（谱范数条件）**：||Σ|| = ||ΓΓ'|| ≲ 1 且 ||Σ^{-1}|| ≲ 1。这保证截面相关矩阵的条件数有界，避免退化情形。
- **相比已有文献的放宽/强化**：
    - **放宽**：允许非平稳性（根在单位圆上或外），这是对 [21]（仅平稳）的实质性推广。
    - **强化**：假设噪声密度有界（假设2.1.2），这是Lindeberg替换的技术需要，但排除了离散分布；假设系数为标量（a_l ∈ R），而非矩阵，限制了VAR的 generality。

**主要结果**：
- **定理2.1（N情形，极端特征值）**：设 k_0 由特征多项式根的模长和重数决定（具体地，k_0 = #{l : |a_l| = min{|a_1|,...,|a_{m_0}|}}，其中 a_l 是根 r_l 的留数）。则
  √n(λ̂_1/n - M_{1,1}, ..., λ̂_{k_0}/n - M_{1,1}) 依分布收敛到 (λ_1(G_n[1:k_0]), ..., λ_{k_0}(G_n[1:k_0]))，
  其中 G_n[1:k_0] 是一个 k_0 × k_0 对称随机矩阵，其元素由高斯随机变量构成，协方差结构由 Γ 和根决定。M_{1,1} 是 λ̂_1/n 的渐近均值，由 Γ 和根决定。
  **直觉**：最大 k_0 个特征值携带了非平稳根的信息，它们的波动幅度是 O_p(n^{-1/2})，且极限分布不是TW，而是由有限维随机矩阵决定。
- **定理2.2（N情形，ESD）**：对任意 ε ≍ log^{-1}(n)，(1/n) #{λ̂_k < ε} → 1 依概率。即几乎所有特征值都趋于0，ESD退化为零点处的点质量。
  **直觉**：非平稳性使得大部分特征值"坍缩"到0，只有少数极端特征值发散。
- **定理3.1（SN情形，秩退化）**：若存在模长大于1的根，则 R̂ 的秩依概率收敛到某个有限常数 d_SN（由根的结构决定），且 λ̂_1/n 依概率收敛到 c_1 ∈ (0,1]。
  **直觉**：超非平稳根导致 X 的行向量以指数速率发散，标准化后收敛到有限维子空间，因此 R̂ 渐近为有限秩矩阵。
- **定理3.2（SN情形，极端特征值）**：在噪声为高斯的假设下，√n(λ̂_1/n - M_{1,1}, ..., λ̂_{k_0}/n - M_{1,1}) 的极限分布与定理2.1形式相同，但 k_0 和随机矩阵 G_n 由超非平稳根决定。
  **注意**：定理3.2需要高斯噪声假设，因为SN情形下Lindeberg替换失效（奇异向量不局域化），作者改用精确高斯计算。

**证明路线与技术技巧**：
1.  **整体路线**：
    - **步骤1（分解）**：将 X = Γ ε U，其中 U = T^{-1} 是 VAR 系数矩阵的逆（Toeplitz矩阵）。利用部分分式分解，将 U 分解为各特征根对应的项之和。
    - **步骤2（奇异值结构）**：利用 [15] 的Toeplitz矩阵谱理论，证明 U 的奇异值具有"块结构"：前 k_0 个奇异值远大于其余，且对应的奇异向量在 Fourier 基下"局域化"（即能量集中在少数频率）。
    - **步骤3（Lindeberg替换）**：将 ε 替换为高斯随机矩阵 Z。利用奇异向量的局域化性质，证明替换前后 R̂ 的极端特征值的联合分布之差趋于0（四阶矩条件保证替换误差可控）。
    - **步骤4（有限维近似）**：替换为高斯后，R̂ 的极端特征值近似等于一个 k_0 × k_0 随机矩阵的特征值，该矩阵的元素是高斯随机变量的函数。
    - **步骤5（连续映射）**：利用连续映射定理，从有限维随机矩阵的特征值分布得到极端特征值的极限分布。
2.  **关键技巧**：
    - **部分分式分解**：将 U 分解为 (I - r_l T(1))^{-1} 的线性组合，将问题转化为对每个根的单独分析。
    - **Toeplitz矩阵的渐近谱**：利用 [15] 的结果，将 Toeplitz 矩阵的奇异值问题转化为连续核算子的特征值问题，从而得到奇异值的渐近行为。
    - **Lindeberg替换**：这是证明的核心技巧。作者将非高斯噪声替换为高斯噪声，利用四阶矩条件和奇异向量局域化性质控制替换误差。替换后，问题简化为高斯随机矩阵的谱分析。
    - **奇异向量局域化**：证明 U 的前 k_0 个奇异向量在 Fourier 基下能量集中，这是Lindeberg替换可行的关键。局域化性质由特征多项式根的模长和重数决定。

**真实例子与应用**：本文为纯理论论文，**无真实数据例子、无模拟实验**。所有结果均为渐近定理，没有有限样本性质的数值验证。

**🔎 结论是否比证明窄**：
- **定理2.1的陈述**：定理声称"√n(λ̂_1/n - M_{1,1}, ..., λ̂_{k_0}/n - M_{1,1}) 依分布收敛到 (λ_1(G_n[1:k_0]), ..., λ_{k_0}(G_n[1:k_0]))"，但证明中（步骤4）实际只证明了**联合分布**的收敛，且依赖于 k_0 的有限性。如果 k_0 随 n 增长（例如根的重数随维度变化），定理不适用。作者在假设中隐含了 k_0 固定，但未明确说明。
- **定理2.2的陈述**：定理声称"对任意 ε ≍ log^{-1}(n)，(1/n) #{λ̂_k < ε} → 1"，但证明中使用了 Markov 不等式和 E[λ̂_k] 的界，这只能得到**依概率**收敛，且收敛速度是 O(log^{-1}(n))。作者未讨论能否将 ε 取为更小的量级（如 n^{-α}），这限制了定理的精度。
- **定理3.1的陈述**：定理声称"R̂ 的秩依概率收敛到 d_SN"，但证明中只证明了**特征值之和**的收敛性，并未直接证明秩的收敛。作者通过"若秩大于 d_SN，则存在 d_SN+1 个非零特征值，其和至少为 (d_SN+1)ε"这一反证法来间接证明，但 ε 的选取依赖于 n，且未给出 d_SN 的显式表达式。
- **定理3.2的陈述**：定理声称"在噪声为高斯的假设下，极限分布与定理2.1形式相同"，但证明中使用了精确高斯计算，**未验证非高斯情形下结论是否成立**。作者在Remark 3.2.1中承认Lindeberg替换失效，但未给出反例或替代证明。

### 四、开放问题（点到为止，扎根具体语句）

1. **重尾噪声的推广**：作者在假设2.1中要求四阶矩有限且密度有界，但未讨论重尾情形。Heiny & Yao [16] 处理了重尾独立样本，但非平稳VAR+重尾的组合仍是空白。**扎根**：假设2.1.1的"E[ε^4] < ∞"和假设2.1.2的"密度有界"是Lindeberg替换的技术前提，去掉后结论是否仍成立？
2. **k_0 随维度增长的情形**：定理2.1要求 k_0 固定（由根的重数决定），但若根的重数随 n 增长（例如高维VAR中多个根接近单位圆），k_0 可能发散。此时有限维随机矩阵近似是否失效？**扎根**：定理2.1的陈述中"k_0 ∈ N^+ is a finite integer"（第2页），但未讨论 k_0 → ∞ 的极限。
3. **相变现象的刻画**：当根从单位圆内（平稳）趋近单位圆（非平稳）时，谱分布如何从非退化（Marchenko-Pastur）过渡到退化（点质量）？是否存在临界速率？**扎根**：定理2.2表明非平稳时ESD退化，但未讨论"接近非平稳"（根 = 1 - n^{-α}）时的过渡行为。
