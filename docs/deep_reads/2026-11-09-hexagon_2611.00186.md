### 一、领域脉络与小综述

- **这个方向是什么**：本文属于 cluster algebras（丛代数）的纯组合/代数分支。核心问题是：给定一个初始 seed（簇 + 交换矩阵），对某个目标簇变量，其 denominator vector（分母向量，即 Laurent 展开中各项负指数的极小值向量）如何随初始 seed 的 mutation（变异）而变换？Reading 和 Stella 提出了一组"source–sink recursions"（源–汇递归），试图用初始 seed 的交换矩阵和当前 denominator vector 直接给出 mutation 后的新向量，从而绕开逐项计算 Laurent 展开的困难。该方向处于"猜想驱动、反例修正"的成熟度阶段——已有若干正结果（秩二、有限型、部分曲面），但一般情形的正确递归形式仍是开放问题。

- **发展脉络（history）**：
  - **奠基工作**：Fomin–Zelevinsky（2002, [3]）引入 cluster algebras，证明 Laurent phenomenon（[3, Theorem 3.1]），由此定义 denominator vector。随后（2003, [4]）在有限型情形将 denominator vector 与正根的 simple-root 坐标等同（[4, Theorem 1.9]）。
  - **主要进展**：Ceballos–Pilaud（2015, [1]）用 compatibility degrees（几乎正根对之间的整数）描述有限型中任意初始簇下的 denominator vector（[1, Corollary 3.2]）。Fomin–Shapiro–Thurston（2008, [2]）对曲面 cluster algebra，将坐标解释为 tagged arcs 的交点数（[2, Theorem 8.6]）。Reading–Stella（2018, [7]）观察到 denominator coordinate 等于原 Laurent 展开中旧变量的最高指数（[7, Proposition 2.5]），并证明初始 seed 递归、最高指数公式、denominator 矩阵对偶三者等价（[7, Theorem 2.1]），且在秩二、有限型、以及边界标记点不超过两个的环面上成立（[7, Theorems 2.2–2.4]）。
  - **当前 frontier**：Reading–Stella 将递归推广到 source–sink mutation（[7, Conjectures 2.7, 2.8]），并声称对所有 marked surfaces 成立（[7, Theorem 2.11]）。Rupel–Stella（2020, [8]）用 reflection functors 在初始交换矩阵无圈时证明了递归（[8, Corollary 10]）。本文（Tang, 2026）构造反例，证明该递归对一族无限的四顶点交换矩阵失效。
  - **本文位置**：直接反驳 [7] 的核心猜想和定理，属于"反例修正"型贡献。

- **子线索聚类**：
  1. **有限型与 compatibility degree**（[1], [4]）：用根系理论完全刻画 denominator vector，但仅适用于有限型。
  2. **曲面与 intersection number**（[2], [7], [9]）：用 tagged arcs 的几何交点数计算坐标，适用于 marked surfaces，但 [7] 的递归在边界标记点较多时出错（本文指出）。
  3. **范畴化与 reflection functor**（[8]）：用 2-Calabi–Yau 范畴的维数向量证明无圈情形的递归，但依赖无圈性。
  4. **反例构造与递归失效条件**（本文）：通过四顶点交换矩阵的显式计算，展示 source–sink 递归在非无圈、带环（loop）情形下的系统性偏差。

- **这个方向在追问的核心问题**：
  1. 给定初始 seed 和目标簇变量，denominator vector 能否仅由交换矩阵和当前向量经简单递归算出？（[7, Conjectures 2.7, 2.8]）
  2. 递归的适用边界是什么？哪些交换矩阵/曲面构型下成立，哪些不成立？（本文给出部分答案）
  3. 当递归失效时，能否找到修正项（如 loop correction）？（[7] 曾尝试，但本文显示修正不充分）
  4. denominator vector 与 F-polynomial 的 degree 是否一致？（[5, Conjecture 7.5] 已被 Fu–Keller [6] 反驳，本文的构造与之相关）

- **⚠️ 作者的 framing（必须明确标注成"这是作者的说法"）**：作者将缺口 frame 成"Reading–Stella 的 source–sink 递归对四顶点交换矩阵（含环）失效，且曲面实现反驳了 Theorem 2.11"。他通过构造一族无限的反例，将 [7] 的猜想从"普遍成立"降级为"仅在某些子类成立"。**竞争路线被他淡化或回避的**：他没有讨论 Rupel–Stella [8] 的无圈情形是否仍然成立（他的反例矩阵 B_m 含环，非无圈），也没有提出替代递归或修正公式。**什么明显该被引 / 该存在、却没出现在 intro 里**：他没有引用 [5, Conjecture 7.17] 的原始表述（只在脚注提及 Fu–Keller 的反例），也没有讨论 denominator vector 与 g-vector 的关系（后者在 cluster algebra 中更常用）。**值得研究者去查的问题**：B_m 是否属于某个更大的矩阵类（如含环的 skew-symmetric 矩阵）？[7] 的递归在无圈但含多环的情形是否也失效？

- **张力**：未见明显对立引用。但存在一个微妙张力：Rupel–Stella [8] 的无圈结果与本文的反例并不矛盾（B_m 非无圈），但 [7, Theorem 2.11] 声称对所有 marked surfaces 成立，而本文的曲面实现（环面，一边 1 个标记点、另一边 3 个）直接反驳了它。这说明 [7] 的曲面分类不完整——值得查证 [7] 的证明中哪一步假设了"每个三角形三边不同"或"无环"。


### 二、最核心、最简单的例子 / 数学问题

**第一步：把符号、模型、可观测数据交代清楚**

- **符号**：
  - \(n\)：seed 中变量的个数（本文取 \(n=4\)）。
  - \(\mathbf{x} = (x_1, x_2, x_3, x_4)\)：初始簇（cluster），一组超越基，生成有理函数域 \(\mathbb{Q}(x_1,\dots,x_4)\)。
  - \(B = (b_{ij})\)：\(n\times n\) 交换矩阵（exchange matrix），skew-symmetrizable（存在正权重 \(s_i\) 使 \(s_i b_{ij} = -s_j b_{ji}\)）。本文的 \(B_m\) 是 skew-symmetric（即 \(s_i=1\)）。
  - \(\mu_k\)：在顶点 \(k\) 处的 mutation（变异），将 \(x_k\) 替换为新变量 \(x'_k\)，并按公式 (1) 更新 \(B\)。
  - \(X\)：目标簇变量（本文取 \(X_m\)，由 mutation 序列 \(3,2,1\) 产生）。
  - \(\mathbf{d} = (d_1,\dots,d_n)^T\)：\(X\) 关于初始簇 \(\mathbf{x}\) 的 denominator vector，即 \(d_i = -\min\{\text{Laurent 展开中 } x_i \text{ 的指数}\}\)。
  - \([a]_+ = \max(a,0)\)：正部。
  - source–sink 条件：交换矩阵第 \(k\) 行元素全非负（source）或全非正（sink）。本文中顶点 4 是 source（行 \((0,0,m,0)\) 非负）。

- **模型**：cluster algebra 的 seed 模型。数据生成机制是：给定初始 seed \((\mathbf{x}, B)\)，通过 mutation 序列生成所有簇变量。可观测数据是：初始交换矩阵 \(B_m\)、mutation 序列、以及目标变量 \(X_m\) 的 Laurent 展开（通过公式 (2) 迭代计算）。要估计/计算的量是：\(X_m\) 的 denominator vector \(\mathbf{d}\)，以及它在初始 seed 被 mutation（在顶点 4）后的变化 \(\mathbf{d}'\)。

- **可观测 vs 潜在**：这里没有统计意义上的潜在变量。但有一个"可观测 vs 想要但观测不到"的区分：研究者可以直接计算 Laurent 展开（可观测，但计算量大），而想要的是通过递归公式直接读出 denominator vector（快速但可能错误）。本文的核心是展示递归公式给出的预测值与真实计算值之间的偏差。

**第二步：讲最小内核**

- **最简特例**：取 \(m=1\)，即交换矩阵
  \[
  B_1 = \begin{pmatrix}
  0 & 2 & -1 & 0 \\
  -2 & 0 & 1 & 0 \\
  1 & -1 & 0 & -1 \\
  0 & 0 & 1 & 0
  \end{pmatrix}.
  \]
  这个矩阵的图结构是：顶点 1,2,3 构成一个三角形（1→2 权重 2，2→3 权重 1，3→1 权重 1），顶点 4 通过一条边指向 3（4→3 权重 1）。注意顶点 3 有一个自环（loop）——在 cluster algebra 中，自环对应曲面上的 tagged arc 两端重合。

- **核心命题**：考虑 mutation 序列 \(3,2,1\)（先变 3，再变 2，最后变 1），得到目标变量 \(X_m\)。直接计算（通过公式 (2) 迭代）得到 \(X_m\) 关于初始簇的 denominator vector 为 \((1,1,1,0)^T\)。现在，在初始 seed 上对顶点 4 做 mutation（因为顶点 4 是 source，行 \((0,0,m,0)\) 非负），得到新初始簇。\(X_m\) 关于新初始簇的 denominator vector 为 \((1,1,1,2m)^T\)。

- **递归的预测 vs 实际**：Reading–Stella 的 Conjecture 2.7（公式 (3)）预测：当在 source 顶点 4 做 mutation 时，\(d'_4 = -d_4 + [\sum_j |b_{4j}| d_j]_+ = -0 + [m \cdot 1]_+ = m\)。Conjecture 2.8（公式 (4)）预测：\(d'_4 = -d_4 + \sum_j |b_{4j}| [d_j]_+ = 0 + m \cdot 1 = m\)。但实际值是 \(d'_4 = 2m\)。偏差为 \(m\)，恰好是自环的权重。

- **为什么成立**：关键观察是，顶点 3 的自环导致 mutation 序列 \(3,2,1\) 产生的变量 \(X_m\) 的 Laurent 展开中，\(x_4\) 的负指数不是简单的 \(m\) 倍，而是 \(2m\) 倍。这是因为自环在 mutation 中会"加倍"某些指数。具体地，在公式 (2) 中，\(x_3 u = x_1 + x_2 x_4^m\)，而 \(x_4\) 的指数 \(m\) 在后续 mutation 中会被自环效应放大。Reading–Stella 的递归假设了"无自环"或"自环可忽略"，但这里自环的贡献是 \(m\) 而非 0。

- **最小内核一句话**：本文证明，当交换矩阵含自环时，source–sink 递归的预测值（\(m\)）与实际值（\(2m\)）相差一个自环权重，因此递归失效；这个反例可以通过一个带 1+3 标记点的环面实现，从而也反驳了 [7, Theorem 2.11] 的曲面版本。

### 三、这篇论文做了什么

**三句话**：
1. 研究了 Reading–Stella 关于 denominator vector 的 source–sink 递归猜想（Conjectures 2.7, 2.8）是否对一般交换矩阵成立。
2. 核心方法是构造一族四顶点 skew-symmetric 交换矩阵 \(B_m\)（\(m\ge 1\)），通过显式计算 mutation 序列 \(3,2,1\) 产生的变量 \(X_m\) 的 Laurent 展开，直接验证递归公式。
3. 主要结论是：递归对 \(B_m\) 失效（预测 \(m\)，实际 \(2m\)），且 \(m=1\) 的成员可由带 1+3 标记点的环面实现，从而反驳了 [7, Theorem 2.11]。

**关键设定与假设**：
- **设定**：\(n=4\)，初始 seed 的交换矩阵 \(B_m\) 如公式 (5)。mutation 序列固定为 \(3,2,1\)（按时间顺序）。目标变量 \(X_m\) 是该序列的最终产物。
- **假设**：无系数（coefficient-free）cluster algebra；交换矩阵 skew-symmetric（因此 skew-symmetrizable，权重 \(s_i=1\)）；mutation 按公式 (1)–(2) 标准定义。
- **相比已有工作的放宽/强化**：相比 [7] 的曲面设定（要求无自环或边界标记点少），本文允许自环（loop），这是关键放宽。相比 [8] 的无圈设定，本文的 \(B_m\) 含圈（三角形 1-2-3 加自环 3），因此 [8] 的 reflection functor 方法不适用。

**主要结果**：
- **Theorem 1**：对每个 \(m\ge 1\)，\(X_m\) 关于初始簇的 denominator vector 是 \((1,1,1,0)^T\)；关于在顶点 4 mutation 后的新初始簇，denominator vector 是 \((1,1,1,2m)^T\)。因此 Conjectures 2.7 和 2.8 的预测值 \(m\) 与实际值 \(2m\) 不符，递归失效。
- **Proposition 2**：\(m=1\) 时，\(B_1\) 是带 1+3 标记点的无孔环面的 signed adjacency matrix。因此 [7, Theorem 2.11]（声称对所有 marked surfaces 成立）被反驳。
- **证明路线**：
  1. **计算 mutation 后的矩阵**：先对 \(B_m\) 做 mutation \(\mu_3\)，再 \(\mu_2\)，最后 \(\mu_1\)，得到中间矩阵。关键是用公式 (1) 逐项更新。
  2. **计算 Laurent 展开**：用公式 (2) 迭代，得到 \(X_m\) 的显式表达式。作者给出 \(X_m = \frac{x_1 x_2 x_4^{2m} + (x_1^2 + x_2^2 + x_3) x_4^m + x_1 x_2}{x_1 x_2 x_3}\)（公式 (6) 的整理形式）。这个表达式直接读出 denominator vector \((1,1,1,0)^T\)。
  3. **初始 mutation 后的展开**：在顶点 4 做 mutation，\(x_4 = (1 + x_3^m)/z\)，代入公式 (6) 得到公式 (7)。分子中 \(z\) 的最高负指数是 \(2m\)（来自 \(x_4^{2m}\) 项），因此新 denominator vector 的第四分量是 \(2m\)。
  4. **对比递归预测**：用公式 (3) 和 (4) 计算预测值，均为 \(m\)，与实际值 \(2m\) 不符。
- **技术技巧**：
  - **显式构造**：不依赖抽象理论，直接写出矩阵和 mutation 序列，用初等代数验证。
  - **自环的指数放大**：关键技巧是识别自环在 mutation 中的效应——自环导致 \(x_4\) 的指数从 \(m\) 变为 \(2m\)，这是递归失效的根源。
  - **曲面实现**：用带标记点的环面构造，将代数反例翻译为几何反例，从而反驳 [7] 的曲面定理。这里用了 Fomin–Shapiro–Thurston [2] 的曲面 cluster algebra 对应。

**真实例子与应用**：
- **模拟/数据**：无（纯理论）。
- **真实例子**：\(m=1\) 的环面例子是核心。作者详细描述了如何将四个三角形粘成环面：三角形 (1,2,a)、(1,2,3)、(4,3,b)、(4,c,d)，其中 a 是边界圆，b,c,d 是另一边界的分段。这个构造验证了 \(B_1\) 确实是该环面的 signed adjacency matrix。
- **例子想说明什么**：这个例子说明，即使在一个"看起来简单"的曲面（环面，4 个标记点）上，[7] 的递归也会失效。它比 Fu–Keller [6] 的三顶点例子更"几何自然"，因为它是曲面实现的。

**🔎 结论是否比证明窄**：
- 作者在 Theorem 1 中只证明了 \(B_m\) 这一族矩阵的失效，没有给出失效的一般条件。他在 Proposition 2 中只处理了 \(m=1\) 的曲面实现，没有讨论 \(m>1\) 是否也能曲面实现（可能不能，因为 \(B_m\) 的权重 \(m\) 可能不对应标准曲面）。
- 作者在引言中提到 Fu–Keller [6] 的三顶点例子，但没有说明自己的例子与 [6] 的关系（是推广、独立、还是不同机制）。这是一个值得追问的点。
- 作者没有讨论 [7] 的递归是否在"无自环但含多圈"的矩阵上成立，也没有提出修正公式。因此，结论的适用范围比证明的窄——他只证明了"存在反例"，没有刻画"何时成立"。

### 四、开放问题

1. **失效条件的刻画**：本文只给出了一族反例。要确认"source–sink 递归在哪些交换矩阵上成立"，需要更系统的分类。扎根于 Theorem 1 的证明——自环是失效的关键，但自环是否唯一原因？无自环但含多圈（如两个三角形共享一条边）的矩阵是否也失效？建议去读 [7] 的证明，找出哪一步假设了"无自环"。

2. **修正公式的存在性**：本文显示预测值 \(m\) 与实际值 \(2m\) 相差一个自环权重。是否存在一个修正项（如加上自环贡献）使递归恢复？扎根于公式 (7) 的分子结构——\(z\) 的指数 \(2m\) 来自 \(x_4^{2m}\) 项，而 \(x_4^{2m}\) 来自公式 (6) 中 \(x_4^{2m}\) 的系数。这个系数是否可以用交换矩阵的某种组合不变量（如圈数）表达？

3. **曲面版本的边界**：[7, Theorem 2.11] 被 \(m=1\) 的环面例子反驳，但 [7] 的其他曲面结果（如 [7, Theorems 2.2–2.4]）是否仍然成立？特别是，[7] 声称的"边界标记点不超过两个"的环面情形是否安全？扎根于 Proposition 2 的构造——它用了 1+3 标记点，恰好超出 [7] 的覆盖范围。建议去读 [7] 的 Theorem 2.11 证明，看它是否在"每边标记点 ≤2"时成立。

4. **与 Fu–Keller 例子的关系**：Fu–Keller [6] 的三顶点例子反驳了 F-polynomial 的 degree 与 denominator vector 的等同。本文的四顶点例子是否与 [6] 有共同机制？扎根于引言最后一段——作者提到 [6] 但没有展开。建议去读 [6, Example 6.7]，比较两个例子的交换矩阵结构。

5. **对 cluster algebra 理论的更广影响**：denominator vector 的递归失效是否影响其他依赖它的结果（如 g-vector 的符号模式、cluster 变量间的线性关系）？扎根于 [5, Section 7] 的讨论——Fomin–Zelevinsky 曾指出初始 seed 递归的困难。建议去查 [5] 的 Remark 7.7 之后的内容，看是否有已知的替代方法。

**提醒**：要确认上述哪条是真正的 gap，建议去读 [7] 的完整证明和 [6] 的 Example 6.7，以及近 5 年关于 denominator vector 的文献（如 arXiv 上引用 [7] 的文章）。如果多篇近期论文都指向"递归仅在无自环时成立"，那就是共识；如果互相矛盾，那就是机会。
