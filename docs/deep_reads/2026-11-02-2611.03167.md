### 一、领域脉络与小综述

#### 这个方向是什么

本文研究的根本问题是：**当因果推断中的关键变量（混杂因子与中介变量）无法被直接观测，而只能通过高维、含噪的代理变量（surrogates）间接测量时，如何识别和估计自然直接效应（NDE）与自然间接效应（NIE）？** 这是一个典型的"测量误差 + 因果推断"交叉问题，其核心困难在于：代理变量的维度远高于样本量（p, q ≫ n），但潜在因子的维度是固定的低维（p̄, q̄ 固定）。该方向当前处于快速发展期——因子模型（factor model）与因果推断的结合是近年来的热点，但大多数现有工作要么假设混杂因子可直接观测，要么只处理单一潜在变量（如潜在中介），对"混杂因子与中介因子同时潜在"这一更贴近实际的设定研究较少。

#### 发展脉络

- **奠基工作：经典中介分析与因子模型**。作者在引言中明确将 Baron and Kenny (1986) 的乘积系数法、Rubin (1974) 的潜在结果框架、Robins and Greenland (1992) 与 Pearl (2022) 的自然效应定义作为因果中介分析的理论基石。同时，因子模型的基础来自 Bai (2003) 与 Fan et al. (2013) 的"pervasive factor"假设——即因子载荷矩阵的奇异值随维度线性增长，这一假设是本文识别策略的数学前提。
- **主要进展：高维中介分析与代理变量方法**。引言指出，现有高维中介分析（如 Zhang et al., 2016; Huang and Pan, 2016; Chén et al., 2018; Guo et al., 2022, 2023, 2024; Rakshit and Guo, 2024; Bo et al., 2024）主要处理"中介变量可观测但数量巨大"的情形，通过稀疏性假设进行变量选择。而代理变量方法（如 Ghassami et al., 2025 的 hidden mediator 方法）虽然允许中介潜在，但通常要求混杂因子可直接观测或通过额外假设消除。
- **当前 frontier：潜在因子 + 因果中介的融合**。作者将本文定位为"第一个同时处理潜在混杂因子与潜在中介因子"的工作。引言特别强调，与 Zhang et al. (2026a) 的 PRIME 方法相比，本文的差异在于：(1) PRIME 中的高维变量是可观测的暴露与中介，而本文的 X 和 M 是潜在因子的代理；(2) PRIME 研究高维暴露的组间效应，而本文聚焦于二元处理下的总体 NDE/NIE；(3) PRIME 依赖稀疏性假设，本文不要求稀疏性。
- **本文的位置**：作者声称本文是"首个"在潜在因子模型下建立 NDE/NIE 近似识别、√n 一致估计与渐近正态性的工作。这一"首个"的定位基于引言中的文献梳理——现有工作要么假设因子可观测，要么只处理单一潜在变量，要么不提供推断理论。

#### 子线索聚类

1. **因果中介分析的识别与推断**（Baron and Kenny, 1986; Imai et al., 2010; VanderWeele and Vansteelandt, 2014; Tchetgen Tchetgen and Shpitser, 2012）：这条线索关注在何种假设下 NDE/NIE 可由观测数据识别，以及如何构造半参数有效估计量。本文继承了其潜在结果框架，但将识别对象从"可观测中介"推广到"潜在中介"。
2. **高维中介分析与变量选择**（Zhang et al., 2016; Huang and Pan, 2016; Chén et al., 2018; Guo et al., 2022, 2023, 2024; Rakshit and Guo, 2024; Bo et al., 2024）：这条线索处理"中介数量巨大"的问题，通常依赖稀疏性假设。本文的贡献在于用因子结构替代稀疏性，从而允许"每个中介都贡献微小信号"的情形。
3. **因子模型与高维协方差估计**（Bai, 2003; Fan et al., 2013; Fan and Liao, 2022）：这条线索提供了从高维观测中恢复低维潜在因子的工具。本文的识别策略直接建立在其"pervasive factor"假设之上——即因子载荷的奇异值随维度线性增长，使得投影方向能够一致估计。
4. **代理变量与隐藏变量因果推断**（Ghassami et al., 2025; Albert et al., 2016）：这条线索处理"关键变量不可观测"的问题。本文的独特之处在于同时处理混杂因子与中介因子的潜在性，而现有工作通常只处理其中之一。

#### 这个方向在追问的核心问题

1. **识别问题**：当混杂因子和中介因子都潜在时，NDE/NIE 是否可识别？本文的回答是"近似识别"——即存在一个随代理维度增长而消失的偏差项，而非精确识别。这一偏差项来源于因子估计误差与投影方向的不确定性。
2. **估计问题**：如何构造 √n 一致的估计量？本文的答案是交叉拟合（cross-fitting）加两阶段回归：第一阶段用主成分估计因子，第二阶段用投影后的因子做回归。关键的技术难点在于控制投影方向估计误差对回归系数的影响。
3. **推断问题**：如何构造有效的置信区间？本文证明了渐近正态性并给出了方差估计量，但方差估计需要处理投影方向估计带来的额外变异性。作者在附录 C.3 中给出了详细的证明。
4. **维度条件**：代理维度 p, q 需要以多快的速度增长才能保证 √n 一致性？本文的假设 5.2(ii) 要求 (p ∧ q)/n → ∞，这是一个相当强的条件——意味着代理维度必须远大于样本量。作者在结论中承认，将这一条件放宽到比例 regime（p/n → c）是未来工作。

#### ⚠️ 作者的 framing（这是作者的说法）

作者将本文的核心贡献框定为"**在潜在因子模型下，高维代理变量可以实现对因果中介效应的近似识别与 √n 推断**"。具体而言，作者声称：(1) 当代理维度趋于无穷时，观测数据函数 θ₀,ₚ,ₚ 逼近潜在目标 θ₀，偏差以 O(1/p + 1/q) 的速度消失（定理 3.1）；(2) 交叉拟合估计量 √n 一致且渐近正态（定理 5.2）；(3) 方差估计量一致（引理 5.1）。作者在引言中强调，这一结果"首次"将因子模型与因果中介分析结合，并特别指出与 Zhang et al. (2026a) 的 PRIME 方法在目标、假设和推断框架上的本质差异（见附录 E.1 的对比表）。

**值得注意的淡化**：作者在引言和结论中淡化了两个潜在局限。其一，**近似识别而非精确识别**——这意味着当代理维度有限时，估计量存在系统性偏差，而作者没有给出偏差的显式界（只给出了渐近阶）；其二，**维度条件 (p ∧ q)/n → ∞ 的强假设**——作者在结论中承认这是"未来工作"，但没有讨论在更现实的维度条件下方法是否仍然可用。此外，作者对"pervasive factor"假设的依赖（假设 3.2(ii)）意味着每个因子必须在几乎所有代理变量上都有非零载荷，这在某些应用中可能过于严格。

#### 张力

- **识别与偏差的张力**：作者证明了近似识别（偏差随维度消失），但这一结果依赖于"因子载荷奇异值随维度线性增长"的假设。如果因子是"弱因子"（即奇异值增长慢于线性），偏差可能不会消失。作者没有讨论弱因子情形下的识别问题。
- **维度条件与实用性的张力**：假设 5.2(ii) 要求 (p ∧ q)/n → ∞，这意味着代理维度必须远大于样本量。在基因组学应用中（如 ADNI 数据），这通常成立（p ≈ 3206, n ≈ 649），但在许多社会科学应用中，代理维度可能只有几十个，此时本文的理论结果不适用。
- **与 PRIME 的竞争叙事**：作者在附录 E.1 中详细对比了本文与 Zhang et al. (2026a) 的差异，强调本文不依赖稀疏性、处理二元处理、聚焦总体效应。但这种对比也暗示了两种方法适用于不同场景——PRIME 适合"高维可观测暴露"的问题，而本文适合"低维潜在因子"的问题。作者没有讨论哪种设定在实际应用中更常见。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型与可观测数据

**潜在变量（Latent variables）**：
- f_X ∈ ℝ^p̄：潜在混杂因子（pre-treatment covariates），p̄ 固定且远小于 p。
- f_M ∈ ℝ^q̄：潜在中介因子（mediator），q̄ 固定且远小于 q。
- A ∈ {0, 1}：二元处理变量。
- Y ∈ ℝ：连续结果变量。

**可观测变量（Observed variables）**：
- X ∈ ℝ^p：f_X 的高维含噪代理（surrogates），满足 X = Γ_X f_X + u_X。
- M ∈ ℝ^q：f_M 的高维含噪代理，满足 M = Γ_M f_M + u_M。
- 其中 Γ_X ∈ ℝ^{p×p̄}, Γ_M ∈ ℝ^{q×q̄} 是载荷矩阵，u_X, u_M 是 idiosyncratic 噪声。

**结构方程（Structural equations）**：
```
f_M = (1-A)(δ_0 + B_0 f_X + u_XM,0) + A(δ_1 + B_1 f_X + u_XM,1)
Y   = (1-A)(α_0 + β_0^T f_X + γ_0^T f_M + ε_0) + A(α_1 + β_1^T f_X + γ_1^T f_M + ε_1)
```
其中 δ_0, δ_1 ∈ ℝ^q̄ 是截距，B_0, B_1 ∈ ℝ^{q̄×p̄} 是 f_X 对 f_M 的效应矩阵，α_0, α_1 ∈ ℝ 是截距，β_0, β_1 ∈ ℝ^p̄ 是 f_X 对 Y 的直接效应系数，γ_0, γ_1 ∈ ℝ^q̄ 是 f_M 对 Y 的效应系数。u_XM,0, u_XM,1 是中介方程的结构噪声，ε_0, ε_1 是结果方程的噪声。

**因果目标（Causal estimand）**：
```
θ₀ = E[Y(1, f_M(0))] = α_1 + γ_1^T δ_0
```
这是"在控制条件下（A=0）的中介因子取值下，处理组（A=1）的平均潜在结果"。由此可得：
- NDE = θ₁₀ - θ₀₀ = α₁ - α₀ + (γ₁ - γ₀)^T δ₀
- NIE = θ₁₁ - θ₁₀ = γ₁^T (δ₁ - δ₀)
- 总效应 = NDE + NIE

**关键假设**：
1. **序贯可忽略性（Sequential ignorability）**：给定 f_X，处理 A 与潜在结果独立；给定 f_X 和 A，中介 f_M 与潜在结果独立。
2. **因子可识别性**：载荷矩阵 Γ_X, Γ_M 满足"pervasive factor"假设（假设 3.2(ii)），即最小奇异值 σ_min(Γ_X) ≥ c√p, σ_min(Γ_M) ≥ c√q。
3. **噪声条件**：u_X, u_M 的协方差矩阵有界，且与 f_X, f_M, A 独立。
4. **维度条件**：log(p ∨ q)/n → 0 且 (p ∧ q)/n → ∞（假设 5.2(ii)）。

#### 第二步：最小内核

**核心困难**：我们无法直接观测 f_X 和 f_M，只能观测到 X 和 M。如果直接用 X 和 M 做回归，会得到什么？

**朴素回归（Naive Regression）**：
假设我们忽略因子结构，直接用代理变量做回归：
- 第一步：在 A=1 的样本中，回归 Y 对 (1, X, M)，得到系数 (â₁, b̂₁, ĉ₁)。
- 第二步：在 A=0 的样本中，回归 M 对 (1, X)，得到截距 d̂₀。
- 估计 θ̂₀ = â₁ + ĉ₁^T d̂₀。

**问题**：由于 X = Γ_X f_X + u_X 包含噪声 u_X，而 M = Γ_M f_M + u_M 包含噪声 u_M，这些噪声会通过以下渠道污染估计：
1. **测量误差偏差**：X 中的噪声 u_X 与 f_X 不相关，但与 X 自身相关，导致回归系数 b̂₁ 有偏（衰减偏差）。
2. **中介噪声泄漏**：M 中的噪声 u_M 与 f_M 不相关，但 u_M 可能与 Y 的噪声 ε 相关（如果 u_M 与 ε 相关），导致 ĉ₁ 有偏。
3. **维度灾难**：p, q 远大于 n，直接回归不可行（设计矩阵奇异）。

**因子投影（Factor Projection）**：
作者的核心思想是：**用主成分分析（PCA）从 X 和 M 中提取低维因子，然后用投影后的因子做回归**。

具体来说：
1. **因子估计**：在训练集上，对 X 的样本协方差矩阵做特征分解，取前 p̄ 个主成分方向 V̂_X ∈ ℝ^{p×p̄}，定义投影算子 W_X = √p V̂_X。类似地，对 M 取前 q̄ 个主成分方向 V̂_M ∈ ℝ^{q×q̄}，定义 W_M = √q V̂_M。
2. **投影变量**：对每个样本 i，计算投影后的变量：
   - f̂_X,i = (1/p) W_X^T X_i = (1/√p) V̂_X^T X_i
   - f̂_M,i = (1/q) W_M^T M_i = (1/√q) V̂_M^T M_i
3. **两阶段回归**：
   - 第一阶段（处理组）：回归 Y 对 (1, f̂_X, f̂_M)，得到 (â₁, b̂₁, ĉ₁)。
   - 第二阶段（对照组）：回归 f̂_M 对 (1, f̂_X)，得到截距 d̂₀。
   - 估计 θ̂₀ = â₁ + ĉ₁^T d̂₀。

**为什么有效？**

**关键引理（不变性）**：由于 H_X = (1/p) W_X^T Γ_X 和 H_M = (1/q) W_M^T Γ_M 是"广义逆"矩阵（满足 H_X^† H_X = I_{p̄} 等），投影后的变量满足：
- f̂_X = H_X f_X + e_X，其中 e_X = (1/p) W_X^T u_X 是投影噪声。
- f̂_M = H_M f_M + e_M，其中 e_M = (1/q) W_M^T u_M 是投影噪声。

**关键性质**：
1. **投影噪声的方差**：由于 W_X 的列是标准正交的，且 u_X 的协方差矩阵有界，投影噪声 e_X 的协方差为 O(1/p)（即随代理维度增加而消失）。
2. **回归系数的收敛性**：在假设 5.2(ii) 下（(p ∧ q)/n → ∞），投影噪声对回归系数的影响是 o_p(n^{-1/2})，因此两阶段回归的估计量达到 √n 一致性。
3. **偏差的消失**：定理 3.1 表明，θ₀,ₚ,ₚ 与 θ₀ 的偏差以 O(1/p + 1/q) 的速度消失，因此当 p, q → ∞ 时，近似识别变为精确识别。

**最小内核的数学表述**：

**定理 3.1（近似识别）**：在假设 3.1-3.2 下，
|θ₀ - θ₀,ₚ,ₚ| ≤ C(1/p + 1/q)，

其中 C 是一个不依赖于 p, q 的常数。这意味着：**代理维度越大，观测数据函数越接近潜在目标**。

**定理 5.2（渐近正态性）**：在假设 3.1-3.2 和 5.1-5.2 下，
√n(θ̂₀ - θ₀) → N(0, σ²)，

其中 σ² 由影响函数给出。这意味着：**交叉拟合估计量达到 √n 一致性，且方差可以一致估计**。

**为什么交叉拟合？**

交叉拟合（cross-fitting）是本文方法的关键技术细节。在第一步中，投影方向 W_X, W_M 是在训练集上估计的；在第二步中，回归系数是在验证集上估计的。这种"样本分割"避免了投影方向估计误差与回归系数估计误差之间的相关性，从而简化了渐近分析。如果不做交叉拟合，投影方向的估计误差会通过设计矩阵进入回归系数的渐近方差，导致方差估计变得复杂。

**这个最小内核揭示了什么？**

本文的核心贡献在于：**在因子模型假设下，高维代理变量不仅不会阻碍因果推断，反而通过"因子投影"这一操作，将高维问题转化为低维问题，同时保持了 √n 的收敛速度**。这一结果的关键在于"pervasive factor"假设——它保证了投影方向能够一致估计，且投影噪声的方差随维度增加而消失。如果这一假设不成立（例如因子是稀疏的），则投影噪声可能不会消失，近似识别的偏差也不会趋于零。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：当混杂因子 f_X 和中介因子 f_M 都不可直接观测，只能通过高维含噪代理 X 和 M 观测时，如何识别和估计自然直接效应（NDE）与自然间接效应（NIE）。
2. **核心方法**：提出因子调整回归（FARMA）框架——先用主成分分析从 X 和 M 中提取低维因子，再用交叉拟合的两阶段回归估计潜在目标 θ₀ = α₁ + γ₁^T δ₀。
3. **主要结论**：在"pervasive factor"假设和维度条件 (p ∧ q)/n → ∞ 下，FARMA 估计量达到 √n 一致性和渐近正态性，且近似识别偏差以 O(1/p + 1/q) 的速度消失。

#### 关键设定与假设

- **模型**：线性结构方程模型（2.1），允许处理-混杂交互（A × f_X）和处理-中介交互（A × f_M）。
- **因子结构**：X = Γ_X f_X + u_X, M = Γ_M f_M + u_M，其中 p̄, q̄ 固定，p, q 随 n 增长。
- **假设 3.1（采样与误差）**：i.i.d. 样本；误差项均值为零、方差有界；u_X, u_M 与 f_X, f_M, A 独立。
- **假设 3.2（因子可识别性）**：载荷矩阵满足"pervasive factor"假设（σ_min(Γ_X) ≥ c√p 等），且因子协方差矩阵正定。
- **假设 5.1（子高斯性）**：所有随机变量具有子高斯尾。
- **假设 5.2（维度条件）**：log(p ∨ q)/n → 0 且 (p ∧ q)/n → ∞。

**相比已有工作的变化**：
- **放宽**：不要求稀疏性（相比 Zhang et al., 2016 等），不要求因子可直接观测（相比 Ghassami et al., 2025）。
- **强化**：要求"pervasive factor"假设（相比 PRIME 的稀疏因子假设），要求 (p ∧ q)/n → ∞（相比更弱的 log(p)/n → 0）。

#### 主要结果

**定理 3.1（近似识别）**：|θ₀ - θ₀,ₚ,ₚ| ≤ C(1/p + 1/q)。这意味着当代理维度趋于无穷时，观测数据函数逼近潜在目标。证明思路：将 θ₀,ₚ,ₚ 分解为 θ₀ 加上三个余项（分别来自投影方向估计误差、投影噪声、以及高阶项），然后利用"pervasive factor"假设和矩阵扰动界控制这些余项。

**定理 5.2（渐近正态性）**：√n(θ̂₀ - θ₀) → N(0, σ²)。证明思路：将估计误差分解为影响函数之和加上可忽略余项。关键步骤包括：
1. 证明投影方向估计误差对回归系数的影响是 o_p(n^{-1/2})（利用交叉拟合和维度条件）。
2. 证明投影噪声对回归系数的影响是 o_p(n^{-1/2})（利用 (p ∧ q)/n → ∞）。
3. 利用 Lyapunov 中心极限定理得到渐近正态性。

**引理 5.1（方差估计一致性）**：σ̂² → σ²。证明思路：将方差估计量表示为影响函数的经验二阶矩，然后利用一致大数定律和投影方向估计的一致性。

#### 证明路线与技术技巧

**整体路线**：
1. **识别**：先证明潜在目标 θ₀ 可由观测数据函数 θ₀,ₚ,ₚ 近似识别（定理 3.1）。
2. **估计**：构造交叉拟合估计量 θ̂₀，将其分解为影响函数之和加上可忽略余项。
3. **推断**：证明影响函数满足 Lyapunov 条件，得到渐近正态性；构造方差估计量并证明一致性。

**关键技巧**：
1. **交叉拟合**：将样本分为训练集和验证集，投影方向在训练集上估计，回归系数在验证集上估计。这避免了投影方向估计误差与回归系数估计误差之间的相关性，简化了渐近分析。
2. **矩阵扰动界**：利用 Davis-Kahan sin Θ 定理（Yu et al., 2015）控制投影方向估计误差，利用 Woodbury 恒等式（引理 D.2）简化矩阵逆的展开。
3. **影响函数展开**：将估计误差分解为影响函数之和加上可忽略余项，这是半参数理论的经典技巧。作者在附录 C.2 中详细给出了每一步的展开和余项控制。
4. **高阶矩控制**：利用子高斯假设（假设 5.1）控制高阶矩，从而验证 Lyapunov 条件。

#### 真实例子与应用

**ADNI 数据应用**：
- **研究问题**：抑郁症状（A，二元）是否通过 DNA 甲基化（M，高维代理）影响认知功能（Y，ADAS-Cog 评分）？
- **数据**：649 名受试者，X 为 171 维临床协变量（含多项式展开），M 为 3206 个 CpG 位点的甲基化水平。
- **方法应用**：用 PCA 从 X 和 M 中提取因子（p̄ = q̄ = 3），用 FARMA 估计 NDE、NIE 和总效应。
- **结果**：总效应为 3.62（95% CI [1.68, 6.19]），其中直接效应为 3.59（95% CI [1.57, 6.15]），间接效应为 0.04（95% CI [-0.51, 0.49]）。间接效应不显著，表明甲基化介导的路径在统计上不显著。
- **敏感性分析**：改变工作维度 κ = p̃ = q̃ 从 1 到 30，估计结果保持稳定（表 5），表明方法对工作维度的选择不敏感。

**这个例子想说明什么**：
1. FARMA 可以在高维代理设定下进行因果中介分析，且计算简单（只需 PCA 加 OLS）。
2. 方法对工作维度的选择具有鲁棒性，即使过度估计因子维度也不会导致严重偏差。
3. 在 ADNI 数据中，抑郁对认知的影响主要通过直接路径而非甲基化介导的间接路径。

#### 🔎 结论是否比证明窄

**是的，存在几处"证明窄于结论"的地方**：

1. **近似识别的误差界**：定理 3.1 只给出了 |θ₀ - θ₀,ₚ,ₚ| ≤ C(1/p + 1/q) 的渐近阶，但没有给出常数 C 的显式表达式。这意味着在实际应用中，无法判断给定 p, q 时偏差是否足够小。作者在结论中承认这一点，但没有提供偏差的数值估计方法。

2. **维度条件的充分性**：假设 5.2(ii) 要求 (p ∧ q)/n → ∞，这是一个充分条件而非必要条件。作者在结论中承认，这一条件可能可以放宽到 (p ∧ q)/√n → ∞，但没有给出证明。此外，作者没有讨论当 p, q 与 n 同阶（比例 regime）时方法是否仍然有效。

3. **线性模型的限制**：所有理论结果都基于线性结构方程模型（2.1）。作者在结论中承认，推广到非线性模型（如广义线性模型）需要新的技术，但没有给出具体方向。

4. **因子维度的估计**：方法假设 p̄, q̄ 已知或可以通过经验法则选择（如累计方差贡献率），但没有给出 p̄, q̄ 的估计理论。作者在敏感性分析中表明方法对 κ 的选择不敏感，但这只是数值证据，不是理论保证。

5. **方差估计的有限样本性质**：引理 5.1 只证明了方差估计量的一致性，没有给出有限样本偏差的阶。在模拟中，覆盖概率接近 95%，但作者没有给出覆盖概率的理论保证。

### 四、开放问题

1. **偏差的显式界**：定理 3.1 给出了近似识别的渐近阶，但没有给出常数 C 的显式表达式。能否构造一个可计算的偏差上界，使得在实际应用中能够判断给定 p, q 时偏差是否可接受？（扎根于定理 3.1 的陈述）

2. **维度条件的放宽**：假设 5.2(ii) 要求 (p ∧ q)/n → ∞。能否将这一条件放宽到 (p ∧ q)/√n → ∞ 或比例 regime（p/n → c）？在比例 regime 下，投影方向估计误差可能不再可忽略，需要新的技术来处理。（扎根于假设 5.2(ii) 和结论中的"future work"）

3. **非线性模型的推广**：本文的线性结构方程模型（2.1）能否推广到广义线性模型或非参数模型？例如，当 Y 是二元结果时，logistic 回归的渐近理论是否仍然成立？（扎根于结论中的"extending FARMA to generalized linear and other nonlinear outcome and mediator models"）

4. **因子维度的自适应选择**：方法假设 p̄, q̄ 已知或通过经验法则选择。能否构造一个数据驱动的因子维度选择准则（如基于特征值间隙或交叉验证），并证明其最优性？（扎根于敏感性分析中"κ = p̃ = q̃"的选择方式）

5. **弱因子情形**：本文的"pervasive factor"假设要求载荷矩阵的奇异值随维度线性增长。如果因子是"弱因子"（奇异值增长慢于线性），近似识别的偏差是否仍然消失？能否建立弱因子情形下的识别理论？（扎根于假设 3.2(ii) 的"pervasive"条件）

6. **敏感性分析的理论化**：作者在 ADNI 应用中进行了敏感性分析，表明方法对工作维度 κ 的选择不敏感。能否将这一数值观察转化为理论结果，即证明估计量在 κ 偏离真实维度时仍然保持 √n 一致性？（扎根于表 5 的敏感性分析）
