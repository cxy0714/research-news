### 一、领域脉络与小综述

#### 这个方向是什么

本文所处的子方向是**非参数工具变量（NPIV）模型中的假设检验**，具体聚焦于**均值外生性（mean exogeneity）检验**。其根本的统计问题是：在存在内生回归变量 X 的情况下，如何在不估计结构函数 g（及其伴随的病态逆问题）的前提下，检验工具变量 Z 是否足以消除内生性偏误，即检验 E[U|W] = 0 是否成立。该方向的成熟度处于**发展阶段**：NPIV 的估计理论（Newey & Powell 2003; Hall & Horowitz 2005; Darolles et al. 2011）已相当成熟，但**检验理论**，尤其是具有良好水平控制且计算可行的检验，仍是活跃的研究前沿。

#### 发展脉络

- **奠基工作**：**Newey and Powell (2003)** 建立了 NPIV 模型的识别与估计框架，其核心是**完备性条件（completeness）**，这是后续所有检验工作的理论基石。**Hall and Horowitz (2005)** 则揭示了结构函数估计的**病态逆问题**，其收敛速度远慢于普通非参数估计，这直接催生了"避免估计结构函数"的检验思路。
- **主要进展**：检验文献沿两条路线展开。一是**直接检验结构函数**，如 **Horowitz (2006)** 和 **Santos (2012)**，但受制于病态逆问题，功效和稳健性受限。二是**间接检验**，如 **Blundell and Horowitz (2007)** 和 **Fu et al. (2021)** 采用积分矩条件，**Breunig (2015)** 和 **Breunig (2020)** 采用级数方法。本文作者在引言中明确指出，这些方法"要么需要选择谱截断参数，要么需要选择级数长度"，且"其有限样本性质对调参敏感"。
- **当前前沿**：**Breunig and Chen (2024)** 提出了自适应、速率最优的检验，代表了理论最优性的追求。**Antoine and Lavergne (2023)** 将 ICM 思想引入线性 IV 模型，但结构方程仍为线性。本文的定位是：**将 ICM 原理推广到完全非参数的结构函数**，同时通过巧妙的矩条件重构，**完全绕开结构函数的估计**。

#### 子线索聚类

1.  **基于积分矩条件的检验**：以 **Blundell and Horowitz (2007)** 和 **Fu et al. (2021)** 为代表。这类方法构造关于工具变量的积分矩，利用**非奇异积分算子**避免病态逆，但通常需要估计密度或条件分布，且对带宽选择敏感。
2.  **基于级数（sieve）的检验**：以 **Breunig (2015, 2020)** 为代表。这类方法用级数逼近条件矩函数，检验统计量是二次型，但需要选择级数长度这一关键调参量。
3.  **基于 ICM 原理的检验**：以 **Bierens (1982, 1990)** 和 **Stute (1997)** 为方法论源头，**Antoine and Lavergne (2023)** 将其用于线性 IV。本文属于此线索，但首次将其与 NPIV 的完备性条件结合，并处理了非参数估计带来的额外变异性。

#### 这个方向在追问的核心问题

1.  **如何构造一个不依赖病态逆问题的检验统计量？** 这是所有间接检验方法的出发点。本文的答案是：利用完备性条件，将原假设等价地转化为一个只涉及普通回归函数 G 的条件矩限制（Lemma 1）。
2.  **如何控制非参数估计（估计 G 和条件分布 F）对检验统计量极限分布的影响？** 这是技术核心。本文通过 Hoeffding 分解和 U-过程理论，精确刻画了估计效应，并发现其贡献是 n^{-1/2} 阶的（Proposition 1 和 2）。
3.  **如何构造一个计算简单且渐近有效的临界值？** 直接 bootstrap 失效，本文提出"指示变量校正"的乘子 bootstrap，其计算量远小于重估非参数模型的传统 bootstrap。

#### ⚠️ 作者的 framing（这是作者的说法）

作者将缺口 frame 为：现有检验（BH 2007; BS 2015; Fu et al. 2021）要么基于积分变换（需要选择谱截断），要么基于级数（需要选择级数长度），这些调参选择在有限样本下影响显著。作者声称其 ICM 方法"避免了这些选择"，且"计算上更简单"，因为"只需一次非参数估计，bootstrap 只重加权和"。作者还强调其方法在**局部备择假设**下具有 n^{-1/2} 的检测能力，这与参数检验的效率相匹配。

#### 张力

未见明显对立引用。但存在一个**内在张力**：完备性条件（Assumption C）本身是不可检验的，且其强度远超普通 IV 假设。作者在引言中承认完备性是"识别结构函数所必需"，但未讨论当完备性仅近似成立时检验的稳健性。此外，作者在 Remark 2 中构造的例子表明，即使在完备性下，密度估计的校正项也可能不为零，这与直觉相悖，是值得注意的技术细节。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型与可观测数据

- **模型**：Y = g(X, Z₁) + U，其中 E[U|Z] = 0。这里：
  - **Y**：结果变量（可观测）。
  - **X**：潜在内生回归变量（可观测），维度 p。
  - **Z₁**：包含的外生变量（可观测），维度 q₁。
  - **Z₂**：被排除的工具变量（可观测），维度 q₂。
  - **W = (X', Z₁')'**：全部回归变量（可观测），维度 r = p + q₁。
  - **Z = (Z₁', Z₂')'**：全部工具变量（可观测），维度 q = q₁ + q₂。
  - **g(·)**：结构函数（未知，待估计，但本文检验中不需要估计它）。
  - **U**：结构误差（不可观测），满足 E[U|Z] = 0（工具有效性）。
  - **G(W) = E[Y|W]**：普通回归函数（可识别，可用非参数方法估计）。
  - **ε = Y - G(W)**：回归残差（不可直接观测，但可通过估计 G 得到残差）。
- **参数 / 估计目标**：本文的 estimand 不是某个系数，而是一个**假设检验的决策规则**。原假设 H₀: E[U|W] = 0（均值外生性）。在完备性条件下，这等价于 H₀: g(W) = G(W) a.s.，进而等价于 Lemma 1 中的条件矩限制 E[ε·1(Z ≤ z)] = 0 对所有 z ∈ Π 成立。
- **可观测数据**：i.i.d. 样本 {(Yᵢ, Wᵢ, Zᵢ)}ᵢ₌₁ⁿ。研究者能观测到 Y, W, Z，但观测不到 U 和 ε。ε 需要通过非参数回归估计 G 得到残差。**关键点**：检验统计量建立在可观测的 (Y, W, Z) 之上，但通过完备性条件，将不可观测的结构误差 U 的矩条件转化为可观测的回归残差 ε 的矩条件。

#### 第二步：最小内核

**核心命题（Lemma 1 的简化版）**：在工具有效性 E[U|Z]=0 和完备性条件下，以下三个命题等价：
1. H₀: E[U|W] = 0（结构误差对 W 均值独立）。
2. H₀: g(W) = G(W) a.s.（结构函数等于回归函数）。
3. H₀: E[ε·1(Z ≤ z)] = 0 对所有 z ∈ Π（回归残差与工具变量的指示函数不相关）。

**为什么这是最小内核？** 因为命题 3 给出了一个**可直接检验**的矩条件，它只涉及可观测的 Y, W, Z 和可估计的回归函数 G。检验统计量就是经验矩过程：

$$\hat{T}_n(z) = \frac{1}{n} \sum_{i=1}^n \hat{\varepsilon}_i \mathbf{1}(Z_i \le z)$$

其中 $\hat{\varepsilon}_i = Y_i - \hat{G}_i$ 是 leave-one-out 非参数回归残差。

**数学上最难的一点**：$\hat{T}_n(z)$ 不是简单的经验过程，因为 $\hat{\varepsilon}_i$ 依赖于非参数估计 $\hat{G}_i$，而 $\hat{G}_i$ 又依赖于所有其他观测。这导致 $\hat{T}_n(z)$ 的极限分布不能直接由经典 Donsker 定理给出。**本文的核心技术贡献**（Proposition 1 和 2）在于证明：

$$\hat{T}_n(z) = \frac{1}{n} \sum_{i=1}^n \varepsilon_i \left[ \mathbf{1}(Z_i \le z) - \mathbf{1}(Z_{1i} \le z_1) F_{Z_2|W}(z_2 | W_i) \right] + o_p(n^{-1/2})$$

**这个公式的直觉**：非参数估计 $\hat{G}$ 的效应，等价于将原始指示函数 $\mathbf{1}(Z_i \le z)$ 替换为其关于 W 的条件期望的"中心化"版本。这个中心化项 $\mathbf{1}(Z_{1i} \le z_1) F_{Z_2|W}(z_2 | W_i)$ 正是密度估计效应（Proposition 1 中的 $\hat{F}$ 项）和回归估计效应（Proposition 2 中的 $\hat{G}$ 项）经过 Hoeffding 分解后留下的**一阶投影**。它不能被忽略，否则 bootstrap 失效。

**为什么直接 bootstrap 失效**：如果直接用 $\hat{\varepsilon}_i$ 作为乘子，bootstrap 过程的条件协方差会收敛到 $E[\varepsilon^2 \mathbf{1}(Z \le z)\mathbf{1}(Z \le z')]$，而真实过程的协方差是中心化后的 $E[\varepsilon^2 \{\mathbf{1}(Z \le z) - \mathbf{1}(Z_1 \le z_1)F(z_2|W)\}\{\cdots\}]$。两者不等，除非 $F(z_2|W)$ 是常数（即 Z₂ 与 W 独立）。因此，**必须对指示函数进行中心化校正**，这正是本文提出的"指示变量校正"乘子 bootstrap 的核心。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：在 NPIV 模型（Y = g(X, Z₁) + U, E[U|Z]=0）中，如何检验均值外生性假设 H₀: E[U|W] = 0，且检验方法应避免估计结构函数 g 及其病态逆问题。
2. **核心方法**：利用完备性条件，将原假设等价转化为一个只涉及普通回归函数 G 的条件矩限制（Lemma 1），构造基于残差的经验过程 $\hat{T}_n(z)$，并证明其极限分布是高斯过程。
3. **主要结论**：推导了原假设下和 n^{-1/2} 阶 Pitman 局部备择下的极限分布；发现直接乘子 bootstrap 因"非参数估计效应"而失效，提出**指示变量校正**的乘子 bootstrap 并证明其渐近有效性；模拟显示其水平控制良好且功效优于现有方法；应用于 Card (1995) 数据，拒绝教育均值外生性。

#### 关键设定与假设

- **Assumption A1（采样、支撑、矩）**：i.i.d. 观测；W 的支撑是紧矩形，密度有正下界；Z 在 Π 上有全支撑；Y 的条件指数矩有界。这保证了核估计的均匀收敛速度和经验过程的 Donsker 性。
- **Assumption A2（光滑性）**：G、F（条件分布）、f（密度）都属于 L^s_∞ 类（s 阶光滑），且 s > r/2（r = dim W）。这保证了核估计的偏差项可控，且 leave-one-out 估计的余项可忽略。
- **Assumption A3（核与边界校正）**：使用 s 阶局部多项式等价核，在边界处有校正。这保证了核估计在边界处也有足够好的性质，且核的矩条件满足。
- **Assumption A4（带宽条件）**：h → 0，nh^r / ln n → ∞，√n h^s → 0，n² h^{3r} / (ln n)³ → ∞，h^{2-r} √n → 0。这些条件确保了：核估计的偏差可忽略（√n h^s → 0），方差可控（nh^r → ∞），高阶余项可忽略（n² h^{3r} / (ln n)³ → ∞），以及重复指标项可忽略（h^{2-r} √n → 0）。
- **Assumption A5（乘子）**：乘子 Vᵢ 独立于数据，均值为 0，方差为 1，且有 2+δ 阶矩。这是乘子 bootstrap 的标准条件。
- **Assumption C（完备性）**：算子 a(W) ↦ E[a(W)|Z] 是单射。这是 NPIV 识别的核心条件，用于保证原假设的等价转化。

**相比已有文献的放宽/强化**：与 Blundell and Horowitz (2007) 相比，本文**不需要**选择谱截断参数；与 Breunig (2015) 相比，本文**不需要**选择级数长度。但本文的假设 A2 要求 s > r/2，且 A4 要求 h^{2-r} √n → 0，当 r ≥ 3 时需要高阶核（s 足够大），这比 Breunig (2015) 的级数方法对光滑性的要求可能更严格。

#### 主要结果

- **定理 1（原假设下）**：在 H₀ 和 A1–A4 下，$\sqrt{n}\hat{T}_n \Rightarrow \mathcal{G}$ 在 ℓ^∞(Π) 中，其中 $\mathcal{G}$ 是零均值高斯过程，协方差由 (16) 给出。**关键点**：协方差包含中心化指示函数，而非原始指示函数。
- **定理 2（局部备择下）**：在 n^{-1/2} 阶 Pitman 备择下，$\sqrt{n}\hat{T}_n \Rightarrow \mathcal{G} - E[\delta(W)\mathbf{1}(Z \le z)]$。**关键点**：检验能检测 n^{-1/2} 阶的偏离，且功效由高斯过程的移位决定。
- **定理 3（固定备择下）**：在固定备择下，$\sup_z |\hat{T}_n(z) - m(z)| \to_p 0$ 且 $\sqrt{n}\sup_z |\hat{T}_n(z)| \to_p \infty$，其中 $m(z) = E[\varepsilon \mathbf{1}(Z \le z)]$。**关键点**：检验一致性。
- **定理 4（bootstrap 有效性）**：在 H₀ 下，$\sqrt{n}\hat{T}_n^* \Rightarrow_{P^*} \mathcal{G}$，即 bootstrap 过程与原过程有相同的极限分布。**关键点**：指示变量校正是必要的，否则 bootstrap 失效。
- **定理 5（bootstrap 局部备择）**：在局部备择下，bootstrap 过程仍收敛到 $\mathcal{G}$，而原过程有移位，因此检验功效趋向于高斯移位下的概率。
- **定理 6（bootstrap 固定备择）**：在固定备择下，bootstrap 临界值有界，而原统计量发散，因此检验一致性。

#### 证明路线与技术技巧

1. **整体路线**：
   - **Step 1（等价转化）**：用 Lemma 1 将原假设转化为矩条件 E[ε·1(Z ≤ z)] = 0。
   - **Step 2（线性化）**：将 $\hat{T}_n(z)$ 分解为"oracle 过程"（用真实 G 和 F）+ "估计效应"（Ĝ - G 和 F̂ - F 的贡献）。
   - **Step 3（Hoeffding 分解）**：对 oracle 过程进行 Hoeffding 分解，分离出一阶投影（主导项）和高阶项（可忽略）。
   - **Step 4（估计效应分析）**：证明估计效应可以合并为一阶投影的一部分，即中心化指示函数。
   - **Step 5（bootstrap 验证）**：证明乘子 bootstrap 过程与原过程有相同的极限分布。

2. **关键技巧**：
   - **Leave-one-out 估计**：使用 $\hat{G}_i$ 和 $\hat{F}_i$ 避免自影响，简化 Hoeffding 分解。
   - **U-过程理论**：使用 Lemma B.3（VC 型 U-过程界）来控制高阶项和估计效应的余项。
   - **中心化指示函数**：这是本文的核心技巧。通过将 $\mathbf{1}(Z \le z)$ 替换为 $\mathbf{1}(Z \le z) - \mathbf{1}(Z_1 \le z_1)F(z_2|W)$，使得一阶投影的条件均值为零，从而获得 Donsker 性。
   - **条件乘子 CLT**：使用 van der Vaart & Wellner (1996) 的条件乘子 CLT，结合 VC 型类的覆盖数界，证明 bootstrap 过程的条件收敛。

#### 真实例子与应用

- **模拟**：三个设计（线性、非线性、无强条件外生性），样本量 n ∈ {200, 400, 800}，ρ ∈ {0, 0.5, 1, 2}。结果显示：
  - 原假设下，经验拒绝率接近名义水平（0.045–0.058 在 5% 水平），表明水平控制良好。
  - 备择假设下，功效随 n 和 ρ 增加而增加。
  - 与 BH (2007) 和 BS (2015) 相比，本文方法在大多数设计下功效更高，尤其在非线性设计中优势明显。
- **实证**：Card (1995) 数据，n = 3010（nearc4）和 n = 2657（motheduc）。OLS 系数 0.093，2SLS 系数 0.259（nearc4）和 0.157（motheduc）。本文 KS 和 CvM 检验在 1% 水平拒绝均值外生性，p 值均为 0.001 或 0.003。BH 检验 p 值为 0.214 和 0.308，不拒绝。作者认为本文方法更敏感，但**注意**：BH 的设定可能不同（如是否包含协变量），直接比较需谨慎。

#### 🔎 结论是否比证明窄

- **定理 1–3 的证明**：在 A1–A4 下严格成立，结论与证明一致。
- **定理 4–6 的证明**：在 A1–A5 下严格成立，结论与证明一致。
- **潜在窄处**：
  1. **定理 2 的局部备择**：只考虑了 G_n(W) = g(W) + δ(W)/√n 这种特定形式，且要求 δ 有界。更一般的局部备择（如 δ 随 z 变化）未覆盖。
  2. **定理 3 的固定备择**：要求 m(z) 连续且 sup_z |m(z)| > 0。若 m(z) 在某些 z 处为零但在其他处非零，sup 仍为正，结论成立；但若 m(z) 在 Π 上恒为零但 g ≠ G（例如在零测集上不同），则检验可能失效。作者未讨论这种"局部偏离"的情形。
  3. **bootstrap 的适用性**：定理 4–6 要求乘子 Vᵢ 有 2+δ 阶矩，且数据满足 A1–A4。对于重尾数据或非紧支撑，结论可能不成立。
  4. **带宽选择**：作者在模拟中使用了 CV 选择带宽，但定理的证明假设带宽满足 A4 的确定性条件。CV 选择的带宽是否满足这些条件，作者未给出理论证明，仅通过模拟验证。

### 四、开放问题

1. **完备性条件的稳健性**：本文的等价转化（Lemma 1）依赖于完备性条件（Assumption C）。当完备性仅近似成立（例如，条件期望算子接近但非严格单射）时，检验的水平和功效如何变化？作者在 Remark 2 中构造了完备性成立但密度校正项非零的例子，但未讨论完备性轻微违反的情形。**扎根点**：Assumption C 的陈述及 Remark 2。

2. **带宽选择的正式理论**：模拟中使用 CV 选择带宽，但定理的证明假设带宽满足确定性条件 A4。CV 带宽是否满足这些条件？若不满足，是否存在更优的带宽选择准则？**扎根点**：A4 的陈述及模拟部分对 CV 的使用。

3. **高维 W 的扩展**：本文假设 W 的维度 r 固定。当 r 随 n 增长（高维协变量）时，核估计的收敛速度会恶化，检验是否仍然有效？能否用机器学习方法（如随机森林、神经网络）替代核估计？**扎根点**：A1–A4 对 r 的固定假设。

4. **强条件外生性检验**：本文只检验了均值外生性 E[U|W]=0。如何将方法推广到检验强条件外生性 E[U|W,Z₂]=0？作者在 7.2 节讨论了这一扩展，但未给出完整理论。**扎根点**：7.2 节的讨论。

5. **局部备择的功效优化**：定理 2 给出了 n^{-1/2} 阶局部备择下的极限分布，但未讨论如何选择权重函数（如 KS vs CvM）以最大化对特定方向的功效。是否存在局部最优的检验统计量？**扎根点**：定理 2 及 5 节的功效比较。

6. **与显著性检验的关系**：本文检验的是"是否存在内生性"，而非"内生性是否显著"。在实证中，拒绝 H₀ 后如何进一步量化内生性的程度？能否构造内生性大小的置信区间？**扎根点**：实证部分对拒绝结果的解释。
