### 一、领域脉络与小综述

#### 这个方向是什么

本文所处的子方向是**纵向因果推断中的参数化 g-computation（parametric G-computation）**。其根本科学问题是：在存在**竞争事件（competing events）**和**右删失（right-censoring）**的观察性纵向数据中，如何估计某个暴露（如历史注射吸毒）对多个结局（如 HAART 启动、AIDS/死亡）的**边际总效应（marginal total effect）**。该方向的成熟度较高——g-computation 本身是因果推断的经典方法（Robins 1986），但**在竞争风险设定下的实现细节**（尤其是 nuisance 模型的选择与拟合）仍是方法学讨论的活跃地带，本文正是这一讨论中的一个"实现简化"型贡献。

#### 发展脉络（history）

- **奠基工作**：**Robins (1986)** 提出 g-computation 算法，为纵向数据中的因果效应估计提供了非参数识别公式。这是整个方向的根基——它说明在序贯可忽略性（sequential ignorability）和一致性（consistency）假设下，边际效应可以通过对协变量历史的迭代条件期望来识别。
- **主要进展**：**Hernán & Robins (2020)** 的教科书系统化了参数化 g-computation 的实践流程，其中标准做法是**拟合多个 pooled logistic 回归模型**——每个时间点一个，用于估计各时间点的条件事件概率。这一做法成为流行病学中的默认实现。**Young et al. (2011)** 等进一步讨论了 g-computation 在竞争风险下的扩展，指出需要同时建模各竞争事件的发生概率。
- **当前 frontier**：近年来，方法学关注点转向**nuisance 模型的灵活性与鲁棒性**——例如用数据自适应方法（如 Super Learner）替代参数模型，以及处理高维协变量。但**在竞争风险下，如何用更简洁的 nuisance 模型实现 g-computation** 仍是一个开放问题，尤其是当多个结局需要同时建模时。
- **本文的位置**：本文提出用**单一 pooled multinomial logistic 模型**替代多个 pooled logistic 回归模型，作为参数化 g-computation 的 nuisance 模型。这是一个**实现层面的简化**——它不改变识别假设，也不改变估计的因果解释，但减少了模型拟合的数目，并天然保证了各竞争事件概率之和为 1（这是多个独立 logistic 模型不自动满足的）。

#### 子线索聚类

这些被引文献大致落在两条子线索上：

1. **g-computation 的理论与实现**（Robins 1986; Hernán & Robins 2020; Young et al. 2011）：这条线关注识别条件、估计流程、以及在不同数据结构（如竞争风险、时变暴露）下的推广。本文直接属于这条线。
2. **竞争风险建模**（Fine & Gray 1999 等，虽未在 intro 中直接引用，但属于该方向的背景）：这条线关注如何建模竞争事件——包括 cause-specific hazard 和 subdistribution hazard 两种框架。本文的 multinomial 方法本质上属于 cause-specific 框架的离散时间版本。

#### 这个方向在追问的核心问题

1. **如何正确估计存在竞争事件时的边际效应？** 主流方法是 cause-specific hazard 建模 + g-computation 或 IPW。瓶颈在于需要同时建模多个事件，且模型设定错误会直接影响效应估计。
2. **如何选择 nuisance 模型？** 参数模型（如 pooled logistic）简单但可能 misspecification；非参数/半参数方法灵活但实现复杂。本文的贡献是提供一个**中间选项**——multinomial logistic 在保持参数模型简洁性的同时，更自然地处理多类别结局。
3. **如何处理右删失？** 标准做法是假设删失独立于事件发生（条件于协变量），并在 g-computation 中通过逆概率加权或直接建模删失机制来处理。本文的处理方式是将其纳入多类别结局（即把删失视为一个"事件"类别）。

#### ⚠️ 作者的 framing（必须明确标注成"这是作者的说法"）

**这是作者的说法**：作者将缺口 frame 成"参数化 g-computation 在竞争风险下通常需要拟合多个 pooled logistic 模型，这既繁琐又可能产生概率之和不为 1 的不一致问题；因此，用单一 pooled multinomial logistic 模型是'显然的下一步'"。作者淡化了以下竞争路线：（1）**非参数 nuisance 模型**（如 Super Learner + g-computation）——作者未讨论其相对优劣；（2）**subdistribution hazard 框架**（Fine-Gray 模型）——作者完全未提及，而该框架在竞争风险文献中是另一主流选择。**什么明显该被引 / 该存在、却没出现在 intro 里？** 作者未引用 Fine & Gray (1999) 或任何 subdistribution hazard 相关工作，也未讨论 g-computation 与 IPW 在竞争风险下的效率比较（如 Young et al. 2011 的模拟比较）。这些是值得研究者去查的缺口。

#### 张力

未见明显对立引用。但存在一个潜在张力：**multinomial logistic 隐含了 IIA（无关选择的独立性）假设**，即任意两个结局类别的相对概率不受其他类别影响。这在竞争风险中是否合理？作者未讨论这一点。这是一个值得研究者注意的潜在弱点。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：把符号、模型、可观测数据交代清楚

**符号**（逐个点名）：

- **\(i = 1, \dots, n\)**：个体编号，\(n = 1,164\)（WIHS 样本量）。
- **\(t = 0, 1, \dots, T\)**：离散时间点（本文中为随访月数，\(T = 24\) 个月）。
- **\(A\)**：暴露变量（本文中为历史注射吸毒，二值：是/否）。
- **\(L_t\)**：时变协变量（在时间 \(t\) 测量的混杂因素，如 CD4 计数、病毒载量等）。
- **\(Y_t\)**：结局指示变量，在本文中为**多类别**：\(Y_t \in \{0, 1, 2\}\)，其中 0 = 既未启动 HAART 也未发生 AIDS/死亡（即"存活且未启动"），1 = 启动 HAART，2 = 发生 AIDS/死亡（竞争事件）。注意：这是一个**吸收状态**设定——一旦进入状态 1 或 2，个体不再回到状态 0。
- **\(C_t\)**：删失指示（右删失，如失访）。
- **\(\bar{L}_t = (L_0, \dots, L_t)\)**：协变量历史。
- **\(\bar{Y}_{t-1}\)**：结局历史（在本文的设定中，由于结局是吸收状态，这简化为"是否已进入某状态"）。
- **\(Y_t(a)\)**：**潜在结局**（counterfactual）——若暴露 \(A = a\)，个体在时间 \(t\) 的结局状态。这是 estimand 的定义基础。
- **\(\psi(a)\)**：**边际风险**（estimand），即 \(\psi(a) = P(Y_T(a) = 1)\)（HAART 启动的 2 年风险）或 \(P(Y_T(a) = 2)\)（AIDS/死亡的 2 年风险）。本文估计的是**风险差** \(\psi(1) - \psi(0)\)。
- **\(p_t(a)\)**：在 g-computation 中需要估计的**条件概率**——给定协变量历史和暴露 \(A = a\)，在时间 \(t\) 进入各状态的条件概率。

**模型**（数据生成机制）：

- 观测数据为 \((A_i, \bar{L}_{i,T}, \bar{Y}_{i,T}, \bar{C}_{i,T})\)，\(i = 1, \dots, n\)。
- 识别假设（作者默认采用，但未在摘要中展开）：
  - **序贯可忽略性（sequential ignorability）**：\(Y_t(a) \perp A \mid \bar{L}_{t-1}, \bar{Y}_{t-1}\)（给定协变量历史和结局历史，暴露分配与潜在结局独立）。
  - **一致性（consistency）**：观测到的结局等于潜在结局在观测暴露下的值。
  - **删失机制**：假设删失独立于事件发生（条件于协变量历史），即 \(C_t \perp Y_t \mid \bar{L}_t, \bar{Y}_{t-1}, A\)。
- **可观测数据**：研究者实际能观测到的是每个个体在每个时间点的协变量 \(L_t\)、结局状态 \(Y_t\)（0/1/2）、删失指示 \(C_t\)，以及基线暴露 \(A\)。**不可观测**的是潜在结局 \(Y_t(a)\)（每个个体只能观测到其实际暴露下的结局路径）。

#### 第二步：讲最小内核

**最小特例**：假设只有两个时间点（\(T = 1\)），结局为二值（无竞争事件，只有 HAART 启动 vs. 未启动），无时变协变量（只有基线协变量 \(L_0\)），无删失。此时：

- 标准 g-computation 的做法是：拟合一个 logistic 回归 \(P(Y_1 = 1 \mid A, L_0)\)，然后对每个暴露水平 \(a\)，用该模型预测所有个体的 \(P(Y_1(a) = 1)\)，取平均得到 \(\hat{\psi}(a)\)。
- 本文的"最小内核"是：当结局变为**三类别**（启动 HAART / AIDS-死亡 / 两者皆非）时，标准做法需要拟合**两个** logistic 模型（一个对 HAART 启动，一个对 AIDS/死亡），而本文提出拟合**一个** multinomial logistic 模型，直接输出三个类别的概率。在 \(T = 1\) 的简单情形下，这只是一个**参数化选择**——两种方法在 MLE 下给出的边际风险估计在数值上完全一致（因为 multinomial logistic 的似然可以分解为条件 logistic 似然的乘积）。

**为什么这个特例能体现核心思想**：本文的贡献不在于改变识别或估计的因果逻辑，而在于**用一个多类别模型统一了多个二值模型**。在 \(T = 1\) 时，这纯粹是计算便利；在 \(T > 1\) 时（本文的实际设定），好处更明显——**多个 pooled logistic 模型需要分别处理时间-事件交互项，而 multinomial 模型天然将时间作为协变量纳入，且保证了各事件概率之和为 1**。最小内核的数学命题是：

> 在离散时间竞争风险设定下，用 pooled multinomial logistic 模型替代多个 pooled logistic 模型进行 g-computation，得到的边际风险估计在 MLE 下是**数值等价**的（因为似然分解），但前者更简洁且避免了概率不一致问题。

这个命题的证明只需用到多类别 logistic 的似然分解性质，不涉及新的因果识别理论。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：在存在竞争事件（AIDS/死亡）和右删失的纵向观察性数据中，如何用参数化 g-computation 估计暴露（历史注射吸毒）对多个结局（HAART 启动、AIDS/死亡）的边际总效应。
2. **核心工具 / 方法**：提出用**单一 pooled multinomial logistic 回归模型**替代多个 pooled logistic 回归模型作为 g-computation 的 nuisance 模型，并在 Women's Interagency HIV Study（WIHS）数据上实现。
3. **主要结论**：两种实现（多个 pooled logistic vs. 单一 pooled multinomial）产生**完全一致**的边际风险估计；例如，历史注射吸毒对 HAART 启动的风险差为 −12.5%（95% CI: −18.0%, −7.0%），对 AIDS/死亡的风险差为 13.2%（6.8%, 19.7%）。multinomial 方法简化了实现且避免了概率不一致问题。

#### 关键设定与假设

在第二节最小记号的基础上，本文的完整设定为：

- **数据**：WIHS 队列，\(n = 1,164\) 名 HIV 阳性女性，随访 24 个月。
- **暴露**：历史注射吸毒（基线测量，二值）。
- **结局**：三类别竞争事件——HAART 启动、AIDS/死亡、两者皆非（吸收状态）。
- **协变量**：基线与时变的混杂因素（如 CD4 计数、病毒载量、年龄等），用于构建 nuisance 模型。
- **识别假设**（作者默认采用 g-computation 的标准假设）：
  - 序贯可忽略性：给定协变量历史和结局历史，暴露分配与潜在结局独立。
  - 一致性：观测结局等于潜在结局。
  - 删失独立于事件发生（条件于协变量历史）。
- **相比已有文献的差异**：本文不改变识别假设，只改变 nuisance 模型的**参数化形式**。相比多个 pooled logistic 模型，multinomial 模型**自动保证各事件概率之和为 1**，且减少了模型拟合次数。

#### 主要结果

- **核心量化结论**：两种 g-computation 实现（多个 pooled logistic vs. 单一 pooled multinomial）在 WIHS 数据上产生**完全一致**的边际风险估计。具体数值：
  - 历史注射吸毒对 HAART 启动的风险差：−12.5%（95% CI: −18.0%, −7.0%）。
  - 历史注射吸毒对 AIDS/死亡的风险差：13.2%（6.8%, 19.7%）。
- **与 baseline 对比**：baseline 是多个 pooled logistic 回归的 g-computation；本文的 multinomial 方法在估计值上与之完全一致，但实现更简洁。
- **稳健性**：作者未报告额外的敏感性分析或模拟研究，仅报告了 WIHS 数据的实证结果。

#### 证明路线与技术技巧

本文为**应用型论文**，无新定理证明。其"证明"在于：

1. **似然等价性**：multinomial logistic 的似然可以分解为多个条件 logistic 似然的乘积（在吸收状态设定下），因此 MLE 给出的条件概率估计与分别拟合多个 pooled logistic 模型**数值等价**。这是本文方法有效性的理论基础，但作者未在文中显式证明，而是通过实证结果展示。
2. **g-computation 算法**：用拟合的 multinomial 模型预测每个个体在给定暴露水平下的各时间点状态转移概率，然后通过**累积乘积**计算 2 年边际风险。具体步骤为：
   - 拟合 pooled multinomial logistic 模型：\(\log \frac{P(Y_t = j \mid \bar{L}_t, \bar{Y}_{t-1} = 0, A)}{P(Y_t = 0 \mid \bar{L}_t, \bar{Y}_{t-1} = 0, A)} = \alpha_j + \beta_j A + \gamma_j \bar{L}_t + \delta_j t\)，其中 \(j = 1, 2\)。
   - 对每个暴露水平 \(a\)，设置所有个体的 \(A = a\)，用模型预测每个时间点的状态转移概率。
   - 计算 2 年风险：\(\hat{P}(Y_T(a) = j) = \sum_{t=1}^T \hat{P}(Y_t = j, Y_{t-1} = 0 \mid A = a)\)，其中 \(\hat{P}(Y_t = j, Y_{t-1} = 0 \mid A = a)\) 通过模型预测的转移概率累积得到。
   - 风险差：\(\hat{\psi}(1) - \hat{\psi}(0)\)，用 bootstrap 或 delta method 计算置信区间。
3. **技术技巧**：将右删失视为一个额外的"事件"类别纳入 multinomial 模型，从而避免单独建模删失机制。这是本文的一个实用技巧。

#### 真实例子与应用

- **数据**：Women's Interagency HIV Study（WIHS），\(n = 1,164\) 名 HIV 阳性女性。
- **场景**：估计历史注射吸毒对 2 年内 HAART 启动和 AIDS/死亡风险的边际总效应。
- **结果**：历史注射吸毒显著降低了 HAART 启动风险（风险差 −12.5%），同时显著增加了 AIDS/死亡风险（风险差 13.2%）。这一结果符合临床预期——注射吸毒者可能因依从性或社会因素而延迟启动 HAART，从而增加 AIDS/死亡风险。
- **例子想说明什么**：multinomial g-computation 在真实数据上可行，且与标准方法结果一致，同时实现更简单。

#### 🔎 结论是否比证明窄

- 作者在摘要和结论中声称"multinomial 方法简化了估计过程"，但**未提供模拟研究**来验证在更复杂设定（如时变暴露、非吸收状态）下的表现。因此，其结论的适用范围**窄于**其声称的"简化估计"——目前仅在 WIHS 数据上验证。
- 作者未讨论 multinomial logistic 的 **IIA 假设**在竞争风险设定下是否合理，也未与 **Fine-Gray subdistribution hazard 模型**进行比较。这些是结论中未覆盖的空白。

### 四、开放问题

1. **模拟验证**：本文仅在单一真实数据集上验证了 multinomial g-computation 与标准方法的一致性。一个开放问题是：在有限样本、模型 misspecification、高维协变量等条件下，两种方法的相对表现如何？这需要系统的模拟研究。（扎根于：本文无模拟实验，结论仅基于 WIHS 数据。）
2. **IIA 假设的检验**：multinomial logistic 隐含 IIA 假设，即任意两个结局类别的相对概率不受其他类别影响。在竞争风险中，这一假设是否合理？若违反，估计是否仍有意义？这是一个未被作者讨论的潜在弱点。（扎根于：作者未提及 IIA 或 Hausman-type 检验。）
3. **与 Fine-Gray 框架的比较**：竞争风险文献中另一主流方法是 subdistribution hazard 模型（Fine & Gray 1999）。multinomial g-computation 与 Fine-Gray 方法在估计效率、稳健性和解释性上的比较，是一个值得探索的问题。（扎根于：intro 未引用 Fine-Gray 相关工作。）
4. **扩展到时变暴露**：本文的暴露（历史注射吸毒）是基线测量的。若暴露是时变的，multinomial g-computation 的实现和性质如何变化？这需要进一步研究。（扎根于：本文设定为基线暴露，未涉及时变暴露。）

**提示**：要确认上述问题是否为真 gap，建议去读近 5 年关于"parametric g-computation + competing risks"的论文 intro——若多篇都指向同一问题，则为共识性 gap；若互相矛盾，则可能是机会。
