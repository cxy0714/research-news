# Weighted conformal prediction under covariate shift: process limits, estimated weights and efficiency

**作者**: Mehrdad Pournaderi  
**主题**: 数理统计 / 假设检验  
**相关性**: 7/10  
**链接**: <https://arxiv.org/abs/2611.20052>

### 一、领域脉络与小综述

- **这个方向是什么**：本文研究的核心问题是**加权分裂共形预测（weighted split conformal prediction）在协变量偏移（covariate shift）下的训练条件覆盖率（training-conditional coverage）的渐近分布与效率性质**。具体而言，当测试分布与训练分布不同（但条件分布 P(Y|X) 不变）时，需要对校准分数按似然比 v = dQ_X/dP_X 加权，而加权后的经验分布函数（EDF）的随机波动直接决定了实际部署的预测集的覆盖率误差。该子方向处于**半参数效率理论与 conformal inference 的交叉前沿**，其成熟度体现在：有限样本界（PX26）、单点中心极限定理（P26）和过程极限（G24）均已建立，但**估计权重下的过程极限与效率刻画**仍是开放问题。

- **发展脉络（history）**：
  - **奠基工作**：Vovk et al. (2005) 提出分裂共形预测，在交换性假设下给出边际覆盖率保证；Tibshirani et al. (2019) 引入似然比加权，将共形预测推广到协变量偏移场景，证明加权后的边际覆盖率仍受控。
  - **主要进展（训练条件视角）**：Vovk (2012) 首次研究训练条件覆盖率；Bian and Barber (2023)、Liang and Barber (2025) 和 Duchi (2025) 进一步刻画了训练条件覆盖率的分布性质，但均局限于交换性场景。
  - **加权场景的有限样本界**：Pournaderi and Xiang (2026)（PX26）证明加权 DKW 不等式，给出训练条件覆盖率的偏差界，但常数不明确且尺度为 B = sup v。
  - **单点极限与方差代理**：Pournaderi (2026)（P26）在固定水平上建立中心极限定理，发现方差代理由 K² = 1 + χ²(Q||P) 控制而非 B，并给出有限样本界的显式常数。
  - **过程极限（G24）**：Gazin (2024) 通过泛函 delta 方法得到交换性场景下 FCP 的过程极限，但**仅适用于有界确定性权重且为分数的函数**，并将估计权重下的极限分布列为开放问题。
  - **本文位置**：本文填补了 G24 留下的空白——在**无界协变量权重**和**估计权重**下建立过程极限，并首次给出**半参数效率刻画**。

- **子线索聚类**：
  1. **有限样本界与浓度不等式**（PX26, P26）：关注覆盖率偏差的显式上界，以 B 或 K² 为尺度。
  2. **过程极限与渐近分布**（G24, 本文）：关注覆盖率作为水平函数的联合分布，为同时推断提供基础。
  3. **估计权重与效率**（本文第 6-7 节）：关注权重估计对极限分布的影响，以及半参数效率界。
  4. **重尾与稳定极限**（本文第 8 节）：当 χ²(Q||P) = ∞ 时，极限分布从高斯变为 p-稳定分布。

- **这个方向在追问的核心问题**：
  1. **训练条件覆盖率的渐近分布是什么？** 这决定了能否对实际部署的预测集进行精确的误差控制。
  2. **估计权重是否影响极限分布？** 若影响，如何修正推断程序？
  3. **加权共形阈值是否半参数有效？** 若否，显式的效率损失是多少？
  4. **当 χ²(Q||P) = ∞ 时，覆盖率误差的收敛速率和极限分布是什么？**

- **⚠️ 作者的 framing**：作者将本文定位为"**过程极限视角下的统一理论**"，声称"弱收敛是有限样本界的正确渐近对应物"（Section 1），并强调"估计权重在均匀意义下不改变一阶极限"（Theorem 6.2）。作者还提出"**自归一化是控制变量**"的观点（Lemma 2.1），认为这是理解加权共形预测的关键。**被淡化或回避的竞争路线**包括：① 有限样本精确界（PX26 的路线）——作者承认其常数不明确但未尝试改进；② 贝叶斯或条件方法——作者完全未讨论；③ 非参数权重估计的效率——作者仅处理参数模型。**明显该被引却没出现**：Romano et al. (2019) 的 CQR 方法、Barber et al. (2023) 的加权共形预测的有限样本理论（虽被引用但未深入讨论其与本文的互补性）。

- **张力**：未见明显对立引用。但存在一个**微妙的张力**：P26 的有限样本界以 K² 为尺度且常数显式，而本文的 Berry–Esseen 界（Proposition 5.1）虽然速率最优但常数不显式（含通用常数 C₀）。作者在 Section 5 承认这一点，但未解释为何不能将 P26 的显式常数推广到过程情形。

### 二、最核心、最简单的例子 / 数学问题

**第一步：符号、模型、可观测数据**

- **符号**：
  - **参数/estimand**：θ_t(P) = F_Q(t) = E_P[v(X)·1{S≤t}]，即测试分布下分数的 CDF；q_Q(β) = F_Q^{-1}(β) 为 β 分位数；覆盖率误差 C_m(β) = β − F_Q(τ̂(β))。
  - **随机变量/样本**：校准样本 Z_i = (X_i, Y_i) ~ P，i = 1,...,m；测试点 Z = (X, Y) ~ Q；分数 S_i = s(Z_i)（固定 score 函数）；似然比 v_i = v(X_i) = dQ_X/dP_X(X_i)。
  - **过程**：加权 EDF F̂_m(t) = Σ v_i·1{S_i≤t} / Σ v_i；加权分数过程 Z_m(t) = √m(F̂_m(t) − F_Q(t))；覆盖率过程 √m C_m(β)。
  - **关键量**：K² = E_P[v²] = 1 + χ²(Q||P)（二阶矩）；G(t) = E_Q[v·1{S≤t}]（加权时钟）；B = sup v（有界性假设，本文大部分结果不需要）。
  - **潜在/不可观测量**：真实似然比 v 通常未知，需估计；F_Q 和 q_Q(β) 是目标量，不可直接观测。

- **模型**：
  - 数据生成：X ~ P_X（训练），X' ~ Q_X（测试），Y|X ~ P_Y|X（共享），S = s(X,Y)（固定 score 函数）。
  - 协变量偏移假设：Q_X ≪ P_X，且 P_Y|X 不变。
  - 权重估计：v̂ 从无标签协变量样本估计（如通过分类器或矩估计），可能依赖校准协变量 X_1,...,X_m。

- **可观测数据**：
  - 校准样本：{(X_i, Y_i)}_{i=1}^m，可观测分数 S_i 和协变量 X_i。
  - 辅助数据：无标签协变量样本（用于估计 v̂），可能包含校准协变量。
  - 测试点：X（协变量可观测，Y 未知）。

**第二步：最小内核**

**最简特例**：假设 v 已知且恒定（无估计误差），分数 S 在 P 和 Q 下都连续，且 m 很大。此时：

- **要证的命题**：Z_m(t) = √m(F̂_m(t) − F_Q(t)) 在 ℓ^∞(R) 中弱收敛到高斯过程 G_Q(t) = W(G(t)) − F_Q(t)W(K²)，其中 W 是标准布朗运动。

- **为什么成立**：
  1. **分子分解**：由 Lemma 2.1，Z_m(t) = G_m h_t / P_m v，其中 h_t = v(1{S≤t} − F_Q(t))，G_m 是经验过程。
  2. **分母收敛**：P_m v → E_P v = 1（强大数定律），故分母可视为 1 + o_p(1)。
  3. **分子 CLT**：h_t 是平方可积函数类（因为 E_P h_t² ≤ K² < ∞），且该类是 DKW 类的子集（由 Lemma A.2 的括号数估计），故 G_m h_t 在 ℓ^∞(R) 中弱收敛到高斯过程 G 满足 Cov(G(s), G(t)) = P(h_s h_t) = C(s,t)。
  4. **协方差计算**：展开 C(s,t) = G(s∧t) − F_Q(s)G(t) − F_Q(t)G(s) + K²F_Q(s)F_Q(t)，这正是 W(G(t)) − F_Q(t)W(K²) 的协方差（因为 W 的独立增量性和 G 的单调性）。

- **核心思想**：自归一化（除以 P_m v）将加权 EDF 转化为**单函数类的经验过程**，从而避免了处理随机分母的困难。这个"控制变量"技巧是全文的基石——它使得 Donsker 理论可以直接应用，而不需要处理非平稳的权重过程。

- **为什么这是最小内核**：去掉所有技术假设（连续性、有界性、估计权重）后，上述 4 步就是全部论证。一般情形（估计权重、无界 v、重尾）只是在这个骨架上添加"扰动项"并证明其可忽略（Theorem 6.2, 6.4, 8.2）。

### 三、这篇论文做了什么

**三句话**：
1. **研究了什么问题**：加权分裂共形预测在协变量偏移下的训练条件覆盖率，作为水平 β 的函数，其渐近分布、估计权重的影响、以及半参数效率性质。
2. **核心工具/方法**：自归一化加权经验过程（Lemma 2.1 的控制变量恒等式）+ Donsker 理论（括号数估计）+ 半参数效率理论（投影到切线空间）+ 稳定分布理论（正则变化尾部）。
3. **主要结论**：在 χ²(Q||P) < ∞ 下，覆盖率过程弱收敛到高斯过程 W(Ĝ(β)) − βW(K²)；估计权重不改变一阶极限（Theorem 6.2），但通过协方差项影响二阶性质（Theorem 6.4）；已知权重下，加权共形阈值半参数有效当且仅当 G(t) = K²F_Q(t)，否则给出显式效率修正（Theorem 7.1-7.2）；χ²(Q||P) = ∞ 时，极限为 p-稳定分布（Theorem 8.2-8.3）。

**关键设定与假设**：
- **核心假设**：K² = E_P v² < ∞（二阶矩条件，Theorem 3.1 的必要条件，由 Proposition 3.3 证明）；F_Q 连续（Theorem 4.1）；估计权重满足 Donsker 条件（Assumption 6.1）。
- **相比已有工作的放宽**：相比 PX26 的 B = sup v < ∞，本文只需 K² < ∞（更弱）；相比 G24 的有界确定性权重，本文允许无界随机权重（更一般）；相比 P26 的单点极限，本文给出过程极限（更强）。
- **相比已有工作的强化**：本文的 Berry–Esseen 界（Proposition 5.1）在单点情形达到参数速率 m^{-1/2}，但常数不显式；P26 的常数显式但仅限固定水平。

**主要结果**：
1. **Theorem 3.1（过程 CLT）**：Z_m ⇝ G_Q 在 ℓ^∞(R) 中，G_Q(t) = W(G(t)) − F_Q(t)W(K²)。证明基于括号数估计（Lemma A.2）和 Ossiander 定理。
2. **Theorem 4.1（覆盖率过程）**：√m C_m(β) ⇝ L(β) = G_Q(q_Q(β))，且与 Z_m(q_Q(β)) 的差为 o_p(m^{-1/2}) 一致。证明是加权 Bahadur–Kiefer 表示（Lemma B.1 + 精确表示）。
3. **Theorem 6.2（估计权重）**：若 v̂ 在 Donsker 类中且 L² 一致，则 √m(F̌_m − F_Q) = Z_m + o_p(1) 一致。证明利用 Lemma 2.1 的恒等式和 Donsker 类的稳定性。
4. **Theorem 6.4（参数估计权重）**：估计误差通过协方差项 γ(t) 进入极限，方差可能低于 oracle（Example 6.6）。
5. **Theorem 7.1-7.2（效率）**：已知权重下，加权共形阈值半参数有效当且仅当 G(t) = K²F_Q(t)；否则，效率损失为 (G(t) − K²F_Q(t))²/(K²−1)，并给出显式修正。
6. **Theorem 8.2-8.3（稳定极限）**：χ²(Q||P) = ∞ 且尾部指数 p ∈ (1,2) 时，有限维分布以速率 m^{1-1/p} 收敛到 p-稳定分布。

**证明路线与技术技巧**：
- **整体路线**：从 Lemma 2.1 的恒等式出发，将问题转化为单函数类经验过程 → 用括号数估计证明 Donsker 性 → 用连续映射定理得到过程极限 → 用 Bahadur–Kiefer 表示处理分位数 → 用半参数投影处理效率。
- **关键技巧**：
  - **括号数估计**（Lemma A.2）：用 partition lemma 将 ℓ^∞(R) 的括号数控制在 O(K²/ε²)，这是 Donsker 性的核心。
  - **控制变量恒等式**（Lemma 2.1）：自归一化将随机分母转化为可忽略的扰动，避免了处理非平稳权重。
  - **Bahadur–Kiefer 表示**（Theorem 4.1 证明）：精确表示 √m C_m(β) = Z_m(q_Q(β)) + o_p(m^{-1/2})，将分位数问题转化为 EDF 问题。
  - **半参数投影**（Theorem 7.1）：将切线空间分解为条件部分和边际部分，投影得到效率界。
  - **稳定极限**（Theorem 8.2）：用点过程方法处理重尾，验证 Lévy 测度条件。

**真实例子与应用**：
- **模拟实验**（Section 9）：使用回归模型 Y = 2X + ε，ε|X ~ N(0, (0.2+|X|)²)，三种协变量偏移：(A) 有界多项式权重 v = 4x³；(B) 无界指数权重 v = e^{x-1/2}；(C) 重尾权重 v = (1/3)x^{-2/3}。验证了 Theorem 3.1 的极限分布（Table 3）、Theorem 4.1 的覆盖率过程（Table 4）、Theorem 6.4 的估计权重效应（Table 5）、Theorem 7.2 的效率增益（Table 10）以及 Theorem 8.3 的稳定极限（Figure 3）。
- **实际意义**：为协变量偏移下的共形预测提供了**同时覆盖多个水平**的精确推断工具，避免了 Bonferroni 校正的保守性。

**🔎 结论是否比证明窄**：
- **Theorem 6.2** 的证明假设 v̂ 在 Donsker 类中且 L² 一致，但结论声称"无论 v̂ 如何依赖校准样本"都成立。实际上，证明依赖于 v̂ 与校准样本的独立性（通过 Donsker 类的稳定性），若 v̂ 直接使用校准协变量拟合（如 logistic 回归），可能需要额外的交叉拟合条件。
- **Theorem 7.1** 的效率界在 G(t) = K²F_Q(t) 时退化为 oracle 方差，但作者未讨论该条件何时成立（Example 6.6 中仅给出一个特例）。
- **Theorem 8.2** 的稳定极限只在有限维分布意义下证明，作者在 Remark 8.4 中承认过程级收敛（Skorokhod 拓扑）是开放问题。

### 四、开放问题

1. **稳定极限的过程级收敛**（Section 10, (i)）：Theorem 8.2 的有限维收敛应推广到 ℓ^∞ 中的过程收敛，需要处理重尾过程的 tightness。扎根于 Theorem 8.2 的证明和 Remark 8.4(a)。
2. **估计权重的效率**（Section 10, (ii)）：在 M3 模型中，非参数估计的权重是否达到 V3 界？Theorem 6.4 仅处理参数模型。扎根于 Theorem 6.4 和 Proposition 7.3(b)。
3. **无分布诊断**（Section 10, (iii)）：Proposition 4.7 的检验统计量依赖 (F_Q, G)，能否构造 Khmaladze 变换使其无分布？扎根于 Proposition 4.7 的讨论。
4. **锐利速率**（Section 10, (iv)）：Theorem 5.2 的 m^{-1/4} 速率是否可改进为 m^{-1/2}？模拟（Figure 2）暗示可能，但证明需要避免 Bahadur–Kiefer 步骤。
5. **有限样本证书**（Section 10, (v)）：Proposition 5.1 的 Berry–Esseen 界常数不显式，能否结合 P26 的显式常数给出可操作的有限样本保证？
