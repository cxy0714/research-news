### 一、领域脉络与小综述

- **这个方向是什么**：本文研究的核心问题是：给定一个图序列 \(\{G_n\}\)，当顶点被独立地染成红/蓝两色（概率分别为 \(p\) 和 \(1-p\)）时，单色边数 \(T_n\) 的渐近分布何时是正态的？这个问题处于**随机图组合学**与**高维统计/非参数检验**的交叉点。其根本的统计问题是：一个由局部依赖的二元指标（边是否单色）构成的复杂和，在什么条件下满足中心极限定理（CLT），以及如何用低阶矩来刻画这种收敛。该方向的成熟度较高，已有大量关于平衡情形（\(p=1/2\)）的经典结果，但非平衡情形（\(p\neq 1/2\)）的完整刻画是当前的前沿。

- **发展脉络（history）**：
  - **奠基工作**：Nualart 和 Peccati (2005) [43] 发现了 Wiener 混沌中的"四阶矩现象"：固定阶多重随机积分的序列依分布收敛到正态，当且仅当其四阶矩收敛到 3。这是整个"矩现象"研究的起点。随后，Nourdin 和 Peccati (2007) [39, 41] 用 Stein 方法给出了该定理的定量误差界，并推广到更一般的框架。
  - **主要进展**：Bhattacharya、Diaconis 和 Mukherjee (2013) [6] 将四阶矩现象推广到随机图染色问题，证明了在平衡情形 \(p=1/2\) 下，单色边数的渐近正态性等价于四阶矩条件。这一结果将抽象的混沌理论落地到具体的组合对象上。随后，Döbler 和 Krokowski (2019) [19] 研究了 Rademacher 混沌的四阶矩条件，并发现了例外概率 \(p = (1\pm 1/\sqrt{3})/2\)，在这些点上四阶矩条件失效。本文作者之一 Bhattacharya 及其合作者 (2022) [11] 进一步刻画了二次混沌的分布极限。
  - **当前 frontier**：本文的工作站在两个前沿的交汇处：(i) 将"矩现象"从四阶推广到三阶，这是一个全新的现象；(ii) 将理论结果应用于图基两样本检验，为 K-近邻图等几何图上的检验统计量提供严格的渐近正态性条件。特别是，Kanekar (2026) [31] 最近才建立了有向 K-NN 检验在 \(K=o(n)\) 时的相合性，而本文则处理了无向 K-NN 情形并给出了更精细的条件。

- **子线索聚类**：被引文献大致落在三条子线索上：
  1. **Wiener 混沌与 Malliavin 微积分**（[39, 40, 41, 43]）：这是"矩现象"的理论源头，处理高斯空间上的泛函。核心工具是 Malliavin 算子、混沌展开和 Stein 方法。
  2. **离散混沌与图染色**（[6, 8, 9, 11, 18, 19, 21, 42]）：将矩现象推广到 Rademacher 变量、图染色和子图计数。核心工具是组合计数、图论中的 motif 计数以及离散的 Stein 方法。这一支与本文关系最直接。
  3. **图基两样本检验**（[4, 5, 13, 22, 28, 29, 31, 46, 49, 51, 52]）：将图结构（如最小生成树、K-近邻图、匹配）用于非参数两样本检验。核心问题是检验统计量在原假设下的渐近分布，以及检验的相合性和功效。本文的贡献在于将第 2 支的矩现象结果应用于这一支的检验问题。

- **这个方向在追问的核心问题**：
  1. **矩条件的普适性**：对于一般的图泛函（不仅是单色边数），四阶矩条件（或三阶矩条件）是否是渐近正态性的充要条件？在什么条件下会失效？
  2. **例外概率的刻画**：在哪些参数值（如染色概率 \(p\)）下，矩条件会失效？这些例外值是否有统一的刻画？
  3. **稀疏图情形的处理**：当图变得稀疏（如 \(p\to 0\)）时，矩条件如何变化？能否给出统一的充分条件？
  4. **检验统计量的渐近分布**：对于实际使用的图基检验统计量（如 K-近邻图上的边计数），能否在更宽松的条件下（如 \(K\) 随 \(n\) 增长）证明渐近正态性？

- **⚠️ 作者的 framing（这是作者的说法）**：作者在引言中明确将本文的贡献 frame 为"发现了第三个矩现象"（a new third moment phenomenon），并强调这是"在偏置图染色下的新现象"。作者将例外概率 \(p = (1\pm 1/\sqrt{3})/2\) 的出现归因于"四阶矩中 4-star 项的系数恰好为零"，从而使得四阶矩条件失效。作者还声称，本文的 K-近邻图两样本检验结果"提供了第一个在任意 \(K\) 下都成立的渐近正态性条件"（见 Theorem 1.6 的表述）。这些说法是否成立，需要读者自行对照原文和 Kanekar [31] 的结果来判断。

- **张力**：被引文献之间存在一个明显的张力：Döbler 和 Krokowski [19] 发现四阶矩条件在例外概率处失效，而本文进一步发现三阶矩条件在这些例外点仍然有效。这暗示"矩条件"本身可能不是一个统一的原理，而是依赖于具体的参数和泛函结构。另一个张力在于：经典的四阶矩现象（Wiener 混沌）是"当且仅当"的充要条件，而本文在稀疏情形（Theorem 1.2）只给出了充分条件，且明确指出"neither is necessary for asymptotic normality"（见第 1.1 节末）。这说明在稀疏情形下，矩条件可能过于严格，存在更弱的充分条件。

### 二、最核心、最简单的例子 / 数学问题

**第一步：符号、模型、可观测数据**

- **图序列**：\(\{G_n\}_{n\in\mathbb{N}}\)，其中 \(G_n\) 是顶点集为 \([n]:=\{1,\dots,n\}\) 的简单无向图。边集记为 \(E(G_n)\)。
- **染色**：每个顶点 \(i\in[n]\) 独立地以概率 \(p\) 染红（\(X_i=1\)）、以概率 \(1-p\) 染蓝（\(X_i=0\)）。这里 \(p\in(0,1)\) 是固定的（固定 p 情形）或随 \(n\) 变化（稀疏情形 \(p=p_n\to 0\)）。
- **目标统计量**：单色边数 \(T_n := \sum_{\{i,j\}\in E(G_n)} \mathbf{1}\{X_i = X_j\}\)。这是所有两端颜色相同的边的总数。
- **标准化统计量**：\(U_n := \frac{T_n - \mathbb{E}[T_n]}{\sqrt{\mathrm{Var}[T_n]}}\)。我们关心 \(U_n\) 是否依分布收敛到标准正态 \(N(0,1)\)。
- **关键参数**：
  - \(u := (2p-1)^2 \in [0,1)\)。这个参数刻画了染色的"偏置程度"：\(p=1/2\) 时 \(u=0\)（平衡），\(p\to 0\) 或 \(p\to 1\) 时 \(u\to 1\)（完全偏置）。
  - **Motif 计数**：\(N(H, G_n)\) 表示图 \(G_n\) 中同构于 \(H\) 的子图数量。本文特别关注 \(N(\raisebox{-0.5pt}{\includegraphics[height=8pt]{edge.png}}, G_n)\)（边数）、\(N(\raisebox{-0.5pt}{\includegraphics[height=8pt]{wedge.png}}, G_n)\)（2-star 数，即长度为 2 的路径）、\(N(\raisebox{-0.5pt}{\includegraphics[height=8pt]{triangle.png}}, G_n)\)（三角形数）、\(N(\raisebox{-0.5pt}{\includegraphics[height=8pt]{4star.png}}, G_n)\)（4-star 数，即一个顶点连接 4 个叶子的子图）等。
- **可观测数据**：研究者实际能观测到的是图 \(G_n\) 的结构（即边集 \(E(G_n)\)）以及染色结果 \(\{X_i\}_{i=1}^n\)。**不可观测**的是染色过程的潜在机制（即 \(p\) 的真实值），但 \(p\) 是模型参数，可以通过数据估计。在因果推断的语境下，这里的"处理"是染色，而"结果"是边是否单色；但本文不涉及反事实，只关心联合分布。

**第二步：最小内核**

本文的核心数学问题是：**在什么条件下，\(U_n\) 的分布收敛到标准正态？** 作者给出的答案是：这取决于 \(U_n\) 的三阶矩和四阶矩是否收敛到正态分布的相应矩（即 0 和 3）。

**最小例子**：考虑最简单的图序列——完全图 \(G_n = K_n\)（任意两个顶点之间都有边）。此时：
- 边数 \(N(\raisebox{-0.5pt}{\includegraphics[height=8pt]{edge.png}}, G_n) = \binom{n}{2}\)。
- 2-star 数 \(N(\raisebox{-0.5pt}{\includegraphics[height=8pt]{wedge.png}}, G_n) = 3\binom{n}{3}\)（每个 3-顶点子集贡献 3 个 2-star）。
- 4-star 数 \(N(\raisebox{-0.5pt}{\includegraphics[height=8pt]{4star.png}}, G_n) = \binom{n}{5} \cdot 5\)（每个 5-顶点子集贡献 5 个 4-star，以每个顶点为中心）。
- 方差 \(\mathrm{Var}[T_n] = \frac{1-u^2}{4}N(\raisebox{-0.5pt}{\includegraphics[height=8pt]{edge.png}}, G_n) + \frac{u-u^2}{2}N(\raisebox{-0.5pt}{\includegraphics[height=8pt]{wedge.png}}, G_n) \sim \frac{1-u^2}{8}n^2 + \frac{u-u^2}{4}n^3 \sim \frac{u-u^2}{4}n^3\)（当 \(u>0\) 时，2-star 项主导）。

**关键观察**：当 \(p\neq 1/2\)（即 \(u>0\)）时，方差的主要贡献来自 2-star 结构（两条共享一个顶点的边）。这是因为两条共享顶点的边是否单色是相关的（它们共享的那个顶点的颜色同时影响两条边）。这种相关性使得 \(T_n\) 的波动幅度比独立情形大一个数量级。

**核心命题（退化为例）**：对于完全图 \(K_n\)，当 \(p\neq 1/2\) 固定时，可以证明 \(U_n \xrightarrow{d} N(0,1)\) 当且仅当 \(N(\raisebox{-0.5pt}{\includegraphics[height=8pt]{4star.png}}, G_n) = o((N(\raisebox{-0.5pt}{\includegraphics[height=8pt]{edge.png}}, G_n) + N(\raisebox{-0.5pt}{\includegraphics[height=8pt]{wedge.png}}, G_n))^2)\)。对于完全图，这个条件显然成立（因为 \(N(\raisebox{-0.5pt}{\includegraphics[height=8pt]{4star.png}}, G_n) \sim n^5\)，而 \((N(\raisebox{-0.5pt}{\includegraphics[height=8pt]{edge.png}}, G_n) + N(\raisebox{-0.5pt}{\includegraphics[height=8pt]{wedge.png}}, G_n))^2 \sim n^6\)），所以 \(U_n\) 渐近正态。

**为什么三阶矩？** 在非平衡情形（\(u>0\)），\(T_n\) 的展开式中包含线性项（来自单个顶点的颜色）和二次项（来自边的颜色）。三阶矩的收敛性恰好捕捉了线性项与二次项之间的"干扰"是否消失。当 \(p\) 取例外值 \(p = (1\pm 1/\sqrt{3})/2\) 时，四阶矩中 4-star 项的系数恰好为零，导致四阶矩恒等于 3，但线性项与二次项的干扰仍然存在，因此正态性失败。此时，三阶矩的收敛性成为唯一可靠的判据。

### 三、这篇论文做了什么

**三句话**：
1. **研究了什么问题**：本文研究了图序列上独立红蓝染色时单色边数 \(T_n\) 的渐近正态性，目标是给出在固定染色概率 \(p\) 和稀疏染色概率 \(p_n\to 0\) 两种情形下，\(U_n\) 收敛到标准正态的充要条件（固定 p）或充分条件（稀疏 p）。
2. **核心工具 / 方法**：本文使用 Stein 方法（具体是局部依赖的 Stein 方法）结合 motif 计数（子图计数）来建立 \(U_n\) 的 Wasserstein 距离上界，并通过三阶矩和四阶矩的展开来刻画收敛条件。关键技术是将 \(T_n\) 的矩展开为图 \(G_n\) 中各种 motif 的计数，并利用组合不等式（如 Kruskal-Katona 定理）来控制高阶 motif 的贡献。
3. **主要结论**：本文发现了"三阶矩现象"：对任意固定 \(p\neq 1/2\)，\(U_n\) 渐近正态当且仅当 \(E[U_n^3]\to 0\)。在例外概率 \(p = (1\pm 1/\sqrt{3})/2\) 处，四阶矩条件失效（四阶矩恒趋于 3 但正态性失败），而三阶矩条件仍然有效。在稀疏情形 \(p_n\to 0\)，三阶矩条件是充分条件。作为应用，本文推导了无向 K-近邻图两样本检验统计量在原假设下的渐近正态性，给出了 \(K\) 的增长条件。

**关键设定与假设**：
- **固定 p 情形（Theorem 1.1）**：
  - 假设 \(N(\raisebox{-0.5pt}{\includegraphics[height=8pt]{edge.png}}, G_n) \to \infty\)（边数发散）。
  - 定义 \(u = (2p-1)^2\)。
  - 结论 (i) 对 \(p \in (0,1) \setminus \{1/2, (1\pm 1/\sqrt{3})/2\}\)：\(U_n \xrightarrow{d} N(0,1)\) 当且仅当 \(N(\raisebox{-0.5pt}{\includegraphics[height=8pt]{4star.png}}, G_n) = o((N(\raisebox{-0.5pt}{\includegraphics[height=8pt]{edge.png}}, G_n) + N(\raisebox{-0.5pt}{\includegraphics[height=8pt]{wedge.png}}, G_n))^2)\)。
  - 结论 (ii) 对 \(p = (1\pm 1/\sqrt{3})/2\)：\(U_n \xrightarrow{d} N(0,1)\) 当且仅当 \(E[U_n^3]\to 0\)（等价于一个更复杂的 motif 条件，见 Theorem 1.1(ii) 的陈述）。
  - 结论 (iii) 对 \(p=1/2\)：\(U_n \xrightarrow{d} N(0,1)\) 当且仅当 \(N(\raisebox{-0.5pt}{\includegraphics[height=8pt]{4cycle.png}}, G_n) = o(N(\raisebox{-0.5pt}{\includegraphics[height=8pt]{edge.png}}, G_n)^2)\)（即 4-cycle 数远小于边数平方）。
- **稀疏 p 情形（Theorem 1.2, Proposition 1.3, Lemma 1.4）**：
  - 假设 \(p_n \to 0\) 且 \(N(\raisebox{-0.5pt}{\includegraphics[height=8pt]{edge.png}}, G_n) \to \infty\)。
  - Theorem 1.2：若 \(E[U_n^3]\to 0\)，则 \(U_n \xrightarrow{d} N(0,1)\)。
  - Proposition 1.3：四阶矩条件蕴含三阶矩条件（即 \(E[U_n^4]\to 3 \Rightarrow E[U_n^3]\to 0\)）。
  - Lemma 1.4：\(E[U_n^4]\to 3\) 当且仅当 \(p_n(N(\raisebox{-0.5pt}{\includegraphics[height=8pt]{edge.png}}, G_n) + N(\raisebox{-0.5pt}{\includegraphics[height=8pt]{wedge.png}}, G_n)) \to \infty\) 且 \(N(\raisebox{-0.5pt}{\includegraphics[height=8pt]{4star.png}}, G_n) = o(p_n(N(\raisebox{-0.5pt}{\includegraphics[height=8pt]{edge.png}}, G_n) + N(\raisebox{-0.5pt}{\includegraphics[height=8pt]{wedge.png}}, G_n))^2)\)。

**证明路线与技术技巧**：
1. **整体路线**：
   - **Step 1（矩展开）**：将 \(E[U_n^3]\) 和 \(E[U_n^4]\) 展开为 \(G_n\) 中各种 motif 的计数。具体地，\(T_n\) 是边指示器的和，其矩可以分解为若干条边（最多 4 条）的联合矩，而联合矩只取决于这些边构成的子图结构。
   - **Step 2（Stein 方法）**：使用 Stein 方法（具体是 Chatterjee [18] 的交换对方法或局部依赖的 Stein 方法）将 Wasserstein 距离上界转化为对 \(U_n\) 的三阶和四阶矩的估计。关键公式是 \(W_1(U_n, N(0,1)) \lesssim E[|E[U_n^3| \mathcal{F}]|] + \dots\)，其中 \(\mathcal{F}\) 是某个条件代数。
   - **Step 3（组合估计）**：利用图论中的不等式（如 Kruskal-Katona 定理、Sidorenko 不等式等）来估计 motif 计数之间的相对大小，从而将矩条件转化为 motif 条件。
   - **Step 4（应用）**：对于 K-近邻图，利用几何图的性质（如度上界、局部弱收敛等）来验证 motif 条件。

2. **关键跳跃点**：
   - **三阶矩的符号问题**：\(E[U_n^3]\) 可以是负的，因此"\(E[U_n^3]\to 0\)"不能直接由绝对值上界推出。作者通过仔细分析三阶矩展开中各项的符号，证明了在非平衡情形下，三阶矩的绝对值可以被 motif 条件控制。
   - **例外概率的发现**：在计算四阶矩时，作者发现 4-star 项的系数是 \(u^2(1-u)(3u-1)\) 的倍数。当 \(u=1/3\)（即 \(p=(1\pm 1/\sqrt{3})/2\)）时，该系数为零，导致四阶矩恒等于 3。这是一个代数巧合，但作者通过三阶矩分析证明了此时正态性仍然可能失败。
   - **稀疏情形的处理**：当 \(p_n\to 0\) 时，方差的主要贡献从 2-star 项转移到边项，导致展开式的结构发生变化。作者通过引入 \(p_n\) 的显式依赖，给出了统一的处理框架。

**真实例子与应用**：
- **例子 6.1（星图 \(K_{1,n}\)）**：在 \(p=(1+1/\sqrt{3})/2\) 时，\(U_n\) 的四阶矩趋于 3，但 \(U_n\) 不收敛到正态，而是收敛到一个两点分布。这直接证明了四阶矩条件在例外概率处失效。
- **例子 6.2（完全二分图 \(K_{2,n}\)）**：在 \(p=1/2\) 时，\(U_n\) 的三阶矩趋于 0，但 \(U_n\) 不收敛到正态，而是收敛到一个混合分布（正态与 0 的混合）。这证明了三阶矩条件在平衡情形下不充分。
- **例子 6.3（稀疏星图 + 边）**：在 \(p_n = 1/n^3\) 时，\(U_n\) 渐近正态，但三阶矩不趋于 0。这证明了稀疏情形下三阶矩条件不必要。
- **例子 6.4（稀疏星图 + 边）**：在 \(p_n = 1/n^2\) 时，三阶矩趋于 0，但 \(U_n\) 不收敛到正态。这证明了稀疏情形下三阶矩条件不充分。
- **K-近邻图两样本检验（Theorem 1.6）**：在 Poisson 化设定下，无向 K-近邻图上的两样本检验统计量在原假设下渐近正态，条件是 \(K\) 固定或 \(K=o(n)\)。这个结果将前面的矩现象理论应用于实际的非参数检验问题。

**🔎 结论是否比证明窄**：
- **Theorem 1.1(i)** 声称 \(E[U_n^3]\to 0\) 是渐近正态的充要条件，但证明中只给出了充分性（通过 Stein 方法）和必要性（通过三阶矩的显式计算）。必要性部分依赖于一个额外的假设：\(N(\raisebox{-0.5pt}{\includegraphics[height=8pt]{edge.png}}, G_n) \to \infty\) 且 \(N(\raisebox{-0.5pt}{\includegraphics[height=8pt]{wedge.png}}, G_n) = O(N(\raisebox{-0.5pt}{\includegraphics[height=8pt]{edge.png}}, G_n))\)。这个假设在文中没有明确说明，但在证明中使用了。
- **Theorem 1.1(ii)** 声称在例外概率处，三阶矩条件等价于一个复杂的 motif 条件。但证明中只给出了"motif 条件 \(\Rightarrow\) 三阶矩条件 \(\Rightarrow\) 渐近正态"的链条，没有证明反向的"渐近正态 \(\Rightarrow\) motif 条件"。因此，严格来说，Theorem 1.1(ii) 只证明了充分性，而非充要性。
- **Theorem 1.6** 的证明依赖于 Lemma 5.1 中的几何图性质，这些性质对 K-近邻图成立，但对一般的相似性图（如 K-最小生成树）是否成立并未验证。作者在 Corollary 1.7 中声称结果可以推广到 K-匹配图，但并未给出详细证明。

### 四、开放问题

1. **稀疏情形的必要性**：Theorem 1.2 只给出了三阶矩条件的充分性，但例子 6.3 表明该条件不必要。能否给出稀疏情形下渐近正态的充要条件？这可能需要引入新的 motif 条件或更精细的矩条件。
2. **例外概率的推广**：本文发现的例外概率 \(p = (1\pm 1/\sqrt{3})/2\) 是单色边数的特殊性质，还是更一般的图泛函（如单色三角形数、单色路径数）的普遍现象？Döbler 和 Krokowski [19] 的结果暗示这可能与 Rademacher 混沌的代数结构有关，但完整的刻画尚不清楚。
3. **K-近邻图的相合性**：Theorem 1.6 给出了原假设下的渐近正态性，但未讨论备择假设下的检验功效。Kanekar [31] 对有向 K-近邻图给出了检测阈值，本文的无向情形是否也能得到类似的阈值？特别是，当 \(K\) 以何种速率增长时，检验能检测到局部备择？
4. **更一般的相似性图**：Corollary 1.7 声称结果适用于 K-匹配图，但证明依赖于 K-近邻图的特殊性质（如度上界）。对于更一般的相似性图（如 K-最小生成树、K-最近邻图的变体），是否也有类似的渐近正态性？这需要验证相应的 motif 条件。
5. **收敛速率**：本文只证明了 Wasserstein 距离趋于 0，但未给出收敛速率。能否从 Stein 方法的证明中提取出显式的收敛速率？这在实际应用中（如确定样本量）是有价值的。

**提示**：要确认上述问题是否是真 gap，建议去读最近 5 年关于"图基两样本检验"的文献（如 Zhu and Chen [52]、Kanekar [31] 的后续工作），以及关于"矩现象"在更一般图泛函上的推广（如 Das 等人关于单色子图计数的 CLT）。如果这些文献都没有解决上述问题，那么它们就是值得投入的研究方向。
