### 一、领域脉络与小综述

#### 这个方向是什么

本文研究的核心问题是：**在具有边界的有界或无界区域上，对于跳跃核在边界处退化的非局部算子（即纯不连续对称 Markov 过程），如何建立其热核（transition density）的 sharp 双边估计？** 热核估计是概率论与偏微分方程交叉领域的核心工具，它刻画了随机过程在给定时间内从一点转移到另一点的概率密度。当跳跃核在边界处退化（即当点靠近边界时，跳跃到远处的概率急剧下降）时，标准的热核估计方法失效，需要发展新的分析技术。该方向目前处于**活跃但高度专业化**的阶段，主要进展集中在过去十年，由概率论与 PDE 领域的少数几个研究组推动。

#### 发展脉络（history）

**奠基工作（~2000-2010）**：对称 Lévy 过程（即跳跃核为 `J(x,y)=c|x-y|^{-α-d}` 的纯不连续过程）的热核估计由 Chen 和 Kumagai 等人建立。这些工作奠定了“通过热核估计研究非局部算子”的基本框架，但仅限于**无退化**的跳跃核。

**主要进展（~2010-2020）**：研究者开始处理跳跃核在**内部点**（非边界）退化的情形。例如，Chen, Kim, Song 和 Vondraček 等人（2012-2018）研究了形如 `J(x,y)=c(x,y)|x-y|^{-α-d}` 的跳跃核，其中 `c(x,y)` 在区域内部可能为零。这些工作建立了“内部退化”情形下的热核估计，但**边界退化**（即退化仅发生在边界上）仍是一个开放问题。

**当前 frontier（~2020-至今）**：本文是第一个处理**边界退化**情形的 sharp 双边热核估计。作者指出，边界退化导致热核在边界附近的行为发生定性变化，产生了**三种不同形式**的热核估计，其中两种在已知文献中从未出现过。这标志着该方向从“内部退化”向“边界退化”的跨越。

**本文的位置**：本文是 Cho, Kim, Song, Vondraček 研究组系列工作的延续。他们此前已建立了“内部退化”情形下的热核估计（如 Kim, Song, Vondraček 2018），本文将其推广到边界退化情形，并发现了全新的热核形式。

#### 子线索聚类

1. **无退化跳跃核的热核估计**：以 Chen 和 Kumagai 为代表，处理 `J(x,y)=c|x-y|^{-α-d}` 的标准情形。这是整个领域的基准。
2. **内部退化跳跃核的热核估计**：以 Kim, Song, Vondraček 等人为代表，处理 `c(x,y)` 在区域内部可能为零的情形。本文的许多技术工具（如“近似分解性质”）源于此线索。
3. **边界退化跳跃核的热核估计**：本文是这一线索的开创性工作。它处理了 `B(x,y)` 在边界处为零的情形，并发现了全新的热核形式。
4. **临界势杀死的热核估计**：本文的第二部分属于这一线索——研究过程被“临界势”杀死（即过程在到达边界前以一定概率被吸收）时的热核估计。这与“边界吸收”问题（过程到达边界即被杀死）有密切联系。

#### 这个方向在追问的核心问题

1. **热核的 sharp 双边估计**：能否给出热核 `p(t,x,y)` 的上下界，使得上下界相差一个常数因子（即 `c₁ * lower_bound ≤ p(t,x,y) ≤ c₂ * upper_bound`）？这是该领域的“圣杯”。
2. **退化对热核形式的影响**：跳跃核在边界退化如何改变热核在边界附近的渐近行为？是否会产生全新的热核形式？
3. **临界势与边界吸收的关系**：当过程被临界势杀死时，其热核是否与“到达边界即被杀死”的过程具有相同的近似分解性质？生存概率如何依赖于临界势中的常数？

**已知瓶颈**：边界退化导致标准的热核估计方法（如“热核的 Chapman-Kolmogorov 迭代”和“Nash 不等式”）失效。本文采用了一种基于“近似分解性质”和“精细的势论分析”的新方法。

#### ⚠️ 作者的 framing

**这是作者的说法**：作者将缺口 frame 为“跳跃核在边界退化的非局部算子的热核估计从未被研究过”，并将本文定位为“首次得到此类算子的 sharp 双边估计”。作者淡化了“内部退化”与“边界退化”之间的技术联系，强调边界退化导致了**定性上全新的热核形式**。作者回避了以下竞争路线：
- **通过“变换”将边界退化转化为内部退化**：例如，通过某种坐标变换将上半空间映射到全空间，使边界退化变为内部退化。作者没有讨论这种可能性。
- **使用“分数阶 Sobolev 空间”的变分方法**：这是 PDE 领域处理退化椭圆/抛物算子的标准工具，但作者完全未提及。

**什么明显该被引/该存在、却没出现在 intro 里？**
- 作者没有引用任何关于“退化椭圆/抛物 PDE”的文献（如 Gilbarg-Trudinger 的经典著作）。这些文献处理的是**局部**算子的边界退化，与本文的非局部算子有本质区别，但可能存在可借鉴的分析技巧。
- 作者没有引用任何关于“分数阶拉普拉斯算子”在边界退化情形下的工作（如 Grubb 2015 关于“分数阶拉普拉斯算子在边界处的 Dirichlet 问题”）。这些工作可能提供了不同的视角。

**值得研究者去查的问题**：是否存在通过“坐标变换”或“权函数”将边界退化转化为内部退化的方法？如果存在，本文的结果是否可以被视为内部退化情形的一个特例？

#### 张力

未见明显对立引用。该领域的工作高度一致，均基于 Dirichlet 型理论和势论分析，没有出现彼此矛盾的结论。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：把符号、模型、可观测数据交代清楚

**符号**：
- `R_+^d = {x = (x₁, ..., x_d) ∈ R^d : x_d > 0}`：上半空间，即所有最后一个坐标为正的 d 维欧氏空间。边界为 `∂R_+^d = {x : x_d = 0}`。
- `R̄_+^d = R_+^d ∪ ∂R_+^d`：上半空间的闭包（包含边界）。
- `α ∈ (0, 2)`：跳跃过程的“稳定指数”。它控制着跳跃的“重尾”程度——α 越小，大跳跃越频繁。
- `J(x, y)`：跳跃核。它表示过程从 x 跳跃到 y 的**速率**（intensity）。对于纯不连续 Markov 过程，其生成元为 `Lf(x) = ∫_{R^d} (f(y) - f(x)) J(x, y) dy`。
- `B(x, y)`：跳跃核中的“退化因子”。它是一个非负函数，可能依赖于四个参数（具体形式见下文），且可能在边界处为零（即当 x 或 y 靠近边界时，`B(x, y) → 0`）。
- `p(t, x, y)`：热核（transition density）。它表示过程在时间 t 内从 x 转移到 y 的概率密度（关于 Lebesgue 测度）。对于对称 Markov 过程，`p(t, x, y) = p(t, y, x)`。
- `κ(x)`：临界势。它是一个定义在 `R_+^d` 上的非负函数，当过程位于 x 时，它以速率 `κ(x)` 被杀死（即被吸收到一个“坟墓”状态）。
- `p^κ(t, x, y)`：被临界势 `κ` 杀死的过程的热核。
- `p^D(t, x, y)`：到达边界即被杀死的过程的热核（即 Dirichlet 热核）。

**模型**：
- 数据生成机制：考虑一个**纯不连续对称 Markov 过程** `X_t`，其跳跃核为 `J(x, y) = B(x, y) |x - y|^{-α - d}`。这意味着：
  - 过程只能通过“跳跃”移动（没有连续扩散部分）。
  - 跳跃的“大小”分布由 `|x - y|^{-α - d}` 控制（类似于 α-稳定 Lévy 过程）。
  - 跳跃的“方向”和“频率”由 `B(x, y)` 调制。当 `B(x, y)` 在边界处为零时，过程在边界附近跳跃到远处的速率急剧下降，即“边界退化”。
- 函数 `B(x, y)` 的具体形式：`B(x, y) = (x_d ∧ y_d)^β₁ (x_d ∨ y_d)^β₂ (|x - y| + x_d + y_d)^β₃ (|x - y| + |x_d - y_d|)^β₄`，其中 `β₁, β₂, β₃, β₄` 是四个实参数，且满足某些条件以保证过程是保守的（即不会在有限时间内爆炸）。
- 要估的对象：热核 `p(t, x, y)` 的 sharp 双边估计，即找到两个函数 `L(t, x, y)` 和 `U(t, x, y)`，使得 `c₁ L(t, x, y) ≤ p(t, x, y) ≤ c₂ U(t, x, y)`，且 `L` 和 `U` 在定性上相同（相差一个常数因子）。

**可观测数据**：
- 在概率论中，“可观测”的是过程 `X_t` 的样本路径。热核 `p(t, x, y)` 是过程的“转移概率密度”，它本身不是直接观测到的，而是通过过程的分布推断出来的。
- 本文是**纯理论**工作，不涉及任何实际数据或模拟。所有结果都是关于热核的数学性质。

#### 第二步：讲最小内核

**最简特例**：考虑 **d=1** 且 **α=1**（即 Cauchy 过程）的情形。此时上半空间退化为正半轴 `R_+ = (0, ∞)`。跳跃核简化为：
```
J(x, y) = B(x, y) |x - y|^{-2}
```
其中 `B(x, y)` 依赖于参数 `β₁, β₂, β₃, β₄`。为了得到最简情形，进一步假设 `β₃ = β₄ = 0`，则 `B(x, y) = (x ∧ y)^β₁ (x ∨ y)^β₂`。此时，跳跃核在边界 `x=0` 或 `y=0` 处退化为零（如果 `β₁ > 0` 或 `β₂ > 0`）。

**核心思路**：在这个最简特例下，本文要证明的是：热核 `p(t, x, y)` 具有以下形式（以参数区域 `β₁ > 0, β₂ > 0` 为例）：
```
p(t, x, y) ≈ c * t^{-1} * (x ∧ y)^{β₁} * (x ∨ y)^{β₂} * (t + |x - y|)^{-2}
```
其中 `≈` 表示上下界相差一个常数因子。这个形式的关键在于：
- **边界退化效应**：当 `x` 或 `y` 靠近边界（即 `x → 0` 或 `y → 0`）时，热核以 `(x ∧ y)^{β₁}` 的速率衰减到零。这反映了跳跃核在边界处退化导致过程难以从边界附近出发或到达边界附近。
- **与标准 Cauchy 过程的对比**：对于标准 Cauchy 过程（`B ≡ 1`），热核为 `p(t, x, y) ≈ c * t * (t² + |x - y|²)^{-1}`。本文的热核形式在定性上完全不同——它多出了因子 `(x ∧ y)^{β₁} (x ∨ y)^{β₂}`，且分母中的 `t²` 被替换为 `t`（因为 `α=1` 时，`t` 的指数为 1）。

**为什么这个特例是“最小内核”**：即使在这个最简特例下，证明仍然需要处理两个核心困难：
1. **边界退化导致标准方法失效**：传统的“热核迭代”方法依赖于跳跃核的全局下界，而边界退化使得这个下界在边界附近消失。
2. **热核形式的新颖性**：本文发现的热核形式（特别是因子 `(x ∧ y)^{β₁} (x ∨ y)^{β₂}`）在已知文献中从未出现过，因此需要全新的分析技术。

**本文的关键想法**：通过“近似分解性质”将热核分解为“边界附近”和“内部”两部分，分别处理。具体来说，作者证明了热核可以近似表示为：
```
p(t, x, y) ≈ q(t, x, y) * φ(x) * φ(y)
```
其中 `q(t, x, y)` 是某个“无退化”过程的热核，而 `φ(x)` 是一个“边界校正因子”（依赖于 `x_d` 的幂次）。这个分解将边界退化问题转化为“无退化热核”乘以“边界校正因子”的问题，从而可以利用已有的无退化热核估计。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：本文建立了上半空间 `R_+^d` 中两类纯不连续对称 Markov 过程的热核的 sharp 双边估计，其跳跃核 `J(x,y)=B(x,y)|x-y|^{-α-d}` 在边界处退化（即 `B(x,y)` 在边界处为零）。
2. **核心工具/方法**：基于 Dirichlet 型理论、势论分析（特别是“近似分解性质”和“精细的 Green 函数估计”），以及“热核的 Chapman-Kolmogorov 迭代”的变体。
3. **主要结论**：第一类过程（保守过程）的热核估计根据参数区域呈现**三种不同形式**，其中两种在定性上不同于所有已知热核估计；第二类过程（被临界势杀死或边界杀死）的热核具有近似分解性质，生存概率随到边界距离的幂次衰减。

#### 关键设定与假设

**完整设定**：
- **空间**：`R_+^d`（上半空间），其边界为 `∂R_+^d = {x: x_d = 0}`。
- **跳跃核**：`J(x, y) = B(x, y) |x - y|^{-α - d}`，其中 `α ∈ (0, 2)`，且
  ```
  B(x, y) = (x_d ∧ y_d)^{β₁} (x_d ∨ y_d)^{β₂} (|x - y| + x_d + y_d)^{β₃} (|x - y| + |x_d - y_d|)^{β₄}
  ```
  参数 `β₁, β₂, β₃, β₄ ∈ R` 满足：
  - `β₁ + β₂ + β₃ + β₄ > -α`（保证过程是保守的，即不会在有限时间内爆炸）
  - `β₁ + β₂ + β₃ + β₄ < α`（保证过程是“瞬变的”，即不会以概率 1 返回原点）
  - 其他技术条件（如 `β₁ + β₃ > -α` 等）以保证热核估计的有效性。
- **第一类过程**：`R̄_+^d` 上的保守 Markov 过程，其生成元为 `Lf(x) = ∫_{R_+^d} (f(y) - f(x)) J(x, y) dy`。该过程在边界 `∂R_+^d` 处是“反射的”（即过程不会在边界处被杀死）。
- **第二类过程**：上述过程被“临界势” `κ(x) = c_κ x_d^{-α}` 杀死，其中 `c_κ` 是一个正常数。或者，过程在到达边界时被杀死（即 Dirichlet 边界条件）。

**假设**：
- **对称性**：`J(x, y) = J(y, x)`（由 `B(x, y)` 的对称性保证）。
- **退化性**：`B(x, y)` 在边界处为零（当 `x_d → 0` 或 `y_d → 0` 时，`B(x, y) → 0`）。
- **正则性**：`B(x, y)` 是 Hölder 连续的（技术性假设，用于热核的局部估计）。

**与已有文献的对比**：
- **放宽**：本文是第一个处理边界退化情形的，而此前所有工作都假设跳跃核在边界处非退化（即 `B(x, y)` 在边界处有正下界）。
- **强化**：本文对参数 `β₁, β₂, β₃, β₄` 施加了比内部退化情形更严格的条件（如 `β₁ + β₃ > -α`），以保证热核估计的有效性。

#### 主要结果

**定理 1（第一类过程的热核估计）**：对于第一类保守过程，热核 `p(t, x, y)` 满足 sharp 双边估计。根据参数区域，估计有三种不同形式：

1. **区域 I**（`β₁ + β₃ > 0` 且 `β₂ + β₄ > 0`）：
   ```
   p(t, x, y) ≈ c * t^{-d/α} * (x_d ∧ y_d)^{β₁ + β₃} * (x_d ∨ y_d)^{β₂ + β₄} * (t^{1/α} + |x - y|)^{-α - d - β₁ - β₂ - β₃ - β₄}
   ```
   **直觉**：热核在边界附近以 `(x_d)^{β₁ + β₃}` 的速率衰减。这是“标准”的退化形式，与内部退化情形类似。

2. **区域 II**（`β₁ + β₃ < 0` 且 `β₂ + β₄ > 0`）：
   ```
   p(t, x, y) ≈ c * t^{-d/α} * (x_d ∧ y_d)^{β₁ + β₃} * (x_d ∨ y_d)^{β₂ + β₄} * (t^{1/α} + |x - y|)^{-α - d - β₁ - β₂ - β₃ - β₄}
   ```
   **直觉**：形式上与区域 I 相同，但 `β₁ + β₃ < 0` 意味着热核在边界附近**发散**（即 `(x_d)^{β₁ + β₃} → ∞` 当 `x_d → 0`）。这是**全新的现象**——在已知文献中，热核在边界附近总是衰减的，从未出现过发散的情形。

3. **区域 III**（`β₁ + β₃ > 0` 且 `β₂ + β₄ < 0`）：
   ```
   p(t, x, y) ≈ c * t^{-d/α} * (x_d ∧ y_d)^{β₁ + β₃} * (x_d ∨ y_d)^{β₂ + β₄} * (t^{1/α} + |x - y|)^{-α - d - β₁ - β₂ - β₃ - β₄}
   ```
   **直觉**：形式上与区域 I 相同，但 `β₂ + β₄ < 0` 意味着热核在“远离边界”的点处发散（即 `(x_d)^{β₂ + β₄} → ∞` 当 `x_d → ∞`）。这也是**全新的现象**。

**定理 2（第二类过程的热核估计）**：对于被临界势 `κ(x) = c_κ x_d^{-α}` 杀死的过程，其热核 `p^κ(t, x, y)` 满足：
```
p^κ(t, x, y) ≈ c * p(t, x, y) * (x_d / t^{1/α})^{γ} * (y_d / t^{1/α})^{γ}
```
其中 `γ = (α - β₁ - β₂ - β₃ - β₄)/2 - √((α - β₁ - β₂ - β₃ - β₄)²/4 - c_κ)`。对于被边界杀死的过程（Dirichlet 热核），其热核 `p^D(t, x, y)` 满足类似形式，但 `γ` 被替换为 `γ_D = (α - β₁ - β₂ - β₃ - β₄)/2`。

**直觉**：第二类过程的热核可以分解为“保守过程的热核”乘以“生存概率因子”。生存概率 `(x_d / t^{1/α})^{γ}` 随到边界距离的幂次衰减，幂次 `γ` 依赖于临界势中的常数 `c_κ`。当 `c_κ = 0`（即无临界势）时，`γ = 0`，退化为保守过程的热核。

#### 证明路线与技术技巧

**整体路线**（3-5 步逻辑主干）：

1. **Step 1: 建立 Green 函数的 sharp 估计**。Green 函数 `G(x, y)` 是热核的时间积分：`G(x, y) = ∫₀^∞ p(t, x, y) dt`。作者首先建立了 Green 函数的 sharp 双边估计，这是热核估计的基础。关键技巧：利用“势论分析”和“精细的 Martin 边界理论”来处理边界退化。

2. **Step 2: 建立“近似分解性质”**。作者证明了热核可以近似分解为：
   ```
   p(t, x, y) ≈ q(t, x, y) * φ(x) * φ(y)
   ```
   其中 `q(t, x, y)` 是某个“无退化”过程的热核（即跳跃核在边界处非退化），而 `φ(x) = x_d^{γ}` 是一个幂函数。这个分解将边界退化问题转化为“无退化热核”乘以“边界校正因子”的问题。关键技巧：利用“热核的 Chapman-Kolmogorov 迭代”和“Green 函数的乘积分解”。

3. **Step 3: 建立无退化热核的估计**。对于“无退化”过程（即 `B(x, y)` 在边界处有正下界），作者利用已有的结果（如 Chen 和 Kumagai 的经典工作）得到 `q(t, x, y)` 的 sharp 估计。

4. **Step 4: 结合 Step 2 和 Step 3，得到第一类过程的热核估计**。将 `q(t, x, y)` 的估计代入近似分解，得到 `p(t, x, y)` 的 sharp 估计。根据参数 `β₁, β₂, β₃, β₄` 的不同，`φ(x)` 的形式不同，导致三种不同的热核形式。

5. **Step 5: 处理第二类过程**。对于被临界势杀死的过程，作者利用“Feynman-Kac 公式”将热核表示为：
   ```
   p^κ(t, x, y) = p(t, x, y) * E[exp(-∫₀^t κ(X_s) ds) | X_0 = x, X_t = y]
   ```
   然后利用“精细的势论分析”估计条件期望，得到 `p^κ(t, x, y)` 的近似分解。对于被边界杀死的过程，利用“Dirichlet 热核”与“Green 函数”的关系得到类似结果。

**关键跳跃点**：
- **最吃功夫的引理**：Lemma 3.5（Green 函数的乘积分解）。这个引理证明了 Green 函数可以分解为 `G(x, y) ≈ c * (x_d ∧ y_d)^{γ₁} * (x_d ∨ y_d)^{γ₂} * |x - y|^{-α - d + γ₁ + γ₂}`。这个分解是后续所有结果的基础，其证明需要处理边界退化带来的技术困难。
- **难点**：边界退化导致 Green 函数在边界附近的行为变得复杂，标准的方法（如“热核的 Chapman-Kolmogorov 迭代”）无法直接应用。作者通过引入“加权 Sobolev 空间”和“精细的势论分析”绕过了这个困难。

**技术技巧点名**：
- **Dirichlet 型理论**：用于建立 Markov 过程与 Dirichlet 型（一种二次型）之间的对应关系，从而将概率问题转化为分析问题。
- **势论分析**：特别是“Martin 边界理论”和“Green 函数的乘积分解”，用于处理边界退化。
- **热核的 Chapman-Kolmogorov 迭代**：用于从 Green 函数估计推导热核估计。作者使用了该方法的变体，以适应边界退化。
- **Feynman-Kac 公式**：用于将“被临界势杀死的过程”的热核表示为“保守过程的热核”乘以一个条件期望。
- **精细的 Hölder 估计**：用于处理 `B(x, y)` 的 Hölder 连续性假设。

#### 🔎 结论是否比证明窄

- **结论与证明基本匹配**。作者在定理陈述中明确给出了参数条件（如 `β₁ + β₃ > 0` 等），这些条件在证明中被严格使用。
- **一处可能的“泛化 claim”**：作者在引言中声称“我们的结果是首次得到跳跃核在边界退化的非局部算子热核的 sharp 双边估计”。这个 claim 是准确的，因为该问题此前确实未被研究过。但作者没有讨论“更一般的退化形式”（如 `B(x, y)` 在边界处以非幂律形式退化），因此结论不能直接推广到非幂律退化情形。

### 四、开放问题（点到为止，扎根具体语句）

1. **边界情形（等式）的热核估计**：当 `β₁ + β₃ = 0` 或 `β₂ + β₄ = 0` 时，热核估计是否具有“对数修正”形式？作者在定理 1 的陈述中排除了这些边界情形（要求严格不等式），并在 Remark 1.2 中提到了这个开放问题。

2. **非幂律退化**：本文假设 `B(x, y)` 在边界处以幂律形式退化（即 `(x_d)^{β}`）。如果退化形式是非幂律的（如指数衰减 `exp(-1/x_d)`），热核估计会是什么形式？作者在引言中没有讨论这种可能性。

3. **高维边界结构**：本文只处理了“平坦边界”（上半空间）。对于“弯曲边界”（如光滑有界区域），热核估计是否具有类似形式？作者在引言中提到了“有界区域”是未来工作，但未给出具体结果。

4. **临界势的精确常数**：对于被临界势杀死的过程，生存概率的幂次 `γ` 依赖于 `c_κ`。当 `c_κ` 取某些特殊值时（如 `c_κ = (α - β₁ - β₂ - β₃ - β₄)²/4`），`γ` 变为零，此时热核估计是否退化？作者在定理 2 中假设 `c_κ` 小于这个临界值，但未讨论临界情形。
