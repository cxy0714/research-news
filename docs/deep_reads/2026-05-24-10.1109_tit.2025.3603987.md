### 一、领域脉络与小综述

#### 这个方向是什么

本文所处的子方向是**高维稀疏线性回归中的非凸迭代算法**，其根本的统计问题是：在 p ≫ n 的设定下，如何设计一个计算上可行（多项式时间）的算法，使其估计误差达到（或超越）经典的 minimax 下界，同时具备对未知稀疏度 s\* 和信号强度的自适应能力。该方向的成熟度较高——从早期的压缩感知（compressed sensing）理论，到后来的统计-计算折中（statistical-computational tradeoff）研究，已有大量工作。但本文指出一个关键缺口：**经典的 HTP 算法在理论上能否同时达到 oracle 估计率、精确支持恢复、以及无需先验知识的全自适应，此前并未被完整回答。**

#### 发展脉络（history）

- **奠基工作：NP-hardness 与凸松弛的兴起。** 问题 (1) 的 ℓ0 约束最小二乘被 Natarajan (1995) 证明为 NP-hard，这直接催生了 LASSO (Tibshirani, 1996) 和 SLOPE (Bogdan et al., 2015) 等凸松弛方法。这些方法在 RIP 或受限特征值条件下达到 minimax 率 σ{s\* log(p/s\*)/n}^{1/2}（Bickel et al., 2009; Bellec et al., 2018），但作者明确指出其固有缺陷："convex algorithms can only achieve the original minimax optimal rate when the beta-min condition holds"——即凸方法无法利用信号强度的先验信息突破 minimax 率。

- **主要进展：非凸算法的理论保证。** IHT (Blumensath and Davies, 2009) 和 HTP (Foucart, 2011) 作为 ℓ0 问题的贪心/投影算法被提出。Jain et al. (2014) 证明了 IHT 在 RIP 条件下的 minimax 最优性（含对数因子）。Yuan et al. (2018) 和 Huang et al. (2018) 分别分析了 HTP 在 s = s\* 和 s ≥ s\* 情形下的 ℓ2 与 ℓ∞ 误差界。但这些工作的共同局限是：**要么假设稀疏度 s 已知，要么需要更强的 beta-min 条件，且未给出 oracle 率。**

- **当前 frontier：自适应与精确恢复。** 作者引用了两条前沿线索。其一是 Ndaoud (2019, 2020) 的工作：在 beta-min 条件 mini∈S\* |β\*\_i| ≥ Cσ{log(p/s\*)/n}^{1/2} 下，minimax 率从 σ{s\* log(p/s\*)/n}^{1/2} 改善为 oracle 率 σ(s\*/n)^{1/2}，且这一改善在凸方法中无法实现（Bellec, 2018 证明了凸估计器的"噪声屏障"）。其二是 Zhu et al. (2020) 和 Yuan and Li (2022) 对 HTP 类方法的分析，但他们需要更强的 beta-min 条件（如 σ{s\* log p log log n/n}^{1/2}）或假设 s\* = O(log p)。

- **本文的位置。** 作者声称（这是他们的 framing）：在仅依赖 RIP 假设的前提下，**首次**证明 HTP 算法在 beta-min 条件 mini∈S\* |β\*\_i| ≥ Cσ(log p/n)^{1/2} 下达到 oracle 率 σ(s\*/n)^{1/2}，并给出一个计算上高效（仅需运行 O(s\_max) 次 HTP）的全自适应调参程序（FAHTP），同时实现精确支持恢复。这一结果将 Ndaoud (2019) 在序列模型中的结论推广到了线性回归，且避开了 Zhu et al. (2020) 和 Yuan and Li (2022) 的更强条件。

#### 子线索聚类

被引文献大致落在三条子线索上：

1. **凸松弛的 minimax 理论**（LASSO, SLOPE, Bickel et al., Bellec et al.）：研究 ℓ1 型方法的估计误差与变量选择一致性，核心工具是 empirical process 和 restricted eigenvalue。已知瓶颈：无法突破 minimax 率，且精确支持恢复需要 irrepresentable 条件（Zhao and Yu, 2006; Wainwright, 2009）。

2. **非凸迭代算法的收敛性**（IHT, HTP, Zhu et al., Yuan and Li）：研究贪心类算法的迭代动态与统计误差。已知瓶颈：要么需要已知 s，要么 beta-min 条件过强，且缺乏对自适应调参的理论保证。

3. **序列模型中的自适应与 oracle 率**（Ndaoud, Butucea et al., Johnstone）：在 Gaussian sequence model 中刻画了 beta-min 条件下的 minimax 率相变现象，证明了 oracle 率的可达性。本文的核心贡献是将这一结论从序列模型推广到 RIP 设计下的线性回归。

#### 这个方向在追问的核心问题

1. **何时能突破 minimax 率？** 在 beta-min 条件下，估计误差能否从 σ{s\* log(p/s\*)/n}^{1/2} 改善为 σ(s\*/n)^{1/2}？Ndaoud (2019) 给出了序列模型的答案，本文将其推广到线性回归。
2. **非凸算法能否自适应？** 能否在不预先知道 s\* 和 σ 的情况下，通过数据驱动的方式选择模型大小，同时保持 minimax 或 oracle 最优性？
3. **精确支持恢复需要什么条件？** 在 RIP 而非 irrepresentable 条件下，能否实现精确支持恢复？本文的答案是肯定的，但需要 beta-min 条件。

#### ⚠️ 作者的 framing

作者将缺口 frame 为："**HTP 算法在最优 beta-min 条件下能否同时达到 oracle 估计率、精确支持恢复、以及全自适应？**" 他们声称这是"显然的下一步"，因为：(i) Ndaoud (2019) 已证明序列模型中 oracle 率可达；(ii) HTP 的迭代动态分析（Proposition 1）显示其能"检测"大信号并"收缩"小信号；(iii) 信息准则 (4) 已被 Verzelen (2012) 证明在穷举搜索下是 minimax 自适应的。作者将这三块拼在一起，声称得到完整答案。

**被淡化或回避的竞争路线**：
- **凸方法（LASSO/SLOPE）**：作者引用 Bellec (2018) 的"噪声屏障"结果，暗示凸方法在 beta-min 条件下无法达到 oracle 率，因此 HTP 的优越性是本质的。但作者没有讨论**去偏 LASSO（debiased LASSO）**或**凸的 ℓ1 自适应方法**（如 adaptive Lasso）在 beta-min 条件下是否也能达到类似效果。
- **其他非凸方法**：作者没有与 **IHT 的变体**（如 GraHTP, CoSaMP）或 **ℓ0 正则化的局部最优解**（如 SCAD/MCP 的 oracle 性质）进行系统比较。SCAD/MCP 在 Fan and Li (2001) 和 Zhang (2010) 中已被证明具有 oracle 性质，但需要较强的正则条件。
- **计算复杂性**：作者声称 FAHTP 只需运行 O(s\_max) 次 HTP，但**没有讨论每次 HTP 的迭代复杂度**，也没有与凸方法（如坐标下降）的计算成本进行对比。

**值得研究者去查的问题**：
- Bellec (2018) 的"噪声屏障"结果是否适用于所有凸估计器？还是仅适用于 ℓ1 型惩罚？如果存在凸方法能突破 minimax 率，本文的"非凸优越性"论点就会被削弱。
- 本文的 beta-min 条件 mini∈S\* |β\*\_i| ≥ Cσ(log p/n)^{1/2} 与 Ndaoud (2019) 中的条件 mini∈S\* |β\*\_i| ≥ Cσ{log(p/s\*)/n}^{1/2} 相比，哪个更弱？作者声称"最优"，但需要对照 Ndaoud (2019) 的下界证明来核实。

#### 张力

未见明显对立引用。但存在一个微妙的张力：作者声称 HTP 在 beta-min 条件下达到 oracle 率，而凸方法（LASSO）在相同条件下只能达到 minimax 率。然而，**Bellec et al. (2018)** 的 SLOPE 论文表明，SLOPE 在某些稀疏设定下可以达到自适应 minimax 率（含 log 因子），且不需要已知 s\*。作者没有直接回应 SLOPE 的自适应性质是否与本文的 FAHTP 可比。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

- **模型**：线性回归 y = Xβ\* + ξ，其中 y ∈ Rⁿ 是响应向量，X ∈ Rⁿˣᵖ 是设计矩阵，β\* ∈ Rᵖ 是未知系数向量，ξ ∈ Rⁿ 是次高斯随机误差（次高斯参数 σ）。
- **稀疏性**：β\* 是 s\*-稀疏的，即支撑集 S\* = {i : β\*\_i ≠ 0} 的基数 |S\*| = s\* ≪ n。
- **可观测数据**：(y, X) 是研究者实际能观测到的。**不可观测**的是：真实系数 β\*、支撑集 S\*、稀疏度 s\*、噪声水平 σ。
- **目标量（estimand）**：
  - 估计误差：∥β̂ − β\*∥₂
  - 支撑恢复：Ŝ 与 S\* 的一致性（精确恢复意味着 Ŝ = S\*）
  - 自适应：在 s\* 和 σ 未知的情况下达到上述目标的最优率
- **关键假设**：
  - **RIP(s, δ\_s)**：对所有 |S| ≤ s 的集合 S，有 (1 − δ\_s)∥u∥₂² ≤ ∥X\_S u∥₂²/n ≤ (1 + δ\_s)∥u∥₂²。这是本文唯一的实质性设计假设，用于控制设计矩阵的"近等距"性质。
  - **次高斯误差**：ξ\_i 独立同分布，E[ξ\_i] = 0，且 P(|ξ\_i| > t) ≤ 2 exp(−t²/(2σ²))。
  - **beta-min 条件**：mini∈S\* |β\*\_i| ≥ λ，其中 λ 的阈值在 Theorem 3 中给出（λ ≥ (1+3ε)σ{2 log(p/s\*)/n}^{1/2} 或 λ ≥ (2+2ε)σ(2 log p/n)^{1/2}，取决于具体结论）。
- **算法**：HTP（Algorithm 1）——迭代执行梯度下降 + 硬阈值投影 + 最小二乘去偏。FAHTP（Algorithm 2）——沿 s = 1, ..., s\_max 运行 HTP，用信息准则 (4) 选择最优模型大小。

#### 第二步：最小内核

**最小内核**：考虑一个**理想化的两阶段问题**，它剥离了 HTP 的迭代复杂性，只保留其核心机制——"先检测大信号，再精估计"。

**设定**：假设我们已知一个"候选支撑集" Ŝ，且 |Ŝ| = s（s 可能大于或小于 s\*）。定义 **oracle 估计量** β̃ = (X\_Ŝᵀ X\_Ŝ)⁻¹ X\_Ŝᵀ y，即在 Ŝ 上的最小二乘投影。

**核心问题**：在什么条件下，β̃ 的估计误差能达到 oracle 率 σ(s\*/n)^{1/2}，而不是 minimax 率 σ{s\* log(p/s\*)/n}^{1/2}？

**答案（本文 Proposition 1 的简化版）**：将 S\* 分为"大信号集" S\*\_1 = {i ∈ S\* : |β\*\_i| ≥ C₁σ(log p/n)^{1/2}} 和"小信号集" S\*\_2 = S\* \ S\*\_1。如果 HTP 的迭代能保证：
1. **检测**：经过 t 次迭代后，Ŝ 包含 S\*\_1 中所有元素（不漏掉大信号）；
2. **排除**：Ŝ 不包含太多假阳性（Ŝ \ S\* 的基数可控）；
3. **收缩**：小信号 S\*\_2 的总能量 ∥β\*\_S\*\_2∥₂ 被硬阈值算子"压"到可忽略水平；

那么估计误差可以分解为：
∥β̂ − β\*∥₂ ≤ C₂σ(|S\*\_1|/n)^{1/2} + C₃∥β\*\_S\*\_2∥₂

**为什么这个分解是关键**：第一项是"大信号"的 oracle 率（与 p 无关），第二项是"小信号"的收缩误差。当 beta-min 条件满足时（即 S\*\_2 为空或足够小），第二项消失，整体达到 oracle 率 σ(s\*/n)^{1/2}。**这就是 HTP 超越凸方法的机制**：凸方法（LASSO）的 ℓ1 惩罚会同时收缩大信号和小信号，导致系统性偏差；而 HTP 的硬阈值操作只保留大信号，对已检测到的信号做无偏的最小二乘估计。

**证明的难点**：如何保证迭代过程中"检测"和"排除"同时成立？这需要控制梯度下降步骤中的统计误差（由噪声 ξ 引起）和优化误差（由 RIP 常数 δ\_3s 引起）的交互。本文的核心技术贡献在于**精确刻画了迭代阈值动态**——即每一步中，大信号如何被保留、小信号如何被压缩、假阳性如何被清除。

**最小内核的数学表述**：在 RIP(3s, δ\_3s) 且 δ\_3s < 0.3478 的条件下，HTP 的迭代映射是一个**收缩映射**（contraction），收缩因子 γ\_3s = 2δ\_3s√((1+δ\_3s)/(1−δ\_3s)) < 1。这个收缩性质保证了优化误差的指数衰减，而统计误差则被控制在 σ(s log(p/s)/n)^{1/2} 的量级。当 s = s\* 且 beta-min 条件满足时，统计误差进一步改善为 σ(s\*/n)^{1/2}。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：在高维线性回归中，经典的 HTP 算法能否在仅依赖 RIP 假设的条件下，同时达到 oracle 估计率 σ(s\*/n)^{1/2}、精确支持恢复、以及对未知稀疏度和信号强度的全自适应？
2. **核心工具/方法**：提出了全自适应 HTP（FAHTP）算法，通过信息准则 (4) 选择模型大小，并利用 HTP 的迭代阈值动态分析（Proposition 1）证明其理论性质。
3. **主要结论**：在 beta-min 条件 mini∈S\* |β\*\_i| ≥ Cσ(log p/n)^{1/2} 下，FAHTP 达到 oracle 估计率并精确恢复支撑集；即使不满足 beta-min 条件，也以高概率达到比经典 minimax 率更紧的误差界。

#### 关键设定与假设

- **RIP(3s, δ\_3s)**：这是本文的核心假设，要求设计矩阵 X 的所有 3s 列子矩阵近似等距。相比 LASSO 分析中常用的 restricted eigenvalue (RE) 条件，RIP 更强但更简洁。作者在 Remark 1 中指出，δ\_3s < 0.3478 即可保证收缩因子 γ\_3s < 1，这比 Huang et al. (2018) 的 δ\_3s < 0.1599 和 Zhu et al. (2020) 的 δ\_3s < 0.1877 更宽松。
- **次高斯误差**：ξ\_i 独立同分布，次高斯参数 σ。这是高维统计的标准假设，用于控制噪声的集中不等式。
- **beta-min 条件**：Theorem 3 要求 λ ≥ (1+3ε)σ{2 log(p/s\*)/n}^{1/2}，Theorem 4 要求 λ ≥ (2+2ε)σ(2 log p/n)^{1/2}。前者是"最优"的（与 Ndaoud (2019) 的下界匹配），后者稍强但允许精确支持恢复。
- **初始估计**：Theorem 3 假设初始估计 β⁰ 是 minimax 最优的，即 ∥β⁰ − β\*∥₂ ≤ C₁σ{s\* log(p/s\*)/n}^{1/2}。这个假设可以通过一次 LASSO 或 HTP 运行实现。
- **与已有文献的比较**：相比 Zhu et al. (2020) 的 s\* log p log log n/n 条件，本文的 beta-min 条件更弱；相比 Yuan and Li (2022) 的 s\* = O(log p) 假设，本文不要求稀疏度有界。

#### 主要结果

- **Theorem 1（ℓ2 误差界）**：对任意 s ≥ s\*，HTP 的迭代误差以概率 1 − C₁exp{−C₂s log(p/s)} 满足 ∥βᵗ − β\*∥₂ ≤ γᵗ\_3s∥β\*∥₂ + 12σ/(1−γ\_3s)·{s log(p/s)/n}^{1/2}。这个结果给出了**非渐近的迭代收敛率**，其中第一项是优化误差（指数衰减），第二项是统计误差（minimax 率）。
- **Theorem 2（minimax 自适应）**：信息准则 (4) 选择的模型大小 ŝ 满足 P(ŝ ≤ 2s\*) ≥ 1 − C₂exp{−C₃s\* log(p/s\*)}，且对应的估计器达到 minimax 率。这是对 Verzelen (2012) 结果的算法化推广。
- **Theorem 3（oracle 率）**：在 beta-min 条件下，FAHTP 的估计误差满足 ∥β̂ − β\*∥₂ ≤ C₂,εσ(s\*/n)^{1/2}，达到 oracle 率。这是本文的核心定理，证明的关键在于**迭代阈值动态的精确刻画**——即大信号在迭代中被保留、小信号被压缩、假阳性被清除。
- **Theorem 4（收敛到 oracle 估计量）**：在更强的 beta-min 条件下，HTP 估计量以高概率收敛到 oracle 最小二乘估计量 β̃\*，误差为 ∥βᵗ − β̃\*∥₂ ≤ (9/10)ᵗC₁,εσ{s\* log p/n}^{1/2} + C₂,εσ{2τ log p/n}^{1/2}（其中 τ = s − s\*）。
- **Corollary 3（精确支持恢复）**：当 s = s\* 且 t ≥ 2log((C₂/ε)²s\*) 时，P(Sᵗ = S\*) → 1（当 s\*/p → 0）。这是对 HTP 支持恢复能力的**首个在最优 beta-min 条件下的证明**。

#### 证明路线与技术技巧

**整体路线**（5 步）：
1. **误差分解**：将迭代误差分解为优化误差（∥βᵗ − β\*∥₂ 中由迭代未收敛引起的部分）和统计误差（由噪声 ξ 引起的部分）。
2. **收缩映射**：利用 RIP(3s, δ\_3s) 证明 HTP 的迭代映射在 ℓ2 范数下是收缩的，收缩因子 γ\_3s < 1。这一步的关键是控制梯度下降步骤中的交叉项。
3. **统计误差控制**：利用次高斯集中不等式，证明统计误差以高概率被 σ{s log(p/s)/n}^{1/2} 控制。这一步的关键是**避免对设计矩阵的列做独立性假设**，仅依赖 RIP。
4. **迭代阈值动态**：这是本文最核心的技术贡献。作者证明，在 beta-min 条件下，硬阈值算子 T\_s 在迭代中扮演"信号检测器"的角色——大信号（|β\*\_i| ≥ Cσ(log p/n)^{1/2}）在一步迭代后被保留，小信号被压缩到阈值以下。这一动态分析使得作者能够**超越传统的 ℓ2 误差界**，得到 oracle 率。
5. **自适应调参**：利用信息准则 (4) 的"模型选择一致性"（Theorem 2），证明 FAHTP 能以高概率选择正确的模型大小，从而在未知 s\* 的情况下达到 oracle 率。

**关键技术技巧**：
- **ℓ∞ 界的桥接**：为了从 ℓ2 误差界推导出支持恢复结果，作者需要 ℓ∞ 误差界。他们通过**连接 oracle 最小二乘估计量**（Theorem 4）来获得 ℓ∞ 界，而不是直接分析迭代过程。
- **概率事件的嵌套**：证明中使用了多个高概率事件的嵌套（如统计误差事件、检测事件、排除事件），通过 union bound 和条件概率控制它们的交集。
- **常数追踪**：作者明确追踪了所有常数（如 C₁,ε, C₂,ε），这使得定理的适用条件（如 n ≥ C₀s\* log(p/s\*)）是显式的。

#### 真实例子与应用

- **模拟实验（Section 5.1–5.3）**：作者设计了三个模拟场景：
  1. **最小信号强度收敛**（图 4）：固定 n=300, p=1000, s\*=10, σ=1，验证 Theorem 5 的预测——当 s = s\* 时，最小信号强度收敛到真值；当 s > s\* 时，最小信号强度低于阈值。
  2. **自适应调参的收益**（图 5）：固定 n=300, p=2000, s\*=30, σ=1，改变最小信号强度 k，比较 FAHTP 与 IC 方法的估计误差、支持恢复和变量选择表现。结果显示，当最小信号强度较大时，FAHTP 显著优于 IC 方法。
  3. **与主流方法对比**（图 6）：固定 p=2000, s\*=30, SNR=10，改变样本量 n 从 300 到 1300，比较 FAHTP 与 LASSO-CV、SCAD-CV、MCP-CV、SCAD-IC、MCP-IC 的估计误差、稀疏度误差和 MCC。结果显示 FAHTP 在样本量较大时达到 oracle 估计器的表现。
- **真实数据（Section 5.4）**：使用一个超市数据集（n=464, p=6398），目标是预测每日顾客数。FAHTP 平均选择 2.33 个变量，测试 MSE 为 0.410，优于所有对比方法。这个例子展示了 FAHTP 在实际应用中的稀疏性和预测精度。

#### 🔎 结论是否比证明窄

**是的，存在几处"证明窄于结论"的地方，值得研究者注意**：

1. **Theorem 3 的初始估计假设**：定理要求初始估计 β⁰ 是 minimax 最优的（∥β⁰ − β\*∥₂ ≤ C₁σ{s\* log(p/s\*)/n}^{1/2}）。但作者在 Algorithm 2 中并未明确说明如何获得这样的初始估计。虽然可以通过一次 LASSO 运行实现，但这引入了额外的调参（LASSO 的惩罚参数），且 LASSO 的 minimax 率需要 RE 条件而非 RIP。**这是一个潜在的逻辑缺口**。

2. **Theorem 4 的"收敛到 oracle"是渐近的**：定理的表述是"以概率 1 − s\*/p 的某个幂次"，但收敛速度依赖于迭代次数 t 和 s\*/p 的比值。作者没有给出**有限样本下的显式迭代次数**，只给出了 t ≥ 2log((C₂/ε)²s\*) 的条件。这意味着在实际应用中，用户需要自行判断迭代是否充分。

3. **Corollary 3 的"精确恢复"是概率性的**：结论是 P(Sᵗ = S\*) → 1 当 s\*/p → 0，但**没有给出收敛速度**。对于有限样本，精确恢复的概率可能远低于 1，特别是当 beta-min 条件接近临界值时。

4. **自适应调参的理论保证不完整**：Theorem 2 证明了 ŝ ≤ 2s\* 的概率界，但**没有证明 ŝ ≥ s\*/2 的下界**（虽然 Theorem 5 的分离性暗示了这一点）。这意味着 FAHTP 可能选择过小的模型，导致漏掉一些真实信号。

5. **RIP 条件的验证问题**：作者假设 X 满足 RIP(3s, δ\_3s)，但**没有讨论如何验证这一条件**。在高维设定下，RIP 常数的计算是 NP-hard 的。虽然随机高斯/次高斯设计以高概率满足 RIP，但实际数据（如超市数据集）是否满足 RIP 并未验证。

### 四、开放问题

以下问题均扎根于本文的具体语句，供研究者自行判断价值：

1. **初始估计的构造**（扎根于 Theorem 3 的假设"Let the initial estimator β⁰ be a minimax optimal estimator"）：如何在不引入额外调参的前提下，构造满足 Theorem 3 条件的初始估计？能否用 HTP 自身的前几次迭代作为初始估计，从而完全消除对 LASSO 的依赖？

2. **自适应调参的下界**（扎根于 Theorem 2 的结论"pr(ŝ ≤ 2s\*) ≥ 1 − C₂exp{−C₃s\* log(p/s\*)}"）：能否证明 ŝ ≥ s\*/2 的概率界？如果 ŝ 可能远小于 s\*，FAHTP 是否会系统性地漏掉弱信号？

3. **RIP 条件的替代**（扎根于 Assumption 2 "Design matrix X satisfies RIP(3s, δ\_3s)"）：本文的分析完全依赖 RIP。能否将结论推广到更弱的 RE 条件或部分相关性条件？这在因果推断和高维工具变量设定中尤为重要。

4. **beta-min 条件的必要性**（扎根于 Theorem 3 的 lambda 阈值）：作者证明了 beta-min 条件是达到 oracle 率的充分条件，但**未证明其必要性**。是否存在比 beta-min 更弱的条件（如"大部分信号足够强"）也能达到 oracle 率？

5. **高阶梯矩的扩展**（扎根于 Theorem 6 的 ℓ2 误差界）：本文只给出了 ℓ2 误差界。能否将迭代阈值动态分析扩展到 ℓ∞ 误差界或逐坐标误差界？这对于变量选择和因果推断中的置信区间构建至关重要。

6. **与因果推断的连接**：本文的 HTP 算法可视为一种"去偏 + 阈值"的估计器。在因果推断中，高维混淆控制（如 double selection 或 post-double-selection）面临类似的"信号检测"问题。能否将 FAHTP 的调参策略应用于因果效应的估计与推断？

7. **计算复杂度的显式刻画**（扎根于 Algorithm 2 的循环结构）：FAHTP 需要运行 O(s\_max) 次 HTP，每次 HTP 的迭代次数为 O(log(s\*))。总计算复杂度为 O(s\_max · log(s\*) · (n + s³))。在 p 极大时，s\_max 可能接近 n，此时计算是否仍然可行？能否设计更高效的路径（如二分搜索或 warm-start）？
