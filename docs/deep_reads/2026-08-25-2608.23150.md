### 一、领域脉络与小综述

#### 这个方向是什么
本文研究的核心问题是：**在非参数统计中，图拉普拉斯算子（Graph Laplacian）谱的方差控制，能否像经典非参数估计（如核密度估计）一样，仅依赖于数据生成测度的最弱正则性（如测度的有界性），而不依赖于被估计对象（如密度、流形）的光滑性？** 具体而言，给定来自概率测度 µ 的 n 个 i.i.d. 样本，在固定带宽 h > 0 下，比较经验加权拉普拉斯算子 ∆_{µ_n}^h 的特征值与总体版本 ∆_µ^h 的特征值。该方向当前成熟度：在流形假设（µ 在 d 维紧流形上有 C^{2+ε} 密度）下，已有最优收敛速率 n^{-2/(d+4)} 的结果 [GTLV25]，但方差项的控制依赖于流形几何与密度光滑性。本文试图将方差控制推广到几乎无正则性假设的极弱条件下。

#### 发展脉络（history）
- **奠基工作**：Belkin & Niyogi [BN03, BN06] 和 Coifman & Lafon [CL06] 开创了图拉普拉斯在流形学习中的应用，建立了当 h→0 时 ∆_{µ_n}^{K_h} 收敛到流形上加权拉普拉斯算子的框架。但早期工作主要关注点态收敛，缺乏谱收敛的定量速率。
- **主要进展**：García Trillos, Gerlach, Hein & Slepčev [GTGHS20] 通过最优传输变分分析，首次给出了谱收敛的定量误差界。Calder & García Trillos [CT22] 和 Cheng & Wu [CW22] 分别对 ε-图和 k-NN 图建立了收敛速率。Wahl [Wah24] 给出了核方法的分析。
- **当前 frontier**：García Trillos, Li & Venkatraman [GTLV25] 在流形假设下（µ 有 C^{2+ε} 密度）建立了谱收敛的 minimax 速率 n^{-2/(d+4)}，并引入了多尺度 Poincaré 不等式作为核心工具。但该结果要求流形结构和密度光滑性，且存在对数因子。
- **本文位置**：Divol 将 [GTLV25] 的方差控制从流形推广到**粗 PI 测度**（coarse PI measures）类——一个包含度量图、有规则边界/角点/分支点的空间、以及这些空间在 O(h) 尺度上的离散化或加厚的极广类。核心贡献是：方差项 1/√(n v_µ(h)) 的界仅需测度属于粗 PI 类，无需任何光滑性或流形结构；即使在流形上，也去掉了 [GTLV25] 中的对数因子。本文还借鉴了 Burago, Ivanov & Kurylev [BIK19] 的相对 Prokhorov 扰动框架，但将确定性扰动替换为随机扰动，从而利用浓度不等式获得更紧的界。

#### 子线索聚类
1. **流形假设下的谱收敛**：以 [GTLV25] 为代表，假设 µ 在 d 维流形上有光滑密度，利用 Riemann 几何工具，获得 minimax 最优速率。瓶颈：需要流形结构和密度光滑性。
2. **一般度量空间上的谱稳定性**：以 [BIK19] 为代表，研究任意扰动 ν 下 ∆_µ^h 谱的稳定性，使用最优传输和相对 Prokhorov 距离。优点：适用于一般度量空间；缺点：确定性扰动界太粗糙，无法得到随机样本下的最优速率。
3. **粗 PI 测度与多尺度分析**：本文开创的路线，将 [GTLV25] 的多尺度 Poincaré 不等式从流形推广到粗 PI 类，并利用 Auscher, Hytönen & Tapiola [AH13, HT14] 的几乎 Lipschitz 样条系统替代 dyadic cubes，简化了证明。核心工具：粗 PI 测度的稳定性（在相对 Prokhorov 扰动下封闭）、多尺度 Poincaré 不等式、V-统计量的浓度不等式。

#### 这个方向在追问的核心问题
1. **方差控制的最小正则性条件是什么？** 经典非参数统计中，方差仅需测度有界即可控制。图拉普拉斯谱的方差是否也有类似性质？本文回答：是的，只需测度属于粗 PI 类。
2. **谱收敛的 minimax 速率是什么？** 在流形上，[GTLV25] 得到 n^{-2/(d+4)}。本文的方差界 1/√(n v_µ(h)) 在 v_µ(h) ≍ h^d 时也是该速率（但无对数因子）。作者猜想在粗 PI 类上该速率是 minimax 的（Remark 1.5）。
3. **如何构造可检验的“弱流形假设”？** 粗 PI 类在采样下稳定（Theorem 2.12），意味着可以通过检验经验测度 µ_n 是否属于粗 PI 类来检验 µ 是否属于该类，这为可操作的几何假设检验提供了第一步。

#### ⚠️ 作者的 framing
- **作者把缺口 frame 成**：现有谱收敛结果（如 [GTLV25]）的方差控制依赖于流形几何和密度光滑性，但方差本质上应“盲于”被估计对象的正则性。因此，需要将方差控制推广到极弱正则性条件，并引入粗 PI 测度类作为“正确的”工作空间。
- **被淡化或回避的竞争路线**：作者明确提到“本文的分析也可用 (1.3) 形式的核进行，但技术更简单”（Remark 1.2），但他选择了 (1.7) 的归一化核，因为后者对维度 d 不敏感。这回避了非归一化核下的技术细节。此外，作者未深入讨论与 [GTLV25] 中多尺度 Poincaré 不等式在流形上的具体差异，而是直接声称样条系统简化了证明。
- **什么明显该被引/该存在、却没出现在 intro 里？** 作者未引用 Koltchinskii & Lounici [KL17] 关于经验协方差算子谱的相对扰动界，尽管该工作与本文的“相对误差界”精神一致（本文引用了 Jirak & Wahl [JW20, JW23] 作为替代）。此外，关于“统计-计算权衡”的文献（如低度多项式障碍）完全未被提及，但本文的粗 PI 类稳定性可能为计算可行性提供新视角。

#### 张力
未见明显对立引用。所有被引工作基本一致认为：在流形假设下，谱收敛速率由偏-方差权衡决定；本文则声称方差项可在极弱条件下控制，与已有结果互补而非矛盾。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：把符号、模型、可观测数据交代清楚

- **符号**：
  - (X, ρ)：Polish 度量空间（完备可分度量空间），X 是空间，ρ 是距离。
  - µ：X 上的 Borel 概率测度（数据生成分布）。
  - X₁, …, Xₙ：来自 µ 的 i.i.d. 样本。
  - µₙ = (1/n) Σᵢ δ_{Xᵢ}：经验测度。
  - h > 0：固定带宽（不随 n 变化）。
  - η: [0, +∞) → [0, +∞)：有界可测函数，满足条件 (N)：连续、支撑在 [0,1]、∥η∥_∞ ≤ 1、在 [0,1/2] 上 η ≥ 1/2。
  - K_h^µ(x, y) = h^{-2} η(ρ(x,y)/h) / √(η_µ^h(x) η_µ^h(y))，其中 η_µ^h(x) = ∫ η(ρ(x,z)/h) dµ(z)。这是归一化核（Coifman-Lafon α=1/2 归一化）。
  - ∆_µ^h：作用于 L²(µ) 的加权拉普拉斯算子：(∆_µ^h u)(x) = 2 ∫ K_h^µ(x, y)(u(y) - u(x)) dµ(y)。
  - -∆_µ^h 是非负自伴算子，其谱包含在 [0, +∞) 中。
  - λ_ℓ(µ, K_h^µ)：-∆_µ^h 的第 ℓ 个特征值（按升序排列，λ₀ = 0 当且仅当存在非平凡常数函数）。
  - v_µ(h) = inf_{x∈X} µ(B(x, h))：半径为 h 的球的最小质量。
  - 粗 PI 测度类 PI_r(C_D, C_PI, κ)：满足粗加倍性质（DM_r）和粗 Poincaré 不等式的测度类（定义见 (1.4)-(1.5)）。

- **模型**：数据生成机制为 X₁, …, Xₙ ~ i.i.d. µ。µ 是未知的，但假设属于粗 PI 类 PI_{βh}(C_D, C_PI, κ)（β 是某个依赖于 C_D 的常数）。核 K_h^µ 依赖于 µ 本身（通过 η_µ^h），因此是“数据自适应”的。目标：估计 -∆_µ^h 的特征值 λ_ℓ(µ, K_h^µ)。

- **可观测数据**：研究者实际能观测到的是样本 X₁, …, Xₙ，以及由此构造的经验测度 µₙ 和经验核 K_h^{µₙ}。经验拉普拉斯算子 ∆_{µₙ}^h 是作用于 L²(µₙ) 的矩阵（即图拉普拉斯矩阵）。**想要但观测不到**的是总体拉普拉斯算子 ∆_µ^h 及其特征值 λ_ℓ(µ, K_h^µ)。识别依赖于：µₙ 是 µ 的随机近似，且粗 PI 类在采样下稳定（Theorem 2.12），使得 µₙ 也属于粗 PI 类。

#### 第二步：讲最小内核

**最简特例**：假设 X = [0,1]（一维区间），ρ 为欧氏距离，µ 为 Lebesgue 测度（均匀分布）。此时 v_µ(h) = 2h（因为最小球质量在端点处为 h）。核取最简单的形式：η(t) = 1_{[0,1]}(t)（指示函数），但为了满足连续性条件 (N)，可近似为连续函数。归一化核 K_h^µ(x, y) = h^{-2} 1_{|x-y|≤h} / √(η_µ^h(x) η_µ^h(y))，其中 η_µ^h(x) = µ(B(x, h)) = 2h（内部点）或 h（端点附近）。

在这个特例下，总体算子 -∆_µ^h 的特征值 λ_ℓ(µ, K_h^µ) 是某个积分算子的特征值。经验算子 -∆_{µₙ}^h 是 n×n 矩阵，其元素为 K_h^{µₙ}(X_i, X_j)。**要证明的核心命题**：对于 ℓ 满足 λ_ℓ(µ, K_h^µ) ≲ h^{-2} 且特征值间隔 ≥ γ λ_ℓ，有
E[(λ_ℓ(µₙ, K_h^{µₙ}) - λ_ℓ(µ, K_h^µ))²] ≤ C (λ_ℓ)² (1 + C_PI) / (n v_µ(h)) = C (λ_ℓ)² / (n h)。

**证明思路（特例下的简化）**：
1. **相对扰动框架**：将特征值误差转化为对特征函数 φ 的残差 v = (∆_µ^h - ∆_{µₙ}^h)φ 在负 Sobolev 范数 ∥·∥_{H^{-1}_{h,s}(µₙ)} 下的控制（Lemma 6.1-6.3）。关键：用负范数代替 L² 范数，因为残差的高频部分被阻尼。
2. **多尺度 Poincaré 不等式**：在粗 PI 测度 µₙ 上，将负范数分解为多尺度投影的和（Proposition 4.4）：
   ∥v∥_{H^{-1}_{h,s}(µₙ)} ≤ C [ h∥v∥_{L²(µₙ)} + Σⱼ min(δʲ, s^{-1/2}) ∥Π_{j,µₙ} v∥_{L²(µₙ)} ]。
   其中 Π_{j,µₙ} 是到样条空间 Vⱼ 上的正交投影。
3. **V-统计量浓度**：投影系数 ⟨v, sⱼₖ⟩_{µₙ} 是 V-统计量（二阶 U-统计量），其方差可通过 Proposition 5.2 控制。关键：利用核 K_h^µ 的局部性和特征函数 φ 的几乎 Lipschitz 性质（Lemma 6.6），得到方差上界为 O(1/(n v_µ(h)))。
4. **求和**：将多尺度分解中的项求和，利用 v_µ(δʲ) 的粗增长性质（Lemma 2.6），得到最终界。

**为什么这个特例抓住了核心困难**：即使在一维均匀分布下，经验核 K_h^{µₙ} 依赖于 µₙ 而非 µ，导致 ∆_{µₙ}^h 与 ∆_µ^h 的差异包含两部分：测度替换（µ→µₙ）和核替换（K_h^µ→K_h^{µₙ}）。后者需要额外的浓度控制（Lemma 6.10）。此外，特征函数 φ 的几乎 Lipschitz 性质（Lemma 6.6）是连接 V-统计量方差与 Dirichlet 能量的关键，该性质在一般粗 PI 测度下仍成立（通过粗 Poincaré 不等式和路径论证）。

### 三、这篇论文做了什么

#### 三句话
1. **研究了什么问题**：在固定带宽 h > 0 下，给定 n 个 i.i.d. 样本，比较经验加权拉普拉斯算子 ∆_{µₙ}^h 与总体版本 ∆_µ^h 的特征值，建立相对误差界。
2. **核心工具/方法**：引入粗 PI 测度类（coarse PI measures），利用多尺度 Poincaré 不等式（基于几乎 Lipschitz 样条系统）和 V-统计量浓度不等式，将特征值稳定性转化为对残差的负 Sobolev 范数控制。
3. **主要结论**：若 µ 属于粗 PI 类 PI_{βh}(C_D, C_PI, κ)，且 n v_µ(h) ≥ C₁ log n，则对于满足间隔条件 min_{k≠ℓ} |λ_k^h - λ_ℓ^h| ≥ γ λ_ℓ^h 且 λ_ℓ^h ≲ h^{-2} 的特征值，有 E[(λ_ℓ^h(µₙ) - λ_ℓ^h(µ))²] ≤ C₀ (λ_ℓ^h)² (1 + C_PI) / (n v_µ(h))。

#### 关键设定与假设
- **粗 PI 测度类 PI_r(C_D, C_PI, κ)**：由两个条件定义：
  1. **粗加倍性质 (DM_r)**：∀x∈X, ∀t≥r, µ(B(x, t)) ≤ C_D µ(B(x, t/2))。这是经典加倍性质的“粗”版本，只要求半径 ≥ r 的球满足加倍。
  2. **粗 Poincaré 不等式**：∀x∈X, ∀t≥r, ∀u, ∫_B |u - u_B|² dµ ≤ C_PI t² ∫_{κB} (Lip_{µ,r}[u])² dµ，其中 Lip_{µ,r}[u](x) = ess sup_{y∈B(x,r)} |u(x)-u(y)|/r。这是经典 Poincaré 不等式的“粗”版本，用粗 Lipschitz 常数代替梯度。
  - **相比已有文献**：经典 PI 空间（r=0）要求所有尺度下的加倍和 Poincaré 不等式，而粗 PI 类只要求 ≥ r 的尺度，因此包含度量图、有角点/分支点的空间等非流形结构。这是本文的核心创新：将谱收敛的方差控制从流形推广到这些奇异空间。
- **核条件 (N)**：η 连续、支撑在 [0,1]、∥η∥_∞ ≤ 1、在 [0,1/2] 上 η ≥ 1/2。这些条件保证核的局部性和正性。
- **特征值间隔条件**：min_{k≠ℓ} |λ_k^h - λ_ℓ^h| ≥ γ λ_ℓ^h。这是相对扰动理论的标准条件，确保特征值可区分。
- **样本量条件**：n v_µ(h) ≥ C₁ log n。这保证每个半径为 h 的球至少包含一个样本点，避免零特征值的多重性破坏稳定性。

#### 主要结果
- **Theorem 1.3（主定理）**：在上述假设下，简单特征值的相对误差界为 O(1/√(n v_µ(h)))。当 v_µ(h) ≍ h^d 时，该界为 O(1/√(n h^d))，与 [GTLV25] 的方差项一致但去掉了对数因子。**关键改进**：该界不要求 µ 有密度，更不要求光滑性；即使在流形上，也仅需密度有界远离 0 和 ∞。
- **Theorem 6.12（特征函数收敛）**：在相同条件下，特征函数在 ˙H¹_h(µₙ) 范数和 L²(µₙ) 范数下也有相同的收敛速率。作者指出 L² 范数下的速率可能次优（应为 h/√(n v_µ(h))），但需要额外结构。
- **Corollary 2.12（粗 PI 类的采样稳定性）**：若 µ ∈ PI_r，则以高概率 µₙ ∈ PI_{3r}。这是将理论从 µ 推广到 µₙ 的关键桥梁。

#### 证明路线与技术技巧

**整体路线**（3-5 步逻辑主干）：
1. **相对扰动框架**（Section 6）：将特征值误差转化为对残差 v = (∆_µ^h - ∆_{µₙ}^h)φ 在负 Sobolev 范数 ∥·∥_{H^{-1}_{h,s}(µₙ)} 下的控制。利用 Lemma 6.1-6.3，将特征值误差与残差的负范数联系起来。
2. **多尺度 Poincaré 不等式**（Section 4）：在粗 PI 测度 µₙ 上，建立负范数的多尺度分解（Proposition 4.4）：
   ∥v∥_{H^{-1}_{h,s}(µₙ)} ≤ C [ h∥v∥_{L²(µₙ)} + Σⱼ min(δʲ, s^{-1/2}) ∥Π_{j,µₙ} v∥_{L²(µₙ)} ]。
   其中 Π_{j,µₙ} 是到样条空间 Vⱼ 上的正交投影。该不等式是 [GTLV25] 中“多尺度 Poincaré 不等式”的推广，但用几乎 Lipschitz 样条系统替代了 dyadic cubes，避免了不连续性带来的技术困难。
3. **V-统计量浓度**（Section 5）：将投影系数 ⟨v, sⱼₖ⟩_{µₙ} 分解为两部分：测度替换（µ→µₙ）和核替换（K_h^µ→K_h^{µₙ}）。前者是二阶 V-统计量，其方差通过 Proposition 5.2 控制；后者通过 Lemma 6.10 控制。关键：利用特征函数 φ 的几乎 Lipschitz 性质（Lemma 6.6）将方差与 Dirichlet 能量 ∥φ∥²_{˙H¹_h(µ)} 联系起来。
4. **求和与概率控制**：将多尺度分解中的项求和，利用粗 PI 测度的粗增长性质（Lemma 2.6）控制 v_µ(δʲ) 的尺度行为。通过 Theorem 2.11 和 Lemma 6.10 控制坏事件的概率，最终得到期望误差界。

**关键跳跃点**：
- **从 L² 范数到负范数**：直接控制 ∥(∆_µ^h - ∆_{µₙ}^h)φ∥_{L²(µₙ)} 会得到 O(1/√(n v_µ(h))) 的界，但该界乘以 h^{-2} 后太粗糙。负范数通过阻尼高频成分，将界改进为 O(λ_ℓ^h / √(n v_µ(h)))。
- **样条系统替代 dyadic cubes**：[GTLV25] 使用 dyadic cubes 导致投影系数不连续，需要 Riemann 几何处理。本文使用 Auscher-Hytönen-Tapiola 的几乎 Lipschitz 样条系统（Appendix C），其连续性使得多尺度 Poincaré 不等式的证明在粗 PI 类上成立。
- **粗 PI 类的采样稳定性**：Theorem 2.10 证明粗 PI 类在相对 Prokhorov 扰动下封闭，而 Theorem 2.11 证明 µₙ 与 µ 以高概率是 (O(h), O(1))-close。两者结合得到 µₙ ∈ PI_{3h}，从而多尺度 Poincaré 不等式可应用于 µₙ。

**技术技巧点名**：
- **几乎 Lipschitz 样条系统**（Appendix C）：基于随机 Voronoi 划分和随机半径，构造满足 Hölder 连续性（指数 ϑ 接近 1）的样条函数。用于多尺度分解，替代 dyadic cubes。
- **相对 Prokhorov 扰动**（Definition 2.7）：允许丢弃少量质量（τ 控制）后再进行最优传输（ε 控制）。比 ∞-Wasserstein 距离更灵活，适用于离散测度 µₙ。
- **V-统计量浓度**（Proposition 5.2）：二阶 V-统计量的方差界，利用核的局部性和特征函数的 Lipschitz 性质，将方差与 Dirichlet 能量联系起来。
- **粗增长性质**（Lemma 2.6）：粗 PI 测度的球质量至少线性增长（v_µ(t)/t ≥ c v_µ(r)/r），这是多尺度求和收敛的关键。

#### 真实例子与应用
本文为纯理论论文，无实证例子。作者在 Remark 1.5 中提到了一个猜想（粗 PI 类上 1/√(n v_µ(h)) 是 minimax 速率），但未给出模拟或数据验证。

#### 🔎 结论是否比证明窄
- **Theorem 1.3 的结论**：要求特征值间隔条件 min_{k≠ℓ} |λ_k^h - λ_ℓ^h| ≥ γ λ_ℓ^h。对于多重特征值，该定理不适用。作者在 Section 6 中仅处理了简单特征值的情况。
- **特征函数收敛的 L² 界**：Theorem 6.12 得到 L²(µₙ) 下的收敛速率为 O(1/√(n v_µ(h)))，但作者明确指出该界可能次优，正确速率应为 O(h/√(n v_µ(h)))（见 Section 1.3 末尾）。该改进需要额外结构（如 X 是 d 维流形），但本文未证明。
- **核的选择**：作者选择了归一化核 (1.7)，并声称非归一化核 (1.3) 也可处理但更简单（Remark 1.2）。然而，归一化核的优点是维度无关，但代价是核本身依赖于 µ，导致额外的浓度项（Lemma 6.10）。对于非归一化核，该浓度项可能消失或更易处理，但作者未展开。

### 四、开放问题

1. **特征函数 L² 收敛的最优速率**：Theorem 6.12 得到 L²(µₙ) 下的速率为 O(1/√(n v_µ(h)))，但作者猜测正确速率为 O(h/√(n v_µ(h)))。该改进需要额外结构（如 X 是 d 维流形），但本文未证明。**扎根点**：Section 1.3 末尾“We expect, however, that such a control is suboptimal with respect to the L²(µₙ)-norm and that the correct rate is of order h/√(n v_µ(h)).”

2. **粗 PI 类上的 minimax 速率**：作者猜想在粗 PI 类上，1/√(n v_µ(h)) 是特征值估计的 minimax 速率，且图拉普拉斯估计量在该类上不可去偏。**扎根点**：Remark 1.5 “We conjecture that such a debiasing method requires some smoothness, and is therefore impossible for a general coarse PI measure, suggesting that the rate 1/√(n v_µ(h)) becomes minimax on this larger class.”

3. **可检验的几何假设检验**：作者提出可以通过检验 µₙ 是否属于粗 PI 类来检验 µ 是否属于该类，但未开发具体算法。**扎根点**：Section 1.2 末尾“We do not develop this here, leaving this problem (and in particular the development of practical algorithms) to further inquiry.”

4. **多重特征值的处理**：Theorem 1.3 仅适用于简单特征值（满足间隔条件）。对于多重特征值或特征值簇，需要不同的扰动分析。**扎根点**：Theorem 1.3 的条件 min_{k≠ℓ} |λ_k^h - λ_ℓ^h| ≥ γ λ_ℓ^h 排除了多重特征值情况。
