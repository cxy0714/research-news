# Bootstrap Inference for Dynamic Panel Data Models with Common Correlated Effects

**作者**: Arturas Juodis, Ovidijus Stauskas, Sander Tromp  
**主题**: 数理统计 / 假设检验  
**相关性**: 6/10  
**链接**: <https://arxiv.org/abs/2609.31442>

---

### 一、领域脉络与小综述

**这个方向是什么**  
本文属于「动态面板数据 + 共同因子（交互固定效应）」下的推断问题。核心场景是：每个截面单元同时受到可观测回归元、滞后因变量、以及不可观测的共同因子（如全球宏观经济冲击）的影响。此时若忽略共同因子，估计会不一致；若用 Pesaran (2006) 的 Common Correlated Effects (CCE) 估计量，用截面平均作为因子代理，则在静态面板中表现良好。但在动态面板中，CCE 估计量会同时遭受两类偏差：一是滞后因变量带来的“Nickell 偏差”（量级约 1/T），二是用截面平均估计因子带来的偏差（量级约 1/N）。本文研究的问题是：在这些偏差存在时，递归设计野 bootstrap（recursive-design wild bootstrap, RD-WB）能否为 CCE 估计量提供有效的推断。

**发展脉络**  
- **奠基工作**：Nickell (1981) 指出动态面板固定效应估计的偏差；Arellano and Bond (1991) 提出 GMM 方法处理小 T 大 N 情形。  
- **共同因子处理**：Pesaran (2006) 提出 CCE 估计量，用被解释变量和解释变量的截面平均来代理不可观测因子；Bai (2009) 与 Moon and Weidner (2015) 发展交互固定效应（interactive fixed effects）的主成分方法。  
- **动态 CCE 的偏差理论**：Juodis et al. (2021) 给出了动态 CCE 估计量的渐近展开，明确指出偏差由“Nickell 偏差”和“因子估计偏差”两部分组成；De Vos and Everaert (2021a) 提出固定 T 下的偏差校正方法；De Vos and Staudkas (2024) 进一步研究了截面平均导致的偏差。  
- **Bootstrap 推断**：Gonçalves and Kaffo (2015) 证明递归设计野 bootstrap 对含固定效应的动态面板 FE 估计量有效；Kapetanios (2008) 讨论 CCE 回归中的 bootstrap；Gonçalves and Perron (2014) 研究因子增强回归中的 bootstrap。  
- **当前边界**：在动态面板 + 共同因子 + 弱外生回归元这一组合下，bootstrap 是否能够复制 CCE 估计量的偏差和方差，此前没有系统结果。本文填补了这一交叉点。

**子线索聚类**  
1. **共同因子的估计方法**：CCE（Pesaran 2006）、主成分（Bai 2009；Moon and Weidner 2015）、正则化方法（Juodis 2022）。  
2. **动态面板偏差校正**：解析偏差校正（Hahn and Kuerstiner 2011）、Jackknife（Dhaene and Jochmans 2015）、固定 T 校正（De Vos and Everaert 2021a,b）。  
3. **Bootstrap 方法**：截面 bootstrap（Kapetanios 2008）、递归设计野 bootstrap（Gonçalves and Kaffo 2015）、迭代 bootstrap（Heller and Jochmans 2026）。  
4. **推断中的因子不确定性**：Brown et al. (2026) 提出 CCE 回归的方差估计；本文则关注 bootstrap 是否能自动覆盖因子估计带来的方差。

**这个方向在追问的核心问题**  
- 在 N 和 T 都趋于无穷、且 N/T → κ ∈ (0,∞) 的渐近框架下，CCE 估计量的极限分布是什么？  
- Bootstrap 能否同时复制极限分布的均值偏移（偏差）和方差（含因子估计方差）？  
- 弱外生回归元（即 x 依赖于滞后 y）是否会破坏 bootstrap 的有效性？  
- 实际应用中，如何将 bootstrap 与偏差校正结合以获得可靠的置信区间？

**⚠️ 作者的 framing（这是作者的说法）**  
作者把缺口定义为：现有文献要么只研究静态 CCE 的 bootstrap，要么只研究无共同因子的动态面板 bootstrap，而「动态 CCE + 弱外生回归元」的 bootstrap 性质是未知的。作者的核心信息是：  
- 在纯 AR(1) 情形下，RD-WB 能完全复制 CCE 估计量的渐近分布（包括偏差）；  
- 在 ARX(1) 情形下，由于回归元在 bootstrap 中被固定，bootstrap 无法复制因子估计方差和弱外生性带来的偏差；  
- 因此，实际使用时应将 RD-WB 与偏差校正（如 HPJ 或解析校正）结合，并采用适当的 studentization。

**张力**  
- **固定 T 与双渐近的张力**：De Vos and Everaert (2021a) 的固定 T 偏差校正依赖 T 固定、N 大的框架；本文采用 N,T 联合发散且 N/T → κ 的框架。两种框架对偏差的分解不同，结论不能直接互推。  
- **Bootstrap 方法的张力**：Gonçalves and Kaffo (2015) 的递归设计 bootstrap 对 FE 估计有效，但本文发现对 CCE 估计在 ARX(1) 下失效。这说明 bootstrap 的有效性高度依赖估计量的具体结构，不能从 FE 情形直接推广。  
- **严格外生与弱外生的张力**：Corollary 1 显示，若 θ₀=0（严格外生），bootstrap 能复制 Nickell 偏差；但弱外生时不能。这一边界条件在以往文献中常被忽略。

### 二、最核心、最简单的例子 / 数学结构

**记号与模型**  
观测数据：对每个截面单元 i=1,…,N 和时间 t=1,…,T，观测到  
\[
y_{i,t} = \alpha\, y_{i,t-1} + \beta' x_{i,t} + \gamma_{y,i}' f_t + \varepsilon_{i,t},
\]
其中 \(f_t\in\mathbb{R}^R\) 是不可观测共同因子，\(\gamma_{y,i}\) 是因子载荷，\(\varepsilon_{i,t}\) 是 idiosyncratic 误差。回归元 \(x_{i,t}\) 的生成过程为
\[
x_{i,t} = \theta\, y_{i,t-1} + \Gamma_{x,i}' f_t + \nu_{i,t}.
\]
这里 \(\theta\) 刻画了 \(x\) 对滞后 \(y\) 的依赖：若 \(\theta=0\)，则 \(x\) 是严格外生的；若 \(\theta\neq 0\)，则 \(x\) 是弱外生的，因为 \(y_{i,t-1}\) 本身受过去冲击影响，从而 \(x_{i,t}\) 与过去的 \(\varepsilon\) 相关。

**CCE 估计量**  
令 \(w_{i,t} = [y_{i,t-1},\, x_{i,t}']'\)，\(\delta = [\alpha,\beta']'\)。CCE 估计量是如下可行最小二乘：
\[
\hat\delta_{\text{CCEP}} = \left(\sum_{i=1}^N W_i' M_{\hat F} W_i\right)^{-1}
\left(\sum_{i=1}^N W_i' M_{\hat F} y_i\right),
\]
其中 \(W_i = [y_{i,-1},\, X_i]\)，\(\hat F\) 由所有观测变量的截面平均（含滞后）构成，\(M_{\hat F}=I_T-\hat F(\hat F'\hat F)^{-1}\hat F'\)。

**渐近展开**  
在 N,T → ∞ 且 N/T → κ 下，
\[
\sqrt{NT}(\hat\delta_{\text{CCEP}}-\delta_0) \Rightarrow N(b, V),
\]
其中偏差 \(b = b_1 + b_2\)：
- \(b_1\)：Nickell 偏差，来自滞后因变量与个体效应/因子载荷的相关性；
- \(b_2\)：因子估计偏差，来自用截面平均 \(\hat F\) 代替真实因子 \(F\)。

**最小内核：为什么 AR(1) 能工作，ARX(1) 会失败**  
考虑最简单的 AR(1)（无 x）：
\[
y_{i,t} = \alpha_0 y_{i,t-1} + \gamma_i f_t + \varepsilon_{i,t}.
\]
递归设计野 bootstrap 生成
\[
y^*_{i,t} = \hat\alpha_{\text{CCEP}}\, y^*_{i,t-1} + \hat\gamma_{y,i}' \hat f_t + \omega^*_{i,t}\hat\varepsilon_{i,t},
\]
其中 \(\omega^*_{i,t}\) 是 iid 野权重（如 Rademacher），\(\hat f_t\) 由截面平均构造。因为 bootstrap 数据是递归生成的，它保留了与原始数据相同的动态依赖结构，所以 bootstrap 估计量的渐近分布与原始估计量一致，包括偏差项 \(b_1\) 和 \(b_2\)。

现在加入回归元 \(x\)，并在 bootstrap 中保持 \(x\) 固定：
\[
y^*_{i,t} = \hat\alpha_{\text{CCEP}}\, y^*_{i,t-1} + \hat\beta'_{\text{CCEP}} x_{i,t} + \hat\gamma_{y,i}' \hat f_t + \omega^*_{i,t}\hat\varepsilon_{i,t}.
\]
问题在于：原始数据中 \(x_{i,t}\) 是内生的（通过 \(\theta y_{i,t-1}\) 与过去的 \(\varepsilon\) 相关），而 bootstrap 数据中 \(x\) 被固定，因此 \(x\) 与 bootstrap 误差 \(\omega^*\hat\varepsilon\) 的条件独立。这导致：
- 原始估计量的偏差 \(b_2\)（因子估计偏差）部分来自 \(x\) 的截面平均与 \(\varepsilon\) 的相关性，而 bootstrap 无法复制这一相关性；
- 弱外生性（\(\theta\neq 0\)）产生的额外偏差也无法在 bootstrap 中重现。

因此，RD-WB 在 ARX(1) 下不能自动复制 CCE 估计量的完整渐近分布。这就是全文最核心的“最小内核”：**bootstrap 的有效性取决于 bootstrap 数据生成过程是否保留了原始数据中导致偏差和方差的关键依赖关系。**

### 三、这篇论文做了什么

**三句话概括**  
1. 研究了动态面板数据模型（含共同因子）中，CCE 估计量在递归设计野 bootstrap 下的渐近性质。  
2. 理论上证明：纯 AR(1) 情形下 bootstrap 有效；含额外回归元（尤其弱外生）时 bootstrap 失效，并提出结合偏差校正与 studentization 的修正方案。  
3. 通过蒙特卡洛模拟和温度—GDP 增长实证分析，展示了所提方法在有限样本下优于传统截面 bootstrap 和未校正的 CCE。

**关键设定与假设**  
- 模型：一阶动态面板，含共同因子和可观测回归元；回归元允许弱外生（通过 θ 刻画）。  
- 渐近框架：N,T 联合趋于无穷，N/T → κ ∈ (0,∞)。  
- 假设 1–6 包括：误差项矩条件（最高 8 阶矩）、因子和载荷的秩条件、平稳性和混合条件、初始值条件等。这些假设与 Juodis et al. (2021) 和 De Vos and Everaert (2021a) 基本一致，但本文额外要求 bootstrap 权重有界且满足矩条件。

**主要结果**  
- **定理 1（AR(1)）**：在纯 AR(1) 模型下，RD-WB 的 bootstrap 分布与 CCE 估计量的渐近分布一致，即 bootstrap 能同时复制 Nickell 偏差和因子估计方差。  
- **定理 2（ARX(1)）**：在含回归元的模型中，RD-WB 的 bootstrap 分布与真实渐近分布存在系统性差异。具体地，bootstrap 无法复制因子估计方差 \(\xi_\perp\) 和弱外生性带来的偏差项。  
- **推论 1（严格外生）**：若 θ₀=0，则 Nickell 偏差部分可以被 bootstrap 复制，但因子估计方差仍可能不匹配。  
- **修正方案**：将 RD-WB 应用于偏差校正后的估计量（如 HPJ 或解析校正），并使用 studentized bootstrap 置信区间；蒙特卡洛显示，这种组合在 N,T 较小时显著改善覆盖概率。

**证明路线**  
1. 将 CCE 估计量的误差分解为三部分：  
   - 主项（由误差驱动，渐近正态）；  
   - Nickell 偏差项（来自滞后因变量）；  
   - 因子估计偏差项（来自截面平均代理因子）。  
2. 对原始数据和 bootstrap 数据分别建立上述分解，并逐项比较。  
3. 关键步骤是证明 bootstrap 的“主项”与原始数据同分布，但“因子估计偏差项”在 bootstrap 中消失或改变，因为 bootstrap 中 x 固定，截面平均不再是随机估计量。  
4. 使用 bootstrap CLT（对野权重和递归依赖结构）和连续映射定理得到最终结论。

**技术技巧**  
- **递归设计野 bootstrap**：不是简单重抽样残差，而是从估计的模型递归生成 y*，从而保留动态依赖。  
- **Rademacher 权重**：满足矩条件且便于证明 bootstrap CLT。  
- **偏差分解**：把偏差拆成可复制的部分（Nickell）和不可复制的部分（因子估计），这是诊断 bootstrap 失效的关键。  
- **studentization**：用 bootstrap 估计方差对统计量进行标准化，以消除方差不匹配的影响。  
- **迭代 bootstrap**：附录中讨论了 Heller and Jochmans (2026) 的迭代 bootstrap 作为替代方案。

**真实例子与应用**  
- 数据：125 个国家 1961–2003 年的气候—经济面板，按贫富分组，两个子面板分别有 93 和 118 个国家，T=20。  
- 模型：  
\[
g_{i,t} = \alpha g_{i,t-1} + c_i + \beta_1 T_{i,t} + \beta_2 T_{i,t-1} + \gamma_i' f_t + \varepsilon_{i,t},
\]
其中 \(g\) 为 GDP 增长率，\(T\) 为温度，\(c_i\) 为个体效应，\(f_t\) 为共同因子。  
- 结果：使用 RD-WB 结合偏差校正后，温度冲击对贫穷国家当期 GDP 增长有显著负效应，滞后项为正且大致抵消，说明冲击主要是暂时的；HPJ 方法给出的效应更小且不显著。作者用这个例子说明，推断方法的选择会改变实证结论。

**🔎 结论是否比证明窄**  
- 论文严格证明的是 AR(1) 和 ARX(1) 两种设定；对 AR(p) 和 VAR(p) 只在附录中给出扩展讨论，没有完整证明。  
- 论文对“bootstrap 失效”的机制解释得很清楚，但没有给出一个通用的充分条件来判定何时 bootstrap 有效。  
- 结论部分明确说“We conjecture that the RD-WB is valid for this class of estimators, at least when the regressors are strictly exogenous”，这句话本身就是一个未证明的猜想，比正文的定理要宽。

### 四、开放问题

1. **PC 估计量的 bootstrap 有效性**  
   论文只在结论中猜想：对主成分（PC）类交互固定效应估计量，RD-WB 在严格外生回归元下可能有效。这个猜想没有证明。可以研究：PC 估计量的因子估计误差与 CCE 不同，bootstrap 是否能复制其方差结构？在弱外生下是否同样失效？

2. **重抽样 x 的 bootstrap 设计**  
   论文指出失效根源是 x 在 bootstrap 中被固定。一个自然的改进是：在 bootstrap 中也对 x 的生成过程建模（例如用 VAR 或因子模型重抽样 x），使 bootstrap 数据保留 x 与 y 的反馈。这个方向需要额外的模型假设，但可能让 bootstrap 在弱外生下也有效。

3. **高阶精度与覆盖误差率**  
   论文只证明了一阶渐近有效性。可以进一步做 Edgeworth 展开，比较 RD-WB、studentized bootstrap 和解析偏差校正的覆盖误差率，判断哪种方法在 T 较小时更精确。

4. **异质性斜率与横截面相关**  
   论文假设斜率同质、误差横截面独立。实际宏观面板中，国家间可能存在空间相关或异质温度效应。可以研究在这些更复杂结构下，RD-WB 是否仍然能复制偏差和方差，或者需要新的 bootstrap 方案。

5. **确认真 gap 的方法提醒**  
   若要判断上述哪一条是“真问题”，建议去读同子领域近 5 篇论文的引言：如果多篇都指向同一个未解决问题，那就是共识性 gap；如果各篇互相打架，则可能是机会更大的争议点。
