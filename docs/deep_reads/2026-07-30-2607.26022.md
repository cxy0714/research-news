### 一、领域脉络与小综述

#### 这个方向是什么

本文所针对的根本统计问题是：**如何在维度 p 远大于样本量 n 的高维情形下，对具有组成性质（compositional）的数据进行两组或多组均值向量的假设检验**。组成数据的核心特征是每个样本的观测向量落在单纯形（simplex）上，即各分量非负且总和为 1，这导致分量之间存在固有的负相关结构，且协方差矩阵必然奇异。经典多元检验（如 Hotelling T²）在高维下失效，而现有的高维均值检验方法（如基于极大范数的检验）通常要求数据满足特定的分布假设或协方差结构，且大多未考虑组成数据的特殊约束。该子方向当前处于活跃发展阶段，主要服务于微生物组学研究——通过 16S rRNA 测序得到的分类单元（taxa）相对丰度数据天然是组成的，研究者关心不同临床分组（如疾病 vs. 对照）之间微生物群落整体结构是否有显著差异。

#### 发展脉络

- **奠基工作**：Aitchison [1982, 2003] 首次系统提出组成数据的统计分析框架，引入 log-ratio 变换（包括中心化 log-ratio，即 CLR）将单纯形数据映射到欧氏空间，从而使得经典多元统计方法在变换后的数据上可用。这一框架奠定了后续所有组成数据分析方法的基础。
- **高维均值检验的兴起**：Bai-Saranadasa 型检验和 Cai-Liu-Xia 型极大范数检验开启了高维两样本均值检验的研究。Cao et al. [2017] 首次将极大范数检验引入组成数据，提出基于 CLR 变换的 max-norm 检验，但其理论要求两组协方差相等（等协方差假设），且依赖渐近正态/Gumbel 极值逼近。
- **放宽等协方差假设**：Li et al. [2022] 提出 MECAF（Maximum-type test that is Equal-Covariance-Assumption-Free），将 Cao et al. [2017] 推广到不等协方差情形，但仍依赖大样本渐近逼近（Gumbel 极值分布），在样本量不足时 size 控制不佳。
- **bootstrap 方法的引入**：Xue and Yao [2020] 和 Chakraborty and Sakhanenko [2023] 提出基于 multiplier bootstrap 的高维均值检验，试图摆脱对协方差结构的显式估计。但作者指出，multiplier bootstrap 无法保持组成数据的 CLR 变换所隐含的零和约束（即变换后向量各分量之和为零），因此直接套用会破坏数据结构。
- **本文的位置**：在上述工作的基础上，本文提出经验 bootstrap（empirical bootstrap）框架，其核心创新在于——经验 bootstrap 从原始数据**重采样**，因此天然保持 CLR 变换后的零和约束（因为重采样不改变数据的代数结构），而 multiplier bootstrap 通过乘随机权重破坏这一约束。这使得本文方法在组成数据场景下具有原理上的优势。

#### 子线索聚类

1. **组成数据的变换与建模**：Aitchison [1982, 2003]、Greenacre [2021]、Lin and Peddada [2020a, 2020b]。这一线索关注如何将单纯形数据转化为适合经典统计方法的形式，以及不同变换（CLR、ILR、ALR）的性质。
2. **高维均值检验的渐近理论**：Cao et al. [2017]、Li et al. [2022]、Xue and Yao [2020]、Chakraborty and Sakhanenko [2023]、Wu and Hu [2024]。这一线索关注检验统计量的构造（极大范数、二次型等）及其在 p≫n 下的渐近零分布，核心难点在于协方差矩阵的估计与极值分布的逼近。
3. **bootstrap 方法在高维推断中的应用**：Chernozhukov et al. [2017, 2022] 建立了高维 bootstrap 的理论基础（Gaussian approximation 与 bootstrap 一致性），本文直接依赖这一理论框架。这一线索关注如何用重采样方法避免对渐近分布的显式推导。

#### 核心问题

1. **如何在 p≫n 下构造对组成数据有效的检验统计量？** 当前主流答案是 CLR 变换 + 极大范数，但极大范数对稀疏信号敏感、对稠密微弱信号不敏感。
2. **如何在不依赖协方差结构假设的前提下校准检验的临界值？** 渐近极值逼近（Gumbel）收敛速度慢，在有限样本下 size 失真严重；multiplier bootstrap 虽不依赖协方差估计，但破坏组成数据的结构约束。
3. **如何在不同组协方差不等、样本量不平衡、数据稀疏（大量零计数）时保持检验的有效性？** 这是微生物组数据的实际痛点。

#### ⚠️ 作者的 framing

作者将缺口 frame 为：**现有高维均值检验方法（包括 multiplier bootstrap）无法在保持 CLR 变换零和约束的同时提供有效的临界值校准**。具体而言，作者在 Remark 1 中指出，multiplier bootstrap 对 CLR 变换后的数据乘随机权重后，所得向量的各分量之和不再为零，从而偏离了组成数据的代数结构。作者将经验 bootstrap 定位为"显然的下一步"——因为它通过重采样天然保持这一约束。作者淡化的竞争路线包括：基于二次型（quadratic form）的检验（如 Bai-Saranadasa 型），以及基于 ILR 变换的检验（作者仅在结论中提及 ILR 变换下的推广作为未来方向，暗示当前方法对 ILR 不适用）。

#### 张力

未见明显对立引用。但存在一个值得注意的张力：Cao et al. [2017] 和 Li et al. [2022] 依赖渐近极值分布，而本文依赖 bootstrap 一致性（Chernozhukov et al. 2017 的框架）。这两条路线在理论上都对，但有限样本行为可能不同——本文的模拟显示 EBC 在 size 控制上优于两者，但这只是模拟证据，不是理论矛盾。另一个潜在张力是：Chernozhukov et al. [2017] 的 bootstrap 理论要求数据具有次指数尾或多项式矩条件，而微生物组计数数据经 CLR 变换后是否满足这些条件，本文未给出验证。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

**符号清单**（逐个点名）：

| 记号 | 含义 | 类型 |
|------|------|------|
| $p$ | 分类单元（taxa）数量，即维度 | 指标（可随 n 增长） |
| $n_k$ | 第 k 组的样本量，$k=1,\dots,K$ | 指标 |
| $N = \sum_{k=1}^K n_k$ | 总样本量 | 指标 |
| $X^{(k)}_i \in \mathcal{S}^{p-1}$ | 第 k 组第 i 个样本的组成向量（单纯形上） | 可观测随机变量 |
| $W^{(k)}_i \in \mathbb{R}^p_{++}$ | 第 k 组第 i 个样本的潜在丰度向量（未观测） | 潜在变量 |
| $V^{(k)}_i = \log W^{(k)}_i$ | 对数丰度向量 | 潜在变量 |
| $\mu^{(k)} = E(V^{(k)}_i)$ | 第 k 组对数丰度均值向量 | 参数（estimand） |
| $\Sigma^{(k)}_i$ | 第 k 组第 i 个样本的协方差矩阵 | 参数（可随 i 变化） |
| $Z^{(k)}_i = G_p V^{(k)}_i$ | CLR 变换后的向量 | 可观测（由 X 确定） |
| $G_p = I_p - \frac{1}{p} \mathbf{1}_p \mathbf{1}_p^\top$ | 中心化投影矩阵 | 已知线性算子 |
| $\nu^{(k)} = G_p \mu^{(k)}$ | CLR 变换后的均值向量 | 参数（可检验的 estimand） |
| $S^{(k)}_{n_k} = n_k^{-1/2} \sum_{i=1}^{n_k} (Z^{(k)}_i - \bar{Z}^{(k)})$ | 标准化样本和 | 随机变量 |
| $T_{n,K}$ | 检验统计量（极大范数） | 随机变量 |
| $Q_{\alpha,K}$ | bootstrap 临界值 | 数据驱动阈值 |
| $\rho(\cdot,\cdot)$ | Kolmogorov 距离 | 度量 |

**模型**（数据生成机制）：

1. **组成结构**：观测数据 $X^{(k)}_i$ 是潜在丰度向量 $W^{(k)}_i$ 的归一化：
   $$X^{(k)}_{ij} = \frac{W^{(k)}_{ij}}{\sum_{j'=1}^p W^{(k)}_{ij'}}, \quad i=1,\dots,n_k, \ j=1,\dots,p, \ k=1,2.$$
   
2. **对数尺度**：$V^{(k)}_i = \log W^{(k)}_i$，假设 $V^{(k)}_1, \dots, V^{(k)}_{n_k}$ 是独立同分布样本，来自均值为 $\mu^{(k)}$、协方差为 $\Sigma^{(k)}_i$ 的分布（允许各样本协方差不同）。

3. **CLR 变换**：对观测组成 $X^{(k)}_i$ 做中心化对数比变换：
   $$Z^{(k)}_i = G_p \log X^{(k)}_i = G_p V^{(k)}_i,$$
   其中 $G_p = I_p - \frac{1}{p}\mathbf{1}_p\mathbf{1}_p^\top$。由于 $G_p \mathbf{1}_p = 0$，$Z^{(k)}_i$ 自动满足零和约束 $\sum_{j=1}^p Z^{(k)}_{ij} = 0$。

4. **可检验的假设**：由于 $\nu^{(k)} = G_p \mu^{(k)}$ 是 $\mu^{(k)}$ 在 $G_p$ 值域上的投影，原假设 $\mu^{(1)} = \mu^{(2)} + c\mathbf{1}_p$（即两组对数丰度只差一个常数）等价于 $\nu^{(1)} = \nu^{(2)}$。因此检验问题为：
   $$H_0: \nu^{(1)} = \nu^{(2)} \quad \text{vs.} \quad H_a: \nu^{(1)} \neq \nu^{(2)}.$$

5. **检验统计量**（两样本情形）：
   $$T_{n,2} = \max_{1 \leq j \leq p} \left| \lambda_1 S^{(1)}_{n_1 j} - \lambda_2 S^{(2)}_{n_2 j} \right|,$$
   其中 $\lambda_1 = \sqrt{n_1 n_2/(n_1+n_2)}$，$\lambda_2 = \sqrt{n_1 n_2/(n_1+n_2)}$（注意文中 $\lambda_1 = n_2^{1/2}(n_1+n_2)^{-1/2}$，$\lambda_2 = n_1^{1/2}(n_1+n_2)^{-1/2}$，两者乘积关系保证 $\lambda_1^2 + \lambda_2^2 = 1$ 的某种归一化），$S^{(k)}_{n_k} = n_k^{-1/2}\sum_{i=1}^{n_k}(Z^{(k)}_i - \bar{Z}^{(k)})$。

**可观测数据**：研究者实际能观测到的是组成矩阵 $X^{(1)}$（$n_1 \times p$）和 $X^{(2)}$（$n_2 \times p$），每行是一个样本的组成向量。**不可观测**的是潜在丰度 $W^{(k)}_i$ 和对数丰度 $V^{(k)}_i$——它们只能通过 CLR 变换间接推断。**关键识别条件**：由于组成数据只包含相对信息，$\mu^{(k)}$ 本身不可识别，只有 $\nu^{(k)} = G_p \mu^{(k)}$ 可识别。这就是为什么原假设必须是"差一个常数"的形式。

#### 第二步：最小内核

**最小内核**：本文的全部理论贡献可以归结为一个问题——

> **在 $p \gg n$ 且数据具有 CLR 零和约束的条件下，如何用经验 bootstrap 构造检验统计量 $T_{n,K}$ 的临界值 $Q_{\alpha,K}$，使得检验的 size 收敛到名义水平 $\alpha$，且对稀疏备择具有一致性？**

**最简特例**：考虑 $K=2$（两组比较），$p$ 固定（不随 $n$ 增长），$n_1 = n_2 = n$，且 $Z^{(k)}_i$ 为独立同分布的高斯向量（均值为 $\nu^{(k)}$，协方差为 $\Sigma$）。此时：

- 检验统计量退化为 $T_{n,2} = \max_{1 \leq j \leq p} |\sqrt{n}(\bar{Z}^{(1)}_j - \bar{Z}^{(2)}_j)|$（在 $\lambda_1 = \lambda_2 = \sqrt{n/2}$ 的归一化下）。
- 在原假设下，$\sqrt{n}(\bar{Z}^{(1)} - \bar{Z}^{(2)}) \xrightarrow{d} N(0, 2\Sigma)$。
- 经验 bootstrap 的机制是：从 $Z^{(1)}$ 和 $Z^{(2)}$ 中分别**有放回重采样**，得到 bootstrap 样本 $Z^{*(1)}$ 和 $Z^{*(2)}$，然后计算 $T^*_{n,2} = \max_j |\sqrt{n}(\bar{Z}^{*(1)}_j - \bar{Z}^{*(2)}_j) - \sqrt{n}(\bar{Z}^{(1)}_j - \bar{Z}^{(2)}_j)|$（即中心化的 bootstrap 统计量）。
- 关键性质：由于重采样不改变数据的代数结构，$Z^{*(k)}$ 的每一行仍然满足零和约束（因为 $Z^{(k)}_i$ 的每一行都满足零和，重采样只是复制整行）。而 multiplier bootstrap 中，$Z^{*(k)}_i = e_i (Z^{(k)}_i - \bar{Z}^{(k)})$ 乘以随机权重 $e_i$ 后，零和约束被破坏。
- 在这个特例下，Chernozhukov et al. [2017] 的定理保证：$\rho(T_{n,2}, T^*_{n,2}) \to 0$ 依概率，从而 bootstrap 临界值 $Q_{\alpha,2}$ 一致估计真实临界值，检验的 size 收敛到 $\alpha$。

**为什么这个内核是"最小"的**：它剥离了高维（$p$ 固定）、组成结构（高斯假设）、协方差估计（已知 $\Sigma$）等所有复杂性，只保留了一个核心机制——**经验 bootstrap 通过重采样保持数据的代数约束，从而在 CLR 变换后的空间提供有效的临界值校准**。本文的一般性定理（Theorem 1-2）本质上是在说：当 $p$ 随 $n$ 增长、数据非高斯、协方差未知且组间不等时，上述机制仍然成立，只是需要额外的矩条件和尾概率控制。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：在高维组成数据（微生物组相对丰度）下，如何检验两组或多组样本的微生物群落均值向量是否相等（等价地，CLR 变换后的均值向量是否相等），并保证检验在 $p \gg n$ 时具有有效的 size 和良好的 power。
2. **核心工具/方法**：提出经验 bootstrap（Empirical Bootstrap for Compositional data，简称 EBC）框架，对 CLR 变换后的数据做有放回重采样，用 bootstrap 分布逼近检验统计量在原假设下的分布，从而得到数据驱动的临界值。该方法适用于两样本、配对和多样本（K 组）设定。
3. **主要结论**：在温和的矩条件和尾概率条件下（Theorem 1），EBC 检验的 size 收敛到名义水平 $\alpha$；在备择假设下（Theorem 2），只要组间差异在极大范数意义下超过某个阈值，检验的 power 趋于 1。模拟和两个真实数据（结直肠腺瘤/癌症、妊娠早产）分析表明，EBC 在 size 控制和 power 上优于 Cao et al. [2017] 的 CLL 检验和 Li et al. [2022] 的 MECAF 检验，尤其在样本量小、零膨胀高、组间协方差不等时。

#### 关键设定与假设

在第二节最小记号的基础上，补全完整设定：

- **数据模型**：$K$ 组独立样本，第 $k$ 组有 $n_k$ 个观测，每个观测是 $p$ 维组成向量 $X^{(k)}_i \in \mathcal{S}^{p-1}$。潜在对数丰度 $V^{(k)}_i = \log W^{(k)}_i$ 独立同分布，均值为 $\mu^{(k)}$，协方差为 $\Sigma^{(k)}_i$（允许随样本变化）。
- **CLR 变换**：$Z^{(k)}_i = G_p \log X^{(k)}_i$，其中 $G_p = I_p - \frac{1}{p}\mathbf{1}_p\mathbf{1}_p^\top$。变换后的数据满足零和约束 $\sum_{j=1}^p Z^{(k)}_{ij} = 0$。
- **检验统计量**（多样本推广）：
  $$T_{n,K} = \max_{1 \leq k < l \leq K} \max_{1 \leq j \leq p} \left| \lambda_{k,l} S^{(k)}_{n_k j} - \lambda_{l,k} S^{(l)}_{n_l j} \right|,$$
  其中 $\lambda_{k,l} = \sqrt{n_l/(n_k+n_l)}$（注意文中定义），$S^{(k)}_{n_k} = n_k^{-1/2}\sum_{i=1}^{n_k}(Z^{(k)}_i - \bar{Z}^{(k)})$。
- **假设 (A.1)**：样本量比例有界，即 $n_k/(n_k+n_l) \in (c_1, c_2)$ 对某常数 $0 < c_1 < c_2 < 1$。这保证没有哪一组样本量占比趋于 0 或 1。
- **假设 (A.2)**：CLR 变换后的数据 $Z^{(k)}_i$ 的方差有下界（$\min_j \sigma^{(k)}_{jj} > b > 0$），且协方差矩阵满足一个"近似对角占优"条件：$\sum_{i \neq j} |\sigma^{(k)}_{ij}| \leq a_p \sigma^{(k)}_{jj}$，其中 $a_p \to \infty$ 但 $a_p = o(p)$。这个条件比要求协方差矩阵稀疏更弱，允许每行有 $o(p)$ 个非零协方差项。
- **假设 (A.3)**：$Z^{(k)}_i$ 的 $2+\ell$ 阶矩有界（$\ell = 1, 2$），即 $\max_j E|Z^{(k)}_{ij} - \nu^{(k)}_j|^{2+\ell} \leq B_n^\ell$。
- **假设 (A.4) 或 (A.5)**：尾概率条件。 (A.4) 要求次指数尾：$E\exp(B_n^{-1}|Z^{(k)}_{ij} - \nu^{(k)}_j|) \leq 2$； (A.5) 要求多项式尾：$E|B_n^{-1}(Z^{(k)}_{ij} - \nu^{(k)}_j)|^q \leq 2$ 对某个 $q > 4$。这两个条件分别对应 Chernozhukov et al. [2017] 和 [2022] 的框架。
- **假设 (A.6)**（备择假设下的可检测性条件）：存在至少一对组 $(k,l)$ 和至少一个坐标 $j$，使得组间均值差异在极大范数意义下超过阈值：
  $$\max_{1 \leq k < l \leq K} \left\{ \max_j |\nu^{(k)}_j - \nu^{(l)}_j| - p^{-1}\sum_j |\nu^{(k)}_j - \nu^{(l)}_j| \right\} \geq C_s \left( \frac{B_n \log(Np)}{N} \right)^{1/2},$$
  其中 $C_s$ 是足够大的常数。这个条件要求组间差异在"去均值化"后仍然足够大，排除了"整体平移"这种不可检测的差异。

**相比已有文献的放宽/强化**：
- 相比 Cao et al. [2017] 和 Li et al. [2022]：放宽了等协方差假设（允许 $\Sigma^{(k)}_i$ 随组和样本变化），且不要求协方差矩阵的稀疏结构（(A.2) 允许每行有 $o(p)$ 个非零项）。
- 相比 Xue and Yao [2020] 和 Chakraborty and Sakhanenko [2023]：作者声称 multiplier bootstrap 不适用于 CLR 变换后的数据（因为破坏零和约束），而经验 bootstrap 天然保持这一约束。这是本文的核心卖点。
- 相比 Wu and Hu [2024]：后者需要估计协方差矩阵（在 $p \gg n$ 下不稳定），本文的经验 bootstrap 完全避免了协方差估计。

#### 主要结果

**Theorem 1（零假设下的 size 有效性）**：在假设 (A.1)-(A.4) 或 (A.1)-(A.3)+(A.5) 下，当 $N \to \infty$ 且 $p$ 可以随 $N$ 增长到 $p = O(e^{N^c})$（$c$ 为某常数）时，
$$\sup_{x \geq 0} \left| P(T_{n,K} \leq x) - P^*(T^*_{n,K} \leq x) \right| \to 0,$$
其中 $P^*$ 是给定数据条件下的 bootstrap 概率。这意味着 bootstrap 临界值 $Q_{\alpha,K}$ 满足 $P(T_{n,K} > Q_{\alpha,K}) \to \alpha$，即检验的 size 渐近等于名义水平。

**Theorem 2（备择假设下的一致性）**：在 Theorem 1 的条件下，若假设 (A.6) 成立，则
$$P(T_{n,K} > Q_{\alpha,K}) \to 1,$$
即检验的 power 趋于 1。

**证明路线**：
1. **重写检验统计量**：将 $T_{n,K}$ 写成 $\|AS_n - AD_K\nu\|_\infty$，其中 $A$ 是一个分块矩阵，$S_n$ 是标准化样本均值向量，$D_K$ 是对角矩阵。这样将多样本问题转化为一个统一的 sup-norm 形式。
2. **Gaussian 逼近**：利用 Chernozhukov et al. [2017] 的 Proposition 2.1，证明 $\tilde{T}_{n,K}$（中心化后的检验统计量）的分布可以被一个高斯向量 $Y \sim N(0, \Gamma_u)$ 的 sup-norm 分布逼近，逼近误差为 $O((B_n^2 \log^7(Np)/N)^{1/6})$。
3. **bootstrap 一致性**：证明经验 bootstrap 统计量 $T^*_{n,K}$ 的条件分布同样可以被同一个高斯分布逼近（以高概率），从而 $\rho^*(T_{n,K}, T^*_{n,K}) \to 0$。
4. **关键引理**：
   - **Lemma 2**：证明 CLR 变换后的数据满足方差下界和矩条件（由 (A.2)-(A.3) 推出）。
   - **Lemma 3**：证明组间均值差异在 CLR 变换后不会消失（由 (A.6) 推出）。
   - **Lemma 4**：矩阵范数不等式，用于控制 $A$ 的谱范数。
   - **Lemma 5**：核心技术引理，给出三个逼近误差的界（Gaussian 逼近、bootstrap 逼近、协方差估计误差），是证明 Theorem 1-2 的关键。

**技术技巧点名**：
- **sup-norm 统计量与 Gaussian approximation**：直接借用 Chernozhukov et al. [2017] 的框架，将检验统计量的分布逼近问题转化为高维中心极限定理问题。
- **经验 bootstrap 而非 multiplier bootstrap**：这是本文的核心技巧。经验 bootstrap 通过重采样保持 CLR 的零和约束，而 multiplier bootstrap 会破坏这一约束。作者在 Remark 1 中明确指出了这一点。
- **K 组问题的矩阵化处理**：通过构造分块矩阵 $A$，将 $K$ 组比较统一为一个 sup-norm 问题，避免了逐对比较的复杂性。
- **尾概率条件的灵活处理**：同时给出次指数（(A.4)）和多项式尾（(A.5)）两个版本，后者允许更重的尾部但需要更高的矩条件（$q > 4$）。

#### 真实例子与应用

**数据集 1：结直肠腺瘤/癌症粪便菌群（Hale et al. [2017]）**
- 数据：801 个粪便样本（229 腺瘤、38 癌症、534 对照），2140 个分类单元（taxa）。
- 分析：比较腺瘤+癌症组 vs. 对照组，以及年龄分层（<65 vs. ≥65）。
- 结果：EBC 检测到年龄相关的显著差异（p = 0.030），而 CLL 和 MECAF 未检测到（p = 0.437 和 0.442）。作者将此归因于 EBC 对分布式微弱信号的敏感性以及更好的有限样本 size 控制。

**数据集 2：妊娠早产阴道菌群（Stout et al. [2017]）**
- 数据：53 个妊娠中期阴道样本（20 早产、33 足月），88 个 OTU。
- 分析：比较早产 vs. 足月，以及种族分层（黑人 vs. 其他）。
- 结果：EBC 检测到种族相关的显著差异（p = 0.001），而 CLL 和 MECAF 未检测到（p = 0.736 和 0.774）。早产 vs. 足月比较中，所有方法均未发现显著差异，与 Stout et al. [2017] 和 Fettweis et al. [2019] 的结论一致。

**这些例子想说明什么**：EBC 在样本量小（n=53）、组间样本量不平衡（36 vs. 17）、零膨胀高（大量未检出的 taxa）、组间协方差可能不等的情况下，仍能保持 size 控制并检测到真实信号，而依赖渐近极值分布的 CLL 和 MECAF 在这些条件下失效。

#### 🔎 结论是否比证明窄

- **Theorem 1-2 的证明条件 vs. 泛化声称**：作者在结论中声称方法"适用于一般的高维组成数据"，但证明中假设 (A.2) 要求协方差矩阵的"近似对角占优"条件（$\sum_{i \neq j} |\sigma^{(k)}_{ij}| \leq a_p \sigma^{(k)}_{jj}$，$a_p = o(p)$）。这个条件排除了强相关的 taxa 网络（例如同一菌门的 taxa 高度共线），而微生物组数据中这种强相关很常见。作者在模拟中使用了分块相关结构，但分块的大小是固定的（$d=10$），不随 $p$ 增长，因此并未真正检验 (A.2) 被违反的情形。
- **bootstrap 一致性的证明 vs. 实际使用**：Theorem 1 的证明依赖于 Chernozhukov et al. [2017] 的 Gaussian approximation 框架，该框架要求数据具有次指数尾（(A.4)）或高阶矩（(A.5)）。但微生物组计数数据经 CLR 变换后，由于大量零值和厚尾，是否满足这些条件，作者未给出验证。模拟中使用的是高斯和对数正态分布，未覆盖零膨胀的计数数据生成过程。
- **多样本设定的证明 vs. 两样本的模拟**：Theorem 1-2 声称适用于 $K \geq 2$ 组，但模拟部分只报告了 $K=2$ 的结果（Tables 1-3），多样本结果仅在补充材料中（作者提到 Table S3）。多样本检验统计量涉及 $\max_{1 \leq k < l \leq K}$，其 bootstrap 逼近的误差项可能随 $K$ 增长，作者未给出 $K$ 与 $p, n$ 的联合增长条件。
- **真实数据结论的稳健性**：作者在真实数据中报告 EBC 检测到年龄/种族差异而 CLL/MECAC 未检测到，但未提供多重比较校正（如 FDR）的细节，也未报告效应量或置信区间。p 值差异可能部分源于 CLL/MECAF 的 size 膨胀（而非 EBC 的 power 优势），但作者未提供校准后的 power 比较。

### 四、开放问题

1. **强相关 taxa 网络下的表现**：假设 (A.2) 要求协方差矩阵近似对角占优，但微生物组数据中 taxa 之间存在系统发育相关性（同一菌门的 taxa 高度共线）。在强相关结构下，EBC 的 size 是否仍然有效？这需要放松 (A.2) 或发展新的理论工具。扎根于：假设 (A.2) 的讨论（第 5 节）和模拟中分块相关结构的选择（第 7 节）。

2. **零膨胀计数数据的理论保证**：微生物组数据通常有大量零值（未检测到的 taxa），经 CLR 变换后会产生厚尾。Theorem 1-2 的证明依赖次指数尾（(A.4)）或高阶矩（(A.5)），但零膨胀分布是否满足这些条件？如果不满足，EBC 的 size 是否仍然可控？扎根于：假设 (A.4)-(A.5) 的陈述（第 5 节）和模拟中未包含零膨胀分布（第 7 节）。

3. **多样本设定下 $K$ 与 $p, n$ 的联合增长条件**：Theorem 1-2 声称适用于 $K \geq 2$，但未给出 $K$ 的增长速度限制。当 $K$ 随 $n$ 增长时，bootstrap 逼近的误差项如何变化？扎根于：Theorem 1-2 的陈述（第 6 节）和多样本模拟仅出现在补充材料（第 7 节）。

4. **ILR 变换下的推广**：作者在结论中承认方法对 ILR 变换不适用（因为 ILR 引入旋转，破坏坐标-wise 的极大范数结构）。但 ILR 在组成数据分析中具有更好的统计性质（如等距性）。能否发展 ILR 变换下的类似 bootstrap 检验？扎根于：结论部分对 ILR 的讨论（第 9 节）。

5. **效应量与置信区间**：本文只提供了 p 值，未提供组间差异的效应量估计或置信区间。在高维组成数据下，如何构造同时覆盖所有坐标的置信带？扎根于：结论部分对方法局限性的讨论（第 9 节）。
