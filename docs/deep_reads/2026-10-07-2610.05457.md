### 一、领域脉络与小综述

#### 这个方向是什么

本文研究的根本问题是：**给定一条连续路径的离散采样观测，如何非参数地估计其"粗糙度"（roughness）**。粗糙度是描述路径不规则程度的量，在随机过程、金融波动率建模、信号处理等领域有广泛应用。该子方向的核心挑战在于：粗糙度本身不是直接可观测的量，而是需要通过路径的局部增量行为（如幂变差）来间接识别。当前该方向的成熟度处于"方法多样但理论基础仍在发展"的阶段——已有基于幂变差的估计方法（如 [NS02]），但对其在一般路径（非随机过程模型）下的收敛性质缺乏系统认识。

#### 发展脉络

- **奠基工作**：Norvaiša 和 Salopek [NS02] 首次系统研究了从离散观测估计 p-变差指数（p-variation index）的问题，使用振荡求和统计量，并应用于金融数据。这项工作确立了"通过比较不同阶幂变差的渐近行为来识别粗糙度"的基本思路。
- **路径正则性与粗糙度的联系**：Cont 和 Perkowski [CP19] 建立了沿路径的 p-次变差与路径正则性之间的系统联系，为路径wise（pathwise）分析提供了严格框架。这一工作将粗糙度从随机过程模型（如分数布朗运动）推广到一般连续路径。
- **Takagi–Landsberg 函数与构造性例子**：Mishura 和 Schied [MS19] 系统研究了 Takagi–Landsberg 函数的 p-次变差性质，这类确定性函数具有精确可计算的变差指数，成为检验估计方法的重要测试平台。Schied [Sch16] 进一步构造了具有线性二次变差的广义 Takagi 函数。
- **粗糙度估计的近期进展**：Han 和 Schied [HS25b] 发展了基于 Faber–Schauder 系数能量的路径wise 估计理论，建立了粗糙度指数与系数能量衰减之间的联系。Chong 等 [CHL+24] 则从 minimax 视角研究了潜在波动率粗糙度的统计推断极限。
- **本文的位置**：Cont 和 Das 提出了一种基于**归一化幂变差**（normalized power variation）的新估计量，其核心创新在于：(i) 不需要临界变差收敛（critical variation convergence）即可获得一致性；(ii) 适用于非均匀采样网格；(iii) 给出了显式的收敛速率。本文试图填补"路径wise 估计量在一般路径下的收敛理论"这一空白。

#### 子线索聚类

被引文献大致落在三条子线索上：

1. **路径wise 变差理论**（[Föl81, CC18, CP19, C26]）：研究沿给定路径（而非随机过程）的变差概念，建立 p-次变差与路径正则性的联系。这一线索为估计量的定义提供了数学基础。
2. **粗糙度估计方法**（[NS02, HS25b, HS23, CHL+24]）：从离散观测估计粗糙度/变差指数的具体方法，包括振荡求和、系数能量、幂变差等不同技术路线。
3. **确定性构造与反例**（[Sch16, MS16, MS19, DS26]）：通过构造具有特定变差性质的确定性函数（如 Takagi–Landsberg 函数），揭示变差指数与临界变差存在性之间的微妙关系，为理论分析提供测试案例。

#### 这个方向在追问的核心问题

1. **识别问题**：从离散采样中，粗糙度指数（如变差指数 p₀）是否可识别？需要什么样的采样条件？
2. **估计问题**：如何构造估计量？其收敛速率是多少？是否达到最优？
3. **稳健性问题**：当临界变差不收敛（如振荡的临界幂和）时，估计量是否仍然一致？
4. **模型依赖问题**：估计结果是否依赖于对数据生成过程的模型假设（如分数布朗运动）？

已知瓶颈：现有方法（如 [NS02]）通常要求临界变差收敛或假设特定的随机过程模型，这在一般路径下难以验证。此外，收敛速率通常只有对数阶（1/log），在实际应用中可能过慢。

#### ⚠️ 作者的 framing

作者将缺口 frame 为：**现有估计量要么依赖临界变差收敛（如 [NS02]），要么需要特定的随机模型假设（如 [HS25b]），缺乏在一般路径下仅依赖局部变差界的一致性理论**。作者声称其贡献在于：(i) 证明一致性仅需"粗尺度临界幂和"非退化与"细尺度临界幂和"一致有界，无需临界变差收敛；(ii) 适用于非均匀网格；(iii) 给出显式收敛速率。作者淡化了与 minimax 最优性（[CHL+24]）的比较，也未讨论估计量的渐近分布（正态性）问题。

**值得研究者去查的问题**：作者在引言中提到"latent roughness"（潜在粗糙度）问题（[HS23, CHL+24]），但本文明确不处理该问题——这是否意味着本文方法无法推广到潜在变量场景？另外，作者未引用近期关于粗糙度估计的贝叶斯方法或正则化方法，这些竞争路线是否已被作者有意回避？

#### 张力

未见明显对立引用。但存在一个微妙的张力：作者强调"不需要临界变差收敛"，而 [DS26] 的结果表明随机符号的 Takagi–Landsberg 桥的临界变差可能依赖于划分或发散——这意味着"变差指数存在"与"临界变差收敛"确实是两个独立的概念，本文的贡献正是利用这一区分。这一张力是建设性的，而非矛盾的。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

**符号**（逐个点名）：

- **x**：被研究的路径，x ∈ C([0,T], ℝ)，即 [0,T] 上的连续实值函数。这是**研究对象**，不是随机变量（在路径wise 框架下）。
- **π = (πₙ)ₙ≥₁**：一列有限划分，πₙ = {0 = tₙ⁰ < tₙ¹ < ... < tₙ^{N(πₙ)} = T}，网格趋于零（|πₙ| → 0）。这是**采样网格**，即可观测数据的载体。
- **|πₙ|**：划分 πₙ 的网格大小（最大区间长度）。**πₙ**（下划线）：最小区间长度。
- **N(πₙ)**：划分 πₙ 的区间数。
- **Aₙ^(p)(t)**：沿 πₙ 到时间 t 的 p-次幂变差和，Aₙ^(p)(t) = Σ_{I=[u,v]∈πₙ, v≤t} |Δ_I x|^p。这是**可观测统计量**（由采样值计算）。
- **Sₙ(p)**：Aₙ^(p)(T)，即全区间上的 p-次幂变差和。
- **p₀**：变差指数（variation index），即 p₀ = inf{p ≥ 1 : limsupₙ Sₙ(p) = 0}。这是**目标参数（estimand）**，是想要估计的量。
- **H**：粗糙度指数（roughness index），H = 1/p₀。在分数布朗运动情形下 H 即 Hurst 参数。
- **W(L,K,π,q,t,x)**：归一化幂变差统计量，见下文定义。
- **Δ_I x**：路径 x 在区间 I 上的增量，Δ_I x = x(v) - x(u)。
- **ω_x(h)**：路径 x 的连续模，ω_x(h) = sup_{|t-s|≤h} |x(t) - x(s)|。
- **Λ_K**：Λ_K = M_{L(K)} N_K^{1/p₀}，其中 M_{L(K)} = max_{J∈π_{L(K)}} |Δ_J x| 是细网格上的最大增量，N_K 是粗网格的区间数。这是**收敛速率的关键量**。
- **δ_K**：δ_K = |π_{L(K)}|，即细网格大小。

**模型**：

- **数据生成机制**：路径 x 是确定性的（pathwise 框架），但满足一定的正则性假设（Hölder 连续）。观测数据是 x 在划分 π_L 上的值 {x(t_L^j)}。
- **统计模型**：这不是一个传统意义上的概率模型——没有误差项、没有随机抽样。相反，这是一个**确定性路径的离散观测问题**。不确定性来自"我们只看到有限个采样点，却想推断路径的全局粗糙度"。
- **已知 vs 未知**：已知的是采样值 {x(t_L^j)} 和划分结构 π_L；未知的是路径 x 的全局性质（Hölder 指数、变差指数 p₀）。

**可观测数据**：

- 研究者实际能观测到的是：路径在细网格 π_{L(K)} 上的值 {x(t_{L(K)}^j)}。
- 从这些值可以计算：细网格上的 p-次幂变差和 D_{L(K),I}(q)（对每个粗区间 I），以及粗网格上的幂变差和 S_K(q)。
- **不可观测**：路径在非采样点的值、路径的全局 Hölder 正则性、临界变差 [x]^(p₀) 是否存在。

#### 第二步：最小内核

**核心估计量**：归一化幂变差统计量

W(L,K,π,q,t,x) = Σ_{I=[u,v]∈π_K, v≤t} |I| · |Δ_I x|^q / D_{L(K),I}(q)

其中 D_{L(K),I}(q) = Σ_{J∈π_{L(K)}, J⊆I} |Δ_J x|^q 是粗区间 I 内细网格上的 q-次幂变差和。

**核心思想**：在粗区间 I 上，|Δ_I x|^q 度量了粗尺度增量的大小，而 D_{L(K),I}(q) 度量了细尺度局部增量之和。如果路径的粗糙度指数为 H = 1/p₀，那么：

- 当 q < p₀ 时，细尺度增量之和 D_{L(K),I}(q) 相对于粗尺度增量 |Δ_I x|^q 会**发散**（因为细增量虽然小，但数量多，且 q < p₀ 时"小增量"的贡献不够小），所以 W 趋于 0。
- 当 q > p₀ 时，细尺度增量之和 D_{L(K),I}(q) 相对于粗尺度增量 |Δ_I x|^q 会**趋于 0**（因为细增量太小，q > p₀ 时"小增量"的贡献更小），所以 W 趋于 ∞。
- 当 q = p₀ 时，两者**同阶**，W 趋于某个正常数（在归一化条件下趋于 T）。

因此，**估计方程 W(L,K,π,q,T,x) = T 的解 ˆp 就逼近 p₀**。

**最小例子**：考虑分数布朗运动 B^H，H ∈ (0,1)，p₀ = 1/H。取均匀划分 π_K（粗）和 π_{L(K)}（细），L(K) = ⌈aK⌉, a > 1。则：

- 粗尺度增量：Δ_I B^H ≈ |I|^H · ξ_I，其中 ξ_I 是标准正态（近似）。
- 细尺度增量之和：D_{L(K),I}(q) ≈ |I| · |J|^q · E|ξ|^q · (细区间数) = |I| · (|I|/2^{L-K})^q · 2^{L-K} · E|ξ|^q = |I|^{qH+1} · 2^{(L-K)(1-qH)} · E|ξ|^q。

因此：
W(L,K,π,q,T,x) ≈ Σ_I |I| · (|I|^q · |ξ_I|^q) / (|I|^{qH+1} · 2^{(L-K)(1-qH)} · E|ξ|^q)
= Σ_I |ξ_I|^q / (|I|^{qH} · 2^{(L-K)(1-qH)} · E|ξ|^q)
= 2^{K(qH-1)} · 2^{(L-K)(qH-1)} · (1/E|ξ|^q) · Σ_I |ξ_I|^q
= 2^{L(qH-1)} · (1/E|ξ|^q) · Σ_I |ξ_I|^q。

当 q < p₀ = 1/H 时，qH - 1 < 0，所以 2^{L(qH-1)} → 0，W → 0。
当 q > p₀ 时，qH - 1 > 0，所以 2^{L(qH-1)} → ∞，W → ∞。
当 q = p₀ 时，qH - 1 = 0，W ≈ (1/E|ξ|^{p₀}) · Σ_I |ξ_I|^{p₀} ≈ (1/E|ξ|^{p₀}) · 2^K · E|ξ|^{p₀} = 2^K = T/|π_K|。

这里需要归一化：W/T = W/2^K ≈ 1。这正是估计方程 W = T 的含义。

**这个例子的要点**：估计量的行为完全由 qH - 1 的符号决定。当 q 从下方逼近 p₀ 时，W 从 0 跳到 ∞，这个"跳变点"就是 p₀。收敛速率由 Λ_K = M_{L(K)} N_K^{1/p₀} 控制，在分数布朗运动情形下 Λ_K ≈ 2^{-K(1-H)}·2^{K/p₀} = 2^{-K(1-H)}·2^{KH} = 2^{-K(1-2H)}（当 H < 1/2 时趋于 0）。

**为什么这个例子是"最小内核"**：它展示了估计量的全部核心机制——通过比较粗尺度与细尺度的相对行为来识别临界指数。所有一般性假设（Hölder 正则性、局部临界幂和界、尺度分离）都是为了确保这个机制在更一般的路径上仍然成立。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：从离散采样观测中非参数估计连续路径的变差指数（粗糙度），建立了基于归一化幂变差的估计量的一致性理论。
2. **核心工具/方法**：归一化幂变差统计量 W(L,K,π,q,t,x)，通过比较粗尺度增量与细尺度局部幂变差和的比值来识别临界指数 p₀。
3. **主要结论**：在 Hölder 正则性、粗尺度临界幂和非退化、细尺度临界幂和一致有界、以及两个采样尺度分离的条件下，估计量逐点一致收敛到 p₀，收敛速率为 O(1/log(1/|π_K|))；对分数布朗运动和 Takagi–Landsberg 函数给出了具体应用。

#### 关键设定与假设

**设定**：

- 路径 x ∈ C([0,T], ℝ)，π = (πₙ) 是细化划分序列（πₙ ⊆ πₙ₊₁），网格趋于零。
- 粗尺度 K 和细尺度 L(K) 满足 L(K) > K，且 L(K) - K → ∞。
- 参数区间 P = [p⁻, p⁺] ⊂ (1, ∞)，p₀ ∈ (p⁻, p⁺)。

**假设（Assumption 1）**：

1. **平衡划分**：存在 B > 0 使得 |πₙ|/πₙ ≤ B（πₙ 为最小区间长度）。这确保划分不会太不均匀。
2. **Hölder 正则性**：x ∈ C^{H-}，即对任意 α < H，x 是 α-Hölder 连续的。这给出了路径粗糙度的上界。
3. **粗尺度临界幂和非退化**：存在常数 0 < c₀ ≤ C₀ < ∞ 使得 c₀ ≤ S_K(p₀) ≤ C₀ 对所有充分大的 K。这确保了粗尺度上的临界幂和不会退化到 0 或发散到 ∞。
4. **细尺度局部临界幂和一致有界**：存在常数 0 < c₁ ≤ C₁ < ∞ 使得 c₁|I| ≤ D_{L(K),I}(p₀) ≤ C₁|I| 对所有粗区间 I ∈ π_K 和充分大的 K。这确保了细尺度上的局部临界幂和与区间长度成正比。

**相比已有文献的放宽/强化**：

- **放宽**：不要求临界变差收敛（即不要求 S_K(p₀) 收敛到某个极限），只要求非退化（有界且远离 0）。这比 [NS02] 和 [HS25b] 的假设更弱。
- **放宽**：不要求有限样本统计量的单调性（即 W(L,K,π,q,T,x) 作为 q 的函数不必单调），因此不需要唯一性假设。
- **强化**：要求细尺度局部临界幂和的一致有界性（假设 4），这是已有文献中未明确提出的条件。

#### 主要结果

**定理 3.3（一致性 + 误差界）**：

- 假设 Assumption 1 和尺度分离条件 δ_K ≤ C|π_K|^a（a > 1）成立。
- 则 Λ_K = M_{L(K)} N_K^{1/p₀} → 0。
- 对任意 ε > 0，当 K 充分大时，估计方程 W(L(K),K,π,q,T,x) = T 在 [p⁻, p⁺] 中有解，且所有解都落在 (p₀ - ε, p₀ + ε) 内。
- 收敛速率：|ˆp - p₀| ≤ C₂ / log(1/Λ_K) ≤ C₃ / log(1/|π_K|)。

**证明路线**：

1. **上界估计**（q < p₀ 时 W → 0）：利用 Hölder 不等式和细尺度局部临界幂和的上界，证明 W(L,K,π,q,T,x) ≤ C · Λ_K^{p₀-q} → 0。
2. **下界估计**（q > p₀ 时 W → ∞）：利用粗尺度临界幂和的非退化性和细尺度局部临界幂和的下界，证明 W(L,K,π,q,T,x) ≥ c · Λ_K^{-(q-p₀)} → ∞。
3. **根的存在性**：W 关于 q 连续（因为 x 连续且所有增量非零），且 W(q) 在 q < p₀ 时趋于 0、在 q > p₀ 时趋于 ∞，由介值定理保证根的存在。
4. **根的集中性**：对任意 ε > 0，当 K 充分大时，W(q) < T 对所有 q ≤ p₀ - ε 成立，W(q) > T 对所有 q ≥ p₀ + ε 成立，因此所有根都在 (p₀ - ε, p₀ + ε) 内。
5. **收敛速率**：将 W(q) 的上下界代入根的条件 W(ˆp) = T，解出 |ˆp - p₀| 的上界。

**关键技术技巧**：

- **Hölder 不等式**：用于将细尺度幂变差和与粗尺度增量联系起来。
- **尺度分离**：通过 δ_K ≤ C|π_K|^a（a > 1）确保细网格远细于粗网格，使得细尺度信息能够"分辨"粗尺度行为。
- **介值定理**：用于证明根的存在性，避免了单调性假设。
- **对数化**：将乘性误差转化为加性误差，从而得到对数收敛速率。

#### 对分数布朗运动的应用（定理 6.3）

- 对分数布朗运动 B^H，p₀ = 1/H。
- 在采样规则 L(K) = ⌈aK⌉（a > 1）下，证明了强一致性。
- 关键验证：分数布朗运动满足 Assumption 1 的所有条件（Hölder 正则性、临界幂和非退化、局部临界幂和界）。
- 收敛速率：O(1/K)（因为 |π_K| = 2^{-K}，所以 log(1/|π_K|) = K log 2）。

#### 对 Takagi–Landsberg 函数的应用（定理 5.2）

- 对带符号的 Takagi–Landsberg 函数，得到了更精细的均匀渐近公式。
- 关键结果：W(L,K,π,q,1,x) = 2^{d(Hq-1)}(1 + O_P(ρ^K + ρ^d))，其中 d = L - K，ρ = 2^{-(1-H)}。
- 这给出了根的显式误差界：|ˆp - p₀| ≤ C_P (ρ^K + ρ^d)/(d)。

#### 稳定性结果（命题 7.1）

- 如果 x 满足 Assumption 1，则以下变换保持 Assumption 1：
  1. 加上更光滑的扰动：y = x + v，v ∈ C^γ，γ > H；
  2. 乘以光滑函数：y = a·x + b，a,b ∈ C¹，min|a| > 0；
  3. 光滑复合：y = F(x)，F ∈ C¹，inf|F'| > 0。
- 应用：分数 Ornstein–Uhlenbeck 过程的估计量强一致。

#### 数值实验（第 8 节）

- **Takagi–Landsberg 函数**：精确计算 p-次变差，验证估计量收敛到真实 H。表 1 显示估计值随 L 增加趋近真实 H，且 H 接近 1 时收敛较慢（与理论预测一致）。

#### 🔎 结论是否比证明窄

- **定理 3.3 的假设 4（细尺度局部临界幂和一致有界）** 在正文中只对分数布朗运动和 Takagi–Landsberg 函数验证了，但作者在讨论中声称"适用于更一般的路径"。这一推广并未在论文中严格证明，属于**证明窄于声称**。
- **定理 6.3 的收敛速率**：作者声称 O(1/K)，但证明中只给出了 O(1/log(1/|π_K|)) 的通用界。对分数布朗运动，O(1/K) 的速率依赖于对 Λ_K 的更精细估计，这一估计在论文中只是简要提及（"using the p-roughness property"），未给出完整证明。
- **例 5.5 的"一致性"**：作者展示了即使临界变差不收敛，估计量仍然一致。但这一结论只在特定的振荡系数序列下验证，**未给出一般性的充分条件**。作者在讨论中承认"我们不知道在什么条件下临界变差的不收敛不影响一致性"。
- **无渐近分布理论**：论文只证明了逐点一致性，未给出渐近正态性或置信区间。作者在讨论中明确说"渐近分布理论留待未来工作"。

### 四、开放问题

1. **渐近分布理论**（扎根于第 9 节讨论）：作者明确说"asymptotic normality of the estimator requires further analysis"。要证明什么：在什么条件下，√N(ˆp - p₀) 依分布收敛到正态？方差是多少？这需要建立 W(L,K,π,q,T,x) 作为 q 的函数的弱收敛理论，可能涉及经验过程或高斯近似。

2. **最优收敛速率**（扎根于定理 3.3 的速率 O(1/log(1/|π_K|))）：这个速率是否是最优的？是否存在更快的估计量？要证明什么：建立 minimax 下界，比较不同估计量（如基于系数能量的 [HS25b]）的速率。这需要刻画"从离散观测估计变差指数"这一问题的统计难度。

3. **临界变差不收敛时的一致性条件**（扎根于例 5.5）：作者展示了振荡临界幂和情形下的一致性，但未给出一般条件。要证明什么：找出"临界变差不收敛但估计量一致"的充分必要条件。这可能涉及路径的局部振荡结构（如变差测度的奇异部分）。

4. **潜在粗糙度的估计**（扎根于第 1 节引言）：作者明确说"latent roughness is not treated here"。要证明什么：当观测的是潜在波动率的函数（如积分方差）而非路径本身时，如何估计粗糙度？这需要结合测量误差模型和反卷积技术。

5. **自适应选择粗尺度 K**（扎根于第 8.2 节图 3）：作者展示了 K 的选择对精度有显著影响，但未给出数据驱动的选择准则。要证明什么：如何从数据中自适应选择 K（或 L 与 K 的比例 a）？这可能涉及偏差-方差权衡的刻画。

6. **多维路径与函数型数据**（扎根于第 9 节讨论）：作者提到"extension to multidimensional paths is straightforward"，但未给出细节。要证明什么：对 ℝ^d 值路径，如何定义归一化幂变差？收敛速率是否依赖于维数 d？
