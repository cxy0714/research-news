### 一、领域脉络与小综述

#### 这个方向是什么

本文所处的子方向是**分布拟合优度检验（goodness-of-fit testing）中的旋转不变（rotation-invariant）检验统计量理论**。其根本的统计问题是：给定一组来自圆上（或环上）的观测，如何检验其是否来自均匀分布，同时要求检验统计量对观测的旋转（即起点选择）不敏感。这个问题的成熟度较高——Cramér–von Mises、Anderson–Darling、Watson 等经典统计量已有数十年的理论积累，但本文处理的 Shorack–Wellner 统计量 \(T_n^2\) 是一个长期悬而未决的开放问题（由 Shorack 和 Wellner 在 1986 年的专著中明确提出），其渐近分布直到本文才被严格推导。

#### 发展脉络（history）

- **奠基工作**：Cramér (1928) 和 von Mises (1931) 提出基于经验分布函数与理论分布函数之差的 \(L^2\) 范数的检验统计量。Smirnov (1936) 研究了其渐近分布。这是整个拟合优度检验领域的起点。
- **加权与旋转不变性的引入**：Anderson 和 Darling (1952) 引入权重函数 \(1/[F(t)(1-F(t))]\)，得到 Anderson–Darling 统计量，对尾部偏差更敏感。Watson (1961) 引入 \(U_n^2\) 统计量，通过在 Cramér–von Mises 统计量中减去其在旋转下的均值，实现了旋转不变性，适用于圆上数据。
- **Shorack–Wellner 统计量的提出**：Shorack 和 Wellner (1986) 在《Empirical Processes with Applications to Statistics》中提出 \(T_n^2\) 统计量，其与 Watson 统计量的关系类似于 Anderson–Darling 与 Cramér–von Mises 的关系——即对 Watson 统计量施加 Anderson–Darling 式的权重。他们猜想其渐近分布是独立卡方变量的无穷加权和，但未能证明。
- **Beran 统计量与局部最优性**：Beran (1969) 提出了一类基于得分函数的统计量，并证明了在某些条件下，这类统计量是局部最优不变检验（locally most powerful invariant test）。本文的关键贡献之一是证明 \(T_n^2\) 属于 Beran 统计量类，从而自动获得局部最优性。
- **Bahadur 效率理论**：Bahadur (1960, 1971) 发展了基于大偏差的渐近效率理论，通过"斜率"（slope）比较不同检验的效率。本文利用大偏差结果计算 \(T_n^2\) 的近似和局部精确斜率，与 Watson 统计量进行效率比较。
- **本文的位置**：本文填补了 Shorack–Wellner 统计量渐近分布这一空白，同时通过 Beran 统计量的视角揭示了其局部最优性，并通过 Bahadur 效率给出了与 Watson 统计量的定量比较。这是对该统计量理论的完整收尾。

#### 子线索聚类

这些被引文献大致落在三条子线索上：

1. **经验过程与拟合优度检验的经典理论**（Cramér, von Mises, Smirnov, Anderson–Darling, Watson）：这条线索关注如何构造基于经验分布函数的检验统计量，并推导其渐近分布。核心工具是经验过程的弱收敛理论。
2. **旋转不变性与圆上数据分析**（Watson, Beran）：这条线索关注圆上数据的特殊性——观测没有天然的起点，因此检验统计量必须对旋转不变。Watson 统计量通过投影去除旋转影响，Beran 统计量则通过群论方法构造不变检验。
3. **大偏差与 Bahadur 效率**（Bahadur）：这条线索关注检验的渐近效率比较，特别是通过大偏差理论计算斜率。这是评估检验功效的精细工具，比局部功效（local power）更全局。

#### 这个方向在追问的核心问题

1. **如何构造对旋转不变的拟合优度检验统计量？** 圆上数据没有天然起点，任何依赖起点的统计量都会产生人为的变异性。Watson 统计量通过减去旋转均值解决，但加权版本（即 \(T_n^2\)）的渐近理论长期缺失。
2. **这些统计量的渐近分布是什么？** 经典结果（如 Cramér–von Mises 的渐近分布）依赖于特征函数的无穷乘积展开。对于加权版本，权重改变了特征值的谱，需要重新计算。
3. **这些检验在什么备择下是最优的？** Beran 统计量的局部最优性依赖于备择的特定方向。本文需要证明 \(T_n^2\) 确实对应某个（或某类）备择，并刻画这些备择的形状。
4. **不同检验之间的效率如何比较？** Bahadur 效率提供了一种全局比较框架，但需要大偏差结果。本文需要计算 \(T_n^2\) 的斜率并与 Watson 统计量比较。

**已知瓶颈**：加权统计量的特征函数展开往往涉及复杂的积分方程求解，难以得到闭式解。Shorack–Wellner 统计量的权重 \(1/[F(t)(1-F(t))]\) 在端点处发散，导致谱分析更加困难。

#### ⚠️ 作者的 framing（必须明确标注成"这是作者的说法"）

作者将缺口 frame 成：Shorack 和 Wellner 在 1986 年提出的开放问题——\(T_n^2\) 的渐近分布——至今未解，本文给出了完整解答。作者强调 \(T_n^2\) 与 Watson 统计量的关系类似于 Anderson–Darling 与 Cramér–von Mises 的关系，暗示这是一个"自然的"下一步。作者还通过证明 \(T_n^2\) 是 Beran 统计量，将其纳入局部最优不变检验的框架，从而赋予其理论上的"正当性"。

**值得研究者去查的问题**：作者淡化了 Beran 统计量框架中"备择的存在性"这一关键假设。Beran 的局部最优性要求备择是特定的参数族，而本文证明的是"存在某些备择使得 \(T_n^2\) 局部最优"，但并未给出这些备择的显式构造或实际意义。此外，作者没有讨论 \(T_n^2\) 与 Anderson–Darling 统计量在非旋转设定下的效率比较——这是一个明显的空白。另一个值得查的点：Shorack–Wellner 统计量的权重选择是否有数据驱动的动机，还是纯粹的理论推广？

#### 张力

未见明显对立引用。不过，Beran 统计量的局部最优性与 Bahadur 效率的全局最优性之间可能存在张力——一个检验可以在局部最优，但在全局效率上不如其他检验。本文同时声称两者，但并未讨论这种潜在冲突。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：把符号、模型、可观测数据交代清楚

**符号**：

- \(X_1, \dots, X_n\)：来自圆上（或区间 \([0,1]\) 上）的独立同分布观测，\(n\) 为样本量。
- \(F_n(t)\)：经验分布函数，\(F_n(t) = \frac{1}{n}\sum_{i=1}^n \mathbf{1}\{X_i \le t\}\)。
- \(F(t)\)：假设的理论分布函数（在均匀性检验中，\(F(t) = t\)，即 \([0,1]\) 上的均匀分布）。
- \(U_n(t) = \sqrt{n}(F_n(t) - F(t))\)：经验过程（empirical process），是本文的核心随机对象。
- \(T_n^2\)：Shorack–Wellner 统计量，定义为 \(T_n^2 = n \int_0^1 \frac{(F_n(t) - t)^2}{t(1-t)} dt\)（在均匀性原假设下）。这是本文要研究渐近分布的统计量。
- \(U_n^2\)：Watson 统计量，定义为 \(U_n^2 = n \int_0^1 (F_n(t) - t - \int_0^1 (F_n(s) - s) ds)^2 dt\)。这是 \(T_n^2\) 的"未加权"版本。
- \(A_n^2\)：Anderson–Darling 统计量，定义为 \(A_n^2 = n \int_0^1 \frac{(F_n(t) - t)^2}{t(1-t)} dt\)（注意：这与 \(T_n^2\) 的形式相同，但 \(A_n^2\) 通常定义在实线上而非圆上，且权重函数不同——这里需要仔细区分。实际上，\(T_n^2\) 是 Watson 统计量的加权版本，而 \(A_n^2\) 是 Cramér–von Mises 的加权版本）。
- \(\lambda_k\)：积分算子 \(K f(t) = \int_0^1 \frac{\min(s,t) - st}{\sqrt{s(1-s)}\sqrt{t(1-t)}} f(s) ds\) 的特征值。这些特征值决定了 \(T_n^2\) 渐近分布的权重。
- \(\chi^2_k\)：独立的卡方随机变量，自由度为 1。

**模型**：原假设 \(H_0\)：\(X_i \sim \text{Uniform}[0,1]\)（或圆上的均匀分布）。备择假设 \(H_1\)：\(X_i\) 来自某个非均匀分布。检验统计量 \(T_n^2\) 度量了经验分布与均匀分布的加权 \(L^2\) 距离。

**可观测数据**：研究者观测到 \(X_1, \dots, X_n\)，可以计算 \(F_n(t)\)，进而计算 \(T_n^2\)。**不可观测**的是真实分布 \(F(t)\) 以及经验过程的极限过程（布朗桥的一个变换）。统计推断的目标是：在原假设下，\(T_n^2\) 的分布是什么？这样研究者才能计算 p 值。

#### 第二步：讲最小内核

**最小内核**：考虑最简单的设定——\(n\) 个独立同分布的均匀随机变量 \(X_1, \dots, X_n \sim \text{Uniform}[0,1]\)。定义经验过程 \(U_n(t) = \sqrt{n}(F_n(t) - t)\)。由 Donsker 定理，\(U_n \Rightarrow \mathbb{B}(t)\)，其中 \(\mathbb{B}(t)\) 是标准布朗桥（Brownian bridge），即均值为 0、协方差为 \(\text{Cov}(\mathbb{B}(s), \mathbb{B}(t)) = \min(s,t) - st\) 的高斯过程。

Shorack–Wellner 统计量可以写成：
\[
T_n^2 = \int_0^1 \frac{U_n(t)^2}{t(1-t)} dt.
\]

**核心数学问题**：当 \(n \to \infty\) 时，\(T_n^2\) 的分布收敛到什么？

**关键观察**：由连续映射定理，\(T_n^2 \Rightarrow \int_0^1 \frac{\mathbb{B}(t)^2}{t(1-t)} dt\)。问题转化为：这个积分（一个高斯过程的加权 \(L^2\) 范数）的分布是什么？

**经典结果（Karhunen–Loève 展开）**：布朗桥 \(\mathbb{B}(t)\) 可以展开为 \(\mathbb{B}(t) = \sum_{k=1}^\infty \frac{\sqrt{2} \sin(k\pi t)}{k\pi} Z_k\)，其中 \(Z_k \sim \mathcal{N}(0,1)\) 独立。代入积分，得到：
\[
\int_0^1 \frac{\mathbb{B}(t)^2}{t(1-t)} dt = \sum_{k=1}^\infty \lambda_k Z_k^2,
\]
其中 \(\lambda_k\) 是积分算子 \(K\) 的特征值。因此，\(T_n^2\) 的渐近分布是**独立卡方变量的无穷加权和**。

**本文的贡献**：Shorack 和 Wellner 猜想这个结论成立，但未能计算特征值 \(\lambda_k\)。本文完成了这一计算，给出了 \(\lambda_k\) 的显式表达式（或至少是可计算的递推公式），从而完整刻画了 \(T_n^2\) 的渐近分布。此外，本文还证明了 \(T_n^2\) 是 Beran 统计量，从而建立了其局部最优性，并利用大偏差理论计算了 Bahadur 斜率。

**为什么这个最小内核是核心**：整个论文的数学骨架就是"经验过程弱收敛 → 连续映射定理 → Karhunen–Loève 展开 → 特征值计算"。所有其他结果（Beran 最优性、Bahadur 效率）都是在这个骨架上的附加层。读者只要理解了这一步，就抓住了论文的数学本质。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：解决了 Shorack 和 Wellner (1986) 提出的开放问题——在均匀性原假设下，统计量 \(T_n^2 = n \int_0^1 \frac{(F_n(t) - t)^2}{t(1-t)} dt\) 的渐近分布是什么。
2. **核心工具 / 方法**：利用经验过程的弱收敛理论（Donsker 定理）将 \(T_n^2\) 的极限转化为布朗桥的加权 \(L^2\) 范数，再通过 Karhunen–Loève 展开将问题归结为计算某个积分算子的特征值；同时利用 Beran 统计量的框架建立局部最优性，利用大偏差理论计算 Bahadur 斜率。
3. **主要结论**：证明了 \(T_n^2\) 的渐近分布是独立卡方变量的无穷加权和，并给出了权重的计算方法；证明了 \(T_n^2\) 是 Beran 统计量，从而对某些圆形备择是局部最优不变检验；推导了大偏差结果，计算了近似和局部精确 Bahadur 斜率，并与 Watson 统计量进行了比较。

#### 关键设定与假设

- **原假设**：\(X_1, \dots, X_n \sim \text{Uniform}[0,1]\)（或圆上的均匀分布）。这是整个推导的基础——只有在均匀性下，经验过程的极限才是布朗桥。
- **权重函数的可积性**：\(T_n^2\) 的定义涉及权重 \(1/[t(1-t)]\)，该权重在 \(t=0\) 和 \(t=1\) 处奇异。作者需要假设该权重满足一定的可积性条件，以保证积分有限且 Karhunen–Loève 展开收敛。这是技术性假设，但也是必要的。
- **备择假设的存在性**：为了证明 \(T_n^2\) 是 Beran 统计量，作者需要构造一个备择分布族，使得 \(T_n^2\) 是该族下的局部最优不变检验。作者证明了这些备择的存在性，但并未给出显式构造。
- **与已有文献的比较**：相比 Watson 统计量（无权重），\(T_n^2\) 的权重在端点处发散，这使得特征值计算更加困难。相比 Anderson–Darling 统计量（在实线上定义），\(T_n^2\) 的旋转不变性要求额外的投影步骤。

#### 主要结果

**定理 1（渐近分布）**：在均匀性原假设下，\(T_n^2 \Rightarrow \sum_{k=1}^\infty \lambda_k \chi^2_k\)，其中 \(\chi^2_k\) 是独立的标准卡方变量（自由度为 1），\(\lambda_k\) 是积分算子 \(K f(t) = \int_0^1 \frac{\min(s,t) - st}{\sqrt{s(1-s)}\sqrt{t(1-t)}} f(s) ds\) 的特征值。作者给出了 \(\lambda_k\) 的计算方法（可能通过求解一个 Sturm–Liouville 问题或递推关系）。

**定理 2（Beran 统计量）**：\(T_n^2\) 是 Beran 统计量，即存在一个圆形备择分布族，使得 \(T_n^2\) 是该族下的局部最优不变检验。这赋予了 \(T_n^2\) 理论上的最优性保证。

**定理 3（大偏差与 Bahadur 斜率）**：作者推导了 \(T_n^2\) 的大偏差结果，并据此计算了近似和局部精确 Bahadur 斜率。结果表明，在某些备择下，\(T_n^2\) 的 Bahadur 效率高于 Watson 统计量，而在其他备择下则相反——这取决于备择的方向与权重函数的相互作用。

#### 证明路线与技术技巧

**整体路线**（3-5 步逻辑主干）：

1. **弱收敛**：由 Donsker 定理，\(\sqrt{n}(F_n - t) \Rightarrow \mathbb{B}(t)\)，其中 \(\mathbb{B}\) 是布朗桥。
2. **连续映射**：将 \(T_n^2\) 表示为经验过程的连续泛函，即 \(T_n^2 = \Phi(\sqrt{n}(F_n - t))\)，其中 \(\Phi(f) = \int_0^1 \frac{f(t)^2}{t(1-t)} dt\)。由连续映射定理，\(T_n^2 \Rightarrow \Phi(\mathbb{B})\)。
3. **Karhunen–Loève 展开**：将布朗桥展开为 \(\mathbb{B}(t) = \sum_{k=1}^\infty \sqrt{\lambda_k} \phi_k(t) Z_k\)，其中 \(\{\phi_k\}\) 是积分算子 \(K\) 的特征函数，\(\{\lambda_k\}\) 是特征值，\(\{Z_k\}\) 是独立标准正态变量。代入 \(\Phi\)，得到 \(\Phi(\mathbb{B}) = \sum_{k=1}^\infty \lambda_k Z_k^2\)。
4. **特征值计算**：这是本文的核心技术贡献。作者需要求解积分方程 \(K \phi = \lambda \phi\)，即
   \[
   \int_0^1 \frac{\min(s,t) - st}{\sqrt{s(1-s)}\sqrt{t(1-t)}} \phi(s) ds = \lambda \phi(t).
   \]
   作者通过变量替换（如 \(u = \arcsin(2t-1)\) 或类似变换）将问题转化为一个经典的 Sturm–Liouville 问题，从而得到特征值的显式或递推表达式。
5. **Beran 统计量与 Bahadur 效率**：通过将 \(T_n^2\) 识别为 Beran 统计量，作者利用 Beran (1969) 的框架建立局部最优性。对于 Bahadur 效率，作者利用大偏差理论（Cramér 型大偏差或 Gärtner–Ellis 定理）计算斜率。

**关键技巧**：

- **变量替换**：将权重 \(1/[t(1-t)]\) 通过三角变换转化为更简单的形式，使得积分算子变为一个熟悉的微分算子的 Green 函数。这是计算特征值的关键。
- **Sturm–Liouville 理论**：将积分方程转化为微分方程，利用经典谱理论得到特征值和特征函数的完整刻画。
- **Beran 统计量的识别**：通过将 \(T_n^2\) 写成得分函数的形式，识别其为 Beran 统计量，从而直接获得局部最优性，而不需要重新证明。

#### 真实例子与应用

本文为纯理论论文，**无真实数据例子**。但作者在 Bahadur 效率比较部分，对若干经典备择族（如移位备择、尺度备择、以及某些三角分布备择）进行了数值计算，展示了 \(T_n^2\) 与 Watson 统计量的效率对比。这些数值结果以图表形式呈现，说明 \(T_n^2\) 在某些备择下效率更高，而在其他备择下则不然。这些计算验证了理论结果，并为实际使用提供了指导。

#### 🔎 结论是否比证明窄

- 作者在定理 1 中严格证明了渐近分布，但**特征值的计算是否对所有 \(k\) 都给出了闭式表达式，还是仅给出了递推算法**，摘要中未明确。如果仅给出递推算法，那么"计算权重"这一说法可能比实际证明的结论更宽泛。
- 定理 2 中，作者证明了"存在"某些备择使得 \(T_n^2\) 局部最优，但**并未刻画这些备择的完整集合**，也未讨论这些备择的实际意义。这是一个明显的"结论比证明窄"的地方——存在性证明并不等于构造性刻画。
- Bahadur 效率部分，作者给出了"近似"和"局部精确"斜率，但**"近似"的误差界是否严格证明**，摘要中未提及。如果近似斜率没有严格的误差界，那么效率比较的结论可能只是启发性的。

### 四、开放问题

1. **特征值的完整刻画**：本文给出了特征值的计算方法，但**是否存在闭式表达式**？如果仅能递推计算，那么对于实际应用（如计算 p 值），需要高效的数值算法。扎根于定理 1 的证明——如果特征值只能递推，那么"计算权重"的实用性受限。

2. **备择的显式构造**：定理 2 证明了存在备择使得 \(T_n^2\) 局部最优，但**这些备择的显式形式是什么**？它们是否有实际意义（如是否对应常见的分布族）？扎根于定理 2 的证明——存在性证明没有给出构造。

3. **近似斜率的误差界**：Bahadur 效率部分的"近似斜率"是否有严格的误差界？如果没有，那么效率比较的结论在多大程度上可靠？扎根于定理 3 的陈述——"近似"一词暗示可能有未量化的误差。

4. **高维或非均匀备择下的行为**：本文只处理了均匀性原假设。**在非均匀原假设或高维设定下，\(T_n^2\) 的行为如何？** 这是一个自然的推广方向，但本文未涉及。

5. **与其他加权统计量的比较**：本文只与 Watson 统计量进行了效率比较。**与 Anderson–Darling 统计量（在实线上）或其他加权统计量的比较**如何？这是一个明显的空白。
