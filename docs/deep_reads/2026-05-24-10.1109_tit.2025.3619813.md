### 一、领域脉络与小综述

#### 这个方向是什么

本文研究的根本问题是：**在两张部分相关的随机图之间，如何恢复隐藏的顶点对应关系（即图匹配/对齐），以及需要多少"相关顶点"才能保证恢复成功**。这里的"部分相关"是关键——与经典的完全相关图匹配不同，本文允许两张图中只有一小部分顶点（诱导子图）之间存在相关性，其余顶点完全独立。这是一个信息论层面的问题：给定观测到的两张图，我们想知道在什么条件下（相关顶点数 m、图密度 p、相关系数 ρ 的组合），理论上存在（或不存在）能够恢复隐藏映射的估计量。该方向处于随机图论、信息论与高维统计推断的交叉地带，近年来因社交网络去匿名化、生物网络比对等应用而受到关注。从成熟度看，完全相关情形下的阈值已被基本解决（如 [WXY22]），而部分相关情形是当前的前沿。

#### 发展脉络

- **奠基工作**：问题框架由 [PG11] 提出，将图匹配问题形式化为在相关随机图上恢复潜在双射。早期工作 [NS08, NS09] 从社交网络去匿名化角度引入该问题，[BBM05, CSS06] 从模式识别角度，[SXB08, VCL+15] 从计算生物学角度。这些工作确立了图匹配作为跨领域基础问题的地位。
- **完全相关情形的阈值刻画**：核心进展来自 [WXY22]，该工作**"settled the sharp reconstruction thresholds of random graph matching"**（作者原话），即完全相关 Erdős-Rényi 图匹配的精确阈值。同时 [GML21] 证明了稀疏情形下部分恢复的不可能性条件，[HM23] 给出了部分恢复的充分条件（`np(p∨ρ) ≳ log(1+ρ/p) ∨ 1`）和必要条件（`n ≳ d_KL(p+ρ−pρ ∥ p) log n`）。[DD23b] 在稀疏情形下证明了精确阈值。这些工作共同确立了完全相关情形下的信息论极限。
- **部分相关模型的提出**：本文（以及其会议版本 [HSY24]）首次系统提出部分相关模型，其中仅一对诱导子图相关。这是对完全相关模型的自然推广，但引入了新的困难：**不仅要恢复映射，还要先识别哪些顶点是相关的**（即支持集恢复）。
- **本文的位置**：作者将问题分解为两个子问题——支持集恢复（找到 S* 和 T*）和映射恢复（在支持集内匹配）。本文的核心贡献是给出了部分相关模型下 partial recovery 和 exact recovery 的**最优阈值**，并指出新阈值 `log n / (p²φ(γ))` 反映了支持集恢复的难度，这是完全相关模型中没有的。

#### 子线索聚类

1. **图匹配的算法与计算复杂性**：[BES80, Bol82, DCKG19, GM20, DMW21, MRT23, MWXY23, DL23, MS24]。这条线关注如何在多项式时间内近似或精确匹配，例如 [MWXY23] 通过计数"烛台"（chandeliers）实现多项式时间匹配，[DMWX21] 提出基于度序列的算法。这些工作与本文的信息论阈值互补——本文不关心计算效率，只关心信息极限。
2. **相关性的检测与恢复阈值**：[GML21, WXY22, HM23, DD23b, DD23a]。这条线关注在何种参数条件下检测相关性或恢复映射是可能的。本文直接建立在这条线上，特别是 [WXY22] 的完全相关阈值作为其特例。
3. **低度多项式与计算-信息差距**：[HS17, Hop18, KWB19, MWXY24, DDL23]。这条线关注计算有效算法与信息论最优之间的差距。作者在 Related Work 中明确提到 [MWXY24] 证明了当 ρ² ≤ 1/polylog(n) 时不存在多项式时间检测算法，暗示部分相关模型可能存在类似的计算-信息差距，但本文不处理计算复杂性。

#### 这个方向在追问的核心问题

1. **最小相关顶点数**：需要多少个相关顶点 m 才能保证恢复成功？本文给出了精确答案：partial recovery 需要 m ≳ log n / (p²φ(γ))，exact recovery 需要 m ≳ log n / (p²φ(γ)) ∨ log(1/(p²γ)) / (p²γ)。
2. **相关系数与图密度的权衡**：ρ 和 p 如何共同决定恢复难度？本文通过参数 γ = ρ(1−p)/p 统一刻画，揭示了弱信号（γ = O(1)）与强信号（γ = ω(1)）之间的相变。
3. **支持集恢复 vs 映射恢复**：哪个子问题更难？本文的结论是，在部分相关模型下，支持集恢复的难度主导了整体阈值（在弱信号区），这与完全相关模型有本质区别。

#### ⚠️ 作者的 framing

作者将本文的贡献框架为"**在部分相关模型下建立 partial recovery 和 exact recovery 的最优阈值**"，并强调新阈值 `log n / (p²φ(γ))` 反映了支持集恢复的难度。这是作者的说法——他们把自己放在 [WXY22] 的"自然推广"位置上。被淡化的竞争路线包括：(1) 计算复杂性——作者明确说"we do not address polynomial algorithms or the computational hardness on partial models"，但 [MWXY24] 的结果暗示可能存在计算-信息差距；(2) 更一般的相关结构——本文假设所有相关边的相关系数相同，且相关子图大小 m 已知，这些假设在实际中可能过强。**值得去查的问题**：作者在 Remark 5 中提到 m 未知时的惩罚估计器，但未给出理论保证——这是否是一个真正的开放问题？另外，[DD23b] 在完全相关情形下证明了精确常数，本文只给出了常数因子，这是否可以改进？

#### 张力

未见明显对立引用。但有一个微妙的张力： [HM23] 给出的部分恢复充分条件 `np(p∨ρ) ≳ log(1+ρ/p) ∨ 1` 与本文的阈值 `m ≳ log n / (p²φ(γ))` 在形式上不同，前者关注 n 的规模，后者关注 m 的规模。两者在 m = n 时是否一致？作者在 Remark 1 中声称与 [WXY22] 匹配，但未与 [HM23] 直接对比。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

**符号清单**（逐个点名）：

| 符号 | 含义 | 类型 |
|------|------|------|
| n | 每张图的顶点数 | 已知常数（规模参数） |
| m | 相关顶点数（|S*| = |T*| = m） | 已知常数（规模参数） |
| p | 边概率（Erdős-Rényi 参数） | 已知常数 |
| ρ | 相关系数（边相关性） | 已知常数 |
| G₁, G₂ | 观测到的两张图，各 n 个顶点 | 可观测数据 |
| S* ⊆ V(G₁) | 图 G₁ 中参与相关的顶点子集 | 潜在（不可观测） |
| T* = π*(S*) ⊆ V(G₂) | 图 G₂ 中对应的相关顶点子集 | 潜在（不可观测） |
| π* : S* → T* | 真实的潜在双射（顶点对应关系） | 目标参数（estimand） |
| π̂ : Ŝ → V(G₂) | 估计器输出的映射 | 估计量 |
| β_e(G) | 边 e 的权重（0 或 1） | 可观测 |
| overlap(π*, π̂) | 正确匹配比例 | 损失函数 |
| γ = ρ(1−p)/p | 相对信号强度 | 派生参数 |
| φ(γ) = (1+γ)log(1+γ) − γ | 信号函数 | 派生参数 |

**模型（数据生成机制）**：

- **部分相关 Erdős-Rényi 模型**（Definition 4）：
  - 存在潜在子集 S* ⊆ V(G₁)，|S*| = m，以及单射 π* : S* → V(G₂)。
  - 对任意 u, v ∈ S*：边对 (β_uv(G₁), β_{π*(u)π*(v)}(G₂)) 服从相关系数为 ρ 的二元 Bernoulli 分布，边缘概率均为 p。即：P(两条边都存在) = p² + ρp(1−p) = p₁₁。
  - 对所有其他边对（至少一端不在 S* 内，或不对应）：两条边独立，各以概率 p 存在。
  - 观测到 G₁ 和 G₂ 的完整边集，但不知道 S* 和 π*。

- **部分相关 Gaussian Wigner 模型**（Definition 5）：
  - 同上，但每条边是标准正态权重，相关边对服从相关系数为 ρ 的二元正态分布。

**可观测 vs 潜在**：可观测的是两张图的全部边（共 2·C(n,2) 个二元/实值变量）。潜在的是 S*、T*、π*。注意：**m 是已知的**（作者假设已知相关顶点数），但 S* 的位置和 π* 的对应关系未知。

#### 第二步：最小内核

**核心问题**：给定观测 (G₁, G₂)，能否恢复 π*？

**最小内核（最简特例）**：考虑 n 很大、m 很小、p 和 ρ 为常数的情形。此时每张图都是稠密图，任意两个候选顶点对之间都有大量"证据"（共同邻居、边模式等）。

**为什么难**：候选映射的数量是组合爆炸的——从 n 个顶点中选 m 个，再与另一张图的 m 个顶点匹配，共有 C(n,m)² · m! 种可能。信息论阈值回答的问题是：**在什么条件下，正确的 π* 在所有这些候选中"脱颖而出"？**

**本文的核心数学贡献**：作者证明了 partial recovery 的阈值是
$$m \gtrsim \frac{\log n}{p^2 \phi(\gamma)}$$
其中 φ(γ) = (1+γ)log(1+γ) − γ，γ = ρ(1−p)/p。

**直觉**：每个正确匹配的顶点对贡献约 p²φ(γ) 的"信号"（KL 散度），而错误匹配的顶点对之间是独立的。要区分正确映射和错误映射，需要总信号超过 log n（候选数量的对数）。因此 m · p²φ(γ) ≳ log n。

**为什么难（技术层面）**：难在**相关性结构**。错误匹配的边之间不是独立的——一个错误映射可能在某些边上"碰巧"与正确映射重合，导致相关性。作者引入 correlated functional digraph 来精确刻画这种相关性，将边集分解为独立的路径和环，从而可以用 cumulant generating function 来界定错误概率。这是本文最核心的技术创新。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：在部分相关 Erdős-Rényi 模型和部分相关 Gaussian Wigner 模型下，确定 partial recovery 和 exact recovery 的信息论阈值（即所需的最小相关顶点数 m）。
2. **核心工具/方法**：引入 correlated functional digraph 来分解边集的相关性结构，结合低阶累积量生成函数（cumulant generating functions）的上界、广义 Fano 不等式和 Chernoff 型不等式，分别建立可达性（possibility）和不可达性（impossibility）结果。
3. **主要结论**：partial recovery 的阈值是 m ≍ log n / (p²φ(γ))；exact recovery 在 Erdős-Rényi 模型下的阈值是 m ≍ log n / (p²φ(γ)) ∨ log(1/(p²γ))/(p²γ)，在 Gaussian Wigner 模型下是 m ≍ log n / log(1/(1−ρ²))。特别地，在 Gaussian Wigner 模型中 partial 和 exact recovery 的阈值重合。

#### 关键设定与假设

- **假设 1（已知 m）**：相关顶点数 m 已知。作者在 Remark 5 中讨论了 m 未知时的惩罚估计器，但未给出理论保证。
- **假设 2（同质相关性）**：所有相关边对的相关系数相同（ρ）。这排除了异质相关结构。
- **假设 3（已知 p, ρ）**：图密度 p 和相关系数 ρ 已知。估计器设计依赖这些参数。
- **假设 4（p ≥ 1/n）**：在 Erdős-Rényi 模型中假设 p ≥ 1/n，排除完全稀疏情形。
- **相比已有文献的放宽**：与 [WXY22] 的完全相关模型相比，本文允许 m < n（部分相关），这是本质性推广。与 [HM23] 相比，本文给出了 exact recovery 的阈值，而 [HM23] 只处理 partial recovery。

#### 主要结果

**定理 1（Erdős-Rényi，partial recovery）**：存在常数 c₁(δ) 使得当 m ≥ c₁(δ) log n / (p²φ(γ)) 时，存在估计器以概率 1−o(1) 达到 overlap ≥ δ；反之，当 m ≤ c₂(c,δ) log n / (p²φ(γ)) 时，任何估计器以概率 ≥ 1−c 失败。

**定理 2（Erdős-Rényi，exact recovery）**：阈值是 m ≍ log n / (p²φ(γ)) ∨ log(1/(p²γ))/(p²γ)。在弱信号区（γ = O(1)），exact 和 partial 的阈值一致；在强信号区（γ = ω(1)），exact recovery 需要更多顶点，因为此时挑战在于给定支持集后的精确匹配。

**定理 3（Gaussian Wigner）**：阈值是 m ≍ log n / log(1/(1−ρ²))，且 partial 和 exact recovery 的阈值重合。这是因为 Gaussian 权重提供了更强的信号，使得支持集恢复不再是瓶颈。

#### 证明路线与技术技巧

**可达性（上界）**：
1. 构造估计器：最大化总相似度分数（公式 6），即对每个候选映射 π 计算所有边对的相似度之和。
2. **关键步骤**：将边集 E 分解为独立部分。作者引入 correlated functional digraph，其顶点是边，边表示相关性。该图的最大度 ≤ 2（因为每条边最多与两条其他边相关），因此可以分解为路径和环。
3. **核心引理（引理 1）**：对任意 π，log E[e^{tβ_E(H^f_π)}] ≤ |E|/2 · κ₂^C(t) + L·(κ₁^C(t) − 1/2·κ₂^C(t))，其中 L 是自环数。这个引理将高阶累积量用低阶累积量（κ₁, κ₂）来界定，是证明的关键。
4. 然后对每个 k 用 Chernoff 型不等式，再对 k 从 1 到 m 做并界（union bound），利用 |T_k| ≤ n^{3k}/k!² 来吸收组合项。

**不可达性（下界）**：
1. 使用广义 Fano 不等式。构造一个 packing set M_δ，其中任意两个映射的距离 ≥ (1−δ)m。
2. **关键步骤**：计算互信息 I(π*; G₁, G₂) 的上界。作者利用 KL 散度的可加性，将互信息分解为每个边对的贡献，得到 I ≤ C·m²·p²φ(γ)（Erdős-Rényi）或 I ≤ C·m²·log(1/(1−ρ²))（Gaussian）。
3. 对 partial recovery 的下界，需要构造 packing set 使得任意两个映射的 overlap < δ，这需要更精细的组合论证（引理 5 的 (20)）。

**技术技巧点名**：
- **Correlated functional digraph**：将边集的相关性结构图形化，使得可以分解为独立分量。这是本文的核心创新，用于处理部分相关模型中特有的"部分重叠"问题。
- **低阶累积量生成函数**：用 κ₁, κ₂ 来界定高阶累积量，避免了直接计算高阶矩的困难。
- **广义 Fano 不等式**：通过构造 packing set 和上界互信息来得到下界。
- **Hanson-Wright 不等式**：用于 Gaussian 情形下二次型的集中不等式。
- **Chernoff 不等式**：用于 Bernoulli 情形的尾概率估计。

#### 真实例子与应用

本文为纯理论论文，**无真实数据实验**。但作者在引言中提到了几个应用场景：
- **社交网络去匿名化**：不同平台上的同一用户群体构成相关子图，需要识别跨平台的对应关系 [NS08, NS09]。
- **生物网络比对**：蛋白质相互作用网络的跨物种比对 [SXB08, VCL+15]。
- **模式识别**：图像中的图结构匹配 [BBM05, CSS06]。

作者在 Remark 2 中讨论了与 [DDG24] 的联系：在稀疏情形下，最大边重叠可以在多项式时间内近似，暗示本文的阈值在计算上可能是可达的。

#### 🔎 结论是否比证明窄

1. **定理 1 的常数**：可达性证明中的常数 c₁(δ) 依赖于 δ，但作者未给出显式表达式。下界中的常数 c₂(c,δ) 同样不显式。这意味着阈值只确定到常数因子，而非精确常数。
2. **Gaussian 情形的 partial recovery 下界**：定理 3 的下界只证明了 partial recovery 不可能（即任何估计器的 overlap < δ 的概率 ≥ 1−c），但未给出 exact recovery 的下界。作者在 Remark 1 中声称 exact 和 partial 阈值重合，但下界证明似乎只覆盖了 partial。
3. **m 已知的假设**：作者在 Remark 5 中承认 m 未知时的处理是启发式的，没有理论保证。这意味着实际应用中如果 m 估计不准，阈值可能失效。
4. **同质相关性假设**：所有相关边的 ρ 相同。如果 ρ 在不同边上变化，阈值可能不同，但作者未讨论。

### 四、开放问题

1. **精确常数**：定理 1-3 的阈值只确定到常数因子。能否确定精确常数？作者在 Remark 1 中声称与 [WXY22] 匹配，但 [WXY22] 的常数也是非显式的。要确认这是否是真正的 gap，可对比 [DD23b] 在完全相关情形下的精确常数结果。

2. **计算-信息差距**：作者在 Related Work 中引用了 [MWXY24] 的低度多项式下界（ρ² ≤ 1/polylog(n) 时无多项式时间算法），但本文只给出信息论阈值。在部分相关模型下，是否存在类似的计算-信息差距？这是否意味着存在一个"计算阈值"高于信息论阈值？——扎根于 Related Work 中对 [MWXY24] 的讨论。

3. **m 未知时的自适应估计**：作者在 Remark 5 中提出惩罚估计器但未分析。能否证明在 m 未知时，自适应估计器达到同样的阈值？这需要发展新的技术来处理模型选择与估计的耦合。

4. **异质相关结构**：如果相关边的相关系数 ρ 随边变化，阈值如何改变？这可能需要更精细的 correlated functional digraph 分析。

5. **稀疏情形**：作者假设 p ≥ 1/n，但 [DD23b] 在完全相关情形下处理了 p = n^{-1+o(1)} 的稀疏情形。部分相关模型的稀疏情形是否也有类似的精确阈值？——扎根于 Related Work 中对 [DD23b] 的引用。

6. **检测与恢复的关系**：作者在 Related Work 中提到 [WXY23] 研究了相关检测问题。在部分相关模型下，检测问题（判断两张图是否相关）的阈值是否与恢复问题的阈值一致？如果检测比恢复容易，那么是否存在一个中间区域，其中检测可能但恢复不可能？

**提醒**：要确认上述问题是否是真 gap，建议去读以下近期论文的引言部分（约 5 篇）：[DD23b]（精确阈值）、[MWXY24]（低度多项式下界）、[DDG24]（多项式时间近似）、[HM23]（部分恢复的充分/必要条件）、[WXY23]（检测阈值）。如果这些论文的引言都指向同一个未解决问题，那就是共识性 gap；如果它们互相矛盾或在不同条件下给出相反结论，那可能是更值得深挖的张力点。
