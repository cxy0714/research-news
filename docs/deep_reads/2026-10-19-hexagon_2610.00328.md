### 一、领域脉络与小综述

#### 这个方向是什么

本文所处的子方向是**组合稳定性（combinatorial stability）与覆盖族（covering families）的鲁棒性**：当一个集合族的每个成员都经历少量删除后，整个并集还能保留多少？这个问题在计算复杂性理论（尤其是证明复杂性，proof complexity）中有直接动机——Alekseev 和 Gaevoy 在研究基于奇偶校验的消解系统 Res(⊕) 的多项式深度下界时，需要一个关于仿射子空间并集稳定性的组合引理。该子方向的核心张力在于：**局部信息（每个集合保留了多少）与全局信息（并集保留了多少）之间的鸿沟**。没有结构假设时，删除可以精确地集中在多重覆盖度低的点上，从而造成不成比例的全局损失；而本文表明，即使集合是结构良好的仿射子空间、余维数很小、并集覆盖整个空间，这个鸿沟依然无法弥合。

#### 发展脉络（history）

1. **奠基工作：覆盖与删除的朴素直觉**。组合学中一个经典观察是：如果一族集合覆盖了全集，且每个集合只删除一小部分，那么并集通常不会损失太多——前提是删除是"均匀"或"随机"的。但确定性删除可以对抗这种直觉：选择那些只被少数集合覆盖的点删除，就能以很小的局部代价造成很大的全局损失。这是本文引言第一句就点出的"无结构假设时的障碍"。

2. **Alekseev–Gaevoy 猜想（2026）**：在 Res(⊕) 下界研究中，Alekseev 和 Gaevoy [1, Conjectures 1.4 and 4.2] 提出了一个稳定性断言：若仿射子空间 Φ₁,…,Φₘ ⊆ F₂^N 的余维数至多 (log N)^q，且并集大小至少 2^{N−1}，则当每个成员保留至少 (1 − N^{−r}) 比例的点时，并集应保留至少 (1 − N^{−rc}) 比例的点，其中 c 仅依赖于 q。这个猜想的直观基础是：仿射子空间是高度规则的几何对象，它们的并集不应表现出"病态"的删除敏感性。**注意：这是作者对 Alekseev–Gaevoy 工作的转述，具体猜想的表述以原文为准。**

3. **本文（Xiu, 2026）**：构造了一个反例，直接否证上述猜想。关键洞察是：**坐标子空间（coordinate subspaces）的并集可以覆盖整个空间，但它们的"薄弱点"——中间 Hamming 层——恰好是每个子空间都只覆盖一次的点**。删除这一层，每个子空间只损失 1/N 比例，但并集损失了约 1/√N 比例（精确值为 binom(2k,k)/4^k ≈ 1/√(πk)）。这个反例是"全指数"的：对任意固定 c > 0，都存在任意大的 N 使得损失超过 N^{−c}。

4. **形式化验证（Lean 4）**：本文的独特之处在于，反例不仅在纸上构造，还在 Lean 4 中完整形式化验证。这反映了证明复杂性领域近年来的一个趋势——用交互式定理证明器验证组合构造的正确性，尤其是在涉及精细计数和集合论论证时。

#### 子线索聚类

被引文献（本文引用极少，仅 [1]）大致落在以下线索上：

- **证明复杂性下界（Res(⊕)）**：Alekseev–Gaevoy 的工作属于这一线索，他们试图通过组合稳定性引理推导多项式深度下界。本文的反例切断了这条路径，但不排除其他证明策略。
- **组合覆盖与删除鲁棒性**：更广义地，这是关于"覆盖族的局部扰动如何影响全局覆盖"的研究，与容错计算、编码理论中的删除纠错有联系。
- **形式化数学验证**：Lean 4 数学库（mathlib）中的组合构造验证，是近年来活跃的方向，本文是这一线索上的一个具体案例。

#### 这个方向在追问的核心问题

1. **稳定性断言的边界在哪里？** 在什么条件下，局部保留能保证全局保留？Alekseev–Gaevoy 猜想试图给出一个充分条件（仿射子空间、小余维数、大并集），本文否证了它，但并未回答"什么样的条件才是充分的"。
2. **Res(⊕) 下界的替代路径**：如果稳定性引理不成立，证明复杂性下界还能用什么工具推导？这是 Alekseev–Gaevoy 工作的直接后续问题。
3. **反例的构造原理能否推广？** 本文的构造依赖于坐标子空间和 Hamming 层的特殊结构，能否构造更一般的反例（例如非坐标仿射子空间、不同基域）？

#### 张力

未见明显对立引用。本文是单一反例构造，直接否证一个具体猜想，不涉及多个工作之间的冲突。但存在一个隐含张力：**Alekseev–Gaevoy 的猜想在直觉上"应该"成立**（仿射子空间是高度规则的），而本文表明这种直觉是错误的。这种"直觉 vs 反例"的张力正是组合学中反例构造的典型价值所在。


### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

- **N**：环境空间的维数，本文取 N = 2k（k 为正整数）。
- **F₂^N**：二元域上的 N 维向量空间，即所有长度为 N 的 0/1 串构成的集合，大小为 2^N。
- **U = {1, …, 2k}**：前 2k 个坐标的指标集（"区分坐标"）。注意 N = 2k，所以 U 是全部坐标的一部分（当 k ≥ 2 时，2k ≤ 2^k = N，U 确实只是前 2k 个坐标）。
- **S ⊆ U，|S| = k**：U 的 k 元子集，用于定义子空间。
- **b ∈ F₂ = {0, 1}**：一个比特值。
- **Φ_{S,b}**：仿射子空间 {x ∈ F₂^N : x_i = b 对所有 i ∈ S}。即固定 S 中所有坐标为 b，其余坐标自由。余维数 = k，大小 = 2^{N−k}。
- **B**：中间 Hamming 层 {x ∈ F₂^N : |{i ∈ U : x_i = 1}| = k}。即在 U 中恰好有 k 个 1 的点。大小 = binom(2k, k) · 2^{N−2k}。
- **Φ'_{S,b}**：删除后的子空间 Φ_{S,b} \ B。
- **δ_k**：全局损失比例 |B| / 2^N = binom(2k, k) / 4^k。
- **m**：族中成员数 = 2 · binom(2k, k) ≤ 2N²。

**可观测数据**：这里没有统计意义上的"数据"。这是一个纯组合构造：研究者可以显式列出所有 Φ_{S,b} 和 B，验证覆盖关系和删除损失。所有量都是确定性的、可计算的。

**关键区分**：
- **可观测**：每个 Φ_{S,b} 的具体元素、B 的具体元素、并集的大小。
- **想要但不可直接观测**：删除后并集的大小——但在这个构造中，它是精确可计算的（Lemma 3.2），不需要估计。

#### 第二步：最小内核

**最简特例**：取 k = 2，则 N = 4，U = {1, 2, 3, 4}。族中每个子空间固定 2 个坐标为常数，余维数 2，大小 2^{4−2} = 4。共有 2 · binom(4, 2) = 12 个成员。B 是 U 中恰好有 2 个 1 的点，即 {1100, 1010, 1001, 0110, 0101, 0011} × {自由坐标（后 2 位）}，共 6 × 4 = 24 个点，占全空间 16 个点的 6/16 = 3/8。

**核心命题**（在这个特例下）：
1. **覆盖**：任意 x ∈ F₂⁴，在 U 的 4 个坐标中，要么至少有 2 个 1，要么至少有 2 个 0。若至少有 2 个 1，选这 2 个 1 的位置为 S，则 x ∈ Φ_{S,1}；若至少有 2 个 0，选这 2 个 0 的位置为 S，则 x ∈ Φ_{S,0}。所以并集 = 全空间。
2. **局部删除**：对每个 Φ_{S,b}，|Φ_{S,b} ∩ B| = 2^{N−2k} = 2^{4−4} = 1。即每个子空间只被删掉 1 个点，占其大小的 1/4 = 1/N。
3. **全局删除**：删除 B 后，并集 = F₂⁴ \ B，损失比例 = |B| / 16 = 6/16 = 3/8 = binom(4,2)/4²。

**为什么这个特例体现了核心困难**：每个子空间只损失 1/N = 25% 的点，但并集损失了 37.5% 的点——损失被放大了 1.5 倍。放大因子来自 B 中每个点恰好被 2 个成员覆盖（一个对应"至少 2 个 1"的选择，一个对应"至少 2 个 0"的选择），因此删除 B 中一个点，需要两个成员同时"失职"才能从并集中移除它。但在这个构造中，B 中每个点确实被两个成员覆盖，而这两个成员都删除了它，所以它从并集中消失了。

**一般化**：当 k 增大时，B 中每个点被覆盖的次数恰好为 2（一个来自"k 个 1"的选择，一个来自"k 个 0"的选择），而每个成员删除 B 中点的比例恒为 2^{−k} = 1/N。但 B 本身占全空间的比例是 binom(2k,k)/4^k ≈ 1/√(πk)，远大于 1/N = 2^{−k}。因此，局部损失 1/N 被放大为全局损失 ≈ 1/√(π log₂ N)，这个放大因子是超多项式的——对任意 c > 0，当 k 足够大时，1/√(πk) > 2^{−ck} = N^{−c}。

**一句话总结核心数学事实**：存在一族余维数 log₂ N 的仿射子空间覆盖 F₂^N，使得每个成员删除 1/N 比例的点后，并集损失 ≈ 1/√(log₂ N) 比例——局部损失被超多项式放大。


### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：Alekseev–Gaevoy 关于仿射子空间并集稳定性的猜想是否成立——即当每个仿射子空间只删除 1/N 比例的点时，并集是否必然保留 (1 − N^{−c}) 比例的点。
2. **核心工具/方法**：构造一族坐标子空间（固定 k 个坐标为常数），删除中间 Hamming 层（U 中恰好 k 个 1 的点），利用二项式系数精确计算局部和全局损失。
3. **主要结论**：对任意 c > 0 和任意 N₀，存在 N ≥ N₀ 和一族余维数 ≤ (log N)² 的仿射子空间，覆盖全空间，每个成员删除 1/N 比例后并集损失 > N^{−c}——猜想被否证。

#### 关键设定与假设

- **基域 F₂**：构造依赖二元域的特殊性质（每个坐标只有 0/1 两个值，Hamming 层的计数用二项式系数）。
- **坐标子空间**：Φ_{S,b} 是"固定坐标"型子空间，不是一般仿射子空间。这是构造的关键简化——一般仿射子空间可能更复杂，但坐标子空间足以否证猜想。
- **删除方式**：每个成员删除相同的集合 B（全局一致的删除）。这是否证猜想的最强方式——如果连"每个成员删同样的点"都能破坏稳定性，那么更灵活的删除方式更不可能稳定。
- **余维数**：k = log₂ N，满足猜想中 (log N)² 的界（因为 k ≤ (log N)² 对 k ≥ 2 成立）。
- **族大小**：m ≤ 2N²，猜想未对族大小设限，因此不构成障碍。

**相比 Alekseev–Gaevoy 猜想的设定**：本文完全在猜想框架内构造反例，没有放宽任何假设。唯一需要注意的是，猜想可能隐含"子空间是任意仿射子空间"而非"坐标子空间"，但坐标子空间是仿射子空间的特殊情形，因此反例有效。

#### 主要结果

**定理 1.1**（核心结果）：对任意 c > 0 和任意 N₀，存在 N ≥ max{1, N₀} 和一族仿射子空间 Φᵢ ⊆ F₂^N，满足：
1. 并集 = F₂^N（完全覆盖）；
2. 每个 Φᵢ 的余维数 ≤ (log N)²；
3. 每个 Φᵢ 保留 (1 − 1/N) 比例的点（即删除 1/N）；
4. 并集保留 < (1 − N^{−c}) 比例的点（即损失 > N^{−c}）。

**关键量化结果**：
- 局部损失：每个成员删除比例 = 2^{−k} = 1/N（Lemma 3.1）。
- 全局损失：δ_k = binom(2k, k) / 4^k ≥ 1/(2k+1)（Lemma 3.2）。
- 放大因子：δ_k / (1/N) = binom(2k,k) · 2^k / 4^k = binom(2k,k) / 2^k ≈ √(2/(πk))——超多项式增长。

**推论**：Alekseev–Gaevoy 猜想（Conjectures 1.4 和 4.2）对 q = 2, r = 1 失败，且失败方式是"全指数"的——不存在任何固定的 c > 0 能挽救稳定性结论。

#### 证明路线与技术技巧

**整体路线**（3-5 步主干）：

1. **构造**：取 N = 2k，区分前 2k 个坐标。对每个 k 元子集 S ⊆ U 和 b ∈ {0,1}，定义 Φ_{S,b} = {x : x_i = b ∀i ∈ S}。族 = 所有这样的子空间。

2. **证明覆盖**（Lemma 2.2）：对任意 x ∈ F₂^N，在 U 的 2k 个坐标中，1 的个数要么 ≥ k 要么 ≤ k。若 ≥ k，选 k 个 1 的位置为 S，则 x ∈ Φ_{S,1}；若 ≤ k，则 0 的个数 ≥ k，选 k 个 0 的位置为 S，则 x ∈ Φ_{S,0}。因此并集 = 全空间。

3. **计算局部损失**（Lemma 3.1）：对固定 (S, b)，Φ_{S,b} ∩ B 中的点必须满足：S 中全为 b，且 U 中恰好 k 个 1。当 b = 1 时，S 已提供 k 个 1，所以 U\S 必须全为 0；当 b = 0 时，S 已提供 k 个 0，所以 U\S 必须全为 1。无论哪种情况，U 中所有 2k 个坐标都被确定，剩下 N − 2k 个坐标自由。因此 |Φ_{S,b} ∩ B| = 2^{N−2k}，占 |Φ_{S,b}| = 2^{N−k} 的比例为 2^{−k} = 1/N。

4. **计算全局损失**（Lemma 3.2）：删除 B 后，并集 = F₂^N \ B（因为每个 B 中的点都被所有覆盖它的成员删除，且 B 外的点不被任何成员删除）。因此全局损失 = |B| / 2^N = binom(2k, k) · 2^{N−2k} / 2^N = binom(2k,k) / 4^k。

5. **下界估计**：用二项式系数最大值不等式 4^k ≤ (2k+1) · binom(2k,k)，得到 δ_k ≥ 1/(2k+1)。然后选择 k 使得 2k+1 < 2^{ck}（即 1/(2k+1) > 2^{−ck} = N^{−c}），这由指数增长 vs 线性增长保证（Lemma 4.1）。

**关键技巧**：
- **Hamming 层的选择**：B 是"中间层"——每个点恰好被两个成员覆盖（一个来自"选 1 的位置"，一个来自"选 0 的位置"）。这保证了删除 B 中每个点需要两个成员同时失职，但在这个构造中它们确实同时失职了。
- **坐标子空间的简化**：固定坐标而非一般线性约束，使得计数变得精确可算（二项式系数），避免了复杂的几何论证。
- **二项式系数下界**：用简单的 4^k ≤ (2k+1) · binom(2k,k) 就得到了足够强的下界，不需要 Stirling 近似。

**形式化验证**：本文在 Lean 4 中完整验证了构造的正确性，包括覆盖性、局部删除比例、全局损失比例和最终的反例声明。验证只依赖 propExt、Classical.choice 和 Quot.sound，无额外公理。这为构造的正确性提供了机器可检查的保证。

#### 🔎 结论是否比证明窄

- **明确声明**：作者在"Scope of the obstruction"一节明确说明，反例只否证"保留子集是任意子集"的猜想版本。如果猜想要求保留子集具有额外结构（如仿射子空间），本文的反例不适用。
- **未声称**：作者没有声称 Res(⊕) 下界本身失败，只声称其依赖的组合引理失败。
- **潜在 gap**：定理 1.1 要求"对任意 c > 0 和任意 N₀，存在 N ≥ N₀"，但构造中 N = 2^k 是 2 的幂。如果 Alekseev–Gaevoy 的猜想只对"所有足够大的 N"（而非"任意大的 N"）要求稳定性，本文的反例仍然有效，因为 2 的幂可以任意大。但如果猜想对"所有 N"要求稳定性，本文的反例只覆盖了 N 为 2 的幂的情况——不过由于 N₀ 任意，这已经足够否证"对所有足够大的 N"的版本。
- **未讨论**：如果保留子集被要求是仿射子空间（而非任意子集），稳定性是否恢复？作者未讨论这一点。


### 四、开放问题

1. **保留子集的结构限制**：如果 Φ'ᵢ 被要求是仿射子空间（而非任意子集），Alekseev–Gaevoy 猜想的稳定性结论是否恢复？本文的构造中 Φ'ᵢ = Φᵢ \ B 不是仿射子空间（删除 Hamming 层后不再封闭），因此不适用于这个变体。扎根于"Scope of the obstruction"一节。

2. **其他基域**：本文构造依赖 F₂ 的特殊性质（Hamming 层的二项式计数）。在 F_q（q > 2）上，是否存在类似的反例？扎根于构造的"坐标子空间 + Hamming 层"结构。

3. **Res(⊕) 下界的替代路径**：Alekseev–Gaevoy 的猜想被否证后，他们原本的目标（Res(⊕) 的多项式深度下界）是否还能通过其他组合引理实现？本文未提供任何替代方案。扎根于引言中对 [1] 的引用。

4. **稳定性成立的充分条件**：本文只给出了一个反例，没有刻画"什么样的条件下稳定性成立"。是否存在一个关于子空间族结构的自然条件（如覆盖重数上界、子空间维数下界）能保证稳定性？扎根于定理 1.1 的构造中"每个点被覆盖恰好 2 次"这一关键特征。

5. **放大因子的最优性**：本文的放大因子是 ≈ 1/√(log₂ N)（全局损失 vs 局部损失 1/N）。是否存在构造能实现更大的放大因子（例如 1/log N 或 1/log log N）？还是说 1/√(log N) 是某种意义上的最优？扎根于 Lemma 3.2 的 δ_k 表达式。
