### 一、领域脉络与小综述

#### 这个方向是什么

本文所处的子方向是**单位根检验的局部渐近理论**，其根本统计问题是：在时间序列可能含有单位根（非平稳）的假设下，如何构造检验统计量并刻画其在局部备择（local alternative）下的功效。该方向的成熟度较高，自 Dickey-Fuller (1979) 以来已有四十余年积累，形成了以局部到单位根（local-to-unity）参数化为核心的渐近分析范式。本文聚焦于一个特殊的退化情形——近单位根近白噪声（NINW），即自回归系数以速率 1/T 趋近 1、同时移动平均系数以速率 1/√T 趋近 −1，导致长期方差（LRV）以速率 1/T 坍缩到 0。这一框架由 Nabeya and Perron (1994) 提出，用于刻画"看似单位根、实则近可逆"的边界情形。

#### 发展脉络

- **奠基工作**：Dickey and Fuller (1979) 提出 ADF 检验，Said and Dickey (1984) 将其扩展至 ARMA 误差。Phillips and Perron (1988) 引入基于 LRV 估计的非参数修正，形成 PP 检验族。这些工作确立了单位根检验的基本范式：检验统计量 =（估计量 − 1）/（LRV 修正项）。
- **功效基准的建立**：Elliott, Rothenberg and Stock (1996, ERS) 推导了高斯功效包络（Gaussian power envelope），即在 Gaussian 似然下、对局部备择 c 的最优不变检验所能达到的功效上界。该文同时提出 GLS 去趋势（quasi-differencing）方法，使检验统计量在标准局部到单位根框架下逼近此包络。Dufour and King (1991) 从不变检验角度给出了点最优不变检验（POI）的构造，为 GLS 去趋势提供了理论支撑。
- **M 检验族的兴起**：Stock (1990) 提出 M 检验族（基于矩条件的修正统计量），Perron and Ng (1996, 1998) 系统发展并分析其性质，Ng and Perron (2001) 将 GLS 去趋势与 M 检验结合，得到在标准框架下功效接近 ERS 包络且尺寸性质优于 PP 检验的 M^GLS 检验族。Perron and Qu (2007) 进一步建议用 OLS 去趋势构造修正信息准则以解决功效反转问题。
- **NINW 框架的引入**：Nabeya and Perron (1994) 提出 NINW 局部嵌入，其中 MA 系数 θ_T = −1 + δ/√T，使得谱密度在频率 0 处坍缩。在此框架下，标准局部到单位根渐近失效，因为 LRV 不再收敛到正常数。Perron and Ng (1996) 在无确定性项情形下推导了 M 检验的 NINW 极限分布。
- **本文的位置**：本文在 NINW 框架下补全了未知线性趋势的情形，推导了 M^OLS 与 M^GLS 检验族的极限分布，证明高斯功效包络与 ERS 标准包络渐近等价，并刻画了可行统计量因 LRV 估计（自回归估计）高估而产生的额外扭曲。

#### 子线索聚类

1. **检验统计量的构造线索**：ADF（Said-Dickey 1984）→ PP（Phillips-Perron 1988）→ M 检验（Stock 1990; Perron-Ng 1996）→ M^GLS（Ng-Perron 2001）。这条线索的核心问题是：如何在误差序列相关时保持检验的尺寸与功效。
2. **功效基准线索**：POI 检验（Dufour-King 1991）→ ERS 高斯包络（1996）→ NINW 包络（本文 Theorem 4.1）。这条线索追问：给定局部备择，最优检验能达到多高的功效？
3. **退化局部框架线索**：标准局部到单位根（c 固定）→ NINW（δ 固定，LRV 坍缩）→ 本文的可行统计量分析。这条线索处理的是：当标准渐近假设失效时，检验统计量的极限行为如何改变。

#### 核心问题与已知瓶颈

- **核心问题 1**：在 NINW 下，M 检验族的极限分布是什么？是否仍与标准局部到单位根框架下的极限分布一致？
- **核心问题 2**：高斯功效包络在 NINW 下是否改变？若不变，则检验功效的损失源于统计量的低效而非问题的内在困难。
- **核心问题 3**：可行 LRV 估计（自回归估计）在 NINW 下是否仍一致？若不，则可行统计量的极限分布与 oracle 版本有何差异？
- **已知瓶颈**：NINW 下 LRV 坍缩导致标准"绝对一致"的 LRV 估计失效；自回归估计在 NINW 下高估 LRV，且高估程度依赖于 δ 与 κ（滞后截断比例）；GLS 去趋势的拟差分操作在 NINW 下引入额外噪声项，使 M^GLS 的极限分布比 M^OLS 更复杂。

#### ⚠️ 作者的 framing

作者将缺口 frame 为：**"Perron and Ng (1996) 和 Ng and Perron (2001) 在 NINW 框架下分析了 M 检验与滞后选择，但未完全刻画未知线性趋势下的极限分布、高斯功效包络、以及可行 LRV 估计的联合行为。"** 作者声称本文是"显然的下一步"，因为：(i) 未知趋势是实证中最常见的设定；(ii) 功效包络的等价性证明需要新的论证（标准 ERS 证明依赖正谱密度条件，NINW 下该条件失败）；(iii) 可行统计量的极限分布此前未知。

**值得研究者去查的问题**：作者在 intro 中淡化了 Seo (2005) 与 Perron-Qu (2007) 关于功效反转的讨论——功效反转是否在 NINW 下更严重？作者也未引用 Phillips (1987) 关于近单位根检验的早期工作，以及 Müller and Elliott (2003) 关于渐近功效包络的推广。这些遗漏是否意味着本文的包络等价性证明依赖 Gaussian 假设而不可推广？

#### 张力

未见明显对立引用。但存在一个微妙的张力：Perron and Ng (1996) 在无确定性情形下声称 M 检验在 NINW 下具有"合理"的性质，而本文表明在未知趋势下 M^GLS 的极限分布被额外噪声项污染，且存在 δ 依赖的零功效区域。这暗示"合理"的结论对确定性设定敏感。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

**数据生成过程（模型 1）**：
- 观测序列：{y_t}_{t=1}^T，其中 y_t = β_0 + β_1 t + u_t。
- 不可观测成分：u_t = ρ_T u_{t-1} + v_t，ρ_T = 1 + c/T，c ≤ 0 固定。
- 误差过程：v_t = e_t + θ_T e_{t-1}，θ_T = −1 + δ/√T，δ > 0 固定。
- 初始化：u_0 = e_0 = 0。
- 创新：{e_t} i.i.d.，E[e_t] = 0，E[e_t²] = σ_e²，E|e_t|⁴ < ∞。**不要求 Gaussian**。

**关键参数与 estimand**：
- c：局部到单位根参数（local-to-unity parameter），刻画自回归根偏离 1 的程度。c = 0 对应单位根原假设，c < 0 对应局部平稳备择。
- δ：NINW 参数，刻画移动平均根偏离 −1 的程度。δ 越大，MA 根越远离可逆边界。
- ρ_T、θ_T：随 T 变化的局部参数序列，是**理论构造**而非待估参数。
- β_0, β_1：确定性趋势系数，未知 nuisance 参数。

**可观测数据**：研究者实际观测到 {y_t}，知道模型形式（1），但不知道 c、δ、σ_e²、β_0、β_1。检验目标是 H₀: c = 0 vs H₁: c < 0。

**统计量定义（第 2.3 节）**：
- 去趋势数据：M^OLS 用 OLS 残差 \tilde{y}_t^{OLS}；M^GLS 用 GLS 拟差分残差 \tilde{y}_t^{GLS}（在 ¯c < 0 下拟差分）。
- 核心矩：T^{-2} Σ \tilde{y}_{t-1}²（水平二阶矩），T^{-1} \tilde{y}_T²（端点项），T^{-1} Σ (\Delta \tilde{y}_t)²（差分二阶矩）。
- LRV：ω_T² = σ_e²(1+θ_T)² = σ_e²δ²/T，即 v_t 的谱密度在频率 0 处的值，**以 1/T 速率坍缩到 0**。
- 统计量族：MZ_α = (T^{-1} \tilde{y}_T² − s_AR²) / (2 T^{-2} Σ \tilde{y}_{t-1}²)，MSB = (T^{-2} Σ \tilde{y}_{t-1}² / s_AR²)^{1/2}，MZ_t = MZ_α × MSB，MP_T = (¯c² T^{-2} Σ \tilde{y}_{t-1}² − ¯c T^{-1} \tilde{y}_T²) / s_AR²。其中 s_AR² 是自回归 LRV 估计（式 30-31）。

**可观测 vs 潜在**：c 和 δ 是**局部参数**，不可直接观测，只能通过统计量的极限分布间接推断。LRV ω_T² 是**理论量**，实际中必须估计（s_AR²）。本文的核心区分是 oracle（已知 ω_T²）与 feasible（用 s_AR²）两种情形。

#### 第二步：最小内核

**最小内核**：在 NINW 框架下，M 检验统计量的极限分布是什么？它是否与标准局部到单位根框架下的极限分布一致？

**最简设定**：去掉趋势项（β_0 = β_1 = 0），去掉自回归估计（假设 LRV 已知），只保留一个统计量 MZ_α。此时模型退化为：

u_t = (1 + c/T) u_{t-1} + e_t + (−1 + δ/√T) e_{t-1}。

**关键观察**：v_t = e_t − e_{t-1} + (δ/√T) e_{t-1}。当 T 大时，v_t 近似为 e_t − e_{t-1}（一阶差分），其部分和 Σ v_t ≈ e_T − e_0 = e_T，是 O_p(1) 而非 O_p(√T)。因此 u_t = Σ_{s≤t} ρ_T^{t-s} v_s 的规模是 O_p(1) 而非 O_p(√T)。这正是 NINW 的退化性：**LRV 坍缩使得部分和不再扩散**。

**核心数学命题（退化版）**：在 NINW 下，T^{-1} Σ u_{t-1}² ⇒ σ_e² ∫₀¹ J_c^δ(r)² dr，其中 J_c^δ 是 Ornstein-Uhlenbeck 过程 J_c 与边界项 ε₁、ε_∞ 的混合（见 Proposition 3.1-3.2）。**关键点**：极限分布包含 ε₁ 和 ε_∞——即第一个和最后一个创新——这是标准局部到单位根框架（LRV 为正）中不出现的项。

**为什么难**：标准框架下，泛函中心极限定理给出 u_{⌊Tr⌋}/√T ⇒ σ J_c(r)，其中 σ² = LRV > 0。NINW 下 LRV = 0，标准化失效，需要新的尺度（T^{-1/2} 而非 T^{-1}），且边界项不再渐近可忽略。本文的技术核心就是处理这些边界项。

**证明路线（最小版）**：
1. 将 u_t 分解为"扩散部分"（由 X_t = ρ_T X_{t-1} + e_t 驱动）和"边界部分"（由 e_t 和 e_T 驱动）。
2. 证明扩散部分在 T^{-1/2} 尺度下收敛到 J_c 的泛函。
3. 证明边界部分收敛到 ε₁、ε_∞ 的线性组合。
4. 合并两部分，得到极限分布。

**这个最小内核说明了什么**：M 检验在 NINW 下的极限分布**不是**标准局部到单位根框架的简单推广——它包含额外的噪声项（ε₁、ε_∞），且这些项在 δ → 0 时主导分布，导致检验功效趋于零。这就是"零功效区域"的机制。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：在 NINW 框架（自回归根以 1/T 趋近 1、MA 根以 1/√T 趋近 −1）下，推导了 M 检验族（M^OLS 与 M^GLS）在未知线性趋势下的极限分布，并刻画了 oracle 与 feasible 两种情形的差异。
2. **核心工具/方法**：将样本矩分解为扩散部分与边界部分，利用泛函中心极限定理（FCLT）与连续映射定理推导极限；对可行统计量，证明自回归 LRV 估计在 NINW 下以 coth²(κδ/2) 的因子高估真实 LRV。
3. **主要结论**：M^GLS 的极限分布因拟差分而受额外噪声项污染，M^OLS 受污染较轻；高斯功效包络与 ERS 标准包络渐近等价（不依赖 δ）；oracle M 检验相对该基准功效低效；可行统计量因 LRV 高估而改变极限分布，且有限样本中无统一满意的方案。

#### 关键设定与假设

- **模型**：式 (1)，含截距与线性趋势。**相比 Perron and Ng (1996) 的贡献**：后者仅处理无确定性情形，本文补全了趋势项。
- **创新分布**：仅假设 i.i.d.、零均值、四阶矩有限（Assumption 2.1）。**不要求 Gaussian**，因此极限分布中的 ε₁、ε_∞ 依赖创新分布，而非标准正态。
- **局部参数**：c ≤ 0 固定，δ > 0 固定。**相比标准局部到单位根**：δ 的引入使得 LRV 坍缩，标准渐近失效。
- **滞后截断**：k 满足 k/√T → κ ∈ (0, ∞)。这是可行 LRV 估计的关键假设——k 必须与 √T 同阶，否则 s_AR² 的极限行为改变。
- **相比已有文献的放宽/强化**：放宽了 Gaussian 假设（标准功效包络推导常用 Gaussian）；强化了确定性设定（从无趋势到线性趋势）。

#### 主要结果

**定理 3.4（oracle M^OLS）**：
- MZ_α^{OLS} ⇒ (ε_∞ + δ J_c^τ(1))² − δ² / [2(1 + δ² ∫₀¹ J_c^τ(r)² dr)]
- MSB^{OLS} ⇒ (1/δ)(1 + δ² ∫₀¹ J_c^τ(r)² dr)^{1/2}
- **直觉**：极限分布是 δ 的函数，且包含 ε_∞（最后一个创新）。当 δ → 0 时，分子趋于 ε_∞² − δ²，分母趋于 2，统计量趋于 ε_∞²/2，不再依赖 c——检验失去对 c 的区分能力。
- **必要条件**：四阶矩有限（用于控制边界项）；k = o(T)（保证样本矩收敛）。

**定理 3.5（oracle M^GLS）**：
- 极限分布包含 ε₁ 和 ε_∞ 的线性组合（通过 q_¯c 项），以及 V_{c,¯c}（GLS 去趋势的 OU 过程）。
- **关键差异**：M^GLS 比 M^OLS 多出 ε₁ 项（来自拟差分的第一观测），且 q_¯c 依赖 ¯c。当 δ → 0 时，M^GLS 的极限分布同样失去对 c 的依赖，但零功效区域比 M^OLS 更宽（因为 ε₁ 和 ε_∞ 两个边界项）。

**推论 3.8（支撑界）**：
- MZ_α ≥ −δ²/2，MSB ≥ 1/δ，MZ_t ≥ −δ/2，MP_T ≥ ¯c²/δ²（a.s.）。
- **含义**：当 δ < √(2|c_v|)（c_v 为临界值）时，检验的渐近拒绝概率恰好为零。例如，5% 临界值 −17.3 对应 δ* ≈ 5.88。这意味着在 NINW 下，M^GLS 检验对 δ < 5.88 的序列完全失效。

**定理 4.1（高斯功效包络）**：
- Π_{NINW}^τ(c, δ; α) = Π_{ERS}^τ(c; α)，即 NINW 下的高斯功效包络与 ERS 标准包络**逐点相等**。
- **证明路线**：构造 Gaussian 似然比，证明在 NINW 下，最优不变检验的极限分布与标准框架相同。关键步骤是证明拟差分后的残差在 NINW 下仍满足局部渐近正态性（LAN），且边界项在似然比中可忽略。
- **含义**：NINW 问题本身并不比标准问题更难——信息量没有损失。M 检验的低效是统计量构造的问题，而非问题的内在困难。

**命题 5.1（可行 LRV 估计）**：
- 在 k/√T → κ 下，s_AR²/ω_T² → coth²(κδ/2) > 1。
- **含义**：自回归 LRV 估计在 NINW 下**不一致**（高估），且高估因子随 κδ 增大而减小。这改变了可行统计量的极限分布，使其与 oracle 版本不同。
- **技术难点**：s_AR² 的极限需要处理"估计的 AR 系数"与"真实 MA 系数"之间的偏差，这涉及高阶展开和边界项的控制。

**定理 5.2-5.3（可行 M^OLS 与 M^GLS）**：
- 可行统计量的极限分布是 oracle 版本与 coth²(κδ/2) 因子的混合。
- **关键结论**：可行 M^GLS 的零功效区域比 oracle 更宽（因为 LRV 高估进一步压缩了统计量的取值范围），而可行 M^OLS 的零功效区域与 oracle 相同（因为 M^OLS 的极限分布中 LRV 高估因子被抵消）。

#### 证明路线与技术技巧

**整体路线**：
1. **样本矩分解**：将 \tilde{y}_t 分解为"扩散部分"（由 X_t 驱动）和"边界部分"（由 e₁、e_T 驱动）。这是整个证明的基石。
2. **FCLT 与连续映射**：对扩散部分，利用标准 FCLT 得到 J_c 的泛函收敛；对边界部分，利用 e₁、e_T 的独立性得到 ε₁、ε_∞。
3. **联合收敛**：证明扩散部分与边界部分的联合收敛，然后通过连续映射定理得到统计量的极限分布。
4. **可行 LRV 分析**：对 s_AR²，利用 Yule-Walker 方程和 AR(k) 逼近的偏差展开，得到 coth²(κδ/2) 的极限。

**关键引理**：
- **引理 A.1**：构造 ε₁、ε_∞ 与 Brownian motion 的联合收敛。难点在于 e₁ 和 e_T 与部分和过程的依赖关系——通过"修剪"部分和（去掉首尾项）解决。
- **引理 A.2**：u_t 的分解 u_t = a_T e_t + b_T X_t，其中 a_T → 1，b_T = O(T^{-1/2})。这个分解将 NINW 的退化性转化为"小参数"问题。
- **引理 A.4-A.5**：GLS 去趋势的代数性质，特别是拟差分后截距和趋势的渐近行为。关键技巧是**离散求和**（summation by parts），将趋势项转化为边界项。

**技术技巧点名**：
- **离散求和**（summation by parts）：用于处理趋势项，将 T^{-1} Σ t u_t 转化为边界项加积分项。
- **修剪部分和**（trimmed partial sums）：用于处理 e₁、e_T 与部分和的依赖，通过去掉首尾 O(1) 项实现渐近独立。
- **Yule-Walker 方程**：用于推导 s_AR² 的极限，将 AR(k) 估计的偏差转化为 MA 系数的函数。
- **连续映射定理**：将样本矩的联合收敛转化为统计量的极限分布。
- **LAN 展开**：用于证明功效包络的等价性，通过 Gaussian 似然比的二阶展开。

#### 🔎 结论是否比证明窄

- **Theorem 4.1 的证明依赖 Gaussian 假设**。作者在 Section 4 开头明确假设 Gaussian，但 Theorem 4.1 的陈述并未标注 Gaussian 条件。虽然作者在 Remark 4.2 中声称"不依赖 Gaussian"，但证明中使用了 Gaussian 似然比和 LAN 展开，这些在非 Gaussian 下需要额外的 Edgeworth 展开或高阶累积量条件。**这是一个值得研究者去查的 gap**。
- **Proposition 5.1 的证明仅覆盖确定性 k 序列**。作者在 Remark 5.5 中讨论了 κ 的解释，但未证明数据依赖的 k（如 MAIC 选择的 k）是否仍满足 k/√T → κ。这是可行统计量分析的一个缺口。
- **Corollary 3.8 的"零拒绝概率"结论是渐近的**。作者在 Remark 3.9 中给出了 δ* 的数值，但未讨论有限样本下零拒绝概率区域的边界如何随 T 变化。模拟结果（Section 6）显示有限样本行为与渐近预测有偏差，但作者未给出理论解释。

### 四、开放问题

1. **非 Gaussian 下的功效包络**：Theorem 4.1 的证明依赖 Gaussian 假设。能否在非 Gaussian 下证明包络等价性？需要什么条件（如 Edgeworth 展开、累积量条件）？这直接关系到"NINW 问题不比标准问题更难"的结论是否稳健。

2. **数据依赖的滞后选择**：Proposition 5.1 仅覆盖确定性 k 序列。MAIC/MBIC 选择的 k 是否仍满足 k/√T → κ？若不，可行统计量的极限分布如何改变？这需要分析信息准则在 NINW 下的选择行为。

3. **零拒绝概率区域的有限样本边界**：Corollary 3.8 给出渐近零拒绝概率的 δ 阈值，但模拟显示有限样本行为有偏差。能否刻画有限样本下零拒绝概率区域的边界如何随 T 变化？这可能需要 Edgeworth 展开或鞍点近似。

4. **更一般的确定性项**：本文处理了线性趋势。能否推广到结构突变、多项式趋势或更一般的确定性函数？NINW 的退化性是否在这些设定下仍然成立？

5. **M^OLS 与 M^GLS 的零拒绝概率区域差异**：Theorem 5.2-5.3 显示可行 M^OLS 与 M^GLS 的零拒绝概率区域不同。能否给出统一的刻画？是否存在某种"最优"的 LRV 估计器能消除这一差异？

6. **功效反转问题在 NINW 下的表现**：Perron and Qu (2007) 提出的 OLS 信息准则解决了标准框架下的功效反转。在 NINW 下，功效反转是否更严重？OLS 信息准则是否仍然有效？

**提醒**：要确认上述某条是否是真 gap，建议去读近 5 年单位根检验方向的论文（如 Journal of Econometrics、Econometric Theory 上的相关文章）的引言——如果多条文献都指向同一问题，说明是共识性 gap；如果文献之间结论互相矛盾，则可能是更好的研究机会。
