# An optimal design framework for lasso sign recovery

**作者**: Jonathan W Stallrich, Kade Young, Maria L Weese, Byran J Smucker, David J Edwards  
**主题**: 数理统计 / 假设检验  
**相关性**: 7/10  
**链接**: <https://doi.org/10.1093/jrsssb/qkaf026>

### 一、领域脉络与小综述

#### 这个方向是什么

本文所处的子方向是**超饱和设计（Supersaturated Designs, SSDs）下的变量选择与符号恢复**。其根本的统计问题是：在因子数 p 大于试验次数 n（即 n < p + 1）的极端高维设定下，如何设计实验矩阵 X（元素为 ±1），使得后续基于惩罚回归（如 lasso）的分析能以最高概率识别出真正活跃的因子及其效应方向。该方向的核心张力在于：传统最优设计理论（如 D-optimality）建立在最小二乘估计的方差最小化之上，而 SSD 场景下最小二乘不可用，分析必须依赖惩罚估计器，因此设计准则应当直接面向惩罚估计器的统计性质（如符号恢复概率），而非间接的方差准则。当前该方向的成熟度处于"准则提出与启发式构造"阶段，缺乏统一的最优性理论框架。

#### 发展脉络（history）

- **奠基工作**：Booth and Cox (1962) 提出 E(s²) 准则，通过最小化设计矩阵列间内积的平方和来度量设计对正交性的偏离。这是 SSD 构造的第一个系统性准则，奠定了"以接近正交为目标"的构造范式。其留下的口子是：该准则纯粹是几何性的，与任何特定分析方法的统计性质无直接关联。
- **主要进展**：Jones and Majumdar (2014) 提出 UE(s²) 准则，将截距列纳入考量，扩展了 E(s²) 的适用范围。Weese et al. (2017, 2021) 提出 Var(s⁺) 准则，首次引入"已知效应方向"的假设，鼓励列间正相关，并通过模拟发现正相关设计在活跃效应为正时产生更明确的 lasso 解路径。这些工作的共同特征是：准则仍是启发式的，缺乏对"为何这些准则能提升符号恢复概率"的理论解释。
- **当前 frontier**：Singh and Stufken (2023) 提出基于受限等距性质（RIP）和不可表示条件（irrepresentable condition）的 Dantzig-based Consistency Designs (DCDs)，首次将设计准则与惩罚估计器的理论充分条件挂钩。但其准则仍是充分条件的间接代理，而非符号恢复概率本身的直接优化。
- **本文的位置**：Stallrich et al. (2025) 将设计准则直接定义为 lasso 符号恢复概率的函数，建立了从"设计矩阵 → lasso 解路径 → 符号恢复概率"的端到端最优性框架。本文的核心贡献在于：(1) 证明当活跃因子符号未知时，正交设计是理想结构；(2) 证明当符号已知且为正时，常数小正相关设计是理想结构；(3) 提出两阶段构造算法 HILS（Heuristic-Initiated Lasso Sieve），先用启发式准则筛选候选设计，再从中选择最大化符号恢复概率的设计。

#### 子线索聚类

这些被引文献大致落在三条子线索上：

1. **几何准则线索**（Booth and Cox 1962; Lin 1993; Wu 1993; Nguyen 1996; Li and Wu 1997; Tang and Wu 1997; Ryan and Sarkar 2009）：以设计矩阵的列间相关性为优化对象，目标是使 X'X 尽可能接近 nI。这条线索的优点是计算简单、构造快速；缺点是准则与统计性质脱节，无法保证最优设计在分析层面有优势。
2. **分析驱动准则线索**（Li and Lin 2002; Phoa et al. 2009; Marley and Woods 2010; Draguljić et al. 2014; Weese et al. 2015, 2017, 2021）：以特定分析方法的模拟表现来比较设计，或提出与分析方法相关的启发式准则（如 Var(s⁺)）。这条线索的优点是贴近实际使用；缺点是缺乏理论保证，模拟结论难以推广。
3. **理论充分条件线索**（Zhao and Yu 2006; Wainwright 2009; Deng et al. 2013; Xing 2015; Singh and Stufken 2023）：基于 lasso 符号恢复的充分条件（如不可表示条件）构建设计准则。这条线索的优点是理论严谨；缺点是充分条件通常过强，满足条件的设计可能不存在或过于保守。

本文属于第三条线索的深化，但将充分条件的间接代理替换为符号恢复概率的直接优化。

#### 这个方向在追问的核心问题

1. **设计准则与统计性质的一致性**：什么样的设计准则能真正反映 lasso 符号恢复的概率？现有准则（E(s²), UE(s²), Var(s⁺)）是否在某种意义下最优？
2. **符号信息的价值**：当实验者事先知道活跃效应的方向（如全部为正）时，设计应如何调整？正相关设计为何有效？
3. **计算可行性**：精确最大化符号恢复概率的设计搜索在计算上是否可行？如何设计高效的近似算法？

**已知瓶颈**：(1) 符号恢复概率的精确计算涉及高维正态概率，计算复杂度随 k 指数增长；(2) 设计空间是离散的（±1 矩阵），组合优化困难；(3) 理论结果多依赖充分条件，最优性结论难以推广到一般设定。

#### ⚠️ 作者的 framing（必须明确标注成"这是作者的说法"）

作者将缺口 frame 成："现有 SSD 准则（E(s²), UE(s²), Var(s⁺)）都是启发式的，没有直接最大化 lasso 的符号恢复概率。本文通过建立直接面向符号恢复概率的最优性框架，回答了'何种设计在 lasso 分析下最优'这一根本问题，并证明了 Var(s⁺) 准则在已知符号为正时的合理性。" 作者淡化的竞争路线包括：(1) 贝叶斯最优设计方法（未在文中讨论）；(2) 基于 RIP 的 DCD 准则——作者指出 DCD 的构造需要大量计算且不保证全局最优，但未系统比较 DCD 与 HILS 在符号恢复概率上的差异；(3) 随机设计（如随机 SSD）作为基准——作者仅在模拟中部分涉及。

**值得研究者去查的问题**：作者声称"正交设计在符号未知时是理想结构"，但这一结论是否依赖于高斯误差和固定 λ 的假设？在非高斯误差或自适应 λ 选择下是否仍然成立？此外，作者未讨论设计矩阵的行正交化（即 X 的列是否应正交于截距列）对结果的影响。

#### 张力

未见明显对立引用。但存在一个微妙张力：Singh and Stufken (2023) 的 DCD 准则基于 RIP/不可表示条件，其隐含的最优设计倾向是"尽可能正交"；而本文证明在符号已知时正相关设计更优。这两者并不矛盾（因为 DCD 不利用符号信息），但说明"最优设计"高度依赖于实验者对符号的先验知识，这在实际应用中可能是一个被低估的因素。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：把符号、模型、可观测数据交代清楚

**符号**：

- **设计矩阵**：X 为 n × p 矩阵，元素 x_ij ∈ {±1}。F = (I − P₁)X V^(−1/2) 是中心化、标准化后的设计矩阵，其中 P₁ = n⁻¹ 11' 是投影到截距列的投影矩阵，V 是对角矩阵，其第 j 个对角元素为 n⁻¹ x_j' (I − P₁) x_j（即第 j 列的中心化平方和）。
- **模型**：y = β₀ 1 + Xβ + e，其中 e ~ N(0, σ² I)。假设 σ² = 1，因此 β 是信噪比（signed signal-to-noise ratios）。
- **参数 / 估计目标**：β 为 p 维稀疏系数向量，支持集 A = {j : |β_j| > 0}，|A| = k < p。符号向量 z = sign(β)，其中 z_j ∈ {−1, 0, +1}。**估计目标**是恢复 z（比恢复 A 更严格，因为还要求符号正确）。
- **随机变量 / 样本**：y 是 n 维观测响应向量；e 是 n 维标准正态噪声向量。X 是**设计变量**（实验者选择，非随机），但在分析中视为固定。
- **潜在 / 不可观测量**：β 的真实值、支持集 A、符号向量 z 都是不可观测的潜在量。误差 e 不可观测。**关键点**：在 SSD 设定下（n < p + 1），X 的列不可能线性无关，因此 β 在最小二乘意义下不可识别；lasso 通过 ℓ₁ 惩罚实现识别，但符号恢复概率取决于 X 的相关结构。
- **关键衍生量**：
  - C = F'F 是 p × p 相关矩阵（对角线为 1）。
  - C_A 是 C 中对应于活跃集 A 的子矩阵。
  - C_IA 是 C 中非活跃集 I 与活跃集 A 的交叉相关矩阵。
  - λ > 0 是 lasso 的调参参数（固定）。
  - 事件 S_λ := {u < √n V_A^(1/2) β_A}，其中 u ~ N(λ√n Z_A C_A⁻¹ z_A, Z_A C_A⁻¹ Z_A)，对应活跃系数的符号正确。
  - 事件 I_λ := {|v| ≤ λ√n 1}，其中 v ~ N(λ√n C_IA C_A⁻¹ z_A, C_I − C_IA C_A⁻¹ C_AI)，对应非活跃系数被正确排除。
  - 符号恢复概率：P(ẑ = z | X, β, λ) = P(S_λ ∩ I_λ | C, V_A, β)。

**模型**：数据生成机制为 y = β₀ 1 + Xβ + e，e ~ N(0, I)。**已知**：X（设计者选择）、β（假设已知，用于设计准则）、λ（固定）。**要估计**：z = sign(β)。**可观测数据**：y（n 维向量）。**不可观测**：β、e、z。

#### 第二步：最小内核

**最小内核**：考虑最简单的非平凡情形——p = 2 个因子，其中 k = 1 个活跃因子（设为因子 1），且其效应方向已知为正（z₁ = +1）。试验次数 n 满足 n < p + 1 = 3，即 n = 2。设计矩阵 X 为 2 × 2 矩阵，元素 ±1。

**问题**：在 n = 2, p = 2, k = 1, z₁ = +1 的设定下，lasso 的符号恢复概率 P(ẑ = z | X, β, λ) 作为 X 的函数，其最大值在何处取得？

**分析**：
- 由于 n = 2，X 的两列要么相同（完全正相关，c = +1），要么相反（完全负相关，c = −1），要么正交（c = 0，但 n = 2 时两列 ±1 只能相同或相反，无法正交）。因此，唯一可调的自由度是两列的相对符号。
- 设 X = [x₁, x₂]，其中 x₁ = (1, 1)'，x₂ = (1, −1)'（正交情形在 n = 2 时不可达，但若允许非 ±1 设计则可）。实际可行的设计只有两种：x₂ = x₁（c = +1）或 x₂ = −x₁（c = −1）。
- 对于 c = +1：C_A = [1]，C_IA = [1]，C_I = [1]。事件 S_λ：u ~ N(λ√2 − β, 1)，P(S_λ) = Φ(β − λ√2)。事件 I_λ：v ~ N(λ√2, 0)（退化），P(I_λ) = 1 当且仅当 λ√2 ≤ λ√2（恒成立）。因此 P(ẑ = z) = Φ(β − λ√2)。
- 对于 c = −1：C_A = [1]，C_IA = [−1]，C_I = [1]。事件 S_λ：u ~ N(λ√2 − β, 1)，P(S_λ) = Φ(β − λ√2)。事件 I_λ：v ~ N(−λ√2, 0)（退化），P(I_λ) = 1 当且仅当 |−λ√2| ≤ λ√2（恒成立）。因此 P(ẑ = z) = Φ(β − λ√2)。
- 两种设计的符号恢复概率相同！这说明在 k = 1 时，设计的相关结构不影响符号恢复概率。

**关键洞察**：当 k = 1 时，符号恢复概率只取决于活跃因子的信噪比 β 和 λ，与设计无关。**当 k ≥ 2 时，设计才起作用**。考虑 k = 2, p = 3, n = 2 的设定（n < p + 1 = 4）。此时活跃集 A = {1, 2}，非活跃集 I = {3}。设计矩阵 X 为 2 × 3 矩阵。符号恢复概率 P(ẑ = z) = P(S_λ) × P(I_λ)。事件 S_λ 的概率取决于 C_A 的特征值（通过 u 的协方差），事件 I_λ 的概率取决于 C_IA C_A⁻¹ z_A 和 C_I − C_IA C_A⁻¹ C_AI。**核心数学困难**：最大化 P(S_λ ∩ I_λ) 涉及高维正态概率的优化，且 C_A 和 C_IA 相互制约（因为 X 的列必须满足 Gram 矩阵半正定约束）。

**本文的核心思想**：将设计问题分解为两步——(1) 在理论上证明，在符号未知时，正交设计（C = I）最大化符号恢复概率；(2) 在符号已知时，常数小正相关设计（C 的对角线为 1，非对角线为小正数 c > 0）是理想的。这个结论通过分析 S_λ 和 I_λ 事件在 C 上的单调性得出，并利用矩阵平均技术（matrix averaging）将高维优化约化为单变量优化。

**为什么这个内核重要**：它揭示了设计准则与 lasso 统计性质之间的直接联系——正交性并非无条件最优，符号信息的存在会改变最优设计的结构。这为 Var(s⁺) 准则提供了理论依据，也为实际实验设计提供了可操作的指导。

### 三、这篇论文做了什么

#### 三句话

① **研究了什么问题**：在超饱和设计（n < p + 1）下，如何构造最大化 lasso 符号恢复概率的最优设计矩阵 X，并回答两个开放问题：现有启发式准则（E(s²), UE(s²), Var(s⁺)）是否最优，以及为何正相关设计在符号已知时产生更明确的解路径。
② **核心工具 / 方法**：将符号恢复概率分解为两个独立事件 S_λ（活跃系数符号正确）和 I_λ（非活跃系数被排除）的概率之积；利用矩阵平均技术将设计优化约化为对完全对称相关矩阵 C ∈ C_{p,k} 的单变量优化；提出两阶段构造算法 HILS，先用启发式准则（最大化 tr(V)、最小化 ||C − C*||_F）筛选候选设计，再从中选择最大化符号恢复概率的设计。
③ **主要结论**：(1) 当符号未知时，正交设计（C = I）是理想结构，且在局部意义下最优；(2) 当符号已知且为正时，常数小正相关设计（C 的非对角线为 c > 0）是理想结构，且 c 的最优值可通过单变量优化确定；(3) HILS 算法能在可接受的计算时间内构造出在符号恢复概率上优于或等同于现有准则（E(s²), UE(s²), Var(s⁺), DCD）的设计。

#### 关键设定与假设

- **模型**：y = β₀ 1 + Xβ + e，e ~ N(0, σ² I)，σ² = 1。
- **设计矩阵**：X 为 n × p 矩阵，元素 ±1，中心化后 F = (I − P₁)X V^(−1/2)，C = F'F 为相关矩阵。
- **稀疏性**：活跃集 A 大小 k < n（保证 C_A 可逆），非活跃集 I 大小 p − k。
- **符号已知性**：在"符号已知"设定下，假设 z_A = 1（所有活跃效应为正），且通过列翻转（将 x_j 替换为 −x_j）可将任意符号向量转化为 z_A = 1。
- **λ 固定**：lasso 调参参数 λ > 0 视为固定，不涉及 λ 的选择策略。
- **关键假设**：符号恢复概率可分解为 P(ẑ = z) = P(S_λ) × P(I_λ)，其中 S_λ 和 I_λ 独立（由 Lemma 1 证明，基于 u 和 v 的协方差为零）。
- **相比已有文献的放宽/强化**：相比 Singh and Stufken (2023) 的 DCD 准则（基于 RIP/不可表示条件的充分条件），本文直接优化符号恢复概率，不依赖充分条件；相比 Var(s⁺) 准则（Weese et al. 2021），本文提供了理论证明而非仅模拟证据。但本文的结论限于高斯误差和固定 λ，未推广到非高斯或自适应 λ。

#### 主要结果

**定理 1（符号翻转等价性）**：对于任意设计 X 和符号向量 z，ϕ_λ(X | β) = ϕ_λ(X Z̃ | β̃)，其中 Z̃ 是对角线为 z 的对角矩阵，β̃ = Z̃β。这意味着设计优化可以假设 z_A = 1 而不失一般性。

**定理 2（符号已知时的最优性）**：对于 β_A = β 1（所有活跃效应大小相同且为正），在 C ∈ C_{p,k}（完全对称相关矩阵）的约束下，ψ_λ(c | k, β) 在 c > 0 处取得最大值，且 c 的最优值随 β 和 λ 变化。具体地，当 λ 满足 (18) 式（即 2λ ≥ g(τ)/G(τ)，其中 τ = β − λ）时，d/dc ψ_λ(c|k,β)|_{c=0} > 0，说明正交设计（c = 0）不是最优的，正相关设计更优。

**定理 3（符号未知时的局部最优性）**：对于 ψ_λ^±(c | k, β)（对所有符号取平均），c = 0 是局部最大值，即正交设计在符号未知时是局部最优的。这为 E(s²) 和 UE(s²) 准则提供了理论依据。

**引理 2（事件概率的显式形式）**：当 C ∈ C_{p,k} 时，S_λ 和 I_λ 的概率可以写成关于 c 的显式函数，使得单变量优化可行。具体地，u ~ N(λ/(1+c(k−1)) 1, 1/(1−c) [I − γJ])，v ~ N(λkγ 1, (1−c)[I + γJ])，其中 γ = c/(1+c(k−1))。

**HILS 算法**：两阶段构造——(1) 用坐标交换算法（coordinate exchange）在 Pareto 前沿上优化 tr(V) 和 ||C − C*||_F（C* 为理论最优完全对称矩阵）；(2) 对 Pareto 前沿上的候选设计，用数值方法评估 ϕ_λ 或 ϕ_λ^±，选择最优者。计算复杂度：阶段 1 为 O(n p²) 量级，阶段 2 需要 O(p^k) 次概率评估，但通过采样（如 NBIBD）可降至 O(1) 量级。

#### 真实例子与应用

**场景 1（n = 9, p = 10, 符号未知）**：HILS 算法在 k = 3, β = 3 下构造的设计，其 Φ_λ^± 曲线在 log(λ) ∈ [−2, 1] 范围内优于 UE(s²)-optimal 设计，最大差异约 0.05（在 log(λ) ≈ 0 处）。当 k = 5 时，HILS 设计与 UE(s²)-optimal 设计差异减小，但仍略优。

**场景 2（n = 9, p = 10, 符号已知为正）**：HILS 算法在 k = 3, β = 3 下构造的设计，其 Φ_λ 曲线在 log(λ) ∈ [−1, 1] 范围内优于 Var(s⁺)-optimal 设计，最大差异约 0.08（在 log(λ) ≈ 0.5 处）。当 k = 5, β = 4 时，DCD 在 log(λ) ≈ 0.8 处略优于 HILS 设计（差异约 0.02），但 HILS 设计在更大 λ 范围内表现更稳定。

**场景 3（n = 14, p = 20, 符号已知为正）**：HILS 算法在 k = 5, β = 2 下构造的设计，其 Φ_λ 曲线与 Var(s⁺)-optimal 和 DCD 设计几乎重合，差异小于 0.01。但 HILS 设计的构造时间约 1 小时 21 分钟，远快于 DCD 的"数十小时"。

**这些例子想说明什么**：HILS 设计在符号已知时能显著提升符号恢复概率（场景 2），在符号未知时至少不劣于传统准则（场景 1），且计算效率远高于 DCD（场景 3）。但场景 3 显示，当 n 远小于 p 时，设计自由度受限，不同准则的差异减小。

#### 🔎 结论是否比证明窄

- **定理 2 的证明仅覆盖 β_A = β 1 的情形**，但作者在讨论中声称"正相关设计在符号已知时更优"是普遍结论。对于 β_A 元素大小不等的情形，最优 c 可能不再是常数，且正相关设计是否仍最优未证明。
- **定理 3 仅证明 c = 0 是局部最大值**，未排除其他 c ≠ 0 的全局最大值。作者在数值实验中观察到 c = 0 是全局最优，但未给出理论证明。
- **HILS 算法的 Pareto 前沿优化基于启发式准则**（tr(V) 和 ||C − C*||_F），作者未证明 Pareto 前沿上的设计一定包含全局最优设计。这是一个"算法启发式 + 理论目标"的混合框架，严格性弱于纯理论最优性。
- **所有理论结果假设高斯误差和固定 λ**，作者在讨论中承认推广到非高斯或自适应 λ 是未来工作，但未给出任何猜想或部分结果。

### 四、开放问题

1. **非均匀效应大小的最优设计**：定理 2 假设 β_A = β 1。当活跃效应的幅度不同（β_j 各异）时，最优相关结构是否仍为常数正相关？若不是，如何刻画？这需要推广矩阵平均技术到非对称情形。（扎根于定理 2 的证明假设）

2. **全局最优性的证明**：定理 3 仅证明正交设计在符号未知时是局部最优。是否存在 c ≠ 0 的全局最优？作者在数值实验中未发现，但缺乏理论证明。这可能需要新的分析工具，如对数凹性验证或随机序方法。（扎根于定理 3 的陈述）

3. **自适应 λ 的扩展**：本文固定 λ，但实际中 λ 通常通过交叉验证选择。若 λ 是数据的函数，符号恢复概率的分解（Lemma 1）是否仍然成立？这涉及 λ 与 X 的依赖结构，可能需要经验过程理论。（扎根于第 6 节的 future work 讨论）

4. **非高斯误差的鲁棒性**：本文假设 e ~ N(0, I)。对于重尾噪声或异方差噪声，符号恢复概率的表达式会改变，最优设计是否仍为常数正相关？这需要将证明推广到椭圆分布或次高斯框架。（扎根于第 6 节的 future work 讨论）

5. **HILS 算法的理论保证**：Pareto 前沿优化基于启发式准则，作者未证明前沿上的设计包含全局最优。能否给出一个"近似最优"的界，例如证明 HILS 设计的符号恢复概率至少达到全局最优的某个比例？（扎根于第 4 节的算法描述）

6. **最小-最大准则**：本文考虑平均符号恢复概率（对所有 A 和 z 取平均）。若采用最小-最大准则（最坏情形下的符号恢复概率），最优设计是否改变？这可能与 DCD 的 RIP 准则产生联系。（扎根于第 6 节的讨论）

**提示**：要确认这些是否是真 gap，建议去读近 5 年 SSD 构造文献（如 *Technometrics*、*JSPI* 上的相关论文）的引言部分——如果多篇都指向同一问题，则是共识性 gap；如果互相矛盾，则是机会。
