### 一、领域脉络与小综述

#### 这个方向是什么

本文研究的核心问题是：在过参数化线性回归中，最小 ℓ_q-范数插值估计量（即在完美拟合所有训练数据的前提下，具有最小 ℓ_q-范数的系数向量）何时能够实现“良性过拟合”（benign overfitting）——即虽然模型完美记住了训练数据，但其总体风险（population risk）仍然趋于零。这个问题的根本在于理解插值估计量的“隐式正则化”机制：尽管没有显式的惩罚项，最小范数约束本身如何在高维空间中引导算法找到一个泛化性能良好的解。该方向处于高维统计、随机矩阵理论和凸几何的交叉点，其成熟度处于快速发展阶段，核心挑战在于将 ℓ₂ 和 ℓ₁ 范数的特例推广到一般 ℓ_q 范数的连续谱系。

#### 发展脉络

1. **奠基工作：ℓ₂ 范数插值**。该领域的起点是 Bartlett 等人 (2020) 对最小 ℓ₂-范数插值估计量的开创性分析。他们通过将特征空间分解为“信号子空间”和“噪声吸收子空间”，揭示了良性过拟合发生的两个关键条件：一是信号子空间的维度远小于样本量（|J|/N → 0），二是噪声吸收子空间能够有效吸收噪声（N·σ²ξ/R_k → 0）。这一分解思想（即本文所称的 FSD 框架）成为后续所有工作的理论基础。

2. **主要进展：ℓ₁ 范数与稀疏性**。随后，Wang, Donhauser 和 Yang (2022) 将分析扩展到最小 ℓ₁-范数插值估计量（即基追踪），证明了在稀疏信号假设下，ℓ₁ 范数插值同样可以表现出良性过拟合。这一工作表明，不同的几何约束（ℓ₁ 球 vs. ℓ₂ 球）会导致截然不同的隐式正则化行为，从而引发了对一般 ℓ_q 范数插值的研究兴趣。

3. **当前前沿：一般 ℓ_q 范数与超越高斯假设**。本文（Adamczak, Lecué, Shang, Strzelecka, 2026）代表了当前的前沿。它首次将 FSD 框架推广到任意 1 < q < ∞ 的 ℓ_q 范数，并同时处理了三个关键的理论挑战：
   - **超越高斯性**：通过 Dvoretzky-Milman 型定理，将分析从高斯设计推广到凸浓度、弱矩和对数凹三种更广泛的分布假设。
   - **超越各向同性**：允许协方差矩阵 Σ 非对角（在凸浓度情形），只需满足块对角结构。
   - **超越 CGDT 技术**：绕过了以往依赖高斯极小极大定理（CGDT）的分析路径，为处理非高斯、非对称问题提供了新工具。

#### 子线索聚类

- **几何与范数结构**：这一线索关注不同 ℓ_q 范数的几何性质如何影响插值估计量的行为。关键工作包括 Koehler 等人 (2021) 对一般范数插值的统一分析框架，以及本文对 ℓ_q 球在 q<2 和 q>2 时截然不同的几何行为（凸 vs. 非凸）的刻画。
- **概率与集中不等式**：这一线索关注随机矩阵的谱性质。核心工具包括凸浓度不等式（Talagrand 1995）、对数凹向量的集中性（Paouris 2006）、以及本文新建立的 ℓ_q 范数下的 Dvoretzky-Milman 型定理。
- **统计与学习理论**：这一线索关注泛化误差的刻画。关键工作包括 Tsigler 和 Bartlett (2023) 对岭回归的精确刻画，以及本文对插值估计量在非高斯设计下的风险上界。

#### 核心问题

1. **良性过拟合的充分条件**：在什么条件下，最小 ℓ_q-范数插值估计量的总体风险趋于零？本文给出了三个关键条件（见定理 1.1）：信号子空间维度可忽略（|J|/N → 0）、信号与协方差结构的对齐（∥β*_J∥_q·ℓ*/√N → 0）、以及噪声吸收子空间的有效性（N·σ²ξ/R* → 0）。
2. **自正则化机制**：最小 ℓ_q-范数约束如何在无显式惩罚的情况下实现正则化？本文通过 FSD 框架揭示了这一机制：在估计子空间 J 上，估计量表现为一个自正则化的经验风险最小化器（见公式 2.12），其惩罚项由 ℓ_q 范数自然产生。
3. **分布的普适性**：良性过拟合现象是否依赖于高斯假设？本文通过建立三种不同分布假设下的 Dvoretzky-Milman 型定理，证明了该现象的普适性。

#### ⚠️ 作者的 framing

作者将本文定位为“FSD 框架超越欧几里得和高斯设定的推广”。他们强调的核心贡献是：(i) 建立了 ℓ_q 范数下的 Dvoretzky-Milman 型同构定理，这本身是凸几何的独立贡献；(ii) 揭示了最小 ℓ_q-范数插值估计量在估计子空间上等价于一个自正则化的 ERM，从而将插值问题转化为经典的正则化问题；(iii) 证明了良性过拟合的充分条件可以表达为信号-协方差对齐和噪声吸收子空间的谱性质。作者淡化了与 CGDT 方法的对比，而是强调 FSD 框架的几何直观性。

#### 张力

本文与 Koehler 等人 (2021) 的框架存在一个有趣的张力：Koehler 等人强调通过“局部范数”刻画插值估计量的风险，而本文则强调全局的 FSD 分解。两者在 ℓ₂ 情形下等价，但在一般 ℓ_q 情形下，FSD 分解的“信号/噪声”二分法可能不如 Koehler 等人的局部范数方法精细。此外，本文的充分条件（定理 1.1）与 Koehler 等人的必要条件之间的关系尚不明确——本文没有讨论其条件的必要性。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

**模型设定**：考虑线性回归模型
$$Y = \langle \beta^*, X \rangle + \xi,$$
其中：
- $X \in \mathbb{R}^p$ 是**中心化**的特征向量，协方差矩阵为 $\Sigma = \mathbb{E}[X X^\top]$。
- $\xi \in \mathbb{R}$ 是独立于 $X$ 的噪声，满足 $\mathbb{E}[\xi] = 0$，$\mathbb{E}[\xi^2] = \sigma^2_\xi$。
- $\beta^* \in \mathbb{R}^p$ 是未知的真实系数向量。

**观测数据**：我们观测到 $N$ 个独立同分布的样本 $\{(X_i, Y_i)\}_{i=1}^N$，其中 $X_i \overset{\text{i.i.d.}}{\sim} X$，$Y_i = \langle \beta^*, X_i \rangle + \xi_i$。

**估计量**：最小 ℓ_q-范数插值估计量定义为
$$\hat{\beta} = \arg\min_{\beta \in \mathbb{R}^p} \|\beta\|_q \quad \text{subject to} \quad X \beta = y,$$
其中 $X$ 是 $N \times p$ 的设计矩阵（第 $i$ 行为 $X_i^\top$），$y = (Y_1, \dots, Y_N)^\top$。这里 $1 < q < \infty$，$\|\beta\|_q = (\sum_{j=1}^p |\beta_j|^q)^{1/q}$。

**目标量**：总体过剩风险（excess risk）
$$\mathbb{E}\left[ \left( Y - \langle \hat{\beta}, X \rangle \right)^2 \mid \mathcal{D} \right] - \mathbb{E}\left[ \left( Y - \langle \beta^*, X \rangle \right)^2 \right] = \|\Sigma^{1/2}(\hat{\beta} - \beta^*)\|_2^2,$$
其中 $\mathcal{D}$ 是训练数据。我们关心的是在 $N, p \to \infty$ 时，这个量是否趋于零（良性过拟合）。

**关键记号**：
- **特征空间分解（FSD）**：将坐标集 $[p] = \{1, \dots, p\}$ 分解为 $J \cup J^c$，其中 $J$ 是“估计子空间”（信号所在），$J^c$ 是“噪声吸收子空间”。对应的投影为 $P_J$ 和 $P_{J^c}$。
- **ℓ_q-高斯平均宽度**：$\ell_* = \ell_*(\Sigma_{J^c}^{1/2} B_{J^c}^q)$，其中 $B_{J^c}^q$ 是 $\mathbb{R}^{J^c}$ 中的 ℓ_q-单位球。
- **Dvoretzky 维数**：$d_* = (\ell_* / \text{diam}(\Sigma_{J^c}^{1/2} B_{J^c}^q))^2$。
- **有效秩**：$R_* = \ell_*^{2q'} / \text{Tr}(\Sigma_{J^c}^{q'})$，其中 $q' = q/(q-1)$ 是 Hölder 共轭指数。
- **信号范数**：$\|\beta^*_J\|_q$ 是真实信号在估计子空间上的 ℓ_q-范数。

#### 第二步：最小内核——一维情形下的“信号 vs. 噪声”权衡

为了理解 FSD 框架的核心思想，我们考虑一个极简化的情形：$p = 2$，$J = \{1\}$，$J^c = \{2\}$，且 $\Sigma = \text{diag}(\sigma_1, \sigma_2)$ 是对角矩阵。此时模型为
$$Y = \beta_1^* X_1 + \beta_2^* X_2 + \xi.$$

**插值约束**：最小 ℓ_q-范数插值估计量 $\hat{\beta}$ 必须满足 $X \hat{\beta} = y$，即
$$X_1 \hat{\beta}_1 + X_2 \hat{\beta}_2 = y.$$
由于 $p > N$（过参数化），这个方程有无穷多解。最小 ℓ_q-范数约束选择其中范数最小的解。

**FSD 分解**：将 $\hat{\beta}$ 分解为 $\hat{\beta}_J = \hat{\beta}_1$（估计部分）和 $\hat{\beta}_{J^c} = \hat{\beta}_2$（噪声吸收部分）。插值约束可以重写为：
$$X_1 \hat{\beta}_1 + X_2 \hat{\beta}_2 = X_1 \beta_1^* + X_2 \beta_2^* + \xi.$$

**核心观察**：由于 $\hat{\beta}$ 是 ℓ_q-范数最小的解，它倾向于将“能量”集中在范数贡献较小的方向上。当 $q < 2$ 时，ℓ_q-范数对稀疏解有偏好（类似于 ℓ₁），因此 $\hat{\beta}_2$ 可能趋于稀疏；当 $q > 2$ 时，ℓ_q-范数对均匀解有偏好，因此 $\hat{\beta}_2$ 可能趋于均匀。

**风险分解**：过剩风险为
$$\|\Sigma^{1/2}(\hat{\beta} - \beta^*)\|_2^2 = \sigma_1 (\hat{\beta}_1 - \beta_1^*)^2 + \sigma_2 \hat{\beta}_2^2.$$
这里我们假设 $\beta_2^* = 0$（即真实信号只存在于 $J$ 中），因此 $\hat{\beta}_2$ 纯粹是噪声吸收的产物。

**关键权衡**：
- **估计部分** $\sigma_1 (\hat{\beta}_1 - \beta_1^*)^2$：$\hat{\beta}_1$ 需要从 $y$ 中“提取”信号，但由于 $y$ 包含噪声 $\xi$，$\hat{\beta}_1$ 会有估计误差。这个误差可以通过在 $J$ 上的均匀收敛（RIP 条件）来控制。
- **噪声吸收部分** $\sigma_2 \hat{\beta}_2^2$：$\hat{\beta}_2$ 用于吸收噪声 $\xi$，使其不干扰 $\hat{\beta}_1$ 的估计。这个部分的代价是 $\sigma_2 \hat{\beta}_2^2$，它取决于噪声吸收子空间的谱性质。

**良性过拟合的条件**：为了使过剩风险趋于零，我们需要：
1. **估计部分可控**：$|J|/N \to 0$，使得 $J$ 上的经验过程可以均匀收敛。
2. **噪声吸收部分可控**：$N \sigma_\xi^2 / R_* \to 0$，其中 $R_*$ 是噪声吸收子空间的有效秩。这个条件意味着噪声吸收子空间必须足够“大”（有效秩足够高），才能以较低的范数代价吸收噪声。
3. **信号对齐**：$\|\beta^*_J\|_q \ell_* / \sqrt{N} \to 0$，确保信号与协方差结构的对齐不会导致过大的偏差。

**为什么 Dvoretzky-Milman 定理是关键？** 在上述一维情形中，$\hat{\beta}_2$ 的范数可以通过 Cauchy-Schwarz 不等式直接估计。但在高维情形下，$\hat{\beta}_2$ 是 $X_{J^c}$ 的列空间的某个特定元素，其范数依赖于随机矩阵 $X_{J^c}$ 的谱性质。Dvoretzky-Milman 定理保证了：在适当的条件下，随机矩阵 $X_{J^c}$ 的 ℓ_q-范数行为与高斯矩阵类似，从而可以精确控制 $\hat{\beta}_2$ 的范数。这正是本文的核心技术贡献——将 Dvoretzky-Milman 定理从高斯情形推广到凸浓度、弱矩和对数凹情形。

**为什么这个例子是“最小内核”？** 因为它揭示了 FSD 框架的三个核心要素：
1. **空间分解**：将特征空间分为“估计”和“噪声吸收”两部分。
2. **自正则化**：最小 ℓ_q-范数约束在估计子空间上产生一个隐式的正则化项。
3. **谱控制**：噪声吸收子空间的谱性质（通过 Dvoretzky-Milman 定理刻画）决定了噪声吸收的代价。

一般情形的证明（定理 2.2、3.1、5.2）只是将这个一维情形的思想推广到高维，并用更精细的概率工具（RIP、Dvoretzky-Milman、集中不等式）来控制各个误差项。

### 三、这篇论文做了什么

#### 三句话

1. **研究问题**：本文研究了线性回归中最小 ℓ_q-范数插值估计量（$1 < q < \infty$）的总体过剩风险，给出了其在凸浓度、弱矩和对数凹三种非高斯设计下良性过拟合的充分条件。
2. **核心方法**：采用特征空间分解（FSD）框架，将风险分解为估计部分和噪声吸收部分，并利用新建立的 ℓ_q-范数 Dvoretzky-Milman 型同构定理来控制噪声吸收部分。
3. **主要结论**：在信号子空间维度可忽略、信号与协方差对齐、以及噪声吸收子空间有效秩足够大的条件下，最小 ℓ_q-范数插值估计量表现出良性过拟合；这些条件在 q=2 时与已知最优条件一致，并揭示了 q<2 与 q>2 时截然不同的几何行为。

#### 关键设定与假设

- **凸浓度情形（定理 2.2）**：假设特征向量 $X = \Sigma^{1/2}\zeta$ 满足凸浓度不等式（2.1），即对任意凸 1-Lipschitz 函数 $f$，$f(\zeta_1, \ldots, \zeta_p)$ 围绕其均值指数集中。这比高斯假设弱得多，涵盖了均匀分布在高维凸体上的随机向量、以及具有独立有界坐标的向量。**关键假设**：$X_J$ 与 $X_{J^c}$ 独立（等价于 $\Sigma$ 关于 $J$ 块对角），且 $N \leq \kappa_{DM} d_*$（Dvoretzky-Milman 窗口）。
- **弱矩情形（定理 3.1）**：假设 $\zeta$ 的坐标独立且满足 $\mathbb{E}|\zeta_j|^{2q'+ε} \le M^{2q'+ε}$（$q' = q/(q-1)$），即比有限四阶矩稍强。**关键假设**：$\Sigma$ 对角，且 $N \le \kappa_{DM} d_* \log^{-2}(|J^c|)$（仅当 $q>2$ 时需要对数因子）。
- **对数凹情形（定理 5.5）**：假设 $\zeta$ 是对数凹向量（密度 $e^{-V}$，$V$ 凸）。**关键假设**：$\Sigma$ 对角，且 $N \le \kappa_{DM} d_* \log^{-2}(|J^c|) \log^{-1}\log(|J^c|)$。

**相比已有工作的放宽**：与 Koehler 等人 (2021) 和 Wang 等人 (2022) 相比，本文的主要放宽在于**去掉了高斯假设**，并允许协方差矩阵非对角（在凸浓度情形）。代价是 Dvoretzky-Milman 窗口 $N \le \kappa_{DM} d_*$ 比高斯情形下的 $N \le \kappa d_*$ 更严格（常数 $\kappa_{DM}$ 可能更小），且在弱矩和对数凹情形需要额外的对数因子。

#### 主要结果

**定理 2.2（凸浓度情形）**：在假设 2.1 下，存在常数 $C, c > 0$ 使得当 $C|J| \le N \le \kappa_{DM} d_*$ 时，以概率至少 $1 - 2\exp(-c\min\{|J|, d_*\})$，有
$$\|\Sigma^{1/2}(\hat{\beta} - \beta^*)\|_2 \le C \left[ \left(\frac{|J|}{N}\right)^{\frac{1}{2(q-1)}} S + \left(\frac{\ell_*}{\sqrt{N}}\right)^{\frac{q}{q-1}} B^{\frac{1}{q-1}} + \|\Sigma_{J^c}^{1/2}\beta^*_{J^c}\|_2 \right],$$
其中 $S = \sigma_\xi + \|\Sigma_{J^c}^{1/2}\beta^*_{J^c}\|_2$，$B = \|\beta^*_J\|_q$。

**定理 3.1（弱矩情形，改进的噪声吸收）**：在假设 5.1 下，存在常数 $C, c > 0$ 使得当 $C|J| \le N \le \kappa_{DM} d_* \log^{-2}(|J^c|)^{1_{\{q>2\}}}$ 时，以概率至少 $1 - C/\min\{N^{ε/2}, |J|\}$，有
$$\|\Sigma^{1/2}(\hat{\beta} - \beta^*)\|_2 \le C \left[ L \left(\frac{|J|}{N}\right)^{\delta_0} S + \sigma_\xi \sqrt{\frac{N}{R_*}} + \|\Sigma_{J^c}^{1/2}\beta^*_{J^c}\|_2 \right],$$
其中 $L = \log^{q'}(|J^c|)$，$\delta_0 = \min\{1/(2(q-1)), 1/2\}$，$R_* = \ell_*^{2q'}/\text{Tr}(\Sigma_{J^c}^{q'})$。

**关键改进**：定理 3.1 将噪声吸收项的界从 $\sigma_\xi \sqrt{N/d_*}$（由定理 2.2 的“快速”估计得到）改进为 $\sigma_\xi \sqrt{N/R_*}$，其中 $R_* \ge d_*$ 是有效秩。这个改进在 $q<2$ 时是本质的：它允许协方差谱在 $J^c$ 上缓慢衰减，从而扩大了良性过拟合的参数范围。

#### 证明路线与技术技巧

**整体路线**（以定理 2.2 为例）：

1. **FSD 分解**：将过剩风险分解为三个部分（公式 2.17）：
$$\|\Sigma^{1/2}(\hat{\beta} - \beta^*)\|_2 \le \|\Sigma_{J}^{1/2}(\hat{\beta}_J - \beta^*_J)\|_2 + \|\Sigma_{J^c}^{1/2}\hat{\beta}_{J^c}\|_2 + \|\Sigma_{J^c}^{1/2}\beta^*_{J^c}\|_2.$$
第三项是确定性的“对齐误差”，第一项是“估计误差”，第二项是“噪声吸收误差”。

2. **估计误差控制**（命题 4.5）：利用 $\hat{\beta}_J$ 满足的最优性条件（公式 2.12），证明 $\hat{\beta}_J$ 是一个自正则化的 ERM。具体地，$\hat{\beta}_J$ 是如下问题的解：
$$\hat{\beta}_J = \arg\min_{\beta_J} \left\{ \|y - X_J \beta_J\|_2^2 + \lambda \|\beta_J\|_q^q \right\}$$
其中 $\lambda$ 由 $\ell_*$ 和 $N$ 决定。然后利用 $X_J$ 的 RIP 性质（命题 4.2）和凸浓度不等式，控制 $\hat{\beta}_J - \beta^*_J$ 在 $\Sigma_J$-范数下的误差。

3. **噪声吸收误差控制**（命题 4.3 + 7.5）：这是最核心的技术步骤。$\hat{\beta}_{J^c}$ 是 $X_{J^c}$ 的列空间的元素，其范数可以通过对偶范数来估计。关键在于证明：在 Dvoretzky-Milman 窗口 $N \le \kappa_{DM} d_*$ 内，随机矩阵 $X_{J^c}$ 的 ℓ_q-范数行为与高斯矩阵类似，即
$$\|\Sigma_{J^c}^{1/2} A[\xi]\|_2 \le C \sigma_\xi \sqrt{\frac{N}{d_*}}$$
对 $\xi \in \mathbb{R}^N$ 成立，其中 $A[\xi]$ 是公式 (2.13) 定义的算子。

3. **Dvoretzky-Milman 型定理**（第 8 节）：这是本文的技术核心。作者建立了三种情形下的 ℓ_q-范数同构定理：
   - **凸浓度情形（命题 8.1）**：利用凸浓度不等式和覆盖论证，证明对任意 $A$，随机矩阵 $X = AY$ 满足 $\|\Sigma^{1/2}A[\xi]\|_2 \asymp \ell_* \|\xi\|_2$。
   - **弱矩情形（定理 8.4）**：利用独立性和矩条件，通过截断和 Bernstein 不等式，证明类似的结果，但需要额外的对数因子。
   - **对数凹情形（命题 8.12）**：利用对数凹向量的 Paouris 不等式和覆盖论证，证明类似的结果。

4. **概率合并**：将上述三个误差项的概率事件合并，得到定理 2.2 的结论。

**关键技巧**：
- **对偶范数**：利用 $\|\beta\|_q = \sup_{\|\theta\|_{q'} \le 1} \langle \beta, \theta \rangle$，将 ℓ_q-范数的估计转化为对偶范数的上界。
- **覆盖论证**：用有限 $\varepsilon$-网覆盖单位球，将无穷维的算子范数估计转化为有限维的并集界。
- **截断方法**：在弱矩情形，将重尾变量截断为有界变量，然后应用 Bernstein 不等式。
- **凸浓度不等式**：利用 Talagrand 的凸距离不等式，处理非高斯、非独立的随机向量。

#### 🔎 结论是否比证明窄

**是的，存在明显的“结论比证明窄”的情况**：

1. **定理 2.2 的噪声吸收项不是最优的**：作者在公式 (2.26) 中给出了“快速”估计 $\sigma_\xi \sqrt{N/d_*}$，但随后在第 7 节中证明了改进的界 $\sigma_\xi \sqrt{N/R_*}$（定理 3.1）。然而，定理 2.2 本身仍然使用较弱的界，这意味着定理 2.2 的充分条件比实际证明所允许的要严格。作者在 3.1 节中明确指出了这一点，并称定理 3.1 是“改进的噪声吸收控制”。

2. **凸浓度情形下的协方差结构限制**：定理 2.2 只要求 $\Sigma$ 关于 $J$ 块对角，但第 8 节的 Dvoretzky-Milman 定理（命题 8.1）实际上需要更强的条件（例如，$\Sigma_{J^c}$ 的谱有界）。作者在 Remark 2.3 中承认了这一点，但定理 2.2 的陈述并未明确包含这一限制。

3. **弱矩情形的对数因子**：定理 3.1 中的对数因子 $L = \log^{q'}(|J^c|)$ 可能不是最优的。作者在 5.1 节中推测，在更强的矩条件下可以去掉这个因子，但没有给出证明。

4. **必要性缺失**：本文只给出了良性过拟合的**充分条件**，没有讨论其**必要性**。作者在 2.2 节中与 Koehler 等人 (2021) 的比较表明，在 q=2 时这些条件也是必要的，但对于一般 q 的必要性尚不清楚。

### 四、开放问题

1. **必要性的刻画**：本文给出的充分条件（定理 1.1）是否也是必要的？在 q=2 时，Bartlett 等人 (2020) 证明了类似条件的必要性，但对于一般 q，这个问题完全开放。要回答这个问题，需要构造反例证明当条件不满足时，过剩风险不会趋于零。

2. **对数因子的最优性**：定理 3.1 中的对数因子 $L = \log^{q'}(|J^c|)$ 是否可以去掉？作者在 5.1 节中推测，在更强的矩条件下可以去掉，但没有给出证明。这需要改进第 8 节的 Dvoretzky-Milman 定理，可能涉及更精细的集中不等式。

3. **非对角协方差的一般化**：本文在凸浓度情形下允许 $\Sigma$ 非对角，但第 8 节的 Dvoretzky-Milman 定理实际上需要更强的条件。能否将定理 2.2 推广到一般的非对角 $\Sigma$？这可能需要新的几何工具来处理非坐标子空间。

4. **超越线性回归**：本文的分析仅限于线性回归。能否将 FSD 框架推广到核回归或浅层神经网络？Kur 等人 (2024) 已经开始了这方面的探索，但仅限于 ℓ₂ 范数。对于一般 ℓ_q 范数，这个问题完全开放。

5. **与计算复杂度的联系**：本文关注的是统计性质，但最小 ℓ_q-范数插值估计量的计算复杂度如何？对于 q≠1,2，这是一个非光滑凸优化问题，其计算复杂度可能随 q 变化。是否存在统计最优但计算不可行的 q 值？

- 以及 Koehler 等人 (2021) 和 Wang 等人 (2022) 的后续工作
