### 一、领域脉络与小综述（从 introduction + 参考文献 + 已构建摘要构建）

#### 这个方向是什么

本文所处的领域是**面板数据下的工具变量（Instrumental Variables, IV）方法**，具体聚焦于 Gabaix 和 Koijen (2024) 提出的 **Granular Instrumental Variables (GIV)** 框架。该框架解决的根本问题是：当研究者希望估计总量变量之间的结构关系（如价格弹性、资产价格对资本流动的响应）时，如何利用**少数大型个体（dominant units）的异质性冲击**作为工具变量来克服内生性。GIV 的核心思想是：当少数大个体（如大企业、大银行、大基金）在总量中占据显著份额时，它们的** idiosyncratic shocks**（与总量冲击无关的个体特定冲击）会通过加总传导到总量变量上，从而为内生回归量（如价格）提供外生变异来源。该方向当前处于**理论快速发展的早期阶段**——原始 GIV 论文（GK 2024）在固定 N 框架下建立了基础理论，而本文则试图将理论推广到 N 和 T 均趋于无穷的大面板情形，并系统刻画工具强度随 N 变化的三种 regime。

#### 发展脉络（history）

1. **奠基工作：Gabaix and Koijen (2024)**。GK 在固定 N、T→∞ 的框架下提出 GIV 并建立了最优工具变量理论。其关键假设是存在少数主导单位（dominant units），其 idiosyncratic shocks 可以作为有效工具。GK 的框架假设 N 固定，因此工具强度不随 N 变化，这为后续推广留下了空间。本文在引言中明确指出："the existing theory assumes a fixed number of units"（第 2 页），这是本文要填补的核心缺口。

2. **主要进展：Banafti and Lee (2022)**。BL 将 GIV 推广到高维情形，允许 N 随 T 增长，并推导了可行估计量的渐近分布。然而，本文在 Section 4.3.1 和 Appendix E 中指出，BL 的推导依赖于一个与幂律分布不相容的假设——他们的 Assumption 4(iii) 要求主导单位份额以特定速率衰减，但本文证明该假设与幂律尾部（power-law tail）不能同时成立。这是一个关键的竞争性工作，本文明确挑战其结论："their Theorem 2 and 4 conclude that the first-stage estimation of the instrument has no impact on the asymptotic variance of the GIV estimator. My Theorem 3 reaches the opposite conclusion"（第 24 页）。

3. **当前 frontier：本文的位置**。本文在 GK 和 BL 的基础上，做了三件事：(i) 将 GIV 理论推广到 N, T→∞ 的大面板框架；(ii) 用幂律分布（power-law distribution）的尾部指数 µ 作为工具强度的**单一充分统计量**，刻画了强、近弱、弱三种 regime；(iii) 证明可行估计量（需估计因子结构）的渐近方差与不可行估计量不同，推翻了 BL 的结论。本文的定位是**理论推进型**工作，而非应用型。

#### 子线索聚类

被引文献大致落在三条子线索上：

- **线索一：GIV 理论本身**。包括 GK (2024) 的原始框架、BL (2022) 的高维推广、以及本文的三种 regime 分类。这条线索的核心问题是：工具强度如何随 N 变化？何时 GIV 有效？
- **线索二：因子模型的渐近理论**。本文大量依赖 Bai (2003) 的主成分估计结果（收敛速率、渐近分布），以及 Bai and Ng (2002)、Ahn and Horenstein (2013) 的因子个数选择方法。这条线索为可行 GIV 估计提供了技术基础。
- **线索三：幂律分布与主导单位**。本文引用 Gabaix (2009) 关于幂律分布在经济金融中普遍存在的证据，以及 Gabaix and Ibragimov (2011) 的尾部指数估计方法。这条线索为 µ 的估计和 regime 分类提供了实证工具。

#### 这个方向在追问的核心问题

1. **工具强度如何随 N 变化？** 这是本文的核心问题。在固定 N 框架下，GIV 强度是常数；但当 N→∞ 时，工具强度取决于幂律尾部指数 µ 与 N/T 轨迹的交互。本文的 Proposition 1 给出了精确的衰减速率：µ∈(0,1) 时工具不衰减（强），µ∈(1,2) 时以 N^{1-1/µ} 衰减（近弱），µ>2 时以 N^{-1/2} 衰减（弱）。
2. **弱工具下如何做有效推断？** 本文的回答是：在近弱 regime 下，估计量仍一致且渐近正态（速率变慢），但 Wald 推断在 µ>2 时不可靠，应使用 Anderson-Rubin 置信集。
3. **可行估计（需估计因子结构）是否改变渐近性质？** 本文的答案是：不改变收敛速率，但改变渐近方差，需要修正标准误。

#### ⚠️ 作者的 framing（必须明确标注成"这是作者的说法"）

作者将本文定位为"解决 BL (2022) 遗留的开放问题"的**显然下一步**。具体来说，作者声称：(i) BL 的 Assumption 4(iii) 与幂律假设不相容，因此其结论在幂律设定下不成立；(ii) 本文的三种 regime 分类是"自然的"（natural）和"完整的"（complete）；(iii) 可行估计量的方差修正项是"必要的"（necessary）。这些是**作者自己的 framing**，研究者应独立评估：(i) BL 的假设是否真的在实证中不可接受？(ii) 三种 regime 的划分是否遗漏了边界情形（如 µ=1 和 µ=2，作者在 Appendix F 中单独处理）？(iii) 方差修正项在有限样本中的重要性是否如理论所示？

**什么明显该被引 / 该存在、却没出现在 intro 里？** 一个值得研究者去查的问题是：**弱工具变量的经典文献**（如 Staiger and Stock 1997, Stock and Yogo 2005）在本文中被引用，但**近弱工具（nearly-weak instruments）** 的文献（如 Andrews and Cheng 2012, Antoine and Renault 2021）在 intro 中仅被简要提及。此外，**高维因子模型的稳健推断**（如 Bai and Ng 2006 的置信区间构造）在本文中未被讨论，尽管可行估计量的推断依赖于因子估计的收敛速率。这些可能是作者有意淡化的竞争性方法。

#### 张力

被引工作之间**未见明显对立引用**，但存在一个潜在张力：GK (2024) 在固定 N 框架下强调 GIV 的**最优性**（optimal instrument），而本文在大面板框架下发现工具强度可能随 N 衰减，这意味着 GK 的最优性结论在 N→∞ 时可能不再成立。作者没有直接讨论这一张力，而是通过 regime 分类隐含地处理了它。研究者可以追问：当 µ>2 且 N/T→c 时，GIV 是否仍然是最优工具？如果不是，是否存在更好的工具构造？

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

**符号清单**（按类别分组）：

| 类别 | 符号 | 含义 |
|------|------|------|
| **参数/estimand** | $\phi^d$ | 需求弹性（结构参数，目标估计量） |
| | $\phi^s$ | 供给弹性（供给方程中的参数） |
| | $\beta^d, \beta^y$ | 控制变量系数（附录 G 中处理） |
| **随机变量/样本** | $d_t$ | t 期总量需求变化 |
| | $p_t$ | t 期价格变化（内生回归量） |
| | $y_{it}$ | 个体 i 在 t 期的供给变化 |
| | $y_t = (y_{1t}, \ldots, y_{Nt})'$ | N 维供给向量 |
| | $u_{it}$ | 个体 i 在 t 期的 idiosyncratic 供给冲击 |
| | $\varepsilon_t$ | 总量需求冲击（结构误差） |
| | $F_t$ | 公共因子（r 维） |
| | $\lambda_i$ | 个体 i 的因子载荷（r 维） |
| **维度/指标** | $N$ | 横截面个体数 |
| | $T$ | 时间期数 |
| | $r$ | 因子个数 |
| **构造量** | $S_i$ | 个体 i 的长期市场份额（$S_i = \frac{\mathcal{S}_i}{\sum_j \mathcal{S}_j}$） |
| | $S = (S_1, \ldots, S_N)'$ | 份额向量 |
| | $z_t = S' \bar{u}_t$ | GIV 工具（份额加权的去均值 idiosyncratic 冲击） |
| | $\bar{u}_t = D_N u_t$ | 去均值后的冲击向量（$D_N = I_N - \frac{\iota \iota'}{N}$） |
| | $\bar{y}_t = D_N y_t$ | 去均值后的供给向量 |
| | $\bar{Y}$ | $T \times N$ 去均值供给矩阵 |
| | $\hat{C}_t$ | 估计的公共成分 |
| | $\hat{\Lambda}$ | 估计的载荷矩阵 |
| | $a_N$ | 尺度因子（$a_N = N^{\delta}$，$\delta = \min(1-1/\mu, 1/2)$） |
| **关键函数** | $\Sigma_u$ | 冲击的协方差矩阵 |
| | $\Sigma_{\tilde{\Lambda}}$ | 载荷的协方差矩阵 |
| | $\Sigma_{\tilde{F}}$ | 因子的协方差矩阵 |
| | $\Omega$ | $E[u_t u_t']$ |
| | $\gamma(i,j)$ | $E[u_{it}u_{jt}]$ |
| | $\kappa^2_{conc}$ | 浓度参数（concentration parameter） |

**模型**（两方程系统）：

**需求方程**（结构方程，目标）：
$$d_t = \phi^d p_t + X_t^d + \varepsilon_t \quad (1)$$

**供给方程**（面板数据模型，含交互固定效应）：
$$y_{it} = \phi^s p_t + X_{it}^y + \lambda_i' F_t + u_{it} \quad (2)$$

**市场出清**：$d_t = y_t^S = \sum_{i=1}^N S_i y_{it}$（总量供给等于总量需求）

**可观测数据**：
- 研究者观测到：$\{d_t, p_t, y_t, X_t^d, X_t^y\}_{t=1}^T$，以及市场份额 $S_i$（由长期平均计算）
- 研究者**观测不到**：因子 $F_t$、载荷 $\lambda_i$、idiosyncratic 冲击 $u_{it}$、需求冲击 $\varepsilon_t$

**关键识别假设**（Assumption 1）：
- $E[F_t u_{it}] = 0$（因子与 idiosyncratic 冲击正交）
- $E[\varepsilon_t u_{it}] = 0$（需求冲击与供给冲击正交）
- $E[(y_t^S - \phi^d p_t) u_t] = 0$（排除限制：idiosyncratic 供给冲击不影响需求）

**GIV 工具**：$z_t = S' \bar{u}_t = S' D_N u_t$。直觉：当少数大个体主导总量时，它们的 idiosyncratic 冲击通过份额加权后仍保留在总量中，且与需求冲击 $\varepsilon_t$ 正交，因此可以作为 $p_t$ 的工具。

#### 第二步：最小内核

**核心数学问题**：当 N, T→∞ 时，GIV 估计量 $\hat{\phi}^d = \frac{\sum_t z_t y_t^S}{\sum_t z_t p_t}$ 的渐近行为如何？

**最小例子**：假设没有因子结构（$r=0$），没有控制变量，且 $u_{it}$ 是 i.i.d. 的。此时：
- 工具 $z_t = S' u_t = \sum_{i=1}^N S_i u_{it}$
- 分母（第一阶段）：$\frac{1}{T}\sum_t z_t p_t \to E[z_t p_t]$
- 分子（简化式）：$\frac{1}{\sqrt{T}}\sum_t z_t \varepsilon_t \to N(0, V_{z\varepsilon}(S))$

**关键量**：$z_t$ 的方差 $E[z_t^2] = S' \Omega S$。当 $S_i$ 服从幂律分布 $P(S_i > s) = c s^{-\mu}$ 时：
- 若 $\mu \in (0,1)$：$S' \Omega S = O_P(1)$，工具不衰减 → **强工具**
- 若 $\mu \in (1,2)$：$S' \Omega S = O_P(N^{2-2/\mu})$，工具以 $N^{1-1/\mu}$ 速率衰减 → **近弱工具**
- 若 $\mu > 2$：$S' \Omega S = O_P(N^{-1})$，工具以 $N^{-1/2}$ 速率衰减 → **弱工具**

**为什么这个例子是"最小内核"**：它剥离了因子结构、控制变量、序列相关等所有复杂性，只保留 GIV 的核心机制——份额加权的 idiosyncratic 冲击如何随 N 变化。一旦理解了 $S' \Omega S$ 的阶数如何随 $\mu$ 变化，三种 regime 的划分就自然浮现。因子结构的估计（Section 4）只是在这个内核上"加壳"：估计因子会引入额外的渐近方差项，但不改变收敛速率。

**证明的核心步骤**（以近弱 regime 为例）：
1. **分母**：$\frac{1}{T}\sum_t z_t p_t \xrightarrow{p} \frac{S'\Omega S}{\phi^d - \phi^s}$（由市场出清和供给方程推导）
2. **分子**：$\frac{1}{\sqrt{T}}\sum_t z_t \varepsilon_t \xrightarrow{d} N(0, V_{z\varepsilon}(S))$（由鞅差中心极限定理）
3. **合并**：$\hat{\phi}^d - \phi^d = \frac{\frac{1}{\sqrt{T}}\sum_t z_t \varepsilon_t}{\frac{1}{T}\sum_t z_t p_t} = O_P\left(\frac{1}{\sqrt{T} \cdot S'\Omega S}\right)$
4. **速率**：在近弱 regime，$S'\Omega S = O_P(N^{-2\delta})$，所以 $\hat{\phi}^d - \phi^d = O_P(N^{\delta}/\sqrt{T})$。当 $N/T \to 0$ 时，$N^{\delta}/\sqrt{T} \to 0$，估计量一致。

**为什么难**：难点不在这个最小例子本身，而在于：
1. **因子结构的估计误差**：当 $r>0$ 时，需要先估计 $F_t$ 和 $\lambda_i$，估计误差会传播到工具中（Lemma 2 和 3 处理这个问题）。
2. **幂律分布的极限行为**：$S'\Omega S$ 的阶数依赖于 $\mu$ 的精确值，而 $\mu$ 的估计本身有不确定性。
3. **浓度参数的慢速发散**：在近弱 regime，浓度参数 $\kappa^2_{conc} = O(N^{1-2\delta} \cdot f(N))$ 可能发散得很慢，导致有限样本下 Wald 推断不可靠。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：在大面板（N, T→∞）框架下，系统刻画 GIV 工具强度如何随幂律尾部指数 µ 和 N/T 轨迹变化，并据此划分强、近弱、弱三种工具强度 regime，为每种 regime 提供估计和推断理论。
2. **核心工具/方法**：将幂律分布尾部指数 µ 作为工具强度的充分统计量，结合 Bai (2003) 的主成分因子估计，推导可行 GIV 估计量的渐近分布；在弱工具 regime 下推荐 Anderson-Rubin 置信集。
3. **主要结论**：当 µ∈(0,1) 时 GIV 为强工具，估计量 $\sqrt{T}$-一致且渐近正态；当 µ>1 且 N/T→0 时，估计量以 $\sqrt{T}/N^\delta$ 速率一致且渐近正态（近弱工具）；当 µ>2 且 N/T→c>0 时，估计量不一致（弱工具）。可行估计量的渐近方差包含来自因子估计的额外项，需使用修正的标准误。

#### 关键设定与假设

**核心假设**（在最小内核基础上补全）：

1. **Assumption 1（外生性与平稳性）**：$(p_t, y_t', u_t', \varepsilon_t')'$ 是弱平稳过程，$E[F_t u_t] = 0$，$E[(y_t^S - \phi^d p_t) u_t] = 0$。这保证了工具的**排除限制**（exclusion restriction）和**外生性**（exogeneity）。

2. **Assumption 2（幂律分布）**：个体规模 $S_i$ 服从幂律分布 $P(S_i > s) = c s^{-\mu}$。这是本文的核心假设，它直接决定了工具强度的 regime。相比 GK (2024) 的固定 N 假设，这是一个**实质性推广**——它允许主导单位的存在性随 N 变化。

3. **Assumption 3（因子结构）**：因子载荷 $\lambda_i$ 有界，因子 $F_t$ 满足矩条件。这保证了主成分估计的一致性。

4. **Assumption 4（时间与截面相依性）**：允许弱时间相依（强混合）和弱截面相依，但要求 $\sum_{i,j} |\gamma(i,j)| \leq M$（绝对可和）。这比 GK 的 i.i.d. 假设更一般，但比完全任意的截面相依更严格。

5. **Assumption 5（强混合与高阶矩）**：要求 $E\|F_t\|^{8+2\pi}$、$E|\varepsilon_t|^{8+2\pi}$、$E|u_{jt}|^{8+2\pi}$ 有限，且混合系数满足 $\sum_h \alpha(h)^{\pi/(2+\pi)} < \infty$。这是为了应用中心极限定理。

6. **Assumption 6-8（因子估计的附加条件）**：要求因子载荷有界、因子方差有界且特征值分离、以及弱截面相依条件。这些是 Bai (2003) 的标准条件。

**相比已有文献的放宽/强化**：
- **放宽**：允许 N 随 T 增长（GK 假设 N 固定）；允许弱截面相依（GK 假设 i.i.d.）。
- **强化**：要求幂律分布假设（BL 2022 没有明确假设幂律，但本文证明其 Assumption 4(iii) 与幂律不相容）；要求高阶矩条件（比 GK 的有限二阶矩更强）。

#### 主要结果

**定理 1（强工具 regime，µ∈(0,1)）**：在 Assumptions 1-5 下，条件于 S，GIV 估计量满足
$$\frac{\Gamma_{zp}}{\sqrt{V_{z\varepsilon}(S)}} \cdot \sqrt{T}(\hat{\phi}^d - \phi^d) \xrightarrow{d} N(0,1)$$
其中 $\Gamma_{zp} = \frac{S'\Omega S}{\phi^d - \phi^s}$，$V_{z\varepsilon}(S) = \lim_{T\to\infty} \frac{1}{T}\sum_{s,t} E[z_t z_s \varepsilon_t \varepsilon_s | S]$。

**直觉**：当 µ<1 时，少数大个体占据总量的非零份额，其 idiosyncratic 冲击在加总后不消失，工具强度不随 N 衰减，因此恢复经典 $\sqrt{T}$ 速率。

**定理 2（近弱工具 regime，µ>1 且 N/T→0）**：设 $\delta = \min(1-1/\mu, 1/2)$。则
$$\frac{\Gamma_{zp}}{\sqrt{V_{z\varepsilon}(S)}} \cdot \frac{\sqrt{T}}{N^\delta} (\hat{\phi}^d - \phi^d) \xrightarrow{d} N(0,1)$$
估计量仍一致且渐近正态，但速率降为 $\sqrt{T}/N^\delta$。当 $N/T \to 0$ 时，$\sqrt{T}/N^\delta \to \infty$，故一致性成立。

**定理 3（可行估计量，强工具 regime）**：在 Assumptions 1-8 且 $\sqrt{T}/N \to 0$ 下，可行 GIV 估计量（用估计的因子构造工具）与不可行估计量有相同的收敛速率，但渐近方差不同：
$$V_{z\bar{\varepsilon}}(S) = V_{z\varepsilon}(S) + \text{额外项（来自因子估计）}$$
需要修正标准误。

**定理 4（可行估计量，近弱工具 regime）**：类似地，可行估计量在 $\sqrt{T}/N \to 0$ 下保持 $\sqrt{T}/N^\delta$ 速率，但渐近方差包含额外项。

**定理 5（Anderson-Rubin 检验）**：当 µ>2 且 N/T→c>0 时，GIV 估计量不一致，但 AR 统计量仍渐近 $\chi^2_1$，可用于构造有效置信集。

**命题 1（工具强度的精确速率）**：
$$z_t = \begin{cases} O_P(1) & \mu \in (0,1) \\ O_P(N^{-(1-1/\mu)}) & \mu \in (1,2) \\ O_P(N^{-1/2}) & \mu > 2 \end{cases}$$

**命题 2（HAC 方差估计量一致性）**：在 Assumptions 1-8 且 $N/T \to 0$、$\sqrt{T}/N \to 0$ 下，HAC 方差估计量一致估计渐近方差。

#### 证明路线与技术技巧

**整体路线**（以定理 2 为例）：

1. **第一步：分解估计误差**。将 $\hat{\phi}^d - \phi^d$ 分解为
$$\hat{\phi}^d - \phi^d = \frac{\frac{1}{T}\sum_t z_t \varepsilon_t}{\frac{1}{T}\sum_t z_t p_t}$$
分母收敛到 $\Gamma_{zp}$，分子需要 CLT。

2. **第二步：建立 CLT**。分子 $\frac{1}{\sqrt{T}}\sum_t z_t \varepsilon_t$ 的 CLT 通过以下步骤建立：
   - 条件于 S，$z_t \varepsilon_t$ 是强混合序列（由 Assumption 5）
   - 验证 Lyapunov 条件：$E|z_t \varepsilon_t|^{2+\delta} < \infty$（由高阶矩条件）
   - 应用强混合 CLT（如 Ibragimov 1962）

3. **第三步：处理幂律尾部**。关键步骤是证明 $S'\Omega S$ 的阶数。利用幂律分布的性质：
   - 对 $\mu \in (0,1)$：$\sum_i S_i^2 = O_P(1)$（因为最大份额不消失）
   - 对 $\mu \in (1,2)$：$\sum_i S_i^2 = O_P(N^{2-2/\mu})$（利用幂律尾部的正则变化性质）
   - 对 $\mu > 2$：$\sum_i S_i^2 = O_P(N^{-1})$（因为 $\sum_i S_i^2 \leq \max_i S_i \cdot \sum_i S_i = O_P(N^{-1})$）

4. **第四步：合并**。将分子和分母的阶数合并，得到收敛速率 $\sqrt{T}/N^\delta$。

**关键引理**：
- **引理 1**（Bai 2003 的因子估计收敛速率）：$\|\hat{\Lambda} - \Lambda H\| = O_P(1/\sqrt{N})$，$\|\hat{F}_t - H^{-1} F_t\| = O_P(1/\sqrt{N})$。
- **引理 2**（工具估计误差）：$\hat{z}_t - z_t = O_P(1/\sqrt{N})$，在 $\sqrt{T}/N \to 0$ 下可忽略。
- **引理 3**（HAC 方差估计量一致性）：利用 Newey-West 核估计量的标准结果。

**技术技巧点名**：
- **幂律分布的正则变化性质**（regular variation）：用于确定 $S'\Omega S$ 的阶数
- **强混合 CLT**：用于处理时间相依性
- **鞅差 CLT**：用于处理条件于 S 的渐近分布
- **主成分分析的扰动界**：用于处理因子估计误差
- **Anderson-Rubin 统计量的自标准化性质**：用于构造弱工具稳健的置信集

#### 真实例子与应用

**数据**：三种大宗商品——精炼铜（N=29 国，T=192 个月，2009-2025）、原油（N=21 国，T=611 个月，1973-2025）、天然气（N=27 国，T=156 个月，2010-2025）。

**方法应用**：
1. **估计 Pareto 尾部指数 µ**：使用 Hill (1975) MLE、log-rank OLS、Gabaix-Ibragimov (2011) 三种方法。结果：铜 µ̂=0.58（95% CI [0.28, 0.87]），原油 µ̂=0.65（[0.26, 1.05]），天然气 µ̂=0.32（[0.15, 0.31]）。
2. **Regime 分类**：铜和天然气落入强工具 regime（µ<1），原油的置信区间跨越 µ=1，可能处于近弱 regime。
3. **估计需求弹性**：GIV 估计的短期需求弹性为铜 -0.135、原油 -0.109、天然气 -0.056，均显著为负且绝对值小于 OLS 估计（OLS 因内生性而偏向零）。

**例子想说明什么**：
- 铜和天然气市场的主导单位足够大，GIV 是强工具，标准 Wald 推断可靠。
- 原油市场的 µ 估计不精确，不能排除近弱工具的可能性，因此应使用 Anderson-Rubin 置信集作为稳健性检验。
- 所有三种商品的 GIV 估计都纠正了 OLS 的内生性偏误，得到经济上合理的负弹性。

#### 🔎 结论是否比证明窄

**结论确实比证明窄**。具体表现：

1. **定理 1-4 的证明假设 µ 已知**，但实证中 µ 需要估计。作者在实证部分使用点估计和置信区间进行分类，但没有提供 µ 估计不确定性如何影响 regime 分类的正式理论。这是一个明显的 gap：如果 µ̂ 的置信区间跨越 regime 边界（如原油），理论应提供如何处理这种不确定性的指导。

2. **定理 5（AR 检验）的证明仅覆盖 µ>2 且 N/T→c 的情形**，但作者在结论中推荐 AR 检验用于"µ>2 的所有子情形"。实际上，AR 检验在近弱 regime（µ∈(1,2)）下也有效（因为它是自标准化的），但作者没有正式证明这一点。

3. **可行估计量的渐近方差公式（定理 3-4）依赖因子数 r 已知**。实证中 r 通过 Ahn-Horenstein (2013) 的 ER 准则选择，但作者没有证明 r 的估计误差不影响渐近分布。这是一个标准的"生成回归元"问题，作者在附录中部分处理了，但未完全解决。

4. **实证部分仅报告点估计和标准误**，没有报告 AR 置信区间。作者在理论部分推荐 AR 检验用于弱工具情形，但实证中未展示 AR 置信区间与 Wald 置信区间的对比。

5. **模拟部分只覆盖了 µ∈{0.3, 0.5, 0.8, 1.2, 1.4, 1.8, 2.5, 3.5, 6.0}**，没有覆盖 µ=1 和 µ=2 的边界情形。作者在附录 F 中单独处理了边界情形，但模拟未验证这些理论结果。
