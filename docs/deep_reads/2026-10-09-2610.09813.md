### 一、领域脉络与小综述

#### 这个方向是什么

本文研究的根本问题是：**在离散观测下，如何从带跳的随机微分方程（SDE）中非参数地估计漂移函数**。具体而言，观测对象是一个多维 Lévy 驱动的 SDE（方程 (1)），研究者只能等间隔地观测到过程 X 的一条轨迹，目标是在状态空间的紧集上估计漂移函数 b 的每个分量。这个问题的统计困难在于：观测增量中同时混入了扩散项（连续鞅）和跳项（不连续鞅），而跳项的存在使得观测噪声不再是次高斯的，而是次指数的，这从根本上改变了经验过程分析的浓度工具。

该子方向的成熟度：**中等偏早期**。扩散过程的非参数漂移估计已有较完整的理论（从一维到多维、从连续观测到离散观测），但 Lévy 驱动的跳过程版本在本文之前仅有零星工作（主要集中在一维或有限活动跳），多维、无限活动、离散观测下的非渐近理论几乎是空白。本文是这一空白的第一块完整拼图。

#### 发展脉络（history）

**奠基工作：扩散过程的非参数漂移估计。** 这一支从一维扩散开始，代表性工作包括 Dalalyan [6]（一维扩散的渐近估计）、Comte et al. [5]（惩罚非参数最小二乘）、Gobet et al. [10]（低频观测下的估计）。这些工作确立了"用观测增量除以时间间隔作为响应的代理、对状态变量做非参数回归"的基本范式，并建立了相应的 oracle 不等式与极小极大下界。**留下的口子**：这些方法依赖连续鞅的二次变差结构，无法直接处理跳项。

**主要进展：多维化与神经网络化。** Dalalyan and Reiß [7] 将一维扩散的渐近等价理论推广到多维；Nickl and Ray [18] 在连续观测下用统计反问题的方法处理多维漂移估计。更关键的是 Oga and Koike [19]：他们首次将 Schmidt-Hieber [23] 的稀疏 ReLU 神经网络非参数回归理论引入扩散过程的漂移估计，建立了离散观测多维扩散的 oracle 不等式，并证明在组合结构下可以达到内蕴维数的收敛速率。**留下的口子**：Oga and Koike [19, Remark 2.6] 明确指出，其自正则化不等式依赖于连续局部鞅的路径wise控制，无法直接推广到带跳情形——这正是本文的出发点。

**当前 frontier：带跳过程的非参数估计。** 在本文之前，跳过程的漂移估计仅有 Schmisser [25] 的一维结果（惩罚最小二乘 + 线性逼近空间，需截断观测增量），以及 Mies [17] 的逐点估计方法（用有界变换和跳滤波处理状态依赖的跳活动）。这些工作要么限于一维，要么不提供非渐近界。**留下的口子**：多维、无限活动跳、无截断的神经网络估计器，三者同时成立的理论尚不存在。

**本文的位置**：本文是 Oga and Koike [19] 的 Lévy 驱动版本。它保留了后者的神经网络框架和 oracle 不等式结构，但将核心的噪声控制从"连续鞅的自正则化"替换为"补偿 Poisson 积分的指数超鞅 + ψ₁-链式法则"，从而在**不截断观测增量**的前提下处理了跳项。同时，它补上了极小极大下界（在固定复合 Poisson 子模型上），这是 Oga and Koike [19] 没有做的。

#### 子线索聚类

被引文献大致落在三条子线索上：

1. **扩散过程的非参数估计（连续鞅范式）**：Dalalyan [6]、Comte et al. [5]、Gobet et al. [10]、Dalalyan and Reiß [7]、Nickl and Ray [18]、Oga and Koike [19]。这条线的方法论核心是：利用连续鞅的二次变差作为噪声尺度的估计，用自正则化不等式控制经验过程。**共同假设**：无跳或跳可忽略。

2. **跳过程的参数/半参数推断（跳滤波与截断范式）**：Schmisser [25]、Mies [17]。这条线的方法论核心是：通过截断或滤波将跳项从观测增量中分离，再对剩余部分做估计。**代价**：截断引入额外偏差，且通常限于一维或有限活动跳。

3. **深度神经网络的非参数回归理论（逼近与估计的权衡）**：Schmidt-Hieber [23]、Kohler and Langer [13]、Suzuki [27]、Imaizumi and Fukumizu [11]。这条线提供了稀疏 ReLU 网络的逼近误差界与经验过程控制，是本文与 Oga and Koike [19] 共同的技术底座。

#### 这个方向在追问的核心问题

1. **跳项是否从根本上改变漂移估计的收敛速率？** 本文的回答是：在指数尾条件下，不改变（与扩散情形同阶，至多差常数）。但这一结论依赖 Lévy 测度的指数尾假设，重尾情形下速率是否会恶化仍是开放的。

2. **不截断观测增量能否做到？** Schmisser [25] 需要截断来处理大跳，本文证明在指数尾条件下可以不截断，代价是噪声从次高斯变为次指数，需要 ψ₁-链式法则。这是本文最核心的技术贡献。

3. **神经网络估计器能否在跳过程中保留组合结构的自适应优势？** 本文在定理 3.2 中给出了肯定回答：对层次组合结构，速率由内蕴维数决定，与扩散情形一致。

4. **极小极大下界是否匹配？** 本文在固定复合 Poisson 子模型上证明了匹配的下界（定理 3.5），但该子模型是"高斯 + 有限活动跳"，是否对更一般的 Lévy 测度类成立仍是开放的。

#### ⚠️ 作者的 framing（这是作者的说法）

作者把缺口 frame 成："Oga and Koike [19] 的自正则化方法无法处理跳项，而 Schmisser [25] 的方法需要截断且限于一维。我们证明，在指数尾条件下，**不截断**的神经网络最小二乘估计器可以达到与扩散情形同阶的速率，且是极小极大最优的。" 这个 frame 的潜台词是：跳过程不是"更难的问题"，而是"需要换工具的问题"——只要 Lévy 测度有指数尾，扩散情形的速率可以完整保留。

**被淡化或回避的竞争路线**：
- **截断方法**（Schmisser [25] 的路线）被一笔带过，作者只提"需要截断"这一缺点，未讨论截断方法在重尾情形下的优势。
- **Mies [17] 的逐点估计**被归入"一维"而略过，未讨论其处理状态依赖跳活动的灵活性。
- **连续观测**（Nickl and Ray [18] 的路线）完全未提，尽管连续观测下跳的辨识问题与离散观测本质不同。

**明显该被引、却没出现在 intro 里的**：
- 关于 Lévy 过程统计推断的综述性文献（如 Figueroa-López 关于 Lévy 过程非参数估计的系列工作）未被引用。这些工作处理的是 Lévy 过程本身的 Lévy 测度估计，而非 SDE 的漂移估计，但属于同一生态位。
- 关于 ψ₁-链式法则在统计中的应用，作者引用了 van der Vaart and Wellner [29]，但未引用更近的、在高维统计中发展出的 chaining 技巧（如 Talagrand 的 generic chaining 框架）。

#### 张力

未见明显对立引用。被引工作之间是"递进式"关系而非"竞争式"关系：扩散→跳过程、一维→多维、截断→不截断，每一步都是对前一步的推广。唯一的潜在张力是 Schmisser [25] 的截断方法与本文的不截断方法在重尾 Lévy 测度下的适用性差异，但本文未讨论重尾情形，因此这一张力未被激活。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：把符号、模型、可观测数据交代清楚

**模型**（方程 (1)）：d 维 càdlàg 过程 X 满足
$$X_t = \eta + \int_0^t b(X_{s-}) ds + \int_0^t \Sigma(X_{s-}) dW_s + \int_0^t \int_{\mathbb{R}^d \setminus \{0\}} \Xi(X_{s-}) z \, \tilde{N}(ds, dz),$$
其中：
- **b : ℝ^d → ℝ^d**：漂移函数，**要估计的目标**（本文估计每个分量 bⁱ，记为 f₀ = bⁱ·1_{[0,1]^d}）。
- **Σ : ℝ^d → ℝ^{d×d}**：扩散系数，**已知或可一致估计**（本文假设已知，见 Assumption 2.1 的全局 Lipschitz 条件）。
- **Ξ : ℝ^d → ℝ^{d×d}**：跳系数，**全局有界**（Assumption 2.1），且 Lévy 测度 ν 满足指数尾条件（Assumption 2.4）。
- **W**：d 维标准 Wiener 过程；**Ñ**：补偿 Poisson 随机测度，补偿子为 ds ν(dz)。
- **η**：初始随机向量，与 W、Ñ 独立。

**可观测数据**：X 在等间隔时间点 0, Δ, 2Δ, ..., nΔ 处的值，即观测到 (X₀, X_Δ, ..., X_{nΔ})。**注意**：观测的是 X 本身，不是增量；但估计方法基于增量 Y_{kΔ} = (X_{(k+1)Δ} − X_{kΔ})/Δ。

**关键参数与 estimand**：
- **n**：观测间隔数；**Δ = Δ_n**：采样间隔，满足 Δ → 0 且 nΔ → ∞（高频 + 长期）。
- **f₀ = bⁱ·1_{[0,1]^d}**：第 i 个分量的漂移在 [0,1]^d 上的限制，**要估计的 estimand**。
- **F(L, p, s, F)**：稀疏 ReLU 神经网络函数类，其中 L 为层数，p 为宽度向量，s 为权重非零元总数上界，F 为函数值上界。
- **Q_n(f)**：经验最小二乘损失，基于增量回归分解 (6)：Y_{kΔ} = f₀(X_{kΔ}) + 噪声项。
- **R_n(f̂, f₀)**：泛化风险（广义误差），即 E[(f̂(X') − f₀(X'))²]，X' 为独立副本。
- **φ_n**：极小极大速率，定义为 φ_n = maxᵢ (nΔ)^{−2β*ᵢ/(2β*ᵢ+tᵢ)}，其中 β*ᵢ 是第 i 层组合光滑度，tᵢ 是相应维数。

**哪些是已知、哪些要估计**：
- **已知**：Σ、Ξ 的 Lipschitz 常数上界、Lévy 测度的指数尾参数（λ, C_m）、组合结构 (q, d, t, β, K)。
- **要估计**：漂移函数 b 的每个分量。

**潜在 / 不可观测量**：跳项 Ñ 的路径（不可观测，只能通过增量的统计性质间接处理）；连续鞅部分与跳部分的分离（不可观测，本文通过指数超鞅论证绕过）。

#### 第二步：讲最小内核

**最小内核**：考虑最简单的非平凡情形——**d = 1，无跳（纯扩散），但保留离散观测**。此时模型退化为
$$X_t = \eta + \int_0^t b(X_s) ds + W_t,$$
观测 (X₀, X_Δ, ..., X_{nΔ})。增量回归分解为
$$Y_{kΔ} := \frac{X_{(k+1)Δ} − X_{kΔ}}{Δ} = b(X_{kΔ}) + \frac{1}{Δ}\int_{kΔ}^{(k+1)Δ} (b(X_s) − b(X_{kΔ})) ds + \frac{W_{(k+1)Δ} − W_{kΔ}}{Δ}.$$

这里有三项：
1. **信号项** b(X_{kΔ})：我们要估计的东西。
2. **离散化误差** (1/Δ)∫(b(X_s) − b(X_{kΔ}))ds：来自 b 在区间内的变化，量级为 O(√Δ)（由 X 的 Hölder 正则性）。
3. **噪声项** (W_{(k+1)Δ} − W_{kΔ})/Δ：均值为 0、方差为 1/Δ 的高斯噪声。

**核心困难**：噪声方差是 1/Δ，随 Δ → 0 发散。但有效样本量是 nΔ（总观测时长），因此信噪比由 nΔ · (信号幅度)² 决定。这正是为什么速率以 nΔ 为基本尺度，而不是 n。

**本文的推广**：把上述分解中的高斯噪声换成"高斯 + 补偿 Poisson 积分"的混合噪声。跳项的贡献是
$$J_{kΔ} := \frac{1}{Δ}\int_{kΔ}^{(k+1)Δ}\int_{\mathbb{R}\setminus\{0\}} \Xi(X_{s-}) z \, \tilde{N}(ds, dz),$$
这是一个均值为 0、但尾部为次指数（而非次高斯）的随机变量。**核心困难**：次指数噪声使得经验过程的浓度不等式从 Bernstein 型退化为更弱的 ψ₁ 型，且自正则化项（二次变差）不再有路径wise下界。

**本文的破局点**：不试图控制跳项的二次变差，而是直接用指数超鞅论证控制补偿 Poisson 积分的指数矩，再结合 ψ₁-链式法则处理函数类上的 uniform 浓度。这相当于把"噪声的矩生成函数"作为基本工具，而不是"噪声的方差"。

**一句话总结本文的数学贡献**：**在次指数噪声下，建立稀疏 ReLU 神经网络最小二乘估计器的 oracle 不等式，并证明其速率与次高斯情形（纯扩散）同阶，至多差常数因子。**

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：在离散观测的多维 Lévy 驱动 SDE 中，非参数估计漂移函数 b 的每个分量，并建立非渐近的 oracle 不等式与极小极大最优性。
2. **核心工具 / 方法**：稀疏 ReLU 神经网络最小二乘估计器；技术上，用补偿 Poisson 积分的指数超鞅论证 + ψ₁-链式法则控制次指数噪声下的经验过程，替代扩散情形中的自正则化不等式。
3. **主要结论**：在指数尾 Lévy 测度条件下，估计器的泛化风险达到与纯扩散情形同阶的速率（至多差常数），对层次组合结构给出内蕴维数速率，并在固定复合 Poisson 子模型上证明极小极大下界，从而确立 log 因子意义下的最优性。

#### 关键设定与假设

**Assumption 2.1（系数正则性）**：b、Σ、Ξ 全局 Lipschitz 连续，且 Ξ 全局有界。统计含义：保证 SDE 有唯一强解，且增量矩有界；Ξ 的有界性确保跳项对增量的贡献可控制。

**Assumption 2.2（指数 β-混合）**：X 是指数 β-混合的，即 β_X(t) ≤ C'_β e^{−C_β t}。统计含义：观测序列的相依性随时间指数衰减，使得"有效样本量"接近 nΔ，且允许使用块状独立化技巧。这是从扩散情形继承的假设，本文验证了它在带跳情形下仍成立（通过 Foster–Lyapunov 论证，见引理 3.3 的证明）。

**Assumption 2.3（采样方案）**：Δ ≤ 1 且 nΔ ≥ 2。统计含义：高频 + 长期观测，保证离散化误差可忽略且有效样本量足够大。

**Assumption 2.4（Lévy 测度指数尾）**：存在 C_m, λ > 0 使得 ν({|z| > r}) ≤ C_m e^{−λr} 对 r ≥ 1。统计含义：大跳的概率指数衰减，保证补偿 Poisson 积分的指数矩有限（Λ(a) < ∞ 对 a < λ）。这是本文区别于扩散情形的**关键新假设**，它替代了扩散情形中噪声的次高斯性。

**相比已有工作的强化/弱化**：
- 相比 Oga and Koike [19]：**放宽**了噪声结构（从纯扩散到带跳），但**增加**了 Lévy 测度的指数尾假设（Assumption 2.4）。
- 相比 Schmisser [25]：**强化**了维度（从一维到多维）和跳活动（允许无限活动），但**增加**了指数尾假设；同时**去掉了截断**这一处理手段。

#### 主要结果

**定理 3.1（oracle 不等式）**：对任意取值于 F(L,p,s,F) 的估计器 f̂ₙ，其泛化风险满足
$$R_n(\hat f_n, f_0) \le \tau \left( \Psi_n(\hat f_n) + \inf_{f \in \mathcal F} \|f - f_0\|_\infty^2 \right) + C_\tau F^2 \left( \frac{s(L\log s + \log(n\Delta))\log(n\Delta)}{n\Delta} + \Delta \right).$$

- **结构**：三项分别对应优化误差 Ψₙ、逼近误差 inf‖f−f₀‖∞²、以及随机误差（含熵项和离散化项）。
- **与扩散情形的对比**：随机误差项与 Oga and Koike [19, Theorem 3.1] 同阶，至多差常数。**关键点**：跳项没有引入额外的速率损失，只是常数因子变大。
- **离散化项 Δ**：来自增量回归分解中的离散化误差，与扩散情形一致。

**定理 3.2（组合结构速率）**：若 f₀ ∈ G(q,d,t,β,K)（层次组合函数类），则选择适当的网络架构后，
$$R_n(\hat f_n, f_0) = O\left( \phi_n L \log^3(n\Delta) + \Delta \right), \quad \phi_n = \max_i (n\Delta)^{-\frac{2\beta_i^*}{2\beta_i^* + t_i}}.$$

- **速率**：由最慢的组件决定，φ_n 是层次组合回归的标准极小极大速率（Schmidt-Hieber [23] 的框架）。
- **与扩散情形的对比**：与 Oga and Koike [19, Theorem 3.2] 的速率完全一致，只是 log 幂次从 2 变为 3（ψ₁-链式的代价）。

**定理 3.5（极小极大下界）**：在固定复合 Poisson 子模型上，对任意估计器，
$$\liminf_{n\to\infty} \phi_n^{-1} \sup_{b \in B^J_i} R_n(\hat f_n, f_0) > 0.$$
- **意义**：与定理 3.2 的上界结合，证明估计器在 log 因子意义下极小极大最优。
- **技术要点**：下界在"高斯 + 有限活动跳"的子模型上证明，其中跳的贡献被构造为与漂移估计正交的干扰项。**注意**：这个子模型是固定的（不随 n 变化），因此下界不覆盖无限活动跳的情形——这是作者在 Remark 3.6 中承认的限制。

#### 证明路线与技术技巧

**整体路线**（以定理 3.1 的证明为例）：

1. **回归分解**：将增量 Y_{kΔ} 写成 f₀(X_{kΔ}) + 噪声，其中噪声 = 离散化误差 + 扩散项 + 跳项。这一步与扩散情形相同，但噪声的分布从次高斯变为次指数。

2. **经验过程控制**：核心是控制 sup_{f∈F} |(Pₙ − P)(f − f₀)²|。扩散情形用 Bernstein 不等式 + 自正则化；本文改为：
   - **固定 f**：用补偿 Poisson 积分的指数超鞅论证（引理 4.5）得到次指数浓度。
   - **函数类上的 uniform 控制**：用 ψ₁-链式法则（引理 A.1），将熵积分从 L₂ 型改为 ψ₁ 型。这是本文最核心的技术创新。

3. **自正则化替代**：扩散情形中，二次变差 ⟨M⟩_T 有路径wise下界；跳情形中，跳项的二次变差可能为 0（无跳区间），因此改用**截断的指数矩**作为正则化工具。具体地，用 E[exp(ε|J_{kΔ}|)] 的界替代 E[J_{kΔ}²] 的界。

4. **块状独立化**：利用 β-混合假设（Assumption 2.2），将观测分成块，块间近似独立，块内用指数超鞅控制。这一步与 Oga and Koike [19] 相同，但常数依赖于 Lévy 测度的指数尾参数。

**关键引理**：
- **引理 4.5（指数超鞅）**：对补偿 Poisson 积分 M_t(h)，E[exp(εM_t(h) − A_{ε,t}(h))] ≤ 1。这是整个证明的基石，它替代了扩散情形中的指数鞅不等式。
- **引理 4.7（ψ₁ 增量界）**：对固定 f, g，M_{nΔ}(h_{f,g}) 的 ψ₁ 范数被 ‖f−g‖∞ 控制。这给出了链式法则所需的增量条件。
- **引理 4.8（链式法则应用）**：将 ψ₁ 增量界代入引理 A.1，得到 uniform 浓度。

**技术技巧点名**：
- **指数超鞅**（而非指数鞅）：处理补偿 Poisson 积分的关键工具，利用了 Lévy 测度的指数尾条件。
- **ψ₁-链式法则**：从 van der Vaart and Wellner [29] 的框架中提取，用于次指数噪声下的经验过程控制。
- **截断的指数矩**：替代二次变差作为自正则化工具，避免了对跳项路径wise控制的困难。
- **Foster–Lyapunov 论证**：用于验证复合 Poisson 子模型的指数 β-混合性质（引理 3.3 的证明），这是从扩散情形继承的技术。

#### 真实例子与应用

**本文为纯理论论文，无真实数据例子，无模拟实验。** 唯一的"例子"是定理 3.5 中构造的复合 Poisson 子模型，用于证明极小极大下界。该子模型的具体设定为：
- 跳过程 J_t 是强度 ι 的复合 Poisson 过程，跳大小服从标准正态分布；
- 漂移函数 b 在 [0,1]^d 上取值为层次组合函数类中的函数；
- 初始分布 η 有指数矩。

这个子模型的作用是**验证下界论证的可行性**，而非展示方法的实际表现。作者在 Remark 3.6 中说明，下界论证只依赖跳机制的"固定、非平凡、有指数矩"这三个性质，因此可以推广到更一般的 Lévy 测度。

#### 🔎 结论是否比证明窄

**是，存在几处结论比证明窄的地方**：

1. **定理 3.5 的下界仅在复合 Poisson 子模型上证明**，但作者在摘要和引言中声称"极小极大最优"（up to log factors）。严格来说，这个下界只覆盖了"高斯 + 有限活动跳"的子模型，不覆盖无限活动跳或重尾 Lévy 测度。作者在 Remark 3.6 中承认了这一点，但摘要中的表述没有限定。

2. **定理 3.2 的速率依赖组合结构假设**，但定理 3.1 的 oracle 不等式本身不要求组合结构。作者在定理 3.2 的陈述中假设 f₀ ∈ G(q,d,t,β,K)，但定理 3.1 的证明并不需要这个假设。这意味着 oracle 不等式的适用范围比定理 3.2 的速率结论更广。

3. **Assumption 2.2（指数 β-混合）的验证**：作者在引理 3.3 中只对复合 Poisson 子模型验证了该假设，但定理 3.1 和 3.2 的陈述都依赖于它。对于更一般的 Lévy 测度（如无限活动），指数 β-混合是否成立并未证明，只是引用 Masuda [15] 的框架声称"在适当条件下成立"。

4. **离散化误差项 Δ 的处理**：定理 3.1 中离散化误差以 Δ 的线性项出现，但作者没有讨论 Δ 与 n 的最优权衡（即 Δ 应如何随 n 衰减）。在扩散情形中，Oga and Koike [19] 讨论了 Δ = O((nΔ)^{−α}) 的最优选择，本文没有做类似分析。

### 四、开放问题

以下问题均扎根于本文的具体陈述，按"从近到远"排列：

1. **重尾 Lévy 测度下的速率**：本文的 Assumption 2.4 要求指数尾，Schmisser [25] 在重尾情形下需要截断。**要证明什么**：在重尾（如 α-稳定）Lévy 测度下，不截断的神经网络估计器是否仍能达到扩散情形的速率？若不能，最优速率是什么？**扎根于**：Assumption 2.4 和 Remark 3.6 中"指数尾条件可放宽"的暗示。

2. **无限活动跳的极小极大下界**：定理 3.5 的下界仅在复合 Poisson（有限活动）子模型上证明。**要证明什么**：对无限活动跳（如 tempered stable），下界是否仍然匹配？**扎根于**：定理 3.5 的陈述和 Remark 3.6 中"固定非平凡 Lévy 测度"的限制。

3. **Δ 与 n 的最优权衡**：定理 3.1 中离散化误差项 Δ 与随机误差项 (nΔ)^{−1} 的权衡未分析。**要计算什么**：给定总观测时长 T = nΔ，最优采样间隔 Δ* 是什么？对应的最优速率的常数是多少？**扎根于**：定理 3.1 中 Δ 项的线性出现，以及 Oga and Koike [19] 中类似的权衡分析（本文未做）。

4. **跳活动函数的联合估计**：本文只估计漂移 b，假设跳机制（Lévy 测度 ν）已知。**要估计什么**：如果 ν 也未知，能否同时估计 b 和 ν？速率是否会耦合？**扎根于**：方程 (1) 中 ν 作为已知参数出现，以及引言中"跳机制已知"的设定。

5. **自适应选择网络架构**：定理 3.2 的速率依赖组合结构 (q,d,t,β,K)，但实际中这些参数未知。**要证明什么**：是否存在数据驱动的网络架构选择方法，达到与已知结构时相同的速率？**扎根于**：定理 3.2 的假设 (ii)–(iv) 对网络参数的先验要求。

6. **连续观测极限**：本文只处理离散观测。**要证明什么**：当 Δ → 0 且 nΔ → ∞ 时，本文的 oracle 不等式是否能退化到连续观测下的已知结果（如 Nickl and Ray [18]）？**扎根于**：引言中对连续观测文献的引用（Nickl and Ray [18]）以及本文结果与扩散情形的一致性。
