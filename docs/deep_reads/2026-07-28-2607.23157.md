### 一、领域脉络与小综述

#### 这个方向是什么

本文研究的根本问题是：在协变量偏移（covariate shift）下，当研究者已经构造了一个预设的校正函数 w(x)（例如通过密度比估计、领域自适应或因果推断中的加权方法），如何**在数据持续到达的过程中**，以任意时点有效（anytime-valid）的方式确认这个校正是否真正实现了协变量平衡。这里的"平衡"不是指分布完全相等，而是指在一组预设的平衡函数类 F 上，校正后的源分布与目标分布的矩足够接近（在容差 ε 内）。该子方向处于三个领域的交叉点：**协变量偏移下的分布适配**（Tibshirani et al., 2019 等）、**任意时点有效推断**（e-process / confidence sequence 文献，如 Howard et al., 2021；Ramdas et al., 2023）、以及**因果推断中的平衡诊断**（如 Schuirmann, 1987 的等价性检验传统）。其成熟度处于"方法框架已建立、但具体应用场景（协变量平衡确认）尚属新问题"的阶段——作者在引言中明确指出，现有文献主要关注"如何构造校正"，而本文关注"如何确认校正是否足够好"。

#### 发展脉络

**奠基工作：协变量偏移下的加权与平衡。** 协变量偏移的数学框架由 Shimodaira (2000) 奠定，其核心思想是：当 P_t(X) ≠ P_s(X) 但 P_t(Y|X) = P_s(Y|X) 时，可以通过重要性加权 w*(x) = dP_t^X / dP_s^X 来修正分布失配。这一思想被直接推广到密度比估计（Kanamori et al., 2009；Sugiyama et al., 2007）和因果推断中的平衡权重构造（Zubizarreta, 2015；Chan et al., 2016；Athey et al., 2018）。这些工作的共同点是：它们解决的是**构造问题**——如何找到一组权重使得样本矩平衡。但正如作者在引言中所指出的，这些方法"choose weights so that prescribed balancing functions match across treatment groups or between a weighted sample and a target"，却**没有回答**：给定一个已经构造好的权重，如何**在数据流上持续验证**它是否真的达到了平衡目标。

**关键转折：从"检测差异"到"确认等价"。** 传统的平衡诊断（如 Schuirmann, 1987 的双单侧检验 TOST）是**固定样本量**的等价性检验：设定一个容差区间，检验差异是否落在区间内。但这类方法有两个局限：一是需要预先固定样本量，无法在数据持续到达时随时做出有效判断；二是它检验的是"差异是否为零"或"是否在容差内"，而非"我们是否有足够证据确认平衡"。本文的贡献在于将这一传统问题**移植到顺序/连续监测的框架**中，用 confidence sequence 替代固定样本置信区间，从而允许数据依赖的停止时间。

**当前 frontier：任意时点有效推断的普及。** 近年来，e-process 和 confidence sequence 方法在假设检验和估计中获得了系统化发展。Howard et al. (2021) 给出了均值估计的显式 confidence sequence 构造（含 Hoeffding、empirical Bernstein 等变体）；Ramdas et al. (2023) 系统阐述了 e-value 和 betting 解释；Waudby-Smith and Ramdas (2024) 将 betting 方法用于均值估计。这些工作为本文提供了**工具基础**——本文的 Theorem 2 本质上是在说：只要对每个平衡函数 f_j 有一个同时有效的 confidence sequence（满足 (12) 式），那么"等待所有 confidence sequence 都落入容差带内再停止"就是一个有效的任意时点确认程序。本文的**新意**不在于 confidence sequence 本身，而在于**将这一工具应用于协变量平衡确认这一具体问题**，并区分了"确认"（contracted band）与"兼容性诊断"（expanded band）两种不同的推断目标。

**最接近的前驱：标签偏移的任意时点确认。** 作者在引言和 Table 1 中明确将本文定位为 Choi (2026) 的"协变量偏移版本"——后者处理的是标签偏移（label shift）下的预测校正确认。本文的核心变化是：标签偏移下校正对象是预测分布 P_t(Y|X)（通过似然比倾斜），而协变量偏移下校正对象是输入分布 P_t(X)（通过输入加权）。这一变化看似简单，但带来了实质性的技术差异：标签偏移的似然比可以直接从标注数据估计，而协变量偏移的权重 w(x) 通常需要从源数据和目标数据中估计，且其归一化常数（normalizing constant）本身就有不确定性（见 Section 5.4）。

#### 子线索聚类

被引文献大致落在四条子线索上：

1. **协变量偏移与密度比估计**（Shimodaira, 2000；Sugiyama et al., 2007；Kanamori et al., 2009；Sugiyama et al., 2012）：关注如何**估计** w*(x)，包括 KLIEP、LSIF、分类器 odds 等方法。本文的定位是"这些方法的输出作为输入"——即假设 w 已经给定，本文不关心 w 是怎么来的。

2. **平衡权重构造**（Zubizarreta, 2015；Chan et al., 2016；Athey et al., 2018；Ben-Michael et al., 2021）：关注如何在**有限样本**上构造满足矩平衡约束的权重。本文与这条线索的关系是互补的：构造方法解决"如何得到 w"，本文解决"如何确认 w 在目标流上仍然有效"。

3. **任意时点有效推断**（Ville, 1939；Wald, 1945；Howard et al., 2021；Grünwald et al., 2024；Ramdas et al., 2023；Waudby-Smith and Ramdas, 2024）：提供 e-process、confidence sequence、betting 等工具。本文是这些工具的一个**新应用场景**。

4. **等价性检验与平衡诊断**（Schuirmann, 1987；Wellek, 2010）：提供"确认差异足够小"的统计框架。本文将其从固定样本推广到顺序监测。

#### 这个方向在追问的核心问题

- **Q1（确认问题）**：给定预设的平衡函数类 F 和容差 ε，如何构造一个程序，使得在任意（数据依赖的）停止时间 τ 停止时，若 τ < ∞ 则能以高概率保证真正的平衡偏差不超过 ε？（Theorem 2 回答）
- **Q2（全局方向问题）**：如何在不依赖平衡函数类的情况下，判断校正方向是否"总体上"正确？（Section 4 的 e-process 回答，但只是方向性的）
- **Q3（有限样本源问题）**：当源数据有限、权重需要估计时，如何同时控制源侧和目标侧的不确定性？（Section 5.4 的 contracted band 回答）
- **Q4（下游影响问题）**：平衡确认的结论如何转化为下游任务的保证（如加权 conformal prediction 的覆盖率）？（Section 6 回答）

**已知瓶颈**：一是**局部性**——确认结论只对预设的 F 有效，无法推广到 F 之外的函数（作者在实验 Section 7.2 中明确展示了这一点：仅包含前 5 个坐标的 F 会漏掉后 15 个坐标的失配）；二是**功率问题**——当容差 ε 很小或平衡函数方差很大时，确认可能需要极长的监测时间；三是**源侧不确定性**——当源样本量 n_s 有限时，contracted band 可能为空，导致确认永远无法完成（作者在 Section 5.4.2 中承认这一点，并建议用 expanded band 做兼容性诊断作为替代）。

#### ⚠️ 作者的 framing（这是作者的说法）

作者将本文的核心贡献 frame 为"**将协变量平衡从构造问题转化为确认问题**"，并强调这是"post-construction"的验证步骤。具体来说，作者在引言中写道："Constructing a correction, however, is not the same as knowing that it is safe to use"，并将本文定位为"complementary"于密度比估计和平衡权重构造文献。作者还刻意区分了三种不同的推断目标：(1) 全局相对证据（e-process，方向性）；(2) 局部绝对确认（confidence sequence + contracted band，用于下游部署）；(3) 兼容性诊断（expanded band，仅用于排除明显失配）。**作者淡化了**以下竞争路线：(a) 直接检验 P_t^X = P_s^X 的全局两样本检验（如 MMD），认为其"不能给出容差级别的确认"；(b) 固定样本的等价性检验（TOST），认为其"无法处理连续监测"；(c) 在线密度比估计（即边估计边确认），作者明确说"we do not develop this adaptive extension here"（Section 3），将其留给未来工作。

**值得研究者去查的问题**：作者在引言中没有引用任何关于**在线/顺序密度比估计**的文献（如在线 KLIEP 或在线 MMD 流），也没有引用**多假设检验中的族错误率控制**文献（虽然 (12) 式本质上是一个同时置信区间问题）。这两条线索可能是被作者刻意淡化的竞争路线。另外，作者对"确认"的定义是**逐点**的（每个 f_j 的均值），而非**函数空间**的（如 sup-norm 距离），这意味着 F 的选取对结论的强度有决定性影响——这一点作者在实验部分承认，但在理论部分没有给出 F 的选取准则。

#### 张力

未见明显对立引用。但有一个微妙的张力值得注意：**e-process 的"方向性"与 confidence sequence 的"绝对性"之间的张力**。作者在 Section 4 中强调 e-process 只能提供"相对证据"（相对于源分布），而在 Section 5 中强调 confidence sequence 能提供"绝对确认"（相对于目标分布）。但这两者并非总是兼容的：一个校正可能在全局 e-process 上表现良好（KL 方向正确），但在某个平衡函数上超出容差（局部失配）。作者在实验 Section 7.2 中实际上展示了这种张力（partial correction 有正 e-process 漂移但无法通过平衡确认），但在理论部分没有系统讨论这两种证据如何整合。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

**符号清单**（按类别分组）：

| 类别 | 符号 | 含义 |
|------|------|------|
| **分布** | P_s, P_t | 源分布、目标分布（联合分布，定义在 X × Y 上） |
| | P_s^X, P_t^X | 对应的输入边际分布 |
| | P_w^X | 校正后的输入分布，dP_w^X/dP_s^X = w(x)（归一化后） |
| **数据** | D_src = {(X_i^s, Y_i^s)}_{i=1}^{n_s} | 源标注数据（用于构造 w 和估计源矩） |
| | X_1, X_2, ... | 目标输入流（iid ~ P_t^X，无标注） |
| **参数/函数** | w: X → [0, ∞) | 预设的校正函数（归一化：E_s[w(X)] = 1） |
| | F = {f_1, ..., f_m} | 预设的平衡函数类（有限维） |
| | ε_j ≥ 0 | 第 j 个平衡函数的容差 |
| **目标量** | µ_{t,j} = E_t[f_j(X)] | 目标分布下第 j 个平衡函数的期望 |
| | µ_{w,j} = E_w[f_j(X)] | 校正分布下第 j 个平衡函数的期望 |
| | ∆_F(w) = max_j \|µ_{t,j} − µ_{w,j}\| | 平衡偏差（population 量） |
| **推断工具** | C_{n,j} = [L_{n,j}, U_{n,j}] | 第 j 个平衡函数在 n 个目标样本后的 confidence sequence |
| | τ_bal | 停止时间（数据依赖） |
| | δ, η | 目标侧和源侧的错误控制水平 |

**模型**（数据生成机制）：

1. **协变量偏移假设**：P_t(Y|X) = P_s(Y|X)，但 P_t^X ≠ P_s^X。这是整个框架的基石——条件分布不变，只有输入边际变化。
2. **预设校正**：w 是固定的、在监测开始前已经构造好的函数（G_0-可测）。它可以是密度比估计、领域自适应输出、或人工设定的权重。
3. **目标流**：X_1, X_2, ... iid ~ P_t^X。这是监测的数据来源，不需要标注。
4. **源数据**：D_src 用于估计源矩 E_s[f_j(X)] 和归一化常数 E_s[w(X)]。源数据在监测开始前已经固定。

**可观测 vs 不可观测**：
- **可观测**：源数据 D_src（含标注）、目标输入流 X_1, X_2, ...（无标注）、预设的 w。
- **不可观测**：目标分布 P_t^X 本身、真正的密度比 w*(x)、以及平衡偏差 ∆_F(w)（这是要推断的目标量）。

#### 第二步：最小内核

**核心问题**：我们有一个预设的校正 w，想要确认"校正后的源分布 P_w^X 是否与目标分布 P_t^X 在 F 上足够接近"。但 P_t^X 未知，我们只能通过目标输入流 X_1, X_2, ... 来学习它。

**最简特例**：假设只有一个平衡函数 f(x) = x（一维、有界于 [0,1]），容差 ε > 0，且源矩 µ_{w,1} = E_w[X] 已知（先忽略源不确定性）。目标是要确认 |µ_{t,1} − µ_{w,1}| ≤ ε。

**为什么不能直接用固定样本置信区间？** 如果我们预先设定样本量 n_0，计算置信区间 [L_{n_0}, U_{n_0}]，然后检查它是否落在 [µ_{w,1} − ε, µ_{w,1} + ε] 内——这在固定样本量下是有效的。但如果我们**持续监测**，每来一个新样本就检查一次，那么"在某个 n 时区间落入容差带内"这个事件在零假设下发生的概率会远大于名义水平，因为我们在多个时间点做了多次检查。这就是**多重比较/可选停止**问题。

**本文的解法**：使用 confidence sequence——一个对所有 n ≥ 1 **同时**有效的区间序列：
P{∀ n ≥ 1 : µ_{t,1} ∈ C_{n,1}} ≥ 1 − δ.

**关键洞察**：Theorem 2 的证明逻辑是**反证法**。假设真正的偏差超出容差，即 |µ_{t,1} − µ_{w,1}| > ε。那么在**任何** n 下，任何包含 µ_{t,1} 的置信区间都不可能完全落在 [µ_{w,1} − ε, µ_{w,1} + ε] 内——因为区间包含 µ_{t,1}，而 µ_{t,1} 本身在容差带之外。因此，"C_{n,1} ⊆ [µ_{w,1} − ε, µ_{w,1} + ε]" 这个事件意味着 µ_{t,1} 不在 C_{n,1} 中（否则区间会包含带外的点），而 confidence sequence 的同时覆盖保证了这个事件在零假设下的概率至多为 δ。所以：
- 若校正**超出**容差（坏情况），错误确认的概率 ≤ δ；
- 若校正**在**容差内（好情况），确认最终会发生的概率取决于 confidence sequence 的收缩速度（即 power）。

**为什么"同时覆盖"是关键？** 因为停止时间 τ_bal 是数据依赖的——我们不知道会在哪个 n 停止。confidence sequence 保证了**无论何时停止**，只要停止时区间在带内，错误概率都受控。这比"在每个固定 n 做检验然后 Bonferroni 校正"更高效，因为 confidence sequence 的宽度增长是 O(√(log log n / n)) 而不是 O(√(log n / n))（后者是 Bonferroni 的代价）。

**最小内核的数学表述**：
- 目标：构造 C_{n,1} 使得 (12) 成立，即 P{∀ n ≥ 1 : µ_{t,1} ∈ C_{n,1}} ≥ 1 − δ。
- 停止规则：τ_bal = inf{n ≥ 1 : C_{n,1} ⊆ [µ_{w,1} − ε, µ_{w,1} + ε]}。
- 保证：若 |µ_{t,1} − µ_{w,1}| > ε，则 P(τ_bal < ∞) ≤ δ。

**这个内核的推广方向**（本文实际做的）：
1. **多平衡函数**：从单个 f 到有限类 F = {f_1, ..., f_m}，需要同时覆盖所有 j，用 union bound 或更精细的同时置信区域。
2. **源不确定性**：µ_{w,j} 未知，需要从源数据估计，得到区间 [ℓ_{w,j}, u_{w,j}]，然后用 contracted band（交集）来保持保证。
3. **全局监测**：e-process（Section 4）不依赖 F，但只能提供方向性证据。

**这个内核揭示了本文的核心技术贡献**：将 confidence sequence 的"同时覆盖"性质与"容差带包含"这一几何条件结合，得到一个**不需要 e-process 的确认程序**。这与 Section 4 的 e-process 形成对比：e-process 是"证据积累"（martingale），而 confidence sequence 是"不确定性收缩"（区间估计）。作者明确指出，确认程序不需要 e-process 的 martingale 结构，只需要同时覆盖。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：在协变量偏移下，给定一个预设的校正函数 w(x)，如何构造一个任意时点有效的程序，使得在数据持续到达时，一旦所有预设平衡函数的目标矩落入容差带内即可停止并确认平衡，且错误确认的概率受控。
2. **核心工具/方法**：将 confidence sequence 的同时覆盖性质与容差带包含条件结合，构造确认程序（Theorem 2）；区分 contracted band（确认）与 expanded band（兼容性诊断）；辅以 e-process 作为全局方向性监测（Section 4）。
3. **主要结论**：确认程序在"校正超出容差"时错误确认概率 ≤ δ（或 δ + η，当源矩需估计时）；在"校正真实平衡"时最终会确认（在 confidence sequence 收缩条件下）；e-process 的 KL 漂移恒等式刻画了校正方向，但 e-process 不能替代确认程序。

#### 关键设定与假设

**设定**：
- 纯协变量偏移：P_t(Y|X) = P_s(Y|X)，只有输入边际变化。
- 预设校正：w 是 G_0-可测的固定函数，在监测前已构造。
- 目标流：X_1, X_2, ... iid ~ P_t^X。
- 有限平衡函数类 F = {f_1, ..., f_m}，每个 f_j 有界或满足 confidence sequence 所需的矩条件。

**假设**（按重要性排序）：
1. **Assumption 1（预设归一化校正）**：w 是 G_0-可测的，且 E_s[w(X)] = 1。这是 e-process 的基础——保证 E_s[w(X)] = 1 使得 w(X_i) 在源参考零假设下是条件 e-value。**统计含义**：校正必须是"概率比"的形式（归一化），不能是任意权重。
2. **同时覆盖条件（(12) 式）**：P{∀ n ≥ 1, ∀ j ≤ m : µ_{t,j} ∈ C_{n,j}} ≥ 1 − δ。这是 Theorem 2 的核心假设，不依赖于特定的 confidence sequence 构造。
3. **有界性或次高斯条件**：用于显式 confidence sequence 构造（Hoeffding 或 sub-Gaussian），见 Section 5.2 和 7.2。
4. **源侧条件**：源数据独立于目标流，且源矩估计有有效的置信区间（用于 Section 5.4 的 contracted band）。

**相比已有文献的放宽/强化**：
- **放宽**：不要求 w 是最优的或真实密度比——任何预设的 w 都可以被检验。
- **强化**：要求 w 是 G_0-可测的（固定），不允许在线更新。作者明确说"we do not develop this adaptive extension here"。
- **与 Choi (2026) 的关系**：本文是标签偏移版本到协变量偏移版本的移植，但协变量偏移下没有标注数据，所以 e-process 的构造更简单（不需要条件似然比），但确认程序需要处理源矩的不确定性。

#### 主要结果

**Theorem 1（输入似然比 e-process）**：在 Assumption 1 和源参考零假设下，M_n = ∏_{i=1}^n w(X_i) 是非负鞅，且 P(sup_n M_n ≥ 1/α) ≤ α。**证明路线**：直接验证 w(X_i) 是条件 e-value（E[w(X_i)|G_{i-1}] = 1），然后应用 Ville 不等式。**技术要点**：这是标准的 e-process 构造，但作者强调其"校准"性质——它只在源参考零假设下有效，不是对目标分布的有效检验。

**Proposition 1（KL 漂移恒等式）**：在一般监测分布 Q^X 下，E_Q[log w(X)] = D_KL(Q^X ∥ P_s^X) − D_KL(Q^X ∥ P_w^X)。**证明路线**：Radon-Nikodym 链式法则。**统计含义**：e-process 的漂移方向由校正分布与目标分布的 KL 距离决定——校正越接近目标，漂移越大；校正比源更差时，漂移为负。**注意**：这个恒等式是"方向性"的，不提供"绝对"的平衡保证。

**Theorem 2（任意时点协变量平衡确认）**：假设 (12) 式成立，定义停止时间 τ_bal = inf{n ≥ 1 : C_{n,j} ⊆ [µ_{w,j} − ε_j, µ_{w,j} + ε_j] for all j}。若存在 j 使得 |µ_{t,j} − µ_{w,j}| > ε_j，则 P(τ_bal < ∞) ≤ δ。**证明路线**：反证法——若 τ_bal < ∞ 且 µ_{t,j} 超出容差，则 C_{n,j} 包含 µ_{t,j} 但被容差带包含，矛盾；因此 τ_bal < ∞ 意味着所有 µ_{t,j} 都在容差带内，而 confidence sequence 的同时覆盖保证了这个事件在零假设下的概率 ≤ δ。**技术要点**：这个证明不需要 e-process 或鞅结构，只需要同时覆盖。**关键推论**：确认程序是"绝对"的（相对于目标分布），而 e-process 是"相对"的（相对于源分布）。

**Corollary 2（有限源确认）**：当源矩需估计时，用 contracted band B_conf_j = ∩_{ν∈[ℓ_{w,j}, u_{w,j}]} [ν − ε_j, ν + ε_j] 替代固定带，错误确认概率 ≤ δ + η。**证明路线**：联合事件分解——源区间覆盖事件（概率 ≥ 1 − η）和目标 confidence sequence 覆盖事件（概率 ≥ 1 − δ）的交集上，确认意味着真实偏差在容差内。**技术要点**：contracted band 是保守的（交集），可能为空；expanded band（并集）仅用于兼容性诊断。

**Proposition 3（下游 conformal 覆盖）**：在 plug-in 阈值下，若校准分布与目标分布有界偏差，则覆盖率的损失由偏差控制。**证明路线**：条件化于校准数据，将覆盖率分解为校准误差和分布失配误差。**统计含义**：确认的平衡保证了 conformal 覆盖率的近似有效性。

#### 证明路线与技术技巧

**整体路线**（Theorem 2 的证明逻辑）：
1. **建立同时覆盖**：选择满足 (12) 式的 confidence sequence（如 Hoeffding 或 sub-Gaussian 构造）。
2. **定义停止规则**：τ_bal 是"所有 confidence sequence 都落入容差带内"的首达时间。
3. **反证法**：假设真实偏差超出容差，则任何包含真实均值的区间都不可能被容差带包含，因此 τ_bal < ∞ 意味着 confidence sequence 失败。
4. **概率控制**：confidence sequence 的同时覆盖保证失败概率 ≤ δ。

**关键跳跃点**：
- **从"固定样本"到"任意时点"**：这是本文最核心的技术跳跃。固定样本置信区间在持续监测下会失效（多重比较问题），而 confidence sequence 通过同时覆盖避免了这个问题。作者没有发明新的 confidence sequence，而是**识别出**这个工具恰好适合确认问题。
- **从"e-process"到"confidence sequence"**：作者明确区分了两种工具——e-process 是"证据积累"（鞅），confidence sequence 是"不确定性收缩"（区间估计）。确认程序不需要 e-process，只需要 confidence sequence。这个区分在文献中不常见，是本文的一个概念贡献。
- **contracted vs expanded band**：这是处理源侧不确定性的关键。contracted band（交集）保持确认的保证，但可能为空；expanded band（并集）仅用于诊断。这个区分在 Section 5.4.2 和 Table 4 中详细阐述。

**技术技巧点名**：
- **Ville 不等式**（Theorem 1）：用于 e-process 的边界控制。
- **Radon-Nikodym 链式法则**（Proposition 1）：用于 KL 漂移恒等式的推导。
- **同时覆盖的 union bound**（(12) 式）：用于多平衡函数的联合控制。
- **反证法**（Theorem 2）：核心证明技巧，将"确认"转化为"区间包含"的几何条件。
- **Bonferroni 校正**（Section 5.4）：用于源侧多矩的联合区间。

#### 真实例子与应用

本文包含两个数值实验场景：

**场景 1（Section 7.1-7.2）：高斯协变量偏移**。源分布 P_s^X = N(0, I_d)，目标分布 P_t^X = N(µ, I_d)，d = 5，‖µ‖ = 1.2。预设校正为 w_a(x) = exp{aµ^T x − (a²/2)‖µ‖²}，对应校正分布 N(aµ, I_d)。实验验证了：(1) e-process 在源参考零假设下的错误穿越率 ≤ α（Table 5 中 0.024 < 0.05）；(2) 平衡确认在"校正超出容差"时错误确认率受控（Table 6 中 partial correction 确认率为 0）；(3) 确认的局部性——仅包含前 5 个坐标的 F 会漏掉后 15 个坐标的失配（Table 6 中 weak balance 场景）。

**场景 2（Section 7.4）：加权 conformal prediction**。响应 Y = 0.5X_1 + 0.8X_1² + 0.5X_2 + ε，ε ~ N(0, 0.6²)，源分布 N(0, I_5)，目标分布 N(µ, I_5)，µ = (0.8, 0, ..., 0)。实验展示了：未加权校准覆盖率 0.814 远低于名义 0.90；精确加权校准恢复覆盖率至 0.902；部分加权（a = 0.5）仅恢复至 0.838。这个例子说明了平衡确认的下游价值：只有确认了平衡，conformal 覆盖率才有保证。

**这些例子想说明什么**：实验的核心目的是展示**确认与方向性监测的区别**。e-process 可以快速给出"校正方向正确"的证据（Table 5 中 partial correction 有正漂移），但只有 confidence sequence 能给出"平衡在容差内"的绝对确认（Table 6 中 partial correction 无法确认）。这种区分是本文的核心概念贡献。

#### 🔎 结论是否比证明窄

**明确的窄结论**：
1. **Theorem 2 的保证是"错误确认"控制，不是"确认"的 power 保证**。作者在 Section 5.2 中承认："even when the correction is truly within tolerance, confirmation may take a long time if the tolerances are tight, the balancing-function variance is large, or the target stream is short." 这意味着 Theorem 2 只提供了第一类错误控制，没有提供第二类错误（漏确认）的保证。
2. **有限源确认的 δ + η 保证依赖于源区间的有效性**。Corollary 2 的证明假设源区间有 1 − η 的覆盖，但作者没有给出源区间的具体构造（只提到"conditionally valid simultaneous source confidence intervals"），也没有讨论源数据量 n_s 对确认时间的影响。
3. **e-process 的"校准"性质**：Theorem 1 的保证只在源参考零假设下有效，作者明确说"crossing the input e-process of Section 4 ... is not a level-controlled test of the composite null that the correction is no better than the source"（Section 4 末尾）。这意味着 e-process 不能用于假设检验，只能作为诊断工具。

**被泛化的地方**：
1. **"确认"的绝对性**：作者在摘要和引言中声称确认程序提供"absolute"的保证，但这个绝对性只在预设的 F 和 ε 下成立。作者在实验 Section 7.2 中承认了这一点，但在理论部分没有给出 F 的选取准则。
2. **"任意时点"的范围**：Theorem 2 的保证在 iid 采样下成立，作者在 Section 3 末尾说"the abstract confidence-sequence result extends beyond iid sampling whenever a valid time-valid confidence sequence is available for a fixed target parameter under the actual sequential distribution"，但没有给出具体的非 iid 例子。
3. **conformal 覆盖率的保证**：Proposition 3 的保证是条件于校准数据的，且需要"score-relevant functions"在 F 中。作者在 Remark 3 中承认"if one instead confirms only the data-dependent function f_hat(q_hat_w)，the calibration data and threshold must be fixed before an independent target monitoring stream is used"，但没有讨论如何选择 F 使得 score-relevant functions 被包含。

### 四、开放问题

以下开放问题均扎根于本文的具体语句：

1. **自适应校正的确认**（Section 3 末尾）：作者明确说"we do not develop this adaptive extension here"，即 w 是固定的、不允许在线更新。开放问题：**如何构造一个预测的（predictable）权重序列 w_i，使得在每一步都保持 e-process 或 confidence sequence 的有效性？** 这需要处理权重与目标样本之间的依赖关系。扎根语句："Online updating is possible in principle, but it would require a separate predictable construction: the weight w_i used at monitoring index i must be chosen from the past, before observing X_i, and must remain normalized under the source input distribution."

2. **平衡函数类的自适应选择**（Section 5.2 和实验 7.2）：作者承认确认结论的局部性，但没有给出 F 的选取准则。开放问题：**如何根据下游任务自动选择平衡函数类 F，使得确认的结论对下游覆盖率有可证明的保证？** 这需要将 Proposition 3 中的 score-relevant functions 与 F 的选取联系起来。扎根语句："The balancing-function class determines the meaning of balance" 和 "If the class ignores those functions, balance can be confirmed in the chosen moments while the conformal score distribution remains mismatched"（Section 6.2.3）。

3. **源侧不确定性的更精细处理**（Section 5.4.2）：contracted band 可能为空，导致确认永远无法完成。开放问题：**当源数据量有限时，如何构造一个既能保持确认保证又不会过于保守的 band？** 可能需要考虑源侧和目标侧的联合置信区域，而不是简单的交集。扎根语句："An empty confirmation band is not evidence that the correction is poor. It says that the source sample is too uncertain to confirm the requested tolerance for that balancing function."

4. **e-process 的正式推断**（Section 4 末尾）：作者承认 e-process 不能提供"level-controlled"的检验。开放问题：**如何构造一个在"校正不比源更好"的复合零假设下有效的 e-process？** 这需要处理复合零假设下的 e-value 构造。扎根语句："We do not turn decay into a formal refutation procedure here, which would require a separate martingale under a 'no worse than source' null. We leave this as an open direction."

5. **非 iid 目标流的确认**（Section 3 末尾）：Theorem 2 的保证在 iid 采样下成立，作者只提到"whenever a valid time-valid confidence sequence is available"。开放问题：**在目标流具有时间依赖（如马尔可夫或混合）时，如何构造同时覆盖的 confidence sequence？** 这可能需要依赖混合条件下的鞅不等式。

**提示**：要确认上述问题是否是真 gap，建议去读以下子领域近期约 5 篇论文的引言：(a) e-process 和 confidence sequence 的最新进展（如 betting-based 方法）；(b) 协变量偏移下的在线密度比估计；(c) 因果推断中的平衡诊断（特别是顺序监测场景）。如果这些论文的引言都指向"构造问题"而非"确认问题"，那么本文的确认框架确实是一个新方向。
