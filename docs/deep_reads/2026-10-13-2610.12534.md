### 一、领域脉络与小综述

#### 这个方向是什么

本文所处的子方向是**大规模张量的随机化范数估计**。其根本的统计/计算问题是：当一个 d 阶张量 A ∈ R^{n₁×⋯×n_d} 过大、无法显式存储或遍历其所有条目时，如何仅通过若干次"多线性收缩"（multilinear contractions）——即用随机探针向量沿各模式与张量做内积——来高概率地估计其 Frobenius 范数平方 ‖A‖²_F。这个问题的本质是**用随机投影换取计算可行性**：将原本需要 O(N^d) 次浮点运算的精确范数计算，替换为 O(k·N) 次收缩运算，其中 k 是探针样本数。该方向当前处于**成熟但仍有缺口**的状态：矩阵情形（即随机迹估计）已有非常完整的理论，但高阶张量情形下探针分布的选择、方差的最优性、以及置信区间的构造仍有开放空间。

#### 发展脉络（history）

**奠基工作**：该方向的源头是 Hutchinson (1990) 的随机迹估计器 [18]，其核心思想是用 Rademacher 或高斯随机向量 x 估计 tr(B) = E[x^T B x]。这一框架奠定了"用随机向量探测矩阵、以样本均值估计迹"的基本范式。Avron 和 Toledo [2] 随后将这一框架系统化，给出了对称正定矩阵迹估计的方差分析与实用算法。Cortinovis 和 Kressner [14] 进一步将分析推广到不定矩阵，给出了更精细的尾部界。

**主要进展**：Bujanović 和 Kressner [8] 将随机范数/迹估计从矩阵推广到张量，研究了 Kronecker 结构随机向量（即各模式独立采样）下的范数估计问题，给出了实值情形下的方差界。Meyer 和 Avron [22] 则对 Kronecker 迹估计给出了精确的方差公式，并揭示了实值与复值高斯探针之间的本质差异——复值探针的方差更小，因为其模的平方具有更集中的分布。这两篇工作是本文最直接的竞争对手和参照系。

**当前 frontier**：在 [8, 22] 之后，张量随机估计的方向主要围绕三个问题展开：(i) 如何构造更优的探针分布（如结构化随机向量、低偏差采样）；(ii) 如何对一般张量（而非秩一或正交 CP 张量）给出可用的方差界；(iii) 如何将随机估计嵌入到自适应算法（如自适应低秩逼近）中作为停止准则。本文的位置正是在 (i) 和 (ii) 的交汇处——它首次将四元数高斯探针引入该问题，并给出了对一般张量的**锐利**（sharp）矩界。

**本文的位置**：本文声称的贡献是：(a) 对秩一张量给出精确的方差公式，并证明在相同实高斯随机数预算下，四元数探针在 d≥3 时严格优于四个独立实探针；(b) 将精确方差公式推广到正交 CP 张量，用参与比有效秩（participation-ratio effective rank）刻画方差；(c) 对任意张量证明锐利的均匀矩界，并给出 Chebyshev 与分块中位数置信保证。这一定位使其成为 [8] 和 [22] 的自然延伸——它回答了"如果允许使用更丰富的代数结构（四元数），能否在相同随机数预算下获得更小的方差"这一问题。

#### 子线索聚类

这些被引文献大致落在三条子线索上：

**线索一：随机迹/范数估计的经典框架**。包括 Hutchinson [18]、Avron-Toledo [2]、Cortinovis-Kressner [14]。这条线索的核心问题是：给定一个只能通过矩阵-向量乘法访问的隐式矩阵，如何用最少的随机探针获得 tr(B) 的高精度估计？其方法论工具是方差分析 + Chebyshev/Markov 不等式 + 集中不等式。本文的 Chebyshev 界和分块中位数构造直接继承自这条线索。

**线索二：Kronecker 结构下的张量估计**。包括 Bujanović-Kressner [8] 和 Meyer-Avron [22]。这条线索的核心问题是：当探针向量具有 Kronecker 乘积结构（即各模式独立采样）时，张量范数估计的方差如何依赖于张量的结构（秩、正交性、能量分布）？[22] 的关键发现是复值探针的方差比实值探针小一个因子 2^{d-1}，这直接启发了本文对四元数探针的研究。本文的定理 3.3 和 4.3 正是这条线索的延伸。

**线索三：张量分解与隐式张量运算**。包括 Anandkumar et al. [1]（张量分解用于潜变量模型）、Bachmayr-Dahmen [3]（自适应低秩张量逼近）、Xu-Ye [27] 和 Chen-Fu-Ye [12]（广义 Mercer 核与 RKBS）。这条线索提供了本文应用场景的动机——隐式张量（如核张量、矩张量）的范数监控是自适应算法和插值问题的实际需求。本文第 6 节的无穷级数核张量和 EEG 插值正是这条线索的体现。

#### 这个方向在追问的核心问题

1. **探针分布的最优性**：在给定随机数预算（即底层实高斯向量的总数）下，哪种探针分布（实、复、四元数，或更一般的 Clifford 代数）能最小化估计量的方差？本文给出了四元数优于实数的结论，但"是否还有更好的代数结构"是开放的。
2. **方差与张量结构的依赖关系**：对于一般张量（非秩一、非正交 CP），方差如何依赖于张量的谱结构？本文给出了上界，但精确刻画（而非仅上界）仍是开放的。
3. **置信区间的构造**：由于高阶张量探针的分布具有重尾（秩一张量的单样本是 d-1 个 Gamma 变量的乘积），如何构造具有指数衰减误差概率的置信区间？本文用分块中位数解决了"存在性"，但常数是否最优是开放的。

#### ⚠️ 作者的 framing（这是作者的说法）

作者将缺口 frame 为：**"在相同的实高斯随机数预算下，四元数探针通过模内池化（modewise pooling）实现了比独立实探针更小的方差"**。具体而言，作者声称四元数探针的增益不是来自非交换性本身，而是来自将四个实高斯分量在乘法前先进行池化（pooling），从而减少了最终乘积的波动。这一 framing 将问题从"寻找更好的随机分布"转化为"在固定随机数预算下优化池化策略"。作者淡化了四元数代数的特殊性，强调其本质是"分组平均"效应——这为后续推广到更高维 Clifford 代数或分组高斯探针留下了空间。

**被作者淡化或回避的竞争路线**：(i) 作者没有与**结构化探针**（如 Hadamard 变换、稀疏随机投影）进行比较，这些方法在矩阵情形下已被证明可以显著降低方差；(ii) 作者没有讨论**自适应探针选择**（即根据前几轮收缩结果调整后续探针分布）的可能性；(iii) 作者回避了**计算成本**的详细比较——四元数算术的每次乘法比实数乘法贵约 4 倍，虽然随机数预算相同，但算术成本可能抵消方差优势。

**什么明显该被引 / 该存在、却没出现在 intro 里？**：作者没有引用 Roosta-Khorasani 和 Ascher 关于迹估计的改进工作，也没有引用 Cortinovis 和 Kressner 关于**不定矩阵**迹估计的尾部界（[14] 虽被引用，但仅作为 Hutchinson 框架的延伸）。更值得注意的是，作者没有引用任何关于**四元数随机矩阵**或**四元数主成分分析**的文献（如 Zhang 等人关于四元数随机向量的工作），这使得四元数高斯探针的构造看起来像是全新的，而实际上四元数随机向量的性质在信号处理文献中已有大量研究。

#### 张力

被引工作之间未见明显对立结论。但存在一个微妙的张力：Meyer-Avron [22] 证明复值探针在 Kronecker 迹估计中优于实值探针，而本文证明四元数探针在张量范数估计中优于实值探针。这两者并不矛盾（复数是四元数的子情形），但 [22] 的框架是"矩阵的 Kronecker 积的迹"，而本文的框架是"张量的多线性收缩"，两者的联系与区别作者没有明确讨论。另一个张力是：Bujanović-Kressner [8] 的实值 Kronecker 探针界是**上界**（可能不紧），而本文的秩一公式是**精确**的；对于一般张量，本文的界是否比 [8] 的界更紧，作者没有直接比较。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

**符号**（逐个点名）：

- **A ∈ R^{n₁×⋯×n_d}**：目标张量，实值、d 阶。这是**要估计范数的对象**，不是随机变量，而是固定的未知量。假设其过大无法显式存储，但可通过收缩 oracle 访问。
- **‖A‖²_F**：Frobenius 范数平方，即所有条目平方和。这是**目标 estimand**——我们要估计的量。
- **x_j ∈ F^{n_j}**（j = 2, …, d）：第 j 个模式的随机探针向量。F ∈ {R, C, H} 是探针所在的域。这些是**随机变量**，由算法生成，分布已知。
- **F**：实数域 R、复数域 C、四元数域 H。探针的代数结构是本文的核心变量。
- **β_F**：标量探针的实自由度，β_R = 1, β_C = 2, β_H = 4。这是**常数**，刻画一个标量高斯变量包含多少个独立实高斯分量。
- **g ~ N_F(0, 1)**：标准 F-高斯标量变量。在 R 上即标准正态；在 C 上即复正态 (实部虚部独立 N(0, 1/2))；在 H 上即四元数正态（四个分量独立 N(0, 1/4)）。**随机变量**。
- **Y = ‖(A ×_d x_d) ⋯ ×_2 x_2‖²₂**：单次收缩的平方范数。这是**单样本估计量**（未归一化），是随机变量。
- **Est_G_k = (1/k) Σ_{i=1}^k Y_i**：k 次独立收缩的样本均值。这是**最终估计量**，随机变量。
- **re_ff(A)**：参与比有效秩，定义为 (Σ_r λ²_r)² / Σ_r λ⁴_r，其中 λ_r 是正交 CP 分解的系数。这是**张量结构的标量摘要**，不是随机变量，而是 A 的确定性函数。
- **ϱ(p, F)**：p 阶矩因子，ϱ(p, F) = (2/β_F)^p · Γ(p + β_F/2) / Γ(β_F/2)。这是**常数**，刻画 F-高斯变量模平方的 p 阶矩。
- **A_(1)**：A 的模式-1 展开矩阵，尺寸 n₁ × (n₂⋯n_d)。这是**确定性矩阵**，用于将多线性收缩重写为矩阵-向量乘积。
- **⊗**：Kronecker 积；**⊙**：Khatri-Rao（列式 Kronecker）积。这些是**代数运算**。

**模型**（数据生成机制）：

本文是**非参数、确定性张量 + 随机探针**的设定，不是传统的统计模型（没有噪声、没有分布假设）。数据生成机制完全由算法控制：

1. 对 j = 2, …, d，独立采样探针矩阵 X_j = [x_j¹, …, x_j^k] ∈ F^{n_j × k}，每个元素独立服从标准 F-高斯分布。
2. 对每个 i = 1, …, k，计算收缩 Y_i = ‖(A ×_d x_dⁱ) ⋯ ×_2 x_2ⁱ‖²₂。
3. 输出 Est_G_k = (1/k) Σ Y_i。

**可观测数据**：研究者能观测到的是 k 个收缩值 Y₁, …, Y_k。**不可观测**的是张量 A 本身（或其任何条目）。关键识别假设是：收缩 oracle 存在且计算代价远低于显式存储 A。

#### 第二步：最小内核

**最简特例**：取 d = 2（矩阵情形），A = B ∈ R^{n₁×n₂}，探针 x ∈ F^{n₂}。此时

Y = ‖B x‖²₂ = x^H B^H B x = x^H C x, 其中 C = B^H B ∈ F^{n₂×n₂} 是半正定矩阵。

**核心问题**：用 k 个独立样本 Y_i = x_i^H C x_i 估计 tr(C) = ‖B‖²_F，需要多少样本才能保证相对误差 ≤ ε？

**为什么这个例子是"最小内核"**：因为 d = 2 时，多线性收缩退化为矩阵-向量乘积，而 ‖B x‖²₂ = x^H C x 恰好是经典的二次型。此时：

- **无偏性**：E[Y] = E[x^H C x] = tr(C) = ‖B‖²_F。这是 Proposition 2.2 在 d = 2 时的退化情形。
- **方差**：Var(Y) = (1 + 2/β_F) - 1 = 2/β_F · ‖B‖⁴_F。对于实探针 β_F = 1，Var(Y) = 2‖B‖⁴_F；对于四元数探针 β_F = 4，Var(Y) = (1/2)‖B‖⁴_F。四元数探针的方差是实探针的 1/4。
- **为什么四元数更好**：因为 x^H C x 中，四元数探针的模平方 |x|² 是 4 个独立实高斯变量的平方和（除以 4），其波动远小于单个实高斯变量的平方。这本质上是**池化效应**：将 4 个实高斯分量先平均再平方，比先平方再平均的波动更小。

**一般 d 的推广**：当 d ≥ 3 时，秩一张量的单样本 Y/‖A‖²_F 是 d-1 个独立 Gamma(β_F/2, 2/β_F) 变量的乘积。其方差因子为 (1 + 2/β_F)^{d-1} - 1，即：

- 实探针：3^{d-1} - 1
- 复探针：2^{d-1} - 1
- 四元数探针：(3/2)^{d-1} - 1

**为什么这是"支撑整篇论文的最小内核"**：因为所有后续结果（正交 CP 的精确方差、一般张量的上界、分块中位数置信）都是这个秩一情形的推广。秩一情形给出了**最坏情况**的方差（因为一般张量可以分解为秩一张量的叠加，而交叉项的贡献在期望中消失），因此它既是下界的见证者，也是上界证明的起点。

**证明为什么成立**（以 d = 3, 实探针为例）：

1. 设 A = a₁ ⊗ a₂ ⊗ a₃，‖a_j‖ = 1，则 ‖A‖²_F = 1。
2. Y = |⟨a₁, x₁⟩|² · |⟨a₂, x₂⟩|²，其中 x₁, x₂ 独立标准实高斯。
3. 令 Z_j = |⟨a_j, x_j⟩|² ~ χ²₁（因为 a_j 是单位向量，投影后仍是标准正态）。
4. 因此 Y = Z₁ · Z₂，E[Y] = 1，E[Y²] = E[Z₁²]E[Z₂²] = 3 · 3 = 9。
5. Var(Y) = 9 - 1 = 8 = 3² - 1 = 3^{d-1} - 1（d = 3 时）。

**四元数情形**：Z_j = |⟨a_j, x_j⟩|² 中，x_j 是四元数高斯，⟨a_j, x_j⟩ 是四元数内积，其模平方 |⟨a_j, x_j⟩|² = (1/4)Σ_{ℓ=0}³ q_ℓ² ~ Gamma(2, 1/2)，即 E[Z_j] = 1，E[Z_j²] = 1 + 2/4 = 3/2。因此 Var(Y) = (3/2)² - 1 = 5/4 = (3/2)^{d-1} - 1（d = 3 时）。

**这个最小内核揭示了什么**：四元数探针的增益完全来自**每个标量探针的模平方具有更小的相对方差**（实高斯：Var(|g|²) = 2；四元数高斯：Var(|g|²) = 1/2）。当 d 增大时，这个优势被指数放大，因为方差因子是 (1 + 2/β_F)^{d-1}。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：在张量只能通过多线性收缩访问、无法显式存储的设定下，如何用独立高斯探针估计实值 d 阶张量的 Frobenius 范数平方，并最小化给定随机数预算下的估计方差。
2. **核心工具/方法**：将实、复、四元数高斯探针统一在一个框架下，利用 Gamma 分布的矩生成函数给出秩一张量的精确分布，进而推导正交 CP 张量的精确方差和一般张量的锐利上界；用分块中位数构造指数置信区间。
3. **主要结论**：四元数探针在 d ≥ 3 时严格优于四个独立实探针（在相同实高斯随机数预算下），其方差因子为 (3/2)^{d-1} - 1，而四个独立实探针的方差因子为 (3^{d-1} - 1)/4；对一般张量，方差上界由秩一情形达到，因此是锐利的。

#### 关键设定与假设

**设定**（在第二节基础上补全）：

- **张量**：A ∈ R^{n₁×⋯×n_d}，实值、固定、未知。不假设任何低秩结构（除非在第四节明确假设正交 CP）。
- **探针**：对每个模式 j = 2, …, d，独立采样 k 个探针向量 x_jⁱ ∈ F^{n_j}，F ∈ {R, C, H}。探针的每个分量独立服从标准 F-高斯分布，即实部/虚部/四元数分量独立 N(0, 1/β_F)。
- **收缩 oracle**：给定探针元组 (x₂, …, x_d)，可计算 (A ×_d x_d) ⋯ ×_2 x_2 ∈ F^{n₁}，代价为 O(n₁·n₂⋯n_d) 的算术运算（若 A 有结构则更低）。这是唯一的访问接口。
- **估计量**：Est_G_k = (1/k) Σ_{i=1}^k ‖(A ×_d x_dⁱ) ⋯ ×_2 x_2ⁱ‖²₂。

**假设**（相比已有文献的放宽/强化）：

- **放宽**：不假设张量对称、不假设正定性、不假设探针与张量结构匹配。A 可以是任意实张量。
- **强化**：要求探针是**独立**的（而非仅不相关），且要求**精确的矩信息**（Gamma 分布），而非仅用次高斯性。这使得方差公式是精确的而非仅上界。
- **相比 [22]**：本文的估计量是"逐模式收缩后取模平方"，而 [22] 的 Kronecker 迹估计是"整体 Kronecker 积后取二次型"。两者在 d = 2 时等价，但 d ≥ 3 时本文的收缩顺序是固定的（从模式 d 到模式 2），而 [22] 允许任意 Kronecker 结构。本文的设定更贴近实际计算（逐模式收缩是张量计算的标准原语）。

#### 主要结果

**定理 3.3（秩一精确分布）**：对 A = a₁ ⊗ ⋯ ⊗ a_d，单样本 Y/‖A‖²_F 是 d-1 个独立 Gamma(β_F/2, 2/β_F) 变量的乘积。因此：

- E[Y] = ‖A‖²_F（无偏）
- Var(Y) = [(1 + 2/β_F)^{d-1} - 1] ‖A‖⁴_F
- 相对标准差 = √[(1 + 2/β_F)^{d-1} - 1]

**定理 3.4（等随机数预算比较）**：在相同总随机数预算下（即 4(d-1) 个实高斯标量），四元数探针（k_H 个样本，每个用 4(d-1) 个实标量）与四个独立实探针的平均（k_R = 4k_H 个样本）相比：

- d = 2 时两者方差相等（都是 2/k · ‖A‖⁴_F）
- d ≥ 3 时四元数探针严格更优，因为 (3/2)^{d-1} - 1 < (3^{d-1} - 1)/4

**定理 4.3（正交 CP 精确方差）**：对 A = Σ_r λ_r u₁_r ⊗ ⋯ ⊗ u_d_r（各模式因子正交），

Var(Est_G_k)/‖A‖⁴_F = [(1 + 2/β_F)^{d-1} - 1] / (k · re_ff(A))

其中 re_ff(A) = (Σ_r λ²_r)² / Σ_r λ⁴_r 是参与比有效秩。这推广了秩一情形（re_ff = 1）。

**定理 5.2（一般张量上界）**：对任意 A ≠ 0，

Var(Est_G_k) ≤ [(1 + 2/β_F)^{d-1} - 1] / k · ‖A‖⁴_F

且该上界由秩一张量达到，因此是锐利的。

**定理 5.5（分块中位数置信）**：设 b = ⌈4V/ε²⌉，t 为奇数且 t ≥ 8 log(1/δ)。则分块中位数估计量 μ̂ 满足：

P(|μ̂ - ‖A‖²_F| > ε‖A‖²_F) ≤ e^{-t/8} ≤ δ

其中 V 是已知的相对方差上界（对一般张量取 V = (1 + 2/β_F)^{d-1} - 1，对正交 CP 取 V = [(1 + 2/β_F)^{d-1} - 1]/re_ff(A)）。

**证明路线**：

1. **无偏性**（Proposition 2.2）：逐模式条件期望。先固定 x₃, …, x_d，对 x₂ 取期望。利用探针的独立性和各向同性，E[‖(A ×_d x_d) ⋯ ×_2 x_2‖²₂ | x₃, …, x_d] = ‖(A ×_d x_d) ⋯ ×_3 x_3‖²_F。逐模式递推得到 E[Y] = ‖A‖²_F。关键技巧是**逆序积分**：从最后收缩的模式开始，逐步向前取期望。

2. **秩一精确分布**（定理 3.3）：利用旋转不变性。对秩一张量，⟨a_j, x_j⟩ 是标准 F-高斯标量，其模平方是 Gamma(β_F/2, 2/β_F)。各模式独立，因此 Y 是 d-1 个独立 Gamma 变量的乘积。矩公式直接来自 Gamma 分布的矩生成函数。

3. **正交 CP 精确方差**（定理 4.3）：利用正交性消除交叉项。收缩后 Y = Σ_r λ²_r Y_r，其中 Y_r 是秩一贡献。正交性保证 Y_r 之间不相关（虽然不独立），因此 Var(Y) = Σ_r λ⁴_r Var(Y_r)。代入秩一方差公式并除以 ‖A‖⁴_F = (Σ_r λ²_r)² 即得。

4. **一般张量上界**（定理 5.2）：将 A 分解为秩一张量的和（CP 分解，不要求正交）。利用三角不等式和 Jensen 不等式处理交叉项。关键观察是：交叉项的期望为零（因为探针独立且零均值），但方差贡献为正。通过 Cauchy-Schwarz 将交叉项方差上界为秩一贡献的乘积，最终得到与秩一情形相同的上界。

5. **分块中位数**（定理 5.5）：标准的中位数-of-均值论证。每块的均值偏差超过 ε 的概率 ≤ 1/4（由 Chebyshev + 方差上界），t 个块的中位数偏差超过 ε 当且仅当至少 (t+1)/2 个块偏差超过 ε。Hoeffding 不等式给出指数衰减。

**技术技巧点名**：

- **逆序条件期望**：从最后收缩的模式开始逐模式取期望，避免了对高维联合分布的复杂积分。
- **Gamma 分布的矩生成函数**：将秩一情形的矩计算归结为 Gamma 函数的比值，得到闭式公式。
- **旋转不变性**：利用 F-高斯分布在各向同性变换下的不变性，将 ⟨a_j, x_j⟩ 化为标准 F-高斯标量。
- **正交性消除交叉项**：在正交 CP 情形，利用因子正交性将方差分解为各分量的贡献之和。
- **Jensen + Cauchy-Schwarz 处理交叉项**：在一般情形，用凸性上界交叉项的贡献。
- **分块中位数 + Hoeffding**：将 Chebyshev 的常数概率放大为指数衰减。

#### 🔎 结论是否比证明窄

**明确的窄结论**：

1. **定理 3.3 的秩一分布**：证明是精确的，但只对秩一张量成立。作者在推论中将其推广到正交 CP 张量（定理 4.3），但**没有证明**对一般张量的精确分布——只给出了上界（定理 5.2）。作者在第五节末尾承认："The exact distribution for a general tensor remains open."

2. **定理 5.2 的锐利性**：作者证明了上界由秩一张量达到，但**没有证明**对所有张量该上界都是紧的。实际上，对于接近正交 CP 的张量，真实方差可能远小于上界。作者在第五节提到："The bound is sharp in the worst case, but may be loose for structured tensors."

3. **定理 5.5 的置信保证**：证明依赖方差上界 V 的已知性。对一般张量，V = (1 + 2/β_F)^{d-1} - 1 是保守的；对正交 CP，V 依赖 re_ff(A) 的已知性。但 re_ff(A) 本身需要知道 λ_r，而这通常不可得。作者在第六节的应用中**没有**使用定理 5.5 的置信保证，而是直接用样本均值，说明这一保证在实际中难以操作。

4. **计算成本**：作者在第三节的比较中声称四元数探针"在相同随机数预算下"更优，但**没有分析算术成本**。四元数乘法的计算量是实数乘法的 4 倍，在收缩计算中，如果张量-探针收缩本身是计算瓶颈，则四元数探针的总计算时间可能并不占优。作者在结论中承认："The comparison is at fixed Gaussian budget, not at fixed arithmetic cost."

**被泛化的地方**：作者在摘要和引言中声称"四元数探针在 d ≥ 3 时严格优于四个独立实探针"，但这一结论**只在秩一和正交 CP 情形被证明**。对一般张量，定理 5.2 只给出上界，且该上界对四元数探针和四个实探针的平均都成立，但**没有证明**四元数探针的上界更紧。作者在第五节末尾谨慎地写道："For general tensors, the ordering of the bounds follows from the rank-one case, but a direct comparison of the actual variances remains open."

### 四、开放问题

1. **一般张量的精确方差**：定理 5.2 只给出上界，且上界由秩一情形达到。对一般张量（非秩一、非正交 CP），能否给出精确的方差公式？这需要理解张量的谱分解与探针收缩之间的交互。扎根于第五节："The exact distribution for a general tensor remains open."

2. **算术成本匹配的比较**：作者在固定高斯预算下比较了四元数与实探针，但没有分析算术成本。四元数乘法的计算量是实数的 4 倍，在收缩计算中可能抵消方差优势。能否设计一种"计算成本匹配"的比较框架？扎根于结论："Future work includes comparisons at matched arithmetic cost."

3. **自适应停止准则的认证**：第六节的算法 2 使用重复检验同一组探针来决定是否停止，这引入了多重检验偏差。作者承认："The stopping rule is empirical." 能否设计一种**无偏的自适应停止准则**，使得最终估计量在停止时仍具有有效的置信保证？扎根于第六节末："The fixed-truncation variance bound alone does not certify a stopping decision made by repeatedly testing the same probes."

4. **更高维代数结构的探针**：四元数（β_F = 4）优于复数（β_F = 2）优于实数（β_F = 1），这一趋势是否延续到八元数（β_F = 8）或克利福德代数？八元数的非结合性是否会影响收缩计算的正确性？扎根于第三节的讨论："The variance factor decreases with β_F, suggesting that higher-dimensional algebras may further improve the estimator."

5. **与低秩近似算法的交互**：本文的估计器假设收缩 oracle 是精确的。但在自适应低秩近似（如 [3, 11]）中，收缩本身可能带有噪声或截断误差。估计器的方差分析如何与这些误差交互？扎根于引言的第一个应用场景："Adaptive tensor methods explicitly require error control [4, 23, 3, 11, 10]."

6. **有效秩的估计**：定理 4.3 的方差公式依赖 re_ff(A)，但 re_ff(A) 通常未知。能否用探针收缩本身来估计 re_ff(A)？这类似于随机矩阵理论中谱密度估计的问题。扎根于定理 4.3 后的讨论："The effective rank can also be computed from any mode unfolding."
