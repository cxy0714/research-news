### 一、领域脉络与小综述

#### 这个方向是什么

本文所处的子方向是**极值图论中的“圈多重性”（cycle multiplicity）问题**：在给定边密度（或最小度）条件下，一个哈密顿图（Hamiltonian graph）中，长度为 ℓ 的简单圈至少有多少个？这个问题介于两个经典主题之间——**哈密顿圈的存在性**（Dirac、Bondy 等）与**固定长度圈的计数**（Erdős 的三角形计数定理等）。其成熟度属于“经典问题、长期悬而未决、近期因新工具而突破”的状态：Hilton 于 1977 年提出猜想，Li–Xu–Zhou 在 2026 年证明了 ℓ ≥ 11 及 ℓ = 3,4,5 的情形，本文补上了 ℓ = 6,7,8,9,10 的缺口。

#### 发展脉络（history）

- **奠基工作**：Dirac (1952) [1] 证明最小度 ≥ n/2 蕴含哈密顿圈；Bondy (1971) [2] 加强为“泛圈性”（pancyclic），即所有长度 3 到 n 的圈都存在，唯一的例外是平衡完全二分图。这奠定了“密度条件 → 圈的存在性”这一研究范式。
- **主要进展（计数方向）**：Erdős (1962) [3] 的三角形计数定理给出 c₃(G) ≥ n−1 的下界，并构造了达到该界的图（完全二分图加两条边）。这为“圈多重性”的精确下界提供了第一个非平凡例子。Sheehan (1977) [5] 证明了边数 > ⌊n²/4⌋+1 的哈密顿图至少有两条每个长度的圈，并在此文中记录了 Hilton 的猜想（即本文要证的 (2) 式）。
- **当前 frontier（弱泛圈性与计数下界的结合）**：Brandt (1997) [10] 和 Brandt–Faudree–Goddard (1998) [9] 建立了“弱泛圈性”（weak pancyclicity）——在非二分图且边数足够多时，图包含从 3 到其周长（circumference）的所有长度圈。这为“存在性”提供了工具，但未给出计数下界。Li–Xu–Zhou (2026) [8] 首次将计数下界与弱泛圈性结合，证明了 Hilton 猜想在 ℓ ≥ 11 及 ℓ = 3,4,5 的情形，并留下 ℓ = 6,7,8,9,10 的缺口。
- **本文的位置**：作者 Qiyue Tang 直接补上了 Li–Xu–Zhou 留下的五个长度缺口，从而完整证明了 Hilton 猜想。方法上，作者沿用了 [8] 的“反例归约”（counterexample reduction）框架，但针对短圈长度（ℓ ≤ 10）引入了新的块结构（block）分析，特别是对边界阶数（n = 2ℓ−1, 2ℓ）的精细处理。

#### 子线索聚类

1. **存在性线索**：Dirac → Bondy → Brandt → Brandt–Faudree–Goddard。这条线回答“什么条件下圈存在”，工具是度条件、边条件、弱泛圈性。
2. **计数线索**：Erdős（三角形）→ Sheehan（两个哈密顿圈）→ Li–Xu–Zhou（Hilton 猜想的大部分情形）→ 本文（完整证明）。这条线回答“圈有多少个”，工具是极值下界构造 + 反例归约。
3. **结构线索**：Kopylov (1977) [12] 的界（周长受限图的边数上界）→ Füredi–Kostochka–Luo–Verstraëte (2017) [13] 的稳定性版本 → 本文的块分析。这条线为“没有长圈时图的结构”提供刻画，是证明的核心技术支撑。

#### 这个方向在追问的核心问题

1. **密度阈值与圈多重性的关系**：边数超过 ⌊n²/4⌋+1 后，每个长度的圈至少有多少个？Hilton 猜想给出了精确答案 cℓ(G) ≥ n−ℓ+2，本文证明了这个下界对所有 ℓ 成立。
2. **短圈与长圈的难度差异**：为什么 ℓ ≥ 11 的情形相对容易（Li–Xu–Zhou 已解决），而 ℓ = 6,7,8,9,10 需要新的块分析？因为短圈对图的局部结构更敏感，边界阶数（n = 2ℓ−1, 2ℓ）附近的构造更复杂。
3. **二分图例外**：Bondy 的泛圈性定理中，平衡完全二分图是唯一例外。在计数问题中，这个例外如何体现？本文的定理 2 对偶数 ℓ 允许省略非二分假设，说明二分图在短偶圈计数中确实需要单独处理。

#### ⚠️ 作者的 framing（这是作者的说法）

作者在引言中把缺口 frame 成“Li–Xu–Zhou 的定理 3.1 覆盖了 ℓ ≥ 11 及 ℓ = 3,4,5，但留下了 ℓ = 6,7,8,9,10 的五个长度”。作者声称本文的贡献是“通过块分析处理边界阶数，补上这五个缺口”。注意：作者**淡化**了以下竞争路线——（a）Brandt–Faudree–Goddard 的弱泛圈性定理在非二分图中已经给出了所有中间长度的存在性，但作者没有讨论能否用纯存在性工具推出计数下界；（b）Erdős–Füredi–Kostochka–Luo–Verstraëte 的稳定性定理可能提供更一般的计数框架，但作者只用了 Kopylov 界的精确形式。**值得研究者去查的问题**：Li–Xu–Zhou [8] 的定理 3.1 是否真的只差这五个长度？他们的方法在 ℓ = 6,7,8,9,10 时具体卡在哪里？作者在引言中没有详细说明 [8] 的技术障碍，只说了“remaining orders”的表格。

#### 张力

未见明显对立引用。所有引用的工作方向一致：从存在性到计数，从弱泛圈性到精确下界。唯一的微妙之处是：Bondy 的泛圈性定理要求最小度 ≥ n/2，而本文和 [8] 使用的是边数条件（e(G) > ⌊n²/4⌋+1），两者在边界情形（n 为偶数时）略有差异，但作者没有讨论这种差异是否影响计数下界的紧性。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

- **图 G**：有限简单图，顶点集 V(G)，边集 E(G)，阶数 n = |V(G)|，边数 e(G) = |E(G)|。
- **哈密顿图**：包含一个通过所有顶点的简单圈（哈密顿圈）。
- **圈长 ℓ**：简单圈的长度（顶点数），取值范围 3 ≤ ℓ ≤ n。
- **圈多重性 cℓ(G)**：G 中长度为 ℓ 的简单圈的个数（不计起点、方向）。
- **t₂(n)**：⌊n²/4⌋，即 Turán 图（平衡完全二分图）的边数，是极值图论中的基准量。
- **可观测数据**：研究者能观测到的是图 G 的邻接关系（即边集 E(G)）。**不可观测**的是“所有可能的圈”——它们是图的结构性质，需要通过边集推导。**关键点**：本文的定理 1 是一个**纯图论存在性+计数命题**，不涉及概率或潜在结果。但在证明中，作者使用了“反例归约”：假设存在一个满足边数条件但没有足够多 ℓ-圈的图，然后通过删除低度顶点、分析剩余结构来导出矛盾。这里的“反例”是**假设存在但实际不存在的对象**，类似于因果推断中的“反事实”。

#### 第二步：最小内核

**最简特例**：考虑 n = 2ℓ+1（奇数阶），ℓ = 6（即 n = 13）。假设 G 是哈密顿图，e(G) > ⌊13²/4⌋+1 = 42+1 = 43，且 G 没有长度为 6 的圈。我们要证明 c₆(G) ≥ 13−6+2 = 9，即 G 至少有 9 个六圈。

**为什么这个特例是核心**：ℓ = 6 是本文处理的五个长度中最小的，且 n = 2ℓ+1 是边界阶数（定理 2 要求 n ≥ 2ℓ−1）。在这个特例中，所有关键思想都会出现：

1. **删除低度顶点**：从 G 中删除度 < (n+2)/3 ≈ 5 的顶点，最多删 3 个（引理 3 的归约）。剩下的图 R 有最小度 ≥ 5，且边数仍然很高。
2. **二分图情形**：如果 R 是二分图，由于 R 的边数 ≥ ⌊13²/4⌋−13+6+1 = 42−13+7 = 36，而平衡完全二分图 K₆,₇ 的边数是 42，R 的边数接近 Turán 界。此时 R 必须包含 K₆,₇ 的某种近似结构，而 K₆,₇ 中显然有六圈（取 3 个顶点在一边、3 个在另一边，交替排列）。这直接矛盾。
3. **非二分图情形**：如果 R 是非二分图，用 Brandt 的弱泛圈性定理，R 包含从 3 到其周长的所有长度圈。由于 R 的边数很高，其周长至少为 6（否则边数会被 Kopylov 界限制）。于是 R 有六圈，矛盾。
4. **边界阶数的精细处理**：当 n = 2ℓ−1 = 11 时，删除 3 个顶点后 R 的阶数只有 8，此时需要更精细的块分析（定理 2 的“Blocks at the boundary orders”部分）。作者证明 R 的块结构只能是两个完全图 K₆ 和 K₅ 共享一个顶点，然后通过路径拼接构造六圈。

**这个特例揭示了整篇论文的数学本质**：**将“圈计数下界”归约为“无 ℓ-圈图的边数上界”**。如果 G 没有足够多的 ℓ-圈，那么删除低度顶点后得到的图 R 要么是二分图（此时边数接近 Turán 界，必须包含 ℓ-圈），要么是非二分图（此时弱泛圈性保证 ℓ-圈存在），要么是边界阶数（此时块结构分析直接构造 ℓ-圈）。三种情况都导出矛盾，因此 G 必须有足够多的 ℓ-圈。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：证明了 Hilton 猜想——任意哈密顿图 G（阶数 n，边数 e(G) > ⌊n²/4⌋+1）中，长度为 ℓ 的圈至少有 n−ℓ+2 个（3 ≤ ℓ ≤ n）。
2. **核心工具 / 方法**：反例归约（假设存在反例，删除低度顶点得到高最小度图）+ 弱泛圈性定理（Brandt 等）+ Kopylov 界（周长受限图的边数上界）+ 块结构分析（边界阶数的精细刻画）。
3. **主要结论**：定理 1 完整解决了 Hilton 猜想；定理 2 是更强的存在性结果——对 ℓ ∈ {6,7,8,9,10} 且 n ≥ 2ℓ−1，任何满足边数条件的 2-连通非二分图都包含 Cℓ。

#### 关键设定与假设

- **定理 1 的假设**：G 是哈密顿图，e(G) > ⌊n²/4⌋+1。注意：**不需要最小度条件**，哈密顿性 + 边数条件就足够了。相比 Bondy 的泛圈性定理（要求最小度 ≥ n/2），本文的边数条件更弱（因为哈密顿图本身蕴含最小度 ≥ 2，但边数条件允许更稀疏的图）。
- **定理 2 的假设**：H 是 2-连通非二分图，e(H) ≥ t₂(n)−n+ℓ+1。这里 2-连通性替代了哈密顿性（哈密顿图一定是 2-连通的），非二分性排除了 Bondy 定理中的例外情形。**相比 [8] 的定理 3.1**：本文的定理 2 只处理 ℓ ∈ {6,7,8,9,10}，但假设更弱（2-连通而非哈密顿），结论更强（存在 Cℓ 而非计数下界）。
- **技术性假设**：在边界阶数（n = 2ℓ−1, 2ℓ）处，作者假设 R 的块结构满足特定形式（两个完全图共享一个顶点）。这个假设来自 Kopylov 界的等式情形，是**证明中唯一需要验证的紧性条件**。

#### 主要结果

- **定理 1**：Hilton 猜想成立。这是本文的核心结果，解决了 1977 年以来的开放问题。
- **定理 2**：对 ℓ ∈ {6,7,8,9,10}，边数条件 e(H) ≥ t₂(n)−n+ℓ+1 足以保证 2-连通非二分图中存在 Cℓ。这个结果比 [8] 的定理 3.1 更一般（[8] 只处理了 ℓ ≥ 11 及 ℓ = 3,4,5）。
- **引理 3**（路径与奇偶性）：在二分图中，给定端点颜色，可以构造任意长度的路径（长度与端点颜色的奇偶性一致）。这是构造 Cℓ 的基本工具。
- **引理 4**（耳）：在 2-连通非二分图中，如果删除少量顶点后得到二分图，则存在一条“耳”（路径），其长度与端点颜色的奇偶性不一致。这提供了构造奇圈的途径。
- **引理 5**（近完全图）：在至多删除两条边的完全图中，任意两个指定顶点之间有所有长度 2 到 a−3 的路径。这是边界阶数处块分析的直接工具。

#### 证明路线与技术技巧

**整体路线**（定理 2 的证明，5 步）：

1. **反设与归约**：假设 H 是满足条件的 2-连通非二分图但没有 Cℓ。删除度 < (q+2)/3 的顶点（q 为当前阶数），最多删 3 次。得到图 R，最小度 ≥ (q+2)/3，且边数 e(R) ≥ M_r(n)（引理 3 的归约）。
2. **二分图分支**：如果 R 是二分图，用引理 3 构造 Cℓ。关键是用边数条件保证 R 的二分图部分足够大，使得任意两个同色顶点之间有足够长的路径。对于偶数 ℓ，直接构造；对于奇数 ℓ，需要引理 4 的耳来调整奇偶性。
3. **非二分图分支**：如果 R 是非二分图，用 Brandt 的弱泛圈性定理（[10]），R 包含从 3 到其周长的所有长度圈。由于 R 的边数 ≥ M_r(n)，用 Kopylov 界（[12]）反推周长至少为 ℓ，于是 R 有 Cℓ，矛盾。
4. **边界阶数**：当 n = 2ℓ−1 或 2ℓ 时，上述分支可能失效（因为删除 3 个顶点后 R 的阶数太小，弱泛圈性定理不适用）。此时用块分析：R 的每个块（2-连通分量）的阶数 ≤ ℓ−1（否则用 Kopylov 界推出矛盾）。然后枚举所有可能的块结构，证明只有两种情形（两个完全图共享一个顶点），再用引理 5 构造 Cℓ。
5. **闭合矛盾**：所有分支都导出矛盾，因此 H 必须包含 Cℓ。

**关键技巧**：

- **删除低度顶点**：这是极值图论的标准技巧，但作者将其与边数条件结合，得到了精确的剩余边数下界 M_r(n)。这个下界在边界阶数处恰好等于 Kopylov 界的等式情形，使得块分析成为可能。
- **奇偶性控制**：引理 4 是关键创新——在非二分图中，通过耳来调整路径长度的奇偶性。这比直接构造奇圈更精细，因为它允许在二分图中构造奇长度的路径。
- **块结构枚举**：在边界阶数处，作者没有使用一般的弱泛圈性定理，而是直接枚举所有可能的块结构。这种“暴力”方法虽然繁琐，但避免了弱泛圈性定理在边界情形的不精确性。

#### 🔎 结论是否比证明窄

- **定理 1 的证明**：作者声称“由定理 2 和 [8] 的定理 3.1 直接推出”。但注意：定理 2 要求 H 是 2-连通非二分图，而定理 1 中的 G 是哈密顿图（蕴含 2-连通），但可能是二分图。作者在证明中通过 [8] 的引理 3.3 排除了二分图情形（即如果 G 是二分图且边数足够，则它必须有足够的 ℓ-圈）。**这个排除过程在本文中没有详细展开**，而是引用了 [8] 的结论。因此，定理 1 的证明严格依赖于 [8] 的未公开细节。
- **定理 2 的边界阶数**：作者在“Blocks at the boundary orders”部分只处理了 n = 2ℓ−1 和 n = 2ℓ 两种情形，但定理 2 的陈述要求 n ≥ 2ℓ−1。对于 n > 2ℓ，作者使用弱泛圈性定理（步骤 3），但**没有明确说明弱泛圈性定理在 n > 2ℓ 时是否总是适用**。从证明看，当 n ≥ 2ℓ+1 时，删除 3 个顶点后 R 的阶数 ≥ 2ℓ−2，此时弱泛圈性定理适用。但对于 n = 2ℓ−1 和 n = 2ℓ，需要块分析。**这个分界是清晰的，但作者没有在定理陈述中明确标注**。
- **引理 5 的适用范围**：引理 5 要求 a ≥ 5，但在块分析中，较小的块（阶数 < 5）如何处理？作者在证明中隐含地假设了这些小块不会影响构造（因为它们太小，无法提供足够的路径）。这个假设是合理的，但**没有显式验证**。

### 四、开放问题

1. **紧性**：定理 1 的下界 cℓ(G) ≥ n−ℓ+2 是否紧？作者在引言中提到了 Erdős 的三角形构造（n = 2m+1 时 c₃ = n−1），但没有讨论其他长度 ℓ 的紧性。要确认：是否存在达到下界的图族？这需要构造每个长度 ℓ 的极值图，可能涉及与二分图例外相关的精细构造。（扎根于引言中“The triangle endpoint is consistent with the classical triangle-counting theorem of Erdős”一句——作者只验证了 ℓ = 3 的紧性。）

2. **边数条件的改进**：定理 1 要求 e(G) > ⌊n²/4⌋+1。这个阈值是否可以降低？Sheehan [5] 证明了低于此阈值时可能只有一个哈密顿圈。是否存在中间阈值，使得 cℓ(G) ≥ 1 但 cℓ(G) < n−ℓ+2？这需要更精细的极值分析。（扎根于引言中“Sheehan’s 1977 paper studies how dense a graph with exactly one Hamilton cycle can be”——作者没有讨论阈值以下的计数行为。）

3. **最小度条件版本**：定理 2 使用边数条件，但 Brandt–Faudree–Goddard [9] 的弱泛圈性定理使用最小度条件。是否存在最小度版本的 Hilton 猜想？即：最小度 ≥ n/2 的哈密顿图中，cℓ(G) 的下界是什么？这可能比边数条件版本更难，因为最小度条件允许更不均匀的图。（扎根于引言中“Brandt, Faudree and Goddard obtained a corresponding conclusion under the minimum-degree condition (q+2)/3”——作者没有讨论最小度版本的计数问题。）

4. **随机图视角**：在随机图 G(n,p) 中，当 p 超过哈密顿阈值时，cℓ(G) 的典型行为是什么？这与本文的极值下界有何关系？随机图的圈计数可能为极值下界提供概率性验证。（扎根于引言中“Degree and edge conditions that force a Hamilton cycle often also force shorter cycles”——作者没有讨论随机图模型。）

**提醒**：要确认上述问题是否是真 gap，建议去读近 5 年极值图论中关于圈计数和弱泛圈性的论文（如 Füredi–Kostochka–Luo–Verstraëte 系列），看是否已有相关结果。特别是问题 1（紧性）和问题 3（最小度版本），如果已有文献涉及，则本文的贡献需要重新定位。
