### 一、领域脉络与小综述

#### 这个方向是什么

本文所处的子方向是**半参数效率提升（semiparametric efficiency augmentation）**：在生存分析中，当研究者拥有一个与主要结局（time-to-event）相关的辅助结局（auxiliary outcome）时，如何在不指定联合似然的前提下，利用辅助信息来提高 Cox 回归中目标参数（如处理效应 log-hazard ratio）的估计效率。该方向的核心统计问题是：辅助信息何时能带来效率增益、增益有多大、以及在模型设定错误（两个结局的基线协变量效应不一致）时如何避免偏差。当前该方向的成熟度处于"方法百花齐放但缺乏统一框架"的阶段——已有工作分别处理外部汇总信息（Huang et al., 2016）、迁移学习（Li et al., 2023）、缺失数据下的辅助信息（Chen et al., 2008b），但鲜有工作处理"同一队列中同时观测到的连续辅助结局"这一设定。

#### 发展脉络

- **奠基工作：联合建模框架**。Tsiatis et al. (1995)、Wulfsohn and Tsiatis (1997)、Tsiatis and Davidian (2004) 建立了纵向标记物与生存结局的联合模型，通过共享随机效应连接两个结局。这些工作奠定了"辅助信息可提高效率"的直觉，但要求完全指定联合似然，对分布假设敏感。Song et al. (2002) 进一步扩展了联合建模的适用范围。**留下的口子**：联合似然指定在复杂数据中不可行或不可靠，需要不依赖完整似然的方法。

- **主要进展 I：外部汇总信息的整合**。Huang et al. (2016) 提出利用外部亚组生存概率（如疾病登记处的 t 年生存率）通过经验似然方法改进 Cox 回归效率；Huang and Qin (2020) 将其推广为统一框架，用广义矩方法（GMM）整合外部协变量效应信息；Sheng et al. (2022) 进一步引入惩罚经验似然处理人群异质性。**这条线的特点**：外部信息是**汇总层面**的（aggregate），不要求个体水平的辅助结局。**留下的口子**：当辅助信息来自**同一队列的个体水平连续结局**时，这些方法不直接适用。

- **主要进展 II：迁移学习视角**。Li et al. (2023) 将问题重新表述为迁移学习：从源队列（如癌症登记处）向目标队列（如单中心）迁移风险估计知识，允许时变的人群异质性。**这条线的特点**：强调源-目标人群差异的自适应处理，但主要处理**外部数据**。**留下的口子**：同一队列内、两个结局共享基线协变量效应的结构未被利用。

- **主要进展 III：缺失数据与代理变量**。Chen et al. (2008b) 在 GMM 框架下研究辅助数据（auxiliary data）对半参数效率的影响，证明当缺失机制满足特定条件时，辅助数据可缩小效率界。**这条线的特点**：理论严谨，但设定是"主数据缺失、辅助数据完整"，与本文"两个结局都完整观测"不同。

- **本文的位置**：本文填补的缺口是——**同一队列中，连续辅助结局（服从部分线性模型）与生存结局（服从 Cox 模型）同时被观测，且二者的基线协变量效应可能相同（共享）或不同（不共享）**。作者用二次惩罚连接两个非参数函数，在惩罚水平固定时证明效率不损失，在惩罚趋于零时恢复共享效应估计，在惩罚趋于无穷时退化为单独估计。这比外部信息整合更灵活（不需要外部数据源），比联合建模更稳健（不需要指定联合似然），比迁移学习更简单（不需要处理人群异质性）。

#### 子线索聚类

1. **联合建模与代理结局**（Tsiatis et al., 1995; Wulfsohn and Tsiatis, 1997; Song et al., 2002; Tsiatis and Davidian, 2004; Prentice, 1989）：用似然方法连接两个结局，效率增益来自共享结构，但依赖完整分布假设。
2. **外部信息整合**（Huang et al., 2016; Huang and Qin, 2020; Sheng et al., 2022）：用 GMM/经验似然整合汇总统计量，不要求个体水平辅助数据，但外部信息的信息量有限。
3. **迁移学习**（Li et al., 2023）：将辅助数据视为源域，目标域估计通过自适应加权实现，强调异质性处理。
4. **缺失数据与辅助样本**（Chen et al., 2008b）：理论效率界分析，辅助数据用于补全缺失信息。

#### 这个方向在追问的核心问题

1. **效率增益的来源与条件**：辅助信息何时能提高目标参数的估计效率？本文的回答是：当两个结局的基线协变量效应共享（或接近）时，通过惩罚连接可以实现效率增益，且增益大小由交叉信息矩阵 C 决定（Theorem 2 中的公式 (34)）。
2. **模型错误设定下的鲁棒性**：当共享效应假设不成立时，如何避免偏差？本文的回答是：固定惩罚会改变目标（Proposition 2），但局部 n^{-1/2} 差异只产生可量化的均值偏移（Theorem 3），自适应惩罚可以检测并退化为单独估计（Theorem 4）。
3. **非参数函数的估计效率**：在部分线性模型 + Cox 模型的组合下，如何同时估计两个非参数函数并保持目标参数的根号 n 收敛？本文通过 sieve 方法处理，但 Theorem 5 的条件（Assumptions 6-8）是"待验证"的，作者在 Appendix C 明确承认"does not verify them for a particular spline basis"。

#### ⚠️ 作者的 framing

作者将缺口 frame 成："**同一队列中，辅助结局与生存结局的基线协变量效应可以通过惩罚连接实现信息借用，且不损失目标参数的渐近效率**"。这个 framing 的关键假设是：两个结局的基线协变量效应在某种尺度下可比（本文通过标准化辅助结局实现）。作者淡化的竞争路线包括：(1) 联合建模（认为需要完整似然，过于严格）；(2) 外部信息整合（认为需要外部数据源，不适用于同一队列的个体水平数据）；(3) 多任务学习/迁移学习（认为主要处理人群异质性，而非同一人群内的信息共享）。

**值得研究者去查的问题**：作者在 intro 中没有引用以下可能相关的工作：(a) 半参数效率理论中关于"辅助信息对效率界的影响"的经典结果（如 Bickel et al., 1993 的 semiparametric efficiency 框架）；(b) 关于"惩罚连接两个回归函数"的贝叶斯或频率学派先例（如 joint modeling 中的 shared frailty 模型）；(c) 关于"自适应惩罚"在转移学习中的近期工作（如 Li et al., 2022 的 adaptive transfer learning）。这些缺失可能意味着作者有意回避了更一般的效率理论框架，或者这些工作确实不直接适用。

#### 张力

未见明显对立引用。但有一个微妙的张力：Huang et al. (2016) 和 Sheng et al. (2022) 强调外部信息的**不确定性**需要被纳入推断（否则会低估方差），而本文的辅助结局来自同一队列、被视为完全观测，因此不需要处理外部信息的不确定性。这实际上是两种不同的设定，而非对立结论。另一个潜在张力：Li et al. (2023) 强调**时变异质性**需要被建模，而本文假设共享效应是静态的（不随时间变化），这可能限制了方法在长期随访数据中的适用性。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

**符号清单**（按类别分组）：

| 符号 | 含义 | 类别 |
|------|------|------|
| \(Y\) | 连续辅助结局 | 可观测随机变量 |
| \(T\) | 事件时间 | 可观测随机变量（可能被删失） |
| \(C\) | 删失时间 | 可观测随机变量 |
| \(\tilde{T} = \min(T, C)\) | 观测到的事件时间 | 可观测随机变量 |
| \(\Delta = 1(T \leq C)\) | 事件指示符 | 可观测随机变量 |
| \(Z \in \mathbb{R}^p\) | 目标协变量（如处理指示符） | 可观测随机变量 |
| \(X\) | 基线协变量（用于调整） | 可观测随机变量 |
| \(\alpha_0 \in \mathbb{R}^p\) | 辅助结局中 Z 的回归系数 | 参数（nuisance） |
| \(\beta_0 \in \mathbb{R}^p\) | Cox 模型中 Z 的回归系数 | **目标参数（estimand）** |
| \(f_{Y0}(X)\) | 辅助结局中 X 的非参数效应 | 非参数 nuisance |
| \(f_{T0}(X)\) | Cox 模型中 X 的非参数效应 | 非参数 nuisance |
| \(\lambda_0(t)\) | 基线风险函数 | 非参数 nuisance |
| \(\varepsilon\) | 辅助结局的误差项，\(E(\varepsilon \mid Z, X) = 0\) | 潜在（不可观测） |
| \(\sigma_Y^2\) | 辅助结局的残差方差 | 参数（nuisance） |
| \(\lambda \geq 0\) | 惩罚参数 | 调参（tuning） |
| \(b_K(x) \in \mathbb{R}^K\) | sieve 基函数 | 已知构造 |
| \(G_n\) | 经验 Gram 矩阵 | 可观测数据的函数 |
| \(G\) | 总体 Gram 矩阵 | 理论量 |
| \(E\) | 辅助结局的 Hessian（profiled） | 理论量 |
| \(A, C, D\) | Cox 信息矩阵的分块 | 理论量 |
| \(H_\lambda = D + K_\lambda\) | 惩罚后的 nuisance 信息 | 理论量 |
| \(K_\lambda = \lambda G - \lambda^2 G(E + \lambda G)^{-1} G\) | 惩罚贡献 | 理论量 |
| \(W_\lambda = \lambda G (E + \lambda G)^{-1}\) | 借用权重矩阵 | 理论量 |
| \(P_X\) | X 的分布 | 理论量 |
| \(\|\cdot\|_n\) | 经验 L2 范数 | 可观测数据的函数 |
| \(\|\cdot\|_{P_X}\) | 总体 L2 范数 | 理论量 |

**模型**（两个方程，通过惩罚连接）：

1. **辅助结局**（部分线性模型）：
   \[
   Y = Z^\top \alpha_0 + f_{Y0}(X) + \varepsilon, \quad E(\varepsilon \mid Z, X) = 0
   \]
   这里 \(f_{Y0}\) 是 X 的非参数函数，\(\alpha_0\) 是 Z 的线性系数。

2. **生存结局**（Cox 比例风险模型）：
   \[
   \lambda(t \mid Z, X) = \lambda_0(t) \exp\{Z^\top \beta_0 + f_{T0}(X)\}
   \]
   这里 \(f_{T0}\) 是 X 的非参数函数，\(\beta_0\) 是目标参数。

3. **连接机制**：二次惩罚 \(\frac{\lambda}{2} \|f_Y - f_T\|_n^2\)，其中 \(\|g\|_n^2 = \frac{1}{n} \sum_{i=1}^n g^2(X_i)\)。

**可观测数据**：\(O_i = (Y_i, \tilde{T}_i, \Delta_i, Z_i, X_i)\)，i.i.d.，\(i = 1, \ldots, n\)。

**关键识别条件**：
- 条件独立删失：\(T \perp C \mid (Z, X)\)
- 中心化条件：\(E\{f_{Y0}(X)\} = E\{f_{T0}(X)\} = 0\)
- 辅助结局的尺度固定（标准化），使 \(f_Y\) 与 \(f_T\) 可比

**估计方法**：最小化联合准则 \(Q_n(\alpha, \beta, f_Y, f_T; \lambda) = L_{Y,n}(\alpha, f_Y) + L_{T,n}(\beta, f_T) + \frac{\lambda}{2} \|f_Y - f_T\|_n^2\)，其中 \(L_{Y,n}\) 是平方误差损失，\(L_{T,n}\) 是 Cox 偏似然的负对数。

#### 第二步：最小内核

**最小内核**：考虑最简单的设定——\(p = 1\)（单个目标协变量 Z），\(X\) 为一维连续变量，sieve 基为 K 维 B-spline，删失独立于 (Z, X)。**要证明的核心命题是**：

> **命题（Theorem 2 的特例）**：当 \(f_{Y0} = f_{T0} = f_0\)（两个结局的基线协变量效应完全一致）时，对任意固定惩罚水平 \(\lambda \geq 0\)，Cox 回归系数估计量 \(\hat{\beta}_\lambda\) 的渐近方差 \(V_\lambda\) 满足 \(V_\lambda \preceq V_0\)，其中 \(V_0\) 是单独拟合 Cox 模型（不利用辅助信息）时的渐近方差。

**为什么这个命题成立（直觉）**：

1. **惩罚不改变目标**：当 \(f_{Y0} = f_{T0}\) 时，惩罚项在真实函数处取值为零，因此目标参数 \(\beta_0\) 仍是联合准则的全局最小点（Proposition 1）。这意味着估计量仍然一致。

2. **辅助信息增加曲率**：联合准则的 Hessian 比单独 Cox 准则的 Hessian 多了一个正定块（来自辅助结局的似然贡献和惩罚项）。在信息恒等式成立和得分正交的条件下，额外的曲率转化为更小的渐近方差。

3. **数学机制**：Theorem 2 的公式 (34) 显示
   \[
   V_\lambda = P_\lambda^{-1} - P_\lambda^{-1} C H_\lambda^{-1} \Delta_\lambda H_\lambda^{-1} C^\top P_\lambda^{-1}
   \]
   其中 \(P_\lambda = A - C H_\lambda^{-1} C^\top\) 是 profiled 信息矩阵，\(\Delta_\lambda = K_\lambda - W_\lambda E W_\lambda^\top \succeq 0\)（Lemma 3）。第二项是**非负**的，因此 \(V_\lambda \preceq P_\lambda^{-1}\)。又因为 \(H_\lambda \succeq D\)（Lemma 3），所以 \(P_\lambda^{-1} \preceq P_0^{-1} = V_0\)。两步合起来得到 \(V_\lambda \preceq V_0\)。

4. **关键条件**：这个效率增益不是免费的。它依赖于：
   - **信息恒等式**（Assumption 3）：\(Var(s_Y) = E\)，即辅助结局的得分方差等于其 Hessian。这要求辅助结局的似然被正确指定（本文用平方误差损失，对应高斯似然）。
   - **得分正交**（Assumption 4）：辅助结局的得分与 Cox 得分不相关。Lemma 1 给出充分条件：\(E\{\varepsilon \, dM(t) \mid Z, X\} = 0\)，即辅助结局的误差与事件过程的条件协方差为零。

5. **当共享效应不成立时**：如果 \(f_{Y0} \neq f_{T0}\)，固定惩罚会引入偏差（Proposition 2）。但 Theorem 3 显示，若差异是局部的（n^{-1/2} 阶），偏差是显式的 \(B_\lambda(h) = -P_\lambda^{-1} C H_\lambda^{-1} K_\lambda h\)，且随 \(\lambda \to 0\) 消失。这启发了自适应惩罚：先估计差异大小，差异小时用大惩罚（借用信息），差异大时用小惩罚（退化为单独估计）。

**这个最小内核揭示了本文的本质贡献**：它不是在提出一个新的估计量，而是在**刻画"惩罚连接两个半参数模型"这一通用策略的效率-偏差权衡**。Theorem 2 给出了效率增益的精确公式，Theorem 3 给出了偏差的精确公式，Theorem 4 给出了自适应选择惩罚的理论保证。这三者合在一起，构成了一个"何时借用、借用多少、何时不借用"的完整理论框架。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：在 Cox 比例风险模型下，如何利用同一队列中观测到的连续辅助结局（服从部分线性模型）来提高目标回归系数 \(\beta_0\) 的估计效率，同时控制因两个结局基线协变量效应不一致而产生的偏差。
2. **核心工具/方法**：通过二次惩罚 \(\frac{\lambda}{2}\|f_Y - f_T\|_n^2\) 联合估计两个半参数模型，利用 sieve 方法处理非参数函数，基于 sandwich 协方差进行推断，并提出数据驱动的自适应惩罚选择规则。
3. **主要结论**：当两个基线协变量效应一致时，对任意固定惩罚水平，Cox 估计量的渐近方差不大于单独估计（Theorem 2）；当存在局部 n^{-1/2} 差异时，产生显式的均值偏移（Theorem 3）；自适应惩罚在两种情形下都能达到最优权衡（Theorem 4）。

#### 关键设定与假设

- **模型设定**：辅助结局为部分线性模型 \(Y = Z^\top \alpha_0 + f_{Y0}(X) + \varepsilon\)，生存结局为 Cox 模型 \(\lambda(t \mid Z, X) = \lambda_0(t) \exp\{Z^\top \beta_0 + f_{T0}(X)\}\)。两个模型通过惩罚连接，但不要求联合似然。
- **删失机制**：条件独立删失 \(T \perp C \mid (Z, X)\)，观测时窗 \(\tau < \infty\)，\(P(\tilde{T} \geq \tau) > 0\)，\(\Lambda_0(\tau) < \infty\)。
- **辅助结局的尺度**：标准化使 \(f_Y\) 与 \(f_T\) 可比。这是一个关键但容易被忽视的假设——如果辅助结局的尺度选择不当，惩罚项的含义会改变。
- **sieve 设定**：固定维 K 的 sieve 空间 \(\mathcal{F}_n\)，中心化条件 \(n^{-1}\sum_i f(X_i) = 0\)。固定 K 时理论是精确的；增长 K 时（Theorem 5）需要额外条件（Assumptions 6-8），但作者明确承认这些条件"not verified for a particular spline basis"。
- **信息恒等式**（Assumption 3）：\(Var(s_Y) = E\)，即辅助结局的得分方差等于其 Hessian。这等价于要求辅助结局的似然被正确指定。
- **得分正交**（Assumption 4）：辅助结局得分与 Cox 得分不相关。Lemma 1 给出充分条件 \(E\{\varepsilon \, dM(t) \mid Z, X\} = 0\)。

**相比已有工作的变化**：
- 相比 Huang et al. (2016) 和 Huang and Qin (2020)：本文处理的是**个体水平**的辅助结局，而非外部汇总统计量，因此不需要处理外部信息的不确定性。
- 相比 Li et al. (2023)：本文不涉及源-目标人群的迁移，而是同一人群内的信息共享，因此不需要建模时变异质性。
- 相比联合建模（Tsiatis et al., 1995）：本文不指定联合似然，因此对分布假设更稳健，但代价是效率增益可能小于完全正确的联合模型。

#### 主要结果

**Theorem 1（固定 sieve 的渐近展开）**：在 Assumptions 1-5 下，\(\sqrt{n}(\hat{\vartheta}_\lambda - \vartheta_0) = A_\lambda^{-1} \frac{1}{\sqrt{n}} \sum_{i=1}^n \psi_\lambda(O_i) + o_p(1)\)，其中 \(\psi_\lambda\) 是联合得分，\(A_\lambda\) 是惩罚后的 Hessian。这个展开是后续所有结果的基础。

**Theorem 2（效率增益）**：当 \(f_{Y0} = f_{T0}\) 时，\(V_\lambda \preceq V_0\)，且增益由公式 (34) 精确刻画。关键发现是：增益通过两个渠道实现——(i) 惩罚项直接增加 nuisance 方向的曲率（\(K_\lambda \succeq 0\)）；(ii) 辅助结局的得分通过交叉信息 C 传递到目标参数方向。当 \(C = 0\) 时（辅助结局与生存结局的得分正交），增益为零（Corollary 1）。

**Theorem 3（局部差异的偏差）**：当 \(f_{Y0} - f_{T0} = n^{-1/2} h\) 时，\(\sqrt{n}(\hat{\beta}_\lambda - \beta_0) \Rightarrow N(B_\lambda(h), V_\lambda)\)，其中 \(B_\lambda(h) = -P_\lambda^{-1} C H_\lambda^{-1} K_\lambda h\)。这个公式显示：偏差与惩罚水平 \(\lambda\) 成正比（通过 \(K_\lambda\)），与交叉信息 C 成正比，与目标方向的曲率 \(P_\lambda\) 成反比。

**Theorem 4（自适应惩罚）**：基于 pilot 估计的差异大小 \(\hat{D}_n = \|\hat{f}_Y^{sep} - \hat{f}_T^{sep}\|_n\)，选择惩罚 \(\hat{\lambda}_n = \lambda_+ \omega(\hat{D}_n / \tau_n)\)。在差异为零时 \(\hat{\lambda}_n \to \lambda_+\)（借用信息），差异固定时 \(\hat{\lambda}_n \to 0\)（退化为单独估计）。这保证了自适应估计量在两种情形下都达到最优。

**Theorem 5（增长 sieve）**：在 Assumptions 6-8 下，固定 sieve 的结果可以推广到 \(K = K_n \to \infty\)。但作者在 Appendix C 中明确承认，这些条件（特别是 sieve 逼近率和经验过程界的验证）"requires explicit assumptions on smoothness, basis growth, and the covariate and risk-set distributions"，并未在本文中完成验证。

#### 证明路线与技术技巧

**整体路线**（以 Theorem 2 为例）：

1. **线性化**：将联合估计方程在真值处做 Taylor 展开，得到 \(\sqrt{n}(\hat{\vartheta}_\lambda - \vartheta_0) \approx A_\lambda^{-1} \sqrt{n} \Psi_n(\vartheta_0)\)。
2. **消去 nuisance**：利用分块矩阵求逆公式，将 \(\hat{\beta}_\lambda\) 的渐近协方差表示为 profiled 信息矩阵 \(P_\lambda\) 的逆加上一个修正项。
3. **比较**：将 \(V_\lambda\) 与 \(V_0 = (A - C D^{-1} C^\top)^{-1}\) 比较，证明差矩阵半正定。
4. **关键引理**：
   - **Lemma 2**：消去 \(\theta_Y\) 后，系统简化为 \((\beta, \theta_T)\) 的估计方程，其 Hessian 为 \(\tilde{A}_\lambda\)，得分协方差为 \(\tilde{B}_\lambda\)。
   - **Lemma 3**：\(K_\lambda \succeq 0\) 和 \(\Delta_\lambda \succeq 0\) 的矩阵不等式证明。这里用到了 \(E, G\) 的正定性以及 Schur 补的性质。
   - **Lemma 4**：\(A_\lambda\) 和 \(\tilde{A}_\lambda\) 的正定性证明，确保估计方程有唯一解。

**技术技巧点名**：
- **分块矩阵消元**：通过 Schur 补将三维参数 \((\beta, \theta_T, \theta_Y)\) 的问题约化为二维 \((\beta, \theta_T)\)，这是处理高维 nuisance 的标准技巧。
- **矩阵不等式链**：证明 \(V_\lambda \preceq V_0\) 的关键是构造两个矩阵不等式：(i) \(H_\lambda \succeq D\) 推出 \(P_\lambda^{-1} \preceq P_0^{-1}\)；(ii) \(\Delta_\lambda \succeq 0\) 推出修正项非负。这两步都用到了 Loewner 序在矩阵求逆下的反转性质。
- **局部渐近展开**：Theorem 3 使用局部 n^{-1/2} 邻域展开，将固定差异的偏差问题转化为对惩罚梯度的期望计算。
- **自适应选择的"oracle"论证**：Theorem 4 的证明依赖于"选择正确惩罚的概率趋于 1"这一事实，从而将自适应估计量的行为归结为固定惩罚估计量的行为。

#### 真实例子与应用

**模拟研究**（Section 4）：
- **设定**：\(X \sim \text{Unif}(-1, 1)\)，\(Z \sim \text{Bernoulli}(1/2)\)，事件时间服从 Cox 模型，辅助结局服从部分线性模型。样本量 \(n \in \{300, 600, 1200\}\)，删失率 30% 或 60%。
- **关键发现**：
  - 当 \(f_{Y0} = f_{T0}\) 时，固定惩罚 \(\lambda = 1\) 的相对效率（相对于单独估计）在 30% 删失时为 1.016（n=600），在 60% 删失时为 1.071（n=300）。增益随删失率增加而增大——因为删失越多，生存数据自身的信息越少，辅助信息的边际价值越大。
  - 当存在固定差异时（\(\delta = 0.30\)），\(\lambda = 1\) 的偏差为 -0.027，覆盖率降至 91.6%；自适应惩罚将平均惩罚降至 0.20，偏差降至 -0.010，覆盖率恢复至 93.9%。
  - 方向效应验证了 Theorem 3 的预测：与目标参数正交的差异方向不产生偏差，而与目标参数对齐的差异方向产生最大偏差。

**真实数据**（Section 5）：ACTG 175 试验，\(n = 2139\)，生存结局为复合事件（CD4 显著下降、进展至 AIDS 或死亡），辅助结局为 20 周 CD4 变化。单独估计的 log-hazard ratio 为 -0.689（SE 0.096），在 \(\lambda = 0.3\) 时 SE 降至 0.092（方差比 1.084），但点估计移动至 -0.667。自适应规则选择 \(\hat{\lambda} = 0\)（因为 \(\hat{D}_n = 0.795\) 远超阈值 \(\tau_n = 0.257\)），因此最终报告单独估计结果。这个例子说明：**自适应惩罚在实际数据中可能选择不借用**——当两个结局的基线效应差异较大时，借用信息的风险超过收益。

#### 🔎 结论是否比证明窄

需要指出的几个"证明窄于结论"之处：

1. **Theorem 5 的条件未验证**：作者在 Appendix C 中明确承认，增长 sieve 的理论（Theorem 5）依赖于 Assumptions 6-8，但这些条件"does not verify them for a particular spline basis"。这意味着本文的核心理论贡献（Theorem 2-4）严格来说只对**固定维 sieve** 成立，而实际实现中 K 必然随 n 增长。这是一个真实的 gap。

2. **效率增益的普适性**：Theorem 2 的结论 \(V_\lambda \preceq V_0\) 依赖于 Assumption 3（信息恒等式）和 Assumption 4（得分正交）。作者在 Lemma 1 中给出了 Assumption 4 的充分条件 \(E\{\varepsilon \, dM(t) \mid Z, X\} = 0\)，但这个条件在辅助结局与生存结局存在未观测混杂时可能不成立。作者在正文中没有讨论这一限制。

3. **自适应惩罚的"oracle"性质**：Theorem 4 的证明依赖于"选择正确惩罚的概率趋于 1"，但这是**逐点**收敛，不是**一致**收敛。在差异大小接近阈值 \(\tau_n\) 的中间区域，自适应惩罚的行为没有理论保证。作者在模拟中避开了这一区域。

4. **方差估计**：论文没有讨论如何估计 sandwich 协方差中的 nuisance 项（如 \(E, G, A, C, D\)），也没有给出标准误的收敛性证明。在模拟中，ASE 与 ESD 的匹配良好，但这只是经验证据。

### 四、开放问题

以下问题均扎根于论文的具体语句：

1. **增长 sieve 的严格理论**（扎根于 Appendix C："This appendix explains the high-level conditions used in Theorem 5. It does not verify them for a particular spline basis."）：能否为 B-spline 或其他的具体 sieve 基验证 Assumptions 6-8？特别是，sieve 逼近率与经验过程界的组合条件是否在 Cox 模型 + 部分线性模型的组合下成立？这是一个直接的技术 gap，适合有经验过程背景的研究者。

2. **自适应惩罚的中间区域行为**（扎根于 Theorem 4 的证明："These probability-one-in-the-limit selection statements also imply part (iii)"）：当差异大小 \(D_0\) 与阈值 \(\tau_n\) 同阶时，自适应惩罚的极限分布是什么？是否存在一个"过渡区域"，其中估计量既不是完全借用也不是完全不借用？这需要更精细的局部渐近分析。

3. **方差估计的稳健性**（扎根于 Section 5："Standard errors in this section use the full empirical sandwich covariance"）：当辅助结局的误差项存在异方差或自相关时，sandwich 协方差是否仍然有效？作者在 Assumption 3 中假设了条件同方差 \(E(\varepsilon^2 \mid Z, X) = \sigma_Y^2\)，但实际数据中这一假设可能不成立。能否推导出异方差稳健的方差公式？

4. **与半参数效率界的联系**（扎根于 Theorem 2 的公式 (34)）：本文的效率增益是否达到了半参数效率界？也就是说，是否存在一个"最优惩罚水平"\(\lambda^*\) 使得 \(V_{\lambda^*}\) 等于利用辅助信息后的半参数效率下界？作者没有讨论这个问题，但这是半参数效率理论的自然延伸。

5. **多源辅助信息的扩展**（扎根于 intro 中对外部信息工作的引用）：如果存在多个辅助结局（如多个生物标志物），惩罚结构应如何设计？是两两配对惩罚，还是引入一个联合惩罚项？这涉及到高维惩罚估计的计算与理论。

6. **删失机制的敏感性**（扎根于 Assumption 1 和条件独立删失假设）：如果删失依赖于辅助结局 Y（例如，Y 值异常的患者更可能失访），条件独立删失假设是否仍然合理？这需要引入删失机制模型，可能改变效率增益的结论。

**确认 gap 的方法建议**：要判断上述哪一条是真正的 gap，建议去读以下近期工作的 intro：(a) 关于"transfer learning for survival analysis"的 2023-2025 年文献；(b) 关于"penalized joint modeling"的 Biometrics/Statistics in Medicine 近期论文；(c) 关于"semiparametric efficiency with auxiliary data"的理论文献。如果这些文献都没有解决上述问题，那么它们就是值得投入的 gap。
