### 一、领域脉络与小综述

#### 这个方向是什么

本文所处的子方向是**基于家系数据的遗传力（heritability）与遗传相关（genetic correlation / coheritability）的统计推断**，其根本科学问题是：在无法进行随机化实验的人类群体中，如何利用亲属间的表型相似性，将表型方差分解为可遗传的加性遗传成分与不可遗传的环境成分，并进一步估计两个不同表型之间共享遗传基础的程度。该方向的成熟度较高——ACE 模型（加性遗传 A、共同环境 C、独特环境 E）自 20 世纪双生子研究以来就是标准框架，但本文针对的是**电子健康记录（EHR）这一新型数据源**，其特点是：样本量巨大、家系结构不完整且不规则、表型多为二元诊断或偏态连续指标、存在大量缺失。传统方法（正态 ACE 模型、结构方程模型）在计算上难以扩展到数十万家庭，且在二元表型下需要高维积分。本文试图填补的缺口是：**在 EHR 规模下，如何对混合类型（连续+二元）表型进行联合的遗传力与遗传相关估计，同时保持计算可行性和对分布假设的稳健性**。

#### 发展脉络（history）

- **奠基工作：ACE 模型与 Falconer 方法**。Byrd (2012) 的《Introduction to Quantitative Genetics》[1] 被引用为 ACE 模型参数估计的经典框架来源，文中明确指出三种传统估计路径：Falconer 矩估计、结构方程模型（SEM）、以及假设表型正态的似然方法。这一代方法的共同限制是：要么假设正态性（似然法），要么仅适用于连续表型（Falconer），要么在非正态或大规模数据下计算不可行（SEM）。
- **关键转折：GEE 框架的引入**。Arbet et al. (2017) [2] 提出了 GEE2 框架，将广义估计方程引入双生子研究，使得非正态分布（过离散计数、重尾连续）下的遗传力估计成为可能，且无需完整似然。这是本文最直接的"前驱"——本文明确说 Arbet 的方法"不适用于联合建模异构数据类型"，这正是本文的切入点。
- **并行脉络：基于 SNP 的遗传相关估计**。Bulik-Sullivan et al. (2015) [3] 的 cross-trait LD score regression 和 Lee et al. (2013) [5] 的基于 SNP 的遗传相关估计，代表了另一条不依赖家系、直接利用全基因组关联研究（GWAS）汇总统计量的路线。本文引用这些工作是为了说明：**基于家系的设计在 EHR 数据中仍有独特价值**，因为 GWAS 方法需要基因型数据，而 EHR 家系研究只需表型与亲属关系。
- **应用背景：精神与代谢疾病的共享遗传基础**。Wray et al. (2018) [4] 的重度抑郁症 GWAS 和 Gan et al. (2014) [6] 的抑郁-冠心病 meta 分析，为本文的真实数据应用提供了科学动机——精神疾病与代谢疾病之间的共病现象可能反映共享遗传结构。Park et al. (2023) [10] 的 500 万人代谢综合征多变量 GWAS 进一步强化了这一背景。
- **EHR 家系研究的直接先驱**：Polubriaginof et al. (2018) [9] 开发了 RIFTEHR 算法，从 EHR 急诊联系信息中重建家系关系，这是本文数据来源的技术基础。Jia et al. (2019) [13] 则展示了在无基因型数据条件下，仅凭 EHR 家系关系估计遗传力的可行性。

#### 子线索聚类

1. **传统家系遗传力估计**（[1], [8], [22]）：ACE 模型、Falconer 方法、SEM。核心是方差分解，假设表型正态或可转化为正态。
2. **稳健/非正态扩展**（[2], [23]）：GEE/GEE2 框架，放宽分布假设，但主要处理单表型。
3. **基于 SNP 的遗传相关**（[3], [5], [10]）：LD score regression、GREML 等，需要基因型数据，可扩展至大规模 GWAS 汇总统计。
4. **EHR 家系推断与应用**（[9], [13]）：从 EHR 中提取亲属关系，估计遗传参数，但此前仅限于单表型或同类型表型。

#### 这个方向在追问的核心问题

1. **如何在不假设正态性的前提下，对非正态表型（二元、计数、偏态）进行遗传力估计？** 主流解法是 GEE/矩估计，但代价是效率损失。
2. **如何联合估计多个表型的遗传相关，尤其是当表型类型不同（一连续一二元）时？** 似然方法需要高维积分，矩方法需要处理混合矩条件。
3. **如何在 EHR 这种"自然实验"数据中处理家系结构的不完整性和选择偏差？** 即：并非所有家庭成员都在 EHR 中，且进入 EHR 的概率可能与表型相关。
4. **计算可扩展性**：当家庭数达数万、表型数达数十时，如何避免 O(n³) 或更高阶的矩阵运算？

**已知瓶颈**：传统似然法在二元表型下需要数值积分，无法扩展到大规模 EHR；GEE2 虽稳健但仅限单表型；SNP 方法需要基因型数据，而 EHR 家系研究往往只有表型。本文的定位是：**用矩估计（GEE）框架统一处理混合类型表型，以计算效率换取似然效率，从而在 EHR 规模下实现联合估计**。

#### ⚠️ 作者的 framing（这是作者的说法）

作者将缺口 frame 为："现有方法要么假设正态性（NACE/SEM），要么仅适用于单表型（GEE2），要么需要基因型数据（LD score regression），**没有一种方法能在 EHR 规模下联合估计混合类型表型的遗传力与遗传相关**。" 因此本文提出的 MPCE 方法被定位为"显然的下一步"。被淡化的竞争路线包括：**基于 SNP 的遗传相关方法**（作者仅用一段话提及，强调其需要基因型数据，但未讨论其在大规模 GWAS 中的成熟度和可靠性）；**全似然贝叶斯方法**（如 MCMC 实现的 ACE 模型，作者完全未提及，尽管这类方法在小样本下可能更高效）。**值得去查的问题**：为什么作者没有考虑将 GEE2 扩展到多表型（而非重新设计矩条件）？为什么没有讨论矩估计在遗传相关接近边界时的有限样本偏差（作者在讨论部分承认了数值稳定性问题，但未给出理论解释）？

#### 张力

未见明显对立引用。但有一个值得注意的隐含张力：**基于家系的遗传力估计（本文路线）与基于 SNP 的遗传力估计（[3], [5] 路线）在数值上经常不一致**——前者通常估计的是"广义遗传力"（包含所有遗传效应），后者估计的是"SNP 遗传力"（仅常见变异捕获的部分）。本文未讨论这一差异，但真实数据结果（如肥胖-痴呆遗传相关 0.147）若与 GWAS 估计比较，需要谨慎解释。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

**符号清单**（逐个点名）：

| 符号 | 含义 | 类型 |
|------|------|------|
| $i = 1, \dots, n$ | 家系（family）索引 | 样本单位 |
| $j = 1, \dots, n_i$ | 家系 $i$ 内的成员索引 | 样本单位 |
| $k = 1, \dots, K$ | 表型（phenotype）索引 | 维度 |
| $Y_{ijk}$ | 第 $i$ 家系第 $j$ 个成员的第 $k$ 个**连续**表型 | 随机变量（可观测） |
| $Z_{ijk}$ | 第 $i$ 家系第 $j$ 个成员的第 $k$ 个**二元**表型，$Z_{ijk} = I(Y_{ijk} > 0)$ | 随机变量（可观测） |
| $X_{ijk}$ | 协变量向量（年龄、性别、种族等） | 可观测 |
| $\alpha_k$ | 表型 $k$ 的截距 | 参数 |
| $\beta_k$ | 表型 $k$ 的协变量效应向量 | 参数 |
| $b_i$ | 家系 $i$ 的共享环境效应（共同环境 C） | 潜在随机效应 |
| $\gamma_k$ | 表型 $k$ 对共享环境的载荷（$\gamma_1 = 1$ 为识别约束） | 参数 |
| $u_{ijk}$ | 家系 $i$ 成员 $j$ 表型 $k$ 的**加性遗传效应** | 潜在随机效应 |
| $\epsilon_{ijk}$ | 独特环境 + 测量误差（E） | 潜在随机效应 |
| $\sigma_k^2$ | $\text{Var}(u_{ijk})$，表型 $k$ 的加性遗传方差 | 参数（目标） |
| $\rho_{km}$ | 表型 $k$ 与 $m$ 的遗传相关系数 | 参数（目标） |
| $\sigma_b^2$ | $\text{Var}(b_i)$，共享环境方差 | 参数 |
| $\sigma_{\epsilon k}^2$ | $\text{Var}(\epsilon_{ijk})$，独特环境方差 | 参数 |
| $C_i = (c_{ijs})$ | 家系 $i$ 的亲缘系数矩阵（kinship matrix），$c_{ijs}$ 为成员 $j,s$ 的亲缘系数 | 已知常数 |
| $\Sigma$ | $K \times K$ 遗传协方差矩阵，$[\Sigma]_{km} = \rho_{km}\sigma_k\sigma_m$ | 参数 |
| $\theta$ | 所有方差/协方差参数的集合 | 参数 |
| $h_k^2$ | 表型 $k$ 的遗传力，$h_k^2 = \sigma_k^2 / (\sigma_k^2 + \sigma_b^2 + \sigma_{\epsilon k}^2)$ | 导出量 |
| $h_{km}^2$ | 表型 $k,m$ 的共遗传力，$h_{km}^2 = \rho_{km} h_k h_m$ | 导出量 |

**模型**（以连续表型为例，式 1）：

$$Y_{ijk} = \alpha_k + \beta_k^T X_{ijk} + \gamma_k b_i + u_{ijk} + \epsilon_{ijk}$$

- $b_i \sim N(0, \sigma_b^2)$：家系共享环境，对家系内所有成员、所有表型共同作用（通过载荷 $\gamma_k$ 区分影响大小）。
- $u_{ijk}$：加性遗传效应，其协方差结构为 $\text{cov}(u_{ijk}, u_{ism}) = c_{ijs} [\Sigma]_{km}$。即：同一家系内，亲缘系数为 $c_{ijs}$ 的两个成员，其遗传效应的协方差等于亲缘系数乘以对应表型的遗传协方差。**这是遗传力估计的核心识别来源**。
- $\epsilon_{ijk} \sim N(0, \sigma_{\epsilon k}^2)$：独特环境，独立于所有其他项。

**可观测数据**：$\{(X_{ijk}, Y_{ijk})\}$ 或 $\{(X_{ijk}, Z_{ijk})\}$，加上已知的亲缘系数矩阵 $C_i$。**不可观测**：$b_i, u_{ijk}, \epsilon_{ijk}$ 以及潜在的连续表型 $Y_{ijk}$（当观测到的是二元 $Z_{ijk}$ 时）。

**识别逻辑**（一句话）：亲属间表型协方差 = 亲缘系数 × 遗传协方差 + 共享环境协方差。通过比较不同亲缘关系（如亲子的 $c=1/2$、配偶的 $c=0$）的表型协方差，可以分离遗传与环境贡献。

#### 第二步：最小内核

**最小特例**：$K=1$（单一表型）、$n_i=4$（父母+两个孩子）、无协变量、连续表型、无共享环境（$\sigma_b^2 = 0$）。

此时模型退化为：

$$Y_{ij} = \alpha + u_{ij} + \epsilon_{ij}, \quad \text{cov}(u_{ij}, u_{is}) = c_{ijs} \sigma_1^2$$

**要估计的参数**：$\theta = (\sigma_1^2, \sigma_{\epsilon 1}^2)$，目标 $h_1^2 = \sigma_1^2 / (\sigma_1^2 + \sigma_{\epsilon 1}^2)$。

**可用的矩条件**（从观测数据计算）：

| 矩 | 期望值 |
|----|--------|
| $\text{Var}(Y_{ij})$ | $\sigma_1^2 + \sigma_{\epsilon 1}^2$ |
| $\text{Cov}(Y_{ij}, Y_{is})$，$j,s$ 为亲子或同胞（$c=1/2$） | $\frac{1}{2}\sigma_1^2$ |
| $\text{Cov}(Y_{ij}, Y_{is})$，$j,s$ 为配偶（$c=0$） | $0$ |

**核心思想**：用样本矩（如家系内成员表型方差的平均值、亲子/同胞表型协方差的平均值）代入上述等式，解出 $\sigma_1^2$ 和 $\sigma_{\epsilon 1}^2$。这就是一个**矩估计**（method of moments）——不需要假设表型正态，只需要协方差结构正确。当 $K=2$ 且涉及二元表型时，核心困难在于：二元表型的方差和协方差不能直接观测，需要通过潜在连续变量 $Y$ 的矩来间接估计，而 $Y$ 的矩又需要通过观测到的二元 $Z$ 的联合概率来反推。这就是本文算法 2 中"用条件期望替换潜在变量"的步骤——本质上是用 EM 算法或矩条件迭代求解。

**为什么这个内核是"最小"的**：它抓住了整篇论文的数学本质——**用可观测的家族内表型协方差，通过矩条件反解遗传方差成分**。所有额外的复杂性（多表型、二元表型、缺失数据、协变量、加权）都是在这个内核上"加壳"。

**证明的关键**：在一般 $K$ 表型、混合类型、缺失数据下，矩条件 $V(\theta) = \widehat{\text{cov}}(Y)$ 是一个非线性方程组。作者证明其可解性的思路是：将方程组转化为最小化一个凸目标函数（如附录 A 中的加权最小二乘形式），从而保证数值解的存在性。但作者**没有**给出估计量的渐近正态性证明，只通过 bootstrap 提供推断——这是本文理论上的一个薄弱环节（见第四节）。


### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：在 EHR 家系数据中，如何对混合类型（连续+二元）表型对，联合估计遗传力与遗传相关（共heritability），同时处理大规模家系、缺失成员和协变量。
2. **核心方法**：提出 MPCE（Multi-type Phenotype Co-inheritance Estimation）框架，基于多水平潜变量模型，将表型协方差分解为遗传、共享环境、独特环境三部分，用广义估计方程（GEE）的矩条件迭代估计参数，避免高维积分。
3. **主要结论**：模拟实验表明估计量具有一致性且覆盖率达到名义水平；应用于哥伦比亚大学医学中心的 4 万+ 核家系 EHR 数据，发现肥胖与痴呆（0.147）、肥胖与帕金森病（0.147）、2 型糖尿病与痴呆（0.187）等存在显著正遗传相关，支持精神/神经疾病与代谢疾病共享遗传基础的假说。

#### 关键设定与假设

在第二节最小记号基础上，完整设定如下：

- **模型结构**（式 1）：连续表型 $Y_{ijk}$ 服从线性混合模型；二元表型 $Z_{ijk}$ 通过潜在变量 $Y_{ijk}$ 的阈值模型定义（$Z = I(Y > 0)$）。所有表型共享同一个家系水平随机效应 $b_i$（共享环境）和各自的遗传效应 $u_{ijk}$。
- **协方差结构**：
  - 遗传效应：$\text{cov}(u_{ijk}, u_{ism}) = c_{ijs} [\Sigma]_{km}$，其中 $c_{ijs}$ 为亲缘系数，$\Sigma$ 为 $K \times K$ 遗传协方差矩阵。
  - 共享环境：$\text{cov}(\gamma_k b_i, \gamma_m b_i) = \gamma_k \gamma_m \sigma_b^2$，对家系内所有成员相同。
  - 独特环境：$\text{cov}(\epsilon_{ijk}, \epsilon_{ism}) = 0$ 除非 $(j,k) = (s,m)$。
- **识别约束**：$\gamma_1 = 1$（固定第一个表型的共享环境载荷为 1），否则模型不可识别（共享环境与遗传效应可交换）。
- **缺失数据处理**：允许家系成员缺失，通过"成对完整观测"（pairwise complete observations）构造矩条件，并用逆概率加权（IPW）校正缺失偏差。IPW 权重基于年龄、性别、种族、共病指数（CCI）和邮政编码区域拟合多项 logit 模型得到。
- **分布假设**：潜在变量 $Y$ 在给定随机效应下服从多元正态。这是一个强假设——虽然矩估计本身不依赖正态性，但**二元表型的矩条件计算（即 $E[Y|Z]$ 的解析表达式）依赖正态性**。如果潜在变量非正态，矩条件将不成立。

**相比已有文献的放宽/强化**：
- 放宽了 Arbet et al. (2017) [2] 的单表型限制，允许 $K \geq 2$ 且类型混合。
- 放宽了正态 ACE 模型的分布假设（对连续表型部分），用矩估计替代似然。
- 但**强化**了潜在变量正态性假设（对二元表型部分），且**未提供**渐近理论（无一致性证明、无收敛速率），仅依赖 bootstrap 推断。

#### 主要结果

**模拟实验**（Section 3）：
- 设定：$K=2$，核家系 4 人（父母+2 子女），亲缘系数矩阵如附录 A 所示。四种参数组合覆盖 (高,高,低)、(高,低,低)、(低,低,低)、(高,高,高) 的遗传力与遗传相关。
- 结果：所有参数的估计中位数接近真值；随着家系数从 500 增至 1000，RMSE 平均下降约 28%（连续）、34.2%（二元）、24%（混合）。bootstrap 覆盖率在 0.90–0.98 之间，但 $\rho_{12}$ 在接近边界（如 0.6）时覆盖率偏高（接近 1），作者归因于数值求解的边界问题。
- 与单表型分析的比较：联合分析（integrated）相比分别分析（separated），遗传力估计的 RMSE 改善约 7–15%（连续）、0–13%（二元），但 $\beta$ 的 RMSE 无一致改善。

**真实数据**（Section 4）：
- 数据：哥伦比亚大学医学中心 EHR，40,666 个核家系，129,322 名患者。12 个二元表型（精神/神经疾病）和 6 个连续表型（代谢/内分泌指标），72 个表型对。
- 主要发现：
  - 肥胖-痴呆遗传相关 0.147（95% CI: 0.083–0.228），肥胖-帕金森病 0.118（0.062–0.186），2 型糖尿病-痴呆 0.187（0.147–0.227），2 型糖尿病-帕金森病 0.135（0.062–0.186）。
  - 精神分裂症-2 型糖尿病遗传相关 0.217（0.174–0.257），精神分裂症-肥胖 0.452（0.275–0.743，宽区间）。
  - 与文献一致：作者指出这些结果与 Charisis et al. (2023) [14]（肥胖影响阿尔茨海默病相关基因表达）和 Baranova et al. (2023) [12]（精神分裂症-2 型糖尿病遗传相关）一致。
  - 但作者也承认：精神分裂症-肥胖的遗传相关 0.452 与 Baranova et al. 报道的精神分裂症-2 型糖尿病负相关（-0.16）方向相反，作者将其归因于表型定义差异（EHR 二元诊断 vs. GWAS 临床诊断）和家系 vs. 人群样本差异。

#### 证明路线与技术技巧

**整体路线**（以连续表型为例，算法 1）：

1. **去均值**：用 OLS 回归 $Y$ 对 $X$ 得到残差，消除固定效应 $\beta$ 的影响。
2. **构造样本协方差矩阵**：对每个家系 $i$，计算残差向量的外积 $r_i r_i^T$，然后对所有家系取平均，得到 $\widehat{\text{cov}}(Y)$ 的估计。
3. **建立矩方程**：将理论协方差 $V(\theta)$（由模型结构推导出的关于 $\theta$ 的函数）与样本协方差 $\widehat{\text{cov}}(Y)$ 相等，得到非线性方程组。
4. **求解**：将方程组转化为最小化目标函数 $f(\theta) = \|V(\theta) - \widehat{\text{cov}}(Y)\|^2$（加权最小二乘形式），用数值优化（如 Nelder-Mead 或 BFGS）求解。

**关键技巧**：

- **成对协方差分解**：将 $V(\theta)$ 分解为三部分——遗传（$\Sigma \otimes C_i$）、共享环境（$\sigma_b^2 (\gamma\gamma^T) \otimes J J^T$）、独特环境（对角阵）。这种分解使得矩方程可以逐元素写出，便于求解。
- **二元表型的条件期望替换**（算法 2）：对于二元表型，观测到的是 $Z$ 而非 $Y$。作者用条件期望 $E[Y_{ijk}|Z_{ijk}, X_{ijk}, \beta, \theta]$ 和 $E[Y_{ijk}Y_{ism}|Z_{ijk}, Z_{ism}, X, \beta, \theta]$ 替换潜在变量 $Y$ 的矩。这些条件期望有解析表达式（基于截断正态分布），从而避免了高维积分。这是本文最核心的技术贡献——**将二元表型的似然积分问题转化为一维/二维截断正态矩计算**。
- **IPW 加权**：对缺失数据，用逆概率权重加权矩条件，权重由观测概率的 logistic 模型估计。这保证了在"可忽略缺失"（missing at random）假设下的一致性。
- **Bootstrap 推断**：采用家系级 bootstrap（resample families，而非个体），以保留家系内相关性结构。

**技术难点与作者的解法**：

| 难点 | 解法 |
|------|------|
| 二元表型的似然涉及高维积分 | 用条件期望替换，转化为截断正态矩计算（最多二维积分） |
| 大规模数据下协方差矩阵维度高 | 利用家系结构的稀疏性，逐家系计算外积再累加 |
| 矩方程可能无解析解 | 转化为最小化问题，数值求解 |
| 缺失数据导致矩条件有偏 | IPW 加权 |
| 遗传相关接近边界时数值不稳定 | 作者承认存在此问题，但未给出理论解决方案（仅建议用更多 bootstrap 样本） |

#### 🔎 结论是否比证明窄

**是，存在多处"证明窄于结论"的情况**：

1. **一致性证明缺失**：作者在摘要和引言中声称估计量"一致"（consistent），但正文中**没有**给出任何一致性定理或证明。模拟实验只展示了有限样本下的中位数接近真值，这不能替代渐近理论。作者在讨论部分也未提及这一缺失。
2. **二元表型的矩条件依赖正态性假设**：作者在方法部分假设潜在变量 $Y$ 正态，但未讨论该假设违反时的后果。模拟实验只覆盖了正态潜在变量情形。结论中"对分布假设稳健"的说法（摘要）与这一未检验的假设之间存在张力。
3. **IPW 的一致性条件未验证**：作者假设缺失机制是可忽略的（MAR），但未检验 EHR 数据中缺失是否满足 MAR。EHR 数据中，缺失可能与疾病严重程度相关（例如，病情重的患者更可能有多条记录），这可能导致 MNAR（不可忽略缺失），使 IPW 失效。
4. **bootstrap 覆盖率的边界问题**：作者承认 $\rho$ 接近边界时覆盖率偏高（接近 1），但未解释这是否意味着检验的保守性（conservativeness）还是估计量的有限样本偏差。这直接影响真实数据中"显著遗传相关"的解读。
5. **真实数据结果的因果解读**：作者在讨论中暗示遗传相关支持"共享病因假说"，但遗传相关本身不蕴含因果关系——它只反映加性遗传效应的协方差，不排除连锁不平衡、群体分层或选择偏差的贡献。作者未对此加以限定。

### 四、开放问题

以下问题均扎根于本文的具体语句或缺失，**只罗列、不判断可行性**：

1. **渐近理论缺失**（扎根于：全文无任何定理陈述，仅依赖模拟和 bootstrap）。要证明什么：在 $n \to \infty$、家系大小有界或缓慢增长时，MPCE 估计量是否 $\sqrt{n}$-一致且渐近正态？其渐近方差是否达到半参数效率界（即矩估计是否有效率损失）？这个问题直接关系到方法能否推广到更大规模的 EHR 数据（如 UK Biobank，作者在讨论中提及但未展开）。

2. **二元表型潜在变量正态性假设的稳健性**（扎根于：Section 2.2 中条件期望的计算依赖正态性）。要研究什么：当潜在变量服从 $t$ 分布、混合正态或偏态分布时，矩条件是否仍然近似成立？估计量的偏差有多大？是否存在对分布假设更稳健的矩条件（如基于秩或 U-statistic 的版本）？

3. **缺失机制的敏感性**（扎根于：Section 2.2 中 IPW 的使用，但未讨论 MNAR）。要研究什么：当缺失与潜在表型相关（MNAR）时，IPW 估计的偏差方向与大小？能否用双稳健估计（doubly robust）或基于工具变量的方法校正？

4. **遗传相关接近边界时的推断**（扎根于：作者承认 $\rho$ 接近 1 时 bootstrap 覆盖率偏高）。要研究什么：是否存在参数变换（如 Fisher z 变换）或重参数化使得边界附近的推断更可靠？能否构造基于得分检验（score test）的假设检验以避免估计边界参数？

5. **与 SNP 遗传相关的整合**（扎根于：引言中提及 GWAS 方法但未深入）。要研究什么：MPCE 估计的家系遗传相关与 LD score regression 估计的 SNP 遗传相关在 EHR 数据中是否一致？差异是否反映"缺失遗传力"（missing heritability）或家系数据的特殊偏差（如选择偏差、亲属环境共享）？

6. **计算复杂度与扩展性**（扎根于：算法 1 和 2 中逐家系计算外积，但未给出复杂度分析）。要研究什么：当表型数 $K$ 从 2 增至 10 或 20 时，矩方程的数量（$O(K^2)$）和求解难度如何增长？是否存在利用稀疏结构的更高效算法？
