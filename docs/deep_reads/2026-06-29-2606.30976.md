# Residual-on-Residual Regression as a Tool for Effect Estimation in Observational Data

**作者**: Ashley I. Naimi, Qianhui Jin, Ya-Hui Yu, Sara M. Parisi, Lisa M. Bodnar  
**主题**: 因果推断  
**相关性**: 8/10  
**链接**: <https://arxiv.org/abs/2606.30976>

### 一、领域脉络与小综述

- **这个方向是什么**：本文属于"用机器学习做因果效应估计"这一子方向，核心问题是：在高维混杂调整下，如何稳健地估计暴露对结局的平均效应。该方向已相当成熟，形成了以 AIPW 和 TMLE 为代表的"双稳健"估计框架，其理论基础是半参数效率理论——通过 Neyman 正交化构造对一阶 nuisance 估计误差不敏感的估计方程，从而允许用灵活的机器学习方法估计 nuisance 函数而不破坏根号 n 收敛与渐近正态性。当前 frontier 在于处理实际数据中的"非理想"条件：弱阳性违背、nuisance 估计不稳定、以及效应异质性下的估计目标解释。

- **发展脉络（history）**：
  - **奠基工作**：Robinson (1988) 提出残差对残差回归，证明在部分线性模型下，用非参数方法估计两个 nuisance 回归后做 OLS 可以得到根号 n 一致且渐近正态的暴露效应估计。这是本文方法论的直接源头，也是半参数估计中"partialling-out"思想的经典表述。
  - **主要进展**：AIPW（Robins & Greenland, 1994）和 TMLE（van der Laan, 2006）将半参数效率理论推向实用化，通过构造 Neyman 正交得分或目标化扰动步骤，获得双稳健性质——即暴露模型或结局模型之一正确指定时估计仍一致。Kennedy (2022) 的综述系统梳理了这一框架，强调其与半参数效率界的联系。Chernozhukov et al. (2018) 的 DML 框架进一步将交叉拟合与 Neyman 正交性结合，放宽了对 nuisance 估计收敛速率的要求。
  - **当前 frontier**：Yadlowsky (2022) 用高维渐近理论解释了为何 AIPW 和 TMLE 在实际数据中表现不同——在 d 与 n 同阶时，两者的方差结构出现分化。Lal & Chou (2025) 则揭示了残差回归在效应异质性下的估计目标问题：它估计的不是 ATE，而是条件方差加权的平均效应。本文正是在这一脉络中，将残差回归重新定位为 AIPW/TMLE 的"稳定替代方案"，并系统评估其在弱阳性违背下的表现。

- **子线索聚类**：
  - **半参数效率理论**：Kennedy (2022)、Tsiatis (2006)、Chen et al. (2026)——为双稳健估计提供理论框架，核心是效率界与 Neyman 正交性。
  - **机器学习 + 因果推断的实践问题**：Naimi et al. (2017)、Zivich & Breskin (2021)、Díaz (2019)——关注机器学习估计 nuisance 时的偏差、交叉拟合的必要性、以及实际应用中的稳定性问题。
  - **估计目标与解释**：Lal & Chou (2025)、Vansteelandt & Dukes (2020)——讨论在模型误指定或效应异质性下，不同估计量收敛到何种总体量，以及如何解释。
  - **阳性假设与极端权重**：Petersen et al. (2010)、Westreich & Cole (2010)、Rudolph et al. (2022)——专门研究阳性违背的诊断与应对，是本文实证部分的直接对标。

- **这个方向在追问的核心问题**：
  1. 如何在 nuisance 估计不完美时仍获得根号 n 一致的效应估计？（答案：Neyman 正交化 + 交叉拟合）
  2. 当阳性假设被违背时，双稳健估计量是否仍然可靠？（本文的核心问题）
  3. 当效应异质性存在时，不同估计量究竟估计了什么总体量？（Lal & Chou 的贡献）
  4. 在有限样本下，理论上等价的估计量为何表现不同？（Yadlowsky 的高维渐近解释）

- **⚠️ 作者的 framing（这是作者的说法）**：作者将缺口 frame 为"AIPW 和 TMLE 在弱阳性违背下不稳定，残差回归提供了更稳定的替代"。具体来说，作者声称：(i) 残差回归通过避免显式逆概率加权，天然对极端倾向得分不敏感；(ii) 在效应近似恒定时，残差回归与 AIPW/TMLE 估计同一参数，但有限样本表现更稳健；(iii) 因此残差回归应作为三角验证（triangulation）策略的一部分。**被淡化或回避的**：Lal & Chou (2025) 明确指出残差回归在效应异质性下不估计 ATE，作者仅在讨论部分承认这一点，但未深入讨论其实际后果；此外，作者未提及残差回归在暴露为连续变量时的解释问题（此时估计的是方差加权平均导数，而非均匀平均效应）。**值得去查的问题**：为什么作者没有引用 Yadlowsky (2022) 的高维渐近框架来解释 AIPW 的不稳定性？该框架是否能为残差回归的稳定性提供更系统的理论解释？

- **张力**：未见明显对立引用。但存在一个微妙的张力：Lal & Chou (2025) 将残差回归的方差加权解释视为"缺陷"（因为它偏离 ATE），而本文将其视为"特性"（因为它带来稳定性）。这两种立场在"什么才是好的估计目标"上有实质分歧，值得研究者注意。


### 二、最核心、最简单的例子 / 数学问题

**第一步：符号、模型、可观测数据**

设观测数据为 i.i.d. 样本 `{O_i = (Y_i, A_i, W_i), i = 1, ..., n}`，其中：

- **Y**：结局变量（本文中为二值：先兆子痫发生与否）
- **A**：暴露变量（本文中为二值：高蔬菜摄入密度 ≥1.25 cups/1000 kcal）
- **W = (W₁, ..., W_p)**：混杂向量（本文中 p 较大，包含社会人口学、行为、医疗、邻里等多维变量）

**参数 / 估计目标**：
- **ψ**（本文核心 estimand）：部分线性模型中的暴露系数，定义为 `Y = ψA + g(W) + ε`，其中 `g(·)` 为未知非参数函数，`E[ε|A, W] = 0`。在效应恒定假设下，ψ 等于 ATE。
- **µ(A, W) = E[Y|A, W]**：结局回归（nuisance 1）
- **π(W) = P(A = 1|W)**：倾向得分（nuisance 2）
- **ν(W) = E[Y|W]**：结局对混杂的边际回归（nuisance 3，残差回归特有）
- **η(W) = E[A|W]**：暴露对混杂的回归（nuisance 4，残差回归特有）

**可观测数据**：研究者能观测到 `(Y_i, A_i, W_i)` 的完整实现。**不可观测**：潜在结果 `Y_i(1)` 和 `Y_i(0)`（同一单位在两种暴露水平下的结局），以及个体效应 `θ_i = Y_i(1) - Y_i(0)`。因果推断依赖标准识别假设：无未测量混杂（`Y(a) ⊥ A | W`）、一致性（`Y = A·Y(1) + (1-A)·Y(0)`）、阳性（`0 < π(W) < 1`）。

**第二步：最小内核**

本文方法的核心是一个三步骤程序，其本质是 Robinson (1988) 的 partialling-out 思想：

1. **拟合 nuisance**：用机器学习（本文为 Super Learner）分别估计 `ν(W) = E[Y|W]` 和 `η(W) = E[A|W]`，得到预测值 `ν̂(W)` 和 `η̂(W)`。
2. **构造残差**：计算 `Ỹ = Y - ν̂(W)`（结局残差）和 `Ã = A - η̂(W)`（暴露残差）。
3. **残差回归**：做无截距 OLS，将 `Ỹ` 对 `Ã` 回归，得到 `ψ̂`。

**为什么这个程序有效？** 关键洞察是：在部分线性模型 `Y = ψA + g(W) + ε` 下，对两边取条件期望并相减，得到：

```
Y - E[Y|W] = ψ(A - E[A|W]) + ε
```

因为 `E[Y|W] = ψE[A|W] + g(W)`，所以 `g(W)` 被消掉了。这意味着**不需要估计 g(W)**——无论 g 多么复杂，只要 `ν(W)` 和 `η(W)` 被一致估计，残差回归就能恢复 ψ。这就是"部分线性"的含义：暴露的效应是线性的，但混杂的影响可以完全非参数。

**最小例子**：设 `W ~ Uniform(-1, 1)`，`A ~ Bernoulli(logit(-0.3 + 1.5W))`，`Y = 0.5A + 2W² + ε`（注意 g(W) = 2W² 是非线性的）。若直接用线性回归 `Y ~ A + W`，会因遗漏 W² 项而产生偏倚。但残差回归的做法是：先用灵活模型（如样条或随机森林）估计 `E[Y|W]` 和 `E[A|W]`，然后对残差做 OLS。由于 `E[Y|W] = 0.5E[A|W] + 2W²`，残差 `Y - E[Y|W] = 0.5(A - E[A|W]) + ε`，OLS 系数一致估计 0.5。

**与 AIPW/TMLE 的关键区别**：AIPW 和 TMLE 都显式构造逆概率权重 `1/π̂(W)` 或 `1/(1-π̂(W))`，当某些协变量组合下 π̂(W) 接近 0 或 1 时，这些权重爆炸，导致估计量方差剧增。残差回归完全不涉及概率的倒数，而是通过残差化"隐式"地调整混杂，因此对弱阳性违背天然更稳健。这是本文的核心主张，也是其模拟实验的重点验证对象。


### 三、这篇论文做了什么

**三句话**：
1. **研究了什么问题**：在高维混杂调整的观察性研究中，AIPW 和 TMLE 在弱阳性违背下可能不稳定，本文评估残差对残差回归（Robinson 估计量）作为替代方案的有限样本表现。
2. **核心工具 / 方法**：将残差对残差回归（部分线性模型下的 partialling-out 估计）与 AIPW、TMLE 并列，在 nuMoM2b 队列数据（n=7,923）和 Monte Carlo 模拟中系统比较偏差、方差、置信区间覆盖率和计算稳定性。
3. **主要结论**：在暴露效应近似恒定且存在弱阳性违背时，残差回归无偏、覆盖接近名义水平，表现优于 AIPW 和 TMLE，且显著优于误设的参数模型；在 nuMoM2b 数据中三者结论一致，支持高蔬菜摄入密度与先兆子痫风险适度降低的关联。

**关键设定与假设**：
- **部分线性模型**（公式 2）：`Y = ψA + g(W) + ε`。这是残差回归的核心假设——暴露效应恒定（无 A×W 交互），且暴露进入模型是线性的。作者在讨论中承认，若效应异质性存在，残差回归估计的是方差加权平均而非 ATE。
- **nuisance 估计**：所有方法共用同一 Super Learner 库（4 个 GLM 变体），10 折交叉拟合。这保证了比较的公平性——差异来自估计策略而非 nuisance 质量。
- **阳性假设**：主模拟中通过调节倾向得分函数的系数 ζ 制造不同程度的阳性违背，ζ=6 时约 30% 样本的真实倾向得分落在 [0.05, 0.95] 之外。
- **识别假设**：无未测量混杂、一致性、 positivity（理论要求，但实证部分正是要检验其违背时的表现）。

**主要结果**：
- **主模拟（效应恒定）**：残差回归在所有 ζ 水平下偏差 < 0.02，覆盖 93-94%；AIPW 在 ζ≥4 时 RMSE 急剧上升（从 0.12 到 0.46），SE 比降至 0.71，表明方差估计严重低估；TMLE 表现居中，但在 ζ=6 时覆盖降至 88.7%。误设的线性 OLS 在所有场景下偏差显著。
- **nuisance 质量诊断**：作者记录了 Super Learner 对各 nuisance 的交叉验证损失，显示在 ζ 增大时，倾向得分模型的估计不确定性增大，但残差回归对此不敏感。
- **实证应用**：三者均估计出负向关联（高蔬菜摄入与先兆子痫风险降低），残差回归点估计 -1.49/100（95% CI: -2.94, -0.03），AIPW 和 TMLE 的置信区间更宽且包含零。作者将此解读为"三角验证"的成功案例——点估计一致，但残差回归提供了更精确的推断。

**证明路线与技术技巧**：
- 本文是应用导向，无新定理证明。其"证明"依赖两条路径：
  1. **理论引用**：Robinson (1988) 的根号 n 一致性与渐近正态性；Chernozhukov et al. (2018) 的 DML 框架保证交叉拟合下 nuisance 估计误差的一阶不敏感性；Lal & Chou (2025) 对异质性下概率极限的刻画。
  2. **模拟验证**：10,000 次 Monte Carlo 重复，共享随机种子（common random numbers）以降低跨场景比较的 Monte Carlo 噪声。这是本文的主要"证据"。
- **技术技巧**：
  - **交叉拟合**：所有 nuisance 用 5 折交叉拟合，避免过拟合导致的偏差。
  - **Super Learner**：用交叉验证加权组合 4 个 GLM 变体，保证 nuisance 估计的灵活性。
  - **HC3 稳健标准误**：残差回归使用 HC3 而非经典 OLS 标准误，以应对可能的异方差。
  - **共同随机数**：跨 ζ 场景共享随机种子，使性能差异可归因于场景而非抽样噪声。

**真实例子与应用**：
- **数据**：nuMoM2b 队列，n=7,923 名初产妇，暴露为高蔬菜摄入密度（≥1.25 cups/1000 kcal，25.8%），结局为先兆子痫（8.6%）。
- **混杂集**：包含社会人口学（年龄、教育、种族、婚姻状况、保险）、行为（吸烟、饮酒、体力活动）、医疗（慢性高血压、糖尿病、孕前 BMI）、心理（抑郁评分）、邻里（贫困率、步行性）等多维变量，符合"高维混杂调整"的场景设定。
- **分析**：10 折交叉拟合 Super Learner 估计三个 nuisance（π, µ, ν），然后分别用残差回归、AIPW、TMLE 估计风险差。结果一致性支持结论稳健性，但作者谨慎地将其定位为"关联"而非"因果"。

**🔎 结论是否比证明窄**：
- **明确承认的局限**：作者在讨论中承认，残差回归在效应异质性下不估计 ATE（引用 Lal & Chou 2025），且模拟仅覆盖了"效应恒定"的场景。因此，"残差回归优于 AIPW/TMLE"的结论严格限于效应近似恒定的设定。
- **未明确承认的窄处**：
  1. 模拟中 nuisance 估计仅用 GLM 变体，未测试树模型、神经网络等更灵活的估计器。作者声称残差回归对 nuisance 质量不敏感，但这一结论可能依赖于 GLM 族的特定结构。
  2. 阳性违背仅通过单一机制（强化 W₂ 的系数）诱导，未测试其他违背模式（如协变量支撑不重叠）。
  3. 作者未讨论残差回归在暴露为连续变量时的行为，尽管 Lal & Chou 已指出此时问题更复杂。
  4. 实证分析中未报告 positivity 的诊断统计量（如倾向得分分布的重叠程度），读者无法判断"弱阳性违背"在真实数据中的严重程度。


### 四、开放问题（点到为止，扎根具体语句）

1. **效应异质性下的估计目标**：作者承认"残差回归在效应异质性下估计的是方差加权平均而非 ATE"（讨论部分，引用 Lal & Chou 2025），但未给出实际偏离程度的量化。要确认这是否为真 gap，可读 Lal & Chou 原文及近期 DML 文献——若多篇独立指出同一问题，则为共识性 gap。

2. **nuisance 估计器族的外推性**：模拟仅用 4 个 GLM 变体作为 Super Learner 库。作者声称残差回归"对 nuisance 估计质量不敏感"，但这一结论是否在树模型、神经网络等非光滑估计器下成立？可查 Zivich & Breskin (2021) 的模拟——他们发现交叉拟合对高复杂度 nuisance 尤为重要。

3. **阳性违背的多样性与诊断**：模拟仅通过单一机制诱导弱阳性。作者引用了 Petersen et al. (2010) 的 positivity 诊断框架，但未在实证分析中实施。一个具体可做的方向：将 Petersen 的 bootstrap 诊断方法应用于 nuMoM2b 数据，量化实际违背程度，并检验残差回归在更真实的违背模式下的表现。

4. **连续暴露的扩展**：作者在讨论中提及"对于连续暴露，残差回归的估计目标更复杂"（基于 Lal & Chou 的连续剂量分析），但未展开。这是一个明确的开放问题：在剂量-反应关系中，残差回归估计的方差加权平均导数如何解释？是否需要新的估计目标定义？

5. **与高维渐近理论的衔接**：Yadlowsky (2022) 用 d ~ n 的高维框架解释了 AIPW 与 TMLE 的差异，但本文未引用。一个值得探索的问题：残差回归在高维渐近框架下是否具有更优的有限样本性质？这需要将随机矩阵理论工具（研究者熟悉的方向）引入因果估计的比较分析。
