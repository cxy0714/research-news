### 一、领域脉络与小综述

#### 这个方向是什么

本文所处的子方向是 **bootstrap 条件一致性（conditional consistency of the bootstrap）**。其根本的统计问题是：当我们关心的推断对象是"给定某个共同冲击（common shock）的条件分布"时（例如给定一个观测到的网络结构、一个共同的宏观冲击、或一个未观测的环境变量），重抽样方法（bootstrap）能否在条件意义下提供有效的近似？经典 bootstrap 一致性关注的是无条件分布的重抽样逼近，而这里要求的是：对几乎所有的冲击实现，重抽样统计量的条件分布（给定冲击和数据）与原始统计量给定冲击的条件分布之间的 Kolmogorov 距离趋于零。这个子方向的核心困难在于：条件分布本身是随机的（依赖于冲击），因此"收敛"必须在几乎必然意义下定义，且允许条件 σ-代数随样本量变化。

该方向的成熟度属于**中等偏理论**：已有经典结果（Belyaev and Sjöstedt-De Luna, 2000; Berti et al., 2006; van der Vaart and Wellner, 2023）建立了随机概率测度收敛的基本框架，但将这些工具系统性地应用于 bootstrap 条件一致性、并给出有限样本覆盖误差界的工作尚不多见。本文试图填补这一空白。

#### 发展脉络（history）

**奠基工作**：该方向的理论根基来自两个独立脉络。一是 **merging of probability measures**（D'Aristotile et al., 1988; Davydov and Rotar, 2009），它研究两个概率测度序列在何种意义下"渐近不可区分"，且不要求存在共同的极限对象——这正是本文处理"比较分布随 n 变化"场景的框架。二是 **随机概率测度的几乎必然弱收敛**（Berti et al., 2006），它给出了随机概率测度序列几乎必然弱收敛的充分条件，本文的 F-弱收敛概念直接建立在其上。

**主要进展**：在 bootstrap 领域，Chernozhukov et al. (2013, 2017) 建立了高维高斯近似与 multiplier bootstrap 的有限样本误差界，其核心工具是反集中不等式（anti-concentration），本文第 5.2、5.3 节直接调用这些结果。Bücher and Kojadinovic (2019) 则给出了一个重要的等价性刻画：当重抽样在给定数据下条件 i.i.d. 时，bootstrap 一致性等价于统计量与其两个重抽样副本的联合无条件弱收敛到独立同分布的极限——这为验证条件一致性提供了无条件路径。Kojevnikov et al. (2021) 为网络依赖过程建立了 CLT 和 bootstrap 工具，是本文第 5 节例子的直接动机来源。

**当前 frontier 与本文位置**：当前的前沿问题是：当比较分布没有固定极限（即非 pivot 情形）时，如何验证 bootstrap 的有效性？本文的贡献在于：将 merging 框架与条件弱收敛结合，提出了一种**不依赖共同极限**的条件一致性定义，并给出了可验证的充分条件（定理 3.2 的条件 (a)–(b)），同时提供了有限样本覆盖误差界（定理 3.1）。这比经典结果更灵活——允许条件 σ-代数互不相关、比较分布随 n 变化、数据维度随 n 增长。

#### 子线索聚类

这些被引文献大致落在三条子线索上：

1. **随机概率测度的收敛理论**（Berti et al., 2006; Belyaev and Sjöstedt-De Luna, 2000; Davydov and Rotar, 2009; D'Aristotile et al., 1988）：研究随机概率测度序列的收敛概念、merging 的等价刻画，以及几乎必然弱收敛的充分条件。这是本文第 2 节的理论骨架。

2. **高维 bootstrap 与高斯近似**（Chernozhukov et al., 2013, 2017）：提供高维统计量（最大值、二次型）的 Gaussian 和 bootstrap 逼近的有限样本误差界，核心工具是反集中不等式。本文第 5.2、5.3 节用这些结果验证条件 (a)–(b)。

3. **依赖数据的极限理论**（Kojevnikov et al., 2021; Kojevnikov and Song, 2022; Kuersteiner and Prucha, 2013）：为网络依赖、面板数据等复杂依赖结构提供 CLT、Berry–Esseen 界和 bootstrap 工具。本文第 5.1 节的 martingale Berry–Esseen 界直接来自 Kojevnikov and Song (2022)。

#### 这个方向在追问的核心问题

1. **条件一致性的恰当定义**：当比较分布随 n 变化且没有固定极限时，"bootstrap 有效"意味着什么？本文的回答是：在 Kolmogorov 距离下，两个条件分布对几乎所有冲击实现都渐近不可区分（merging）。
2. **可验证的充分条件**：如何将抽象的条件一致性转化为可操作的假设？本文的回答是：只需验证 (a) 原始统计量与比较分布的条件 merging，以及 (b) bootstrap 统计量与比较分布的条件 merging（定理 3.2）。
3. **有限样本误差界**：条件覆盖误差能否以显式速率收敛到零？本文的定理 3.1 给出了一个通用框架，将覆盖误差分解为三个可分别控制的项。

#### ⚠️ 作者的 framing（这是作者的说法）

作者在引言中明确将本文定位为"**不要求共同极限**"的条件 bootstrap 一致性框架，并强调其与经典结果（van der Vaart and Wellner, 2023 的条件弱收敛）的区别在于：允许条件 σ-代数互不相关、比较分布随机且随 n 变化。作者声称这一框架"直接适用于"网络依赖、共同冲击等场景。**注意**：作者在摘要和引言中反复强调"有限样本覆盖误差界"（定理 3.1），但该界的实际意义取决于 ∆n 和 κn 能否以可操作的速率收敛——作者在第 5 节的例子中给出了具体速率，但通用框架本身不提供速率。

#### 张力

未见明显对立引用。但有一个值得注意的潜在张力：Bücher and Kojadinovic (2019) 的等价性刻画（bootstrap 一致性 ⇔ 联合无条件弱收敛）在非可测情形下需要小心处理，而本文的 merging 框架绕过了这一困难，但代价是引入了更强的几乎必然收敛要求。这两条路径的适用范围不同，作者没有直接讨论这一取舍。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

在展开技术细节之前，先把记号一次性立清楚。本文的核心对象如下：

| 记号 | 含义 | 类型 |
|------|------|------|
| \((\Omega, \mathcal{H}, P)\) | 底层概率空间 | 基础结构 |
| \(\mathcal{C} = \{\mathcal{C}_n\}\) | 条件 σ-代数序列，代表"共同冲击" | 条件结构 |
| \(X_n\) | 原始样本，取值于 Polish 空间 \(\mathcal{X}_n\) | 可观测数据 |
| \(X_n^*\) | 重抽样样本（bootstrap 伪样本） | 可观测（由重抽样机制产生） |
| \(T_n(\theta_n) = T_n(X_n, \theta_n)\) | 目标统计量，\(\theta_n\) 是 \(\mathcal{C}_n\)-可测参数 | 估计量 |
| \(T_n^*(\theta_n^*) = T_n(X_n^*, \theta_n^*)\) | bootstrap 统计量 | 估计量 |
| \(Q_n^{\mathcal{C}_n} = \mathcal{L}(T_n \mid \mathcal{C}_n)\) | 原始统计量给定冲击的条件分布 | 目标分布（随机概率测度） |
| \(Q_n^{*,\mathcal{G}_n} = \mathcal{L}(T_n^* \mid \mathcal{G}_n)\) | bootstrap 统计量给定数据和冲击的条件分布 | 近似分布（随机概率测度） |
| \(d_K\) | Kolmogorov 距离 | 度量 |
| \(d_{BL}\) | 有界 Lipschitz 度量 | 度量 |
| \(\Delta_n = d_K(Q_n^{\mathcal{C}_n}, Q_n^{*,\mathcal{G}_n})\) | 条件 Kolmogorov 距离 | 核心随机变量 |
| \(\kappa_n\) | \(\Delta_n^*\) 的条件 Ky Fan 距离 | 辅助量 |

**模型**：数据 \(X_n\) 的分布受一个"共同冲击"驱动，该冲击由 σ-代数 \(\mathcal{C}_n\) 表示。研究者关心的是 \(T_n\) 给定 \(\mathcal{C}_n\) 的条件分布 \(Q_n^{\mathcal{C}_n}\)。Bootstrap 的目标是用 \(Q_n^{*,\mathcal{G}_n}\)（给定数据 \(X_n\) 和冲击 \(\mathcal{C}_n\) 的重抽样分布）来逼近 \(Q_n^{\mathcal{C}_n}\)。注意：\(\mathcal{C}_n\) 和 \(\mathcal{G}_n = \mathcal{C}_n \vee \sigma(X_n)\) 可以随 n 变化，且不同 n 之间不需要任何相容性条件。

**可观测数据**：研究者实际能观测到的是 \(X_n\)（原始样本）和由重抽样机制产生的 \(X_n^*\)。**不可观测**的是：冲击本身（只通过 \(\mathcal{C}_n\) 体现）、以及 \(T_n\) 的真实条件分布 \(Q_n^{\mathcal{C}_n}\)——后者正是要推断的对象。

#### 第二步：最小内核

把论文的所有技术细节剥掉，剩下的核心数学问题是：

> **给定两个随机概率测度序列 \(Q_n\) 和 \(Q_n^*\)（分别代表原始统计量和 bootstrap 统计量的条件分布），在什么条件下，对几乎所有冲击实现 \(\omega\)，有 \(d_K(Q_n(\omega), Q_n^*(\omega)) \to 0\)？**

这个问题的"最小版本"可以这样理解。假设我们有一个统计量 \(T_n\)，其条件分布 \(Q_n^{\mathcal{C}_n}\) 是随机的（依赖于冲击）。Bootstrap 给出另一个随机条件分布 \(Q_n^{*,\mathcal{G}_n}\)。我们想知道：这两个随机分布是否"几乎必然地"彼此接近？

**为什么这比经典 bootstrap 一致性难？** 在经典设定中，目标是一个固定的极限分布 \(Q\)（如正态分布），我们只需证明 \(d_K(Q_n, Q) \to 0\) 和 \(d_K(Q_n^*, Q) \to 0\)，然后由三角不等式得到 \(d_K(Q_n, Q_n^*) \to 0\)。但在本文的设定中，**没有共同的极限**——比较分布 \(Q_n^{\mathcal{C}_n}\) 本身随 n 变化且是随机的。因此，三角不等式失效，必须直接比较 \(Q_n\) 和 \(Q_n^*\)。

**本文的核心洞察**（定理 3.2 的证明思路）是：不需要共同极限，只需验证两个条件：

- **(a)** 原始统计量 \(T_n\) 与某个"比较序列" \(S_n\) 的条件分布 merging（即 \(d_K(Q_n^{\mathcal{C}_n}, Q_n^{S,\mathcal{C}_n}) \to 0\)）；
- **(b)** bootstrap 统计量 \(T_n^*\) 与同一个比较序列 \(S_n\) 的条件分布 merging（即 \(d_K(Q_n^{*,\mathcal{G}_n}, Q_n^{S,\mathcal{C}_n}) \to 0\) 在条件概率意义下）。

然后由三角不等式，\(d_K(Q_n^{\mathcal{C}_n}, Q_n^{*,\mathcal{G}_n}) \to 0\)。

**为什么这个"三角不等式"能成立？** 关键在于比较序列 \(S_n\) 的选择。在经典情形，\(S_n\) 就是极限分布 \(Q\)（常数）。在本文的设定中，\(S_n\) 可以是任何"足够光滑"的随机变量——例如，在第 5.1 节中，\(S_n\) 是条件高斯分布；在第 5.2 节中，\(S_n\) 是高斯最大值。**比较序列的作用是提供一个"中间锚点"**，使得原始统计量和 bootstrap 统计量都能被它近似。

**最小例子**：考虑最简单的非平凡情形——\(T_n = \sqrt{n}(\bar{X}_n - \mu)\)，其中 \(X_1, \ldots, X_n\) 在给定冲击 \(\mathcal{C}_n\) 下条件 i.i.d.，条件均值为 \(\mu\)，条件方差为 \(\sigma_n^2\)（随 n 变化）。此时：
- 原始统计量的条件分布 \(Q_n^{\mathcal{C}_n} \approx N(0, \sigma_n^2)\)（条件 CLT）；
- Bootstrap 统计量的条件分布 \(Q_n^{*,\mathcal{G}_n} \approx N(0, \hat{\sigma}_n^2)\)，其中 \(\hat{\sigma}_n^2\) 是样本方差。

如果 \(\hat{\sigma}_n^2 / \sigma_n^2 \to 1\)（条件概率意义下），那么两者都 merging 到 \(N(0, \sigma_n^2)\)，从而 bootstrap 条件一致。**注意**：这里没有固定的极限分布——\(\sigma_n^2\) 可以随 n 任意变化，甚至可以是随机的。这正是本文框架比经典结果更灵活的地方。

**这个最小内核的数学困难**在于：当比较分布随 n 变化时，如何控制 Kolmogorov 距离的收敛速率？本文的回答是：通过反集中不等式（第 5.2 节）或 Berry–Esseen 界（第 5.1 节）来量化 merging 的速率，然后代入定理 3.1 的有限样本界。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：在允许条件 σ-代数随样本量变化、比较分布没有固定极限、数据维度可以增长的条件下，建立了 bootstrap 条件一致性的充分条件，并给出了条件覆盖误差的有限样本界。
2. **核心工具/方法**：将概率测度的 merging 概念（D'Aristotile et al., 1988; Davydov and Rotar, 2009）与条件弱收敛（Berti et al., 2006）结合，提出"条件 d_K-一致性"的定义，并通过"比较序列"技巧将问题分解为两个可分别验证的 merging 条件。
3. **主要结论**：定理 3.2 表明，若原始统计量与比较序列条件 merging（条件 (a)），且 bootstrap 统计量与比较序列在条件概率意义下 merging（条件 (b)），则 bootstrap 条件 d_K-一致；定理 3.1 进一步给出了有限样本覆盖误差界，其形式为 \( \sup_\alpha |P(T_n \le c_n^*(\alpha) \mid \mathcal{C}_n) - \alpha| \le Q_0(S_n \mid \mathcal{C}_n) + \Delta_n + 2\kappa_n \)。

#### 关键设定与假设

在第二节最小记号的基础上，本文的完整设定如下：

- **Polish 空间序列**：\(X_n\) 取值于 Polish 空间 \(\mathcal{X}_n\)，\(\theta_n\) 是 \(\mathcal{C}_n\)-可测参数，取值于 Polish 空间 \(\Theta_n\)。这允许数据空间和参数空间随 n 变化。
- **条件 σ-代数**：\(\mathcal{C} = \{\mathcal{C}_n\}\) 是任意子 σ-代数序列，**不要求单调、不要求相容**。这是与经典条件弱收敛文献（van der Vaart and Wellner, 2023, Section 1.13）的关键区别——后者通常要求固定的条件 σ-代数。
- **比较序列**：\(S_n\) 是辅助随机变量，其条件分布 \(Q_n^{S,\mathcal{C}_n}\) 作为"锚点"。\(S_n\) 的选择是自由的，但需要满足：(i) 条件分布足够光滑（无原子），(ii) 与 \(T_n\) 和 \(T_n^*\) 的 merging 条件可验证。
- **重抽样机制**：\(X_n^*\) 的条件分布给定 \(\mathcal{G}_n = \mathcal{C}_n \vee \sigma(X_n)\) 由重抽样权重决定。本文不指定具体的重抽样方案（可以是 i.i.d. bootstrap、multiplier bootstrap、m-out-of-n 等），而是将其抽象为条件分布 \(Q_n^{*,\mathcal{G}_n}\)。
- **光滑性假设**：比较序列 \(S_n\) 的条件分布满足 \(\mathcal{C}_n\)-渐近等度连续（定义 2.2 的 asymptotic equicontinuity），即对任意 \(\epsilon > 0\)，\(\lim_{\delta \to 0} \sup_n Q_n^{S,\mathcal{C}_n}(\cdot, [x, x+\delta]) = 0\) 几乎必然。这是从 Kolmogorov 距离收敛到 merging 的关键桥梁。

相比已有文献，本文的设定**放宽了**：(i) 不要求固定极限分布；(ii) 允许条件 σ-代数随 n 变化且互不相关；(iii) 允许数据维度随 n 增长（第 5.2、5.3 节）。**强化了**：要求几乎必然（而非概率）意义下的 merging，这比经典的无条件 bootstrap 一致性更强。

#### 主要结果

**定理 3.1（有限样本覆盖误差界）**：对每个 \(n\) 和 \(\alpha \in (0,1)\)，
\[
\sup_{\alpha \in (0,1)} |P(T_n \le c_n^*(\alpha) \mid \mathcal{C}_n) - \alpha| \le Q_0(S_n \mid \mathcal{C}_n) + \Delta_n + 2\kappa_n \quad \text{a.s.}
\]
其中 \(Q_0(S_n \mid \mathcal{C}_n)\) 是比较序列的最大原子质量，\(\Delta_n = d_K(Q_n^{\mathcal{C}_n}, Q_n^{S,\mathcal{C}_n})\)，\(\kappa_n\) 是 \(\Delta_n^* = d_K(Q_n^{*,\mathcal{G}_n}, Q_n^{S,\mathcal{C}_n})\) 的条件 Ky Fan 距离。这个界的意义在于：它将条件覆盖误差分解为三个可分别控制的项——比较序列的光滑性、原始统计量的 merging 误差、bootstrap 统计量的 merging 误差。

**定理 3.2（条件 d_K-一致性的充分条件）**：若 (a) \(\Delta_n \to 0\) 几乎必然，且 (b) \(\Delta_n^* \xrightarrow{\mathcal{C}\text{-p}} 0\)（条件概率意义下），则 \(d_K(Q_n^{\mathcal{C}_n}, Q_n^{*,\mathcal{G}_n}) \to 0\) 几乎必然。证明的关键是三角不等式加上条件概率的收敛性。

**定理 3.3（条件分位数的一致性）**：在定理 3.2 的条件下，bootstrap 条件分位数 \(c_n^*(\alpha)\) 满足 \(P(T_n \le c_n^*(\alpha) \mid \mathcal{C}_n) \to \alpha\) 几乎必然，且覆盖误差的收敛速率由 \(\Delta_n\)、\(\kappa_n\) 和 \(Q_0(S_n \mid \mathcal{C}_n)\) 的收敛速率决定。

**第 4 节（光滑统计量）**：将上述框架应用于依赖估计量或 nuisance 参数的光滑统计量。核心结果是引理 4.1：若线性化统计量 \(T_n^1\) 满足 merging 条件，且非线性项在条件概率意义下可忽略，则原统计量也满足 merging 条件。这为处理 nuisance 估计提供了通用模板。

**第 5 节（三个例子）**：
- **5.1 固定维度的最大值**：\(T_n = \max_{1 \le j \le 2} \sqrt{n}(\bar{Y}_{n,j} - \theta_{n,j})\)，其中 \(\theta_n\) 是条件均值向量。比较序列 \(S_n\) 是条件高斯最大值。验证条件 (a) 用 Kojevnikov and Song (2022) 的 Berry–Esseen 界，条件 (b) 用 Bickel and Freedman (1981) 的 bootstrap CLT。得到 \(\Delta_n = O(n^{-1/4})\) 和 \(\kappa_n = O(n^{-1/4})\)。
- **5.2 增长维度的最大值**：\(p_n \to \infty\)，\(T_n = \max_{1 \le j \le p_n} \sqrt{n}(\bar{Y}_{n,j} - \theta_{n,j})\)。比较序列是高斯最大值。用 Chernozhukov et al. (2017) 的高维 Gaussian approximation 和 multiplier bootstrap 定理，得到 \(\Delta_n = O((n^{-1} \log^7(p_n n))^{1/6})\) 和 \(\kappa_n = O((n^{-1} \log^7(p_n n))^{1/6})\)，条件是 \(\log^7(p_n n) = o(n)\)。
- **5.3 增长维度的相关性**：对相关系数矩阵的非对角元做联合推断。用第 4 节的框架处理 nuisance 参数（对角线元素），验证了光滑性条件。

#### 证明路线与技术技巧

**整体路线**（以定理 3.2 为例）：
1. **定义 merging**：两个随机概率测度序列 \(Q_n, Q_n'\) merging，如果 \(d_{BL}(Q_n, Q_n') \to 0\) 几乎必然。
2. **三角不等式**：\(d_K(Q_n^{\mathcal{C}_n}, Q_n^{*,\mathcal{G}_n}) \le d_K(Q_n^{\mathcal{C}_n}, Q_n^{S,\mathcal{C}_n}) + d_K(Q_n^{S,\mathcal{C}_n}, Q_n^{*,\mathcal{G}_n})\)。
3. **控制第一项**：条件 (a) 直接给出。
4. **控制第二项**：利用条件 (b) 和引理 2.6（merging 与 Kolmogorov 距离的桥梁），将 \(d_K(Q_n^{S,\mathcal{C}_n}, Q_n^{*,\mathcal{G}_n})\) 的控制转化为对 \(d_{BL}\) 的控制，再结合比较序列的渐近等度连续性。
5. **有限样本版本**：将上述渐近论证量化，得到定理 3.1 的显式界。

**关键技巧**：
- **比较序列技巧**：引入 \(S_n\) 作为"锚点"，避免了对固定极限分布的需求。这是本文最核心的方法论贡献。
- **条件 Ky Fan 距离**：\(\kappa_n\) 的定义使得有限样本界的证明可以统一处理"条件概率收敛"和"几乎必然收敛"两种模式。
- **反集中不等式**：在第 5.2、5.3 节中，用 Chernozhukov et al. (2017) 的反集中不等式来控制高斯最大值的光滑性，这是验证条件 (a)–(b) 的关键。
- **Lévy 集中函数**：引理 2.6 的证明用到了 Lévy 集中函数来连接 Kolmogorov 距离和 merging，这是处理非连续分布比较的标准技巧。

#### 🔎 结论是否比证明窄

有几处值得注意：

1. **定理 3.1 的界是"存在性"而非"可计算性"**：定理给出的界涉及 \(\Delta_n\) 和 \(\kappa_n\)，但这两个量本身可能难以显式计算。在第 5 节的例子中，作者通过 Berry–Esseen 界和高斯近似给出了显式速率，但通用框架不提供这些速率。**作者在摘要中声称"提供有限样本界"，但该界的实际可操作性取决于具体应用**。

2. **条件 (b) 的验证在非 i.i.d. 重抽样下可能困难**：第 5 节的例子都假设重抽样是条件 i.i.d. 的（或 multiplier bootstrap）。对于更复杂的重抽样方案（如 block bootstrap、subsampling），条件 (b) 的验证可能需要新的工具。**作者在文中没有讨论这一限制**。

3. **第 4 节的光滑性框架要求 nuisance 估计量的一致收敛**：引理 4.1 的条件 (4.2) 要求 \(\|\hat{\vartheta}_n - \vartheta_n\| \xrightarrow{\mathcal{C}\text{-p}} 0\)，这在许多半参数问题中需要额外的条件（如 Donsker 条件）。**作者没有讨论这些条件在具体应用中的可验证性**。

4. **第 5.3 节的例子中，相关性矩阵的维度是 \(p_n^2\)，但作者只给出了 \(\log^7(p_n n) = o(n)\) 的条件**：这意味着 \(p_n\) 可以增长到 \(e^{n^{1/7}}\) 的量级，但作者没有讨论这个条件在实际样本量下是否合理。

### 四、开放问题

以下开放问题均扎根于本文的具体语句：

1. **有限样本界的可操作性**（扎根于定理 3.1 的陈述）：定理 3.1 的界涉及 \(\Delta_n\) 和 \(\kappa_n\)，但作者没有给出这两个量在一般情形下的可计算上界。一个自然的后续问题是：**能否为特定的重抽样方案（如 multiplier bootstrap、m-out-of-n）推导出 \(\Delta_n\) 和 \(\kappa_n\) 的显式上界，使其可以直接用于选择 bootstrap 重复次数 \(B\)？**

2. **非 i.i.d. 重抽样的条件一致性**（扎根于第 5 节所有例子均假设条件 i.i.d. 重抽样）：本文的框架是否适用于 block bootstrap、subsampling 等更复杂的重抽样方案？这些方案的条件分布 \(Q_n^{*,\mathcal{G}_n}\) 可能不满足条件 (b) 的验证条件，需要新的技术。

3. **nuisance 估计的 Donsker 条件**（扎根于引理 4.1 的条件 (4.2)）：引理 4.1 要求 nuisance 估计量的一致收敛，但在高维或非光滑设定下，这一条件可能过强。**能否用更弱的条件（如局部一致收敛）替代？**

4. **最优收敛速率**（扎根于第 5.2 节的 \(\Delta_n = O((n^{-1} \log^7(p_n n))^{1/6})\)）：这个速率是否是最优的？能否通过更精细的反集中不等式或 Edgeworth 展开来改进？

5. **条件覆盖误差的自适应控制**（扎根于定理 3.1 的界）：定理 3.1 的界是均匀的（对 \(\alpha\) 一致），但在某些应用中，我们可能只关心特定的分位数（如 95% 分位数）。**能否针对特定分位数给出更紧的界？**
