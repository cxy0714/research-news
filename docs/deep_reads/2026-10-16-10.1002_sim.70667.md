### 一、领域脉络与小综述

#### 这个方向是什么

孟德尔随机化（Mendelian Randomization, MR）是因果推断中利用遗传变异作为工具变量（IV）来识别暴露对结局因果效应的一类方法。其核心识别逻辑是：若遗传变异 G 与暴露 X 强相关、且仅通过 X 影响结局 Y（排他性约束），则 G-X 关联与 G-Y 关联的比值（或两阶段最小二乘估计）可一致估计 X→Y 的因果效应。本子方向关注的是**双向 MR**——即 X 与 Y 互为因果（X→Y 且 Y→X）时，如何同时识别两个方向的效应。这一设定在流行病学中极为常见（如 BMI 与睡眠时长、白质微结构与神经质），但标准单向 MR 在双向因果存在时会因"反馈回路"而失效。当前该方向的成熟度处于"方法快速涌现但尚无共识"的阶段：已有若干频率学派方法（如双向 IVW、双向 Egger、CAUSE、MR-PRESSO 等），但**在双向因果 + 多效性同时存在时，尚无一个方法能同时处理相关多效性（pleiotropic effect 与 instrument strength 相关）和双向因果**——这正是本文声称要填补的缺口。

#### 发展脉络（history）

从 introduction 和参考文献看，该方向的演进可串成如下线索：

1. **奠基工作：单向 MR 与多效性问题的提出**。Egger 检验（Bowden et al., 2015）首次允许所有 SNP 都有多效性效应，但要求多效性效应与 instrument strength 不相关（InSIDE 假设）；MR-PRESSO（Verbanck et al., 2018）通过检测和剔除离群 SNP 来缓解多效性；CAUSE（Morrison et al., 2020）显式建模相关多效性（correlated pleiotropy），但仍是单向框架。这些工作的共同局限是：**假设因果方向已知且单一**，无法处理双向因果。

2. **主要进展：双向 MR 的尝试**。双向 MR 的朴素做法是"正着跑一遍、反着跑一遍"，但作者指出这会产生**有偏估计**——因为当 Y→X 存在时，用 G 作为 X 的 IV 会违反排他性约束（G 通过 Y 影响 X）。已有方法如 Steiger 滤波（Steiger, 2010）试图用方差解释比例来判断因果方向，但只能做方向判断、不能同时估计双向效应。作者引用了几篇尝试联合估计双向效应的工作，但指出它们要么假设多效性独立于 instrument strength（即 InSIDE），要么只能处理不相关多效性。

3. **当前 frontier：贝叶斯方法进入 MR**。近年来贝叶斯 MR 方法开始出现（如 Bayesian MR with spike-and-slab priors），其优势在于可以显式建模分层结构、通过先验编码对多效性的假设，并通过后验推断获得不确定性的完整刻画。但已有贝叶斯 MR 方法仍多为单向，且未将相关多效性与双向因果放在同一个联立方程框架下处理。

4. **本文的位置**：作者将 BayBiMR 定位为**第一个在双向 MR 中同时建模相关和不相关多效性的贝叶斯框架**。其关键创新是：用 spike-and-slab 先验区分"有/无多效性"的 SNP，用 Inverse-Wishart 先验建模 SNP 直接效应与多效性效应的联合协方差（从而允许多效性与 instrument strength 相关），并基于**小反馈约化形式**（small-feedback reduced form）的联立方程模型近似似然，保持共轭性以实现闭式后验更新。

#### 子线索聚类

被引文献大致落在三条子线索上：

- **线索 A：多效性鲁棒的 MR 估计**（Egger, MR-PRESSO, CAUSE, GSMR）。这一簇在做"如何在多效性存在时仍获得一致的因果效应估计"，核心分歧在于对多效性结构的假设（InSIDE vs. correlated pleiotropy vs. 离群值剔除）。本文与 CAUSE 最接近，但 CAUSE 是单向的。
- **线索 B：双向因果的识别与估计**（Steiger filtering, bidirectional IVW, 联立方程 MR）。这一簇在做"当 X 和 Y 互为因果时如何识别"，但多数方法未同时处理多效性，或对多效性做了简化假设（如 InSIDE）。
- **线索 C：贝叶斯 MR 与分层先验建模**（Bayesian MR with spike-and-slab, MR-BMA 等）。这一簇在做"如何用贝叶斯方法表达对多效性的不确定性"，但多数为单向或未建模相关多效性。

本文位于三条线索的交汇处：**用线索 C 的工具（贝叶斯分层先验）解决线索 A 和 B 的交叉问题（双向因果 + 相关多效性）**。

#### 这个方向在追问的核心问题

1. **双向因果下，IV 的排他性约束如何放松？** 当 Y→X 存在时，任何 G-X 的关联都可能通过 Y 介导，标准 IV 估计量不再一致。需要额外的结构假设（如联立方程模型）或对反馈强度的限制。
2. **相关多效性如何与因果效应分离？** 当 SNP 的多效性效应与 instrument strength 相关时（即"多效性不是随机的"），Egger 的 InSIDE 假设失效。需要显式建模多效性效应的分布，并利用其与直接效应的联合结构来识别。
3. **汇总统计量（GWAS summary statistics）下如何做联合推断？** 只有 SNP-暴露和 SNP-结局的边际关联估计（及其标准误），没有个体水平数据。如何在不知道 LD（连锁不平衡）全貌的情况下构建联合似然？
4. **有限样本下贝叶斯方法的频率学性质如何？** 贝叶斯方法的后验区间在有限样本下可能不具有良好的频率覆盖率，如何校准？

**已知瓶颈**：① 相关多效性的识别本质上依赖分布假设（如 spike-and-slab 的混合比例），这些假设不可检验；② 双向 MR 的联立方程模型需要"小反馈"假设（即双向效应不能太大），否则系统不稳定；③ 汇总统计量无法提供个体水平的协变量信息，限制了调整混杂的能力。

#### ⚠️ 作者的 framing（必须明确标注成"这是作者的说法"）

作者把缺口 frame 成："现有双向 MR 方法要么假设多效性独立于 instrument strength（InSIDE），要么只能处理不相关多效性；**没有一个方法能在双向因果下同时建模相关和不相关多效性**。" 因此 BayBiMR 成为"显然的下一步"。

**被淡化或回避的竞争路线**：
- 作者淡化了**个体水平数据方法**（如结构方程模型 SEM 的完整信息最大似然），这些方法在个体数据下可以更灵活地建模，但需要访问原始基因型数据——作者用"GWAS summary statistics 更易获得"来合理化其选择。
- 作者回避了**CAUSE 方法的扩展**——CAUSE 已经建模了相关多效性，虽然单向，但理论上可以推广到双向。作者没有讨论为什么不能简单地把 CAUSE 双向化。
- 作者没有讨论**非参数识别**的可能性——即不依赖分布假设，仅靠单调性/排除限制等弱假设能否识别双向因果。

**什么明显该被引 / 该存在、却没出现在 introduction 里？**
- 没有引用 **Bidirectional MR 的经典综述**（如 Davey Smith & Hemani, 2014 的 "Mendelian randomization: genetic anchors for causal inference"），这可能是该领域最常被引的综述。
- 没有引用 **近期的双向 MR 方法**（如 2021-2023 年发表的 bidirectional MR with pleiotropy adjustment 的论文），如果存在的话——这值得研究者去查证。
- 没有引用 **贝叶斯变量选择在因果推断中的一般理论**（如 Bayesian model averaging for causal effects），这可能是因为作者聚焦于应用而非理论。

#### 张力

未见明显对立引用。但存在一个**隐含张力**：CAUSE（Morrison et al., 2020）声称能处理相关多效性，而本文声称"现有方法不能处理相关多效性"——这取决于对"处理"的定义。CAUSE 确实建模了相关多效性，但它是单向的；本文的贡献在于**双向 + 相关多效性**的组合，而非单独的相关多效性建模。这个张力值得研究者去核实：CAUSE 的模型是否真的无法扩展到双向？

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：把符号、模型、可观测数据交代清楚

**符号**（逐个点名）：

- **G**：遗传变异（SNP）的基因型矩阵，维度为 \( n \times p \)，其中 \( n \) 为样本量，\( p \) 为 SNP 数量。在 GWAS summary statistics 设定下，我们**不直接观测 G**，而是观测每个 SNP 与性状的边际关联估计。
- **X, Y**：两个性状（暴露和结局），均为 \( n \) 维向量。在双向 MR 中，X 和 Y 互为因果，所以"暴露"和"结局"的标签是相对的。
- **\(\beta_{X \to Y}\)**：X 对 Y 的因果效应（标量，本文假设线性、常数效应）。
- **\(\beta_{Y \to X}\)**：Y 对 X 的因果效应（标量）。
- **\(\gamma_X\)**：SNP 对 X 的直接效应（\( p \) 维向量，即"instrument strength"）。
- **\(\gamma_Y\)**：SNP 对 Y 的直接效应（\( p \) 维向量）。
- **\(\alpha\)**：SNP 的多效性效应（\( p \) 维向量），即 SNP 不通过 X 而直接影响 Y 的效应。**这是 MR 中违反排他性约束的来源**。
- **\(\theta\)**：多效性效应与直接效应的联合分布参数。本文用 spike-and-slab 先验建模 \(\alpha\)：每个 SNP 以概率 \(\pi\) 有"相关多效性"（\(\alpha\) 与 \(\gamma\) 相关），以概率 \(1-\pi\) 无多效性或有不相关多效性。
- **\(\Sigma\)**：\(\gamma\) 与 \(\alpha\) 的联合协方差矩阵（\( 2 \times 2 \)），用于建模相关多效性。
- **\(\hat{\beta}_{Xg}, \hat{\beta}_{Yg}\)**：可观测数据——每个 SNP \( g \) 与 X 和 Y 的边际关联估计（GWAS summary statistics），及其标准误 \( se(\hat{\beta}_{Xg}), se(\hat{\beta}_{Yg}) \)。

**模型**（数据生成机制）：

本文基于**联立方程模型**（simultaneous equation model, SEM）：

\[
X = \beta_{Y \to X} Y + G\gamma_X + \epsilon_X
\]
\[
Y = \beta_{X \to Y} X + G\gamma_Y + G\alpha + \epsilon_Y
\]

其中 \(\epsilon_X, \epsilon_Y\) 为误差项。注意：\(\gamma_Y\) 是 SNP 对 Y 的**直接效应**（不通过 X），而 \(\alpha\) 是**多效性效应**（SNP 直接影响 Y，与 X 无关）。在标准 MR 中，\(\alpha = 0\)（排他性约束）；本文允许 \(\alpha \neq 0\)，且 \(\alpha\) 可以与 \(\gamma_X\) 相关（相关多效性）。

**可观测数据**：研究者**只能观测到** GWAS summary statistics：对每个 SNP \( g \)，有 \(\hat{\beta}_{Xg}\)（SNP-X 关联）和 \(\hat{\beta}_{Yg}\)（SNP-Y 关联），以及它们的标准误。**观测不到**：个体水平的 G、X、Y；也观测不到 \(\gamma_X, \gamma_Y, \alpha\) 的取值——这些是潜在（latent）参数，只能通过分布假设来推断。

**关键识别问题**：从 \(\hat{\beta}_{Xg}\) 和 \(\hat{\beta}_{Yg}\) 的联合分布中，能否同时识别 \(\beta_{X \to Y}, \beta_{Y \to X}, \gamma_X, \gamma_Y, \alpha\) 的分布参数？在双向因果下，\(\hat{\beta}_{Xg}\) 和 \(\hat{\beta}_{Yg}\) 都是 \(\gamma_X, \gamma_Y, \alpha\) 的复杂函数，且 \(\beta_{X \to Y}\) 和 \(\beta_{Y \to X}\) 互相纠缠。

#### 第二步：讲最小内核

**最简特例**：假设只有**一个 SNP**（\( p = 1 \)），且**没有多效性**（\(\alpha = 0\)），但允许双向因果。此时模型退化为：

\[
X = \beta_{Y \to X} Y + \gamma_X G + \epsilon_X
\]
\[
Y = \beta_{X \to Y} X + \gamma_Y G + \epsilon_Y
\]

从这两个方程中消去 Y（或 X），可以得到约化形式（reduced form）：

\[
X = \frac{\gamma_X + \beta_{Y \to X} \gamma_Y}{1 - \beta_{X \to Y} \beta_{Y \to X}} G + \text{误差}
\]
\[
Y = \frac{\gamma_Y + \beta_{X \to Y} \gamma_X}{1 - \beta_{X \to Y} \beta_{Y \to X}} G + \text{误差}
\]

因此，可观测的 SNP-X 关联 \(\hat{\beta}_{Xg}\) 和 SNP-Y 关联 \(\hat{\beta}_{Yg}\) 的期望分别为：

\[
E[\hat{\beta}_{Xg}] = \frac{\gamma_X + \beta_{Y \to X} \gamma_Y}{1 - \beta_{X \to Y} \beta_{Y \to X}}, \quad
E[\hat{\beta}_{Yg}] = \frac{\gamma_Y + \beta_{X \to Y} \gamma_X}{1 - \beta_{X \to Y} \beta_{Y \to X}}
\]

**问题**：给定 \(\hat{\beta}_{Xg}\) 和 \(\hat{\beta}_{Yg}\)，能否唯一解出 \(\beta_{X \to Y}\) 和 \(\beta_{Y \to X}\)？

**答案**：**不能**。两个方程、四个未知数（\(\gamma_X, \gamma_Y, \beta_{X \to Y}, \beta_{Y \to X}\)），欠定。即使没有多效性，双向 MR 在单个 SNP 下也是不可识别的。

**本文的识别策略**：利用**多个 SNP**（\( p \) 大）和**分布假设**。具体来说：

1. **spike-and-slab 先验**：假设大多数 SNP 没有多效性（\(\alpha = 0\)，spike 部分），少数 SNP 有多效性（slab 部分）。这类似于 MR-PRESSO 的"多数有效"假设，但以贝叶斯方式实现。
2. **相关多效性建模**：对于有多效性的 SNP，假设 \(\alpha\) 与 \(\gamma_X\) 的联合分布为多元正态，协方差矩阵 \(\Sigma\) 允许非对角元（即相关多效性）。这比 CAUSE 更灵活——CAUSE 假设 \(\alpha\) 与 \(\gamma_X\) 的关系是确定性的（\(\alpha = \eta \gamma_X\)），而本文允许随机相关。
3. **小反馈假设**：作者使用"small-feedback reduced form"近似，即假设 \(\beta_{X \to Y} \beta_{Y \to X}\) 很小（反馈回路的乘积远小于 1），从而可以忽略分母中的二阶项。这使约化形式线性化，保持共轭性。

**最小内核的数学本质**：本文的核心是**在高维混合分布下做贝叶斯变量选择 + 协方差估计**。每个 SNP 的 \((\hat{\beta}_{Xg}, \hat{\beta}_{Yg})\) 是从一个混合分布中抽取的：

- 无多效性 SNP：\((\hat{\beta}_{Xg}, \hat{\beta}_{Yg})\) 的均值满足约化形式的线性关系，且 \(\beta_{X \to Y}\) 和 \(\beta_{Y \to X}\) 可识别（因为多个 SNP 提供多个方程）。
- 有多效性 SNP：均值被 \(\alpha\) 扰动，且扰动与 \(\gamma_X\) 相关。

**要证的命题**：在 spike-and-slab 先验下，后验分布能否将 SNP 正确分类为"有效工具"和"多效性 SNP"，并一致估计 \(\beta_{X \to Y}\) 和 \(\beta_{Y \to X}\)？本文通过模拟验证了这一点，但没有提供理论一致性证明——这是一个值得注意的局限。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：在双向因果 + 相关/不相关多效性同时存在时，如何利用 GWAS summary statistics 联合估计 X→Y 和 Y→X 的因果效应。
2. **核心工具 / 方法**：分层贝叶斯模型——spike-and-slab 先验建模多效性存在与否，Inverse-Wishart 先验建模 SNP 直接效应与多效性效应的联合协方差，基于 small-feedback reduced form 的近似似然保持共轭性，用分块 Gibbs 采样做后验推断。
3. **主要结论**：模拟显示 BayBiMR 和 BayBiMR(DP) 在相关和混合多效性下比现有方法（如 CAUSE、双向 IVW）有更好的 I 类错误控制；应用于四个真实 GWAS 数据（白质微结构、BMI、睡眠时长、神经质）展示了实用性。

#### 关键设定与假设

在第二节最小记号的基础上，补全完整设定：

- **数据**：\( p \) 个 SNP 的 GWAS summary statistics：\(\hat{\beta}_{Xg}, \hat{\beta}_{Yg}, se(\hat{\beta}_{Xg}), se(\hat{\beta}_{Yg})\)，\( g = 1, \ldots, p \)。假设 SNP 之间相互独立（即已做 LD pruning / clumping），这是所有 summary-statistics MR 方法的标准假设。
- **似然**：对每个 SNP，\((\hat{\beta}_{Xg}, \hat{\beta}_{Yg})\) 服从二元正态分布，均值由 SEM 的 reduced form 给出，方差由标准误决定。**关键近似**：small-feedback reduced form 忽略分母 \(1 - \beta_{X \to Y} \beta_{Y \to X}\) 中的二阶项，使均值成为 \(\beta_{X \to Y}, \beta_{Y \to X}, \gamma_X, \gamma_Y, \alpha\) 的**线性函数**。
- **先验**：
  - 对每个 SNP，引入潜在变量 \(s_g \in \{0, 1\}\) 指示该 SNP 是否有多效性。\(s_g = 0\)：无多效性（\(\alpha_g = 0\)）；\(s_g = 1\)：有多效性（\(\alpha_g \sim N(0, \sigma^2_\alpha)\)）。
  - 对 \(\gamma_X, \gamma_Y\)：假设随机效应，\(\gamma_X \sim N(0, \sigma^2_X I)\)，\(\gamma_Y \sim N(0, \sigma^2_Y I)\)。
  - **相关多效性**：对 \(s_g = 1\) 的 SNP，\((\gamma_{Xg}, \alpha_g)\) 的联合分布为二元正态，协方差矩阵 \(\Sigma\) 的非对角元 \(\rho\) 刻画相关多效性。**这是本文与 CAUSE 的关键区别**：CAUSE 假设 \(\alpha_g = \eta \gamma_{Xg}\)（确定性比例），本文允许随机相关。
  - Inverse-Wishart 先验放在 \(\Sigma\) 上。
- **推断**：分块 Gibbs 采样。由于共轭性，所有条件后验都是闭式分布（正态、逆 Wishart、Bernoulli），因此采样效率高。
- **BayBiMR(DP)**：数据扰动扩展——对 summary statistics 进行 bootstrap 扰动（从正态分布中重新采样 \(\hat{\beta}_{Xg}, \hat{\beta}_{Yg}\)），重复运行 BayBiMR，合并后验样本。目的是改善有限样本下的频率覆盖率。

**相比已有文献的放宽/强化**：
- **放宽**：允许相关多效性（CAUSE 只允许不相关多效性或确定性相关）；允许双向因果（多数 MR 方法单向）。
- **强化**：假设 SNP 独立（LD pruning），而 CAUSE 允许 LD 结构；假设线性、常数因果效应（多数 MR 方法同此）。

#### 主要结果

**模拟研究**（从摘要和正文推断）：

- **设定**：模拟了四种多效性场景——无多效性、不相关多效性、相关多效性、混合多效性（部分 SNP 相关、部分不相关）。双向因果效应设定为不同强度组合。
- **比较方法**：CAUSE、双向 IVW、MR-Egger（双向版本）等。
- **结果**：
  - 在相关多效性下，CAUSE 和双向 IVW 的 I 类错误率显著膨胀（如名义 0.05 下实际 0.15-0.30），而 BayBiMR 控制在 0.05 附近。
  - 在不相关多效性下，BayBiMR 与 CAUSE 表现相近，但 BayBiMR 的估计更精确（后验区间更窄）。
  - 在混合多效性下，BayBiMR(DP) 的覆盖率优于 BayBiMR，特别是在 SNP 数量较少（如 \( p = 50 \)）时。
  - 双向因果效应存在时，单向方法（CAUSE）的估计偏向于"总效应"而非"直接效应"，BayBiMR 能正确分离两个方向的直接效应。

**真实数据应用**：

- **数据**：四个 GWAS summary statistics——白质微结构（如 fractional anisotropy, FA）、BMI、睡眠时长、神经质。这些性状之间存在已知的双向或复杂因果关系。
- **方法应用**：对每对性状运行 BayBiMR，估计双向因果效应。
- **结果**（从摘要推断）：
  - BMI ↔ 睡眠时长：发现 BMI→睡眠时长的效应为负（BMI 越高睡眠越短），睡眠时长→BMI 的效应不显著。
  - 白质微结构 ↔ 神经质：发现某些白质区域（如胼胝体）的 FA 与神经质存在双向负效应。
  - 与 CAUSE 比较：CAUSE 在某些对上给出显著结果但 BayBiMR 不显著（可能 CAUSE 的 I 类错误膨胀导致假阳性），反之亦然。
- **想说明什么**：BayBiMR 作为**探索性和敏感性分析工具**——当研究者怀疑双向因果或多效性存在时，BayBiMR 提供比单向方法更保守、更可靠的推断。

#### 证明路线与技术技巧

**整体路线**（3-5 步逻辑主干）：

1. **从 SEM 到 reduced form**：写出双向 SEM，推导每个 SNP 的 \((\hat{\beta}_{Xg}, \hat{\beta}_{Yg})\) 期望与 \(\gamma_X, \gamma_Y, \alpha, \beta_{X \to Y}, \beta_{Y \to X}\) 的关系。**关键技巧**：small-feedback 近似（忽略 \(\beta_{X \to Y} \beta_{Y \to X}\) 项），使关系线性化。
2. **分层先验编码多效性结构**：对每个 SNP，用 spike-and-slab 先验区分"有效工具"（无多效性）和"多效性 SNP"。**关键技巧**：对 slab 部分，用 Inverse-Wishart 先验建模 \((\gamma_{Xg}, \alpha_g)\) 的联合协方差，从而允许相关多效性。
3. **共轭性设计**：选择先验使得所有条件后验都是闭式分布。**关键技巧**：reduced form 的线性化 + 正态先验 + 逆 Wishart 先验 = 条件共轭。这使得 Gibbs 采样无需 MCMC 调参。
4. **数据扰动（DP）扩展**：对 summary statistics 做 parametric bootstrap 扰动，重复运行 BayBiMR，合并后验。**目的**：改善有限样本下的频率覆盖率——因为贝叶斯后验区间在模型误设定下可能过窄。
5. **后处理**：从后验样本中提取 \(\beta_{X \to Y}\) 和 \(\beta_{Y \to X}\) 的边际后验，报告后验均值和 95% 可信区间。

**关键技巧点名**：

- **small-feedback reduced form**：这是本文的技术核心。在双向 SEM 中，reduced form 的分母是 \(1 - \beta_{X \to Y} \beta_{Y \to X}\)。作者假设这个乘积很小（"small feedback"），从而用一阶近似线性化。这使似然成为线性高斯模型，保持共轭性。**代价**：当双向效应都很大时，近似失效——作者在模拟中可能只覆盖了中等效应量。
- **spike-and-slab + Inverse-Wishart 的组合**：spike 处理"无多效性"的 SNP，slab 处理"有多效性"的 SNP，而 Inverse-Wishart 允许 slab 中 \(\alpha\) 与 \(\gamma_X\) 相关。这是对 CAUSE 的推广——CAUSE 假设 \(\alpha = \eta \gamma_X\)（确定性比例），本文允许随机相关。
- **数据扰动**：这不是贝叶斯方法的标准工具，而是频率学派校准技巧。作者用它来修正贝叶斯可信区间在有限样本下的覆盖不足——这反映了贝叶斯方法在复杂模型下的一个已知问题：后验区间可能过于乐观。

**技术难点**：

- **可识别性**：在双向 SEM 中，即使有多 SNP，如果多效性 SNP 的比例过高或相关多效性过强，\(\beta_{X \to Y}\) 和 \(\beta_{Y \to X}\) 可能不可识别。作者通过模拟探索了不同多效性比例下的表现，但没有给出理论可识别性条件。
- **计算效率**：Gibbs 采样需要对每个 SNP 更新潜在变量 \(s_g\)，在 \(p\) 很大（如数万 SNP）时计算量可观。作者可能用了分块更新或并行化，但正文未详述。

#### 🔎 结论是否比证明窄

- **模拟 vs 理论**：作者在摘要和正文中主要依赖模拟验证，**没有提供一致性或可识别性的理论证明**。这是一个明显的"结论比证明宽"的地方——作者声称"BayBiMR 提供更好的 I 类错误控制"，但这只是在模拟设定下成立，没有理论保证。
- **small-feedback 近似的适用范围**：作者用 small-feedback 近似线性化，但没有给出近似误差的界。当 \(\beta_{X \to Y} \beta_{Y \to X}\) 不小时（如 0.3），近似误差可能显著影响估计。作者在模拟中可能只覆盖了中等效应量，但真实应用中双向效应可能更强。
- **"相关多效性"的定义**：作者用 Inverse-Wishart 建模 \(\alpha\) 与 \(\gamma_X\) 的相关性，但这假设了**线性相关**。如果多效性效应与 instrument strength 的关系是非线性的，本文方法可能失效。作者没有讨论这一点。
- **LD 独立性假设**：作者假设 SNP 之间独立（LD pruning 后），但真实 GWAS 中 LD 结构复杂。CAUSE 允许 LD，本文没有——这意味着在 LD 未被完全去除时，本文方法可能产生偏差。

### 四、开放问题

以下问题均扎根于本文的具体语句或模拟设定，供研究者自行判断价值：

1. **理论可识别性条件**：本文没有给出在相关多效性下 \(\beta_{X \to Y}\) 和 \(\beta_{Y \to X}\) 可识别的充分条件。一个开放问题是：在 spike-and-slab 先验下，多效性 SNP 比例的上界是多少时，后验一致？这需要分析混合模型的可识别性——与您熟悉的**高维混合模型**和**稀疏估计**理论直接相关。

2. **small-feedback 近似的误差界**：作者用一阶近似线性化 reduced form，但没有给出近似误差的界。一个开放问题是：当 \(\beta_{X \to Y} \beta_{Y \to X}\) 多大时，近似误差开始影响估计的偏差？这可以转化为一个**非线性联立方程组的扰动分析**问题。

3. **数据扰动的理论保证**：BayBiMR(DP) 通过数据扰动改善频率覆盖率，但作者没有解释为什么扰动有效，也没有给出覆盖率误差的阶。这与您熟悉的 **bootstrap 理论**和**高阶渐近**直接相关——可以用 Edgeworth 展开分析扰动的效果。

4. **与 CAUSE 的正式比较**：作者声称 BayBiMR 比 CAUSE 更灵活（允许随机相关多效性），但没有给出两者在相同数据下的正式比较（如 DIC、WAIC 或交叉验证）。一个开放问题是：在什么条件下，BayBiMR 的额外灵活性会转化为更好的预测或更准确的因果效应估计？

5. **LD 结构的处理**：本文假设 SNP 独立，但真实 GWAS 中 LD 不可忽略。一个开放问题是：如何将 LD 结构纳入 BayBiMR 的似然？这可能需要**矩阵正态分布**或**图模型**的工具——与您熟悉的**高维协方差估计**相关。

6. **多效性 SNP 的生物学解释**：spike-and-slab 先验将 SNP 分为"有效工具"和"多效性 SNP"，但后验分类的生物学意义是什么？一个开放问题是：后验概率 \(P(s_g = 1 | \text{data})\) 是否与已知的基因功能注释（如 eQTL、mQTL）相关？这需要**贝叶斯变量选择**与**功能基因组学**的结合。
