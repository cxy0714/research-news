### 一、领域脉络与小综述

- **这个方向是什么**：本文研究的根本问题是：当目标分布（如贝叶斯后验）随着逆温度参数 n 增大而越来越集中（concentrate）于有限个模态（mode）时，如何构造一个**计算上可行且理论上可保证**的采样/积分方案。核心思路是用"多模态 Laplace 近似"——即以负对数密度局部极小值为中心的高斯混合——作为 proposal distribution，然后通过重要性采样（IS）或独立 Metropolis-Hastings（IMH）来估计关于目标分布的期望。这个子方向处于"贝叶斯计算 + 渐近理论"的交叉地带，其成熟度在于：单模态 Laplace 近似的误差分析已有较完整理论（如 [24, 11, 25]），而多模态情形下的**非渐近、显式维度依赖**的误差界是当前活跃的研究前沿。

- **发展脉络（history）**：
  - **奠基工作**：Laplace 方法本身是经典渐近分析工具（[30] Wong 2001 的专著是标准参考）。将其用于贝叶斯后验近似并给出收敛性分析，可追溯到 [13] Hwang (1980) 关于概率测度弱收敛的 Laplace 方法。这些工作奠定了"用高斯分布近似集中测度"的基本思想。
  - **单模态误差分析**：Schillings, Sprungk, Wacker [24] (2020) 首次系统分析了 Laplace 近似在 Hellinger 距离下的收敛速率，证明在噪声水平 σ→0 时误差为 O(σ²)，并讨论了基于 Laplace 的 IS 和 QMC 的鲁棒性。这是本文最直接的"前作"，本文将其从单模态推广到多模态。Helin & Kretschmann [11] (2022) 进一步给出非渐近误差估计，显式刻画了非线性映射和维度的影响。Spokoiny [25] (2022) 则从高维角度出发，给出**维度无关**（dimension-free）的非渐近界，引入"有效维度" p_G 的概念，强调先验在高维中的非可忽略作用。Katsevich & Spokoiny [15] (2025) 统一并推广了上述结果，提出更精细的误差分解框架。
  - **多模态情形的挑战**：多模态 Laplace 近似的困难在于：(i) 需要知道所有局部极小值的位置；(ii) 模态间的权重（coefficients c_{n,k}）如何确定；(iii) 模态间的"隧道效应"（tunneling）导致 MCMC 混合缓慢。Hasenpflug, Rudolf, Sprungk [10] (2023) 研究了集中测度序列的 Wasserstein 收敛速率，为理解多模态情形的几何结构提供了基础。本文正是在此基础上，将 [24] 的单模态结果推广到多模态，并给出 IS 和 IMH 的效率分析。
  - **IMH 的收敛理论**：Mengersen & Tweedie [17] (1996) 给出了 IMH 几何遍历性的经典判据（权重函数有界）。Roberts & Rosenthal [20] (1997) 和 Gallegos-Herrada et al. [6] (2022) 进一步梳理了几何遍历性与谱隙、收敛速率之间的等价条件。本文利用这些工具，将 Laplace 近似的误差界转化为 IMH 的谱隙下界。
  - **本文的位置**：本文是上述两条线索（Laplace 近似误差分析 + IMH 收敛理论）的汇合点。它首次在**多模态、非渐近、显式维度依赖**的框架下，同时给出了 (i) Laplace 混合近似与目标分布的 Hellinger 距离界；(ii) 基于此 proposal 的 IS 有效样本量（ESS）和 IMH 谱隙的渐近行为。其创新点在于：将 [24] 的单模态 Hellinger 界推广到多模态，并利用 [10] 的 Wasserstein 结果处理模态间距离。

- **子线索聚类**：
  1. **Laplace 近似的误差分析**（[24], [11], [25], [15], [13]）：这一簇在回答"高斯近似与目标分布到底差多少"的问题，从渐近（n→∞）到非渐近，从固定维度到高维，从单模态到多模态。核心工具是 Taylor 展开、集中不等式、Hellinger/Total variation 距离的分解。
  2. **基于 Laplace 近似的蒙特卡洛方法**（[24], [1], [10], 本文）：这一簇关注"有了一个好的 proposal，如何用它做积分"。核心指标是 IS 的 ESS、IMH 的接受概率/谱隙/自相关。关键洞见（来自 [1] Agapiou et al. 2017）是：IS 的代价由 χ² 散度刻画，而 χ² 散度又由 proposal 与 target 的"有效维度"决定。
  3. **IMH 与 MCMC 的收敛理论**（[17], [20], [6], [2], [7], [29], [5]）：这一簇提供"proposal 与 target 的距离如何转化为链的混合速度"的桥梁。核心结果是：权重函数的有界性 ⇔ 均匀遍历性；权重函数的矩条件 ⇒ 多项式收敛（[5] Deligiannidis et al. 2024）。
  4. **高维 Laplace 近似的修正**（[14] Katsevich 2023, [16] Katsevich & Spokoiny 2025）：这一簇关注在高维情形下标准 Laplace 近似的失效模式，提出 skew correction 等改进。本文未直接涉及，但 [15] 的框架为本文的维度依赖分析提供了基础。

- **这个方向在追问的核心问题**：
  1. **Laplace 近似的误差如何随 n、维度 d、模态数 K 变化？** 现有答案（本文 Theorem 3.1/3.2）：Hellinger 距离以 n^{-1/2} 衰减，常数随 d 多项式增长（非渐近情形），但模态间距离的指数衰减会导致误差项中出现 e^{-n·dist} 形式的项。
  2. **基于 Laplace 近似的 IS/IMH 是否随 n 增大而变得更高效？** 现有答案（本文 Theorem 4.2/4.3/4.4）：是的。ESS 趋于总样本量 N（速率为 n^{-1} 的偏差），IMH 的接受概率趋于 1、谱隙趋于 1（速率为 n^{1-3q}，q∈(1/3,1/2)）。这与先验采样（prior-based IS）的 n^{-d/2} 恶化形成鲜明对比。
  3. **如何确定多模态 Laplace 近似的权重 c_{n,k}？** 本文采用"局部 Laplace 近似的归一化常数之比"（即 c_{n,k} ∝ det(H_k)^{-1/2} π_k），但未讨论模态搜索（mode finding）的计算代价。这是一个被淡化的实际困难。
  4. **当模态数 K 随 n 增长时，理论是否仍然成立？** 本文假设 K 固定。若 K 随 n 增长（如高维参数空间中的大量局部极小），误差界中的 K 因子会如何影响？这是开放问题。

- **⚠️ 作者的 framing（这是作者的说法）**：作者将缺口 frame 为"**多模态 Laplace 近似的非渐近误差分析及其在 IS/IMH 中的效率保证**"。他们声称：(i) 现有单模态结果 [24] 无法处理多模态目标；(ii) 现有高维结果 [25, 15] 未给出采样方法的效率分析；(iii) 本文首次在统一框架下同时处理近似误差和采样效率。被淡化或回避的竞争路线包括：(a) **模态搜索的计算代价**——作者假设所有模态已知，但实际中寻找所有局部极小值是 NP-hard 的；(b) **自适应方法**（如 variational inference 或 SMC），这些方法不需要显式枚举模态，但缺乏本文这种理论保证；(c) **MCMC 的全局混合**（如 parallel tempering），这类方法不依赖 Laplace 近似，但收敛速度难以刻画。**什么明显该被引 / 该存在、却没出现在 intro 里？**——作者未引用关于**模式搜索/优化**的文献（如梯度下降的全局收敛性分析），也未引用**贝叶斯神经网络中模态对称性**的专门研究（如神经元置换对称性导致的模态结构），尽管他们在数值实验中使用了这一例子。这暗示作者有意将"模态已知"作为理想化假设，回避了实际应用中最困难的部分。

- **张力**：未见明显对立引用。但存在一个微妙的张力：**单模态 Laplace 近似的误差界（如 [24] 的 O(n^{-1})）与本文多模态情形的 O(n^{-1/2}) 之间的差距**。作者将这一差距归因于模态间权重的估计误差（c_{n,k} 的收敛速度），但未讨论是否可以通过更精细的权重估计（如高阶展开）来恢复 n^{-1} 速率。另一个张力是：**高维结果 [25] 强调"维度无关"的界，而本文的界虽然多项式依赖于 d，但指数依赖于模态间距离**。在模态间距很小（几乎重叠）时，本文的界可能比单模态结果更差，但作者未讨论这一退化情形。


### 二、最核心、最简单的例子 / 数学问题

**第一步：把符号、模型、可观测数据交代清楚**

- **目标分布（target）**：π_n(dx) ∝ e^{-n Φ_n(x)} π_0(dx)，定义在 (R^d, B(R^d)) 上。
  - n ∈ N：逆温度参数（可理解为样本量或精度）。n 越大，分布越集中。
  - Φ_n : R^d → [0, ∞)：势函数（负对数似然/负对数密度），允许依赖 n。
  - π_0：参考分布（先验），假设有 Lebesgue 密度，且 π_0 ∈ C²(R^d, (0,∞))。
  - Z_n = ∫ e^{-nΦ_n(x)} π_0(dx)：归一化常数（配分函数），**不可直接计算**，是推断的难点。

- **多模态 Laplace 近似（proposal）**：L^K_{π_n}(dx) = (1/\hat{Z}^K_n) Σ_{k=1}^K π_n^{(k)} exp(-n/2 ‖x - x_n^{(k)}‖²_{H_n^{(k)}}) dx。
  - K ∈ N：模态个数（假设已知且固定）。
  - x_n^{(1)}, …, x_n^{(K)}：Φ_n 的局部极小值点（**假设已知**，这是理想化假设）。
  - H_n^{(k)} = ∇² Φ_n(x_n^{(k)})：在模态处的 Hessian（正定，由假设保证）。
  - π_n^{(k)} = e^{-nΦ_n(x_n^{(k)})} π_0(x_n^{(k)})：模态 k 的"未归一化权重"。
  - \hat{Z}^K_n = Σ_{k=1}^K π_n^{(k)} (2π/n)^{d/2} det(H_n^{(k)})^{-1/2}：归一化常数，**可解析计算**。
  - 注意：L^K_{π_n} 是**可采样**的（高斯混合），且其密度可逐点求值。

- **可观测数据**：研究者**能观测/计算**的是：
  - 对任意 x ∈ R^d，能求值 Φ_n(x)、∇Φ_n(x)、∇²Φ_n(x)（即能算对数密度及其导数）。
  - 能通过数值优化找到局部极小值 x_n^{(k)} 和 Hessian H_n^{(k)}。
  - 能从 L^K_{π_n} 中采样（高斯混合采样）。
  - **不能**直接计算 Z_n，也不能直接从 π_n 采样。
  - 目标：计算 E_{π_n}[f] = ∫ f dπ_n，其中 f 是某个感兴趣的量（如预测均值、方差）。

- **关键量**：
  - 权重函数 w_n(x) = dπ_n/dL^K_{π_n}(x) = (Z_n / \hat{Z}^K_n)^{-1} · e^{-nΦ_n(x)}π_0(x) / [Σ_k π_n^{(k)} exp(-n/2 ‖x-x_n^{(k)}‖²_{H_n^{(k)}})]。
  - χ²(π_n ‖ L^K_{π_n}) = E_{L^K_{π_n}}[w_n²] - 1：衡量 proposal 与 target 的失配程度，是 IS 效率的核心。
  - ‖w_n‖_∞：权重函数的上确界，决定 IMH 的谱隙。

**第二步：讲最小内核**

把上述一般设定全部剥掉，考虑**最简单、最能体现核心思想**的情形：

- **设定**：d = 1，K = 2，π_0 ≡ 1（平坦先验，在 R 上，可想象为截断在足够大的区间上），Φ_n(x) = Φ(x) 不依赖 n，且 Φ 有两个全局极小值点 x_1^* = -1 和 x_2^* = +1，Φ(x_1^*) = Φ(x_2^*) = 0，Φ''(x_1^*) = Φ''(x_2^*) = 1。于是：
  - π_n(dx) ∝ e^{-nΦ(x)} dx，当 n 大时，π_n 集中在 x = ±1 附近，各占约 1/2 质量。
  - 多模态 Laplace 近似：L^K_{π_n} = (1/2) N(-1, 1/n) + (1/2) N(+1, 1/n)，即两个方差为 1/n 的高斯各半混合。

- **要回答的问题**：π_n 与 L^K_{π_n} 的 Hellinger 距离 d_H(π_n, L^K_{π_n}) 以什么速率随 n 衰减？

- **核心观察**：在 x = +1 附近，π_n 的密度 ≈ e^{-n/2 (x-1)²}（因为 Φ 在极小值处二阶展开），而 L^K_{π_n} 的密度 ≈ (1/2) · (n/2π)^{1/2} e^{-n/2 (x-1)²}。两者只差一个常数因子 (1/2)·(n/2π)^{1/2} / Z_n^{-1}。**关键在于这个常数因子是否被正确估计**——L^K_{π_n} 的权重 c_{n,k} = 1/2 恰好等于 π_n 分配给每个模态的渐近质量（因为两个极小值对称），所以常数因子匹配，Hellinger 距离只来自 Taylor 展开的高阶项（三阶及以上），贡献为 O(n^{-1/2})。

- **为什么难**：如果 Φ 在 x = -1 和 x = +1 处的二阶导数不同（比如 Φ''(-1) = 1, Φ''(+1) = 2），那么 π_n 分配给两个模态的质量比 ≈ (Φ''(-1))^{-1/2} : (Φ''(+1))^{-1/2} = 1 : 1/√2，而 L^K_{π_n} 若仍用等权重 c_{n,k} = 1/2，就会产生 O(1) 的 Hellinger 距离——proposal 完全失效。正确的权重必须是 c_{n,k} ∝ det(H_n^{(k)})^{-1/2} π_n^{(k)}，这正是本文定义的权重。**最小内核的数学本质**：多模态 Laplace 近似的误差由两部分组成——(i) 每个模态内部的"高斯近似误差"（来自三阶及以上 Taylor 项），贡献 O(n^{-1/2})；(ii) 模态间权重估计误差（来自 c_{n,k} 与真实模态质量的偏差），贡献 O(n^{-1/2})（因为 c_{n,k} 的估计误差本身是 O(n^{-1}) 量级，但会通过 Hellinger 距离的平方根放大为 O(n^{-1/2})）。本文的核心定理（Theorem 3.2）就是在一般条件下同时控制这两部分。

- **一句话总结**：本文在数学上干的事是——**证明"用局部 Hessian 信息构造的高斯混合"与"集中分布"之间的 Hellinger 距离以 n^{-1/2} 速率收敛，且常数仅随维度多项式增长，并由此推出基于该混合的 IS 和 IMH 算法的效率随 n 增大而趋于最优**。


### 三、这篇论文做了什么

**三句话**：
1. **研究了什么问题**：当目标分布 π_n ∝ e^{-nΦ_n}π_0 随 n 增大而集中于有限个模态时，多模态 Laplace 近似 L^K_{π_n}（高斯混合）与 π_n 的 Hellinger 距离的收敛速率，以及基于 L^K_{π_n} 作为 proposal 的自归一化重要性采样（SNIS）和独立 Metropolis-Hastings（IMH）算法的效率。
2. **核心工具/方法**：将 Hellinger 距离分解为"模态内部"和"模态之间"两部分；模态内部用 Taylor 展开和 Gaussian 积分控制（推广 [24] 的单模态结果），模态之间用权重函数的逐点界和集中不等式控制；对 IS 和 IMH 的效率，分别用 χ² 散度和权重函数上确界 ‖w_n‖_∞ 来刻画。
3. **主要结论**：在适当的正则性条件下，(i) d_H(π_n, L^K_{π_n}) = O(n^{-1/2})，常数随 d 多项式增长（Theorem 3.1 渐近、Theorem 3.2 非渐近）；(ii) SNIS 的 ESS 满足 ESS/N → 1（概率收敛），速率为 n^{-1+δ}（Theorem 4.2）；(iii) IMH 的平均接受概率 → 1、谱隙 → 1（Theorem 4.3/4.4），速率为 n^{-1/2}（接受概率）和 n^{1-3q}（谱隙，q∈(1/3,1/2)）。

**关键设定与假设**（在最小记号基础上补全）：
- **正则性假设**（Assumption 1）：Φ_n ∈ C³(R^d, [0,∞))；存在有限个模态 x_n^{(1)},…,x_n^{(K)}，Hessian 一致正定（H_n^{(k)} ⪰ ρ² I_d，ρ>0）；三阶导数在模态邻域内一致有界（‖D³Φ_n(x)‖ ≤ M，对 x 在邻域内）；模态邻域两两不交。
- **尾部假设**（Assumption 2，渐近版本）：在模态邻域之外，Φ_n 有正的下界（inf > ε>0），且存在可积控制函数 g 使得 e^{-nΦ_n}π_0 ≤ g（保证尾部可忽略）。
- **尾部假设**（Assumption 3，非渐近版本）：更强的 Gaussian 型尾部控制：在模态邻域之外，e^{-nΦ_n(x)} ≤ Σ_k π_n^{(k)} exp(-nδ‖x-x_n^{(k)}‖²_{H_n^{(k)}})，δ>0。这比 Assumption 2 更强，但允许显式的非渐近常数。
- **与已有文献的比较**：相比 [24] 的单模态假设，本文允许 K ≥ 1 个模态，且不要求模态权重已知；相比 [25] 的高维框架，本文的假设更偏向"低维但多模态"的情形，且显式处理了模态间距离对误差的影响。相比 [10] 的 Wasserstein 结果，本文关注 Hellinger 距离（对 IS/IMH 更自然），且给出了非渐近常数。

**主要结果**：
- **Theorem 3.1（渐近 Hellinger 界）**：在 Assumption 1 和 2 下，d_H(π_n, L^K_{π_n}) = O(n^{-1/2})。证明思路：将 Hellinger 距离平方分解为模态邻域内和尾部两部分；邻域内用 Taylor 展开将 π_n 的密度写成 Gaussian 密度乘以 (1 + O(n^{-1/2}‖x-x_k‖³)) 的形式，然后与 L^K_{π_n} 的 Gaussian 项比较；尾部用 Assumption 2 的指数衰减控制。
- **Theorem 3.2（非渐近 Hellinger 界）**：在 Assumption 1 和 3 下，对每个 n ∈ N，d_H(π_n, L^K_{π_n}) ≤ 13 d^{3/2} M/(n^{1/2} ρ³) + 2^{d/2+2} exp(-ρ² n^{1-2q}/(8M^{2/3}))（其中 q∈(1/3,1/2)，R = ρ²/M^{2/3}）。第一项来自模态内部的 Taylor 余项，第二项来自尾部。**关键点**：常数对 d 是多项式的（d^{3/2}），对 K 是线性的（隐含在求和项中），对 n 的依赖是 n^{-1/2} + 指数衰减。
- **Theorem 4.2（SNIS 的 ESS）**：在 Assumption 1 和 3 下，对任意 δ>0，有 ESS_n/N → 1（概率收敛），且 1 - ESS_n/N = O_p(n^{-1+δ})。证明思路：ESS/N = 1/(1+χ²(π_n‖L^K_{π_n}))，而 χ² 由 Hellinger 距离控制（χ² ≤ 4 d_H²/(1-d_H²) 当 d_H < 1），结合 Theorem 3.2 即得。
- **Theorem 4.3（IMH 的接受概率）**：在 Theorem 3.1 或 3.2 的假设下，平均接受概率 E_{π_n⊗L^K_{π_n}}[α_n] → 1，且 1 - E[α_n] = O(n^{-1/2})。证明思路：接受概率 α_n(x,y) = 1 ∧ w_n(y)/w_n(x)，其期望与 Hellinger 距离通过不等式 E[1-α] ≤ 2 d_H(π_n, L^K_{π_n}) 联系。
- **Theorem 4.4（IMH 的谱隙）**：在 Corollary 3.2 的条件下（即 δ≥1/2 且 n 足够大），谱隙 gap_{π_n}(M_n) ≥ 1 - O(n^{1-3q}) → 1。证明思路：利用 Proposition 4.2 的谱隙下界 gap ≥ 1/‖w_n‖_∞，结合 ‖w_n‖_∞ ≤ 1 + O(n^{1-3q})（由 Theorem 3.2 的尾部控制导出）。

**证明路线与技术技巧**：
- **整体路线**：三步走。第一步（Section 3）：证明 L^K_{π_n} 逼近 π_n 的 Hellinger 误差界。第二步（Section 4.1）：将 Hellinger 界转化为 SNIS 的 ESS 下界。第三步（Section 4.2）：将 Hellinger 界转化为 IMH 的接受概率和谱隙的界。
- **关键跳跃点**：
  1. **模态内部 Taylor 展开的余项控制**（Lemma A.3 的核心）：需要将 e^{-nΦ_n(x)} 在模态 x_n^{(k)} 附近展开为 e^{-n/2‖x-x_k‖²_{H_k}} · (1 + R_n(x))，其中余项 R_n(x) 需要被控制在 O(n^{-1/2}‖x-x_k‖³) 的量级。难点在于：余项中的三阶导数项 D³Φ_n 需要一致有界（Assumption 1(iii)），且模态邻域的半径需要随 n 收缩（取 R = ρ²/M^{2/3}，与 n 无关，但要求 n 足够大使得邻域内三阶项远小于二次项）。
  2. **尾部积分的指数衰减**（Assumption 3 的作用）：在模态邻域之外，需要证明 ∫_{V^c} e^{-nΦ_n}π_0 dx 相对于 Gaussian 积分的归一化常数可忽略。Assumption 3 直接给出了 Gaussian 型上界，使得尾部积分可以用 Lemma A.2（Gaussian 尾部估计）控制为 e^{-n^{1-2q}·const}。
  3. **权重函数的逐点界**（Proposition B.1）：证明 w_n(x) = dπ_n/dL^K_{π_n}(x) 在"高概率区域"（即模态邻域并集）内满足 1 - c n^{1-3q} ≤ w_n(x) ≤ 1 + c n^{1-3q}。这需要同时控制分子（π_n 的密度）和分母（L^K_{π_n} 的密度）的偏差，且要求模态间距离足够大（由 Assumption 1(i) 的邻域不交保证）。
  4. **谱隙下界**（Proposition 4.2）：证明 IMH 的谱隙 gap ≥ 1/‖w_n‖_∞。这是经典结果（Mengersen-Tweedie 1997），但本文给出了自包含的证明，利用"全空间是小集"这一事实（因为 w_n 有界）。
- **技术技巧点名**：
  - **Hellinger 距离的平方分解**：将 d_H² 分解为模态邻域内和尾部两部分，分别控制。
  - **Gaussian 积分与 Gamma 函数的估计**（Lemma A.1）：用于计算 Gaussian 分布的高阶矩，得到 d 的多项式依赖。
  - **Gaussian 尾部估计**（Lemma A.2）：用于控制模态邻域外的积分，得到 e^{-n·const} 的指数衰减。
  - **权重函数的"归一化常数比"技巧**：将 w_n(x) 写成 (Z_n/\hat{Z}^K_n)^{-1} · [e^{-nΦ_n}π_0] / [Σ_k π_k e^{-n/2‖·‖²}]，然后分别估计 Z_n/\hat{Z}^K_n 和逐点比值。
  - **Markov 链谱隙的"小集"论证**：利用 w_n 的有界性，直接构造谱隙下界，避免复杂的漂移条件验证。

**真实例子与应用**：
- **简单例子（Section 5.1）**：d ∈ {1,…,7}，π_0 = N(0, I_d)，G 为多项式映射（G_1 = x_1² + x_1, G_2 = 2x_2 + x_1², …），观测 y = 2_d + 噪声。后验 π_n 有 K = 2（d ≤ 4）或 K = 4（d ≥ 5）个模态。作者比较了 Laplace-based IS 和 prior-based IS 的 ESS，以及 Laplace-based IMH 的接受概率和自相关。结果显示：Laplace-based IS 的 ESS/N 以 n^{-1} 速率趋于 1（与 Theorem 4.2 一致），而 prior-based IS 的 ESS/N 以 n^{-d/2} 速率趋于 0（维度灾难）。Laplace-based IMH 的接受概率以 n^{-1/2} 速率趋于 1，自相关以 n^{-1/2} 速率趋于 0。
- **贝叶斯神经网络（Section 5.2）**：一个单隐层、2 个神经元的 MLP，输入 1 维，输出 1 维。由于神经元的排列对称性（permutation symmetry），后验有 K = 2 个对称模态。作者用 Laplace-based IS 和 IMH 估计预测均值，并与 Hamiltonian Monte Carlo (HMC) 对比。结果显示：Laplace-based 方法在 n 较大时（数据量增大）效率接近 HMC，且计算成本远低于 HMC。**这个例子特别重要**，因为它展示了多模态 Laplace 近似的实际动机：神经网络后验的模态对称性是结构性的（不是噪声引起的），而单模态 Laplace 近似会完全失效。
- **例子想说明什么**：(i) 理论速率（n^{-1/2} 或 n^{-1}）在有限 n 下即可观察到；(ii) 维度 d 的影响主要体现在常数项而非速率；(iii) 多模态 Laplace 近似在实际问题（如 BNN）中是可行的，只要模态已知且 Hessian 可计算。


### 四、开放问题

1. **模态数 K 随 n 增长的情形**：本文假设 K 固定。若 K = K_n 随 n 增长（例如高维参数空间中局部极小值的数量随数据量增加），Hellinger 界中的 K 因子会如何影响收敛速率？是否存在 K_n 的临界增长速率使得 n^{-1/2} 速率仍然成立？——扎根于 Theorem 3.2 的常数项对 K 的线性依赖。

2. **模态搜索的计算代价**：本文假设所有模态 x_n^{(k)} 已知，但实际中寻找所有局部极小值是 NP-hard 的。是否存在高效的模态搜索策略（如随机初始化 + 局部优化）能保证以高概率找到所有"重要"模态（即权重 c_{n,k} 非零的模态）？——扎根于 Section 2 中"假设模态已知"的理想化设定。

3. **权重 c_{n,k} 的估计误差**：本文的权重 c_{n,k} 由局部 Laplace 近似的归一化常数之比给出，但未分析 Hessian 估计误差（当 Hessian 只能近似计算时）对 Hellinger 界的影响。若 Hessian 估计有 O(n^{-α}) 的误差，Hellinger 界会如何退化？——扎根于 Theorem 3.2 证明中对 Hessian 精确已知的依赖。

4. **高维情形的维度依赖**：本文的常数随 d 多项式增长，但多项式次数是多少？对于 d 很大（如 d ~ n）的情形，n^{-1/2} 速率是否仍然成立？——扎根于 Theorem 3.2 中 d^{3/2} 的显式常数。

5. **IMH 的亚几何收敛**：当 δ ≤ 1/2 时（即 Assumption 3 不满足），IMH 可能不再几何遍历。此时能否给出多项式收敛速率？——扎根于 Theorem 4.4 对 δ > 1/2 的依赖，以及 [5] 中关于无界权重函数的亚几何收敛结果。

6. **大数据极限的理论覆盖**：本文的理论主要针对小噪声极限（Φ_n 不依赖 n 或弱依赖），但数值实验显示大数极限也有类似行为。能否在更一般的 Φ_n 依赖 n 的设定下证明类似的 Hellinger 界？——扎根于 Section 5.1 中"大数极限"的数值观察与理论未覆盖之间的 gap。
