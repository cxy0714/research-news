### 一、领域脉络与小综述

#### 这个方向是什么

本文所处的子方向是**随机动力系统的极端事件概率估计**，其根本科学问题是：对于由小噪声随机微分方程（SDE）或随机偏微分方程（SPDE）驱动的复杂系统，如何高效且精确地估计其罕见事件（如污染物浓度超标、结构失效）的发生概率。该方向的成熟度处于"理论框架已建立、数值方法正待突破"的阶段——大偏差理论（Large Deviation Theory, LDT）提供了指数尺度的渐近估计，但精确到多项式尺度的"prefactor"计算在高维和无限维情形下仍是一个开放的计算挑战。

#### 发展脉络（history）

- **奠基工作**：Freidlin–Wentzell 理论（[41]）建立了小噪声随机扰动系统的大偏差原理，将极端事件概率的指数衰减率归结为作用量泛函的最小值问题。这是整个领域的基石，但只给出了对数尺度的精度（即 rate function I(z)）。
- **主要进展**：Ben Arous（[9]，1988）在 Wiener 空间上建立了 Laplace 方法的严格理论，将大偏差估计提升到"sharp"级别——即不仅给出指数项，还给出多项式 prefactor。这一理论工作为本文提供了数学基础。同期，Grafke 与 Vanden-Eijnden 等（[51, 92]）发展了"instanton 方法"的数值实现，将寻找大偏差最小化子（instanton）转化为可计算的优化问题。
- **近期进展**：Schorlepp 等人（[93]，2023）将上述方法系统化，针对**加性噪声** SDE 提出了可扩展的 prefactor 计算方法，并成功应用于高维 SPDE（如三维 Navier-Stokes 方程）。这是本文的直接前作。
- **当前 frontier 与本文位置**：加性噪声情形的可扩展算法已解决，但**乘性噪声**（即扩散系数依赖于状态变量）的情形仍缺乏可扩展的数值方法。本文正是填补这一缺口——将 [93] 的算法框架推广到乘性噪声，并指出 naive 的有限维离散化方法在此情形下会失效，需要引入 Carleman–Fredholm 行列式和正则化技巧。

#### 子线索聚类

被引文献大致落在三条子线索上：

1. **大偏差理论与 Laplace 方法的严格数学基础**（[9, 41, 61, 80, 103]）：这一簇在建立"极端事件概率的渐近展开"的严格理论，包括 Schilder 定理、Varadhan 引理、Wiener 空间上的 Laplace 方法等。核心问题是：在什么条件下，概率的渐近展开是有效的？prefactor 的数学表达式是什么？
2. **数值算法与计算实现**（[51, 92, 93, 107]）：这一簇关注如何将理论结果转化为可计算的算法——包括 instanton 的数值求解（最小作用量路径）、Hessian 算子的特征值计算、以及如何利用自动微分实现黑盒式实现。核心问题是：如何在高维离散化下保持计算效率？
3. **可靠性工程中的 SORM 方法**（[19, 20, 32, 58, 83]）：这是工程应用侧的线索，关注结构可靠性分析中的一阶/二阶可靠性方法（FORM/SORM），其核心思想与 Laplace 方法一致，但通常限于有限维参数空间。本文的贡献之一是将这些工程方法与无限维的数学理论连接起来。

#### 这个方向在追问的核心问题

1. **如何计算 prefactor？** 大偏差理论给出 P ≈ exp(-I(z)/ε)，但 prefactor C(z) 的精确计算涉及 Hessian 算子的行列式，在无限维空间中需要正则化。这是本文的核心问题。
2. **如何保证数值可扩展性？** 当时间离散化 n_t 和空间维度 n 增大时，naive 的矩阵方法（如显式构造 Hessian 矩阵并计算行列式）的计算量会急剧增长。本文的目标是设计一种计算量不随分辨率恶化的算法。
3. **乘性噪声与加性噪声的本质区别是什么？** 加性噪声下 Hessian 算子是"恒等算子 + 紧算子"的形式，其 Fredholm 行列式可以直接定义；而乘性噪声下会出现更复杂的结构，需要 Carleman–Fredholm 行列式，且 naive 离散化会引入虚假的"紫外发散"。

#### ⚠️ 作者的 framing（这是作者的说法）

作者将缺口 frame 成：**"naive 地将有限维 SORM 公式应用于乘性噪声 SDE 的离散化会失效，因为 Hessian 算子不再是 trace class，需要正确的无限维理论来指导数值方法。"** 具体而言，作者声称：
- 乘性噪声下，naive 离散化的 Hessian 矩阵的特征值呈现 ∝ i^(-1) 的衰减（而非加性噪声下的 ∝ i^(-2)），导致特征值之积（即行列式）不收敛；
- 正确的做法是使用 Carleman–Fredholm 行列式，并显式地减去一个"发散项"（即文中的 ⟨e_z, Ã_z e_z⟩ 项）；
- 这一修正项恰好对应 Itô–Stratonovich 修正，从而在物理上有清晰解释。

作者淡化的竞争路线包括：基于蒙特卡洛的重要性采样方法（[23]）、子集模拟等。这些方法在低维可行，但在高维和极低概率（如 10^-8 以下）时效率不足。

#### 张力

未见明显对立引用。但值得注意的是，[94, 102] 等可靠性工程文献对 SORM 在高维下的实用性持怀疑态度，认为其"维度灾难"不可避免。本文的贡献正是回应这一质疑——通过利用问题的无限维结构（而非回避它），实现了维度无关的计算复杂度。这一"正面回应"而非"回避"的策略，是本文与工程文献中常见降维思路（如 [4] 的 active subspace 方法）的关键区别。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

**符号**（逐个点名）：

| 符号 | 含义 | 类型 |
|------|------|------|
| ε > 0 | 噪声强度参数，趋于 0 | 标量参数 |
| X^ε_t ∈ R^n | SDE 的状态过程 | 随机过程 |
| b: R^n → R^n | 漂移项 | 已知函数 |
| σ: R^n → R^{n×n} | 扩散系数（乘性噪声的关键） | 已知函数 |
| W_t | 标准 n 维 Brownian 运动 | 随机过程 |
| f: R^n → R | 观测函数（最终时刻的标量输出） | 已知函数 |
| z ∈ R | 极端事件的阈值 | 标量参数 |
| P^ε(z) = P[f(X^ε_T) ≥ z] | 目标量：极端事件概率 | **待估的 estimand** |
| F: L²([0,T], R^n) → R | 噪声到观测的映射（noise-to-observable map） | 确定性泛函 |
| η ∈ L²([0,T], R^n) | 噪声实现（L² 空间中的函数） | 随机变量（白噪声的"原像"） |
| I(z) | rate function，I(z) = min_{η: F[η]=z} ½‖η‖² | 标量函数 |
| η_z | instanton，上述优化问题的唯一最小子 | **参数（待求）** |
| λ_z | Lagrange 乘子，λ_z = I'(z) | 标量参数 |
| A_{λ_z} | 拉格朗日函数的二阶变分算子（Hessian） | 无限维算子 |
| Ã_{λ_z} | 乘性噪声特有的"奇异部分"算子 | 无限维算子 |
| C(z) | prefactor | **标量参数（待求）** |
| n_t | 时间离散化步数 | 数值参数 |
| n_x | 空间离散化模式数（SPDE 情形） | 数值参数 |

**模型**（数据生成机制）：

考虑 Itô 型 SDE：
```
dX^ε_t = b(X^ε_t) dt + √ε σ(X^ε_t) dW_t,    X^ε_0 = x
```
其中 ε 是小参数。我们关心的是最终时刻观测 f(X^ε_T) 超过阈值 z 的概率 P^ε(z)。

**可观测数据**：在实际应用中，研究者可以观测到：
1. 漂移 b 和扩散 σ 的解析表达式（或高精度数值近似）；
2. 初始条件 x；
3. 观测函数 f 和阈值 z。

**不可观测 / 潜在量**：噪声实现 η（即驱动 SDE 的 Brownian 路径）本身是不可观测的，它是潜在变量。instanton η_z 是"最可能"导致极端事件的噪声实现，是推断的目标。

#### 第二步：最小内核

**核心数学问题**：计算极端事件概率的 sharp 渐近展开
\[
P^\varepsilon(z) \;\underset{\varepsilon \downarrow 0}{\sim}\; \varepsilon^{1/2} (2\pi)^{-1/2} C(z) \exp\left(-\frac{1}{\varepsilon} I(z)\right)
\]
其中 I(z) 由 instanton 优化问题给出，而 C(z) 是 prefactor。

**最简特例**：考虑一维几何 Brownian 运动（GBM），这是乘性噪声的最简非平凡例子：
```
dX^ε_t = -β X^ε_t dt + √(2ε) X^ε_t dW_t,    X^ε_0 = 1
```
观测 f(x) = ½(log x)²，阈值 z > 0。

**在这个特例下，要证的命题退化成什么？**

1. **Instanton 问题**：最小化 ½∫₀ᵀ η(t)² dt 约束 F[η] = z。对于 GBM，可以解析求解：η_z(t) = -√(2βz/T)（常数），对应的最优路径为 X_z(t) = exp(-βt/(1-2λT))，其中 λ = I'(z) = √(βz/(2T))。

2. **Prefactor 计算**：naive 的有限维 SORM 公式给出
   C_naive = [det(I - A_λ)]^(-1/2)
   其中 A_λ 是离散化的 Hessian 矩阵。但计算发现，A_λ 的特征值 μ_i ≈ 2λT/i（而非加性噪声下的 ∝ 1/i²），因此特征值之积 ∏(1 - μ_i) 不收敛——这就是"naive 方法失效"的具体含义。

3. **正确的 prefactor**：定理 2.1 告诉我们，正确的公式是
   C(z) = [2I(z)]^{-1/2} det₂(I - A_λ)^(-1/2) × exp(½⟨e_z, Ã_λ e_z⟩)
   其中 det₂ 是 Carleman–Fredholm 行列式（对非 trace-class 但 Hilbert–Schmidt 的算子定义），而 Ã_λ 是"奇异部分"。在 GBM 例子中，det₂(I - A_λ) = 1（因为 A_λ 的秩为 1），而 ⟨e_z, Ã_λ e_z⟩ = -2λT，因此
   C(z) = [2I(z)]^{-1/2} × exp(-λT) = [2I(z)]^{-1/2} × exp(-√(βzT/2))
   
   这与精确解（对数正态分布的矩生成函数）完全吻合。

**为什么这个例子是"最小内核"？**

- 它展示了乘性噪声与加性噪声的本质区别：Hessian 算子从 trace-class 退化为 Hilbert–Schmidt，导致 naive 行列式发散；
- 它揭示了正确的"重整化"步骤：减去 Ã_λ 的迹（对应 Itô–Stratonovich 修正），使得剩余部分是良定义的；
- 它说明 Carleman–Fredholm 行列式不是抽象的理论工具，而是可以数值计算的量。

**一般情形的推广**：对于一般的乘性噪声 SDE，A_λ 的特征值衰减为 ∝ 1/i（而非加性噪声的 1/i²），因此需要：
- 用 Carleman–Fredholm 行列式替代 Fredholm 行列式；
- 显式计算"发散部分"的迹（即 ⟨e_z, Ã_λ e_z⟩ 项）；
- 利用自动微分实现黑盒式的算子-向量乘积，从而用迭代特征值求解器（如 ARPACK）计算前 M 个特征值。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：如何高效计算乘性噪声 SDE/SPDE 中极端事件概率的 sharp 渐近估计（即 SORM 估计量），使得计算复杂度不随时间/空间离散化精度恶化。
2. **核心工具/方法**：将 [93] 中针对加性噪声的 scalable SORM 方法推广到乘性噪声，核心创新是识别出 Hessian 算子从 trace-class 退化为 Hilbert–Schmidt，需要用 Carleman–Fredholm 行列式替代 Fredholm 行列式，并显式处理 Itô–Stratonovich 修正项。
3. **主要结论**：通过两个数值例子（捕食者-猎物模型和二维随机平流扩散方程）证明，修正后的 SORM 估计量与蒙特卡洛模拟高度吻合，且计算成本不随分辨率显著增长；而 naive 的有限维 SORM 方法在乘性噪声下会失效。

#### 关键设定与假设

- **SDE 设定**：Itô 型 SDE (2.12)，漂移 b 和扩散 σ 满足足够的正则性条件（光滑性、有界性等），保证大偏差原理和 Laplace 方法的适用性。
- **唯一性假设**：对每个 z，存在唯一且非退化的 instanton η_z（即拉格朗日函数的海森矩阵在约束子空间上正定）。这是定理 2.1 的核心假设，对应 (2.8)。
- **可微性假设**：噪声到观测的映射 F 足够光滑（至少 C³），以保证二阶变分的良定义。
- **低秩假设**：扩散系数 σ 的秩远小于状态空间维度 n（在 SPDE 例子中，随机强迫只作用于少数 Fourier 模式），这是计算可扩展性的关键。
- **相比 [93] 的放宽/强化**：本文放宽了 σ 为常数的限制（允许 σ = σ(X_t)），但强化了对 σ 的正则性要求（需要 σ 及其导数有界），以保证 Ã_λ 是 Hilbert–Schmidt 算子。

#### 主要结果

**定理 2.1**（核心理论结果）：对于乘性噪声 SDE (2.12)，在唯一非退化 instanton 假设下，极端事件概率的 sharp 渐近展开为
\[
P^\varepsilon(z) \;\underset{\varepsilon \downarrow 0}{\sim}\; \varepsilon^{1/2} (2\pi)^{-1/2} C(z) \exp\left(-\frac{1}{\varepsilon} I(z)\right)
\]
其中 prefactor 由 (2.23) 给出：
\[
C(z) = \left[2I(z) \det_2\left(I - \mathrm{pr}_{\eta_z^\perp} A_{\lambda_z} \mathrm{pr}_{\eta_z^\perp}\right)\right]^{-1/2} \exp\left\{\frac{1}{2}\left\langle e_z, \tilde{A}_{\lambda_z} e_z\right\rangle\right\}
\]
这里 det₂ 是 Carleman–Fredholm 行列式，Ã_λ 是 (2.24)-(2.25) 定义的"奇异部分"算子。

**关键的技术创新**：
1. **识别出 Ã_λ 的结构**：Ã_λ 对应"单次积分"的路径（即从噪声到状态只有一次积分），其核函数是 σ(φ_z(t))∇σ(φ_z(t))θ_z(t) 的某种组合。这个算子是 Hilbert–Schmidt 但不是 trace-class，因此需要 Carleman–Fredholm 行列式。
2. **可计算的修正项**：⟨e_z, Ã_λ e_z⟩ 可以用一个额外的 ODE 求解来计算（(4.5) 中的 ˜γ^(1)），不需要显式构造 Ã_λ 的矩阵表示。
3. **自动微分实现**：利用 JAX 的 `jax.jvp` 和 `jax.grad` 实现黑盒式的算子-向量乘积，从而可以用迭代特征值求解器计算 Carleman–Fredholm 行列式的前 M 个特征值。

#### 证明路线与技术技巧

**整体路线**（4 步）：
1. **从有限维到无限维**：先证明有限维离散化的 SORM 公式 (2.17) 在 n_t → ∞ 时发散（因为特征值 ∝ 1/i 导致乘积不收敛），从而说明需要新的理论。
2. **识别发散源**：通过 Wiener-Itô 混沌分解（附录 D.2.2），将二阶变分算子 A_λ 分解为"正则部分"（trace-class）和"奇异部分"（Ã_λ，仅 Hilbert–Schmidt）。奇异部分对应 Itô 积分的"非适应"部分。
3. **重整化**：证明正确的 prefactor 应该用 Carleman–Fredholm 行列式 det₂(I - A_λ) 替代 Fredholm 行列式 det(I - A_λ)，并乘以 exp(½⟨e_z, Ã_λ e_z⟩) 修正项。这个修正项恰好抵消了 naive 离散化中的发散。
4. **数值验证**：通过两个例子验证理论结果，并展示算法的可扩展性。

**关键引理/技巧**：
- **Goodman 定理**（附录 D.2.4，定理 D.18）：用于证明 A_λ - Ã_λ 是 trace-class。这是整个证明的基石——它保证了"减去奇异部分后，剩余部分是良定义的"。
- **Wiener-Itô 混沌分解**（附录 D.2.2）：将随机变量分解为不同阶的混沌分量，从而将二阶变分算子的谱性质与 Itô 积分的迭代结构联系起来。
- **Carleman–Fredholm 行列式的性质**（附录 D.2.1，定义 D.6）：对于 Hilbert–Schmidt 算子 B，det₂(I - B) = det((I - B)exp(B)) 是良定义的，且可以通过特征值乘积 ∏(1 - μ_i)exp(μ_i) 计算。
- **Riccati 方程方法**（附录 A）：作为迭代特征值求解器的替代方案，通过求解矩阵 Riccati 微分方程直接计算 prefactor，适用于状态空间维度 n 较小但时间离散化 n_t 很大的情形。

**数值实现技巧**：
- **JAX 自动微分**：`jax.jvp` 用于计算 Jacobian-vector 乘积，`jax.grad` 用于计算梯度，从而避免显式构造 Hessian 矩阵。
- **隐式重启 Arnoldi 方法**（ARPACK）：用于计算对称算子的前 M 个特征值，计算量约为 O(M) 次算子-向量乘积。
- **低秩结构利用**：在 SPDE 例子中，随机强迫的协方差算子只有少量非零特征值，这大大降低了算子-向量乘积的计算成本。

#### 🔎 结论是否比证明窄

**是的，存在几处"证明窄于结论"的地方**：

1. **定理 2.1 的假设 vs 数值例子的验证范围**：定理要求"唯一且非退化的 instanton"（2.8），但数值例子中并未严格验证这一条件。特别是平流扩散例子中，可能存在多个局部极小点，文中仅通过多次随机初始化来规避，没有理论保证。

2. **Itô 情形的严格性**：定理 2.1 的证明（附录 D）基于 [9] 的框架，但 [9] 处理的是 Stratonovich SDE。文中声称 Itô 情形可以通过 Girsanov 变换归约，但这一归约的严格性条件（如 Novikov 条件）并未详细讨论。对于退化噪声（σ 不满秩），Girsanov 变换可能不成立。

3. **SPDE 情形的外推**：文中将 SDE 的理论结果直接应用于 SPDE 的半离散化（第 4.2 节），但并未给出 SPDE 情形的严格证明。作者在 Remark 2.3 中承认"well-posed SPDEs"的推广是"direct"的，但未提供细节。

4. **误差估计的缺失**：文中没有给出有限 M（截断特征值数）和有限 n_t（时间离散化）对 prefactor 估计误差的定量界。Remark 3.1 明确将"严格的误差估计"列为未来工作。

5. **"scalable"的精确含义**：文中声称算法是 scalable 的，但只给出了经验证据（表 2 中 N_eval 不随分辨率增长）。没有给出严格的计算复杂度分析，特别是迭代特征值求解器的收敛性对条件数的依赖。

### 四、开放问题

1. **严格的误差估计**（扎根于 Remark 3.1）：如何定量刻画有限 M 和有限 n_t 对 prefactor C(z) 估计的误差？能否建立形如 |C_approx - C_exact| ≤ C(M, n_t) · ε^α 的显式界？这需要更精细的谱分析——特别是特征值 ∝ 1/i 的渐近行为如何影响截断误差。

2. **非凸情形与多重 instanton**（扎根于 Remark 2.3 和数值例子中的初始化问题）：当存在多个局部极小点时，如何系统地处理？能否发展出类似模拟退火或 homotopy 方法的全局优化策略？这与"玻璃态"物理中的复杂性景观有深刻联系。

3. **SPDE 情形的严格理论**（扎根于 Remark 2.3 的"direct generalization"声明）：能否将定理 2.1 推广到无穷维状态空间？这需要处理 Wiener 空间上的 Laplace 方法在 SPDE 情形下的技术细节，特别是 Ã_λ 的 Hilbert–Schmidt 性质在无穷维下是否仍然成立。

4. **退化噪声情形**（扎根于第 2.2.2 节 GBM 例子中 σ 可逆的假设）：当扩散系数 σ(x) 不满秩时（例如某些分量无噪声），Hessian 算子的谱性质会如何变化？Carleman–Fredholm 行列式是否仍然良定义？这在实际应用中很重要，因为许多物理系统的噪声是退化的。

5. **与采样方法的结合**（扎根于引言中对蒙特卡洛方法的讨论）：SORM 估计能否作为重要性采样的提议分布，从而结合两者的优势？具体地，能否用 instanton 附近的 Gaussian 近似构造高效的 proposal，使得蒙特卡洛估计的方差显著降低？

6. **时间依赖的极端事件**（扎根于第 4.2 节中固定时间 T 的设定）：如果观测函数依赖于整个路径（如路径积分型观测），prefactor 的计算会如何变化？这需要将 Laplace 方法推广到路径空间上的泛函。
