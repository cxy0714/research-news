# Co-sufficient weighting: leveraging sparsity for more powerful variable selection in the linear model

**作者**: Souhardya Sengupta, Lucas Janson  
**主题**: 数理统计 / 假设检验  
**相关性**: 7/10  
**链接**: <https://arxiv.org/abs/2610.42122>

### 一、领域脉络与小综述

#### 这个方向是什么

本文研究的根本问题是：在高斯线性模型 `y ~ N(Xβ, σ²Iₙ)` 中，如何在**控制多重检验错误率**（FWER 或 FDR）的前提下，利用对系数向量 β 的**稀疏性信念**（即相信大部分 βⱼ = 0）来**提高变量选择的功效**。这是一个典型的"受控变量选择"问题，处于高维统计推断与多重检验的交叉地带。该方向的成熟度较高——FWER/FDR 控制的理论框架（Bonferroni、Holm、BH）早已成熟，但如何**在保证有效性的前提下，将稀疏性这一结构信息系统地转化为功效提升**，仍是一个活跃的研究前沿。

#### 发展脉络

- **奠基工作**：多重检验的基石是 Bonferroni 校正（控制 FWER）和 Benjamini–Hochberg 过程（控制 FDR）。Holm（1979）提出的逐步拒绝法是对 Bonferroni 的改进，而 Benjamini 和 Hochberg（1995）则开创了 FDR 控制这一更宽松、功效更高的范式。这些方法均不利用任何结构信息，是"无信息"的基准。
- **加权多重检验的引入**：为了利用外部信息，加权版本的 Bonferroni 和 BH 过程被提出。Genovese et al.（2003）系统研究了加权 BH 的性质，其有效性要求权重满足一定的条件。然而，这些方法通常需要**外部定量信息**（如先验重要性评分）来设定权重，而这在实际中往往难以获得。
- **利用稀疏性的早期尝试**：在变量选择领域，Lasso 及其变体（如 SLOPE）通过凸优化隐式地利用稀疏性，但它们的理论保证通常是关于预测误差或模型选择一致性，而非严格的错误率控制。稳定性选择（Meinshausen & Bühlmann, 2010）和基于样本分裂的方法（Wasserman & Roeder, 2009）试图将稀疏估计与推断结合，但往往需要额外的假设（如 beta-min 条件）或损失功效。
- **Knockoffs 框架**：Barber 和 Candès（2015）提出的固定 X knockoffs 是第一个在有限样本下严格控制 FDR 且能利用稀疏性的方法，但其要求 n ≥ 2d，限制了其在高维设定下的应用。
- **ℓ-test 与稀疏性利用**：Sengupta 和 Janson（2024）提出的 ℓ-test 是本文的直接前驱，它通过利用稀疏性构造了比 t-test 功效更高的 p 值，且满足与 t-test 相同的独立性条件。这为本文的权重构造提供了关键的 p 值基础。
- **本文的位置**：本文在上述脉络中填补了一个关键缺口——**如何在不依赖任何外部信息的情况下，仅从数据本身（通过充分统计量）构造出满足有效性条件且能提升功效的权重**。其核心创新在于"co-sufficient weighting"（CSW）框架，该框架将权重构造与稀疏性信念直接挂钩，并严格证明了其满足加权多重检验有效性的充分条件。

#### 子线索聚类

1. **多重检验的加权方法**：这条线索关注如何将外部信息（权重）纳入 FWER/FDR 控制过程。代表工作包括 Holm（1979）、Genovese et al.（2003）、Ignatiadis et al.（2023）。其核心问题是：权重需要满足什么条件才能保证错误率控制？已知瓶颈是权重通常需要外部信息，且随机权重会破坏有效性。
2. **利用稀疏性的变量选择**：这条线索关注如何利用稀疏性提高选择精度。代表工作包括 Lasso、SLOPE、稳定性选择、knockoffs。其核心问题是：如何在利用稀疏性的同时保证统计推断的有效性？已知瓶颈是往往需要额外假设（如 beta-min）或限制适用条件（如 n ≥ 2d）。
3. **基于充分统计量的推断**：这条线索关注如何利用充分统计量进行条件推断。代表工作包括 co-sufficient sampling（Stephens, 2012）和条件随机化检验。其核心问题是：如何从充分统计量中提取关于信号的信息而不破坏检验的有效性？已知瓶颈是计算复杂度和对模型假设的依赖。

#### 这个方向在追问的核心问题

1. **如何将稀疏性信念转化为可验证的权重？** 即，能否构造一个数据驱动的权重，使其在稀疏设定下提升功效，同时严格满足加权多重检验的有效性条件？
2. **随机权重的有效性条件是什么？** 当权重依赖于数据时，如何保证 FWER/FDR 控制不被破坏？
3. **如何在功效与稳健性之间取得平衡？** 当稀疏性信念正确时，权重应显著提升功效；当信念错误（即 β 稠密）时，权重不应导致功效大幅下降。

#### ⚠️ 作者的 framing

作者将缺口 frame 为：**"在没有任何外部定量信息的情况下，能否仅利用稀疏性信念和充分统计量构造出有效的权重？"** 他们声称这是"显然的下一步"，因为现有加权方法需要外部信息，而现有稀疏性方法（如 knockoffs）有 n ≥ 2d 的限制。作者淡化了以下竞争路线：（1）贝叶斯方法，它们通过先验分布利用稀疏性，但难以保证频率学错误率；（2）基于 e-values 的方法（如 Ignatiadis et al., 2023），作者认为其权重构造需要额外的假设。**值得研究者去查的问题**：为什么作者没有讨论将 CSW 与 e-value 框架结合的可能性？以及，CSW 在 n < d 的高维设定下是否完全失效？

#### 张力

未见明显对立引用。但存在一个隐含张力：knockoffs 框架强调"无需假设稀疏性即可控制 FDR"，而本文的方法则**依赖**稀疏性信念来提升功效。这两种哲学——"稳健但保守"与"高效但有条件"——之间的权衡是值得注意的。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

- **符号**：
  - `y ∈ ℝⁿ`：响应向量（可观测）。
  - `X ∈ ℝⁿˣᵈ`：设计矩阵，列满秩（固定、非随机）。
  - `β ∈ ℝᵈ`：未知系数向量（参数）。
  - `σ² > 0`：噪声方差（参数，未知）。
  - `S = {j : βⱼ ≠ 0}`：真实信号集（目标估计对象）。
  - `Hⱼ : βⱼ = 0`：第 j 个原假设。
  - `pⱼ`：检验 Hⱼ 的 p 值。
  - `wⱼ`：赋予第 j 个假设的权重。
  - `S⁽ʲ⁾ = (X₋ⱼᵀy, ‖(Iₙ − P₋ⱼ)y‖²)`：Hⱼ 下的最小充分统计量，其中 `X₋ⱼ` 是去掉第 j 列的 X，`P₋ⱼ` 是投影到 `X₋ⱼ` 列空间的投影矩阵。
  - `Aⱼ(y)`：衡量第 j 个变量重要性的得分（可随机化）。
  - `ŵⱼ`：CSW 权重，是 `Aⱼ(y)` 在 Hⱼ 下条件期望的蒙特卡洛估计。

- **模型**：`y ~ N(Xβ, σ²Iₙ)`，即同方差高斯线性模型。X 固定，β 和 σ² 未知。
- **可观测数据**：研究者观测到 `(y, X)`。**关键点**：在 Hⱼ 下，`S⁽ʲ⁾` 是充分统计量，意味着给定 `S⁽ʲ⁾`，y 的条件分布不依赖于 βⱼ。这是 CSW 构造的基石——它允许在 Hⱼ 下生成与观测数据"同分布"的合成响应 `ỹ⁽ʲ⁾`，而无需知道 βⱼ 的真实值。

#### 第二步：最小内核

**核心问题**：在 Hⱼ 下，pⱼ 与 `S⁽ʲ⁾` 独立（这是 t-test p 值满足的性质，即 Assumption 3.1）。我们希望构造权重 `ŵⱼ`，使其与 pⱼ 独立（以保证加权检验的有效性），同时让 `ŵⱼ` 在 βⱼ ≠ 0 时倾向于更大（以提升功效）。

**最小例子**：考虑最简单的单变量情形（d=1），但为了体现"co-sufficient"的思想，我们考虑 d=2 且 X₁ 与 X₂ 相关的情形。假设我们想检验 H₁ : β₁ = 0。

1. **充分统计量**：在 H₁ 下，`S⁽¹⁾ = (X₂ᵀy, ‖(Iₙ − P₂)y‖²)` 是充分的。这意味着，给定 `X₂ᵀy` 和残差平方和，y 的条件分布与 β₁ 无关。
2. **合成数据生成**：从 `y | S⁽¹⁾` 的条件分布中抽取 `ỹ⁽¹⁾`。这可以通过 `ỹ⁽¹⁾ = P₂y + ‖(Iₙ − P₂)y‖ · V⁽¹⁾u` 实现，其中 `V⁽¹⁾` 是 `Col.sp.(X₂)⊥` 的正交基，`u ~ Unif(Sⁿ⁻ᵈ)`。
3. **权重计算**：令 `A₁(y) = |β̂₁|`（Lasso 或 OLS 估计的绝对值）。则 `ŵ₁ = A₁(ỹ⁽¹⁾) / Σᵢ Aᵢ(ỹ⁽¹⁾)`。由于 `ỹ⁽¹⁾` 是在 H₁ 下生成的，`ŵ₁` 与 p₁ 独立（因为 p₁ 只依赖于 `S⁽¹⁾`，而 `ỹ⁽¹⁾` 的条件分布给定 `S⁽¹⁾` 后与 p₁ 无关）。
3. **为什么有效**：如果 β₁ ≠ 0，那么真实的 y 与在 H₁ 下生成的 `ỹ⁽¹⁾` 分布不同。`A₁(y)` 倾向于较大（因为 y 包含 β₁ 的信号），而 `A₁(ỹ⁽¹⁾)` 倾向于较小（因为 `ỹ⁽¹⁾` 是在 β₁ = 0 的假设下生成的）。因此，`ŵ₁` 倾向于大于其在 H₁ 下的期望值，从而在加权检验中给予 H₁ 更大的权重，提升功效。

**这个例子的本质**：CSW 的核心思想是**利用充分统计量在 Hⱼ 下生成"无信号"的合成数据，并通过比较真实数据与合成数据上的重要性得分来构造权重**。这使得权重在 Hⱼ 下与 p 值独立（保证有效性），同时在备择假设下倾向于放大信号（提升功效）。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：在高斯线性模型中，如何仅利用稀疏性信念（无需外部信息）构造数据驱动的权重，以提升加权 FWER/FDR 控制过程的功效。
2. **核心工具/方法**：提出了 co-sufficient weights（CSW），通过从 Hⱼ 下的充分统计量条件分布中采样合成数据，并比较真实与合成数据上的重要性得分来构造权重。权重被用于加权 Holm 和加权 BH 过程。
3. **主要结论**：CSW 权重满足加权多重检验有效性的充分条件（Assumption 2.1），在稀疏设定下显著提升功效，在稠密设定下仅有轻微功效损失；通过模拟和 HIV 数据验证了方法的优越性。

#### 关键设定与假设

- **模型**：`y ~ N(Xβ, σ²Iₙ)`，X 列满秩，n > d。
- **p 值**：满足 Assumption 3.1，即 pⱼ 在 Hⱼ 下与 `S⁽ʲ⁾` 独立。t-test 和 ℓ-test 均满足此性质。
- **重要性得分 Aⱼ(y)**：可以是 Lasso 系数的绝对值（`Aⱼᴸᴬˢˢᴼ`）或蒸馏软阈值（distilled soft-thresholding）系数的绝对值（`Aⱼᵈˢᵀ`）。A 可以依赖于外部随机性（如交叉验证的折）。
- **权重构造**：`ŵⱼ = (1/B) Σᵦ Aⱼ(ỹ⁽ʲ⁾_b) / Σᵢ Aᵢ(ỹ⁽ʲ⁾_b)`，其中 `ỹ⁽ʲ⁾_b` 是从 `y | S⁽ʲ⁾` 条件分布中抽取的 B 个独立样本。
- **关键假设**：稀疏性信念（β 中大部分元素为零）。方法本身不要求该信念正确，但功效提升依赖于其正确性。

#### 主要结果

- **定理 3.1**：CSW 权重满足 Assumption 2.1，即 (a) 对每个零假设 j，`ŵⱼ` 与 pⱼ 独立；(b) 零假设下权重的期望和 ≤ 1。这保证了加权 Bonferroni 和加权 Holm 过程的 FWER 控制。
- **定理 3.2**：基于 CSW 权重的加权 Holm 过程（算法 1）在任意 p 值依赖结构下控制 FWER 于 α 水平。
- **模拟结果**：
  - 在稀疏设定下（k/d ≤ 5%），CSW-Holm 和 CSW-BH 的功效显著高于未加权对应方法，且 CSW-BH 在多数设定下优于 knockoffs+ 和 cknockoff*。
  - 在稠密设定下（k/d = 50%），CSW 方法的功效与未加权方法相当，仅轻微下降。
  - CSW-BH 的经验 FDR 在几乎所有设定下都控制在名义水平附近，表现出高度稳健性。
  - 在 MCC 设计（存在白化现象）下，CSW-BH 优于 cknockoff*。
- **HIV 数据应用**：在 16 个药物耐药性回归中，CSW 方法在 FDR 和 FWER 控制下均比未加权方法发现更多已知耐药突变，且 CSW-BH 的发现集与 cknockoff* 高度重叠但数量更多。

#### 证明路线与技术技巧

- **整体路线**：
  1. **建立权重有效性**：通过证明 `ŵⱼ` 满足 Assumption 2.1，直接套用 Ignatiadis et al.（2023）的定理，得到加权 Bonferroni/Holm 的 FWER 控制。
  2. **证明算法 1 等价于闭包**：证明算法 1 是加权 Bonferroni 检验的闭包，从而继承 FWER 控制。
  3. **经验验证**：通过大规模模拟和真实数据验证功效与稳健性。
- **关键跳跃点**：
  - **如何证明 `ŵⱼ` 与 pⱼ 独立**：关键在于 `ŵⱼ` 只依赖于 `S⁽ʲ⁾` 和外部随机性（合成数据的生成），而 pⱼ 在 Hⱼ 下与 `S⁽ʲ⁾` 独立。因此，条件独立成立。
  - **如何处理随机权重**：通过条件期望的定义，将随机权重的期望转化为对合成数据分布的积分，从而验证 Assumption 2.1(b)。
  - **如何实现高效计算**：利用 Cholesky 分解和 Schur 补公式，避免对每个 j 重新计算矩阵逆；利用蒸馏软阈值（dST）避免运行 B 次 Lasso。
- **技术技巧点名**：
  - **Co-sufficient sampling**：从 `y | S⁽ʲ⁾` 条件分布中采样，这是整个方法的核心。
  - **蒸馏（distillation）**：先用 Lasso 筛选变量，再对筛选后的变量做 OLS，得到 dST 重要性得分，兼顾稀疏性与计算效率。
  - **矩阵更新技巧**：利用 Schur 补公式和 Cholesky 分解，将计算复杂度从 O(d⁴) 降至 O(d³)。
  - **闭包原理**：将加权 Holm 过程视为加权 Bonferroni 检验的闭包，从而简化证明。

#### 🔎 结论是否比证明窄

- **明确声明但未严格证明**：论文声称 CSW-BH 具有"高度稳健的经验 FDR 控制"，但并未给出 FDR 控制的严格理论保证（仅依赖模拟）。作者在讨论部分承认了这一点，并指出在一般依赖结构下，加权 BH 的 FDR 控制本身就是一个开放问题。
- **条件独立性的证明依赖于 p 值的特定性质**：定理 3.1 要求 pⱼ 满足 Assumption 3.1（与 `S⁽ʲ⁾` 独立）。虽然 t-test 和 ℓ-test 满足该性质，但并非所有 p 值都满足。作者未讨论该假设不满足时的后果。
- **计算复杂度的声明**：作者声称 dST 方法比 Lasso 快 20 倍，但这一结论仅基于特定模拟设定（d=100），未提供理论复杂度分析。

### 四、开放问题

1. **FDR 控制的严格理论保证**：CSW-BH 的经验 FDR 控制非常稳健，但缺乏理论证明。能否在某种合理的依赖结构假设下（如正回归依赖 PRDS）证明加权 BH 的 FDR 控制？这需要将 CSW 权重的特殊结构纳入分析。
2. **高维设定（n < d）的扩展**：本文方法要求 n > d。能否将 CSW 思想扩展到 n < d 的情形？可能需要借助去偏 Lasso 或 debiased ML 工具构造重要性得分，但如何保证权重与 p 值的独立性是一个挑战。
3. **重要性得分的理论最优性**：本文提出了 Lasso 和 dST 两种重要性得分，但未讨论其最优性。是否存在某种意义下最优的 Aⱼ(y) 选择？这可能需要建立功效与权重分布之间的变分刻画。
4. **与其他稀疏性利用方法的理论比较**：本文在模拟中比较了与 knockoffs 的功效，但缺乏理论比较。能否证明在某种稀疏性模型下，CSW 方法的功效优于 knockoffs？
5. **权重估计的误差分析**：CSW 权重通过蒙特卡洛估计，其估计误差对检验有效性和功效的影响尚未分析。能否给出 B 的选择准则，使得权重估计误差可忽略？

**提示**：要确认这些是否是真 gap，建议去读近 5 年关于加权多重检验（如 Ignatiadis et al. 2023, 2024）和条件随机化检验（如 Candès et al. 2022）的论文引言——如果多个独立工作都指向同一问题，那大概率是共识性的 gap；如果各说各话，则可能是机会所在。
