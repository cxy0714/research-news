**作者**: Houtian Yi, Zhaolun Wang, Xin Zhao  
**主题**: 非参数 / 半参数  
**相关性**: 6/10  
**链接**: <https://arxiv.org/abs/2611.20904>

### 一、领域脉络与小综述

#### 这个方向是什么

本文所处的子方向是**流式数据（streaming data）下的非参数回归**。其根本的统计问题是：当数据以批次形式持续到达、且历史原始观测无法重复访问时，如何在不损失统计效率的前提下，序贯地更新一个非参数函数估计量。该方向的成熟度处于"方法百花齐放但理论框架尚未统一"的阶段——已有多种在线估计策略（随机梯度、可再生似然、核方法等），但如何在函数空间动态扩展（即估计的表示能力随时间增长）的同时保持历史信息的有效压缩，仍是一个开放问题。本文的定位是：在广义非参数回归（generalized nonparametric regression, GNR）框架下，将"可再生估计"（renewable estimation）与"动态样条基"（dynamic spline bases）结合，并给出 L2 收敛速率。

#### 发展脉络（history）

- **奠基工作：可再生估计框架**。Luo and Song (2020) 提出了广义线性模型（GLM）下的可再生估计与增量推断框架。其核心思想是：将历史数据的似然贡献压缩为有限维充分统计量（得分向量与 Hessian 矩阵），新批次到达时只需将新似然与历史二次型相加即可更新估计。本文直接继承此框架，并将其从参数模型推广到非参数样条模型。引用语境（"Luo and Song (2020, Section 3.1, Eq. (10)) proposed the aforementioned renewable estimation framework"）表明这是本文方法论的直接源头。

- **关键推进：动态样条基**。Xue and Yao (2022) 开发了在线非参数回归的动态惩罚样条程序，其核心机制是**嵌套样条空间**（nested spline spaces）与**投影更新**（projection-based updates）。当数据积累到一定程度时，通过插入新节点扩展样条空间，并将旧空间中的估计投影到新空间。本文引用语境（"Xue and Yao (2022, Section 2.1) provided relevant constructions for dynamic spline spaces and projection-based updates"）表明这是本文"动态基"的直接来源。但 Xue and Yao 的方法在基扩展时对历史摘要的处理是"朴素投影"，本文的 Gram 度量回拉机制正是针对这一缺口。

- **理论基石：惩罚样条的渐近理论**。Huang and Su (2021) 建立了凹广义线性模型下惩罚样条估计的收敛速率理论，涵盖了样条逼近、经验-总体范数等价性、凸性条件等关键工具。本文的证明大量依赖此工作（引用语境："Huang and Su (2021, Propositions 2.1–2.3, Lemma 4.1, and Section 7) provide the relevant foundations for spline approximation, spline-space complexity, empirical–population norm equivalence, convexity, and generalized regression conditions"）。

- **并行路线：在线非参数估计的其他策略**。包括：(i) 平滑回扣（smooth backfitting）用于广义可加模型（Yang et al., 2024）；(ii) 筛网随机梯度下降（sieve stochastic gradient descent, Zhang and Simon, 2022）与再生核希尔伯特空间投影估计（Zhang and Simon, 2023），后者证明了在 Sobolev 椭球下的 minimax 最优性；(iii) 单遍惩罚基展开（Quan and Lin, 2024），在内存约束下达到最优速率；(iv) 滚动验证的在线自适应非参数估计（Zhang and Lei, 2025）；(v) 可再生复合分位数回归（Chen et al., 2024），将可再生思想推广到稳健回归。本文的差异化在于：**同时处理"基扩展"与"历史摘要的几何一致性"**，而上述工作要么固定基（Zhang-Simon, Quan-Lin），要么在基扩展时未考虑历史二次型的几何保持（Xue-Yao）。

#### 子线索聚类

1. **可再生似然/估计方程线索**：Luo-Song (2020) → Chen et al. (2024) → 本文。核心问题：如何将历史似然压缩为有限维摘要并序贯更新。本文的贡献：将二次型摘要从固定参数空间推广到嵌套函数空间，并引入 Gram 度量回拉。

2. **在线非参数估计线索**：Xue-Yao (2022) → Zhang-Simon (2022, 2023) → Quan-Lin (2024) → Zhang-Lei (2025) → 本文。核心问题：在流式设置下如何平衡逼近误差与估计方差。本文的贡献：在似然框架下实现基扩展，而非仅依赖投影或梯度。

3. **惩罚样条渐近理论线索**：Xiao (2019) → Huang-Su (2021) → 本文。核心问题：惩罚样条估计量的收敛速率与最优性。本文的贡献：将离线理论推广到可再生序贯设置，并处理基扩展带来的额外误差项。

#### 这个方向在追问的核心问题

1. **历史信息的充分压缩**：在流式设置下，历史数据的哪些函数（充分统计量）足以保证估计效率不损失？Luo-Song 对 GLM 给出了答案（得分+ Hessian），但非参数模型的"充分统计量"维度随基扩展而增长，如何压缩？
2. **基扩展与历史摘要的一致性**：当样条空间扩大时，旧空间中的历史摘要如何"翻译"到新空间？朴素投影会引入偏差，本文的 Gram 度量回拉是否是最优的翻译方式？
3. **计算-统计权衡**：在线估计的计算代价（存储、每次更新的浮点运算）与统计效率之间的最优平衡点在哪里？Quan-Lin (2024) 从内存约束角度给出了部分答案，本文从摘要维度角度切入。
4. **自适应基选择**：何时触发基扩展？如何选择新节点位置？本文采用基于曲率的启发式规则，但缺乏理论最优性保证。

#### ⚠️ 作者的 framing（这是作者的说法）

作者将缺口 frame 为：**"当初始样条空间表达不足时，需要扩展基函数，但历史摘要需在新空间中重新表达，为此需要一种机制"**（引言第 3 段）。具体地，作者声称：(i) 固定基在流式数据下会因初始表示不足而产生不可消除的逼近误差；(ii) 朴素投影（如 Xue-Yao 的方法）在基扩展时会扭曲历史二次型；(iii) 本文的 Gram 度量回拉是"保留历史二次型在嵌入旧空间上"的几何正确方式。作者淡化或回避的竞争路线包括：(a) 随机梯度类方法（Zhang-Simon）——作者未讨论其与可再生似然在统计效率上的理论比较；(b) 核方法/再生核希尔伯特空间投影——作者未提及这些方法在基扩展时的处理方式；(c) 自适应节点选择的贝叶斯或全贝叶斯方法——作者仅采用启发式曲率规则。

**值得研究者去查的问题**：引言中未提及的近期工作包括：(i) 在线非参数回归的 minimax 自适应理论（是否有比 O(N^{-2/5}) 更优的速率？）；(ii) 可再生估计在非似然框架（如分位数回归）中的推广是否已有更完整的理论；(iii) 流式因果推断中的非参数估计（本文方法是否可直接迁移到增量处理效应估计？）。这些"该存在却未出现"的引用可能暗示作者对竞争方法的刻意回避或文献覆盖不全。

#### 张力

未见明显对立引用。但存在一个微妙的张力：Luo-Song (2020) 的可再生框架在 GLM 中保证估计量与全数据 MLE 渐近等价，而本文的定理只给出 L2 收敛速率 O(N^{-2/5})，并未声称与全数据惩罚似然估计的渐近等价性。这意味着本文的"可再生"在统计效率上可能弱于 Luo-Song 的"可再生"——这是一个值得研究者注意的潜在 gap。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

**符号**（逐个点名）：

| 记号 | 含义 | 类型 |
|------|------|------|
| \(Y \mid X=x\) | 响应变量，服从指数族分布 | 随机变量 |
| \(g_0(x)\) | 未知的自然参数函数，估计目标 | 参数（函数）/ estimand |
| \(a_0\) | 已知的尺度参数（如高斯方差） | 已知常数 |
| \(b(\cdot)\) | 累积函数（cumulant function） | 已知函数 |
| \(S_K\) | 区间 [0,1] 上全三次 C² 样条空间，维度 K | 函数空间 |
| \(\mathbf{B}(x) = (B_1(x), \ldots, B_K(x))^\top\) | B 样条基 | 基函数向量 |
| \(\beta \in \mathbb{R}^K\) | 样条系数向量 | 参数（有限维） |
| \(g_\beta(x) = \mathbf{B}(x)^\top \beta\) | 样条逼近函数 | 函数 |
| \(D_0\) | 启动批次（startup batch），样本量 \(n_0 = m\) | 数据 |
| \(D_j\) | 第 j 个算法子批次，样本量 \(n_j\) | 数据 |
| \(N_j = n_0 + \sum_{\ell=1}^j n_\ell\) | 累计样本量 | 标量 |
| \(\ell_j(\beta)\) | 第 j 个子批次的 log-likelihood | 函数 |
| \(U_j(\beta), H_j(\beta)\) | 得分向量与负 Hessian 矩阵 | 随机向量/矩阵 |
| \(h_j, M_j\) | 累计得分摘要与累计曲率摘要 | 充分统计量 |
| \(S_j\) | 第 j 步的接收样条空间 | 函数空间 |
| \(A_j\) | 嵌套空间嵌入矩阵，满足 \(\mathbf{B}_{j-1}(x) = A_j^\top \mathbf{B}_j(x)\) | 矩阵（\(K_{j-1} \times K_j\)） |
| \(R_j = (A_j^\top G_j A_j)^{-1} A_j^\top G_j\) | Gram 度量左逆 | 矩阵（\(K_j \times K_{j-1}\)） |
| \(G_j = \int_0^1 \mathbf{B}_j(x) \mathbf{B}_j(x)^\top dx\) | 接收空间的 Gram 矩阵 | 矩阵 |
| \(P_j\) | 惩罚矩阵（二阶导数 + 微小岭） | 矩阵 |
| \(\lambda^{\text{raw}}_{N_j}\) | 原始惩罚乘子 | 标量 |
| \(\alpha_t = t^{-4/5}\) | 归一化惩罚参数 | 标量 |
| \(\|\cdot\|_{\alpha}\) | 能量范数，\(\|u\|_\alpha^2 = \|u\|_2^2 + \alpha J(u)\) | 范数 |
| \(H^2[0,1]\) | Sobolev 空间（二阶弱导数平方可积） | 函数空间 |
| \(\Pi_j\) | 到 \(S_j\) 的 L2 正交投影 | 算子 |

**模型**：

数据生成机制：\((X_i, Y_i)\) 独立同分布（每行内），\(X_i \in [0,1]\)，给定 \(X_i = x\) 时 \(Y_i\) 服从自然参数为 \(g_0(x)\) 的指数族分布：

\[
f(y \mid x) = \exp\left\{ \frac{y g_0(x) - b(g_0(x))}{a_0} + c(y, a_0) \right\}, \quad g_0(x) \in \Theta.
\]

**可观测数据**：流式到达的批次 \(D_0, D_1, D_2, \ldots\)，其中 \(D_0\) 为启动批次（样本量 \(m\)），后续每个算法子批次 \(D_j\) 的样本量 \(n_j \le b^* < \infty\)（有界）。**关键约束**：处理完 \(D_j\) 后，\(D_0, \ldots, D_{j-1}\) 的原始观测不可再访问，只能访问压缩后的摘要 \((h_{j-1}, M_{j-1})\) 和当前拟合 \(\hat{\beta}_{j-1}\)。

**估计目标**：\(g_0\) 本身（而非某个有限维参数）。在样条框架下，目标转化为在嵌套空间序列 \(S_0 \subseteq S_1 \subseteq \cdots\) 中序贯求解惩罚似然问题。

#### 第二步：最小内核

**核心困难**：当样条空间从 \(S_{j-1}\) 扩展到 \(S_j\)（\(K_j > K_{j-1}\)）时，历史摘要 \((h_{j-1}, M_{j-1})\) 是在旧坐标系（基 \(\mathbf{B}_{j-1}\)）下表达的。新空间中的系数向量 \(\beta \in \mathbb{R}^{K_j}\) 无法直接与旧摘要相加——维度不匹配。一个朴素做法是"零填充"（将旧系数嵌入新空间，新维度置零），但这会扭曲历史二次型的几何意义。

**最小例子**（线性回归 + 二次样条扩展）：

假设 \(S_{j-1}\) 是区间 [0,1] 上的线性函数空间（\(K_{j-1} = 2\)，基为 \(\{1, x\}\)），\(S_j\) 是二次样条空间（\(K_j = 3\)，基为 \(\{1, x, x^2\}\)）。嵌套嵌入矩阵为：

\[
A_j = \begin{pmatrix} 1 & 0 & 0 \\ 0 & 1 & 0 \end{pmatrix}, \quad \mathbf{B}_{j-1}(x) = A_j^\top \mathbf{B}_j(x) = (1, x, x^2)^\top \text{ 的前两维}
\]

旧系数 \(\beta_{j-1} = (a, b)^\top\) 嵌入新空间为 \(\tilde{\beta}_{j-1} = A_j \beta_{j-1} = (a, b, 0)^\top\)。但历史曲率摘要 \(M_{j-1}\)（一个 \(2 \times 2\) 矩阵）不能直接嵌入为 \(3 \times 3\) 矩阵——需要决定新维度上的曲率值。**Gram 度量回拉**的做法是：将旧摘要 \(M_{j-1}\) 视为定义在子空间 \(\text{span}\{1, x\}\) 上的二次型，通过左乘 \(R_j^\top\)、右乘 \(R_j\) 将其"拉回"到新空间：

\[
M_j^- = R_j^\top M_{j-1} R_j, \quad h_j^- = R_j^\top h_{j-1}
\]

其中 \(R_j = (A_j^\top G_j A_j)^{-1} A_j^\top G_j\) 是 Gram 度量左逆。这个操作保证：对于任意旧空间函数 \(u = \mathbf{B}_{j-1}^\top \beta\)，其在新空间中的像 \(\tilde{u} = \mathbf{B}_j^\top A_j \beta\) 满足

\[
\tilde{u}^\top M_j^- \tilde{u} = \beta^\top M_{j-1} \beta
\]

即**历史二次型在旧空间上的取值被精确保持**。这就是"回拉"（pullback）的几何含义：不是简单嵌入，而是通过度量诱导的映射保持二次型。

**为什么这能工作**：因为样条空间是嵌套的（\(S_{j-1} \subset S_j\)），旧空间中的每个函数在新空间中都有唯一的坐标表示（通过 \(A_j\)）。Gram 度量左逆 \(R_j\) 是"从新空间坐标投影回旧空间坐标"的算子，满足 \(R_j A_j = I\)。因此，将旧摘要先投影回旧空间、再嵌入新空间，等价于在旧空间上精确保持二次型，同时对新维度赋予"零信息"（由后续数据决定）。

**这个最小内核揭示了本文的核心数学命题**：在嵌套样条空间序列上，通过 Gram 度量回拉传输的历史二次型，与"理想的全数据二次型"之间的差异，可以被控制在 \(O(N^{-1/2} \log^4 N)\) 的量级（由 Corollary 3.2 的能量范数差异给出）。这使得可再生估计的统计误差与基扩展的逼近误差可以分离处理，最终得到 L2 收敛速率 \(O_p(N^{-2/5})\)。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：在流式数据（批次到达、历史不可重访）下，如何对广义非参数回归模型进行序贯估计，特别是当初始样条空间表达不足、需要动态扩展基函数时，如何保持历史摘要的几何一致性。
2. **核心工具/方法**：将 Luo-Song (2020) 的可再生似然框架推广到嵌套样条空间，提出 Gram 度量回拉机制（\(R_j = (A_j^\top G_j A_j)^{-1} A_j^\top G_j\)）来传输历史得分与曲率摘要，并配合基于曲率的节点插入策略实现动态基扩展。
3. **主要结论**：在正则条件下，可再生估计量达到 L2 收敛速率 \(O_p(N^{-2/5})\)，且与匹配的全数据离线估计量（使用相同终端样条空间和惩罚）之间的能量范数差异为 \(O_p(N^{-1/2} \log^8 N)\)，即可再生估计的统计效率损失是渐近可忽略的。

#### 关键设定与假设

- **模型设定**：单协变量 \(X \in [0,1]\)，响应服从正则指数族（自然参数函数 \(g_0 \in H^2[0,1]\)）。**注意**：本文只处理标量协变量，多元情形仅在讨论中提及。
- **数据流结构**：启动批次 \(D_0\)（样本量 \(m\)，\(m \to \infty\) 且 \(m/N \to 0\)），后续算法子批次 \(D_j\) 样本量有界（\(n_j \le b^* < \infty\)）。**关键**：子批次边界由物理批次边界与基扩展事件共同决定。
- **样条空间**：全三次 C² 样条，节点由曲率驱动插入，空间嵌套（\(S_0 \subseteq S_1 \subseteq \cdots\)）。维度增长满足 \(K_j \asymp N_j^{2/3}\)（与最优非参数收敛速率匹配）。
- **惩罚**：固定二次惩罚 \(J(g) = \int (g'')^2 + \epsilon \int g^2\)，\(\epsilon = 10^{-8}\) 保证正定性。
- **关键正则条件**（Assumptions 1–5）：
  - (A1) 行内 i.i.d.，协变量密度有界上下限，指数族满足局部有界性（\(b \in C^3\)，\(b''\) 上下有界）。
  - (A2) 样条空间嵌套、节点拟均匀、维度增长 \(K_j \asymp N_j^{2/3}\)。
  - (A3) 启动批次足够大（\(m \to \infty\)），初始估计达到 \(O_p(m^{-2/5})\)。
  - (A4) 子批次大小有界（\(n_j \le b^*\)），基扩展事件可预测（在子批次边界发生）。
  - (A5) 惩罚参数选择满足 \(\lambda^{\text{raw}}_{N_j} \asymp N_j^{1/5}\)（对应 \(O(N^{-4/5})\) 的惩罚强度）。

**相比已有工作的放宽/强化**：
- 相比 Luo-Song (2020)：从参数 GLM 推广到非参数样条，但**增加了**对基扩展事件的可预测性要求（A4）。
- 相比 Xue-Yao (2022)：用 Gram 度量回拉替代朴素投影，但**增加了**对启动批次大小的要求（A3），且未处理多元协变量。
- 相比 Zhang-Simon (2022)：本文是似然框架而非随机梯度，理论更强（有收敛速率），但**计算复杂度更高**（每次更新需解一个 \(K_j\) 维凸优化）。

#### 主要结果

**Theorem 3.1（一致性与收敛速率）**：在 Assumptions 1–5 下，可再生估计量满足
\[
\|\hat{g}^{\text{ren}}_N - g_0\|_{\alpha_N} = O_p(N^{-2/5}), \quad \|\hat{g}^{\text{ren}}_N - g_0\|_{L^2} = O_p(N^{-2/5}).
\]
其中 \(\alpha_N = N^{-4/5}\)。这是非参数回归在 \(H^2\) 光滑类下的最优 minimax 速率（在 log 因子内）。

**Corollary 3.2（匹配离线差异）**：设 \(\hat{g}^{\text{off,matched}}_N\) 为使用相同终端样条空间和惩罚的离线估计量，则
\[
\|\hat{g}^{\text{ren}}_N - \hat{g}^{\text{off,matched}}_N\|_{\alpha_N} = O_p(N^{-1/2} \log^8 N) = o_p(N^{-2/5}).
\]
即可再生估计与全数据离线估计的差异比主收敛速率更快趋于零，说明"可再生"不损失一阶效率。

**证明路线（4 步）**：

1. **样条逼近与随机界**（Appendix A.1）：利用 Huang-Su (2021) 的命题，建立样条投影的逼近误差 \(\|s_t - g_0\|_2 = O(t^{-4/3})\)，以及经验过程/鞅的集中不等式，得到得分与曲率算子的随机界。
2. **启动估计**（Appendix A.2）：启动批次是离线问题，直接应用 Huang-Su (2021) 的定理，得到初始误差 \(\|\hat{g}_0 - g_0\|_{\alpha_m} = O_p(m^{-2/5})\)。
3. **递归误差传播**（Appendix A.3）：将目标函数分解为历史二次型（经 Gram 回拉）+ 新批次似然 + 惩罚。利用强凸性（由 A1 的 \(b''\) 下界保证）和梯度控制，建立递推不等式：
   \[
   \|\hat{g}_j - g_0\|_{\alpha_{N_j}} \le C\{N_j^{-2/5} L(N_j) + N_j^{-9/10} C_{j-1}\}
   \]
   其中 \(C_{j-1}\) 是历史累积误差。
4. **累积误差控制**（Appendix A.4）：通过势垒（barrier）论证，证明历史累积误差 \(C_j\) 以高概率被控制在 \(O(N_j^{2/5} \log^8 N_j)\) 内。关键技巧是离散 Gronwall 不等式和鞅的 Doob 不等式，处理基扩展事件带来的非平稳性。

**技术技巧点名**：

- **Gram 度量回拉**（核心创新）：\(R_j = (A_j^\top G_j A_j)^{-1} A_j^\top G_j\)，保持历史二次型在旧空间上的取值。
- **能量范数**（\(\|\cdot\|_{\alpha}\)）：将惩罚项纳入范数定义，简化强凸性论证。
- **势垒论证**（barrier argument）：处理递归误差传播中的"坏事件"。
- **离散 Gronwall 不等式**：处理累积误差的指数增长风险。
- **鞅集中不等式**：处理流式数据的依赖结构（子批次间条件独立）。

#### 真实例子与应用

**数据集 1：Catalina 变星分类**（Drake et al., 2017）
- **数据**：33,648 条南方 Catalina 周期变星记录，响应为二分类（脉动星 vs. 食双星），协变量为 \(\log_{10}(\text{周期/天})\)。
- **流式设定**：启动批次 \(n_0 = 50\)，物理批次大小 300，共 103 次更新，接受 39 次基扩展，终端维度 \(K = 44\)。
- **结果**：M3（本文方法）的预拟然 log-loss 为 0.495310，优于 M1（固定基，0.559524）和 M2（朴素投影，0.496775）；AUC 从 M1 的 0.6557 提升至 M3 的 0.7652。与匹配离线估计 M0（0.482799）的差距为 0.0125，远小于 M1 与 M0 的差距。
- **说明什么**：当初始样条空间不足时（M1 表现差），动态基扩展能显著提升预测性能；Gram 回拉（M3 vs M2）在 log-loss 上带来 0.0015 的改进，在函数估计距离上改进更明显（概率 RMS 距离从 0.0214 降至 0.0155）。

**数据集 2：Voice 性别识别**（Becker, 2016）
- **数据**：3,168 条语音记录，响应为性别（女=1），协变量为模态频率（kHz）。
- **流式设定**：启动批次 \(n_0 = 50\)，\(K_0 = 5\)，8 次基扩展至 \(K = 13\)，17 次更新。
- **结果**：M3 的预拟然 log-loss 为 0.591471，优于 M1（0.595057）和 M2（0.593566）；AUC 为 0.7431，优于 M1（0.7383）和 M2（0.7360）。与 M0（0.551018）的差距为 0.0405。
- **说明什么**：在较小数据集上，动态基扩展的收益仍然存在，但幅度小于 Catalina；Gram 回拉在 AUC 上带来 0.007 的提升。

**模拟实验**：三个场景（线性趋势 S1、局部峰 S2、高频振荡 S3），500 次重复。核心发现：(i) 当初始基足够时（S1），M1 与 M3 表现接近，动态扩展收益小；(ii) 当初始基不足时（S2、S3），M3 显著优于 M1，且 Gram 回拉（M3 vs M2）带来额外改进；(iii) M3 与匹配离线估计 M0 的差距随 N 增大而缩小，验证了 Corollary 3.2 的理论预测。

**计算成本**：Catalina 数据上，M3 的累计运行时间约为 M0（全量重拟合）的 1/12，存储需求约为 M0 的 1/4（仅需保留摘要而非原始数据）。

#### 🔎 结论是否比证明窄

**是，存在明显差距**：

1. **Theorem 3.1 的证明依赖"精确算术"假设**（Assumption 4），但实际实现使用浮点运算和数值优化。作者在 Section 4 承认"浮点优化"与理论假设的差距，但未给出数值误差的传播界。这意味着理论保证在实际实现中可能不严格成立。

2. **Corollary 3.2 的证明假设终端样条空间和惩罚是"匹配"的**，但实际中终端空间由数据驱动的基扩展过程决定，具有随机性。作者未证明随机终端空间下的匹配性质，只证明了确定性终端空间下的差异界。

3. **收敛速率 \(O_p(N^{-2/5})\) 是固定光滑度 \(s=2\) 下的结果**。作者在 Section 6 讨论中推测高阶样条或自适应光滑度选择可能达到更优速率，但未给出证明。这意味着本文的速率结果可能不是最优的。

4. **模拟和真实数据中，M3 与 M0 的差距在有限样本下并不总是可忽略**（如 Voice 数据上 log-loss 差距为 0.04），作者将其归因于"有限样本效应"，但未给出有限样本的显式界。

5. **作者声称"Gram 度量回拉保留历史二次型"**，但只证明了在旧空间上的保持性质（等式 2.32），未证明在新空间上的最优性——即是否存在其他传输机制（如最优传输、信息几何投影）能获得更小的信息损失。

### 四、开放问题

1. **多元协变量的扩展**（扎根于 Section 6："extending the framework to multivariate nonparametric regression such as additive models"）：本文只处理标量协变量。对于多元情形，样条空间的张量积结构会使 Gram 矩阵的维度急剧增长，回拉机制的计算代价可能不可控。需要研究低秩近似或稀疏化策略。

2. **自适应光滑度选择**（扎根于 Section 6："investigating practical dimension-reduction approaches"）：本文的节点插入策略基于曲率启发式，缺乏理论最优性保证。是否存在数据驱动的节点选择规则，使得收敛速率自适应于未知光滑度 \(s\)？

3. **分布理论**（扎根于 Theorem 3.1 的收敛速率，但未给出极限分布）：本文只建立了 \(O_p(N^{-2/5})\) 的收敛速率，未给出 \(\hat{g}^{\text{ren}}_N\) 的渐近正态性或置信带。对于流式设置下的统计推断（如增量置信区间），需要建立功能性极限定理。

4. **非正则情形的推广**（扎根于 Assumption 1 的正则条件）：当响应分布不属于正则指数族（如零膨胀、混合分布）时，似然函数的强凸性可能不成立，本文的证明框架需要实质性修改。

5. **计算-统计最优权衡**（扎根于 Section 4.4 的计算实验）：本文的基扩展策略在每次扩展时需重新优化整个目标函数。是否存在增量式更新算法（如利用 Schur 补或低秩更新），使得每次更新的计算代价与维度增量成正比而非与总维度成正比？

6. **与深度学习的衔接**（扎根于 Section 6 对 DNN 的提及）：本文的 Gram 度量回拉机制是否可类比为神经网络中的"增量特征学习"？能否将可再生框架推广到在线深度非参数回归？
