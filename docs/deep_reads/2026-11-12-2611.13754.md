# Harnessing collaborative networks for nonparametric quantile learning

**作者**: Jinyuan Chang, Yue Wang, Heng Lian, Wen-Xin Zhou  
**主题**: 非参数 / 半参数  
**相关性**: 6/10  
**链接**: <https://arxiv.org/abs/2611.13754>

### 一、领域脉络与小综述

#### 这个方向是什么

本文研究的根本问题是：**当数据分散存储在多个节点（agent）上、且不允许交换原始数据时，如何协作地估计条件分位数函数**。这是一个"分布式非参数统计推断"与"网络优化"的交叉问题。其统计核心是：在再生核希尔伯特空间（RKHS）中，通过正则化经验风险最小化估计分位数回归函数；其计算核心是：在无中心协调器（central coordinator）的完全去中心化网络拓扑下，设计通信高效的分布式优化算法。该方向的成熟度处于**快速发展期**——分布式均值/线性回归已有较成熟的理论（如 Duchi et al., 2012; Jordan et al., 2019; Fan et al., 2019），但**非参数分位数回归**因其目标函数非光滑、且核方法的表示定理依赖全局数据基，在去中心化场景下仍缺乏系统的统计-计算联合分析。

#### 发展脉络

- **奠基工作：分布式优化的收敛理论。** Duchi et al. (2010) 建立了对偶平均法在分布式环境下的收敛性，指出标准梯度下降（DGD）在常数步长下只能收敛到最优解的邻域，需衰减步长才能精确收敛（次线性速率）。这一"常数步长不精确、衰减步长次线性"的困境，是本文算法设计的直接动机。
- **主要进展：通信高效的分布式统计估计。** Jordan et al. (2016) 提出通信高效替代似然（CSL）框架，通过构造代理似然实现单轮通信即达全样本效率；Fan et al. (2019) 的 CEASE 算法进一步实现了线性收敛。但这些工作主要针对**光滑、强凸**的有限维参数模型（如线性回归、逻辑回归），其核心技巧（如梯度平均、代理似然）依赖目标函数的强凸性和光滑性。
- **关键缺口：非参数与分位数回归的分布式化。** 分位数回归的 check loss 非光滑，破坏了上述光滑优化理论的前提。在集中式场景，Li et al. (2007) 建立了 RKHS 分位数回归的统计理论；He et al. (2023) 的 conquer 方法通过卷积平滑将 check loss 转化为光滑目标，实现了大规模推断。在分布式场景，Chen et al. (2018) 研究了内存受限下的分位数回归，但采用**中心化主从架构**（divide-and-conquer），而非去中心化网络。Wang and Li (2018) 提出了传感器网络上的分布式线性分位数回归，但限于**线性模型**。**去中心化网络上的非参数分位数回归**——即本文的位置——在此前无人系统处理。
- **本文的位置**：作者将卷积平滑（来自 He et al., 2023 的 conquer 传统）与随机特征近似（Rahimi and Recht, 2007; Rudi and Rosasco, 2017）结合，构造了一个**光滑、有限维、数据无关参数化**的目标函数，从而将去中心化优化理论（来自 Duchi et al., 2010 的 DGD 传统和 ADMM 传统）应用于非参数分位数回归。其理论贡献在于**联合刻画**了统计误差（平滑偏差 + 正则化偏差 + 随机特征近似误差 + 采样方差）与优化误差（网络拓扑 + 算法迭代）之间的权衡。

#### 子线索聚类

被引文献大致落在三条子线索上：

1. **分布式优化算法**（Duchi et al., 2010; Ling et al., 2015; Liu et al., 2019; Xu et al., 2021）：关注如何在网络上高效求解凸优化问题，核心指标是通信轮数和每轮通信量。代表方法：DGD、ADMM、通信裁剪（communication-censoring）。
2. **分布式统计推断**（Zhang et al., 2013; Jordan et al., 2016; Fan et al., 2019; Chen et al., 2018）：关注如何从分布式数据中恢复全样本统计效率，核心指标是估计量的统计误差与通信成本之间的权衡。代表方法：分治平均、代理似然、迭代精化。
3. **核方法与随机特征**（Rahimi and Recht, 2007; Rudi and Rosasco, 2017; Dai et al., 2023）：关注如何用有限维随机特征近似无限维 RKHS，核心指标是近似误差随特征数 L 的衰减速率。

本文是这三条线索的**首次交汇**：用线索 3 的工具（随机特征）将线索 1 的算法（ADMM）应用于线索 2 的问题（分布式分位数回归）。

#### 这个方向在追问的核心问题

1. **统计-计算权衡**：在分布式非参数估计中，通信预算（每轮传输的维度 L）如何影响统计收敛速率？是否存在一个"最小通信量"使得统计速率不劣于集中式估计？
2. **非光滑目标的分布式优化**：如何将非光滑损失（如 check loss）转化为适合分布式优化的光滑目标，同时不损失统计效率？
3. **网络拓扑的影响**：去中心化网络的谱隙（spectral gap）如何进入收敛速率？通信裁剪策略能否在保持线性收敛的同时显著降低通信量？

#### ⚠️ 作者的 framing（这是作者的说法）

作者将缺口 frame 为："现有去中心化方法主要针对光滑强凸的有限维模型，而**非参数分位数回归**因其非光滑性和数据依赖基而无法直接应用。" 因此本文的贡献被定位为"通过卷积平滑 + 随机特征，将非参数分位数回归转化为光滑有限维问题，从而适配去中心化优化"。作者淡化的竞争路线包括：(a) **中心化主从架构**（如 Chen et al., 2018 的 divide-and-conquer），作者仅以"服务器可能成为瓶颈或单点故障"一句带过，未深入比较两种架构的统计效率差异；(b) **其他非参数分布式方法**（如分布式样条、分布式局部多项式），这些方法在均值回归场景已有研究，但作者未讨论其是否可推广到分位数回归。**值得去查的问题**：为什么作者不采用 divide-and-conquer 加单轮通信的策略（如 Jordan et al., 2016 的 CSL 框架）？去中心化相比中心化主从架构，在统计效率上是否有本质损失？作者未在 intro 中正面回答这个问题。

#### 张力

未见明显对立引用。但存在一个微妙的张力：Duchi et al. (2010) 的 DGD 分析表明常数步长只能收敛到邻域，而本文的 GADMM 通过引入对偶变量（dual variable）实现了线性收敛到精确解。这一对比暗示：**梯度下降类方法（DGD）与 ADMM 类方法在去中心化场景下的收敛行为有本质差异**——前者受限于步长衰减，后者可通过对偶变量的累积修正达到精确收敛。这一张力值得深挖：是否存在一类问题（如强凸但非光滑），ADMM 的线性收敛会失效？


### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

**数据生成与观测结构：**
- 网络：无向连通图 G = (V, E)，V = [m] 为节点（agent）集合，E 为边集。节点 j 与 k 相邻当且仅当 (j,k) ∈ E。
- 数据：总样本 {(xᵢ, yᵢ)}_{i=1}^{N}，i.i.d. 来自联合分布 P。节点 j 持有子集 Dⱼ，|Dⱼ| = n，N = mn。**可观测数据**：每个节点仅能看到自己的 {(xᵢ, yᵢ) : i ∈ Dⱼ}，以及从邻居收到的参数向量（而非原始数据）。
- 协变量：x ∈ X ⊂ ℝᵖ，p 为协变量维数（固定，不随样本量增长）。
- 响应：y ∈ ℝ。

**目标量（estimand）：**
- 条件 τ 分位数函数 f\*\_τ(x) = Q_τ(y | x)，即给定 x 时 y 的条件 τ 分位数。τ ∈ (0,1) 固定。本文关注 f\* 的估计，而非推断（无置信区间）。

**模型与函数空间：**
- RKHS H = H_k：由核 k(·,·) 诱导的再生核希尔伯特空间，范数 ‖·‖_H。
- 核 k 为平移不变核（如高斯核 k(x,x') = exp{−‖x−x'‖²/(2σ²)}），满足 Condition 1（有界）与 Condition 2（特征值多项式衰减，即 µⱼ ≍ j^(−α)，α > 1）。
- 真实函数 f\* 满足源条件（source condition）：f\* = T^r g\*，r ∈ [1/2, 1]，‖g\*‖₂ ≲ 1。这里 T 是积分算子 (Tf)(x) = ∫ k(x,x') f(x') dP_X(x')。r 越大，f\* 越光滑。

**要估计的参数：**
- 在随机特征近似后，问题变为有限维：f(x) ≈ βᵀφ_L(x)，其中 φ_L(x) = L^(−1/2)(cos(⟨w₁,x⟩+b₁), ..., cos(⟨w_L,x⟩+b_L))ᵀ，w_l ~ N(0, σ^(−2)I_p)，b_l ~ Uniform[0, 2π]。**β ∈ ℝ^L 是唯一的优化变量**（L 为随机特征数，是算法中的关键维度参数）。
- 正则化参数 λ > 0：控制函数复杂度。
- 平滑带宽 h > 0：控制 check loss 的光滑化程度。
- 算法参数：γ（ADMM 惩罚参数）、c（线性化参数）、µ 和 v（通信裁剪阈值序列参数）。

**关键量：**
- 有效维度（effective dimension）：N(λ) = Tr(T(T+λI)⁻¹) = Σⱼ µⱼ/(µⱼ+λ)。它刻画了问题的统计复杂度，在多项式特征值衰减 µⱼ ≍ j^(−α) 下，N(λ) ≍ λ^(−1/α)。
- 平滑后的 check loss：ρ_{τ,h}(u) = ∫ ρ_τ(v) K_h(u−v) dv，其中 K_h(u) = h⁻¹K(u/h)，K 为光滑核。ρ_{τ,h} 是 ρ_τ 的卷积平滑版本，具有 Lipschitz 梯度。

**可观测 vs 不可观测：**
- 可观测：每个节点的局部数据 Dⱼ、网络拓扑 G、随机特征 {w_l, b_l}（所有节点共享同一随机种子生成）。
- 不可观测：其他节点的数据、全局目标函数的完整梯度、真实分位数函数 f\*。

#### 第二步：最小内核

**剥去所有技术细节后，本文的核心数学问题是：**

> **如何在无中心协调的去中心化网络上，最小化一个非光滑、强凸的全局目标函数，使得优化误差以线性速率收敛到零，同时每轮通信只传输 L 维向量？**

**最小例子（m=2，一条边）：**

设两个节点各持 n 个样本。全局目标为
F(β) = (1/2)[F₁(β) + F₂(β)]，其中 Fⱼ(β) = (1/n)Σ_{i∈Dⱼ} ρ_{τ,h}(yᵢ − βᵀφ_L(xᵢ)) + λ‖β‖²。

**为什么直接做不行？**
- 若用标准 DGD：β^{(t+1)}ⱼ = Σ_k w_jk β^{(t)}_k − η∇Fⱼ(β^{(t)}ⱼ)，常数步长 η 只能收敛到最优解的 O(η) 邻域；衰减步长 η_t = O(1/t) 虽可精确收敛，但速率是次线性的 O(1/t)。
- 若用经典 ADMM：需要每个节点在 β-更新步精确求解一个局部子问题（因为 Fⱼ 非二次），这需要内层迭代，计算代价高。

**本文的破法（三步走）：**

1. **光滑化**：用卷积平滑将 check loss 替换为 ρ_{τ,h}，其梯度 Lipschitz 连续（常数 M = O(1/h)）。代价是引入 O(h²) 的平滑偏差。
2. **随机特征**：用 φ_L(x) 将无限维 RKHS 问题转化为 L 维参数问题。代价是引入 O(L^(−1/2)) 的近似误差（或更精细的 O(L^(−α)) 在多项式衰减下）。
3. **梯度调整的 ADMM（GADMM）**：在 β-更新步，不做精确最小化，而是用**一步梯度下降**替代，但用对偶变量 v 累积修正网络不一致性。具体地，对每条边 (j,k)，引入辅助变量 z_jk，约束 βⱼ = z_jk 和 β_k = z_jk。GADMM 的更新为：
   β^{(t+1)}ⱼ = β^{(t)}ⱼ − (1/c)[∇Fⱼ(β^{(t)}ⱼ) + γ Σ_{k∈Nⱼ}(β^{(t)}ⱼ − β^{(t)}_k) + v^{(t)}ⱼ]
   v^{(t+1)}ⱼ = v^{(t)}ⱼ + γ Σ_{k∈Nⱼ}(β^{(t+1)}ⱼ − β^{(t+1)}_k)

**为什么能线性收敛？**
关键观察：虽然 Fⱼ 非二次，但 Fⱼ 是强凸（λ > 0）且梯度 Lipschitz 的。因此，一步梯度下降足以保证 β-更新步的"近似最小化"质量随迭代指数改善。对偶变量 v 的更新确保了网络一致性约束（βⱼ = β_k）在极限下精确满足。联合 Lyapunov 论证给出线性收敛率 1/(1+η)，其中 η 由 λ、M、γ、c 和网络谱隙共同决定。

**这个最小内核揭示了本文的本质贡献：**
- 统计上：证明了随机特征 + 平滑的估计量达到全核估计量的最优速率（在合适的 λ、h、L 选择下）。
- 计算上：证明了 GADMM 以线性速率收敛到随机特征问题的全局最优解。
- 通信上：证明了 CE-GADMM 通过选择性传输，在保持线性收敛的同时，将通信量从 O(T·|E|·L) 降至约 O(T·|E|·L·µ^t)（指数衰减的通信频率）。


### 三、这篇论文做了什么

#### 三句话

① **研究了什么问题**：在无中心协调的去中心化网络上，如何协作地进行非参数分位数回归——即估计 RKHS 中的条件分位数函数，同时保证统计效率不损失、通信成本可控。
② **核心工具/方法**：将卷积平滑（处理 check loss 非光滑性）与共享随机特征（处理表示定理的数据依赖基问题）相结合，构造光滑、有限维、数据无关参数化的目标函数；提出梯度调整的 ADMM（GADMM）算法及其通信增强变体（CE-GADMM）。
③ **主要结论**：在合适的参数选择下，随机特征平滑估计量达到全核估计量的最优统计速率（定理 1）；GADMM 和 CE-GADMM 均以线性速率收敛到随机特征问题的全局最优解（定理 2、3）；CE-GADMM 在保持线性收敛的同时显著降低通信量。

#### 关键设定与假设

- **Condition 1（核有界）**：sup_{x∈X} k(x,x) ≲ 1。这保证 RKHS 嵌入到 L∞，是后续浓度不等式的基础。
- **Condition 2（源条件）**：f\* = T^r g\*，r ∈ [1/2, 1]，‖g\*‖₂ ≲ 1。r 控制目标函数的平滑度，r = 1/2 对应 f\* ∈ H（RKHS 内），r > 1/2 对应更高阶平滑。
- **Condition 3（条件密度）**：条件密度 f_{ε|x}(u) 在 u = 0 附近一致有界且远离 0，其一阶导数有界。这是分位数回归特有的假设，用于控制 check loss 的曲率。
- **Condition 4（平滑核）**：K 为对称、非负、有界、紧支撑的概率密度核，且 ∫ u²K(u)du < ∞。这保证平滑偏差为 O(h²)。
- **Condition 5（特征映射有界）**：sup_{x,ω} |φ(x,ω)| ≲ 1。这是随机特征分析的标准假设。

**相比已有文献的放宽/强化**：
- 相比 Xu et al. (2021)（去中心化核岭回归）：本文处理的是**非光滑**的 check loss，而非光滑平方损失；但代价是需要 Condition 3（条件密度下界），这是分位数回归特有的。
- 相比 He et al. (2023)（集中式平滑分位数回归）：本文增加了网络约束，但定理 1 的统计速率与集中式一致，说明去中心化不损失统计效率。
- 相比 Wang and Li (2018)（分布式线性分位数回归）：本文允许**非线性**条件分位数函数，但需要随机特征近似。

#### 主要结果

**定理 1（统计速率）**：在 Conditions 1–5 下，若 h² ≤ λ^r，L ≳ λ^(−1) N(λ)^(2r−1) t，且 λ ≥ {N(λ)+t}/N，则随机特征平滑估计量满足
‖f̂_{h,RF} − f\*‖₂² ≲ λ^(2r) + {N(λ) + t}/N，
以概率至少 1 − C N(λ) e^(−t)。

**解读**：第一项 λ^(2r) 是正则化偏差（由源条件决定），第二项 {N(λ)+t}/N 是方差项（由有效维度和样本量决定）。在多项式特征值衰减 µⱼ ≍ j^(−α) 下，N(λ) ≍ λ^(−1/α)，最优平衡给出
‖f̂ − f\*‖₂² ≲ N^(−2rα/(2rα+1))，
这正是非参数回归的最优极小化速率（Stone, 1982）。**关键信息**：随机特征数 L 只需满足 L ≳ λ^(−1) N(λ)^(2r−1)，在 r ≤ 1 时远小于 N，说明随机特征近似不改变统计速率。

**定理 2（GADMM 线性收敛）**：在 Conditions 4–5 下，若 c 和 γ 满足适当条件，GADMM 产生的迭代序列满足
max_j ‖β^{(t)}ⱼ − β̂‖² ≲ (1+η)^(−t) · (初始误差)，
其中 η > 0 由 λ、M（梯度 Lipschitz 常数）、γ、c 和网络谱隙共同决定。

**解读**：这是本文的核心优化贡献。与 DGD 的次线性收敛（常数步长只能到邻域）相比，GADMM 通过对偶变量的累积修正实现了**精确的线性收敛**。代价是需要 λ > 0（强凸性），这由正则化自然提供。

**定理 3（CE-GADMM 通信效率）**：在定理 2 的条件下，若裁剪阈值 c_j(t) = v µ^t 且 (1+η)µ² < 1，CE-GADMM 仍以线性速率收敛，且通信次数从 O(T) 降至 O(log T)（指数衰减的通信频率）。

**解读**：这是工程贡献。通过"只在变化显著时通信"的策略，CE-GADMM 在理论上保证了通信量的指数级减少，同时不破坏线性收敛。代价是收敛速率常数略差（η 变小），但通信量的节省远超过这一损失。

#### 证明路线与技术技巧

**定理 1 的证明路线**：
1. **误差分解**：‖f̂_{h,RF} − f\*‖₂² ≤ 3(‖f̂_{h,RF} − f̂_h‖₂² + ‖f̂_h − f̂_λ‖₂² + ‖f̂_λ − f\*‖₂²)，分别对应随机特征近似误差、平滑偏差、正则化偏差。
2. **随机特征近似误差**：利用 Concentration 不等式（如 Bernstein 型）控制经验核矩阵与真实核矩阵的谱范数差异，结合有效维数 N(λ) 给出 L 的下界。
3. **平滑偏差**：利用 Condition 4 的核函数性质，证明 |ρ_{τ,h}(u) − ρ_τ(u)| ≤ C h²，从而平滑偏差为 O(h²)。
4. **正则化偏差**：利用源条件 f\* = T^r g\* 和算子插值理论，得到 ‖f̂_λ − f\*‖₂² ≲ λ^(2r)。

**定理 2 的证明路线**：
1. **Lyapunov 函数构造**：定义 V(t) = ‖β^{(t)} − β̂‖²_P + (1/γ)‖v^{(t)} − v̂‖²，其中 P 是适当选择的加权矩阵。
2. **单步收缩**：利用强凸性（λ > 0）和梯度 Lipschitz 性（M < ∞），证明 V(t+1) ≤ (1+η)⁻¹ V(t)。
3. **网络一致性**：利用对偶变量 v 的更新，证明网络不一致性 Σ_{(j,k)∈E} ‖βⱼ − β_k‖² 随 t 指数衰减。

**技术技巧点名**：
- **卷积平滑**：将非光滑 check loss 转化为光滑函数，使得梯度 Lipschitz 常数 M = O(1/h) 可控。这是连接非光滑统计问题与光滑优化理论的桥梁。
- **随机特征**：用 Bochner 定理将平移不变核分解为随机特征的期望，将无限维 RKHS 问题转化为有限维线性问题。关键技巧是**共享随机种子**，使所有节点使用相同的随机特征，从而保证共识约束的一致性。
- **梯度调整的 ADMM**：在 β-更新步用一步梯度下降替代精确最小化，避免了内层迭代。这是"线性化 ADMM"（linearized ADMM）思想在非参数问题中的应用。
- **通信裁剪**：通过阈值序列 c_j(t) = v µ^t 控制通信频率，利用"陈旧信息"的误差可控性证明收敛性不受影响。

#### 真实例子与应用

**数据集**：北京多站点空气质量数据集（Beijing Multi-Site Air-Quality dataset），包含 2013 年 3 月至 2017 年 2 月期间 12 个监测站的逐小时污染物浓度和气象数据，聚合为日度数据后每站 n = 1,461 个观测。

**问题设定**：将 12 个监测站视为去中心化网络中的 12 个 agent，节点间按地理邻近关系连接（每个节点与其地理上最近的 2 个站点相连）。目标是协作估计 PM2.5 日平均浓度的条件分位数（τ = 0.5, 0.8, 0.9, 0.95），预测变量为 SO₂、NO₂、CO、O₃ 浓度及温度、气压、露点温度、风速等 8 个变量。

**结果**：
1. **预测精度**：GADMM 和 CE-GADMM 的预测误差接近集中式基准 CenQR，显著优于局部估计 LocQR 和朴素平均 AvgQR。在 τ = 0.95 时，GADMM 相对 LocQR 的预测误差降低约 30-40%。
2. **通信效率**：CE-GADMM 相比 GADMM 减少约 50% 的通信量，而预测精度几乎无损失。
3. **变量重要性**：使用排列重要性（VPI）分析发现，CO、露点温度（DEWP）和温度（TEMP）是预测 PM2.5 分位数的最重要变量。在 τ = 0.9 和 0.95 时，DEWP 和 TEMP 的重要性超过 CO，说明气象条件对极端污染事件的影响更大。

**例子想说明什么**：该应用展示了去中心化非参数分位数回归的实际价值——在数据隐私和通信成本受限的场景下（如环境监测网络），协作学习可以显著提升极端事件的预测能力，且通信裁剪策略在保持精度的同时大幅降低通信开销。


### 四、开放问题

以下开放问题均扎根于本文的具体语句或直接推论：

1. **最优通信-统计权衡的刻画**：定理 1 给出了 L 的下界（L ≳ λ^(−1) N(λ)^(2r−1) t），但这是充分条件而非必要条件。是否存在更紧的 L 下界？更一般地，对于给定的通信预算 B（总传输比特数），最优的 (λ, h, L, T) 配置是什么？这需要建立通信复杂度与统计风险之间的精确权衡曲线。（扎根于定理 1 的陈述："L ≥ C λ^(−1) N(λ)^(2r−1) t for a sufficiently large constant C > 0"——常数 C 未明确，且未讨论 L 的下界是否紧。）

2. **自适应参数选择**：本文的定理要求 h² ≤ λ^r 且 λ ≥ {N(λ)+t}/N，但未给出数据驱动的 λ、h、L 选择准则。在去中心化场景下，如何仅用局部数据选择这些参数？交叉验证在分布式环境下如何实现？（扎根于定理 1 的条件："assume that h² ≤ λ^r, L ≥ C λ^(−1) N(λ)^(2r−1) t"——这些条件需要未知的 r 和特征值衰减速率。）

3. **异质性数据与网络拓扑的交互**：本文假设各节点数据 i.i.d. 同分布。当节点数据分布不同（如不同监测站的地理特征差异）时，共识估计量是否仍然一致？网络谱隙如何影响统计效率？（扎根于 intro 中"fully decentralized architecture"的设定，但未讨论数据异质性。）

4. **推断与不确定性量化**：本文仅给出点估计的收敛速率，未构造置信区间或进行假设检验。在去中心化场景下，如何基于局部估计构造全局置信区间？分位数回归的 Bootstrap 在分布式环境下如何实现？（扎根于定理 1 的误差界——只给了 ‖f̂ − f\*‖₂² 的界，无分布近似结果。）

5. **更高阶分位数与极值分位数**：本文关注固定 τ ∈ (0,1)。当 τ → 0 或 τ → 1（极值分位数）时，条件密度 Condition 3 的 f ≤ f_{ε|x}(u) 下界可能失效。极值分位数的分布式估计需要不同的技术（如极值理论）。这直接关系到空气质量数据中"极端污染事件"的预测。（扎根于 Condition 3 的假设："there exist constants M₁ > 0 and 0 < f ≤ f̄ < ∞ such that ... f ≤ f_{ε|x}(u) ≤ f̄"——该假设在尾部可能不成立。）

**验证建议**：要确认上述问题是否为真 gap，建议去读以下近期文献的 intro（各约 5 篇）：(a) 分布式非参数回归（如 distributed kernel ridge regression, distributed spline estimation）；(b) 分布式分位数回归（如 divide-and-conquer quantile regression）；(c) 去中心化优化理论（如 decentralized SGD, primal-dual methods）。如果这些文献的 intro 都指向同一问题，则为共识性 gap；如果互相矛盾，则为机会性 gap。
