### 一、领域脉络与小综述

#### 这个方向是什么

本文所处的子方向是**部分识别（partial identification）模型在高维/机器学习第一阶段的估计与推断**。其根本的统计问题是：当目标参数 θ 不是点识别（point-identified），而是由一个依赖于 nuisance 参数 ξ₀ 的矩不等式系统定义出一个识别集（identified set）Θ_I 时，如何用数据估计这个集合，并构造对其有渐近覆盖保证的置信区域。该方向的成熟度处于"方法框架已建立、但向非参数/高维第一阶段推广仍在进行中"的阶段——经典的部分识别推断理论（如 Chernozhukov et al., 2007）假设矩条件中的 nuisance 已知或可根号 N 估计，而本文处理的是 nuisance 由机器学习方法估计、收敛速度可能慢于 N^{-1/2} 的情形。

#### 发展脉络（history）

- **奠基工作**：Chernozhukov, Hong & Tamer (2007) 建立了部分识别模型的 criterion-function 框架，将识别集表示为 population criterion 的零水平集，并给出了基于水平集的估计与推断理论。这是本文方法论的直接源头——本文的定理 A.1 和 A.2 明确以该文的 Condition C.2–C.5 为对应物（见附录 A.1 的引用语境）。
- **主要进展（第一阶段估计的引入）**：Kaido & White (2014) 将部分识别模型推广到两阶段设定，允许 nuisance 参数的存在，但限于有限维参数。本文明确将自己的框架定位为"将 Kaido & White (2014) 的两阶段框架扩展到函数值（function-valued）第一阶段"（见引言第 3 段）。
- **当前 frontier（去偏机器学习进入部分识别）**：Semenova (2023) 提出识别集边界（support function）的去偏估计，Semenova (2025) 提出广义 Lee 界，Heiler (2024) 处理异质性处理效应界，Liu & Molinari (2024) 处理公平性-准确性前沿。这些工作将 Neyman-orthogonality 与 cross-fitting 引入部分识别，但大多限于一维参数或凸识别集。本文的贡献在于：将正交矩不等式与 criterion-function 水平集方法结合，直接估计整个识别集（而非单个边界点），并允许矩条件非线性于 θ。
- **本文的位置**：在方法论谱系上，本文处于"去偏机器学习"与"部分识别推断"的交汇处。与 Tian (2025) 的对比是关键定位——Tian 处理类似的两阶段问题但依赖第一阶段估计的渐近线性（asymptotically linear），而本文通过正交化允许更慢的第一阶段收敛率，且覆盖的是整个识别集而非逐点推断。

#### 子线索聚类

被引文献大致落在三条子线索上：

1. **部分识别的 criterion-function 推断**（Chernozhukov et al., 2007; Andrews & Guggenberger, 2009; Andrews & Soares, 2010; Bugni, 2010; Chen et al., 2016; Romano & Shaikh, 2008, 2010）：处理矩不等式模型的识别集估计与推断，核心工具是水平集、子抽样和 moment selection。本文的定理框架直接继承此线索。
2. **去偏/正交机器学习**（Chernozhukov et al., 2018; Chernozhukov et al., 2022a,b; Ichimura et al., 2016; Belloni et al., 2013, 2017）：提供 Neyman-orthogonality、cross-fitting 和正则化第一阶段的理论基础。本文的 Assumption A.3 和 A.4 是该线索在部分识别场景的移植。
3. **部分识别在劳动经济学中的应用**（Blundell et al., 2007; Manski, 1994, 2003; Fernández-Val et al., 2023, 2024, 2025; Semenova, 2025; Heiler, 2024）：工资分布、性别工资差距、样本选择等具体问题，提供矩不等式结构的具体形式。本文的两个应用例子（工资分布分位距、区间删失工资的性别差距）直接来自此线索。

#### 这个方向在追问的核心问题

1. **识别集的估计速率**：当第一阶段 nuisance 以慢于 N^{-1/2} 的速率收敛时，识别集的 Hausdorff 距离收敛速率如何退化？本文的答案是：只要 nuisance 误差的乘积为 o(N^{-1/2})（即每个误差可以慢，但乘积要快），识别集估计就能达到参数速率。
2. **推断的有效性**：如何构造覆盖整个识别集（而非单个点）的置信区域，且不依赖第一阶段估计的渐近分布？本文的答案是：子抽样 + 正交矩 + 平衡分块。
3. **非凸/非线性识别集**：当矩条件非线性于 θ 时，水平集方法是否仍然有效？本文的定理 A.2 处理了 θ↦g(z;θ,ξ) 连续的情形，附录 B.4.5 处理了不连续（kink）的情形。

#### ⚠️ 作者的 framing（这是作者的说法）

作者将本文的贡献 frame 为"**将去偏机器学习的正交性思想从点识别推广到集合识别**"，并强调两个卖点：(i) 第一阶段可以以慢于 N^{-1/2} 的速率收敛而不影响一阶推断；(ii) 矩条件可以非线性于 θ，识别集可以非凸。作者同时淡化了两点：(a) 与 Tian (2025) 的竞争——作者强调自己覆盖整个识别集而 Tian 只做逐点推断，但未讨论 Tian 的方法在均匀覆盖（uniform coverage）方面的潜在优势；(b) 子抽样方法的保守性——作者承认投影到一维是保守的（见第 5 节），但未量化这种保守性在有限样本中的代价。**值得研究者去查的问题**：引言中提到的"允许第一阶段收敛慢于 N^{-1/2}"是否真的在定理 A.2 的证明中被用到，还是仅仅在 Assumption A.3(e) 中以乘积形式出现？从附录 B.3 的证明看，关键条件是 √N·s̄_N = o(1)，这实际上要求乘积速率，而非单个 nuisance 的速率——作者在引言中的表述可能比定理条件更宽泛。

#### 张力

未见明显的对立引用。但存在一个微妙的张力：Chernozhukov et al. (2007) 的 criterion-function 方法依赖水平集的紧致性和连续性，而本文的定理 A.2 在 θ↦g(z;θ,ξ) 不连续时（如分位距例子）需要额外的近似条件（附录 B.4.5 的 kink 处理）。这意味着"非线性"和"不连续"是两个不同的困难，作者将它们都归入"非仿射"的标题下，可能掩盖了不连续情形下需要更强条件的事实。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

**符号清单**（按本文第 2 节顺序）：

| 记号 | 含义 | 类型 |
|------|------|------|
| Z₁, …, Z_N | i.i.d. 样本，取值于可测空间 Z | 可观测随机变量 |
| P₀ | 样本的真实分布 | 未知分布 |
| θ | 目标参数，θ ∈ Θ ⊂ ℝ^{d_θ}，Θ 紧 | **参数 / estimand** |
| ξ | nuisance 参数，ξ ∈ Ξ（函数空间，带 L²(P₀) 范数） | **nuisance / 第一阶段** |
| ξ₀ | nuisance 的真值 | 未知但点识别 |
| ξ̂ | ξ₀ 的估计（cross-fitted） | 估计量 |
| g: Z × Θ × Ξ → ℝ^L | 矩函数，L ≥ 1 | 已知函数 |
| Θ_I := {θ ∈ Θ : Eg(Z;θ,ξ₀) ≤ 0} | **识别集**（目标推断对象） | 集合值 estimand |
| Q(θ,ξ) := ‖Eg(Z;θ,ξ)‖₊² | population criterion | 非负函数 |
| Q_N(θ,ξ̂) | 样本 criterion（cross-fitted） | 随机函数 |
| C_N(c;ξ̂) := {θ ∈ Θ : N·Q_N(θ,ξ̂) ≤ c} | 水平集（估计量/置信区域） | 随机集合 |
| c_N | 初步水平（如 log N） | 调参 |
| bĉ_τ | 子抽样临界值 | 数据驱动 |
| b | 子抽样块大小 | 调参 |
| K | cross-fitting 折数 | 固定常数 |

**模型**（数据生成机制）：

- 观测单元 Z_i = (X_i, D_i, D_i·W_i)（例 1）或 (X_i, D_i, Y_{L,i}, Y_{U,i})（例 2）。
- 第一阶段 nuisance ξ₀ = (p₀, F₁₀(w₁|·), …, F₁₀(w_S|·))，其中 p₀(x) = P(D=1|X=x) 是倾向得分，F₁₀(w|x) = P(W≤w|X=x, D=1) 是就业者工资的条件分布函数。
- 第二阶段目标 θ₀ = (F₀(w₁), …, F₀(w_S))，即无条件工资分布函数在网格上的值。
- **可观测**：Z_i 的 iid 样本。**不可观测**：失业者的工资 W（当 D=0 时），以及 ξ₀ 本身（需估计）。

**关键识别结构**：目标 θ₀ 由矩不等式系统界定，而非等式。具体地，例 1 中每个坐标 θ_k 满足 ℓ₀,k ≤ θ_k ≤ u₀,k，其中 ℓ₀,k = E[F₁₀(w_k|X)]，u₀,k = E[F₁₀(w_k|X)p₀(X) + 1−p₀(X)]。这些界依赖 nuisance ξ₀，因此识别集 Θ_I 的形状和位置都随 ξ₀ 的估计误差而变动。

#### 第二步：最小内核

**剥掉所有一般性假设后，本文的核心数学问题是**：

> 设 Θ_I = {θ ∈ Θ : m(θ) ≤ 0}，其中 m(θ) = Eg(Z;θ,ξ₀) 是 L 维向量值函数。我们观测到的是 Q_N(θ,ξ̂)（ξ̂ 是 cross-fitted 估计），而非 Q_N(θ,ξ₀)。问：水平集 Θ̂_I = {θ : N·Q_N(θ,ξ̂) ≤ c_N} 在 Hausdorff 距离下以什么速率收敛到 Θ_I？以及，如何选取临界值 bĉ_τ 使得 P(Θ_I ⊆ C_N(bĉ_τ;ξ̂)) → 1−τ？

**最简特例**（一维、仿射、已知 nuisance 的情形）：

设 L = 1，d_θ = 1，Θ = [0,1]，矩函数为 g(Z;θ,ξ₀) = θ − ξ₀（即 θ 被单侧不等式 θ ≤ ξ₀ 界定）。此时 Θ_I = [0, ξ₀]。若 ξ₀ 已知，则 population criterion Q(θ,ξ₀) = (θ−ξ₀)₊²，水平集 {θ : N·Q_N(θ,ξ₀) ≤ c} 的 Hausdorff 收敛速率由经验过程的波动决定，为 O_P(N^{-1/2})（Chernozhukov et al., 2007 的经典结果）。

**加入 nuisance 估计后的退化**：

现在设 ξ₀ 未知，用 ξ̂ 估计，且 ‖ξ̂−ξ₀‖_{P,2} = O_P(r_N)（r_N 可能慢于 N^{-1/2}）。则：

Q_N(θ,ξ̂) − Q_N(θ,ξ₀) ≈ 2·(θ−ξ₀)₊·(ξ̂−ξ₀) + (ξ̂−ξ₀)²

在 θ 接近 ξ₀ 处（即 Θ_I 的边界），(θ−ξ₀)₊ 很小，但 (ξ̂−ξ₀)² 的贡献是 O_P(r_N²)。因此水平集的边界估计误差为：

d_H(Θ̂_I, Θ_I) = O_P( max{ N^{-1/2}, r_N² } )

**关键观察**：如果 r_N = N^{-1/4}，则 r_N² = N^{-1/2}，与经验过程的波动同阶——这就是本文 Assumption A.3(e) 中"乘积为 o(N^{-1/2})"条件的本质。**Neyman-orthogonality 的作用**是消除一阶项 (θ−ξ₀)₊·(ξ̂−ξ₀)，使得 nuisance 误差只以平方形式进入。这正是本文定理 A.1 的证明核心（附录 B.2 的分解）。

**为什么这个例子是"最小内核"**：它展示了本文的全部三个关键要素——(i) 水平集作为识别集的估计量；(ii) 正交性将 nuisance 误差从一阶降为二阶；(iii) 乘积速率条件 r_N² = o(N^{-1/2}) 是参数速率成立的充分条件。一般情形（多维 θ、非线性 g、不连续 g）只是在这个内核上添加技术条件（Lipschitz、熵界、kink 处理），并不改变基本逻辑。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：当部分识别模型的矩不等式依赖于一个由机器学习估计的高维/非参数 nuisance 函数时，如何估计识别集并构造有渐近覆盖保证的置信区域。
2. **核心工具/方法**：将 Neyman-orthogonality 与 cross-fitting 引入 criterion-function 水平集估计，配合平衡块子抽样（balanced-block subsampling）构造置信区域。
3. **主要结论**：在 nuisance 估计误差的乘积为 o(N^{-1/2}) 的条件下，可行水平集估计器在 Hausdorff 距离下达到与不可行估计器相同的参数速率 O_P(N^{-1/2})；子抽样临界值给出渐近有效的覆盖。

#### 关键设定与假设

**设定**（在第二节最小记号基础上补全）：

- **矩不等式系统**：L 个不等式 Eg_l(Z;θ,ξ₀) ≤ 0，l = 1,…,L。识别集 Θ_I = {θ ∈ Θ : Eg(Z;θ,ξ₀) ≤ 0}。
- **Cross-fitted nuisance**：数据分为 K 折，第 k 折的观测用其余 K−1 折估计的 ξ̂⁽ᵏ⁾ 来评估矩条件。这是 Chernozhukov et al. (2018) 的标准做法，避免过拟合偏差。
- **水平集估计器**：Θ̂_I = C_N(c_N; ξ̂) = {θ ∈ Θ : N·Q_N(θ,ξ̂) ≤ c_N}，其中 c_N → ∞ 且 c_N/N → 0（如 c_N = log N）。
- **子抽样**：将样本分为 B_N 个不相交的块，每块大小 b，b → ∞ 且 b/N → 0。每块计算块级 criterion 并取最大值，得到临界值 bĉ_τ。

**核心假设**（按重要性排序）：

1. **Neyman-orthogonality（Assumption A.3(d)）**：对每个 θ ∈ Θ，∂_r Eg(Z;θ,ξ_r)|_{r=0} = 0，其中 ξ_r = ξ₀ + r(ξ−ξ₀)。这是整个方法的基石——它保证 nuisance 误差的一阶项消失。**相比已有文献**：Chernozhukov et al. (2018) 对点识别参数要求同样的条件，本文将其推广到矩不等式（逐点 θ 成立）。
2. **乘积速率条件（Assumption A.3(e)）**：sup_{θ∈Θ} |Eg(Z;θ,ξ̂) − Eg(Z;θ,ξ₀)| ≤ s̄_N = o(N^{-1/2})。注意这是**偏差**的界，而非方差——它要求 nuisance 估计的**乘积**（如倾向得分误差 × 回归误差）足够小。**相比已有文献**：这是本文最关键的推广——Tian (2025) 要求第一阶段估计本身是渐近线性的（即偏差为 O_P(N^{-1/2})），而本文只要求偏差的乘积为 o(N^{-1/2})，允许每个 nuisance 单独以慢于 N^{-1/2} 的速率收敛。
3. **Donsker 性质（Assumption A.2）**：矩函数类 {g(·;θ,ξ₀) : θ ∈ Θ} 是 P₀-Donsker。这是经验过程收敛的基础，保证 sup_{θ∈Θ} |G_N g(θ,ξ₀)| = O_P(1)。
4. **连续性/正则性（Assumption A.4）**：矩函数在 nuisance 方向上 Lipschitz，且熵条件成立。这保证 nuisance 误差从偏差到方差的传递是可控的。
5. **识别条件（Assumption A.1）**：population criterion 在 Θ_I 外以距离的幂次下界分离，即 Q(θ,ξ₀) ≥ C_min [d(θ,Θ_I) ∧ δ_min]²。这是水平集方法收敛的必要条件，对应 Chernozhukov et al. (2007) 的 Condition C.2。

**相比已有文献的强化/弱化**：
- **强化**：允许矩条件非线性于 θ（例 2 的分位距），且识别集可以非凸。已有文献（如 Semenova, 2023）大多限于凸识别集或仿射矩条件。
- **弱化**：第一阶段 nuisance 的收敛率要求从 N^{-1/2} 放宽到乘积 o(N^{-1/2})，但代价是**点态覆盖**而非**均匀覆盖**——本文定理 A.2 的覆盖保证是逐点（pointwise）的，作者在附录 A.1 末尾明确承认这一点。

#### 主要结果

**定理 A.1（估计的收敛速率）**：在 Assumptions A.1–A.4 下，若 bc 满足 (A.5)，则
d_H(Θ̂_I, Θ_I) = O_P( √(1∨bc)/N )。
当 bc = log N 时，速率为 √(log N/N)。**关键点**：这个速率与不可行估计器（已知 ξ₀）相同——正交化使得 nuisance 估计的贡献降为二阶。

**定理 A.2（子抽样的覆盖有效性）**：在 Assumptions A.1–A.7 下，若 b → ∞ 且 b·c_N/N → 0，则
P(Θ_I ⊆ C_N(bĉ_τ; ξ̂)) = 1−τ + o(1)。
**关键点**：子抽样临界值 bĉ_τ 一致估计了不可行统计量 sup_{θ∈Θ_I} N·Q_N(θ,ξ₀) 的 (1−τ) 分位数。平衡块构造（每块含每折等量观测）恢复了块间独立性，绕过了 cross-fitting 引入的跨块依赖。

**推论 4.1–4.3（应用例子的验证）**：三个例子分别验证了 Assumptions A.1–A.7：
- 例 1（工资分布）：验证了正交矩（3.7）的构造，其中关键技巧是**双重稳健**形式——矩函数同时包含倾向得分和条件分布函数的估计，使得偏差为两者的乘积。
- 例 2（分位距）：验证了非仿射矩条件的 Lipschitz 性质和 kink 处理（附录 B.4.5）。
- 例 3（区间删失）：验证了正部 kink 的二次偏差界（Assumption 4.8）。

#### 证明路线与技术技巧

**整体路线**（3-5 步逻辑主干）：

1. **偏差-方差分解**：将可行 criterion Q_N(θ,ξ̂) 分解为不可行 criterion Q_N(θ,ξ₀) 加上 nuisance 估计的贡献。正交性（A.3(d)）保证一阶项消失，只剩二阶项。
2. **二阶项控制**：用 Cauchy-Schwarz 和 Lipschitz 条件将二阶项分解为各 nuisance 误差的乘积，再用 A.3(e) 的乘积速率条件控制。这是 Lemma B.3 的核心。
3. **经验过程收敛**：对不可行 criterion 应用 Donsker 性质（A.2）和熵条件（A.4），得到 sup_{θ∈Θ} |G_N g(θ,ξ₀)| = O_P(1)。
4. **水平集包含关系**：利用 population criterion 的分离性（A.1），将 Θ̂_I ⊆ Θ_I^ϵ 的事件转化为 criterion 差值的上界事件，再用步骤 2-3 的概率界。
5. **子抽样的一致性**：对块级统计量应用同样的偏差-方差分解，利用块间独立性（平衡构造）和 b·c_N/N → 0 条件，证明块级经验分布的极限与全样本一致。

**关键技术技巧**：

- **双重稳健矩构造**（例 1）：矩函数 (3.7) 中的 ϕ_L 设计为 F₁(w|X) + D(1{W≤w}−F₁(w|X))/p(X)，其期望的偏差为 E[(F₁−F₁₀)(p−p₀)/p]，即两个 nuisance 误差的乘积。这是 A.3(e) 条件在具体例子中的实现。
- **平衡块子抽样**：每块从每个 cross-fitting 折中抽取等量观测，使得块内观测与块外估计的 nuisance 独立。这避免了直接对 cross-fitted 统计量使用标准子抽样时出现的跨块依赖。
- **Hoffman 界**（Lemma B.4）：对仿射矩系统，用 Hoffman 不等式将距离 d(θ, Θ_I) 与矩违反量 ‖(Aθ−c)₊‖ 联系起来，从而将 A.1 的分离性转化为可验证的线性代数条件。
- **kink 处理**（附录 B.4.5）：对不连续矩（如分位距中的示性函数），用 Lipschitz 逼近和二次偏差界（Assumption 4.8）替代导数条件，控制正部函数的偏差。

#### 🔎 结论是否比证明窄

**是，存在三处"证明比结论窄"的情况**：

1. **点态 vs 均匀覆盖**：定理 A.2 的覆盖保证是点态的（对固定 P₀），但引言和摘要中的表述"asymptotically valid coverage"可能被读者理解为均匀覆盖。作者在附录 A.1 末尾承认"uniform coverage is a conjecture"，但正文第 2 节并未明确标注这一限制。**具体位置**：第 2.2 节 Algorithm 2.1 后的段落。

2. **固定折数 K**：定理 A.1 和 A.2 的证明假设 K 固定。但例 1 中 nuisance 的估计（倾向得分和条件分布）在实际中可能用交叉验证选择调参，这会使 K 随 N 变化。附录 B.4 的验证没有讨论 K → ∞ 的情形。**具体位置**：附录 B.4.1 的"Affine moment systems"段落。

3. **连续型 kink 假设**：例 2 的验证（附录 B.4.5）假设工资分布连续且密度有界，但正文第 3.2 节的表述"the identified set need not be convex"暗示了更一般的适用性。对于离散工资数据（如实际 CPS 数据中的 heaping），kink 处理需要额外条件。**具体位置**：第 3.2 节最后一段。

### 四、开放问题（点到为止，扎根具体语句）

1. **均匀覆盖的建立**：定理 A.2 的覆盖保证是点态的，作者在附录 A.1 末尾写道"uniform coverage is a conjecture"。要建立均匀覆盖，需要控制 population criterion 在 Θ_I 附近的局部行为随 P₀ 变化的速率，这可能需要比 Assumption A.1 更强的分离条件（分离常数不随 P₀ 退化）。**扎根**：附录 A.1 最后一段。

2. **第一阶段估计的 adaptivity**：Assumption A.3(e) 要求乘积偏差 s̄_N = o(N^{-1/2})，但未说明如何在实际中验证这一条件。对于具体的机器学习算法（如 lasso、随机森林、神经网络），需要推导其 L² 收敛率的乘积界。**扎根**：Assumption A.3(e) 的陈述。

3. **矩条件数量 L 随 N 增长**：例 1 中网格点数 S 固定，但实际应用中可能希望 S → ∞ 以逼近连续分布。当 L = L_N → ∞ 时，Donsker 性质（A.2）和熵条件（A.4）需要重新验证，且子抽样的块数 B_N 与 L_N 的交互效应未知。**扎根**：第 3.1.1 节"Linear case"的设定。

4. **非凸识别集的推断效率**：本文的置信区域覆盖整个 Θ_I，但未讨论如何构造对 Θ_I 的某个函数（如体积、投影）更高效的推断。Kaido et al. (2019) 的投影方法可能与此结合，但需要处理 cross-fitted nuisance 带来的额外不确定性。**扎根**：第 5 节对投影保守性的讨论。

5. **与 Tian (2025) 的对比**：Tian 的方法要求第一阶段渐近线性，但可能提供更紧的置信区域（因为直接传播了 nuisance 的抽样分布）。本文通过正交化放宽了第一阶段条件，但代价是覆盖可能更保守。两者在有限样本下的相对表现是开放问题。**扎根**：引言第 4 段的对比。
