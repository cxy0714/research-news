**主题**: 统计计算 / 算法  
**相关性**: 6/10  
**链接**: <https://arxiv.org/abs/2610.29083>

### 一、领域脉络与小综述

#### 这个方向是什么

本文研究的根本问题是：**在大数据回归中，当协变量包含稀有二元特征（rare binary features）时，如何设计子采样（subsampling）方案，使得估计量在计算可行性与统计效率之间达到最优平衡**。子采样是处理海量数据回归的标准策略——从全量数据中抽取一个子集来拟合模型，从而降低计算成本。然而，当某些特征在数据中极为稀疏（如患病率 0.1%）时，均匀随机子采样会以极高概率丢失携带这些特征信息的观测，导致系数不可估计或收敛极慢。本文的核心贡献在于：**将采样概率与特征稀有度耦合**，证明收敛速率取决于"特征出现频率 × 采样概率"这一乘积，并据此设计自适应采样方案。

该方向的成熟度：子采样理论（Wang et al., 2018; Yu et al., 2022）已建立了基于最优设计准则（A-optimal、L-optimal）的完整框架，但**这些工作均假设所有特征具有相似的频率**。稀有特征问题在"稀有结果"（rare outcome）场景下已有大量研究（King and Zeng, 2001; Owen, 2007; Wang et al., 2021），但**从协变量角度出发、而非结果角度出发的稀有性研究，在本文之前缺乏系统性理论**。本文填补的正是这一空白。

#### 发展脉络

- **奠基工作：最优子采样设计**。Wang et al. (2018) 建立了基于 A-optimal 和 L-optimal 准则的子采样框架，证明最优采样概率与"杠杆值"（leverage score）成正比，即对估计影响大的观测应被赋予更高采样概率。这一框架成为后续所有工作的基准。**留下的口子**：该框架假设所有特征频率相当，未考虑特征稀有度对收敛速率的异质性影响。

- **主要进展：稀有结果的处理**。King and Zeng (2001) 和 Owen (2007) 系统研究了稀有二元结果（rare events）下的 logistic 回归问题，指出稀有结果导致的小样本偏差和方差膨胀。Wang et al. (2021) 将最优子采样扩展到稀有结果场景，提出负采样（negative sampling）策略——保留所有正例，仅对负例子采样。Keret and Gorfine (2023) 进一步将这一思路推广到 Cox 回归。**留下的口子**：这些工作关注的是**结果**的稀有性，而非**协变量**的稀有性。当协变量本身稀有时，即使结果平衡，估计问题依然存在。

- **当前 frontier：稀有协变量的理论刻画**。Yan and Bien (2021) 在高维线性模型中研究了稀有特征导致的估计不一致问题，提出特征聚合（feature aggregation）策略。Chen et al. (2024) 和 Mishra et al. (2024) 分别从树结构聚合和因子回归角度处理稀有特征。**这些工作均未涉及子采样场景**——它们假设使用全量数据，只是通过特征变换来缓解稀有性问题。

- **本文的位置**：本文是**第一个将"稀有特征"与"子采样设计"结合起来的系统性工作**。它建立了三个层次的贡献：(i) 理论层面，证明全量数据估计量的收敛速率由特征频率决定（定理1）；(ii) 设计层面，提出稀有普查（RC）和稀有性自适应（RA）两类采样方案，并证明 RA 方案能达到最优收敛速率；(iii) 实现层面，提出联合样本估计量处理两阶段采样中的样本重叠问题。

#### 子线索聚类

这些被引文献大致落在三条子线索上：

1. **最优子采样设计**（Wang et al., 2018; Yu et al., 2022; Wang et al., 2022; Zhang et al., 2024）：核心问题是"给定采样预算，如何分配采样概率以最小化估计方差"。方法：基于 A-optimal/L-optimal 准则的杠杆值加权。**本文的对话方式**：指出这些方法在稀有特征下失效，因为杠杆值本身依赖于全量估计，而稀有特征的杠杆值估计极不稳定。

2. **稀有结果/稀有事件分析**（King and Zeng, 2001; Owen, 2007; Wang et al., 2021; Keret and Gorfine, 2023）：核心问题是"当结果极不平衡时，如何修正估计偏差和方差"。方法：负采样 + 偏差校正。**本文的对话方式**：将"稀有性"从结果推广到协变量，指出协变量稀有性带来的挑战在结构上不同于结果稀有性——结果稀有性可以通过保留所有正例解决，而协变量稀有性需要识别哪些观测携带稀有特征。

3. **稀有特征的高维处理**（Yan and Bien, 2021; Chen et al., 2024; Mishra et al., 2024）：核心问题是"在高维稀疏设计中，如何对稀有特征进行选择或聚合"。方法：特征聚合、树结构正则化。**本文的对话方式**：这些方法假设全量数据可用，而本文关注的是子采样场景下稀有特征信息的保留。

#### 这个方向在追问的核心问题

1. **收敛速率的精确刻画**：稀有特征的系数估计到底以什么速率收敛？本文的答案是 (Nρ_j)^(-1/2)，其中 ρ_j 是特征频率——这比标准 N^(-1/2) 慢得多。这个速率是否是最优的？在什么条件下可以改进？

2. **采样概率与特征频率的最优耦合**：给定采样预算 n，如何分配采样概率使得所有系数的估计误差最小？本文证明 RA 方案（ω_j ≍ min{h_N/ρ_j, 1}）能达到最优速率，但这是否在 minimax 意义下最优？

3. **两阶段采样的信息利用**：当需要先采一个试点样本（pilot）来估计最优采样概率时，如何避免浪费试点样本的信息？本文的联合样本估计量是一个答案，但其效率是否达到半参数有效界？

4. **稀有特征与稀有结果的联合处理**：当协变量和结果同时稀有时（如罕见疾病的罕见基因变异），最优采样方案是什么？本文第5.3节给出了初步方案，但理论分析仅限于 logistic 回归。

#### ⚠️ 作者的 framing

作者将缺口 frame 为："**现有子采样方法未考虑特征稀有度，导致稀有特征系数估计的收敛速率严重退化**"。这个 framing 使得本文的贡献成为"显然的下一步"——既然子采样理论已经成熟，稀有特征问题又真实存在，那么将两者结合就是自然的推进。

**被淡化或回避的竞争路线**：
- **全量数据的稀有特征处理**（Yan and Bien, 2021 等）被一笔带过，作者暗示这些方法"不适用于大数据场景"，但未给出计算复杂度对比。
- **在线学习/流式算法**（如 SGD 及其变体）完全未被提及——这些方法不需要子采样，而是逐步处理数据块，可能天然规避稀有特征问题。
- **压缩感知/稀疏恢复**方法未被讨论——当特征极稀疏时，是否可以先用特征筛选再回归？

**明显该被引、却没出现在 intro 里的**：
- **Drovandi et al. (2017) 关于自适应子采样的综述**——该综述系统比较了各类自适应采样策略，本文的 RA 框架与之有直接对话关系。
- **Tibshirani (1996) 的 LASSO**——当特征极稀疏时，正则化方法是否比子采样更有效？这是一个自然的竞争问题。
- **Hellerstein (2008) 关于数据库采样的综述**——数据库领域的稀有值采样（rare value sampling）与本文问题高度相关。

#### 张力

未见明显对立引用。但存在一个微妙的张力：Wang et al. (2018) 的 A-optimal 设计在标准场景下是最优的，而本文证明它在稀有特征下失效。这并非矛盾——A-optimal 的推导假设所有特征频率相当，在稀有特征下该假设被违反。但作者没有明确讨论**在什么条件下 A-optimal 仍然可用**（例如，当稀有特征与结果不相关时，是否值得为它们牺牲非稀有特征的效率？）。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

**符号清单**（按"参数/估计目标 → 随机变量/样本 → 维度/规模 → 潜在量"的顺序）：

| 符号 | 含义 | 类型 |
|------|------|------|
| β₀ ∈ ℝ^d | 真实回归系数 | 参数（估计目标） |
| β = (β_u^T, β_r^T)^T | 系数分解：非稀有部分 β_u ∈ ℝ^{d_u}，稀有部分 β_r ∈ ℝ^{d_r} | 参数 |
| (Y, X) ∈ ℝ × ℝ^d | 响应变量与特征向量 | 随机变量 |
| X = (U^T, Z^T)^T | 特征分解：U ∈ ℝ^{d_u} 非稀有特征，Z ∈ {0,1}^{d_r} 稀有二元特征 | 随机变量 |
| ρ_{j,N} = E(Z_{·j}) | 第 j 个稀有特征的出现频率（患病率） | 参数（随 N 变化） |
| ψ(Y, X, β) = {Y - μ(X^Tβ)}X | 估计方程（estimating equation）的核函数 | 函数 |
| Ψ_N(β) = N^{-1} Σ ψ(Y_i, X_i, β) | 全量数据的估计方程 | 样本量 N 的函数 |
| Ψ_n(β) = N^{-1} Σ [δ_i/π(Y_i, X_i)] ψ(Y_i, X_i, β) | 子采样后的加权估计方程（Horvitz-Thompson 型） | 样本量 n 的函数 |
| π(Y, X) = min{h_N φ(Y, X), 1} | 采样概率函数 | 设计量 |
| h_N = n/N | 基础采样率 | 设计量 |
| φ(Y, X) | 权重函数（由具体设计决定） | 设计量 |
| D_N = diag{1_{d_u}^T, ρ_N^{1/2}} | 对角缩放矩阵，ρ_N = (ρ_{1,N}, ..., ρ_{d_r,N})^T | 缩放矩阵 |
| Ω_N = diag{h_N^{1/2} 1_{d_u}^T, ω_N^{1/2}} | 子采样诱导的缩放矩阵，ω_N = (ω_{1,N}, ..., ω_{d_r,N})^T | 缩放矩阵 |
| ω_{j,N} = E{π(Y,X) \| Z_{·j}=1} | 稀有观测的平均采样概率 | 设计量 |
| M_r(β₀), Λ_r(β₀) | 缩放后的 Fisher 信息矩阵和方差矩阵的极限 | 极限量 |
| M_π(β₀), Λ_π(β₀) | 子采样后的 Fisher 信息矩阵和方差矩阵的极限 | 极限量 |
| δ_i | 采样指示变量（1 = 被选中） | 随机变量 |
| V_i ~ Uniform(0,1) | 采样阈值变量 | 随机变量（辅助） |
| N | 全量数据规模 | 规模 |
| n | 期望子采样规模 | 规模 |
| n_pl, n† | 试点样本和第二阶段样本的实际规模 | 规模 |

**模型**：数据生成机制为 (Y_i, X_i) ~ i.i.d. P，满足估计方程 E{ψ(Y, X, β₀)} = 0。这涵盖了广义线性模型（GLM），其中 μ(·) 是链接函数的逆。**关键结构**：特征 X 分为非稀有部分 U 和稀有部分 Z，Z 的每个分量以概率 ρ_{j,N} → 0 取值为 1。

**可观测数据**：研究者**实际能观测到**的是全量数据 F_N = {(Y_i, X_i)}_{i=1}^N，但**不能直接用于拟合**（因为计算成本）。研究者可以：(1) 以任意概率 π(Y_i, X_i) 抽取一个子样本；(2) 观测被抽中样本的 (Y_i, X_i) 完整信息。**不可观测/潜在量**：全量数据的估计方程值 ψ(Y_i, X_i, β)（因为无法对所有 N 个观测计算）；最优采样概率（依赖于未知的 β₀ 和 M_N(β₀)）；以及"如果使用全量数据会得到什么估计"这一反事实。

**核心识别条件**：采样概率 π(Y, X) 必须满足 **positivity**（0 < π ≤ 1），且采样机制是**泊松采样**（每个观测独立决定是否被选中），从而保证 Horvitz-Thompson 型加权估计方程的无偏性。这是整个理论框架的基石。

#### 第二步：最小内核

**最小例子**：考虑最简单的 logistic 回归，只有一个非稀有特征（截距）和一个稀有二元特征 Z：

- 模型：P(Y=1 | X) = σ(β₀ + β₁Z)，其中 σ 是 sigmoid 函数。
- 数据：N = 10⁵，ρ = 0.1%（即只有 100 个观测携带 Z=1）。
- 目标：估计 β₁（稀有特征的系数）。

**全量数据的困境**：即使使用全量数据，β₁ 的估计精度也受限于携带 Z=1 的观测数（约 100 个），其方差约为 O(1/(Nρ)) = O(1/100)。这是**信息论下界**，任何方法都无法突破。

**均匀子采样的灾难**：如果均匀随机抽取 n = 10³ 个观测，期望只有 1 个观测携带 Z=1。此时 β₁ 几乎不可估计——估计方程的稀有特征分量几乎为零，信息矩阵接近奇异。

**核心数学问题**：如何设计采样概率 π(Y, X)，使得子采样后的估计量达到**全量数据的最优收敛速率**？

**本文的答案**（在最小例子中的体现）：

1. **定理1（全量数据基线）**：β̂_N 的收敛速率是 (Nρ)^(-1/2)，而非 N^(-1/2)。这是因为信息矩阵的稀有特征分量是 O(Nρ)，其逆的平方根给出 (Nρ)^(-1/2)。

2. **定理2（子采样速率）**：子采样估计量 ˇβ_n 的收敛速率是 (Nρ·ω)^(-1/2)，其中 ω = E{π(Y,X)|Z=1} 是稀有观测的平均采样概率。**关键洞察**：速率由"全量数据中稀有观测数 Nρ"与"这些观测被采到的概率 ω"的乘积决定。

3. **RA 设计（最优速率）**：要达到全量数据速率，需要 ω ≍ min{h_N/ρ, 1}。当 h_N ≥ ρ（即采样预算足够覆盖所有稀有观测）时，ω = 1，即**保留所有稀有观测**；当 h_N < ρ 时，ω = h_N/ρ，即**按比例放大稀有观测的采样概率**。

4. **BL 设计（无需先验）**：由于最优设计需要知道哪些观测是稀有的（即需要先验知识），BL 设计通过平衡分数 b(X) 自动实现这一目标——**不需要预先指定稀有特征集**，而是根据每个二元特征的经验频率自动调整采样概率。

**为什么这个例子是"最小内核"**：它剥离了所有一般性技术假设（多个稀有特征、特征间相关性、非线性链接函数等），保留了核心矛盾——**稀有特征的信息集中在少数观测中，子采样必须保护这些观测**。本文的所有理论结果（定理1、2、3）和设计（RC、RA-Lopt、BL）都是这个最小例子的严格推广。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：在大数据回归中，稀有二元特征导致系数估计收敛速率退化（从 N^(-1/2) 降至 (Nρ)^(-1/2)），且子采样可能进一步恶化这一问题；本文研究如何设计采样概率以恢复最优收敛速率。
2. **核心工具/方法**：建立了稀有特征下的子采样渐近理论（定理1-3），提出三类采样设计——稀有普查（RC）、稀有性自适应 L-最优（RA-Lopt）、平衡设计（BL），并开发了联合样本估计量处理两阶段采样的样本重叠。
3. **主要结论**：收敛速率由"特征频率 × 采样概率"决定；RC 设计保留所有稀有观测但可能耗尽预算；RA-Lopt 通过逆频率缩放达到最优速率但需要试点估计；BL 设计仅基于二元特征信息、无需先验指定稀有集，且能达到 RA 目标阶。

#### 关键设定与假设

- **模型类**：估计方程框架，涵盖 GLM。核心假设是 μ(·) 连续可微且严格递增（保证估计方程的唯一解）。
- **稀有特征设定**：ρ_{j,N} → 0 且 Nρ_{j,N} → ∞。这个"中间地带"排除了两种平凡情形：ρ 不趋于 0（特征不稀有，标准理论适用）和 Nρ 不趋于无穷（特征过于稀有，即使全量数据也无法估计）。
- **采样机制**：泊松采样（Poisson sampling），每个观测独立决定是否被选中。这是技术性假设，使得 Horvitz-Thompson 加权估计方程的无偏性成立。相比 Wang et al. (2018) 的"固定大小采样"（fixed-size sampling），泊松采样的实际样本量有波动，但理论分析更简洁。
- **正则性条件**（假设1-3）：缩放后的信息矩阵 M_r(β₀) 和方差矩阵 Λ_r(β₀) 有正定极限。这是标准条件，但**关键创新**在于缩放矩阵 D_N 的选择——用 ρ^{1/2} 而非 1 来缩放稀有特征坐标，这反映了稀有特征信息量的真实尺度。
- **假设4-5**（子采样）：权重函数有下界（α > 0），且缩放后的信息矩阵有正定极限。这些条件保证子采样估计量的渐近正态性。
- **假设6**（两阶段）：试点估计量 √n_pl-一致，且采样概率对试点估计的 Lipschitz 依赖有界。这是联合样本估计量理论的关键。

**相比已有文献的放宽/强化**：
- **放宽**：允许特征频率随 N 变化（ρ_{j,N} → 0），这是对 Wang et al. (2018) 固定特征分布假设的实质性推广。
- **强化**：要求泊松采样（而非固定大小采样），这简化了理论但限制了实用性。
- **新增**：两阶段采样的联合样本估计量（定理3），这是 Wang et al. (2018) 和 Yu et al. (2022) 未涉及的。

#### 主要结果

**定理1（全数据估计量的收敛速率）**：
√(N) D_N (β̂_N - β₀) → N(0, M_r^{-1}(β₀) Λ_r(β₀) M_r^{-1}(β₀))

- **直觉**：D_N 的对角元对稀有特征坐标是 ρ^{1/2}，因此 β̂_{N,r,j} 的收敛速率是 (Nρ_j)^(-1/2)。这比标准 N^(-1/2) 慢，但这是信息论下界——携带稀有特征信息的观测数只有 Nρ_j 个。
- **必要条件**：Nρ_{j,N} → ∞。如果 Nρ 有界，则信息矩阵的稀有特征分量不趋于无穷，估计量甚至不一致。
- **技术难点**：需要处理三角阵列（triangular array）的 CLT，因为 ρ 随 N 变化。作者用 Lindeberg-Feller CLT 验证了条件。

**定理2（子采样估计量的收敛速率）**：
√(N) Ω_N D_N (β̂_n - β₀) → N(0, M_π^{-1}(β₀) Λ_π(β₀) {M_π^{-1}(β₀)}^T)

- **直觉**：Ω_N 的对角元对稀有特征坐标是 ω^{1/2}，因此子采样后稀有特征系数的收敛速率是 (Nρ_j ω_j)^(-1/2)。**核心洞察**：速率由"全量数据中稀有观测数 Nρ_j"与"这些观测被采到的概率 ω_j"的乘积决定。
- **RA 条件**：要达到全量数据速率，需要 ω_j ≍ min{h_N/ρ_j, 1}。当 h_N ≥ ρ_j 时，ω_j = 1（保留所有稀有观测）；当 h_N < ρ_j 时，ω_j = h_N/ρ_j（按比例放大）。
- **技术难点**：需要处理 Horvitz-Thompson 加权估计方程的二阶性质，以及采样概率与估计量之间的相关性。

**命题1（不可识别性风险）**：均匀采样下，P(至少一个稀有特征无观测) ≥ max_j exp(-Nρ_j h_N)。当 Nρ_j h_N 较小时，这个概率不可忽略。

**命题2（RC 最优设计）**：RC-Aopt 和 RC-Lopt 的权重函数。RC 设计保留所有稀有观测，但需要 n > |R_N|，且剩余预算可能不足以采样足够的非稀有观测。

**命题4（RA-Lopt）**：权重 φ_RA-Lopt(Y_i, X_i) ∝ |Y_i - μ(X_i^T β₀)| ||D_N^{-2} X_i||。通过逆频率缩放 D_N^{-2} 实现稀有特征放大，同时保留 L-optimal 的残差加权。

**命题5（BL 设计）**：权重 φ_BL(X_i) ∝ b(X_i)，其中 b(X_i) = Σ_{k∈B} |X_{ik} - X̄_{·k}| / X̄_{·k}。BL 仅基于二元特征的经验频率，无需模型参数或残差估计，且能达到 RA 目标阶。

**定理3（联合样本估计量）**：
√(N) Ω⁰_{ag,N} D_N (β̂_ag - β₀) → N(0, {M⁰_ag(β₀)}^{-1} Λ⁰_ag(β₀) {M⁰_ag(β₀)}^{-T})

- **直觉**：联合样本估计量将试点样本和第二阶段的观测合并，通过 Horvitz-Thompson 型加权处理重叠。其渐近方差由"或"概率（union probability）决定，即观测在任一阶段被选中的概率。
- **条件**：h_N √n_pl → ∞ 和 √(h_pl,N/h_N) → 0。前者保证试点估计的误差可忽略，后者保证试点样本的规模远小于第二阶段样本。
- **技术难点**：需要处理估计的采样概率（pilot 估计）与真实概率之间的差异，以及两个阶段样本的相关性。作者用"或"概率构造了联合估计方程，并证明了可行性（feasibility）不影响渐近分布。

#### 真实例子

**Covertype 数据集**（N = 581,012）：11 个地质-气候组作为二元特征，其中多个组频率低于 1%。实验显示：
- 均匀采样在 n = 2,000 时对稀有组系数有 20-40% 的不可估计率；
- BL 设计将不可估计率降至 0%，且稀有系数 RMSE 降低 50-80%；
- RA-Lopt(BL) 在稀有系数 RMSE 上最优，但 BL 在整体 RMSE 上更稳健。

**IRIS 眼病登记数据**（N = 47,872,555）：甲状腺眼病患病率 0.086%，亚洲人种频率 2.9%。这是一个"双重稀有"场景（稀有结果 + 稀有特征）。实验显示：
- 仅处理结果稀有性的负采样方法（Wang et al., 2021）在稀有特征系数上表现不佳；
- BL+CC（结合病例对照采样）在稀有特征和稀有结果上均优于单一策略；
- 联合样本估计量比仅用第二阶段样本的估计量在稀有系数 RMSE 上降低 30-40%。

#### 🔎 结论是否比证明窄

**明确被证明但未充分强调的**：
- 定理2 的速率 (Nρ_j ω_j)^(-1/2) 实际上给出了一个**精确的权衡关系**：采样概率 ω_j 每增加一倍，稀有系数方差减半。这个关系在正文中没有被提炼为可操作的"采样预算分配公式"。
- 命题5 中 BL 的"无需先验"性质，实际上意味着它可以作为**通用预处理器**——先 BL 采样，再用任何其他设计（Aopt、Lopt 等）做第二阶段。这个"两阶段模板"的思想在正文中只是隐含。

**被泛化声称但只在特定条件下成立的**：
- 摘要声称"RA 框架保护稀有特征"，但定理2 的证明依赖于**泊松采样**和**固定维度 d**。对于"固定大小采样"（实际中更常用）或"维度随 N 增长"的情形，结论是否成立未经验证。
- 第5.3节的"双重稀有"方案（BL+CC）只在 logistic 回归中验证，其理论性质（如渐近正态性）未给出证明，仅靠模拟支持。

**被回避的**：
- **稀有特征之间的相关性**：如果两个稀有特征高度相关（如两个罕见基因突变总是一起出现），本文的独立 Bernoulli 假设不成立，信息矩阵的缩放可能需要更复杂的结构。
- **模型误设定**：如果 μ(·) 不是正确链接函数，稀有特征系数的解释会受影响，但本文未讨论稳健性。

### 四、开放问题

1. **固定大小采样的理论**：本文的泊松采样假设简化了分析，但实际中子采样通常要求精确的样本量。将定理2-3 推广到固定大小采样（如条件泊松采样）需要处理样本量随机性的影响，这是一个自然的技术延伸。

2. **高维稀有特征**：当 d_r 随 N 增长（如基因数据中数千个稀有变异），本文的固定维度假设失效。此时需要新的缩放矩阵和正则化策略，可能涉及稀疏性假设和 minimax 下界。

3. **稀有特征与稀有结果的联合最优设计**：第5.3节的 BL+CC 方案是启发式的，缺乏理论保证。一个开放问题是：在"双重稀有"场景下，最优采样方案是否具有某种分离结构（先处理结果稀有性，再处理特征稀有性）？

4. **自适应采样的序贯性质**：本文的两阶段设计假设试点样本只用于估计采样概率。如果允许**多轮自适应**（每轮根据当前估计更新采样概率），是否能在不增加总采样预算的情况下进一步降低方差？这涉及 bandit 式探索-利用权衡。

5. **模型误设定下的鲁棒性**：当估计方程错误指定时，稀有特征系数的解释会变化。一个开放问题是：本文的采样设计是否对模型误设定鲁棒，或者是否需要针对误设定调整采样准则？

> **提示**：要确认上述哪条是真正的 gap，建议去读**子采样领域**（Wang et al., 2018; Yu et al., 2022; Wang et al., 2022）和**稀有特征分析**（Yan and Bien, 2021; Chen et al., 2024）近期各约 5 篇论文的引言。如果多个独立工作都指向同一个问题（例如"固定大小采样下的稀有特征理论"），那很可能是共识性 gap；如果各说各话，则可能是机会。
