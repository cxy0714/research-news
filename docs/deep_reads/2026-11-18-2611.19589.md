### 一、领域脉络与小综述

#### 这个方向是什么

本文研究的核心问题是：**在高斯相依结构下，Benjamini-Hochberg (BH) 过程能否控制错误发现率 (FDR)**。具体而言，当 p 值来自高斯潜在变量且允许任意单调变换（对应单侧检验）时，研究者关心的是：在名义水平 q 下，FDR 的最大可能值是多少？这个最大值是否由"全局零假设"（所有假设均为真）达到？这个问题属于多重检验理论中"相依性稳健性"（dependence robustness）的子方向，其根本关切是：BH 过程在脱离独立性假设后，其最坏情况表现如何。该方向目前处于**活跃发展阶段**——经典结果（如 PRDS 条件下的 FDR 控制）已确立，但近年来一系列工作表明，在更一般的相依结构下，BH 的 FDR 可能超过名义水平，且精确的最坏情况分析仅在低维或特殊结构（如秩一相关）中完成。

#### 发展脉络

- **奠基工作**：Benjamini 和 Hochberg (1995) 提出 BH 过程，证明在独立均匀 p 值下 FDR 恰好等于 m₀q/K。Benjamini 和 Yekutieli (2001) 将控制推广到正回归相依（PRDS）条件，并给出任意相依下的保守界 m₀qH_K/K（H_K 为第 K 个调和数）。这些工作确立了 BH 过程在"温和相依"下的有效性，但也暗示了任意相依下 FDR 可能膨胀。
- **主要进展**：Chi, Ramdas 和 Wang (2025) 在负相依条件下建立了 Simes 不等式的小水平渐近结果（本文 Theorem 4.1 的直接前驱），其 Theorem 8(III) 给出了固定相关矩阵下全局零假设的 Simes 检验小水平上界。Dobriban (2026) 则首次证明：对双侧高斯检验，即使所有相关系数均为正，BH 过程也可能在名义水平之上失效——这打破了"正相关足够安全"的直觉。Lei (2026) 进一步在维度随 q↓0 增长的设定下，给出单侧检验最坏 FDR 的下界 q√(log(1/q))/√π，表明相依性导致的膨胀可以随维度增长。
- **当前 frontier**：精确刻画"最坏情况 FDR 由何种配置达到"以及"膨胀从哪个维度开始出现"。本文的位置在于：在秩一相关类中，首次证明维度 8 是单侧检验 FDR 膨胀的起始维度，并给出跨维度的精确乘性上界 2W(1)（W 为 Lambert W 函数）。
- **本文的位置**：作者在引言中明确将自身工作定位为对 Chi et al. (2025) 和 Lei (2026) 的补充——前者处理固定矩阵的小水平渐近，后者处理增长维度的下界，而本文填补了"固定维度、任意水平、秩一相关类"这一中间地带。

#### 子线索聚类

1. **相依性结构对 FDR 的影响**（核心线索）：从 PRDS（Benjamini-Yekutieli 2001）到负相依（Chi et al. 2025），再到正相关失效（Dobriban 2026），这条线索追问：什么样的相依结构会让 BH 失效？本文的秩一相关类分析属于此线索的精确化。
2. **最坏情况配置的刻画**：Roquain 和 Villers (2011) 通过精确计算 FDP 分布，识别了最小有利配置（least favorable configurations）。本文的 Theorem 5.2 和 5.3 延续这一思路，但将分析限制在高斯秩一相关类中。
3. **Simes 不等式的相依推广**：从 Hommel (1983) 的任意相依界，到 Block et al. (2008) 的负相依反转，再到 Chi et al. (2025) 的高斯小水平渐近。本文 Theorem 4.1 的有限水平界属于此线索。
4. **FDR 链接定理**：Su (2018) 提出 FDR-linking 定理，将混合零假设的 FDR 与全局零假设的 Simes 概率联系起来。本文 Lemma 5.1 的 oracle 界直接使用这一原理，但保留了有限个备择假设的约束。

#### 这个方向在追问的核心问题

1. **全局零假设是否最不利？** 即 f_K(q) = s_K(q) 是否成立？本文证明在 K≤3 时成立，但在 K=8 时被一个显式混合零构造打破。
2. **膨胀的起始维度是多少？** 本文在秩一相关类中给出答案：K=8。
3. **最坏 FDR 随维度如何增长？** 本文给出上界 2W(1)≈1.134，并证明该界在维度趋于无穷时被逼近。
4. **已知瓶颈**：对于一般相关矩阵（非秩一），精确的最坏 FDR 分析在 K≥4 时仍然开放；本文的秩一限制是分析可行性的关键假设。

#### ⚠️ 作者的 framing（这是作者的说法）

作者将缺口 frame 为："在秩一相关类中，全局零假设是否最不利？"——通过证明维度 8 的显式反例，作者将自身工作呈现为对"全局零假设最不利"这一直觉的首次系统性反驳。作者淡化的竞争路线包括：(i) 一般相关矩阵下的最坏情况分析（仅在引言中提及 Dobriban 2026 和 Lei 2026 作为背景，未深入比较）；(ii) 双侧检验的情形（明确排除在模型外）；(iii) 增长维度下的渐近分析（Remark 2.3 明确声明不处理）。**值得研究者去查的问题**：作者在 Theorem 6.5 的证明中依赖 Lemma E.5 这一跨尾精细不等式，该引理是否对更一般的相关结构（如两因子模型）成立？以及：Lei (2026) 的 q√(log(1/q))/√π 下界与本文的 2W(1) 上界之间，是否存在一个统一的中间维度渐近？

#### 张力

未见明显对立引用。但存在一个微妙的张力：Chi et al. (2025) 的负相依结果暗示"负相关可能比正相关更危险"，而本文的秩一构造同时包含正负相关（通过 ±Z 实现），其维度 8 的膨胀同时依赖正负两个方向。这与 Dobriban (2026) 的"全正相关即可失效"形成对照——两者并不矛盾，但说明"相关符号"与"相关结构"对 FDR 的影响是分离的。


### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

**符号清单**（按类别分组）：

| 类别 | 符号 | 含义 |
|------|------|------|
| 参数/estimand | q | BH 名义 FDR 水平，q∈(0,1) |
| | K | 假设检验总数 |
| | m₀ | 真零假设个数 |
| | FDR | E[FDP]，其中 FDP = F/(R∨1)，F 为错误拒绝数，R 为总拒绝数 |
| 随机变量/样本 | X = (X₁,...,X_K) | 中心化高斯潜在向量，X∼N(0,Σ)，边际方差为 1 |
| | Z | 标准正态随机变量（秩一情形的公共因子） |
| | U = Φ(Z) | 均匀随机变量（秩一情形的公共 p 值） |
| | P_i | 第 i 个假设的 p 值：真零假设下 P_i = Φ(X_i)；备择假设下 P_i = a_i(X_i)，a_i 为任意 Borel 非降函数 |
| 指标/维度 | Σ ∈ C_K | K×K 相关矩阵（允许奇异） |
| | s_K(q) | 全局零假设下 Simes 检验拒绝概率的上确界（对所有 Σ） |
| | f_{m₀,K}(q) | 恰有 m₀ 个真零假设时 FDR 的上确界 |
| | f_K(q) | max_{m₀} f_{m₀,K}(q) |
| | f_K^(1)(q) | 限制在秩一相关类中的 f_K(q) |
| 辅助量 | H_K = Σ_{r=1}^K 1/r | 第 K 个调和数 |
| | W(1) | Lambert W 函数在 1 处的值，满足 W(1)e^{W(1)}=1，W(1)≈0.567143 |
| | Φ, φ | 标准正态分布函数与密度 |
| | t = Φ^{-1}(q) | q 的标准正态分位数 |
| | d(Σ,I₀) | min_{i∈I₀, j≠i} (1-ρ_{ij}²) |

**模型**（数据生成机制）：

1. **潜在高斯结构**：存在中心化高斯向量 X∼N(0,Σ)，Σ∈C_K（允许奇异）。
2. **p 值生成**：每个假设 i 的 p 值由 X_i 经单调变换得到。真零假设下 P_i = Φ(X_i)（均匀分布）；备择假设下 P_i = a_i(X_i)，a_i 为任意 Borel 非降函数（允许跳跃、平坦区域、不连续）。
3. **可观测数据**：研究者观测到 p 值向量 P = (P₁,...,P_K) ∈ [0,1]^K，但不知道哪些是零假设、哪些是备择假设，也不知道相关矩阵 Σ 和变换 a_i。**关键点**：Σ 和 a_i 都是未知的、可对抗选择的（adversarial），且可以依赖于 q。
4. **BH 过程**：给定 P，BH 过程在水平 q 下拒绝 R 个最小的 p 值，其中 R = max{r : P_(r) ≤ rq/K}。

**可观测与不可观测的区分**：研究者可观测 P；不可观测的是 Σ、零假设集合 I₀、备择变换 a_i。FDR 是 F/(R∨1) 的期望，其中 F 和 R 都由 P 和 I₀ 决定。

#### 第二步：最小内核

**核心数学问题**：在秩一相关类中（即 X_i = s_i Z，s_i∈{±1}，Z∼N(0,1)），对所有可能的零假设集合 I₀、所有备择变换 a_i，FDR 的最大值是多少？特别地，这个最大值是否由全局零假设（I₀ = 全部）达到？

**最简例子（K=2）**：

设 K=2，q∈(0,1/2)，h=q/2。考虑秩一相关：X₁ = Z，X₂ = -Z（完全负相关）。真零假设下，P₁ = Φ(Z)，P₂ = Φ(-Z) = 1 - Φ(Z)。注意 P₁ + P₂ = 1。

BH 过程在水平 q 下：
- 若 P₁ ≤ h 且 P₂ ≤ 2h = q，则 R=2，F=2，FDP=1。
- 若 P₁ ≤ h 但 P₂ > q，则 R=1，F=1，FDP=1。
- 若 P₁ > h，则 R=0，FDP=0。

事件 {P₁ ≤ h} 的概率为 h（因为 P₁ 均匀）。因此全局零假设下 FDR = h·1 + h·1 = 2h = q。这里 FDR 恰好等于 q，没有膨胀。

**为什么需要维度 8？** 直觉上，膨胀需要"多个零假设同时被拒绝"且"备择假设的拒绝帮助抬高了阈值"。在 K=2 时，两个零假设完全负相关，它们不可能同时被拒绝（因为 P₁ + P₂ = 1 > 2h 当 q < 1/2）。膨胀需要更复杂的结构：多个零假设在某个尾部同时小，而备择假设在另一个尾部提供额外的拒绝数。

**最小内核的数学表述**：

在秩一相关类中，设 a 个零假设取 U = Φ(Z)，b 个零假设取 1-U = Φ(-Z)，ℓ 个备择假设。由于备择变换可以任意选择，最坏情况是备择假设在某个尾部"恰好"帮助达到下一个 BH 阈值。核心不等式是：

对于任意备择变换，FDR ≤ (G_ℓ(a) + G_ℓ(b))/K · q，

其中 G_ℓ(m) = m + Σ_{j=1}^ℓ m/(m+j)。这个上界在 K=8 时被一个显式构造达到（Proposition 6.1），给出 FDR = 21q/20 > q。

**关键洞察**：膨胀来自"备择假设的拒绝数"与"零假设的拒绝数"之间的耦合。在秩一相关中，零假设的 p 值只有两种形式（U 或 1-U），因此问题简化为两个"块"的计数问题。维度 8 之所以特殊，是因为需要足够的块大小来让备择假设的贡献超过全局零假设的 Simes 概率。


### 三、这篇论文做了什么

#### 三句话

① **研究了什么问题**：在高斯相依下，单侧 p 值的 BH 过程的最坏情况 FDR 是否由全局零假设达到？如果不是，膨胀从哪个维度开始？

② **核心工具/方法**：秩一相关类中的块结构分析（将零假设分为 U 块和 1-U 块）、oracle 上界（Lemma 5.1，基于 Su 2018 的 FDR-linking 原理）、显式构造（Proposition 6.1 的维度 8 例子）、以及跨尾精细不等式（Lemma E.5）。

③ **主要结论**：在秩一相关类中，K≤3 时全局零假设确实最不利（f_K = s_K）；K=8 时存在显式混合零构造给出 FDR = 21q/20，首次证明膨胀；跨维度最坏 FDR 的精确乘性上界为 2W(1)≈1.134，且该界在维度趋于无穷时被逼近。

#### 关键设定与假设

1. **高斯潜在结构**：X∼N(0,Σ)，Σ∈C_K（允许奇异）。相比已有文献（如 Benjamini-Yekutieli 2001 的 PRDS），这里允许任意相关结构，包括负相关和奇异相关。
2. **单调备择变换**：备择假设的 p 值 a_i(X_i) 为任意 Borel 非降函数。这比标准高斯均值偏移模型更一般——允许非参数、不连续的备择。
3. **秩一相关限制**（Theorem 6.5 的核心假设）：X_i = s_i Z，s_i∈{±1}。这是分析可行性的关键——它使问题简化为两个"块"的计数。相比 Lei (2026) 的一般相关矩阵，这是显著限制。
4. **固定维度、任意水平**：与 Chi et al. (2025) 的小水平渐近不同，本文在固定 K 下对 q∈(0,1/2) 给出精确结果。
5. **可对抗选择**：Σ、I₀、a_i 都可以依赖于 q，且可以随 q 变化。这是最坏情况分析的standard设定。

**相比已有文献的放宽/强化**：
- 放宽：备择变换允许任意单调函数（比高斯均值偏移更广）。
- 强化：限制在秩一相关类（比一般相关矩阵更窄）。
- 新增：跨维度的精确乘性上界 2W(1)，这是已有文献没有的。

#### 主要结果

**定理 3.1（稳定性）**：固定 K≥2，若 d(Σ,I₀) ≥ η(q) 且 η(q)log(1/q)→∞，则 FDR/q → m₀/K 一致成立。这意味着：只要涉及零假设的相关系数不趋近于 ±1，FDR 就趋近于独立性基准。**必要条件**：d 的衰减速度不能快于 1/log(1/q)。**技术难点**：需要处理相关矩阵随 q 变化的情形，且不假设备择变换的连续性。

**定理 4.1（非正相关全局零）**：在全局零假设下，若所有相关系数非正，则对 q≤0.1，P{S_K(P)≤q} ≤ q + Σ_{k=2}^K C(K,k) (k/2) (q/K)^2 (kq/K)^{k-2}。**技术难点**：需要高斯密度比较引理（Lemma C.1），证明在非正相关下，联合密度被独立均匀密度逐点控制。**关键改进**：相比 Chi et al. (2025) 的弱负相依假设，这里直接处理高斯非正相关，且给出有限水平（非渐近）界。

**定理 5.2（一个零假设）**：f_{1,K}(q) = qH_K/K。**证明思路**：oracle 上界 + 显式构造。构造中，唯一零假设的 p 值取 U，备择假设在 U 的每个区间"恰好"帮助达到下一个阈值。

**定理 5.3（两个零假设）**：f_{2,K}(q) ≤ s_K(q)。**证明思路**：将两个零假设的 p 值 (U,V) 映射到全局零假设的二维高斯向量，利用重复构造保持 Simes 事件。

**定理 6.5（秩一分类）**：f_K^(1)(q) = q 对 K≤7，f_8^(1)(q) = 21q/20。**证明路线**：
1. 上界：将秩一模型分解为两个尾部（U 块和 1-U 块），对每个尾部应用 Lemma E.3 的单调计数界，再用 Lemma E.5 处理跨尾耦合。
2. 下界：Proposition 6.1 的显式构造，K=8 时取 a=b=3, ℓ=2，备择变换在左尾和右尾分别"帮助"达到阈值。
3. **关键引理**：Lemma E.3（单调计数界）、Lemma E.4（至多一个非单调辅助时的界）、Lemma E.5（跨尾精细不等式）。

**定理 6.6（跨维度上界）**：sup_K f_K^(1)(q)/q = 2W(1)≈1.134。**证明思路**：将 Theorem 6.3 的块结构上界转化为优化问题，最优配置是 a=b=2W(1)/(1+W(1))·K/2，即约 72.4% 的零假设。

#### 真实例子与应用

**Proposition 6.1 的显式构造（维度 8）**：
- 取 K=8, q∈(0,1/2), h=q/8。
- 零假设：3 个取 U = Φ(Z)，3 个取 1-U = Φ(-Z)。
- 备择假设：2 个，分别取 A₁(U) 和 A₂(U)（定义见原文）。
- 在左尾 U∈(0,3h]：3 个 U 块零假设被拒绝，A₁ 在 U≤3h 时为 1（不参与），A₂ 在 U<1-3h 时为 λ（参与）。
- 在区间 (3h,5h]：A₁ 降为 λ，A₂ 仍为 λ，使得 5 个 p 值 ≤ 5h，达到第 5 个阈值。
- 右尾对称。
- 计算得 FDR = 2[3h + 2h·(3/5)] = 21q/20。

**这个例子说明什么**：膨胀需要"备择假设在两个尾部都提供帮助"，且零假设在两个尾部都有分布。维度 8 是满足这一条件的最小维度——需要至少 3+3 个零假设和 2 个备择假设。

**模拟建议**：作者未提供模拟，但定理 3.1 的稳定性结果暗示，在中等维度（K≤7）且相关系数不极端时，BH 的 FDR 接近名义水平；而在 K≥8 且存在强相关时，需要警惕膨胀。

#### 🔎 结论是否比证明窄

**是的，存在几处**：
1. **Theorem 6.5 的"第一膨胀维度"仅对秩一相关类成立**。作者在引言中明确声明："We do not know whether dimension eight is the first inflation dimension for general Gaussian dependence."（原文第 3 页）。但摘要和结论部分使用了"first inflation dimension"的表述，未每次都限定"in the monotone rank-one class"。
2. **Theorem 6.6 的 2W(1) 上界仅对秩一相关类证明**。作者在定理陈述中明确写了"in the monotone rank-one class"，但结论部分（第 10 页）说"the worst-case FDR over all dimensions in this class is twice the omega constant"，这里的"this class"指秩一相关类，但读者可能误读为一般高斯相关。
3. **Theorem 4.1 的界不声称最优**。作者在证明后明确说"These are upper bounds, not claimed maxima"（第 9 页），但摘要中未提及这一点。
4. **定理 3.1 的稳定性结果不覆盖 d 衰减快于 1/log(1/q) 的情形**。作者在 Remark 3.2 中承认："The condition d(q)log(1/q)→∞ is sharp for our proof technique, but we do not know whether it is necessary."（原文第 8 页）。


### 四、开放问题

1. **一般相关矩阵下的第一膨胀维度**（扎根于 Theorem 6.5 的限定"in the monotone rank-one class"）：对于一般高斯相关矩阵，维度 4-7 是否可能已经出现膨胀？作者在引言中承认："The unrestricted comparison f_K = s_K remains open in dimensions four through seven."（原文第 3 页）。**验证方法**：读 Lei (2026) 的 arXiv 2607.14812v4，看其下界构造是否能在 K=4 时给出超过 s_K 的 FDR。

2. **2W(1) 是否是一般相关下的最坏 FDR 上界**（扎根于 Theorem 6.6 的限定"in the monotone rank-one class"）：作者在结论部分说："Whether the constant 2W(1) remains the sharp bound for general Gaussian dependence is an open question."（原文第 10 页）。**验证方法**：检查 Dobriban (2026) 的双侧检验构造是否能在单侧情形下给出更大的膨胀。

3. **定理 3.1 中 d 的衰减速率是否最优**（扎根于 Remark 3.2 的承认）：是否存在相关矩阵使得 d(q)log(1/q) 有界但 FDR/q 不收敛到 m₀/K？**验证方法**：构造 d(q) = c/log(1/q) 的相关矩阵序列，检查 FDR 是否偏离 m₀/K。

4. **非正相关全局零假设的有限水平界是否可改进**（扎根于 Theorem 4.1 的"not claimed maxima"）：式 (4.2) 的系数 (k-1)/(2k) 是否最优？**验证方法**：对 K=3, q=0.05 计算精确的 Simes 概率，与 (4.2) 的界比较。

5. **备择变换的连续性假设**（扎根于模型设定）：本文允许任意 Borel 非降变换，但定理 3.1 的证明依赖单调计数。如果备择变换允许非单调（如双侧检验），最坏 FDR 是否会更大？**验证方法**：将本文的秩一构造与 Dobriban (2026) 的双侧构造对比，看单侧限制是否实质性地降低了最坏 FDR。

**确认 gap 的方法**：要确认上述某条是否是真 gap，去读 Lei (2026)、Dobriban (2026)、Chi et al. (2025) 三篇论文的引言和结论——如果三篇都指向同一个未解决问题（如一般相关下的第一膨胀维度），那就是共识性 gap；如果三篇各说各话，则可能是伪 gap。
