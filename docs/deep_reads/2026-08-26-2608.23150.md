### 一、领域脉络与小综述

- **这个方向是什么**：本文属于非参数统计与谱图理论交叉的一个基础性问题：当我们用有限样本（经验测度）去近似一个未知概率测度时，由该测度诱导的某个微分算子（这里是带带宽 h 的加权图拉普拉斯算子）的谱（特征值）如何随样本变化？更具体地说，它研究的是"经验谱"对"总体谱"的**方差**（而非偏差）的控制。这是一个纯理论问题，不涉及具体应用场景，其成熟度处于"基础理论正在被逐步完善"的阶段——已知结果仅在流形假设下成立，本文试图将之推广到更一般的度量测度空间。

- **发展脉络（history）**：
  - **奠基工作**：图拉普拉斯算子的谱在数据科学中的核心地位由谱聚类（[VL07]）和扩散映射（[CL06]）确立。这些工作奠定了"用图拉普拉斯特征向量/值做降维与聚类"的范式，但缺乏严格的统计保证。
  - **主要进展（流形情形）**：García Trillos, Li 和 Venkatraman [GTLV25] 给出了流形假设下特征值估计的 minimax 速率，其偏差-方差分解中，方差项为 1/√(nh^d)（d 为流形维数），并带有对数因子。这是当前 state-of-the-art，但其技术严重依赖黎曼几何结构（如测地距离、指数映射等）。
  - **确定性扰动理论**：Burago, Ivanov 和 Kurylev [BIK19] 在纯度量测度空间框架下建立了谱的确定性稳定性界，但其条件（球面层条件、球交体积条件）较强，且只适用于指示核 η = 1_[0,1]，无法处理连续核。
  - **本文位置**：Divol 将 [GTLV25] 的方差界从流形推广到"coarse PI 测度"类，同时将 [BIK19] 的确定性扰动理论从指示核推广到连续核，并去掉了 [GTLV25] 中的对数因子。它填补的缺口是：**方差控制到底需要多少几何结构？** 答案是"coarse PI"——一个比流形弱得多、但足以支撑 Poincaré 不等式的条件。

- **子线索聚类**：
  1. **谱聚类与流形学习的算法基础**（[VL07], [BN03], [CL06], [MHM18]）：这些工作从算法和应用角度确立了图拉普拉斯谱的核心地位，是本文问题的来源。
  2. **图拉普拉斯谱的统计收敛性**（[GTLV25], [CT22], [CW22], [GTGHS20], [Wah24], [LTLS25]）：这一簇直接研究经验谱对总体谱的收敛速率，是本文的直接竞争/对话对象。其中 [GTLV25] 是本文的主要对标。
  3. **度量测度空间上的分析**（[BIK19], [AH13], [HT14], [HK98], [HKST15]）：这一簇提供工具——coarse PI 条件、几乎 Lipschitz 样条系统——使得在无微分结构下做分析成为可能。
  4. **相对谱扰动理论**（[BD90], [Ips98], [JW20], [JW23]）：这一簇提供将算子差转化为特征值差的抽象框架，本文第 6 节直接调用。

- **这个方向在追问的核心问题**：
  1. **方差控制的本质条件**：控制经验谱的方差，到底需要测度的什么性质？流形结构是必要的，还是可以被更弱的"粗几何"条件替代？
  2. **速率的最优性**：1/√(nh^d) 是否是方差项的最优速率？对数因子是否可以去掉？
  3. **特征函数的收敛**：特征值之外，特征函数（特征向量）的收敛速率如何？其最优速率是否与特征值不同？（本文第 6 节给出一个上界，但作者自己认为可能非最优。）

- **⚠️ 作者的 framing（必须明确标注成"这是作者的说法"）**：作者把缺口 frame 成"方差控制不需要流形结构，只需要 coarse PI 条件"。他通过引入 coarse PI 测度类，将 [GTLV25] 的流形假设替换为更弱的条件，从而声称自己的结果是"更一般"的。**被淡化/回避的竞争路线**：(a) 作者没有讨论偏差项的处理——他固定 h，只比较同一 h 下的经验与总体算子，回避了 h→0 时偏差-方差权衡的完整问题；(b) 作者没有与 [LTLS25] 的中心极限定理对话，后者可能给出更精细的分布信息；(c) 作者对特征函数 L² 收敛的速率自认非最优，但没有讨论如何改进。**什么明显该被引 / 该存在、却没出现在 intro 里**：作者没有引用 von Luxburg, Belkin 和 Bousquet [VLBB08] 关于谱聚类一致性的经典工作，尽管该文已经指出了"特征值低于本质谱下界"这一关键条件（本文第 3 节的核心假设之一）；也没有引用随机矩阵理论中关于 Wigner 矩阵谱的经典结果——虽然本文的 V-统计量方法与之有潜在联系。

- **张力**：未见明显对立引用。但有一个值得注意的张力点：[GTLV25] 的 minimax 下界暗示 1/√(nh^d) 在流形类上是最优的，而本文在更大的 coarse PI 类上达到了同样的上界（且去掉对数因子）。这意味着要么 [GTLV25] 的下界可以改进（在流形类上），要么 coarse PI 类上的 minimax 速率实际上比流形类更慢（即本文的上界在 coarse PI 类上非最优）。作者在 Remark 1.5 中提到了这个张力，但没有解决它。

### 二、最核心、最简单的例子 / 数学问题

**第一步：把符号、模型、可观测数据交代清楚**

- **度量空间**：(X, ρ) 是一个 Polish 度量空间（完备可分），有界直径。这是最一般的框架——不需要微分结构。
- **概率测度**：μ 是 X 上的 Borel 概率测度，是我们要估计的总体对象。μ 满足 coarse PI 条件（见下）。
- **样本**：X₁, ..., Xₙ ~ μ i.i.d.。经验测度 μₙ = (1/n)Σδ_{Xᵢ}。这是**可观测数据**——我们只有这 n 个点。
- **核函数**：η : [0,∞) → [0,∞)，有界、连续、支撑在 [0,1] 内，且在 [0,1/2] 上 ≥ 1/2。η 是已知的、由用户选择的。
- **带宽**：h > 0，固定。这是平滑参数，控制"局部"的尺度。
- **加权核**：K_h(x, y) = h⁻² η(ρ(x,y)/h) / √(η_h^μ(x) η_h^μ(y))，其中 η_h^μ(x) = ∫ η(ρ(x,y)/h) dμ(y)。注意这里用了**两个**不同的测度来归一化：K_h^μ 用 μ 归一化（总体核），K_h^{μₙ} 用 μₙ 归一化（经验核）。这是本文与 [GTLV25] 的一个关键区别——[GTLV25] 只用 μ 归一化。
- **算子**：Δ_μ^h 是 L²(μ) 上的算子，定义为 ⟨Δ_μ^h u, v⟩_μ = ∫∫ K_h^μ(x,y) (u(x)-u(y))(v(x)-v(y)) dμ(x)dμ(y)。这是**总体算子**（我们想要的对象）。Δ_{μₙ}^h 是 L²(μₙ) 上的对应算子，用 μₙ 和 K_h^{μₙ} 定义。这是**经验算子**（我们实际能计算的）。
- **谱**：λ_{ℓ,μ}^h 是 -Δ_μ^h 的第 ℓ 个特征值（按升序排列，0 = λ₀ < λ₁ ≤ λ₂ ≤ ...）。λ_{ℓ,μₙ}^h 是 -Δ_{μₙ}^h 的对应特征值。**注意**：λ_{ℓ,μₙ}^h 是随机变量（因为 μₙ 是随机的），而 λ_{ℓ,μ}^h 是确定性常数。
- **关键量**：v_μ(h) = inf_{x∈X} μ(B(x,h))，即半径 h 球的最小质量。这是控制整个问题的核心量——它度量了测度在最小尺度 h 上的"集中度"。如果 v_μ(h) 太小（某些小球几乎不含质量），那么经验测度在这些球上就会很不稳定。
- **coarse PI 条件**：μ ∈ PI_r(C_D, C_PI, κ) 意味着 (i) μ 在尺度 ≥ r 上是 doubling 的（μ(B(x,2t)) ≤ C_D μ(B(x,t)) 对所有 t ≥ r）；(ii) 对任意球 B 半径 t ≥ r 和任意局部有界函数 u，有 Poincaré 不等式 ∫_B |u - u_B|² dμ ≤ C_PI t² ∫_{κB} Lip_{μ,r}[u]² dμ。这里 Lip_{μ,r}[u] 是"粗 Lipschitz 常数"（在半径 r 尺度上的局部 Lipschitz 常数）。直观上，coarse PI 条件说：在尺度 ≥ r 上，测度既不太"稀薄"（doubling），又允许函数空间的 Poincaré 不等式成立。**注意**：r 可以远小于 h（本文取 r = βh，β 很小）。

**第二步：讲最小内核**

本文要证明的核心命题可以归结为以下最小问题：

> **最小问题**：设 μ 是 X 上的概率测度，满足 coarse PI 条件（在尺度 βh 上）。给定 n 个 i.i.d. 样本，经验测度 μₙ。问：对任意"光滑"函数 u（例如，u 是 -Δ_μ^h 的特征函数），经验算子 Δ_{μₙ}^h 作用在 u 上的结果，与总体算子 Δ_μ^h 作用在 u 上的结果，在"弱范数"（H^{-1}）下相差多少？

**为什么这个问题是核心？** 因为一旦我们控制了 ∥(Δ_μ^h - Δ_{μₙ}^h)u∥_{H^{-1}}，就可以通过相对扰动理论（第 6 节）将特征值之差 λ_{ℓ,μₙ}^h - λ_{ℓ,μ}^h 转化为这个量的函数。而特征值之差正是我们最终想要的。

**最小例子的具体化**：考虑最简单的情形——X = [0,1]（一维区间），μ = Lebesgue 测度，η = 1_{[0,1]}（指示核）。此时：
- K_h^μ(x,y) = h⁻² 1_{|x-y|≤h} / (h · h) = h⁻⁴ 1_{|x-y|≤h}（近似，忽略边界效应）。
- Δ_μ^h u(x) ≈ h⁻⁴ ∫_{|x-y|≤h} (u(y)-u(x)) dy = h⁻⁴ (∫_{x-h}^{x+h} u(y) dy - 2h u(x))。
- 对光滑 u，Taylor 展开给出 Δ_μ^h u(x) ≈ h⁻⁴ (h² u''(x) + O(h⁴)) = h⁻² u''(x) + O(1)。所以 -Δ_μ^h 近似于 h⁻² 乘以二阶导数算子，其特征值约为 h⁻² (πℓ)²。
- 现在，经验算子 Δ_{μₙ}^h 用 μₙ 代替 μ。关键观察：**经验核 K_h^{μₙ} 的分母 η_h^{μₙ}(x) = (1/n)Σⱼ 1_{|x-Xⱼ|≤h} 是一个经验计数**。当 n 很大时，η_h^{μₙ}(x) ≈ η_h^μ(x) ≈ 2h（对 Lebesgue 测度）。但**当 n 不够大时，η_h^{μₙ}(x) 可能为 0**（如果 x 附近 h 范围内没有样本点），此时 K_h^{μₙ} 无定义！

**这就是本文要解决的核心困难**：经验核的分母可能为 0，导致经验算子无定义。coarse PI 条件的作用是保证：只要 n v_μ(h) ≳ log n，那么以高概率，**每个点的 h 邻域内都有足够多的样本**，从而 η_h^{μₙ}(x) 不会太小。这正是定理 2.12 的内容。

**最小问题的答案**（定理 1.3 的核心）：在上述条件下，
\[
\mathbb{E}[(\lambda_{\ell,\mu_n}^h - \lambda_{\ell,\mu}^h)^2] \lesssim (\lambda_{\ell,\mu}^h)^2 \frac{1 + C_{PI}}{n v_\mu(h)}.
\]
也就是说，**相对误差的平方以 1/(n v_μ(h)) 为界**。这个速率与流形情形下的结果一致（除了对数因子），但**不要求 μ 有任何光滑性或流形结构**——只需要 coarse PI。

**为什么这个结果非平凡？** 因为经验算子的定义本身就依赖于样本（分母归一化），而样本的随机性会通过两条路径影响特征值：(1) 核的分子（经验测度的积分）的波动；(2) 分母（η_h^{μₙ}）的波动。第二条路径在流形情形下被几何结构（测地距离的稳定性）所控制，而在一般度量空间中没有这种结构可用。本文的贡献在于证明：coarse PI 条件足以同时控制这两条路径。

### 三、这篇论文做了什么

**三句话**：
1. **研究了什么问题**：在固定带宽 h > 0 下，经验图拉普拉斯算子 Δ_{μₙ}^h 的特征值如何逼近总体算子 Δ_μ^h 的特征值，以及这种逼近的方差以什么速率衰减。
2. **核心工具/方法**：引入"coarse PI 测度"这一新的测度类（比流形假设弱得多），结合几乎 Lipschitz 样条系统（Auscher–Hytönen–Tapiola 构造）建立多尺度 Poincaré 不等式，再通过 V-统计量的集中不等式控制经验算子的波动。
3. **主要结论**：在 coarse PI 条件下，对阶数小于 h⁻² 的特征值，相对误差的均方以 (1 + C_PI)/(n v_μ(h)) 为界；该界不依赖被测度的正则性，且对光滑流形情形去掉了 [GTLV25] 中的对数因子。

**关键设定与假设**：
- **设定**：Polish 度量空间 (X, ρ)，有界直径；概率测度 μ；核 η 连续、支撑在 [0,1]、在 [0,1/2] 上 ≥ 1/2；带宽 h > 0 固定。
- **假设（定理 1.3）**：
  1. μ ∈ PI_{βh}(C_D, C_PI, κ)，即 μ 在尺度 βh 上是 coarse PI 的（β 是依赖于 C_D, κ 的小常数）。
  2. n v_μ(h) ≥ C₁ log(n(1 + C_PI))，其中 C₁ 是足够大的常数。这个条件保证每个 h 球内都有足够的样本。
  3. 特征值 λ_{ℓ,μ}^h 满足 gap 条件：min_{k≠ℓ} |λ_{k,μ}^h - λ_{ℓ,μ}^h| ≥ γ λ_{ℓ,μ}^h（γ ∈ (0,1]）。
  4. λ_{ℓ,μ}^h ≤ C₀ h⁻²（特征值不超过算子范数的常数倍）。
- **相比已有文献的放宽/强化**：
  - **放宽**：不要求 μ 有密度，不要求 X 是流形，不要求测度有光滑性。coarse PI 条件比流形假设弱得多——它只要求测度在粗尺度上是 doubling 的且满足 Poincaré 不等式。
  - **强化**：去掉了 [GTLV25] 中的对数因子（在光滑流形情形下）。代价是假设了特征值的 gap 条件（[GTLV25] 也有类似假设）。

**主要结果**：
- **定理 1.3（主定理）**：在上述假设下，存在常数 C 使得
  \[
  \mathbb{E}[(\lambda_{\ell,\mu_n}^h - \lambda_{\ell,\mu}^h)^2] \le C (\lambda_{\ell,\mu}^h)^2 \frac{1 + C_{PI}}{n v_\mu(h)}.
  \]
  证明分三步：(i) 定理 2.12 证明 μₙ 以高概率是 coarse PI 的（稳定性）；(ii) 定理 5.3 证明经验算子与总体算子的差在 H^{-1} 范数下以 1/√(n v_μ(h)) 衰减（浓度）；(iii) 定理 6.8 将 H^{-1} 范数控制转化为特征值差（相对扰动理论）。
- **定理 6.12（特征函数收敛）**：在相同假设下，特征函数在 H¹ 范数下的收敛速率与特征值相同。作者自认此速率可能非最优（L² 范数下可能更快），但未给出改进。

**证明路线与技术技巧**：
- **整体路线**：三步走——(1) 证明经验测度 μₙ 继承 coarse PI 性质（定理 2.12）；(2) 证明经验算子与总体算子的差在 H^{-1} 范数下可控制（定理 5.3）；(3) 通过相对扰动理论将 H^{-1} 控制转化为特征值差（定理 6.8）。
- **关键技巧 1：几乎 Lipschitz 样条系统**。这是本文最核心的技术工具。Auscher–Hytönen–Tapiola [AH13, HT14] 构造了在 doubling 度量空间上的样条系统，具有以下性质：(i) 局部支撑（支撑在半径 ~δʲ 的球内）；(ii) 几乎 Lipschitz（Hölder 指数 ϑ 任意接近 1）；(iii) 构成 L²(μ) 的框架（frame）。本文的关键观察是：**这些样条系统在 coarse 尺度上仍然存在**（只需 doubling 在尺度 ≥ r 上成立），从而可以用它们来建立多尺度 Poincaré 不等式。
- **关键技巧 2：多尺度 Poincaré 不等式**。定理 4.5 证明：对任意 u ∈ L²(μ)，有
  \[
  \|u - \Pi_{j,\mu} u\|_{L^2(\mu)}^2 \lesssim (1 + C_{PI}) \delta^{2j} \langle -\Delta_\mu^h u, u \rangle_\mu
  \]
  其中 Π_{j,μ} 是到样条空间 V_j 的正交投影。这个不等式将 L² 范数（在细尺度上的波动）与 H¹ 能量（粗尺度上的梯度）联系起来。证明的关键是：样条系统的几乎 Lipschitz 性质允许我们用"粗梯度"来控制"细波动"。
- **关键技巧 3：V-统计量的集中不等式**。定理 5.2 将经验算子的波动转化为 V-统计量的波动。具体地，∥(Δ_μ^h - Δ_{μₙ}^h)u∥_{H^{-1}} 可以表示为 (1/n²)Σ_{i,j} ψ(X_i, X_j) 的形式，其中 ψ 是退化核。然后利用 V-统计量的 Hoeffding 型不等式（通过 U-统计量的投影分解）得到 1/√(n v_μ(h)) 的速率。这里的难点是处理核的退化性——ψ 的均值不为零，但可以通过中心化处理。
- **关键技巧 4：相对扰动理论**。第 6 节将 H^{-1} 范数控制转化为特征值差。这里的关键是：对于自伴算子 A 和 B，如果 ∥(A-B)φ∥_{A^{-1/2}} 很小，那么特征值之差可以被控制。作者使用了 [BD90, Ips98] 的经典框架，但将其推广到无穷维和一般度量空间。

**真实例子与应用**：本文为纯理论论文，**没有任何真实数据例子或模拟实验**。作者在引言中提到了潜在的应用场景（谱聚类、扩散映射、流形学习），但没有给出具体的数值演示。这一点在评估时需要留意：本文的价值在于理论贡献（更弱的假设、更快的速率），而非实证表现。

**🔎 结论是否比证明窄**：
- **是的，存在结论比证明窄的地方**。具体来说：
  1. **定理 1.3 只覆盖了"简单特征值"**（gap 条件），对于重特征值（如流形上的对称性导致的特征值重数 > 1）没有给出结果。作者在定理 6.12 中处理了特征函数的收敛，但只针对简单特征值。
  2. **定理 1.3 的速率 1/√(n v_μ(h)) 是均方误差**，而非高概率界。作者在证明中实际上得到了高概率界（指数衰减），但定理陈述只写了均方形式。这意味着高概率界可能更强，但作者没有明确陈述。
  3. **特征函数收敛（定理 6.12）的速率可能非最优**。作者自己承认 L² 范数下的收敛可能更快（h/√(n v_μ(h)) 而非 1/√(n v_μ(h))），但没有给出改进。这是一个明确的"结论比证明窄"的例子——证明方法可能支持更强的结论，但作者没有去证明。
  4. **没有讨论偏差项**。作者固定 h，只比较同一 h 下的经验与总体算子。但在实际应用中，h 通常随 n 趋于 0，此时偏差项（λ_{ℓ,μ}^h 与极限算子特征值之差）也需要控制。作者没有处理这个问题，因此定理 1.3 不能直接用于 h→0 的设定。

### 四、开放问题

1. **特征函数 L² 收敛的最优速率**：作者在定理 6.12 中给出了 H¹ 范数下的收敛速率，但自认 L² 范数下可能更快（见第 6 节末尾的讨论）。要证明 L² 范数下的最优速率，可能需要额外的结构假设（如测度的局部正则性），或者更精细的谱理论工具。这是一个明确的开放问题，扎根于定理 6.12 的陈述。

2. **重特征值的处理**：定理 1.3 的 gap 条件排除了重特征值。但在实际应用中（如对称流形），重特征值是常见的。如何处理重特征值？可能需要考虑特征空间的收敛（而非单个特征向量），或者使用谱投影的收敛。这是一个自然的推广方向，扎根于定理 1.3 的假设。

3. **偏差-方差权衡的完整刻画**：本文只处理了方差项。要得到特征值估计的完整风险，需要同时控制偏差项（λ_{ℓ,μ}^h 与极限算子特征值之差）。这需要研究 h→0 时 λ_{ℓ,μ}^h 的收敛速率，以及它与方差项 1/√(n v_μ(h)) 之间的权衡。这是一个重要的开放问题，扎根于定理 1.3 的设定（固定 h）。

4. **coarse PI 条件的可检验性**：本文引入了 coarse PI 测度类，但如何从数据中检验一个测度是否属于这个类？这是一个统计推断问题。作者在引言中提到"这是迈向可检验的弱流形假设的第一步"，但没有给出具体的检验方法。这是一个应用导向的开放问题，扎根于第 1.2 节的讨论。

5. **偏差校正与去偏**：定理 1.3 的速率 1/√(n v_μ(h)) 是否可以通过偏差校正（如 debiasing）进一步改进？作者在 Remark 1.5 中提到 minimax 速率可能更慢（在 coarse PI 类上），但没有给出下界。要确认这一点，需要构造一个 coarse PI 测度类上的 minimax 下界。这是一个理论问题，扎根于 Remark 1.5 的猜想。
