# Low-discrepancy quasi-uniform digital sequences in every dimension

**主题**: 统计计算 / 算法  
**相关性**: 6/10  
**链接**: <https://hexagonmath.org/abs/2610.00664v1>

### 一、领域脉络与小综述

#### 这个方向是什么

本文研究的核心问题是：**能否构造出在任意维度下都"拟均匀"（quasi-uniform）的数字序列**。所谓拟均匀，是指对序列的任意前 N 个点，其覆盖半径（covering radius）和分离距离（separation）都达到最优阶 N^{-1/s}（s 为维度），即网格状分布的理想性质。这个问题处于**计算数论**与**拟蒙特卡洛（QMC）方法**的交叉地带：QMC 方法用低差异序列（low-discrepancy sequences）逼近高维积分，而拟均匀性则进一步要求点集在任意前缀下都像网格一样"铺开"，这比传统的低差异性质更强。该方向在 2026 年仍处于活跃发展阶段，核心挑战在于：经典的低差异序列（Halton、Faure、Sobol'、Niederreiter）虽然差异度低，但**分离性质差**——存在任意接近的点对，导致其网格比（mesh ratio）无界。

#### 发展脉络

1. **奠基工作：QMC 与低差异序列**。Niederreiter [30] 和 Faure [12] 建立了基于有限域上多项式基的数字序列理论，其核心是 (t,s)-序列的概念——通过生成矩阵将整数索引映射到单位立方体中的点。这类序列的差异度（discrepancy）达到最优阶 O((log N)^s / N)，但**分离性质从未被系统研究**。

2. **问题的提出：拟均匀性的系统研究**。Dick、Goda 和 Suzuki [10] 首次系统研究了 QMC 点集的拟均匀性，证明了二维 Larcher–Pillichhammer 网是拟均匀的，并提出了一个关键猜想：是否存在任意维度的拟均匀数字序列？他们同时证明了 Faure 序列（s=p 时）不是拟均匀的。Goda、Hofer 和 Suzuki [16] 进一步证明了 Halton 序列和三类 Halton 型序列不是拟均匀的，并提出了开放问题：**是否存在任何 Halton 型序列是拟均匀的？**

3. **负面结果：经典序列的失败**。本文第 3 节给出了一个统一的失败机制：**进位（carry）**。经典序列的每个坐标独立读取索引的多项式表示，当一个坐标发生进位时，其他坐标的"前导数字"完全不变，导致两个索引差为"进位"的点在所有其他坐标上几乎重合。这个机制不仅解释了已知的负面结果，还推广到了更广的类别——**只要有一个坐标是"radical inverse"（即读取索引的 p 进制数字），无论其他坐标如何加扰，序列都不可能是拟均匀的**（定理 6、推论 14）。

4. **正面构造：留数定理作为设计工具**。本文的核心创新在于第 4-6 节：将数字序列的坐标读取重新解释为**射影直线上的留数**。一个关键观察是，如果所有坐标都从同一个有理函数的留数中读取数字，那么**一个坐标的进位会被其他坐标"感知"**——因为留数定理（引理 21(c)）保证了所有坐标的数字之和为零。这打破了经典序列中"坐标独立"的障碍，使得构造拟均匀序列成为可能。

5. **当前前沿：精确关系的极限**。第 7 节证明了在"有界深度的精确线性关系"这一框架内，每个序列最多携带约一个关系/层（定理 51），这解释了为什么构造如此困难。第 8 节则通过"窗口"（允许关系在一定范围内变化）突破了这一限制，在**每个**全层都实现了接近最优的分离，代价是常数从 1 变为 1−O(1/p)。

#### 子线索聚类

- **负面结果线索**：经典序列的失败机制（第 3 节）。核心工具是**多项式基的整除性**——构造一个索引差 D，使其在一个坐标中表现为"进位"，在其他所有坐标中表现为"高次整除"。这条线索的顶点是定理 6，它统一了 Halton、Faure、Sobol'、Niederreiter 的失败。

- **正面构造线索**：留数定理与自相似加扰（第 4-6 节）。核心工具是**射影直线上的留数**和**Mahler 方程**。这条线索从"砖墙"（二维）到"块周期"（任意维度），逐步构造出拟均匀序列。

- **极限与权衡线索**：精确关系的计数（第 7 节）与窗口方法（第 8 节）。核心工具是**留数定理的代数约束**——每个有界深度的关系对应一个多项式，而多项式的个数受维度限制。

#### 这个方向在追问的核心问题

1. **存在性问题**：是否存在任意维度的拟均匀数字序列？本文给出了肯定的构造性回答（定理 68），但构造的常数 1−O(1/p) 是否最优仍开放。
2. **分类问题**：哪些数字序列是拟均匀的？本文给出了一个充分条件（自相似加扰），但必要条件仍不清楚。
3. **效率问题**：拟均匀序列的分离常数能达到多大？本文的构造在 p 较大时接近 1，但小素数（p=2,3）的情况仍开放。

#### ⚠️ 作者的 framing

作者将缺口 frame 成：**经典序列的失败源于"坐标独立"的读取方式，而留数定理提供了一种"坐标耦合"的读取方式**。这个 framing 使得本文的构造看起来是"显然的下一步"——既然独立读取导致失败，那就让坐标共享同一个有理函数。作者淡化了以下竞争路线：(a) **非数字序列**的构造（如 Kronecker 序列、格点序列），这些序列在任意维度都存在拟均匀的例子，但没有低差异保证；(b) **随机化方法**（如 Owen 加扰），这些方法在概率意义下拟均匀，但几乎必然不拟均匀 [39]。作者在引言中明确将范围限定在"数字序列"内，这既是本文的力量（构造是显式的、确定性的），也是其局限（不覆盖其他类型的点集）。

**值得研究者去查的问题**：作者在引言中声称"没有找到文献中关于拟均匀数字序列的构造"，但**第 3 节的失败机制是否适用于更广的"多项式基"序列**（如 Niederreiter-Xing 序列）？作者在第 11 节（开放问题）中提到了这一点，但没有给出答案。此外，**"窗口"方法是否可以在非自相似加扰下实现**？作者在第 8.5 节中排除了与骨架关系的组合，但没有排除其他类型的窗口。

#### 张力

被引工作之间存在一个明显的张力：**Dick-Goda-Suzuki [10] 和 Goda-Hofer-Suzuki [16] 的负面结果**表明经典序列失败，而**本文的正面构造**则表明通过"坐标耦合"可以修复。这个张力不是矛盾，而是揭示了"数字序列"这个类别的内部结构：经典序列是"坐标独立"的极端，而本文的构造是"坐标耦合"的极端。另一个张力在于**分离与差异的权衡**：本文的构造在分离上达到最优，但差异度是否仍然是最优的 O((log N)^s / N)？作者在引言中声称"低差异"（因为 (0,s)-序列的差异度自动最优），但没有给出具体的差异常数。

### 二、最核心、最简单的例子 / 数学知识

#### 第一步：符号、模型、可观测数据

**符号**（按本文第 2 节）：

- **q = p^r**：基数（base），p 为素数，r ≥ 1。数字序列的每个坐标读取索引的 q 进制数字。
- **s**：维度（坐标数）。
- **V(z) = Σ_k V_k z^k ∈ F_q[z]**：索引多项式。整数索引 N 被编码为多项式 V，其系数 V_k 是 N 的 q 进制数字。
- **ι(V) = Σ_k enc(V_k) q^k**：索引多项式的整数取值，enc: F_q → {0, ..., q-1} 是固定的数字编码。
- **P_m = {y(V) : deg V < m}**：序列的前 q^m 个点。每个点 y(V) ∈ [0,1)^s 有 s 个坐标。
- **y_{c,n}(V)**：点 y(V) 的第 c 个坐标的第 n 个数字（n = 0 是最重要的数字）。
- **生成矩阵 C_c**：s 个无穷矩阵，C_c[n][k] 是第 c 个坐标的第 n 个数字对索引数字 V_k 的依赖系数。数字序列的定义是 y_{c,n}(V) = Σ_k C_c[n][k] V_k。
- **帧（frame）**：一组不同的点 a_0, ..., a_{s-1} ∈ F_q，以及索引读取位置 ∞。经典 Faure 序列的帧是 a_c = c，索引在 ∞ 读取。
- **Pascal 矩阵 P_a**：P_a[n][k] = binom(n, k) a^{n-k}，是 Faure 序列的生成矩阵。
- **加扰（scramble）L_c**：下三角可逆矩阵，作用于生成矩阵 C_c = L_c P_{a_c}。
- **偏移映射（offset map）**：从单元数字（cell digits，即索引的前 K 个数字）到几何数字（geometric digits，即坐标的第 K 个及更深的数字）的线性映射。
- **进位长度（carry length）l**：从一个单元到相邻单元时，索引数字发生变化的位数。
- **响应（response）D_i(l)**：进位长度为 l 时，几何数字的变化量。
- **分离（separation）δ(P)**：点集中任意两点的最小距离。
- **覆盖半径（covering radius）h(P)**：任意点到点集的最大距离。
- **网格比（mesh ratio）**：h(P)/δ(P)，拟均匀要求该比值有界。
- **自相似加扰（self-similar scramble）**：满足特定代数条件的加扰，使得偏移映射不依赖于层数 K。
- **留数（residue）Res_a(F dz)**：有理函数 F 在点 a 处的留数，即 Laurent 展开中 (z-a)^{-1} 的系数。
- **局部根（local root）z_c(x)**：满足 w(z_c(x)) = x 的形式幂级数，其中 w = Π_c (z - a_c)。
- **均匀化子（uniformizer）**：在点 a_c 处的一次函数 z - a_c。

**模型**（数据生成机制）：

数字序列的模型是：**索引 N → 多项式 V → 在每个坐标的"位置" a_c 处读取 V 的 Taylor 系数**。具体地，坐标 c 的第 n 个数字是 y_{c,n}(V) = Res_{a_c}(V (z - a_c)^{-n-1} dz)（未加扰时）。加扰 L_c 是对这些数字的线性变换。**关键的可观测数据**是：对于任意前缀 P_m，点集的分离 δ(P_m) 和覆盖半径 h(P_m)。**要估计的目标**是：分离常数 sep(P_m) = δ(P_m) · N^{1/s} 是否对所有 m 有正下界。

#### 第二步：最小内核

**最小内核**：**一个坐标的进位如何被其他坐标感知？**

**最简例子**：二维 Faure 序列，基数 p，帧 (0, 1)，索引在 ∞ 读取。未加扰时，坐标 0 读取 V 在 0 处的 Taylor 系数，坐标 1 读取 V 在 1 处的 Taylor 系数。

考虑两个索引 N 和 N'，其差 D = N' - N 是一个"进位"：在坐标 0 的基数 p 表示中，D 是 p^K 的倍数（即 D 的前 K 个数字为 0），但在坐标 1 的基数 p 表示中，D 的前 K 个数字不全为 0。例如，取 D = p^K - 1（即 p 进制下的 111...1，K 个 1）。

- **坐标 0**：V' - V = D 在 0 处的 Taylor 系数为 0（因为 D 是 p^K 的倍数），所以坐标 0 的前 K 个数字不变。
- **坐标 1**：V' - V = D 在 1 处的 Taylor 系数为 D(1) = p^K - 1 ≡ -1 (mod p)，所以坐标 1 的最重要数字改变。

现在看两个点的位置。在单元尺度（cell scale）下，坐标 0 的前 K 个数字决定了点所在的"列"，坐标 1 的前 K 个数字决定了"行"。由于 D 在坐标 0 的前 K 个数字为 0，两个点在坐标 0 的列相同；由于 D 在坐标 1 的前 K 个数字为 -1，两个点在坐标 1 的行相邻。因此，两个点位于相邻的列，且坐标 0 的位置几乎相同（差一个进位）。

**为什么这导致分离差**：在坐标 0，两个点的位置差为 D 的 Taylor 系数，即 D 在 0 处的展开。由于 D = p^K - 1，其 Taylor 系数为 -1 在 0 处，即 D(z) = -1 + O(z^K)。所以坐标 0 的位置差为 -1/p^K（在单元尺度下），而坐标 1 的位置差为 1/p^K（因为 D(1) = -1）。两个点的距离约为 √2 / p^K，而单元边长为 1/p^K，所以分离常数约为 √2，**不随 K 增长**——这看起来不错。但问题在于，**存在更长的进位**：取 D = p^{K+1} - 1，则坐标 0 的前 K+1 个数字不变，坐标 1 的前 K+1 个数字改变，两个点的距离约为 √2 / p^{K+1}，而单元边长为 1/p^{K+1}，分离常数仍为 √2。**关键在于**：对于任意 K，都存在这样的进位 D，使得两个点的距离约为 √2 / p^K，而单元边长为 1/p^K。因此，分离常数 sep(P_K) 不随 K 增长，但**覆盖半径**呢？覆盖半径要求任意点附近都有序列点，而分离只要求点之间不靠近。拟均匀要求两者都达到最优阶。

**本文的修复**：**留数定理**。考虑一个有理函数 F = V / (w(z) - x)，其中 w(z) = (z - a_0)(z - a_1)。在射影直线上，F 的留数之和为零。具体地，F 在 a_0, a_1 和 ∞ 处的留数满足：

Res_{a_0}(F dz) + Res_{a_1}(F dz) + Res_∞(F dz) = 0.

如果坐标 0 读取 Res_{a_0}(F dz)，坐标 1 读取 Res_{a_1}(F dz)，那么**一个坐标的进位会被另一个坐标"感知"**：当坐标 0 的进位发生时，坐标 1 的留数会相应改变，以保持总和为零。这就是"砖墙"（brick wall）的基本思想：**坐标之间的耦合通过留数定理实现**。

**为什么这修复了分离**：在砖墙中，坐标 0 的进位导致坐标 1 的几何数字改变，使得两个点在坐标 1 的位置差不再是 1/p^K，而是约 1/2（半格）。因此，两个点的距离约为 1/2 个单元，而不是 √2 个单元。更重要的是，**这个耦合在所有尺度上都成立**，因为留数定理不依赖于层数 K。这就是为什么砖墙能在所有全层保持分离常数。

**最小内核的数学本质**：**留数定理将"坐标独立"的读取方式替换为"坐标耦合"的读取方式**。在经典序列中，每个坐标独立读取索引的多项式表示，进位只影响一个坐标；在砖墙中，所有坐标共享同一个有理函数，进位被所有坐标"分担"。这个替换的关键是**射影直线上的留数定理**：所有留数之和为零，因此一个坐标的进位必然导致其他坐标的响应。

**为什么这很难**：留数定理给出的关系是**线性**的，但分离性质要求的是**非线性**的约束（点之间的距离）。本文通过"窗口"方法（第 8 节）将线性关系转化为非线性约束，但代价是常数从 1 变为 1−O(1/p)。这个权衡是本文的核心技术贡献。
