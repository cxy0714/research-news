# Detecting Random Geometric Graphs with General Kernel

**作者**: Dong Huang, Shuangping Li  
**主题**: 高维统计 / 随机矩阵  
**相关性**: 7/10  
**链接**: <https://arxiv.org/abs/2610.12765>

### 一、领域脉络与小综述

#### 这个方向是什么

本文研究的是一个**假设检验**问题：给定一个 $n$ 个顶点的图，判断它是由潜在的高维几何结构生成的（随机几何图，RGG），还是一个纯粹的随机图（Erdős–Rényi 图，$G(n,p)$），且两者具有相同的期望边密度。核心挑战在于，随着潜在维度 $d$ 增大，球面上随机点的内积分布趋于集中（集中在 0 附近），RGG 与 $G(n,p)$ 的局部结构（如边、树）越来越相似，几何信号变得极其微弱。这个方向要回答的根本问题是：**在什么维度 $d$ 下，几何结构在统计上仍然可检测？** 临界维度 $d_\star = d_\star(n, K)$ 由顶点数 $n$ 和核函数 $K$ 的局部光滑性共同决定。该问题属于高维统计与随机图模型的交叉，其核心数学工具是球面调和分析、谱分解和子图计数的矩方法。

#### 发展脉络

- **奠基工作：硬阈值核（Hard Threshold Kernel）**。Bubeck, Ding, Eldan, and Rácz (2016) [BDER16] 研究了经典的硬阈值 RGG（即 $K(t) = \mathbf{1}\{t \ge \tau\}$，两点距离足够近才连边），证明了临界维度 $d_\star \asymp n^3$。他们的下界证明依赖于将 RGG 与 Wishart 矩阵的谱性质联系起来，并与高斯正交系综（GOE）进行比较。这项工作确立了"谱方法"和"矩方法"两条技术路线。
- **主要进展：光滑核（Smooth Kernel）**。Mao, Wu, and Xu (2026) [MWX26] 将结果推广到 $K'(0) \neq 0$ 的光滑核，证明 $d_\star \asymp n^{3/4}$。关键洞察是：对于光滑核，几何信号主要由核函数在 0 点的一阶导数（即线性项）控制，而线性项对应的球面调和 $P_{1,d}(t) = \sqrt{d}\, t$ 的谱性质决定了信号强度。这个结果首次揭示了**核的局部光滑性**与检测阈值之间的定量关系。
- **当前前沿：核的奇异性与高阶导数**。本文（Huang & Li, 2026）填补了硬阈值核（$d_\star \asymp n^3$）与一阶光滑核（$d_\star \asymp n^{3/4}$）之间的空白。作者引入了"尖点类"（cusp class）核，允许核在 0 点不可导（如 $|t|^\alpha$，$0<\alpha<1$），并证明了临界维度为 $d_\star = n^{3/(3\alpha+2)}$（纯偶尖点）或 $d_\star = n^{3/(3\beta+1)}$（纯奇尖点）。对于 $K'(0)=0$ 但 $K^{(m)}(0)\neq 0$ 的光滑核，则得到 $d_\star = n^{3/(3m+q_m)}$，其中 $q_m=1$（$m$ 奇）或 $q_m=2$（$m$ 偶）。这给出了一个**统一的阈值公式**，将核的局部 Taylor 展开阶数与检测难度直接挂钩。
- **相关平行工作**。Bangachev and Bresler (2024) [BB24a] 在环面 $L^\infty$ 度量下发现四边形计数优于三角形计数，表明几何的"度量类型"会影响最优统计量。Luo (2026) [Luo26] 构造了依赖于 $d$ 的核，其中三角形信号消失但四边形仍可检测，进一步支持了本文的结论。

#### 子线索聚类

1. **基于子图计数的检验**：利用符号三角形计数 $S_3$ 和符号四边形计数 $S_4$ 作为检验统计量。这是本文的主要方法。其核心是计算这些统计量在 RGG 和 $G(n,p)$ 下的均值差（信号）和方差（噪声），信号-噪声比决定了可检测性。
2. **基于谱方法的检验**：比较图的邻接矩阵谱与 GOE 谱。这是 [BDER16] 的方法，适用于硬阈值核。本文的证明中，谱分析（特别是 Gram 矩阵的谱）也作为关键技术出现，但主要用于不可检测性的证明。
3. **基于后验展开的不可检测性证明**：这是本文的核心技术贡献。通过将 KL 散度展开为不同阶的"相互作用"项，并利用球面调和分析控制这些项，从而证明当 $\Lambda_{n,d} \to 0$ 时，任何检验都无法区分 RGG 与 $G(n,p)$。

#### 这个方向在追问的核心问题

1. **临界维度的精确刻画**：给定核 $K$，$d_\star$ 是多少？它与 $K$ 的什么性质有关？（答案：局部 Taylor 展开的首个非零项的阶数和系数。）
2. **最优检验的构造**：什么统计量能达到 $d_\star$？是三角形计数、四边形计数，还是更高阶的子图计数？
3. **计算与统计的权衡**：达到最优阈值的检验是否可以在多项式时间内计算？子图计数是多项式时间的，但是否存在更复杂的统计量能突破 $d_\star$ 但计算上不可行？

#### ⚠️ 作者的 framing

作者在引言中明确将缺口定义为：**"连接硬阈值核（$d_\star \asymp n^3$）与光滑核（$d_\star \asymp n^{3/4}$）之间的无人区"**。他们声称：
- 对于不可导的连续核（尖点），阈值由核的 Hölder 指数 $\alpha$ 决定，公式为 $d_\star = n^{3/(3\alpha+2)}$（偶）或 $n^{3/(3\beta+1)}$（奇）。
- 对于 $K'(0)=0$ 的光滑核，阈值由首个非零导数阶数 $m$ 决定，公式为 $d_\star = n^{3/(3m+q_m)}$。
- 他们**反驳了 [MWX26] 的猜想**（即三角形计数对所有核都是最优的），给出了一个具体的反例：当核的奇偶分量满足特定关系时，三角形信号消失，四边形计数成为最优。

**值得注意**：作者在"讨论"部分（第 6 节）明确提到，他们的结果**反驳了 [MWX26, Conjecture 1]**，即"三角形计数对一般核总是最优"的猜想。这是一个重要的声明，但它的正确性依赖于本文定理的证明，研究者应亲自验证。

#### 张力

- **未见明显对立引用**：在提供的文本中，没有发现直接相互矛盾的引用。但存在一个隐含的张力：**几何类型（球面 vs 环面 $L^\infty$）对最优统计量的影响**。[BB24a] 在环面上发现四边形优于三角形，而本文在球面上发现三角形在大多数情况下最优（除特殊抵消情况）。这说明结论可能对几何的"对称性"敏感，这是一个值得注意的开放问题。
- **另一个张力**：本文的不可检测性证明依赖于"后验展开"和"谱分析"，而 [BDER16] 的证明依赖于 Wishart-GOE 比较。这两种技术路线是否在更一般的设定下等价？作者没有讨论这一点。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型与可观测数据

**符号清单**（按类别分组）：

| 符号 | 含义 | 类别 |
|---|---|---|
| $n$ | 顶点数 | 规模参数 |
| $d$ | 潜在空间维度 | 规模参数 |
| $X_1, \dots, X_n$ | 独立均匀分布于球面 $S^{d-1}$ 的潜在点 | 潜在变量（不可观测） |
| $A = (A_{ij})$ | 邻接矩阵，$A_{ij} \in \{0,1\}$ | **可观测数据** |
| $K: [-1,1] \to [c, 1-c]$ | 核函数（连接概率），$0<c<1/2$ 固定 | 模型参数（已知） |
| $p_d = \mathbb{E}[K(\langle X_1, X_2\rangle)]$ | 边际边概率 | 导出量 |
| $s_d = \sqrt{p_d(1-p_d)}$ | 边概率标准差 | 导出量 |
| $\kappa_d(t) = (K(t) - p_d)/s_d$ | 中心化核 | 导出量 |
| $T_{\kappa_d}$ | 以 $\kappa_d(\langle x,y\rangle)$ 为核的积分算子 | 谱对象 |
| $\tau_{\ell,d} = \operatorname{Tr}(T_{\kappa_d}^\ell)$ | 第 $\ell$ 个迹（循环矩） | 谱对象 |
| $Y_{ij} = (A_{ij} - p_d)/s_d$ | 标准化边指示 | 导出量 |
| $S_3 = \sum_{i<j<k} Y_{ij}Y_{jk}Y_{ki}$ | 符号三角形计数 | 检验统计量 |
| $S_4 = \sum_{i<j<k<\ell} (Y_{ij}Y_{jk}Y_{k\ell}Y_{\ell i} + \dots)$ | 符号四边形计数 | 检验统计量 |
| $\Lambda_{n,d} = n^3 \tau_{3,d}^2 + n^4 \tau_{4,d}^2$ | 总信号强度 | 关键量 |
| $P = P_{n,d}(K)$ | RGG 的图分布 | 备择假设 |
| $Q = Q_{n,d}$ | $G(n, p_d)$ 的图分布 | 原假设 |

**模型**（数据生成机制）：

1. **原假设 $Q$**：$A_{ij} \sim \text{Bernoulli}(p_d)$ 独立同分布。
2. **备择假设 $P$**：
   - 先采样潜在点 $X_1, \dots, X_n \overset{\text{i.i.d.}}{\sim} \sigma_d$（$S^{d-1}$ 上的均匀分布）。
   - 给定 $X$，边 $A_{ij}$ 条件独立，且 $P(A_{ij}=1 \mid X) = K(\langle X_i, X_j\rangle)$。
   - 因此，$P$ 下的边分布是**可交换的**（exchangeable），但**不独立**——这是与 $Q$ 的本质区别。

**可观测数据**：只有邻接矩阵 $A$。潜在点 $X$ 完全不可观测。

**目标**：判断观测到的图来自 $P$ 还是 $Q$。由于 $P$ 和 $Q$ 的边分布相同（都是 $p_d$），任何检验都必须利用**边之间的相关性**。

#### 第二步：最小内核——为什么三角形能检测几何？

**核心问题**：在 $P$ 下，边之间存在什么 $Q$ 下没有的相关性？这种相关性如何随 $d$ 衰减？

**最简设定**：$n=3$，即只考虑三个顶点 $1,2,3$。在 $Q$ 下，三条边 $A_{12}, A_{23}, A_{31}$ 独立，因此
\[
\mathbb{E}_Q[Y_{12}Y_{23}Y_{31}] = \mathbb{E}_Q[Y_{12}]\mathbb{E}_Q[Y_{23}]\mathbb{E}_Q[Y_{31}] = 0.
\]
在 $P$ 下，给定潜在点 $X_1, X_2, X_3$，边条件独立，因此
\[
\mathbb{E}_P[Y_{12}Y_{23}Y_{31} \mid X] = \kappa_d(\langle X_1, X_2\rangle) \kappa_d(\langle X_2, X_3\rangle) \kappa_d(\langle X_3, X_1\rangle).
\]
对 $X$ 取期望，得到
\[
\mathbb{E}_P[Y_{12}Y_{23}Y_{31}] = \mathbb{E}[\kappa_d(\langle X_1, X_2\rangle) \kappa_d(\langle X_2, X_3\rangle) \kappa_d(\langle X_3, X_1\rangle)] = \tau_{3,d}.
\]
这里 $\tau_{3,d} = \operatorname{Tr}(T_{\kappa_d}^3)$ 是积分算子 $T_{\kappa_d}$ 的三次迹。**这就是信号**：在 $P$ 下，三角形三条边的标准化乘积的期望不为零，而在 $Q$ 下为零。

**为什么 $\tau_{3,d}$ 会随 $d$ 衰减？** 因为当 $d$ 很大时，$\langle X_i, X_j\rangle$ 以高概率集中在 0 附近（测度集中现象），而 $\kappa_d$ 是中心化的（$\mathbb{E}[\kappa_d(\langle X_1, X_2\rangle)] = 0$），所以 $\kappa_d(\langle X_i, X_j\rangle)$ 的典型值很小。$\tau_{3,d}$ 的衰减速度取决于 $\kappa_d$ 在 0 点的局部行为：
- 若 $K$ 在 0 点可导且 $K'(0) \neq 0$，则 $\kappa_d(t) \approx \text{const} \cdot \sqrt{d}\, t$（因为 $P_{1,d}(t) = \sqrt{d}\, t$ 是 $L^2$ 归一化的），于是 $\tau_{3,d} \asymp d^{-3/2}$。
- 若 $K$ 在 0 点不可导，如 $K(t) - K(0) \asymp |t|^\alpha$，则 $\kappa_d$ 在 $L^2$ 意义下主要投影到低阶球面调和，$\tau_{3,d}$ 的衰减会不同。

**检验统计量**：符号三角形计数
\[
S_3 = \sum_{1 \le i < j < k \le n} Y_{ij}Y_{jk}Y_{ki}.
\]
在 $Q$ 下，$\mathbb{E}_Q[S_3] = 0$，$\mathrm{Var}_Q(S_3) = \binom{n}{3}$（因为 $Y_{ij}$ 独立且方差为 1）。在 $P$ 下，
\[
\mathbb{E}_P[S_3] = \binom{n}{3} \tau_{3,d} \approx \frac{n^3}{6} \tau_{3,d}.
\]
因此，信号-噪声比为
\[
\frac{\mathbb{E}_P[S_3]}{\sqrt{\mathrm{Var}_Q(S_3)}} \approx \frac{n^3 \tau_{3,d}}{6 \cdot n^{3/2}} = \frac{n^{3/2} \tau_{3,d}}{6}.
\]
当 $n^{3/2} |\tau_{3,d}| \to \infty$ 时，三角形检验成功。对于 $K'(0) \neq 0$，$\tau_{3,d} \asymp d^{-3/2}$，所以条件变为 $d \ll n$。但 [MWX26] 证明的临界维度是 $d_\star \asymp n^{3/4}$，这比 $n$ 小得多。**为什么？** 因为 $\tau_{3,d}$ 的估计过于粗糙——实际上，对于光滑核，$\tau_{3,d}$ 的**符号**可能为正也可能为负，且其绝对值可能远小于 $d^{-3/2}$（因为高阶球面调和项的贡献会部分抵消）。更精细的分析（本文的定理 1.2 和 1.4）表明，$\tau_{3,d}$ 的精确阶数取决于核的 Taylor 展开的**首个非零项**，而不仅仅是线性项。

**最小内核的完整表述**：

> **命题（最小内核）**：考虑 $n=3$ 的特殊情形。RGG 与 $G(n,p)$ 的可区分性完全由三阶矩 $\tau_{3,d} = \mathbb{E}[\kappa_d(\langle X_1, X_2\rangle)\kappa_d(\langle X_2, X_3\rangle)\kappa_d(\langle X_3, X_1\rangle)]$ 决定。若 $\tau_{3,d} = 0$（例如核为偶函数且 $K'(0)=0$），则三角形检验失效，需要转向四阶矩 $\tau_{4,d}$（四边形检验）。一般地，第 $\ell$ 阶矩 $\tau_{\ell,d}$ 对应长度为 $\ell$ 的循环子图计数，而**最优检验的阶数**由核的局部 Taylor 展开中首个非零项的阶数决定。

这个最小内核揭示了整篇论文的逻辑：**核的局部光滑性 $\leftrightarrow$ 谱分解中非零特征值的分布 $\leftrightarrow$ 循环矩 $\tau_{\ell,d}$ 的衰减速率 $\leftrightarrow$ 临界维度 $d_\star$**。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：对于固定核函数 $K$ 的随机几何图与同边密度 Erdős–Rényi 图的假设检验问题，确定临界维度 $d_\star(n, K)$，使得当 $d \ll d_\star$ 时可检测、$d \gg d_\star$ 时不可检测。
2. **核心方法**：引入"尖点类"核（允许在 0 点不可导），利用球面调和分析和后验展开，证明符号三角形计数和符号四边形计数分别达到最优检测阈值；对于 $K'(0)=0$ 的光滑核，证明三角形计数仍然最优，但阈值指数由首个非零导数的阶数决定。
3. **主要结论**：给出了统一的阈值公式 $d_\star = n^{3/(3m+q_m)}$（$m$ 为首个非零 Taylor 项的阶数，$q_m$ 由奇偶性决定），填补了硬阈值核（$d_\star \asymp n^3$）与一阶光滑核（$d_\star \asymp n^{3/4}$）之间的空白，并**反驳了 [MWX26] 关于三角形计数普遍最优的猜想**。

#### 关键设定与假设

- **核函数类**：$K: [-1,1] \to [c, 1-c]$，$0<c<1/2$ 固定。分为三类：
  1. **尖点类**（Cusp）：$K(t) = p_0 + a_e |t|^\alpha + a_o \operatorname{sgn}(t)|t|^\beta + o(|t|^\alpha + |t|^\beta)$，其中 $0 < \alpha, \beta \le 1$，$a_e, a_o \neq 0$（若对应项存在）。
  2. **光滑类**（Smooth）：$K \in C^{m+6}([-1,1])$，$K'(0) = \cdots = K^{(m-1)}(0) = 0$，$K^{(m)}(0) \neq 0$，$m \ge 2$。
  3. **跳跃类**（Jump）：$K(0+) - K(0-) \neq 0$（即 $K$ 在 0 点不连续）。
- **渐近框架**：$n, d \to \infty$，$d$ 与 $n$ 的关系由阈值公式决定。核固定，不随 $n, d$ 变化。
- **可观测性**：只有邻接矩阵 $A$，潜在点 $X$ 不可观测。
- **检验准则**：总变差距离 $TV(P_{n,d}, Q_{n,d}) \to 1$ 表示可检测，$\to 0$ 表示不可检测。

#### 主要结果

**定理 1.2（尖点类）**：设 $K$ 属于尖点类，定义
\[
\Lambda_{n,d} = n^3 \tau_{3,d}^2 + n^4 \tau_{4,d}^2.
\]
则：
- 若 $\Lambda_{n,d} \to \infty$，则 $TV(P_{n,d}, Q_{n,d}) \to 1$（可检测）。
- 若 $\Lambda_{n,d} \to 0$，则 $TV(P_{n,d}, Q_{n,d}) \to 0$（不可检测）。

**推论（阈值公式）**：
- 纯偶尖点（$K(t) = p_0 + a_e |t|^\alpha$，$a_e \neq 0$）：$\tau_{3,d} \asymp d^{-\alpha/2-1}$，$\tau_{4,d} \asymp d^{-\alpha-2}$，故 $d_\star = n^{3/(3\alpha+2)}$。
- 纯奇尖点（$K(t) = p_0 + a_o \operatorname{sgn}(t)|t|^\beta$，$a_o \neq 0$）：$\tau_{3,d} \asymp d^{-\beta/2-1/2}$，$\tau_{4,d} \asymp d^{-\beta-1}$，故 $d_\star = n^{3/(3\beta+1)}$。
- 跳跃核：$\tau_{3,d} \asymp d^{-1}$，$\tau_{4,d} \asymp d^{-1}$，故 $d_\star = n^3$（与硬阈值核一致）。

**定理 1.4（光滑类）**：设 $K \in C^{m+6}$，$K'(0) = \cdots = K^{(m-1)}(0) = 0$，$K^{(m)}(0) \neq 0$。则 $d_\star = n^{3/(3m+q_m)}$，其中 $q_m = 1$（$m$ 奇）或 $q_m = 2$（$m$ 偶）。该阈值由符号三角形计数达到。

**关键推论（反驳猜想）**：对于混合尖点（$K(t) = p_0 + a_e |t|^\alpha + a_o \operatorname{sgn}(t)|t|^\beta$），当 $\beta = \alpha + 1/3$ 且 $a_o^3 M_{\beta+1}^3 + (a_e \alpha M_\alpha)^3/2 = 0$ 时，$\tau_{3,d}$ 的首项抵消，三角形信号消失。此时四边形计数达到最优阈值 $d_\star = n^{6/(6\alpha+5)}$，而三角形计数只能达到 $d_\star = n^{3/(3\alpha+2)}$，两者不同。这直接反驳了 [MWX26, Conjecture 1]。

#### 证明路线

**检测方向（可检测性）**：
1. 构造符号三角形计数 $S_3$ 和符号四边形计数 $S_4$。
2. 计算 $S_\ell$ 在 $P$ 下的均值 $\mathbb{E}_P[S_\ell] = \binom{n}{\ell} \tau_{\ell,d}$（$\ell = 3, 4$）。
3. 计算 $S_\ell$ 在 $P$ 和 $Q$ 下的方差，通过分类重叠子图（共享 0、1、2 条边等）并利用球面调和分析控制高阶项。
4. 使用 Chebyshev 不等式证明当 $\Lambda_{n,d} \to \infty$ 时，检验误差趋于 0。

**不可检测方向（不可检测性）**：
1. **后验展开**：将 KL 散度 $KL(P\|Q)$ 展开为
   \[
   KL(P\|Q) = \sum_{k=2}^{n} G_k, \quad G_k = \binom{n}{k+1} \bar{g}_k,
   \]
   其中 $\bar{g}_k$ 是"后验相互作用"项，衡量 $k$ 个潜在点对图分布的联合影响。
2. **谱分析**：利用球面调和分解，将 $\bar{g}_k$ 表示为积分算子 $T_{\kappa_d}$ 的迹的组合。关键工具是 Funk–Hecke 公式，它将球面上的卷积算子对角化为球面调和基。
3. **关键估计**：
   - 对 $k = 2$：$\bar{g}_2 \asymp \tau_{4,d}$（四边形信号）。
   - 对 $k = 3$：$\bar{g}_3 \asymp \tau_{3,d}^2$（三角形信号的平方）。
   - 对 $k \ge 4$：利用超压缩性（hypercontractivity）和 Hölder 不等式，证明高阶项在 $\Lambda_{n,d} \to 0$ 时趋于 0。
4. **结论**：当 $\Lambda_{n,d} \to 0$ 时，$KL(P\|Q) \to 0$，由 Pinsker 不等式得 $TV(P,Q) \to 0$。

**技术技巧清单**：
- **球面调和展开**：将核函数 $K(\langle x,y\rangle)$ 展开为球面调和基，将卷积算子对角化。
- **Funk–Hecke 公式**：计算球面卷积算子的特征值。
- **后验展开（cavity method）**：将 KL 散度分解为不同阶的相互作用项，类似于统计物理中的空腔方法。
- **超压缩性（hypercontractivity）**：用于控制高阶矩，特别是 $\|h_k\|_4$ 相对于 $\|h_k\|_2$ 的增长。
- **矩阵 Bernstein 不等式**：用于控制 Gram 矩阵的谱范数。
- **截断与局部化**：将核在 0 点附近的行为与远离 0 的行为分离，利用测度集中现象。

#### 真实例子与应用

- **例子 1（混合尖点）**：$K(t) = 1/2 + a_e |t|^\alpha + a_o \operatorname{sgn}(t)|t|^{\alpha+1/3}$，其中 $a_e, a_o$ 满足 $a_o^3 M_{\alpha+4/3}^3 + (a_e \alpha M_\alpha)^3/2 = 0$。此时三角形信号消失，四边形计数成为最优检验。这个例子是反驳 [MWX26] 猜想的关键。
- **例子 2（跳跃核）**：$K(t) = 1/2 + (1/4)\operatorname{sgn}(t)$。此时 $d_\star = n^3$，与硬阈值核相同。这表明跳跃不连续性与硬阈值在检测难度上等价。
- **例子 3（光滑核）**：$K(t) = 1/2 + t^2$（$m=2$，偶函数）。此时 $d_\star = n^{3/8}$，比 $K'(0) \neq 0$ 的情形（$d_\star = n^{3/4}$）小得多，说明核越"平坦"，几何信号越弱，检测越难。

### 四、开放问题

1. **稀疏图情形**：本文只处理了稠密图（$p$ 固定）。当 $p \to 0$ 时，阈值公式如何变化？[LMSY24] 和 [DMS+26a] 处理了硬阈值核的稀疏情形，但一般核的稀疏情形完全开放。要证明什么：稀疏 RGG 与稀疏 $G(n,p)$ 的检测阈值是否仍由核的局部 Hölder 指数决定？还是会出现新的现象（如渗流阈值）？

2. **核函数随维度变化**：如果 $K = K_d$ 依赖于 $d$（例如，连接概率随维度缩放），阈值公式如何推广？[Luo26] 构造了 $d$ 依赖核的例子，但一般理论缺失。要证明什么：是否存在一个"局部极限"定理，使得 $d_\star$ 仅由 $K_d$ 在 0 点的"极限 Taylor 展开"决定？

3. **计算复杂性与统计最优性之间的间隙**：本文证明子图计数（多项式时间）达到最优阈值。但这是否意味着**所有**多项式时间检验都无法超越这个阈值？是否存在一个"计算-统计间隙"（即信息论上可检测但计算上不可检测的区域）？要证明什么：对于某些核，是否存在比子图计数更复杂的多项式时间算法能突破 $d_\star$？或者能否证明子图计数在某种计算模型（如低次多项式）下是最优的？

4. **更一般的几何**：本文只考虑了球面 $S^{d-1}$ 上的均匀分布。如果潜在点来自其他分布（如高斯分布、双峰分布）或其他度量空间（如环面、双曲空间），阈值公式如何变化？[BB24a] 在环面 $L^\infty$ 度量下发现了不同的最优统计量，说明几何类型至关重要。要证明什么：是否存在一个"几何类型"的分类，使得每一类都有对应的最优统计量和阈值公式？

5. **高阶矩的完备性**：本文证明了三角形和四边形计数在尖点类和光滑类中达到最优。但对于更一般的核（如 $K(t) = p_0 + a |t|^\alpha$ 且 $\alpha$ 为无理数），是否可能需要更高阶的循环计数（五边形、六边形等）？要证明什么：是否存在一个核，其最优检测需要长度 $\ell \ge 5$ 的循环计数？如果是，$\ell$ 与核的 Hölder 指数有何关系？

6. **自适应检验**：在实际应用中，核函数 $K$ 通常是未知的。是否存在一个**自适应检验**，不需要知道 $K$ 的具体形式，就能在 $d \ll d_\star$ 时检测到几何结构？要证明什么：能否构造一个统计量，它对所有核都达到最优（或接近最优）的检测阈值？
