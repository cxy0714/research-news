### 一、领域脉络与小综述

#### 这个方向是什么

本文所处的子方向是**含 nuisance 参数的似然模型中的估计与推断问题**，其核心关切是：当模型中存在大量（甚至随样本量增长的）nuisance 参数时，如何构造对 nuisance 参数估计误差不敏感的估计方程，从而获得对目标参数 θ 具有良好性质的估计量。这个问题在计量经济学中被称为 **incidental parameter problem**（Neyman & Scott, 1948），在面板数据、网络数据、高维回归等场景中尤为突出。该方向的成熟度较高——从 Neyman (1959) 的经典工作算起已有六十余年历史，但近年来随着 DML（double/debiased machine learning）文献的兴起（Chernozhukov et al., 2018）以及面板/网络数据模型的复兴，该方向重新成为活跃的研究前沿。

#### 发展脉络

- **奠基工作**：Neyman (1959) 提出了正交性（orthogonality）的概念，即构造对 nuisance 参数一阶不敏感的矩条件。这是整个方向的起点。Neyman & Scott (1948) 则最早揭示了 incidental parameter problem 的本质——当 nuisance 参数维度随样本量增长时，极大似然估计可能不一致。
- **主要进展**：
  - **条件似然方法**：Andersen (1970)、Chamberlain (1980) 在面板 Logit 模型中通过条件似然（conditional likelihood）消除固定效应，这是"完全正交"的特例。
  - **Functional differencing**：Bonhomme (2012) 提出了一种系统性的方法，通过投影构造对固定效应不敏感的矩条件，适用于更一般的模型。
  - **DML 框架**：Chernozhukov et al. (2018) 将 Neyman 正交性与机器学习方法结合，建立了 DML 的理论框架，使得 nuisance 参数可以用灵活的非参数方法估计而不影响目标参数的推断。
  - **高阶正交性**：Mackey, Syrgkanis, and Zadik (2018) 提出了 q 阶 Neyman 正交性的概念，将正交性从一阶推广到任意有限阶。
  - **面板/网络数据的偏差校正**：Hahn & Newey (2004)、Dhaene & Jochmans (2015a,b) 等发展了针对固定效应模型的偏差校正方法。
- **当前 frontier**：本文作者 Bonhomme, Jochmans, Weidner (2024) 的前作已经建立了高阶正交性与 Bhattacharyya 基的联系。本文在此基础上，将三种正交性概念（Neyman、q 阶、完全）统一在一个投影框架下，并给出了显式构造。此外，Chetverikov, Sørensen, Tsyvinski (2026) 和 Bonhomme, Jochmans, Newey, Weidner (2026) 正在将高阶正交性推广到无似然结构的矩条件模型。
- **本文的位置**：本文是一篇综述性/统一性论文（为 Journal of Applied Econometrics 讲座撰写），其贡献在于：(i) 将三种正交性概念统一为嵌套投影序列；(ii) 给出一般似然模型中的显式构造；(iii) 通过三个例子（Logit、Poisson、非线性回归）展示不同正交性概念的适用条件和效果。

#### 子线索聚类

1. **正交矩的构造方法**：Neyman (1959) 的投影方法 → Bonhomme (2012) 的 functional differencing → 本文的嵌套投影框架。这条线索关注"如何构造"正交矩。
2. **偏差校正与高阶渐近**：Hahn & Newey (2004)、Dhaene & Jochmans (2015a,b) 关注如何修正 incidental parameter 偏差；Mackey et al. (2018) 和本文关注如何通过高阶正交性从根源上消除偏差。
3. **DML 与半参数效率**：Chernozhukov et al. (2018) 将正交性与交叉拟合结合，关注 nuisance 参数以慢于 n^{-1/4} 的速率收敛时的推断问题；本文的 q 阶正交性可视为这一思路的高阶推广。
4. **面板/网络数据的特定模型**：Rasch (1961)、Andersen (1970)、Chamberlain (1980) 的条件似然方法；Chatterjee, Diaconis, Sly (2011)、Graham (2017)、Jochmans (2018) 的网络形成模型；Abowd, Kramarz, Margolis (1999) 的工资分解模型。

#### 这个方向在追问的核心问题

1. **正交性到什么程度才够？** 一阶正交（Neyman）在 nuisance 参数以 n^{-1/4} 速率收敛时足以消除一阶偏差；但当 nuisance 参数收敛更慢（如面板固定效应以 T^{-1/2} 收敛）时，需要更高阶的正交性。q 阶正交性需要 nuisance 参数以 n^{-1/[2(q+1)]} 速率收敛。完全正交则完全不需要对 nuisance 参数的估计。
2. **正交矩是否存在且可构造？** 完全正交的矩条件并非总是存在（如 Logit 模型中连续协变量的平均效应）。何时存在、如何构造、构造的代价（信息损失）是什么？
3. **正交性与效率的权衡**：投影掉越多 nuisance 方向，目标参数的信息损失可能越大。如何在正交性和效率之间取得平衡？
4. **超出似然框架**：Neyman 正交性在矩条件模型中已有成熟理论（DML），但高阶正交性和完全正交性在无似然结构时如何定义和构造？

#### ⚠️ 作者的 framing（这是作者的说法）

作者将本文定位为"统一三种正交性概念的综述性论文"，其核心论点是：**三种正交性概念（Neyman、q 阶、完全）可以通过投影到嵌套子空间这一统一框架来理解**。作者强调，这个框架不仅统一了已有方法，还揭示了新的构造（如 Logit 模型中的高阶正交矩），并指出了完全正交性的存在性条件。作者淡化了以下竞争路线：(i) 基于偏差校正的方法（如 Hahn-Newey 解析偏差校正），认为这些方法"事后修正"而非"事前消除"偏差；(ii) 贝叶斯方法或随机效应方法，这些方法通过建模 nuisance 参数的分布来避免 incidental parameter problem。值得注意的是，作者在引言中**没有引用**以下可能相关的工作：面板数据中的偏得分方法（Arellano & Bonhomme, 2009）、高维固定效应模型的正则化方法（如 Belloni et al., 2017）、以及半参数效率理论中关于 nuisance 参数切空间的标准结果（Bickel et al., 1993）。这些遗漏可能是作者有意为之（聚焦似然框架），也可能是值得读者去查证的 gap。

#### 张力

未见明显的对立引用。不过有一个微妙的张力值得注意：作者声称"完全正交性是最强的正交性概念"，但在 Logit 模型的例子中，完全正交矩不存在，而高阶正交矩存在。这说明三种正交性概念之间并非简单的"越强越好"的递进关系，而是存在适用条件的差异。另一个张力是：在 Poisson 模型中，Neyman 正交性自动达到完全正交性（因为似然具有乘法可分性），而在 Logit 模型中则不然。这种"模型结构决定正交性可达阶数"的现象是本文的一个重要洞见。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

**符号**：

- **θ ∈ Θ ⊆ ℝ^{d_θ}**：目标参数（低维），是研究者关心的 estimand。
- **η ∈ H ⊆ ℝ^{d_η}**：nuisance 参数（可能高维），不是直接关心的对象，但必须处理。
- **y ∈ 𝒴**：结果变量（可观测）。
- **x ∈ 𝒳**：协变量（可观测，可能包含内生变量和外生变量）。
- **f(y|x; θ, η)**：给定 x 时 y 的条件密度/似然，已知函数形式，依赖于 (θ, η)。
- **u(y, x, θ, η)**：矩函数（moment function），满足 E[u(y, x, θ₀, η₀)] = 0。
- **w_j(y, x, θ, η) = ∇^j_{η'} r_{η'}(y, x, θ, η)|_{η'=η}**：第 j 阶广义得分（generalized score），其中 r_{η'} = f(y|x; θ, η')/f(y|x; θ, η) 是似然比。
- **S_{x;θ,η}**：由似然比张成的闭线性子空间（L² 空间中的）。
- **Proj_{x;θ,η}[v|S]**：v 在 S 上的 L² 正交投影。
- **n**：样本量（在面板数据中 n = N·T，N 为个体数，T 为时期数）。
- **N, T**：面板数据的个体数和时期数。

**模型**：

- 数据生成机制：{(y_i, x_i)}_{i=1}^n 独立同分布（或面板数据中 {(y_{it}, x_{it})}_{t=1}^T 对每个 i 独立），y_i | x_i ~ f(·|x_i; θ₀, η₀)。
- 目标：基于观测数据估计 θ₀，并对 η₀ 的存在保持鲁棒。
- 估计方法：plug-in GMM——先用某种方法估计 η（记为 η̂），然后求解 ∑_i u(y_i, x_i, θ, η̂) = 0 得到 θ̂。

**可观测数据**：

- 观测到的是 (y_i, x_i) 的样本实现。
- **不可观测**的是：θ₀（要估计）、η₀（nuisance）、潜在结果（如果涉及因果推断）。
- 关键：η₀ 的估计误差 η̂ - η₀ 会通过矩函数 u 的 η 依赖性传导到 θ̂ 的偏差中。正交性的目的就是切断或减弱这种传导。

#### 第二步：最小内核

**最简特例**：考虑一个**单参数 nuisance 的标量矩条件**问题。

设 d_θ = d_η = 1，观测数据为 i.i.d. 样本 {y_i}_{i=1}^n，似然为 f(y; θ, η)。目标参数 θ₀ 通过矩条件识别：

E[u(y; θ₀, η₀)] = 0。

假设我们有一个 η 的估计量 η̂（例如 MLE），收敛速度为 n^{-κ}（κ > 0）。Plug-in 估计量 θ̂ 满足：

∑_i u(y_i; θ̂, η̂) = 0。

对 θ̂ 做泰勒展开（在 (θ₀, η₀) 处）：

0 = ∑_i u(y_i; θ₀, η₀) + (θ̂ - θ₀) ∑_i ∇_θ u(y_i; θ₀, η₀) + (η̂ - η₀) ∑_i ∇_η u(y_i; θ₀, η₀) + ...

取期望并除以 n，忽略高阶项：

0 ≈ E[∇_θ u] · (θ̂ - θ₀) + E[∇_η u] · (η̂ - η₀) + O_p(n^{-1/2})。

因此：

θ̂ - θ₀ ≈ - (E[∇_θ u])^{-1} E[∇_η u] · (η̂ - η₀) + O_p(n^{-1/2})。

**关键观察**：如果 E[∇_η u(y; θ₀, η₀)] ≠ 0，则 θ̂ 的偏差与 (η̂ - η₀) 同阶。若 η̂ 以 n^{-κ} 收敛（κ < 1/2），则 θ̂ 的偏差为 n^{-κ}，大于 n^{-1/2}，导致 θ̂ 的渐近分布不以 n^{-1/2} 为中心——这就是 incidental parameter bias。

**Neyman 正交性**要求 E[∇_η u(y; θ₀, η₀)] = 0，即矩函数对 nuisance 参数的一阶导数在真值处期望为零。此时偏差项消失，θ̂ 的渐近分布以 n^{-1/2} 速率收敛到 θ₀。

**q 阶正交性**进一步要求 E[∇^j_η u(y; θ₀, η₀)] = 0 对所有 j = 1, ..., q 成立。此时偏差为 O_p(||η̂ - η₀||^{q+1}) = O_p(n^{-κ(q+1)})。若 κ(q+1) > 1/2，则偏差可忽略。

**完全正交性**要求 E[u(y; θ₀, η)] = 0 对所有 η ∈ H 成立，即矩函数对 nuisance 参数完全免疫。

**构造方法**：在似然框架下，将原始矩函数 u 投影到广义得分张成的子空间的正交补上。具体地：

u* = u - Proj[u | span{w_1, ..., w_q}]。

这个投影保证了 u* 与 w_j 正交（在 L² 意义下），从而 E[∇^j_η u*] = 0。

**为什么这个最小内核重要**：它揭示了正交性的本质——不是消除 nuisance 参数的估计误差，而是使矩函数对 nuisance 参数的变化不敏感。投影操作是线性的，因此计算上可行；而投影空间的选择（Neyman、q 阶、完全）决定了正交性的强度和信息保留的多少。

### 三、这篇论文做了什么

#### 三句话

① **研究了什么问题**：在似然模型中，如何系统地构造对 nuisance 参数不敏感的矩函数（正交矩），以缓解 incidental parameter problem，并统一三种正交性概念（Neyman、q 阶、完全正交）。
② **核心工具/方法**：将矩函数投影到由广义得分（Bhattacharyya 基）张成的子空间的正交补上，得到一个嵌套的投影序列；通过三个例子（Logit、Poisson、非线性回归）展示构造方法和性质。
③ **主要结论**：三种正交性概念对应于嵌套的子空间序列；q 阶正交性在 nuisance 参数以 n^{-1/[2(q+1)]} 速率收敛时足以消除偏差；完全正交性等价于矩函数对 nuisance 参数全局不敏感，但并非总是存在；在 Logit 模型中，高阶正交矩可以通过投影到幂次得分上显式构造，且当 q 达到面板长度 T 时恢复条件 Logit 得分。

#### 关键设定与假设

- **似然框架**：假设 f(y|x; θ, η) 是已知的似然函数，θ 和 η 可分离（至少在局部）。
- **矩条件**：目标参数通过 E[u(y, x, θ₀, η₀)] = 0 识别，u 可以是得分函数或其他矩函数。
- **样本分割**：假设 η̂ 在独立样本上估计（或满足足够的独立性条件），以便利用条件期望的分解。
- **正则条件**：矩函数和似然函数满足一定的光滑性和矩条件（文中未详细列出，但隐含在泰勒展开和 L² 投影的论证中）。
- **L² 可积性**：似然比 r_{η'} 属于 L²(f(·|x; θ, η))，保证投影良定义。

**相比已有文献的放宽/强化**：
- 相比 Neyman (1959) 的一阶正交，本文的 q 阶正交允许更高的正交阶数，适用于 nuisance 参数收敛更慢的场景。
- 相比 Bonhomme (2012) 的 functional differencing，本文将其推广到一般似然模型，并明确了与 Bhattacharyya 基的联系。
- 相比 DML 文献（Chernozhukov et al., 2018），本文聚焦于似然结构，利用广义得分而非一般的 Neyman 正交条件，因此构造更具体。

#### 主要结果

**定理/命题层面**（文中以公式和论证形式给出，未编号为独立定理）：

1. **Neyman 正交性的等价刻画**（第 3 节）：在似然框架下，矩函数 u 是 Neyman 正交的当且仅当它与 nuisance 得分 w_1 在 L² 中正交。构造：u*₁ = u - Proj[u | span{w_1}]。

2. **q 阶正交性的等价刻画**（第 5 节）：矩函数 u 是 q 阶正交的当且仅当它与前 q 个 Bhattacharyya 基函数 w_1, ..., w_q 正交。构造：u*_q = u - Proj[u | span{w_1, ..., w_q}]。偏差阶数为 O_p(||η̂ - η₀||^{q+1})。

3. **完全正交性的刻画**（第 4 节）：矩函数 u 是完全正交的当且仅当它与所有似然比 r_{η'} (η' ∈ H) 正交，等价于 u 属于条件期望算子 E_{x;θ} 的零空间。构造：u*_∞ = u - Proj[u | S_{x;θ,η}]，其中 S_{x;θ,η} = span{r_{η'} : η' ∈ H}。

4. **嵌套关系**（第 5 节末尾）：span{w_1} ⊆ span{w_1, ..., w_q} ⊆ S_{x;θ,η}，因此 Neyman 正交 ⊇ q 阶正交 ⊇ 完全正交。投影序列 u*₁, u*₂, ..., u*_∞ 构成一个递减的信息含量序列。

5. **Logit 模型的显式构造**（第 5.3 节）：在面板 Logit 模型中，w_j 是得分 w_1 的 j 次幂的多项式（系数为累积量），因此 q 阶正交矩可以通过投影到 {s, s², ..., s^q} 上得到，其中 s = ∑_t y_t 是充分统计量。当 q = T 时，投影空间包含所有充分统计量的函数，u*_T 等于条件 Logit 得分。

6. **Poisson 模型的完全正交性**（第 3 节例 2）：在面板 Poisson 模型中，Neyman 正交性自动达到完全正交性，因为似然具有乘法可分性，条件期望算子的零空间恰好是 Neyman 正交矩函数的集合。

7. **非线性回归的 q 阶正交矩**（第 5.3 节例 3）：在 Gaussian 非线性回归中，Bhattacharyya 基由 Hermite 多项式给出，q 阶正交矩可以通过 Hermite 展开显式构造。

**模拟结果**（附录 C，文中提及但未在正文展示图表）：
- Logit 模型：q=2 的正交矩显著降低偏差，q=3 与条件 Logit 几乎无差异。
- Poisson 模型：Neyman 正交矩已无偏差。
- 非线性回归：q=2 的正交矩在 nuisance 参数收敛较慢时优于 q=1。

#### 证明路线与技术技巧

**整体路线**（以 q 阶正交性的构造为例）：

1. **从正交性条件到投影**：将 q 阶正交性条件（E[∇^j_η u*] = 0, j=1,...,q）转化为 u* 与 w_j 的 L² 正交性条件（利用似然比导数与广义得分的关系）。
2. **投影构造**：定义投影算子 Proj_{x;θ,η}[·|span{w_1,...,w_q}]，证明 u*_q = u - Proj[...] 满足正交性条件。
3. **偏差阶数分析**：对 plug-in 估计量做高阶泰勒展开，利用正交性条件消去前 q 阶偏差项，得到偏差阶数为 O_p(||η̂ - η₀||^{q+1})。
4. **例子验证**：在 Logit、Poisson、非线性回归中验证构造的显式形式。

**关键跳跃点**：

- **从导数条件到 L² 正交**（第 5.2 节）：这是最核心的步骤。作者利用恒等式 E[∇^j_η u] = (-1)^j E[u w_j]（通过分部积分/似然比导数），将矩函数的导数条件转化为与广义得分的正交性条件。这个恒等式在指数族中尤其简洁。
- **Bhattacharyya 基的完备性**（第 5.2 节）：作者论证 w_j 张成的空间在适当的条件下是完备的（即包含所有零均值函数），从而完全正交性等价于投影到整个 L² 空间。
- **Logit 模型的有限维截断**（第 5.3 节）：在 Logit 模型中，由于充分统计量 s 的支撑有限（{0,...,T}），投影空间在 q=T 时达到饱和，此时 u*_T 等于条件 Logit 得分。这个观察将高阶正交性与条件似然方法联系起来。

**技术技巧点名**：

- **L² 投影**：核心工具，用于构造正交矩。投影的几何直观（图 1）帮助理解三种正交性的嵌套关系。
- **Bhattacharyya 基**：广义得分的集合，是投影空间的一组基。在指数族中，它们与充分统计量的幂次相关。
- **泰勒展开与偏差分析**：用于量化正交性对偏差的削减效果。
- **Hermite 多项式**：在 Gaussian 非线性回归中，Bhattacharyya 基由 Hermite 多项式给出，利用其正交性简化投影计算。
- **Fàa di Bruno 公式**：用于计算复合函数的导数，在推导 w_j 的显式形式时使用。

  - 第 7 节："Choosing the order q in practice remains an open question."——q 的选择是开放问题。
  - 第 4 节关于完全正交矩的存在性条件，作者给出了 Logit 例子中不存在的证明，但一般条件下的存在性刻画并未完全给出。

- **证明严格但结论表述较窄的地方**：
  - 第 5.3 节中关于 Logit 模型 q 阶正交矩的构造，作者证明了 q=T 时达到条件 Logit 得分，但**没有证明** q<T 时的高阶正交矩是否具有某种最优性（如最小方差）。
  - 第 6 节关于其他目标参数（如平均效应）的正交矩构造，作者给出了 Neyman 和 q 阶的显式形式，但**没有证明**这些构造在效率意义上是最优的。
  - 模拟结果仅报告了偏差的减少，**没有报告**方差的变化或置信区间的覆盖概率。

### 四、开放问题

1. **q 阶正交矩的最优性**（扎根于第 5.3 节）：在 Logit 模型中，q=2 的正交矩与条件 Logit 得分在模拟中表现相似，但作者未证明 q 阶正交矩在某种效率准则下的最优性。是否可以证明 q 阶正交矩在给定正交性约束下的半参数效率界？

2. **完全正交矩的存在性刻画**（扎根于第 4 节和第 6.5 节）：作者证明了 Logit 模型中连续协变量的平均效应不存在完全正交矩，但一般条件下完全正交矩存在性的充要条件是什么？这与模型的识别结构有何关系？

3. **q 的选择**（扎根于第 7 节）：作者明确指出"Choosing the order q in practice remains an open question"。是否存在数据驱动的方法来选择 q？q 的选择与 nuisance 参数的收敛速率、样本量、模型复杂度之间有何权衡？

4. **超出似然框架的高阶正交性**（扎根于第 7 节和引言）：作者提到 Chetverikov et al. (2026) 和 Bonhomme et al. (2026) 正在将高阶正交性推广到矩条件模型。在无似然结构时，Bhattacharyya 基的类比是什么？如何定义和构造高阶正交矩？

5. **非线性模型中的完全正交矩**（扎根于第 6.5 节）：在模型 (6.18) 中，二次型 µ₀ 的完全正交矩是否存在？作者将此留作未来工作。这涉及到弯曲指数族中充分统计量的结构。

6. **有限样本性质**（扎根于附录 C 的模拟设计）：模拟仅报告了偏差，未报告方差、置信区间覆盖或检验的 size/power。高阶正交矩在有限样本下的方差膨胀是否可控？是否存在偏差-方差权衡？
