### 一、领域脉络与小综述

#### 这个方向是什么

本文处理的根本问题是：**当总体是离散分布时，经典分位数估计量（样本分位数）失去了相合性和渐近正态性**。经典分位数定义为 Q(α) := inf{x : F(x) ≥ α}，当 F 是阶梯函数时，Q(α) 作为 α 的函数是分段常数且不连续的，这导致样本分位数（基于经验 CDF 的逆）的极限行为退化——它不再收敛到唯一的总体分位数，而是收敛到一个离散分布（即"不相合"），且没有通常的 √n 渐近正态性。这个问题在计数数据（count data）广泛存在的经济学、流行病学、保险精算等领域尤为突出。该子方向的成熟度属于"经典问题的新解法"——问题本身（离散数据分位数推断失效）早已被认识，但本文声称提供了一个同时具备理论性质（相合性、渐近正态性）和推断有效性（可构造有保证覆盖率的区间）的新方案。

#### 发展脉络（history）

作者在引言中梳理的脉络大致如下：

1. **奠基工作：经典分位数理论**。Serfling (1980) 的教科书给出了经典分位数函数 Q(α) = inf{x : F(x) ≥ α} 的定义及其在绝对连续总体下的渐近理论（相合性、渐近正态性）。这是整个领域的基准——所有后续工作都在试图解决或绕开经典定义在离散情形下的失效。

2. **问题暴露：离散情形下经典分位数的失效**。Genton et al. (2006) 通过蒙特卡洛模拟展示了离散总体下样本中位数不服从渐近正态分布；Jentsch and Leucht (2016) 给出了一个抛硬币（Bernoulli）例子，严格证明了样本中位数**不相合**——其极限分布是一个等权重的两点离散分布，而非退化到总体中位数。这是对问题严重性的最清晰刻画：不是收敛速度慢，而是根本不收敛。

3. **主要进展：平滑化/连续化修正路线**。这一路线的代表是 Ma et al. (2011) 提出的**中位数分位数（mid-quantile）**，其构造思路是对离散 CDF 做连续化修正（mid-cumulative distribution function, mid-CDF），然后取逆得到分位数。mid-quantile 在离散和绝对连续总体下都恢复了相合性和渐近正态性。这是与本文最直接竞争的方案。此外还有两条辅助路线：(a) Chen and Lazar (2010) 通过 jittering（加噪声）技术结合经验似然来估计离散总体的分位数，但作者指出其限制是要求支撑集为连续整数；(b) Chernozhukov et al. (2020) 通过反演 CDF 的置信带构造分位数的置信区间，允许离散总体，但走的是推断路线而非重新定义分位数。

4. **当前 frontier**：作者认为，尽管 mid-quantile 恢复了渐近性质，但它存在一个关键缺陷——**与原始总体的"错配"（mismatch）问题**。作者用 Proposition 1 和 2 严格刻画了这一缺陷：mid-CDF 与原始 CDF 的相对大小关系不确定（Proposition 1），因此基于 mid-quantile 构造的预测区间**不能保证**覆盖概率（Proposition 2 给出了覆盖概率可能低于名义水平的明确条件）。本文的位置是：提出两个新的分位数定义（上分位数 upper-quantile 和下分位数 lower-quantile），它们**同时**满足：(i) 在离散和绝对连续总体下都有相合性和渐近正态性；(ii) 能构造**有保证覆盖概率**的预测区间（Proposition 3）。作者声称这是此前所有方案（包括 mid-quantile）都未能同时达到的。

#### 子线索聚类

被引文献大致落在三条子线索上：

- **线索 A：分位数的重新定义（平滑化路线）**。Ma et al. (2011) 的 mid-quantile、Wang and Hutson (2011) 的分数阶次序统计量（fractional order statistic）平滑分位数。这条线索的核心思路是：既然经典分位数在离散情形下"太粗糙"，就构造一个平滑版本。本文的 upper-/lower-quantile 也属于这条线索，但作者强调其与 mid-quantile 的关键区别在于**与原始总体的关系是可控的**（一个从上方逼近，一个从下方逼近，而不是像 mid-quantile 那样方向不定）。

- **线索 B：推断方法（绕过重新定义）**。Chernozhukov et al. (2020) 的 CDF 置信带反演法、Chen and Lazar (2010) 的 jittering + 经验似然法。这条线索不重新定义分位数，而是直接针对经典分位数构造有效的推断程序。作者承认这些方法的价值，但指出它们要么计算复杂（CDF 置信带反演），要么有支撑集限制（jittering 要求连续整数支撑）。

- **线索 C：离散数据的回归与建模**。Geraci and Farcomeni (2022) 将 mid-quantile 推广到离散响应回归。这条线索是应用驱动——计数数据回归中的条件分位数估计。作者在结论部分将其列为 future work 的方向之一。

#### 这个方向在追问的核心问题

1. **如何定义离散总体的分位数，使其既保留经典分位数的解释性（与原始总体的联系），又恢复良好的渐近性质？** 这是定义层面的问题。mid-quantile 的教训是：平滑化可以恢复渐近性质，但可能牺牲与原始总体的精确联系。
2. **如何基于新的分位数定义构造有保证覆盖率的推断（预测区间、置信区间）？** 这是推断层面的问题。作者用 Proposition 2 证明 mid-quantile 在这一条上失败，用 Proposition 3 证明自己的方案成功。
3. **新定义在绝对连续总体下是否退化为经典分位数？** 这是兼容性问题。作者声称 upper-/lower-quantile 是经典分位数的推广（在绝对连续情形下两者重合），但这一点的详细论证在正文中着墨不多，值得读者去 Supplementary Material 中核实。

#### ⚠️ 作者的 framing（这是作者的说法）

作者把缺口 frame 成："现有替代方案（mid-quantile）虽然恢复了渐近性质，但**不能保证**基于其构造的预测区间有名义覆盖概率；我们提出的 upper-/lower-quantile 同时解决了渐近性质和推断有效性问题。" 这个 framing 的关键在于 Proposition 2——它精确刻画了 mid-quantile 失效的条件。**值得研究者去查的问题**：

- 作者在引言中**没有引用**任何关于**离散数据分位数回归**的近期工作（除了 Geraci and Farcomeni 2022 一句话带过）。这个领域在计量经济学中有大量文献（如 count data quantile regression），作者完全回避了。这是否意味着 upper-/lower-quantile 向回归的推广存在本质困难？
- 作者**没有讨论** upper-/lower-quantile 与**经典分位数回归估计量**（如 Koenker-Bassett）在离散响应下的关系。经典分位数回归在离散响应下同样面临不连续问题，但计量经济学文献已有多种处理方案（如 jittering、平滑）。作者对这些方案的回避是否合理？
- 作者声称 upper-/lower-quantile 是"显然的下一步"，但**没有引用**任何关于**分位数函数的非光滑性对推断的影响**的近期理论工作（如关于分位数回归的弱收敛、bootstrap 有效性的文献）。这是一个明显的文献缺口。

#### 张力

未见明显对立引用。但有一个值得注意的**隐含张力**：Ma et al. (2011) 的 mid-quantile 和本文的 upper-/lower-quantile 都声称解决了离散分位数的渐近问题，但**两者对"正确"的分位数定义给出了不同的答案**。作者用 Proposition 2 论证 mid-quantile 在推断上失败，但 mid-quantile 的支持者可能会反驳说：预测区间覆盖概率不是唯一标准，mid-quantile 在某些准则（如中位无偏性）下可能更优。这个张力在本文中没有被正面处理。


### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

- **X**：感兴趣的随机变量，服从分布 F。本文的核心设定是 **X 为离散型**，支撑集为 {x₁ < x₂ < ... < x_L}，概率质量 p_l = Pr(X = x_l)，l = 1, ..., L。L 可以是有限或无限（但本文主要讨论有限情形）。
- **F(x)**：X 的累积分布函数（CDF），阶梯函数，在 x_l 处有跳跃 p_l。
- **F(x−)**：F 在 x 处的左极限，即 Pr(X < x)。
- **Q(α) := inf{x : F(x) ≥ α}**：经典分位数函数，α ∈ (0,1)。这是**目标量（estimand）**，但本文认为它在离散情形下"行为不良"。
- **F_M(x)**：mid-CDF（Ma et al. 2011 的定义），通过连接点 (x_l, F(x_l) − 0.5·p_l) 的线性插值构造的连续函数。
- **Q_M(α) := inf{x : F_M(x) ≥ α}**：mid-quantile 函数。
- **F_U(x)**：**upper-CDF**（本文新定义），通过连接点 (x_l, F(x_l)) 的线性插值构造的连续函数。注意：F_U 在 x_l 处取值 F(x_l)（即右连续版本的 CDF 值），在 x_l 与 x_{l+1} 之间线性连接。
- **F_L(x)**：**lower-CDF**（本文新定义），通过连接点 (x_l, F(x_l−)) 的线性插值构造的连续函数。注意：F_L 在 x_l 处取值 F(x_l−)（即左极限）。
- **Q_U(α) := inf{x : F_U(x) ≥ α}**：**upper-quantile**（本文核心新定义）。
- **Q_L(α) := inf{x : F_L(x) ≥ α}**：**lower-quantile**（本文核心新定义）。
- **X₁, ..., X_n**：i.i.d. 样本，来自 F。这是**可观测数据**。
- **F̂_n(x)**：经验 CDF，F̂_n(x) = (1/n) Σᵢ I(Xᵢ ≤ x)。
- **F̂_U,n(x), F̂_L,n(x)**：基于经验 CDF 的 upper-/lower-CDF 估计（用样本频率 p̂_l,n = r_l,n/n 替换 p_l）。
- **Q̂_U,n(α), Q̂_L,n(α)**：样本 upper-/lower-quantile，即 F̂_U,n 和 F̂_L,n 的广义逆。

**可观测 vs 不可观测**：研究者能观测到的是样本 X₁, ..., X_n 及其经验分布。总体分布 F、概率质量 p_l、以及所有总体分位数（Q, Q_M, Q_U, Q_L）都是**不可直接观测的目标量**，需要通过样本去估计。这里没有因果推断中的潜在结果——这是一个纯分布估计问题。

#### 第二步：最小内核

**最简特例**：设 X 服从 Bernoulli(θ)，即支撑集 {0, 1}，p₁ = Pr(X=0) = 1−θ，p₂ = Pr(X=1) = θ。这是 Jentsch and Leucht (2016) 用来证明经典样本中位数不相合的同一个例子。

在这个特例下，经典分位数函数是：
- Q(α) = 0 当 0 < α ≤ 1−θ；Q(α) = 1 当 1−θ < α < 1。

**经典样本分位数的问题**：当 α = 1/2（中位数）且 θ = 1/2 时，Q(1/2) = 0（因为 F(0) = 1/2 ≥ 1/2）。但样本中位数 Q̂_n(1/2) 的极限行为是：当 n 为偶数时，它取 0 或 1 取决于中间两个次序统计量的值；当 n 为奇数时，它取中间那个观测值。Jentsch and Leucht (2016) 证明了 Q̂_n(1/2) 依分布收敛到一个**两点分布**（各占 1/2 概率在 0 和 1），而不是退化到 0。这就是"不相合"——估计量不收敛到目标量。

**本文的 upper-/lower-quantile 如何解决**：在 Bernoulli(1/2) 情形下：
- F_U(x)：连接 (0, 1/2) 和 (1, 1) 的线性函数。F_U(x) = 1/2 + x/2 对 0 < x < 1。
- Q_U(1/2) = inf{x : F_U(x) ≥ 1/2} = 0（因为 F_U(0) = 1/2）。
- F_L(x)：连接 (0, 0) 和 (1, 1/2) 的线性函数。F_L(x) = x/2 对 0 < x < 1。
- Q_L(1/2) = inf{x : F_L(x) ≥ 1/2} = 1（因为 F_L(1) = 1/2）。

所以 upper-quantile 和 lower-quantile 在 α = 1/2 时分别给出 0 和 1——它们**框住了**经典分位数的取值。更重要的是，样本版本的 Q̂_U,n(1/2) 和 Q̂_L,n(1/2) 是连续插值的结果，它们**不会**像经典样本分位数那样在 0 和 1 之间跳跃，而是随着样本频率的变化平滑移动，从而恢复了相合性和渐近正态性。

**核心数学困难**：经典分位数在离散情形下失效的根源是 F 的**不可逆性**——F 是阶梯函数，其"逆"在跳跃点处是多值的。本文的解决思路是：用线性插值构造 F 的**连续近似**（F_U 和 F_L），使得逆映射是良定义的。但这里有一个微妙的权衡：插值引入了**偏差**（upper-quantile 系统性偏高，lower-quantile 系统性偏低），这个偏差的量级是 O(相邻支撑点间距)。当支撑点间距趋于 0（即离散分布逼近连续分布）时，偏差消失；但当间距固定时，偏差是**一阶**的，不随 n 增大而消失。因此，upper-/lower-quantile 的"相合性"是指**收敛到 Q_U(α) 和 Q_L(α)**（即插值后的目标量），而不是收敛到经典 Q(α)。这是一个重要的概念区分——作者实际上是在说："我们换了一个目标量来估计，这个新目标量有好的性质。" 至于这个新目标量是否比经典分位数更"正确"，这是一个留给使用者的判断。


### 三、这篇论文做了什么

#### 三句话

① **研究了什么问题**：离散总体下经典分位数估计量不相合、不渐近正态的问题，提出了两个新的分位数定义（upper-quantile 和 lower-quantile），它们通过线性插值消除经典分位数函数的不连续性，从而恢复相合性和渐近正态性。② **核心工具/方法**：线性插值构造的连续 CDF 近似（upper-CDF 和 lower-CDF），以及基于经验版本的广义逆估计量；理论工具包括经验过程理论、delta 方法、以及针对离散情形特殊处理的渐近展开。③ **主要结论**：样本 upper-/lower-quantile 在离散和绝对连续总体下都相合且渐近正态（Theorem 1-5）；基于它们构造的预测区间有**保证的**覆盖概率（Proposition 3, Corollary 1）；在绝对连续情形下，upper-/lower-quantile 与经典分位数渐近等价（Theorem 4-5 的推论）。

#### 关键设定与假设

- **离散总体设定**：X 的支撑集为有限集 {x₁ < ... < x_L}，概率质量 p_l > 0。这是全文最核心的设定。作者没有讨论 L → ∞ 的情形（即支撑集无限但可数），这是一个潜在的限制。
- **对绝对连续总体的扩展**：Theorem 4-5 将结果推广到绝对连续情形，此时 upper-/lower-quantile 与经典分位数渐近等价。这个扩展的意义在于**统一性**——同一个估计量在两种情形下都有好的性质，无需事先知道总体是离散还是连续。
- **对 F 的假设**：在绝对连续情形下，要求 F 在 Q(α) 处可导且导数（密度）为正。这是经典分位数渐近理论的标凊假设，没有额外加强。
- **相比已有文献的放宽/强化**：相比 Ma et al. (2011) 的 mid-quantile，本文的 upper-/lower-quantile 多了一个关键性质——**与原始总体的序关系是确定的**（upper-quantile ≥ 经典分位数 ≥ lower-quantile），这使得预测区间的覆盖概率可以被精确控制（Proposition 3）。相比 Chen and Lazar (2010) 的 jittering 方法，本文不需要假设支撑集为连续整数，适用范围更广。相比 Chernozhukov et al. (2020) 的 CDF 置信带反演法，本文直接给出了估计量的渐近分布，推断更直接。

#### 主要结果

**定理 1（相合性）**：对给定 α ∈ (0,1)，Q̂_U,n(α) → Q_U(α) 且 Q̂_L,n(α) → Q_L(α)（依概率）。这个结果看似平凡，但关键在于它**同时**覆盖了离散和绝对连续两种情形——经典样本分位数在离散情形下连这个最基本的性质都没有。

**定理 2（离散情形下 upper-quantile 的渐近分布）**：这是全文最核心的技术结果。根据 α 相对于概率质量 {p_l} 的位置，分为四种情形：
- **情形 1**（α < p₁）：Q̂_U,n(α) 以概率收敛到 x₁，且 √n[Q̂_U,n(α) − x₁] 的极限分布是退化分布（在 0 处有概率 1）。这是因为 α 落在第一个支撑点之前，插值区间是 [x₁, x₂]，但估计量总是取 x₁。
- **情形 2**（α = ω·p*_l + (1−ω)·p*_{l+1}，0 < ω < 1，即 α 落在插值区间的内部）：√n[Q̂_U,n(α) − Q_U(α)]·f_U[Q_U(α)] → N(0, α(1−α) + ω²p_{l+1} − ω·p_{l+1})。注意这里的方差比经典情形多了一项 ω²p_{l+1} − ω·p_{l+1}，这一项是**负的**（因为 0 < ω < 1），反映了插值带来的"方差缩减"效应。
- **情形 3**（α = p*_l，即 α 恰好等于某个累积概率）：√n[Q̂_U,n(α) − Q_U(α)] 的极限分布是**两片正态分布**（two-piece normal），在正半轴和负半轴分别有不同的方差。这是因为估计量从左侧和右侧逼近 x_l 时，插值斜率不同。
- **情形 4**（α = p₁，左边界）：极限分布是 N(0, α(1−α)) 在正半轴的部分，且在 0 处有 1/2 的概率质量。

**定理 3**：与定理 2 完全平行，给出 lower-quantile 的渐近分布。

**定理 4-5（绝对连续情形）**：当 F 绝对连续且在 Q(α) 处密度为正时，√n[Q̂_U,n(α) − Q(α)]·f[Q(α)] → N(0, α(1−α))，与经典样本分位数**完全相同**。这说明 upper-/lower-quantile 是经典分位数的**严格推广**——在绝对连续情形下不损失任何效率。

**命题 3（预测区间的保证覆盖）**：对任意 α ∈ (0,1)，Pr(Q_U(α/2) ≤ X ≤ Q_L(1−α/2)) ≥ 1−α。这是 upper-/lower-quantile 相比 mid-quantile 的核心优势——mid-quantile 无法保证这一点（Proposition 2 给出了反例条件）。

#### 证明路线与技术技巧

**整体路线**（以定理 2 为例）：
1. **重参数化**：将 Q̂_U,n(α) 的偏差分解为"插值偏差"（Q_U(α) 与经典分位数的差）和"估计偏差"（Q̂_U,n(α) 与 Q_U(α) 的差）。前者是确定性的，由插值构造决定；后者是随机的，需要渐近分析。
2. **经验过程逼近**：利用经验 CDF 的强逼近（如 Komlós-Major-Tusnády 逼近）或 Donsker 定理，将 √n(F̂_U,n − F_U) 逼近为一个高斯过程。这是处理插值后 CDF 的关键——插值使得 F̂_U,n 是分段线性的，其逆的波动可以通过 F̂_U,n 在特定点处的波动来控制。
3. **情形分类**：根据 α 落在插值区间的内部、端点、还是外部，分别处理。这是全文技术细节最密集的部分——不同情形下，Q̂_U,n(α) 对 F̂_U,n 的"敏感性"不同，导致不同的极限分布。
4. **delta 方法**：在插值区间内部（情形 2），F_U 在 Q_U(α) 处可导，直接套用经典的 delta 方法。在端点处（情形 3），F_U 不可导，需要更精细的展开，得到两片正态分布。

**关键技巧**：
- **线性插值的方差缩减效应**：情形 2 中方差项 ω²p_{l+1} − ω·p_{l+1} 为负，这是插值带来的直接后果。直觉上，插值"抹平"了离散跳跃，使得估计量对样本波动的响应更平滑，从而方差更小。这个效应在 mid-quantile 中也有，但本文首次在离散情形下给出了精确的方差公式。
- **两片正态分布的处理**：情形 3 中，估计量从左右两侧逼近 x_l 时，收敛速度不同（因为 F_U 在 x_l 处左右导数不同），导致极限分布不对称。作者用"两片正态"来刻画这种不对称性，并给出了构造置信区间的具体方法（用 0.025 分位数和 0.975 分位数分别来自两个不同的正态分布）。
- **bootstrap 的讨论**：作者在补充材料中讨论了 bootstrap 方法。对于离散数据，标准 bootstrap 对经典分位数失效（因为重抽样无法产生支撑集之外的值），但对 upper-/lower-quantile 有效——这是另一个实际优势。

#### 真实例子与应用

**例 5.1（离散均匀分布）**：支撑集 {−1.5, −1, 0, 0.7, 2}，等概率。验证了定理 2 和 3 的四种情形，样本量 n=500，1000 次重复。结果显示经验覆盖概率与名义水平 0.95 吻合良好，且置信区间在情形 3（α 落在累积概率点上）时呈现预期的不对称性。

**例 5.2（二项分布 Bin(3, 0.5)）**：支撑集 {0, 1, 2, 3}，概率 {0.125, 0.375, 0.375, 0.125}。这个例子特别有意思，因为 α = 0.5 恰好落在累积概率点 p*₂ = 0.5 上，对应定理 2 的情形 3。模拟结果验证了两片正态分布的理论预测。

**例 5.3（连续分布，验证兼容性）**：F(x) = Φ(x/2) 当 x ≤ 0，F(x) = Φ(x/3) 当 x > 0。这是一个在 0 处有"尖点"的连续分布（左右导数不同），用来验证定理 4-5 在连续情形下的表现。结果显示 upper-/lower-quantile 与经典样本分位数表现几乎一致。

**例 5.4（二项分布参数的置信区间）**：这是最贴近实际应用的例子。利用 Repro samples 方法（Xie and Wang 2026），将 upper-/lower-quantile 用于构造二项分布参数 θ 的置信区间。结果显示：(1) upper-/lower-quantile 方法能保证覆盖概率（与 C-P 方法一致），而 mid-quantile 方法在某些参数配置下覆盖概率低于名义水平；(2) upper-/lower-quantile 方法的区间宽度与 C-P 方法几乎相同，但计算更简单。这个例子直接回应了作者在引言中的核心主张——mid-quantile 的覆盖概率缺陷不是理论上的吹毛求疵，而是实际推断中的真实问题。

#### 🔎 结论是否比证明窄

- **定理 2 和 3 只覆盖了 L 有限的情形**。作者在定理陈述中明确假设支撑集有限，但引言中讨论的许多应用（如 Poisson 计数数据）支撑集是无限可数的。作者在结论部分提到"推广到无限支撑集是 future work"，但这是一个重要的限制——实际计数数据的支撑集几乎总是无限的。
- **命题 3 的覆盖概率是"保守"的**（即 ≥ 1−α），但作者没有讨论这个保守性有多大。从例 5.4 的结果看，区间宽度与 C-P 方法相当，说明保守性不大，但缺乏理论上的精确刻画。
- **定理 4-5 的"绝对连续"假设**：作者证明了在绝对连续情形下 upper-/lower-quantile 与经典分位数渐近等价，但**没有讨论混合分布**（既有离散又有连续成分）的情形。实际数据（如零膨胀计数数据）经常是混合分布。
- **bootstrap 的结果放在补充材料中**，正文只提到"见补充材料"。对于实际使用者来说，bootstrap 的可行性是关键问题，但正文没有给出任何关于 bootstrap 一致性的理论保证。
