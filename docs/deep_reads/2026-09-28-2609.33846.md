### 一、领域脉络与小综述

**这个方向是什么**：中介分析（mediation analysis）中的效应量（effect size）度量问题。根本任务是：在总效应被分解为直接效应（DE）与间接效应（IE）后，如何用一个标量概括"中介路径的贡献有多大"。最经典的度量是比例中介 PM = IE/TE（Alwin and Hauser, 1975; MacKinnon, 2008），它在 DE 与 IE 同向（一致中介）时直观且落在 [0,1] 内。但当 DE 与 IE 反向（不一致中介，又称抑制效应）时，PM 的分母 TE 是净效应，可能趋近于零，导致 PM 无界、符号反常、失去比例解释。本文要解决的就是这个缺口：在不一致中介下，给出有界、稳定、且保留"比例"直觉的替代度量。

**发展脉络**：

- **奠基工作**：Alwin and Hauser (1975) 在路径分析框架中引入效应分解，确立了 DE + IE = TE 的加法结构；MacKinnon et al. (1995, 2000) 系统研究了不一致中介（抑制效应），明确指出 PM 在此情形下会超出 [0,1] 甚至无定义，并用 ATLAS 项目数据（Goldberg et al., 1996）给出了实证例证——这是本文直接继承的问题来源。
- **主要进展（效应量度量）**：Fairchild et al. (2009) 提出基于方差解释（R²）的效应量，试图绕开 PM 的符号问题；但 de Heus (2012) 指出这类方法将 DE 与 IE 的重叠方差全部归于间接效应，导致反直觉结果；Preacher and Kelley (2011) 系统评述了中介效应量，提出 κ² 等标准化度量；Lachowicz et al. (2018) 进一步改进方差类度量。这些工作的共同点是：要么停留在方差尺度（与 PM 的效应尺度不一致），要么计算复杂、解释门槛高。
- **当前 frontier**：如何在保持 PM 的"效应尺度 + 比例解释"的同时，处理不一致中介、多路径、以及比值比/风险比等非线性尺度。本文的位置正是这个 frontier：提出 MMS 与抑制程度 σ，在效应尺度上给出有界度量，并声称在一致中介下退化为 PM。

**子线索聚类**：被引文献大致落在三条线索上——

1. **比例/效应尺度线索**：PM 及其变体（Alwin and Hauser, 1975; MacKinnon et al., 1995, 2000; Vanderweele, 2015）。核心是"IE 占总效应的比例"，问题是不一致中介下分母失效。
2. **方差解释线索**：R² 类度量（Fairchild et al., 2009; de Heus, 2012; Lachowicz et al., 2018）。核心是"中介路径解释了多少方差"，问题是与效应尺度脱节、重叠方差分配武断。
3. **因果中介分析线索**：Vanderweele (2015) 的专著为 DE/IE 提供了潜在结果框架下的因果定义，但本文只引用了其存在，没有深入讨论识别条件。

**这个方向在追问的核心问题**：

1. 如何在不一致中介下定义有界的"中介比例"？
2. 如何同时量化"中介贡献"与"抑制/抵消"这两个正交特征？
3. 如何将度量推广到多条中介路径、以及比值比/风险比等非线性尺度？
4. 如何为这些度量建立统计推断（标准误、置信区间）？

**⚠️ 作者的 framing（这是作者的说法）**：作者把缺口 frame 成——"PM 在不一致中介下会超出 [0,1] 或变得不稳定，因此需要新的度量；MMS 在一致中介下退化为 PM，所以是 PM 的自然推广而非替代；σ 量化了被抵消的幅度比例，这是 PM 无法提供的信息。" 被淡化或回避的竞争路线包括：方差类度量（只引用未比较）、因果识别假设（只在讨论段一句带过）、估计与推断问题（全文无任何标准误或置信区间）。**什么明显该被引却没出现**：VanderWeele and Vansteelandt (2009) 的因果中介分解论文、Pearl (2001) 的因果中介公式——这两篇是因果中介分析的基石，本文既然声称"可应用于因果中介分析"，却未讨论这些文献中的识别条件（如 sequential ignorability），是一个值得注意的省略。

**张力**：未见明显对立引用。但存在一个隐含张力：de Heus (2012) 对 Fairchild et al. (2009) 的批评表明方差类度量有内在缺陷，本文选择效应尺度是对此的回应，但作者没有直接说明为什么效应尺度优于方差尺度——这个论证是缺失的。

### 二、最核心、最简单的例子 / 数学问题

**第一步：符号、模型、可观测数据**

本文是纯代数/度量层面的工作，不涉及数据生成机制或估计。全部符号如下：

- **效应量（参数/estimand）**：
  - DE：直接效应，一个实数（可正可负）
  - IE：间接效应，一个实数（可正可负）
  - TE = DE + IE：总效应（加法分解是本文的起点假设）
  - IEᵢ（i = 1,…,k）：第 i 条中介路径的间接效应，k ≥ 1
- **由 DE、IE 导出的量**：
  - d = |DE|，m = |IE|：效应的绝对值
  - L = d + m = |DE| + |IE|：DE 与 IE 的幅度之和（本文的核心分母）
  - PM = IE / TE：传统比例中介（当 TE = 0 时无定义）
  - MMS = m / L = |IE| / (|DE| + |IE|)：本文提出的中介幅度份额
  - σ = 1 − |TE| / L：本文提出的抑制程度
- **二元结局情形**：
  - DE_R、IE_R：比值比（OR）或风险比（RR）尺度上的直接/间接效应（乘法分解 TE_R = DE_R × IE_R）
  - log(DE_R)、log(IE_R)：对数变换后的加法效应（本文建议在 log 尺度上应用 MMS 和 σ）
- **可观测数据**：本文不涉及数据。所有量均假设已被"正确识别和估计"（作者在讨论段承认这一点，但未展开）。

**第二步：最小内核**

剥掉多路径、二元结局等扩展后，本文的核心就是一个代数观察：

> **当 DE 与 IE 同号时，|TE| = |DE| + |IE| = L；当 DE 与 IE 异号时，|TE| = ||DE| − |IE|| < L。因此，L 是 |TE| 的一个上界，且 L 永远 ≥ |TE|。**

基于这个观察，两个度量自然产生：

**MMS = |IE| / (|DE| + |IE|)**：分子是间接效应的幅度，分母是 DE 与 IE 幅度之和。因为 0 ≤ |IE| ≤ L，所以 MMS ∈ [0,1]。当 DE 与 IE 同号时，|TE| = L，此时 MMS = |IE| / |TE| = IE / TE = PM——这就是"MMS 在一致中介下退化为 PM"的含义。当 DE 与 IE 异号时，PM 可能为负、无界或无定义，而 MMS 依然在 [0,1] 内，解释为"间接效应占 DE 与 IE 总幅度之和的比例"。

**σ = 1 − |TE| / L**：度量的是"由于 DE 与 IE 方向相反，总效应被抵消了多少比例"。当 DE 与 IE 同号时，|TE| = L，σ = 0；当 DE = −IE（完全抑制）时，TE = 0，σ = 1。σ 与 MMS 互补：MMS 描述"间接路径的相对幅度"，σ 描述"幅度因抵消而损失的比例"。

**最简数值例子**（ATLAS 数据，MacKinnon et al., 2000）：

- DE = −0.181，IE = 0.042（异号，不一致中介）
- TE = −0.139，L = 0.223
- PM = 0.042 / (−0.139) ≈ −0.30（负值，无法解释为"比例"）
- MMS = 0.042 / 0.223 ≈ 0.188（"间接路径占 DE 与 IE 总幅度的 18.8%"）
- σ = 1 − 0.139 / 0.223 ≈ 0.376（"总效应因抵消损失了 37.6% 的幅度"）

再对比一个一致中介的例子：DE = 2，IE = 1 → TE = 3，PM = 1/3，MMS = 1/3，σ = 0。两者完全一致。

再对比完全抑制：DE = 1，IE = −1 → TE = 0，PM 无定义，MMS = 0.5，σ = 1。

**为什么这个内核"撑得起"整篇论文**：多路径扩展只是把 L 的定义换成 L = |DE| + Σ|IEᵢ|，MMSᵢ = |IEᵢ|/L，σ 的定义不变；二元结局只是用 log 变换把乘法分解变成加法分解。所有命题的证明都只依赖三角不等式 |a + b| ≤ |a| + |b| 和绝对值的初等性质。论文在数学上做的事情，本质上就是**用 L = |DE| + |IE| 替换 TE = DE + IE 作为分母，从而把 PM 从无界度量变成有界度量，并额外引入 σ 来记录被抵消的信息**。

### 三、这篇论文做了什么

**三句话**：
1. **研究了什么问题**：比例中介 PM 在不一致中介（DE 与 IE 异号）下会超出 [0,1]、变负甚至无定义，本文提出两个互补的效应尺度度量来替代 PM。
2. **核心工具/方法**：定义 MMS = |IE| / (|DE| + |IE|) 和 σ = 1 − |TE| / (|DE| + |IE|)，利用三角不等式建立两者的有界性，并推广到多条中介路径和二元结局（log OR / log RR 尺度）。
3. **主要结论**：MMS 在一致中介下精确退化为 PM；σ 在一致中介下为 0、在完全抑制下为 1；两者在任意 DE、IE 组合下都落在 [0,1] 内，且在多路径和比值尺度下保持同样的解释。

**关键设定与假设**：

- **加法可分解性**：TE = DE + IE（或 log 尺度上的 log TE_R = log DE_R + log IE_R）。这是整个框架的地基，论文没有讨论 DE 和 IE 如何被识别或估计。
- **L > 0**：排除 DE = IE = 0 的平凡情形（此时 MMS 和 σ 都无定义）。
- **效应量为实数**：DE、IE 被当作已给定的数值，不讨论其不确定性。
- **相比已有文献的放宽/强化**：相比 PM，MMS 不要求 TE ≠ 0，这是放宽；但 MMS 放弃了"占总效应比例"的解释，改为"占总幅度比例"，这是解释层面的代价。相比 R² 类方差度量（Fairchild et al., 2009; de Heus, 2012），MMS 保持在效应尺度上，避免了方差重叠分配问题，但论文没有给出形式化的比较论证。

**主要结果**（按论文结构）：

1. **两路径情形**（Section 2）：
   - MMS ∈ [0,1]，且 MMS = 0 ⟺ IE = 0；MMS = 1 ⟺ DE = 0。
   - 一致中介下 MMS = PM（证明：当 DE·IE > 0 时，|TE| = |DE| + |IE| = L，故 MMS = |IE|/L = |IE|/|TE| = IE/TE = PM）。
   - σ ∈ [0,1]；σ = 0 ⟺ 一致中介；σ = 1 ⟺ TE = 0（完全抑制）。
   - MMS 与 σ 的关系：σ = 1 − |TE|/L，MMS = |IE|/L，两者共享分母 L，互补描述同一系统。

2. **多路径情形**（Section 3）：
   - L = |DE| + Σ|IEᵢ|，MMSᵢ = |IEᵢ|/L。
   - 所有 MMSᵢ 与 |DE|/L 之和等于 1（因为 Σ|IEᵢ| + |DE| = L）。
   - σ 的定义不变，仍为 1 − |TE|/L。
   - 论文指出，当路径间存在抑制时，各 MMSᵢ 依然有界且可加，而对应的 PMᵢ = IEᵢ/TE 则可能无界。

3. **二元结局**（Section 4）：
   - 对 OR/RR 尺度，用 log 变换将乘法分解 log TE_R = log DE_R + log IE_R 转化为加法，然后直接套用 MMS 和 σ 的定义。
   - 论文指出，在 OR 尺度上，log(OR) 的对称性使得 MMS 对"效应方向"的编码与比值比的自然属性一致。

**证明路线与技术技巧**：

- **整体路线**（以两路径情形为例）：
  1. 定义 L = d + m，由三角不等式 |TE| = |DE + IE| ≤ |DE| + |IE| = L 得到 |TE| ≤ L。
  2. 由 0 ≤ m ≤ L 直接推出 MMS ∈ [0,1]。
  3. 分情况讨论 DE·IE 的符号：同号时 |TE| = L，异号时 |TE| = |d − m| < L。
  4. 一致中介下代入 |TE| = L 验证 MMS = PM。
  5. σ 的界限由 |TE| ≥ 0 和 |TE| ≤ L 直接推出。
- **关键技巧**：
  - **绝对值分解**：用 |DE| 和 |IE| 替代 DE 和 IE 作为基本量，从而消除符号对分母的影响。
  - **三角不等式**：唯一的分析工具，所有界限都从它导出。
  - **对数变换**：把比值尺度的乘法结构映射到加法结构，使 MMS 的定义可以平移。
  - **归一化**：MMSᵢ 的定义保证所有路径的 MMS 之和为 1，保留了"份额"的可加性。

**真实例子与应用**：

- **ATLAS 项目**（Goldberg et al., 1996; MacKinnon et al., 2000）：干预减少类固醇使用意图，DE = −0.181，IE = 0.042（通过"增加使用理由"这条反向路径）。PM ≈ −0.30 无法解释；MMS = 0.188 给出"间接路径占 DE 与 IE 总幅度的 18.8%"；σ = 0.376 给出"总效应因抵消损失了 37.6% 的幅度"。
- **多路径数值例子**（Section 3）：DE = 0.10，IE₁ = 0.60（有害），IE₂ = −0.55（保护），TE = 0.15。PM₁ = 4，PM₂ ≈ −3.67，均无意义；MMS₁ ≈ 0.48，MMS₂ ≈ 0.44，|DE|/L ≈ 0.08，三者之和为 1，解释清晰。
- 论文为纯方法论文，**无模拟实验、无真实数据拟合、无代码**。ATLAS 例子仅用于说明，数据来自已发表文献。

**🔎 结论是否比证明窄**：

- **"可应用于因果中介分析"（Section 5）**：论文只在讨论段声称"MMS 和 σ 的解释不限于关联分析，可应用于因果中介分析"，但全文没有给出任何在潜在结果框架（如 sequential ignorability）下的形式化结果。这是一个**结论比证明宽**的地方——MMS 和 σ 是 DE、IE 的纯函数，其性质不依赖识别假设，但"可应用于因果分析"这个 claim 需要额外论证 DE、IE 本身可被因果识别。
- **"MMS 是 PM 的推广"**：论文证明了在一致中介下 MMS = PM，但没有讨论 DE = 0 或 IE = 0 的边界情形（此时 PM = 0 或未定义，MMS = 0 或 1）。这个边界行为是干净的，但论文没有明确写出。
- **多路径情形**：论文定义了 MMSᵢ 但**没有给出任何命题或定理**，只是用数值例子说明。多路径下的性质（如路径间相关、抑制来源分解）是留白的。
- **二元结局**：论文只给出 log 变换的建议，**没有证明 log(OR) 尺度上的 DE、IE 分解在何种条件下成立**（例如，在非罕见结局下 OR 的不可压缩性）。这是一个明显的未处理问题。

### 四、开放问题

1. **统计推断完全缺失**：论文只定义了总体量 MMS 和 σ，没有给出任何估计量、标准误、置信区间或假设检验。扎根：全文无一处涉及抽样分布或估计。要确认这是不是真 gap，去读中介分析效应量文献（如 Preacher and Kelley, 2011）近 5 年的后续工作，看是否已有推断方法。

2. **因果识别条件未形式化**：Section 5 声称"可应用于因果中介分析"，但没有给出在潜在结果框架下的识别条件（如 sequential ignorability、no intermediate confounding）。扎根：论文最后一段 "their causal interpretation depends on the underlying identifying assumptions"——这句话承认了依赖，但没有展开。去读 VanderWeele and Vansteelandt (2009) 和 Pearl (2001)，看 MMS 在这些框架下是否有明确定义。

3. **多路径情形的性质未证明**：Section 3 只有定义和数值例子，没有命题。MMSᵢ 在路径间相关、路径合并/分解下的行为是开放的。扎根：Section 3 的 "We next consider these measures for binary outcomes" 之后直接进入二元结局，多路径的理论性质被跳过。

4. **二元结局的有限样本性质**：log(OR) 在小样本下有已知的偏差问题，log(RR) 有约束问题（概率在 [0,1] 内）。MMS 和 σ 在这些尺度上的估计行为完全未讨论。扎根：Section 4 只有代数变换，无任何统计性质。

5. **与现有效应量的系统比较**：论文引用了 R² 类度量（Fairchild et al., 2009; de Heus, 2012）和 κ²（Preacher and Kelley, 2011），但没有与 MMS/σ 做数值或理论比较。MMS 在什么条件下优于这些度量？扎根：引言部分只陈述"there remains a need"，没有给出比较证据。

**提醒**：要确认以上哪几条是真 gap，去读同子领域（mediation effect size measures）近期约 5 篇的 introduction——都指向它 = 共识（真 gap），互相打架 = 机会。
