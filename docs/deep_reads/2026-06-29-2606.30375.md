### 一、领域脉络与小综述

#### 这个方向是什么

本文研究的核心问题是：**如何利用连续收缩先验（以 horseshoe 先验为代表）在高维稀疏设定下进行多重假设检验，并同时实现频率学派意义上的 FDR 控制与最优检测功效。** 该方向处于贝叶斯高维推断与频率学派多重检验的交叉地带。其根本困难在于：连续收缩先验不产生精确零点，因此无法直接定义后验包含概率（ℓ-value），而后者正是 spike-and-slab 先验下实现 FDR 控制与最优检验风险的核心工具。当前该子方向的成熟度处于“方法已有、理论刚起步”的阶段——大量实证工作使用 horseshoe 进行变量选择，但缺乏系统的频率学派理论保证。

#### 发展脉络

**奠基工作：**
- **Carvalho, Polson & Scott (2010)** [12]：提出 horseshoe 先验，通过 half-Cauchy 全局-局部尺度混合实现自适应收缩。该文奠定了连续收缩先验用于稀疏估计的基础，但未涉及多重检验。
- **Efron et al. (2001)** [21] 与 **Robbins (1956)** [39]：建立了经验贝叶斯多重检验的框架（two-groups model），为后续贝叶斯 FDR 控制提供了方法论基础。

**主要进展：**
- **van der Pas, Szabó & van der Vaart (2017)** [49]：建立了 horseshoe 先验的后验收缩率与自适应性质，证明了 MMLE 对全局参数 τ 的估计一致性。这是本文理论分析的关键技术来源。
- **van der Pas, Szabó & van der Vaart (2017)** [50]：研究了 horseshoe 后验的不确定性量化，发现基于边际可信区间的变量选择方法在频率学派意义下是保守的。该文直接提出了“如何用 horseshoe 做多重检验”这一开放问题。
- **Castillo & Roquain (2020)** [15]：对 spike-and-slab 先验下的 ℓ-value 程序建立了频率学派 FDR 控制与最优检测边界。该文是本文的直接对标工作——作者试图将类似的理论保证推广到连续收缩先验。
- **Abraham, Castillo & Roquain (2024)** [3]：建立了稀疏正态均值模型下多重检验风险 R = FDR + FNR 的 sharp minimax 边界。该文为本文提供了最优性基准。

**当前 frontier：**
- **Paul, Ghosh & Chakrabarti (2026)** [36]：最近预印本，使用单组收缩先验（one-group shrinkage priors）研究多重检验的 sharp 渐近 minimax 性质，但假设已知稀疏度 s_n 或使用简单经验估计 τ，适应性有限。
- **Salomond (2017)** [42]：对高斯尺度混合下的阈值规则进行了风险量化，但仅获得大信号情形的初步结果。

**本文的位置：** 作者声称本文是上述工作的“自然延续”——将 [50] 中提出的开放问题（如何为 horseshoe 设计有理论保证的多重检验程序）与 [15, 3] 中为 spike-and-slab 先验建立的最优性理论相结合，首次为连续收缩先验提供了同时实现最优检测边界与 FDR 渐近控制的程序。

#### 子线索聚类

1. **Spike-and-slab 先验下的多重检验理论**（[15, 3, 2, 1, 44, 45]）：使用离散混合先验（Dirac spike + continuous slab），通过 ℓ-value（后验包含概率）进行决策。理论成熟，已建立 sharp minimax 最优性与 FDR 控制。计算瓶颈：高维（p > 1000）时 MCMC 采样困难。

2. **连续收缩先验的估计与不确定性量化**（[12, 47, 49, 50, 8, 9, 4, 26]）：以 horseshoe 为代表，通过全局-局部尺度混合实现自适应收缩。计算可扩展（可处理 p 在 10000 量级），但缺乏多重检验的理论保证。现有变量选择方法（后验均值阈值化、可信区间法）是经验性的，无 FDR 控制保证。

3. **经验贝叶斯多重检验**（[21, 43, 20, 29, 30]）：通过估计先验参数（如 w 或 τ）实现自适应。本文的 MMLE 方法属于此线索，但需要比已有结果（如 [49] 中仅到常数级别的单侧集中）更精确的集中性（匹配常数的双侧集中）。

4. **变分贝叶斯近似**（[18, 38]）：通过 VB 近似 spike-and-slab 后验，计算可扩展，但变量选择性质的理论几乎空白。

#### 这个方向在追问的核心问题

1. **如何为连续收缩先验定义 ℓ-value 的替代物？** 由于后验连续，Π[θ_i = 0 | X] ≡ 0，需要找到可计算且具有类似决策理论性质的代理量。
2. **能否同时实现 FDR 控制与最优检测功效？** 对于 spike-and-slab 先验，ℓ-value 程序可同时达到 minimax 最优 R-risk 与目标 FDR 水平。连续收缩先验能否做到？
3. **全局参数 τ 的估计精度要求有多高？** 对于 R-risk 最优性，只需 τ 集中到常数级别；对于精确 FDR 控制，需要匹配常数的双侧集中——这比已有结果更精细。
4. **理论能否推广到更复杂模型（线性回归、图模型）？** 序列模型是理论分析的理想化设定，但实际应用需要高维回归与图模型的理论保证。

#### ⚠️ 作者的 framing

作者将缺口 frame 为：“连续收缩先验缺乏有理论保证的多重检验程序”——这是对 [50] 中开放问题的直接回应。作者声称其 s-value 是 ℓ-value 的“自然类比”，并通过 SSL 先验的对比（Section 2.4 & Appendix C）论证了这一类比的有效性。

**被淡化/回避的竞争路线：**
- **Spike-and-slab 先验的快速采样算法**（[34, 52]）：作者承认“steady progress”，但认为高维（>1000）仍是挑战。然而 [52] 声称可处理 n=10^4 量级——这与本文 horseshoe 的规模相当。作者未提供直接的计算时间对比。
- **变分贝叶斯方法**（[18, 38]）：作者仅用一句话提及“very little is known so far on their variable-selection properties”，但未讨论 VB 方法在 FDR 控制方面的潜力。
- **Knockoff 方法**（[6, 11]）：仅在引言中作为 FDR 控制的“popular option”提及，未与本文方法进行任何比较。

**明显该被引/该存在、却没出现在 intro 里的：**
- **Donoho & Johnstone (1994) 的阈值理论**：虽然间接通过 [29, 30] 体现，但直接引用 wavelet 阈值与检测边界的关系可能更有助于定位本文的贡献。
- **Meinshausen & Bühlmann (2010) 的 stability selection**：这是高维变量选择中另一种有 FDR 控制保证的方法，与本文的贝叶斯路径形成对比。
- **Bogdan et al. (2015) 的 SLOPE**：通过排序的 ℓ1 惩罚实现 FDR 控制，是频率学派路径的代表。本文未与之比较。

#### 张力

未见明显对立引用。各工作之间在技术假设上存在差异（如信号强度要求、稀疏度已知与否），但未发现根本性矛盾。一个值得注意的微妙之处：**[49] 证明 MMLE 对 τ 的上界集中到常数级别，但下界集中未建立**——本文需要下界集中（Proposition 1）以及匹配常数的双侧集中（Proposition 3），这是对已有结果的重要细化。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据交代清楚

**符号：**
- **n**：观测/坐标个数（序列模型中的样本量）。
- **s_n**：真实非零参数个数（稀疏度），满足 s_n → ∞ 且 s_n/n → 0。
- **θ = (θ_1, ..., θ_n) ∈ ℝⁿ**：未知参数向量。
- **θ₀**：真实参数（固定、非随机）。
- **X = (X_1, ..., X_n)**：可观测数据向量。
- **ε_i ~ N(0,1)**：独立标准正态噪声。
- **S₀ = {i : θ₀,i ≠ 0}**：真实支撑集，|S₀| = s_n。
- **τ ∈ (0,1)**：horseshoe 先验的全局收缩参数。
- **λ_i ~ C⁺(0,1)**：局部尺度参数，服从标准 half-Cauchy 分布。
- **Π[· | X]**：后验分布。
- **s_i(X) = s(X_i; τ)**：s-value，定义见下文。
- **S_i(X) = S(X_i; τ)**：S-value，定义见下文。
- **t ∈ (0,1)**：目标 FDR 水平。
- **φ_t(X) = (φ_1, ..., φ_n)**：多重检验决策规则，φ_i ∈ {0,1}。
- **FDR(θ, φ) = E_θ[ FP / (1 ∨ TP) ]**：错误发现率。
- **FNR(θ, φ) = E_θ[ FN / (1 ∨ s_n) ]**：错误否定率。
- **R(θ, φ) = FDR + FNR**：组合检验风险。
- **Φ(·), ϕ(·)**：标准正态分布函数与密度函数。
- **Φ̄(u) = 1 - Φ(u)**：标准正态生存函数。
- **ζ_{s_n/n} = √[2 log(n/s_n)]**：检测边界的关键量。
- **τ_n(s_n) = (s_n/n) √[log(n/s_n)]**：τ 的“oracle”量级。
- **C* = (2/π)^{3/2}**：证明中出现的常数。
- **h(u) = u²ϕ(u)/2**：辅助函数，用于 s-value 的界。
- **H(u) = 1/(u Φ̄(u))**：辅助函数，用于 S-value 的界。
- **λ(·) = h^{-1}(·)**：h 的反函数。
- **Λ(·) = H^{-1}(·)**：H 的反函数。

**模型（稀疏正态均值模型）：**
- 数据生成：X_i = θ_i + ε_i，ε_i ~ N(0,1)，i = 1, ..., n。
- 先验：θ_i | λ_i, τ ~ N(0, τ²λ_i²)，λ_i ~ C⁺(0,1)（horseshoe 先验）。
- 目标：同时检验 H₀ᵢ : θ_i = 0 vs H₁ᵢ : θ_i ≠ 0，控制 FDR 并最小化 FNR。
- 真实参数 θ₀ 属于稀疏类 ℓ₀[s_n] = {θ ∈ ℝⁿ : |{i : θ_i ≠ 0}| ≤ s_n}。
- 为建立最优性，考虑信号强度类 L₀[s_n; b] = {θ ∈ ℓ₀[s_n] : |θ_i| ≥ ζ_{s_n/n} + b, ∀i ∈ S_θ, |S_θ| = s_n}，其中 b 为固定实数。

**可观测数据：**
- 研究者实际观测到的是 X = (X_1, ..., X_n)，即带噪声的信号。
- 不可观测的是：真实参数 θ₀、噪声 ε_i、局部尺度 λ_i。
- 关键识别假设：噪声分布已知（N(0,1)），先验分布完全指定（除 τ 外），τ 通过 MMLE 从数据估计。

#### 第二步：最小内核

**最简特例：d = 1（单个坐标），τ 已知，信号强度在检测边界上**

考虑最简单的情形：只有一个坐标（n=1），观测 X = θ + ε，ε ~ N(0,1)。假设 θ 服从 horseshoe 先验 Π_τ（τ 已知），真实 θ₀ 要么为 0（H₀），要么为 μ = ζ_{1/1} + b = b（因为 n/s_n = 1 时 ζ = 0，但为保持一般性，假设 μ 足够大）。

**核心问题：** 如何基于后验分布 Π[θ | X] 构造一个决策规则 φ(X) ∈ {0,1}，使得：
- 若 θ₀ = 0，P(φ=1) 小（控制 type I error）；
- 若 θ₀ = μ，P(φ=0) 小（控制 type II error）。

**Spike-and-slab 先验的做法：** 使用 ℓ-value = Π[θ=0 | X]。若 ℓ-value < t，拒绝 H₀。这是贝叶斯分类器，有最优性保证。

**连续收缩先验的困难：** Π[θ=0 | X] = 0（因为先验连续），无法直接使用。

**本文的关键想法：** 定义 s-value = 2 × min{Π[θ<0 | X], Π[θ>0 | X]}。由于后验在 0 附近集中质量（但不精确为 0），Π[θ<0 | X] 和 Π[θ>0 | X] 中较小的那个捕捉了“θ 接近 0”的后验概率的一半（另一半在另一侧）。乘以 2 后，s-value 近似于“θ 在 0 附近”的后验概率。

**为什么这有效？** 在 SSL 先验（连续 spike + 连续 slab）下，可以显式计算 ℓ-value 和 s-value，并证明它们非常接近（Lemma C.1 & Figure 17）。对于 horseshoe，虽然无法显式计算，但通过积分估计（Lemma 6.2）可以证明 s-value 具有类似 ℓ-value 的阈值行为：当 |X| 小时 s-value ≈ 1（不拒绝），当 |X| 大时 s-value ≈ 0（拒绝）。

**在这个特例下，要证的命题退化成什么？**
- **Theorem 1（s-value 的 R-risk 最优性）退化为：** 对于单个坐标，s-value 程序 φ_t^s(X) = 1{s(X;τ) < t} 的 type I + type II error 之和渐近等于 Φ̄(b)（最优值）。
- **Theorem 2（S-value 的 FDR 控制）退化为：** S-value 程序 φ_t^S(X) = 1{S(X;τ) < t} 的 type I error 渐近等于 t，type II error 渐近等于 Φ̄(b)。

**证明的核心数学困难：** 需要精确估计 s-value 和 S-value 作为 X 和 τ 的函数，特别是当 X 在检测边界 ζ_{s_n/n} 附近时。这涉及对 half-Cauchy 混合积分的精细渐近展开（Lemma 6.2, A.6），以及对 MMLE ˆτ 的匹配常数集中性（Proposition 3）。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题：** 在高维稀疏正态均值模型下，使用连续收缩先验（以 horseshoe 为代表）进行多重假设检验，目标是同时实现频率学派意义上的 FDR 控制与最优检测功效。
2. **核心工具/方法：** 提出了三种基于后验的决策规则——s-value、S-value 和 Cs-value 程序，其中 s-value = 2 × min{Π[θ_i<0|X], Π[θ_i>0|X]} 作为 ℓ-value 的连续类比，S-value 通过条件概率 Π[θ_i<0 | |X_i| ≥ |x|] 实现目标 FDR 控制。
3. **主要结论：** (a) s-value 程序在稀疏正态均值模型中达到 FDR+FNR 的 sharp minimax 最优检测边界（Theorem 1）；(b) S-value 程序在给定目标 FDR 水平 t 下，渐近实现 FDR → t 且 FNR → Φ̄(b)，达到最优（Theorem 2）；(c) 模拟实验在序列模型、高维线性回归和高斯图模型中验证了理论预测。

#### 关键设定与假设

**完整设定（在第二节最小记号基础上补充）：**

- **模型：** X_i = θ_i + ε_i, ε_i ~ N(0,1), i=1,...,n（稀疏正态均值模型）。
- **先验：** θ_i | λ_i, τ ~ N(0, τ²λ_i²), λ_i ~ C⁺(0,1), τ 通过 MMLE 估计（或 hierarchical Bayes 采样）。
- **稀疏类：** θ₀ ∈ ℓ₀[s_n] = {θ : |{i: θ_i ≠ 0}| ≤ s_n}，s_n → ∞, s_n/n → 0。
- **信号强度类（用于最优性）：** L₀[s_n; b] = {θ ∈ ℓ₀[s_n] : |θ_i| ≥ √[2 log(n/s_n)] + b, ∀i ∈ S_θ}，其中 b 为固定实数。
- **L₀^=[s_n; b]**：与 L₀ 相同但等式成立（用于 Theorem 2 的精确 FDR 控制）。
- **τ 的估计：** MMLE ˆτ = argmax_{τ∈[1/n,1]} ∏_{i=1}^n ∫ ϕ(X_i - θ) h_τ(θ) dθ。

**关键假设：**
1. **噪声分布已知（N(0,1)）：** 这是序列模型的标准假设。在回归与图模型中，噪声方差也通过先验处理。
2. **独立同分布先验：** θ_i 独立同分布 horseshoe 先验。在序列模型中，后验因此也是独立的（坐标间独立）。
3. **稀疏度 s_n 未知：** 程序完全自适应于 s_n，无需先验知识。
4. **τ 的估计：** 理论部分使用 MMLE，模拟中也使用 hierarchical Bayes（half-Cauchy 先验于 τ）。作者声称两者行为相似。
5. **信号强度条件：** 对于 Theorem 1，信号强度至少为 √[2 log(n/s_n)] + b；对于 Theorem 2，信号强度精确等于该值（边界信号）。

**相比已有文献的放宽/强化：**
- 相比 [15]（spike-and-slab）：本文处理的是连续先验，无法直接使用 ℓ-value，需要新的代理量。
- 相比 [49]（horseshoe 估计）：本文从估计转向检验，需要更精细的 τ 集中性（匹配常数 vs 仅常数级别）。
- 相比 [42, 36]（连续先验检验）：本文的适应性更强（无需已知 s_n），且建立了 sharp minimax 最优性。

#### 主要结果

**Theorem 1（s-value 的 R-risk 最优性）：**
- **陈述：** 设 ˆφ_t^s 为使用 MMLE ˆτ 的 s-value 程序。则对任意固定 b ∈ ℝ，当 n, s_n → ∞ 时，
  sup_{θ₀ ∈ L₀[s_n;b]} {FDR(θ₀, ˆφ_t^s) + FNR(θ₀, ˆφ_t^s)} = Φ̄(b) + o(1)。
- **直觉：** s-value 程序达到 minimax 最优的 R-risk，匹配 [3] 中为 spike-and-slab 建立的边界。这意味着连续收缩先验在检验风险意义上与离散先验同样有效。
- **必要条件：** 信号强度至少为 √[2 log(n/s_n)] + b（检测边界附近）。
- **解决的技术难点：** 需要证明 MMLE ˆτ 集中到 [d₁τ_n(s_n), d₂τ_n(s_n)]（Proposition 1），其中下界集中是新的（[49] 仅有上界）。

**Theorem 2（S-value 的 FDR 控制）：**
- **陈述：** 设 ˆφ_t^S 为使用 MMLE ˆτ 的 S-value 程序，t ∈ (0, 1/2]。则对任意固定 b ∈ ℝ，当 n, s_n → ∞ 时，对任意 θ₀ ∈ L₀^=[s_n;b]，
  FDR(θ₀, ˆφ_t^S) → t, FNR(θ₀, ˆφ_t^S) → Φ̄(b)。
- **直觉：** S-value 程序在边界信号上渐近实现精确的 FDR 控制（目标水平 t），同时 FNR 达到最优值 Φ̄(b)。这意味着它比 s-value 程序（FDR → 0）更不保守，且是最优的。
- **必要条件：** 信号强度精确等于 √[2 log(n/s_n)] + b（边界信号）。作者声称可推广到更一般的信号形状（见 Remark）。
- **解决的技术难点：** 需要 MMLE ˆτ 的匹配常数集中性（Proposition 3），即 ˆτ 集中到 [τ_n(s_n)Φ(b-δ)/C*, τ_n(s_n)Φ(b+δ)/C*]。这比 Proposition 1 更精细，因为 FDR 控制需要精确的常数匹配。

**Cs-value 程序：** 作者未提供理论结果，但基于 [2] 中 Cℓ-value 的结果，推测 Theorem 2 对 Cs-value 也成立。模拟显示 Cs-value 的 FDR 略高于目标水平（但接近），TDR 更高。

#### 证明路线与技术技巧

**Theorem 1 的证明路线（Section 6 & Appendix A.1）：**

1. **s-value 的渐近界（Lemma 6.2）：** 将 s-value 表示为两个 half-Cauchy 混合积分的比值。通过变量替换和积分展开，得到在 |x| ∈ [√2, M_τ] 和 |x| > M_τ 两个区域的上下界。关键技巧：使用 Φ(-w) ≤ e^{-w²/2} 和 Φ(-w) ≥ (1 - 1/w²)ϕ(w)/w 等标准正态尾部界。

2. **MMLE ˆτ 的集中性（Proposition 1）：** 证明 ˆτ ∈ [d₁τ_n(s_n), d₂τ_n(s_n)] 以高概率成立。上界来自 [49]；下界是新的，通过分析边际似然导数在 τ 小时的符号得到。关键技巧：将导数分解为 M₀（来自零坐标）和 M₁（来自非零坐标），分别控制。

3. **FNR 上界：** 在事件 A（ˆτ 集中）上，将 FNR 分解为 (I) + (II)。(I) 对应 |X_i| ∈ [√2, M_τ⁺]，使用 s-value 上界得到阈值条件；(II) 对应 |X_i| 在区间外，证明其贡献可忽略。最终得到 FNR ≤ Φ̄(b) + o(1)。

4. **FDR 上界（→ 0）：** 类似地控制 FP，使用 s-value 下界和 τ 的上界。关键技巧：证明 E[FP] = o(s_n)，然后利用 x/(x+d) 的凹性得到 FDR = o(1)。

**Theorem 2 的证明路线（Appendix A.3）：**

1. **S-value 的渐近界（Lemma A.6）：** 比 s-value 的界更精细，需要精确到常数。关键技巧：对分母 ∫_x^∞ D(y)dy 使用 I_{-1/2} 的展开（Lemma A.15），得到 Φ̄(x) + τC*/2x 的形式。

2. **MMLE 的匹配常数集中性（Proposition 3）：** 证明 ˆτ 集中到 [τ_n(s_n)Φ(b-δ)/C*, τ_n(s_n)Φ(b+δ)/C*]。这需要比 Proposition 1 更精细的分析，特别是对 M₁ 项中信号坐标的贡献进行精确控制。关键技巧：将信号坐标分为三类（小 |X_i|、中等、大 |X_i|），分别处理。

3. **FDR 渐近等于 t：** 通过集中性证明 FP 和 TP 的期望满足 E[FP] / E[TP] → t/(1-t)，然后利用 FDR ~ E[FP]/(E[FP]+E[TP])。关键技巧：证明 MMLE ˆτ 恰好平衡了 FP 和 TP 的期望，使得 FDR 收敛到 t。

4. **FNR 下界：** 使用“sparsity preserving procedure”的概念（Proposition 2），引用 [3] 的 Theorem 3 得到 FNR ≥ Φ̄(b) + o(1)，与上界结合得到等式。

**技术技巧点名：**
- **Empirical process / 集中不等式：** 用于控制 MMLE 的集中性（Bernstein 不等式，Lemma A.4）。
- **积分展开与变量替换：** 用于 s-value 和 S-value 的渐近界（Lemma 6.1, A.6, A.15）。
- **Poisson-Binomial 的随机占优：** 用于控制 TP 和 FP 的集中性（Lemma S-25 in [3]）。
- **Jensen 不等式与凹性：** 用于将 FDR 的期望界转化为期望的比值（FDR ≤ E[FP]/(E[FP]+c s_n)）。
- **匹配常数集中性：** 通过分析边际似然导数的符号，得到 ˆτ 的精确渐近位置（Proposition 3），这是本文最精细的技术贡献。

#### 真实例子与应用

**1. 稀疏序列模型（Section 4.1）：**
- **数据：** n=10⁴, s_n=10（或 100），信号强度 μ 从 0 到 8 变化。
- **方法：** 使用 MMLE 估计 τ，通过 binary search 高效计算 s-value 阈值。
- **结果（Figure 2）：** s-value 程序的 FDR 始终接近 0（无论 μ 大小），TDR 在大信号时接近 1；S-value 程序的 FDR 接近目标水平 t（0.05, 0.1, 0.2），TDR 高于 s-value；Cs-value 程序的 FDR 略高于目标但接近；阈值法（Thresh）的 FDR 过大。
- **说明：** 验证了 Theorem 1（s-value 的保守性）和 Theorem 2（S-value 的精确 FDR 控制）。

**2. 高维线性回归（Section 4.2）：**
- **数据：** (n,p) = (3000,6000) 和 (5000,10000)，s=10,20,30,40,60,80，信号强度 μ ∈ [0,0.3]。设计矩阵包括独立（Σ=I）、AR(ρ) 和等相关系数（Σ_ρ）三种。
- **方法：** 使用 Mhorseshoe 包进行 hierarchical Bayes 采样（half-Cauchy 先验于 τ），从后验样本计算 s-value。
- **结果（Figures 3-4）：** 在独立设计下，s-value 和 Cs-value 的表现与序列模型定性一致。在相关设计下，FDR 控制仍然良好（略高于目标但可接受），TDR 略有下降。
- **说明：** 展示了方法在更复杂模型中的适用性，尽管理论仅覆盖序列模型。

**3. 高斯图模型（Section 4.3）：**
- **数据：** n=120, p=100,200，四种网络结构（随机、scale-free、hub）。
- **方法：** 使用 graphical horseshoe (GHS) 先验 [33] 进行后验采样，对每个精度矩阵元素计算 s-value。
- **结果（Tables 1-2）：** s-value 程序的 FDR 远低于目标水平（保守），Cs-value 程序的 FDR 接近目标。与 [27] 中报道的四种频率学派方法相比，本文方法在控制 FDR 的同时实现了可比的 TDR。
- **说明：** 展示了方法在非序列模型、不同先验（GHS）下的通用性。

**4. 附录中的额外模拟：**
- **Hierarchical Bayes（Figure 8）：** 使用 half-Cauchy 先验于 τ，结果与 MMLE 定性一致。
- **Spike-and-Slab LASSO 先验（Appendix C.4, Figures 18-21）：** 验证了 s-value 与 ℓ-value 的数值接近性，以及 S-value 与 q-value 的接近性。

#### 🔎 结论是否比证明窄

1. **Theorem 2 的 FDR 控制仅对边界信号 L₀^=[s_n;b] 严格证明。** 作者在 Remark 中声称可推广到更一般的信号形状（如 Θ_b^=），但未给出完整证明。模拟中使用的信号强度范围（μ 从 0 到 8）远宽于边界条件，但理论保证仅覆盖边界情形。

2. **Cs-value 程序无理论保证。** 作者明确声明“we do not consider theory for the Cs–value procedure”，仅基于 [2] 的类比推测 Theorem 2 也成立。然而模拟中 Cs-value 的 FDR 有时略高于目标水平（Figure 2, Tables 1-2），这与推测不完全一致。

3. **理论仅覆盖序列模型。** 线性回归和图模型的模拟结果良好，但作者承认“This goes beyond the scope of the present work”。Theorem 1 和 2 的证明强烈依赖于坐标独立性和噪声方差已知，推广到回归模型需要处理设计矩阵的相关性和未知噪声方差。

4. **MMLE 的集中性证明依赖于信号强度条件。** Proposition 1 和 3 的证明使用了 L₀[s_n;b] 类中信号至少为 √[2 log(n/s_n)] + b 的条件。对于更弱的信号（如 O(1) 量级），ˆτ 的集中性可能不成立。

5. **S-value 的 FDR 控制要求 t ≤ 1/2。** 这是 Theorem 2 的明确条件。对于 t > 1/2，理论不覆盖，但模拟中 t=0.2 表现良好。

### 四、开放问题

1. **Cs-value 程序的理论保证。** 作者推测 Theorem 2 对 Cs-value 也成立，但未证明。扎根于 Section 3.3 末尾：“we do not consider theory for the Cs–value procedure... we do recommend it in practice though”。要证明这一点，需要处理“双重经验”（s-value 本身是经验的，Cs-value 的阈值也是经验的）带来的技术复杂性，可能需借鉴 [2] 中 Cℓ-value 的证明思路。

2. **高维线性回归与图模型的理论推广。** 模拟显示方法在回归和图模型中表现良好，但理论仅覆盖序列模型。扎根于 Section 5：“A very natural setting to derive further theory would be high-dimensional linear regression... a minimax multiple testing framework for this setting has not yet been investigated”。这需要建立回归模型下的 minimax 检验边界（类比 [3]），并处理设计矩阵相关性和未知噪声方差带来的技术困难。

3. **其他连续收缩先验的理论。** 作者推测结果对 SSL 先验 [40] 和 Dirichlet-Laplace 先验 [9] 也成立，但未证明。扎根于 Section 5：“We conjecture that all the results of the paper remain valid for example for the Spike and Slab LASSO prior”。验证这一猜想需要为每个先验建立类似 Lemma 6.2 和 A.6 的积分估计。

4. **弱信号区域的 FDR 控制。** Theorem 2 的 FDR 控制仅对边界信号（强度 ≥ √[2 log(n/s_n)] + b）证明。对于更弱的信号（如 O(1) 量级），FDR 可能低于目标水平（保守），但理论未刻画这一过渡区域。扎根于 Theorem 2 的 Remark：“the arguments go through as soon as the optimality quantity Λ_n(b) has a limit”。这需要研究 Λ_n(b) 在弱信号区域的渐近行为。

5. **Hierarchical Bayes 的理论等价性。** 作者使用 MMLE 进行理论分析，但模拟中也使用 hierarchical Bayes（half-Cauchy 先验于 τ）。扎根于 Section 2.7：“one can expect the results in Section 3 to go through as well for the HB approach”。要严格证明这一点，需要建立后验分布中 τ 的集中性（类似于 [49] 中关于 posterior contraction 的结果），并证明其与 MMLE 的渐近等价性。
