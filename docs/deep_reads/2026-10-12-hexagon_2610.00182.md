### 一、领域脉络与小综述

#### 这个方向是什么

本文处于**代数表示论与同调代数的交叉地带**，核心研究对象是有限维代数的两个同调不变量：**Hochschild 同调**（`HH_n(A/k)`，衡量代数的"非交换微分形式"结构）与**整体维数**（`gldim A`，衡量代数的同调复杂度）。Han 猜想（2006，[4]）断言：对有限维代数，若其 Hochschild 同调从某阶起全部消失（eventual vanishing），则整体维数必然有限。这个猜想若成立，将给出一个用同调不变量判定代数"良结构"的简洁准则；本文则通过构造反例，证明该猜想在**任意域**上不成立。

#### 发展脉络（history）

- **奠基工作**：Han 本人在 2006 年提出该猜想（[4]），其动机来自对有限维代数 Hochschild（上）同调维数的系统研究。猜想的直观背景是：Hochschild 同调的消失应反映代数的"光滑性"或"有限性"，而整体维数有限正是这种性质的经典刻画。
- **主要进展**：Kong–Liu–Shen（[6]）在复数域 ℂ 上构造了第一个反例，其核心策略是**从 phantom category（幻影范畴）出发**——一个非零的、Hochschild 同调全消失的三角范畴——再通过取 endomorphism algebra 将其"实现"为一个有限维代数。Liu–Shen（[7]）进一步给出一个显式的三顶点代数（three-vertex algebra），带有非满的例外三元组（nonfull exceptional triple），在特征零情形下验证了反例。
- **当前 frontier**：本文（Tang, 2026）的贡献在于**消除特征限制**。Kong–Liu–Shen 和 Liu–Shen 的构造在特征 2、3、5、7 处因例外对象自同态环的退化而失效（具体表现为某些扩展群的维数发生跳变）。Tang 通过为这四个特征分别设计新的输入数据（替换例外三元组），将反例推广到**任意域**。
- **本文的位置**：这是对 Han 猜想的**最终否定**——不是"在某个域上不成立"，而是"在任何域上都不成立"。作者明确表示不主张所有权，欢迎他人整理正式版本。

#### 子线索聚类

1. **反例构造线索**（[6], [7], 本文）：核心思路是"范畴层面构造 → 代数层面实现"。先在一个三角范畴（如 singularity category）中找到 Hochschild 同调消失但非零的对象，再通过 endomorphism algebra 将其转化为有限维代数。这条线索的关键技术是 **phantom category** 与 **exceptional collection** 的理论。
2. **同调不变量与 singularity category 的桥梁**（[1], [2], [9]）：这条线索提供将范畴层面的性质转化为代数层面性质的工具。Chen（[1]）的 partial resolution theorem 和 Chen–Wang（[2]）的 dg enhancement 比较定理，以及 Wang–Arunachalam–Keller（[9]）关于 singularity category 的 Hochschild 同调与代数本身的 Hochschild 同调之间的转移公式（`HH_n(D_sg(A)) ≅ HH_{n-1}(A/k)`），是本文证明的核心支柱。
3. **计算与验证线索**（本文附录）：通过整数 Smith 标准型和有限域上的秩计算，精确控制扩展群的维数。这是本文区别于前作的技术亮点——用计算手段处理特征依赖问题。

#### 这个方向在追问的核心问题

1. **Han 猜想的真伪**：eventual vanishing of Hochschild homology 到底能否推出有限整体维数？本文给出否定答案。
2. **反例的最小复杂度**：构造反例需要多大的代数？本文给出的代数维数高达 10786/10787，这是否是最小维度？
3. **特征依赖的本质**：为什么某些特征会破坏特征零的构造？例外对象的自同态环在特殊特征下的退化机制是什么？

#### ⚠️ 作者的 framing（这是作者的说法）

作者将本文定位为"基于 Kong–Liu–Shen 和 Liu–Shen 的构造，在任意域上给出 Han 猜想反例"。他明确承认**核心构造不是原创**，而是对已有工作的**特征依赖修补**。作者在引言中写道："We use their ungraded input and construct replacements for its exceptional triple in the four characteristics where direct reduction fails."——即他的贡献仅限于为特征 2、3、5、7 找到替代的例外三元组。作者还特别声明"不寻求所有权"，欢迎他人整理正式版本，这暗示他认为本文的贡献是**技术性的而非概念性的**。

#### 张力

未见明显对立引用。所有被引工作（[1], [2], [4], [6], [7], [9]）在方法论上是一致的：都认可 phantom category 与 singularity category 是构造反例的正确工具。唯一的内部张力是**特征依赖问题**——[6] 和 [7] 的构造在特殊特征下失效，而本文修补了这一缺陷，但这属于"继承中的修补"而非"对立中的突破"。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据交代清楚

**符号清单**（逐个点名）：

| 记号 | 含义 | 类型 |
|------|------|------|
| `k` | 任意域 | 基础对象 |
| `A` | 有限维酉结合 `k`-代数 | 研究对象 |
| `HH_n(A/k)` | `Tor_{A⊗_k A^op}^n(A,A)`，Hochschild 同调 | 不变量（要证明其消失） |
| `gldim A` | 整体维数 | 不变量（要证明其为无穷） |
| `Q` | 三顶点箭图，顶点 1,2,3，箭头 `a_1..a_4: 1→2`，`b_1..b_5: 2→3` | 组合数据 |
| `R = kQ/(ρ_1,...,ρ_7)` | 三顶点代数，由 7 个二次关系定义 | 核心代数 |
| `E, F, G` | 三个左 `R`-模，维数向量 (3,2,1), (1,1,1), (1,2,4) | 例外三元组 |
| `Γ = R^op` | `R` 的反环 | 技术工具 |
| `Perf(Γ)` | 完美复形范畴 | 范畴环境 |
| `P = E^⊥` | 例外三元组的右正交 | 关键对象（phantom） |
| `Λ = Γ ⊗_k k[ε]/(ε²)` | 加平方零元素的代数 | 折叠工具 |
| `A_k = End_Λ(M)` | 最终反例代数 | 目标对象 |
| `M` | 折叠构造的 Λ-模 | 中间对象 |

**模型（数据生成机制）**：

1. **输入**：一个三顶点箭图 `Q`，带 7 个二次关系 `ρ_1..ρ_7`，定义代数 `R`。`R` 的维数为 25（3 个顶点幂等元 + 9 个箭头 + 13 个长度 2 路径模关系）。
2. **例外三元组**：三个左 `R`-模 `E, F, G`，满足 split exceptional 条件（`Hom(E_i, E_i[n]) = k` 当 `n=0`，否则为 0；`Hom(E_j, E_i[n]) = 0` 当 `j > i`）。
3. **右正交**：`P = E^⊥` 是 `Perf(Γ)` 中与 `E, F, G` 正交的对象的全子范畴。非满性（nonfullness）意味着 `P ≠ 0`。
4. **折叠**：取 `Λ = Γ ⊗_k k[ε]/(ε²)`，构造 `M = Λ ⊕ N_E ⊕ N_F ⊕ N_G`，其中 `N_X` 是 `X` 的折叠（folding）——将 `X` 的投射分解与 `ε` 的作用结合。
5. **输出**：`A_k = End_Λ(M)`，一个有限维代数。

**可观测数据**：研究者可以观测到的是 `R` 的关系矩阵（7×20 整数矩阵）、`E, F, G` 的表示矩阵（附录 A 中列出）、以及通过 Smith 标准型计算出的扩展群维数。**不可直接观测**的是 `P` 的内部结构——只能通过 `HH_0` 的计算间接推断其非零性。

#### 第二步：最小内核

**核心命题**（剥去所有技术细节后的最小内核）：

> **存在一个有限维代数 `A`，使得 `HH_n(A/k) = 0` 对所有 `n ≥ 1`，但 `gldim A = ∞`。**

**为什么这看起来不可能**：对"好"的代数（如有限整体维数的代数），Hochschild 同调在高于整体维数的阶数自动消失。反过来，如果 Hochschild 同调从某阶起全消失，直觉上代数应该"接近"有限整体维数。Han 猜想正是把这个直觉形式化。

**最小例子（为什么构造是必要的）**：

考虑最简情形：`A = k[x]/(x²)`（dual number）。则：
- `HH_0(A) = k`，`HH_1(A) = k`，`HH_n(A) = 0` 对 `n ≥ 2`。
- `gldim A = ∞`（因为 `k` 作为 `A`-模有无限投射分解）。

这个例子**不构成反例**，因为 `HH_1 ≠ 0`。Han 猜想要求的是**所有正阶**同调消失，而不仅仅是高阶消失。这个例子说明：要构造反例，必须让 `HH_1` 也消失，同时保持整体维数无穷。

**核心困难**：`HH_1` 的消失意味着代数的"非交换微分"结构完全消失。对有限维代数，这通常暗示代数"太简单"（如半单），而半单代数必然有有限整体维数。要打破这个循环，需要借助范畴层面的工具——这就是 phantom category 的用武之地。

**最小内核的证明思路**（三步走）：

1. **范畴层面**：构造一个非零三角范畴 `P`，使得 `HH_*(P) = 0`。这通过取例外三元组的右正交实现——非满性保证 `P ≠ 0`，而例外性保证 `P` 的 Hochschild 同调消失。
2. **代数层面**：通过折叠构造，将 `P` 实现为某个代数 `A` 的 singularity category 的组成部分。具体地，`D_sg(A) ≃ Perf(P ⊗_k k[t,t⁻¹])`。
3. **转移**：利用 Wang–Arunachalam–Keller 的公式 `HH_n(D_sg(A)) ≅ HH_{n-1}(A/k)`，从 `HH_*(P) = 0` 推出 `HH_n(A/k) = 0` 对所有 `n ≥ 1`。同时，`P ≠ 0` 意味着 `D_sg(A) ≠ 0`，从而 `gldim A = ∞`。

**为什么特征是个问题**：在特征 0 下，[7] 的输入数据工作良好。但在特征 2、3、5、7 下，某些扩展群 `Ext^1` 或 `Ext^2` 的维数会因整数矩阵的 Smith 标准型中某些项被特征整除而改变，导致例外性条件被破坏。本文的贡献就是为这四个特征分别找到新的输入数据，使得例外性在模 `p` 后仍然成立。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：Han 猜想（有限维代数的 Hochschild 同调 eventual vanishing 蕴含有限整体维数）是否在任意域上成立。
2. **核心工具/方法**：基于 Kong–Liu–Shen 和 Liu–Shen 的 phantom category 构造，通过为特征 2、3、5、7 设计替代的例外三元组，消除特征依赖。
3. **主要结论**：对**每个域** `k`，存在有限维代数 `A_k`，满足 `HH_n(A_k/k) = 0`（`n ≥ 1`）且 `gldim A_k = ∞`。反例的维数为 10787（特征 2、43）或 10786（其他特征）。

#### 关键设定与假设

**设定**：

- `Q` 为三顶点箭图，顶点 1,2,3，箭头 `a_1..a_4: 1→2`，`b_1..b_5: 2→3`。
- `R = kQ/(ρ_1,...,ρ_7)`，其中 `ρ_ℓ = Σ_{j,i} r_{ℓji} b_j a_i`，`r_{ℓji}` 为整数系数，构成 7×20 矩阵。
- 三个左 `R`-模 `E, F, G`，维数向量分别为 (3,2,1), (1,1,1), (1,2,4)。

**假设**（逐条说明）：

1. **`R` 的秩为 7**：关系矩阵在任意特征下秩为 7，保证 `dim R = 25`。
2. **`(E, F, G)` 是 split exceptional collection**：即 `Hom(E_i, E_i[n]) = k` 当 `n=0`，否则为 0；`Hom(E_j, E_i[n]) = 0` 当 `j > i` 且任意 `n`。这保证右正交 `P` 是 admissible 子范畴。
3. **非满性**：`P ≠ 0`，即例外三元组不生成整个 `Perf(Γ)`。这是通过 `HH_0` 的计算验证的——`dim HH_0(B) > 1` 意味着 `P` 非零。
4. **`HH_*(P) = 0`**：右正交的 Hochschild 同调全消失。这是通过构造保证的——`P` 由 `E, F, G` 的右正交生成，而例外性使得其 Hochschild 同调为零。

**相比已有工作的变化**：

- 相比 [6]（ℂ 上构造），本文覆盖任意域。
- 相比 [7]（特征 0 的显式构造），本文为特征 2、3、5、7 提供新的输入数据。
- 相比 [9]（转移公式），本文将其作为黑箱工具使用，未做修改。

#### 主要结果

**定理 1.1**（核心定理）：对每个域 `k`，存在有限维酉结合 `k`-代数 `A_k`，使得：
- `HH_n(A_k/k) = 0` 对所有 `n ≥ 1`；
- `gldim A_k = ∞`。

**维度公式**：
```
dim A_k = 10787, 若 char k ∈ {2, 43}
          10786, 若 char k ∉ {2, 43}
```

**证明结构**（五步）：

1. **构造 `R` 和 `E, F, G`**（第 2 节）：定义三顶点代数 `R` 和三个模，验证其满足例外性条件。
2. **计算扩展群**（第 3 节）：通过 Smith 标准型和有限域秩计算，确定所有扩展群 `Ext^n(X, Y)` 的维数。关键结果：在特征 2、43 下，`Ext^2(F, G)` 的维数从 7 变为 8；在特征 2 下，`Ext^1(E, F)` 的维数从 5 变为 6。
3. **验证非满性**（第 4 节）：计算 `HH_0(B)`，其中 `B` 是例外三元组的 endomorphism 代数。`dim HH_0(B) = 1 + dim Ext^2(E,F) · dim Ext^2(F,G) · dim Ext^2(E,G) > 1`，从而 `P ≠ 0`。
4. **折叠构造**（第 5 节）：将 `E, F, G` 的投射分解折叠为 `Λ = Γ ⊗_k k[ε]/(ε²)` 上的模，取 `M = Λ ⊕ N_E ⊕ N_F ⊕ N_G`，令 `A_k = End_Λ(M)`。
5. **转移论证**（第 6 节）：利用 [9] 的公式 `HH_n(D_sg(A)) ≅ HH_{n-1}(A/k)`，从 `HH_*(P) = 0` 推出 `HH_n(A_k/k) = 0`；从 `P ≠ 0` 推出 `gldim A_k = ∞`。

**技术技巧点名**：

- **Smith 标准型**：用于计算整数矩阵的秩和不变因子，确定扩展群维数在模 `p` 下的行为。
- **有限域秩证书**：通过构造 `H` 矩阵（满足 `M = M[:,J]H`）和验证 `det M[I,J] ≠ 0`，给出秩的精确下界。
- **最小模型（minimal model）**：用于构造 `E` 的 A∞ 代数结构，验证例外性条件。
- **dg 增强（dg enhancement）**：用于将范畴层面的 Hochschild 同调与代数层面的 Hochschild 同调联系起来。
- **Vogel 范畴**：用于处理 dg 商范畴的模型，证明折叠构造与 singularity category 的等价性。
- **Künneth 谱序列**：用于计算 `Perf(P ⊗_k U)` 的 Hochschild 同调。

#### 真实例子与应用

**本文为纯理论论文，无真实数据应用**。但包含一个重要的"计算实验"维度：

- **附录 A** 列出了五组输入数据（特征 0、2、3、5、7），每组包含 `R` 的关系矩阵和 `E, F, G` 的表示矩阵。
- **附录 B** 提供了一个 Python 程序（使用 SymPy），用于验证：
  - 关系矩阵的秩为 7；
  - 模满足例外性条件；
  - 扩展群维数与论文声称一致。
- **验证方式**：程序计算整数 Smith 标准型和有限域秩，输出扩展群维数表。论文声称"ALL FIVE INPUTS AND THE INTEGER SMITH TABLE VERIFIED"。

**这个例子的意义**：它展示了**计算辅助证明**在纯数学中的应用——不是用计算机证明定理，而是用计算机验证构造的正确性，从而将人工验证的工作量降到最低。

#### 🔎 结论是否比证明窄

**是，存在明显的"证明-结论"差距**：

1. **定理 1.1 声称"每个域"**，但证明中对于特征 2、3、5、7 的验证依赖于附录 B 的 Python 程序。虽然程序是确定性的（整数运算），但论文没有给出人工可验证的完整证明，而是依赖"程序输出正确"这一信任假设。作者在附录 B 中写道："The finite computations enter the proof only through Proposition 3.1."——这暗示计算是证明的必要组成部分。

2. **维度公式的奇异性**：特征 2 和 43 时维数为 10787，其他特征为 10786。作者没有解释为什么恰好是这两个特征导致维度增加，也没有说明这是否是构造的偶然性质。

3. **`HH_0(B) > 1` 的证明**：第 4 节通过计算 `dim HH_0(B)` 来证明非满性，但论文没有给出 `HH_0(B)` 的完整计算过程，而是直接引用附录 B 的程序输出。对于不信任程序验证的读者，这个证明是不完整的。

4. **作者明确声明不主张所有权**："By posting this manuscript on this platform, I do not seek to assert ownership of the results or claim priority."——这暗示作者自己也不认为这是最终版本，可能存在未发现的错误或需要完善的地方。

### 四、开放问题

1. **最小维度问题**：本文给出的反例维度为 10786/10787，这是否是最小维度？是否存在更小的反例？这扎根于定理 1.1 的维度公式——作者没有讨论最优性。

2. **特征依赖的本质**：为什么恰好是特征 2、3、5、7 需要特殊处理？这些特征与例外三元组的自同态环的退化有何具体联系？作者在引言中仅说"direct reduction fails"，未给出机制性解释。

3. **构造的普适性**：本文的构造依赖于特定的三顶点箭图和关系矩阵。是否存在系统性的方法，从任意 phantom category 出发构造反例？这扎根于 [6] 和 [7] 的构造框架，但本文未给出一般化方案。

4. **`HH_0(B)` 的精确计算**：第 4 节中 `dim HH_0(B) = 1 + dim Ext^2(E,F) · dim Ext^2(F,G) · dim Ext^2(E,G)` 的公式是否对所有特征成立？在特征 2、43 下，`Ext^2(F,G)` 的维数变化如何影响 `HH_0(B)`？作者未给出详细推导。

5. **验证程序的独立性**：附录 B 的 Python 程序是唯一的验证手段。是否存在不依赖计算的人工可验证证明？这扎根于作者"欢迎他人整理正式版本"的声明。
