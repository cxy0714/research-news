### 一、领域脉络与小综述

#### 这个方向是什么

本文研究的根本问题是：**如何对非平稳时间序列进行结构性分类**。具体而言，给定两类由不同机制生成的、具有时变二阶统计特性（如时变自协方差函数）的局部平稳时间序列，我们希望设计一个分类器，使得当两类序列的二阶特性仅存在轻微差异时，分类错误率仍能渐近趋于零。该问题的核心挑战在于：序列的非平稳性使得传统的平稳时间序列分类方法（如基于谱密度或AR系数估计的方法）不再适用，而需要发展能够捕捉时变二阶结构的新方法。当前该子方向的成熟度处于**理论框架初步建立、但应用与推广空间仍大**的阶段——本文建立在Ding和Zhou (2023)的AR逼近理论基础之上，但将目标从估计与推断转向了分类任务。

#### 发展脉络

**奠基工作：局部平稳过程的理论框架。** 这一子方向的根基是Dahlhaus (2012)对局部平稳过程的系统综述，以及Dahlhaus et al. (2019)与Wu (2005)对非线性局部平稳过程的物理依赖度量的推广。这些工作确立了局部平稳过程的基本定义——即过程在每一时刻附近可以被一个平稳过程局部逼近，且其谱密度或自协方差函数随时间平滑变化。Dahlhaus et al. (2019)与Wu (2005)进一步引入了物理依赖度量（physical dependence measure），为量化非平稳过程的短程依赖性提供了工具。

**关键突破：AR逼近定理。** 本文的核心理论支柱是Ding和Zhou (2023)建立的AR逼近定理。该定理表明，任何满足一定条件的局部平稳过程都可以被一个时变AR过程在$L^2$意义下以可控制的误差逼近，且AR阶数$b$可以随样本量$n$缓慢增长。这一结果的重要性在于：它将非平稳过程的复杂二阶结构简化为有限维的时变AR系数函数$\phi_j(t)$，从而使得基于AR系数函数的统计推断成为可能。Ding和Zhou (2025)进一步研究了局部平稳过程的偏自相关函数（PACF）的估计与推断，为本文的特征构造提供了理论支撑。

**分类方法的谱系。** 在分类方法层面，本文引用的工作可分为几个谱系。一是基于距离度量的方法，如动态时间规整（DTW）及其变体（Jeong et al., 2011; Kate, 2016; Marteau, 2007），这类方法直接度量时间序列之间的相似性，但缺乏理论保证。二是基于特征提取的方法，如Rocket及其变体（Dempster et al., 2020; Tan et al., 2022; Dempster et al., 2023），通过随机卷积核提取特征后接线性分类器，计算效率高但特征构造缺乏统计解释。三是基于树的方法，如STSForest（Cabello et al., 2020）和Shapelet（Lines et al., 2012），通过监督区间搜索提取判别特征。四是基于深度学习的方法（Ismail Fawaz et al., 2019; Sherstinsky, 2020），如TimeCNN和TimeRNN，虽然灵活但缺乏理论保证且计算成本高。五是基于谱的方法，如LSW（Fryzlewicz和Ombao, 2009; Krzemieniewska et al., 2014）和DWT（Maharaj和Alonso, 2007），这些方法利用小波变换提取时频特征，但主要针对平稳或弱非平稳序列。

**本文的位置。** 本文的定位是：**在Ding和Zhou (2023)的AR逼近理论基础上，首次为局部平稳时间序列的二阶结构分类提供了严格的理论保证**。与上述方法相比，本文的方法具有三个显著特点：(i) 特征构造基于时变AR系数函数的最大偏差，具有明确的统计解释；(ii) 理论证明表明，当两类序列的二阶特性仅轻微差异时，分类错误率渐近为零；(iii) 方法不要求训练样本量$N_1, N_2$趋于无穷，而是允许$N_1 = N_2 = 1$（即每类仅一条长序列），这更符合实际应用场景。

#### 子线索聚类

被引文献大致可归为以下四条子线索：

1. **局部平稳过程的理论基础**（Dahlhaus, 2012; Dahlhaus et al., 2019; Wu, 2005; Vogt, 2012; Zhou和Wu, 2009）：建立局部平稳过程的定义、物理依赖度量、以及估计与推断的基本理论。这条线索为本文提供了模型框架和依赖度量工具。

2. **AR逼近与PACF推断**（Ding和Zhou, 2020, 2023, 2025）：建立局部平稳过程的AR逼近定理，发展基于Yule-Walker方程的PACF估计与推断方法。这条线索是本文方法的直接理论来源。

3. **通用时间序列分类方法**（Dempster et al., 2020; Tan et al., 2022; Dempster et al., 2023; Cabello et al., 2020; Lines et al., 2012; Ismail Fawaz et al., 2019; Sherstinsky, 2020; Marteau, 2007; Jeong et al., 2011; Kate, 2016）：涵盖基于距离、特征、树、卷积和深度学习的各类分类方法。本文在数值实验中将这些方法作为基准进行比较。

4. **谱域分类方法**（Fryzlewicz和Ombao, 2009; Krzemieniewska et al., 2014; Maharaj和Alonso, 2007; Sakiyama和Taniguchi, 2004; Huang et al., 2004）：利用小波或谱表示提取时频特征进行分类。这条线索与本文的时域方法形成对比。

#### 这个方向在追问的核心问题

1. **如何从有限长度的非平稳序列中可靠地估计时变二阶结构？** 当前主流方法是局部平稳过程的AR逼近（Ding和Zhou, 2023），但AR阶数$b$和基函数个数$c$的选择缺乏统一准则，且对强非平稳序列的逼近误差控制仍不完善。

2. **如何设计具有最优分类精度的特征？** 本文采用时变AR系数函数的最大偏差作为特征，但这一选择是否在minimax意义下最优，尚未得到回答。

3. **如何处理高维与多通道数据？** 本文仅考虑单变量时间序列，但EEG等实际应用通常涉及多通道信号。将本文方法推广到多变量局部平稳时间序列，需要处理通道间依赖结构的建模与分类，这是一个开放问题。

4. **如何应对类别不平衡与训练样本量有限的问题？** 本文的方法不要求训练样本量大，但数值实验显示在类别不平衡时性能有所下降（见Figure 3(b)），如何从理论上刻画这种下降并设计鲁棒的阈值选择方法，仍有待研究。

#### ⚠️ 作者的 framing

**这是作者的说法**：作者将本文定位为"基于二阶时域特征的局部平稳时间序列结构性分类"的首个严格理论框架。作者在引言中强调，现有局部平稳时间序列分类方法要么缺乏理论保证（如深度学习、Rocket类方法），要么仅适用于平稳序列（如谱域方法），而本文通过AR逼近理论为分类任务提供了"可解释、可验证、计算高效"的解决方案。作者特别指出，本文方法的核心优势在于"不要求训练样本量"，即$N_1 = N_2 = 1$即可实现渐近零错误率，这在实际应用中（如单患者EEG分类）具有重要价值。

**值得注意的淡化**：作者在引言中未充分讨论本文方法的一个潜在局限——当两类序列的差异主要体现在高阶矩（如偏度、峰度）而非二阶矩时，本文方法将失效。此外，作者对深度学习方法的批评（"特征构造可能缺乏统计解释"）在某种程度上回避了深度学习方法在复杂模式识别中的实际优势。

#### 张力

被引工作之间未见明显对立结论。但存在一个值得注意的张力：Ding和Zhou (2023)的AR逼近理论要求序列的时变参数满足一定的光滑性条件（如Lipschitz连续），而实际应用中（如EEG信号）的时变结构可能并不光滑。本文的理论框架继承了这一假设，但未讨论当光滑性条件不满足时方法的鲁棒性。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

**符号清单**（按类别分组）：

| 符号 | 含义 | 类别 |
|------|------|------|
| $z = (z_i)_{i=1}^n \in \mathbb{R}^n$ | 单条长度为$n$的时间序列 | 可观测数据 |
| $x_{k_1} \in \mathbb{R}^{n_{k_1}}$，$y_{k_2} \in \mathbb{R}^{m_{k_2}}$ | 第$k_1$条类别1序列、第$k_2$条类别2序列 | 可观测数据 |
| $N_1, N_2$ | 类别1、类别2的训练序列条数 | 样本量指标 |
| $b$ | AR逼近的阶数 | 模型参数（需选择） |
| $c$ | 基函数个数 | 模型参数（需选择） |
| $\phi_j(t)$，$j=1,\ldots,b$ | 时变AR系数函数，$t \in [0,1]$ | 参数（目标估计量） |
| $\alpha_\ell(t)$，$\ell=1,\ldots,c$ | 基函数（如Legendre多项式） | 已知函数 |
| $a_{j\ell}$ | 基函数展开系数 | 参数（需估计） |
| $\epsilon_i$ | 时变白噪声 | 随机误差 |
| $\gamma(t, k)$ | 时变自协方差函数：$\gamma(t, k) = \text{Cov}(z_{\lfloor tn \rfloor}, z_{\lfloor tn \rfloor + k})$ | 参数（目标特征） |
| $\Gamma_b(t)$ | $b \times b$ Toeplitz矩阵，$[\Gamma_b(t)]_{\ell_1 \ell_2} = \gamma(t, \lvert \ell_1 - \ell_2 \rvert)$ | 参数（目标特征） |
| $\Omega_b(t) = [\Gamma_b(t)]^{-1}$ | 精度矩阵 | 参数（目标特征） |
| $D(j)$ | 最大偏差特征：$D(j) = \sup_{t_1, t_2 \in [0,1]} \lvert \hat{\phi}_j(t_1) - \hat{\phi}_j(t_2) \rvert$ | 估计量（分类特征） |
| $S_k$ | 聚合特征：$S_k = \sup_{\max\{b_k - b^* + 1, b^*\} \leq j \leq b_k} D_k(j)$ | 估计量（分类特征） |
| $\vartheta$ | 分类阈值 | 参数（需选择） |
| $\tau$ | 物理依赖度量中的衰减指数（$\delta(j,q) = O(j^{-\tau})$） | 假设参数 |
| $d$ | 自协方差函数的光滑度（$\gamma(t,\cdot) \in C^d([0,1])$） | 假设参数 |

**模型**（数据生成机制）：

1. **局部平稳过程**（定义1）：序列$z = (z_i)_{i=1}^n$满足
   $$\text{Cov}(z_i, z_j) = \gamma(t_i, |i-j|) + O\left(\frac{|i-j|+1}{n}\right), \quad t_i = \frac{i}{n},$$
   其中$\gamma(t, \cdot)$对每个$t$是一个平稳过程的自协方差函数，且$\gamma(\cdot, k)$在$t$上Lipschitz连续。

2. **物理表示**（公式15）：$z_i = G(i/n, \mathcal{F}_i)$，其中$\mathcal{F}_i = (\ldots, \xi_{i-1}, \xi_i)$是独立同分布随机变量的历史，$G$是可测函数，且满足矩条件（16）。

3. **AR逼近**（公式1）：对任意局部平稳过程，存在时变AR($b$)过程逼近：
   $$z_i = \sum_{j=1}^{b} \phi_j\left(\frac{i}{n}\right) z_{i-j} + \epsilon_i + o_{L^2}(1),$$
   其中$\phi_j(t)$是光滑函数，$b$随$n$缓慢增长。

4. **基函数展开**（公式2）：$\phi_j(t) = \sum_{\ell=1}^{c} a_{j\ell} \alpha_\ell(t) + O(c^{-d})$，其中$\{\alpha_\ell\}$是基函数（如Legendre多项式），$d$是光滑度。

**可观测数据**：训练集包含$N_1$条类别1序列$\{x_{k_1}\}_{1 \leq k_1 \leq N_1}$和$N_2$条类别2序列$\{y_{k_2}\}_{1 \leq k_2 \leq N_2}$，每条序列长度分别为$n_{k_1}$和$m_{k_2}$。测试集包含$N_3$条未标记序列$\{z_{k_3}\}_{1 \leq k_3 \leq N_3}$。

**关键区分——可观测 vs. 潜在**：
- **可观测**：每条时间序列的原始观测值$z_i$；每条序列的类别标签（训练集）。
- **潜在/不可观测**：时变AR系数函数$\phi_j(t)$（只能通过估计获得）；两类序列的"真实"二阶结构差异（只能通过特征推断）；物理依赖度量$\delta(j,q)$（理论工具，不可直接观测）。

#### 第二步：最小内核

**核心命题（最小形式）**：假设我们有两类局部平稳时间序列，其自协方差函数分别为$\gamma_1(t, k)$和$\gamma_2(t, k)$。如果这两类序列在二阶结构上存在差异，即存在某个滞后$k$和时间点$t$使得$\gamma_1(t, k) \neq \gamma_2(t, k)$，那么能否仅基于每条序列的有限观测，构造一个分类器使得分类错误率渐近为零？

**为什么这个问题非平凡**：对于平稳时间序列，二阶结构完全由自协方差函数$\gamma(k)$决定，且$\gamma(k)$可以被一致地估计。但对于局部平稳序列，$\gamma(t, k)$同时依赖于时间和滞后，估计误差包含两个来源：(i) 时间方向的非平稳性导致的偏差；(ii) 有限样本导致的方差。当两类序列的$\gamma_1(t, k)$和$\gamma_2(t, k)$仅轻微差异时，这两个误差来源可能淹没真实的差异信号。

**本文的核心思想（三步走）**：

1. **特征提取**：对每条序列，使用时变AR逼近估计AR系数函数$\hat{\phi}_j(t)$，然后计算最大偏差特征$D(j) = \sup_{t_1,t_2} |\hat{\phi}_j(t_1) - \hat{\phi}_j(t_2)|$。这个特征度量了AR系数在时间上的波动程度，反映了序列的二阶结构非平稳性。

2. **特征聚合**：对每条序列，取$S = \sup_{\max\{b-b^*+1,b^*\} \leq j \leq b} D(j)$，即所有滞后中最大偏差的最大值。这个聚合特征捕捉了序列二阶结构中最显著的非平稳特征。

3. **阈值分类**：比较测试序列的$S$值与训练集得到的阈值$\vartheta$，若$S > \vartheta$则归为类别1，否则归为类别2。

**为什么这个思想有效（直觉）**：定理1表明，$D^*(j)$（$D(j)$的总体版本）可以表示为自协方差函数$\gamma(t, \cdot)$在时间方向上的最大偏差的线性组合。因此，如果两类序列的$\gamma_1(t, k)$和$\gamma_2(t, k)$在时间方向上的波动模式不同，那么它们的$D^*(j)$就会不同。定理2进一步表明，当两类序列的$D^*(j)$差异足够大时（条件29），估计误差可以被控制，从而分类错误率渐近为零。

**最小例子**：考虑两类时变AR(1)模型：
- 类别1：$x_i = a_1(i/n) x_{i-1} + \epsilon_i$，其中$a_1(t) = 0.5 + 0.3\sin(2\pi t)$
- 类别2：$y_i = a_2(i/n) y_{i-1} + \epsilon_i$，其中$a_2(t) = 0.5 + 0.3\cos(2\pi t)$

两类序列的AR系数函数具有相同的振幅（0.3）但不同的相位。对于类别1，$D^*(1) = \sup_{t_1,t_2} |a_1(t_1) - a_1(t_2)| = 0.6$；对于类别2，$D^*(1) = 0.6$。在这个例子中，两类序列的$D^*(1)$相同，因此本文的方法无法区分它们。但如果类别2的$a_2(t) = 0.5 + 0.1\cos(2\pi t)$，则$D^*(1) = 0.2$，两类序列可以被区分。这个例子说明，本文方法的核心判别能力取决于两类序列在"AR系数时间波动幅度"上的差异。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：本文研究了基于二阶时域特征的局部平稳时间序列二分类问题，目标是在两类序列的二阶特性仅轻微差异时实现渐近零分类错误率。
2. **核心工具/方法**：本文利用Ding和Zhou (2023)的时变AR逼近理论，构造基于AR系数函数最大偏差的判别特征，结合集成聚合和距离阈值进行分类。
3. **主要结论**：在温和条件下，本文方法在训练样本量$N_1 = N_2 = 1$时即可实现渐近零分类错误率，且在数值模拟和EEG数据分类中优于多种现有方法。

#### 关键设定与假设

**设定**：
- 两类局部平稳时间序列，每类$N_g$条（$g = 1, 2$），每条长度$n_g$。
- 序列满足物理表示（15）和物理依赖度量衰减条件（18）。
- AR逼近阶数$b$和基函数个数$c$通过交叉验证选择。

**假设**（在第二节符号基础上补全）：
- **假设1**（物理依赖度量）：$\delta(j,q) \leq C j^{-\tau}$，$\tau > 1$。这保证了序列的短程依赖性，使得局部估计可行。
- **假设2**（光滑性）：自协方差函数$\gamma_g(t, \cdot) \in C^{d_g}([0,1])$，$d_g \geq 1$。这保证了AR系数函数可以用基函数以$O(c^{-d_g})$的误差逼近。
- **条件（28）**：$b_g c_g (\xi_{c_g}^2 / \sqrt{n_g} + \xi_{c_g}^2 n_g^{2/(\tau_g+1)} / n_g) = o(1)$。这保证了AR系数估计的一致性。
- **条件（29）**：两类序列的总体特征差异远大于估计误差，即$\sup_{t_1,t_2} |\sum_{j'} w_{j_g,g}(j')(\gamma_g(t_1, j') - \gamma_g(t_2, j'))| \gg \Psi_g$。这是分类可行的核心条件。
- **条件（30）**：两类序列的总体特征满足分离性条件，即类别1的特征值恒大于类别2的特征值乘以某个大常数$C$。

**相比已有文献的放宽/强化**：
- **放宽**：不要求训练样本量$N_1, N_2$趋于无穷，允许$N_1 = N_2 = 1$。
- **强化**：要求两类序列的二阶特性差异满足条件（30）的分离性，这比一般的分类问题假设更强。

#### 主要结果

**定理1（总体特征刻画）**：
- (a) 最大偏差特征$D^*(j)$可以表示为自协方差函数$\gamma(t, \cdot)$的线性组合，具体形式为$D^*(j) = \sup_{t_1,t_2} |\sum_{j'=1}^{b} \Omega^b_{j'j}(t_1)\gamma(t_1, j') - \sum_{j'=1}^{b} \Omega^b_{j'j}(t_2)\gamma(t_2, j')|$。
- (b) 当$j \asymp b^a$时，$D^*(j)$的上界由两项组成：一项是自协方差函数在时间方向上的最大偏差的加权和，另一项是$O(b^{-\tau+2})$的残差项。
- (c) $D^*(j)$的下界由自协方差函数在时间方向上的最大偏差的加权和减去$O(b^{-\tau+2})$的残差项给出。

**定理2（估计一致性）**：
- (a) 估计误差$\sup_{1 \leq j \leq b_g} |D_g(j) - D^*_g(j)| = O_P(\xi_{c_g}\zeta_{c_g}\sqrt{b_g c_g / n_g}(1 + b_g c_g^{-d_g} + b_g^2/n_g) + c_g^{-d_g})$。
- (b) 当条件（29）和（30）成立时，分类错误率$P(\text{misclassification}) = o(1)$。

**推论1（强分类一致性）**：在定理2的条件下，测试集上的分类错误率渐近为零。

**证明路线与技术技巧**：

**整体路线（4步）**：
1. **AR逼近**：利用Ding和Zhou (2023)的定理，将局部平稳过程$z$表示为时变AR($b$)过程加$o_{L^2}(1)$残差。
2. **系数估计**：采用Yule-Walker方程和基函数展开（Legendre多项式），通过OLS估计AR系数函数$\hat{\phi}_j(t)$。
3. **特征误差分解**：将$|D_g(j) - D^*_g(j)|$分解为三项——逼近误差（AR逼近的残差）、估计误差（OLS估计的方差）、截断误差（基函数展开的截断）。分别用物理依赖度量、矩条件（16）和光滑性条件（假设2）控制这三项。
4. **分类一致性**：利用条件（29）和（30），证明类别1和类别2的特征值之差远大于估计误差，从而阈值分类正确。

**关键跳跃点**：
- **跳跃1**：从AR系数估计误差到特征$D(j)$的误差传播。作者利用$D(j)$的定义（最大偏差）和三角不等式，将特征误差转化为AR系数估计误差的$\sup$范数，再通过基函数的性质（$\zeta_c$）控制。
- **跳跃2**：条件（28）的充分性。作者需要确保$b_g c_g(\xi_{c_g}^2/\sqrt{n_g} + \xi_{c_g}^2 n_g^{2/(\tau_g+1)}/n_g) = o(1)$，这要求$b_g$和$c_g$不能增长太快。作者通过选择$b_g \asymp n_g^{1/(2\tau_g+2)}$和$c_g \asymp n_g^{1/(2d_g)}$来满足这一条件。
- **跳跃3**：条件（30）的构造。作者将分类问题转化为特征值的比较问题，条件（30）确保类别1的特征值恒大于类别2的特征值乘以大常数$C$，从而阈值$\vartheta$可以稳定地分离两类。

**技术技巧点名**：
- **物理依赖度量**（Wu, 2005; Dahlhaus et al., 2019）：用于控制AR逼近误差和估计误差，是证明的核心工具。
- **Yule-Walker方程**：用于从自协方差函数估计AR系数，是时变AR逼近的标准方法。
- **基函数展开（Legendre多项式）**：将时变AR系数函数$\phi_j(t)$展开为有限维基函数，将无限维问题转化为有限维OLS问题。
- **交叉验证**：用于选择AR阶数$b$和基函数个数$c$，在数值实现中采用leave-one-out交叉验证。
- **集成聚合**：通过取最大偏差的$\sup$，将多个滞后的信息聚合为一个标量特征，降低维度并增强判别力。

#### 真实例子与应用

**EEG数据分类（第5节）**：作者使用Temple University Hospital (TUH) Abnormal EEG Corpus，该数据集包含504个训练受试者和150个测试受试者的EEG记录，每个受试者被标记为正常或异常（癫痫相关）。作者选取CZ、C3、C4三个通道，将每个受试者的EEG信号预处理为长度$n = 1000$的序列（降采样至1 Hz），然后应用本文方法进行分类。

**具体操作**：
1. 对每个受试者的EEG序列，使用时变AR逼近估计AR系数函数$\hat{\phi}_j(t)$。
2. 计算最大偏差特征$D(j)$，并聚合为$S$。
3. 在训练集上计算类别1和类别2的$S$值分布，选择阈值$\vartheta$最大化训练集分类准确率。
4. 对测试集序列计算$S$值并与$\vartheta$比较，得到分类结果。

**结果**：本文方法在CZ通道上达到94.7%的分类准确率，在C3和C4通道上分别达到74.7%和72.6%，均优于所有对比方法（包括Rocket、MultiRocket、Arsenal、STSForest、Shapelet、DWT、LSW、TimeCNN、TimeRNN和FLogistic）。值得注意的是，在类别不平衡的情况下（$N_1 = 50, N_2 = 250$），本文方法仍保持较高准确率（见Figure 3(b)）。

**这个例子想说明什么**：EEG数据分类验证了本文方法在实际应用中的有效性，特别是在以下方面：(i) 非平稳性处理——EEG信号具有明显的时变特性，本文方法通过时变AR逼近有效捕捉了这种非平稳性；(ii) 小样本鲁棒性——即使训练样本量有限（$N_1 = 50$），本文方法仍能保持较高准确率；(iii) 可解释性——提取的特征直接反映了AR系数的时间波动，为临床医生提供了直观的判别依据。

#### 🔎 结论是否比证明窄

**结论比证明窄的地方**：
1. **定理2的证明仅针对$N_1 = N_2 = 1$**：作者在定理2的证明中明确假设$N_1 = N_2 = 1$，但数值实验中使用了$N_1 = 50, N_2 = 250$等更大的训练样本量。虽然作者声称"我们的方法不要求训练样本量"，但定理2的证明并未覆盖$N_1, N_2 > 1$的情形。这是一个明显的"证明窄于结论"之处。
2. **条件（30）的验证**：作者在数值实验中并未直接验证条件（30）是否成立，而是通过模拟结果间接说明。条件（30）要求类别1的特征值恒大于类别2的特征值乘以大常数$C$，这在理论上是一个很强的分离性条件，但作者未给出如何在实际数据中验证该条件的方法。
3. **非线性模型的覆盖**：定理1和定理2的证明基于线性AR逼近，但数值实验中的模型4和模型6是非线性时变AR模型。作者在附录中声称这些模型满足条件（28），但未给出详细的验证过程。
4. **"轻微差异"的量化**：作者在摘要和引言中声称方法在"两类序列的二阶特征仅轻微差异"时有效，但未给出"轻微差异"的量化定义。条件（29）和（30）给出了分离性的充分条件，但未讨论这些条件是否等价于"轻微差异"。

### 四、开放问题

以下开放问题均扎根于本文的具体语句：

1. **多变量推广**（扎根于第5节EEG分析）：作者在EEG分析中仅独立处理每个通道（CZ、C3、C4），并在结论中写道"从单变量到多变量时间序列的推广是未来研究的有趣方向"。具体要解决的是：如何建模通道间的依赖结构，并将其纳入分类特征？这涉及多变量时变AR模型的估计与推断，以及通道间相关性的判别信息提取。

2. **最优阈值选择**（扎根于第2.2节）：作者在公式(13)中通过最大化训练集分类准确率选择阈值$\vartheta$，但未讨论该选择在理论上的最优性。一个开放问题是：是否存在一个数据驱动的阈值选择准则，使得分类错误率在minimax意义下最优？这需要建立分类错误率与阈值之间的精确渐近关系。

3. **高阶矩差异的判别**（扎根于第2.3节）：作者在比较分析中指出，本文方法仅利用二阶特征，而"当两类序列的差异主要体现在高阶矩时，本文方法可能失效"。一个开放问题是：如何将高阶矩信息（如时变偏度、峰度）纳入分类框架？这可能需要发展基于高阶谱或非线性变换的特征构造方法。

4. **类别不平衡的理论刻画**（扎根于Figure 3(b)）：作者在数值实验中观察到类别不平衡时性能下降，但未给出理论解释。一个开放问题是：分类错误率如何随类别比例$\kappa = N_2/N_1$变化？是否存在一个临界比例，超过该比例后分类一致性不再成立？

5. **AR阶数$b$的自适应选择**（扎根于第2.1节）：作者通过交叉验证选择$b$和$c$，但未给出$b$的理论最优选择准则。一个开放问题是：是否存在一个数据驱动的准则，使得$b$的选择在分类错误率意义下最优？这需要建立$b$与分类错误率之间的精确关系。
