### 一、领域脉络与小综述

#### 这个方向是什么

Prediction-Powered Inference (PPI) 是近年来兴起的半参数推断框架，解决的根本问题是：**当研究者拥有一个大规模未标注数据集（仅含协变量 X）和一个小规模标注数据集（含协变量 X 与真实结果 Y）时，如何利用预训练机器学习模型在未标注数据上的预测来提升对某个总体参数 θ\* 的估计效率，同时保证推断的有效性（即置信区间有正确的覆盖概率）**。其核心洞察是：预测虽然可能有偏，但预测与真实结果之间的系统偏差可以通过小标注样本校准，从而在保持无偏性的同时利用未标注数据的大样本量来降低方差。该方向当前处于快速发展期——从 2023 年 PPI 框架提出至今，已有大量变体（PPI++、RePPI、PSPA、EPI 等）涌现，但**几乎所有现有方法都只使用预测的"点值"（如均值或众数）作为辅助信息**，而现代预测模型（尤其是 LLM）输出的完整预测分布（如 token 概率、评分分布）中可能包含点预测丢失的信息。本文正是针对这一 gap 提出 distribution-informed PPI (DiPPI)。

#### 发展脉络

**奠基工作：PPI 框架的提出。** Angelopoulos et al. (2023a, *Science*) 首次系统提出 prediction-powered inference，将未标注数据上的预测与标注数据上的校准相结合，构建了适用于均值、分位数、线性回归系数等估计量的有效推断程序。其核心思想是：用预测在未标注数据上的均值估计一个"辅助量"，再用标注数据估计预测误差的期望，两者相减得到对目标参数的无偏估计。该工作直接继承了更早的 post-prediction inference 思想——Wang et al. (2020, *PNAS*) 指出，将 ML 预测直接当作真实结果进行下游推断会产生极端偏差和不可控方差，并提出了基于标注子样本的偏差校正方法。**这一支线的核心问题是：如何在不假设预测模型正确的前提下，利用预测提升统计效率？**

**主要进展：效率优化与自适应。** 后续工作沿着"如何更充分地利用预测信息"这一主线推进。Angelopoulos et al. (2023b, PPI++) 引入功率调优（power tuning），通过自适应权重在标注样本与未标注样本之间分配，使得估计量在预测质量差时退化为标注样本估计、在预测质量好时接近全标注估计，从而保证"永远不会比只用标注数据更差"。Miao et al. (2025, PSPA) 提出 assumption-lean 框架，强调不依赖预测模型正确性的自适应推断。Gan et al. (2024) 通过预测去相关（prediction de-correlation）进一步消除预测误差与协变量之间的相关性带来的效率损失。**这一阶段的方法论共识是：预测信息应当被"自适应地"加权使用，而非固定地全盘接受。**

**当前 frontier：从点预测到分布预测。** 最近的工作开始探索更丰富的预测信息形式。Ji et al. (2026, RePPI) 将 PPI 重新表述为"预测作为替代结局"（surrogate outcomes）问题，通过校准（recalibration）学习最优的"插补损失函数"，在更弱的条件下达到比 PPI++ 更高的效率。Wang et al. (2025, EPI) 将经验似然与 PPI 结合，通过辅助矩条件整合预测信息。**但上述所有方法都默认预测信息被压缩为一个标量或向量（点预测）**。本文作者指出，当预测系统输出的是一个分布 Q（如 LLM 对评分的概率分布）时，Q 的形状特征（方差、偏度、分位数等）可能携带与点预测互补的信息——例如，两个预测均值相同的样本，其预测方差可能不同，而方差可能指示预测的可靠性或结果的条件均值差异。**本文的位置：首次系统性地将"完整预测分布"作为辅助信息引入 PPI 框架，并证明其效率增益的来源与条件。**

#### 子线索聚类

被引文献大致落在三条子线索上：

1. **偏差校正与有效性**（Wang et al., 2020; Angelopoulos et al., 2023a）：核心是保证推断的有效性——即使用有偏预测，置信区间仍覆盖真实参数。方法：用标注样本估计预测偏差并校正。
2. **效率优化与自适应**（Angelopoulos et al., 2023b; Gan et al., 2024; Miao et al., 2025）：核心是在有效性基础上进一步提升效率——通过权重选择、去相关、自适应估计等策略，使估计量在预测质量变化时仍保持最优或接近最优。
3. **预测信息的更优利用**（Ji et al., 2026; Wang et al., 2025）：核心是重新思考"预测如何进入估计方程"——通过校准、经验似然等工具，将预测信息转化为更有效的辅助矩条件。**本文属于这一子线索的延伸**：将辅助信息从"点预测"推广到"预测分布"。

#### 这个方向在追问的核心问题

1. **有效性**：如何保证基于预测的推断在预测模型任意（甚至对抗性）错误下仍然有效？（已基本解决：通过标注样本校准。）
2. **效率**：给定预测质量，如何达到最小的渐近方差？（部分解决：PPI++ 的自适应权重在特定条件下达到最优；RePPI 在更弱条件下改进。）
3. **信息利用的边界**：预测中哪些信息是"可用的"？点预测是否已经穷尽了预测对目标参数的全部有用信息？——**这是本文回答的问题**：当预测分布 Q 与真实结果 Y 之间存在"分布层面的相关性"（如方差与条件均值相关）时，点预测会丢失信息，而完整分布可以捕获。
4. **已知瓶颈**：现有方法对预测信息的利用是"手动的"——需要人为指定如何将预测转化为辅助量（如均值、分位数）。缺乏一个统一的框架来自动发现预测分布中哪些特征对目标参数有信息量。

#### ⚠️ 作者的 framing（这是作者的说法）

作者将缺口 frame 为：**"现有 PPI 方法将预测压缩为点值，丢弃了预测分布中可能包含的、与目标估计方程相关的信息"**。他们通过两个机制论证这一 gap 的存在：(i) 当预测分布 Q 的方差（或其他形状特征）与条件均值 E[Y|X, Q] 相关时，点预测（均值）无法捕获这一关联；(ii) 在估计方程框架下，最优辅助量是条件期望 E[U_θ\*(X,Y)|X,Q]，而这一期望通常依赖于 Q 的完整分布而非仅其均值。作者**淡化**了以下竞争路线：(a) 直接使用预测分布的均值作为"连续型替代结局"的 RePPI 框架——作者认为 RePPI 虽然灵活，但其校准步骤仍以点预测为输入；(b) 将 Q 的高维表示直接作为协变量加入回归的做法——作者认为这需要额外的维度假设，而他们的框架通过"分布特征选择"避免了这一问题。**值得研究者去查的问题**：作者在 intro 中未提及的、可能相关的文献包括——(i) 半参数效率理论中关于"辅助信息的最优利用"的经典工作（如 Bickel et al. 1993 的 semiparametric efficiency 理论中关于 nuisance parameter 的处理）；(ii) 迁移学习 / 领域自适应中利用未标注数据分布信息的效率分析；(iii) 因果推断中利用"代理变量"（proxies）进行效率提升的文献（如 Tchetgen et al. 2020 的 proximal causal inference）——这些工作是否已经隐含地处理了"分布信息"？

#### 张力

未见明显对立引用。但存在一个微妙的张力：**PPI++ 的功率调优在预测质量差时退化为标注样本估计，而 DiPPI 声称即使预测质量差（如 Q 与 Y 独立），使用完整分布也不会比点预测更差**——这两者并不矛盾（DiPPI 的"不更差"是相对于点预测 PPI，而非相对于标注样本估计），但作者在 intro 中未明确讨论 DiPPI 在预测完全无信息时的行为是否与 PPI++ 的退化性质一致。这是一个值得研究者去核对的细节。


### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

**符号清单**（按类别分组）：

| 类别 | 符号 | 含义 |
|------|------|------|
| 参数 / estimand | θ\* ∈ Θ ⊆ ℝᵈ | 目标参数，由矩条件 E[U_θ\*(X,Y)] = 0 定义 |
| 参数 / estimand | U_θ : 𝒳 × 𝒴 → ℝᵈ | 已知的估计方程（estimating function），如得分函数、回归残差×协变量 |
| 随机变量 / 样本 | (X, Y) | 协变量与真实结果，联合分布 P |
| 随机变量 / 样本 | Q = A(X, Z) | 预测系统 A 输出的预测分布（𝒫(𝒴) 上的一个元素），是 (X, Z) 的确定性函数 |
| 随机变量 / 样本 | Z | 预测系统使用的额外输入（如文本描述、检索到的记录），研究者可能无法直接建模 |
| 随机变量 / 样本 | D_L = {(Xᵢ, Yᵢ, Qᵢ) : i = 1,...,n} | 标注样本（含真实结果），i.i.d. 来自 (X, Y, Q) 的联合分布 |
| 随机变量 / 样本 | D_U = {(Xⱼ, Qⱼ) : j = n+1,...,n+N} | 未标注样本（仅含协变量与预测分布），i.i.d. 来自 (X, Q) 的边缘分布 |
| 维数 / 样本量 | n, N | 标注样本量、未标注样本量；假设 n/N → r ∈ (0, ∞) |
| 维数 / 样本量 | p, d | 协变量维度、参数维度 |
| 潜在 / 不可观测 | E[U_θ\*(X,Y) \| X, Q] | 给定 (X, Q) 时估计方程的条件期望——这是最优辅助量，但不可直接观测（因为 Y 未观测） |
| 潜在 / 不可观测 | μ(X, Q) | 对上述条件期望的估计（用标注样本拟合） |
| 潜在 / 不可观测 | M_μ | 校准矩阵，Cov{U_θ\*(X,Y), μ(X,Q)} Cov{μ(X,Q)}⁻¹ |

**模型**：数据生成机制如下——
1. 存在一个总体分布 P，使得 E[U_θ\*(X,Y)] = 0 唯一确定 θ\*。
2. 预测系统 A 是固定的（不随样本变化），对每个 (X, Z) 输出一个预测分布 Q ∈ 𝒫(𝒴)。**关键假设**：Q 与 Y 在给定 (X, Z) 下可能相关（即 Q 包含关于 Y 的信息），但 Q 的生成不依赖于标注样本（即 A 是在外部数据上训练的，与当前分析无关）。
3. 标注样本 D_L 和未标注样本 D_U 共享相同的 (X, Q) 边缘分布，但只有 D_L 包含 Y。

**可观测数据**：研究者实际能观测到的是——
- 标注样本中的 (Xᵢ, Yᵢ, Qᵢ)，共 n 组；
- 未标注样本中的 (Xⱼ, Qⱼ)，共 N 组。

**不可观测 / 只能靠假设识别**：
- 未标注样本中的真实结果 Yⱼ（这正是 PPI 要利用预测来"弥补"的缺失）；
- 条件期望 E[U_θ\*(X,Y) | X, Q]——这是最优辅助量，但只能通过标注样本估计；
- 预测系统 A 的内部机制（Z 的具体内容、模型参数）——研究者只需访问 Q 的输出，无需理解其内部。

#### 第二步：最小内核

**最简特例**：假设目标是估计总体均值 θ\* = E[Y]，估计方程为 U_θ(X,Y) = Y − θ。此时：

- **可观测数据**：标注样本 {(Yᵢ, Qᵢ) : i = 1,...,n}（忽略 X），未标注样本 {Qⱼ : j = n+1,...,n+N}。
- **经典 PPI 估计量**（使用点预测 m(Q) = E_Q[Y]）：
  θ̂_PPI = (1/N) Σ_{j=n+1}^{n+N} m(Qⱼ) + (1/n) Σ_{i=1}^n [Yᵢ − m(Qᵢ)]。
  即：用未标注样本上的预测均值估计总体均值，再用标注样本上的预测误差均值校正偏差。

- **DiPPI 的核心改进**：不使用点预测 m(Q)，而是使用完整分布 Q 来构造辅助量。具体地，DiPPI 估计量（简化形式）为：
  θ̂_DiPPI = (1/N) Σ_{j=n+1}^{n+N} μ̂(Qⱼ) + (1/n) Σ_{i=1}^n [Yᵢ − μ̂(Qᵢ)]，
  其中 μ̂(Q) 是 E[Y | Q] 的估计（用标注样本拟合，例如将 Q 的分布特征——均值、方差、分位数——作为回归输入）。

- **为什么分布比点预测更好？** 考虑一个简单情形：Y = f(Q) + ε，其中 f(Q) 依赖于 Q 的方差而非均值。例如，Q 是均值为 0、方差为 V 的正态分布，而 Y = V + ε。此时：
  - 点预测 m(Q) = 0 对所有 Q 相同，不携带任何关于 Y 的信息，PPI 退化为标注样本估计。
  - 完整分布 Q 的方差 V 携带全部关于 Y 的信息，DiPPI 可以利用这一信息，达到更小的渐近方差。

- **这个特例揭示的核心数学事实**：在估计方程框架下，最优辅助量是条件期望 E[U_θ\*(X,Y) | X, Q]。当这一条件期望依赖于 Q 的分布特征（而非仅其均值）时，使用完整分布 Q 可以严格提升效率。**本文的全部理论贡献，就是回答"如何估计这一条件期望"以及"估计误差如何影响最终推断"这两个问题。**

- **为什么需要矩阵校准？** 在实际中，μ̂(Q) 只是 E[Y | Q] 的近似估计（因为标注样本有限，且回归模型可能 misspecified）。直接用 μ̂ 构造估计量会引入偏差。矩阵校准（即乘以 M_μ）的作用是：**将 μ̂ 的预测误差投影到与目标参数正交的方向上，从而消除因 μ̂ 不精确引入的一阶偏差**。这正是 Theorem 1 中 M_μ 的统计含义——它保证了即使 μ̂ 不是最优的，DiPPI 估计量仍然渐近无偏，且渐近方差不超过标注样本估计。


### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：在 PPI 框架下，当预测系统输出完整预测分布 Q（而非仅点预测）时，如何利用 Q 中的分布信息（方差、分位数、形状等）来进一步提升估计效率，并保证推断的有效性。
2. **核心方法**：提出 DiPPI 框架——用标注样本估计条件期望 μ(X,Q) = E[U_θ\*(X,Y) | X, Q]（以 Q 的分布特征为输入），通过矩阵校准消除估计误差的一阶影响，构造渐近正态且渐近方差不超过标注样本估计的估计量。
3. **主要结论**：DiPPI 的渐近方差由条件期望的拟合质量决定；当 Q 包含点预测丢失的信息时，DiPPI 严格优于 PPI++ 和 RePPI；通过三个真实数据应用（葡萄酒评分、森林覆盖类型、礼貌性评分）验证了效率增益。

#### 关键设定与假设

在第二节最小记号的基础上，本文的完整设定如下：

- **估计方程框架**：目标参数 θ\* 由 E[U_θ\*(X,Y)] = 0 定义。这涵盖了均值（U = Y − θ）、线性回归系数（U = X(Y − Xᵀθ)）、逻辑回归得分等常见情形。
- **预测分布 Q**：Q = A(X, Z) 是固定预测系统的输出，取值于 𝒫(𝒴)。**关键设定**：Q 与 Y 在给定 (X, Z) 下相关，但研究者不需要知道 Z 的具体内容或 A 的内部机制——只需访问 Q。
- **有限维表示**：研究者选择 Q 的一个有限维特征映射 Φ(Q) ∈ ℝᵍ（如均值、方差、若干分位数、熵等），并假设条件期望 E[U_θ\*(X,Y) | X, Q] 可以（近似）表示为 (X, Φ(Q)) 的函数。**这是本文与"直接使用完整分布"之间的关键妥协**——完整分布是无穷维对象，必须降维才能估计。
- **交叉拟合**：将标注样本分成三折，每折轮流作为校准集，其余两折用于拟合 μ̂。交叉拟合保证了 μ̂ 与用于构造估计量的样本之间的独立性，这是渐近理论成立的关键。
- **假设 1（正则性）**：U_θ 在 θ\* 附近连续可微，H_θ\* = E[∇_θ U_θ\*(X,Y)] 非奇异，且 U_θ\* 具有有限二阶矩。
- **假设 2（估计量质量）**：μ̂ 满足均方收敛条件 E‖μ̂(X,Q) − μ(X,Q)‖² = o_p(1)，且交叉拟合的每一折都满足独立性条件。
- **假设 3（特征选择）**：Φ(Q) 的选择使得 μ(X,Q) 在 (X, Φ(Q)) 的函数类中有良好的逼近（即近似误差可控）。

**相比已有工作的关键差异**：
- 相比 PPI/PPI++（使用点预测 m(Q)），本文允许 μ̂ 以 Q 的任意分布特征为输入，因此可以捕获点预测丢失的信息。
- 相比 RePPI（使用点预测 + 校准），本文的校准对象是"分布特征的条件期望"而非"点预测的条件期望"，因此更灵活。
- 相比 PSPA（assumption-lean 自适应），本文的矩阵校准提供了更直接的最优性保证（Theorem 1 的 oracle 最优性）。

#### 主要结果

**定理 1（oracle 最优性）**：在所有基于 (X, Q) 的辅助量中，条件期望 μ\*(X,Q) = E[U_θ\*(X,Y) | X, Q] 是最优的——它使渐近方差达到最小。这一结果将 PPI 的效率问题归结为"如何估计条件期望"的问题。

**定理 2（渐近正态性）**：在交叉拟合和正则性条件下，√n(θ̂_DiPPI − θ\*) ⇒ N(0, Σ_μ^DiPPI)，其中 Σ_μ^DiPPI 由公式 (7) 给出。关键结论是：**即使 μ̂ 不是 μ 的一致估计（即存在 misspecification），矩阵校准也能保证渐近无偏性**——这是 Theorem 1 中 M_μ 的核心作用。

**推论 3（效率增益）**：Σ_μ^DiPPI ⪯ Σ_C（标注样本估计的渐近方差），且等号成立当且仅当 μ(X,Q) 与 U_θ\*(X,Y) 在给定 X 下条件不相关。**这意味着 DiPPI 永远不会比只用标注数据更差，且在 Q 包含额外信息时严格更好。**

**定理 4（推断有效性）**：公式 (10) 给出的方差估计量是一致的，即 Wald 置信区间有正确的渐近覆盖概率。

**证明路线与技术技巧**：

1. **整体路线**（以定理 1 为例）：
   - 第一步：将 DiPPI 估计量重写为"标注样本估计 + 未标注样本校正"的形式，即 θ̂_DiPPI = θ̂_C + 校正项。
   - 第二步：利用交叉拟合的独立性，将校正项的渐近分布分解为两部分——标注样本的贡献和未标注样本的贡献。
   - 第三步：对校正项中的 μ̂ 做一阶泰勒展开，利用矩阵校准 M_μ 消去 μ̂ 的估计误差项（这是 Lemma 5 的核心）。
   - 第四步：利用中心极限定理和 Slutsky 定理得到渐近正态性，并计算渐近方差。

2. **关键跳跃点**：
   - **Lemma 5（校准误差的渐近可忽略性）**：这是整个证明中最吃功夫的部分。难点在于：μ̂ 是用标注样本拟合的，而标注样本又同时用于构造估计方程，因此 μ̂ 与 U_θ 之间存在相关性。作者通过交叉拟合（三折）打破这种相关性，并证明交叉拟合的误差项是 o_p(n^{-1/2})。证明的关键技巧是**条件期望的迭代性质**：在给定训练折的条件下，μ̂ 是固定的，从而可以将标注样本的贡献分解为条件期望和噪声两部分。
   - **矩阵校准的几何解释**：M_μ = Cov{U, μ} Cov{μ}⁻¹ 实际上是 U 对 μ 的最小二乘投影系数。乘以 M_μ 的作用是将 μ̂ 的预测值投影到 U 所在的空间，从而消除 μ̂ 中与 U 正交的分量——这些分量对估计 θ 没有贡献，但会引入噪声。这一技巧与半参数效率理论中的" nuisance parameter 正交化"一脉相承。

3. **技术技巧点名**：
   - **交叉拟合（cross-fitting）**：用于打破 μ̂ 与估计方程之间的相关性，是 DML 框架的标准技巧。
   - **矩阵校准（matrix calibration）**：与 PPI++ 的功率调优类似，但更一般——它允许 μ̂ 是任意函数（不限于点预测的线性变换），并通过最小二乘投影实现最优校准。
   - **经验过程理论**：用于处理 μ̂ 的估计误差在 sup-norm 下的一致收敛（定理 2 的证明中）。
   - **条件期望的迭代性质**：用于分解渐近方差，将标注样本和未标注样本的贡献分开计算。

#### 真实例子与应用

本文包含三个真实数据应用：

1. **葡萄酒评分（Wine）**：目标是从品酒评论文本预测葡萄酒评分（80-99 的整数）。协变量 X 包括价格、产区等，预测系统 GPT-5.4 nano 根据评论文本输出评分分布 Q。目标参数是 log 价格的回归系数。结果显示，DiPPI 的置信区间宽度比 PPI++ 窄约 15-25%，且覆盖概率接近名义水平。**这个例子说明**：LLM 输出的评分分布（而非仅均值）包含了关于评分不确定性的信息，这些信息与回归残差相关，从而提升了效率。

2. **森林覆盖类型（Forest）**：目标是从 54 个协变量预测森林覆盖类型（5 类），使用 XGBoost 输出类别概率 Q。目标参数是标准化坡度的多项式 logit 系数。DiPPI 使用完整概率向量作为分布特征，比使用点预测（最大概率类别）的 PPI++ 效率提升约 10-20%。**这个例子说明**：类别概率的"分布形状"（如置信度）携带了关于真实类别的信息。

3. **礼貌性评分（Politeness）**：目标是从对话文本预测礼貌性评分（1-25 的整数），使用 GPT-5.4 nano 输出评分分布 Q。目标参数是 hedging 指示变量的回归系数。DiPPI 的置信区间比 PPI++ 窄约 20-30%。**这个例子说明**：在评分任务中，预测分布的方差和分位数包含了点预测丢失的信息。

**这些例子的共同模式**：DiPPI 的效率增益来源于"预测分布的特征（方差、分位数、概率向量）与估计方程残差之间的相关性"。当这种相关性存在时（即预测分布包含点预测丢失的信息），DiPPI 严格优于基于点预测的方法；当这种相关性不存在时（即预测分布的信息全部浓缩在均值中），DiPPI 与 PPI++ 效率相当。

#### 🔎 结论是否比证明窄

- **定理 1 的 oracle 最优性**是在"所有基于 (X, Q) 的辅助量"这一类别中证明的，但**未考虑辅助量的估计成本**。在实际中，μ̂ 的估计需要标注样本，而标注样本是有限的——如果 Φ(Q) 的维度太高，μ̂ 的估计误差会增大，可能抵消效率增益。作者在定理 2 中假设 μ̂ 是 √n-一致的，但未给出 Φ(Q) 维度与标注样本量之间的具体权衡条件。**这是一个值得研究者去核对的窄化点**：oracle 最优性是在"μ̂ 已知"的意义下成立的，而实际估计中 μ̂ 的误差可能使 DiPPI 的效率增益变小甚至消失。
- **定理 4 的方差估计**依赖于 μ̂ 的估计误差可忽略（Lemma 5），但 Lemma 5 的证明假设 μ̂ 的收敛速度至少是 n^{-1/4}（通过均方误差条件）。**如果 μ̂ 的收敛速度更慢（如高维非参数回归），方差估计的一致性可能不成立**。作者在正文中未明确讨论这一边界条件。
- **三个真实数据应用均使用线性或多项式 logit 目标参数**，未涉及更复杂的估计方程（如分位数回归、Cox 模型）。**DiPPI 框架对非线性估计方程的适用性**在理论上已覆盖（定理 1 的估计方程框架），但实证验证有限。


### 四、开放问题

以下开放问题均扎根于本文的具体语句或证明中的边界条件：

1. **Φ(Q) 的维度选择与自适应**。作者在 Section 2.3 中提到"对于连续响应，一个实用的起点是均值、标准差和几个分位数"，但未给出如何根据标注样本量 n 自适应选择 Φ(Q) 维度的准则。**要确认这是否为真 gap**：去读 PPI++、RePPI、EPI 近期的实证论文，看是否有关于"分布特征选择"的系统研究——若没有，这是一个可做的方向（可结合高维统计中的模型选择理论）。

2. **μ̂ 的收敛速度与效率增益的权衡**。定理 2 假设 μ̂ 是 √n-一致的，但实际中 μ̂ 的收敛速度取决于 Φ(Q) 的维度和回归方法的复杂度。**要确认**：是否存在一个"有效维度"阈值，超过该阈值后 DiPPI 的效率增益被 μ̂ 的估计误差抵消？这需要推导有限样本界，可结合 minimax 下界技术（researcher 的 very_familiar 工具）。

3. **分布信息与因果推断的结合**。作者在 intro 中未提及 causal inference 的应用，但 DiPPI 的框架天然适用于 ATE 估计——只需将估计方程替换为 IPW 或 AIPW 得分。**要确认**：在 unconfoundedness 假设下，使用预测分布 Q 作为"代理变量"是否比使用点预测更能提升 ATE 估计效率？这直接关联 researcher 的 primary interest 中 causal inference 与 efficiency theory 的交叉。

4. **分布信息的最优表示**。作者证明了条件期望 μ\*(X,Q) 是最优辅助量，但未回答"如何找到 Q 的最优有限维表示"。**要确认**：是否存在一个"充分降维"的框架（如 sufficient dimension reduction），使得 Φ(Q) 的维度可以自适应地选择到最小充分统计量？这需要结合高维统计中的稀疏性假设。

5. **与半参数效率界的精确比较**。作者在公式 (7) 中给出了 Σ_μ^DiPPI 的表达式，但未与半参数效率下界（即所有正则估计量的最小渐近方差）进行精确比较。**要确认**：在给定 (X, Q) 可观测的假设下，DiPPI 是否达到半参数效率界？若未达到，差距有多大？这需要计算 efficient influence function 并验证 DiPPI 估计量的 influence function 是否与之匹配。
