### 一、领域脉络与小综述

#### 这个方向是什么

本文所处的子方向是**因果推断中的分布效应（distributional causal effects）估计**。其根本科学问题是：平均处理效应（ATE）可能掩盖处理对个体异质性的影响——例如，处理可能使一部分人受益、另一部分人受损，而均值恰好为零。因此，研究者希望估计完整的反事实分布 \(p(y(x))\)、分布函数、分位数、随机占优关系等更丰富的目标。该方向的成熟度处于"方法百花齐放但缺乏统一框架"的阶段：频率学派有半参数效率理论（如 Kennedy et al., 2023），贝叶斯学派有基于 Dirichlet 过程混合的隐变量建模（如 Roy et al., 2018），而本文试图引入一种新的贝叶斯计算范式（martingale posterior）来填补"非参数 + 不确定性量化 + 计算快"的空白。

#### 发展脉络

- **奠基工作**：Chernozhukov et al. (2013) 建立了反事实分布的识别与估计框架，利用分位数回归和重新加权技术，为后续研究提供了基准。Donald and Hsu (2014) 将其推广到正式的推断（置信带、检验），Ai et al. (2022) 进一步扩展到连续处理设定。这些工作奠定了"分布效应可识别、可估计"的理论基础，但主要停留在频率学派框架，且对不确定性量化依赖渐近正态近似。
- **主要进展（频率学派）**：Kennedy et al. (2023) 提出半参数反事实密度估计，推导了效率界并构造了 doubly robust 估计量；Ham et al. (2024) 在 log-concavity 形状约束下实现了可推断的密度估计；Martinez-Taboada and Kennedy (2024) 用 kernel Stein 散度构造 doubly robust 密度估计器。这些工作的共同特点是追求效率最优和渐近有效性，但**对 epistemic uncertainty 的量化要么依赖渐近近似，要么需要复杂的方差估计**。
- **主要进展（贝叶斯学派）**：Roy et al. (2018) 用 enriched Dirichlet process 建模联合分布，Xu et al. (2022) 提出贝叶斯半参数方法估计因果分位数效应。这些方法天然提供后验不确定性，但**计算通常依赖 MCMC，在高维或大样本下成本高**，且对模型误设的稳健性缺乏理论保证。
- **当前 frontier**：两条线并行——(i) 深度生成模型（如 normalizing flows, Melnychuk et al., 2022）追求表达力但缺乏不确定性量化；(ii) 基础模型（foundation models）如 TabPFN (Hollmann et al., 2025) 被用于因果推断，但频率学派一致性存疑（Melnychuk et al., 2026 专门分析此问题）。本文的位置是：**将 martingale posterior 这一新兴贝叶斯计算范式引入因果推断，试图同时获得非参数灵活性、完整的不确定性量化、以及极快的计算速度**。

#### 子线索聚类

1. **频率学派半参数方法**：Kennedy et al. (2023)、Ham et al. (2024)、Martinez-Taboada and Kennedy (2024)、Ai et al. (2022)、Donald and Hsu (2014)。核心工具：效率影响函数、doubly robust 估计、形状约束。优势：效率最优、理论成熟；劣势：不确定性量化依赖渐近近似。
2. **贝叶斯非参数方法**：Roy et al. (2018)、Xu et al. (2022)。核心工具：Dirichlet process、贝叶斯半参数模型。优势：天然后验不确定性；劣势：计算慢、对先验敏感。
3. **深度生成 / 基础模型方法**：Melnychuk et al. (2022)、Hollmann et al. (2025)、Ng et al. (2026)。核心工具：normalizing flows、transformer。优势：表达力强、可扩展；劣势：不确定性量化不完善、理论保证弱。
4. **Martingale posterior 方法**：Fong et al. (2023)、Battiston and Cappello (2025)、Ng et al. (2026)、Melnychuk et al. (2026)。核心工具：predictive resampling、copula update、a.c.i.d. 序列。优势：计算快、无需 MCMC、理论上有渐近保证；劣势：对 predictive rule 的选择敏感、理论仍在发展中。

#### 这个方向在追问的核心问题

1. **如何在不牺牲效率的前提下量化反事实分布的 epistemic uncertainty？** 频率学派效率最优但不确定性量化弱，贝叶斯方法不确定性量化好但效率未必最优。
2. **如何在高维协变量下保持稳健性？** 现有方法（如 kernel Stein）在高维下可能失效。
3. **如何将非参数灵活性与计算可扩展性结合？** 深度生成模型快但缺乏理论保证，贝叶斯非参数有理论但慢。
4. **在 IV 等复杂识别设定下，如何估计整个分布而非仅均值？** 现有 IV 方法多聚焦于均值或分位数，分布层面的工作较少。

#### ⚠️ 作者的 framing

作者将缺口 frame 为："现有方法要么只关注均值（掩盖分布信息），要么在不确定性量化上不完整（频率学派）或计算昂贵（MCMC）。Martingale posterior 提供了一种**计算上廉价、理论上可证明收敛、且能对任意目标 estimand 提供相干不确定性量化**的替代方案。" 作者淡化了以下竞争路线：(i) 频率学派 doubly robust 方法在效率上的优势（本文未讨论效率界）；(ii) 深度生成模型在表达力上的优势（本文的 copula update 可能不如 flow 灵活）；(iii) 现有贝叶斯非参数方法（如 Roy et al.）在模型解释性上的优势。作者还回避了 martingale posterior 对 predictive rule 选择的敏感性——不同的 update 规则可能导致不同的后验，而如何选择最优规则仍是开放问题。

#### 张力

未见明显对立引用。但存在一个潜在张力：Fong et al. (2023) 的 martingale posterior 理论依赖于 predictive rule 满足 martingale 条件，而本文在因果推断中引入的 copula update 是否在所有识别设定下都满足该条件，作者只给出了充分条件（定理 1 的 regularity conditions），未讨论违反条件时的行为。这与 Battiston and Cappello (2025) 的 a.c.i.d. 理论形成互补——后者允许近似 martingale，但代价是收敛速度可能变慢。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

**符号清单**（按类别分组）：

| 类别 | 符号 | 含义 |
|------|------|------|
| 随机变量 | \(Y\) | 结果变量（连续或离散） |
| | \(X\) | 处理变量（二值或连续） |
| | \(W\) | 协变量向量（外生） |
| | \(Z\) | 工具变量（IV 设定中） |
| 分布 | \(P\) | 观测数据的联合分布 |
| | \(p(y(x))\) | 反事实分布（处理水平 \(x\) 下的潜在结果分布） |
| | \(p(y \mid x, w)\) | 条件结果分布 |
| | \(p(w)\) | 协变量边际分布 |
| 样本 | \(D_{1:n} = \{(y_i, x_i, w_i)\}_{i=1}^n\) | 观测样本 |
| 预测序列 | \(p_i(y \mid x, w)\) | 第 \(i\) 步的条件结果预测密度 |
| | \(p_i(w)\) | 第 \(i\) 步的协变量边际预测密度 |
| | \(p_i(y(x))\) | 第 \(i\) 步的反事实预测密度 |
| 参数 | \(N\) | 预测序列长度（截断） |
| | \(B\) | 预测序列条数（后验样本数） |
| | \(\rho, \rho_x, \rho_y\) | copula 相关参数（带宽） |
| | \(\alpha_i\) | 更新权重 |
| 潜在量 | \(Y(x)\) | 潜在结果（反事实） |
| | \(Y(x) \perp\!\!\!\perp X \mid W\) | 无混杂（unconfoundedness） |
| | \(p_{AT}, p_{NT}, p_{CP}, p_{DF}\) | IV 响应类型概率 |

**模型**（以无混杂设定为例）：

1. **观测模型**：\((Y, X, W) \sim P\)，其中 \(P\) 为未知联合分布。
2. **识别假设**：一致性（\(Y = Y(x)\) 当 \(X = x\)）、无混杂（\(Y(x) \perp\!\!\!\perp X \mid W\)）、重叠（\(0 < p(x \mid w) < 1\)）。
3. **目标 estimand**：反事实分布 \(p(y(x)) = \int p(y \mid x, w) p(w) \, dw\)，以及其泛函（分位数、随机占优、分布间距离等）。
4. **可观测数据**：\(\{(y_i, x_i, w_i)\}_{i=1}^n\)，即每个个体的结果、处理、协变量三元组。

**核心识别公式**（公式 2）：

\[
p(y(x)) = \int p(y \mid x, w) p(w) \, dw
\]

这个公式表明：反事实分布可以通过**条件结果分布** \(p(y \mid x, w)\) 和**协变量边际分布** \(p(w)\) 的积分来识别。在 martingale posterior 框架下，这两个分量分别由 predictive rule 递归更新。

#### 第二步：最小内核

**最小内核问题**：假设我们观测到 \(n\) 个 i.i.d. 样本 \((y_i, x_i, w_i)\)，想要推断反事实分布 \(p(y(x))\) 的完整后验分布。**最小内核**是：**如何构造一个预测序列 \(p_i(y \mid x, w)\) 和 \(p_i(w)\)，使得它们满足 martingale 条件，并且积分后的 \(p_i(y(x))\) 收敛到正确的极限？**

**最简特例**：考虑**无协变量**（\(W = \emptyset\)）、**二值处理**（\(X \in \{0, 1\}\)）、**连续结果** \(Y\) 的情形。此时目标简化为：

\[
p(y(x)) = p(y \mid X = x)
\]

即反事实分布就是条件结果分布本身。

**核心困难**：在 martingale posterior 框架中，我们需要构造一个预测序列 \(p_i(y \mid x)\)，使得：
1. **martingale 性质**：\(E[p_i(y \mid x) \mid \mathcal{F}_{i-1}] = p_{i-1}(y \mid x)\)，即预测密度在期望意义下不漂移；
2. **收敛性**：\(p_i(y \mid x) \to p(y \mid x)\) 几乎必然；
3. **计算可行性**：每一步更新 \(O(1)\) 或 \(O(n)\) 时间。

**为什么难**：对于 copula update（公式 1），更新规则是
\[
p_{i+1}(y \mid x) = (1 - \alpha_{i+1}) p_i(y \mid x) + \alpha_{i+1} c_\rho(P_i(y \mid x), P_i(y_{i+1} \mid x)) p_i(y \mid x)
\]
这个更新在**固定 \(x\)** 时是 martingale，但当我们需要对 \(x\) 积分（即计算 \(p_i(y(x)) = \int p_i(y \mid x, w) p_i(w) dw\)）时，**两个预测序列的乘积的期望不等于各自期望的乘积**。这正是定理 1 中 \(\gamma_i(x)\) 项的来源——它是两个增量 \(\Delta_i(y \mid x, w)\) 和 \(\Delta_i(w)\) 的协方差。**最小内核的数学本质**是：**证明这个协方差项可求和（summable），从而积分后的序列仍然是（近似）martingale，并收敛到正确的极限**。

**证明的关键步骤**（定理 1 的证明路线）：
1. 将 \(p_i(y(x))\) 分解为 \(p_{i-1}(y(x)) + \gamma_i(x)\)，其中 \(\gamma_i(x)\) 是协方差项；
2. 利用 copula 密度的有界性（\(\sup c_\rho < \infty\)）和 Bayesian bootstrap 的增量界（\(|\Delta_i(w)| \leq 2/i\)），证明 \(|\gamma_i(x)| \leq C/i^2\)；
3. 由 \(\sum_i 1/i^2 < \infty\)，应用 Battiston and Cappello (2025) 的 a.c.i.d. 收敛定理，得到 \(p_i(y(x))\) 几乎必然弱收敛到某个极限；
4. 结合识别假设（无混杂），证明该极限等于真实的反事实分布 \(p(y(x))\)。

**这个最小内核告诉我们**：本文的核心贡献不是提出新的识别策略（识别公式 2 是标准的），而是**在 martingale posterior 框架下构造了一个计算上可行、理论上可证明收敛的算法**，用于估计反事实分布的完整后验。其数学创新在于**处理两个预测序列乘积的协方差项**，这在标准 martingale posterior 理论中是不需要的。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：如何在贝叶斯框架下对反事实分布 \(p(y(x))\) 进行完整的后验推断，包括密度、分布函数、分位数等任意泛函的不确定性量化，并扩展到工具变量设定。
2. **核心工具 / 方法**：基于 martingale posterior 框架（Fong et al., 2023），将因果推断中的反事实分布识别公式（公式 2）与 predictive resampling 相结合，通过 copula update 和 Bayesian bootstrap 构造预测序列，并利用 a.c.i.d. 理论证明收敛性。
3. **主要结论**：在无混杂和 IV 设定下，所提出的算法生成的预测序列几乎必然弱收敛到真实的反事实分布；模拟和真实数据表明该方法在有限样本下表现良好，计算速度快，且能提供校准良好的 credible intervals。

#### 关键设定与假设

**无混杂设定**：
- **假设 1（一致性）**：\(Y = Y(x)\) 当 \(X = x\)。标准假设，确保观测结果与潜在结果一致。
- **假设 2（无混杂）**：\(Y(x) \perp\!\!\!\perp X \mid W\)。标准假设，确保条件结果分布 \(p(y \mid x, w)\) 可识别反事实分布。
- **假设 3（重叠）**：\(0 < p(x \mid w) < 1\)。标准假设，确保所有处理水平在每层协变量下都有正概率。

**IV 设定**（额外假设）：
- **假设 4（随机分配）**：\(Z \perp\!\!\!\perp (Y(x, z), X(z))\)。工具变量随机分配。
- **假设 5（排除限制）**：\(Y(x, z)\) 在 \(z\) 上恒定，即工具变量仅通过处理影响结果。
- **假设 6（单调性）**：\(X(1) \geq X(0)\) 以概率 1 成立，且 \(X(1) > X(0)\) 的概率为正。排除 defiers。

**技术假设**（定理 1 的 regularity conditions）：
- 预测密度 \(p_i(y \mid x, w)\) 和 copula 密度 \(c_\rho\) 一致有界。
- 协方差项 \(\gamma_i(x)\) 满足 \(\sum_i |\gamma_i(x)| < \infty\) 几乎必然。

**相比已有文献的差异**：
- 相比频率学派（Kennedy et al., 2023）：本文不追求效率最优，而是提供完整的后验分布；不依赖渐近正态近似。
- 相比传统贝叶斯非参数（Roy et al., 2018）：本文不需要 MCMC，计算速度快几个数量级。
- 相比深度生成方法（Melnychuk et al., 2022）：本文有收敛性保证，且不确定性量化是"免费的"（来自 martingale posterior 的随机性）。

#### 主要结果

**定理 1（无混杂设定下的收敛性）**：在假设 1-3 和技术条件下，预测序列 \(p_i(y(x))\) 几乎必然弱收敛到某个随机概率测度 \(P_\infty(y(x))\)，且该测度以概率 1 等于真实的反事实分布 \(p(y(x))\)。

**定理 2（IV 设定下的收敛性）**：在假设 4-6 和技术条件下，complier 反事实分布 \(p_i(y(x) \mid CP)\) 几乎必然弱收敛到真实值。

**证明的技术难点**：
- **难点 1**：两个预测序列乘积的期望不等于期望的乘积。解决：将协方差项 \(\gamma_i(x)\) 分解，利用有界性和增量界证明其可求和。
- **难点 2**：IV 设定中 complier 分布的比值形式（公式 4）涉及分母 \(p_{CP}\)，需要保证其远离零。解决：利用严格单调性假设（假设 6）保证 \(p_{CP} \geq \varepsilon > 0\)。
- **难点 3**：copula update 的 martingale 性质只在固定 \(x\) 时成立，积分后可能破坏。解决：利用 a.c.i.d. 理论（Battiston and Cappello, 2025），允许近似 martingale 性质。

**使用的技术工具**：
- **a.c.i.d. 序列理论**（Battiston and Cappello, 2025）：用于证明近似 martingale 序列的收敛性。
- **copula update**（Fong et al., 2023）：构造连续预测密度。
- **Bayesian bootstrap**（Rubin, 1981）：更新离散分布（协变量、处理）。
- **自然梯度更新**：用于参数化预测模型（如 logistic 回归）。

#### 真实例子

**例子 1：锌含片对感冒持续时间的影响**
- **数据**：多项随机双盲安慰剂对照试验，结果变量为感冒持续时间（天），处理为锌含片 vs 安慰剂。
- **方法应用**：估计反事实分布 \(p(y(1))\) 和 \(p(y(0))\)，以及分位数处理效应 \(Q_1(\delta) - Q_0(\delta)\)。
- **结果**：后验均值显示处理组分布左移（持续时间缩短），且**分位数处理效应随 \(\delta\) 变化**——在低分位数（短感冒）处效应较小，在高分位数（长感冒）处效应较大。这揭示了均值效应掩盖的异质性：锌含片对严重感冒的绝对收益更大。
- **与 baseline 对比**：与频率学派 doubly robust 估计（Kennedy et al., 2023）的点估计一致，但本文提供了完整的 credible bands，且计算时间从分钟级降至秒级。

**例子 2：维生素 A 补充对儿童生存率（IV 设定）**
- **数据**：印度尼西亚村庄随机分配维生素 A 补充，存在单侧不依从（部分处理组未服用）。
- **方法应用**：以随机分配为工具变量，估计 complier 反事实分布 \(p(y(1) \mid CP)\) 和 \(p(y(0) \mid CP)\)。
- **结果**：complier 平均处理效应与 Imbens and Rubin (1997a) 的贝叶斯分析一致，但本文额外提供了**完整的 complier 结果分布**，显示维生素 A 不仅提高平均生存率，还降低了极端低生存率个体的比例。
- **与 baseline 对比**：与 Imbens and Rubin (1997a) 的 MCMC 结果相比，本文的 credible intervals 略窄，计算时间从小时级降至分钟级。

**例子 3：职业培训对收入的影响（LaLonde 数据）**
- **数据**：LaLonde (1986) 实验数据，结果变量为 1978 年实际收入，处理为职业培训。
- **方法应用**：估计 ATT 的反事实分布，特别关注收入为零的点质量（失业）。
- **结果**：处理组在零收入处的点质量显著降低，且正收入部分的分布右移。分位数处理效应显示效应主要集中在低收入分位数。
- **与 baseline 对比**：与 Hahn et al. (2020) 的 BCF 方法相比，本文的 credible intervals 更宽（反映了非参数模型的额外不确定性），但计算速度快得多。

#### 🔎 结论是否比证明窄

**结论确实比证明窄**，具体表现在：

1. **定理 1 的证明假设了 copula 密度的有界性**（\(\sup c_\rho < \infty\)），但 Gaussian copula 在 \(\rho \to 1\) 时密度无界。作者在正文中未讨论这一边界情况，仅在第 2.3.2 节提到"\(\rho \in (0,1)\)"，未说明 \(\rho\) 接近 1 时的行为。**这是证明与结论之间的一个 gap**。

2. **定理 2 的证明依赖于 Bayesian bootstrap 的增量界**（公式 10-11），但该界只在离散分布下成立。若协变量 \(W\) 是连续的，Bayesian bootstrap 的增量需要修改（如用 Dirichlet process），此时增量界可能不成立。作者在正文中声称"可应用于连续协变量"，但证明未覆盖该情形。

3. **收敛性证明只保证了弱收敛**（weak convergence），未给出收敛速率。作者在模拟中观察到良好的有限样本表现，但未提供理论上的有限样本界。这意味着**无法保证在特定样本量下 credible intervals 的覆盖概率**。

4. **IV 扩展（附录 B）是启发式的**：作者承认"我们考虑更一般的设定，但将详细的理论分析留待未来工作"。附录 B 的模拟仅验证了经验表现，未提供收敛性证明。

5. **未讨论效率性质**：作者未与半参数效率界（Kennedy et al., 2023）进行比较，也未讨论 martingale posterior 的后验是否渐近效率最优。这是一个重要的理论空白。

### 四、开放问题

1. **copula 密度的有界性条件**：定理 1 要求 \(\sup c_\rho < \infty\)，但 Gaussian copula 在 \(\rho \to 1\) 时违反此条件。**要证明什么**：在 \(\rho\) 接近 1 时，收敛性是否仍然成立？若成立，收敛速率如何变化？若不成立，是否存在其他 copula 族（如 t-copula）可以避免该问题？

2. **连续协变量的 Bayesian bootstrap**：定理 2 的证明依赖离散分布的增量界。**要证明什么**：当 \(W\) 连续时，用 Dirichlet process 替代 Bayesian bootstrap，增量界是否仍然可求和？收敛速率是否改变？

3. **收敛速率与有限样本保证**：定理 1 和 2 只证明了弱收敛，未给出速率。**要证明什么**：在何种条件下，\(p_i(y(x))\) 到 \(p_\infty(y(x))\) 的收敛速率是 \(O(i^{-1/2})\) 或更快？能否构造有限样本的覆盖概率界？

4. **效率性质**：martingale posterior 的后验是否渐近效率最优？**要证明什么**：与半参数效率界（Kennedy et al., 2023）相比，本文方法的信息损失是多少？是否存在 predictive rule 的选择使得后验达到效率最优？

5. **IV 扩展的严格理论**：附录 B 的 IV 扩展缺乏收敛性证明。**要证明什么**：在一般 IV 设定下（连续处理、多工具变量），complier 反事实分布的 martingale posterior 是否收敛？需要哪些额外条件？

6. **predictive rule 的选择**：本文推荐 copula update，但未讨论其他选择（如 kernel 平滑、深度生成模型）。**要证明什么**：不同的 predictive rule 对后验的影响有多大？是否存在最优的 rule 选择准则？
