### 一、领域脉络与小综述

- **这个方向是什么**：本文研究的是**表示论与范畴论交叉领域**中的一个具体猜想——Lusztig 关于 Fourier 矩阵的猜想。该猜想断言：对于有限 Coxeter 群，其渐近 Hecke 范畴的 Drinfeld 中心的 S 矩阵（模论意义下）应等于 Lusztig 构造的 Fourier 矩阵。这个方向的核心问题是**理解 Hecke 代数的渐近结构与单值特征层（unipotent character sheaves）之间的深层联系**。该领域成熟度较高，已有大量关于晶体型（crystallographic）Coxeter 群的结果，但非晶体型（noncrystallographic）群（如 H₃、H₄、I₂(m)）的验证长期缺失。

- **发展脉络（history）**：
  - **奠基工作**：Lusztig 在 [10, 11] 中提出了 Fourier 矩阵的概念，并猜想其与渐近 Hecke 代数的中心结构一致。这一猜想源于他对 Hecke 代数胞腔理论（cell theory）的深刻洞察——每个双边胞腔对应一个渐近代数，其中心应携带某种"Fourier 变换"的结构。
  - **主要进展**：Elias 和 Williamson [3] 建立了渐近 Hecke 范畴的 Soergel 构造，证明了其刚性（rigidity）和 pivotal 结构的存在性，为后续的范畴化研究奠定了基础。Rogel 和 Thiel [20] 证明了二面体群（dihedral groups）和 H₃、H₄ 的部分胞腔的 Fourier 矩阵断言，但**中间胞腔（middle cell）** 的 74×74 大矩阵块始终悬而未决。
  - **当前 frontier**：He 和 Liu [8] 提出了 Fibonacci 生成张量范畴的固定种子唯一性定理（fixed-seed tensor uniqueness theorem），为识别具体张量范畴提供了新工具。同时，Alvis [1] 给出了 H₄ 的渐近 Hecke 代数的显式子环结构，为计算提供了基础数据。
  - **本文的位置**：本文填补了 H₄ 中间胞腔这一最后缺口，通过构造 Morita 等价将问题归结为交叉积范畴的计算，并用计算机辅助证明完成了 74×74 矩阵的精确验证。

- **子线索聚类**：
  1. **渐近 Hecke 范畴的构造与刚性**（[3], [4]）：这一簇工作建立了 Soergel 双模的范畴化框架，证明了刚性、pivotal 结构等基本性质，是后续所有工作的基础。
  2. **Fourier 矩阵与中心 S 矩阵的对应**（[10], [11], [14], [2], [20]）：这一簇工作直接研究 Lusztig 猜想，包括二面体群和 H₃、H₄ 的部分胞腔验证。
  3. **张量范畴的分类与唯一性**（[8], [18], [6]）：这一簇工作提供识别具体张量范畴的工具，包括 Fibonacci 范畴的固定种子唯一性、秩 2 范畴分类、K₄ 融合环的分类等。
  4. **计算与验证方法**（[15], [16], [1]）：这一簇工作提供计算工具（CHEVIE 包、python-flint）和显式数据结构（Alvis 的子环表），使得大规模精确计算成为可能。

- **这个方向在追问的核心问题（2-4 个）**：
  1. **Lusztig 猜想是否对所有有限 Coxeter 群成立？** 这是本文直接回答的问题——答案是肯定的，但证明依赖计算机辅助。
  2. **渐近 Hecke 范畴的 Drinfeld 中心如何计算？** 本文展示了通过 Morita 等价和交叉积范畴来间接计算的方法，避免了直接构造整个中心的困难。
  3. **如何严格验证计算机辅助证明？** 本文通过分离界（separation bound）将数值计算转化为精确的代数等式验证，这是计算机辅助证明在纯数学中的典型应用方式。
  4. **非晶体型群的表示论与晶体型群有何本质差异？** 本文表明，尽管 H₄ 的中间胞腔结构复杂，但其中心结构仍与 Fibonacci 范畴密切相关，暗示了某种统一性。

- **⚠️ 作者的 framing（必须明确标注成"这是作者的说法"）**：
  - 作者将缺口 frame 成"**中间胞腔的 74×74 矩阵块**是唯一未验证的大块"，从而本文成为"显然的下一步"。
  - 作者淡化了**直接计算整个 Drinfeld 中心**的路线，转而通过 Morita 等价和交叉积范畴间接计算，这回避了直接构造中心的巨大计算量。
  - **什么明显该被引 / 该存在、却没出现在 intro 里？** 作者没有引用任何关于**计算复杂性**或**算法效率**的文献，尽管本文本质上是一个大规模计算项目。也没有引用关于**计算机辅助证明的形式化验证**（如 Coq、Lean）的文献，尽管附录 B 详细描述了验证协议。这些缺失可能暗示作者认为计算细节不是数学贡献的核心。

- **张力**：未见明显对立引用。但值得注意的是，[20] 中 Rogel 和 Thiel 对 H₄ 的部分胞腔使用了与本文不同的方法（直接计算 vs. Morita 等价），两种方法在中间胞腔上的适用性差异值得关注——作者没有明确讨论为什么直接计算在中间胞腔上失败。

### 二、最核心、最简单的例子 / 数学问题

**第一步：把符号、模型、可观测数据交代清楚**

- **符号**：
  - **W**：有限 Coxeter 群，本文关注非晶体型：I₂(m)（m≥3）、H₃、H₄。
  - **S**：Coxeter 生成元集合。
  - **c**：W 的一个双边 Kazhdan–Lusztig 胞腔。
  - **J_c**：Lusztig 渐近代数，是 Hecke 代数的胞腔商。
  - **A_c**：渐近 Hecke 范畴，是 J_c 的范畴化（multifusion category）。
  - **Z(A_c)**：A_c 的 Drinfeld 中心。
  - **S_c**：Z(A_c) 的 S 矩阵（模论意义下）。
  - **F_c**：Lusztig 构造的 Fourier 矩阵（模论约定下）。
  - **a(c)**：胞腔 c 的 Lusztig a-函数值。
  - **A_x**：对应元素 x∈W 的简单对象。
  - **ϵ_x**：pivotal 结构的符号修正因子，ϵ_x = (−1)^{ℓ(x)−a(c)}。
  - **D**：总维数，D = 1080 + 480√5（H₄ 中间胞腔）。
  - **K**：基域 Q(√5)。
  - **ζ₆₀**：60 次本原单位根，用于标记 twist。

- **模型**：数据生成机制是**渐近 Hecke 范畴 A_c**，其对象是 Soergel 双模的胞腔商，态射是次数为零的 Soergel 态射模去低胞腔。**要估的对象**是 Drinfeld 中心 Z(A_c) 的 S 矩阵 S_c。**可观测数据**是 A_c 的融合规则（fusion rules）、pivotal 结构、以及通过 Morita 等价得到的交叉积范畴的 tube 代数。

- **关键区分**：**可观测**的是 A_c 的局部数据（融合规则、pivotal 符号、Soergel 态射的显式矩阵）；**想要但观测不到**的是 Z(A_c) 的整体结构（S 矩阵）。本文的核心策略是通过 Morita 等价将 Z(A_c) 转化为一个更易计算的交叉积范畴的中心。

**第二步：讲最小内核**

本文的最小内核可以归结为以下问题：

> **给定一个有限 Coxeter 群 W 和一个双边胞腔 c，如何计算 Z(A_c) 的 S 矩阵？**

最简特例：**二面体群 I₂(m) 的非平凡胞腔**。

- 此时 A_c 是 Fibonacci 范畴（或 Yang-Lee 范畴的变体），融合规则为 u² = 1 + u。
- Drinfeld 中心 Z(A_c) 有 4 个简单对象（对于 Fibonacci 情形）。
- S 矩阵是 4×4 的，可以手算验证。
- 本文的贡献在于：**将这个方法推广到 H₄ 的中间胞腔**，其中 A_c 的秩为 24，Z(A_c) 的秩为 74，S 矩阵是 74×74 的。

**核心数学困难**：直接计算 Z(A_c) 需要解大量的线性方程（tube 代数），计算量巨大。本文的突破在于：

1. **Morita 等价**：构造一个可分离代数 A = 1 ⊕ g，使得 A_c A ≃ C₀(A₃) ⋊ σ C₂。这将对 A_c 的研究归结为对更简单的交叉积范畴的研究。
2. **Tube 代数的部分计算**：不直接计算整个 tube 代数，而是计算其"可见部分"（40 + 32 个简单对象），再通过一个完备性论证（Lemma 7.1）证明剩余部分（2 个对象）的存在性和唯一性。
3. **分离界**：通过精确的代数数论论证，将数值计算转化为精确等式验证。

**为什么成立**：核心原因在于 A_c 具有**正定的 pivotal 结构**（positive spherical structure），这使得 S 矩阵的每个元素都有明确的模论意义，且可以通过 tube 代数中的迹（trace）来计算。Morita 等价保持了中心结构，因此可以在更简单的模型中计算。

### 三、这篇论文做了什么

**三句话**：
1. **研究了什么问题**：Lusztig 的 Fourier 矩阵猜想对所有有限非晶体型 Coxeter 群（I₂(m)、H₃、H₄）成立。
2. **核心工具 / 方法**：Soergel 范畴的渐近结构、Drinfeld 中心的 Morita 等价、tube 代数的部分计算、计算机辅助证明（精确算术 + 分离界）。
3. **主要结论**：对每个胞腔 c，Z(A_c) 的 S 矩阵等于模论约定下的 Fourier 矩阵 F_c^mod；特别地，H₄ 中间胞腔的 74×74 矩阵块被精确验证。

**关键设定与假设**：
- **Soergel 范畴**：使用 Elias–Williamson 的 Soergel 双模范畴，其刚性由 [3] 保证。
- **pivotal 结构**：继承自 Soergel 范畴的 ordinary double-dual 映射，通过 Proposition 3.1 证明其符号由 ϵ_x = (−1)^{ℓ(x)−a(c)} 给出。
- **正定性**：假设 A_c 具有正定的 pivotal 结构（即所有简单对象的维度为正实数）。这是通过 Frobenius–Perron 维度论证的。
- **Morita 等价**：构造 A = 1 ⊕ g 作为可分离代数，需要验证 A 的连通性、分离性和 Frobenius 性质。
- **外部输入**：依赖 [8] 的固定种子唯一性定理、[6] 的 K₄ 分类定理、[20] 的二面体群结果。

**主要结果**：
- **Proposition 3.1**：证明了 pivotal 符号公式 ϵ_x = (−1)^{ℓ(x)−a(c)}，并由此确定正定 pivotal 结构的唯一性。
- **Proposition 4.2**：对二元素胞腔（order-two pointed corners），证明了其中心 S 矩阵等于 Fourier 矩阵（4×4 块）。
- **Proposition 5.4**：构造了 Morita 等价 A_c A ≃ C₀(A₃) ⋊ σ C₂，并证明了交叉积范畴的中心与 A_c 的中心一致。
- **Proposition 8.3**：对 H₄ 中间胞腔，验证了 74×74 S 矩阵与 Fourier 矩阵的精确等式。

**证明路线与技术技巧**：
- **整体路线**：
  1. 对每个胞腔 c，确定其对角范畴（diagonal corner）的结构。
  2. 对简单胞腔（秩 1、Fibonacci、二元素），直接计算中心。
  3. 对 H₄ 中间胞腔，构造 Morita 等价，将问题归结为交叉积范畴。
  4. 在交叉积范畴中，计算 tube 代数的"可见部分"，用完备性论证补全剩余部分。
  5. 用分离界将数值计算转化为精确等式。
- **关键技巧**：
  - **相对 Hodge–Riemann 论证**：用于确定 pivotal 符号，这是本文的核心创新之一。
  - **Tube 代数的部分计算**：不计算整个 tube 代数，而是计算其"可见部分"，再用 Lemma 7.1 的完备性论证补全。
  - **分离界**：利用代数数论中的范数论证，将数值误差转化为精确等式。
  - **计算机辅助证明**：使用 Python + FLINT 进行精确算术，使用 Arb 进行 certified 浮点计算。

**真实例子与应用**：
- **二面体群 I₂(m)**：验证了 Fibonacci 范畴的中心 S 矩阵。
- **H₃**：验证了所有胞腔（秩 1、Fibonacci、二元素）。
- **H₄**：验证了所有 13 个胞腔，其中中间胞腔是核心难点。
- **数据**：使用了 CHEVIE 包中的 H₄ Fourier 矩阵（HS4），以及 Alvis 的渐近 Hecke 代数子环表。

**🔎 结论是否比证明窄**：
- 作者在 Theorem 1.2 中声称对所有非晶体型 Coxeter 群成立，但证明依赖计算机辅助验证。作者在 Remark 8.4 中明确指出"区间重叠本身从不用于建立无限制的代数等式"，即数值计算只是提出猜想，最终等式由分离界保证。
- 作者在 Section 9 中声称结论可推广到直积（Corollary 9.1），但这一推广依赖张量积的范畴化性质，作者没有给出详细证明。
- 作者在附录 B 中详细描述了验证协议，但明确指出"验证协议不构成形式化证明"，即没有使用 Coq/Lean 等证明助手。这意味着证明的可靠性依赖于对计算代码的信任。

### 四、开放问题

1. **晶体型群的完整验证**：本文只处理了非晶体型群。对于晶体型群（如 E₆、E₇、E₈），Lusztig 猜想是否成立？[13] 中 Lusztig 的原始框架是否可以直接推广？
2. **形式化验证**：本文的计算机辅助证明能否用证明助手（如 Coq、Lean）形式化？附录 B 的验证协议能否转化为机器可检查的证明？
3. **Morita 等价的系统性构造**：本文对 H₄ 中间胞腔构造了 Morita 等价，但这一构造是否对所有 Coxeter 群的中间胞腔都适用？是否存在系统性的方法？
4. **计算复杂性的改进**：本文的 tube 代数计算涉及大规模线性代数。是否存在更高效的算法？能否利用范畴的对称性（如 braiding）简化计算？
5. **与单值特征层的几何联系**：Lusztig 猜想源于对单值特征层的期望。本文的范畴论证明是否暗示了非晶体型群的单值特征层的某种几何构造？
