### 一、领域脉络与小综述（从 introduction + 参考文献 + 已检索摘要构建）

- **这个方向是什么**：本文研究的是高维统计中的核心问题——当数据维度 p 远大于样本量 n 时，如何用高斯分布近似 n 个独立随机向量之和的分布。具体而言，关注的是在**矩形集合**（即坐标方向的区间乘积）上的 Kolmogorov 距离，这直接对应着最大值统计量的分布近似和联合置信区域的构造。该问题的根本挑战在于：当协方差矩阵奇异或坐标高度相关时，传统的高维 CLT 结果会退化，而本文的目标是在**不施加协方差非退化条件**的情况下获得最优的近似速率。

- **发展脉络（history）**：作者在引言中明确梳理了该方向的演进：
    - **奠基工作**：Chernozhukov, Chetverikov, and Kato (2013) [10] 和 Chernozhukov, Chetverikov, and Kato (2017) [12] 建立了高维 CLT 的基本框架，但早期结果依赖于协方差矩阵的非退化假设。
    - **主要进展**：Chernozhukov, Chetverikov, Kato, and Koike (2022) [14] 在无协方差限制下获得了 n^{-1/4} 的速率（至多对数因子），这是本文的直接前驱。作者在引言中明确提到，本文的**四阶矩修正**结果（Theorem 2(ii)）证实了 [14, Theorem 2.5] 中关于 n^{-1/4} 速率最优性的猜想。
    - **当前 frontier**：Lopes and Masini [27]（2026年11月13日提交，与本文几乎同时）在独立同分布且次高斯坐标的设定下获得了 n^{-1/2} 的速率，但维度依赖是次优的。本文的 Corollary 1 和 Corollary 2 在更一般的独立（非同分布）设定下，获得了与 [27] 相同甚至更优的维度依赖。
    - **本文的位置**：作者将本文定位为"研究计划接近完成"的一步——在无协方差限制下，将速率从 n^{-1/4} 提升到 n^{-1/2}（至多对数因子），并证明该速率在若干机制下是最优的（包括对数因子）。

- **子线索聚类**：被引文献大致落在三条子线索上：
    1. **高维 CLT 与最大值统计量**（[10], [12], [14], [18], [22]）：这条线索关注如何用高斯过程近似高维随机向量之和的分布，特别是最大值统计量。核心工具包括 Stein 方法、Slepian 插值、反集中不等式等。
    2. **无协方差限制的近似**（[14], [24], [27]）：这条线索专门处理协方差矩阵奇异或近奇异的情形。关键技巧包括坐标标准化、截断、以及利用高斯宽度（Gaussian width）而非维度 p 来控制误差。
    3. **下界构造与最优性**（[18], [22]）：这条线索通过构造具体的反例来证明上界速率的最优性。本文的 Theorem 3-8 属于这一线索，其构造基于独立偏斜坐标和对称稀有分量。

- **这个方向在追问的核心问题（2-4 个）**：
    1. **速率最优性**：在无协方差限制下，高斯近似的误差随样本量 n 衰减的最优速率是什么？本文证明 n^{-1/2}（至多对数因子）在多种机制下是最优的，但**额外的对数因子是否必要**（Conjecture 1）仍是开放的。
    2. **维度依赖**：误差如何依赖于维度 p？本文通过高斯宽度 g_Σ 取代了最坏情况下的 √(log p) 因子，但这是否是**所有**协方差结构下的最优依赖？
    3. **矩条件的刻画**：在无界坐标下，需要什么样的矩条件才能获得 n^{-1/2} 速率？本文的 Theorem 2 表明，仅需 q>4 阶矩（加上坐标四阶矩条件）即可，但 q=4 时速率退化为 n^{-1/4}，这是否是本质的？
    4. **计算与统计的权衡**：虽然本文是纯理论结果，但其背后的动机是**计算受限的统计推断**——在高维中，精确的分布计算不可行，因此需要高斯近似来构造有效的检验和置信区间。

- **⚠️ 作者的 framing（必须明确标注成"这是作者的说法"）**：作者在引言中把本文的贡献框架为"**将高维 CLT 的速率从 n^{-1/4} 提升到 n^{-1/2}（至多对数因子），并证明其最优性**"。具体来说：

    - 作者将 Theorem 2(ii) 的 n^{-1/4} 速率（在 q=4 时）描述为"**证实了我们早前的猜想**"，即 [14, Theorem 2.5] 的速率是最优的。
    - 作者在 Section 5 中明确将 Conjecture 1（去除额外对数因子）作为**本文最重要的开放问题**，并指出"我们相信这个因子可以被去除"。
    - **被淡化或回避的竞争路线**：作者在引言中仅用一段话提及 [27]（Lopes and Masini），并强调本文的独立（非同分布）设定更一般。但作者**没有讨论** [27] 中可能存在的、在次高斯设定下更精细的常数优化，也没有讨论**自举方法**（bootstrap）在高维 CLT 中的替代作用——尽管 [15] 的综述中提到了这一点。

### 二、最核心、最简单的例子 / 数学问题（先把符号 / 模型 / 可观测数据交代清楚）

**第一步：把符号、模型、可观测数据交代清楚**

- **符号**：
  - **参数 / estimand**：ρ_R(W, Z) := sup_{A∈R} |P(W∈A) − P(Z∈A)|，即 W 和 Z 在矩形集合上的 Kolmogorov 距离。这是本文要**上界估计**的量。
  - **随机变量 / 样本**：
    - ξ_i ∈ R^p：第 i 个独立同分布（或独立）的随机向量，i = 1, …, n。满足 Eξ_i = 0，协方差矩阵 Σ = Cov(W)，其中 W := Σ_{i=1}^n ξ_i。
    - W := Σ_{i=1}^n ξ_i：n 个随机向量之和，是我们要近似的对象。
    - Z ~ N(0, Σ)：与 W 具有相同协方差的高斯向量，是近似的目标。
    - ξ_i 的坐标：ξ_{ij}，j = 1, …, p。
  - **指标 / 维度**：
    - n：样本量（随机向量个数）。
    - p：维度（坐标个数）。
    - m = 2p：矩形集合的约束个数（每个坐标有上下界）。
    - L := log(ep)：维度对数。
    - g_Σ := E||Z||_∞：高斯宽度，即高斯向量最大坐标的期望。
  - **潜在 / 不可观测量**：
    - 潜在结果：本文是纯统计理论，不涉及潜在结果框架。
    - 不可观测量：ξ_i 的**真实分布**是未知的，我们只能观测到其样本实现。Z 是**构造的**高斯向量，不是直接观测的。

- **模型**：
  - **数据生成机制**：ξ_1, …, ξ_n 是独立（但不一定同分布）的随机向量，每个 ξ_i 的坐标可以任意相关。关键假设是：
    1. **中心化**：Eξ_i = 0。
    2. **标准化**：Σ_{jj} = 1（每个坐标方差为 1）。
    3. **有界性（Theorem 1）**：||ξ_i||_∞ ≤ δ a.s.，即每个随机向量的最大坐标绝对值不超过 δ。
    4. **矩条件（Theorem 2）**：E||ξ_i||_∞^q ≤ B^q（q>2），以及坐标四阶矩条件（见 (9)）。
  - **统计模型**：这是一个**非参数模型**——我们没有对 ξ_i 的分布施加任何参数形式，只施加了矩条件。因此，这是一个**分布自由**（distribution-free）的高维 CLT 问题。

- **可观测数据**：
  - 研究者实际能观测到的是：ξ_1, …, ξ_n 的样本实现（即 n 个 p 维向量）。
  - 从这些数据中，可以计算 W = Σ_{i=1}^n ξ_i，并估计其协方差矩阵 Σ。
  - **想要但观测不到**：W 的真实分布函数 F_W(x) = P(W ≤ x)（在矩形集合上）。我们只能通过高斯近似 Z 来估计它。

**第二步：讲最小内核**

本文的核心数学问题可以归结为**一个最小例子**：

> **最小内核（一维情形）**：设 X_1, …, X_n 是独立同分布的实值随机变量，EX_i = 0，EX_i^2 = 1，|X_i| ≤ δ a.s.。令 S_n = n^{-1/2} Σ_{i=1}^n X_i，Z ~ N(0, 1)。那么 Berry-Esseen 定理给出：
> sup_x |P(S_n ≤ x) − Φ(x)| ≤ C δ.
> 
> 这个结果在**一维**情形下是**最优**的（δ 的指数不能改进）。

本文的**核心创新**在于将这个一维结果推广到**高维**，并且**不要求协方差矩阵非奇异**。具体来说：

- **最简例子（p=2, n=1）**：设 ξ_1 = (X, X) 是一个二维随机向量，其中 X 是均值为 0、方差为 1/2 的有界随机变量。那么 W = ξ_1 的协方差矩阵是 Σ = [[1/2, 1/2], [1/2, 1/2]]，它是**奇异的**（秩为 1）。此时，Z = (Z_1, Z_2) 满足 Z_1 = Z_2 几乎必然。对于矩形集合 A = (-∞, x] × (-∞, y]，我们有：
  - P(W ∈ A) = P(X ≤ x, X ≤ y) = P(X ≤ min(x, y))。
  - P(Z ∈ A) = P(Z_1 ≤ x, Z_2 ≤ y) = P(Z_1 ≤ min(x, y))。
  
  因此，ρ_R(W, Z) = sup_{x,y} |P(X ≤ min(x,y)) − Φ(min(x,y)/√(1/2))|，这本质上是一个**一维** Berry-Esseen 问题。本文的 Theorem 1 给出的上界是 δ g_Σ L，其中 g_Σ = E||Z||_∞ = E|Z_1| = √(1/π)，L = log(2e)。这个例子说明，**即使协方差奇异，只要高斯宽度 g_Σ 有界，近似误差仍然可以控制**。

- **核心思想**：本文的证明方法可以概括为**三步走**：
  1. **平滑化**：用 logistic 函数近似矩形指示函数，将问题转化为光滑函数的期望之差。
  2. **插值**：沿着 Slepian 插值路径，从 W 平滑地过渡到 Z，将期望之差表示为路径积分。
  3. **矩估计**：利用**边界集中**（boundary concentration）和**高斯宽度**来控制路径积分中的各项。

这个最小内核揭示了本文的**数学本质**：在高维中，高斯近似的误差主要由**高斯宽度 g_Σ**（而非维度 p）和**矩条件**（δ 或 B）决定。当坐标高度相关时，g_Σ 可能远小于 √(log p)，从而获得比最坏情况更好的速率。

### 三、这篇论文做了什么（本次重心，务必讲透）

**三句话**：
1. **研究了什么问题**：在协方差矩阵可以奇异、坐标可以任意依赖的高维设定下，研究 n 个独立随机向量之和在矩形集合上的高斯近似误差，目标是获得**最优的样本量速率**（至多对数因子）。
2. **核心工具 / 方法**：采用 **logistic 平滑 + Slepian 插值** 的路径比较方法，结合**边界集中**（boundary concentration）和**高斯宽度**（Gaussian width）估计，以及**截断**和**条件化**技术处理无界坐标。
3. **主要结论**：对于有界坐标，获得了 n^{-1/2} 的速率（至多对数因子），且该速率在多种机制下是最优的；对于 q>4 阶矩的坐标，获得了 n^{-1/2+1/q} 的速率；对于 q=4 阶矩，n^{-1/4} 的速率不可改进。

**关键设定与假设**：
- **设定**：ξ_1, …, ξ_n 是独立（但不一定同分布）的随机向量，Eξ_i = 0，Σ_{jj} = 1。
- **假设（Theorem 1）**：||ξ_i||_∞ ≤ δ a.s.（有界坐标）。
- **假设（Theorem 2）**：max_i E||ξ_i||_∞^q ≤ B^q（q>2），以及坐标四阶矩条件（见 (9)）。
- **相比已有文献的放宽**：不要求 Σ 正定，不要求坐标独立，不要求同分布。相比 [14] 的 n^{-1/4} 速率，本文在**有界坐标**下获得了 n^{-1/2} 速率；相比 [27] 的次高斯假设，本文的矩条件更弱。

**主要结果**：
- **Theorem 1（有界坐标）**：ρ_R(W, Z) ≤ C min{1, g_Σ L (δ + √(s_4 D_L))}，其中 s_4 是相对四阶矩，D_L 是额外的对数因子。当 s_4 ≤ C δ² 时，速率为 δ g_Σ L。
- **Theorem 2（多项式矩）**：
  - (i) 仅需 q>2 阶矩：ρ_R(W, Z) ≤ C_q min{1, (g_Σ/√L) V_q {log(en)}^{α_q}}，其中 V_q = B n^{-α_q} L^{1+α_q}，α_q = 1/2 − 1/q。
  - (ii) 加上坐标四阶矩：ρ_R(W, Z) ≤ C_q min{1, (g_Σ/√L)(U + V_q / L^{1−1/q}_q)}，其中 U = B^{1/2} n^{-1/4} L^{5/4}，L_q = log(e + K_q)。
- **推论**：
  - Corollary 1（归一化观测）：对于有界坐标，ρ_R(W_n, Z_n) ≤ C min{1, B g_n L √(1 + log_+(√n/(B√L)))/√n}。
  - Corollary 2（次指数坐标）：ρ_R(W_n, Z_n) ≤ C min{1, K g_n L √(1 + log_+(√n/(K√L)))/√n}。
  - Corollary 3（多面体转移）：将矩形集合的结果推广到多面体。

**证明路线与技术技巧**：
- **整体路线**：
  1. **平滑化**：定义 logistic 近似 F_{a,h}(x)，将矩形指示函数平滑化。误差由 Lemma 2 控制，为 O(h L)。
  2. **Slepian 插值**：构造路径 W_s = √s W + √(1−s) Z，将平滑期望之差表示为路径积分。
  3. **导数估计**：利用 Gaussian integration by parts（Stein 方法）将导数分解为**边界项**和**体积项**。
  4. **边界集中**：核心技巧是 Lemma 1（矩形反集中不等式），它用高斯宽度 g_Σ 控制边界层的概率。
  5. **矩估计**：对于有界坐标，直接用 δ 控制高阶矩；对于无界坐标，使用截断和条件化，将大观测分离出来。
- **关键技巧**：
  - **Gaussian integration by parts**：将导数转化为 Hermite 多项式与 logistic 权重的乘积，从而利用高斯宽度。
  - **边界集中**：Lemma 1 是证明的核心，它给出了边界层概率的上界，避免了维度 p 的显式依赖。
  - **截断与条件化**：Theorem 2 中，将大观测（||X_i||_∞ > T）分离出来，用条件期望控制其影响。
  - **Bennett 不等式**：在 Theorem 2(ii) 中，用 Bennett 不等式控制大观测的贡献，得到对数改进。
- **证明的难点**：主要难点在于**协方差奇异**时，无法使用传统的 Cholesky 分解或特征值下界。作者通过**坐标标准化**和**高斯宽度**绕过了这一障碍。

**真实例子与应用**：
- **例子**：考虑 p = n 的情形，ξ_i 的坐标是独立同分布的 Rademacher 变量（取 ±1 等概率）。此时 Σ = I_p，g_Σ ~ √(2 log p) ~ √(2 log n)。Theorem 1 给出 ρ_R ≤ C δ √(log n) log n / √n，这与已知的最优速率一致。
- **应用**：该结果可直接用于高维检验中最大值统计量的临界值构造，例如高维均值向量的检验、高维协方差矩阵的检验等。在**计算受限**的场景下，高斯近似提供了一种快速且理论上可靠的替代方案。

**🔎 结论是否比证明窄**：
- **Theorem 1** 的证明是完整的，结论与证明匹配。
- **Theorem 2(i)** 的证明依赖于条件截断，结论中的对数因子 {log(en)}^{α_q} 在证明中明确出现，没有过度声明。
- **Theorem 2(ii)** 的证明中，Bennett 不等式的使用依赖于坐标四阶矩条件 (9)，结论中的 L_q 因子在证明中明确出现。
- **Corollary 3（多面体）** 的证明是转移论证，结论与证明匹配。
- **一个值得注意的点**：作者在 Section 5 中明确将 Conjecture 1（去除额外对数因子）作为开放问题，并指出 Theorem 1 的证明中该因子来自**第四阶余项的对数积分**。这意味着**结论的紧性**在证明层面并未完全解决，作者对此是诚实的。

### 四、开放问题（点到为止，扎根具体语句）

1. **Conjecture 1（去除额外对数因子）**：作者在 Section 5 中明确写道："我们猜想，在 (1) 下，ρ_R(W, Z) ≤ C min{1, δ g_Σ L} 成立，其中 L = log(ep)。" 这个猜想扎根于 Theorem 1 的证明中，额外因子 √D_L 来自第四阶余项的对数积分。**要确认这是否是真 gap**：去读 [2]（AL 2026）和 [27]（Lopes-Masini 2026）的近期工作，看他们是否在特定设定下解决了这个问题。
