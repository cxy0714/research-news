# Exact Simes inequalities for two-sided Gaussian tests

**主题**: 数理统计 / 假设检验  
**相关性**: 6/10  
**链接**: <https://arxiv.org/abs/2611.02513>

### 一、领域脉络与小综述

- **这个方向是什么**：本文研究的是多重检验中 Simes 检验在双侧高斯检验全局零假设下的 type I error 控制问题。具体而言，对于 m 个均值为零、方差为一的高斯随机变量（允许任意协方差结构），其双侧 p 值为 \(P_i = 2\bar{\Phi}(|Z_i|)\)，Simes 检验在名义水平 \(\alpha\) 下的拒绝概率为 \(F_\Sigma^{(m)}(\alpha) = \mathbb{P}\{P_{(k)} \le k\alpha/m \text{ for some } 1\le k\le m\}\)。核心问题是：是否对**所有**协方差矩阵 \(\Sigma\) 都有 \(F_\Sigma^{(m)}(\alpha) \le \alpha\)？该问题在任意协方差下是否成立此前悬而未决。该方向处于中等成熟度：经典结果覆盖独立情形（Simes, 1986）和正相依条件（如 PRDS，Benjamini and Yekutieli, 2001），但任意协方差（特别是负相关）下的精确有限样本控制仍是开放问题。

- **发展脉络（history）**：
  - **奠基工作**：Simes (1986) 证明了对独立均匀 p 值，拒绝概率恰为 \(\alpha\)。这是整个领域的起点。
  - **正相依扩展**：Sarkar (1998) 和 Benjamini-Yekutieli (2001) 将有效性推广到满足 PRDS（正回归相依于子集）的 p 值。Karlin and Rinott (1981) 给出了高斯向量绝对值满足 MTP2 的充要条件（逆协方差非对角元非正），这为 PRDS 提供了高斯特例。
  - **反例与边界**：Yekutieli (2008) 给出了两两比较中 Simes 检验在非 PRDS 情形下仍有效的例子，但仅限特定结构。Ristl et al. (2016) 对三个标准高斯变量（任意相关）证明了单侧阈值情形的概率上界，但未覆盖双侧 Simes 检验。
  - **近期进展**：Chen et al. (2026) 证明了 \(F_\Sigma^{(m)}(\alpha) = \alpha + o(\alpha)\) 的一阶渐近，但未确定误差符号。Dobriban (2026) 和 Lei (2026) 构造了含假备择时 FDR 超标的反例，说明全局零假设下的控制不能直接推广到混合情形。
  - **本文位置**：作者声称对固定 m 证明小水平下的精确不等式，并给出 m 增长时的显式阈值，填补了"任意协方差 + 双侧检验 + 精确有限样本"的空白。

- **子线索聚类**：
  1. **正相依条件下的有效性**（Simes 1986; Sarkar 1998; Benjamini-Yekutieli 2001）：核心工具是 MTP2/PRDS 和正相依不等式。局限：不覆盖负相关。
  2. **反例与边界情形**（Yekutieli 2008; Ristl et al. 2016; Finner-Roters 2024）：研究特定协方差结构（如两两比较、三变量）下的有效性或失效。局限：缺乏一般性。
  3. **渐近与一阶展开**（Chen et al. 2026）：证明 \(F_\Sigma = \alpha + o(\alpha)\)，但未解决符号问题。本文将其加强为精确不等式。
  4. **FDR 控制与混合情形**（Dobriban 2026; Lei 2026）：显示全局零假设下的控制不能自动推广到含假备择的情形，强调精确全局零假设分析的必要性。

- **这个方向在追问的核心问题**：
  1. **任意协方差下的 Simes 不等式是否成立？** 即 \(F_\Sigma^{(m)}(\alpha) \le \alpha\) 对所有 \(\Sigma \in C_m\) 是否成立？这是本文的核心问题。
  2. **等号何时成立？** 作者证明等号仅在独立或完全复制（up to sign）时成立，这给出了 Simes 检验"最坏情形"的完整刻画。
  3. **m 增长时如何保持有效性？** 当协方差结构允许稀疏相关（如度有界图）或独立块时，需要多大的 m 才能保证有效性？本文给出显式阈值。
  4. **与 FDR 控制的关系**：全局零假设下的精确控制是 FDR 控制的基础，但混合情形需要额外条件（如 Dobriban 2026 的反例所示）。

- **⚠️ 作者的 framing（必须明确标注成"这是作者的说法"）**：作者将缺口 frame 成"任意协方差下 Simes 不等式的精确有限样本证明"，并强调其结果是"对固定 m 的小水平有效性和 m 增长时的显式阈值"。作者淡化了以下竞争路线：(1) PRDS 条件虽然充分但不必要，本文的结果覆盖了 PRDS 失效的情形；(2) 渐近展开（Chen et al. 2026）无法确定误差符号，本文的精确不等式解决了这一问题；(3) 作者未讨论混合情形下的 FDR 控制，仅聚焦全局零假设。**值得研究者去查的问题**：作者声称的"小水平"阈值 \(a_m\) 是否在数值上足够大以覆盖实际使用的水平（如 0.05）？对 m=3 的 0.05 证明是否可推广到 m>3？作者未提及的"任意协方差"是否包含奇异协方差矩阵（文中允许半正定，但证明是否覆盖秩亏情形）？

- **张力**：未见明显对立引用。但存在一个潜在张力：Ristl et al. (2016) 对三变量单侧检验的证明依赖于协方差矩阵的特定参数化，而本文的三变量证明采用计算机辅助验证，两者方法不同但结论一致。另一个张力是：Yekutieli (2008) 的两两比较例子表明 Simes 检验在某些非 PRDS 情形下仍有效，但本文的定理 2.1 表明这种有效性在小水平下对所有协方差成立，这暗示 Yekutieli 的例子可能只是更一般现象的特例。

### 二、最核心、最简单的例子 / 数学问题

**第一步：把符号、模型、可观测数据交代清楚**

- **符号**：
  - \(m\)：检验总数（正整数）。
  - \(\Sigma \in C_m\)：\(m \times m\) 半正定相关矩阵（对角元为 1）。
  - \(Z = (Z_1, \dots, Z_m) \sim N_m(0, \Sigma)\)：高斯检验统计量向量。
  - \(P_i = 2\bar{\Phi}(|Z_i|)\)：第 i 个双侧 p 值，其中 \(\bar{\Phi} = 1 - \Phi\) 为标准正态生存函数。
  - \(P_{(1)} \le \dots \le P_{(m)}\)：p 值的顺序统计量。
  - \(F_\Sigma^{(m)}(\alpha) = \mathbb{P}\{P_{(k)} \le k\alpha/m \text{ for some } 1\le k\le m\}\)：Simes 检验的拒绝概率（全局零假设下）。
  - \(c_u = \bar{\Phi}^{-1}(u/2)\)：水平 u 对应的双侧高斯临界值。
  - \(E_m\)：\(m \times m\) 矩阵集合，由坐标置换和符号变化得到的分块对角全 1 矩阵（独立组内完全复制）。
  - \(a_m\)：定理 2.1 中的小水平阈值，依赖于 m。
  - \(F_w(\Gamma, \alpha)\)：带重复 p 值的拒绝概率，\(\Gamma\) 为 q 个代表变量的相关矩阵，w 为重复次数向量。
  - \(D_m = \sum_{e \in E(\Gamma)} d_e\)：图上的总亏损（pair deficits 之和）。
  - \(R\)：Simes 检验的最大拒绝秩（最大 k 使得 \(P_{(k)} \le k\alpha/m\)）。

- **模型**：数据生成机制为 \(Z \sim N_m(0, \Sigma)\)，其中 \(\Sigma\) 是任意半正定相关矩阵（允许奇异）。所有 m 个原假设均为真（全局零假设）。观测数据为 p 值向量 \((P_1, \dots, P_m)\)，Simes 检验在名义水平 \(\alpha\) 下拒绝全局零假设当且仅当存在 \(k \in \{1, \dots, m\}\) 使得 \(P_{(k)} \le k\alpha/m\)。

- **可观测数据**：研究者实际能观测到的是 p 值向量 \((P_1, \dots, P_m)\)，其联合分布由 \(\Sigma\) 决定。**想要但观测不到**的是：潜在的检验统计量 \(Z\) 的完整协方差结构 \(\Sigma\)（只能通过 p 值的联合行为间接推断），以及各检验统计量背后的潜在信号（在全局零假设下均为零）。关键识别问题是：仅从 p 值向量无法唯一确定 \(\Sigma\)，因此 Simes 检验的有效性必须对所有可能的 \(\Sigma\) 成立。

**第二步：讲最小内核**

本文的核心数学问题可以归结为以下最小内核：

> **最小命题**：对任意 \(m \ge 2\)，存在 \(a_m > 0\) 使得对所有 \(\Sigma \in C_m\) 和所有 \(0 < \alpha \le a_m\)，有 \(F_\Sigma^{(m)}(\alpha) \le \alpha\)，且等号当且仅当 \(\Sigma \in E_m\)。

**最简特例**：考虑 \(m = 2\) 的情形。此时 Simes 检验拒绝当且仅当 \(P_{(1)} \le \alpha/2\) 或 \(P_{(2)} \le \alpha\)。由于 \(P_{(2)} \le \alpha\) 意味着两个 p 值都不超过 \(\alpha\)，而 \(P_{(1)} \le \alpha/2\) 意味着至少一个 p 值很小。对于两个标准高斯变量 \(Z_1, Z_2\) 相关系数为 \(\rho\)，拒绝概率为：
\[
F_\Sigma^{(2)}(\alpha) = \mathbb{P}\{|Z_1| \ge c_{\alpha/2} \text{ 或 } |Z_2| \ge c_{\alpha/2} \text{ 或 } (|Z_1| \ge c_\alpha \text{ 且 } |Z_2| \ge c_\alpha)\}.
\]
当 \(\rho = 0\)（独立）时，\(F = 1 - (1-\alpha/2)^2 = \alpha - \alpha^2/4 < \alpha\)。当 \(\rho = 1\)（完全复制）时，\(F = \alpha\)。当 \(\rho = -1\) 时，\(Z_2 = -Z_1\)，两个 p 值相同，\(F = \alpha\)。对于中间相关，需要验证 \(F \le \alpha\)。本文的定理 2.1 保证对足够小的 \(\alpha\) 成立，且等号仅在 \(\rho = \pm 1\) 或 \(\rho = 0\) 时出现（后者对应 \(E_2\) 中的独立组）。

**为什么这个最小内核是核心**：整个证明的难点在于处理任意协方差矩阵。作者采用归纳法，将 m 个变量的问题归结为更少变量的问题。关键步骤是：
1. **对 p 值排序**：将 p 值按大小排序，考虑最大拒绝秩 R。
2. **分解拒绝概率**：将 \(F_\Sigma\) 分解为独立贡献（\(\alpha\)）减去 pair deficits（\(D_m\)）加上高阶误差。
3. **控制高阶误差**：通过图论方法（度有界图）和概率不等式（Chernoff 界、Gaussian 尾部估计）证明高阶误差远小于 pair deficits。
4. **归纳**：对代表变量数 q 归纳，每次处理一个"几乎复制"的簇。

这个最小内核展示了本文的核心思想：**Simes 检验的 type I error 控制可以归结为对 pair deficits 的精确估计**，而 pair deficits 总是非负的，因此只要高阶误差足够小，不等式就成立。

### 三、这篇论文做了什么

**三句话**：
1. **研究了什么问题**：Simes 检验在双侧高斯检验全局零假设下，对任意协方差矩阵的 type I error 控制问题，特别是小水平下的精确不等式和 m 增长时的显式阈值。
2. **核心工具 / 方法**：结合解析方法（Hermite 多项式展开、Gaussian 尾部估计、pair deficits 分解）和计算机辅助证明（有限证书、区间算术），通过归纳法处理任意协方差结构。
3. **主要结论**：对固定 m，存在小水平阈值 \(a_m\) 使得对所有协方差矩阵和所有 \(\alpha \le a_m\)，Simes 检验有效（拒绝概率 \(\le \alpha\)），等号仅在独立组内完全复制时成立；对 m 增长，在度有界图或独立块设定下，给出显式阈值和误差界。

**关键设定与假设**：
- **设定**：\(Z \sim N_m(0, \Sigma)\)，\(\Sigma\) 为半正定相关矩阵（允许奇异）。所有原假设为真。Simes 检验使用名义水平 \(\alpha\)。
- **假设**：
  - 固定参数：\(W\)（最大重复次数）、\(r_1\)（相关上界）、\(a_1\)（水平上界）、\(\beta\)（度增长参数）。
  - 度有界图：每个代表变量最多与 \(\Delta_m\) 个其他代表变量相关。
  - 独立块：变量分成独立块，块内任意相关，块间独立。
  - 水平上界：\(\alpha \le a_1 < 1\)。
  - 相关上界：\(|\Sigma_{ij}| \le r_1 < 1\)（对非复制对）。
- **相比已有文献**：本文不要求 PRDS 或 MTP2，允许任意符号的相关；不要求正定，允许奇异；不要求独立，允许任意相关结构（在度或块约束下）。

**主要结果**：
1. **定理 2.1（小水平有效性）**：对固定 m，存在 \(a_m > 0\) 使得对所有 \(\Sigma \in C_m\) 和所有 \(0 < \alpha \le a_m\)，\(F_\Sigma^{(m)}(\alpha) \le \alpha\)，等号当且仅当 \(\Sigma \in E_m\)（独立组内完全复制）。
2. **定理 3.1（三变量 0.05 水平）**：对 m=3，在 \(\alpha = 1/20\) 时，对所有协方差矩阵（包括奇异）有 \(F_\Sigma^{(3)}(1/20) \le 1/20\)，等号仅在独立或完全复制时成立。
3. **定理 4.1（图稀疏设定）**：当协方差图度有界（\(\Delta_m \log(\Delta_m+1) = o(\log m)\)）时，对所有 \(\alpha \le a_1\)，有 \(F_\Sigma = \alpha - D_m + o(D_m)\)，其中 \(D_m\) 是 pair deficits 之和，且 \(D_m > 0\) 当存在非平凡相关时。
4. **定理 5.1（混合设定）**：允许独立块（块内任意相关）加上图稀疏部分，给出类似的有效性结论。
5. **定理 5.2（块大小增长）**：当块大小 \(Q_m\) 满足特定增长条件时，有效性成立。
6. **命题 5.3（单变量超额）**：构造例子说明单个坐标的期望份额可以超过其名义份额，但整个块的份额不超过名义份额。

**证明路线与技术技巧**：
- **整体路线**：
  1. **分解**：将拒绝概率 \(F_\Sigma\) 分解为独立贡献 \(\alpha\) 减去 pair deficits \(D_m\) 加上高阶误差。
  2. **pair deficits 下界**：证明每个 pair deficit \(d_e > 0\) 当且仅当对应相关非零，且给出定量下界。
  3. **高阶误差上界**：通过图论方法（度有界图）和概率不等式（Chernoff 界、Gaussian 尾部估计）证明高阶误差远小于 pair deficits。
  4. **归纳**：对代表变量数 q 归纳，每次处理一个"几乎复制"的簇。
  5. **计算机辅助**：对三变量情形，将协方差空间划分为有限个区域，用区间算术验证每个区域的不等式。

- **关键技巧**：
  1. **Hermite 多项式展开**：将 p 值事件的指示函数展开为 Hermite 多项式，利用正交性分离不同阶的相关贡献。
  2. **pair deficits 分解**：将拒绝概率分解为独立贡献减去 pair deficits，每个 pair deficit 对应一条相关边。
  3. **图论方法**：用协方差图（节点为变量，边为相关）来组织高阶误差的估计，度有界图保证高阶项可控制。
  4. **Chernoff 界**：用于控制大量小 p 值同时出现的概率。
  5. **Gaussian 尾部估计**：结合 Mills 不等式和尾部渐近，给出临界值附近的精确估计。
  6. **计算机辅助证明**：对三变量情形，用区间算术和有限证书验证所有协方差区域。

**🔎 结论是否比证明窄**：
- 定理 2.1 的证明给出了 \(a_m\) 的存在性，但**没有给出数值**。作者在结论部分明确说"我们不知道 \(a_m\) 的数值"（对应原文 "We do not obtain numerical values for the general small-level cutoffs"）。这是一个明显的"结论比证明窄"的点：定理保证了存在性，但无法直接用于实际检验。
- 定理 3.1 的证明依赖计算机辅助验证，其有效性依赖于 IEEE 754 浮点运算的可靠性假设（原文 Section B.10 明确列出）。这是一个"证明依赖外部假设"的点。
- 定理 4.1 的证明要求度有界图，但**没有给出 \(\Delta_m\) 的具体上界**，只给出了渐近条件。实际应用中需要知道 \(\Delta_m\) 多大时有效。
- 定理 5.2 的证明给出了块大小增长条件，但**没有给出最优增长速率**，只给出了充分条件。
- 作者在结论部分承认："The general Simes inequality for two-sided Gaussian tests remains open"（对应原文 "The general Simes inequality for two-sided Gaussian tests remains open"），即对任意 m 和任意 \(\alpha\) 的完全控制仍未解决。

### 四、开放问题

1. **一般情形的 Simes 不等式**：对任意 m 和任意 \(\alpha \in (0,1)\)，是否对所有协方差矩阵有 \(F_\Sigma^{(m)}(\alpha) \le \alpha\)？本文只证明了小水平（定理 2.1）和特定 m（定理 3.1）。扎根于原文结论："The general Simes inequality for two-sided Gaussian tests remains open."

2. **数值阈值 \(a_m\)**：定理 2.1 中的 \(a_m\) 没有给出数值。能否计算或估计 \(a_m\) 的下界？扎根于原文："We do not obtain numerical values for the general small-level cutoffs."

3. **最优增长速率**：定理 5.2 给出了块大小增长条件，但最优速率未知。扎根于原文："The stated growth condition keeps these errors below the positive corrections in the proof."

4. **PRDS 条件的必要性**：本文的结果覆盖了 PRDS 失效的情形，但 PRDS 是否在某种意义上是"最优"的充分条件？扎根于原文 Section 7 对 PRDS 的讨论。

5. **混合情形的 FDR 控制**：本文仅处理全局零假设。当存在假备择时，Dobriban (2026) 和 Lei (2026) 的反例表明 FDR 控制可能失效。能否在本文的协方差条件下恢复 FDR 控制？扎根于原文 Section 7.3 的讨论。

6. **计算机辅助证明的可验证性**：定理 3.1 的证明依赖有限证书，能否用纯解析方法替代？扎根于原文 Section B.10 对计算假设的说明。
