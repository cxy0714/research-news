### 一、领域脉络与小综述

#### 这个方向是什么

本文所处的子方向是**因果效应的部分识别（partial identification）**，具体聚焦于一个在应用研究中极为常见但理论上尚未被充分系统化的困境：当我们想估计同一个处理（treatment）在多个不同"setting"（如不同地区、不同时期、不同子群体）下的因果效应时，往往在每个 setting 内部都无法找到理想的工具变量或自然实验，只能退而求其次依赖"可观测变量选择"（selection-on-observables）与条件独立性假设。然而，这类假设在任何一个 setting 中都可能被违反。本文的核心主张是：**即使每个 setting 单独来看都无法点识别因果效应，但如果我们愿意假设不同 setting 之间的遗漏变量偏误（omitted variable bias, OVB）存在某种结构性关系（如成比例），就可以联合收紧多个 setting 的识别集**。这个方向处于"敏感性分析"（sensitivity analysis）与"异质性因果效应"（heterogeneous treatment effects）的交汇处，成熟度属于"方法正在快速扩张但缺乏统一框架"的阶段。

#### 发展脉络（history）

- **奠基工作：敏感性分析的现代复兴**。本文的出发点直接承袭自 **Cinelli and Hazlett (2019)** 与 **Oster (2019)**。Cinelli and Hazlett 的关键贡献在于将传统的 OVB 公式重新参数化为偏 R²（partial R²）的形式，使得研究者可以直观地设定"未观测混杂与处理的偏 R²"以及"未观测混杂与结果的偏 R²"来构造偏误的边界。Oster (2019) 则提出了基于系数稳定性和 R² 移动的比例性假设（proportional selection relationship）。这两篇工作共同确立了"用可解释的敏感性参数来界定偏误"的现代范式，但它们都只处理**单一 setting** 的情形。
- **主要进展：从单 setting 到多 setting 的桥接**。本文的关键理论桥接在于 **Masten and Poirier (2018)**，他们提出了"条件部分独立"（conditional partial independence）的概念，允许处理分配概率在偏离条件独立假设时仍能导出识别集。本文将其从单一设定推广到多设定联合框架。另一条重要线索是 **Yadlowsky et al. (2022)**，他们用损失最小化框架估计 CATE 的边界，并显式建立了 CATE 边界与 ATE 边界之间的联系——这为本文"用 setting 间关系收紧联合识别集"提供了技术上的可行性论证。
- **当前 frontier：数据融合与跨设定推断**。最接近本文的前沿工作是 **Lanners et al. (2026)** 的数据融合部分识别框架，他们处理的是"多个数据源"（如 RCT + 观察性数据）的融合问题，而本文处理的是"多个 setting"（同一数据源内的子群体）的联合识别问题。两者在数学结构上高度相似（都是利用 setting 间的相似性来收紧识别集），但本文更强调"偏误比例性"这一具体假设，而非一般性的数据融合。此外，**Rambachan and Roth (2023)** 在 DID 框架下对平行趋势违背的敏感性分析（通过限制不同时期偏误的变化幅度）与本文的"限制 setting 间偏误关系"在精神上高度一致，但前者针对 DID 识别策略，后者针对 selection-on-observables。
- **本文的位置**：本文处于上述脉络的"收束点"——它把 Cinelli-Hazlett 式的单 setting 敏感性分析、Masten-Poirier 式的部分独立假设、以及 Rambachan-Roth 式的跨 setting 约束三者结合起来，提出了一个统一的"多 setting 联合识别集"框架。

#### 子线索聚类

1. **单 setting 敏感性分析**：Cinelli and Hazlett (2019)、Oster (2019)、Imbens (2003)、Altonji et al. (2005)。核心问题：给定一个 setting，如何用可解释参数界定 OVB 的影响？
2. **部分识别与边界估计**：Manski (2020)、Tamer (2010)、Masten and Poirier (2018)。核心问题：在弱假设下，因果参数的识别集是什么？如何构造？
3. **异质性效应与 CATE 估计**：Wager and Athey (2018)、Yadlowsky et al. (2022)。核心问题：如何估计随协变量或 setting 变化的因果效应？CATE 的边界如何与 ATE 的边界联系？
4. **跨 setting / 跨数据源融合**：Rambachan and Roth (2023)、Lanners et al. (2026)、Chen et al. (2023)。核心问题：如何利用 setting 间的相似性或数据源间的互补性来收紧识别？

#### 这个方向在追问的核心问题

- **Q1**：当条件独立假设在每个 setting 内部都不成立时，我们还能对因果效应说些什么？（答案：部分识别，而非点识别）
- **Q2**：如何将"setting 间偏误相关"这一先验知识形式化，并转化为对联合识别集的约束？
- **Q3**：联合识别集在什么条件下能严格小于各 setting 独立识别集的笛卡尔积？（即"1+1>2"何时成立）
- **Q4**：如何对部分识别集进行统计推断（置信区域），而非仅仅给出点估计？

#### ⚠️ 作者的 framing（这是作者的说法）

作者将缺口 frame 为：**"现有的部分识别方法（如 Cinelli-Hazlett）在每个 setting 内部独立应用时，往往产生过宽的边界，以至于结论缺乏信息量。但研究者通常面对的是多个 setting，且这些 setting 的偏误往往有共同的结构性来源（如相同的未观测混杂因素）。本文利用这一结构，通过约束 setting 间偏误的比例关系来收紧联合识别集。"** 作者淡化了以下竞争路线：(1) 寻找更好的工具变量或自然实验（作者认为这在多 setting 场景下往往不可得）；(2) 完全放弃因果解释，只报告关联性（作者认为这过于保守）；(3) 贝叶斯方法（作者未提及）。**值得研究者去查的问题**：作者没有引用任何关于"多 setting 联合识别"的已有工作（除了 Rambachan-Roth 和 Lanners et al.），这是否意味着这是一个真正未被系统化的 gap？还是说存在其他文献（如 meta-analysis 中的偏误调整方法）已经处理过类似问题但未被作者纳入？

#### 张力

未见明显对立引用。但存在一个微妙的张力：**Masten and Poirier (2018)** 的框架允许偏误方向在不同 setting 间变化（甚至符号相反），而本文的**比例性假设（Assumption 3）**本质上要求偏误方向一致（因为 ρ>0）。这意味着本文的方法在"偏误方向可能相反"的场景下会失效，而 Masten-Poirier 的框架则不会。作者没有明确讨论这一限制。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

**符号清单**（逐个点名）：

| 记号 | 含义 | 类型 |
|------|------|------|
| $S = \{1, \dots, K\}$ | setting 的集合（如州、年份、子群体） | 指标 |
| $i \in S$ | 某个特定 setting | 指标 |
| $Y_i$ | setting $i$ 中的结果变量（连续值） | 可观测随机变量 |
| $D_i$ | setting $i$ 中的处理变量（实值） | 可观测随机变量 |
| $X_i$ | setting $i$ 中的可观测协变量向量 | 可观测随机变量 |
| $A_i$ | setting $i$ 中的未观测协变量向量 | **不可观测**随机变量 |
| $\theta_i$ | setting $i$ 中的**真实因果效应**（目标 estimand） | 参数（要识别/估计的对象） |
| $\theta_i^s$ | setting $i$ 中"短回归"（遗漏 $A_i$）得到的概率极限 | 可识别参数（由可观测数据决定） |
| $f^i(\cdot)$ | setting $i$ 中的结果回归函数（含 $A_i$） | 未知函数 |
| $f^i_s(\cdot)$ | setting $i$ 中省略 $A_i$ 的结果回归函数 | 未知函数 |
| $B_i$ | setting $i$ 中的遗漏变量偏误：$B_i \equiv \theta_i^s - \theta_i$ | 不可观测的偏差项 |
| $\nu_i^l, \nu_i^u$ | $B_i$ 的已知下界和上界 | 用户设定的敏感性参数 |
| $\rho_{jk}$ | setting $j$ 与 $k$ 之间偏误的比例系数：$B_j = \rho_{jk} B_k$ | 用户设定的敏感性参数 |
| $\rho_{jk}^l, \rho_{jk}^u$ | $\rho_{jk}$ 的已知下界和上界 | 用户设定的敏感性参数 |

**模型**（每个 setting $i$ 内）：

**真实模型（长回归）**：
$$Y_i = \theta_i D_i + f^i(X_i, A_i) + \varepsilon_i, \quad E[\varepsilon_i | D_i, X_i, A_i] = 0$$

**估计模型（短回归，省略 $A_i$）**：
$$Y_i = \theta_i^s D_i + f^i_s(X_i) + \varepsilon_i^s$$

**可观测数据**：$\{(Y_{i,n}, D_{i,n}, X_{i,n})\}_{n=1}^{N_i}$，对每个 $i \in S$ 独立可得。注意：$A_i$ **从未被观测到**。

**关键区分**：
- **可观测**：$Y_i, D_i, X_i$（有样本）；$\theta_i^s$（可由短回归一致估计）。
- **不可观测（潜在/反事实）**：$A_i$；$\theta_i$（真实效应）；$B_i$（偏误）；$\rho_{jk}$（偏误比例）。

#### 第二步：最小内核

**剥掉所有一般性假设后，本文的核心数学问题是：**

> 给定每个 setting $i$ 的短回归估计 $\hat{\theta}_i^s$（或已知其概率极限 $\theta_i^s$），以及每个 setting 的偏误边界 $B_i \in [\nu_i^l, \nu_i^u]$，如果我们额外假设**偏误之间存在比例关系** $B_j = \rho_{jk} B_k$（其中 $\rho_{jk} \in [\rho_{jk}^l, \rho_{jk}^u]$），那么真实效应向量 $(\theta_1, \dots, \theta_K)$ 的联合识别集是什么？

**最简特例（K=2，对称边界）**：

设 $K=2$，两个 setting 的短回归估计分别为 $\theta_1^s = \theta_2^s = 1$。假设每个 setting 的偏误边界对称：$B_i \in [-1, 1]$（即 $\nu_i^l = -1, \nu_i^u = 1$）。

- **无跨 setting 约束时**：识别集为 $[0, 2] \times [0, 2]$（笛卡尔积）。
- **加入比例性假设**：设 $\rho_{12} \in [1/2, 2]$（即 $B_1$ 是 $B_2$ 的 0.5 到 2 倍）。则联合识别集变为：
  $$J_{12} = \{(\theta_1, \theta_2) : \theta_1 \in [0,2], \theta_2 \in [0,2], \theta_1 - \theta_2 \in [-c, c]\}$$
  其中 $c$ 由 $\rho$ 的边界决定。具体地，$B_1 - B_2 = (\rho_{12} - 1) B_2$，当 $\rho_{12} \in [1/2, 2]$ 且 $B_2 \in [-1, 1]$ 时，$B_1 - B_2 \in [-1, 1]$。因此 $\theta_1 - \theta_2 = (\theta_1^s - \theta_2^s) - (B_1 - B_2) = 0 - (B_1 - B_2) \in [-1, 1]$。

**为什么这个约束有用？** 它排除了 $(\theta_1, \theta_2) = (0, 2)$ 和 $(2, 0)$ 这样的极端组合——虽然每个 setting 单独看，这些值都在各自的识别集内，但联合来看，它们要求 $B_1$ 和 $B_2$ 的差异过大，与比例性假设矛盾。

**证明思路（最简版）**：
1. 由 $\theta_i = \theta_i^s - B_i$，识别集由 $B_i$ 的可行域决定。
2. 无约束时，$B_i$ 独立变化于 $[\nu_i^l, \nu_i^u]$，识别集为笛卡尔积。
3. 加入比例约束 $B_j = \rho_{jk} B_k$ 后，$B_j$ 和 $B_k$ 不再独立，可行域缩小为一条"带状"区域。
4. 联合识别集 $J_{jk}$ 是 $\theta_j^s - B_j$ 和 $\theta_k^s - B_k$ 在这个带状区域上的像。
5. 投影到单个维度（如 $\theta_j$）时，识别集可能不变（因为对任意 $B_j \in [\nu_j^l, \nu_j^u]$，总能找到合适的 $B_k$ 满足比例约束），但联合识别集严格变小。

**为什么一般情形只是"加壳"？** 当 $K > 2$ 时，比例约束变成一个线性不等式组，识别集变成一个多面体（polytope）。Proposition 4 的核心就是证明这个多面体可以由至多 $2K + K(K-1)$ 个线性不等式描述，并且每个 setting 的边际识别集可以通过线性规划求解。本质上，数学结构没有变——只是从二维的"带状区域"变成了高维的"多面体"。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：当研究者想在多个 setting 下估计因果效应，但每个 setting 都只能依赖可能被违反的 selection-on-observables 假设时，如何利用 setting 间遗漏变量偏误的结构性关系来收紧联合识别集。
2. **核心工具/方法**：将每个 setting 的 OVB 视为一个未知但有界的量，通过假设 setting 间 OVB 成比例（比例系数有界），构造联合识别多面体；提出"pinning"操作来探索条件识别集。
3. **主要结论**：联合识别集可以严格小于各 setting 独立识别集的笛卡尔积；边际识别集在特定条件下（Proposition 3）可以被收紧；但对称等边界情形下（Corollary 1），边际识别集可能不变，只有联合识别集变小。

#### 关键设定与假设

- **Assumption 1（部分线性模型）**：每个 setting 内，$Y_i = \theta_i D_i + f^i(X_i, A_i) + \varepsilon_i$，且 $E[\varepsilon_i | D_i, X_i, A_i] = 0$。这是标准的部分线性模型假设，允许 $f^i$ 完全非参数。相比 Cinelli-Hazlett 的线性模型设定，这是一个**推广**。
- **Assumption 2（OVB 有界性）**：$B_i \in [\nu_i^l, \nu_i^u]$，常数已知。这是敏感性分析的标准做法，但本文**没有**要求 $B_i$ 的符号已知（允许跨零），这比 Oster (2019) 的"比例选择"假设更弱。
- **Assumption 3（比例偏误关系）**：$B_j = \rho_{jk} B_k$，$\rho_{jk} \in [\rho_{jk}^l, \rho_{jk}^u]$，$0 < \rho_{jk}^l \le 1 \le \rho_{jk}^u$。这是本文的**核心新假设**。它隐含要求 $B_j$ 和 $B_k$ **同号**（除非一方为零）。相比 Masten-Poirier (2018) 允许偏误方向任意变化，这是一个**实质性限制**，作者在 Remark 中承认了这一点。
- **Assumption 4（比例混杂跨 setting）**：$B_i^{ss}$（由观测协变量子集引起的偏误）的比值可以用于界定 $\rho_{jk}$。这是"supershort"回归方法的基础，本质上是将 Cinelli-Hazlett 的"观测混杂可基准化"思想推广到跨 setting 情形。

**相比已有文献的强化/弱化**：
- 相比 Cinelli-Hazlett (2019)：从单 setting 推广到多 setting，但增加了比例性假设。
- 相比 Oster (2019)：不要求"选择比例"（selection proportionality）在 setting 内成立，但要求跨 setting 的比例关系。
- 相比 Rambachan-Roth (2023)：从 DID 的平行趋势违背推广到一般 OVB 框架，但失去了 DID 的特定结构（如时间趋势）。

#### 主要结果

**Proposition 1（单 setting 识别集）**：在 Assumptions 1-2 下，$\theta_i \in [\theta_i^s - \nu_i^u, \theta_i^s - \nu_i^l]$。这是标准结果，作为后续分析的基石。

**Proposition 2（双 setting 联合识别集）**：在 Assumptions 1-3 下，$(\theta_j, \theta_k)$ 属于一个由 6 个线性不等式定义的凸多边形（2 个来自单 setting 边界，4 个来自比例约束）。关键性质：联合识别集**总是**严格小于笛卡尔积 $I_j \times I_k$（除非 $\rho$ 的边界退化）。

**Proposition 3（边际收紧条件）**：给出了边际识别集被严格收紧的充要条件。核心条件是：$\nu_j^u > \nu_k^u + c_{jk}^u$ 或 $\nu_j^l < \nu_k^l + c_{jk}^l$（即一个 setting 的边界比另一个 setting 的边界加比例约束后的范围更宽）。**直觉**：只有当 setting $j$ 的单独识别集比 setting $k$ 的识别集（经比例约束映射后）更宽时，跨 setting 信息才能收紧 $j$ 的边际识别集。

**Corollary 1（对称边界无边际收紧）**：当 $\nu_j^l = -\nu_j^u$ 且 $\nu_k^l = -\nu_k^u$（对称边界）且 $\rho_{jk}^l = 1/\rho_{jk}^u$（对称比例）时，边际识别集**永远不会**被收紧。这是一个重要的负面结果：**对称假设下，跨 setting 信息只能收紧联合识别集，不能收紧任何单个 setting 的边际识别集**。

**Proposition 4（K-setting 推广）**：联合识别集是一个多面体，由至多 $2K + K(K-1)$ 个线性不等式定义。边际识别集可以通过线性规划求解。

#### 证明路线与技术技巧

**整体路线（3-5 步）**：

1. **从 OVB 定义出发**：$B_i = \theta_i^s - \theta_i = E[(g_i^s - g_i)(\alpha_i^s - \alpha_i)]$，将偏误表示为"结果回归误差"与"处理预测误差"的协方差。
2. **引入比例假设**：将 $B_j = \rho_{jk} B_k$ 转化为对 $(\theta_j, \theta_k)$ 的线性约束。关键技巧是**消去 $B_k$**：由 $B_k = \theta_k^s - \theta_k$，得 $B_j = \rho_{jk}(\theta_k^s - \theta_k)$，从而 $\theta_j = \theta_j^s - \rho_{jk}(\theta_k^s - \theta_k)$。
3. **构造联合识别集**：将单 setting 边界（Proposition 1）和比例约束（步骤 2）联立，得到一个由线性不等式定义的多面体。
4. **边际投影**：对多面体做投影（消去其他 setting 的变量），得到单个 setting 的边际识别集。这一步用到了**线性规划的对偶理论**——边际识别集的端点对应于约束条件的特定组合。
5. **收紧条件分析**：通过比较投影后的区间与原始单 setting 区间，推导 Proposition 3 的条件。

**关键跳跃点**：

- **难点 1**：如何从"偏误有界"过渡到"偏误成比例"而不丢失识别集的凸性？作者的处理是直接假设比例关系（Assumption 3），而非从更基本的假设推导。这避免了非线性约束，但代价是假设较强。
- **难点 2**：边际收紧条件的推导。这里的技巧是**将边际识别集的端点表示为约束条件的线性组合**，然后比较不同约束组合下的区间端点。Corollary 1 的证明特别精巧——它展示了在对称假设下，比例约束的投影恰好与原边界重合。
- **难点 3**：K-setting 情形下多面体的描述。作者没有试图显式刻画多面体的所有顶点，而是用线性规划来求解边际识别集，这大大简化了计算。

**技术技巧点名**：

- **Frisch-Waugh-Lovell 分解**：用于将 $\theta_i$ 表示为投影残差的协方差，这是 OVB 公式的现代表述。
- **线性规划/多面体投影**：用于计算 K-setting 情形下的边际识别集。
- **对偶理论**：用于推导边际收紧条件（Proposition 3 的证明）。
- **"Pinning"操作**：这不是一个数学技巧，而是一个**计算/可视化工具**，用于探索条件识别集——固定一个 setting 的值，看其他 setting 的识别集如何变化。

#### 真实例子与应用

**例子 1：大学教育回报随时间的变化（Section 6）**

- **数据**：美国社区调查（ACS）2003、2008、2013、2018、2023 年数据。
- **Setting**：5 个年份。
- **处理**：是否上过大学（至少一年）。
- **结果**：收入。
- **协变量**：种族、年龄、西班牙裔、性别、退伍军人身份、州、英语能力。
- **方法应用**：
  1. 在每个年份内，用短回归（含协变量）估计 $\hat{\theta}_i^s$。
  2. 用 Cinelli-Hazlett 方法设定每个年份的偏误边界 $[\nu_i^l, \nu_i^u]$（假设未观测混杂强度不超过观测混杂的一半）。
  3. 用 supershort 方法估计 $\rho_{jk}$ 的边界（比较加入/去掉协变量子集后的估计变化）。
  4. 计算联合识别集，并做 pinning 分析。
- **结果**：单独看，每个年份的识别集都较宽（约 ±0.1 的区间）；联合约束后，识别集略有缩小，但幅度不大。Pinning 分析显示，如果 2003 年的效应处于其识别集的高端，则其他年份的效应也被迫处于高端——即效应的时间趋势被约束为相对平滑。

**例子 2：大学教育回报的地理差异（Section 7）**

- **Setting**：美国各州（相邻州之间有约束）。
- **方法应用**：只对相邻州施加 $\rho_{jk}$ 约束（$\rho_{jk} \in [1/1.1, 1.1]$），非相邻州无约束。
- **结果**：对于识别集较宽的州（如内华达州），相邻州约束显著缩小了其识别集。这展示了"地理邻近性"作为偏误相关性的合理代理。

**例子说明什么**：两个例子分别展示了方法的两种应用场景——时间序列（约束效应平滑性）和横截面（约束空间相关性）。例 1 的结果相对温和（边际识别集几乎不变），例 2 的结果更显著（部分州的识别集大幅缩小）。这恰好验证了 Proposition 3 的预测：边际收紧取决于各 setting 识别集宽度的不对称性。

#### 🔎 结论是否比证明窄

- **明确承认的局限**：作者在 Conclusion 中明确说明"本文不提供统计推断方法"（即没有给出识别集的置信区域），并指出"识别集是 population 对象，未考虑 $\hat{\theta}_i^s$ 的抽样误差"。这是一个**诚实的窄化**——Proposition 2-4 只处理了识别（identification），而非估计（estimation）和推断（inference）。
- **隐含的过度 claim**：作者在 Abstract 中说方法"sharpens the jointly identified set"，但 Proposition 3 和 Corollary 1 表明，在对称边界下，**边际识别集完全不会被收紧**。作者在正文中承认了这一点，但 Abstract 的表述可能让读者高估方法的效力。
- **未证明的 conjecture**：作者在 Section 4.2 中建议用 supershort 回归来设定 $\rho_{jk}$ 的边界，但**没有证明** Assumption 4（比例混杂跨 setting）在什么条件下成立。这是一个明显的 gap——如果 Assumption 4 不成立，supershort 方法给出的 $\rho_{jk}$ 边界可能完全错误。
- **被淡化的竞争方法**：作者没有讨论贝叶斯方法（如带先验的层次模型）或 Rosenbaum 敏感性分析框架，这些方法也能处理多 setting 的偏误相关性问题。作者将本文定位为"frequentist 部分识别"框架下的贡献，但未解释为何该框架优于贝叶斯替代方案。

### 四、开放问题

1. **统计推断问题**（扎根于 Section 7 最后一段和 Conclusion）：作者明确说"本文不处理推断"。要建立识别集的置信区域，需要同时考虑 $\hat{\theta}_i^s$ 的抽样误差和 $\nu_i^l, \nu_i^u, \rho_{jk}^l, \rho_{jk}^u$ 的估计误差。这是一个自然的下一步，但技术上不平凡——多面体的端点是非光滑函数，标准的 delta method 不适用。**可查证方向**：读 Imbens and Manski (2004) 和 Stoye (2009) 关于部分识别置信区域的最新进展，看能否推广到多面体情形。

2. **Assumption 4 的检验问题**（扎根于 Section 4.2 的 Remark）：supershort 方法假设"观测协变量引起的偏误比例"可以代理"未观测协变量引起的偏误比例"。这个假设能否用数据检验？例如，能否用安慰剂检验（placebo test）——随机选择一个无关协变量作为"伪未观测混杂"，检验其偏误比例是否与 supershort 估计一致？**可查证方向**：读 Cinelli and Hazlett (2020) 关于"benchmarking"的讨论，看是否有现成的检验框架。

3. **偏误符号相反的情形**（扎根于 Assumption 3 的"同号"限制）：本文假设 $B_j$ 和 $B_k$ 同号（因为 $\rho > 0$）。如果研究者认为某些 setting 的偏误方向可能相反（例如，一个 setting 中高能力者更可能上大学，另一个 setting 中低能力者更可能上大学），本文的方法会失效。能否推广到允许 $\rho_{jk}$ 为负的情形？**可查证方向**：读 Masten and Poirier (2018) 的条件部分独立框架，看能否放松同号限制。

4. **非线性模型与离散结果的推广**（扎根于 Assumption 1 的线性设定）：本文的 OVB 公式依赖于线性模型。对于二元结果（如就业）或计数结果（如住院次数），偏误的结构会不同。能否将本文的框架推广到广义线性模型或非参数模型？**可查证方向**：读 Chernozhukov et al. (2026) 的推广，看他们如何处理非线性。

5. **"Pinning"的统计解释**（扎根于 Definition 3）：pinning 操作目前是纯描述性的——固定一个 setting 的值，看其他 setting 的识别集。能否为 pinning 结果提供统计推断？例如，能否构造"给定 $\theta_j = t$ 时 $\theta_k$ 的条件置信区域"？**可查证方向**：读 Imbens and Manski (2004) 关于条件置信区域的工作。
