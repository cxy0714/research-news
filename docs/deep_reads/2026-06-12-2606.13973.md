### 一、领域脉络与小综述

#### 这个方向是什么

本文所处的子方向是**点过程上的扫描统计量（scan statistics）**：在时间或空间域上滑动一个窗口，考察窗口内事件计数是否异常偏高，从而检测局部聚集（cluster）。其根本的统计问题是——在基线强度非齐次（nonhomogeneous）且未知的场景下，如何为"最大窗口计数"这个极值统计量构造可用的零分布，从而在控制第一类错误的前提下获得检验功效。该方向的成熟度属于"方法成熟但理论缺口明确"：经典扫描统计量理论（Glaz et al. 系列）覆盖了齐次 Poisson 和 i.i.d. 模型，但非齐次 Poisson 过程（NHPP）下的严格极限分布结果仍然稀缺，尤其是两样本设定。

#### 发展脉络（history）

- **奠基工作**：Glaz 与 Balakrishnan (1999) 主编的《Scan Statistics and Applications》和 Glaz, Naus, Wallenstein (2001) 的专著系统建立了扫描统计量的经典理论框架，覆盖离散与连续模型、精确与近似尾部概率计算方法。这是该领域的"教科书级"起点。
- **应用驱动的扩展**：Kulldorff 等 (2006) 将扫描统计量推广到椭圆窗口形状，Kulldorff 等 (2009) 将其用于连续型数据的空间聚类检测。这些工作把扫描统计量从理论工具推向公共卫生与流行病学的实际应用，但也暴露了非齐次基线下的校准困难。
- **点过程视角的引入**：Shen 和 Zhang (2012) 提出非齐次 Poisson 过程的变点模型，用于拷贝数变异（CNV）检测，用似然比统计量识别强度函数的局部变化。这是本文最直接的"前身"——同样的应用场景（CNV 检测）、同样的模型（NHPP），但 Shen-Zhang 走的是变点/分割路线，而非扫描统计量路线。
- **连续检验框架**：Picard, Reynaud-Bouret, Roquain (2018) 提出"连续检验"（continuous testing）框架，将滑动窗口上的局部检验视为一个连续统，通过控制 FWER/FDR 来报告显著窗口。这是本文的主要竞争对手——同样处理非齐次 Poisson 强度检验，但采用多重检验而非极值极限的路线。
- **本文的位置**：Wu (2017) 已证明离散网格扫描统计量在非齐次 Poisson 过程下收敛到连续扫描统计量（分布意义下），本文在此基础上进一步建立**极值极限定理**——证明网格扫描统计量（经归一化后）收敛到 GEV 分布，并用极值指数（extremal index）刻画重叠窗口的相关性。这是对 Wu (2017) 的实质性推进：从"近似连续"到"极限分布可计算"。

#### 子线索聚类

这些被引文献大致落在三条子线索上：

1. **扫描统计量的分布理论**（Glaz 系列、Wu 2017、本文）：核心问题是"最大窗口计数的零分布是什么"。经典方法依赖精确组合计算或 Poisson 近似；本文走的是极值极限路线——用 GEV 分布作为渐近近似。
2. **非齐次 Poisson 过程的变点/分割方法**（Shen-Zhang 2012）：核心问题是"强度函数在哪里发生了变化"。这类方法将检测问题转化为变点估计问题，输出的是分割点而非显著性检验。
3. **连续检验/多重检验框架**（Picard et al. 2018）：核心问题是"哪些窗口显著偏离零假设"。这类方法通过控制 FWER/FDR 来报告显著窗口集合，不依赖极值极限定理。

#### 这个方向在追问的核心问题

1. **非齐次基线下的零分布**：当基线强度 λ₀(t) 未知且非齐次时，扫描统计量的零分布是什么？经典理论假设齐次 Poisson 或 i.i.d.，直接套用到 NHPP 会失真。
2. **重叠窗口的相关性如何刻画**：相邻窗口共享大部分数据，导致窗口计数序列强相关。这种相关性对极值极限的影响是什么？如何量化？
3. **两样本设定下的校准**：当病例与对照的强度成比例（λ₁ = ρλ₀）时，如何构造不依赖 ρ 和 λ₀ 的检验统计量？本文用经验时间变换（empirical CDF transform）将问题归约为均匀分布上的扫描，这是一个关键技巧。

#### ⚠️ 作者的 framing（这是作者的说法）

作者把缺口 frame 成："在 NHPP 模型下，扫描统计量的严格零分布结果仍然有限，尤其是在两样本框架中"（引言原话："rigorous null distributions for scan statistics under nonhomogeneous Poisson process (NHPP) models remain limited, especially in the two-sample framework"）。由此，本文的贡献被定位为"显然的下一步"：既然 Wu (2017) 已经建立了网格到连续的收敛，那么下一步自然是建立极值极限定理并给出可操作的校准方法。

**被淡化或回避的竞争路线**：
- Picard et al. (2018) 的连续检验框架被用作 baseline 比较，但作者没有深入讨论两种框架在误差控制哲学上的差异——极值极限控制的是"最大窗口"的渐近第一类错误，而连续检验控制的是 FWER/FDR。两者在多重性校正上的立场不同。
- Shen-Zhang (2012) 的变点方法被引用为应用背景，但作者没有讨论变点方法与扫描统计量在检测精度上的理论比较（例如变点估计的收敛速率 vs 扫描检验的功效）。

**明显该被引、却没出现在 intro 里的**：作者引用了 Glaz 系列专著和 Kulldorff 的窗口形状扩展，但没有引用 **Janson (1984)** 关于扫描统计量极值极限的经典工作，也没有引用 **Arias-Castro, Donoho, Huo (2005)** 关于高维稀疏检测的扫描方法——后者与"局部聚集检测"在数学结构上高度相关，且其 minimax 速率分析可能为本文的功效分析提供参照。

#### 张力

未见明显对立引用。但存在一个值得注意的**方法路线张力**：Picard et al. (2018) 的连续检验框架强调"非渐近、有限样本"的误差控制（通过多重检验实现），而本文的 GEV 校准本质上是渐近的（依赖极值极限定理）。两种方法在有限样本下的行为可能显著不同——本文的模拟显示 GEV 校准在大窗口下第一类错误略偏高，这恰好印证了这一张力。作者对此的解释是"远离收缩窗口 regime"，但未给出定量刻画。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

**模型设定**（两样本 NHPP）：

- **可观测数据**：
  - 对照（control）样本：X₁, ..., X_{n₀}，为 [0,1] 上的点，来自强度 λ₀(t) 的 NHPP，条件于总数 n₀ 后为 i.i.d. 样本，密度 f_X(t) = λ₀(t)/Λ₀(1)。
  - 病例（case）样本：Y₁, ..., Y_{n₁}，为 [0,1] 上的点，来自强度 λ₁(t) 的 NHPP，条件于总数 n₁ 后为 i.i.d. 样本，密度 f_Y(t) = λ₁(t)/Λ₁(1)。
- **参数 /  estimand**：
  - λ₀(t), λ₁(t)：两个过程的强度函数（未知、非齐次）。
  - ρ > 0：零假设下的比例常数，λ₁(t) = ρλ₀(t)。
  - ω ∈ (0,1)：扫描窗口宽度（用户指定）。
  - τ ∈ [0, 1−ω]：聚集（cluster）的起始位置（备择假设下的未知参数）。
  - s：聚集的长度（备择假设下）。
  - c > 0：聚集的强度增量（备择假设下，λ₁(t) = λ₀(t) + c 在 [τ, τ+s] 内）。
- **潜在 / 不可观测量**：
  - 真实的强度函数 λ₀(t), λ₁(t) 本身不可观测，只能通过点过程实现来估计。
  - 零假设下的"理想"变换 F_X(t) = Λ₀(t)/Λ₀(1) 未知，只能用经验 CDF \hat{F}_X 近似。
- **关键变换**（本文的核心技巧）：
  - 定义 U_j = F_X(Y_j)，j = 1, ..., n₁。在零假设下，U_j 是 i.i.d. Uniform(0,1)。
  - 实际中使用 \hat{F}_X（对照样本的经验 CDF）代替 F_X，得到 V_j = \hat{F}_X(Y_j)。
  - 这个变换将"非齐次 Poisson 上的扫描"归约为"均匀分布上的扫描"，从而绕开了对 λ₀ 的显式建模。

**扫描统计量**：

- 网格版：在网格点 u_i = (i−1)Δ_m, i = 1, ..., m_{n₁} 上定义窗口计数
  C_i(ω) = Σ_{j=1}^{n₁} 1{V_j ∈ [u_i, u_i+ω]}，
  网格扫描统计量 S_m(ω) = max_{1≤i≤m_{n₁}} C_i(ω)。
- 连续版：S(ω) = sup_{0≤t≤1−ω} Y(t+ω) − Y(t)，其中 Y(t) 是病例过程的计数函数。

#### 第二步：最小内核

**剥掉所有一般性设定后，本文要解决的最小数学问题是**：

> **问题**：设 U₁, ..., U_n 是 i.i.d. Uniform(0,1)。在 [0,1] 上放置 m 个长度为 ω 的滑动窗口（窗口中心间距为 Δ_m），每个窗口内的点数记为 C_i（服从 Binomial(n, ω)）。令 M_m = max_{1≤i≤m} C_i。当 n → ∞, ω → 0, m → ∞ 时，M_m 的极限分布是什么？

**为什么这个最小问题是核心**：

- 如果 U_j 是均匀的，那么每个窗口计数 C_i ~ Binomial(n, ω)，边缘分布完全已知。
- 但相邻窗口共享数据，C_i 之间强相关——相关性由窗口重叠量决定：两个窗口中心距离为 kΔ_m 时，重叠长度为 max(0, ω − kΔ_m)。
- 极值极限的关键困难在于：**如何在强相关的序列中建立极值定理**。经典的 i.i.d. 极值理论（Fisher-Tippett-Gnedenko）不适用，因为 C_i 不是独立的。
- 本文的解法是：验证 Leadbetter 的分布混合条件（Lemma 3），从而将极值指数 θ 引入极限分布。**θ 量化了重叠窗口导致的"有效独立窗口数"的缩减**——若窗口完全独立则 θ = 1，完全重叠则 θ → 0。

**在这个最小例子下，要证的命题退化为**：

> 存在归一化常数 a_n > 0, b_n 使得
> P( (M_m − b_n)/a_n ≤ x ) → exp(−θ e^{−x})，
> 即 M_m 的极限分布是 Gumbel 分布的 θ 次幂（等价于 GEV 分布，ξ = 0，位置和尺度参数被吸收进 b_n 和 a_n）。

**证明的直观路径**（对应本文 Theorem 1 的证明结构）：

1. **边缘分布**：C_i ~ Binomial(n, ω)，用 Cramér 型大偏差近似得到尾部概率 P(C_i > b_n + a_n x) ≈ (1/n) e^{−x}（选择合适的 b_n, a_n）。
2. **混合条件**：验证分布混合条件（Lemma 3），即相距足够远的窗口计数近似独立。这需要 ω → 0 且 nω² → 0——直观上，窗口越窄，重叠区域越小，相关性越弱。
3. **极值指数**：由于相邻窗口强相关，极值事件（某个窗口计数超过阈值）倾向于成簇出现。θ 度量了簇的平均大小（的倒数）。用超阈值聚类法估计 θ。
4. **极限定理**：应用 Leadbetter 的极值定理，得到带极值指数的 Gumbel 极限。

**为什么这个证明有微妙之处**：

- Lemma 3 的证明依赖于 Poisson 化技巧（将固定 n₁ 的多项分布替换为 Poisson(n₁) 的独立增量过程），然后用 Le Cam 不等式控制两者之间的全变差距离。这个技巧在"固定 n₁"和"随机 N ~ Poisson(n₁)"之间架桥，是证明的技术核心。
- 条件 n₁ω² → 0 是关键的：它保证了窗口重叠区域内的期望点数趋于 0，从而相邻窗口的计数在渐近意义下"几乎独立"。若 n₁ω² 不趋于 0（如 ω = 0.05, n₁ = 5000 时 n₁ω² = 12.5），则混合条件可能不成立，GEV 近似的精度下降——这正是模拟中观察到的现象。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：在两样本非齐次 Poisson 过程框架下，如何为扫描统计量构造可用的零分布，从而在异质基线强度下检测局部聚集（如 CNV 扩增）。
2. **核心工具 / 方法**：经验时间变换（empirical CDF transform）将非齐次问题归约为均匀分布上的扫描；极值极限定理证明扫描统计量收敛到带极值指数的 GEV 分布；GEV 参数用极大似然估计，极值指数用超阈值聚类法估计；另提供置换检验作为非参数替代。
3. **主要结论**：GEV 校准在小窗口下能较好地控制第一类错误，置换校准在所有设定下均接近名义水平；两种方法在异质基线下的功效与连续检验方法（CTS）相当，且检测到的 CNV 区域与 SeqCBS 一致。

#### 关键设定与假设

- **两样本独立 NHPP**：对照 X ~ NHPP(λ₀)，病例 Y ~ NHPP(λ₁)，两者独立。零假设 H₀: λ₁ = ρλ₀（比例风险）。
- **条件于总数**：全文条件于 n₀ 和 n₁，将点过程转化为 i.i.d. 样本。这是一个标准但重要的简化——它避免了处理随机总数的额外复杂性。
- **窗口收缩条件**（Theorem 1 的核心假设）：
  - ω_{n₁} → 0（窗口宽度趋于 0）
  - n₁ω_{n₁} → ∞（窗口内期望点数趋于无穷）
  - n₁ω²_{n₁} → 0（窗口重叠区域的期望点数趋于 0）
  - n₁²Δ_m → 0（网格间距足够细）
  - log m_{n₁} = o((n₁ω_{n₁})^{1/3})（网格点数不能增长太快）
  - 这些条件共同刻画了"收缩窗口"（shrinking window）渐近 regime：窗口越来越窄，但包含的点数越来越多。
- **经验变换的近似**：实际中使用 \hat{F}_X 代替 F_X。作者在 Remark 中承认这引入了额外误差，但未给出严格的理论刻画（列为 future work）。

#### 主要结果

**理论结果（Theorem 1）**：

- 在 H₀ 和上述收缩条件下，网格扫描统计量 S_m(ω_{n₁}) 经归一化后依分布收敛到 GEV 分布（Gumbel 型，ξ = 0），即
  P( (S_m − b_{n₁})/a_{n₁} ≤ x ) → exp(−θ e^{−x})。
- 归一化常数 b_{n₁}, a_{n₁} 由二项分布尾部决定（具体形式为 b_{n₁} = n₁ω + σ d_m，其中 d_m 是 Gumbel 归一化常数，σ² = n₁ω(1−ω)）。
- **极值指数 θ 是关键新元素**：它捕捉了重叠窗口导致的依赖结构。θ 越小，依赖越强，极限分布的尾部越重（即观察到极端扫描统计量的概率越高）。

**方法贡献**：

1. **GEV 校准流程（Algorithm 1）**：
   - 用对照样本构造经验 CDF \hat{F}_X，变换病例样本得到 V_j。
   - 计算网格扫描统计量序列 {C_i}。
   - 设定高阈值 u（如 0.99 分位数），用超阈值聚类法估计极值指数 \hat{θ}。
   - 用极大似然估计 GEV 参数（μ, σ, ξ）。
   - 计算 (1−α) 分位数作为临界值，拒绝 H₀ 当 S_m 超过临界值。
   - 用 bootstrap（有放回抽样）生成多个 GEV 拟合，取中位数作为最终临界值，以平滑估计波动。

2. **置换检验**：作为非参数替代，通过随机重标号（pool 后随机分配 n₀/n₁）生成零分布。作者指出置换检验在有限样本下更可靠，但计算成本更高。

**模拟结果**：

- **第一类错误**：置换检验在所有设定下接近名义水平 0.05；GEV 校准在小窗口（ω = 0.005）下接近名义水平，但在大窗口（ω = 0.05）下偏高（约 0.08–0.12），与理论预测一致（远离收缩 regime）。
- **功效**：在嵌入 cluster 的备择假设下，GEV 和置换方法在大多数设定下功效相当，且在异质基线（线性、指数）下优于或持平 CTS。CTS 在快速增长的指数基线下表现较差，可能因其对基线强度的估计不够稳健。

**应用结果（CNV 检测）**：

- 使用 SeqCBS 包中的合成测序数据（模拟 HCC1954/BL1954 肿瘤-正常配对），n₀ = 15193, n₁ = 16452。
- GEV-ST 和置换方法在三个窗口宽度（ω = 0.005, 0.0075, 0.01）下均检测到相同的三个主要 CNV 区域，区间与 SeqCBS 报告的一致。
- CTS 在 ω = 0.0075 和 0.01 时额外检测到第四个区域，作者认为这可能是 CTS 对邻近或较宽局部偏离更敏感所致。

#### 证明路线与技术技巧

**整体路线**（Theorem 1 的证明结构）：

1. **归约为均匀情形**：在 H₀ 下，F_X(Y_j) 是 i.i.d. Uniform(0,1)，因此问题归约为均匀分布上的扫描统计量。
2. **边缘尾部近似**：对 Binomial(n₁, ω) 用 Cramér 型大偏差，得到在极端水平 b_{n₁} + a_{n₁}x 处的尾部概率 ≈ (1/m_{n₁}) e^{−x}。
3. **混合条件验证**（Lemma 3）：证明 {C_i} 满足分布混合条件。关键步骤：
   - 引入 Poisson 化模型（N ~ Poisson(n₁)），将固定 n₁ 的多项分布替换为独立增量过程。
   - 用 Le Cam 不等式（Poisson 二项近似）控制固定 n₁ 与 Poisson 化模型之间的全变差距离，误差为 O(n₁ω²)。
   - 在 Poisson 化模型中，相距超过 ⌈ω/Δ_m⌉ 的窗口计数独立，从而验证混合条件。
4. **极值定理应用**：引用 Leadbetter 的极值定理（适用于满足混合条件的平稳序列），得到带极值指数 θ 的 Gumbel 极限。

**技术技巧点名**：

- **Poisson 化 + Le Cam 不等式**：这是处理"固定 n₁ 的多项分布"与"独立 Poisson 增量"之间差异的标准技巧，但在这里被用于验证极值理论所需的混合条件，而非通常的分布近似。
- **超阈值聚类法估计 θ**：将超过阈值 u 的窗口计数按连续游程分组，θ̂ = n_c/n_u（簇数/超阈值数）。这是极值文献中估计极值指数的标准方法（见 Coles 2001, §8.2）。
- **Bootstrap 平滑 GEV 拟合**：对扫描统计量序列做有放回抽样，重复拟合 GEV，取参数中位数。这相当于一种 bagging 技巧，用于减少单次拟合的方差。

#### 🔎 结论是否比证明窄

**明确的窄结论**：

1. **Theorem 1 只对"网格"扫描统计量成立**，但实际应用和模拟中使用的是"连续"扫描统计量 S(ω) = sup_t Y(t+ω) − Y(t)。Lemma 4 证明了在 n₁²Δ_m → 0 的条件下两者以概率 1 相等，但这个条件在模拟中是否满足未经验证（Δ_m 的选择未在模拟部分明确说明）。
2. **Theorem 1 只对"已知 F_X"（oracle）情形成立**。实际中使用 \hat{F}_X 的误差被推迟到 future work。这是一个实质性的 gap——经验变换的误差可能改变极值极限的归一化常数。
3. **极值指数 θ 的估计一致性未证明**。作者使用超阈值聚类法估计 θ，但没有给出该估计量的渐近性质（如相合性、收敛速率）。模拟中 θ̂ 的波动可能影响 GEV 校准的精度。
4. **功效分析是纯模拟的**。论文没有提供任何理论功效下界或 minimax 分析，因此无法判断该方法在何种信号强度下是最优的。

**被泛化陈述但未证明的地方**：

- 引言声称方法"适用于广泛的非齐次基线"，但 Theorem 1 的证明实际上只要求变换后的点均匀分布，对 λ₀ 的具体形式没有额外假设——这一点是成立的。然而，**经验变换的误差可能依赖于 λ₀ 的光滑性**，这在 future work 中未被讨论。
- 结论部分声称"GEV 校准提供了计算高效的渐近替代"，但计算效率没有与置换检验或 CTS 做定量比较。

### 四、开放问题

以下问题均扎根于论文的具体语句，供你自行判断价值：

1. **经验变换的误差分析**（扎根于 Section 5："A full theoretical treatment of this empirical-transformation error is an important direction for future work"）。要证明：当 \hat{F}_X 代替 F_X 时，扫描统计量的极值极限是否仍然成立？归一化常数如何修正？这需要控制经验过程 \sqrt{n₀}(\hat{F}_X − F_X) 在极值水平上的影响——可能涉及加权经验过程与极值理论的结合。**这是一个理论上有实质难度的问题**，且与你的半参数理论背景直接相关。

2. **极值指数 θ 的估计理论**（扎根于 Section 2.3，作者仅给出估计量 θ̂ = n_c/n_u，未给出渐近性质）。要证明 θ̂ 的相合性和收敛速率，并刻画其对 GEV 分位数估计的影响。这涉及强相依序列的极值簇分析，可能需要引入关于窗口重叠结构的更精细条件。

3. **最优窗口宽度选择**（扎根于 Remark 3，作者仅给出 n₁ω → ∞ 和 n₁ω² → 0 的渐近约束，未讨论有限样本下的最优选择）。这是一个数据自适应的问题：如何在功效和分辨率之间权衡？可能需要对备择假设下的信号强度做更具体的假设（如 cluster 高度 c 和宽度 s 的缩放关系）。

4. **与高维扫描的联系**（扎根于引言对 CNV 检测的动机，但未讨论）。当基因组被划分为大量位点、每个位点独立做扫描检验时，如何控制全局错误率？这与多重检验的 FDR 控制直接相关，但论文没有讨论。**这可能是连接你高维统计背景的切入点**。

5. **功效的 minimax 分析**（论文完全没有涉及）。在收缩窗口 regime 下，扫描统计量检验的 minimax 检测边界是什么？与 Picard et al. (2018) 的连续检验方法相比，哪种方法在何种信号强度下更优？这需要将极值极限与检验功效的渐近分析结合。
