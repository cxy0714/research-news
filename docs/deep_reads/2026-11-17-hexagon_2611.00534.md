### 一、领域脉络与小综述（从 introduction + 参考文献 + 已构建摘要构建）

- **这个方向是什么**：本文属于微分几何与非线性偏微分方程（PDE）的交叉领域，研究的是**光滑闭曲面在三维欧氏空间中的等距弯曲（isometric bending）**。核心问题是：一个闭曲面（如球面）能否在保持其内蕴度量不变的前提下，在空间中发生非刚性的连续形变？这是一个经典的几何刚性问题，其现代形式可追溯到 Cohn-Vossen、Alexandrov 等人的工作，而本文则是在光滑（\(C^\infty\)）范畴内首次给出肯定回答。该问题的数学核心是求解一个**混合型 Monge–Ampère 型方程**（即 Darboux 方程），其类型（椭圆/双曲）随曲率符号变化，且需要在无穷多个类型转换点（turning circles）上满足高阶匹配条件。

- **发展脉络（history）**：
  - **奠基工作**：Cohn-Vossen [CV27, CV30] 与 Alexandrov [Ale47] 证明了凸闭曲面（正曲率）的刚性，即不存在非平凡的等距弯曲。这为问题划定了第一个边界：任何柔性例子必须包含负曲率区域。
  - **多面体情形**：Connelly [Con77] 构造了第一个**多面体**柔性球面，证明了在分段线性范畴内柔性是可能的。但多面体的棱边在光滑范畴内对应曲率奇点，无法直接推广。
  - **低正则性突破**：Nash [Nas54] 与 Kuiper [Kui55] 的 \(C^1\) 等距嵌入定理表明，在低正则性下几何刚性完全消失，但这与光滑情形有本质区别。
  - **局部与半整体结果**：Lin [Lin86]、Han [Han05]、Khovanskii [Khu07] 等处理了曲率在一条曲线上改变符号的局部问题，但均局限于有限个转换点或有限正则性。Han–Khuri [HK10, HK13] 的局部混合型方程理论是本文最直接的先驱，但其方法无法处理**无穷多个累积于边界的转换点**。
  - **本文的位置**：本文首次在**光滑闭曲面**上构造出非平凡的等距弯曲族，填补了 Connelly 多面体例子与光滑范畴之间的空白。其核心创新在于将 Nash–Moser 迭代与**精确可解的 Schrödinger 算子谱理论**结合，构造出具有无穷多个累积转换点的参考度量，并证明其线性化算子可逆。

- **子线索聚类**：
  1. **几何刚性理论**（[CV27, Her43, Pog73]）：凸曲面的刚性定理，为柔性例子设定曲率符号约束。
  2. **混合型 PDE 的局部理论**（[Lin86, Han05, Khu07, HK10, HK13]）：处理曲率符号变化处的方程类型转换，是本文分析工具的直接来源。
  3. **Nash–Moser 迭代与隐函数定理**（[Ham82]）：用于处理损失导数的非线性问题，本文将其应用于退化椭圆-双曲混合型方程。
  4. **可积系统与 Schrödinger 算子**（[Mor29, Tes09]）：Morse 势与谐振子的精确谱理论，为构造参考度量提供显式解。
  5. **柔性多面体**（[Con77]）：问题的组合几何版本，本文是其光滑类比。

- **这个方向在追问的核心问题**：
  1. **光滑闭曲面是否柔性？**（本文给出肯定回答，但仅对特定构造的度量）
  2. **柔性曲面的曲率分布有何约束？**（必须包含负曲率区域，且转换点需无穷累积）
  3. **等距弯曲族的正则性边界在哪里？**（\(C^1\) 柔性 vs \(C^\infty\) 刚性的分界）
  4. **混合型方程的全局可解性条件**（本文通过构造性方法绕过了抽象存在性）

- **⚠️ 作者的 framing（必须明确标注成"这是作者的说法"）**：
  - 作者将问题归结为"构造一个非径向高度函数 \(z\)，使其满足 Darboux 方程且在边界上平坦到无穷阶"，并声称"**一旦这样的高度函数存在，几何结论就自动成立**"（Theorem 2.5）。这实际上将几何问题完全转化为分析问题。
  - 作者强调"**参考度量的选择是自由的**"，即通过精心设计 \(w\) 的振荡模式来使线性化算子可逆。这暗示问题的难度不在于几何本身，而在于 PDE 的解析处理。
  - **被淡化/回避的竞争路线**：作者在 §1.7 提到 Sa Earp–Toubiana [SET02] 和 Ghomi–Qiu–Raffaelli–Zhang [GQRZ26] 构造了**成对**的等距非全等曲面，但明确指出这些工作不提供**连续路径**。作者将"连续路径"作为本文的核心贡献，但未讨论这些成对构造是否可能通过某种同伦方法升级为路径。
  - **明显该被引、却没出现在 intro 里的**：关于混合型方程的正规性理论（如 Tricomi 问题的一般理论），作者仅引用了 Han–Khuri 的局部结果，未提及更一般的全局存在性文献（如 Morawetz 的守恒律方法）。这可能是因为本文的构造性方法绕过了这些抽象理论。

- **张力**：未见明显对立引用。但存在一个微妙的内在张力：作者声称构造是"初等的"（elementary），但实际证明依赖于 Nash–Moser 迭代、精确谱理论、以及无穷多个转换点的精细匹配——这三者的结合远非初等。作者在 §1.6 承认"具体数字不重要"，但正是这些数字的选择（如指数 \(2n^3/3\)、\(n^{5/2}\)）构成了证明的骨架。

### 二、最核心、最简单的例子 / 数学问题（先把符号 / 模型 / 可观测数据交代清楚）

**第一步：把符号、模型、可观测数据交代清楚**

- **几何设定**：
  - \(\Sigma \subset \mathbb{R}^3\)：待构造的光滑嵌入球面（拓扑为 \(S^2\)）。
  - \(g\)：\(\Sigma\) 上的黎曼度量，由 \(\mathbb{R}^3\) 的欧氏度量诱导。
  - \(F_\tau : \Sigma \to \mathbb{R}^3\)：等距嵌入族，\(\tau \in \mathbb{R}\) 为参数，满足 \(F_\tau^* g_E = g_\Sigma\)（\(g_E\) 为欧氏度量），且 \(F_{\tau+1} = F_\tau\)（周期性）。
  - **非全等**：存在 \(\tau_1 \neq \tau_2\) 使得 \(F_{\tau_1}(\Sigma)\) 与 \(F_{\tau_2}(\Sigma)\) 不通过欧氏刚体运动重合。

- **分析设定**（核心简化）：
  - 极坐标 \((r, \theta) \in (r_-, r_+) \times \mathbb{T}\)，其中 \(\mathbb{T} = \mathbb{R}/2\pi\mathbb{Z}\)。
  - **径向斜率函数** \(w = w(r) > 0\)：决定旋转对称度量 \(g = (1 + w(r)^2) dr^2 + r^2 d\theta^2\)。这是**已知的、由我们设计的**参考度量。
  - **高度函数** \(z = z(r, \theta)\)：待求解的未知函数，决定嵌入 \(F(r, \theta) = (P(r, \theta), z(r, \theta))\)，其中 \(P\) 是平面极坐标。
  - **小参数** \(q\)：非线性问题的展开参数，\(z = h + q u\)，其中 \(h' = w\) 是径向高度（对应平凡嵌入），\(u\) 是待求的修正。
  - **Darboux 方程**：\(z\) 必须满足的标量 PDE，等价于要求度量 \(g - dz \otimes dz\) 平坦（即存在水平坐标 \(P\)）。这是**混合型**方程：在 \(w' > 0\) 处椭圆，在 \(w' < 0\) 处双曲。
  - **边界条件**：\(w\) 和 \(z\) 在 \(r_\pm\) 处平坦到无穷阶（即所有导数趋于零），使得嵌入可以光滑地封闭成球面。

- **可观测数据**：
  - 研究者**实际能观测到**的是：参考度量 \(g\)（即 \(w\) 的选择）、高度函数 \(z\) 的数值解、以及嵌入族 \(F_\tau\) 的几何性质（曲率、体积等）。
  - **不可直接观测**的是：线性化算子的谱性质、Nash–Moser 迭代的中间步骤——这些是证明的产物，而非输入。

**第二步：讲最小内核**

本文的数学核心可以归结为**一个线性算子的可逆性问题**。剥去所有几何外衣，支撑整篇论文的最小内核是：

> **构造一个一维 Schrödinger 算子族 \(H_j = -\partial_x^2 + V_j(x)\)，使得在某个能量 \(E=0\) 处，\(H_2\) 有唯一的束缚态（对应种子解 \(\phi_*\)），而所有 \(H_j\)（\(j \ge 4\) 偶数）在零能量处都有谱隙，且其逆在加权空间中一致有界。**

更具体地，最小内核包含三个步骤：

1. **谱设计**：通过 Liouville 变换（Lemma 4.3），将径向方程 \(L_j u = 0\) 化为 Schrödinger 方程 \(H_j \psi = 0\)。设计势函数 \(V_j(x) = V_0(x) - j^2 \rho(x)\)，使得：
   - 在中心区域（harmonic oscillator），\(V_2\) 在零能量处有简并的基态（给出种子 \(\phi_*\)）；
   - 在两端（Morse 势的无穷链），\(V_j\) 对 \(j \ge 4\) 在零能量处有正谱隙。

2. **逆算子构造**：在加权空间 \(Y_\gamma\) 中，通过"深逆"（deep inverse）和"浅逆"（shallow inverse）的拼接，构造 \(L_j\) 的逆。关键在于：
   - 深逆利用 Morse 势的**精确三递推关系**（Lemma 5.6），给出指数衰减的 Green 函数；
   - 浅逆利用谱隙和椭圆正则性，给出局部估计；
   - 两者在过渡区通过**匹配条件**（Lemma 5.9）拼接，保证整体有界。

3. **非线性迭代**：将 Darboux 方程写为 \(F_q(w, u) = 0\)，其线性化在参考解处为 \(L_{w_*}\)。通过 Nash–Moser 迭代（Hamilton 形式），每一步求解一个**带修正的线性方程**：
   \[
   \hat{L}_x \eta + \mu k_x = f
   \]
   其中 \(\hat{L}_x\) 是 \(L_{w_*}\) 的扰动，\(\mu\) 是标量参数（用于消除零模），\(k_x\) 是边界项。关键是证明扰动后的算子仍可逆，且逆满足 tame 估计（Proposition 8.1）。

**为什么这个内核是"最小"的**：去掉谱设计，则线性化算子有零模或共振，迭代无法进行；去掉深逆的精确递推，则无法处理无穷多个累积的转换点；去掉 Nash–Moser 框架，则无法处理损失导数的非线性项。三者缺一不可，而几何构造（Theorem 2.5）只是将分析结果翻译回几何语言。

### 三、这篇论文做了什么（本次重心，务必讲透）

**三句话**：
1. **研究了什么问题**：在光滑范畴内构造一个闭球面的非平凡等距弯曲族，即证明存在 \(C^\infty\) 光滑的柔性闭曲面。
2. **核心工具 / 方法**：将几何问题化为 Darboux 方程的求解，通过**精确可解的 Schrödinger 算子谱理论**（Morse 势 + 谐振子）构造参考度量，并用 **Nash–Moser 迭代**（Hamilton 形式）求解非线性方程。
3. **主要结论**：存在光滑嵌入球面 \(\Sigma \subset \mathbb{R}^3\) 及其周期为 1 的光滑等距弯曲族 \(F_\tau\)，使得 \(F_\tau(\Sigma)\) 不全等，且内盘与补帽在运动中保持固定。

**关键设定与假设**：
- **对称性假设**：度量 \(g\) 是旋转对称的（仅依赖 \(r\)），高度 \(z\) 是偶函数（\(\theta \mapsto \theta + \pi\) 对称）。这大大简化了方程，但并非本质限制。
- **平坦性假设**：\(w\) 在两端平坦到无穷阶，使得嵌入可以光滑封闭。这是构造的关键，也是与局部理论（有限阶平坦）的本质区别。
- **谱假设**：参考度量 \(w_*\) 的 Morse 势参数满足特定的无理条件（\(T_m/\pi\) 为二次无理数），以保证小除数估计（Lemma 4.7）。这是技术性假设，但作者通过显式构造证明了其可实现性。
- **相比已有文献的放宽/强化**：相比 Han–Khuri 的局部结果，本文**强化**了边界条件（无穷阶平坦 vs 有限阶），**放宽**了转换点数量（无穷多个 vs 有限个）；相比 Connelly 的多面体，本文**强化**了正则性（\(C^\infty\) vs 分片线性），但**限制**了度量形式（旋转对称）。

**主要结果**：
- **Theorem A**（几何结论）：存在光滑嵌入球面 \(\Sigma\) 及其等距弯曲族 \(F_\tau\)，满足周期性、固定子集、非全等性。
- **Theorem B**（分析结论）：存在径向斜率 \(w_*\) 和高度 \(z_*\)，使得 Darboux 方程有非径向解，且解在加权空间中光滑。
- **Theorem 10.3**（精确版本）：给出 \(w_*\) 和 \(z_*\) 的定量构造，包括所有常数和收敛速率。

**证明路线与技术技巧**：
- **整体路线**：几何归约（§2）→ 方程推导（§3）→ 参考度量构造（§4–5）→ 线性化算子求逆（§6）→ 非线性迭代（§7–9）→ 端点增益与几何封闭（§10）。
- **关键技巧 1：Liouville 变换**（Lemma 4.3）。将径向方程化为 Schrödinger 方程，使得谱理论可用。变换公式：
  \[
  L_j(P^{-1/2}\psi) = -\frac{\lambda\sqrt{P}}{r_X}(\partial_x^2 + V_0 - j^2\rho)\psi
  \]
  其中 \(x\) 是模型坐标，\(P\) 是密度，\(\rho\) 是曲率相关项。
- **关键技巧 2：Morse 势的精确谱**（§4.6）。Morse 势 \(V(x) = A(e^{-x} - e^{-2x}) - B\) 的束缚态能量为 \(E_m = j^2B - (j\sqrt{A} - m - 1/2)^2\)，通过选择参数使 \(E_0 = 0\) 且 \(E_m \neq 0\)（\(m \ge 1\)），得到谱隙。
- **关键技巧 3：三递推关系**（Lemma 5.6）。将 Schrödinger 方程离散化为三递推，利用连分数理论证明深逆的存在性和衰减性。递推系数为：
  \[
  b_n y_n = c_{n-1} y_{n-1} + c_n y_{n+1}, \quad b_n = \Lambda \mu_n R_n
  \]
  其中 \(\mu_n, R_n\) 是单元的质量和电阻。
- **关键技巧 4：残差修正**（§3.5, §7.5）。通过减去残差的倍数来固定线性化算子的类型转换点和返回映射。第一修正固定类型转换点，第二修正固定返回映射。修正项均为残差与固定函数的乘积，在解处为零。
- **关键技巧 5：Nash–Moser 迭代**（§9）。采用 Hamilton 的 tame 隐函数定理，每一步求解带修正的线性方程，利用 Proposition 8.1 的逆算子估计。迭代的二次误差项通过**损失导数**控制，最终得到光滑解。

**🔎 结论是否比证明窄**：
- **明确被证明、但未在 Theorem A 中强调的**：Theorem 10.3 实际上给出了**一族**参考度量（依赖于参数 \(c_0, \epsilon_R\) 等），而 Theorem A 只声称存在一个例子。作者在 §10.5 提到"参数可以连续变化"，但未证明这给出**连续族**的柔性曲面。
- **被泛化声称、但证明仅覆盖特定情形的**：作者在 §1.1 声称"内盘与补帽固定"，但证明中依赖于 \(\epsilon_R\) 的选取（§10.4），且未讨论 \(\epsilon_R \to 0\) 的极限行为。
- **被 conjecture 而非 theorem 的**：作者在 §1.7 提到"可能可以推广到更高亏格"，但未给出任何具体构造或证明思路。
