### 一、领域脉络与小综述

#### 这个方向是什么

本文所处的子方向是**随机对照试验（RCT）中回归调整估计量的高阶渐近理论**。其根本的统计问题是：当两个估计量在一阶（即 $\sqrt{n}$ 尺度）渐近等价时，如何通过二阶（$1/n$ 尺度）展开来区分它们的有限样本表现，从而为实证研究者在"简单回归调整"与"交互回归调整"之间做出有理论依据的选择。该方向目前处于**理论成熟但应用结论尚未统一**的阶段——一阶理论（即两者渐近方差相同）早已确立，但二阶理论直到本文才给出系统刻画。

#### 发展脉络

- **奠基工作：Freedman 的批评与 Lin 的回应。** Freedman [2008] 基于 Neyman 的随机化推断模型，批评回归调整可能导致渐近精度下降甚至推断失效。Lin [2013]（被引论文 [1]）在超总体抽样框架下回应了这一批评，证明当包含完整的处理-协变量交互项时，回归调整**不会**损害渐近精度，且交互回归弱支配简单回归。这一"弱支配"结论成为后续研究的基准。
- **主要进展：设计-based 与模型-based 框架的融合。** Li and Ding [2017] 建立了有限总体中心极限定理的一般形式（被引论文 [2]），为随机化推断提供了严格的渐近基础。Negi and Wooldridge [2021] 在超总体框架下进一步确认了交互回归的弱支配性，并指出其渐近方差的显式形式。这一阶段的核心结论是：**在一阶意义上，交互回归是安全且最优的选择**。
- **当前 frontier：一阶理论的盲区。** 当随机化概率 $\pi = 0.5$ 时，简单回归与交互回归的一阶渐近方差**完全相同**（见 Proposition 1 中 $V_{REG} = V_{IREG}$ 当 $\pi = 0.5$）。此时一阶理论完全失效，需要高阶展开来区分两者。Zhao and Ding [2023] 基于模拟和参数计数启发式提出简单回归可能更稳定，但缺乏严格理论。**本文正是填补这一空白**：给出两者在 $\pi = 0.5$ 时的二阶 MSE 差的确切公式。
- **本文的位置。** Kelley 和 Wager 将高阶渐近分析（Nagar [1959] 的矩展开传统）引入 RCT 回归调整的比较，首次给出 $D_p$ 的闭式表达式（定理 2），并系统刻画了使简单回归优于交互回归的条件。这是该子方向从"一阶弱支配"走向"二阶精细比较"的关键一步。

#### 子线索聚类

1. **设计-based 随机化推断**：Li and Ding [2017]，Lei and Ding [2021]，Chiang et al. [2025]。这一支关注有限总体下的精确推断，处理协变量维数随样本量增长的情形。
2. **超总体模型-based 回归调整**：Lin [2013]，Negi and Wooldridge [2021]。这一支在超总体抽样框架下比较不同回归调整策略的渐近效率。
3. **高阶渐近与 Edgeworth 展开**：Nagar [1959]，Sargan [1974, 1976]，Bhattacharya and Rao [1976]，Hall [1992]，Ghosh [1994]。这一支提供矩展开和分布近似的数学工具，是本文方法论的直接来源。
4. **异方差稳健方差估计**：MacKinnon and White [1985]，Chesher and Jewitt [1987]，Long and Ervin [2000]，Imbens and Kolesár [2016]。这一支关注有限样本下方差估计量的行为，是本文可行推断部分的基础。

#### 这个方向在追问的核心问题

1. **何时简单回归优于交互回归？** 一阶理论无法回答，二阶理论给出条件：取决于协变量分布的偏度、峰度、异方差性和非线性误设定（定理 2 的 $D_p$ 表达式）。
2. **高阶展开的可靠性边界在哪？** 本文附录 C 明确指出，在重尾分布下二阶近似可能失效，这直接关系到实证结论的可信度。
3. **方差估计量的选择如何影响推断有效性？** 本文比较了 HC1 与刀切法（jackknife）在不同设计下的覆盖概率，发现 HC1 在重尾或稀有极端值情形下严重不足。

#### ⚠️ 作者的 framing（这是作者的说法）

作者将缺口 frame 为："一阶理论在 $\pi = 0.5$ 时无法区分简单回归与交互回归，而现有文献（如 Zhao and Ding [2023]）仅凭模拟和启发式断言简单回归更优，缺乏严格理论。本文通过高阶渐近分析填补这一空白，并给出可操作的决策规则。" 作者淡化的竞争路线包括：(i) 设计-based 框架下有限样本精确推断（如随机化检验）作为替代方案；(ii) 非参数或机器学习回归调整方法（如交叉拟合估计量）的比较。**值得研究者去查的问题**：为什么本文没有讨论 $\pi$ 接近 0.5 但不等时的过渡行为？为什么没有与交叉拟合（cross-fitting）类估计量做二阶比较？这些在引言中均未提及。

#### 张力

未见明显对立引用。但存在一个微妙的张力：Lin [2013] 和 Negi and Wooldridge [2021] 的"交互回归弱支配"结论是在**所有** $\pi$ 下成立的，而本文表明在 $\pi = 0.5$ 时这一支配关系在二阶意义上可能反转。这不是逻辑矛盾（一阶支配不排除二阶反转），但确实是文献叙述中容易被忽视的细微差别。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

**设定**：完全随机化试验（CRT），$n$ 个独立同分布样本 $(X_i, Y_i(0), Y_i(1)) \sim P$，其中 $X_i \in \mathbb{R}^p$ 为协变量，$Y_i(0), Y_i(1)$ 为潜在结果。处理分配 $W_i \in \{0,1\}$ 满足 $\sum_{i=1}^n W_i = n_1 = \lfloor \pi n \rfloor$，且与 $(X_i, Y_i(0), Y_i(1))$ 独立。观测结果为 $Y_i = Y_i(W_i)$。

**参数 / 估计目标**：
- **因果参数**：$\tau = \mathbb{E}[Y_i(1) - Y_i(0)]$，即平均处理效应（ATE）。
- **辅助参数**：$\beta^*(w) = \arg\min_\beta \mathbb{E}[(Y_i(w) - X_i^\top \beta)^2]$，即第 $w$ 组潜在结果对协变量的最优线性预测系数；$\alpha^*(w)$ 为对应截距。$\gamma = \Sigma^{1/2}(\beta^*(1) - \beta^*(0))$ 为**线性处理效应异质性**的度量（经协方差白化后），$\Sigma = \text{Var}(X_i)$。

**可观测数据**：$(X_i, W_i, Y_i)$，$i = 1, \dots, n$。研究者**看不到** $Y_i(0)$ 和 $Y_i(1)$ 的联合分布，只能看到每个样本在其被分配组中的结果。

**两个估计量**（均含截距项）：
1. **简单回归（REG）**：拟合 $Y_i \sim \alpha + X_i^\top \beta + W_i \tau$，取 $W_i$ 的系数 $\hat{\tau}_{REG}$。
2. **交互回归（IREG）**：拟合 $Y_i \sim \alpha + X_i^\top \beta + W_i \tau + W_i X_i^\top \delta$，取 $W_i$ 的系数 $\hat{\tau}_{IREG}$。

**关键记号**：
- $Z_i = \Sigma^{-1/2} X_i$：白化协变量，满足 $\mathbb{E}[Z_i] = 0$，$\mathbb{E}[Z_i Z_i^\top] = I_p$。
- $\varepsilon_i(w) = Y_i(w) - \alpha^*(w) - X_i^\top \beta^*(w)$：第 $w$ 组的**oracle 残差**（最优线性预测误差）。
- $E = \mathbb{E}[Z_i Z_i^\top \varepsilon_i]$，$E_W = \frac{1}{4}(\mathbb{E}[Z_i Z_i^\top \varepsilon_i(1)] - \mathbb{E}[Z_i Z_i^\top \varepsilon_i(0)])$：残差与协变量的高阶矩耦合。
- $K = \mathbb{E}[Z_i Z_i^\top \|Z_i\|^2]$，$S = \mathbb{E}[Z_i \|Z_i\|^2]$，$S_\gamma = \mathbb{E}[Z_i Z_i^\top (Z_i^\top \gamma)]$。
- $V^* = \|\gamma\|^2 + 2\mathbb{E}[\varepsilon_i^2]$：一阶渐近方差（$\pi = 0.5$ 时两者相同）。
- $R^2_\tau = \|\gamma\|^2 / V^*$：线性处理效应异质性占一阶方差的比例。

**分布假设**（定理 2 的核心条件）：
1. $\mathbb{E}[\|X_i\|^{12}] < \infty$（12 阶矩有限）；
2. $\Sigma \succ 0$（协方差非退化）；
3. 潜在结果的条件矩满足 $\mathbb{E}[|Y_i(w)|^{12}] < \infty$；
4. 处理分配为固定比例 $\pi = 1/2$ 的完全随机化。

#### 第二步：最小内核

**核心问题**：当 $\pi = 0.5$ 时，$\hat{\tau}_{REG}$ 和 $\hat{\tau}_{IREG}$ 的一阶渐近方差相同（均为 $V^*/n$），那么它们的**二阶 MSE 差**是什么？

**最小例子**：考虑 $p = 1$（单个协变量），$X \sim N(0,1)$，潜在结果满足
$$Y_i(w) = \alpha^*(w) + \beta^*(w) X_i + \varepsilon_i(w),$$
其中 $\varepsilon_i(w)$ 与 $X_i$ 独立。此时：
- $\gamma = \beta^*(1) - \beta^*(0)$（标量），$V^* = \gamma^2 + 2\mathbb{E}[\varepsilon_i^2]$。
- 由于 $X$ 对称，$S = \mathbb{E}[Z \|Z\|^2] = \mathbb{E}[X^3] = 0$，$S_\gamma = \gamma \mathbb{E}[X^3] = 0$。
- 若 $\varepsilon_i(w)$ 与 $X_i$ 独立，则 $E = E_W = 0$。

此时定理 2 的 $D_p$ 表达式简化为：
$$D_p = -(2p + 3)\|\gamma\|^2 = -5\gamma^2.$$

**解释**：当协变量对称、残差同方差且与协变量独立时，交互回归的二阶 MSE 严格小于简单回归，差值为 $5\gamma^2/n^2$。这意味着**在一阶等价的情况下，交互回归在二阶意义上严格更优**，且优势随线性处理效应异质性 $\gamma$ 的增大而增大。

**为什么这个例子是"最小内核"**：它剥离了偏度（$S = 0$）、异方差性（$E = E_W = 0$）和非线性误设定（残差与协变量独立）等复杂因素，仅保留线性处理效应异质性 $\gamma$ 这一核心驱动因素。定理 2 的一般公式正是这个简单例子的"加壳"——当这些额外因素不为零时，它们会通过 $S$、$S_\gamma$、$E$、$E_W$ 等项进入 $D_p$，可能改变符号，使简单回归反而更优。

**关键直觉**：交互回归多估计了 $p$ 个交互项系数，引入了额外噪声；但它同时消除了简单回归因"池化"两组斜率而带来的**模型误设偏差**。在 $\pi = 0.5$ 时，一阶项完全抵消，二阶项中"偏差消除"与"方差增加"的竞争决定了谁更优。当 $\gamma$ 较大（处理效应异质性明显）时，偏差消除占主导，交互回归胜出；当协变量偏斜或异方差性使得高阶矩项 $S$、$E$ 等增大时，方差增加可能占主导，简单回归胜出。


### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：在 $\pi = 0.5$ 的完全随机化试验中，简单回归调整（REG）与交互回归调整（IREG）的一阶渐近方差相同，本文通过二阶渐近展开给出两者 MSE 差的闭式公式，从而在理论上回答"何时应选择简单回归而非交互回归"。
2. **核心工具 / 方法**：将估计量表示为样本矩的光滑函数，利用 Nagar [1959] 的矩展开方法，通过三阶 Taylor 展开和累积量计算，得到 MSE 差的 $1/n^2$ 阶系数 $D_p$；并利用刀切法（jackknife）和 HC1 方差估计进行可行推断。
3. **主要结论**：$D_p$ 由五个部分组成——线性处理效应异质性（$\gamma$）、协变量偏度（$S$）、峰度（$K$）、残差-协变量高阶矩耦合（$E$、$E_W$）和非线性误设——其符号取决于这些项的竞争；在协变量对称、残差同方差且独立时，交互回归严格更优（$D_p < 0$），但在偏斜或异方差情形下简单回归可能更优；对于可行推断，刀切法比 HC1 更可靠，尤其在重尾或稀有极端值情形下。

#### 关键设定与假设

- **完全随机化试验**：处理分配固定为 $\pi = 1/2$，且与潜在结果独立（即无混杂）。
- **超总体抽样**：$(X_i, Y_i(0), Y_i(1))$ 为 i.i.d. 抽样，而非有限总体固定。
- **12 阶矩条件**：$\mathbb{E}[\|X_i\|^{12}] < \infty$，$\mathbb{E}[|Y_i(w)|^{12}] < \infty$。这比一阶理论所需的二阶矩条件强得多，是为了保证三阶 Taylor 展开的余项可控。
- **协方差非退化**：$\Sigma \succ 0$，保证白化变换 $Z_i = \Sigma^{-1/2} X_i$ 良定义。
- **无唯一性假设**：当设计矩阵秩亏时（如稀有极端值导致某组内样本量不足），估计量可能不唯一；论文通过"完成规则"（finite completion）处理，并证明这对二阶渐近无影响。

**相比已有文献的放宽 / 强化**：
- 相比 Lin [2013] 和 Negi and Wooldridge [2021] 的一阶分析，本文**强化**了矩条件（从二阶到 12 阶），这是高阶展开的必要代价。
- 相比 Zhao and Ding [2023] 的模拟研究，本文**放宽**了对协变量分布的特定假设（如正态性），允许任意分布（只要 12 阶矩有限）。
- 相比设计-based 文献（Li and Ding [2017]），本文**强化**了抽样假设（超总体而非有限总体），但**放宽**了对处理分配机制的依赖（不需要精确固定组大小）。

#### 主要结果

**定理 2（核心定理）**：在定理 2 的条件下，当 $n \to \infty$ 时，
$$n^2 \left( \text{MSE}(\hat{\tau}_{IREG}) - \text{MSE}(\hat{\tau}_{REG}) \right) = D_p + o(1),$$
其中 $D_p$ 的表达式为：
$$D_p = -(2p+3)\|\gamma\|^2 + \gamma^\top K\gamma - (\gamma^\top S)^2 - 3\|S_\gamma\|^2_F - 16\text{tr}(S_\gamma E_W) - 8(\gamma^\top S)\text{tr}(E_W) + 8\gamma^\top E_W S + 8\text{tr}(E^2) + 8S^\top \mathbb{E}[Z\varepsilon^2].$$

**关键推论**：
- **Corollary 4（高斯同方差情形）**：若潜在结果满足线性模型且残差同方差、与协变量独立，则 $D_p = -(p+1)\|\gamma\|^2 < 0$（当 $\gamma \neq 0$），交互回归严格更优，且优势随 $p$ 线性增长。
- **Corollary 5（偏斜异方差情形）**：若残差方差与协变量范数成正比（$\varepsilon_i(w) = \eta_i \|Z_i\|$），则 $D_p$ 中会出现正的 $8\nu^2 \|S\|^2$ 项，可能使 $D_p > 0$，简单回归反而更优。这正是引言中例 (1) 的机制。

**可行推断（表 1-2）**：
- 在低 $R^2_\tau$（线性处理效应异质性占比小）时，REG + 刀切法是最可靠的选择，覆盖率达到名义水平。
- HC1 在偏斜或重尾设计下严重不足（覆盖低至 75%），而刀切法在大多数设计中表现稳健。
- 在高 $R^2_\tau$ 时，IREG + 刀切法是最优选择，但 HC1 仍不可靠。

#### 证明路线与技术技巧

**整体路线**（附录 A）：

1. **两样本表示**：利用完全随机化的条件独立性，将 $\hat{\tau}_{REG}$ 和 $\hat{\tau}_{IREG}$ 表示为处理组和对照组样本矩的函数 $h_{j,r}(\bar{U}_1, \bar{U}_0)$（Lemma 6）。
2. **Taylor 展开**：将 $h_{j,r}$ 在总体矩 $(\mu_1, \mu_0)$ 处做三阶 Taylor 展开，得到 $\hat{\tau}_j - \tau = q_1 + q_2 + q_3 + O_P(\|d\|^4)$，其中 $q_k$ 为 $k$ 阶齐次多项式。
3. **矩计算**：利用累积量方法和 $d$ 的矩结构（Lemma 8），计算 $n^2 \mathbb{E}[(q_1 + q_2 + q_3)^2]$ 的 $n^{-2}$ 阶系数。关键技巧是将 $d$ 的矩分解为处理组和对照组内部的累积量，利用 $W_i$ 的 Bernoulli 结构简化交叉项。
4. **Bernoulli 到 CRT 的校正**（Lemma 9-10）：先计算 Bernoulli 设计下的 $D_{Bern}$，再通过条件化于处理组大小 $n_1$，加上 $4G$ 的校正项得到 CRT 下的 $D_p$。这一步是技术难点——Bernoulli 设计下处理组大小随机，导致额外的方差贡献。
5. **符号计算验证**：使用 SymPy 进行符号计算，验证三阶 Taylor 展开中所有项的系数（附录 A 末尾提到的 verification 脚本）。

**关键技巧点名**：
- **累积量方法**：用累积量而非矩来计算 $d$ 的高阶矩，因为累积量在独立和条件下具有可加性，简化了处理组和对照组交叉项的计算。
- **控制变量（control variate）**：在模拟验证中，利用 $C_b = 2n^2 d_{1,b} L_b$ 作为控制变量，将 Monte Carlo 方差降低 4-11 倍。
- **刀切法**：直接对最终估计量 $\hat{\tau}$ 应用 delete-one jackknife，而非对回归系数，从而自动适应超总体抽样方差和模型误设。

#### 真实例子与应用

本文**没有真实数据应用**，但包含大量模拟实验：

- **表 1-2**：14 个 DGP，覆盖高斯、偏斜、重尾、稀有极端值等情形，$n = 500$，20,000 次重复。核心发现：低 $R^2_\tau$ 时 REG + 刀切法最优；高 $R^2_\tau$ 时 IREG + 刀切法最优；HC1 在偏斜或重尾下不可靠。
- **表 3-5**：验证定理 2 的 $D_p$ 公式，使用控制变量法精确估计 $n^2$ 阶 MSE 差，所有估计值在 2.6 个标准误内与理论值一致。
- **图 1-2**：18 个设计的 $z$-统计量，16 个在 $\pm 1.96$ 内，两个例外是重尾设计（有限样本偏差仍在 $n^{-3}$ 阶）。

**模拟想说明什么**：定理 2 的 $D_p$ 公式不仅是理论结果，还能准确预测有限样本行为；更重要的是，它揭示了"简单回归优于交互回归"的条件——偏斜协变量 + 异方差残差 + 低线性处理效应异质性——这些条件在实证数据中（如用户行为数据）很常见。

#### 🔎 结论是否比证明窄

- **定理 2 的证明**要求 12 阶矩有限，但**结论**在附录 C 中被用于重尾设计（如 $t$ 分布自由度 5），此时 12 阶矩不存在。作者承认"有限样本行为与渐近预测存在偏差"，但未给出重尾下的严格理论。
- **Corollary 4** 的"高斯同方差"假设在证明中并未显式使用——实际上只需 $E = E_W = 0$ 且 $S = 0$。作者在推论陈述中用了更强的假设，但证明实际覆盖了更广的情形。
- **可行推断部分**（表 1-2）的结论是**模拟结果**，而非定理。作者明确说"我们不从理论上证明刀切法的覆盖性质"，但结论部分暗示刀切法是"可靠选择"。
- **$\pi = 0.5$ 的限制**：定理 2 只处理等概率分配。作者在结论中推测 $\pi \neq 0.5$ 时一阶项会重新主导，但未给出证明。

### 四、开放问题

1. **$\pi \neq 0.5$ 时的二阶行为**：定理 2 只覆盖 $\pi = 1/2$。当 $\pi$ 偏离 0.5 时，一阶项 $(\pi - 1/2)^2$ 会以 $1/n$ 阶进入 MSE 差，此时简单回归与交互回归的排序如何变化？是否存在 $\pi$ 的临界值？——扎根于定理 2 的 $\pi = 1/2$ 限制和 Proposition 1 中 $V_{REG} - V_{IREG} \propto (1-2\pi)^2$ 的表达式。

2. **重尾分布下的高阶理论**：附录 C 显示，当 12 阶矩不存在时，$D_p$ 公式的预测与模拟存在系统偏差。能否建立重尾下的替代展开（如截断矩或稳健矩）？——扎根于附录 C 的表 7 和"tail sensitivity"讨论。

3. **非线性回归调整的二阶理论**：本文只考虑线性回归。若使用非参数或机器学习回归调整（如交叉拟合），其二阶行为如何？是否也存在类似的"偏差-方差权衡"？——扎根于引言中提到的"nonparametric adjustments"文献（如 Wager [2025] 的讨论）。

4. **多处理组与因子试验**：本文只处理二元处理。多处理组或因子设计下，回归调整的二阶比较是否会有新的结构？——扎根于 Zhao and Ding [2023] 对多处理组的模拟观察。

5. **可行推断的理论保证**：模拟显示刀切法覆盖良好，但缺乏理论证明。能否证明刀切法方差估计量在二阶意义下的一致性？——扎根于表 1-2 的模拟结果和"我们不做理论证明"的声明。
