**相关性**: 7/10  
**链接**: <https://arxiv.org/abs/2609.36387>

### 一、领域脉络与小综述

#### 这个方向是什么

本文研究的根本问题是：在随机对照试验（RCT）中，当主要结局变量（primary outcome）的测量成本高昂或耗时很长时，如何通过**自适应抽样设计**（adaptive sampling design）在有限的测量预算下，仍然对处理效应（treatment effect）进行有效且无偏的估计。该子方向处于"两相抽样"（two-phase sampling）与"因果推断"（causal inference）的交汇处，其核心张力在于：**抽样决策的灵活性（adaptivity）** 与 **统计推断的有效性（validity and efficiency）** 之间的权衡。该方向当前已具备较成熟的理论框架（半参数效率理论、鞅极限理论），但针对"设盲"（blinded）这一实际约束下的自适应设计，仍存在明确的理论缺口。

#### 发展脉络（history）

- **奠基工作：两相抽样与半参数推断**。该问题的统计根源可追溯至调查抽样中的两相设计（Särndal et al., 1992）以及缺失数据框架下的半参数推断（Robins et al., 1994; Tsiatis, 2006）。这些工作确立了"利用廉价辅助变量 + 对子样本测量昂贵变量"的基本范式，并给出了基于逆概率加权（IPW）或增广逆概率加权（AIPW）的有效估计框架。Tao et al. (2017, 2020) 将两相设计推广至遗传关联研究，系统研究了在给定第一相信息下如何最优选择第二相样本，其核心结论是：**最优抽样概率应与结局的条件残差标准差成正比**（Neyman 分配）。

- **主要进展：从固定设计到自适应设计**。McIsaac and Cook (2015) 首次提出**自适应两相设计**（adaptive two-phase design），即利用内部预试验（internal pilot）的数据来估计最优抽样方案，再据此对剩余样本进行抽样。Chen and Lumley (2020) 进一步将这一思想推广至多波（multi-wave）设计，并提出了基于影响函数（influence function）的抽样准则。Sauer et al. (2023) 则聚焦于实际操作层面，讨论了在整群随机设计中如何用 IPW 或多重插补（MI）来估计最优分配。Zeng et al. (2025) 将自适应分层设计推广至观察性研究中的平均因果效应估计。这一系列工作的共同逻辑是：**用已测量的数据来学习"哪些个体最值得测量"**。

- **当前 frontier：预测驱动与主动推断**。近期的两条前沿线索直接构成了本文的对话对象。其一是 **Prediction-Powered Inference (PPI)**（Angelopoulos et al., 2023）：利用机器学习预测作为辅助信息，对仅测量部分样本的结局进行有效推断，其核心思想是"预测 + 少量真实标签"即可获得有效估计。其二是 **Active Statistical Inference**（Zrnic and Candès, 2024）：将主动学习（active learning）的思想引入统计推断，允许抽样规则随数据积累而更新，并利用鞅中心极限定理（martingale CLT）给出有效的置信区间。这两条线索的共同点是：**预测模型的质量直接影响统计效率**，但均未考虑 RCT 中"设盲"这一操作约束。

- **本文的位置**：本文在上述脉络中填补了一个具体的缺口——**在设盲约束下**（即抽样决策不能使用处理分配信息），如何设计自适应抽样规则并保证估计的有效性。作者将 Zrnic and Candès (2024) 的鞅 CLT 框架移植到 RCT 的设盲场景，并给出了**估计抽样规则所损失方差的显式界**，将初始样本量、模型学习率与最终估计效率联系起来。这是对"自适应设计"文献的一个操作性补充：**在真实临床试验中，设盲不是可选的，而是监管要求**。

#### 子线索聚类

1. **效率理论线索**（Tao et al., 2017, 2020; Gilbert et al., 2014）：关注给定辅助信息下，两相抽样的**最优分配**及其半参数效率界。核心工具是影响函数与 Neyman 分配。本文的 Proposition 3 和 4 直接继承此线索。
2. **自适应设计线索**（McIsaac and Cook, 2015; Chen and Lumley, 2020; Sauer et al., 2023; Zeng et al., 2025）：关注如何**分阶段学习**最优抽样规则，核心工具是影响函数估计与多波抽样。本文的 Theorem 5 和 Corollary 6 属于此线索。
3. **预测驱动推断线索**（Angelopoulos et al., 2023; Zrnic and Candès, 2024; Kluger and Bates, 2026）：关注如何利用机器学习预测**指导抽样**并保证推断有效性，核心工具是鞅 CLT 与交叉拟合（cross-fitting）。本文的 Theorem 2 直接改编自 Zrnic and Candès (2024) 的 Proposition 6.1。
4. **临床试验操作线索**（Dodd et al., 2011; ICH E9, 1999）：关注设盲、独立裁决等**监管约束**下的统计设计。本文的设盲设定直接来源于此线索，但此线索中的统计方法多为简单随机抽样或固定分层，缺乏自适应机制。

#### 这个方向在追问的核心问题

1. **如何在不牺牲有效性的前提下，利用辅助变量提高抽样效率？** 主流答案是 AIPW 估计量 + 与残差标准差成比例的抽样概率（Neyman 分配），但这一答案依赖于对残差方差的准确估计。
2. **当最优抽样规则未知时，如何通过自适应学习逼近它？** 多波设计是主流方案，但现有理论对"学习误差"的刻画多为渐近的，缺乏有限样本的显式界。
3. **设盲约束对自适应设计的影响有多大？** 这是本文提出的新问题。设盲意味着抽样规则不能利用处理分配信息，这在两臂残差方差不等时会造成效率损失。本文给出了这一损失的显式分解。
4. **预测模型与抽样规则的交互如何影响最终推断？** 这是 PPI 与主动推断文献的核心关切，本文的 Theorem 5 给出了一个初步回答：预测误差通过残差方差误差进入方差损失，且该损失是线性的（一般情形）或二次的（无截断情形）。

#### ⚠️ 作者的 framing（这是作者的说法）

作者将本文的贡献框定为"**设盲自适应抽样**"（blinded adaptive sampling），并强调两个卖点：(i) 估计量对任意工作模型均无偏（Theorem 1），这继承了 AIPW 的稳健性；(ii) 给出了学习抽样规则的方差损失界，且该界将初始样本量与模型学习率联系起来（Theorem 5, Corollary 7）。作者将设盲设计的效率损失分解为两项：一项来自两臂残差方差不等（Gσ），另一项来自条件处理效应（Gd），并指出后者在零假设附近是二阶小量。**作者淡化了**以下竞争路线：(a) 完全忽略设盲约束、直接使用处理分配信息的"非设盲"设计（如 Gilbert et al., 2014），认为其在实际中不可行；(b) 固定分层设计（如 Mozer et al., 2026），认为其缺乏自适应性。**一个值得注意的回避**：作者在引言中承认"设盲设计因两臂残差方差不等而损失一项"，但并未讨论这一损失是否可以通过**事后**（post-hoc）利用处理分配信息来部分恢复——尽管 Remark 1 提到了臂特异预测的可能性，但明确将其留作未来工作。

#### 张力

- **未见明显对立引用**。被引工作之间在"最优抽样概率与残差标准差成正比"这一核心结论上高度一致（Gilbert et al., 2014; Tao et al., 2017; Zrnic and Candès, 2024; Kluger and Bates, 2026）。一个微妙的张力存在于 PPI（Angelopoulos et al., 2023）与主动推断（Zrnic and Candès, 2024）之间：PPI 强调"预测 + 随机抽样"即可获得有效推断，而主动推断强调"预测指导抽样"可以进一步提高效率。本文站在后者一边，但 Theorem 5 表明：当预测模型较差时，自适应抽样可能不如简单随机抽样（见 Sfyraki and Wang, 2026 的发现），这是一个值得注意的边界条件。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

**符号清单**（按类别分组）：

| 类别 | 符号 | 含义 |
|------|------|------|
| **参数 / 估计目标** | $\Delta = \mu_1 - \mu_0$ | 边际处理效应（estimand），即两臂结局均值之差 |
| | $\mu_a = E(Y_i^a)$ | 潜在结局 $Y_i^a$ 的期望（$a \in \{0,1\}$） |
| **随机变量 / 样本** | $A_i \in \{0,1\}$ | 随机化处理分配（已知，但设盲期间对抽样者不可见） |
| | $X_i$ | 辅助变量（对所有受试者可见，廉价） |
| | $Y_i$ | 昂贵结局（仅对抽样选中的受试者测量） |
| | $R_i \in \{0,1\}$ | 结局是否被测量的指示变量 |
| | $Y_i^a$ | 潜在结局（counterfactual，不可观测） |
| **维数 / 样本量** | $n$ | 总样本量 |
| | $m = \|S_0\|$ | 初始随机样本量 |
| | $n_a$ | 臂 $a$ 的样本量 |
| **设计参数** | $\pi_i(X_i)$ | 第 $i$ 个受试者的抽样概率（由 $H_{i-1}$ 决定） |
| | $\epsilon, u$ | 抽样概率的下界和上界（$0 < \epsilon \le \pi_i \le u \le 1$） |
| | $\rho$ | 期望测量比例 |
| **模型对象** | $f_i(X_i)$ | 结局的预测模型（工作模型，可错误） |
| | $r_i(X_i)$ | 残差方差模型 $E[\{Y - f_i(X)\}^2 \mid X]$ |
| **信息集** | $H_{i-1}$ | 决策前可用的信息（含 $X$、$S_0$、已测结局，**不含** $A$） |
| | $D_n$ | 完整试验数据（含所有 $A, X, Y$，仅用于理论分析） |

**数据生成机制**：

1. 受试者 $i = 1, \dots, n$ 独立同分布，具有潜在结局 $(Y_i^0, Y_i^1)$ 和辅助变量 $X_i$。
2. 处理分配 $A_i$ 独立于 $(X_i, Y_i^0, Y_i^1)$，且 $P(A_i = a) = p_a$（已知，有界远离 0）。
3. **设盲约束**：抽样决策者只能看到 $H_{i-1}$（含 $X$、初始样本、已测结局），**看不到** $A_i$。
4. **抽样机制**：$P(R_i = 1 \mid D_n, S_0, R_1, \dots, R_{i-1}) = \pi_i(X_i)$，其中 $\pi_i$ 是 $H_{i-1}$-可测的，且 $\epsilon \le \pi_i \le 1$。这称为**可预测抽样**（predictable sampling）。
5. **可观测数据**：对所有 $i$ 观测 $(A_i, X_i)$；对 $R_i = 1$ 的个体观测 $Y_i$；对 $R_i = 0$ 的个体 $Y_i$ 缺失。

**核心识别假设**：一致性（$Y_i = Y_i^{A_i}$）+ 随机化（$A_i \perp (Y_i^0, Y_i^1)$）。注意：**不需要**假设工作模型 $f_i$ 正确，也不需要假设抽样机制已知（只需记录）。

#### 第二步：最小内核

**问题**：设 $n = 4$ 名受试者，$A = (1, 1, 0, 0)$，$X = (x_1, x_2, x_3, x_4)$。预算只允许测量 2 个结局。如何选择测量对象，使得 $\hat{\Delta}$ 的方差最小？

**核心思想**：将估计量写成"预测 + 纠偏"的形式。对每个受试者定义**修正结局**（corrected outcome）：

$$U_i = f_i(X_i) + \frac{R_i}{\pi_i(X_i)}[Y_i - f_i(X_i)]$$

**关键观察**：$U_i$ 的构造使得 $E(U_i \mid D_n, S_0) = Y_i$（Theorem 1）。这意味着**无论 $f_i$ 和 $\pi_i$ 如何选择**（只要满足可预测性），$\hat{\Delta}$ 都是 $\Delta_n$（完整数据下的处理效应）的无偏估计。预测模型 $f_i$ 的作用不是消除偏差，而是**降低方差**：当 $f_i$ 接近真实条件均值时，$Y_i - f_i(X_i)$ 的方差变小，从而抽样不确定性对估计量的影响变小。

**最小例子**：假设 $f_i(x) \equiv \bar{Y}_{S_0}$（初始样本均值），$\pi_i(x) \equiv 1/2$（均匀抽样）。则：

$$U_i = \bar{Y}_{S_0} + 2R_i(Y_i - \bar{Y}_{S_0})$$

- 若 $R_i = 1$：$U_i = 2Y_i - \bar{Y}_{S_0}$
- 若 $R_i = 0$：$U_i = \bar{Y}_{S_0}$

**为什么有效**：$E(U_i \mid D_n, S_0) = \bar{Y}_{S_0} + 2 \cdot \frac{1}{2}(Y_i - \bar{Y}_{S_0}) = Y_i$。无偏性来自**已知的抽样概率**，而非模型的正确性。

**最优抽样规则**：若 $f_i$ 固定，最优 $\pi_i$ 与 $|Y_i - f_i(X_i)|$ 成正比（Neyman 分配）。但 $Y_i$ 未知，所以用 $\sqrt{r_i(X_i)}$ 近似，其中 $r_i$ 是残差方差的估计。**自适应**体现在：先用初始样本估计 $r_i$，再据此设定后续抽样概率。

**本文的核心数学贡献**：当 $\pi_i$ 和 $f_i$ 是从数据中学习的（而非预先固定），Theorem 5 给出了方差损失的显式界。该界将损失分解为两部分：残差方差模型的估计误差（线性项）和预测模型的估计误差（二次项，无截断时）。这回答了"**学习抽样规则本身需要付出多少代价**"这一核心问题。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：在 RCT 中，当结局测量昂贵且抽样决策者对处理分配设盲时，如何设计自适应抽样规则以最小化处理效应估计的方差，同时保证估计的无偏性和置信区间的有效性。
2. **核心工具 / 方法**：增广逆概率加权（AIPW）估计量 + 可预测抽样规则 + 鞅中心极限定理（martingale CLT），并给出了学习抽样规则的方差损失界。
3. **主要结论**：设盲自适应抽样对任意工作模型均无偏；方差损失可分解为残差方差模型误差（线性）和预测模型误差（二次，无截断时）；与使用处理分配的设计相比，设盲设计损失两项——一项来自两臂残差方差不等（Gσ），另一项来自条件处理效应（Gd），后者在零假设附近是二阶小量。

#### 关键设定与假设

- **可预测抽样**（公式 1）：$P(R_i = 1 \mid D_n, S_0, R_1, \ldots, R_{i-1}) = \pi_i(X_i)$，且 $\pi_i$ 是 $H_{i-1}$-可测的。这是整个理论的基石，它保证了鞅差结构，使得 Theorem 1 和 2 成立。相比 Zrnic and Candès (2024) 的设定，本文增加了**设盲约束**（$H_{i-1}$ 不含 $A_i$），这是一个实质性的收紧。
- **概率有界**：$\epsilon \le \pi_i \le u \le 1$，保证逆概率权重不会爆炸。
- **矩条件**：$\sup_{i,n} E\{Y_i^4 + f_i(X_i)^4\} < \infty$，用于鞅 CLT 的 Lyapunov 条件。
- **固定臂样本量**：$n_a$ 由设计固定（RCT 的标准设定），这简化了渐近分析。
- **无正确模型假设**：$f_i$ 和 $r_i$ 可以是错误的，不影响无偏性，只影响效率。

**相比已有文献的放宽/收紧**：
- 相比 Tao et al. (2017, 2020)：本文允许**多波自适应更新**，而非一次性固定抽样概率。
- 相比 Zrnic and Candès (2024)：本文增加了**设盲约束**，并给出了设盲与非设盲设计的效率比较（Theorem 8）。
- 相比 Kluger and Bates (2026)：本文聚焦于**均值差**这一简单估计目标，而非一般 M-估计量，但给出了更精细的方差损失分解。

#### 主要结果

**Theorem 1（抽样无偏性）**：$E(\hat{\Delta} \mid D_n, S_0) = \Delta_n$。这是 AIPW 估计量的标准性质，但本文的贡献在于证明了它在**自适应、可预测、设盲**抽样下仍然成立。证明只需一步条件期望，核心是 $E(R_i/\pi_i \mid D_n, S_0, H_{i-1}) = 1$。

**Theorem 2（渐近正态性）**：$\sqrt{n}(\hat{\Delta} - \Delta) \xrightarrow{d} N(0, V_Y + V_R)$，其中 $V_Y$ 是完整数据下的方差，$V_R$ 是抽样带来的额外方差。证明路线：
1. 将 $\hat{\Delta} - \Delta$ 分解为 $(\Delta_n - \Delta) + (\hat{\Delta} - \Delta_n)$。
2. 第一项是完整数据的中心极限定理，方差 $V_Y$。
3. 第二项是鞅差序列的和，条件方差由 (5) 给出，即 $V_R$。
4. 用鞅 CLT（Hall and Heyde, 1980, Ch. 3）证明联合正态性，关键是验证条件 Lindeberg 条件，这由四阶矩条件和概率下界 $\epsilon$ 保证。
5. 标准误 (6) 的相合性由 $s_a^2 \xrightarrow{p} \text{Var}(U \mid A = a)$ 和鞅差项的方差估计给出。

**Proposition 3（Oracle 抽样概率）**：最优抽样概率 $\pi^*(x) \propto \sqrt{r_f(x)}$，截断到 $[\epsilon, u]$。这是 Neyman 分配在两相抽样中的直接应用，证明用 Cauchy-Schwarz 不等式。

**Proposition 4（Oracle 节省的测量数）**：简单随机抽样需要 $\rho_s = \rho(1 + \kappa_f^2)$ 的测量比例才能达到与 oracle 自适应抽样相同的方差，其中 $\kappa_f$ 是残差标准差的变异系数。这个结果将效率提升量化为了一个简洁的、只依赖于残差标准差变异程度的量。

**Theorem 5（学习抽样规则的代价）**：这是本文的技术核心。它给出了使用估计的 $\hat{r}_k$ 代替真实 $r$ 所造成的方差损失的上界：
- 一般情形：损失 $\le C_\epsilon \|\hat{r}_k - r_k\|_1$（线性界）
- 无截断情形：损失 $\le \frac{E\sqrt{\hat{r}_k}}{\rho} \cdot \frac{1}{\sqrt{r_{\min}}} \|\sqrt{\hat{r}_k} - \sqrt{r_k}\|_2^2$（二次界）

证明路线：
1. 利用 $L_r(\pi)$ 在最优 $\pi^*$ 处的一阶条件，将 $L_r(\hat{\pi}) - L_r(\pi^*)$ 表示为 $\hat{\pi}$ 与 $\pi^*$ 的偏差的二次型。
2. 对一般情形，用 $\hat{\pi}, \pi^* \in [\epsilon, u]$ 的有界性直接放缩，得到线性界。
3. 对无截断情形，利用 $\hat{\pi} = \rho \sqrt{\hat{r}}/E\sqrt{\hat{r}}$ 的显式形式，将偏差表示为 $\sqrt{\hat{r}} - \sqrt{r}$ 的函数，再用 Cauchy-Schwarz 得到二次界。
4. 关键技巧：将 $\hat{r}$ 的误差分解为"残差方差模型的估计误差"和"预测模型的估计误差"两部分，分别处理。

**Theorem 8（设盲的代价）**：设盲设计相对于使用处理分配的设计，方差损失为 $G_\sigma + G_d$，其中 $G_\sigma$ 来自两臂残差标准差不等，$G_d$ 来自条件处理效应。证明路线：
1. 将设盲设计的方差写成 pooled 残差方差 $r_P$ 的函数。
2. 将使用处理分配的设计的方差写成臂特异残差方差 $s$ 的函数。
3. 两者之差分解为 $G_\sigma$（与 $d$ 无关）和 $G_d$（与 $d$ 有关）两部分。
4. $G_\sigma \ge 0$ 由 Cauchy-Schwarz 不等式保证；$G_d \ge 0$ 由 $r_P \ge s$ 保证。
5. 关键洞察：$G_d$ 在零假设（$d = 0$）附近是 $\|d\|^2$ 阶的，因此设盲设计的损失在效应较小时可忽略。

#### 真实例子与应用

**抗真菌试验（Toenail Onychomycosis Trial）**：
- **数据**：De Backer et al. (1998) 的随机双盲试验，比较口服特比萘芬（terbinafine）和伊曲康唑（itraconazole）治疗甲癣的效果。294 名患者，1908 次随访。作者使用 272 名在第 4 次随访时有结局记录的患者。
- **结局**：第 4 次随访时是否存在中重度甲剥离（onycholysis），二值变量。
- **辅助变量**：第 1、2、3 次随访的甲剥离状态、缺失指示、随访时间。
- **目标**：估计风险差（risk difference），完整数据值为 $-0.0126$。
- **方法应用**：初始随机样本 54 人（20%），用其拟合岭回归预测模型和残差方差模型，据此设定剩余 218 人的抽样概率（与 $\sqrt{\hat{r}}$ 成正比，截断到 $[0.05, 0.95]$）。
- **结果**：自适应抽样的经验标准差为 0.0315，而简单随机抽样为 0.0405，相对效率 1.65，即方差降低了 39%。要达到同样的精度，简单随机抽样需要测量 59.8% 的结局，而自适应抽样只需 50%，节省了约 27 个测量。
- **稳健性**：覆盖率为 0.949，接近名义水平 0.95，说明鞅 CLT 的近似在有限样本下是可靠的。改变截断界限、初始样本比例、预测模型（岭回归 vs. 逻辑回归）后，相对效率在 1.54 到 1.66 之间，结论稳健。

#### 🔎 结论是否比证明窄

- **明确被泛化的地方**：Theorem 2 的证明假设了 $\hat{\Delta}$ 的鞅差结构，但 (5) 中的 $V_R$ 是概率极限。作者在 Remark 2 中承认，当 $\pi_i$ 依赖于 $Y$ 的已测值（而非仅 $X$）时，鞅结构仍然成立，但 $V_R$ 的显式形式会改变。**然而**，Theorem 5 的证明假设 $\hat{r}_k$ 只依赖于 $X$ 和已测结局，这在实践中是合理的，但论文没有讨论 $\hat{r}_k$ 依赖已测 $Y$ 值时（例如用已测结局更新方差模型）的额外代价。
- **被泛化的第二个地方**：Theorem 8 的 $G_d$ 项在零假设附近是二阶小量，但论文没有给出"零假设附近"的定量刻画（即 $\|d\|$ 多大时 $G_d$ 可忽略）。模拟中 $d = 0.30$ 且 $G_d$ 较小，但这依赖于具体设定。
- **被回避的地方**：论文没有讨论**多重性**问题——如果试验有多个结局或中期分析，自适应抽样规则的更新是否会影响整体推断？这在 confirmatory trial 中是一个实际问题。
- **总体判断**：结论的表述基本与证明匹配，但"设盲设计的损失在零假设附近可忽略"这一说法在论文中是以定性方式给出的，缺乏定量边界。

### 四、开放问题

1. **最优更新策略**：Theorem 5 给出了单次更新的损失界，但**多次更新的最优频率**是什么？Corollary 6 允许重复更新，但没有回答"何时更新"的问题。扎根于 Corollary 6 后的讨论："More frequent updating does not automatically improve precision."

2. **臂特异预测的设盲近似**：Remark 1 提到臂特异预测可能更高效，但需要额外理论。一个具体问题是：在设盲约束下，能否用**代理变量**（如基线协变量与结局的相关性）来近似臂特异预测，而不违反设盲？扎根于 Remark 1："Arm-specific predictions after unblinding may be more efficient but need separate theory."

3. **有限样本的鞅 CLT 精度**：Theorem 2 是渐近的，模拟中 $n = 2000$ 时覆盖率接近名义水平，但**在 $n = 500$ 或更小时**，鞅 CLT 的近似是否仍然可靠？扎根于 Theorem 2 后的讨论和表 6 中 $n = 500$ 的结果。

4. **非独立同分布数据的推广**：论文假设受试者独立同分布。对于**整群随机试验**或**纵向数据**（如本文示例中的重复测量），抽样规则如何适应聚类结构？扎根于讨论部分："Survival outcomes, recurrent events, clustered trials, and multivariate outcomes would need sampling criteria tailored to their estimands."

5. **与 PPI 的深层联系**：本文的估计量（公式 2）与 Prediction-Powered Inference 的纠偏估计量在形式上高度相似。一个开放问题是：能否将 PPI 的"预测质量度量"（如预测区间宽度）直接纳入抽样概率的设计，从而在预测质量与抽样成本之间做最优权衡？扎根于引言中对 PPI 文献的引用："A related literature on prediction-powered inference combines machine-learning predictions with a small number of measured outcomes."

6. **设盲约束下的效率下界**：Theorem 8 给出了设盲设计的方差损失，但没有证明这是**所有设盲设计**的下界。是否存在更优的设盲自适应策略，其损失小于 $G_\sigma + G_d$？扎根于 Theorem 8 的陈述方式——它比较的是"最优设盲设计"与"最优非设盲设计"，但"最优设盲设计"本身是否就是本文提出的策略，并未证明。
