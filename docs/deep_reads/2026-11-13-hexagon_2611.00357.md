### 一、领域脉络与小综述

- **这个方向是什么**：本文属于**数的表示理论（representation theory of numbers）**中一个非常经典的分支——**二次型（quadratic forms）的普适性（universality）**。根本问题是：给定一个正整数集合 S（如全体正整数、全体奇数、全体素数、全体斐波那契数），能否找到一个**有限的"检验集"（criterion set）**，使得一个正定整系数二次型只要表示了这个有限集中的所有数，就必然表示 S 中的所有数？这个方向的成熟度很高——从 1993 年 Conway–Schneeberger 的十五定理到 2005 年 Bhargava–Hanke 的 290 定理，已经形成了完整的理论框架（"escalation"方法 + 局部-整体原理）。本文是这一框架向**稀疏集合（sparse set）**——斐波那契数列——的一次推广。

- **发展脉络（history）**：
  - **奠基工作**：Conway 的十五定理 [8, 3]（1993/2000）——一个正定整 Gram 矩阵的二次型表示所有正整数，当且仅当它表示 {1,2,3,5,6,7,10,14,15}。这是整个"有限检验集"范式的起点。Bhargava 在 [3] 中给出了 escalation 方法的系统化证明。
  - **主要进展**：Bhargava–Hanke 的 290 定理 [4]（2011 预印本）——将十五定理从"整值整系数"推广到"整值有理系数"（integer-valued forms），检验集扩大到 29 个元素。Rouse 的 451 定理 [22]（2014）——处理"表示所有正奇数"的问题，检验集为 451 个元素。Ju–Kim–Kim–Kim–Oh 的 67 定理 [10]（2021）——处理"表示所有素数"的问题。这些工作的共同点是：**目标集合 S 都是"稠密"的**（自然密度为正）。
  - **当前 frontier**：Kim–Lee–Oh [15]（2022）证明了**一般性定理**：对任意集合 S，最小检验集恰好由"escalation 过程中出现的 truant"组成（Theorem 2.2），并且给出了最小检验集唯一的条件。Kala–Krásenský–Romeo [11]（2026）将这一理论推广到**全实数域（totally real number fields）**上。这是本文直接依赖的两个理论支柱。
  - **本文的位置**：本文是第一个将检验集理论应用于**指数稀疏集合**（斐波那契数列，密度为 O(log X / X)）的工作。作者证明检验集为 10 个元素（最大为 F₄₂ = 267914296），并证明这是唯一最小检验集。关键的技术挑战是：稀疏集合意味着 escalation 过程可能不会在有限步内停止，需要新的论证。

- **子线索聚类**：
  - **线索一：经典普适性定理**（十五定理 [8,3]、290 定理 [4]、451 定理 [22]、67 定理 [10]）——目标集合是全体正整数、奇数、素数等"算术简单"的集合。方法：escalation + 局部-整体原理。
  - **线索二：一般检验集理论**（Kim–Lee–Oh [15]、Kala–Krásenský–Romeo [11]）——不针对具体集合，而是建立"最小检验集 = escalation 中出现的 truant 集合"的一般框架，并推广到数域。这是本文的方法论基础。
  - **线索三：特殊二次型的表示问题**（Ballot–Luca [1]、Berrizbeitia–Luca–Moreno [2]）——研究"哪些斐波那契数能被某个特定二元二次型表示"，与本文的"所有斐波那契数被任意二次型表示"形成互补。
  - **线索四：计算/形式化验证**——本文的 Lean 4 形式化工作属于这一线索，与近期数论定理的机器验证趋势一致。

- **这个方向在追问的核心问题**：
  1. **有限检验集的存在性**：对给定的集合 S，是否存在有限检验集？本文证明对斐波那契数列存在（10 个元素）。
  2. **检验集的最小性**：最小检验集是什么？本文证明 C 是唯一最小检验集（Theorem 1.1 后半部分）。
  3. **escalation 的终止性**：escalation 过程何时停止？对稠密集合，经典理论保证在有限步停止；对稀疏集合，本文展示了如何通过"局部-整体 + 增长估计"证明终止。
  4. **已知瓶颈**：对一般稀疏集合，escalation 可能无限进行（truant 序列无界），需要额外的算术输入（如本文的平方转移和同余覆盖）来截断。

- **⚠️ 作者的 framing（这是作者的说法）**：作者在引言和结论中把本文定位为"十五定理的斐波那契类比"，强调"稀疏集合上的普适性"是自然且未被探索的方向。他淡化了以下竞争路线：(1) 对**一般 Lucas 序列**的推广——作者在 §8 中只给出"自然候选"的讨论，没有给出具体定理；(2) 对**更高秩**二次型的处理——本文的 escalation 论证本质上依赖三元分类，四元及以上的情况未涉及；(3) **计算复杂性**——作者没有讨论检验集大小（10 个元素）是否在某种意义下最优（除了唯一性）。**值得研究者去查的问题**：作者在 §8 提到"Lucas 序列是自然候选"，但 Pell 数（a=2, b=1）在 rank 2 就出现分歧——这是否意味着对一般 Lucas 序列，检验集可能无限？作者没有回答。

- **张力**：未见明显对立引用。但有一个微妙的张力：Kim–Lee–Oh [15] 的一般理论保证最小检验集唯一，但**没有给出检验集大小的上界**；本文给出了具体上界（10），但依赖斐波那契数列的特殊算术（如 Pisano 周期、Lengyel 估值公式）。这两者之间的 gap——"一般理论 vs 具体集合的算术"——是本文的核心贡献，也是未来工作的空间。


### 二、最核心、最简单的例子 / 数学问题

**第一步：把符号、模型、可观测数据交代清楚**

- **符号**：
  - **F = {Fₙ : n ≥ 1}**：斐波那契数列，F₀ = 0, F₁ = 1, Fₙ₊₂ = Fₙ₊₁ + Fₙ。这是**目标集合**（estimand 的对象）。
  - **Q(x) = xᵀGx**：一个正定整系数二次型，G 为对称整数矩阵（Gram 矩阵）。**Q 是研究对象**（参数/对象）。
  - **"表示"（represents）**：Q 表示整数 N，若存在整数向量 x 使得 Q(x) = N。**这是核心关系**。
  - **C = {1, 2, 3, 5, 21, 55, 610, 987, 832040, 267914296}**：检验集（criterion set），即 {F₁, F₃, F₄, F₅, F₈, F₁₀, F₁₅, F₁₆, F₃₀, F₄₂}。**这是主要结论的对象**。
  - **truant**：一个集合 S 的 truant 是 S 中最小不被 Q 表示的元素。**这是 escalation 方法的核心概念**。
  - **escalation**：从一个格 L 出发，若 L 的 truant 为 τ，则构造 L' = L + Z·u（u 的范数为 τ），重复此过程。**这是证明方法**。
  - **regular form**：一个二次型表示所有局部可表示的正整数。**这是局部-整体论证的关键概念**。
  - **eligible**：整数 N 是 eligible 的，若它满足 Propositions 3.2 和 3.3 中的局部条件（即被 f 或 h 局部表示）。**这是技术性定义**。
  - **vₚ(N)**：N 的 p-adic 估值。**用于描述局部障碍**。
  - **uₚ(N) = N / p^{vₚ(N)}**：N 的 p-free 部分。**用于描述局部障碍**。
  - **πₚ**：斐波那契数列模 p 的 Pisano 周期。**用于计算斐波那契数的局部性质**。
  - **ρ_F(p)**：p 在斐波那契数列中的**出现秩（rank of apparition）**，即最小的 n 使得 p | Fₙ。**用于估值公式**。

- **模型**：数据生成机制是纯数学的——所有对象都是确定的整数和格。没有随机性。**可观测数据**是：二次型 Q 的 Gram 矩阵 G（有限整数矩阵）。**想要但观测不到**的是：Q 是否表示所有斐波那契数（无限多个条件）。**识别策略**：通过 escalation 方法，将无限多个条件归结为有限多个（检验集 C）。

**第二步：讲最小内核**

本文的最小内核可以归结为以下问题：

> **给定一个正定整系数二次型 Q，如果 Q 表示了 C = {1, 2, 3, 5, 21, 55, 610, 987, 832040, 267914296} 中的所有数，那么 Q 是否必然表示所有斐波那契数？**

这个问题的答案（本文的 Theorem 1.1）是**肯定的**，而且 C 是**唯一**的最小检验集。

**为什么这个内核是"最小"的？** 因为它剥离了所有技术细节（escalation 的分类、局部-整体论证、平方转移矩阵），只留下核心的数学断言：**一个有限集合（10 个斐波那契数）的表示性蕴含了无限集合（所有斐波那契数）的表示性**。

**这个内核的证明思路（在最小层面上）**：

1. **escalation 过程**：从零格出发，反复添加 truant 范数的向量。如果这个过程在有限步内停止（即得到一个表示所有斐波那契数的格），那么检验集就是过程中出现的所有 truant。
2. **关键观察**：通过 rank 3 的 escalation 分类，所有可能的格只有 9 个（Proposition 3.1）。这些格的 truant 恰好是 C 中的 10 个元素。
3. **关键论证**：对于每个这样的格，需要证明其所有"扩展"（即添加 truant 范数向量得到的四元格）都是斐波那契普适的。这通过以下方式完成：
   - 对 8 个正则格：局部-整体原理 + 增长估计（Lemma 5.3）。
   - 对不规则格 f：平方转移 + 同余覆盖（§6）。

**这个内核的数学本质**：这是一个**"有限检验蕴含无限性质"**的命题。在统计学的类比中，这类似于**"有限个矩条件蕴含分布恒等"**——但这里的机制完全不同（是数论的局部-整体原理，而非概率的矩生成函数）。


### 三、这篇论文做了什么

**三句话**：
1. **研究了什么问题**：一个正定整系数二次型表示所有斐波那契数的充分必要条件是什么？具体地，是否存在一个有限的斐波那契数集合，使得表示它蕴含表示所有斐波那契数？
2. **核心工具/方法**：Conway 的 escalation 方法（通过 truant 逐步构造格），结合局部-整体原理（正则格）、平方转移和同余覆盖（不规则格），以及斐波那契数列的算术性质（Lengyel 估值公式、Pisano 周期）。
3. **主要结论**：存在唯一的最小检验集 C = {1, 2, 3, 5, 21, 55, 610, 987, 832040, 267914296}（Theorem 1.1）。即一个正定整系数二次型表示所有斐波那契数，当且仅当它表示 C 中的所有数。此外，索引 42 是最优的（Corollary 1.2）：存在一个二次型表示 F₁,...,F₄₁ 但不表示 F₄₂。

**关键设定与假设**：
- **正定整系数二次型**：Q(x) = xᵀGx，G 为对称整数矩阵，正定。这是全文的基本设定。
- **整 Gram 矩阵**：G 的所有元素为整数。这排除了半整数 Gram 矩阵（如某些二元二次型）。
- **"表示"的定义**：存在整数向量 x 使得 Q(x) = N。注意 x 的分量可以是负整数。
- **与已有文献的比较**：相比十五定理 [8,3]（目标为全体正整数），本文的目标集合是斐波那契数列——**稀疏得多**（密度为 O(log X / X) vs. 密度为 1）。相比 Kim–Lee–Oh [15] 的一般理论，本文给出了**具体的检验集**，而不仅仅是存在性。相比 Rouse 的 451 定理 [22]（目标为全体奇数），本文的检验集更小（10 vs 451），但目标集合也更稀疏。

**主要结果**：

- **Theorem 1.1（斐波那契检验定理）**：一个正定整系数二次型是斐波那契普适的，当且仅当它表示 C = {1, 2, 3, 5, 21, 55, 610, 987, 832040, 267914296} 中的所有数。此外，C 是唯一的最小检验集。
  - **直觉**：C 中的 10 个元素恰好是 escalation 过程中所有可能的 truant。每个元素都是某个格"卡住"的地方——即该格表示所有更小的斐波那契数，但不表示这个数。
  - **必要条件**：C 中的每个元素都是必要的。例如，格 ⟨1,1,2⟩ 表示 F₁,...,F₄₁ 但不表示 F₄₂（Corollary 1.2 的证明）。

- **Corollary 1.2（索引 42 的最优性）**：索引 42 不能被降低。形式 x² + y² + 2z² 表示 F₁,...,F₄₁ 但不表示 F₄₂。
  - **证明思路**：F₄₂ = 267914296 = 4¹⁰(16·14 + 14)，属于局部障碍类 4ᵃ(16b + 14)。这个形式遗漏的正是这类数。

- **Proposition 3.1（九个三元 escalation）**：通过 rank 3 的 escalation，恰好得到 9 个三元格（7 个对角 + f + g）。这些格的 truant 恰好是 C 中的 10 个元素。
  - **证明思路**：从 rank 0 开始，逐步添加 truant 范数的向量。在 rank 1 和 rank 2，truant 分别是 1, 2, 3, 5。在 rank 3，需要分类所有可能的格，这通过 Minkowski 约化和局部-整体原理完成。

- **Proposition 3.2（正则三元）**：8 个三元格是正则的，其例外集由局部障碍描述。
  - **证明思路**：对每个格，验证其例外集恰好是某个局部障碍族。例如，⟨1,1,1⟩ 的例外集是 4ᵃ(8b + 7)。

- **Proposition 3.3（f 或 h 的表示）**：eligible 整数被 f 或 h 表示。
  - **证明思路**：通过两个辅助素数（5 和 11）的构造，将 eligible 整数分解为 f 或 h 的表示。

- **Proposition 5.1（2-adic 情形）**：6 个在 2 处有障碍的三元格的扩展都是斐波那契普适的。
  - **证明思路**：对每个格，使用 Lemma 5.2 的减法技巧，将斐波那契数减去 qk² 后落入例外集之外。

- **Proposition 6.1（f 的扩展）**：f 的所有扩展都是斐波那契普适的。
  - **证明思路**：使用平方转移矩阵（Table 3）和同余覆盖（Lemma 6.6），将问题归结为有限检查。

**证明路线与技术技巧**：

1. **整体路线**（escalation 方法）：
   - **Step 1**：从零格出发，计算 truant。零格的 truant 是 1，添加范数 1 的向量得到 ⟨1⟩。
   - **Step 2**：⟨1⟩ 的 truant 是 2，添加范数 2 的向量得到 ⟨1,1⟩ 或 ⟨1,2⟩。
   - **Step 3**：⟨1,1⟩ 的 truant 是 3，⟨1,2⟩ 的 truant 是 5。分别添加得到四个三元格。
   - **Step 4**：分类所有可能的三元格，得到 9 个（Proposition 3.1）。每个格的 truant 属于 C。
   - **Step 5**：对每个三元格，证明其所有扩展（四元格）都是斐波那契普适的。这是最困难的部分，分为正则情形（§5）和不规则情形（§6）。

2. **关键跳跃点**：
   - **跳跃点 1**：从 rank 2 到 rank 3 的分类。这里需要证明所有可能的 escalation 路径都收敛到 9 个格。难点在于排除其他可能的格，这通过 Minkowski 约化和局部-整体原理完成。
   - **跳跃点 2**：不规则格 f 的处理。f 不是正则的，局部条件不能保证整体表示。作者使用平方转移矩阵（Table 3）将 f 的表示问题转化为 h 的表示问题，然后通过同余覆盖（Lemma 6.6）处理剩余情况。
   - **跳跃点 3**：增长估计（Lemma 5.3）。需要证明斐波那契数列的增长速度足够快，使得减法技巧（Lemma 5.2）在有限步内终止。这里使用了 Lemma 2.1 的单调性。

3. **技术技巧点名**：
   - **Escalation 方法**（Conway [8]）：通过 truant 逐步构造格，将无限条件转化为有限检验。
   - **局部-整体原理**（Hasse–Minkowski）：正则格的表示性由局部表示性决定。
   - **平方转移矩阵**（Table 3）：通过矩阵 Bₚ 将 f 的表示转化为 h 的表示，利用 Kneser 邻接（[7]）。
   - **同余覆盖**（Lemma 6.6）：用有限个同余类覆盖所有可能的 (q mod 12, Fₙ mod 12) 对。
   - **Lengyel 估值公式**（[16]）：计算斐波那契数的 p-adic 估值，用于局部障碍分析。
   - **Pisano 周期**（[24]）：计算斐波那契数列模 m 的周期，用于同余计算。
   - **四平方定理**（Lagrange）：用于构造 V_t 的表示。

**真实例子与应用**：
- **Corollary 1.2 的构造**：形式 x² + y² + 2z² 表示 F₁,...,F₄₁ 但不表示 F₄₂。这个例子展示了检验集的必要性——每个元素都不能被移除。
- **Table 1**：列出了 10 个 truant 及其对应的 escalation 路径。例如，truant 21 对应格 f，truant 55 对应格 ⟨1,1,1⟩ 等。
- **Table 3**：给出了平方转移矩阵 Bₚ 和斐波那契数列模 p 的周期。这些矩阵是 §6 论证的核心工具。
- **Lean 4 形式化**：Theorem 1.1 已在 Lean 4 中完全形式化，无未证明假设。这为定理的正确性提供了机器验证。

**🔎 结论是否比证明窄**：
- **明确窄的地方**：Theorem 1.1 的**必要性**部分（C 的每个元素都必要）在正文中通过 Table 1 和 Corollary 1.2 的构造证明，但**唯一性**（即不存在更小的检验集）的证明依赖于 Kim–Lee–Oh [15, Theorem 2.2] 的一般理论。作者在 §7 中给出了证明，但该证明依赖 [15] 的框架，而非本文的独立论证。
- **泛化声明**：作者在 §8 中声称"Lucas 序列是自然候选"，但**没有给出任何定理**。这是一个 conjecture 级别的声明，不是证明。

### 四、开放问题

1. **一般 Lucas 序列的检验集**（扎根于 §8）：作者在 §8 中提出 Lucas 序列（如 Pell 数）是自然候选，但指出 Pell 数在 rank 2 就出现分歧。**要证明/证伪**：对一般的 Lucas 序列，检验集是否有限？如果有限，大小是否有统一上界？作者明确说"It is not clear whether this method can yield such a bound"。

2. **检验集大小的统一上界**（扎根于 §8 最后一段）：作者问"whether the number of initial terms that suffices for universality with respect to the sequence can be bounded uniformly over these Lucas sequences"。这是一个具体的、可攻击的问题——需要证明或构造反例。

3. **不规则格的系统处理**（扎根于 §6 和 §8）：本文对不规则格 f 的处理是 ad hoc 的（平方转移 + 同余覆盖）。**要证明**：是否存在一个系统的框架，可以处理所有不规则三元格？这可能需要发展新的工具，类似于 Bhargava 在 [3] 中对十五定理的处理。

4. **更高秩的斐波那契普适性**（扎根于 §8 的"stopping rank need not be four"）：本文只处理了 rank ≤ 4 的情况。**要证明/证伪**：是否存在一个正定整系数二次型，其斐波那契 truant 序列在 rank > 4 时才停止？如果存在，检验集的大小是否仍然有限？

5. **Lean 形式化的扩展**（扎根于 Lean 形式化部分）：本文的 Lean 形式化只覆盖了 rank ≤ 4 的情况。**要证明**：能否将形式化扩展到一般 Lucas 序列？这可能需要新的数学论证，而不仅仅是机械翻译。

**提醒**：要确认上述问题是否是真 gap，建议去读以下文献的近期工作：(1) Kim–Lee–Oh [15] 的后续工作（他们是否有关于稀疏集合的论文？）；(2) Kala–Krásenský–Romeo [11] 的后续工作（数域上的普适性是否有新进展？）；(3) 关于"universality of quadratic forms over sparse sets"的近期预印本（2024-2026）。如果这些文献都指向同一个开放问题，那它很可能是一个共识性的 gap；如果它们互相矛盾，那可能是一个更有意思的机会。
