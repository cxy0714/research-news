### 一、领域脉络与小综述

#### 这个方向是什么

本文所处的子方向是**鲁棒假设检验（robust hypothesis testing）**，具体而言是：当原假设和备择假设都是复合假设（composite）时，如何构造序贯检验（sequential test），使得检验在**任意**备择假设下都能以最优（或接近最优）的速率积累证据并做出决策。该方向的根本张力在于：经典框架（Huber-Strassen）通过"最不利分布对"（least-favorable pair）实现**minimax 最优**，但这是以牺牲在"简单"备择假设下的性能为代价的——检验被设计来对抗最坏情况，却无法利用实际数据的"简单性"。本文的目标是超越这一框架，实现**实例最优性（instance optimality）**：即对每个具体的备择假设 S，检验的表现都能与"事先知道 S 的 oracle"相媲美。

#### 发展脉络（history）

1. **奠基工作：Huber 的截断似然比检验（1965）与 Huber-Strassen 的 minimax 理论（1973）**。Huber (1965) 针对污染模型构造了截断概率比检验（censored probability ratio test），通过对单个似然比因子进行截断来防止少数污染观测主导证据。Huber and Strassen (1973) 则建立了更一般的 minimax 理论：在容量（capacity）条件下，存在最不利分布对 (P⋆, Q⋆)，使得二者的似然比检验同时是 minimax 最优的。这一框架统治了鲁棒检验数十年，但其本质是**对抗性的**——检验针对最坏情况优化，无法适应实际数据的难度。

2. **e 变量与 e 过程的兴起（2019-2024）**。Grunwald et al. (2019) 提出安全检验（safe testing）理论，引入 e 变量（e-variable）作为证据积累的基本单元。关键进展是 Lardy et al. (2024) 和 Larsson et al. (2025) 的逆向信息投影（reverse information projection, RIPr）理论：对于复合原假设 P 和点备择 Q，log-最优 e 变量存在且其密度恰为 Q 对 P 的 RIPr 的似然比。这为"针对特定备择优化"提供了理论基础——**每个备择假设都有一个对应的最优 e 变量**，问题在于如何在不事先知道 S 的情况下自适应地接近它。

3. **power-one 序贯检验的下界（Agrawal et al., 2025）**。Agrawal, Ram, and Ramdas (2025) 给出了 power-one 序贯检验停时的紧下界：在 Wald 设定（α→0，固定 S）下，期望停时下界为 log(1/α)/Γ(S)；在 Farrell 设定（α 固定，Γ(S)→0）下，下界为 Γ(S)⁻¹ log log(1/Γ(S))。这些下界为"实例最优性"提供了精确的基准——**任何检验的停时都不可能低于这些下界**，因此达到这些下界的检验就是实例最优的。

4. **本文的位置**。Saha and Ramdas (2025) 已证明：当 LFD 对存在时，其似然比给出 log-最优 e 变量，并构造了 Huber 鲁棒和 TV 鲁棒的检验。本文的问题是**正交的**：不预设备择类 Q，而是取 Q = Pᶜ（整个补集），并问能否构造一个检验，对**每个** S ∈ Pᶜ 都达到 oracle 性能。这需要将静态的 RIPr 刻画转化为**自适应序贯过程**——在线学习 S 对应的最优 e 变量。

#### 子线索聚类

- **线索 A：minimax 鲁棒检验**（Huber 1965; Huber & Strassen 1973; Saha & Ramdas 2025）。核心工具是 LFD 对和容量理论。优点：有精确的 minimax 最优性；缺点：只对最坏情况最优，且要求备择类具有特定结构（如 TV 球、污染球）。
- **线索 B：e 变量与逆向信息投影**（Grunwald et al. 2019; Lardy et al. 2024; Larsson et al. 2025）。核心工具是 RIPr 和 numeraire e 变量。优点：对任意复合原假设成立，无需正则条件；缺点：静态刻画，未解决自适应序贯问题。
- **线索 C：power-one 序贯检验的停时理论**（Darling & Robbins 1968; Robbins 1970; Agrawal et al. 2025）。核心工具是 Wald 恒等式、鞅停时定理、信息论下界。优点：给出了精确的实例最优基准；缺点：下界本身不构造达到下界的检验。
- **线索 D：在线学习与自适应估计**（本文的贡献）。核心工具是**可预测的 plug-in 估计**——用历史数据估计 S，再用估计值构造下一期的 e 变量因子。这一线索在本文中首次与 RIPr 理论结合。

#### 这个方向在追问的核心问题

1. **实例最优性是否可能？** 即是否存在一个检验，对每个 S ∈ Pᶜ 都达到 oracle 性能（Wald 常数和 Farrell 阶）？本文给出肯定回答（在 TV 球模型下）。
2. **自适应与有效性的权衡**：学习 S 需要数据，但数据本身也在积累证据——如何平衡"探索"（估计 S）与"利用"（用当前估计构造 e 变量）？本文的答案是：plug-in 估计的 regret 只有 O(d log n)，远小于证据积累的线性增长。
3. **计算可行性**：即使统计上最优，检验能否在 O(log d) 时间内更新？本文给出了肯定的答案，通过平衡树维护排序后的似然比。

#### ⚠️ 作者的 framing（这是作者的说法）

作者将缺口 frame 为：**"LFD 框架的 minimax 最优性是以牺牲实例最优性为代价的"**。具体而言，作者在引言中指出："A test optimized for Q⋆ has no reason to exploit the additional separation of a particular Q ∈ Q from the null class"（针对 Q⋆ 优化的检验没有理由利用某个特定 Q 与零假设类之间的额外分离）。作者进一步论证：当 Q = Pᶜ 时，LFD 对不存在（因为补集不是凸的），因此需要全新的方法。**被作者淡化的是**：minimax 最优性本身在"最坏情况"下仍是不可超越的——本文的实例最优性并不矛盾于 minimax 下界，而是在"平均/逐点"意义上更强。作者也没有讨论：当 S 落在 TV 球边界附近时，自适应检验的常数是否可能比 LFD 检验差（尽管渐近上两者一致）。

#### 张力

未见明显对立引用。但存在一个微妙的张力：**Larsson et al. (2025) 的 numeraire e 变量理论强调"无需任何假设即可定义 log-最优 e 变量"**，而本文的 plug-in 方法需要 TV 球的几何结构（截断阈值 a, b 的显式公式）。这意味着：numeraire 理论是**存在性**的，本文是**构造性**的——但构造性依赖于模型的具体结构。对于更一般的凸零假设类，本文的显式公式可能失效，只能退化为数值优化。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

**符号清单**（按类别分组）：

| 类别 | 符号 | 含义 |
|------|------|------|
| **参数/estimand** | P = (P₁,...,P_d) | 名义分布（TV 球的中心），已知 |
| | ϵ₀ | TV 球半径，已知 |
| | P₀ = B_TV(P, ϵ₀) | 零假设类（TV 球） |
| | S | 真实数据生成分布（未知，S ∉ P₀） |
| | Γ(S) = inf_{R∈P₀} D_KL(S‖R) | 信息数（oracle 增长率） |
| **随机变量/样本** | X₁, X₂, ... | i.i.d. 观测，X_t ∈ {1,...,d} |
| | N_i(t) = Σ_{s=1}^t 1{X_s = i} | 到时间 t 为止类别 i 的计数 |
| | Û_{t-1,i} = (N_i(t-1) + α_i)/(t-1 + α₊) | Laplace 平滑的经验分布 |
| **过程/检验** | E_t = E_{Û_{t-1}} | 第 t 期的 e 变量因子（可预测） |
| | M_n = Π_{t=1}^n E_t | 累积 e 过程（wealth） |
| | τ_α = inf{n : M_n ≥ 1/α} | 停时（拒绝零假设的时刻） |
| **辅助量** | a(U), b(U) | 截断阈值（由 U 和 P₀ 决定） |
| | R_U | U 到 P₀ 的逆向 KL 投影 |
| | E_U = U/R_U | 点态最优 e 变量 |

**模型**：观测空间 X = {1,...,d}（有限离散），真实分布 S ∈ Δ_d（d 维单纯形），零假设 P₀ = {R ∈ Δ_d : D_TV(R,P) ≤ ϵ₀}。假设 0 < ϵ₀ < 1 - min_i P_i，保证 P₀ 非平凡且补集非空。

**可观测数据**：研究者**实际能观测到**的是类别计数 N_i(t)（或等价地，经验分布 Û_t）。**不可观测**的是真实分布 S 本身——只能通过数据去估计。关键点：e 变量因子 E_t 必须在观测 X_t 之前确定（可预测性），因此只能用 Û_{t-1} 来构造。

#### 第二步：最小内核

**核心命题**（本文的数学本质）：构造一个可预测的 e 过程 {M_n}，使得对任意固定 S ∉ P₀（全支撑），

\[
0 \le n\Gamma(S) - \mathbb{E}_S \log M_n \le \log \binom{n+d-1}{d-1}
\]

**为什么这是"最小内核"？** 剥去所有技术细节后，本文在数学上只做了一件事：**用历史数据估计 S，然后用估计值构造 e 变量因子**。具体地：

1. **点态 oracle**：如果知道 S，最优 e 变量是 E_S = S/R_S，其中 R_S 是 S 到 P₀ 的逆向 KL 投影。其对数增长率恰为 Γ(S)。

2. **可预测 plug-in**：不知道 S，就用 Û_{t-1} 代替。第 t 期的因子是 E_{Û_{t-1}}。由于 E_U 对每个 U 都是 P₀-有效的（即 sup_{R∈P₀} E_R E_U ≤ 1），plug-in 保持了有效性。

3. **Regret 分析**：关键不等式是
   \[
   n\Gamma(S) - \mathbb{E}_S \log M_n = \sum_{t=1}^n [\Gamma(S) - h(S, \hat{U}_{t-1})]
   \]
   其中 h(S,U) = Σ_i S_i log E_U(i)。Lemma 2.4 给出 h(S,U) ≥ Γ(S) - D_KL(S‖U)，因此 regret 被 D_KL(S‖Û_{t-1}) 的累积和所控制。对 Laplace 平滑的经验分布，这个累积和是 O(d log n)。

4. **为什么成立**：核心观察是**截断阈值 a(U), b(U) 的连续性**。当 Û_{t-1} 接近 S 时，E_{Û_{t-1}} 接近 E_S，增长率损失由 KL 散度控制。而经验分布的 KL 收敛速率是 O((d log n)/n)，累积后得到 O(d log n) 的 regret。

**最小例子**（d=2, ϵ₀ 很小）：设 P = (0.5, 0.5)，ϵ₀ = 0.01。真实 S = (0.9, 0.1)。则 Γ(S) ≈ D_KL(S‖R_S)，其中 R_S 是 S 在 TV 球上的投影。plug-in 过程用 Û_{t-1} 估计 S，当 t 足够大时 Û_{t-1} ≈ S，因子 E_{Û_{t-1}} ≈ E_S，增长率接近 Γ(S)。Regret 来自早期估计不准的时段，总量 O(log n)。

**这个最小内核揭示了本文的本质**：这不是一个"检验构造"问题，而是一个**在线估计与决策的耦合问题**——估计误差如何转化为证据积累的损失，以及这种损失是否能被控制在可接受的范围内。本文的答案：能，且损失仅为对数阶。


### 三、这篇论文做了什么

#### 三句话

① **研究了什么问题**：在 TV 球零假设 P₀ = B_TV(P, ϵ₀) 下，能否构造一个 power-one 序贯检验，使得对**任意**备择 S ∉ P₀，检验的停时都达到 oracle 最优（Wald 常数 log(1/α)/Γ(S)，Farrell 阶 Γ(S)⁻¹ log log(1/Γ(S))）？

② **核心工具/方法**：可预测的 plug-in 截断似然比 e 过程。每期用 Laplace 平滑的经验分布估计 S，代入点态 oracle 映射 E_U = U/R_U（R_U 是 U 到 P₀ 的逆向 KL 投影），得到当期 e 因子。同时设计了基于平衡树的 O(log d) 动态更新算法。

③ **主要结论**：该 e 过程是 P₀-有效的（type-I error 控制），对任意全支撑 S ∉ P₀ 具有 pathwise regret 上界 O(d log n)，从而在 Wald 设定下达到最优常数 1/Γ(S)，在 Farrell 设定下达到最优阶 Γ(S)⁻¹ log log(1/Γ(S))。这是**首次**在鲁棒检验中实现实例最优性。

#### 关键设定与假设

- **离散有限字母表**：X = {1,...,d}，d ≥ 2。这是核心假设——所有显式公式（截断阈值、平衡树更新）都依赖有限字母表。连续情形的推广在讨论中提及但未展开。
- **全支撑备择**：S_i > 0 对所有 i。这保证 KL 散度有限，且 oracle 映射良定义。边界情形（某些 S_i = 0）通过连续性处理。
- **i.i.d. 观测**：全文假设观测独立同分布。自适应（非平稳）备择未考虑。
- **TV 球结构**：P₀ = B_TV(P, ϵ₀)。作者在讨论中指出结果可推广到其他凸零假设类，但显式公式依赖 TV 球的特殊几何。
- **ϵ₀ 固定**：鲁棒半径不随样本量变化。若 ϵ₀ → 0，问题退化为简单假设检验，本文的框架仍适用但常数可改进。

**相比已有文献的放宽/强化**：
- 相比 Huber-Strassen (1973)：**放宽**了备择类的结构假设（不需要 LFD 对存在），**强化**了最优性标准（从 minimax 到实例最优）。
- 相比 Agrawal et al. (2025)：**放宽**了参数假设（他们的下界适用于一般复合假设，但未构造达到下界的检验），**强化**了构造性（本文给出了显式算法）。
- 相比 Larsson et al. (2025)：**放宽**了静态设定（他们考虑固定 e 变量，本文考虑自适应 e 过程），**强化**了停时保证。

#### 主要结果

**定理 2.5（有效性）**：{M_n^CK} 是 P₀ 下的非负 test supermartingale。证明只需验证每个因子 E_{Û_{t-1}} ∈ E₀（由 Theorem 2.2 保证），且可预测性成立。这是整个框架的基石——**plug-in 不破坏有效性**。

**定理 2.6（Pathwise regret）**：对任意观测序列和任意 n，
\[
0 \le \log W_n^\star - \log M_n^{CK} \le \log \binom{n+d-1}{d-1}
\]
其中 W_n^\star 是事后最优（hindsight）wealth。证明的关键步骤：
1. 用 Lemma 2.4 将增长率损失转化为 KL 散度；
2. 对 Laplace 平滑的经验分布，累积 KL 散度有组合数上界；
3. 组合数上界通过 Stirling 近似得到 O(d log n)。

**定理 2.10（Wald 最优停时）**：对固定全支撑 S，E_S τ_α^CK ∼ log(1/α)/Γ(S) 当 α→0。证明需要：
1. 由 Theorem 2.6 得到 E_S log M_n^CK ≥ nΓ(S) - O(d log n)；
2. 结合 Wald 恒等式和停时定义，将 log(1/α) 与 nΓ(S) 关联；
3. 用 Theorem 2.9 的通用下界匹配常数。

**定理 3.2（Farrell 最优停时）**：对固定 α，E_S τ_α^F ≤ C Γ(S)⁻¹ [d + log(1/α) + log log(1/Γ(S))]。证明思路：
1. 构造事件 G_j（估计误差小），证明其在补事件上的概率可忽略；
2. 在 G_j 上，plug-in 因子接近 oracle 因子，增长率至少 Γ(S)/2；
3. 用几何级数求和控制总停时。

**定理 4.5（计算复杂度）**：O(log d) 每期更新。关键技巧：
- 截断阈值 a, b 是排序后前缀和的函数，用平衡树维护；
- 每次观测只改变一个计数，对应一次 O(log d) 的树操作；
- 阈值查询通过树下降完成，不需要重新排序。

#### 证明路线与技术技巧

**整体路线**（3-5 步）：

1. **建立点态 oracle**（Theorem 2.2）：证明 E_U = U/R_U 是 P₀ 上的 log-最优 e 变量，其中 R_U 是 U 到 P₀ 的逆向 KL 投影。这一步将"最优检验"转化为"投影问题"，利用 TV 球的凸性给出显式解。

2. **验证 plug-in 有效性**（Theorem 2.5）：证明对任意可预测的 Û_{t-1}，E_{Û_{t-1}} ∈ E₀。这一步是**自动的**——因为 E_U 对每个 U 都是 P₀-有效的，plug-in 不改变这一性质。

3. **控制 regret**（Theorem 2.6）：将增长率损失分解为逐项 KL 散度，用 Lemma 2.4 的界和组合恒等式得到 O(d log n)。关键技巧是**事后最优 wealth 的分解**：log W_n^\star - log M_n^CK = Σ_t [log E_{S}(X_t) - log E_{Û_{t-1}}(X_t)]，然后逐项控制。

4. **从 regret 到停时**（Theorem 2.10, 3.2）：利用停时定义 τ_α = inf{n : M_n ≥ 1/α}，将 log(1/α) 与 nΓ(S) 关联。关键技巧是**两阶段分析**：先证明在大概率事件上 M_n 以速率 Γ(S) 增长，再控制小概率事件的贡献。

5. **高效实现**（Theorem 4.5）：将截断阈值计算转化为平衡树上的前缀和查询，利用 TV 球的特殊结构（阈值是排序后前缀和的函数）实现 O(log d) 更新。

**关键技术技巧**：

- **逆向 KL 投影的显式解**：TV 球的投影问题可以转化为截断问题，阈值 a, b 由"质量守恒"方程唯一确定。这避免了数值优化，使得 plug-in 估计可以在 O(log d) 内完成。
- **Laplace 平滑的 regret 控制**：选择 α_i = 1 的 Laplace 平滑，使得经验分布始终有全支撑，且累积 KL 散度有组合数上界。这个选择不是任意的——它恰好使得 regret 的常数项最优。
- **两阶段停时分析**：将停时期望分解为"正常增长期"和"异常期"，前者用大偏差控制，后者用鞅不等式控制。这种分解是处理 power-one 检验停时的标准技巧，但本文将其与 plug-in 估计的误差项结合。
- **可预测性保证**：E_t 只用 Û_{t-1}（不含 X_t），保证 e 过程的可预测性。这是 e 过程理论的基本要求，但本文的贡献在于证明 plug-in 不破坏这一性质。

#### 真实例子与应用

**实验设置**：四类别多项分布，P = (0.25, 0.25, 0.25, 0.25)，ϵ₀ = ϵ₁ = 0.05。零假设为 B_TV(P, 0.05)，备择假设为 B_TV(Q, 0.05)，其中 Q = (0.37, 0.13, 0.25, 0.25)。真实数据生成分布 S = (0.37, 0.08, 0.30, 0.25)，位于备择球边界。

**对比方法**：LFD e 过程（固定最不利对 R⋆ = (0.30, 0.20, 0.25, 0.25), Q⋆ = (0.32, 0.18, 0.25, 0.25)）vs. 本文的 plug-in 截断似然比过程 vs. 知道 S 的 oracle。

**结果**：
- 平均累积对数财富：plug-in 过程在 n=500 时达到约 0.05n 的增长率，接近 oracle 的 0.059n，而 LFD 过程仅为 0.015n（约为 oracle 的 1/4）。
- 平均停时：plug-in 过程在 α=0.05 时平均停时约 98.1，LFD 为 195.3，oracle 为 52.7。plug-in 比 LFD 快约 2 倍，但比 oracle 慢约 2 倍。
- 初始学习成本：plug-in 过程在前 50 个观测内增长率低于 LFD，之后反超。这验证了 regret 界 O(d log n) 的预测。

**实验想说明什么**：plug-in 过程在**不牺牲有效性**的前提下，能够自适应地接近 oracle 性能，而 LFD 过程由于针对最坏情况优化，在"简单"备择下性能远低于最优。实验还展示了初始学习成本的存在——这是自适应估计的固有代价，但 regret 仅为对数阶，长期来看可以忽略。

#### 🔎 结论是否比证明窄

**是**。具体表现：

1. **定理 2.10 的证明依赖全支撑假设**，但结论的表述（"Wald 最优"）未明确限定。对于边界备择（某些 S_i = 0），证明中的大偏差控制可能失效，结论是否成立未验证。

2. **定理 3.2 的 Farrell 最优性只证明了上界**，未证明匹配的下界。作者在附录 A.4 中验证了 Agrawal et al. (2025) 的下界适用于 TV 球问题，但这是"借用"而非"证明"——下界本身是在更一般的框架下证明的，未针对 TV 球的特殊结构优化。

3. **计算复杂度的结论（O(log d)）依赖单位成本算术模型**。作者在脚注中承认"不承诺位复杂度或浮点精度"，这意味着在实际硬件上，大数运算可能使复杂度退化。

4. **实验只展示了 d=4 的情形**，未验证高维（d 大）时的表现。虽然 regret 界 O(d log n) 表明维度惩罚是对数阶的，但常数项可能随 d 增长，实验未覆盖。

5. **作者在讨论中声称结果可推广到其他凸零假设类**，但未给出证明。对于一般凸集，逆向 KL 投影可能没有显式解，plug-in 估计的计算成本可能远高于 O(log d)。

### 四、开放问题

1. **连续字母表的推广**：本文的显式公式（截断阈值、平衡树）依赖有限离散字母表。对于连续分布（如高斯位置模型），逆向 KL 投影的显式解是否存在？plug-in 估计的计算复杂度如何？这扎根于作者在讨论中"可以推广到其他凸零假设类"的声明，但未给出具体路径。

2. **边界备择的处理**：定理 2.10 的证明要求 S 有全支撑。对于边界备择（某些 S_i = 0），oracle 增长率 Γ(S) 可能由 KL 散度的边界行为决定，plug-in 估计的收敛速度可能退化。需要专门的边界分析。

3. **自适应 ϵ₀ 的选择**：本文假设鲁棒半径 ϵ₀ 已知且固定。在实际应用中，ϵ₀ 通常未知。能否构造一个对 ϵ₀ 自适应的检验，同时保持实例最优性？这扎根于作者在讨论中"ϵ₀ 固定"的设定。

4. **高维情形的计算-统计权衡**：当 d 很大时，O(d log n) 的 regret 是否可接受？是否存在更高效的估计器（如稀疏估计）能在保持有效性的同时降低 regret？这扎根于作者在讨论中"高维扩展"的提及。

5. **非 i.i.d. 情形的推广**：本文假设观测 i.i.d.。对于时间序列或自适应采样，plug-in 估计的 regret 分析是否仍然成立？这扎根于作者在讨论中"i.i.d. 设定"的限定。
