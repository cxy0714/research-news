### 一、领域脉络与小综述

#### 这个方向是什么

本文属于**组合数论与编码理论的交叉领域**，研究的是"splitter set"（分裂集）的存在性问题。其根本的数学问题是：给定一个有限循环群 Z_q 和一个整数区间 [-k₁, k₂]，能否找到一个子集 B ⊂ Z_q，使得集合 {λb : λ ∈ [-k₁, k₂], b ∈ B} 恰好构成 Z_q 的所有非零元素且无重复？这个问题在编码理论中有直接应用——闪存存储中的非对称有限幅度错误纠正码（asymmetric limited-magnitude error-correcting codes）的构造本质上等价于寻找这样的 splitter set。该领域的成熟度属于**中等偏成熟**：基本框架（群分裂理论）自 1960 年代由 de Bruijn、Hickerson 等人奠定，但针对具体参数（如 B[-1,5](q)）的存在性判定仍是开放问题，属于"经典框架 + 具体参数攻坚"的阶段。

#### 发展脉络（history）

- **奠基工作**：**de Bruijn (1953)** 和 **Hickerson (1983)** 建立了有限阿贝尔群分裂（splitting）的基本理论框架——将 Z_n 分解为 M·S 的形式，其中 M 是乘数集、S 是分裂集。这是本文的理论根基，本文将其中的"分裂"概念与编码理论中的 splitter set 直接对应。
- **编码理论引入**：**Cassuto, Schwartz, Bohossian, Bruck (2010)** 在 IEEE IT 上首次提出非对称有限幅度错误模型，并定义了 splitter set 的概念，将其与闪存存储中的错误纠正码联系起来。这是该领域从纯数学走向应用的关键转折。
- **主要进展**：**Zhang Tao & Ge (2018)** 用分圆多项式证明了某些非奇异完美 splitter set 的不存在性结果，这是本文直接推广的对象（本文引言明确说"generalizes a theorem of [26]"即 Zhang-Ge 的定理）。**Ye, Zhang, Zhang & Ge (2019)** 给出了非奇异完美 splitter set 存在性的充要条件，并系统总结了此前所有已知结果（本文引用的"comprehensive summary and a table of all previously known results"即指此）。**Yuan & Zhao (2019)** 专门研究了 B[-1,3](p) 的情形，给出了奇素数 p 的充要条件，并确定了所有 2 的幂次情形。
- **当前 frontier**：**Yuan (2022)** 给出了完美 B[-1,5](q) splitter set 存在的必要条件（本文引用的"a necessary condition"即指此），但充要条件此前未知。这正是本文的切入点。
- **本文的位置**：本文在 Yuan (2022) 的必要条件基础上，利用分圆多项式方法补上了充分性，从而给出 B[-1,5](q) 的完整充要条件；同时建立了 B[-k,k](q) 与 B[-(k-1),k+1](q) 之间的结构关系，并给出拟完美 splitter set 的两个不存在性结果。

#### 子线索聚类

这些被引文献大致落在 **3 条子线索**上：

1. **群分裂理论（纯代数/数论）**：de Bruijn (1953)、Hickerson (1983)、Szabó & Sands (2009) 的专著。这条线研究有限阿贝尔群分裂的一般理论，不关心编码应用，是数学基础。
2. **splitter set 的存在性与构造（编码理论驱动）**：Cassuto et al. (2010)、Kløve et al. (2011, 2012)、Zhang & Ge (2018)、Ye et al. (2019)、Yuan & Zhao (2019)、Yuan (2022)。这条线直接研究 splitter set 的存在性条件，是本文所在的主线。
3. **相关编码构造（应用扩展）**：Jain, Farnoud, Schwartz, Bruck (2020) 将类似思想推广到 DNA 存储；Wei, Wang, Schwartz (2020) 研究非对称有限幅度球的格覆盖；Xie & Luo (2019, 2021) 研究幅度 4 的单错误纠正码。这条线是应用扩展，与本文关系较远。

#### 这个方向在追问的核心问题

1. **完美 splitter set 的完全刻画**：对给定的 [-k₁, k₂]，确定所有使完美 B[-k₁,k₂](q) 存在的 q。目前只有 k 较小（k=1,2,3,4）的情形有完整答案，一般情形远未解决。
2. **拟完美 splitter set 的存在性**：当 (k₁+k₂) ∤ (q-1) 时，能否达到最大尺寸 ⌊(q-1)/(k₁+k₂)⌋？本文给出了两个不存在性结果，但一般情形完全开放。
3. **分裂集与群结构的关系**：分裂集 B 的稳定子群 π(B) 如何影响分裂的存在性？本文的 Proposition V.1 建立了 B[-k+1,k+1] 与 B[-k,k] 通过 π(B) 的联系，但 π(B) 的一般刻画远未完成。

#### ⚠️ 作者的 framing（这是作者的说法）

作者把缺口 frame 成："**Yuan (2022) 给出了 B[-1,5](q) 存在的必要条件，但充要条件未知；本文用分圆多项式补上了这一缺口**"。同时作者声称其分圆多项式方法"**统一并推广了** Zhang-Ge (2018) 的定理"，并将 B[-k,k] 与 B[-(k-1),k+1] 的关系视为"**理解 splitter set 结构的关键新视角**"。

**值得研究者去查的问题**：作者在 Remark IV.10 中提到 Yuan (2022) 的构造方法（手动构造同态 f）与本文的分圆多项式方法之间的关系——两种方法是否在更深层次上等价？另外，作者对拟完美 splitter set 只给了两个不存在性结果，但**没有讨论任何存在性构造**，这是一个明显的空白。

#### 张力

未见明显对立引用。各文献之间是累积性关系（必要条件→充要条件→推广），没有出现同一问题在不同条件下得到相反结论的情况。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据交代清楚

在展开本文的技术细节之前，先把记号一次性立清楚：

- **q**：正整数，循环群 Z_q = {0, 1, ..., q-1} 的阶。在编码应用中，q 是码元字母表的大小。
- **[-k₁, k₂]**：整数区间，其中 k₁ ≥ 0, k₂ ≥ 1。表示错误幅度的范围。记 k = k₁ + k₂ 为区间长度减 1。
- **B ⊂ Z_q**：splitter set，即我们要找的集合。|B| = n 对应码的块长。
- **B[-k₁,k₂](q)**：满足特定条件的 splitter set 的记号。具体地，B 是 B[-k₁,k₂](q) splitter set 当且仅当集合 {λb : λ ∈ [-k₁,k₂], b ∈ B} 中所有元素互不相同（且非零）。
- **完美（perfect）**：|B| = (q-1)/(k₁+k₂)，即达到理论上限。
- **拟完美（quasi-perfect）**：|B| = ⌊(q-1)/(k₁+k₂)⌋，即达到整数上限（当 (k₁+k₂) ∤ (q-1) 时）。
- **非奇异（nonsingular）**：gcd(q, k₁!k₂!) = 1。这个条件保证乘法群 Z_q^× 中的某些运算不会产生冲突。
- **g**：模 q 的一个本原根（primitive root），当 q 为素数时存在。
- **ind_g(n)**：n 关于本原根 g 的离散对数，即满足 g^{ind_g(n)} ≡ n (mod q) 的最小非负整数。
- **Φ_n(x)**：第 n 个分圆多项式（cyclotomic polynomial），其根为所有 n 次本原单位根。
- **π(B)**：B 的稳定子群（stable subgroup），即 {g ∈ Z_q : g + B = B}。
- **M·S 分裂**：Z_q = M·S 表示 Z_q 的每个非零元素可唯一表示为 m·s（m ∈ M, s ∈ S）的形式。

**可观测数据与模型**：这是一个**纯数学存在性问题**，没有统计意义上的"数据"。研究者"可观测"的是：给定 q, k₁, k₂，通过计算离散对数、分圆多项式的整除性等数论量，来判断是否存在满足条件的 B。关键的"不可观测"量是 B 本身——它需要通过构造或存在性证明来确定。

#### 第二步：最小内核

把本文的所有技术细节剥掉，支撑整篇论文的最小内核是这样一个问题：

> **给定素数 q 和整数 k，问：Z_q^× 能否被区间 [-k, k]^* = {-k, ..., -1, 1, ..., k} 乘以某个集合 B 恰好覆盖一次？**

用离散对数把乘法转化为加法：设 g 是模 q 的本原根，则 Z_q^× ≅ Z_{q-1}（加法群）。于是问题变成：

> **Z_{q-1} 能否被集合 A = {ind_g(λ) : λ ∈ [-k,k]^*} 加上某个集合 C 恰好覆盖一次？**

即是否存在 C ⊂ Z_{q-1} 使得 Z_{q-1} = A + C 是群分裂（group splitting）。

**为什么这个转化是核心**：因为 Z_{q-1} 是循环群，其分裂问题可以用分圆多项式来刻画。具体地，如果 Z_{q-1} = A + C 是分裂，那么 mask 多项式满足：

f_A(x) · f_C(x) ≡ 1 + x + x² + ... + x^{q-2} (mod x^{q-1} - 1)

而 1 + x + ... + x^{q-2} = (x^{q-1} - 1)/(x - 1) = ∏_{d | q-1, d > 1} Φ_d(x)。

**关键观察**：分圆多项式 Φ_{p^k}(x) 在 x = 1 处取值 p，且 Φ_{p^k}(x) 整除 f_A(x) 当且仅当 A 的某些算术结构成立。因此，**分圆多项式的整除性给出了 A 能否成为分裂乘数集的必要条件**。

**最小例子**：考虑 k=1, 即 B[-1,1](q)。此时 A = {ind_g(-1), ind_g(1)} = {0, (q-1)/2}（因为 -1 ≡ g^{(q-1)/2}）。问题是：Z_{q-1} 能否被 {0, (q-1)/2} + C 覆盖？这要求 C 中任意两个元素之差不为 0 或 (q-1)/2，且 C 的大小为 (q-1)/2。这等价于在 Z_{q-1} 中找一个大小为 (q-1)/2 的集合，其任意两个元素之差不是 0 或 (q-1)/2。这样的 C 存在当且仅当 q 是奇数（事实上取 C = {0, 2, 4, ..., q-3} 即可）。这就是 B[-1,1](q) 完美 splitter set 存在的充要条件：q 为奇数。

**本文的一般化**：本文的 Theorem III.3 将上述逻辑推广到任意 |A| = p^n 的情形，给出了 A 是 Z_{p^a m} 的直接因子的充要条件——即 A 的元素在模 p 意义下必须构成特定的算术结构（条件 (1) 和 (2) 描述了 A 的元素在 p 进制展开下的位置约束）。这个定理是整个论文的技术核心，后续所有具体结果（B[-1,5](q) 的充要条件、拟完美不存在性）都是它的推论。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：完美和拟完美 splitter set 在有限循环群 Z_q 中的存在性判定问题，特别是 B[-1,5](q) 的充要条件以及拟完美 splitter set 的不存在性。
2. **核心工具/方法**：分圆多项式（cyclotomic polynomials）的整除性分析，结合群分裂理论中的 mask 多项式方法；核心定理是 Theorem III.3，给出了 |A| 为素数幂时 A 是 Z_{p^a m} 直接因子的充要条件。
3. **主要结论**：① 建立了 B[-k,k](q) 与 B[-(k-1),k+1](q) 之间的结构关系（Proposition V.1）；② 给出了完美 B[-1,5](q) splitter set 存在的充要条件（Theorem VI.3）；③ 给出了拟完美 splitter set 的两个不存在性结果（Proposition VII.1 和 VII.2）。

#### 关键设定与假设

- **群设定**：研究的是循环群 Z_q，而非一般有限阿贝尔群。这是一个实质性简化——循环群的自同构群是交换的，且离散对数给出了显式的坐标系统。
- **非奇异条件**：gcd(q, k₁!k₂!) = 1。这个条件在本文中反复出现，它保证了区间 [-k₁,k₂] 中的元素在 Z_q 中互不相同且非零。当 q 为素数且 q > k₁+k₂ 时自动满足。
- **完美 vs 拟完美**：完美要求 |B| = (q-1)/(k₁+k₂) 且 (k₁+k₂) | (q-1)；拟完美允许 |B| = ⌊(q-1)/(k₁+k₂)⌋ 当 (k₁+k₂) ∤ (q-1)。注意拟完美情形下，覆盖不是完全的——会有 ⌈(q-1)/(k₁+k₂)⌉·(k₁+k₂) - (q-1) 个"洞"。
- **与已有文献的比较**：本文的 Theorem III.3 推广了 Zhang-Ge (2018) 的定理（原文说"generalizes a theorem of [26]"），后者只处理了 |A| = p 的情形；本文处理了 |A| = p^n 的一般情形。相比 Yuan-Zhao (2019) 只处理 B[-1,3](q)，本文推进到了 B[-1,5](q)。

#### 主要结果

**结果 1（Theorem III.3）**：设 p 为素数，A ⊂ Z_{p^a m}（p ∤ m），|A| = p^n，1 ≤ n ≤ a。则 A 是 Z_{p^a m} 的直接因子当且仅当存在 1 ≤ i₁ < i₂ < ... < i_n ≤ a，使得 A 的元素可以标记为 a_{b₁b₂...b_n}（b_i ∈ {0,1,...,p-1}），满足：
- (1) a_{b₁b₂...b_n} 的第 i_j 位（p 进制）等于 b_j；
- (2) a_{b₁b₂...b_{j-1}b_j*} 与 a_{b₁b₂...b_{j-1}0*} 之差 ≡ b_j · p^{i_j-1} (mod p^{i_j})。

**直觉**：这个定理说的是，A 是直接因子当且仅当 A 的元素在 p 进制展开下"占据"了 n 个不同的位（i₁, ..., i_n），且在每个被占据的位上，A 的元素遍历了所有 p 个可能值。这本质上是对 A 的算术结构的一个完全刻画。

**结果 2（Proposition V.1）**：B 是完美 B[-k+1,k+1](q) splitter set 当且仅当 B 是完美 B[-k,k](q) splitter set 且 -k/(k+1) ∈ π(B)（其中 π(B) 是 B 的稳定子群）。

**直觉**：这个命题建立了相邻参数之间的递推关系。它说明，从 B[-k,k] 到 B[-k+1,k+1] 的"扩展"完全由稳定子群 π(B) 是否包含特定元素决定。这为递推构造 splitter set 提供了可能。

**结果 3（Theorem VI.3）**：完美 B[-1,5](q) splitter set 存在的充要条件是以下两条之一：
- 1) v₃(ind_g(2)) < k，v₃(ind_g(2)) < v₃(ind_g(-2/3))，v₃(ind_g(2)) < v₃(ind_g(-4/5))，且 ord_q(-2/3) 和 ord_q(-4/5) 均为奇数；
- 2) v₃(ind_g(2)) < k，v₃(ind_g(2)) < v₃(ind_g(-2/5))，v₃(ind_g(2)) < v₃(ind_g(-3/4))，且 ord_q(-2/5) 和 ord_q(-3/4) 均为奇数。

其中 q = 3^k 2^l m + 1，gcd(6, m) = 1。

**直觉**：这个定理将 B[-1,5](q) 的存在性归结为若干离散对数的 3-adic 估值条件和乘法阶的奇偶性条件。这些条件都是**可计算的**——给定 q，可以在多项式时间内验证。

**结果 4（Proposition VII.1 和 VII.2）**：拟完美 splitter set 的不存在性：
- VII.1：若 m > k 且 k | m，则不存在拟完美 B[0,k](km) splitter set。
- VII.2：若 k 有一个素因子 q 与 m 互素，则每个 B[-(k-1),k](m) set 也是 B[-k,k](m) set。因此，若 ⌊(m-1)/(2k-1)⌋ > ⌊(m-1)/2k⌋，则拟完美 B[-(k-1),k](m) set 不存在。

**直觉**：VII.1 的证明基于一个巧妙的排列论证——将 Z_{km} 的非零元素排成 k 行 m 列的阵列，每行乘以 k 后坍缩为同一个元素，从而迫使 splitter set 每行最多取一个元素，但拟完美要求取 m-1 个元素，矛盾。VII.2 则说明，在特定条件下，拟完美 splitter set 的"近似覆盖"性质会自动加强为完美覆盖，从而排除了拟完美的可能性。

#### 证明路线与技术技巧

**整体路线**：
1. **第一步（Section III）**：建立群分裂的一般理论。用 mask 多项式将分裂问题转化为多项式整除问题。核心是 Theorem III.3 的证明，采用归纳法：先证 n=1 的情形（即 |A| = p），再假设 n-1 成立，通过"模 p^{i_n} 坍缩"将 n 的情形化归为 n-1 的情形。
2. **第二步（Section IV）**：将 Theorem III.3 应用于具体的 |A| = 8 情形（即 B[-4,4], B[-3,5], B[-2,6], B[-1,7]），通过分析 2-adic 估值和乘法阶的奇偶性，得到各情形的充要条件。
3. **第三步（Section V）**：建立 B[-k+1,k+1] 与 B[-k,k] 之间的递推关系（Proposition V.1），证明的关键是验证 -k/(k+1) 是否属于稳定子群 π(B)。
4. **第四步（Section VI）**：将递推关系应用于 B[-1,5]，结合 Yuan (2022) 的必要条件，得到充要条件（Theorem VI.3）。
5. **第五步（Section VII）**：拟完美情形的不存在性证明，使用排列论证和覆盖计数。

**关键技巧**：
- **mask 多项式方法**：将集合的加法分解转化为多项式的乘积分解。这是群分裂理论的标准工具，但本文将其与分圆多项式的整除性结合，得到了更强的结论。
- **p-adic 估值分析**：通过分析离散对数的 p-adic 估值，将乘法群中的条件转化为加法群中的整除条件。这是本文最核心的技术创新——此前的工作（如 Zhang-Ge 2018）主要依赖 case-by-case 分析，而本文用 p-adic 估值给出了统一的处理框架。
- **稳定子群 π(B) 的利用**：Proposition V.1 的核心洞察是，B[-k+1,k+1] 与 B[-k,k] 的差异完全由 π(B) 是否包含 -k/(k+1) 决定。这为递推构造提供了理论依据。

#### 真实例子与应用

本文包含**具体的数值例子**（Example IV.3, IV.5, IV.8, VI.4），但**没有真实数据应用**。这些例子的作用是验证理论结果的正确性，并展示如何将抽象的充要条件转化为具体的构造。例如：

- **Example IV.3**：q = 97，验证了 B[-4,4](97) 存在但 B[-3,5](97) 不存在。这里 -4/5 是模 97 的本原根，因此 ord_q(-4/5) = 96 为偶数，不满足 Theorem IV.2 的条件。
- **Example VI.4**：q = 463 和 q = 1489 分别验证了 Theorem VI.3 的两个条件。特别地，q = 1489 是第一个不满足 Zhang-Ge (2018) 定理条件但满足本文定理的素数，这展示了本文结果的实质性推进。

#### 🔎 结论是否比证明窄

**是，存在明显的不匹配**。具体表现：

1. **Theorem III.3 的陈述是"当且仅当"，但证明只覆盖了充分性的一部分**。在证明"若"方向时，作者构造了 C 的显式形式，但构造的验证依赖于 A 满足条件 (1) 和 (2) 的特定标记方式。作者没有证明这种标记方式在所有满足条件的 A 上都可行——这是一个潜在的 gap。

2. **Proposition V.1 的陈述是"当且仅当"，但证明中"仅当"方向依赖于 π(B) 的完全刻画**。作者证明了如果 B 是 B[-k+1,k+1] 的 splitter set，则 -k/(k+1) ∈ π(B)，但没有证明 π(B) 中不可能包含其他元素——这意味着"仅当"方向可能不完整。

3. **Theorem VI.3 声称是 B[-1,5](q) 的充要条件，但证明中使用了 Yuan (2022) 的必要条件作为引理**。如果 Yuan (2022) 的必要条件本身不完整（例如只覆盖了非奇异情形），那么 Theorem VI.3 的适用范围可能比陈述的窄。作者在 Remark IV.10 中承认了这一点，说"验证被省略"。

4. **Section VII 的拟完美不存在性结果只覆盖了特定参数**（k | m 或 k 有与 m 互素的素因子），但作者在结论部分没有明确说明这些条件是否也是必要的——即是否存在其他参数下拟完美 splitter set 存在。

以下开放问题均扎根于本文的具体陈述：

1. **Theorem III.3 的标记唯一性**：条件 (1) 和 (2) 中的标记 a_{b₁b₂...b_n} 是否唯一？如果存在多种标记方式，是否所有标记都满足条件？这关系到定理的"仅当"方向是否完备。（扎根于 Theorem III.3 的证明，特别是归纳步骤中"不失一般性"的假设。）
