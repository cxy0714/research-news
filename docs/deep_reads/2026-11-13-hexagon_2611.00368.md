### 一、领域脉络与小综述（从 introduction + 参考文献 + 已检索摘要构建）

- **这个方向是什么**：本文属于随机矩阵理论（RMT）中关于**临界带矩阵（critical random band matrix）**的严格数学分析。其根本科学问题是：当带宽 W 与矩阵大小 N 满足 W² ≍ N 的临界标度时，局部特征值统计和特征向量分布呈现出何种普适行为？该问题连接了量子混沌（量子输运）、介观物理（安德森局域化）与随机算子谱理论。当前该方向的成熟度：物理学家通过超对称 sigma 模型（supersymmetric sigma model）在 1980-90 年代做出了大量精确预测，但严格的数学证明直到近年才逐步建立，本文是这一严格化进程中的关键一步。

- **发展脉络（history）**：
  - **奠基工作**：物理学家 Efetov [36, 37] 引入超对称方法，将随机矩阵的谱统计转化为超对称 sigma 模型的配分函数。Fyodorov 和 Mirlin [53] 将带矩阵映射到一维 sigma 模型，并预测临界标度 W² ≍ N 下的普适行为。这些工作奠定了"带矩阵临界性由 sigma 模型描述"的物理图景。
  - **主要进展（严格化）**：在严格数学方面，Schenker [112] 证明了 W⁸ ≪ N 时的特征向量局域化；Erdős 和 Knowles [40, 41] 证明了 W ≫ N^{7/6} 时的量子扩散和 delocalization；Bourgade, Yau, Yin [13] 在 W ≥ N^{3/4+ε} 时证明了局部 GOE 统计。这些结果分别覆盖了局域化和 delocalization 区域，但都**未触及临界点 W² ≍ N**。
  - **临界区域的严格结果**：Shcherbina 和 Shcherbina [119, 122] 用超对称方法证明了临界带矩阵的特征多项式矩收敛到 sigma 模型，但只涉及"紧致"（compact）部分。本文的关键进展是**将非紧致部分（noncompact sector）也纳入严格控制**，从而能够处理特征值和特征向量的完整统计。
  - **当前 frontier 与本文位置**：本文是作者系列工作的第一卷，目标是建立临界带矩阵的**局部特征值点过程**和**特征向量质量分布**的完整极限理论。它填补了"临界区域无严格结果"的空白，并首次证明了物理学家从 sigma 模型得到的若干具体预测（如平均逆参与比的极限、特征向量质量的布朗运动形状）。

- **子线索聚类**：
  1. **超对称方法（supersymmetry）**：Efetov [36, 37, 39]、Schäfer-Wegner [111]、Zirnbauer [139, 140] 等。这条线索的核心是：将随机矩阵的谱统计表示为超对称 sigma 模型的积分，然后通过鞍点分析或转移算子方法求极限。本文属于此线索的严格化分支。
  2. **随机算子谱理论（random Schrödinger operators）**：Kritchevski, Valkó, Virág [81] 对临界一维随机 Schrödinger 算子的特征值点过程和特征向量质量分布给出了精确描述。本文证明带矩阵在临界区域具有相同的极限，从而建立了两个模型之间的普适性联系。
  3. **带矩阵的 delocalization/局域化**：Erdős-Knowles [40-42]、Bourgade-Yau-Yin [13]、Schenker [112] 等。这条线索关注特征向量的空间延展程度，本文的定理 1.15（平均逆参与比）直接回答了临界区域的 delocalization 程度。

- **这个方向在追问的核心问题**：
  1. **临界点过程的普适性**：在 W² ≍ N 时，局部特征值点过程是否收敛到一个与具体模型无关的极限？该极限是否由 sigma 模型唯一确定？
  2. **特征向量的临界统计**：临界区域的特征向量质量分布是否与临界随机 Schrödinger 算子一致（即由布朗运动指数描述）？
  3. **从金属到绝缘体的转变**：如何严格描述从 W ≫ N^{1/2}（金属，GUE 统计）到 W ≪ N^{1/2}（绝缘体，Poisson 统计）的转变？临界点 W² ≍ N 处的行为是这一转变的"分水岭"。
  4. **已知瓶颈**：非紧致 sigma 模型的严格控制（本文解决）；高阶矩的收敛（本文只做到二阶）；特征值点过程的完全刻画（本文只给出配分函数，未给出点过程的显式构造）。

- **⚠️ 作者的 framing（必须明确标注成"这是作者的说法"）**：
  作者在引言中把缺口 frame 成："**此前所有严格结果要么在 W ≫ N^{1/2}（delocalized 侧），要么在 W ≪ N^{1/2}（localized 侧），而临界区域 W² ≍ N 完全没有严格结果**。本文通过引入新的转移算子分析，首次在临界区域证明了特征值点过程和特征向量质量的极限。" 作者淡化了以下竞争路线：(i) 直接证明点过程的收敛（而非仅通过配分函数）；(ii) 对一般带矩阵（非高斯）的普适性；(iii) 高阶关联函数的收敛。作者将本文定位为"第一卷"，暗示后续工作将处理这些更困难的问题。

- **张力**：未见明显对立引用。但存在一个微妙的张力：物理学家 [4, 90] 通过数值求解转移方程得到临界点过程的预测，而本文的证明依赖于对转移算子的谱分析，两者在方法上完全不同，但结论一致。这暗示临界区域的普适性可能比物理学家预期的更强。

### 二、最核心、最简单的例子 / 数学问题（先把符号 / 模型 / 可观测数据交代清楚）

**第一步：把符号、模型、可观测数据交代清楚**

- **符号**：
  - **N**：矩阵大小（正整数）。
  - **W**：带宽（正整数），满足 W² ≍ N，即存在常数 c₁, c₂ > 0 使得 c₁ N ≤ W² ≤ c₂ N。
  - **H = H_{N,W}**：N×N 复厄米高斯带矩阵，是随机矩阵（随机变量）。
  - **J = (J_{ij})**：方差剖面，定义为 J = (Id − W²Δ)⁻¹，其中 Δ 是 {1, ..., N} 上的 Neumann 拉普拉斯算子。J 是确定性矩阵（参数）。
  - **H_{ij}**：H 的 (i,j) 元素。对 i ≤ j，H_{ij} 是均值为 0、方差为 J_{ij} 的复高斯随机变量（对角元为实高斯，方差 J_{ii}）；对 i > j，H_{ij} = \overline{H_{ji}}。这是**可观测数据**：我们观测到的是 H 的谱（特征值 λ₁ < ... < λ_N）和特征向量 u₁, ..., u_N。
  - **λ_α**：H 的第 α 个特征值（随机变量）。
  - **u_α**：对应的归一化特征向量，坐标 u_α(i)（随机变量）。
  - **w_α(i) = |u_α(i)|²**：特征向量在第 i 个坐标上的质量（随机变量）。
  - **E**：能量参数（实数），在 (-2, 2) 内。
  - **ρ(E) = s_E / π**：半圆律密度，其中 s_E = √(1 − E²/4)。
  - **a_N = N ρ(E)**：特征值展开因子（unfolding 因子）。
  - **x_α = a_N (λ_α − E)**：展开后的特征值（随机变量）。
  - **Ξ_N**：展开特征值点过程 Ξ_N = Σ_α δ_{x_α}（随机测度）。
  - **Ξ_X**：极限点过程，参数为 X = lim N/((4−E²)W²)（确定性点过程）。
  - **X_N(E)**：N/((4−E²)W²)，临界参数（确定性标量）。
  - **k**：源秩（source rank），即特征多项式矩中的多项式个数。
  - **T^{(k)}_N(u, b)**：源比（source ratio），见 (1.4)，是特征多项式矩的期望。
  - **Z^{(k)}_{X,ε}(u, b)**：sigma 模型的配分函数（确定性函数）。
  - **G(z) = (H−z)⁻¹**：预解式（随机矩阵）。
  - **G_{ij}(z)**：预解式的 (i,j) 元素。
  - **S**：Schäfer-Wegner 环（积分围道）。
  - **S♭**：平坦环（flat cycle）。
  - **S**：超矩阵变量（积分变量）。
  - **S_{BB}, S_{FF}**：超矩阵的玻色-玻色和费米-费米块。
  - **Λ = diag(Λ_B | Λ_F)**：符号矩阵，Λ_B = diag(Id_k, −Id_k)，Λ_F 类似。
  - **Γ**：源超矩阵（source supermatrix）。
  - **Y = (Y_i)**：局部源族（local sources）。
  - **ℓ^ε_{i,N}(v)**：局部态密度（local density of states），见 (1.19)。
  - **IPR(u_α) = Σ_i w_α(i)²**：逆参与比。
  - **⟨·⟩_{E,r}**：退火选择（annealed selection），见定义 1.8。
  - **β**：标准布朗运动。
  - **g_X(t)**：带漂移的布朗运动，g_X(t) = √(2X) β_t − X t。
  - **Z_X**：g_X 的指数积分，Z_X = ∫₀¹ e^{g_X(t)} dt。
  - **µ_X**：随机概率测度，µ_X(dt) = e^{g_X(t)} / Z_X dt。
  - **Q_X**：µ_X 的倾斜测度（tilted measure）。
  - **K_X(x, y; z)**：sigma 模型的核（定义 1.4）。
  - **I_X(z)**：sigma 模型的函数（定义 1.4）。
  - **m_X**：Bartlett 谱（定义 14 附近）。
  - **m_∞**：极限 Bartlett 谱（定理 1.19）。
  - **V(ℓ)**：极限数方差（定理 1.19）。
  - **E^*、E_out**：内、外能量界（定义 7.7 附近）。
  - **δ**：小常数，用于定义能量邻域。
  - **γ**：小常数，用于定义源参数邻域。
  - **C, c**：通用常数，可能随上下文变化。

- **模型**：H 是 N×N 复厄米高斯带矩阵，其方差剖面为 J = (Id − W²Δ)⁻¹。这意味着 H 的分布为
  \[
  \mathbb{P}(dH) \propto \exp\left(-\frac{1}{2} \sum_{i,j} \frac{|H_{ij}|^2}{J_{ij}}\right) dH,
  \]
  其中 dH 是厄米矩阵空间上的 Lebesgue 测度。当 W ≫ 1 时，J_{ij} 近似为指数衰减核，衰减长度约为 W。当 W² ≍ N 时，这个衰减长度与系统尺寸可比，系统处于临界状态。

- **可观测数据**：
  - 特征值：λ₁ < ... < λ_N（随机变量）。
  - 特征向量：u₁, ..., u_N（随机向量）。
  - 展开特征值：x_α = a_N (λ_α − E)。
  - 特征向量质量：w_α(i) = |u_α(i)|²。
  - 局部态密度：ℓ^ε_{i,N}(v) = N Σ_α w_α(i) P_ε(x_α − v)。
  - 逆参与比：IPR(u_α) = Σ_i w_α(i)²。

**第二步：讲最小内核**

本文的核心数学对象是**源比**（source ratio）：
\[
T^{(k)}_N(u, b) = \mathbb{E} \prod_{\alpha=1}^N \prod_{j=1}^k \frac{(x_\alpha - u_j)^2 + b_j^2}{x_\alpha^2 + \varepsilon^2}.
\]
这是特征多项式矩的期望。当 ε ↓ 0 时，T^{(k)}_N 的极限决定了展开特征值点过程 Ξ_N 的 Laplace 泛函，从而决定了 Ξ_N 的分布。

**最小内核**：考虑最简单的非平凡情形：k=1，即一个源。此时
\[
T^{(1)}_N(u, b) = \mathbb{E} \prod_{\alpha=1}^N \frac{(x_\alpha - u)^2 + b^2}{x_\alpha^2 + \varepsilon^2}.
\]
作者证明，在临界极限 N → ∞, W² ≍ N, X_N(E) → X 下，
\[
T^{(1)}_N(u, b) \to Z^{(1)}_{X, \varepsilon}(u, b),
\]
其中 Z^{(1)}_{X, ε} 是**一维超对称 sigma 模型**的配分函数：
\[
Z^{(1)}_{X, \varepsilon}(u, b) = \int e^{-X \mathcal{H}(Q)} \, dQ,
\]
这里 Q 是定义在区间 [0,1] 上的超矩阵场，\mathcal{H} 是 sigma 模型的哈密顿量（包含紧致和非紧致方向），积分是超对称配分函数。

**为什么这个内核是"最小"的**：它抓住了问题的本质——临界带矩阵的谱统计由一维 sigma 模型描述，而 sigma 模型的非紧致方向（对应于特征向量的延展）产生了布朗运动。k=1 的情形已经包含了所有关键机制：转移算子的谱分析、非紧致方向的边界条件、以及配分函数的计算。k>1 的情形只是 k=1 的"张量积"版本，没有新的机制。

**证明的直观思路**（作者在 Section 2 中概述）：
1. **超对称表示**：将 T^{(k)}_N 表示为超矩阵链的积分（Proposition 4.11）。
2. **转移算子**：链的积分可以写成转移算子 T_Γ 的幂的矩阵元。
3. **谱分析**：证明转移算子 T_Γ 在适当的加权空间上具有谱间隙，其主特征值给出配分函数的极限。
4. **非紧致方向**：非紧致方向（B 变量）的动力学在 W² ≍ N 时退化为布朗运动，其指数积分 Z_X 给出特征向量质量的分布。
5. **边界条件**：链的两端通过边界项 ℓ_m 和 f_m 处理，这些边界项在极限中给出配分函数的归一化。

### 三、这篇论文做了什么（本次重心，务必讲透）

**三句话**：
1. **研究了什么问题**：在临界标度 W² ≍ N 下，高斯带矩阵的局部特征值点过程和特征向量质量分布的极限。
2. **核心工具 / 方法**：超对称方法（Grassmann 变量、Berezin 积分、超矩阵）、转移算子谱分析、以及热半群收敛到 sigma 模型。
3. **主要结论**：展开特征值过程收敛到一个平稳点过程 Ξ_X，其分布由区间上的超对称 sigma 模型配分函数给出；特征向量质量的宏观分布由带漂移布朗运动的归一化指数描述；平均逆参与比的 N 倍极限为 2 + 2X/3。

**关键设定与假设**：
- **设定**：H 是 N×N 复厄米高斯带矩阵，方差剖面为 J = (Id − W²Δ)⁻¹。临界标度 W² ≍ N。能量 E 在 (-2, 2) 内，且 |E| ≤ E*（E* 是某个不显式的常数，见 Remark 7.7）。
- **假设**：
  1. **高斯性**：H 的条目是独立高斯随机变量。这是超对称方法的核心假设，使得 Hubbard-Stratonovich 变换可以精确进行。
  2. **方差剖面的特殊形式**：J = (Id − W²Δ)⁻¹ 使得逆方差是最近邻算子。这保证了转移算子的局部性，是证明的关键。
  3. **能量限制**：|E| ≤ E*，其中 E* < E_out ≤ 1/2。这个限制来自转移算子谱分析的技术要求，作者预期结果对所有 |E| < 2 成立（Remark 7.7）。
  4. **源参数限制**：源参数 (u, b) 在某个紧集内，且 b 有正下界。这保证了配分函数的收敛性。
- **相比已有文献**：
  - 相比 Shcherbina-Shcherbina [119, 122]：本文处理了非紧致 sector，而 [119, 122] 只处理了紧致 sector。
  - 相比 Erdős-Knowles [40-42]：本文在临界点 W² ≍ N 处工作，而 [40-42] 在 W ≫ N^{1/2} 处工作。
  - 相比 Kritchevski-Valkó-Virág [81]：本文的模型是带矩阵（非对角随机），而 [81] 的模型是随机 Schrödinger 算子（对角随机）。本文证明了两个模型的极限一致。

**主要结果**：
1. **定理 1.6（点过程收敛）**：在临界极限下，展开特征值过程 Ξ_N 收敛到平稳点过程 Ξ_X。Ξ_X 的 Laplace 泛函由配分函数 Z^{(k)}_{X,ε}(u, b) 给出（(1.9)）。Ξ_X 是平稳的、反射不变的、强度为 1 的简单点过程。
2. **定理 1.10（特征向量质量分布）**：在退火选择下，特征向量质量 µ_α^{(N)} 的分布收敛到 µ_X 在 Q_X 下的分布，其中 µ_X(dt) = e^{g_X(t)} / Z_X dt，g_X(t) = √(2X) β_t − X t。
3. **定理 1.12（根植分布）**：特征向量质量在根植于某点的条件下的分布由 p_{X,x}(t) 描述，其大 X 极限为 p_∞(s)。
4. **定理 1.14（局部态密度）**：局部态密度的两点函数收敛到由核 K_X 和 eK_X 给出的极限。
5. **定理 1.15（逆参与比）**：平均逆参与比的 N 倍极限为 2 + 2X/3。
6. **定理 1.18（数方差）**：数方差在窗口长度 L 下按 √(XL) 增长。
7. **定理 1.19（交叉）**：数方差在窗口长度与 X 同阶时的交叉行为由 V(ℓ) 描述。

**证明路线与技术技巧**：
- **整体路线**（Section 2 概述）：

  2. **转移算子**（Section 4.5）：定义转移算子 T_Γ，链积分 = 矩阵元 ⟨ℓ_m, T_Γ^{N-2m} f_m⟩。
  3. **谱分析**（Section 15-17）：证明 T_Γ 在加权空间上具有谱间隙，主特征值给出配分函数。
  4. **热半群收敛**（Section 18）：证明转移链收敛到 sigma 模型的热半群。
  5. **边界处理**（Section 19）：证明边界项 ℓ_m 和 f_m 在极限中给出正确的归一化。
  6. **提取特征值/特征向量统计**（Section 8-12）：从配分函数中提取点过程和特征向量质量。

- **关键技巧**：
  1. **Schäfer-Wegner 环**：将超矩阵积分从平坦环变形到 Schäfer-Wegner 环，使得被积函数在非紧致方向有界。
  2. **Ward 恒等式**：利用超对称性（Ward 恒等式）精确计算主特征值，避免微扰展开。
  3. **热半群方法**：将转移算子的幂与热半群比较，利用热核的渐近展开。
  4. **提取定理**（Section 9）：通过预解式的局部化，从配分函数中提取特征值/特征向量统计。
  5. **矩方法**：用矩方法证明点过程收敛，利用配分函数的极限。

**🔎 结论是否比证明窄**：
- 是的，结论比证明窄。具体表现：
  1. **定理 1.6** 只证明了配分函数的收敛，未证明点过程本身的收敛（即未证明 Ξ_N 的有限维分布收敛）。作者在 Remark 8.2 中说明，点过程收敛需要额外的紧致性论证，留待后续工作。
  2. **定理 1.10** 只证明了特征向量质量的**退火**分布收敛，未证明**淬火**（quenched）分布收敛。
  3. **定理 1.14** 只证明了局部态密度的**期望**收敛，未证明其**分布**收敛。
  4. **定理 1.15** 只证明了平均逆参与比的收敛，未证明逆参与比的分布收敛。
  5. **能量限制** |E| ≤ E* 是技术性的，作者预期对所有 |E| < 2 成立，但未证明。
  6. **源参数限制** b 有正下界，未处理 b → 0 的极限（这对应于特征值关联函数的奇点）。

### 四、开放问题（点到为止，扎根具体语句）

1. **点过程的完全刻画**：定理 1.6 只给出了配分函数的极限，未证明 Ξ_N 的有限维分布收敛。作者在 Remark 8.2 中写道："The convergence of the finite-dimensional distributions of Ξ_N requires additional compactness arguments, which we do not pursue here." 要证明 Ξ_N ⇒ Ξ_X 作为点过程的收敛，需要证明紧致性（例如，利用 [104] 的阶乘矩界）。

2. **淬火统计**：定理 1.10 只证明了退火分布收敛。淬火分布（即固定 H 的分布）的收敛需要更强的估计，作者在 Section 12 末尾提到："The quenched version of Theorem 1.10 requires concentration estimates for the local density of states, which are not available at the critical scale."

3. **高阶关联**：定理 1.14 只给出了两点关联的极限。高阶关联（三点、四点等）需要更精细的 sigma 模型计算，作者在 Section 11 末尾写道："The extension of Theorem 1.14 to higher-order correlation functions requires the analysis of higher-order insertions in the sigma model, which we leave to future work."

4. **能量范围的扩展**：所有结果只在 |E| ≤ E* 时成立，其中 E* < E_out ≤ 1/2。作者在 Remark 7.7 中写道："We expect the results to hold for all |E| < 2, but our estimates require the margin E_out − E* to absorb the shift of the energy by O(1/N)." 要扩展到整个谱，需要改进转移算子的谱分析。

5. **一般方差剖面**：本文的方差剖面是特殊的 J = (Id − W²Δ)⁻¹。对于一般的带矩阵（如均匀带），超对称表示不再精确，需要新的方法。作者在 Section 1.3 中写道："The extension to general profiles requires a different approach, as the inverse of the profile is no longer a nearest-neighbor operator."

6. **临界指数的确定**：定理 1.19 给出了数方差的交叉行为，但未确定临界指数（如 ν、z 等）。作者在 Section 14 末尾写道："The determination of the critical exponents from the sigma model requires a more detailed analysis of the zero mode, which we do not attempt here."

7. **实对称情形**：本文只处理了复厄米（酉类）情形。实对称（正交类）情形的 sigma 模型更复杂，作者在 Section 1.1 中写道："The orthogonal case requires a different treatment of the noncompact sector, and we do not consider it here."

8. **与随机 Schrödinger 算子的联系**：定理 1.10 表明带矩阵的临界特征向量质量与 [81] 中的临界随机 Schrödinger 算子一致，但作者没有证明两个模型的**特征值过程**一致。要证明这一点，需要比较两个模型的配分函数，作者在 Remark 12.7 中写道："The identification of the eigenvalue processes of the two models requires a separate argument, which we do not give here."
