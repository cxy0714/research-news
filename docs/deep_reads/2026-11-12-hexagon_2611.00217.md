### 一、领域脉络与小综述

#### 这个方向是什么

本文属于一个高度交叉的领域：**用数理逻辑的工具（逆向数学、Weihrauch 复杂度、证明挖掘）来度量优化理论中各类定理的"证明强度"**。它试图回答一个根本问题：优化理论中的存在性定理、收敛性定理和对偶性定理，各自需要多少"集合存在公理"或"计算资源"才能被证明？这个方向将优化理论从"算法设计"和"收敛速度"的经典视角，转向"逻辑必然性"的视角——即某些定理之所以难以证明或无法获得有效界，不是因为技巧不够，而是因为其逻辑本质决定了它需要更强的公理或更高的计算复杂度。该方向目前处于**从分散结果走向系统化整合**的阶段，本文正是试图绘制第一张"全景地图"。

#### 发展脉络

- **奠基工作**：逆向数学由 Friedman [65] 开创，Simpson [158] 系统化，其核心是确定一个定理在五大子系统（RCA₀、WKL₀、ACA₀、ATR₀、Π¹₁-CA₀）中的精确位置。证明挖掘由 Kohlenbach [98] 开创，其核心是从非构造性证明中提取显式的计算界。Weihrauch 复杂度 [29] 则提供了度量"计算问题"难度的一种精细标尺。
- **主要进展**：Kohlenbach [101] 证明了梯度下降收敛性等价于 ACA₀，这是本文最核心的"已知结果"；Neumann [137] 在 Weihrauch 格中定位了不动点问题，证明了投影问题与 lim 的等价性；Kohlenbach, López-Acedo 和 Nicolae [114] 建立了模正则性与收敛速率之间的逻辑等价；Fernández-Duque, Shafer 和 Yokoyama [58] 完成了 Ekeland 变分原理的逆向数学分类。
- **当前 frontier**：将逆向数学从"定理证明"推广到"算法行为"（如梯度下降的收敛性）；将证明挖掘从确定性算法推广到随机算法（如随机逼近）；将 Weihrauch 复杂度从单次查询推广到有限并行化（如 AoUC\*）；以及将逻辑分类从连续世界延伸到有限世界的复杂度类（如 CLS、PPAD、PLS）。
- **本文的位置**：作者声称这是第一张将三类逻辑工具统一应用于优化理论的"地图"，并填补了几个具体空白：RCA₀ 中凸函数最小值存在性的证明（定理 3.2）、RCA₀ 中 LP 对偶与 minimax 定理的证明（定理 6.1）、梯度下降波动界的维度依赖分析（定理 4.7）、以及极限点坐标的 d.c.e. 刻画（定理 4.9）。

#### 子线索聚类

1. **存在性定理的逻辑强度**（第 3 节）：连续函数极值定理 ↔ WKL₀；凸函数最小值存在性 ↔ RCA₀（本文新结果）；Ekeland 变分原理 ↔ Π¹₁-CA₀ [58]。
2. **收敛性定理的逻辑强度**（第 4 节）：梯度下降收敛性 ↔ ACA₀（Kohlenbach [101]）；选择原理（selection）是收敛性的代价；唯一性或误差界可消除该代价。
3. **对偶性定理的逻辑强度**（第 6 节）：LP 对偶与 minimax ↔ RCA₀（本文新结果）；分离定理 ↔ WKL₀；Kőnig 对偶 ↔ ATR₀。
4. **有限世界的对应物**（第 7 节）：局部搜索问题 ↔ PLS ↔ T¹₂ 的可证全函数；连续局部搜索 ↔ CLS = PPAD ∩ PLS；KKT 点问题 ↔ CLS 完全性。
5. **证明挖掘的量化内容**（第 5 节）：从非构造性证明中提取速率、波动界、稳定性界。

#### ⚠️ 作者的 framing

**这是作者的说法**：作者将优化理论的三类定理（存在、收敛、对偶）置于逻辑强度的光谱上，提出"凸性和 tame 性可以替代紧致性"这一核心洞见，并将"选择原理"（selection）识别为收敛性代价的根源。作者还提出了五个原则（P1–P5），其中 P2（"选择是收敛的代价"）和 P5（"维度是紧致性的代价"）是最具纲领性的。作者淡化了以下竞争路线：（1）**构造性分析**（Bishop 风格）——作者仅在 3.4 节简要提及，未深入比较；（2）**计算复杂性理论**（如信息-复杂度权衡）——作者在 7.2 节将其作为"有限世界的对应物"处理，但未讨论两者之间的精确对应关系；（3）**算法稳定性理论**——作者将稳定性视为"模正则性"的特例，未讨论其独立价值。

#### 张力

- **未见明显对立引用**：各文献之间在分类结果上高度一致（例如 Kohlenbach 与 Neumann 对梯度下降的分类相互印证）。
- **但存在一个微妙张力**：Kohlenbach [101] 的 ACA₀ 等价性是在 R¹ 上证明的，而本文定理 4.7 的波动界是 R^d 上的有限界。作者将两者统一为"选择原理"的代价，但并未证明 R^d 上的收敛性也等价于 ACA₀——这是一个值得注意的缝隙。
- **另一个张力**：作者声称"凸性使存在性在 RCA₀ 中可证"（定理 3.2），但该证明依赖于模一致连续性这一额外假设。在无模假设下，凸函数是否仍在 RCA₀ 中达到最小值？作者在定理 8.1 中将其列为开放问题，暗示这可能不成立。

#### 核心问题

1. **存在性**：一个优化问题有解，需要多少逻辑资源？
2. **收敛性**：一个算法能收敛到解，需要多少逻辑资源？
3. **对偶性**：一个最优性证书存在，需要多少逻辑资源？
4. **维度**：这些逻辑资源的消耗如何随维度变化？
5. **有限 vs 无限**：连续世界的逻辑分类与有限世界的复杂度分类之间是否存在精确对应？

### 二、最核心、最简单的例子 / 数学内核

#### 第一步：符号、模型与可观测数据

**符号**（本文核心记号）：

- **RCA₀**：递归理解公理系统，是逆向数学的基系统，对应"可计算数学"。
- **WKL₀**：RCA₀ + 弱 Kőnig 引理（每个无限二叉树有无限路径），对应"紧致性"。
- **ACA₀**：RCA₀ + 算术理解公理，对应"存在 halting 集"。
- **ATR₀**：算术超限递归，对应"沿良序迭代算术理解"。
- **Π¹₁-CA₀**：Π¹₁ 理解公理，对应"超跳跃"。
- **lim**：给定收敛序列，输出其极限。Weihrauch 等价于 ACA₀。
- **C\[0,1\]**：闭选择问题，给定非空闭集，输出其中一点。C\[0,1\] ≡_sW WKL。
- **XCₙ**：凸选择问题，给定非空凸闭集，输出其中一点。
- **AoUC\***：有限并行化的 all-or-unique choice。
- **d.c.e. 实数**：两个左 c.e. 实数之差，即"弱可计算"实数。
- **模一致连续性**：函数 f 的模 ω 满足 |x−y| < ω(ε) ⇒ |f(x)−f(y)| < ε。
- **模正则性**：ρ 满足 dist(x, S) < ρ(ε) ⇒ f(x) − f\* < ε。
- **模唯一性**：δ 满足 |x−x\*| < δ(ε) ⇒ f(x) − f\* < ε。

**模型**（数据生成机制）：

- **凸光滑对**：f : R^d → R 是凸函数，g = ∇f 是 L-Lipschitz 的。梯度下降迭代：x_{k+1} = x_k − (1/L) g(x_k)。
- **可计算实例**：f 和 g 由可计算函数编码，即存在算法在有理点上以任意精度计算 f 和 g 的值。
- **目标**：研究"给定可计算实例，算法输出极限"这一问题的逻辑复杂度。

**可观测数据**：
- 函数 f 和梯度 g 在有理点上的值（可计算逼近）。
- 初始点 x₀。
- 光滑参数 L 和凸性参数（若已知）。
- 目标：输出极限 lim_k x_k（或至少输出一个可计算逼近）。

#### 第二步：最小内核

**核心问题**：梯度下降的收敛性需要多少逻辑资源？

**最简例子**：考虑一维凸光滑函数 f : R → R，梯度下降 x_{k+1} = x_k − (1/L) f'(x_k)。

**关键观察**：
1. **存在性便宜**：RCA₀ 可证明凸函数在 [0,1] 上达到最小值（定理 3.2(a)）。这是因为凸性排除了局部极大值，使得二分搜索只需有限次比较。
2. **收敛性昂贵**：梯度下降的收敛性（即序列 (x_k) 是 Cauchy 的）等价于 ACA₀（定理 4.1）。原因在于：收敛性要求"知道极限"，而极限可能携带 halting 集的信息。
3. **选择是代价**：梯度下降从初始点 x₀ 出发，其极限是 x₀ 在解集 S 上的投影。这个投影函数是 lim-hard 的（定理 4.3）。即使找到某个 minimizer 是容易的，找到"从 x₀ 出发的那个"是难的。
4. **唯一性消除代价**：若解唯一，则投影函数平凡化，收敛性变得可计算（定理 4.4(a)）。
5. **正则性消除代价**：若存在模正则性 ρ，则收敛性可计算（定理 4.4(b)）。

**数学上到底干了什么**：
- 构造了一个可计算凸光滑函数族 {f_y}，其中 y 编码一个可计算枚举集合。梯度下降的极限恰好是 sup(y)，而 sup(y) 的复杂度随 y 的复杂度变化。
- 证明了"梯度下降收敛"这一命题在逆向数学中等价于 ACA₀，在 Weihrauch 格中等价于 lim。
- 证明了"凸函数最小值存在"这一命题在 RCA₀ 中可证，但"找到最小值"（作为多值问题）等价于 XCₙ，严格低于 WKL。

**为什么这个例子是核心**：它揭示了优化理论中一个深刻的二分法——**存在性可以是构造性的，但收敛性本质上需要非构造性的选择公理**。这个二分法不是算法技巧问题，而是逻辑必然性。

### 三、这篇论文做了什么

#### 三句话

1. **研究问题**：用逆向数学、Weihrauch 复杂度和证明挖掘三种逻辑工具，系统度量优化理论中三类定理（存在性、收敛性、对偶性）所需的证明强度，并绘制一张统一的"逻辑地图"。
2. **核心方法**：将优化问题编码为逻辑命题，通过构造可计算实例（如函数族 f_y）证明其逻辑复杂度下界，通过显式算法（如二分搜索、投影算法）证明其上界，从而确定精确的逻辑位置。
3. **主要结论**：凸性和 tame 性可以替代紧致性使存在性在 RCA₀ 中可证；但收敛性本质上等价于 ACA₀，其代价源于算法对特定 minimizer 的选择；对偶性定理的逻辑强度从 RCA₀（LP 对偶）到 WKL₀（分离定理）再到 ATR₀（Kőnig 对偶）不等。

#### 关键设定与假设

**设定**：

- **凸光滑对**：f : R^d → R 凸，g = ∇f 是 L-Lipschitz。梯度下降 x_{k+1} = x_k − (1/L) g(x_k)。
- **可计算性**：f 和 g 由可计算函数编码，即存在算法在有理点上以任意精度计算 f 和 g 的值。
- **逆向数学**：在 RCA₀ 中形式化"梯度下降收敛"命题，确定其等价于 ACA₀。
- **Weihrauch 复杂度**：将"梯度下降极限"视为多值问题 GDLim_d，确定其等价于 lim。
- **证明挖掘**：从收敛性证明中提取波动界、速率、模正则性。

**假设**：

- **凸性**：f 是凸函数。这是核心假设，它排除了局部极大值，使得二分搜索可行。
- **光滑性**：g 是 L-Lipschitz。这保证了梯度下降的每一步有界。
- **存在 minimizer**：f 有 minimizer（在 R^d 上，凸函数不一定有 minimizer，但若 f 有下界且 coercive，则存在）。
- **可计算性**：f 和 g 可计算。这是逆向数学的标准假设。

**相比已有文献的放宽/强化**：

- **放宽**：本文的定理 3.2(a) 不要求 f 可微，只需凸且连续。这比 Kohlenbach [101] 的设定更一般。
- **强化**：本文的定理 4.7 给出 R^d 上的波动界，而 Kohlenbach 的等价性只在 R¹ 上证明。本文的波动界是维度依赖的，且下界表明维度依赖不可避免。
- **新增**：定理 6.1 证明 LP 对偶在 RCA₀ 中可证，这是全新的结果；定理 4.9 给出梯度下降极限点的 d.c.e. 坐标刻画，也是全新的。

#### 主要结果

**定理 3.2(a)**：RCA₀ 证明凸连续函数 f : [0,1] → R 达到最小值。证明思路：凸性给出 f 的"单峰性"，二分搜索只需有限次比较即可定位最小值点。这是"凸性替代紧致性"原则的最简单体现。

**定理 3.2(b)**：RCA₀ 证明带模一致连续性的凸函数 f : [0,1]^n → R 达到最小值。证明思路：归纳于维度 n，每维用二分搜索，模一致连续性保证搜索的精度。

**定理 3.3**：CMin_n ≡_sW XC_n。凸最小化问题与凸选择问题等价。证明思路：从凸函数构造凸集（epigraph），从凸集构造凸函数（距离函数），两个方向都是可计算的。

**定理 4.1**：梯度下降收敛性（在 R¹ 上）等价于 ACA₀。证明思路：构造函数族 f_y，其梯度下降极限为 sup(y)。sup(y) 的复杂度随 y 的复杂度变化，当 y 是任意可计算枚举集合时，sup(y) 可达 halting 集的复杂度。因此"梯度下降收敛"蕴含 ACA₀。

**定理 4.3**：投影选择（Halpern、Tikhonov 的极限）等价于 lim。证明思路：构造凸函数 f_y，其解集为 [sup(y), 1]，投影选择输出 sup(y)。因此投影选择是 lim-hard 的。

**定理 4.4**：唯一性或模正则性消除代价。若解唯一，则投影选择可计算；若存在模正则性，则收敛性可计算。证明思路：唯一性使投影函数平凡化；模正则性给出距离控制，使二分搜索可行。

**定理 4.7**：R^d 上梯度下降的波动界为 2C_d D/ε，且维度依赖不可避免。证明思路：上界来自自收缩曲线长度界；下界来自构造一个维度依赖的实例，其波动次数达到下界。

**定理 4.9**：梯度下降极限点的坐标是 d.c.e. 实数。证明思路：梯度下降迭代是可计算的，极限是单调序列的极限，因此是 d.c.e.。反过来，每个 d.c.e. 实数都可以作为某个可计算实例的梯度下降极限。

**定理 6.1**：RCA₀ 证明 LP 对偶和 minimax 定理。证明思路：使用符号单纯形法，所有决策都是有限次比较，只需有界 Σ₀¹ 概括即可确定符号。

**定理 3.5**：Tarski 传递：固定格式的多项式优化问题在 RCA₀ 中可证。证明思路：实闭域理论是完备的，RCA₀ 可证明其模型是实闭域。

#### 证明路线与技术技巧

**整体路线**：
1. **存在性**：凸性 → 单峰性 → 二分搜索 → RCA₀ 可证。
2. **收敛性**：构造 f_y → 梯度下降极限 = sup(y) → sup(y) 是 lim-hard → 收敛性等价于 ACA₀。
3. **对偶性**：符号单纯形法 → 有限次比较 → RCA₀ 可证。
4. **有限世界**：局部搜索 ↔ PLS ↔ T¹₂ 的可证全函数。

**关键技巧**：
- **函数族 f_y**：构造参数化的凸函数族，将计算问题编码进函数参数。这是连接逻辑复杂度与计算复杂度的桥梁。
- **自收缩曲线**：利用凸函数的几何性质（自收缩性）证明波动界。
- **符号单纯形法**：将单纯形法的所有决策转化为符号比较，避免实数运算。
- **有界 Σ₀¹ 概括**：在 RCA₀ 中，有限次 Σ₀¹ 概括是允许的，这足以确定符号模式。

#### 🔎 结论是否比证明窄

- **定理 3.2(a)**：证明是完整的，但仅覆盖 [0,1] 一维情形。作者在定理 8.1 中承认，多维情形（无模假设）是否在 RCA₀ 中可证是开放的。
- **定理 4.1**：证明是完整的，但仅覆盖 R¹ 一维情形。作者在定理 8.2 中承认，R^d (d≥2) 的收敛性是否等价于 ACA₀ 是开放的。
- **定理 4.7**：上界证明完整，但下界仅对特定实例成立。作者在定理 8.4 中承认，最优常数 C_d 的精确值未知。
- **定理 6.1**：证明是完整的，但仅覆盖 LP 对偶和 minimax。作者在定理 8.6 中承认，Fenchel 对偶的精确强度未知。
- **定理 4.9**：证明是完整的，但仅覆盖梯度下降。作者在定理 8.5 中承认，其他算法（如加速梯度法）的极限点坐标刻画未知。

### 四、开放问题

1. **多维凸函数最小值存在性**（定理 8.1）：RCA₀ 是否证明每个凸函数 f : [0,1]^n → R（无模假设）达到最小值？作者猜测需要 WKL₀，但未证明。扎根于定理 3.2(b) 的模假设。

2. **多维梯度下降收敛性**（定理 8.2）：R^d (d≥2) 上梯度下降收敛性是否等价于 ACA₀？作者猜测是，但未证明。扎根于定理 4.1 的一维证明。

3. **KKT 问题的精确 Weihrauch 度**（定理 8.3）：KKT_n 是否严格低于 BFT_n？作者猜测是，但未证明。扎根于定理 3.4 和 7.2 节的 CLS 讨论。

4. **最优波动常数**（定理 8.4）：C_d 的精确增长速率未知。作者给出下界 √d/2 和上界 2^{O(d²)}，但间隙巨大。扎根于定理 4.7 和 4.8。

5. **梯度下降极限点的完整刻画**（定理 8.5）：R^d (d≥2) 上梯度下降极限点的坐标是否恰好是 d.c.e. 实数？作者猜测是，但未证明。扎根于定理 4.9 的一维证明。

6. **Fenchel 对偶的逆向数学**（定理 8.6）：Fenchel–Rockafellar 对偶的精确强度是 WKL₀ 还是 ACA₀？作者猜测取决于分离定理的形式。扎根于定理 6.1 和 6.2 节的讨论。
