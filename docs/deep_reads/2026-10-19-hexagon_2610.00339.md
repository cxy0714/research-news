### 一、领域脉络与小综述

#### 这个方向是什么

这篇论文属于**低维拓扑与量子不变量**的交叉领域，具体研究的是**带标记的 Heegaard 边界模（marked Heegaard boundary modules）**。其根本问题是：在量子不变量（如 Witten–Reshetikhin–Turaev 不变量）的构造中，如何为"带边界的流形"建立一套**同时兼容两种不同完备化（disk-adic 与 cyclotomic）**的代数框架。该子方向当前处于**理论建构的早期阶段**——它试图为已有的闭流形量子不变量理论（如 Habiro 的 cyclotomic 完备化理论）补充一个"边界版本"，但尚未形成完整的、被广泛接受的统一框架。

#### 发展脉络

- **奠基工作：Habiro 的 cyclotomic 完备化理论（[22]）**。Habiro 引入了环 $\widehat{\mathbb{Z}[q]}_{\rm cyc}$（cyclotomic 完备化），并证明了对于**积分同调球（integral homology spheres）**，WRT 不变量可以提升为一个统一的 cyclotomic 不变量。这是整个领域的"母体"——本文的 cyclotomic 坐标、对角 Hopf 配对、以及"统一不变量"的构想都直接源于此。
- **关键工具：Kauffman 括号 skein 模与 skein 模的代数结构（[33, 6, 31, 12]）**。Przytycki 的 skein 模理论（[33]）提供了"通过 handle 附着计算 skein 模"的基本工具，特别是"一个 2-handle 附着等价于取某个 slide 差分的商"这一关键命题（本文 Theorem 2.1 的直接依据）。Masbaum–Vogel 的 recoupling 理论（[31]）和 Costantino 的 half-twist 公式（[12]）则提供了具体的代数计算工具。
- **主要进展：Gilmer–Masbaum 的积分 TQFT（[18]）**。他们为**单孔环面（one-holed torus）**建立了完整的积分 TQFT 框架，给出了相对 skein 模的积分基、Hopf 配对和 mapping class group 的表示。本文的"lollipop 基"、"相对 Hopf 配对"、"mapping class 作用"等核心构件都直接取自这里。
- **当前 frontier：边界版本的统一不变量**。Gukov–Putrov–Vafa 的"homological blocks"纲领（[21, 20, 19]）从物理侧提出了"从边界数据重构闭流形不变量"的设想。本文作者（Sun）试图在数学侧为这一纲领提供严格的代数基础——即构造一个"边界模"，使得闭流形的量子不变量可以视为该边界模上的某种配对或泛函。本文是这一计划的**第一步**：先构造边界模本身及其上的代数结构。

#### 子线索聚类

1. **skein 模的代数结构**（[33, 6, 31, 12]）：研究 Kauffman 括号 skein 模作为代数对象的性质，特别是 handle 附着、slide 关系、recoupling 等操作如何改变 skein 模。本文的 Theorem 2.1（填充商）和 Theorem 5.3（lollipop 基）属于这一线索。
2. **量子不变量在根处的行为**（[8, 7, 30]）：研究在单位根处量子不变量如何退化、如何与有限维表示论（如 Yang–Mills 测度）联系起来。本文的"根处迹公式"（Theorem 3.1）和"根处不变量"（Theorem 9.11）属于这一线索。
3. **积分结构与格点理论**（[17, 18]）：研究如何为量子不变量选择"正确的"积分基和格点，使得不变量具有整性。本文的"lollipop 格点"、"端点格点"、"原始/饱和塔"属于这一线索。
4. **完备化与解析延拓**（[22, 14]）：研究如何将形式幂级数不变量延拓到各种完备化（cyclotomic、disk-adic、p-adic）中。本文的"联合完备化"（joint completion）和"分裂完备化"（split completion）属于这一线索。

#### 这个方向在追问的核心问题

1. **边界模的存在性与唯一性**：给定一个带边界的 3-流形，是否存在一个"自然的"边界模，使得闭流形不变量可以从中读出？如果存在，它是否唯一？
2. **两种完备化的兼容性**：disk-adic 完备化（在 $q=0$ 处展开）和 cyclotomic 完备化（在单位根处展开）是两种本质上不同的拓扑。如何构造一个对象，使得它同时在这两种拓扑下有定义且"行为良好"？
3. **积分性的保持**：量子不变量在根处通常需要分母（如 quantum factorial），如何通过选择合适的格点来消除分母，得到积分不变量？
4. **mapping class group 的作用**：边界模上的 mapping class group 作用如何与闭流形不变量中的 Heegaard 分解联系起来？

#### ⚠️ 作者的 framing

作者将本文定位为"为根处量子不变量理论提供边界模基础"的**第一步**。他明确声称（Theorem 1.1）：本文构造了六类数据——填充商、有限阶段联合商、分裂完备化、端点格点、原始/饱和塔、精确盖域——这些数据"可供根处量子不变量理论使用"。作者特别强调本文的**边界性**：所有构造都是"带标记的"（marked），即固定了一个 Heegaard 分解和 spine，而不是构造一个与分解无关的绝对不变量。作者在 Remark 1.2 中明确列出了**本文不做什么**：不构造全局根处求值、不构造根处不变量、不证明分解无关性、不处理 stabilization 的完整理论。这些被推迟到"companion paper"（[34]）中。

**值得注意的张力**：作者在 Section 10.8 中构造了一个"单孔环面 disk S 箭头"（one-holed-torus disk S-arrow），并声称它是"比双盖配对更强但比缺失的 mapping class 算子更弱"的构造。但作者同时承认（Section 10.8.4），这个箭头**不满足**完整的 braid 关系和 central 关系，因此**不是**一个真正的 mapping class 表示。这是一个明显的"未完成"信号——作者自己承认这个构造是"one-way"的，没有逆箭头。

#### 张力

- **未见明显对立引用**：作者引用的文献之间没有明显的矛盾或对立结论。但存在一个**隐含的张力**：Habiro 的理论（[22]）是"闭流形"的，而 Gilmer–Masbaum 的理论（[18]）是"带边流形"的。本文试图将两者结合，但作者自己也承认（Section 10.9），"closed Habiro theory supplies unified cyclotomic scalars for integral homology spheres... It does not supply the boundary functor"。这意味着本文的构造**不能**直接从 Habiro 的理论中"推出"，而需要新的输入。

**模型**（数据生成机制）：

1. **输入**：一个带标记的 Heegaard 分裂 $M_D = H_\alpha \cup_\Sigma H_\beta$，其中 $\Sigma$ 是亏格 $g$ 的曲面，$H_\alpha$ 中固定一个三叉 spine。
2. **skein 模**：$S_K(H_\alpha; R)$ 是由 $H_\alpha$ 中带标记的 tangle 生成的自由 $R$-模，模去 Kauffman 括号 skein 关系。
3. **填充**：依次附着 $\beta$-handle。每附着一条 $\beta$-曲线，就取一个"slide 差分"的商。所有 slide 差分的和记为 $J^R_D$。
4. **滤过**：定义 $j_N = (A^{2N} P_N)$，其中 $A^{2N}$ 控制 disk 阶，$P_N$ 控制 cyclotomic 阶。
5. **可观测**：研究者能观测到的是**有限阶段商** $M/(J^R_D + j_N M)$，以及这些商之间的转移映射。

**关键区分**：
- **可观测**：有限阶段商、有限维矩阵 $S_{c,N}$、有限多项式 $C_n(q)$。
- **不可观测（潜在）**：联合完备化 $\widehat{M}_{\rm joint}$、无限矩阵、极限对象。

#### 第二步：最小内核

**最小内核**：**有限阶段联合商**。

剥去所有技术细节后，本文的核心数学对象是：

$$M/(J^R_D + j_N M)$$

其中 $j_N = (A^{2N} P_N)$。这个对象有两个关键性质：

1. **有限性**：对每个固定的 $N$，这个商是有限生成的 $R/(j_N)$-模。
2. **双滤过性**：$j_N$ 同时包含 disk 因子 $A^{2N}$ 和 cyclotomic 因子 $P_N$。

**为什么这个对象是"最小内核"**：因为本文的所有主要定理——Theorem 4.3（模 CRT）、Theorem 4.5（分裂完备化）、Theorem 5.5（调节配对）、Theorem 9.7（塔）、Theorem 10.9（rigged 配对）——本质上都是在研究这个有限商在 $N \to \infty$ 时的行为。

**最简例子**：**亏格 1、边界颜色 0、真空态**。

取 $g=1$，边界颜色 $c=0$，考虑真空态 $|0\rangle$。此时：

- lollipop 基退化为单个向量 $L_{0,0}$。
- 相对 Hopf 配对为 $B_0(L_{0,0}, L_{0,0}) = \eta_{0,0} = 1$。
- 正 twist 矩阵 $S_{0,N}$ 是 $1\times 1$ 矩阵，元素为 $b^{(0)}_{0,0} = \mu_0 = 1$。
- 截断 Catalan 多项式 $C_0(q) = 1$。

**这个例子说明什么**：它说明在真空态，所有非平凡结构都消失了——配对是平凡的，twist 是平凡的。这验证了构造的**一致性**（真空态必须给出平凡结果），但不提供任何非平凡信息。

**第一个非平凡例子**：**亏格 1、边界颜色 0、第一激发态**。

取 $c=0, n=1$。此时：

- lollipop 基为 $\{L_{0,0}, L_{0,1}\}$。
- Newton 插值积为 $Q^{(0)}_1 = L_{0,1} - \lambda_0 L_{0,0}$，其中 $\lambda_0 = -q - q^{-1}$。
- 对角范数为 $\eta_{0,1} = q^{-1}(1-q)(1-q^2)^2(1+q^2)(1+q+q^2)$。
- 归一化后：$D_{0,1} = q(1-q)^2(1+q^2)(1+q+q^2) \in q(q;q)_1 \mathbb{Z}[q]$。
- 截断 Catalan 多项式 $C_1(q) = 1 + q + q^2$。

**这个例子说明什么**：它展示了本文的核心机制——**Newton 插值积将 lollipop 基对角化**，使得 Hopf 配对变为对角矩阵，且对角元具有精确的 $q$-adic 阶。$D_{0,1}$ 的分解 $q \cdot (1-q)^2 \cdot (1+q^2) \cdot (1+q+q^2)$ 同时展示了 disk 因子（$q$）和 cyclotomic 因子（$(1-q)^2$ 等）的贡献。这正是"联合滤过"的微观体现。

**为什么这个例子是"最小内核"**：因为 $n=1$ 是第一个非平凡的激发态，它包含了本文所有核心思想——Newton 插值、对角化、$q$-adic 阶、cyclotomic 阶——的最小实例。作者在 Section 5.2 的 "Worked checkpoint" 中专门计算了这个例子，说明作者自己也认为它是理解全文的关键。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：为带标记的 Heegaard 边界模构造一套同时兼容 disk-adic 和 cyclotomic 两种完备化的代数框架，使得闭流形量子不变量可以从中读出。
2. **核心工具/方法**：模块 CRT（Theorem 4.3）、分裂完备化（Theorem 4.5）、Newton 插值 lollipop 基（Theorem 5.1）、调节配对（Theorem 5.5）、原始/饱和塔（Theorem 9.7）、rigged 配对（Theorem 10.9）。
3. **主要结论**：在固定亏格和标记下，存在一个"联合完备化" $\widehat{M}_{\rm joint}$，它同时包含 disk 和 cyclotomic 两种坐标；但不存在一个自然的"根处求值"映射，且原始截断序列在 cyclotomic 拓扑下不收敛（Theorem 10.15）。

#### 关键设定与假设

**设定**：
- 固定亏格 $g \geq 0$，固定一个带标记的 Heegaard 分裂 $M_D$。
- 系数环为 $\Lambda = \mathbb{Z}[A]$，局部化为 $R = \mathbb{Z}[A, A^{-1}]$，有理函数域为 $F_A = \mathbb{Q}(A)$。
- skein 模 $S_K(H_\alpha; R)$ 是自由 $R$-模。

**假设**：
- **标记固定**：所有构造都依赖于一个固定的 Heegaard 分解和 spine。作者明确不处理分解无关性（Remark 1.2）。
- **有限亏格**：所有定理都在固定亏格下陈述，没有 stabilization 的完整理论。
- **系数环为 $\mathbb{Z}[A]$**：这是最"经济"的系数选择，避免了分式域中的问题。
- **recoupling 系数**：使用 Masbaum–Vogel 的积分 recoupling 理论（[31]），假设其系数在 $\mathbb{Z}[A]$ 中。

**相比已有文献的放宽/强化**：
- **放宽**：不要求流形是闭的，允许带边界。
- **强化**：要求所有构造都是"积分的"（在 $\mathbb{Z}[A]$ 上），而不是在分式域上。
- **新增**：引入了"联合滤过" $j_N = (A^{2N} P_N)$，这是 Habiro 和 Gilmer–Masbaum 都没有明确使用的。

#### 主要结果

**Theorem 2.1（填充商）**：对每个 $g \geq 0$，skein 模 $S_K(H_\alpha; R)$ 商去填充 slide 核 $J^R_D$ 后，同构于填充流形 $M_D$ 的 skein 模。这是 Przytycki 定理的直接应用，但作者强调了"slide 差分的顺序无关性"。

**Theorem 4.3（模块 CRT）**：对每个 $N$，$M/(J^R_D + j_N M) \cong M/(J^R_D + A^{2N} M) \times M/(J^R_D + P_N M)$。这是本文最核心的代数工具——它将联合滤过分解为两个独立的滤过。

**Theorem 4.5（分裂完备化）**：$\widehat{M}_{\rm joint} \cong \widehat{M}_{\rm disk} \times \widehat{M}_{\rm cyc}$。这是 Theorem 4.3 的极限形式。

**Theorem 5.5（调节 Hopf 配对）**：在 lollipop 基下，Hopf 配对是对角的，且对角元 $D_{c,n}$ 具有精确的 $q$-adic 阶 $n$。

**Theorem 10.9（rigged 配对）**：构造了一个连续的配对 $\mathcal{P}_{\rm res} \times \mathcal{S}^\dagger \to \widehat{\mathbb{Z}[q]}_{\rm joint}$，它同时兼容 disk 和 cyclotomic 两种拓扑。

**Theorem 10.15（第一 cyclotomic 障碍）**：原始截断序列在 $A=-1$ 处不收敛，因此不能通过简单的截断得到 cyclotomic 不变量。

#### 证明路线与技术技巧

**整体路线**：从 skein 模的代数结构出发，先建立有限阶段的 CRT 分解，然后取极限得到分裂完备化，最后在完备化上构造配对。

**关键步骤**：
1. **建立填充商**（Theorem 2.1）：利用 Przytycki 的 handle 附着定理，将填充流形的 skein 模表示为初始 skein 模的商。
2. **建立 CRT 分解**（Theorem 4.3）：利用 $j_N = (A^{2N} P_N)$ 中两个因子的互素性，证明有限阶段商的直积分解。
3. **取极限**（Theorem 4.5）：证明 CRT 分解与转移映射相容，从而得到分裂完备化。
4. **构造 lollipop 基**（Theorem 5.1-5.5）：利用 Newton 插值积将 lollipop 基对角化，计算对角元。
5. **构造配对**（Theorem 10.9）：利用对角化结果，构造连续的配对。
6. **证明障碍**（Theorem 10.15）：通过计算 $A=-1$ 处的值，证明原始截断不收敛。

**关键技术技巧**：
- **Newton 插值积**：$Q^{(c)}_n = \prod_{i=c}^{c+n-1}(z - \lambda_i)$，其中 $\lambda_i = -q^{i+1} - q^{-i-1}$。这个技巧将 lollipop 基对角化。
- **互补 CRT 幂等元**：$e^{\rm disk}_N = b_N P_N$，$e^{\rm cyc}_N = a_N A^{2N}$，它们实现了 CRT 分解。
- **受限积**：$\mathcal{P}_{\rm res}$ 要求每个坐标在某个 $N$ 之后落在 $J_N$ 中，这保证了配对的收敛性。
- **Catalan 多项式**：$C_n(q)$ 的系数是非负的，且 $C_n(1) = \text{Cat}_{n+1}$，这提供了组合解释。

#### 真实例子与应用

**例子 1：单孔环面（Section 5.2 的 Worked checkpoint）**。

取 $c=0, n=1$，作者计算了归一化对角元 $D_{0,1} = q(1-q)^2(1+q^2)(1+q+q^2)$。这个计算验证了：
- $D_{0,1} \in q(q;q)_1 \mathbb{Z}[q]$（cyclotomic 整除性）
- $\text{ord}_q D_{0,1} = 1$（disk 阶）

**例子 2：真空态（Section 10.7）**。

作者证明了在真空态，$D_{\star}(\lambda_0) = 1$，且 $U_{\lambda_0,g} = A^{2g} \mathbf{1}$。这给出了 stabilization 的真空基准。

**例子 3：第一 cyclotomic 障碍（Section 10.8.3）**。

作者计算了 $c=0, N=1$ 时的截断增量，发现其在 $A=-1$ 处不为零。这个计算直接证明了 Theorem 10.15。

**这些例子想说明什么**：
- 例子 1 展示了联合滤过的微观机制。
- 例子 2 展示了 stabilization 的基准。
- 例子 3 展示了为什么不能简单地"截断"得到 cyclotomic 不变量。

#### 🔎 结论是否比证明窄

**是的，存在明显的"结论比证明窄"的情况**：

1. **Theorem 10.9（rigged 配对）**：作者证明了配对是连续的，但**没有**证明它是非退化的。作者在 Section 10.8.4 中明确说"没有证明逆箭头"，这意味着配对可能是"one-way"的。

2. **Theorem 10.12（stabilization gauge）**：作者证明了 contracted kernel 的整除性，但**没有**证明 stabilization 的完整相容性。作者在 Section 10.9 中说"stabilization of the new arrow"是未解决的。

3. **Theorem 10.15（第一 cyclotomic 障碍）**：作者证明了原始截断不收敛，但**没有**提出替代的收敛方案。作者在 Section 10.9 中说需要"non-monomial counterterm"或"independently unified cyclotomic S-row"。

4. **整体框架**：作者在 Theorem 1.1 中列出了六类数据，但**没有**证明这些数据构成一个"完整的"理论——没有证明分解无关性，没有证明 stabilization 的完整相容性，没有证明与 WRT 不变量的完整比较。

**具体语句**：
- Section 10.8.4: "The following statements are distinct. (1) The $r=0$ line of Theorem 10.14 is a continuous row on one declared disk domain. (2) A generic mapping-class $S$ must be an invertible arrow with a declared inverse domain and must satisfy the braid and central relations. The one-holed-torus relations include $t_\alpha t_\beta t_\alpha = t_\beta t_\alpha t_\beta$, $(t_\alpha t_\beta)^6 = t_\delta$. Those completed relations are not proved here."
- Section 10.9: "The smallest unresolved geometric case is therefore a cyclotomic relative row or non-monomial counterterm which is compatible with that disk arrow, together with the inside/outside connection, inverse, and central $SL_2(\mathbb{Z})$ relations."

### 四、开放问题

1. **逆箭头的构造**：Theorem 10.9 构造的配对是"one-way"的，没有逆箭头。要构造一个真正的 mapping class 表示，需要证明配对是非退化的，并构造逆映射。这需要解决"inside/outside connection"问题。

2. **cyclotomic 相对行的构造**：Theorem 10.15 证明了原始截断在 cyclotomic 拓扑下不收敛。要得到 cyclotomic 不变量，需要构造一个"cyclotomic 相对行"（cyclotomic relative row），它可能与 Habiro 的闭流形理论中的"统一不变量"相容。

3. **stabilization 的完整相容性**：Theorem 10.12 只证明了 contracted kernel 的整除性，没有证明 stabilization 的完整相容性。需要构造一个满足 $S$-specific stabilization law 的 lattice embedding。

4. **分解无关性**：所有构造都依赖于固定的 Heegaard 分解。要得到真正的拓扑不变量，需要证明这些构造在 Heegaard 移动下不变。

5. **与 WRT 不变量的比较**：作者声称这些构造"可供根处量子不变量理论使用"，但没有证明它们确实能重构 WRT 不变量。这需要构造一个"根处求值"映射，并证明它与已知的 WRT 不变量一致。

**验证建议**：要确认这些是否是真 gap，建议去读以下文献的近期工作：
- Habiro 的后续工作（关于 cyclotomic 完备化的推广）
- Gukov–Manolescu 关于 homological blocks 的系列论文
- 关于 skein 模的范畴化（categorification）的近期工作
- 关于量子不变量在根处的行为的近期工作（如 Garoufalidis–Lê 的系列论文）
