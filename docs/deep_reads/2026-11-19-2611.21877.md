### 一、领域脉络与小综述

#### 这个方向是什么

本文所处的子方向是**高维正则化 M-估计的留一交叉验证（LOO-CV）近似理论**。其根本的统计问题是：在维度 p 与样本量 n 同阶（比例极限 p/n → δ）的高维设定下，如何从**单次**全量拟合出发，精确近似"删去第 i 个样本后重新拟合"的留一预测误差，从而避免 n 次重复拟合的巨额计算成本。该方向的成熟度已较高：从光滑惩罚（岭回归）到非光滑惩罚（Lasso、group Lasso）的近似公式均有研究，但**一般凸惩罚**的统一处理此前缺失。本文填补的正是这一缺口。

#### 发展脉络

- **奠基工作**：Rahnama Rad & Maleki (2020) [1] 提出了近似留一交叉验证（ALO）的**可扩展估计量**，在高维线性回归中给出了 |LO − ALO| 的有限样本上界，确立了"用一次拟合近似 n 次重拟合"的基本框架。其关键洞察是：留一拟合的变化可通过**影响函数**（influence function）线性化，而影响函数又可通过观测数据的二阶信息显式计算。
- **主要进展**：Wang et al. (2018) [3] 将 ALO 推广到**非光滑损失与正则项**，基于原始-对偶框架提出了 primal 与 dual 两种近似方案，并证明了在光滑性条件下的等价性。Xu et al. (2019) [9] 则在**中等高维**（p/n < 1）回归中证明了留一交叉验证的相合性，为 ALO 提供了统计保证。Bellec & Shen (2021) [8] 进一步揭示了正则化 M-估计的**导数结构**——估计量对数据矩阵 X 的雅可比矩阵满足一个显式的线性方程，这成为后续构造 ALO 修正矩阵的关键工具。
- **当前 frontier**：Auddy et al. (2024) [5] 针对 ℓ₁ 正则项给出了 ALO 误差的显式界，但依赖**活动集的稳定性**假设。Lin et al. (2026) [10] 研究了块状非光滑正则项，将误差分析归结为**活动集扰动**的大小，但要求块大小有界且正则项在原点附近有良好行为。这些工作各自处理特定非光滑正则项，缺乏统一框架。
- **本文位置**：Bellec 的 Part I (2025) [4] 建立了 ALO 与平均场推断的**同时分析框架**，对光滑惩罚和 group Lasso 给出了无条件（无事件限制）的 O(n⁻¹) 预测误差界和 O(n^{-1/2}) 准则误差界。本文（Part II）将这一框架推广到**任意有限值强凸惩罚**，核心贡献是构造了进入修正项的矩阵 A 的显式公式，并完成了 Lean 4 形式化验证。

#### 子线索聚类

1. **ALO 近似理论**（[1], [3], [9]）：关注 |LO − ALO| 的误差界，方法上依赖影响函数与随机矩阵理论。这条线索的瓶颈是**光滑性假设**——非光滑正则项（如 ℓ₁）需要额外的活动集稳定性条件。
2. **非光滑正则项的 ALO**（[5], [10]）：针对 ℓ₁ 或块状正则项，通过活动集扰动分析给出误差界。这条线索的瓶颈是**正则项的具体结构**——每个正则项需要单独分析，缺乏统一处理。
3. **导数结构与影响函数**（[8], [2]）：揭示 M-估计对数据的导数满足显式线性方程，为构造 ALO 修正矩阵提供代数工具。这条线索是本文的直接技术基础。
4. **平均场推断与随机矩阵**（[4] 及本文）：将 ALO 与平均场推断统一分析，利用高斯设计的条件分布和 Stein 引理给出无条件界。本文在此线索上完成了**一般凸惩罚**的推广。

#### 这个方向在追问的核心问题

1. **ALO 修正矩阵 A 的显式形式**：对于一般凸惩罚，进入修正项的矩阵 A 应如何构造？此前仅对光滑惩罚（逆 Hessian）和 group Lasso（活动集逆）已知。
2. **无条件误差界**：能否在**不依赖活动集稳定性**等事件限制的条件下，证明 ALO 与 LOO 的误差为 O(n⁻¹)？Part I 对光滑惩罚和 group Lasso 已实现，一般凸惩罚是否可行？
3. **平均场推断的等价性**：ALO 的逐样本修正与平均场推断的全局修正（trace 项）在何种意义上等价？这种等价性是否需要显式的 A 公式？

#### ⚠️ 作者的 framing

作者将缺口 frame 成：**"Part I 的分析仅覆盖光滑惩罚和 group Lasso，其证明依赖这些惩罚的显式结构（逆 Hessian 或活动集逆）。对于一般有限值强凸惩罚，进入修正项的矩阵 A 缺乏显式公式，因此无法应用 Part I 的概率论证。"** 作者的解决方案是：**"利用惩罚响应在观测次梯度处的普通导数构造 A，其投影-伪逆公式将响应空间与惩罚曲率分离，从而统一了光滑与 group Lasso 的情形。"** 这是作者的说法，其说服力需由读者自行判断。

#### 张力

未见明显对立引用。但值得注意的是：Lin et al. [10] 的块状正则项分析依赖**块大小有界**，而本文的构造允许**任意有限值强凸惩罚**（包括块大小无界的情形），两者在适用条件上存在张力——本文是否真正覆盖了 Lin et al. 的设定，需读者自行核实（特别是 group Lasso 中块大小随 p 增长的情形）。


### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

**可观测数据**：
- 设计矩阵 X ∈ ℝ^{n×p}，行 x_i^T 独立同分布 N(0, Σ)，Σ ≻ 0。
- 响应 y_i ∈ ℝ，通过单指标模型 y_i = f_i(U, x_i^T β) 生成，其中 β ∈ ℝ^p 固定，U 是与 X 独立的任意随机元，f_i 为可测函数。线性回归 y_i = x_i^T β + ε_i 是特例（取 U = ε，f_i(U, t) = t + ε_i）。
- 损失函数 L_y(t) 对每个 y 凸、可微，得分函数 ψ_y = L'_y 满足 |ψ_y| ≤ 1 且 1-Lipschitz。
- 惩罚 R: ℝ^p → ℝ 有限值、强凸（在协方差度量下，见假设 (1.1)）、在 0 处取最小值。

**参数 / 估计量**：
- 全量估计：b̂ = argmin_b { Σ_{i=1}^n L_{y_i}(x_i^T b) + R(b) }。
- 留一估计：b̂^{(-i)} = argmin_b { Σ_{k≠i} L_{y_k}(x_k^T b) + R(b) }。
- 留一预测：t_i^{LOO} = x_i^T b̂^{(-i)}。
- 目标量（estimand）：LOO 准则 (1/n) Σ_i g(t_i^{LOO}, y_i)，其中 g 为 1-Lipschitz 测试函数。

**核心记号**：
- 得分向量 s ∈ ℝ^n，s_i = ψ_{y_i}(t_i)，t_i = x_i^T b̂。
- 曲率对角阵 D = diag(d_i)，d_i = ψ'_{y_i}(t_i)（在不可导处取 0，0 ≤ d_i ≤ 1）。
- 惩罚响应 G_R(v) = argmin_b { R(b) − v^T b }，即惩罚在外部力 v 下的最优响应；G_R(q) = b̂，其中 q = −X^T s ∈ ∂R(b̂)。
- 修正矩阵 A ∈ ℝ^{p×p}：ALO 预测 t_i^{ALO} = t_i + s_i · x_i^T A x_i / (1 − d_i x_i^T A x_i)，平均场预测 t_i^{MF} = t_i + s_i · tr(AΣ)。

**关键假设**：
- 比例极限：p ≤ n/δ，δ > 0 固定。
- 强凸性：R(b) − (nμ/2) b^T Σ b 为凸，μ > 0 固定。
- 高斯设计：X 的行独立 N(0, Σ)。

#### 第二步：最小内核

**核心问题**：留一预测 t_i^{LOO} 需要删除第 i 个样本重新拟合，计算成本为 O(n) 次拟合。能否从单次全量拟合 b̂ 出发，用**显式公式**近似 t_i^{LOO}？

**最小内核（光滑惩罚情形）**：假设 R 是二次可微的（如岭回归 R(b) = (λ/2)‖b‖²）。全量估计的一阶条件为：

Σ_i ψ_{y_i}(x_i^T b̂) x_i + ∇R(b̂) = 0。

删除第 i 个样本后，一阶条件变为：

Σ_{k≠i} ψ_{y_k}(x_k^T b̂^{(-i)}) x_k + ∇R(b̂^{(-i)}) = 0。

将 b̂^{(-i)} 视为 b̂ 的微小扰动 b̂ + δ_i，对一阶条件做一阶泰勒展开：

[∇²R(b̂) + X^T D X] δ_i ≈ ψ_{y_i}(t_i) x_i = s_i x_i。

因此 δ_i ≈ s_i · A x_i，其中 A = [∇²R(b̂) + X^T D X]⁻¹。于是：

t_i^{LOO} = x_i^T b̂^{(-i)} ≈ x_i^T b̂ + s_i · x_i^T A x_i = t_i + s_i · x_i^T A x_i。

**这就是 ALO 的核心思想**：留一预测 ≈ 全量预测 + 一个**影响函数修正项**，修正项由得分 s_i、曲率 D 和惩罚曲率 ∇²R(b̂) 决定。修正项的分子 x_i^T A x_i 是杠杆值（leverage），分母 1 − d_i x_i^T A x_i 来自 Sherman–Morrison 的精确化。

**本文的推广**：当 R 非光滑（如 Lasso、group Lasso）时，∇²R(b̂) 不存在。本文的核心构造是：**用惩罚响应 G_R 在观测次梯度 q 处的普通导数 J 替代 ∇²R(b̂)⁻¹**，得到 A_der = J(PJ + J^T X^T D X J)† J^T。这个公式的直观含义是：惩罚的曲率不是由 Hessian 给出（不存在），而是由**响应函数 G_R 在 q 处的斜率**给出——即使 R 在 b̂ 处不可导，G_R 在 q 处仍可能可导（因为强凸性保证了 G_R 的 Lipschitz 性，而 Lipschitz 函数几乎处处可导）。

**为什么这个构造有效**：强凸性 (1.1) 保证了 G_R 是 (nμ)⁻¹-Lipschitz 的，因此 G_R 在 q 处几乎处处可导。本文选取 G_R 在 q 处的普通导数 J（若不可导则取某个 Borel 可测的极限），并证明由此构造的 A_der 满足与光滑情形相同的代数性质：A_der 是对称半正定的，且满足能量不等式 z^T A_der z ≤ ‖z‖²/(nμ)。这些性质足以让 Part I 的概率论证（基于高斯条件分布和 Stein 引理）原封不动地通过。

**最小内核的数学本质**：本文在数学上干的事情是——**证明存在一个仅依赖观测数据 (X, y)、损失 L 和惩罚 R 的 Borel 可测矩阵 A_der，使得 ALO 和平均场预测与精确留一预测的期望误差分别为 O(n⁻¹) 和 O(n^{-1/2})，且构造 A_der 不需要任何关于惩罚光滑性或活动集稳定性的假设。** 证明的关键是：将非光滑惩罚的曲率信息编码在惩罚响应的导数中，而不是 Hessian 中。


### 三、这篇论文做了什么

#### 三句话

① **研究了什么问题**：对于一般有限值强凸惩罚的正则化 M-估计，如何构造进入 ALO 和平均场修正项的矩阵 A，使得 ALO/平均场预测与精确留一预测的误差达到 O(n⁻¹) / O(n^{-1/2})？

② **核心工具 / 方法**：惩罚响应 G_R 的普通导数（非 Hessian）、投影-伪逆公式、高斯条件分布 + Stein 引理、Lean 4 形式化证明。

③ **主要结论**：构造了数据驱动的 A_der，证明其满足与光滑情形相同的代数性质（对称、半正定、能量界），并由此得到 ALO 和平均场预测的无条件 O(n⁻¹) / O(n^{-1/2}) 误差界；该构造在光滑惩罚和 group Lasso 情形下精确还原已知公式。

#### 关键设定与假设

- **设计**：X 的行独立 N(0, Σ)，Σ ≻ 0，p ≤ n/δ。
- **损失**：L_y 凸、可微，得分 ψ_y 有界且 1-Lipschitz（|ψ_y| ≤ 1, Lip(ψ_y) ≤ 1）。
- **惩罚**：R 有限值、强凸（R(b) − (nμ/2)b^T Σb 凸）、在 0 处取最小值。**不要求可微**。
- **响应模型**：y_i = f_i(U, x_i^T β)，U 独立于 X，β 固定。这覆盖线性回归、单指标模型等。
- **相比已有工作的放宽**：相比 Part I 的光滑惩罚和 group Lasso 设定，本文**不要求惩罚可微**，也不要求活动集稳定性（如严格互补条件）。相比 Lin et al. [10] 的块状正则项分析，本文不要求块大小有界。

#### 主要结果

**定理 7.1（一般惩罚的 ALO 与平均场界）**：在以上假设下，取 A = A_der，则：

(7.1) (1/n) Σ_i E[|t_i^{ALO}(A_der) − t_i^{LOO}|²] ≤ C(μ,δ)/n

(7.2) E|ALO(A_der) − LOO| + E|MF(A_der) − LOO| ≤ C'(μ,δ)/√n

其中 C, C' 仅依赖 μ, δ，不依赖 n, p, β, 损失或惩罚的具体形式。这些是**无条件**期望界——不需要对观测数据施加任何事件限制。

**命题 6.1（公式还原）**：
- 若 R 二次可微，则 A_der = [∇²R(b̂) + X^T D X]⁻¹，精确还原光滑情形的逆 Hessian 公式。
- 对 group Lasso 惩罚，A_der = [Π_{Ŝ}(B_{Ŝ} + X^T D X)Π_{Ŝ}]†，精确还原活动集逆公式（含非活动边界组）。

**定理 F.3（秩比较）**：在非零得分向量的事件上，rank(A_der − A_si) ≤ 4，其中 A_si 是证明中使用的信号切片上的典范算子。这个秩界是 Stein 引理论证的核心——两个算子仅在至多 4 维子空间上不同，因此它们的迹差可以被控制。

#### 证明路线与技术技巧

**整体路线**（5 步）：

1. **信号切片分解**：固定外部随机性 U 和信号方向 β，将设计矩阵 X 分解为信号方向上的分量和正交补。在信号切片上，响应 y_i 仅通过 x_i^T β 影响损失，从而可以将问题转化为一个"有效回归"问题。

2. **典范算子 A_si 的构造**：在信号切片上，定义典范算子 A_si 为全量拟合对设计的导数（通过隐函数定理）。A_si 满足 forcing 方程 A_si(C + M B) = B，其中 B, C 分别是系数和次梯度对设计的导数。

3. **数据驱动算子 A_der 的构造**：用惩罚响应 G_R 在观测次梯度 q 处的普通导数 J 构造 A_der = J(PJ + J^T X^T D X J)† J^T。关键引理（命题 C.1）证明 A_der 满足与 A_si 相同的 forcing 方程，且 rank(A_der − A_si) ≤ 4。

4. **概率比较**：在行范数事件 Ω = {max_i ‖Σ^{-1/2} x_i‖ ≤ √p + √n} 上，利用高斯条件分布和 Stein 引理，将 ALO/平均场权重与 A_si 的权重之差分解为秩 ≤ 4 的项加上可控制的余项。秩 ≤ 4 的项通过高斯矩的有限秩性质控制。

5. **无条件化**：利用高斯尾概率估计控制 Ω 的补集，得到无条件期望界。关键技巧是：在 Ω 上使用条件论证，在 Ω^c 上使用平凡的界（由 A_der 的范数界保证），然后加权求和。

**技术技巧点名**：

- **惩罚响应导数**：用 G_R 的普通导数替代 Hessian，这是处理非光滑惩罚的核心技巧。强凸性保证 G_R 的 Lipschitz 性，从而几乎处处可导。
- **投影-伪逆公式**：A_der = J(PJ + J^T X^T D X J)† J^T 将响应空间（ran J）与惩罚曲率（通过 PJ 项）分离，使得公式在光滑和非光滑情形下统一。
- **有限秩比较**：rank(A_der − A_si) ≤ 4 是 Stein 引理论证的关键——高维随机矩阵的迹差可以通过有限秩扰动控制。
- **Borel 可测选择**：在不可导点，用 Borel 可测的极限选择定义 J，保证 A_der 是良定义的随机矩阵。
- **Lean 4 形式化**：所有构造和证明均在 Lean 4 中形式化，消除了"几乎处处"论证中的测度论细节隐患。

#### 真实例子与应用

本文**没有**包含数值实验或真实数据应用，为纯理论论文。但定理 7.1 的适用范围包括：
- **线性回归**：y_i = x_i^T β + ε_i，损失 L_{y_i}(t) = (1/2)(y_i − t)²，惩罚 R 为任意有限值强凸函数（如岭、elastic net、group Lasso 加 ridge）。
- **鲁棒回归**：L_{y_i}(t) = ρ(y_i − t)，ρ 为 Huber 损失等，得分有界且 Lipschitz。
- **分类**：逻辑回归损失 L_{y_i}(t) = log(1 + exp(−y_i t))，y_i ∈ {−1, 1}。

#### 🔎 结论是否比证明窄

- 定理 7.1 的证明在**信号切片**上进行，要求设计 X 为高斯。作者在 Remark A.1 中说明 A_der 的构造不依赖 Σ，但**证明**使用了高斯条件分布。作者声称"高斯设计"是证明技术所需，而非构造所需——这一区分的可靠性需读者自行判断。
- 定理 7.1 的**预测误差界**是 O(n⁻¹)，但**准则误差界**（即 |ALO(A_der) − LOO|）是 O(n^{-1/2})。作者在 Remark E.1 中说明这是由测试函数的 Lipschitz 性质决定的，但**没有**声称 O(n^{-1/2}) 是最优的。
- 定理 F.3 的秩界 rank(A_der − A_si) ≤ 4 在**非零得分**事件上成立。在零得分事件上，作者仅说明"加权修正项消失"，但**没有**给出 A_der 与 A_si 的秩比较。这一事件在连续损失下概率为零，但在离散损失（如分类）下可能具有正概率。
- 作者在 Section 8 中列出了 Lean 4 形式化的具体声明名称，但**没有**说明形式化覆盖了证明的哪些部分（例如，是否覆盖了所有"几乎处处"论证）。读者需自行检查 Lean 代码确认覆盖范围。


### 四、开放问题

1. **非高斯设计的推广**：定理 7.1 的证明依赖高斯条件分布。作者在 Remark A.1 中暗示构造不依赖 Σ，但**证明**是否能在非高斯设计（如次高斯、独立有界坐标）下成立？扎根于：定理 7.1 的假设"rows of X are independent N(0, Σ) vectors"。

2. **最优常数**：定理 7.1 给出 C(μ,δ) 和 C'(μ,δ) 的存在性，但未给出显式值。这些常数是否随 δ 恶化？扎根于：定理 7.1 的陈述"finite constants C(μ,δ) and C'(μ,δ)"。

3. **零得分事件的精细处理**：定理 F.3 的秩界在零得分事件上不成立。对于分类问题（y_i ∈ {−1,1}），这一事件可能具有正概率。能否给出该事件上的精细界？扎根于：定理 F.3 的陈述"on {s ≠ 0}"。

4. **A_der 的计算效率**：A_der 的构造需要计算惩罚响应 G_R 在 q 处的导数 J。对于一般凸惩罚，J 的计算成本如何？是否存在闭式公式？扎根于：Section 6 中 A_der 的定义（公式 6.2）。

5. **平均场推断的进一步等价性**：本文证明了 ALO 和平均场预测都与 LOO 接近，但**没有**直接比较 ALO 和平均场预测之间的差异。两者在何种条件下等价？扎根于：定理 7.1 分别给出 ALO 和 MF 的界，但未比较两者。
