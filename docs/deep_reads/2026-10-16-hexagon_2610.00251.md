### 一、领域脉络与小综述

- **这个方向是什么**：本文属于低维拓扑与量子拓扑的交叉领域，具体研究 Walker 扩展配边范畴（Walker's extended cobordism category）中"带标记手柄"（marked handles）的相干性（coherence）问题。该范畴是构造（1+1+1）-TQFT（拓扑量子场论）的代数骨架，其对象是带标记的曲面，态射是带标记的配边（cobordism）。本文要解决的根本问题是：当多个手柄操作（handleslide）在空间上分离（disjoint）时，它们的复合是否与操作顺序无关，以及这种无关性在"带相位标记"（phase-labeled）的精细层面上是否仍然成立。该方向当前处于"基础理论构建"阶段——它不直接计算某个具体流形不变量，而是为后续的 TQFT 构造提供严格的范畴论基石。

- **发展脉络（history）**：从引言和参考文献看，这条线的奠基性工作是 Kevin Walker 的未出版手稿 [Wal91]，它提出了扩展配边范畴的基本框架。随后，BHMV [BHMV95] 和 Gilmer–Masbaum [GM07, GM13] 将这一框架与 Kauffman bracket 量子不变量结合，建立了从范畴到数值不变量的"求值"通道，其中 Maslov 指标和 Lagrangian 子空间的选择是关键的技术工具。近期的进展来自 Heegaard Floer 理论一侧：Juhász–Thurston–Zemke [JTZ21] 证明了映射类群在 Heegaard Floer 同调中的自然性，其中包含了 handleslide 的相干性要求；Qin [Qin25] 则证明了 sutured 压缩体复形的单连通性（通过三角形、正方形、五边形关系）。本文作者的前作 [Sun26] 处理了"重叠"（overlapping）手柄滑动的五边形关系，而本文则处理"分离"（disjoint）情形下的布尔立方体相干性。本文的位置是：在 Walker 范畴的框架内，把 [JTZ21] 和 [Qin25] 中隐含的相干性要求，用 [GM13] 的 Maslov 指标技术，做成精确的、带权重的等式。

- **子线索聚类**：这些被引文献大致落在三条子线索上：
  1. **Walker 扩展配边范畴与 TQFT 构造**（[Wal91], [GM07], [GM13], [BHMV95]）：这条线关心的是如何从几何数据（曲面、配边、Lagrangian）构造代数对象（范畴、TQFT 函子），以及如何用 Maslov 指标处理相位问题。本文的主要技术工具（Walker 权重、Maslov 指标、Lagrangian 传输）都来自这条线。
  2. **映射类群与 Heegaard 理论的相干性**（[HT80], [JTZ21], [Qin25]）：这条线关心的是 handleslide 作为映射类群生成元时的关系（braid 关系、五边形关系），以及这些关系在 Floer 同调或复形层面是否严格成立。本文的布尔立方体结构直接对应这条线中的"正方形关系"。
  3. **（隐含的）低维拓扑中的计算工具**：虽然本文没有直接引用，但 handleslide 是 Heegaard 分解和结补空间研究的基本操作，[HT80] 的经典结果（映射类群由 Dehn 扭转生成）是这一切的起点。

- **这个方向在追问的核心问题**：
  1. **相干性到什么程度？** 在 Walker 范畴中，两个 handleslide 的复合是否严格等于另一个 handleslide（而非仅差一个同伦或一个相位因子）？本文的答案是：在分离情形下，严格相等，且权重（Walker weight）只依赖于"匹配数"（match count），不依赖于顺序。
  2. **相位标记如何与几何操作交互？** 当手柄带有"正向/反向"相位标记时，匹配与不匹配的相位对如何影响最终的拓扑类型（S¹×S² vs. 恒等圆柱）？本文的答案是：匹配产生 S¹×S² 因子，不匹配产生恒等因子。
  3. **如何将局部相干性组装为全局相干性？** 单个手柄的局部计算（定理 A）如何通过布尔立方体结构（定理 B）组装为任意有限顺序的全局等式？本文的答案是：通过"分离保护区的逐点交换"和"有限路径的相邻替换"。

- **⚠️ 作者的 framing（必须明确标注成"这是作者的说法"）**：作者在引言和结论中把本文的贡献 frame 成"在 Walker 扩展配边范畴中，对分离手柄滑动建立了完整的、带权重的相干性理论"，并强调这是"精确的源范畴层面的等式，而非仅在同伦或投影层面"。作者刻意淡化了与 Heegaard Floer 同调的直接联系（只在引用 [JTZ21] 时提及"自然性"），也回避了与 WRT 不变量的数值比较（明确列为 non-claim）。**值得研究者去查的问题**：作者在 Section 11.3 列出了 16 条 non-claims，其中第 (15) 条"不做 WRT 比较"和第 (16) 条"不做 bZ 或 Habiro 提升比较"——这两条恰恰是统计学家最关心的"可验证预测"的缺失。如果该相干性理论是正确的，它应该能推出某些数值不变量之间的关系，但作者明确不承诺这一点。另一个值得查的点是：引言中没有引用任何关于"handleslide 复形"（如 Hatcher–Wahl 或其他）的现代工作，这是否意味着作者有意回避了与这些工作的衔接？

- **张力**：被引文献之间未见明显对立。但有一个微妙的张力值得注意：[Qin25] 证明的是 sutured 压缩体复形的**单连通性**（即所有关系都由三角形、正方形、五边形生成），而本文证明的是**分离手柄滑动的严格交换性**（即正方形关系在 Walker 范畴中严格成立）。这两者并不矛盾，但前者暗示"可能存在更复杂的关系"，后者则证明"在分离情形下，关系只有交换性"。如果 [Qin25] 的复形包含非正方形的关系，那么本文的分离性假设（disjoint protected sectors）就是本质的，不能放松。

### 二、最核心、最简单的例子 / 数学问题

**第一步：把符号、模型、可观测数据交代清楚**

在展开技术细节之前，先建立记号。本文的核心对象是 **Walker 扩展配边范畴**，其基本数据如下：

- **对象（Objects）**：带标记的闭曲面。具体地，固定亏格 g ≥ 1 的曲面 Σ_g，以及一个有理 Lagrangian 子空间 λ ⊂ H₁(Σ_g; ℚ)。一个"带标记曲面"记作 (Σ_g, λ)。在本文中，我们从一个"旧"曲面 Σ_g^out 出发，通过在手柄上附加"标记圆盘"（marked disks）得到新的曲面。
- **态射（Morphisms）**：带标记的配边（cobordism）。从一个带标记曲面 (Σ₋, λ₋) 到另一个 (Σ₊, λ₊) 的态射是一个三元组 (W, λ_W, φ)，其中 W 是一个三维流形，∂W = Σ₋ ⊔ Σ₊，λ_W 是 W 上的 Lagrangian，φ 是边界标记的保持映射。态射的复合是配边的粘合。
- **关键记号**：
  - **k**：标记圆盘（即"手柄"）的个数。每个圆盘 d_t (t = 1, ..., k) 是一个分离的、带标签的圆盘，位于旧曲面 Σ_g^out 上。
  - **状态子集 I ⊆ [k]**：记录哪些手柄已经被"附着"（attached）。曲面 Σ_I^out 是通过在 Σ_g^out 上附着 I 中所有手柄得到的。
  - **相位向量 ε, η ∈ {0,1}^k**：每个手柄可以处于相位 0（正向）或相位 1（反向）。ε 是"正向"手柄的相位，η 是"反向"手柄的相位。
  - **权重向量 c, r, u⁺, u⁻ ∈ ℤ^k**：这些是 Walker 权重，分别对应"正向手柄的基础权重"（c_t）、"反向手柄的基础权重"（r_t）、"正向相位附加权重"（u_t⁺）、"反向相位附加权重"（u_t⁻）。权重是整数，可以取负值。
  - **Walker 态射**：C(φ, n) 表示映射 φ 的 Walker 映射柱体（mapping cylinder），权重为 n。C(id_Σ, n) 是恒等映射的柱体，权重为 n。
  - **J^e_{t|I}**：在状态 I 下，第 t 个手柄的"正向"（e = 0）或"反向"（e = 1）附着态射。类型为 Σ_I^out → Σ_{I∪{t}}^out。
  - **R^v_{t|I}**：对应的"反向"（移除）态射，类型为 Σ_{I∪{t}}^out → Σ_I^out。
  - **D_{t|I}(n)**：在状态 I 下，第 t 个手柄的"局部双重"（double），权重为 n，是 R^v_{t|I} J^e_{t|I} 的复合。
  - **S_{i|I}**：第 i 个手柄的"半扭转"（half-turn）映射柱体，权重为 0。
  - **H_{a|A}**：第 a 个"滑动"（slide）的 Walker 柱体，权重为 0。
  - **M^{ε,η}_{α,β}**：混合双重，即反向手柄（相位 η，顺序 β）复合正向手柄（相位 ε，顺序 α）的结果。
  - **N(W)**：配边 W 的 Lagrangian 关系（homological Lagrangian relation）。
  - **μ_Σ(L₁, L₂, L₃)**：Maslov 指标，是三个 Lagrangian 子空间的函数，取整数值。
  - **β₁(W)**：三维流形 W 的第一 Betti 数。
  - **#**：连通和（connected sum）。
  - **d_H(ε, η)**：两个相位向量的汉明距离（即不同的位数）。

- **模型（数据生成机制）**：本文的"模型"是一个几何构造，而非统计模型。数据生成机制如下：
  1. 从旧曲面 (Σ_g^out, λ_g) 出发。
  2. 选择 k 个分离的、带标签的圆盘 d₁, ..., d_k。
  3. 对每个圆盘，选择相位 ε_t（正向）或 η_t（反向），以及权重 c_t, r_t, u_t⁺, u_t⁻。
  4. 按顺序 α 附着正向手柄，得到态射 J^ε_α。
  5. 按顺序 β 移除反向手柄，得到态射 R^η_β。
  6. 复合得到混合双重 M^{ε,η}_{α,β}。

- **可观测数据**：本文的"可观测数据"是最终的 Walker 态射 M^{ε,η}_{α,β} 的拓扑类型（是否同构于恒等柱体加上若干 S¹×S² 因子）和 Walker 权重（N）。研究者可以"观测"到的是：
  - 第一 Betti 数 β₁(M^{ε,η}_{α,β}) = 2g + b，其中 b 是匹配的相位对数。
  - Walker 权重 N = Σ_t (c_t + r_t + ε_t u_t⁺ + η_t u_t⁻)。
  - 态射的复合是否与顺序 α, β 无关。

**第二步：讲最小内核**

本文的核心数学问题可以归结为以下最小内核：

**最小问题**：考虑一个固定的手柄 t。当我们先"正向附着"（相位 ε_t = 0）再"反向移除"（相位 η_t = 0）时，得到的复合 R^0_{t|I} J^0_{t|I} 是什么？

**答案（定理 A 的特例）**：
- 如果 ε_t = η_t（匹配），则 R^0_{t|I} J^0_{t|I} = D_{t|I}(n_t)，其中 D_{t|I}(n_t) ≅ C(id, n_t) # (S¹×S², 0)。也就是说，复合的结果是一个恒等柱体（权重 n_t）与一个 S¹×S² 因子的连通和。这个 S¹×S² 因子是"真正的"拓扑贡献，它来自手柄的附着和移除。
- 如果 ε_t ≠ η_t（不匹配），则 R^1_{t|I} J^0_{t|I} = C(id, n_t)。也就是说，复合的结果只是一个恒等柱体，权重为 n_t，没有 S¹×S² 因子。

**为什么这个例子是核心**：因为整个定理 A 的证明就是把这个单手柄的计算，通过"分离保护区"的假设，推广到 k 个手柄的情形。关键的技术步骤是：
1. **局部化**（Proposition 3.2）：半扭转 S²_{i|I} 可以局部化到第 i 个手柄的邻域内，且满足 S⁴_{i|I} = V_{d_{i|I}}（一个边界扭转）。
2. **吸收**（Proposition 3.3）：反向移除可以吸收边界扭转，即 R^rev_{i|I}(0) V_{d_{i|I}} = R^rev_{i|I}(0)。
3. **匹配计数**（Theorem 5.3）：全局的混合双重 M^{ε,η}_{α,β} 的拓扑类型只取决于匹配的相位对数 b，不取决于顺序 α, β。

**为什么这个结果非平凡**：因为虽然单个手柄的附着和移除看起来像是"先加后减"，但在三维流形中，这个操作并不平凡——它会在流形中留下一个 S¹×S² 因子。这个因子是"拓扑荷"，不能通过连续形变消除。本文的贡献在于证明：当多个手柄分离时，这些拓扑荷是**可加的**，且**不依赖于操作顺序**。

**数学上到底干了什么事**：本文证明了在 Walker 扩展配边范畴中，分离的 handleslide 操作构成一个"严格交换"的族。具体来说，它构造了一个从布尔格 {0,1}^k 到 Walker 范畴的函子，使得每个面（face）都严格交换（而非仅差一个同伦）。这个结果的证明依赖于：
1. **几何分离**：保护区 U_a 两两不相交，且每个保护区包含完整的局部数据。
2. **Walker 权重的可加性**：总权重 N 是各局部权重之和，不依赖于顺序。
3. **Maslov 指标的消没**：所有中间界面的 Maslov 修正都为零，因为每个界面上的 Lagrangian 都有重复项。

### 三、这篇论文做了什么

**三句话**：
1. **研究了什么问题**：在 Walker 扩展配边范畴中，证明了两个精确的相干性结果：(A) 固定位置的"正向-反向"手柄复合，其拓扑类型只取决于相位匹配数，不取决于附着顺序；(B) 分离的 handleslide 操作构成一个完整的布尔立方体，每个面都严格交换，且所有有限路径的复合相同。
2. **核心工具/方法**：使用 Walker 的扩展配边范畴框架，结合 Maslov 指标和 Lagrangian 传输技术，通过"分离保护区"的几何假设，将局部计算（单手柄）组装为全局结果（多手柄）。
3. **主要结论**：定理 A（固定位置相位双重）和定理 B（分离 handleslide 立方体）给出了精确的、带权重的等式；推论给出了第一 Betti 数公式 β₁ = 2g + b，以及一个可选的 SO(3)-TQFT 标量公式。

**关键设定与假设**：
- **分离性假设**：保护区 U_a 两两不相交，且每个保护区包含完整的局部数据（定理 B 的核心假设）。这个假设是本质的，不能放松为"同伦分离"或"同调分离"。
- **标记完整性**：每个保护区包含完整的标记数据：定向曲线、framing、 collar、cut-face 数据、双肋、检测器、符号面等。这是"完整标记"（complete marking）假设。
- **Walker 权重**：权重是整数，可以取负值。权重通过 Maslov 指标计算，且满足可加性。
- **相位向量**：ε, η ∈ {0,1}^k，每个手柄可以处于正向或反向相位。相位匹配（ε_t = η_t）产生 S¹×S² 因子，不匹配产生恒等因子。
- **与已有文献的比较**：相比 [Qin25] 的 sutured 压缩体复形（处理 isotopy 类），本文处理的是**具体的、带标记的**代表元，因此结论更强（严格相等而非同伦）。相比 [JTZ21] 的 Heegaard Floer 自然性，本文不涉及 Floer 同调，只处理源范畴层面的几何。

**主要结果**：
- **定理 A（固定位置相位双重）**：对任意状态 I ⊆ [k] 和 t ∉ I，匹配的相位对贡献一个局部 S¹×S² 因子，不匹配的相位对贡献恒等柱体。总权重 N = Σ_t (c_t + r_t + ε_t u_t⁺ + η_t u_t⁻)。第一 Betti 数 β₁ = 2g + b。
- **定理 B（分离 handleslide 立方体）**：对任意两个不相交的保护区，handleslide 操作严格交换（作为光滑映射，而非仅差同伦）。所有有限路径的复合相同，且端点恒等 telescoping。
- **推论（SO(3)-TQFT 标量）**：在奇数素数 p 的 SO(3)-TQFT 中，固定位置双重的求值为 κ_p^N (D_p^GM)^b 乘以恒等映射。

**证明路线**：
1. **第一步（Section 2-3）**：建立 Walker 范畴的记号，证明局部化定理（Proposition 3.2）和吸收定理（Proposition 3.3）。关键技巧是使用"分离保护区"和"完整标记"来确保所有 Maslov 修正为零。
2. **第二步（Section 4-5）**：证明固定位置的相位双重定理（定理 A）。关键步骤是：(i) 将任意顺序的附着/移除重排为标准顺序；(ii) 使用吸收定理消除中间界面的扭转；(iii) 计算总权重。
3. **第三步（Section 6-7）**：构造分离 handleslide 的保护区，证明局部滑动操作的良定义性（Lemma 6.2）。
4. **第四步（Section 8-9）**：证明 handleslide 的协变性（定理 B）。关键步骤是：(i) 证明每个二维面严格交换（Proposition 9.4）；(ii) 使用相邻替换证明所有有限路径的复合相同（Proposition 9.6-9.8）。
5. **第五步（Section 10）**：应用 SO(3)-TQFT 求值，得到标量公式。

**技术技巧**：
- **分离保护区**：将全局问题分解为局部问题，每个保护区包含完整的标记数据。这是处理"严格相等"而非"同伦相等"的关键。
- **Maslov 指标的消没**：通过选择"公共 Lagrangian"（common Lagrangian），使得所有中间界面的 Maslov 修正为零。这是计算 Walker 权重的核心技巧。
- **吸收引理**：反向移除可以吸收边界扭转，这允许在重排顺序时消除多余的扭转因子。
- **有限路径的相邻替换**：使用 Coxeter 关系的组合学（平方、远处交换、braid 关系）来证明所有路径的复合相同。

**真实例子与应用**：
- **最小例子（k=1）**：单个手柄的相位双重。匹配（ε=η）产生 S¹×S²，不匹配产生恒等柱体。这是整个理论的"原子"。
- **k=2 的例子**：两个手柄，一个匹配一个不匹配。总 Betti 数 β₁ = 2g + 1，权重 N = c₁ + r₁ + c₂ + r₂ + u₂⁻（假设 ε₂=0, η₂=1）。
- **应用**：本文没有直接应用，但为 Walker 范畴的 TQFT 构造提供了严格的相干性基础。任何需要"handleslide 不变性"的 TQFT 构造（如 WRT 不变量的范畴化）都可以使用本文的定理。

**🔎 结论是否比证明窄**：
