### 一、领域脉络与小综述

#### 这个方向是什么

本文所处的子方向是**马尔可夫链蒙特卡洛（MCMC）估计的非渐近误差控制**，更具体地说，是**对平稳分布泛函的经验估计构造显式的、高概率成立的均匀置信带**。根本的统计问题是：当我们用一条马尔可夫链的样本路径去估计平稳分布 π 下某个泛函（如状态空间函数 θ 的 CDF）时，如何给出一个不依赖渐近近似、且对有限样本严格成立的误差界？这个方向的成熟度处于"经典结果已建立、但自适应/数据依赖版本尚待发展"的阶段——经典 DKW 不等式对 iid 数据已完全成熟（Massart 1990 给出最优常数），但对马尔可夫链的推广仍在活跃发展中。

#### 发展脉络

- **奠基工作：经典 DKW 不等式**。Dvoretzky-Kiefer-Wolfowitz (1956) 证明了 iid 样本的经验 CDF 与真实 CDF 的 sup-norm 距离以指数速度衰减；Massart (1990) 确定了最优常数 2，得到 `P(sup_x |F_n(x) - F(x)| > ε) ≤ 2exp(-2nε²)`。这是整个领域的基准——任何马尔可夫链版本的推广都以"能否恢复到这个速率和常数"为衡量标准。本文引用的 Reeve (2024) 给出了该不等式的一个更短证明，并去掉了对失败概率的限制条件，说明这个经典结果本身仍在被简化。

- **向依赖数据的推广：混合条件下的集中不等式**。Doukhan-Massart-Rio (1995) 将不变原理推广到绝对正则（β-混合）序列；Kontorovich-Weiss (2014) 用马尔可夫收缩技术证明了马尔可夫链的 DKW 型不等式，其界依赖于链的谱隙或几何遍历性常数。Pauling (2015) 通过 Marton 耦合和谱方法给出了马尔可夫链的 McDiarmid 型不等式，常数正比于混合时间。这些工作的共同特点是：**误差界中的常数依赖于链的收敛速率（谱隙、混合系数等），而这些量在实践中往往未知或难以估计**。

- **再生方法：将依赖数据转化为"近似 iid"**。Mykland-Tierney-Yu (1995) 提出了再生 MCMC 方法，通过在再生时刻切分样本路径为 iid 的"tour"，将依赖数据问题转化为独立同分布问题。Wintenberger (2017) 对几何遍历马尔可夫链证明了指数不等式，并应用于再生 Metropolis 算法的定量误差界——这是本文最直接的先驱：它已经意识到再生结构可以用于构造误差界，但其界仍然依赖先验的漂移函数和 Lyapunov 函数。

- **经验 Bernstein 不等式：数据依赖的方差项**。Maurer-Pontil (2009) 证明了经验 Bernstein 界，用样本方差替代先验方差上界，使得界在数据实际方差小时自动变紧。Martinez-Taboada-Ramdas (2025) 进一步将其推广到方差估计本身，并去除了独立性假设。这条线索的核心思想是：**用数据本身的信息（样本方差、样本最大值）替代先验知识，使界自适应于数据的实际表现**。

- **当前 frontier 与本文位置**。当前的前沿问题是：能否构造一个 DKW 型不等式，其**主项完全由样本路径计算**，而先验的收敛速率信息只进入低阶项？本文（Jerison 2026）声称首次将"数据依赖"与"马尔可夫链 DKW"结合：主项由样本路径直接计算，先验的 (B, γ) 只影响低阶项。作者在引言中明确说："The recent work [10] provides a substantial quantitative improvement on the techniques of [12]"（指 Martinez-Taboada-Ramdas 对 Maurer-Pontil 的改进），而本文的定位是"the first to combine both of these in a data-dependent DKW inequality"——即首次将经验 Bernstein 的数据依赖思想与马尔可夫链 DKW 结合。

#### 子线索聚类

1. **经典经验过程理论**（DKW, Massart, Reeve）：iid 情形下的最优 sup-norm 界，提供基准速率和常数。
2. **依赖数据的集中不等式**（Doukhan-Massart-Rio, Kontorovich-Weiss, Paulin）：将混合/遍历条件转化为集中界，但常数依赖先验混合速率。
3. **再生方法**（Mykland-Tierney-Yu, Wintenberger）：利用再生结构将依赖数据分解为 iid tours，是本文的直接技术基础。
4. **经验 Bernstein 不等式**（Maurer-Pontil, Martinez-Taboada-Ramdas）：用样本方差替代先验方差，实现数据依赖的自适应界。

#### 这个方向在追问的核心问题

1. **能否去掉对混合速率的先验依赖？** 所有已有马尔可夫链 DKW 型不等式的常数都包含谱隙或混合系数的倒数，而这些量在实践中几乎不可能精确知道。数据依赖的界是绕过这一瓶颈的途径。
2. **最优速率是什么？** 对 iid 数据，sup-norm 误差的最优速率是 √(log(1/δ)/n)。对马尔可夫链，是否仍能保持这个速率？本文声称"nearly optimal"，但 log 因子是否可去？
3. **再生结构是否是必要的？** 是否所有几何遍历链都有再生结构？再生时刻的识别在计算上是否可行？

#### ⚠️ 作者的 framing（这是作者的说法）

作者把缺口 frame 成：已有马尔可夫链 DKW 不等式（Kontorovich-Weiss, Paulin 等）的常数依赖先验混合速率，而实际中这些速率往往比理论保证好得多；本文通过再生结构构造数据依赖的界，使主项由样本路径决定，从而对"实际收敛快于理论保证"的链自动变紧。作者在 1.5 节承认的局限是：**结果仅适用于再生链**，且"fundamental limitation of the techniques in this paper is that they apply only to regenerative chains"。作者淡化的竞争路线是：基于谱隙的集中不等式（Paulin 2015）虽然常数保守，但适用于更广的链类；本文没有讨论能否将数据依赖思想推广到非再生链。

#### 张力

未见明显对立引用。但有一个值得注意的张力：Kontorovich-Weiss (2014) 的 DKW 型不等式对**所有**几何遍历链成立（不要求再生结构），而本文的结果限于再生链。作者用"数据依赖"换取了"适用范围"——这是一个真实的 trade-off，但作者没有直接讨论。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

**模型**：设 (X_t)_{t≥0} 是状态空间 X 上的离散时间马尔可夫链，具有平稳分布 π。我们关注一个可观测泛函 θ: X → R（例如 θ(x) = x 的某个分量，或某个矩条件）。目标是估计 θ 在 π 下的 CDF：

- **F(x) = π(θ ≤ x)** —— 这是**目标量（estimand）**，是我们要估计的未知函数。

**可观测数据**：一条长度为 n 的样本路径 (X_0, ..., X_{n-1})。由此构造经验 CDF：

- **F̂_n(x) = (1/n) Σ_{t=0}^{n-1} 1{θ(X_t) ≤ x}** —— 这是**估计量**，完全由样本路径计算。

**关键结构（再生）**：存在概率测度 ν 和随机时间 T_1 < T_2 < ...（称为再生时刻），使得：
- 每个 tour (X_t)_{T_{k-1} ≤ t < T_k} 是 iid 的；
- 每个 tour 的长度 W_k = T_k - T_{k-1} 是 iid 的；
- 每个 tour 的起点 X_{T_{k-1}} ~ ν。

**核心参数**：
- **K**：观测到的再生次数（固定 K，n = T_K 是随机的）；
- **W_k**：第 k 个 tour 的长度（iid，有指数尾）；
- **M = max(W_1, ..., W_K)**：最长 tour 的长度（数据依赖）；
- **B, γ**：先验常数，满足 P(T > t) ≤ B e^{-γt}（**先验信息**，唯一非数据依赖的部分）；
- **m_j = #{k : W_k > j}**：长度超过 j 的 tour 数（数据依赖）；
- **π_j(·) = P(X_j ∈ · | T > j)**：给定 tour 长度至少为 j 的条件下，第 j 步的条件分布。

**可观测 vs 不可观测**：研究者能观测到样本路径 (X_t) 和再生时刻 T_k（假设可识别）；**不能**直接观测到 π_j、q_j = P(T>j)/E(T) 和 F(x)。B 和 γ 是**先验输入**，不是从数据估计的。

#### 第二步：最小内核

**剥掉所有一般性设定后，本文的核心数学问题是**：

> 给定 K 个 iid 的 tour（每个 tour 是长度随机的一段马尔可夫链轨迹），如何用这些 tour 的拼接来同时估计 (i) 每个"位置 j"的条件分布 π_j 的 CDF，以及 (ii) tour 长度的分布 q_j，使得对**所有 x ∈ R 同时成立**的 sup-norm 误差有显式的高概率界？

**最简特例**：假设每个 tour 的长度都是确定的 L（即 W_k ≡ L，无随机性），且 K 个 tour 是 iid 的。此时：

- n = K·L；
- 对每个 j = 0, ..., L-1，我们有 K 个 iid 样本 X_{T_k + j}（每个 tour 的第 j 个位置），它们服从 π_j；
- 经验 CDF 分解为 F̂_n(x) = (1/L) Σ_{j=0}^{L-1} (m_j/n) F̂_j(x)，其中 m_j = K（因为所有 tour 长度都 > j）。

**在这个特例下，要证的命题退化成什么？**

对每个固定的 j，经典 DKW 不等式给出：
P(sup_x |F̂_j(x) - π_j(x)| > ε) ≤ 2exp(-2Kε²)。

但我们需要**同时对 L 个 j 成立**。用 union bound：
P(∃j : sup_x |F̂_j(x) - π_j(x)| > ε_j) ≤ Σ_j 2exp(-2Kε_j²)。

选择 ε_j = √(log(L/δ)/(2K))，得到每个 j 的误差为 O(√(log(L/δ)/K))。但注意权重 m_j/n = 1/L，所以总误差是：
sup_x |F̂_n(x) - F(x)| ≤ (1/L) Σ_j sup_x |F̂_j(x) - π_j(x)| + |Σ_j (1/L) π_j(x) - q_j π_j(x)|。

第一项 ≤ max_j sup_x |F̂_j(x) - π_j(x)| = O(√(log(L/δ)/K)) = O(√(L log(L/δ)/n))。

**这就是本文的核心困难**：当 L 随 n 增长时（实际中 tour 长度是随机的，L ~ log n），误差项变成 √(L/n) = √(log n / n)，比 iid 情形的 1/√n 多了一个 √(log n) 因子。**本文的贡献在于证明这个 log 因子是必要的（由最长 tour 决定），并且主项中的常数完全由数据（M 和 m_j）决定，而非先验的 B, γ。**

**为什么这个特例抓住了本质？** 因为：
1. 它展示了"多个位置 j 同时估计"带来的 union bound 代价——这是与 iid 情形的本质区别；
2. 它揭示了权重 m_j/n 与 q_j 的偏差——这是 tour 长度随机性带来的额外误差项；
3. 它说明了为什么需要数据依赖：如果先验的 B, γ 很保守（实际链收敛快得多），那么 M 会远小于 (1/γ)log(BK)，此时数据依赖的界会自动变紧。

**一般情形的"加壳"**：随机 tour 长度（用 1-Wasserstein 距离控制经验 tour 长度分布与真实分布的偏差）、指数尾假设（P(T>t) ≤ B e^{-γt}）、以及用 Markov 不等式替代指数集中（导致 δ 依赖从 log(1/δ) 变为 1/√δ）。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：对具有再生结构的马尔可夫链，构造平稳分布泛函 θ 的 CDF 的**数据依赖**均匀置信带，使主项完全由样本路径计算，先验收敛速率只影响低阶项。
2. **核心工具/方法**：将样本路径按再生时刻切分为 iid tours，对每个"位置 j"分别应用经典 DKW 不等式，再用 union bound 组合；tour 长度分布的偏差用 1-Wasserstein 距离控制，最终用 Markov 不等式得到高概率界。
3. **主要结论**：得到了一个显式的、接近最优的 DKW 型不等式（定理 2.1），其主项为 O(M√(log(M/δ)/n))（数据依赖），低阶项为 O((log(BK)/γ)·√(log(1/δ)/n))（先验依赖），并通过反演得到分位数的置信带。

#### 关键设定与假设

- **再生结构**：存在 ν-再生时刻序列，使得 tours 是 iid 的。这是本文最核心的假设，也是其局限——并非所有马尔可夫链都有易于识别的再生结构。
- **指数尾假设 (1.3)**：P(T > t) ≤ B e^{-γt}。这是先验输入，但**只影响低阶项**。相比 Kontorovich-Weiss (2014) 和 Paulin (2015) 的谱隙假设，本文的假设更弱（不需要可逆性、不需要谱隙），但需要再生结构。
- **无有界性假设**：θ 可以是无界函数（只要 CDF 定义良好），这与经典 DKW 的 [0,1] 支撑假设不同，但代价是常数中可能出现 θ 的矩条件。
- **固定 K，随机 n**：本文固定再生次数 K，让总样本量 n = T_K 随机。这与固定 n 的设定略有不同，但通过 E(T) 可以转换。

#### 主要结果（定理 2.1 的拆解）

定理 2.1 的界有三项：

**第一项（主项，数据依赖）**：
```
(1/√(2n)) · Σ_{j=0}^{M-1} √((m_j/n) · log(6n/(δ·m_j)))
```
这一项完全由样本路径计算：m_j 是长度超过 j 的 tour 数，M 是最大 tour 长度。它对应"每个位置 j 的 DKW 误差"的加权和。直觉：m_j 越大（越多 tour 到达位置 j），该位置的估计越准。

**第二项（tour 长度分布偏差）**：
```
(√K/n) · (M/√(δ/3))
```
这一项控制经验 tour 长度分布与真实分布的 1-Wasserstein 距离。它来自 Markov 不等式，因此 δ 依赖是 1/√δ 而非 log(1/δ)——这是本文的一个弱点（作者在 1.5 节承认）。

**第三项（低阶项，先验依赖）**：
```
(2/(n·√(δ/3))) · (log(BK)/γ) · (√log(3/δ) + 1/(1-e^{-γ/2}))
```
这一项是唯一依赖先验 (B, γ) 的部分，且阶为 1/n（比主项的 1/√n 低阶）。它控制"超长 tour"（长度 > (1/γ)log(BK)）的贡献。

**为什么这是"nearly optimal"**：主项的阶为 M√(log(M/δ)/n)。由于 M ~ (1/γ)log(BK)（指数尾假设下最长 tour 的对数阶），主项为 √(log(n)·log(log n)/n)，与 iid 情形的 √(log(1/δ)/n) 只差一个 √(log n) 因子。作者在 1.4 节论证了这个 log 因子是必要的（双峰分布例子）。

#### 证明路线与技术技巧

**整体路线（3-5 步）**：

1. **分解**：将总误差分解为"每个位置 j 的条件分布估计误差"和"tour 长度分布估计误差"两部分（引理 2.3）。前者用三角不等式，后者用 1-Wasserstein 距离的定义。

2. **逐位置 DKW**：对每个固定的 j，利用 tours 的 iid 性，X_{T_k+j}（k=1,...,m_j）是 iid 样本来自 π_j。对这批样本应用经典 DKW 不等式（Massart 形式），得到 sup_x |F̂_j(x) - π_j(x)| ≤ ε_j 以概率 1 - 2exp(-2m_j ε_j²)。

3. **Union bound over j**：对 j = 0, ..., M-1 取 union bound。关键技巧是**自适应选择 ε_j**：ε_j² = (1/(2m_j))·log(6n/(δ·m_j))。这使得每个位置的误差与其样本量 m_j 匹配——m_j 大的位置用更紧的界，m_j 小的位置用更松的界。这是"数据依赖"的核心体现。

4. **控制 tour 长度分布**：用 1-Wasserstein 距离的积分表示 W_1(p̂, p) = Σ_j |P̂_j - P_j|，将问题转化为控制经验生存函数的偏差。这里用 Markov 不等式而非指数集中（因为 tour 长度可能无界），导致 1/√δ 依赖。

5. **合并**：将两项误差合并，用权重 m_j/n 和 q_j 的关系（引理 2.5）处理权重偏差，最终得到定理 2.1。

**关键技巧点名**：

- **自适应 ε_j 选择**：这是本文的核心创新。不同于固定 ε 的 union bound（会导致 M·exp(-2Kε²) 的代价），自适应选择使得总代价为 Σ_j δ·m_j/(3n) = δ/3。这是"数据依赖"的数学实现。
- **1-Wasserstein 距离的生存函数表示**：W_1(p̂,p) = Σ_j |P̂_j - P_j|，将无穷维问题转化为可数求和。
- **Markov 不等式替代指数集中**：因为 tour 长度无界，无法用 Bernstein 型不等式；Markov 不等式虽然给出更差的 δ 依赖，但保持了显式常数。
- **Jensen 不等式（引理 2.2）**：将 Σ_j √(m_j log(1/m_j)) 上界为 √(M log M)，这是得到最终简洁形式的关键。

#### 真实例子与应用

本文**没有真实数据例子**，也没有模拟实验。作者在 1.4 节用一个**理论例子**（双峰分布）论证 log 因子的必要性：构造一个链，其 tour 长度以概率 1/2 为 1、以概率 1/2 为 L，则任何数据无关的界都必须包含 √(log n) 因子，而数据依赖的界可以自动适应。这是一个"最坏情况"论证，说明本文的界在某种意义下不可改进。

#### 🔎 结论是否比证明窄

**是，有一处明显的"证明比结论窄"**：

- 定理 2.1 的陈述是**固定 K**（再生次数），但实际应用中研究者通常固定总样本量 n。作者在 2.1 节提到"n/K 趋近 E(T)"，但没有给出**固定 n、随机 K** 的版本。这是一个真实的 gap：固定 K 的设定在实践中有多少适用性？如果再生很稀疏，K 可能远小于 n 的数量级。

- 另一个"窄"的地方：**δ 依赖**。主项的 log(6n/(δ·m_j)) 是好的，但第二、三项的 1/√δ 来自 Markov 不等式。作者在 1.5 节承认"the dependence on δ is not optimal, due to a step in the proof that uses Markov's inequality"。这意味着对于小的 δ（如 δ = 0.01），界会显著变宽。这是否可以通过更精细的集中不等式改进？作者没有回答。

- 还有一个隐含的窄化：**θ 的 CDF 的 sup-norm**。作者只处理了"θ ≤ x"这种单侧事件。对于双侧事件（如 |θ - μ| ≤ ε）或更一般的函数类，界的形式可能需要修改。

### 四、开放问题

1. **固定 n 的版本**：定理 2.1 固定 K、随机 n。能否得到固定 n、随机 K 的版本？这需要控制 K 的随机性，可能需要关于再生频率的额外假设。扎根于定理 2.1 的陈述方式（"Fix an integer K ≥ 1, and let n = T_K"）。

2. **改进 δ 依赖**：作者明确承认 Markov 不等式导致 1/√δ 依赖（1.5 节："The dependence on δ of (1.2) and (1.3) is not optimal"）。能否用指数集中不等式（如 Bernstein 型）替代 Markov 不等式，得到 log(1/δ) 依赖？这可能需要 tour 长度的矩生成函数假设。

3. **非再生链的推广**：作者承认"fundamental limitation...they apply only to regenerative chains"（1.5 节）。能否将数据依赖的思想推广到一般几何遍历链？可能的路径是：用谱隙的**数据驱动估计**替代先验输入，但这需要估计谱隙的置信下界——这本身就是一个难题。

4. **函数类的推广**：本文只处理了 CDF（即指示函数类 {1{θ ≤ x} : x ∈ R}）。能否推广到更一般的函数类（如 Lipschitz 函数、Donsker 类）？这需要 empirical process 理论，但数据依赖的界在一般函数类上是否仍然可行？

5. **与 Wasserstein 距离的联系**：本文的证明核心是控制 1-Wasserstein 距离 W_1(p̂,p)。Bobkov-Ledoux (2019) 和 Fournier-Guillin (2015) 对 iid 数据的 Wasserstein 距离有精细的界。能否将这些结果推广到再生链的 tour 长度分布？这可能给出更紧的界。

**关于验证 gap 的建议**：要确认上述某条是否是真 gap，建议去读近 5 年关于"Markov chain concentration inequalities"的文献（如 Douc, Moulines, Priouret 等人的工作），看是否有固定 n 版本或非再生链版本的结果。如果多篇近期论文都指向同一个未解决问题，那就是共识性 gap；如果各论文的假设条件互相冲突，那可能是更深层的张力。
