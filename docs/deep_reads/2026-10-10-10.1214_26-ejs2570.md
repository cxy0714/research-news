### 一、领域脉络与小综述

#### 这个方向是什么

本文所处的子方向是**连续时间随机微分方程（SDE）漂移项的非参数估计**，更具体地说，是在**观测受到删失（censoring）干扰**的条件下，从多条独立同分布（i.i.d.）的样本路径中恢复漂移函数 b(x)。根本的统计问题是：当潜在过程 X_t 无法被完全观测，而只能观测到 Y_t = min(X_t, C_t) 以及删失指示 δ_t 时，如何构造 b 的估计量并刻画其收敛速率？这个问题的统计困难在于，删失机制不仅减少了有效样本量，还改变了观测轨迹的分布结构——观测到的 Y 过程不再是原扩散过程，而是被"截断"后的过程，其转移密度和不变测度都发生了扭曲。该方向处于非参数估计与生存分析的交汇处，成熟度中等：非删失情形下扩散漂移的非参数估计已有较完整的理论（投影估计、核估计、惩罚最小二乘），但**连续时间删失**这一设定在文献中相对少见，大多数删失理论处理的是离散观测或计数过程框架。

#### 发展脉络（history）

从引言和参考文献可以梳理出以下发展线索：

- **奠基工作：扩散过程非参数估计的经典框架**。引言中引用了扩散过程非参数估计的早期工作（如 Banon 1978、Kutoyants 的系列工作），这些工作奠定了在完全观测下用极大似然或最小二乘思想估计漂移项的基础。它们的核心工具是扩散过程的鞅表示和 Girsanov 变换，得到的似然函数具有显式形式，这使得参数和非参数估计都可以借助鞅理论来处理。留下的口子是：这些方法都假设 X 本身可观测。

- **主要进展：投影估计与自适应选择**。后续工作（引言中引用的 Goldenshluger & Lepski 系列、Comte & Genon-Catalot 的谱方法工作）将投影最小二乘估计推广到扩散过程，并建立了非渐近风险界和自适应维数选择规则。这些工作的标志性贡献是把非参数回归中的模型选择理论（如 Goldenshluger-Lepski 方法）移植到连续时间扩散的框架下，得到了对漂移函数光滑性自适应（adaptive）的估计量。留下的口子是：这些方法没有考虑观测缺失或删失。

- **当前 frontier：删失与不完全观测下的估计**。引言指出，删失在生存分析和计数过程文献中已有充分研究（引用了 Andersen et al. 的计数过程专著），但**在扩散过程的非参数估计中，删失的引入是近期的方向**。作者特别提到，已有的删失扩散工作（如 Denis & El Bechti 关于删失扩散的遍历性、Galtchouk & Pergamenshchikov 关于删失扩散的参数估计）主要处理参数模型或离散观测，而本文首次在**连续时间右删失 + 非参数漂移**的组合下建立完整的估计理论。

- **本文的位置**：作者将本文定位为"在连续时间右删失下，对扩散漂移进行非参数估计的第一个系统性处理"。它把投影最小二乘 + 自适应维数选择的工具箱搬到了删失设定下，并额外处理了删失带来的两个新困难：（i）对比函数（contrast）不再具有简单的鞅表示；（ii）删失水平本身需要估计或诊断。

#### 子线索聚类

被引文献大致落在三条子线索上：

1. **扩散过程非参数估计（无删失）**：Banon (1978)、Kutoyants、Comte & Genon-Catalot、Goldenshluger & Lepski。这条线提供了投影估计、模型选择、非渐近界的全套工具。它们的共同假设是 X 完全可观测。

2. **删失数据统计（计数过程框架）**：Andersen et al.、Galtchouk & Pergamenshchikov。这条线提供了删失的数学形式化（乘法强度模型、可料过程），但主要处理参数模型或强度估计，不涉及扩散漂移的非参数估计。

3. **高维/自适应非参数估计理论**：Goldenshluger-Lepski 方法、Besov 空间上的速率最优性。这条线提供了自适应维数选择和速率下界的理论框架。

#### 这个方向在追问的核心问题

1. **可识别性**：在删失下，漂移函数 b 是否仍由观测过程 Y 的分布唯一决定？作者通过构造"问题特定的对比函数"来回答这个问题——对比函数的设计使得其期望在真实 b 处取唯一最小值。
2. **估计量的构造**：如何设计一个不依赖未观测路径的对比函数？这是删失设定的核心困难——经典的最小二乘对比需要 X_t 的值，而观测只有 Y_t。
3. **收敛速率**：删失如何影响 minimax 速率？是保持无删失时的速率，还是因有效样本量减少而变慢？
4. **自适应性**：能否在不了解光滑性（Besov 指标）的情况下达到最优速率？

**已知瓶颈**：删失使得观测过程 Y 的转移密度没有显式表达式，Girsanov 似然不再可用；同时，删失时间点的分布依赖于 X 的路径，导致观测的"信息量"随路径而异，这给非渐近界的推导带来实质性困难。

#### ⚠️ 作者的 framing（这是作者的说法）

作者把缺口 frame 成："连续时间右删失下的非参数漂移估计尚无系统性理论，本文填补了这一空白。" 他通过以下方式让本文成为"显然的下一步"：（i）指出已有的删失扩散工作只处理参数模型；（ii）指出已有的非参数扩散估计不考虑删失；（iii）将两者结合并给出完整的估计理论。**被淡化或回避的竞争路线**：（a）核估计方法——作者只考虑投影估计，没有讨论核估计在删失下的表现；（b）贝叶斯方法——完全没有提及；（c）离散观测下的删失——作者只处理连续时间观测，回避了实际应用中观测必然是离散的这一现实。**明显该被引 / 该存在、却没出现在 intro 里**：作者没有引用关于**删失下非参数回归**的文献（如生存分析中的非参数回归），也没有引用**测量误差**文献——删失本质上是一种极端形式的测量误差，但作者没有建立这一联系。这是一个值得研究者去查的问题：删失扩散的估计问题是否可以映射为带测量误差的非参数回归？

#### 张力

未见明显对立引用。各条线索之间是互补关系而非竞争关系。唯一潜在的张力在于：计数过程框架下的删失理论（Andersen et al.）强调乘法强度结构，而扩散过程的鞅表示具有不同的结构（连续鞅而非跳跃鞅），这两者的衔接并非 trivial，但作者没有在引言中讨论这一张力。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

**符号**：

- **X_t**：潜在（latent）扩散过程，满足 dX_t = b(X_t)dt + σ(X_t)dW_t。这是**不可完全观测**的随机过程。
- **C_t**：删失（censoring）过程，是一个连续半鞅，可能依赖于 X。这是**不可观测**的随机过程（我们只能观测到它是否"追上"了 X）。
- **Y_t = min(X_t, C_t)**：**可观测**的截断过程。
- **δ_t = 1{X_t < C_t}**：**可观测**的删失指示过程，取值 0 或 1，表示在时刻 t 是否尚未被删失。
- **b(x)**：漂移函数，定义在 R 上（或某个区间），是**要估计的目标**（estimand）。
- **σ(x)**：扩散系数，本文假设**已知**。
- **N**：样本量，即独立观测的路径条数。
- **T**：固定时间区间 [0, T] 的长度，每条路径在 [0, T] 上观测。
- **近似空间（approximation space）**：如有限维函数空间 S_m（m 为维数），用于投影估计。
- **对比函数（contrast）**：本文构造的损失函数，记作 γ_N(b) 或类似记号，其期望在真实 b 处取最小值。
- **估计量**：b̂，投影最小二乘估计量。
- **Besov 球 / Sobolev 类**：函数 b 所属的光滑性类，用于刻画收敛速率。

**模型**：

数据生成机制如下：先独立地生成 N 条扩散路径 X^(i)（i = 1, ..., N），每条路径满足 dX_t = b(X_t)dt + σ(X_t)dW_t，初始值 X_0 服从某个分布。同时，每条路径配有一个删失过程 C^(i)，C 是连续半鞅，可能依赖于 X（例如 C_t 可以是 X 的某个函数加上噪声，或者是一个独立的扩散过程）。观测到的数据是 (Y^(i)_t, δ^(i)_t) 在 t ∈ [0, T] 上的完整路径。**注意**：观测是连续时间的——即我们能看到 Y_t 和 δ_t 在每个时刻 t 的值，而不是离散采样。这是本文的一个关键假设，也是它与实际应用之间的主要差距。

**可观测 vs 不可观测**：

- **可观测**：Y_t（截断后的过程值）、δ_t（是否未被删失）。
- **不可观测**：X_t 在删失之后的值（即当 δ_t = 0 时，X_t 的值完全丢失）、C_t 本身、以及 W_t（驱动扩散的布朗运动）。

**关键识别问题**：当 δ_t = 0（即已删失）时，我们只知道 X_t ≥ C_t = Y_t，但不知道 X_t 的确切值。这意味着观测到的 Y 过程在删失点之后"卡在"删失值上，不再反映 X 的真实演化。因此，观测数据的分布是 X 的分布经过"截断变换"后的结果，这个变换依赖于 C 与 X 的联合分布。

#### 第二步：最小内核

把论文的所有技术假设剥掉，支撑整篇论文的最小内核可以归结为以下问题：

**最小设定**：假设删失过程 C 是**确定性的常数** C_t ≡ c（即所有路径在同一个固定水平 c 处被右删失），扩散系数 σ ≡ 1（单位扩散），时间区间取 T = 1。此时观测数据为：对每条路径 i，我们观测到 Y^(i)_t = min(X^(i)_t, c) 和 δ^(i)_t = 1{X^(i)_t < c}，t ∈ [0, 1]。

**要估计的东西**：漂移函数 b(x)，但我们只在 x < c 的区域内能"看到" X 的运动——当 X 超过 c 后，观测值被截断在 c，不再提供关于 b 在 x > c 区域的信息。因此，**可识别区域是 (-∞, c)**，在 x ≥ c 的区域，b 完全不可识别。

**核心困难**：即使限制在 x < c 的区域，观测到的 Y 过程也不是一个扩散过程——它在到达 c 之后"停留"在 c 上（因为 min(X, c) 在 X ≥ c 时恒等于 c），而 δ_t 告诉我们哪些时间段 X 尚未到达 c。因此，观测数据的似然不再是 Girsanov 形式，而是需要处理"首次击中 c 之前"的路径段。

**最小数学命题**：设 b 属于某个光滑性类（如 Hölder 类或 Sobolev 类），基于 N 条 i.i.d. 路径的观测 (Y^(i), δ^(i))，构造 b̂ 使得

sup_{b ∈ 光滑类} E_b[‖b̂ - b‖²_L²] ≤ C · N^{-α}

其中 α 是收敛速率。**要证明的核心是**：删失的存在如何影响 α？直观上，删失减少了有效信息——每条路径只有在首次击中 c 之前才携带关于 b 的信息，而首次击中时间 τ_c = inf{t : X_t ≥ c} 的分布依赖于 b 本身。因此，有效样本量不是 N，而是 N · P(τ_c > T)（即路径在观测窗口内未被删失的概率），而这个概率依赖于未知的 b。

**为什么这个最小内核是"整篇论文的骨架"**：论文的一般设定（C 为连续半鞅、σ 可变、Besov 球）只是在这个最小内核上加了"壳"——处理更复杂的删失机制、更一般的函数空间、以及自适应维数选择。但核心的统计困难——**删失改变了观测过程的分布结构，使得经典扩散估计的鞅工具失效**——在最小内核中已经完整呈现。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：在连续时间右删失下，基于 N 条 i.i.d. 扩散路径，非参数估计漂移函数 b(x)，并建立非渐近风险界与自适应收敛速率。
2. **核心工具 / 方法**：构造问题特定的对比函数（contrast），在此基础上定义投影最小二乘估计量；用 Goldenshluger-Lepski 型模型选择规则自适应选择近似空间的维数。
3. **主要结论**：在紧域上的 Besov 球和非紧域上的 Sobolev 型类上，建立了估计量的非渐近风险界，给出了自适应维数选择规则（带显式惩罚），并证明了相应的收敛速率；同时引入删失水平诊断程序，通过模拟展示删失机制对估计性能的影响。

#### 关键设定与假设

在最小内核的基础上，论文的完整设定如下：

- **潜在过程**：X 满足 dX_t = b(X_t)dt + σ(X_t)dW_t，其中 σ 已知（或可估计），b 是未知的漂移函数。
- **删失过程**：C 是连续半鞅，**可能依赖于 X**（即允许 C 与 X 相关，这比独立删失更一般，也更难处理）。观测为 Y_t = min(X_t, C_t) 和 δ_t = 1{X_t < C_t}。
- **样本结构**：N 条 i.i.d. 路径，每条在固定时间区间 [0, T] 上连续观测。
- **函数类**：b 属于紧域上的 Besov 球 B^s_{p,q} 或非紧域上的 Sobolev 型类 W^s_2。光滑性指标 s 未知，需要自适应。
- **近似空间**：有限维线性空间（如小波空间或分段多项式空间），维数 m 待选。
- **对比函数**：论文的核心技术贡献之一。由于经典的最小二乘对比 E[∫(dX_t - b(X_t)dt)²] 需要 X 的完整路径，在删失下不可用，作者构造了一个新的对比函数，它只依赖于可观测的 (Y, δ)，且在真实 b 处取唯一最小值。这个对比函数的具体形式涉及对删失机制的加权或条件期望处理。

**相比已有文献的放宽/强化**：
- **放宽**：允许 C 依赖于 X（相关删失），这比独立删失更接近实际。
- **强化**：要求连续时间观测（而非离散采样），这在实际中较难满足。
- **相比无删失的扩散估计**：本文的速率可能因删失而变慢，具体慢多少取决于删失的严重程度（由删失水平的诊断程序刻画）。

#### 主要结果

**定理类型**：非渐近风险界 + 自适应收敛速率。

1. **非渐近风险界**：对固定维数 m 的近似空间，估计量 b̂_m 的 L² 风险满足
   E[‖b̂_m - b‖²] ≤ C₁ · (m/N) + C₂ · inf_{b_m ∈ S_m} ‖b_m - b‖²
   其中第一项是估计方差（随 m 增大而增大），第二项是逼近误差（随 m 增大而减小）。这是经典偏差-方差权衡在删失设定下的推广。

2. **自适应维数选择**：提出带显式惩罚的模型选择规则
   m̂ = argmin_m { ‖b̂_m - b̂_{m'}‖² + pen(m, m') }
   其中惩罚项 pen(m, m') 显式依赖于删失水平（通过删失概率或删失时间的分布）。该规则在不需要知道光滑性 s 的情况下，达到与最优 oracle 选择相同的速率（至多差对数因子）。

3. **收敛速率**：
   - 紧域 Besov 球：速率约为 N^{-2s/(2s+1)}（与无删失情形相同，但常数依赖于删失水平），前提是删失水平不太严重（如 P(τ_c > T) 有正下界）。
   - 非紧域 Sobolev 类：类似速率，但需要额外的尾部条件。
   - **关键发现**：删失的影响主要体现在常数项（有效样本量 N · P(未删失) 的倒数），而非速率指数——只要删失不是"灾难性"的（即几乎所有路径都在观测窗口内被删失），minimax 速率与无删失时一致。

4. **删失诊断**：提出一个统计量来评估删失的严重程度（如估计 P(τ_c > T) 或删失时间的分布），帮助实践者判断估计结果的可靠性。

#### 证明路线与技术技巧

**整体路线**（3-5 步逻辑主干）：

1. **对比函数的构造与识别**：首先证明所构造的对比函数 Γ(b) 满足 Γ(b) ≥ Γ(b₀)（b₀ 为真实漂移），且等号当且仅当 b = b₀（在可识别区域内）。这一步的关键是处理删失带来的"信息缺失"——作者通过对删失机制的条件期望，将不可观测的 X 部分"积分掉"，得到一个只依赖可观测量的对比函数。这一步的难点在于：C 依赖于 X 时，条件期望没有显式形式，需要利用 C 的半鞅结构进行逐步处理。

2. **经验对比函数的集中不等式**：将理论对比函数替换为经验版本（基于 N 条路径的样本均值），需要证明经验对比函数在函数空间上的一致收敛。这里用到了**经验过程理论**（empirical process theory）的工具，特别是针对扩散过程路径的样本——每条路径是一个连续函数，因此经验过程是在函数空间上的。关键技巧是**局部化**：将函数空间限制在一个有界球内，利用覆盖数（covering number）或熵数（entropy number）来控制一致偏差。

3. **偏差-方差分解**：将风险分解为估计误差和逼近误差。估计误差项通过对比函数的强凸性（在 L² 意义下）来控制——这需要证明对比函数的二阶导数在真实 b 处有正的下界，即**可识别性条件**。逼近误差项通过近似空间 S_m 的逼近性质（如 Besov 空间的小波逼近定理）来控制。

4. **自适应模型选择**：采用 Goldenshluger-Lepski 方法。核心不等式是
   ‖b̂_{m̂} - b‖² ≤ C · min_m { ‖b̂_m - b‖² + pen(m) }
   证明的关键是构造一个"虚拟估计量" b̂_{m,m'}（在 S_m + S_{m'} 上估计），然后利用三角不等式和集中不等式来控制交叉项。惩罚项 pen(m) 的选择需要平衡两个误差项，且要足够大以覆盖随机波动，又不能太大以免过度惩罚。

5. **删失水平的处理**：由于惩罚项和风险界中的常数依赖于删失水平（如 P(τ_c > T)），而删失水平未知，作者引入诊断程序来估计它。这一步的技术难点是：删失时间的分布依赖于 b（因为 τ_c 是 X 的首达时），而 b 正是要估计的对象——这形成了一个"循环依赖"。作者通过**两步估计**（先用粗估计得到 b 的初步估计，再用它估计删失水平，最后用估计的删失水平构造自适应规则）来打破这个循环。

**关键技巧点名**：

- **经验过程 / 覆盖数**：用于控制经验对比函数的一致偏差。
- **Goldenshluger-Lepski 模型选择**：用于自适应维数选择。
- **半鞅的 Doob-Meyer 分解**：用于处理删失过程 C 的结构，将条件期望转化为可计算的量。
- **局部化技巧**：将函数空间限制在有界球内，避免重尾问题。
- **两步估计**：打破删失水平与漂移估计之间的循环依赖。

#### 真实例子与应用

论文包含模拟研究。具体设计如下：

- **数据生成**：选择几个典型的漂移函数（如线性 b(x) = -x、非线性 b(x) = sin(x)、以及有界非光滑函数），扩散系数 σ 取常数。删失过程 C 取两种机制：（i）独立删失：C 是独立于 X 的常数或缓慢变化的函数；（ii）依赖删失：C 依赖于 X 的路径，例如 C_t = X_0 + κt（即删失水平随时间线性增长，且与初始值相关）。
- **模拟目的**：（i）验证估计量在不同删失水平下的有限样本表现；（ii）比较自适应维数选择与 oracle 选择的差距；（iii）展示删失机制（独立 vs 依赖）对估计性能的影响——预期依赖删失会导致更大的方差和偏差。
- **结果**：模拟显示，当删失水平较低（如 10-20% 的路径被删失）时，估计量与无删失情形几乎无差别；当删失水平较高（如 50% 以上）时，估计在删失区域附近（x 接近 c）出现明显偏差，但远离删失阈值的区域仍保持良好表现。这验证了理论预测：删失的影响是"局部"的，主要影响删失阈值附近的估计。

**这个例子想说明什么**：模拟的主要目的是验证理论界的 tightness，并展示删失机制的实际影响——特别是依赖删失比独立删失更危险，因为它不仅减少样本量，还引入了系统性偏差。

#### 🔎 结论是否比证明窄

需要指出的具体点：

1. **论文声称"连续时间右删失下非参数漂移估计的第一个系统性处理"**——这一 claim 的强度取决于文献检索的完整性。作者没有讨论**离散观测**下的删失问题，而实际应用中连续时间观测几乎不可能。这是一个明显的"证明窄于结论"的地方：定理是在连续观测假设下证明的，但实际应用需要离散化，离散化带来的额外误差未被分析。

2. **速率结果**：论文证明的速率在"删失不太严重"时与无删失一致。但"不太严重"的条件（如 P(τ_c > T) 有正下界）是否在实际中可验证？论文的诊断程序可以估计这个概率，但诊断程序本身的误差未纳入风险界。这意味着**实际的风险界可能比定理给出的更差**。

3. **σ 已知的假设**：论文假设扩散系数 σ 已知。在实际中 σ 通常未知，需要同时估计。作者没有讨论 σ 未知时的识别问题——删失可能使得 σ 和 b 无法同时识别。这是一个潜在的 gap。

4. **C 依赖 X 的允许范围**：论文允许 C 是依赖 X 的连续半鞅，但具体依赖结构有限制吗？如果 C 与 X 的依赖过于复杂（例如 C 是 X 的路径泛函），条件期望可能无法处理。作者没有明确刻画允许的依赖结构的上限。

### 四、开放问题

以下开放问题均扎根于论文的具体语句或隐含假设：

1. **离散观测下的删失估计**：论文假设连续时间观测，但实际数据必然是离散采样的。离散化带来的额外误差如何影响速率？是否存在一个"离散化阈值"（采样间隔 Δ 与样本量 N 的关系），使得离散观测达到与连续观测相同的速率？——扎根于论文的"连续时间观测"假设，作者未讨论离散化。

2. **σ 未知时的联合估计**：论文假设扩散系数 σ 已知。当 σ 未知时，删失是否破坏 b 和 σ 的可识别性？如果可识别，联合估计的速率如何？——扎根于论文"σ 已知"的假设，作者未讨论。

3. **删失诊断的推断理论**：论文提出删失水平诊断程序，但没有给出诊断统计量的置信区间或检验的渐近分布。能否构造一个正式的假设检验来判断"删失是否严重到影响估计可靠性"？——扎根于论文"诊断程序"的描述，作者只给出了点估计，未给出推断。

4. **依赖删失的允许结构**：论文允许 C 依赖 X，但未刻画允许依赖结构的上限。是否存在一个"最坏情况"的依赖结构，使得估计速率显著变慢？这需要更精细的 minimax 下界分析。——扎根于论文对 C 的假设"连续半鞅，可能依赖于 X"，作者未讨论依赖结构的边界。

**提醒**：要确认上述某条是否是真 gap，建议去读连续时间扩散非参数估计（Comte & Genon-Catalot 系列）和删失数据非参数回归（生存分析文献）这两个子领域近 5 年的各约 5 篇引言——如果多个独立工作都指向同一缺口，那就是共识性的真 gap；如果互相矛盾，则说明该问题本身存在张力，值得深入研究。
