### 一、领域脉络与小综述

#### 这个方向是什么

本文研究的核心问题是：在主题模型（topic models）这一高维离散混合模型框架下，如何对两个**混合测度**（mixing measures）之间的 **Wasserstein 距离**进行估计与统计推断。这里的"混合测度"指的是定义在主题（topics）集合上的概率分布，它编码了文档中主题的构成比例。该问题的根本统计动机在于：传统的分布间距离（如 Hellinger 距离、全变差距离）度量的是**混合分布**（mixture distributions，即观测到的词频分布）之间的差异，但无法捕捉"相似的混合分布可能源自完全不同的混合成分"这一现象（见文中 Figure 1 的 Pearson 螃蟹数据例子）。因此，直接对混合测度本身进行比较具有重要的科学意义，尤其在文本分析、单细胞生物学（如 cis-regulatory topic modelling, [15, 18]）等应用中，研究者关心的是潜在主题结构的变化，而非观测分布的细微差异。

该方向的成熟度处于**快速发展但尚未定型**的阶段。一方面，混合测度估计的**最优收敛速率**问题在近期已有突破性进展（如 [8] 中关于稀疏混合权重估计的 minimax 结果）；另一方面，关于混合测度间距离的**推断**（即构造置信区间、进行假设检验）则几乎空白——本文作者明确指出，据其所知，这是首次在主题模型框架下研究 Wasserstein 距离的推断问题（见 Section 2.4 开头）。因此，本文的定位是填补"估计"与"推断"之间的鸿沟。

#### 发展脉络

1. **奠基工作：混合测度作为主要研究对象**。Nguyen (2013) [49] 的开创性工作首次系统研究了混合测度估计的收敛性质，建立了混合测度间的 Wasserstein 距离与混合分布间的 Hellinger/全变差距离之间的比较不等式（在强可辨识条件下）。这一工作为后续研究奠定了概念基础：混合测度本身是值得估计和比较的统计量。

2. **主要进展：稀疏主题模型的估计理论**。Bing, Bunea 和 Wegkamp (2020) [9] 以及 Bing et al. (2022) [8] 建立了主题模型下混合成分矩阵 A 和混合权重向量 α 的 minimax 最优估计理论。特别是 [8] 在**一般框架**（A 未知、p 可随样本量增长、权重可稀疏）下，给出了 MLE 型估计器的 ℓ₁ 范数收敛速率，并证明了其稀疏自适应性质。这一结果构成了本文估计部分的理论基础。

3. **当前前沿：从估计到推断的跨越**。在混合测度估计问题基本解决后，自然的问题是：如何对混合测度间的距离进行推断？这一方向在**离散分布距离推断**的文献中有直接先驱：Sommerfeld 和 Munk (2018) [59] 研究了有限离散分布间 Wasserstein 距离的推断问题，证明了 plug-in 估计量的渐近分布由**方向导数**决定，并指出经典 bootstrap 失效。本文正是将这一推断框架从"直接观测的离散分布"推广到"需从主题模型中估计的混合测度"这一更复杂的情形。

4. **并行线索：Wasserstein 距离估计的 minimax 理论**。在更一般的概率测度估计问题中，[43, 50] 等近期工作建立了连续分布间 Wasserstein 距离估计的 minimax 下界。本文的 Theorem 3 借鉴了这些技术，但针对主题模型这一特定结构给出了更精细的刻画。

#### 子线索聚类

- **线索一：混合测度估计理论**（[8, 9, 49, 61] 等）。核心问题是：给定 n 个文档、每个文档 N 个词，如何以最优速率估计混合测度？关键工具包括锚词假设（Assumption 3）、ℓ₁ 范数误差界、稀疏性自适应。
- **线索二：Wasserstein 距离的推断**（[19-23, 57, 59] 等）。核心问题是：给定两个分布的估计，如何构造它们之间 Wasserstein 距离的置信区间？关键工具是方向 Hadamard 可微性、泛函 delta 方法、以及针对非光滑泛函的 bootstrap 修正。
- **线索三：非光滑泛函估计的 minimax 理论**（[36, 43, 50, 68] 等）。核心问题是：对于全变差距离、Wasserstein 距离这类非光滑泛函，估计的固有难度是什么？关键工具是模糊假设（fuzzy hypotheses）方法、Le Cam 不等式。

#### 核心问题与已知瓶颈

1. **非光滑性**：Wasserstein 距离作为混合测度的函数是**非光滑**的（方向 Hadamard 可微但非 Fréchet 可微），这导致经典 delta 方法和 bootstrap 失效。已知瓶颈在于如何刻画其渐近分布并构造可行的推断程序。
2. **稀疏性与边界效应**：当混合权重位于单纯形边界时（稀疏情形），估计量的渐近行为发生质变，标准正态近似失效。这要求发展**去偏**技术。
3. **高维性**：p（词典大小）可以远大于 n（文档数），这给混合成分矩阵 A 的估计带来本质困难，需要锚词等结构假设。

#### ⚠️ 作者的 framing

作者将本文的贡献框架为三个层次：第一，**公理化辩护**（Section 3）：证明混合测度间的 Wasserstein 距离是混合分布间"最具有判别性的凸距离"，从而为这一距离选择提供理论依据；第二，**估计最优性**（Section 4）：首次建立该距离估计的 minimax 下界，证明 plug-in 估计量在宽泛条件下达到最优速率；第三，**推断可行性**（Section 5）：构造去偏估计量并建立其渐近正态性，从而提供首个可用的置信区间程序。作者特别强调，其推断方法在**稀疏**混合测度下依然有效，这是对已有文献（如 [57] 仅处理固定维数情形）的实质性推进。

#### 张力

- **估计与推断的张力**：估计问题的最优速率（Theorem 2）允许 p 随 n 增长，但推断问题（Theorem 5）要求 K 固定。作者在 Remark 4 中承认了这一限制，并指出处理 K 增长的情形需要新的技术。
- **效率与稳健性的张力**：去偏 MLE 在经典框架下是渐近有效的，但其构造依赖于对 A 的精确估计；当 A 的估计误差不可忽略时（如 p 很大），去偏 MLE 可能不如加权最小二乘稳健。作者在 Remark 5 和 Appendix H 中对此进行了讨论。
- **未见明显对立引用**：作者引用的工作之间没有直接矛盾，但 [8] 与 [57] 在推断策略上存在分歧——前者强调去偏，后者强调 bootstrap 修正。本文选择了去偏路线。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

**符号清单**（按类别分组）：

| 类别 | 记号 | 含义 |
|------|------|------|
| **参数/目标量** | $K$ | 主题数量（固定常数） |
| | $p$ | 词典大小（可随 n 增长） |
| | $A = [A_1, \dots, A_K] \in \mathbb{R}^{p \times K}$ | 词-主题矩阵，每列 $A_k \in \Delta_p$（概率单纯形） |
| | $\alpha^{(i)} \in \Delta_K$ | 文档 i 的混合权重向量（稀疏，$\|\alpha^{(i)}\|_0 \le \tau$） |
| | $\boldsymbol{\alpha}^{(i)} = \sum_{k=1}^K \alpha^{(i)}_k \delta_{A_k}$ | 混合测度（定义在度量空间 $(\Delta_p, d)$ 上的概率测度） |
| | $W(\boldsymbol{\alpha}^{(i)}, \boldsymbol{\alpha}^{(j)}; d)$ | 两个混合测度间的 Wasserstein 距离（目标量） |
| **随机变量/样本** | $Y^{(i)} \in \{1,\dots,p\}^N$ | 文档 i 的 N 个词（可重复） |
| | $X^{(i)} = Y^{(i)}/N \in \Delta_p$ | 文档 i 的词频向量（观测数据） |
| | $n$ | 文档数量 |
| **估计量** | $\hat{A}$ | A 的估计量（如 [9] 中的锚词估计器） |
| | $\hat{\alpha}^{(i)}$ | 混合权重的 MLE 型估计量（见公式 (3)） |
| | $\hat{\boldsymbol{\alpha}}^{(i)} = \sum_{k=1}^K \hat{\alpha}^{(i)}_k \delta_{\hat{A}_k}$ | 混合测度的估计 |
| | $\hat{W} = W(\hat{\boldsymbol{\alpha}}^{(i)}, \hat{\boldsymbol{\alpha}}^{(j)}; d)$ | 距离的 plug-in 估计量 |
| **关键中间量** | $\Sigma^{(i)}$ | 权重估计的渐近协方差矩阵（公式 (8)） |
| | $F'_{ij}$ | 方向导数意义下的"有效约束集"（公式 (33)） |
| | $\kappa_\tau$ | 限制性条件数（公式 (19)） |

**模型**（数据生成机制）：

1. **文档生成**：每个文档 i 独立地：
   - 从混合测度 $\boldsymbol{\alpha}^{(i)}$ 中抽取一个主题 $Z_t \sim \boldsymbol{\alpha}^{(i)}$（即 $Z_t = k$ 的概率为 $\alpha^{(i)}_k$）；
   - 给定主题 $Z_t = k$，从词分布 $A_k$ 中抽取一个词 $Y_t \sim A_k$。
   - 重复 N 次，得到词频向量 $X^{(i)} = \frac{1}{N}\sum_{t=1}^N \mathbf{e}_{Y_t}$。

2. **可观测数据**：$\{X^{(1)}, \dots, X^{(n)}\}$，即 n 个 p 维词频向量。**注意**：混合测度 $\boldsymbol{\alpha}^{(i)}$ 和混合成分 $A$ 都是**不可直接观测**的，只能通过 $X^{(i)}$ 间接估计。

3. **目标量**：对任意一对文档 (i, j)，估计 $W(\boldsymbol{\alpha}^{(i)}, \boldsymbol{\alpha}^{(j)}; d)$，其中 $d$ 是 $\Delta_p$ 上的一个度量（如全变差距离或 Wasserstein 距离）。

**关键假设**（简化版）：

- **锚词假设**（Assumption 3）：每个主题至少有一个"锚词"——该词在该主题下出现概率为正，在其他所有主题下出现概率为零。这保证了 A 的可辨识性和可估计性。
- **稀疏性**：$\|\alpha^{(i)}\|_0 \le \tau$，即每个文档只涉及少量主题。
- **正则条件**：$\kappa_\tau$（限制性条件数）有界，$\alpha_{\min}$（最小非零权重）不太小。

#### 第二步：最小内核

**核心数学问题**：给定两个文档的词频向量 $X^{(i)}, X^{(j)}$，以及从整个语料库估计出的 $\hat{A}$，如何估计 $W(\boldsymbol{\alpha}^{(i)}, \boldsymbol{\alpha}^{(j)}; d)$ 并构造置信区间？

**最小内核（最简情形）**：取 $K=2$（两个主题），$d$ 为全变差距离。此时混合测度 $\boldsymbol{\alpha}^{(i)} = \alpha^{(i)}_1 \delta_{A_1} + \alpha^{(i)}_2 \delta_{A_2}$ 由权重 $\alpha^{(i)} = (\alpha^{(i)}_1, \alpha^{(i)}_2)$ 完全决定，且 $\alpha^{(i)}_2 = 1 - \alpha^{(i)}_1$。Wasserstein 距离简化为：

$$W(\boldsymbol{\alpha}^{(i)}, \boldsymbol{\alpha}^{(j)}; d) = |\alpha^{(i)}_1 - \alpha^{(j)}_1| \cdot d(A_1, A_2)$$

**为什么这个例子是核心**：

1. **它揭示了问题的本质结构**：Wasserstein 距离分解为"权重差异"（$|\alpha^{(i)}_1 - \alpha^{(j)}_1|$）和"成分差异"（$d(A_1, A_2)$）的乘积。估计的困难来自两个部分：权重估计的误差（受 N 限制）和成分估计的误差（受 n 限制）。

2. **它展示了非光滑性的来源**：当 $\alpha^{(i)}_1 = \alpha^{(j)}_1$ 时，权重差异为零，此时距离函数在这一点**不可微**（绝对值函数在零点不可导）。这导致 plug-in 估计量的渐近分布不再是简单的高斯分布，而是由**方向导数**决定。

3. **它体现了稀疏性的影响**：若 $\alpha^{(i)}$ 是稀疏的（例如 $\alpha^{(i)}_1 = 0$），则权重估计 $\hat{\alpha}^{(i)}_1$ 的渐近行为发生质变——它不再收敛到高斯分布，而是以正概率取零值。这要求去偏处理。

**在这个最简情形下，本文的核心结果退化为**：

- **Theorem 1（公理化）**：$W(\boldsymbol{\alpha}^{(i)}, \boldsymbol{\alpha}^{(j)}; d)$ 是混合分布间所有满足凸性和等距性的距离中**最大**的。这保证了"用 Wasserstein 距离比较混合测度"是**最保守**（最不容易漏报差异）的选择。
- **Theorem 3（下界）**：任何估计量的误差至少为 $\sqrt{\tau/(N \log^2 \tau)} + \sqrt{pK/(nN \log^2 p)}$。第一项来自权重估计（受文档长度 N 限制），第二项来自成分估计（受文档数 n 限制）。
- **Theorem 5（推断）**：去偏估计量 $\hat{W}$ 满足
$$\sqrt{N}(\hat{W} - W) \xrightarrow{d} \sup_{f \in F'_{ij}} f^\top Z_{ij}$$
其中 $Z_{ij}$ 是高斯向量，$F'_{ij}$ 是"有效约束集"——即所有在最优输运方案中达到等号的约束。这个极限分布**不是**高斯分布，但可以通过蒙特卡洛模拟。

**为什么这个例子"一看就懂"**：它把复杂的主题模型推断问题简化为"估计两个数（权重）和一个距离（成分间距离）"，然后说明这三个部分的误差如何组合。读者可以直观地看到：文档越长（N 大），权重估计越准；语料库越大（n 大），成分估计越准；两者共同决定距离估计的精度。

**这个内核如何推广**：当 $K > 2$ 时，权重差异变为向量差异，绝对值变为 $\ell_1$ 范数，但核心结构不变——Wasserstein 距离仍然是"权重差异"和"成分差异"的某种组合。当 $d$ 变为一般的度量时，$d(A_1, A_2)$ 的计算变得更复杂，但估计误差的分解方式不变。当权重非稀疏时，$F'_{ij}$ 变为整个单纯形，极限分布退化为高斯分布。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：在主题模型框架下，当混合成分矩阵 A 和混合权重向量 α 均需从数据中估计时，如何对两个混合测度间的 Wasserstein 距离进行**最优估计**与**有效推断**。
2. **核心工具/方法**：公理化刻画 Wasserstein 距离为最判别性的凸距离；利用 minimax 下界技术（模糊假设）证明估计最优性；构造**去偏 MLE** 型权重估计器，结合方向 Hadamard 可微性和泛函 delta 方法建立渐近正态性。
3. **主要结论**：① 建立了该距离估计的首个 minimax 下界，证明 plug-in 估计量在宽泛条件下达到最优速率（至多差对数因子）；② 构造了首个在稀疏混合测度下渐近正态的权重估计器；③ 提供了首个理论上保证的置信区间程序，模拟验证其优于 bootstrap 方法。

#### 关键设定与假设

**模型设定**（完整版）：

- **数据**：n 个独立文档，每个文档 N 个词，词来自大小为 p 的词典。
- **生成过程**：文档 i 的混合权重 $\alpha^{(i)} \in \Delta_K$ 是**固定未知**的（非随机），且 $\|\alpha^{(i)}\|_0 \le \tau$（稀疏）。词-主题矩阵 $A \in \mathbb{R}^{p \times K}$ 是固定未知的，满足锚词假设。
- **观测**：词频向量 $X^{(i)} = Y^{(i)}/N$，其中 $Y^{(i)} \sim \text{Multinomial}_p(N, r^{(i)})$，$r^{(i)} = A\alpha^{(i)}$。

**核心假设**（按重要性排序）：

1. **锚词假设**（Assumption 3）：每个主题 k 存在锚词集合 $I_k$，使得对 $j \in I_k$，$A_{jk} > 0$ 且 $A_{jk'} = 0$（$k' \neq k$）。这是 A 可辨识和可估计的关键。
2. **稀疏性**（公式 (15)）：$\|\alpha^{(i)}\|_0 \le \tau$，且 $\tau$ 可能远小于 K。
3. **条件数假设**（公式 (18)-(19)）：限制性条件数 $\kappa_\tau$ 有界，保证权重估计的稳定性。
4. **正则性假设**（公式 (20)）：$\alpha_{\min}$（最小非零权重）不太小，保证可辨识性。
5. **度量假设**（公式 (25)-(26)）：$d$ 与全变差距离双-Lipschitz 等价，保证 Wasserstein 距离与 $\ell_1$ 范数可比。

**相比已有文献的放宽/强化**：

- **放宽**：允许 p 随 n 增长（高维）；允许 α 稀疏；允许 A 未知（需估计）。
- **强化**：要求锚词假设（比一般可辨识性更强）；要求 $\tau$ 不太大（稀疏度有界）。

#### 主要结果

**结果 1（Theorem 1，公理化）**：在仿射独立假设下，SWD（即混合测度间的 Wasserstein 距离）是混合分布集合上满足 (i) 凸性、(ii) 与 d 在成分上等距、(iii) 归一化条件的所有函数中**最大**的。这为 Wasserstein 距离提供了"最判别性"的辩护：任何其他满足这些性质的凸距离都不会比 Wasserstein 距离更能区分不同的混合测度。

**结果 2（Theorem 3，minimax 下界）**：对任意距离估计器 $\hat{W}$，
$$\sup_{\Theta} \mathbb{E}|\hat{W} - W| \gtrsim \frac{c_d^2}{C_d} \left( \kappa_\tau^2 \sqrt{\frac{\tau}{N \log^2 \tau}} + \sqrt{\frac{pK}{nN \log^2 p}} \right)$$
其中第一项来自权重估计的固有难度（即使 A 已知），第二项来自成分估计的固有难度。这个下界与 [8] 中的上界匹配（至多差对数因子），从而证明 plug-in 估计量是**近乎最优**的。

**结果 3（Theorem 4，权重估计的渐近正态性）**：去偏 MLE 估计器 $\tilde{\alpha}$ 满足
$$\sqrt{N} \Sigma^{+1/2} (\tilde{\alpha} - \alpha) \xrightarrow{d} N_K(0, I_{K-1} \oplus 0)$$
其中 $\Sigma$ 是渐近协方差矩阵（公式 (8)）。关键在于：**即使在稀疏情形**（α 在边界上），去偏处理也能恢复渐近正态性，而普通 MLE 在边界上收敛到非正态分布。

**结果 4（Theorem 5，距离估计的渐近分布）**：
$$\sqrt{N}(\hat{W} - W) \xrightarrow{d} \sup_{f \in F'_{ij}} f^\top Z_{ij}$$
其中 $Z_{ij} \sim N_K(0, Q_{ij})$，$F'_{ij}$ 是"有效约束集"。这个极限分布可以通过蒙特卡洛模拟，从而构造置信区间。

**结果 5（Theorem 6，plug-in 推断的可行性）**：通过一致估计 $\Sigma$ 和 $F'_{ij}$，plug-in 方法给出的置信区间具有正确的渐近覆盖概率。

#### 证明路线与技术技巧

**整体路线**（5 步）：

1. **公理化刻画（Theorem 1）**：利用凸分析和对偶理论，证明 SWD 是满足 R1-R2 的最大函数。关键技巧：将 SWD 表示为线性规划的对偶问题，利用凸函数的包络性质。

2. **上界（Theorem 2，来自 [8]）**：将距离估计误差分解为权重误差和成分误差：
$$\mathbb{E}|\hat{W} - W| \leq 2\epsilon_A + \text{diam}(A) \cdot \epsilon_{\alpha,A}$$
其中 $\epsilon_A$ 是 A 的估计误差（由 [9] 的锚词算法控制），$\epsilon_{\alpha,A}$ 是权重估计误差（由 [8] 的 MLE 分析控制）。

3. **下界（Theorem 3）**：采用**模糊假设**方法。构造两个难以区分的参数配置 $(\alpha, A)$ 和 $(\alpha', A')$，使得它们的 Wasserstein 距离差异很大，但似然比很小。关键技巧：
   - **权重项**：固定 A，在 $\alpha$ 和 $\alpha'$ 之间构造"模糊"，利用 Le Cam 不等式得到 $\sqrt{\tau/(N \log^2 \tau)}$ 的下界。
   - **成分项**：固定 α，在 A 和 A' 之间构造"模糊"，利用锚词结构的稀疏性得到 $\sqrt{pK/(nN \log^2 p)}$ 的下界。
   - **乘法 gap 技巧**：这是本文的核心创新。以往的下界（如 [36]）只能控制**加法** gap（$|W - W'|$），而本文需要控制**乘法** gap（$|W - W'|/W$），因为 Wasserstein 距离在零附近的行为不同。为此，作者构造了具有**大乘法 gap** 的先验分布，使得模糊假设方法仍然有效。

4. **权重估计的渐近正态性（Theorem 4）**：
   - **去偏构造**：$\tilde{\alpha} = \hat{\alpha} + \hat{V}^+ \Psi(\hat{\alpha})$，其中 $\Psi$ 是得分函数，$\hat{V}$ 是 Hessian 的估计。
   - **关键引理**：证明 $\sqrt{N}(\tilde{\alpha} - \alpha)$ 的渐近分布由 $\sqrt{N}\Psi(\alpha)$ 决定，而去偏项 $\hat{V}^+ \Psi(\hat{\alpha})$ 恰好消除了 $\hat{\alpha}$ 在边界上的非正态部分。
   - **技术难点**：处理 $\hat{A}$ 与 $\hat{\alpha}$ 的**依赖性**。作者通过条件论证，将 $\hat{A}$ 视为"几乎已知"，然后利用 [8] 中的 $\ell_1$ 误差界控制剩余项。

5. **距离估计的渐近分布（Theorem 5）**：
   - **方向 Hadamard 可微性**：证明 $W(\cdot, \cdot; d)$ 在 $(\alpha^{(i)}, \alpha^{(j)})$ 处方向 Hadamard 可微，导数由"有效约束集" $F'_{ij}$ 决定。
   - **泛函 delta 方法**：结合 Theorem 4 的渐近正态性和方向可微性，得到极限分布。
   - **关键技巧**：将 $F'_{ij}$ 的估计转化为一个**线性规划**问题，从而可以高效计算。

**技术技巧清单**：

- **模糊假设 + 乘法 gap**：处理 Wasserstein 距离在零附近的非光滑性。
- **去偏 MLE**：处理稀疏权重在边界上的非正态性。
- **方向 Hadamard 可微性**：处理非光滑泛函的 delta 方法。
- **锚词结构的利用**：将高维问题转化为低维问题。
- **条件论证**：处理 $\hat{A}$ 与 $\hat{\alpha}$ 的依赖性。

#### 真实例子与应用

**模拟设置**（Appendix F）：

- **数据生成**：$K=5$，$p=500$，$N \in \{25, 50, 100, 300, 500\}$，$n \in \{100, 500, 1000\}$。混合权重在稀疏（$\tau=3$）和稠密（$\tau=5$）两种设置下生成。
- **比较方法**：去偏 MLE（本文方法）、普通 MLE、加权最小二乘、$m$-out-of-$N$ bootstrap、导数 bootstrap。
- **主要结果**：
  - 去偏 MLE 的置信区间覆盖率达到名义水平（约 95%），而普通 MLE 在稀疏设置下覆盖率显著偏低（约 80%）。
  - 去偏 MLE 的置信区间长度比 $m$-out-of-$N$ bootstrap 短约 20-30%。
  - 在稠密设置下，所有方法表现相近，但去偏 MLE 仍略优。
- **结论**：去偏 MLE 在稀疏设置下具有显著优势，且计算成本远低于 bootstrap 方法。

**真实数据应用**：文中未提供真实数据例子，但作者在引言中提及了单细胞 ATAC-seq 数据（cisTopic, [15]）和文本语料库作为潜在应用场景。在这些场景中，研究者关心的是不同细胞类型或文档集合之间主题结构的差异，Wasserstein 距离提供了比传统分布距离更敏感的度量。

#### 🔎 结论是否比证明窄

**结论确实比证明窄，具体体现在**：

1. **Theorem 5 的适用范围**：文中明确假设 $K$ 固定（不随 n 增长），且 $\tau$（稀疏度）有界。但在 Theorem 3 的下界中，$K$ 和 $\tau$ 都可以随样本量增长。这意味着**上界和下界之间存在 gap**：下界允许更一般的参数空间，但上界（即推断结果）只在更窄的参数空间下成立。作者在 Remark 4 中承认了这一点，但未给出 $K$ 增长时的推断结果。

2. **度量 d 的限制**：Theorem 5 要求 d 满足双-Lipschitz 等价条件（公式 (26)）。这排除了某些重要的度量，如**平方 Wasserstein 距离**（不满足三角不等式）或**带权重的 $\ell_1$ 距离**。作者在 Remark 6 中讨论了扩展的可能性，但未给出完整证明。

3. **锚词假设的必要性**：所有结果都依赖于锚词假设（Assumption 3）。虽然作者指出这是主题模型文献中的标准假设，但锚词假设在实际数据中可能不成立（例如，词可能同时出现在多个主题中）。作者未讨论锚词假设不成立时的后果。

4. **"去偏"的代价**：去偏 MLE 虽然恢复了渐近正态性，但其方差可能大于普通 MLE 在内部点情形下的方差。作者在 Appendix F.3 中通过模拟展示了这一点，但未给出理论上的效率损失刻画。

**这些 gap 是否被作者明确承认**：作者在 Remark 4 和 Remark 6 中明确承认了 $K$ 增长和度量扩展的限制，但未讨论锚词假设的稳健性问题。对于"结论比证明窄"这一点，作者在 Conclusion 中将其定位为"首次尝试"，暗示后续工作可以填补这些 gap。

### 四、开放问题

以下开放问题均扎根于本文的具体语句或结果：

1. **$K$ 增长时的推断**（扎根于 Remark 4："In problems in which $K$ is expected to grow with the ambient sample sizes, although joint asymptotic results such as Eq. (78) become ill-posed, one can still study the marginal distributions of $\tilde{\alpha}$"）。作者只给出了边际正态性，但未给出**联合**推断或距离推断在 $K \to \infty$ 时的结果。要证明什么：距离估计在 $K$ 增长时的渐近分布，以及相应的置信区间是否仍然有效。

2. **更一般度量的推断**（扎根于 Remark 6 和公式 (26) 的双-Lipschitz 条件）。作者要求 d 与全变差距离双-Lipschitz 等价，这排除了平方 Wasserstein 距离等常用度量。要证明什么：对于更一般的度量（如 $W_p$ 距离，$p \neq 1$），本文的推断框架是否仍然成立，或者需要哪些新的技术。

3. **锚词假设的稳健性**（扎根于 Assumption 3 及其在 Section 4.1 中的讨论）。锚词假设是本文所有结果的基础，但实际数据中可能不成立。要证明什么：当锚词假设轻微违反时（例如，锚词在其他主题下有很小的正概率），估计和推断的误差如何变化。

4. **去偏 MLE 的效率损失**（扎根于 Appendix F.3 的模拟结果）。模拟显示去偏 MLE 的置信区间比普通 MLE 略宽，但未给出理论上的效率损失刻画。要证明什么：去偏 MLE 相对于普通 MLE 在内部点情形下的渐近效率损失，以及是否存在更优的去偏方案。

5. **计算复杂度与大规模实现**（扎根于 Appendix A 的算法描述）。本文的推断程序需要求解线性规划和蒙特卡洛模拟，在大规模语料库（$p \sim 10^5$，$n \sim 10^6$）上的计算成本可能过高。要证明什么：是否存在更高效的算法，或者本文的方法是否可以与现有的分布式计算框架结合。
