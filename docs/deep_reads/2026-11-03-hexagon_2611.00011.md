### 一、领域脉络与小综述

- **这个方向是什么**：照明数问题（illumination problem）是凸几何与离散几何交叉领域的一个经典问题。它问：给定一个凸体 K（紧致、有非空内部的凸集），最少需要多少个方向（点光源），才能保证 K 的每一个边界点都能被至少一个方向"照亮"（即沿该方向移动一小段距离后进入 K 的内部）？这个最小数目记为 ill(K)。其分数版本 ill*(K) 允许对方向赋予权重（测度），要求每个边界点被照亮的"总质量"至少为 1。该问题的根本困难在于：对于一般凸体，ill(K) 的上界估计与精确计算都极为困难，且与覆盖数、对偶理论、组合结构（如图的支配集）有深刻联系。当前成熟度：这是一个有数十年历史的活跃领域，但精确值仅在少数特殊类别（如多胞形、对称体）中已知，一般维数下的最优界仍是开放问题。

- **发展脉络（history）**：
  - **奠基工作**：Boltyanski 和 Martini [5] 较早研究了直和凸体的照明问题，并断言了多圆柱（polydisc）的照明数公式（后被 [1] 修正）。Levi 的早期工作确立了平面凸体的基本结果。Hadwiger 的覆盖猜想（每个 n 维凸体可被 2^n 个平移覆盖）与照明数问题等价，是该领域的核心驱动。
  - **主要进展**：Naszódi [8] 引入了分数照明的测度论框架，将问题从组合计数推广到测度优化。Rotem、Schejter 和 Slomka [1] 在 2026 年发表了复多圆柱的精确照明数公式（ill(D^n) = 2^{n+1} - 1），并建立了复 1-无条件体的基本框架。Sun 和 Vritsiou [9] 在 2025 年证明了实 1-对称体的上界 M_n ≤ 2^n - 2（n≥3），其"大坐标/小坐标"论证成为后续工作的关键工具。Tikhomirov [10] 证明了在充分大的维数下，非立方体的 1-对称体有 M_n < 2^n，并给出了 2^{n-1} + O(2^n/n) 的构造。
  - **当前 frontier**：本文（Schejter 2026）处于这一进展的最前沿。它改进了 Sun–Vritsiou 的上界，将实 1-对称体的上界从 2^n - 2 降至 2^{n-1} + γ_c(Q_{n-1}) + n - 1（约 2^{n-1}(1 + (1+o(1))/n)），并首次确定了复二维 zonotope 的精确照明数（5 或 7），以及复三维 1-对称非多圆柱体的上界 12。此外，它建立了分数照明的下界 2^n 在一族介于特定内外体之间的凸体上的成立性。
  - **本文的位置**：本文是 [1]、[2]、[9]、[10] 的直接后继。它一方面将 [1] 的复多圆柱结果推广到复 zonotope 和复 1-对称体，另一方面将 [9] 的实 1-对称体上界大幅改进，并引入了新的组合工具（连通支配集）和测度工具（乘积边界测度）。

- **子线索聚类**：
  1. **复空间中的照明**：这条线索由 [1] 开创，研究复向量空间中的凸体（视为实空间中的凸体）的照明数。关键对象是复 1-无条件体（坐标旋转不变）和复 zonotope。本文的 Theorem 2 和 Theorem 3 属于此线索。
  2. **实 1-对称体的上界**：这条线索由 [9] 和 [10] 主导，研究实空间中坐标置换和符号翻转不变的凸体。核心问题是 M_n 的渐近行为。本文的 Proposition 5 属于此线索。
  3. **分数照明与测度方法**：由 [8] 开创，[1] 发展。本文的 Proposition 9 和乘积边界测度属于此线索。
  4. **组合结构（图论）**：本文首次将连通支配集（connected domination）引入照明问题，这是对 [9] 中"大坐标/小坐标"论证的图论化改造。

- **这个方向在追问的核心问题**：
  1. **Hadwiger 猜想的变体**：对一般凸体，ill(K) 是否总 ≤ 2^n？已知对中心对称体成立，但对一般凸体在 n≥3 时开放。
  2. **对称体的精确值**：对 1-对称体（实或复），ill(K) 的精确最大值是多少？已知下界 2^{n-1}（由本文 Proposition 8 的 P_n 给出），上界在本文中改进到 2^{n-1}(1 + (1+o(1))/n)。
  3. **分数 vs 整数**：ill*(K) 与 ill(K) 的差距有多大？[1] 的猜想（ill*(K) ≤ 2^n）在本文的 Proposition 9 中得到部分支持。
  4. **维数依赖**：M_n 的渐近行为是 2^{n-1}(1 + o(1)) 还是 2^n(1 - o(1))？本文的 Proposition 5 支持前者，但未完全确定。
  5. **复 vs 实**：复 1-对称体的照明数是否显著小于实 1-对称体？本文的 Theorem 3（12 方向）与实情形的 2^{n-1} 相比，暗示复结构可能带来更小的照明数。

### 二、最核心、最简单的例子 / 数学问题

**第一步：把符号、模型、可观测数据交代清楚**

- **符号**：
  - K：凸体（compact convex set with nonempty interior），在实空间 R^n 或复空间 C^n（视为 R^{2n}）中。
  - ill(K)：普通照明数，即照亮 K 所需的最少方向数。
  - ill*(K)：分数照明数，即满足每个边界点被照亮总质量 ≥ 1 的测度的最小总质量。
  - D：复单位圆盘 {z ∈ C : |z| ≤ 1}。D^n 是复多圆柱（polydisc）。
  - B：复二维 ℓ₁ 球 {z ∈ C² : |z₁| + |z₂| ≤ 1}。
  - L(a,b)：{z ∈ C² : |z₁| + a|z₂| ≤ 1, b|z₁| + |z₂| ≤ 1}，其中 0 < a, b ≤ 1。
  - Q_d：d 维超立方体图（顶点为 {0,1}^d，边连接恰有一个坐标不同的顶点）。
  - γ_c(Q_d)：Q_d 的连通支配数（connected domination number），即最小的连通支配集大小。
  - M_n：实 n 维 1-对称非立方体的照明数的上确界。
  - U_n：照亮所有归一化复 1-无条件体的单族方向的最小大小。
  - ∥·∥_K：K 的闵可夫斯基泛函（范数）。
  - [n] = {1, ..., n}。
  - supp(x) = {j : x_j ≠ 0}，M_x = {j : |x_j| = ∥x∥_∞}，Z_x = {j : x_j = 0}。
  - h_K(u) = max_{x∈K} [u, x]：支撑函数，其中 [u, x] = Re Σ u_j x̄_j。
  - N_K(x)：x 处的法锥（normal cone）。
  - P_n：{x ∈ [-1,1]^n : Σ |x_j| ≤ n-1}，即截断立方体（truncated cube）。

- **模型**：本文研究的是凸体的照明问题。核心模型是：给定凸体 K，寻找一组方向 {d_i}，使得对任意边界点 x ∈ ∂K，存在某个 d_i 满足 x + t d_i ∈ int K 对某个 t > 0 成立。等价地，用支撑函数表述：方向 d 照亮 x 当且仅当对 x 处的所有支撑法向量 u，有 [u, d] < 0。分数版本则允许对方向赋予权重。

- **可观测数据**：在纯数学论文中，"可观测数据"即凸体 K 的几何描述（如顶点、支撑函数、范数）。本文的核心可观测对象是：
  - K 的支撑函数 h_K(u)（决定 K 的几何形状）。
  - K 的边界点 x 及其法锥 N_K(x)。
  - K 的对称性（1-无条件性、坐标置换不变性等）。

**第二步：讲最小内核**

本文的最小内核可以归结为以下问题：

> **给定一个凸体 K，如何用最少的固定方向照亮其所有边界点？**

最简特例是 **n=1 的区间**：K = [-1, 1]。边界点只有两个：-1 和 1。方向 d 照亮 -1 当且仅当 d > 0（因为 -1 + t d > -1 对 t > 0 成立，且需要 -1 + t d < 1，即 d < 2/t，对足够小的 t 成立）。同理，d 照亮 1 当且仅当 d < 0。因此，ill([-1,1]) = 2（一个正方向和一个负方向）。分数版本 ill*([-1,1]) = 2（因为每个边界点需要至少 1 的质量，而一个方向最多照亮一个边界点）。

这个例子虽然平凡，但揭示了核心机制：**每个边界点需要至少一个"指向内部"的方向**。对于高维凸体，困难在于边界点的法锥可能非常复杂，且一个方向可以照亮多个边界点。

**本文的核心数学困难**在于：对于 1-对称凸体（坐标置换和符号翻转不变），边界点的法锥结构高度对称，但最优照明方向的选择需要同时处理"大坐标"（接近 ±1 的坐标）和"小坐标"（接近 0 的坐标）的边界点。Sun–Vritsiou 的"大坐标/小坐标"论证将问题分解为两部分，但上界不够紧。本文的 Proposition 5 通过连通支配集改进了这一上界，其核心思想是：将"大坐标"边界点对应到立方体图的顶点，将"小坐标"边界点对应到图的支配关系，从而将照明问题转化为图的连通支配问题。

**最简例子**：考虑 n=2 的实 1-对称体 K = [-1,1]²（正方形）。边界点有四类：顶点 (±1, ±1)、边上的点 (±1, x₂) 和 (x₁, ±1)。顶点 (±1, ±1) 的法锥是第一象限（对 (1,1) 而言），需要方向 d 满足 d₁ < 0 且 d₂ < 0。边上的点 (1, x₂)（|x₂| < 1）的法锥是 {u : u₁ ≥ 0, u₂ = 0}，需要 d₁ < 0。因此，方向 (-1, 0) 照亮所有 x₁ = 1 的边界点，方向 (0, -1) 照亮所有 x₂ = 1 的边界点，方向 (1, 0) 照亮 x₁ = -1 的边界点，方向 (0, 1) 照亮 x₂ = -1 的边界点。四个方向足够。但顶点需要两个坐标同时为负的方向，例如 (-1, -1) 照亮 (1, 1)。实际上，ill([-1,1]²) = 4（四个方向 (±1, 0), (0, ±1) 即可）。这个例子说明：**对于 1-对称体，最优照明方向往往取在坐标轴上**，但顶点需要"对角"方向。

本文的 Proposition 8 给出了 n 维截断立方体 P_n = {x ∈ [-1,1]^n : Σ |x_j| ≤ n-1}，其照明数恰好是 2^{n-1}。这个例子的核心是：P_n 的顶点是 (±1, ..., ±1, 0)（即 n-1 个 ±1 和一个 0），共有 n·2^{n-1} 个顶点。每个顶点需要至少一个方向，而一个方向最多照亮一个"零坐标位置"不同的顶点组。通过组合论证，ill(P_n) = 2^{n-1}。

### 三、这篇论文做了什么

**三句话**：
1. **研究了什么问题**：本文研究了复二维 zonotope、复三维 1-对称非多圆柱体、实 n 维 1-对称非立方体的照明数上界，以及一族介于特定内外体之间的凸体的分数照明数下界。
2. **核心工具 / 方法**：复 zonotope 的生成圆盘分解与法锥分析；复 1-对称体的支撑函数与坐标置换论证；实 1-对称体的立方体图连通支配集；乘积边界测度与闵可夫斯基插值。
3. **主要结论**：复二维 zonotope 的照明数为 5（非多圆柱）或 7（多圆柱）；复三维 1-对称非多圆柱体的照明数 ≤ 12；实 n 维 1-对称非立方体的照明数 ≤ 2^{n-1} + γ_c(Q_{n-1}) + n - 1，且存在达到 2^{n-1} 的显式族；介于特定内外体之间的凸体的分数照明数 ≥ 2^n，且在闵可夫斯基插值下达到该下界。

**关键设定与假设**：

- **复 zonotope（Theorem 2）**：Z = Σ_{j∈[N]} D v_j，其中 v_j ∈ C²。假设 Z 是满维的（即生成元张成 C²）。关键假设是生成元可以归约为三个不同复直线上的圆盘。法锥分析表明，非光滑边界点仅出现在三个圆上，每个圆上的点需要特定的方向条件。相比 [1] 的复多圆柱结果（ill(D²) = 7），本文的贡献在于证明了非多圆柱情形只需 5 个方向，且 6 不可能出现。

- **复 1-对称体（Theorem 3）**：K ⊂ C³ 是复 1-对称的（坐标旋转和置换不变），且不是复仿射多圆柱。关键假设是 K 的支撑函数 h_K(u) 只依赖于 |u_j| 的排序。构造使用 12 个方向，每个方向是 13 次单位根的某一行。相比 [2] 的 14 方向上界，本文改进到 12，但未证明 12 是最优的（Corollary 4 只给出 [9, 12] 的区间）。

- **实 1-对称体（Proposition 5）**：K ⊂ R^n 是 1-对称的（坐标置换和符号翻转不变），且不是仿射立方体。关键假设是 K 的支撑函数 h_K(u) 只依赖于 |u_j| 的排序。证明分为"大坐标"和"小坐标"两部分，前者用 Tikhomirov 的构造，后者用连通支配集。相比 [9] 的 2^n - 2 和 [10] 的 2^{n-1} + O(2^n/n)，本文的上界是 2^{n-1} + γ_c(Q_{n-1}) + n - 1，渐近为 2^{n-1}(1 + (1+o(1))/n)。

- **分数照明（Proposition 9）**：H = D^p × B^r ⊆ C ⊆ E = D^p × Π_{j∈[r]} L(a_j, b_j)，其中 p + 2r = n，B 是复二维 ℓ₁ 球，L(a,b) 由 (23) 定义。关键假设是 a_j b_j ≥ 1/2。证明构造了一个乘积测度 ν，其总质量为 2^n，且对任意方向 d，ν 中能被 d 照亮的边界点质量至多为 1。这给出了 ill*(C) ≥ 2^n 的下界。相比 [1] 的复多圆柱分数照明结果（ill*(D^n) = 2^n），本文将其推广到更广的凸体族。

**主要结果**：

- **Theorem 2**：复二维 zonotope 的照明数精确值为 5（非多圆柱）或 7（多圆柱）。证明的关键是：非光滑边界点仅出现在三个圆上，每个圆需要至少 2 个方向，但通过巧妙的 5 方向构造可以覆盖所有三个圆。下界 5 来自法锥的几何约束。

- **Theorem 3**：复三维 1-对称非多圆柱体的照明数 ≤ 12。证明的关键是：12 个方向由 13 次单位根的行构成，每个方向在某个坐标上有大振幅，在其他坐标上有小振幅。通过支撑函数的单调性，可以验证每个边界点都被至少一个方向照亮。

- **Proposition 5**：实 n 维 1-对称非立方体的照明数 ≤ 2^{n-1} + γ_c(Q_{n-1}) + n - 1。证明的关键是：将边界点分为"大坐标"和"小坐标"两类，前者用 Tikhomirov 的 2^{n-1} 方向，后者用连通支配集给出的 γ_c(Q_{n-1}) + n - 1 方向。

- **Proposition 8**：截断立方体 P_n 的照明数为 2^{n-1}。这给出了 M_n 的下界。

- **Proposition 9**：介于 H 和 E 之间的任意凸体 C 满足 ill*(C) ≥ 2^n，且在闵可夫斯基插值 (1-t)H + tC 上达到该下界。

**证明路线与技术技巧**：

- **Theorem 2 的证明路线**：
  1. 将 zonotope Z 的生成元归约为三个不同复直线上的圆盘。
  2. 计算支撑函数 h_Z(u) = Σ |[u, v_j]|，并确定非光滑边界点的位置（三个圆）。
  3. 对每个圆上的点，用法锥条件 (1) 确定需要照亮的方向条件。
  4. 构造 5 个方向，验证它们满足所有三个圆的照明条件。
  5. 下界：证明任何 4 个方向都无法覆盖所有三个圆（通过法锥的几何约束）。
  - **关键跳跃点**：从"三个圆"到"5 个方向"的构造。作者使用了一个巧妙的组合论证，将每个圆上的照明条件转化为开区间覆盖问题，然后用 5 个区间覆盖所有三个圆。
  - **技术技巧**：法锥的显式计算；开区间覆盖的有限性论证。

- **Theorem 3 的证明路线**：
  1. 利用复 1-对称性，将支撑函数 h_K(u) 表示为只依赖于 |u_j| 排序的函数。
  2. 构造 12 个方向，每个方向是 13 次单位根的行，具有特定的振幅模式。
  3. 对任意边界点 x，用支撑函数的单调性验证存在一个方向 d_r 满足 [u, d_r] < 0 对所有支撑法向量 u 成立。
  4. 关键引理：对于任意非空真子集 S ⊂ [3]，存在 r ∈ [12] 使得 f(r) ∈ S 且 Re(z_j v_r^j) ≤ -β 对所有 j ∈ S 成立（引理 (11)）。
  5. 用这个引理处理"大坐标"和"小坐标"两种情况。
  - **关键跳跃点**：引理 (11) 的证明。作者将其归结为一个有限验证问题（546 个情形），并声称有精确的整数运算证书。
  - **技术技巧**：13 次单位根的选择；有限情形验证；支撑函数的单调性。

- **Proposition 5 的证明路线**：
  1. 将边界点分为"大坐标"（至少一个 |x_j| > 1/2）和"小坐标"（所有 |x_j| ≤ 1/2）。
  2. 对"大坐标"点，用 Tikhomirov 的构造（2^{n-1} 个方向）。
  3. 对"小坐标"点，用连通支配集：将坐标 {1, ..., n} 映射到 Q_{n-1} 的顶点，用支配集给出方向。
  4. 关键引理（Lemma 6）：如果 B ⊂ {-1,1}^n × [n] 满足 (17)，则 ill(K) ≤ |B|。
  5. 关键引理（Lemma 7）：如果 A ⊂ {0,1}^n 是顶点覆盖且 T 满足条件，则 B(A,T) 满足 (17)。
  6. 用连通支配集构造 A 和 T。
  - **关键跳跃点**：从"连通支配集"到"照明方向"的转换。作者用了一个巧妙的构造：将支配集中的每个顶点对应到一个方向，该方向在支配集顶点处有负号，在其他坐标处有正号。
  - **技术技巧**：图论中的连通支配集；Hall 匹配定理；坐标置换论证。

- **Proposition 9 的证明路线**：
  1. 构造乘积测度 ν = (2σ)^p × Π_{j∈[r]} ν_{a_j,b_j}，其中 σ 是单位圆上的均匀测度，ν_{a,b} 是 L(a,b) 上的特定测度。
  2. 验证 ν 的总质量为 2^n。
  3. 对任意方向 d，用 Tonelli 定理计算 ν 中能被 d 照亮的边界点质量。
  4. 关键引理：在 L(a,b) 上，任意方向 d 照亮的边界点质量至多为 1。
  5. 乘积测度的因子独立性保证了总质量至多为 1。
  - **关键跳跃点**：L(a,b) 上的测度构造。作者选择 ν_{a,b} = 2σ₁ + 2σ₂，其中 σ₁, σ₂ 分别是两个坐标轴上的均匀测度。这个选择使得任意方向 d 照亮的边界点质量恰好为 1（当 d₁d₂ ≠ 0 时）或 1/2（当 d₁d₂ = 0 时）。
  - **技术技巧**：乘积测度；Tonelli 定理；法锥的测度计算。

**🔎 结论是否比证明窄**：

- **Theorem 2**：结论是精确值（5 或 7），证明是完整的。但注意，证明依赖于"生成元可以归约为三个不同复直线上的圆盘"这一归约，而这一归约的普适性依赖于 [1] 的引理。如果该引理有隐藏条件，结论可能不完整。**值得核查**：归约是否覆盖了所有满维复二维 zonotope？

- **Theorem 3**：结论是上界 12，但 Corollary 4 只给出 [9, 12] 的区间，未证明 12 是最优的。作者在证明中使用了"有限验证"（546 个情形），但未提供验证的细节。**值得核查**：有限验证是否真的覆盖了所有边界情况？是否存在 11 个方向的构造？

- **Proposition 5**：结论是上界 2^{n-1} + γ_c(Q_{n-1}) + n - 1，但作者没有给出 γ_c(Q_{n-1}) 的精确值或更好的渐近估计。Griggs [3] 的结果只给出 γ_c(Q_d) = (1+o(1)) 2^d/d，因此上界是 2^{n-1}(1 + (1+o(1))/n)。**值得核查**：是否存在比连通支配集更紧的组合结构？

- **Proposition 9**：结论是下界 2^n 在介于 H 和 E 之间的凸体上成立，但上界 ill*(C) ≤ 2^n 只对 H 和 E 本身成立（[1] 的结果），对中间凸体 C 未证明。作者在 Remark 1 中承认这一点，并指出这"不矛盾"但"不完整"。**值得核查**：是否存在介于 H 和 E 之间的凸体 C 使得 ill*(C) > 2^n？

### 四、开放问题

1. **复三维 1-对称非多圆柱体的精确照明数**：Theorem 3 给出上界 12，Corollary 4 给出 [9, 12] 的区间。要确定精确值，需要证明 12 是最优的（或构造 11 个方向的方案）。扎根于 Corollary 4 的陈述"lies in [9,12]"。

2. **实 1-对称体的 M_n 的精确渐近**：Proposition 5 给出 M_n ≤ 2^{n-1}(1 + (1+o(1))/n)，Proposition 8 给出下界 2^{n-1}。要确定 M_n - 2^{n-1} 的阶，需要改进连通支配集的构造或证明其最优性。扎根于 Proposition 5 后的讨论"the upper bound has the correct leading term"。

3. **分数照明的上界**：Proposition 9 证明了下界 ill*(C) ≥ 2^n 对介于 H 和 E 之间的凸体成立，但上界 ill*(C) ≤ 2^n 未对任意中间凸体证明。要确认这是否是一个真正的 gap，需要构造一个介于 H 和 E 之间的凸体 C 使得 ill*(C) > 2^n，或证明上界对所有中间凸体成立。扎根于 Remark 1 的陈述"does not contradict the proposed upper bound 2^n"。

4. **复 zonotope 的更高维推广**：Theorem 2 解决了 C² 的情形，但 C³ 及更高维的复 zonotope 的照明数完全未知。扎根于 Theorem 2 的证明中"the reduction to this model is the two-dimensional instance of [1, Lemma 3.4]"。

5. **连通支配集与照明数的深层联系**：Proposition 5 建立了照明数与 Q_{n-1} 的连通支配数之间的联系，但这是否是最优的归约？是否存在更紧的组合结构（如树的路径覆盖）？扎根于 Lemma 7 的构造"the family B(A,T) satisfies (17)"。

**提示**：要确认上述问题是否是真 gap，建议去读 [1]、[2]、[9]、[10] 的引言和结论部分，看它们是否已经提到这些问题。如果近期文献（2025-2026）都指向同一个问题，那很可能是共识性的开放问题；如果文献之间互相矛盾，那可能是一个值得深入的机会。
