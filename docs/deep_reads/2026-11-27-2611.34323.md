### 一、领域脉络与小综述

- **这个方向是什么**：本文研究的是高维随机矩阵理论中的一个核心问题——当样本协方差矩阵由多个具有可分离结构的协方差成分叠加而成时，其线性谱统计量（LSS）的渐近分布。具体而言，数据矩阵 X 是 K 个独立随机矩阵 X_r = A_r^{1/2} Z_r B_r^{1/2} 之和，其中 Z_r 为独立同分布（或近似独立）的零均值单位方差随机变量矩阵，A_r 和 B_r 分别为 p×p 和 n×n 的半正定矩阵，且各自可同时对角化。该模型比经典的单成分可分离协方差模型（K=1）更具一般性，能够刻画多个信号源叠加的复杂数据结构。该方向的核心统计问题是：在 p/n → c ∈ (0,∞) 的高维极限下，LSS 的波动是否服从高斯分布，以及其均值和协方差的具体形式。这一问题的解决为高维统计推断（如假设检验、置信区间构造）提供了理论基础。

- **发展脉络（history）**：
    - **奠基工作**：该方向的起点是 Bai 和 Silverstein (2004) [2] 对经典样本协方差矩阵（即 K=1 且 A_r = I, B_r = I 的情形）LSS 的 CLT 的证明。这项工作建立了 LSS 波动的渐近正态性，并给出了均值和协方差的积分表达式，为后续所有推广工作提供了方法论框架。
    - **主要进展**：Bai, Li 和 Pan (2019) [1] 将上述结果推广到单个可分离协方差结构（K=1），即 X = A^{1/2} Z B^{1/2}。他们通过引入矩阵 Dyson 方程和留一法（leave-one-out）技术，证明了 LSS 的 CLT，并给出了协方差核的显式形式。这一工作成为本文的直接基础。同期，Najim 和 Yao (2016) [6] 对高斯波动情形进行了深入研究，而 Couillet 和 Hachem (2014) [4] 则分析了更一般的可分离协方差类型的 LSD。
    - **当前 frontier**：本文 [Hazarika & Paul, 2026] 将 [1] 的结果从 K=1 推广到 K≥1 的叠加情形。作者指出，这一推广的关键困难在于：确定性等价（deterministic equivalent）不再由单个标量方程描述，而是由 K 维耦合的非线性方程组（矩阵 Dyson 系统）控制。因此，协方差计算中出现的稳定性算子从标量变为矩阵，需要证明其在整个谱域上的一致可逆性。本文的贡献在于建立了这一推广下的 LSS-CLT，并给出了均值和协方差的显式公式（见 (A.8)-(A.10)）。
    - **本文的位置**：本文是作者前期工作 [5]（关于叠加可分离协方差模型 LSD 的刻画）的续篇，将一阶结果（LSD）提升到二阶结果（LSS 的 CLT），是该方向从"谱分布收敛"到"谱统计量推断"的关键一步。

- **子线索聚类**：
    - **经典样本协方差矩阵的 LSS-CLT**：以 Bai-Silverstein (2004) [2] 为代表，处理 X = Z 的情形，建立了最基础的 CLT 框架。
    - **可分离协方差模型的 LSS-CLT**：以 Bai-Li-Pan (2019) [1] 为代表，处理 X = A^{1/2} Z B^{1/2} 的情形，引入了矩阵 Dyson 方程和留一法技术。
    - **更一般的方差剖面（variance profile）模型**：以 Wang, Pan, Jiang (2026) [8] 为代表，处理 X 具有一般方差剖面的情形，其 LSD 和 LSS 的 CLT 需要更复杂的确定性等价技术。
    - **叠加可分离协方差模型**：本文 [Hazarika & Paul, 2026] 及其前作 [5] 处理 X = Σ_r A_r^{1/2} Z_r B_r^{1/2} 的情形，是上述线索的交叉与推广。

- **这个方向在追问的核心问题**：
    1. **LSS 的渐近分布**：在何种条件下，LSS 的波动收敛到高斯过程？均值和协方差函数如何由模型参数（A_r, B_r, c, H, G）显式表达？
    2. **确定性等价的稳定性**：如何证明矩阵 Dyson 系统解的存在唯一性，以及相应的稳定性算子（如 I - c U_{2,2} W_2）在谱域上的一致可逆性？这是技术上的核心难点。
    3. **非高斯推广**：如何将高斯情形的结果推广到更一般的分布（如仅假设四阶矩有界）？本文通过截断、中心化和尺度化步骤处理了这一问题。
    4. **统计应用**：LSS-CLT 如何用于构造高维协方差结构的检验统计量（如球性检验、独立性检验）？本文在 Section 2.6 提出了一个基于谱矩比值的球性检验思路。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：把符号、模型、可观测数据交代清楚

- **符号**：
  - **参数 / 维度**：
    - p, n：矩阵的行数和列数，满足 p/n → c ∈ (0,∞)。
    - K：可分离协方差成分的个数，固定正整数。
    - c：极限维度比。
  - **随机变量 / 矩阵**：
    - Z_r：p×n 随机矩阵，r = 1,...,K，其条目 z_{ij}^{(r)} 独立（或近似独立），零均值、单位方差，且四阶矩有界（见条件 (2.23)）。
    - X_r = A_r^{1/2} Z_r B_r^{1/2}：第 r 个成分的随机矩阵。
    - X = Σ_{r=1}^K X_r：总数据矩阵。
    - S_n = (1/n) X X^*：p×p 样本协方差矩阵（注意这里没有减去样本均值，即假设总体均值为零）。
    - S̃_n = (1/n) X^* X：n×n 对偶样本协方差矩阵。
  - **确定性矩阵**：
    - A_r：p×p 半正定矩阵，r = 1,...,K，且 {A_r} 两两可交换（可同时对角化）。
    - B_r：n×n 半正定矩阵，r = 1,...,K，且 {B_r} 两两可交换。
    - A_j = Σ_{r=1}^K θ_{jr} A_r（见 (4.1) 附近定义，θ_{jr} 为 B_r 的特征值）。
  - **谱对象**：
    - λ_1,...,λ_p：S_n 的特征值。
    - F_{S_n}：S_n 的经验谱分布（ESD）。
    - F_{c,H,G}：极限谱分布（LSD），由矩阵 Dyson 方程 (2.12)-(2.13) 定义。
    - s_n(z), s_n^0(z)：S_n 和 S̃_n 的 Stieltjes 变换。
    - h_n(z), g_n(z)：K 维向量值函数，由 (2.8)-(2.9) 定义，是矩阵 Dyson 方程的有限样本版本。
    - h(z), g(z)：h_n, g_n 的极限。
    - M_n(z) = p(s_n(z) - s_n^0(z))：中心化的谱过程。
    - ξ_n(x) = p(F_{S_n}(x) - F_{c_n,H_n,G_n}(x))：中心化的 ESD 过程。
    - L_n(f) = ∫ f(x) dξ_n(x)：LSS（线性谱统计量）。
    - U_{2,2}, W_2, U_{1,2}, U_{2,3}, U_{3,3}, V_{2,2}, V_{2,3}, V_{3,3}：定义在 (A.4)-(A.10) 的确定性矩阵值函数，是均值和协方差公式的组成部分。
  - **其他**：
    - E_j：关于前 j 列的期望算子。
    - Δ_j = E_j - E_{j-1}：鞅差算子。
    - ϵ_j(z), γ_j(z)：中心化的二次型，见 (4.6)。
    - β_j(z), β̃_j(z), b_j(z), ψ_j(z)：留一法（LOO）和留二法（LTO）相关的随机/确定性量，见 (4.6) 和 (5.22)。

- **模型**：
  - 数据生成机制：X = Σ_{r=1}^K A_r^{1/2} Z_r B_r^{1/2}，其中 Z_r 的条目独立、零均值、单位方差，且满足四阶矩条件 (2.23)。A_r 和 B_r 是确定性半正定矩阵，各自可同时对角化（即 A_r 两两交换，B_r 两两交换）。
  - 观测数据：研究者观测到 X（或等价地，S_n），但不知道 A_r, B_r 的具体形式，只知道它们满足某些正则条件（如谱范数有界、经验谱分布收敛）。
  - 目标：对充分光滑的测试函数 f，研究 LSS L_n(f) = ∫ f(x) dξ_n(x) 的渐近分布，其中 ξ_n(x) = p(F_{S_n}(x) - F_{c_n,H_n,G_n}(x))。

#### 第二步：讲最小内核

**最小内核**：考虑最简单的非平凡情形：K=2，且 A_1 = A_2 = I_p, B_1 = B_2 = I_n。此时 X = Z_1 + Z_2，其中 Z_1, Z_2 是两个独立的 p×n 随机矩阵，条目独立同分布（或近似独立），零均值、单位方差。那么 S_n = (1/n)(Z_1+Z_2)(Z_1+Z_2)^*。由于 Z_1 和 Z_2 独立且同分布（在条目层面），Z_1+Z_2 的条目仍然是独立、零均值、单位方差的（方差相加：1+1=2，但我们可以重新归一化）。因此，这个 K=2 的叠加模型在分布上等价于 K=1 且 A = 2I_p, B = I_n 的可分离模型。此时，LSS 的 CLT 可以直接从 Bai-Li-Pan (2019) [1] 的结果推导出来。

**为什么这个例子是"最小内核"**：它揭示了叠加模型与经典可分离模型之间的本质联系——当所有 A_r 和 B_r 都成比例时，叠加只是改变了总体的方差尺度，并不改变问题的结构。真正的挑战在于当 A_r 和 B_r 不成比例时（例如 A_1 ≠ c A_2），叠加会产生非平凡的耦合效应，导致确定性等价不再是标量方程的解，而是 K 维方程组。因此，这个最小例子告诉我们：**本文的核心贡献不在于处理"叠加"本身，而在于处理叠加带来的"非交换性"（即 A_r 和 B_r 不能同时对角化为同一组基）**。当 A_r 和 B_r 各自可交换但彼此不交换时，矩阵 Dyson 系统才真正变得复杂。

**数学上要证明的核心命题**（在最小例子中退化为）：
对于 K=1 的可分离模型，证明 M_n(z) = p(s_n(z) - s_n^0(z)) 在 C 的紧子集上弱收敛到一个高斯过程，其均值由 m_2(z) 给出，协方差由 ker(z_1, z_2) 给出。证明的关键步骤是：
1. 将 M_n(z) 分解为鞅差序列的和（利用留一法）。
2. 证明鞅差序列的方差收敛到确定性极限（即 ker(z_1, z_2)）。
3. 证明鞅差序列满足 Lindeberg 条件（即高阶矩可忽略）。
4. 利用鞅中心极限定理得到弱收敛。
5. 对偏差项 M_n^2(z) 进行估计，证明其收敛到 m_2(z)。

在 K>1 的叠加模型中，上述步骤中的第 2 步和第 5 步需要处理矩阵值函数 U_{2,2}, W_2 等，并证明稳定性算子 I - c U_{2,2} W_2 的可逆性。这正是本文的技术难点所在。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：在 p/n → c ∈ (0,∞) 的高维极限下，当样本协方差矩阵 S_n 由 K 个独立可分离协方差成分叠加而成时（X = Σ_r A_r^{1/2} Z_r B_r^{1/2}），其线性谱统计量 L_n(f) 的渐近分布。
2. **核心工具 / 方法**：基于留一法（leave-one-out）的鞅差分解、矩阵 Dyson 方程、Stieltjes 变换、截断/中心化/尺度化技术，以及复分析中的围道积分方法。
3. **主要结论**：在四阶矩有界和谱范数有界等条件下，L_n(f) 的中心化版本弱收敛到高斯分布，其渐近均值和协方差由确定性函数 m_2(z) 和 ker(z_1, z_2) 显式给出（见定理 2.8 和 (A.8)-(A.10)）。当 K=1 时，该结果退化为 Bai-Li-Pan (2019) [1] 的经典结论。

#### 关键设定与假设

- **核心假设**：
  - **维度比**：p/n → c ∈ (0,∞)。
  - **创新条目**：Z_r 的条目独立（或近似独立），零均值、单位方差，且满足 Lindeberg 型条件 (2.23)：对任意 δ>0，Σ_{i,j,r} E|z_{ij}^{(r)}|^4 1{|z_{ij}^{(r)}| > δ√n} → 0。这比四阶矩有界稍强，用于控制截断误差。
  - **谱范数有界**：sup_n max_r {||A_r||, ||B_r||} ≤ τ < ∞。
  - **谱分布收敛**：A_r 和 B_r 的经验谱分布（联合地）弱收敛到确定性分布 H 和 G。
  - **可交换性**：{A_r} 两两可交换，{B_r} 两两可交换（这是矩阵 Dyson 方程成立的关键）。
  - **测试函数**：f 在包含 LSD 支撑的区间上是解析的（或至少足够光滑）。
- **相比已有工作的变化**：
  - 相比 [1]（K=1），本文允许 K≥1，且 A_r, B_r 可以不成比例，因此确定性等价由 K 维耦合方程组描述。
  - 相比 [8]（一般方差剖面），本文的模型更结构化（每个成分有可分离形式），因此可以得到更显式的公式。
  - 相比 [2]（经典样本协方差），本文允许非平凡的行列协方差结构。

#### 主要结果

- **定理 2.8**：在假设 1-3 下，对于解析函数 f，LSS 的波动 L_n(f) - E L_n(f) 弱收敛到均值为零、方差为 Σ 的高斯分布。方差 Σ 由协方差核 ker(z_1, z_2) 在围道上的二重积分给出。
- **均值公式**：E L_n(f) 的渐近展开为 (1/p) ∫ f(x) dξ_n(x) 的期望，其主项由 m_2(z) 的围道积分给出（见 (2.25)）。
- **协方差公式**：ker(z_1, z_2) 由 U_{2,2}, W_2 等矩阵值函数构成，其核心是稳定性算子 I - c U_{2,2}(z_1, z_2) W_2(z_1, z_2) 的可逆性（见 (A.10)）。
- **K=1 退化**：当 K=1 时，所有公式退化为 [1] 中的形式（见附录 A.2 的验证）。

#### 证明路线与技术技巧

**整体路线**（5 步）：
1. **截断、中心化、尺度化**（附录 B）：将 Z_r 的条目截断在 δ_n√n 水平，中心化并重新归一化，使得条目有界且满足矩条件。这一步是标准的，但需要仔细控制截断误差。
2. **鞅差分解**（Section 5）：将 M_n(z) = p(s_n(z) - s_n^0(z)) 分解为 Σ_{j=1}^n Δ_j M_n(z)，其中 Δ_j 是鞅差算子。利用留一法，将每个 Δ_j M_n(z) 表示为关于第 j 列的二次型。
3. **方差收敛**（Section 5）：证明 Σ_{j=1}^n E_{j-1} |Δ_j M_n(z)|^2 收敛到确定性极限，该极限由 U_{2,2}, W_2 等矩阵值函数给出。这里的关键是证明留一法（LOO）和留二法（LTO）的确定性等价收敛到矩阵 Dyson 方程的解。
4. **Lindeberg 条件**（Section C）：证明高阶矩（如四阶矩）可忽略，即 Σ_{j=1}^n E_{j-1} |Δ_j M_n(z)|^4 → 0。这需要利用截断后条目的有界性和四阶矩条件。
5. **偏差项估计**（Section 6）：证明 M_n^2(z) = p(E s_n(z) - s_n^0(z)) 收敛到 m_2(z)，即偏差项的主项。这需要对矩阵 Dyson 方程进行线性化，并利用稳定性算子 I - c U_{2,2} W_2 的可逆性。

**关键技术技巧**：
- **留一法（Leave-One-Out）**：通过移除第 j 列来构造鞅差序列，这是处理样本协方差矩阵相关性的标准技巧。
- **矩阵 Dyson 方程**：将确定性等价问题转化为 K 维非线性方程组的求解，并利用 Perron-Frobenius 理论和 Collatz-Wielandt 定理（附录 F）证明稳定性。
- **围道积分**：利用柯西积分公式将 LSS 表示为 Stieltjes 变换的围道积分，从而将问题转化为对 Stieltjes 变换的渐近分析。
- **Wick 公式**（附录 A.3）：用于计算高斯随机变量的高阶矩，特别是在计算偏差项时。
- **截断与中心化**：通过截断和中心化，将一般分布的问题转化为有界分布的问题，从而简化高阶矩估计。

#### 真实例子与应用

- **数值验证**：论文包含数值模拟（Figures 1-4），验证了 K=1,2,3,4,5,6 时理论协方差与模拟协方差的吻合度。模拟使用标准高斯创新，c=1，A_r 和 B_r 取为对角矩阵（特征值分布为均匀分布或离散分布）。
- **应用场景**：论文在 Section 2.6 提出了一个假设检验的应用：检验行和列方差是否为球形（即 A = a_1 I_p, B = a_2 I_n）。检验统计量基于谱矩比值 μ_{2n}/μ_{1n}，其渐近分布可由本文的 CLT 推导。该检验可用于高维方差分析、基因表达数据中的批次效应检测等场景。

#### 🔎 结论是否比证明窄

- **是的，存在结论比证明窄的情况**：
    1. **定理 2.8 的陈述**：定理要求 f 是解析函数，但证明中（特别是附录 C）似乎只用了 f 的有限阶导数有界。作者在 Remark 2.9 中仅提到 K=1 时与 [1] 一致，但未讨论 f 的正则性是否可以放宽到 C^k（k 有限）。这是一个可以探索的窄化点。
    2. **协方差公式的适用性**：协方差公式 (A.10) 中的 ker(z_1, z_2) 是在假设稳定性算子 I - c U_{2,2} W_2 可逆的前提下推导的。但作者在附录 F 中只证明了在谱域边界上的可逆性，对于谱域内部的点（特别是接近实轴的点）是否一致可逆，证明似乎依赖于"谱间隙"假设。如果 LSD 的支撑在实轴上连续（无间隙），该可逆性可能不成立，但定理陈述中未明确排除这种情况。
    3. **偏差项的收敛速度**：作者证明了偏差项 M_n^2(z) 收敛到 m_2(z)，但未给出收敛速度（如 O(1/n) 或 O(1/n^2)）。在 [1] 中，偏差项的收敛速度是明确的。本文未讨论这一点，可能意味着证明中只得到了 O(1) 的收敛，而非更精细的 O(1/n)。
    4. **非高斯推广的细节**：作者在附录 C 中声称通过截断和中心化将非高斯情形归约到高斯情形，但证明中似乎依赖于四阶矩条件 (2.23) 和 Lindeberg 条件。然而，对于非高斯情形，偏差项 m_2(z) 的公式是否与高斯情形完全相同？作者在 Section 6 中似乎暗示了这一点，但未明确证明非高斯情形下偏差项的极限与高斯情形一致。这是一个潜在的窄化点。

### 四、开放问题

1. **正则性条件的放宽**：定理 2.8 要求 f 是解析函数。能否将 f 的正则性要求放宽到 C^k（k 有限）或 Lipschitz 连续？这需要重新审视证明中围道积分和矩估计的步骤，特别是附录 C 中的截断论证。扎根于定理 2.8 的陈述和 Remark 2.9。
2. **谱间隙假设的必要性**：稳定性算子 I - c U_{2,2} W_2 的可逆性证明（附录 F）似乎依赖于 LSD 支撑与围道之间的正距离。如果 LSD 的支撑在实轴上连续（无间隙），该可逆性是否仍然成立？这关系到 CLT 是否适用于临界情形（如 c=1 且 A_r, B_r 退化）。扎根于附录 F 的证明和 (2.37) 的假设。
3. **偏差项的收敛速度**：本文证明了偏差项 m_2(z) 的极限，但未给出收敛速度。能否证明 E s_n(z) - s_n^0(z) = m_2(z)/p + O(1/n^2) 或更精细的展开？这需要更精细的矩估计和留一法分析。扎根于 Section 6 的推导和 [1] 中的对应结果。
4. **非高斯情形的偏差项**：在非高斯情形下，偏差项 m_2(z) 的公式是否与高斯情形完全一致？特别是，四阶累积量是否会影响偏差项？作者在附录 C 中似乎暗示了这一点，但未明确证明。扎根于附录 C 的截断论证和 Section 6 的公式。
5. **检验功效分析**：论文在 Section 2.6 提出了一个球形检验，但未分析其功效。在局部备择假设下，该检验的功效如何？是否可以达到最优？这需要计算检验统计量在备择假设下的渐近分布，可能涉及非中心参数的计算。扎根于 Section 2.6 的应用描述。
