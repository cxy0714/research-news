### 一、领域脉络与小综述

### 二、最核心、最简单的例子 / 数学问题

**第一步：把符号、模型、可观测数据交代清楚**

- **符号**：
  - **格点与模型**：`a` 为三角格子的网格尺寸。每个格点（六边形）独立地以概率1/2为开（open）或闭（closed）。这是**临界**渗流（p=1/2）。
  - **可观测数据（核心）**：
    - `Sa(z)`：格点 `z` 所在开簇的随机符号（±1，等概率）。若 `z` 是闭的，则为0。
    - `Φa(z)`：**密度场**（spin field）的格点正则化。`Φa(z) = c_Φ π_a^{-1} S_a(z)`，其中 `π_a = P^a(0 ↔ ∂B_1(0))` 是单臂概率（一个点连接到单位圆边界的概率），`c_Φ` 是归一化常数。其标度极限的关联函数满足 `⟨Φ(u)Φ(v)⟩ = |u-v|^{-2x}`，其中 **`x = 5/48`** 是密度场的标度维数。
    - `N_a(r,z)`：以 `z` 为圆心、半径为 `r` 的圆盘 `B_r(z)` 内的格点（六边形）数量。
    - `H^a_{B_r(z)} = 2 N_a(r,z) 1{B_r(z)^a is closed}`：**关闭圆盘**的权重。`1{...}` 是指示函数，表示整个圆盘内的所有格点都是闭的。`2N_a` 是归一化因子。
    - **`E^◦_{a,r}(z) = r^{-y} (1 - H^a_{B_r(z)})`**：这是本文的**核心对象**——**标量响应**（scalar response）。它测量"关闭一个半径为 `r` 的圆盘"对系统的影响。`y = 5/4` 是标量场的标度维数。注意，`E^◦` 是一个**可观测的随机变量**，其期望值（在给定外部构型下）就是我们要构造的场。
  - **参数/估计目标**：
    - **`E^◦(z)`**：标量场的**连续极限**，定义为 `E^◦_{a,r}(z)` 在 `a→0, r→0` 时的极限（在分布意义下）。
    - **`T(w)`**：体应力张量（holomorphic part），由论文I构造，通过旋转椭圆测量。
    - **`Ψ(z)`**：本文新构造的**次领头标量场**，权重为 `(77/96, 77/96)`。它是标量-密度融合中的次领头项。
    - **`C_◦`**：标量-密度-密度三点函数的领头系数。
    - **`k`**：一个常数，出现在标量-密度融合的次领头项中。

- **模型（数据生成机制）**：
  - 在平面区域 `U`（或黎曼球面）内，考虑临界渗流构型。
  - 我们**观测**的是"完整记录"（complete record）：即所有格点的开/闭状态，以及每个开簇的符号。
  - 我们**干预**的方式是：**强制关闭**一个半径为 `r` 的圆盘 `B_r(z)`（即把圆盘内所有格点设为闭）。这改变了系统的连接性。
  - **关键等式（4.3）**：`E[E^◦_{a,r}(z) Y_a] = r^{-y} { E[Y_a] - E_{C\B_r(z)}[Y_a] }`。这个等式说明，标量响应的期望值等于"无干预"的期望减去"圆盘内所有格点被强制关闭"的期望。这提供了**从格点可观测量到连续场的桥梁**。

**第二步：讲最小内核**

- **最小内核**：**"关闭一个圆盘"如何改变远处的连接概率？**
- **最简特例**：考虑一个最简单的观测：两个远处的点 `u` 和 `v` 是否连通。设 `Y = 1{u ↔ v}`。
  - **无干预**：`E[Y] = P(u ↔ v)`，这是通常的两点连接概率。
  - **干预后**：`E_{C\B_r(z)}[Y]` 是"圆盘内所有格点被强制关闭"后，`u` 和 `v` 连通的概率。
  - **标量响应**：`E[E^◦_{a,r}(z) Y] = r^{-y} { P(u ↔ v) - P_{C\B_r(z)}(u ↔ v) }`。
  - **物理直觉**：如果圆盘 `B_r(z)` 恰好位于连接 `u` 和 `v` 的"瓶颈"位置，那么关闭它就会**切断**这条连接，使得 `P_{C\B_r(z)}(u ↔ v)` 显著小于 `P(u ↔ v)`。这个差值，归一化后，就定义了标量场 `E^◦(z)` 在 `z` 点的"值"。
  - **为什么是 `r^{-5/4}`？** 因为关闭一个半径为 `r` 的圆盘，其影响是通过**四臂事件**（四条交替的渗流臂从圆盘边界延伸到远处）来传递的。四臂事件的概率在临界点以 `r^{5/4}` 的速率衰减（这是渗流理论中的关键指数）。因此，为了得到一个**非平凡**的极限，我们必须用 `r^{-5/4}` 来归一化。
  - **核心数学困难**：证明这个归一化后的差值在 `a→0, r→0` 时**收敛**到一个非平凡的极限，并且这个极限满足CFT所要求的性质（如Ward恒等式、零恒等式）。这需要极其精细的**多臂估计**（控制四臂、六臂、八臂事件的概率）和**共形协变性**（证明极限在共形映射下如何变换）。

### 四、开放问题

- **1. 能量场与标量场的等价性**：定理4.9的成立依赖于Camia-Feng的渐近公式 [27, (1.9)]。一个直接的开放问题是：**能否独立证明这个渐近公式，或者证明其与本文标量响应的等价性？** 这需要更深入地理解能量场的几何构造。扎根于：定理4.9的假设条件。
- **2. 碰撞极限与OPE**：本文的四点函数公式仅在分离点成立。**能否证明当源点碰撞时（如 `z→w`），关联函数的奇异行为可以被严格展开为OPE，并确定所有OPE系数？** 这需要更精细的短距离估计。扎根于：定理4.8的陈述（"pointwise"）和论文第11-12节的推导。
- **3. 对数场的严格构造**：渗流CFT的中心荷c=0，存在对数场。本文构造了标量场 `E^◦` 和次领头场 `Ψ`，但**能否严格构造出能量场的对数伴侣（logarithmic partner）？** 这可能需要引入新的格点可观测量。扎根于：论文对Camia-Feng [27] 的引用，以及第10节关于能量场与标量场比较的讨论。
- **4. 高阶关联函数与完全CFT**：本文确定了四点函数。**能否将这种方法推广到更高阶的关联函数（如五点、六点），并最终证明这些关联函数满足CFT的所有公理（如交叉对称性、模不变性）？** 这需要处理更复杂的组合结构和更精细的估计。扎根于：论文的结论部分（第15节）提到的"further questions about compatible overlapping fusions and complete field expansions"。
- **5. 数值验证的严格化**：附录B的蒙特卡洛比较是初步的。**能否设计更严格的数值检验，或者证明有限格点修正项的收敛速度，从而为理论预测提供更坚实的证据？** 扎根于：附录B的讨论。
