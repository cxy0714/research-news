### 一、领域脉络与小综述

#### 这个方向是什么

本文所处的子方向是**随机临床试验中复合终点（composite endpoint）的统计推断**，具体聚焦于**广义成对比较（Generalized Pairwise Comparisons, GPC）**这一非参数方法在**纵向数据缺失与删失并存**时的操作特性。GPC 方法的核心思想是：对两组患者的所有可能配对，根据一个**分层复合终点**（hierarchical composite endpoint，如先比生存时间、再比功能评分变化）判定每对患者的"胜/负/平"，然后用胜率（win ratio）、胜差（win difference）等统计量做组间比较。该方向的根本问题是：**当结局数据不完整（删失、纵向访视缺失）时，如何构造一个既保持 Type I error 控制、又尽量不损失功效的估计与推断策略**。当前成熟度：GPC 已被监管机构（如 FDA）接受用于 pivotal trial 的主要分析，但缺失数据下的稳健性策略尚无共识，本文正是针对这一 gap 的模拟研究。

#### 发展脉络（history）

从 introduction 与参考文献看，这条线的演进大致如下：

- **奠基工作**：**Pocock et al. (2012)** 提出 win ratio 方法，将成对比较思想引入复合终点分析，解决了传统复合终点（如"死亡或住院"）把不同临床重要性的事件等权相加的问题。**Finkelstein & Schoenfeld (1999)** 更早提出类似的成对比较框架，但 Pocock 的工作使其在临床试验中流行。这一代工作的隐含假设是：数据完整或仅存在独立删失。
- **主要进展**：**Buyse (2010)** 系统化 GPC 框架，引入"胜差"（net benefit）等统计量，并讨论其在样本量计算中的应用。**Dong et al. (2016, 2018)** 等研究了 win ratio 在删失数据下的性质，指出**删失处理方式（如把删失对视为平局 vs. 剔除）会显著影响估计与检验**。**Bebu & Lachin (2015)** 等讨论了多重插补在复合终点中的应用。这一阶段的核心进展是：认识到删失与缺失不是"数据管理问题"，而是**识别与推断问题**。
- **当前 frontier**：**van Eijk et al. (2023)** 等开始系统评估不同缺失数据处理策略在 GPC 框架下的操作特性。本文（van Eijk & Lu, Statistics in Medicine）正是这一 frontier 的延续：它不再只关注删失，而是**同时考虑纵向数据缺失（intermittent missing）与删失**，并引入**组间差异脱落（differential attrition）**这一在监管审查中高度敏感的场景。
- **本文的位置**：本文是**模拟研究**，不是新方法开发。它的贡献在于**系统比较七种已有策略**，给出在何种缺失机制下哪种策略稳健的**经验证据**。它留下的口子是：**为什么 last common visit 策略稳健？能否从理论上证明？**——这正是统计理论研究者可以切入的点。

#### 子线索聚类

被引文献大致落在三条子线索上：

1. **GPC 方法本身的统计性质**（Pocock 2012; Finkelstein & Schoenfeld 1999; Buyse 2010; Dong 2016, 2018）：定义胜率/胜差，研究其在删失下的渐近性质、效率、样本量公式。这一簇的隐含假设是**数据缺失机制是独立的（independent censoring）**。
2. **缺失数据处理策略**（Little & Rubin 2002; Rubin 1987; Molenberghs & Kenward 2007; van Buuren 2018）：多重插补、末次观测结转（LOCF）、混合模型等。这一簇是**通用缺失数据方法**，不针对 GPC 特化。
3. **临床试验中的估计与敏感性分析**（ICH E9(R1) 估计目标框架; Permutt 2016; Mallinckrodt 2020）：强调**估计目标（estimand）必须先于分析方法**，缺失数据策略必须与估计目标对齐。这一簇是**监管框架**，本文的 framing 明显受其影响。

#### 这个方向在追问的核心问题

1. **GPC 统计量在缺失数据下是否仍能一致估计目标参数？** 即：当缺失机制不是完全随机缺失（MCAR）时，哪种策略能保持无偏性？
2. **Type I error 控制是否稳健？** 本文的核心发现之一是：组间缺失不平衡时，某些策略的 Type I error 膨胀到 0.378，远超名义水平 0.025。
3. **功效与偏差的权衡**：多重插补能恢复功效、减少偏差，但在差异脱落时膨胀 Type I error——是否存在一种策略同时兼顾两者？
4. **估计目标（estimand）与缺失策略的匹配**：不同缺失策略实际上在估计**不同的因果量**（如"治疗组如果坚持治疗的效果" vs. "治疗组在现实依从性下的效果"），监管框架要求明确这一点，但 GPC 文献中对此讨论不足。

#### ⚠️ 作者的 framing（必须明确标注成"这是作者的说法"）

作者把缺口 frame 成：**"GPC 在 pivotal trial 中越来越常用，但缺失数据策略对其操作特性的影响缺乏系统评估"**。他们声称：**"据我们所知，这是首个系统评估多种缺失策略在 GPC 框架下、同时考虑删失与纵向缺失的模拟研究"**。他们淡化/回避的竞争路线包括：
- **基于模型的估计方法**（如联合建模生存与纵向轨迹的 shared random effects model）——作者只在讨论中一笔带过，未纳入比较。
- **加权估计方程（IPW）**——作者未将其作为独立策略纳入，尽管这是因果推断文献中的标准工具。
- **估计目标框架的形式化应用**——作者提到 ICH E9(R1)，但未严格按 estimand 框架重新定义每个策略在估计什么。

**值得研究者去查的问题**：为什么作者没有纳入 IPW 或 DR 估计？是因为 GPC 的非参数结构难以构造权重，还是因为模拟设计下 IPW 表现已知不佳？另外，**"last common visit 策略始终控制 Type I error"这一发现，是否在理论上可解释为它实际上在估计一个"截断的" estimand？**——这可能是理论切入的好问题。

#### 张力

未见明显对立引用。但存在一个**隐含张力**：GPC 方法文献（Pocock 等）倾向于在独立删失假设下宣称稳健性，而缺失数据文献（Little & Rubin 等）早已证明**非随机缺失下没有任何"无假设"的方法**。本文的模拟结果（差异脱落时 Type I error 膨胀）实际上是在**用数值证据揭示这一张力**，但作者未在理论上点破。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：把符号、模型、可观测数据交代清楚

**符号**（逐个点名）：

- **$i = 1, \dots, n$**：患者索引；$n$ 为总样本量。随机分为两组：治疗组 $T$ 与对照组 $C$，组别指示变量 $A_i \in \{0, 1\}$。
- **$T_i$**：生存时间（time-to-event），是**潜在结局**（potential outcome）的一部分——每个患者理论上都有在治疗和对照两种状态下的生存时间，但我们只能观测到其实际分配组下的值。
- **$Y_i(t)$**：纵向结局（如功能评分 ALS-FRS-R），在预设访视时间点 $t_1 < t_2 < \dots < t_K$ 测量。同样是**潜在结局**。
- **$C_i$**：删失时间（censoring time）。观测到的生存时间为 $\tilde{T}_i = \min(T_i, C_i)$，删失指示 $\Delta_i = \mathbb{1}(T_i \le C_i)$。
- **$R_i(t_k)$**：纵向访视缺失指示——$R_i(t_k) = 1$ 表示第 $k$ 次访视有观测值，$=0$ 表示缺失。这是**可观测的**。
- **$X_i$**：基线协变量（如发病年龄、起病部位），用于生成数据，但不一定进入分析。
- **$D_i$**：疾病严重度（如基线功能评分），是**影响缺失机制**的变量——缺失可能与疾病严重度相关（即非随机缺失，MNAR 的一种形式）。

**模型**（数据生成机制，本文基于 ALS 自然史）：

- 生存时间 $T_i$ 由**指数分布**生成，风险率依赖组别与基线严重度：$h(t \mid A_i, D_i) = \lambda_0 \exp(\beta A_i + \gamma D_i)$。
- 纵向结局 $Y_i(t_k)$ 由**线性混合效应模型**生成：$Y_i(t_k) = \alpha_0 + \alpha_1 t_k + \alpha_2 A_i t_k + b_{0i} + b_{1i} t_k + \varepsilon_{ik}$，其中 $(b_{0i}, b_{1i})$ 是患者随机截距与斜率，$\varepsilon_{ik}$ 是测量误差。治疗效应体现在斜率差异 $\alpha_2$ 上。
- **缺失机制**：纵向访视缺失概率依赖**当前疾病严重度**（即 $Y_i(t_k)$ 的值）与组别——这构成**缺失非随机（MNAR）**场景。删失时间 $C_i$ 独立于 $T_i$（给定协变量），但删失率在不同场景中变化。
- **GPC 分层复合终点**：先比生存时间（更长者胜），若生存时间无法判定（如双方均删失或一方删失），则比纵向结局的**变化斜率**（从基线到最后一次观测的斜率，变化更小者胜），仍无法判定则为平局。

**可观测数据**：研究者实际观测到的是 $\{A_i, \tilde{T}_i, \Delta_i, \{Y_i(t_k) R_i(t_k)\}_{k=1}^K, X_i\}$。**关键点**：纵向结局 $Y_i(t_k)$ 在访视缺失时不可观测，且缺失概率与疾病严重度相关——这意味着**简单剔除缺失患者或 LOCF 都会引入选择偏差**。删失时间 $C_i$ 本身不可观测（只能观测到 $\tilde{T}_i$ 与 $\Delta_i$）。

**要估的对象**：GPC 框架下的**胜率（win ratio）** $WR = P(\text{治疗组患者胜}) / P(\text{对照组患者胜})$，或**胜差** $WD = P(\text{治疗组胜}) - P(\text{对照组胜})$。这是**因果 estimand**——它比较的是"如果所有患者都被分配到治疗组 vs. 都被分配到对照组"时的结局分布。

#### 第二步：讲最小内核

**最小特例**：假设只有**一个纵向访视**（$K=1$，即只有基线 $Y_i(0)$ 和终点 $Y_i(1)$），且**无删失**（所有患者都有生存时间观测）。此时 GPC 退化为：对每对 $(i, j)$（$i$ 治疗、$j$ 对照），比较 $T_i$ vs $T_j$；若 $T_i = T_j$（连续分布下概率为 0，但离散化后可能），则比较 $\Delta Y_i = Y_i(1) - Y_i(0)$ vs $\Delta Y_j$。

**核心困难**：假设 $Y_i(1)$ 对部分患者缺失，且缺失概率与 $\Delta Y_i$ 相关（病情恶化快的患者更可能脱落）。此时：
- **完整病例分析（complete case）**：只保留 $Y_i(1)$ 观测到的患者——这相当于在**治疗组和对照组分别做不同的条件化**，破坏随机化保证的可比性，估计的 $WR$ 有偏。
- **LOCF**：用 $Y_i(0)$ 填充 $Y_i(1)$——这相当于假设缺失患者病情无变化，在病情恶化快的患者更易脱落时，**系统性高估治疗组表现**。
- **多重插补（MI）**：从观测数据建模预测缺失值——但如果缺失机制是 MNAR（缺失依赖未观测的 $\Delta Y_i$），MI 模型设定错误时同样有偏。

**本文的核心发现（最小内核）**：在组间缺失**平衡**时（两组脱落率相同），所有策略都近似无偏且控制 Type I error——因为随机化保证了条件独立，缺失不引入组间差异。但在组间缺失**不平衡**时（如治疗组因副作用脱落更多），**last common visit（LCV）策略**——即只比较双方都有观测的最后一个共同访视时间点的数据——是唯一始终控制 Type I error 的策略。**为什么？** 直觉上，LCV 相当于**把 estimand 重新定义为"在共同观测窗口内的比较"**，它不试图外推缺失数据，因此不引入模型假设偏差；代价是功效损失（因为丢弃了部分信息）。MI 能恢复功效，但代价是当 MI 模型未正确捕捉 MNAR 机制时，Type I error 膨胀。

**这个最小内核揭示的数学本质**：GPC 的估计量是**U-统计量**（成对比较的均值），其渐近正态性依赖 Hajek 投影。缺失数据策略本质上是在**改变 U-统计量的核函数**（kernel）——LCV 把核函数截断到共同观测区域，MI 则用插补值替换缺失项。不同策略的偏差-方差权衡，可以形式化为**核函数的偏差（因截断或插补模型错误）与方差（因样本量损失）之间的权衡**。这正是研究者可以用高阶 U-统计量理论切入的点。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：在随机临床试验中，当复合终点同时包含生存时间和纵向结局、且存在删失和纵向数据缺失时，七种缺失数据策略对 GPC 方法的 Type I error、功效和偏差有何影响？
2. **核心工具/方法**：基于 ALS 自然史的条件生成模型（conditional model）进行大规模模拟，生成生存与纵向数据，系统改变删失率、缺失程度、组间差异脱落和缺失-严重度相关性，比较七种策略。
3. **主要结论**：组间缺失平衡时所有策略均无偏且控制 Type I error；不平衡时，LCV 策略是唯一始终控制 Type I error 的方法（0.025 ± 0.002），而 MI 虽恢复功效但膨胀 Type I error（最高达 0.378）。

#### 关键设定与假设

- **数据生成模型**：基于 ALS 自然史的真实参数（来自 PRO-ACT 数据库），生存时间用指数分布，纵向结局用线性混合效应模型。**假设**：治疗效应在生存和纵向结局上均为比例效应（proportional hazards / proportional slope change）。
- **GPC 分层规则**：先比生存、再比纵向斜率变化。**假设**：生存时间优先于纵向结局（临床合理性假设）。
- **缺失机制**：纵向访视缺失概率依赖当前疾病严重度（MNAR），删失独立于结局（给定协变量）。**关键操纵**：组间差异脱落（治疗组 vs 对照组脱落率不同）和缺失-严重度相关性强度。
- **七种策略**：完整病例（complete case）、末次观测结转（LOCF）、末次共同访视（LCV）、多重插补（MI，含不同插补模型）、混合模型重复测量（MMRM）、以及将缺失视为平局（tie）的变体。
- **评估指标**：Type I error（在零效应下）、功效（在备择效应下）、偏差（估计的 win ratio 与真实值之差）。

**相比已有文献的强化/弱化**：本文的强化在于**同时操纵删失和纵向缺失**，且缺失机制是 MNAR（更贴近现实）；弱化在于**未考虑竞争风险**（competing risks）和**非比例效应**（non-proportional hazards），且模拟参数全部来自单一疾病（ALS）。

#### 主要结果

- **平衡缺失**：所有策略的 Type I error 均在名义水平附近（0.020–0.030），偏差可忽略。**结论**：缺失本身不是问题，**组间缺失不平衡**才是。
- **不平衡缺失（治疗组脱落更多）**：
  - 完整病例：Type I error 膨胀至 0.15–0.25（取决于缺失-严重度相关性），偏差显著。
  - LOCF：Type I error 膨胀至 0.20–0.38（最高），偏差最大——因为 LOCF 假设"无变化"，在治疗组脱落更多时系统性高估治疗组。
  - MI（正确设定模型）：Type I error 膨胀至 0.08–0.15，但功效最高——MI 部分纠正了偏差，但未完全消除。
  - **LCV：Type I error 始终在 0.023–0.027，但功效最低**——LCV 通过截断比较窗口避免了外推偏差，但丢弃了删失后的信息。
- **功效排序**（在控制 Type I error 的策略中）：MI > 完整病例 > LCV。**偏差-方差权衡**清晰可见。

#### 证明路线与技术技巧

本文是**模拟研究**，无理论证明。但模拟设计的逻辑可以拆解为：

1. **数据生成**：先抽患者基线特征（$D_i$），再条件生成生存时间 $T_i$ 和纵向轨迹 $\{Y_i(t_k)\}$，最后生成缺失指示 $R_i(t_k)$（依赖 $Y_i(t_k)$ 和 $A_i$）。**技巧**：用真实 ALS 数据校准参数，保证模拟场景临床相关。
2. **GPC 计算**：对所有跨组配对计算胜/负/平，构造 win ratio 估计量。**技巧**：用分层比较（先生存后纵向）减少平局比例，提高检验功效。
3. **操作特性评估**：重复模拟（每个场景 1000 次），记录 Type I error、功效、偏差的蒙特卡洛分布。**技巧**：用 95% 置信区间判断 Type I error 是否显著偏离名义水平。
4. **场景设计**：全因子设计（删失率 × 缺失率 × 差异脱落 × 缺失-严重度相关性），覆盖从 MCAR 到 MNAR 的谱系。

**技术难点**：GPC 的 U-统计量结构使得**方差估计**在缺失数据下不平凡——成对比较之间存在相关性（同一患者参与多对比较），缺失数据进一步破坏对称性。本文未深入讨论方差估计的偏差，但模拟结果间接反映了这一点（Type I error 膨胀部分来自方差低估）。

#### 🔎 结论是否比证明窄

- **明确声明**：作者在讨论中承认"LCV 策略的功效损失在缺失率超过 30% 时变得显著"，且"MI 的 Type I error 膨胀在缺失机制为 MNAR 且插补模型未包含严重度时最严重"——这些是**模拟场景内的结论**，未外推。
- **潜在过度声明**：作者在摘要中称"LCV 是唯一始终控制 Type I error 的策略"——但这一结论仅在**模拟的参数范围内**成立（ALS 数据、指数生存、线性纵向轨迹）。对于非比例效应、竞争风险、或纵向轨迹非线性（如平台期）的场景，LCV 是否仍稳健**未经验证**。
- **未讨论的理论问题**：作者未讨论**LCV 策略实际上在估计什么 estimand**——它是否等价于"在共同观测窗口内的条件效应"？如果是，那么它的 Type I error 控制是以**改变研究问题**为代价的，这在监管语境下需要明确声明。这是本文最值得理论深挖的缺口。

#### 真实例子与应用

本文**无真实数据应用**，但模拟参数基于 PRO-ACT 数据库（ALS 患者登记数据），且模拟场景设计参考了**ENDEAR 试验**（依达拉奉治疗 ALS 的 pivotal trial，使用 ALSFRS-R 作为主要终点）。作者在讨论中明确将结果与 ENDEAR 试验的缺失模式对比，指出该试验中治疗组脱落率更高（与本文的差异脱落场景一致），暗示 LCV 策略可能更适合作为该试验的敏感性分析。

### 四、开放问题

1. **LCV 策略的 estimand 是什么？** 本文模拟显示 LCV 控制 Type I error，但未定义它在估计什么因果量。能否用潜在结果框架形式化"共同观测窗口内的比较"这一 estimand，并推导其与完整数据 estimand 的关系？（扎根于：作者在讨论中承认"LCV 改变了比较的时间范围"，但未深入。）
2. **能否推导 LCV 策略的渐近性质？** GPC 估计量是 U-统计量，LCV 相当于截断核函数。能否用高阶 U-统计量理论推导 LCV 在 MNAR 下的渐近偏差和方差，并给出 Type I error 控制的条件？（扎根于：作者仅提供模拟证据，无理论保证。）
3. **是否存在比 LCV 更优的策略？** 模拟显示 MI 在功效上有优势但牺牲 Type I error。能否构造一种**双重稳健**的 GPC 估计量——结合 MI 的功效和 LCV 的稳健性？（扎根于：作者在结论中呼吁"开发新的缺失数据策略"，但未给出方向。）
4. **组间差异脱落的检验问题**：本文模拟了差异脱落，但未讨论**如何检验**差异脱落是否存在。能否构造一个基于 GPC 结构的检验统计量，在分析前检测组间缺失机制差异？（扎根于：作者在场景设计中操纵了差异脱落，但未将其作为可检验的假设。）

**提示**：要确认这些是否真 gap，建议去读近 5 年 GPC 方法文献（如 *Clinical Trials*、*Statistics in Medicine* 上 Dong、Mao、Bebu 等人的工作）的 introduction——如果多篇都指向"缺失数据下 GPC 的理论性质未解决"，则第一条是真 gap；如果已有理论工作（如 Mao 2021 的 win ratio 渐近理论）覆盖了部分，则需要调整切入角度。
