### 一、领域脉络与小综述

#### 这个方向是什么

本文所处的子方向是**删失生存分析中的部分识别（partial identification）**。其根本的统计问题是：在事件时间 T 与删失时间 C 可能相关（即删失机制完全未知）的情况下，如何对协变量 X 对 T 分布的影响进行推断。传统生存分析几乎都依赖 T⊥C|X 的独立删失假设（或已知依赖结构的 copula 假设），而本文的目标是在**完全不指定 T 与 C 的依赖结构**的前提下，对回归系数进行推断。由于模型在无额外假设时不可点识别（Tsiatis, 1975），研究者只能退而求其次，估计系数的**识别集（identified set）**，即所有与观测数据相容的系数值构成的集合。该方向的成熟度处于**快速发展期**：理论基础（Peterson 界）已有近五十年历史，但将其与现代部分识别推断工具（矩不等式、子向量推断）结合是近十年的前沿工作。

#### 发展脉络

- **奠基工作**：**Tsiatis (1975)** 证明了在完全非参数设定下，T 与 C 的联合分布不可识别，这为所有后续部分识别工作提供了理论基础。**Peterson (1976)** 给出了在仅观测 (Y, Δ, X) 时，T 的边际生存函数的上下界（即 Peterson 界），这是本文方法论的直接起点。**Kaplan 和 Meier (1958)** 的乘积限估计则是独立删失下点估计的基准。
- **主要进展**：**Horowitz 和 Manski (1998)** 将部分识别思想引入删失与缺失数据问题，但他们的方法需要指定权重函数或插补方法，仍对删失机制有间接假设。**Huang 和 Zhang (2008)** 与 **Deresa 和 Van Keilegom (2024)** 等通过引入 copula 函数来参数化 T 与 C 的依赖结构，从而在**点识别**框架下工作，但代价是必须正确指定 copula 形式。**Sakaguchi (2024)** 是本文最直接的竞争者，他在更一般的设定下（允许时变效应）研究了部分识别，但假设效应不随时间变化，且使用了不同的推断方法。**Bei (2024)** 提供了子向量推断的新工具，本文直接借用其检验方法。
- **当前 frontier**：如何在**完全不假设删失机制**的前提下，对**时变效应**进行推断；如何在高维协变量下构造更紧的识别集；如何将部分识别与敏感性分析结合。
- **本文的位置**：本文填补的缺口是——在**完全删失不可知**（agnostic）的设定下，对**时变系数**进行部分识别推断。作者将 Peterson 界与 Bei (2024) 的矩不等式检验结合，构造了系数的识别区间，并证明其具有经典置信区间的解释。这是对 Sakaguchi (2024) 的推广（允许时变效应），同时比 copula 方法（Huang & Zhang, 2008）更稳健。

#### 子线索聚类

1. **删失机制建模**：以 copula 为基础的参数/半参数方法（Huang & Zhang, 2008; Deresa & Van Keilegom, 2024, 2025; Czado & Van Keilegom, 2023; Lo & Wilke, 2023; Ding & Van Keilegom, 2025）。这条线追求点识别，但依赖对依赖结构的正确指定。
2. **部分识别与稳健推断**：不指定删失机制，只求识别集（Peterson, 1976; Horowitz & Manski, 1998; Sakaguchi, 2024; 本文）。这条线更稳健，但代价是只能得到区间估计。
3. **矩不等式推断方法**：为部分识别模型提供检验和置信集构造工具（Andrews & Shi, 2013; Bei, 2024; Kaido et al., 2019; Bugni et al., 2017; Gasparin & Ramdas, 2024）。这是方法论支撑，本文直接应用 Bei (2024) 的检验。
4. **变换模型与半参数回归**：Delgado et al. (2022) 等研究了删失数据下的分布回归，本文的模型 (1) 是其推广。

#### ⚠️ 作者的 framing（这是作者的说法）

作者将缺口 frame 为：**"a truly censoring-agnostic method for doing inference on the Cox PH model has eluded the literature thus far"**（第 1 页）。他们声称自己的贡献是首次在 Cox 模型下实现完全删失不可知的推断。这个 framing 隐含地**淡化了 Sakaguchi (2024) 的贡献**——作者在文献综述中仅用一句话提及 Sakaguchi，并强调其假设"time-independent effects"，而本文允许时变效应。同时，作者**回避了 copula 方法的优势**：当研究者有先验知识认为 T 与 C 的依赖结构属于某参数族时，copula 方法能给出更紧的识别集甚至点估计，而本文的方法会丢弃这些信息。作者也没有讨论**效率问题**——他们的识别区间是否在某种意义下最优，或者是否可以通过选择不同的工具变量来缩小识别集。

#### 张力

未见明显对立引用。但存在一个**隐含张力**：copula 方法（点识别）与删失不可知方法（部分识别）之间的取舍。这两条线的支持者可能对"什么是最小合理假设"有不同看法。此外，**Bei (2024) 的检验**依赖于 Assumption (A8)，该假设在本文中被替换为更易验证的 (A8')，但作者承认 (A8') 排除了某些边界情形（Supplementary E, Example 2），这可能与 Sakaguchi (2024) 的设定不完全一致。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

**符号清单**（按类别分组）：

| 类别 | 符号 | 含义 |
|------|------|------|
| **随机变量** | T | 事件时间（潜在，可能被删失） |
| | C | 删失时间（潜在，不可观测） |
| | Y = min(T, C) | 观测到的随访时间 |
| | Δ = 1{Y = T} | 事件指示符（1=观察到事件，0=删失） |
| | X = (1, X̃)ᵀ | d+1 维协变量向量（含截距项） |
| | W = (Y, Δ, X) | 单个观测的完整数据 |
| **参数/目标量** | β_true,t ∈ ℝ^(d+1) | 在时间 t 处的真实回归系数（**目标 estimand**） |
| | β ∈ B ⊂ ℝ^(d+1) | 候选参数向量 |
| | B_I* | 识别集（所有与数据相容的 β） |
| | B_I,k* | 识别集在第 k 个坐标上的投影 |
| **模型成分** | Λ_t : ℝ → (0,1) | 已知链接函数（如 Cox: Λ_t(u) = 1 - exp(-exp(u))） |
| | G = {g_j, j=1,...,J} | 工具函数类（用于将条件矩转化为无条件矩） |
| | C_θ | 连接 T 与 C 的 copula（本文不指定） |
| **样本量/维数** | n | 样本量 |
| | d | 协变量维数（不含截距） |
| | J | 工具函数个数 |
| | B | 自助法重复次数（模拟中 B = 600） |

**数据生成机制（模型）**：

1. 协变量 X 从某分布 F_X 中独立同分布抽样。
2. 给定 X = x，事件时间 T 的条件生存函数满足模型 (1)：
   P(T > t | X = x) = 1 - Λ_t(xᵀβ_true,t)。
   注意：模型只在**一个固定时间点 t** 上施加约束，不要求对所有 t 同时成立。
3. 删失时间 C 的条件分布 F_{C|X} **完全未知**，且 T 与 C 的依赖结构（copula C_θ）**完全未知**。
4. 观测到 (Y, Δ, X)，其中 Y = min(T, C)，Δ = 1{T ≤ C}。

**可观测数据**：{(Y_i, Δ_i, X_i) : i = 1, ..., n}，独立同分布。

**关键识别问题**：给定观测数据，哪些 β 是"可能的"？即，是否存在某个条件删失分布 F_{C|X} 和某个 copula C_θ，使得模型 (1) 与观测到的 (Y, Δ, X) 的联合分布相容？

#### 第二步：最小内核

**核心思想**：Peterson (1976) 给出了 T 的条件生存函数 S_T(t|x) = P(T > t | X = x) 的**识别界**：

- **下界**：S_T(t|x) ≥ P(Y > t | X = x) （因为 T > t 蕴含 Y > t）
- **上界**：S_T(t|x) ≤ P(Y > t, Δ = 1 | X = x) + P(Y ≤ t, Δ = 0 | X = x) （因为若在 t 之前删失，则 T 可能大于 t）

**最小例子**（d = 1，单个二元协变量 X ∈ {0,1}，固定时间 t）：

假设我们观测到：
- P(Y > t | X = 0) = 0.7, P(Y > t, Δ = 1 | X = 0) = 0.4
- P(Y > t | X = 1) = 0.5, P(Y > t, Δ = 1 | X = 1) = 0.3

那么 Peterson 界给出：
- 对 X = 0：S_T(t|0) ∈ [0.7, 0.4 + (1 - 0.7) = 0.7] = {0.7}（点识别！因为 P(Y ≤ t, Δ = 0 | X = 0) = 0.3，上界 = 0.4 + 0.3 = 0.7）
- 对 X = 1：S_T(t|1) ∈ [0.5, 0.3 + (1 - 0.5) = 0.8] = [0.5, 0.8]

现在假设模型 (1) 采用 Cox 链接：S_T(t|x) = exp(-exp(β_0 + β_1 x))。

- 对 X = 0：S_T(t|0) = exp(-exp(β_0)) = 0.7 ⟹ β_0 = log(-log(0.7)) ≈ -1.03。
- 对 X = 1：S_T(t|1) = exp(-exp(β_0 + β_1)) ∈ [0.5, 0.8] ⟹ β_0 + β_1 ∈ [log(-log(0.8)), log(-log(0.5))] ≈ [-1.50, -0.37]。

因此，β_1 的识别集为：β_1 ∈ [-1.50 - (-1.03), -0.37 - (-1.03)] = [-0.47, 0.66]。

**这个例子说明了什么**：
1. 即使删失机制完全未知，模型 (1) 的系数仍然可以被**部分识别**（即被限制在一个区间内）。
2. 识别集的宽度取决于 Peterson 界的宽度，而后者由观测数据中删失的比例和协变量的分布决定。
3. 当没有删失时（P(Y ≤ t, Δ = 0) = 0），Peterson 界退化为一个点，识别集也退化为一个点，模型变为点识别。

**数学上，本文做了一件什么事**：将上述 Peterson 界（对每个 x 都成立）转化为关于 β 的**条件矩不等式**（式 5），再用工具函数 G 将其转化为**无条件矩不等式**（式 6），最后用 Bei (2024) 的检验对每个候选值 r 检验 H₀(r) : r ∈ B_I,k*，通过检验反演得到识别区间的估计。**核心难点**在于：(i) 如何保证工具函数的选择不丢失信息（Assumption A4）；(ii) 如何处理连续协变量带来的无穷多个条件约束；(iii) 如何构造具有正确渐近水平的检验（Assumptions A8, A9 和 Bei (2024) 的 bootstrap）。

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：在事件时间 T 与删失时间 C 的依赖关系完全未知（censoring-agnostic）的设定下，如何对半参数生存模型（式 1）中的回归系数进行推断，该模型允许协变量效应随时间变化。
2. **核心工具/方法**：将 Peterson (1976) 的条件界转化为条件矩不等式，用工具函数（indicator、B-spline 等）离散化为无条件矩不等式，再借用 Bei (2024) 的广义矩选择（GMS）检验进行子向量推断，通过检验反演得到系数的识别区间。
3. **主要结论**：在温和的正则条件下（A1–A9），所构造的识别区间以至少 1−α 的概率覆盖真实系数 β_true,k（Theorem 1）；模拟显示区间宽度随样本量增大而收缩，随删失率增大而变宽；在删失率较低时，区间宽度接近点估计的置信区间。

#### 关键设定与假设

- **模型（式 1）**：P(T > t | X = x) = 1 - Λ_t(xᵀβ_true,t)。这是**单点约束**模型，只在固定时间 t 上施加结构。Λ_t 已知且严格递增、二次可微（A2）。
- **可观测数据**：W = (Y, Δ, X)，i.i.d.，Y = min(T, C)，Δ = 1{T ≤ C}。
- **核心假设**：
  - **(A1)** i.i.d. 观测。
  - **(A2)** Λ_t 严格递增、二次连续可微。
  - **(A3)** 工具函数 G 有界、连续。
  - **(A4)** 工具函数的支撑覆盖整个协变量空间（保证条件矩不等式的信息不丢失）。
  - **(A5)** 参数空间 B 非空、凸、紧。
  - **(A6)** 协变量空间 X 有界。
  - **(A7)** 矩函数方差一致有界（保证检验统计量渐近正态）。
  - **(A8)** 识别集边界处的"可分离性"条件（保证检验在边界处有正确的渐近水平）。这是对 Bei (2024) Assumption 2 的替代，作者用更易验证的 (A8') 代替。
  - **(A9)** 存在严格可行的参数点（保证 bootstrap 的有效性）。

**相比已有文献的放宽/强化**：
- **放宽**：完全不假设 T 与 C 的依赖结构（对比 copula 方法）；允许时变效应（对比 Sakaguchi, 2024）。
- **强化**：要求工具函数类 G 的支撑覆盖整个协变量空间（A4），这在实际中可能难以完全满足；要求参数空间有界（A5），排除了无界参数的情形。

#### 主要结果

- **Theorem 1**：在 A1–A9 下，估计的识别区间 Î_k 满足 P(β_true,k ∈ Î_k) ≥ 1−α（渐近）。证明思路：验证 Bei (2024) 检验的所有条件，将其 Assumption 2 替换为 A8 + Theorem 3。
- **Theorem 3**：在 A8 下，矩函数在识别集边界附近有线性下界，这保证了检验统计量的渐近分布正确。
- **Theorem 2 & Corollary 1**：矩函数类 {m_j,q(·,β) : β ∈ B} 是 Donsker 类，从而经验过程收敛，bootstrap 有效。
- **模拟结果**（Table 1, 4–14）：
  - 区间宽度随 n 增大而收缩（如 n=500 时宽度约 1.1，n=2000 时约 0.8）。
  - 删失率从 30% 增至 65% 时，宽度约增大 2–3 倍。
  - 正依赖（T 与 C 正相关）比负依赖产生更窄的区间。
  - 增加工具函数数量（NIF 从 12 增至 30）不一定改善区间宽度，甚至可能因方差增大而变宽。
  - 覆盖率在几乎所有设计中接近 1（保守），但在负依赖 + 重删失时可能略低于名义水平。

#### 真实例子

1. **胰腺癌数据（SEER）**：4490 名黑人男性患者，关注肿瘤大小和年龄对生存的影响。在假设独立删失的 Cox 模型下，肿瘤大小效应显著为正；在 censoring-agnostic 方法下，识别区间包含 0，即**无法排除无效应**。年龄效应在两种方法下都显著为正，但识别区间比点估计置信区间宽约 50%。
2. **NLSY 失业数据**：关注教育对失业持续时间的影响。在独立删失假设下，教育效应显著为负（高教育缩短失业）；在 censoring-agnostic 方法下，识别区间在多数亚组中仍不包含 0，但宽度显著增大。在"男性-其他种族"亚组中，Cox 链接模型被判定为误设（空识别区间）。

#### 🔎 结论是否比证明窄

**是，存在明显差距**。具体表现：

1. **Theorem 1 的证明依赖 A8**，而 A8 的定义（式 S1）涉及对**所有** β ∈ B(r) \ B_I(r) 的梯度条件。作者在正文中承认 A8 难以直接验证，并用 A8' 替代，但 A8' 只排除了"边界几乎垂直"的情形，并未完全覆盖 A8。**Supplementary E, Example 2** 展示了 A8 可能不满足的构造例子，但作者未说明该例子的实际发生率。
2. **模拟中覆盖率接近 1 而非名义水平 0.95**，作者将其归因于检验的保守性，但未提供理论解释。这可能意味着区间过宽，效率损失比模拟显示的更大。
3. **对时变效应的处理**：正文声称模型允许时变效应，但**所有模拟和实际应用都只报告了固定时间点 t 的系数**。Supplementary I.5 和 J.2 虽然讨论了时间点选择的影响，但未提供时变系数的完整推断方法（如同时对所有 t 构造置信带）。
4. **工具函数的选择**：作者建议使用 B-spline 和 indicator，但未给出选择工具函数数量的数据驱动准则。模拟显示 NIF 过大可能有害，但正文未提供理论指导。
5. **无协变量时的 Peterson 界**：作者在 Supplementary I.2 中计算了真实识别界，但未将其与估计区间进行系统比较，因此无法判断估计区间是否接近最优。

### 四、开放问题

1. **效率最优性**：本文的识别区间是通过检验反演得到的，但未讨论工具函数的选择是否在某种意义下最优。是否存在一个"最优"工具函数类 G 使得识别区间最窄？这需要建立识别区间宽度的下界，并与 minimax 最优性联系起来。（扎根于 Section 3.2 和 Supplementary D 对工具函数选择的讨论，以及模拟中 NIF 增大反而使区间变宽的现象。）

2. **时变系数的联合推断**：正文允许时变效应，但所有实证都只报告了单点 t 的系数。如何构造系数函数 β_k(·) 的**联合置信带**（simultaneous confidence band）？这需要处理多个时间点检验之间的相依性，可能涉及高斯过程的极值理论。（扎根于 Section 3.3 的时间点组合方法，以及 Supplementary J.2 中关于时间点网格选择的讨论。）

3. **高维协变量**：当 d 较大时，工具函数的数量会随 d 指数增长（式 10 的乘积形式），导致矩条件过多、检验功效下降。如何在高维下选择工具函数或采用正则化方法？这与研究者熟悉的高维统计和随机矩阵理论有直接联系。（扎根于 Section 3.2 对维度的讨论和 Supplementary D 的 remarks。）

4. **假设 A8 的可验证性**：A8 是保证检验正确水平的关键，但作者承认其难以验证。能否构造一个数据驱动的检验来验证 A8，或者用更弱的条件替代？这涉及部分识别模型的推断理论前沿。（扎根于 Theorem 3 的证明和 Supplementary E, Example 2。）

5. **与其他部分识别方法的比较**：Sakaguchi (2024) 使用了不同的方法（可能基于不同的识别策略），本文未与其进行数值比较。两种方法在何种数据生成机制下各有优劣？这需要系统的模拟比较。（扎根于 Section 1.1 的文献综述，作者仅用一句话提及 Sakaguchi。）

6. **敏感性分析框架**：本文的识别区间是在完全无假设下得到的，可能过宽。如果研究者愿意对 T 与 C 的依赖结构施加**部分**假设（如 copula 属于某个参数族，但参数未知），如何将这种信息纳入以缩窄识别区间？这可以看作 copula 方法（点识别）与本文方法（完全不可知）之间的中间地带。（扎根于 Section 3.4 的讨论和 Supplementary H 的未来研究方向。）
