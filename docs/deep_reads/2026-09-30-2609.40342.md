### 一、领域脉络与小综述

#### 这个方向是什么

全局敏感性分析（Global Sensitivity Analysis, GSA）研究的是：当系统输出是若干输入变量的函数时，每个输入变量（或变量组）对输出不确定性的贡献有多大。经典框架假设存在一个可反复查询的确定性或随机模拟器 `f`，分析者可以按设计好的采样方案（如 Sobol' 序列、拉丁超立方）在输入空间任意取点并评估输出，从而通过蒙特卡洛积分估计方差分解分量。这个框架在工程仿真、环境建模等领域已相当成熟，其核心工具是 Sobol' 指数（一阶、总阶）及其各种估计量（Saltelli et al., 2008, 2010）。

但本文关注的是一个不同的设定：**没有可查询的模拟器，只有一批已经观测到的输入-输出数据**。此时无法按设计采样，无法在固定其他变量时任意改变某个输入的值，甚至无法区分"系统本身的随机性"与"观测噪声"。本文要解决的问题是：**仅凭观测数据，能否估计出具有明确解释意义的全局敏感性指数？** 这本质上是把 GSA 从"实验设计+模拟器评估"的范式，迁移到"观测数据+监督学习"的范式。

#### 发展脉络

**奠基工作：方差分解与 Sobol' 指数。** Sobol'（1995）建立了高维函数方差分解的理论基础，将 `f(X)` 的方差分解为各变量子集贡献之和；Homma 和 Saltelli（1996）引入总阶指数，用于刻画包含某变量所有交互作用的贡献。这一阶段的工作假设 `f` 已知或可廉价评估，估计量基于 Monte Carlo 采样，误差分析也已成熟（Owen, 2013）。

**元模型（metamodel）介入。** 当 `f` 评估代价高昂时，一个自然思路是先用少量评估训练一个代理模型（高斯过程、多项式混沌展开等），再在代理模型上做 GSA。Oakley 和 O'Hagan（2004）用贝叶斯高斯过程作为元模型，在代理模型的后验分布上积分出 Sobol' 指数的不确定性；Marrel et al.（2008）进一步给出了高斯过程元模型下 Sobol' 指数估计的解析表达式。这条线的关键特征是：**元模型仍然在"设计采样"下训练**，即训练数据来自主动实验设计，而非被动观测。

**给定数据（given-data）框架。** Borgonovo et al.（2016）提出了一个更一般的视角：许多敏感性度量（包括 Sobol' 指数、密度类度量、CDF 类度量）都可以写成"无条件分布与条件分布之间的某种距离"，因此可以仅从观测样本出发，通过划分输入空间来估计这些距离。他们的"共同原理"（common rationale）框架统一了一大类敏感性度量，并给出了基于划分的估计量及其一致性。这条线不再需要模拟器，但估计量依赖对输入空间的划分策略，在高维时面临维数灾难。

**机器学习可解释性与变量重要性。** 另一条并行发展的线索来自机器学习：如何解释黑箱模型的预测？SHAP（Lundberg and Lee, 2017）从博弈论 Shapley 值出发，给出了一类加性特征归因方法；TreeSHAP（Lundberg et al., 2020）将其推广到树模型并给出多项式时间算法。这些方法衡量的是"特征对预测的贡献"，而非"特征对系统输出的贡献"——两者在观测数据下可能一致，也可能不一致（例如存在未观测混杂时）。Antoniadis et al.（2021）则建立了随机森林置换重要性与总阶 Sobol' 指数之间的理论联系，为"机器学习重要性 ≈ 敏感性指数"提供了部分理论依据。

**本文的位置。** 本文试图把这三条线缝合起来：用监督学习元模型（RF/XGB/NN）从观测数据中学习 `f̂`，然后在 `f̂` 上做两件事——（1）用网格化条件均值估计一阶 Sobol' 指数；（2）提出一个新的"触发指数"（trigger index），衡量预测损失对变量可得性的依赖。与 Borgonovo et al.（2016）的划分策略不同，本文用元模型 + 条件均值来逼近主效应函数；与 SHAP 的博弈论归因不同，本文的触发指数直接定义在预测损失上，且与 Sobol' 指数有理论联系。

#### 子线索聚类

1. **方差分解与敏感性指数估计**：Sobol'（1995）、Homma & Saltelli（1996）、Saltelli et al.（2010）、Owen（2013）、Azzini et al.（2021）、Puy et al.（2022）。这条线关注"给定 `f` 时如何精确估计指数"，是本文的基准参照。
2. **元模型辅助的 GSA**：Oakley & O'Hagan（2004）、Marrel et al.（2008）。这条线关注"用代理模型降低评估成本"，但训练数据来自设计采样。
3. **给定数据敏感性度量**：Borgonovo et al.（2016）、Becker et al.（2021）。这条线关注"仅从观测样本估计敏感性"，是本文最直接的竞争对手。
4. **机器学习可解释性与变量重要性**：Lundberg & Lee（2017）、Lundberg et al.（2020）、Antoniadis et al.（2021）、Gottard et al.（2020）。这条线关注"如何解释黑箱预测"，本文的触发指数与之有概念重叠。

#### 这个方向在追问的核心问题

- **Q1（估计问题）**：仅凭观测数据，能否一致地估计 Sobol' 指数？需要什么条件（元模型一致性、输入独立性、正则性）？
- **Q2（解释问题）**：当输入变量相关时，方差分解不再唯一。此时"敏感性"应该指什么？是预测重要性，还是生成重要性？
- **Q3（计算问题）**：观测数据下 GSA 的计算成本由元模型训练主导。如何设计采样策略（如变量子集采样）使计算可行？
- **Q4（与可解释性的关系）**：机器学习重要性度量（SHAP、置换重要性）与 Sobol' 指数之间是什么关系？能否统一？

#### ⚠️ 作者的 framing（这是作者的说法）

作者在引言中把缺口定义为：**"Classical variance-based GSA is typically formulated in a setting in which the analyst can repeatedly evaluate the input–output model and control how the input space is explored. In many applications, however, the analyst does not have access to the input–output mechanism itself, but only to a finite dataset of input–output pairs."** 也就是说，作者认为传统 GSA 的"可查询模拟器"假设在观测数据场景下不成立，因此需要新的方法。作者把本文的方法定位为"走一条不同的路"（相对于 Borgonovo et al. 的划分策略）：**用监督学习元模型重建输入-输出关系，再在元模型上做敏感性分析**。

**值得注意的回避**：作者没有深入讨论 Borgonovo et al.（2016）的划分策略在什么条件下会失效，也没有讨论当输入变量相关时 Sobol' 指数本身的识别问题（只在 4.1.3 节用实验说明"结果不应被解释为经典 Sobol' 分解"）。此外，作者没有引用因果推断文献中关于"预测重要性 vs 因果重要性"的讨论（如半参数效率理论中的变量重要性度量），这可能是本文的一个盲区。

#### 张力

- **独立性假设 vs 观测数据现实**：经典 Sobol' 分解要求输入独立；本文的理论部分（定理 3）也假设输入独立，但实验部分（4.1.3 节）恰恰处理的是依赖输入。作者的处理方式是"做实验看看"，没有给出依赖输入下的理论解释。
- **元模型一致性 vs 有限样本**：定理 1 假设元模型均方误差收敛到 0，但实际中 RF/XGB/NN 在高维、强噪声下的收敛速度可能很慢，甚至不一致。作者在实验中用 500 次重复的平均表现来掩盖单次运行的方差，这可能是有限样本问题的信号。
- **触发指数 vs Shapley 值**：作者承认触发指数与 Shapley 值有结构相似性，但强调前者定义在预测损失上、后者定义在预测值上。这个区别是否本质？如果预测损失是平方损失，触发指数是否等价于某种 Shapley 值的变换？作者没有回答。

### 二、最核心、最简单的例子 / 数学问题

#### 第一步：符号、模型、可观测数据

**符号清单**（按本文出现顺序）：

| 符号 | 含义 | 类型 |
|---|---|---|
| `X = (X₁, …, X_p)` | 输入变量向量 | 随机变量，可观测 |
| `Y` | 响应变量 | 随机变量，可观测 |
| `f: ℝᵖ → ℝ` | 未知的系统响应函数 | 待估对象（非参数） |
| `ε` | 噪声项，`E[ε|X] = 0` | 不可观测 |
| `D_train = {(x_j, y_j)}_{j=1}^{n_tr}` | 训练集 | 可观测样本 |
| `D_test = {(x_j, y_j)}_{j=1}^{n_te}` | 测试集 | 可观测样本 |
| `f̂_ML` | 元模型（RF/XGB/NN 拟合结果） | 估计量 |
| `X_i` | 第 i 个输入变量 | 随机变量 |
| `X_{∼i}` | 除 X_i 外的所有输入变量 | 随机变量 |
| `x_i^{(k)}` | X_i 的第 k 个经验分位数 | 网格点（确定性） |
| `K` | 网格大小 | 超参数 |
| `f_i(x_i)` | 主效应函数 `E[f(X)|X_i = x_i]` | 目标量（estimand） |
| `S_i^f` | 一阶 Sobol' 指数 `Var(f_i)/Var(f(X))` | 目标量（estimand） |
| `Ŝ_{X_i}` | 一阶 Sobol' 指数的估计量 | 估计量 |
| `γ ∈ {0,1}ᵖ` | 变量包含指示向量 | 随机/设计变量 |
| `q(γ)` | 预测损失（RMSE） | 随机变量 |
| `T̂^s_{X_i}` | 触发指数估计量 | 估计量 |

**数据生成机制**：

```
X ~ P_X          （输入分布，理论部分假设各分量独立）
Y = f(X) + ε     （ε ⊥ X, E[ε] = 0, Var(ε) = σ²）
```

**可观测数据**：`D = {(x_j, y_j)}_{j=1}^n`，i.i.d. 来自 `P_{X,Y}`。注意：**没有设计矩阵，没有重复实验，没有对 `f` 的直接查询能力**。

**要估计的量**：

1. **一阶 Sobol' 指数**（经典目标）：
   ```
   S_i^f = Var(E[f(X)|X_i]) / Var(f(X))
   ```
   其中 `E[f(X)|X_i]` 是主效应函数，`Var(f(X))` 是系统输出的方差（不含噪声）。

2. **触发指数**（本文新提出）：
   ```
   T^s_{X_i} = E_γ[(q(γ^{(i)}) - q(γ))²] / (4 Var_γ(q(γ)))
   ```
   其中 `γ^{(i)}` 是翻转第 i 个坐标的包含指示，`q(γ)` 是仅用 γ 选中的变量训练元模型时的预测损失。

#### 第二步：最小内核

**核心问题**：给定观测数据 `{(x_j, y_j)}`，如何估计 `S_i^f`？

**传统方法为什么不行**：经典 Sobol' 估计量（Saltelli et al., 2010）需要反复调用 `f` 在特定采样点上的值，例如估计 `S_i` 需要计算 `f(V, X_{∼i})` 和 `f(V', X_{∼i})` 的配对样本。观测数据中不存在这样的配对——每个 `x_j` 只出现一次，且 `X_i` 与 `X_{∼i}` 的联合分布是给定的，无法"固定 `X_{∼i}` 而改变 `X_i`"。

**本文的核心想法（两步走）**：

**第 1 步：用元模型近似 `f`。** 在 `D_train` 上训练一个监督学习模型 `f̂_ML`，使其逼近 `f`。这一步把"无法查询的 `f`"替换为"可以任意查询的 `f̂_ML`"。

**第 2 步：在 `f̂_ML` 上做蒙特卡洛 GSA。** 既然 `f̂_ML` 可以任意查询，就可以在 `D_test` 上构造配对样本：

```
对每个网格点 x_i^{(k)}（k = 1, …, K）：
    f̂_i(x_i^{(k)}) = (1/n_te) Σ_{j=1}^{n_te} f̂_ML(x_i^{(k)}, x_{j,∼i})
```

这里 `x_{j,∼i}` 是第 j 个测试样本去掉第 i 个分量后的向量。这个式子就是主效应函数 `f_i(x_i) = E[f(x_i, X_{∼i})]` 的蒙特卡洛估计——用测试样本的经验分布代替 `X_{∼i}` 的分布。

然后计算：

```
Ŝ_{X_i} = Var_k(f̂_i(x_i^{(k)})) / V̂_model
```

其中 `V̂_model` 是 `f̂_ML` 在测试集上的预测方差。

**为什么这个能 work？** 关键在于误差分解：

```
Ŝ_{X_i} - S_i^f = [Var_k(f̂_i) - Var(f_i)] / V̂_model
                  + S_i^f · [Var(f(X)) - V̂_model] / V̂_model
```

第一项是蒙特卡洛误差 + 元模型近似误差，第二项是元模型方差估计误差。定理 1 证明：当 `n_tr → ∞`（元模型一致）、`n_te → ∞`（蒙特卡洛一致）、`K → ∞`（网格细化）时，两项都趋于 0。

**最小内核的直观版本**：

> 你有一堆观测数据，想知道"哪个输入变量对输出影响最大"。你没法做实验，但你可以先训练一个机器学习模型来模仿真实系统，然后在这个"数字孪生"上做你想做的任何实验——固定某个变量、随机化其他变量、计算方差分解。只要你的机器学习模型足够准，你在数字孪生上算出的敏感性就接近真实系统的敏感性。

**触发指数的最小内核**：

> 除了"改变 X_i 的值会改变多少输出方差"（Sobol' 指数），你还可以问另一个问题："如果把 X_i 从预测模型中拿掉，预测误差会变差多少？" 触发指数就是对这个问题的量化。它通过随机采样变量包含向量 γ，训练多个元模型，计算预测损失对 γ 的依赖程度。

**这个内核的数学本质**：本文的方法本质上是用**经验过程理论**（bracketing number + Glivenko-Cantelli）来证明"元模型 + 蒙特卡洛"两步法的收敛性。核心假设是：
- 元模型均方误差收敛（假设 1）
- 真实函数和元模型有界（假设 3）
- 输入变量独立（用于 Sobol' 分解的识别）

### 三、这篇论文做了什么

#### 三句话

1. **研究了什么问题**：在只有观测数据、无法按设计采样查询真实系统的设定下，如何估计一阶 Sobol' 指数，以及如何量化"预测性能对变量可得性的依赖"。
2. **核心工具/方法**：用监督学习元模型（RF/XGB/NN）近似未知响应函数，然后在元模型上做网格化条件均值估计（一阶指数）和随机变量子集采样（触发指数）。
3. **主要结论**：两个估计量在温和条件下一致（定理 1、2）；触发指数在输入独立且变量无关时取零（定理 3）；蒙特卡洛实验和 NHANES 数据表明两种度量提供互补信息。

#### 关键设定与假设

**设定**：
- 观测模型：`Y = f(X) + ε`，`ε ⊥ X`，`E[ε] = 0`
- 数据：`D_train` 和 `D_test` 独立，均来自同一分布 `P_{X,Y}`
- 目标量：`S_i^f = Var(E[f(X)|X_i]) / Var(f(X))`（一阶指数）；`T^s_{X_i}`（触发指数）

**假设**（逐条说明统计含义）：

| 假设 | 内容 | 统计含义 |
|---|---|---|
| A1 | 元模型均方误差收敛：`E[(f̂_ML(X) - f(X))²] → 0` | 元模型必须一致估计 `f`。这是整个方法的地基。RF 在加性模型下满足（Scornet et al., 2015），但一般高维非参数问题未必 |
| A2 | `E[f(X)⁴] < ∞` | 四阶矩条件，保证方差估计的收敛性 |
| A3 | `f` 和 `f̂_ML` 有界 | 保证 bracketing number 有限，从而一致大数定律成立 |
| A4 | 输入变量相互独立 | 保证 Sobol' 分解唯一，且主效应函数 `E[f(X)|X_i]` 与条件分布 `P_{X_{∼i}|X_i}` 无关 |
| A5 | `q(γ)` 的有限二阶矩 | 保证触发指数估计量的收敛性 |
| A6 | `Var_γ(q(γ)) > 0` | 排除退化情形，保证触发指数良定义 |

**相比已有文献的放宽/强化**：
- 相比经典 Sobol' 估计（Saltelli et al., 2010）：**放宽**了"可查询模拟器"假设，但**强化**了元模型一致性假设（A1）。经典方法不需要元模型，但需要设计采样。
- 相比 Borgonovo et al.（2016）：**放宽**了"划分策略"的依赖（不需要选择划分方式），但**强化**了元模型假设。Borgonovo 的估计量直接基于数据划分，不需要训练元模型。
- 相比 SHAP（Lundberg & Lee, 2017）：**放宽**了"可解释性公理"的约束，但**强化**了"预测损失"的定义（需要指定损失函数）。

#### 主要结果

**定理 1（一阶指数一致性）**：在假设 A1–A4 下，`Ŝ_{X_i} → S_i^f`（依概率）。证明思路：
1. 将误差分解为元模型近似误差（A1 控制）和蒙特卡洛误差（A3 的 bracketing 条件控制）
2. 利用 van der Vaart and Wellner (1996) 的 Glivenko-Cantelli 定理得到一致收敛
3. 结合连续映射定理得到比值的收敛性

**定理 2（触发指数一致性）**：在假设 A5–A7 下，`T̂^s_{X_i} → T^s_{X_i}`（依概率）。证明思路与定理 1 类似，但需要额外处理 `q(γ)` 的估计误差。

**定理 3（变量选择性质）**：在输入独立且 `f` 不依赖于 `X_i` 的条件下，`T^s_{X_i} = 0`。证明思路：如果 `f(x) = f(x_{∼i})`，则对任意 γ，`q(γ^{(i)}) = q(γ)`，因此分子为零。

**实验发现**：
- 在 Ishigami 和 Sobol' G 基准函数上，`Ŝ_{X_i}` 能恢复真实一阶指数的排序（表 1）。
- 在依赖结构下（4.1.3 节），`Ŝ_{X_i}` 能区分直接与间接关联（表 2）。
- 触发指数与 TreeSHAP 在基准函数上表现相似，但在相关输入场景下给出不同排序（表 3、4）。
- 在 NHANES 数据上，年龄在两种度量下都排第一，但睡眠时长在触发指数下排名上升（表 6）。

#### 证明路线与技术技巧

**整体路线**：
1. **误差分解**：把 `Ŝ_{X_i} - S_i^f` 分解为"元模型误差"和"蒙特卡洛误差"两部分
2. **元模型误差控制**：用 A1（均方误差收敛）结合 Lipschitz 性质，把 `f̂_ML` 替换为 `f` 的误差控制在 `o_p(1)`
3. **蒙特卡洛误差控制**：用 A3（有界性）保证函数类的 bracketing number 有限，从而一致大数定律成立
4. **连续映射定理**：把分子分母的收敛性传递到比值

**关键技巧**：
- **Bracketing number**：这是证明的核心工具。因为 `f` 和 `f̂_ML` 有界，函数类 `{x_{∼i} ↦ f(x_i, x_{∼i}) : x_i ∈ X_i}` 的 bracketing number 是 `O(1/ε)`，从而可以用 van der Vaart and Wellner (1996) 的定理 2.4.1 得到一致收敛。
- **训练/测试分离**：元模型在 `D_train` 上训练，在 `D_test` 上做蒙特卡洛积分。这避免了过拟合对敏感性估计的污染。
- **网格分位数**：用 `X_i` 的经验分位数作为网格点，而不是均匀网格。这保证了网格点落在 `X_i` 的高概率区域，减少了极端分位数的噪声。

**技术技巧清单**：
| 技巧 | 用在哪儿 | 作用 |
|---|---|---|
| Bracketing number | 定理 1 证明 | 控制一致大数定律的收敛速度 |
| 训练/测试分离 | 整个方法 | 避免过拟合污染敏感性估计 |
| 经验分位数网格 | 一阶指数估计 | 自适应地覆盖 `X_i` 的支撑 |
| 连续映射定理 | 定理 1、2 证明 | 把分子分母的收敛性传递到比值 |
| 随机变量包含向量采样 | 触发指数 | 模拟"变量可得性"的随机变化 |

#### 真实例子与应用

**NHANES 数据**（第 5 节）：
- **数据**：6779 名个体（去重后），8 个连续预测变量（年龄、BMI、身高、脉搏、总胆固醇、直接胆固醇、睡眠时长、贫困收入比），响应为平均收缩压。
- **方法**：RF、XGB、NN 三种元模型；`Ŝ_{X_i}` 用 K=100 网格点；`T̂^s_{X_i}` 用 L=100 随机变量子集。
- **结果**：
  - 年龄在 `Ŝ` 和 `T̂^s` 下都排第一（收缩压随年龄上升是公认的流行病学事实）。
  - 总胆固醇在 `Ŝ` 下排第四，但在 `T̂^s` 下排第七（RF）——说明它对预测的边际贡献有限。
  - 睡眠时长在 `T̂^s` 下排第四（RF），但在 `Ŝ` 下排第七——说明它的预测价值依赖于其他变量的存在。
  - `Ŝ` 与 `T̂^s` 的 Spearman 相关性：RF 下 0.699，XGB 下 0.549——两种度量确实提供不同信息。

**这个例子想说明什么**：`Ŝ` 衡量"变量对输出方差的贡献"，`T̂^s` 衡量"变量对预测损失的贡献"。两者在真实数据上可能给出不同排序，因此联合使用能提供更全面的变量重要性图景。

#### 🔎 结论是否比证明窄

**定理 1 的证明依赖输入独立**（假设 A4），但实验部分（4.1.3 节）明确处理了依赖输入。作者在 4.1.3 节说："这些结果不应被解释为恢复经典 Sobol' 分解"，但定理 1 的证明并没有覆盖这种情况。这是一个**证明与实验之间的缝隙**。

**定理 3 只证明了充分性**：如果 `f` 不依赖 `X_i`，则 `T^s_{X_i} = 0`。但反过来——`T^s_{X_i} = 0` 是否意味着 `f` 不依赖 `X_i`？——没有证明。在输入独立且元模型是加性模型时，这个逆命题可能成立，但一般非参数设定下未必。作者在结论部分也承认了这一点（"a complete characterization of the converse direction remains open"）。

**定理 2 的证明依赖 `q(γ)` 的一致收敛**（假设 A7），但 `q(γ)` 是"重新训练元模型"的预测损失，其收敛性取决于元模型类、调参策略、优化算法等。作者没有给出任何元模型类的具体条件（如 Donsker 类、VC 维有限等），这使得定理 2 的适用范围不够清晰。

**实验部分的统计严谨性**：NHANES 应用中，作者报告了均值和标准差，但没有报告置信区间或假设检验。考虑到 `Ŝ` 和 `T̂^s` 的估计量都是比值形式，其有限样本分布可能高度偏斜，仅报告均值±标准差可能不足以刻画不确定性。

### 四、开放问题

以下问题均扎根于本文的具体语句，供研究者自行判断价值：

1. **定理 3 的逆命题**（本文第 3.2 节末尾）：在输入独立条件下，`T^s_{X_i} = 0` 是否等价于 `f` 不依赖 `X_i`？作者只证明了充分性。要确认这是否为真 gap，可去查近期关于"变量重要性度量的完备性"的文献（如 Covert et al., 2021 关于 Shapley 值的刻画）。

2. **依赖输入下的理论**（本文 4.1.3 节）：作者用实验展示了 `Ŝ` 在依赖输入下能区分直接与间接关联，但没有给出理论保证。在什么条件下（如线性高斯系统、加性噪声），`Ŝ` 能一致估计"直接贡献"？这需要更精细的因果推断框架（如 do-演算、半参数效率理论）。

3. **元模型类与收敛速度**（定理 1、2 的假设 A1、A7）：作者假设元模型均方误差收敛，但没有给出具体元模型类的条件。对于高维（p > n）或强噪声（σ² 大）情形，RF/XGB/NN 的收敛速度如何影响 `Ŝ` 和 `T̂^s` 的有限样本偏差？这可以联系高维统计中的 minimax 理论。

4. **触发指数的计算成本**（第 3.2 节）：`T̂^s_{X_i}` 需要对每个随机变量子集重新训练元模型，计算成本是 `O(L × C_train)`，其中 `C_train` 是单次训练成本。当 p 很大时，L 需要多大才能保证估计精度？是否存在更高效的估计策略（如利用元模型的梯度信息）？

5. **与因果推断的衔接**（全文未提及）：本文的"敏感性"是纯预测性的，不涉及因果解释。但在流行病学应用中（如 NHANES 例子），研究者通常关心的是"如果干预 X_i，Y 会怎样变化"。能否把 `Ŝ` 和 `T̂^s` 扩展到因果参数（如平均处理效应、自然直接效应）？这需要引入潜在结果框架和识别假设。

6. **触发指数与 Shapley 值的理论关系**（第 3.2 节）：作者指出两者"结构相似"，但没有给出精确的数学关系。能否证明 `T^s_{X_i}` 是 Shapley 值在某种损失函数下的变体？或者反过来，Shapley 值是触发指数在某种权重下的特例？这类刻画问题在可解释机器学习文献中有直接对应。
